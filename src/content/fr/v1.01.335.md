# v1.01.335 ERREU14 - Test d'émission des messages d'erreur pour les variables de commande

**Résumé:**

Ce test valide l'émission des messages d'erreur liés à un mauvais usage des variables de commande.

## 1 Principe du test

Ce test est un test informatique. Il valide qu'un mauvais usage des variables de commande conduit à un message d'erreur compréhensible par l'utilisateur.

3 «erreurs» sont testées pour AFFE_MATERIAU / AFFE_VARC :

- L'utilisateur affecte un champ mais les composantes de champ ont un nom incorrect.
- L'utilisateur n'affecte pas les variables de commande sur tous les éléments qui en ont besoin.
- L'utilisateur affecte un champ mais ce champ ne concerne pas tous les éléments en ayant besoin.
