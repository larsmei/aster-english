# v1.01.206 ZZZZ206 - Opérateur CREA_MAILLAGE : validation du mot clé QUAD_LINE

**Résumé:**

L'objectif de ce cas-test est de valider le mot-clé QUAD_LINE de l'opérateur CREA_MAILLAGE. Ce mot-clé permet de convertir un maillage quadratique en un maillage linéaire. Les conversions testées sont les suivantes:

- 1D:

  - SEG3 vers SEG2
- 2D:

  - TRIA6 vers TRIA3
  - QUAD8 vers QUAD4
  - QUAD9 vers QUAD4
- 3D:

  - TETRA10 vers TETRA4
  - PENTA15 vers PENTA6
  - PYRAM13 vers PYRAM5
  - HEXA20 vers HEXA8
  - HEXA27 vers HEXA8

Pour tester le contenu des fichiers résultats, on utilise la commande TEST_FICHIER qui est basée sur une somme de contrôle md5.

Cette documentation est volontairement succincte.
