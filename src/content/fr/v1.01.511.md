# v1.01.511 ZZZZ511 – Test élémentaire de la complétude de certaines fonctionnalités GC

**Résumé:**

Ce test n'a aucune signification physique, c'est un test informatique. Il a pour vocation de tester la complétude de certaines fonctionnalités pour le GC.

Les fonctionnalités examinées sont :

> _ Affectation d'une température ELNO
> _ Affectation d'une déformation anélastique ELNO non nulle sur les éléments 3D
> _ STAT_NON_LINE pour s'assurer de la prédiction -> convergence en 1 itération
> _ OBSERVATION dans STAT_NON_LINE
> _ CALC_CHAMP / VARC_ELGA

Les éléments finis couverts sont : 3D, DKT, GRILLE_MEMBRANE, BARRE, DIS_T_N.

Le chargement est une sollicitation uniaxiale (traction simple) dans la direction y. Le Mouvement est libre dans les autres directions.

Cette documentation est volontairement succincte.
