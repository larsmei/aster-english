# v1.01.366 ZZZZ366 - Test de validation d'IMPR_RESU et LIRE_RESU

**Résumé:**

Ce test valide les permutations de numérotation intervenant dans l'impression et la relecture de champs ELNO au format MED. Les différentes modélisations de ce test correspondent aux différents types de mailles 3D pour lesquels les conventions de numérotation des nœuds des éléments diffèrent entre *Code_Aster*  et MED.

- Modélisation A: vérification pour les HEXA
- Modélisation B: vérification pour les PENTA
- Modélisation C: vérification pour les PYRA
- Modélisation D: vérification pour les TETRA

Cette documentation est volontairement succincte.
