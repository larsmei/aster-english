# u3.13.07 Modélisations AXIS_INCO_UPG, D_PLAN_INCO_UPG

**Résumé:**

Ce document décrit pour les modélisations AXIS_INCO_UPG, D_PLAN_INCO_UPG:

- les degrés de liberté portés par les éléments finis qui supportent la modélisation,
- les mailles supports afférentes,
- les chargements supportés,
- les possibilités non-linéaires,
- les cas-tests mettant en œuvre les modélisations.

Cette modélisation est basée sur des éléments finis adaptés au traitement des problèmes quasi‑incompressibles. Elle est indispensable pour réaliser des calculs d’analyse limite avec la loi de Norton-Hoff et est aussi utile pour les études présentant de fortes déformations plastiques pour lesquelles la formulation classique en déplacement se révèle insuffisante (oscillation des contraintes). La formulation utilisée est une formulation à 3 champs: déplacement-pression-gonflement [R6.03.05](doc:r6.03.05), utilisable avec tous les comportements écrits sous forme incrémentale. Les modélisations sont supportées par des mailles planes de degré 2 (TRIA6 et QUAD8).

## 1 Discrétisation

### 1.1 Degrés de liberté

| **Modélisation** | **Degrés de liberté à tous les nœuds** | **Degrés de liberté uniquement aux nœuds sommets** |
| --- | --- | --- |

| D_PLAN_INCO_UPG | DX, DY | PRES(*), GONF |
| --- | --- | --- |
| AXIS_INCO_UPG | DX, DY | PRES(*), GONF |

- aucune condition cinématique ne peut être imposé sur le degré de liberté PRES.

| --- | --- | --- | --- |

| D_PLAN_INCO_UPG | TRIA6 | Quadratique | Linéaire |
| --- | --- | --- | --- |
|  | QUAD8 | Quadratique | Linéaire |
| AXIS_INCO_UPG | TRIA6 | Quadratique | Linéaire |
|  | QUAD8 | Quadratique | Linéaire |

## 2 Chargements supportés

Les chargements disponibles sont les suivants:

- **'CONTACT'**

Permet de définir les zones soumises à des conditions de contact.

Modélisations supportées : D_PLAN_INCO_UPG, AXIS_INCO_UPG

- **'FORCE_CONTOUR'**

Permet d'appliquer des forces linéaires au bord d'un domaine 2D.

Modélisations supportées : D_PLAN_INCO_UPG, AXIS_INCO_UPG

- **'FORCE_INTERNE'**

Permet d'appliquer des forces volumiques.

Modélisations supportées : D_PLAN_INCO_UPG, AXIS_INCO_UPG

- **'PESANTEUR'**

Permet d'appliquer un chargement de type pesanteur.

Modélisations supportées : D_PLAN_INCO_UPG, AXIS_INCO_UPG

- **'PRES_REP'**

Permet d'appliquer une pression à un domaine de milieu continu.

Modélisations supportées : D_PLAN_INCO_UPG, AXIS_INCO_UPG

## 3 Possibilités non-linéaires

Attention, cette modélisation n’est accessible qu’à partir de STAT_NON_LINE. Elle ne peut pas être utilisée avec MECA_STATIQUE ou par un assemblage manuel.

### 3.1 Lois de comportements

Toutes les lois de comportement utilisables sur des mailles de milieux continus ont un sens physique pour ces modélisations et sont affectables à partir du moment où elles sont accessibles à partir de COMPORTEMENT dans STAT_NON_LINE (Cf. [U4.51.11](doc:u4.51.11)).

Une loi de comportement est spécifique à cette modélisation(dédiée au calcul de charge limite, cf.[R7.07.01]):

```text
/    'NORTON_HOFF'
```

Modélisations supportées : D_PLAN_INCO_UPG, AXIS_INCO_UPG

### 3.2 Déformations

Les déformations disponibles, utilisées dans les relations de comportementsous le mot clé DEFORMATIONpour les opérateurs STAT_NON_LINE etDYNA_NON_LINEsont (Cf. [U4.51.11](doc:u4.51.11)):

```text
/    'PETIT'
```

Les déformations utilisées pour la relation de comportement sont les déformations linéarisées.

```text
/    'SIMO_MIEHE'

/     'GDEF_LOG'
```

Permet de réaliser des calculs en grandes déformations plastiques.

### 3.3 Méthode de Newton

Pour la résolution du problème par la méthode de Newton-Raphson, la matrice élastique n’est pas disponible. Il faut donc utiliser sous le mot-clé NEWTONpour les opérateurs STAT_NON_LINE etDYNA_NON_LINE(Cf. [U4.51.11](doc:u4.51.11)):

```text
/    PREDICTION = ‘TANGENTE’
```

La phase de prédiction est réalisée avec la matrice tangente.

```text
/    MATRICE = ‘TANGENTE’
```

La matrice utilisé pour les itérations globale est la matrice tangente.

**Remarque:**

La formulation utilisée conduit à des matrices non positives et les solveurs actuels ne savent pas toujours bien résoudre les systèmes linéaires qui leur sont associées. En cas de difficulté de convergence, il peut donc être utile de tester les autres solveurs disponibles dans le code ou les autres méthodes de renumérotations (cf. [U4.50.01](doc:u4.50.01)).
