# v1.01.334 ERREU13 – Validation de VERI_BORNE

**Résumé:**

Ce test permet de valider que la vérification des bornes définies pour certaines propriétés matériaux fonctionne correctement. Cette demande de vérification est activée en utilisant le mot-clé VERI_BORNE dans DEFI_MATERIAU.

En cas de dépassement, le comportement attendu est l'émission d'une alarme.

Cette documentation est volontairement succincte.
