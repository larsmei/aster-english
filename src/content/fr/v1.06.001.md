# v1.06.001 HROM001 – Vérification de l’API python pour la construction de base réduite

**Résumé:**

Ce cas-test est destiné à vérifier l’API python pour la construction de base réduite (ROM)
par une *Proper Orthogonal Decomposition* (POD). Différents types de solveurs  d'algèbre linéaire
sont testés, et le test ne porte que sur des matrices de *snapshots* obtenus sur les champs de déplacements
aux noeuds dans le cas d'un calcul mécanique.

Ce test se focalise sur les algorithmes de construction de base au sens de l'algèbre linéaire, et non
la manipulation des champs.

Cette documentation est volontairement succincte.
