# v1.01.129 ZZZZ129 – Validation de la commande CREA_RESU mot clé facteur PROL_RTZ

**Résumé:**

Ce test valide le mot clé PROL_RTZ de la commande CREA_RESU. Il consiste successivement à créer:

- un champ de température sur un ensemble de nœuds d'un maillage 1D. Ce champ est ensuite donné sous la forme d'une structure de données table issue de la commande POST_RELEVE_T.
- un champ sur un maillage axisymétrique (3D) à partir du champ créer précédemment.

Toutes les valeurs aux nœuds du maillage 3D sont testées.

Cette documentation est volontairement succincte.
