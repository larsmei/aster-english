# u4.43.08 Opérateur REST_HOMO_LOCAL

## 1 But

Cette commande permet de reconstruire les champs locaux après un calcul 3D dont les paramètres ont été préalablement homogénéisés à l'aide de la commande CALC_MATE_HOMO.

Elle prend en entrée :

- les correcteurs mécaniques et thermiques issus de :command:`CALC_MATE_HOMO`,
- le résultat homogène, tant élastique que thermique, obtenu sur le maillage global.

### 1.1 Thermique linéaire tridimensionnelle

Dans le cas de la thermique linéaire tridimensionnelle, en notant $\underline{z}$ le vecteur position dans la cellule de base $C$ (placée au point macroscopique $\underline{x}_0$), le champ de température microscopique s'exprime comme la somme du champ de température macroscopique, noté $T^0$ et de la contribution des correcteurs thermiques :

$$
T(\underline{x}_0, \underline{z})
=
T^0(\underline{x}_0)
+
\underline{\nabla} T^0(\underline{x}_0) \cdot \underline{z}
+
\sum_{k} \underline{\nabla} T^0_{k}(\underline{x}_0) \, \zeta^{k}(\underline{z})
$$

### 1.2 Thermoélasticité linéaire tridimensionnelle

Dans le cas d'un calcul de thermoélasticité linéaire tridimensionnelle, en notant $\underline{z}$ le vecteur position dans la cellule de base $C$ (placée au point macroscopique $\underline{x}_0$), le champ de déplacement microscopique s'exprime comme la somme du champ de déplacement macroscopique, noté $\underline{u}^0$, développé sur la cellule de base via la déformation associée $\boldsymbol{\varepsilon}^0$, et de la contribution des correcteurs. Dans cette formulation, on ne conserve que le terme macroscopique de la température, noté $T^0$, sur la cellule de base :

$$
\underline{u}(\underline{x}_0, \underline{z})
=
\underline{u}^0(\underline{x}_0)
+
\boldsymbol{\varepsilon}^0(\underline{x}_0) \cdot \underline{z}
+
\sum_{k,l} \varepsilon_{kl}^0(\underline{x}_0) \, \chi^{kl}(\underline{z})
-
\Bigl( T^0(\underline{x}_0) - T_{\text{réf}} \Bigr)
\Bigl( \alpha \, \mathbf{Id} \cdot \underline{z} + \boldsymbol{\chi}_{\text{dil}}(\underline{z}) \Bigr)
+
p_{\text{app}} \, \boldsymbol{\chi}_{p}^{int}(\underline{z})
$$

### 1.3 Retour de la commande

La commande retourne une structure de données (`sdresu`) contenant la solution locale reconstruite sur le maillage du VER.

## 2 Syntaxe

```text
RELOC_MECA = REST_HOMO_LOCA(
    ◆ TYPE_HOMO = "MASSIF",
    ◆ POSITION = float (size: 3),
    ◇ CORR_MECA = evol_elas_dict,
    ◇ CORR_THER = evol_ther_dict,
    # Si: (exists("CORR_THER") and not exists("CORR_MECA"))
        ◇ OPTION = / "SANS" (par défaut),
                   / "FLUX_ELGA",
    # Si: (exists("CORR_MECA") and not exists("CORR_THER"))
        ◇ OPTION = / "SANS" (par défaut),
                   / "SIEF_ELGA",
    # Si: (exists("CORR_MECA") and exists("CORR_THER"))
        ◇ OPTION = / "SANS" (par défaut),
                   / "SIEF_ELGA",
    ◇ TEMP_REF = float (défaut: 20),
    ◇ PRESSION = float (défaut: 0),
    ◇ EVOL_ELAS = evol_elas,
    ◇ EVOL_THER = evol_ther,
    ◇ INST = float,
    ◇ TOUT_INST = "OUI",
    ◇ CRITERE = / RELATIF (par défaut),
                / ABSOLU,
    ◇ PRECISION = float(défaut: 1.0e-6, val_min=0.0),
    ◇ COMPLET = / NON (par défaut),
                / OUI,
    ◇ TRANSLATION = / NON (par défaut),
                    / OUI,
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Opérandes

### 3.1 Mot clé TYPE_HOMO

Ce mot clé est identique à celui de la commande :command:`CALC_MATE_HOMO`, il définit l'approche utilisée. À l'heure actuelle, seule l'option **MASSIF** est programmée pour l'opération de rélocalisation.

### 3.2 Mot clé POSITION

Spécifie la position du centre du VER dans le maillage global par un triplet de coordonnées (x, y, z).

### 3.3 Mot clé CORR_MECA

Les correcteurs **mécaniques** issus de la commande :command:`CALC_MATE_HOMO` ou :command:`LIRE_CORR_HOMO`.

### 3.4 Mot clé CORR_THER

Les correcteurs **thermiques** issus de la commande :command:`CALC_MATE_HOMO` ou :command:`LIRE_CORR_HOMO`.

### 3.5 Mot clé OPTION

Ce mot clé permet de définir un champ supplémentaire calculé.

- Si le calcul est élastique ou thermo-élastique: calcul de **SIEF_ELGA**.
- Si le calcul est thermique: calcul de **FLUX_ELGA**.

### 3.6 Mot clé  PRESSION

Lorsqu'une pression est appliquée sur les parois internes des "trous" du VER, celle-ci doit être fournie sous la forme d'une fonction du temps.

### 3.7 Mot clé  EVOL_ELAS

Le résultat élastique homogène obtenu sur le maillage global.

### 3.8 Mot clé  EVOL_THER

Le résultat thermique homogène obtenu sur le maillage global.

### 3.9 Mot clé  INST

Liste les instants (temps) permettant de restreindre la reconstruction du résultat.

### 3.10 Mot clé  TRANSLATION

Si défini sur **OUI**, déplace le maillage du VER vers sa position réelle dans le maillage global, donnée sous POSITION.

### 3.11 Mot clé  COMPLET

Si défini sur **OUI**, reconstruit le résultat symétrique des correcteurs sur l'ensemble du VER.
