# u4.82.06 Opérateur RECA_WEIBULL

## 1 But

Recaler les paramètres du modèle de WEIBULL sur des données expérimentales. Ces données sont constituées d’une (ou plusieurs) liste d’instants de rupture déterminés expérimentalement, associées à un (ou plusieurs) concept résultat de STAT_NON_LINE modélisant les essais à ces différents instants. Le module de WEIBULL, ou la contrainte de clivage (dépendant éventuellement de la température), ou encore ces deux paramètres, peuvent être recalés. On utilise la méthode de maximum de vraisemblance ou de régression linéaire [R7.02.09](doc:r7.02.09) pour ce recalage.

Produit une structure de données de type table.

## 2 Syntaxe

```text
table = RECA_WEIBULL(
    ◆ LIST_PARA = / "SIGM_REFE",
                  / "M",
    ◆ RESU = _F(
         ◆ EVOL_NOLI = evol_noli,
         ◆ MODELE = modele,
         ◆ CHAM_MATER = cham_mater,
         ◇ TEMPE = float,
         ◆ LIST_INST_RUPT = float,
         ◇ / TOUT_ORDRE = "OUI" (ou non renseigné),
           / NUME_ORDRE = int,
           / INST = float,
           / LIST_INST = listr8,
         # Si: exists("INST") or exists("LIST_INST")
             ◇ CRITERE = / "RELATIF" (par défaut),
                         / "ABSOLU",
             # Si: equal_to("CRITERE", 'RELATIF')
                 ◇ PRECISION = float (défaut: 1e-06),
             # Si: equal_to("CRITERE", 'ABSOLU')
                 ◆ PRECISION = float,
         ◆ | TOUT = "OUI" (ou non renseigné),
           | GROUP_MA = grma,
         ◇ COEF_MULT = float (défaut: 1.0),
      ),
    ◇ OPTION = / "SIGM_ELGA" (par défaut),
               / "SIGM_ELMOY",
    ◇ CORR_PLAST = / "OUI",
                   / "NON" (par défaut),
    ◇ METHODE = / "MAXI_VRAI" (par défaut),
                / "REGR_LINE",
    ◇ INCO_GLOB_RELA = float (défaut: 0.001),
    ◇ ITER_GLOB_MAXI = int (défaut: 10),
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Opérandes

### 3.1 Opérande LIST_PARA

```text
♦    LIST_PARA
/    'M',
/    'SIGM_REFE',
```

Liste des paramètres du modèle de Weibull dont le recalage est demandé ($m$ , ${\sigma}_{u}$ ou les deux).

### 3.2 Mot clé RESU

#### 3.2.1 Opérande EVOL_NOLI

```text
♦    EVOL_NOLI    =    resu,
```

Nom d’un concept résultat de type evol_noli.

#### 3.2.2 Opérande MODELE

```text
♦    MODELE    =    mo,
```

Nom du modèle sur lequel est effectué le recalage.

#### 3.2.3 Opérande CHAM_MATER

```text
♦    CHAM_MATER    =    chmat,
```

Nom du champ matériau affecté sur le modèle. Celui-ci doit impérativement contenir la valeur initiale des paramètres de la méthode de Weibull (mot-clé WEIBULL de DEFI_MATERIAU [U4.43.01](doc:u4.43.01)) à savoir:

| ${V}_{0}$ | : volume de référence |
| --- | --- |
| $m$ | : exposant de la loi statistique de Weibull |
| ${\sigma}_{u}$ | : contrainte de clivage |

#### 3.2.4 Opérande TEMPE

```text
◊    TEMPE    =    temp,
```

Température associée au résultat resu. Si celle-ci est renseignée, on recalera la contrainte de clivage ${\sigma}_{u}$ pour chaque résultat.

#### 3.2.5 Opérande LIST_INST_RUPT

```text
♦    LIST_INST_RUPT    =    lreel,
```

Liste des instants de rupture de la base de résultat resu sur lesquels seront calculées les contraintes de Weibull (ces instants sont interpolés s’ils ne coïncident pas aux instants du résultat resu). Cette liste d’instants doit être strictement croissante et contenir au moins deux instants. L’instant minimum (respectivement maximum) de cette liste doit bien entendu être nécessairement supérieur (resp. inférieur) à l’instant minimum (resp. maximum) de la liste d’instants du résultat resu.

#### 3.2.6 Opérandes TOUT / GROUP_MA

Le ou les domaines de calcul sont spécifiées par:

```text
♦    /    TOUT    =    'OUI',
```

Un seul domaine est défini et il coïncide avec toute la structure.

```text
/    GROUP_MA    =    lgrma,
```

Chaque groupe de mailles de la liste lgrma définit un domaine de calcul.

#### 3.2.7 Opérandes TOUT_ORDRE / NUME_ORDRE / INST / LIST_INST / PRECISION / CRITERE

# sélection des instants de calcul dans lesquels on cherche à interpoler les contraintes de Weibull aux instants donnés par LIST_INST_RUPT

voir TOUT_ORDRE, NUME_ORDRE, LIST_ORDRE, INST, LIST_INST dans [U4.71.00](doc:u4.71.00)

Aster calcule d’abord les contraintes de Weibull pour tous les instants donnés par TOUT_ORDRE/ NUME_ORDRE/ INST/LIST_INST, il interpole ensuite les contraintes de Weibull aux instants donnés par LIST_INST_RUPT.

#### 3.2.8 Opérande COEF_MULT

```text
◊    COEF_MULT    =    coef,
```

Coefficient multiplicateur de la puissance m-ième de la contrainte de Weibull destiné à la prise en compte des symétries dans le domaine (la valeur par défaut est 1. cf. POST_ELEM [U4.81.22](doc:u4.81.22)).

### 3.3 Opérande OPTION

```text
/    OPTION    =    'SIGM_ELGA',
```

Le champ élémentaire de la contrainte principale maximale est calculé à partir de la représentation du champ de contraintes aux points de Gauss.

```text
/    OPTION    =    'SIGM_ELMOY',
```

Le champ élémentaire de la contrainte principale maximale est calculé à partir de la représentation du champ de contraintes moyenné par rapport aux points de Gauss.

### 3.4 Opérande CORR_PLAST

```text
/    CORR_PLAST    =    'OUI',
```

Le champ de contraintes de Weibull est évalué avec la correction plastique.

```text
/    CORR_PLAST    =    'NON',
```

Le champ de contraintes de Weibull est évalué sans correction plastique.

### 3.5 Opérande METHODE

```text
/    METHODE    =    'MAXI_VRAI',
```

La méthode de recalage employée est celle du maximum de vraisemblance.

```text
/    METHODE    =    'REGR_LINE',
```

La méthode de recalage employée est celle de la régression linéaire.

### 3.6 Mot clé INCO_GLOB_RELA

```text
◊    INCO_GLOB_RELA    =    /    increl,        [R]
/    1.E-3,            [DEFAUT]
```

L’algorithme de recalage continue les itérations si:

$\max(∣\frac{{m}_{k+1}-{m}_{k}}{{m}_{k}}∣;\underset{T}{\max}(∣\frac{{\sigma}_{u(k+1)}(T)-{\sigma}_{u(k)}(T)}{{\sigma}_{u(k)}(T)}∣))>\mathrm{increl}$

### 3.7 Mot clé ITER_GLOB_MAXI

```text
◊    ITER_GLOB_MAXI    =    /    maglob,        [R]
/    10,                [DEFAUT]
```

Nombre d’itérations de recalage maximum effectué.

### 3.8 Opérande INFO

```text
◊    INFO    =
```

Indique le niveau d'impression des résultats de l'opérateur,

| 1: | aucune impression, |
| --- | --- |
| 2: | impression des informations relatives au recalage. |

Les impressions se font dans le fichier 'MESSAGE'.

## 4 Exemple d’utilisation

Pour l’usage de RECA_WEIBULL, on pourra se reporter au cas test SSNA103 [V6.01.103](doc:v6.01.103).

C’est une modélisation axisymétrique d’une éprouvette cylindrique (longueur de 407 mm et rayon de 68 mm) soumise à une traction. Exemple de recalage du paramètre ${\sigma}_{u}$ de la méthode de Weibull par la méthode de régression linéaire sur trois bases de résultats correspondant à des températures distinctes (le module de Weibull $m$ est fixé et égal à 24).
