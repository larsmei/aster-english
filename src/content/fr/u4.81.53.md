# u4.81.53 Opérateur CREA_COUPE

## 1 But

Création d'un tableau représentant des coupes droites unidimensionnelles. Ce tableau décrit les coupes à l'aide de leurs extrémités. On impose aux extrémités d'être localisées sur la surface d'un maillage.

**Principe :**

Cette macro-commande crée une table où chaque ligne correspond à une coupe. À partir d'une table d'entrée formatée de la façon attendue, la macro-commande permet de vérifier que
le tableau spécifié est bien formaté et permet aussi de déplacer les points renseignés de manière à ce
qu'ils soient sur les groupes de mailles surfaciques renseignés dans le tableau.
En plus la macro-commande permet aussi de créer des nouvelles coupes à partir d’un sous-ensemble
de coupes de la table d’entrée par transformation géométrique de révolution autour d’un axe et d’un
centre de rotation.

## 2 Syntaxe

```text
table = CREA_COUPE(
    ◆ COUPE = table,
    ◆ MAILLAGE = maillage,
    ◇ NOM_AUTO = / "NON" (par défaut),
                 / "OUI",
    # Si: (equal_to("NOM_AUTO", 'OUI'))
        ◇ PREFIXE = text (défaut: ""),
        ◇ NUME_INIT = int (défaut: 1),
        ◇ PAS = int (défaut: 1),
    ◇ REVOLUTION = _F(
         ◆ AXE = list[float],
         ◆ CENTRE = list[float],
         ◇ ANGLE_AUTO = / "NON",
                        / "OUI" (par défaut),
         # Si: (equal_to("ANGLE_AUTO", 'OUI'))
             ◆ NOMBRE = int,
             ◆ ANGLE_MAX = float,
         # Si: (equal_to("ANGLE_AUTO", 'NON'))
             ◆ ANGLE = list[float],
         ◆ GROUP_MA_ORIG = grma,
         ◆ GROUP_MA_EXTR = grma,
         ◇ / NOM_COUPE = list[text],
           / GROUP_COUPE = list[text],
         ◇ PREFIXE = text (défaut: ""),
      ),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Opérandes

### 3.1 Opérande COUPE

```text
♦        COUPE    =    table,        [table]
```

Tableau contenant la description des coupes. La table doit contenir les colonnes suivantes :

| Nom de colonne | Type | Description |
| --- | --- | --- |
| COOR_ORIG_X | [R] | Première coordonnée du point d'origine |
| COOR_ORIG_Y | [R] | Deuxième coordonnée du point d'origine |
| COOR_ORIG_Z | [R] | Troisième coordonnée du point d'origine |
| COOR_EXTR_X | [R] | Première coordonnée du point à l'extrémité |
| COOR_EXTR_Y | [R] | Deuxième coordonnée du point à l'extrémité |
| COOR_EXTR_Z | [R] | Troisième coordonnée du point à l'extrémité |
| COOR_TROIS_X | [R] | Première coordonnée du troisième point permettant d'orienter le repère |
| COOR_TROIS_Y | [R] | Deuxième coordonnée du troisième point permettant d'orienter le repère |
| COOR_TROIS_Z | [R] | Troisième coordonnée du troisième point permettant d'orienter le repère |
| NOM | [K24] | Nom de la coupe |
| GROUP | [K24] | Nom des groupes de coupes auxquels vont appartenir la coupe, ces groupes seront des groupes de mailles 1D |
| GROUP_MA_ORIG | [K24] | Nom du groupe de mailles sur lequel projeter le point d'origine |
| GROUP_MA_EXTR | [K24] | Nom du groupe de maille sur lequel projeter le point d'extrémité |
| NB_POINTS | [I] | Nombre de points de discrétisation de la coupe |

### 3.2 Opérande MAILLAGE

```text
♦        MAILLAGE    =    maillage,        [maillage]
```

Maillage support sur lequel réaliser les coupes.

### 3.3 Opérande NOM_AUTO

```text
◇        NOM_AUTO    =  /  'NON',        [DEFAUT]
                        /  'OUI'
```

Renommage automatique de chaque ligne de coupe, de la forme :
`PREFIX_ENTIER`.

L'entier est calculé directement comme étant le numéro de la coupe dans le tableau (numéro de la ligne)
ou peut être redéfini à l'aide des opérandes NUME_INIT et PAS. Lorsque des noms sont déjà définis dans la colonne `NOM`, les noms sont remplacés par les noms générés
par la commande.

#### 3.3.1 Opérande PREFIXE

```text
◇        PREFIXE     =   text       [TXM]
```

Chaîne de caractère par laquelle commencent tous les noms de coupes.

#### 3.3.2 Opérandes NUME_INIT et PAS

```text
◇        NUME_INIT   =   int (défaut: 1),
◇        PAS    =   int (défaut: 1),
```

Entiers permettant de modifier le numéro associé au nom de la coupe. Ce numéro, nommé `ENTIER`,
dans le titre décrit dans la section précédente est calculé comme suit :

$$
ENTIER = NUME_INIT + (i − 1). PAS
$$

Avec $i$ , le numéro de la coupe dans le tableau COUPE.

### 3.4 Opérande REVOLUTION

Ce mot-clé facteur permet de générer des nouvelles coupes à partir de toutes les coupes du tableau
d’entrée (ou d’un sous-ensemble avec les opérandes NOM_COUPE ou GROUP_COUPE).
Ce mot-clé peut être répété.
Les coupes créées sont ajoutées au tableau de sortie ; chaque nouvelle coupe est placée après la coupe
initiale dont elle a été obtenue par révolution.
Le nom de la nouvelle coupe obtenue par révolution suit la règle suivante :

> préfixe (optionnel) + angle de rotation + ‘-‘ + nom de la section d’origine

Si l’angle de rotation n’est pas un entier, seulement le premier chiffre décimal est utilisé, le caractère de
séparation étant ‘-‘.

Le groupe de la coupe `GROUP` et le nombre de points `NB_POINTS` des nouvelles coupes sont reconduits
de la coupe dont elles ont été générées.

#### 3.4.1 Opérande AXE

```text
◆        AXE =    (ar,br,cr),       [l_R]
```

Liste de 3 valeurs réelles des composantes du vecteur direction de l’axe de rotation.
Le vecteur `(ar,br,cr)` peut ne pas être normalisé.

#### 3.4.2 Opérandes CENTRE

```text
◆        CENTRE =    (x,y,z),       [l_R]
```

Liste de 3 valeurs réelles des coordonnées du centre de rotation.

#### 3.4.3 Opérande ANGLE_AUTO

```text
◇        ANGLE_AUTO    =  /  'NON',        [DEFAUT]
                          /  'OUI'
```

Désigne la méthode utilisée pour déterminer les angles de rotation :

- Avec un espacement uniforme si `ANGLE_AUTO = ‘OUI’`
- Avec une liste d’angles renseignée par l’utilisateur si `ANGLE_AUTO = ‘NON’`

##### 3.4.3.1 Opérande NOMBRE

```text
◆        NOMBRE =     int       [I]
```

Numéro entier de révolutions à effectuer pour chaque coupe.
Ce numéro tient compte de la coupe initiale, donc $n le 2$.
Les angles 0° et ±360° sont confondus.

##### 3.4.3.2 Opérande ANGLE_MAX

```text
◆        ANGLE_MAX =     :math:`\theta_{max}`       [R]
```

Angle en dégrés à couvrir par la transformation de révolution.
Il faut que : $-360 le theta_{max} le +360$ et $theta_{max} neq 0$

##### 3.4.3.3 Opérande ANGLE

```text
◆        ANGLE =     float       [l_R]
```

Liste de réels contenant les angles de rotation en dégrés.
Tous les angles de cette liste doivent être compris entre -360° et +360° (0° exclu).

#### 3.4.4 Opérande GROUP_MA_ORIG

```text
◆        GROUP_MA_ORIG =  grma      [grma]
```

Nom du groupe de mailles sur lequel projeter le point d'origine des nouvelles coupes obtenues par
révolution.

#### 3.4.5 Opérande GROUP_MA_EXTR

```text
◆        GROUP_MA_EXTR =  grma      [grma]
```

Nom du groupe de mailles sur lequel projeter le point d'extrémité des nouvelles coupes obtenues par
révolution.

#### 3.4.6 Opérande NOM_COUPE

```text
◇ /      NOM_COUPE = text       [l_TXM]
```

Liste des noms des coupes du tableau d’entrée auxquelles appliquer la transformation de révolution.
Si `NOM_AUTO = ‘OUI’`, il faut renseigner les nouveaux noms assignés.

#### 3.4.7 Opérande GROUP_COUPE

```text
◇ /      GROUP_COUPE = text   [l_TXM]
```

Liste des groupes de coupe du tableau d’entrée auxquelles appliquer la transformation de révolution.

#### 3.4.8 Opérande PREFIXE

```text
◇        PREFIXE = text         [TXM]
```

Chaîne de caractères par laquelle commencent tous les noms des coupes obtenues par révolution.
