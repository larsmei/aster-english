# u4.32.05 Opérateur INFO_FONCTION

## 1 But

Effectuer des opérations mathématiques sur des structures de données de type fonction.

Les opérations suivantes sont actuellement disponibles :

- la recherche des maximums d'une fonction,
- le calcul de la norme ${L}_{2}$ d’une fonction,
- l’écart type d’une fonction,
- la valeur RMS d’une fonction,
- la valeur de l'indicateur de nocivité de séisme.

Produit une structure de données table.

## 2 Syntaxe

```text
table = INFO_FONCTION(
    ◆ / RMS = _F(
           ◇ METHODE = / "SIMPSON",
                       / "TRAPEZE" (par défaut),
           ◆ FONCTION = fonction,
           ◇ INST_INIT = float,
           ◇ INST_FIN = float,

                       / "ABSOLU",
           # Si: (equal_to("CRITERE", 'RELATIF'))
               ◇ PRECISION = float (défaut: 1e-06),
           # Si: (equal_to("CRITERE", 'ABSOLU'))
               ◆ PRECISION = float,
        ),
      / MAX = _F(
           ◆ FONCTION = nappe / fonction,
           ◇ INTERVALLE = float,
        ),
      / NOCI_SEISME = _F(
           ◆ / FONCTION = fonction,
             / SPEC_OSCI = nappe,
           # Si: exists("FONCTION")
               ◇ OPTION = / "INTE_ARIAS",
                          / "INTE_SPEC",
                          / "VITE_ABSO_CUMU",
                          / "DUREE_PHAS_FORT",
                          / "MAXI",
                          / "ACCE_SUR_VITE",
                          / "ASA",
                          / "TOUT" (par défaut),
               # Si: is_in('OPTION', ("TOUT", "ASA"))
                   ◆ FREQ_FOND = float,
                   ◇ FREQ_PAS = float (défaut: 0.01),
                   ◇ NORME = float (défaut: 1.0),
                   ◇ RATIO = float (défaut: 0.4),
               # Si: is_in('OPTION', ("TOUT", "INTE_SPEC","ASA" ))
                   ◆ AMOR_REDUIT = float,
               # Si: is_in('OPTION', ("TOUT", "INTE_ARIAS", "DUREE_PHAS_FORT"))
                   ◆ PESANTEUR = float,
           # Si: exists("SPEC_OSCI")
               ◇ OPTION = "INTE_SPEC",
               ◆ NATURE = / "DEPL",
                          / "VITE",
                          / "ACCE",
               ◆ AMOR_REDUIT = float,
           ◇ INST_INIT = float,
           ◇ INST_FIN = float,
           ◇ COEF = float,
           ◇ FREQ_INIT = float (défaut: 0.4),
           ◇ FREQ_FIN = float (défaut: 10.0),
           ◇ LIST_FREQ = listr8,
           ◇ FREQ = float,
           ◇ NORME = float (défaut: 1.0),
           ◇ BORNE_INF = float (défaut: 0.05),
           ◇ BORNE_SUP = float (défaut: 0.95),
           # Si: (exists("INST_INIT"))or(exists("INST_FIN"))or(exists("FREQ_INIT"))or(exists("FREQ_FIN"))
               ◇ CRITERE = / "RELATIF" (par défaut),
                           / "ABSOLU",

                   ◇ PRECISION = float (défaut: 1e-06),
               # Si: (equal_to("CRITERE", 'ABSOLU'))
                   ◆ PRECISION = float,
        ),

           ◆ FONCTION = nappe,

           ◇ CRITERE = / "RELATIF" (par défaut),

◇ : optionnel
```

## 3 Opérandes

### 3.1 Mot clé MAX

```text
/    MAX =
```

Recherche des abscisses où sont atteint le maximum et le minimum.

Cette opération est disponible sur des fonctions de nature fonction ou nappe.

```text
♦    FONCTION = f
```

Nom de la fonction ou des fonctions dont on cherche les maximums.

Si f est une fonction, le concept produit est une table dont les paramètres d’accès sont:

> FONCTION, TYPE, le NOM_PARAde la fonction, le NOM_RESUde la fonction.

où l’on trouve respectivement le nom de la fonction, MAXI ou MINI, l’abscisse du maximum/minimum, la valeur du maximum/minimum.

Lorsque plusieurs facteurs sont fournis, la table contient la ou les max des max, et le ou les min des min.

Si f est une nappe, le concept produit est une table dont les paramètres d’accès sont:

> FONCTION, TYPE, le NOM_PARA de la nappe, le nom du paramètre des fonctions
(NOM_PARA_FONC), le NOM_RESU des fonctions.

```text
◊    INTERVALLE = inter
```

Liste de réels définissant les bornes des intervalles sur lesquels seront
cherchés les min et les max des fonctions.

`inter` est composé de couples de réels dont le premier correspond à la borne
inférieur du premier intervalle, le second correspond à la borne supérieur de premier intervalle, et ainsi de suite pour les autres intervalles.

`inter` est donc composé d'un nombre pair d'éléments.

Ce mot-clé n'est pas pris en compte pour les nappes.

### 3.2 Mot clé NORME

Ce mot clé permet de suivre la convergence suivant la norme ${L}_{2}$ d’une suite de fonction ${f}_{N}$ donnée sous forme d’une nappe. La table résultat comporte une ligne par fonction, les paramètres d’entrée sont NORME et FONCTION.

```text
♦    FONCTION = f
```

Nom de la nappe dont la norme doit être évaluée.

### 3.3 Mot clé ECART_TYPE

```text
/    ECART_TYPE =
```

On calcule l’écart-type de la fonction $f(t)$ qui est définie par:

$\sigma =\sqrt{\frac{1}{({t}_{\mathit{fin}}-{t}_{\mathit{deb}})}{\int}_{{t}_{\mathit{deb}}}^{{t}_{\mathit{fin}}}{(f(t)-\stackrel{ˉ}{f})}^{2}\mathit{dt}}$ où $\stackrel{ˉ}{f}$ est la moyenne sur $[{t}_{\mathrm{deb}},{t}_{\mathrm{fin}}]$

Les mots clés sont identiques à ceux fournis sous le mot clé facteur RMS.

Le concept produit est une table dont les paramètres d’accès sont:

```text
FONCTION, METHODE, MOYENNE, INST_INIT, INST_FIN, ECART_TYPE.
```

### 3.4 Mot clé RMS

```text
/    RMS =
```

On calcule la valeur RMS de la fonction $f(t)$ qui est définie par:

$\mathrm{RMS}=\sqrt{\frac{1}{({t}_{\mathrm{fin}}-{t}_{\mathrm{deb}})}{\int}_{{t}_{\mathrm{deb}}}^{{t}_{\mathrm{fin}}}{f}^{2}(t)\mathrm{dt}}$

```text
♦    FONCTION = f
```

Nom de la fonction dont on calcule la valeur RMS.

Ne s’applique pas aux concepts de type nappe.

```text
◊    METHODE =
```

Nom de la METHODE que l'on utilise pour calculer l’intégrale.

Deux méthodes sont disponibles: la méthode des 'TRAPEZE' (par défaut) et la méthode de 'SIMPSON'.

```text
◊    INST_INIT = tdeb,
◊    INST_FIN = tfin,
```

Bornes inférieure et supérieure de l’intervalle d’intégration.

Si ces valeurs ne sont pas renseignées, les points de discrétisation inférieur et supérieur (la relation d’ordre étant définie par rapport au paramètre en abscisse) sont pris comme borne de l’intervalle d’intégration.

```text
◊    PRECISION  =     /    0.001,
                      /    prec,

◊    CRITERE    =     /    'ABSOLU',
                      /    'RELATIF',            [DEFAUT]
```

On cherche un point de discrétisation de la fonction dans un intervalle défini par la position absolue ou relative autour d’une valeur du paramètre des abscisses pour laquelle la fonction doit être estimée :

| [inst (1-prec) , inst (1+prec)] | si CRITERE= 'RELATIF' |
| --- | --- |
| [inst - prec , inst + prec] | si CRITERE= 'ABSOLU' |

Le concept produit est une table dont les paramètres d’accès sont:

```text
FONCTION,    METHODE,    INST_INIT,    INST_FIN,    RMS.
```

### 3.5 Mot clé NOCI_SEISME

```text
/    NOCI_SEISME =

    ♦    /    FONCTION = f,
         /    SPEC_OSCI= sro,
```

Nom de la fonction (signal en accélération $a(t)$ ) ou de la nappe considérée qui doivent être défini dans DEFI_FONCTION [U4.31.02](doc:u4.31.02) avec NOM_RESU=’ACCE’.

Si l’on considère une nappe, seul le calcul d’intensité spectrale est disponible.

```text
◊    /    OPTION=
```

Permet de choisir un ou plusieurs des six indices de nocivité suivants:

```text
| 'TOUT'
```

donne l’ensemble des six|ndices de nocivité,

```text
| 'MAXI'
```

donne le maximum de l’accélération $a(t)$ , de la vitesse $v(t)$ et du déplacement (obtenus par intégration)

$\mathit{PGA}=\underset{t\in [{t}_{i},{t}_{f}]}{max}\left\lbrace ∣a(t)∣\right\rbrace$ , $\mathrm{PGV}=\underset{t\in [{t}_{i},{t}_{f}]}{\max}\left\lbrace ∣v(t)∣\right\rbrace$ , $\mathrm{PGD}=\underset{t\in [{t}_{i},{t}_{f}]}{\max}\left\lbrace ∣x(t)∣\right\rbrace$

```text
| 'INTE_ARIAS'
```

donne l’intensité d’Arias ${I}_{A}=\frac{\pi}{2g}{\int}_{{t}_{i}}^{{t}_{f}}{a}^{2}(t)\mathit{dt}$

où $g$ est l’accélération de la pesanteur. Cette valeur doit être enseigné via le mot clé PESANTEUR.

```text
| 'VITE_ABSO_CUMU'
```

donne la valeur absolue cumulée de la vitesse $\mathit{CAV}={\int}_{{t}_{i}}^{{t}_{f}}∣a(t)∣\mathit{dt}$

```text
| 'DUREE_PHAS_FORT'
```

durée de phase forte (l’intensité d'Arias étant une fonction monotone croissante):

Durée minimale ${t}_{\sup}-{t}_{\inf}$ telle que, pour les bornes ${b}_{\inf},{b}_{\sup}$ :

${b}_{\inf}\times {I}_{A}⩽\frac{\pi}{2g}{\int}_{{t}_{inf}}^{{t}_{\sup}}{a}^{2}(f)\mathit{dt}⩽{b}_{\sup}\times {I}_{A}$

où $g$ doit être renseigné par le mot clé PESANTEUR.

La table produite contient ${t}_{inf}$ sous DEBUT_PHAS_FORT.

```text
| 'ASA'(Average Spectral Acceleration)
```

Cet indicateur se base sur la pseudo-accélération spectrale de la structure et dépend de sa fréquence fondamentale.

Un endommagent, caractérisé par une baisse de cette fréquence propre, est pris en compte par l'intégration des pseudo-accélérations spectrales ${S}_{a}(f,\eta )$ .sur une plage de fréquences:

> ${\mathit{ASA}}_{R}=\frac{1}{R{f}_{0}}{\int}_{(1-R){f}_{0}}^{{f}_{0}}{S}_{a}(f,\eta )\mathit{df}$

où R désigne le ratio définissant le domaine d'intégration et $\eta$ est l'amortissement réduit. La valeur du ratio peut être renseigné par l'utilisateur via le mot-clé RATIO. Par défaut, on détermine le ${\mathit{ASA}}_{40}$ avec R=0.4 et amortissement réduit $\eta =0.05$ . Le mot_clé FREQ_PAS permet de définir le pas d'intégration. La pseudo-accélération spectrale sera normé à la NORME renseignée (par défaut 1.0).

Intensité spectrale de Housner, entre les fréquences ${f}_{\mathrm{deb}},{f}_{\mathrm{fin}}$ , ${S}_{V}(f,\eta )$ désignant le Spectre de Réponse d'Oscillateuren pseudo-vitesses pour l'amortissement réduit $\eta$ :

${I}_{H}={\int}_{{f}_{\mathit{deb}}}^{{f}_{\mathit{fin}}}\frac{{S}_{V}(f,\eta )}{{f}^{2}}\mathit{df}$

$\text{ACCE_SUR_VITE}=\frac{\underset{t\in [{t}_{i},{t}_{f}]}{max}\left\lbrace ∣a(t)∣\right\rbrace }{\underset{t\in [{t}_{i},{t}_{f}]}{max}\left\lbrace ∣\nu (t)∣\right\rbrace }$

Suivant l’option, on doit renseigner certains paramètres, si on indique pas d’option, par défaut, on calcule tous les indices donc il faut tout renseigner. La méthode d’intégration est la méthode des 'TRAPEZE'.

```text
INST_INIT = tdeb,
INST_FIN = tfin,
```

Bornes inférieure et supérieure de l’intervalle de temps considéré.

Si ces valeurs ne sont pas renseignées, les points de discrétisation inférieur et supérieur (la relation d’ordre étant définie par rapport au paramètre en abscisse) sont pris comme borne de l’intervalle.

```text
PRECISION   =     /    0.001,
                  /    prec,

CRITERE     =     /    'ABSOLU',
                  /    'RELATIF',            [DEFAUT]
```

On cherche un point de discrétisation de la fonction dans un intervalle défini par la position absolue ou relative autour d’une valeur du paramètre des abscisses pour laquelle la fonction doit être estimée :

| [inst*(1-prec) , inst*(1+prec)] | si CRITERE= 'RELATIF' |
| --- | --- |
| [inst - prec , inst + prec] | si CRITERE= 'ABSOLU' |
| [freq*(1-prec) , freq*(1+prec)] | si CRITERE= 'RELATIF' |
| [freq - prec , freq + prec] | si CRITERE= 'ABSOLU' |

```text
COEF = r1
```

Constante d'intégration, par défaut 0. Dans l’option 'MAXI', on calcule la vitesse et le déplacement par deux intégrations successives de l’amortissement, il faut donc renseigner COEF si l’on ne veut pas le prendre par défaut.

```text
FREQ_INIT = fdeb,

FREQ_FIN = ffin,
```

Fréquences représentant les deux bornes d’intégration pour le calcul de l’intensité spectrale de Housner. Celles-ci doivent être comprises entre les extrema de la base de fréquences définissant la nappe SRO, sinon se pose un problème d’interpolation. Par défaut, ces deux fréquences valent $0,4\mathrm{Hz}$ et $\mathrm{10Hz}$ .

AMOR_REDUIT= am

Amortissement réduit, pour le calcul du Spectre de Réponse d'Oscillateur dans celui de l’intensité spectrale de Housner.

```text
FREQ = lfre
```

fre = $({\Phi}_{1,}\mathrm{...},{\Phi}_{i},\mathrm{...})$ . Liste des fréquences.

```text
LIST_FREQ = lfreq
```

Liste des fréquences fournies sous un concept listr8.

```text
NORME = r2
```

Le spectre d'oscillateur sera normé à la valeur r2 (valeur de la pseudo-accélération).

```text
BORNE_INF = binf,

BORNE_SUP = bsup,
```

Bornes limitant la part d’intensité Arias définissant les instants initial et final de la phase forte (entre $({b}_{\inf})\text{\%}$ et $({b}_{\sup})\text{\%}$ de ${({I}_{A})}_{\max}$ ) du séisme (on prend souvent 5% et 95%).

> PESANTEUR

Accélération de la Pesanteur. Sa valeur dépendant des unités du modèle, ce mot-clé est obligatoire pour les indices INTE_ARIAS, DUREE_PHAS_FORT.

### 3.6 Opérande TITRE

```text
◊    TITRE = t
```

Titre attaché au concept produit par cet opérateur [U4.03.01](doc:u4.03.01).

### 3.7 Opérande INFO

```text
◊    INFO
```

Si INFO=2, on imprime la fonction (IMPR_FONCTION format TABLEAU) dans le fichier MESSAGE.

## 4 Exemples

### 4.1 Sans intervalle

```text
A5=DEFI_FONCTION(
    NOM_RESU='SIGM',
    NOM_PARA='EPSI',
    VALE=(  0.002,  400.0,
            0.003,  500.0,
            0.0045, 550.0,
            0.0065, 580.0,
            0.008,  590.0,
            0.01,   600.0,
            0.02,   600.0,
            ),

    PROL_DROITE='CONSTANT',
    PROL_GAUCHE='LINEAIRE',
)

tab = INFO_FONCTION(MAX=_F(FONCTION=A5),)

IMPR_TABLE(TABLE=tab)
```

donne sur le fichier 'RESULTAT'.


```text
tab2 = INFO_FONCTION(MAX      = _F(FONCTION=A5),
```
