# u4.51.01 Opérateur MECA_STATIQUE

## 1 But

Résoudre un problème de mécanique statique linéaire.

Cet opérateur permet de résoudre soit:

- un problème mécanique statique linéaire avec superposition de différentes conditions aux limites et de différents chargements,
- une analyse thermo-mécanique pour une liste donnée d'instants.
- dans ce cas les caractéristiques mécaniques des matériaux peuvent dépendre de la température: le concept de type cham_mater doit alors être défini à partir de fonctions (Cf.opérateur DEFI_MATERIAU [U4.43.01](doc:u4.43.01) opérande ELAS_FO),
- le chargement de dilatation ne peut être déterminé que si l'on a défini le coefficient de dilatation et la température de référence (Cf. opérateurs DEFI_MATERIAU [U4.43.01](doc:u4.43.01) et AFFE_MATERIAU [U4.43.03](doc:u4.43.03)).

Le concept produit par cet opérateur est de type evol_elas contenant un ou plusieurs champs de déplacements aux différents instants de calcul.

## 3 Opérandes

### 3.1 Opérandes MODELE / CHAM_MATER / CARA_ELEM

On fournit les arguments permettant de calculer la matrice de rigidité (et le second membre):

```text
♦    MODELE=    mo,
```

Nom du modèle dont les éléments font l'objet du calcul mécanique.

```text
♦    CHAM_MATER=    chmat,
```

Nom du champ de matériau.

```text
◊    CARA_ELEM=    carac,
```

Nom des caractéristiques des éléments structuraux (poutre, coque, discrets, ...) s'ils sont utilisés dans le modèle.

### 3.2 Mot clé EXCIT

On définit ici les conditions aux limites et les chargements.

```text
◊    EXCIT=
```

Ce mot clé facteur permet de définir plusieurs concepts de type charge, un par occurrence; la solution est calculée en **superposant**  les effets des différentes charges appliquées.

#### 3.2.1 Opérandes CHARGE / FONC_MULT

```text
♦    CHARGE= char,
```

Nom d'un concept de type char_meca produit par AFFE_CHAR_MECA ou AFFE_CHAR_MECA_F [U4.44.01](doc:u4.44.01) à partir du modèle mo.

On peut également donner le nom d’une “charge cinématique” (type char_cine_meca) résultat des opérateurs AFFE_CHAR_CINE et AFFE_CHAR_CINE_F [U4.44.03](doc:u4.44.03).

```text
◊  FONC_MULT= fmult,
```

Nom d'un concept de type fonction (ou formule) qui permet de définir pour chaque instant de calcul un coefficient multiplicateur appliqué à la charge char.

fmult est une fonction du temps: par défaut c'est une fonction constante qui vaut 1.

### 3.3 Mots clés INST / LIST_INST

```text
◊    /    INST= tps,
```

Mot clé utilisé pour effectuer le calcul à un seul instant tps avec la température correspondant à cet instant.

```text
/    LIST_INST= litps,
```

```text
◊    INST_FIN= tf,
```

La liste litps produite par DEFI_LIST_REEL [U4.34.01](doc:u4.34.01) définit les instants pour lesquels on demande le calcul d'une évolution thermo-mécanique.

Le mot clé INST_FIN permet de ne calculer que les instants antérieurs ou égaux à tf.

Ce mot clé (INST_FIN) combiné au mot clé "RESULTAT" (commande réentrante) permet de fractionner un long transitoire thermo-mécanique.

On fera par exemple:

```text
resu = MECA_STATIQUE (...        LIST_INST = linst, INST_FIN = 10., ...)

MECA_STATIQUE (RESULTAT = resu,    LIST_INST = linst, INST_FIN = 20., ...)

MECA_STATIQUE (RESULTAT = resu,    LIST_INST = linst, INST_FIN = 30., …)
```

### 3.4 Mot clé RESULTAT

Dans le cas où l'on souhaite poursuivre un calcul déjà exécuté, RESULTAT indique quel objet estenrichi. Dans ce cas, la commande se contente de ne pas recalculer les instants précédents déjà calculés.

### 3.5 Mot clé facteur SOLVEUR

Voir [U4.50.01](doc:u4.50.01).

### 3.6 Opérande OPTION

```text
◊    OPTION = / 'SANS'        / 'SIEF_ELGA'
```

Par défaut la commande MECA_STATIQUE calcule les contraintes aux points de Gauss (ou efforts généralisés pour les éléments de structure).

Les autres options de post-traitement seront calculées à posteriori par la commande CALC_CHAMP [U4.81.04](doc:u4.81.04).

Si l’utilisateur indique OPTION = 'SANS', ces contraintes ne seront pas calculées et la structure de données produite sera moins volumineuse.

### 3.7 Opérande INFO

```text
◊    INFO= 1,
```

Imprime les principales caractéristiques des systèmes linéaires à résoudre : nombre d'inconnues, taille de la matrice.

### 3.8 Opérande TITRE

```text
◊    TITRE = titr,
```

Titre que l'on veut donner au résultat [U4.03.01](doc:u4.03.01).

## 4 Exemples de calculs

### 4.1 Calcul statique avec superposition de 2 cas de charge

```text
mest1 = MECA_STATIQUE (        MODELE= mo, CHAM_MATER= chmat,
CARA_ELEM= carac,
EXCIT= ( _F( CHARGE= ch1 , FONC_MULT= COS ),
_F( CHARGE= ch2 ),),)
```

### 4.2 Calcul thermo-élastique à différents instants

```text
chmat = AFFE_MATERIAU (        ..., AFFE_VARC=_F(... EVOL=evoth ...) );

mest2 = MECA_STATIQUE (        MODELE= mo , CHAM_MATER= chmat ,
EXCIT= _F( CHARGE= bloq ),
LIST_INST= litps )
```

## 5 Remarque

Pour certaines études en élasticité linéaire pour lesquelles les caractéristiques de rigidité de la structure sont indépendantes de l'histoire thermique et les conditions aux limites cinématiques indépendantes des autres charges, on peut déterminer les déformées pour plusieurs cas de chargement en utilisant MACRO_ELAS_MULT [U4.51.02](doc:u4.51.02).
