# v2.02.007 SDLL07- P outre élancée sur deux appuis, soumise à une charge mobile de vitesse constante

**Résumé:**

Le test dynamique en élasticité linéaire sert à valider les éléments de poutre droite POU_D_T.

Ce cas-test concerne une poutre élancée sur deux appuis, soumise à une charge mobile de vitesse constante.

On teste les fréquences ainsi que déplacements en comparant des résultats de simulation avec la solution de référence AFNOR (ref. [1]).

Le calcul dynamique de code-aster est effectué à l’aide de l’opérateur DYNA_VIBRA sur la base physique.

## 1 Problème de référence

### 1.1 Chargement

La charge mobile d’intensité Fy = -48 000 N se déplace à une vitesse de 10 m/s pendant 1 s. L’amortissement considéré est nul.

## 3 Synthèse des résultats

Les résultats montrent le bon fonctionnement des éléments `POU_D_T` dans ce cas-test d’une poutre élancée reposant sur deux appuis et soumise à une charge mobile de vitesse constante.

Le post-traitement, réalisé en calculant les enveloppes maximales via l’option `ENVELOPPE="NORME_MOMENT"`, confirme également le bon comportement de cette fonctionnalité.
