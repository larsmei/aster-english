# v2.02.014 SDLL14 - Modes de vibration d’un coude de tuyauterie mince

**Résumé:**

Ce test consiste à rechercher les fréquences propres et les modes de vibration associés d’une tuyauterie coudée. Il permet de valider les modélisations éléments finis TUYAU_3M (SEG3 et SEG4) et TUYAU_6M (SEG3).

Il valide également l'option de calcul des plus grandes fréquences propres d'une structure. Les résultats obtenus sont comparés à une solution de référence analytique.

En plus, il valide les modélisations éléments finis POU_D_T en comparant les résultats obtenus avec les résultats de référence trouvés dans la référence  ainsi que ceux obtenus par le logiciel Pipestress.

## 2 Solution de référence

### 2.1 Méthode de calcul utilisée pour la solution de référence

La méthode de Rayleigh appliquée à des éléments de poutre droite élancée et à un élément de poutre courbe mince permet de déterminer des paramètres tels que :

- flexion dans le plan: ${f}_{i}=\frac{{\lambda}_{i}^{2}}{2\pi {R}^{2}}\sqrt{\frac{E{I}_{z}}{\rho A}}$ $i=1,2$ ;
- flexion transverse: ${f}_{i}=\frac{{\mu}_{i}^{2}}{2\pi {R}^{2}}\sqrt{\frac{G{I}_{p}}{\rho A}}$ $i=1,2$ ;

Les valeurs ${\lambda}_{i}^{2}$ et ${\mu}_{i}^{2}$ sont tirées d’un abaque issu de bib2.

![Figure](/figures/v2.02.014/AbaquesModesPropres.png)

*Abaques issues de bib2 pour les valeurs de $\lambda_i$ et $\mu_i$*

Dans les modélisations présentées, le rapport $\frac{L}{R}$ vaut $0$,
$0.6$ ou $2$. Les valeurs prises dans bib1 sont :

- $\lambda_1^2 = 22.5$ ;
- $\lambda_2^2 = 43$ ;
- $\mu_1^2 = 9.5$ ;
- $\mu_2^2 = 26.9$ ;

**Pour $\frac{L}{R} = 0$ :**

- $\lambda_1^2 = 17.8$ ;
- $\lambda_2^2 = 34$ ;
- $\mu_1^2 = 7.2$ ;
- $\mu_2^2 = 21.5$ ;

**Pour $\frac{L}{R} = 0.6$ :**

- $\lambda_1^2 = 4.8$ ;
- $\lambda_2^2 = 5.1$ ;
- $\mu_1^2 = 3.85$ ;
- $\mu_2^2 = 5.3$ ;

**Pour $\frac{L}{R} = 2$ :**

Cette formulation n’est utilisable que pour les tuyauteries très élancées:

- Élancement des parties droites supérieur à $\frac{l}{{d}_{e}}>20$
- Coude mince tel que $\alpha R>100\sqrt{\frac{{I}_{z}}{A}}$ avec $\alpha$ , angle au centre en radian.

De plus, les valeurs des fréquences propres pour la flexion transverse n'est
valable que pour un coefficient de Poisson $\nu = 0.3$ d'après bib2.

Il n’est pas nécessaire d’utiliser ici un coefficient de flexibilité du coude.
Le coefficient de flexibilité issu du RCC-M vaut $\max(1 ; 1.65 \frac{r_m^2}{e R})$
où $r_m$ est le rayon moyen de la section du coude, $e$
son épaisseur et $R$ le rayon de courbure, qui vaut $1$ dans
le présent cas.

### 2.3 Incertitude sur la solution

Les coefficients $\lambda_i^2$ et $\mu_i^2$ sont issus d'abaques. A ce
titre, il existe une incertitude de l'ordre d'un quart de graduation environ sur
leur valeur, soit en valeur absolue $0.5$ (graduation de $2$).

Ceci porte l'incertitude aux valeurs suivantes :

- $\lambda_1^2 = 22.5 \longrightarrow 2.2\%$ ;
- $\lambda_2^2 = 43 \longrightarrow 1.2\%$ ;
- $\mu_1^2 = 9.5 \longrightarrow 5.3\%$ ;
- $\mu_2^2 = 26.9 \longrightarrow 1.9\%$ ;

**Pour $\frac{L}{R} = 0$ :**

- $\lambda_1^2 = 17.8 \longrightarrow 2.8\%$ ;
- $\lambda_2^2 = 34 \longrightarrow 1.5\%$ ;
- $\mu_1^2 = 7.2 \longrightarrow 7\%$ ;
- $\mu_2^2 = 21.5 \longrightarrow 2.3\%$ ;

**Pour $\frac{L}{R} = 0.6$ :**

- $\lambda_1^2 = 4.8 \longrightarrow 10.4\%$ ;
- $\lambda_2^2 = 5.1 \longrightarrow 9.8\%$ ;
- $\mu_1^2 = 3.85 \longrightarrow 13\%$ ;
- $\mu_2^2 = 5.3 \longrightarrow 9.4\%$ ;

**Pour $\frac{L}{R} = 2$ :**

L'incertitude sur ces valeurs selon bib1 est fixée à $3\%$ sur la
valeur lue sur l'abaque. Ceci ne semble pas en accord avec le fait que
l'échelle soit linéaire. Ainsi, les tolérances imposées dans les tests
devraient au moins être égales à ces incertitudes.

### 7.1 Caractéristiques de la modélisation

Idem que la modélisation A.

### 7.2 Caractéristiques du maillage

Idem que la modélisation A.

### 7.3 Grandeurs testées et résultats

On teste le calcul de la plus grande fréquence propre de la structure, en échangeant à la main les rôles des matrices de masse et de raideur. Il faut notamment transférer les degrés de liberté de Lagrange de la raideur vers la masse.

Le calcul modal est réalisé d'une part avec TYPE_RESU='GENERAL', qui renvoie une valeur propre (charge critique) $\mu$ ; dans ce cas, il faut appliquer la formule $\frac{-1}{2\pi \sqrt{\mu}}$ pour convertir la valeur en fréquence propre. D'autre part avec TYPE_RESU='DYNAMIQUE', qui renvoie une fréquence propre $f$ ; dans ce cas, il faut appliquer la formule $\frac{1}{{(2\pi )}^{2}f}$ pour retrouver la bonne fréquence propre.

La valeur ainsi calculée sert de référence pour la modélisation D.

## 11 Synthèse des résultats

Les résultats obtenus avec les modélisation TUYAU (SEG3 et SEG4 ) et TUYAU_6M (SEG4) sont satisfaisants. L'écart maximum observé est inférieur à $\text{2.1\%}$ .
