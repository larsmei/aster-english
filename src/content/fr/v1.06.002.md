# v1.06.002 HROM002 – Vérification de l’API python pour la construction d'une quadrature empirique

**Résumé:**

Ce cas-test est destiné à vérifier l’API python pour la construction d'une quadrature empirique.
Un solveur d'optimisation pour des moindres carrés à poids positifs est testé (*Non negative least squares*, NNLS).

Ce test se focalise sur les algorithmes de construction d'une quadrature empirique au sens de l'algèbre linéaire,
et non la manipulation des champs.

Cette documentation est volontairement succincte.
