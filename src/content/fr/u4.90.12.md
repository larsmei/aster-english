# u4.90.12 Opérateur POST_MAC3COEUR

## 1 But

Macro-commande dédiée au post-traitement de CALC_MAC3COEUR., pour extraire au format tableau les valeurs ou des analyses du résultat.

## 2 Syntaxe

```text
table = POST_MAC3COEUR(
    ◆ TYPE_COEUR = / "MONO",
                   / "MONO_FROID",
                   / "TEST",
                   / "900",
                   / "1300",
                   / "N4",
                   / "LIGNE900",
                   / "LIGNE1300",
                   / "LIGNEN4",
    # Si: is_in("TYPE_COEUR", ("LIGNE900","LIGNE1300","LIGNEN4"))
        ◆ NB_ASSEMBLAGE = int,
    ◆ RESULTAT = evol_noli,
    ◆ TABLE = table,
    ◆ INST = float,
    ◆ TYPE_CALCUL = / "LAME",
                    / "DEFORMATION",
                    / "FORCE_CONTACT",
    ◇ OPERATION = / "EXTRACTION" (par défaut),
                  / "ANALYSE",
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Opérandes

### 3.1 Opérande TYPE_COEUR

Nom du type de cœur à traiter. Voir [u4.90.11](doc:u4.90.11) CALC_MAC3COEUR.

### 3.2 Opérande NB_ASSEMBLAGE

Dans le cas d’un cœur de type 'LIGNEXXX' (avec XXX='900','1300', 'N4' ou 'EPR'), permet de préciser la longueur de la ligne

### 3.3 Opérande RESULTAT

Nom de la structure de donnée résultat à post-traiter.

### 3.4 Opérande TABLE

Table (au format DAMAC) contenant l'information des assemblages.

### 3.5 Opérande INST

Instant du post-traitement désiré. Un seul instant possible à la fois.

### 3.6 Opérande TYPE_CALCUL

Nature du résultat à post-traiter, lames d’eau, déformations ou forces de contact.

### 3.7 Opérande OPERATION

Nature du post-traitement, extraction ou analyse de valeurs.
