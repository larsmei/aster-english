# u4.66.21 Opérateur MODI_BASE_MODALE

## 1 But

Définir la base modale d’une structure sous écoulement. Cette base est obtenue après un calcul de couplage fluide-élastique réalisé à l’aide de l’opérateur CALC_FLUI_STRU [U4.66.02](doc:u4.66.02). Le concept produit est de type mode_meca.

## 2 Syntaxe

```text
mode_meca = MODI_BASE_MODALE(
    ◇ reuse = <objet de BASE>,
    ◆ BASE = mode_meca,
    ◆ BASE_ELAS_FLUI = melasflu,
    ◆ NUME_VITE_FLUI = int,
    ◇ NUME_ORDRE = int,
    ◇ / AMOR_REDUIT = float,
      / AMOR_UNIF = float,
    ◇ INFO = / 1 (par défaut),
             / 2,
    ◇ TITRE = text,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Opérandes

```text
♦    BASE = mode
```

Concept de type [mode_meca] qui définit les caractéristiques modales avant prise en compte du couplage fluide-élastique. Suivant le choix de l’utilisateur, l’opérateur modifie ce concept d’entrée ou crée un nouveau concept de type [mode_meca].

```text
♦    BASE_ELAS_FLUI = bef
```

Concept de type [melasflu] qui définit les nouvelles caractéristiques des modes pris en compte pour le couplage fluide-élastique, pour différentes vitesses d’écoulement.

```text
♦    NUME_VITE_FLUI = numv
```

Permet de pointer sur les caractéristiques des modes pris en compte pour le couplage fluidélastique, pour une vitesse d’écoulement donnée.

```text
◊    NUME_ORDRE = l_nuor
```

Si l’on modifie le concept d’entrée de type [mode_meca] : liste des numéros d’ordre des modes non perturbés auxquels on souhaite affecter un amortissement réduit.

Si l’on crée un nouveau concept de type [mode_meca] en sortie : liste des numéros d’ordre des modes non perturbés qui sont effectivement retenus pour reconstruire la base modale. La possibilité d’affecter un amortissement réduit à ces modes est maintenue, en recourant aux opérandes AMOR_REDUIT ou AMOR_UNIF ci-dessous.

**Remarque :**

*Par défaut, on sélectionne tous les modes qui n’ont pas été pris en compte pour le couplage fluide-élastique. Ne pas donner dans cette liste des numéros d’ordre correspondants aux modes couplés.*

*La constitution du* [mode_meca] *résultat en fonction des choix pour les opérandes* *NUME_ORDRE,* *AMOR_REDUIT et* *AMOR_UNIF* est précisée en paragraphe [§ 1 *].*

```text
◊    /    AMOR_REDUIT = l_amor
```

Liste des amortissements réduits affectés aux modes non perturbés.

```text
/    AMOR_UNIF = amor
```

Amortissement réduit affecté identiquement aux modes non perturbés.

```text
◊    INFO = 1 ou 2
```

Opérande inactive. Pour obtenir l'impression des résultats, il faut utiliser la commande IMPR_RESU [U4.91.01](doc:u4.91.01).

```text
◊    TITRE = titre
```

Argument de type texte [TXM] définissant le titre attaché au concept [mode_meca] en sortie.
