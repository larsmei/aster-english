# v4.61.104 MTLP104 - Modèle de revenu de l'acier

**Résumé:**

Ce cas-test constitue une validation des modèles de transformations métallurgiques pour la prise
en compte des phases de revenus dans les aciers.
On utilise un modèle de cube avec un transitoire de température imposée et on compare
les résulats entre un script Python réalisant le calcul des phases de revenu et la commande
[CALC_META](doc:u4.85.01) avec le mot-clef REVENU.

## 2 Solution de référence

### 2.1 Résultats de référence

On compare les résultats entre un calcul réalisé par
un script Python (modélisation A), puis par la commande [CALC_META](doc:u4.85.01) avec le
mot-clef REVENU (modélisation B).

Pour le calcul de la dureté (DURT_ELNO), comme c'est une loi des mélanges linéaires, la solution
est analytique.

On a 70% de ferrite et 30% de bainite, le dureté de Vickers vaut
$H_{V}=\sum_{k}{Z}_{k}{H_{V}}_{k} = 0,7 \times 200 + 0,3 \times 300 = 230$.

Et comme on a pris `F3_REVENU_DURT = F3_DURT` et `F4_REVENU_DURT = F4_DURT`, on trouvera
strictement la même chose après revenu.
