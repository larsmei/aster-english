# v1.01.110 ZZZZ110 - Validation de la commande PROJ_CHAMP / ELEM (en 2D et en filaire)

**Résumé:**

Ce cas-test permet de valider la commande PROJ_CHAMP/ELEM dans les cas suivants :

Projection d'un champ de température (modélisations $A$ et $B$ ) :

- Projection d'un maillage $\mathrm{2D}$     sur un autre maillage $\mathrm{2D}$
- Projection d'un maillage $\mathrm{2D}$     sur un maillage filaire $\mathrm{1D}$
- Projection d'un maillage $\mathrm{1D}$ filaire sur un maillage $\mathrm{2D}$
- Projection d'un maillage $\mathrm{2D}\mathrm{axis}$ sur un solide $\mathrm{3D}$

Projection d'un champ de contrainte (modélisations $A$ et $B$ ) :

- Projection d'un maillage $\mathrm{2D}\mathrm{axis}$ sur un solide $\mathrm{3D}$
- Projection d'un maillage $\mathrm{3D}$ sur un solide $\mathrm{3D}$

### 1.2 Solution de référence

#### 1.2.1 Méthode de calcul

**Calcul de la référence pour le champ de température**

Le champ que l'on projette d'un modèle sur l'autre est un champ analytique de température dont l'évolution est la suivante :

> $T=3.+X+Y$

La solution de référence est identique au champ analytique projeté.

**Calcul de la référence pour le champ de contrainte**

L'objectif est d'effectuer un changement de repère, après avoir réalisé une projection d'un champ de contrainte connu sur un maillage vers un maillage 3D.

> Passage d'un repère cylindrique ($\mathrm{XOY}$ ) vers un repère cartésien $\mathrm{3D}$ ($\mathrm{XYZ}$ ).

Le champ de contrainte $(N/{m}^{2})$ dans le repère axisymétrique (axe $\mathrm{OY}$ ) est le suivant:

- $\mathrm{SIXX}=2$
- $\mathrm{SIYY}=y$
- $\mathrm{SIZZ}=1$
- $\mathrm{SIXY}=0.$

Le champ de contrainte dans le repère cartésien ($\mathrm{3D}$ ) est obtenu en effectuant :

- Une projection du tenseur des contraintes évalué sur le maillage $\mathrm{2D}\mathrm{axis}$ sur le maillage 3D.
- Changement de repère du tenseur des contraintes $[{\sigma}_{\mathrm{3D}}]=[P][{\sigma}_{\mathrm{cyl}}]{[P]}^{T}$ ou $[P]$ représente la matrice de changement de repère.

### 1.3 Modélisation B

#### 1.3.1 Géométrie

![Figure](/figures/v1.01.110/Shape1.gif)

Cube de côté : $L=2$

#### 1.3.2 Propriétés du matériau

    - $E=2N/{m}^{2}$
    - $\nu =0.$

#### 1.3.3 Conditions aux limites et chargements

Déplacements imposés

- plan $z=\mathrm{1m}$         $\mathrm{DX}=0.=\mathrm{DY}=0.=\mathrm{DZ}=0.$
- plan $z=3m$         $\mathrm{DZ}=\mathrm{2.m}$

### 1.4 Solution de référence

#### 1.4.1 Méthode de calcul

Le coefficient de poisson est nul $\nu =0$ ce qui nous donne

${\sigma}_{xx}={\sigma}_{yy}={\sigma}_{xy}={\sigma}_{xz}={\sigma}_{yz}=0$

${\sigma}_{zz}=E\epsilon =E\frac{\mathrm{DZ}}{L}$

#### 1.4.2 Résultats de référence

$\mathrm{SIZZ}=2N/{m}^{2}$ En tout point du cube
