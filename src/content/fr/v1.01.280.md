# v1.01.280 ERREU06 - Vérification du fonctionnement du NaN dans Code_Aster

**Résumé:**

Ce test valide le fait qu'en version debug sur le serveur centralisé Aster4, *Code_Aster* s'arrête en erreur lorsqu'on tente de manipuler un NaN (Not-a-Number) de type SNaN (Signalling NaN).

## 1 Principe du test

Ce test est un test informatique. Il valide que le NaN définit dans envima.c est bien du type SNaN et que, de ce fait, n'importe quelle manipulation provoque l'arrêt de l'exécution en «Erreur numérique». Ce test est réalisé à l'aide du mot-clé TEST_NAN='OUI' de la commande TEST_RESU.
