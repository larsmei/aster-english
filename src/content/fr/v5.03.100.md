# v5.03.100 SDNV100 - Impact d'une poutre sur une paroi rigide

**Résumé**

Ce problème correspond à une analyse transitoire directe d'un système non-linéaire modélisé en éléments volumiques. Une première structure élancée (poutre) de section carrée est animée d'une vitesse initiale et vient heurter une paroi rigide. La non‑linéarité vient des conditions de contact entre la structure et la paroi.

## 1 Problème de référence

### 1.1 Géométrie

![Figure](/figures/v5.03.100/100000000000038A000002ADE16397DE6AC269A3.jpg)

### 1.2 Propriétés de matériaux

| **Poutre :** | module d'Young : | $E={2.10}^{11}\mathrm{Pa}$ |
| --- | --- | --- |
|  | coefficient de Poisson : | $\nu =0.3$ |
|  | masse volumique: | $\rho =8000\mathit{kg}/{m}^{3}$ |
| C **ontact :** | coefficients de pénalisation : | ${E}_{n}={10}^{14}\mathrm{Pa}$ |
|  |  | ${E}_{t}=0$ |
|  | coefficient de Coulomb : | $\mu =0$ |

### 1.3 Conditions aux limites et chargements

Le problème est unidirectionnel selon $z$ .

On considère un quart de la poutre avec les conditions de symétrie : on bloque les déplacements

selon $x$ sur le plan $x=0$ et les déplacements selon $y$ sur le plan $y=0$ .

### 1.4 Conditions initiales

A tous les nœuds de la maille de la poutre sont imposés selon l'axe $z$ :

- le déplacement initial : ${u}_{0}=2\mathrm{mm}$
- la vitesse initiale : ${v}_{0}=-100m/s$
