# u4.81.45 Opérateur POST_COMBINAISON

## 1 But

Le but de cette macro-commande est de combiner différentes grandeurs physiques à la suite de calculs aux éléments finis réalisés en amont. Cette commande ne réalisera que des posts-traitements en manipulant des résultats sous forme de champs ou de tables issues de calculs antérieurs.

En entrée, cette macro-commande prend des résultats de plusieurs types ou des tables de type table_sdaster à combiner, suivis d’une table de type table_sdaster des coefficients à appliquer pour chaque combinaison.

En sortie, si des résultats sont combinés, la macro-commande retournera une structure résultat de type mult_elas. En revanche, dans le cas de combinaison de tables, une table table_sdaster est retournée. La table finale des combinaisons de type table_sdaster est retournée dans les deux cas.

## 2 Syntaxe

```text
POST_COMBINAISON(
    ◆ TABLE_COEF = table,
    ◇ TABLE_COEF_RESU = co,
    ◆ TYPE_COMB = / "RESULTAT",
                  / "TABLE",
    # Si: equal_to('TYPE_COMB', 'RESULTAT')
        ◇ / TOUT = "OUI" (ou non renseigné),
          / | GROUP_MA = list[grma],
            | GROUP_NO = list[grno],
        ◆ MODELE = modele,
        ◇ NOM_CHAM = list[text],
        ◆ AFFE = _F(
             ◆ NOM_CAS = text,
             ◆ RESULTAT = evol_elas / mode_meca / mult_elas,
          ),
    # Si: equal_to('TYPE_COMB', 'TABLE')
        ◇ FILTRE = _F(
             ◆ NOM_PARA = text,
             ◇ CRIT_COMP = / "EQ" (par défaut),
                           / "GE",
                           / "GT",
                           / "LE",
                           / "LT",
                           / "MAXI",
                           / "MAXI_ABS",
                           / "MINI",
                           / "MINI_ABS",
                           / "NE",
                           / "NON_VIDE",
                           / "VIDE",
             # Si: (is_in("CRIT_COMP", ('EQ','NE','GT','LT','GE','LE')))
                 ◆ / VALE = float,
                   / VALE_I = int,
                   / VALE_K = list[text],
                   / VALE_C = complex,
                 ◇ CRITERE = / "ABSOLU",
                             / "RELATIF" (par défaut),
                 ◇ PRECISION = float (défaut: 0.001),
          ),
        ◆ AFFE = _F(
             ◆ NOM_CAS = text,
             ◆ TABLE = table,
          ),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Opérandes

### 3.1 Opérande TABLE_COEF

Table contenant les coefficients des combinaisons pour tous les résultats ou les tables à combiner. Chaque colonne doit contenir les coefficients à appliquer à un résultat ou une table. Le nom en tête de colonne doit être cohérent avec le nom renseigné sous le mot-clé NOM_CAS du résultat ou de la table renseigné dans le mot-clé facteur AFFE. Chaque ligne doit représenter une combinaison. Chaque coefficient sera utilisé pour multiplier le résultat/la table dans la combinaison correspondante.

### 3.2 Opérande TABLE_COEF_RESU

Nom de la table finale des coefficients. Cette table est issue de la table donnée en entrée sous le mot-clé TABLE_COEF. Celle-ci est étendue selon les numéros d’ordres contenus dans chaque résultat ou table.
Ce mot-clé est facultatif.

### 3.3 Opérande TYPE_COMB

Indicateur de type texte permettant de spécifier le type de la structure de données à multiplier.

Deux choix sont possibles:

1. RESULTAT: Les structures de données à combiner sont de type sd_resultat. Trois types de résultats sont acceptés: mult_elas, evol_elas et mode_meca
2. TABLE: Structure de données de type sd_table.

**Remarque**

Seules les tables issues de l’opérateur CALC_COUPURE pour des calculs statiques sont prises en charge. Par exemple, les tables issues de CALC_COUPURE pour des calculs sismiques (opérateur COMB_SISM_MODAL) ne sont pas traitées.

### 3.4 Opérandes TOUT/GROUP_MA/GROUP_NO

Les mots clés TOUT, GROUP_MA et GROUP_NO permettent à l'utilisateur de choisir les mailles ou les nœuds sur lesquels il souhaite faire ses combinaisons.

- TOUT = 'OUI'
  Toutes les mailles (porteuses d'éléments finis) seront traitées.
- GROUP_MA = l_grma
  Seules les mailles incluses dans l_grma seront traitées.
- GROUP_NO = l_grno
  Seuls les noeuds inclus dans l_grno seront traités.

**Remarque**

Les mots clés GROUP_MA et GROUP_NO peuvent être utilisés simultanément

### 3.5 Opérande MODELE

Nom du modèle sur lequel sera affecté le résultat de sortie.

### 3.6 Opérande NOM_CHAM

Ce mot clé permet de choisir une liste de noms symboliques de champ à combiner (aux nœuds ou par élément) parmi l'ensemble des possibles. Il est facultatif. S’il n’est pas renseigné, tous les champs sont combinés.

### 3.7 Mot clé facteur AFFE

Le mot clé facteur AFFE permettant de spécifier les résultats à combiner.
On fournit soit des résultats, soit des tables.

- NOM_CAS = l_nomcas
  Nom du résultat à combiner. Celui-ci doit être cohérent avec les noms renseignés dans la table des coefficients.
- RESULTAT= resu
  Structure de données sd_resultat à combiner.
- TABLE= table
  Structure de données sd_resultat à combiner.

### 3.8 Opération FILTRE

Ce mot-clé facteur est facultatif. Il permet de filtrer les lignes de la table. Pour l’utilisation de ce mot-clé voir la commande IMPR_TABLE [U4.91.03](doc:u4.91.03).

### 3.9 Opérande NOM_PARA

Nom des paramètres (colonnes) que l'on veut extraire.
