# v3.04.114 SSLV114 - Mouvements de corps solide 2D et 3D

**Résumé:**

Ce test valide (en 2D et 3D) le mot clé LIAISON_SOLIDE de la commande AFFE_CHAR_MECA.

Ce mot clé sert à rigidifier un ensemble de nœuds par des relations linéaires exprimant que les déplacements des nœuds "rigidifiés" sont liés entre eux par l'équation :

$U(M)=U(A)+\Omega (A)\mathrm{\wedge }\mathit{AM}$

Cette équation n'est valable qu'en petits déplacements.

Le problème teste le 2D et le 3D ainsi que les cas particuliers :

- nœuds confondus géométriquement (2D et 3D),
- nœuds alignés (en 3D).

## 1 Problème de référence

### 1.1 Géométrie

![Figure](/figures/v3.04.114/10000D56000030930000174132DFB8A3C457790A.svg)

### 1.2 Propriétés de matériaux

$E=0$

$\nu =0$

Les éléments finis présents dans ce problème ne servent qu'à définir les degrés de liberté portés par les nœuds. Leur rigidité doit être nulle.

### 1.3 Conditions aux limites et chargements

Dans ce problème, on définit des groupes de nœuds "solides" :

- en 2D :
- $A,B,C,D$
- $\mathrm{E1},\mathrm{E2},\mathrm{E3}$
- en 3D :
- $F,G,H,I,J,K,L,M$
- $O,N,P$
- $\mathrm{Q1},\mathrm{Q2},\mathrm{Q3}$

Pour chacun de ces groupes de nœuds, on impose des déplacements partiels de façon à ce que les "solides" se déplacent en respectant :

| En 2D : | $\lbrace \begin{array}{ccc}\mathrm{translation}& :& T(A)=T(\mathrm{E1})=(\begin{array}{}2.\\ 3.\end{array})\\ \mathrm{rotation}& :& \theta (A)=\theta (\mathrm{E1})=0.01\end{array}$ |
| --- | --- |
| En 3D : | $\lbrace \begin{array}{ccc}\mathrm{translation}& :& T(F)=T(N)=T(\mathrm{Q1})=(\begin{array}{}2.\\ 3.\\ 4.\end{array})\\ \mathrm{rotation}& :& \theta (F)=\theta (N)=\theta (\mathrm{Q1})=(\begin{array}{}0.001\\ 0.002\\ 0.003\end{array})\end{array}$ |

Les déplacements imposés choisis pour conduire aux déplacements "solide" recherchés sont :

| 2D | $\mathrm{DX}(A)=2.$ | $\mathrm{DX}(\mathrm{E1})=2.$ |
| --- | --- | --- |
|  | $\mathrm{DY}(A)=3.$ | $\mathrm{DY}(\mathrm{E1})=3.$ |
|  | $\mathrm{DY}(B)=3.001$ | (+ $\mathrm{DRZ}(\mathrm{E1})=0.001$ pour la modélisation B) |
|  |  |  |
| 3D | $\mathrm{DX}(F,N,\mathrm{Q1})=2.$ |  |
|  | $\mathrm{DY}(F,N,\mathrm{Q1})=3.$ |  |
|  | $\mathrm{DZ}(F,N,\mathrm{Q1})=4.$ |  |
|  |  |  |
|  | $\mathrm{DY}(J,O)=2.002$ |  |
|  | $\mathrm{DY}(J,O)=2.999$ |  |
|  |  |  |
|  | $\mathrm{DX}(I)=1.997$ |  |
|  |  |  |
|  | $\mathrm{DRZ}(N)=0.003$ | pour la modélisation B |
|  | $\mathrm{DRX}(\mathrm{Q1})=0.001$ |  |
|  | $\mathrm{DRY}(\mathrm{Q1})=0.002$ |  |
|  | $\mathrm{DRZ}(\mathrm{Q1})=0.003$ |  |

## 2 Solution de référence

### 2.1 Méthode de calcul utilisée pour la solution de référence

Le mouvement des "solides" étant imposé, la solution de référence (en déplacement) est le mouvement imposé.

La solution de référence est donc exacte (en petites rotations).

### 2.2 Résultats de référence

| En 2D : | $U(C)=(\begin{array}{}1.999\\ 3.001\end{array})$ | $U(\mathrm{E2})=(\begin{array}{}2.\\ 3.\end{array})$ |  |
| --- | --- | --- | --- |
| En 3D : | $U(L)=(\begin{array}{}1.999\\ 3.002\\ 3.999\end{array})$ | $U(P)=(\begin{array}{}1.998\\ 3.001\\ 4.000\end{array})$ | $U(\mathrm{Q3})=(\begin{array}{}2.\\ 3.\\ 4.\end{array})$ |

### 2.3 Incertitude sur la solution

Solution exacte.
