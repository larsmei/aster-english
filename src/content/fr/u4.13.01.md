# u4.13.01 Procédure INCLUDE

## 1 But

Il s'agit d'insérer une suite de commandes qui seront exécutées *presque* telles qu'elles sont écrites. Il n'y a pas de possibilité de passer d'arguments.

Les résultats des commandes sont *exportées* dans le jeu de commandes principal.
Les autres objets sont normalement utilisables dans le fichier de commandes mais ne seront pas disponibles dans une POURSUITE.
Par exemple, une fonction ou classe Python définie dans un INCLUDE pourra être utilisée dans une FORMULE dans le fichier de commandes et évaluée dans celui-ci, mais pas en POURSUITE.

Il est donc conseillé de limiter l'usage de INCLUDE à ces cas simples (un ensemble de commandes définies dans un autre fichier).
Si on souhaite exécuter plus d'instructions Python, il est préférable d'utiliser `import` (utiliser le type 'nom' pour recopier un fichier dans le répertoire d'exécution sans le renommer).

## 2 Syntaxe

```text
INCLUDE(
    ◆ / UNITE = unit,
      / DONNEE = text,
    ◇ ALARME = / "OUI" (par défaut),
               / "NON",
    ◇ INFO = / 0,
             / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Opérandes

Hormis l'emplacement du fichier inclus, le fonctionnement est strictement identique avec UNITE ou DONNEE.

### 3.1 Opérande UNITE

Unité logique du fichier à inclure. Ce numéro doit correspondre au fichier à inclure, défini dans l'interface de lancement ou dans le fichier `.export`. Ce fichier est recopié dans le répertoire d'exécution sous le nom `fort.NN`.

**Remarque**

On ne peut pas utiliser INCLUDE avec une unité logique associée à un nom de fichier avec DEFI_FICHIER. Si nécessaire, on peut utiliser DONNEE=fichier.

### 3.2 Opérande DONNEE

Ce mot-clé, destiné à être utilisé dans les cas-tests, permet d'inclure un fichier stocké dans le répertoire *tests_data* dont la diffusion est restreinte. Cela permet de diffuser un cas-test sauf une petite partie qui doit rester confidentielle.

Ce répertoire est par défaut situé dans le répertoire `share/aster` de l'installation. L'option de la ligne de commande `--rcdir` permet de surcharger cet emplacement.

Le fichier inclus sera donc `xxx/share/aster/tests_data/fichier`.

On peut également fournir le chemin absolu vers le chemin à inclure.

### 3.3 Opérande ALARME

Ce mot-clé permet de supprimer le message alartant sur les précautions d'usage de INCLUDE.

### 3.4 Opérande INFO

| 0 | pas d'impression du contenu du fichier inclus. |
| --- | --- |
| 1 | impression du contenu du fichier inclus, dans le fichier 'MESSAGE' |
| 2 | identique à 1 (cette valeur existe par convention) |

## 4 Exemple d'utilisation

- Fichier principal de commandes:

```python
DEBUT()
INCLUDE(UNITE=91, INFO=1)
mo = AFFE_MODELE(MAILLAGE=ma, AFFE=_F(TOUT="OUI", PHENOMENE="MECANIQUE", MODELISATION="3D"))
INCLUDE(UNITE=92, INFO=1)
FIN()
```

- Fichier de commandes attaché à l'unité 91

```python
ma = LIRE_MAILLAGE()
```

- Fichier de commandes attaché à l'unité 92

```python
lbew = DEFI_FONCTION(
    NOM_PARA="INST",
    VALE=(
        0.0,
        -0.19949,
        0.01000,
        -0.25487,
        # etc.
    ),
)
```
