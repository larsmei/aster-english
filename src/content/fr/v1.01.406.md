# v1.01.406 ZZZZ406 - Validation de la fusion des charges dans l’opérateur CALC_G

**Résumé**

Ce test n'a aucune signification physique, il s'agit d'un test informatique. Il vise à couvrir une partie du code qui réalise la fusion des charges dans l'opérateur CALC_G. Ce test reproduit à quelques modifications près le test forma05.

Il est également utilisé pour vérifier le bon fonctionnement de la commande CALC_CHAMP pour le calcul du champ FORC_NODA sans réentrance (c’est-à-dire sans le mot-clé reuse).

Cette documentation est volontairement succincte.
