# v2.02.003 SDLL03- Poutre élancée encastrée - encastrée avec inerties différentes

**Résumé:**

Le test dynamique en élasticité linéaire sert à valider les éléments de poutre droite POU_D_T.

Ce cas-test concerne une poutre élancée encastrée - encastrée avec inerties différentes.

On teste les fréquences ainsi que déplacements en comparant des résultats de simulation avec la solution de référence AFNOR (ref. [1]). Le calcul réalisé dans code-aster à l’aide de l’opérateur DYNA_VIBRA sur la base modale.
