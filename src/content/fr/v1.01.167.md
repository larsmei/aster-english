# v1.01.167 ZZZZ167 - validation de la commande CALC_THER_MULT

**Résumé :**

Ce test valide le bon fonctionnement de la commande [CALC_THER_MULT](doc:u4.54.04) permettant d’obtenir les réponses d’un modèle thermique pour plusieurs cas de chargement.

La structure du test est la suivante : les résultats de la macro-commande sont comparés aux résultats obtenus en faisant les étapes de calcul de façon séparée avec les commandes correspondantes pour les différents cas de charge.

Cette documentation est volontairement succincte.
