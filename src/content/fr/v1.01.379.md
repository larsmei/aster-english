# v1.01.379 ERREU15 - Test d'émission des messages d'erreur pour la modélisation HHO

**Résumé:**

Ce test valide l'émission des messages d'erreur liés aux limitations des méthodes HHO.

## 1 Principe du test

Ce test est un test informatique.

- Modélisation A: Erreur si un élément fini HHO n'a pas de rigidité.
- Modélisation B: Erreur si MODI_HHO crée un maillage non-conforme.
