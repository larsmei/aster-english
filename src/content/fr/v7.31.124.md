# v7.31.124 WTNV124 - Essai de désaturation-consolidation avec le modèle de Barcelone

**Résumé:**

Ce test permet de valider l'intégration du modèle de Barcelone [r7.01.17](doc:r7.01.17). Le présent test effectué dans la modélisation A, en couplage hydro-mécanique (modélisation HHM), comprend deux trajets de chargement :

- Un trajet de désaturation.
- Un trajet de compression isotrope.

La modélisation est effectuée sur un élément 3D héxaédrique.

### 1.3 Conditions aux limites et chargements

La pression de gaz reste constante égale à $\mathrm{PRE2}={1}$ Pa. Dans la première phase de chargement, on effectue une désaturation, durant laquelle la pression capillaire augmente jusqu'à $\mathrm{PRE1}={400}$ kPa. Dans la seconde phase, en maintenant cette pression capillaire, on effectue une compression isotrope jusqu'à atteindre la contrainte moyenne $\sigma_m=-600$ kPa.
