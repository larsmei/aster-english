# v1.01.343 SUPV004 - Exécution des tests unitaires Python

**Résumé**

Ces modélisations testent le module unittest.

## 1 Problème de référence

Sans objet.

## 2 Solution de référence

Il s'agit d'un test de fonctionnement. Il n'y a pas d'incertitude sur le comportement attendu.

## 3 Modélisation A

Ce test particulier permet d'exécuter de manière systématique, c'est à dire avec la même fréquence que les tests de non-regression, les tests unitaires embarqués dans les modules Python ( module unittest ).

On vérifie que l'exécution s'est bien passée et que le nombre de tests unitaires exécutés est bien celui attendu.

## 4 Modélisation B

On teste dans cette modélisation le module unittest for CommandSyntax.

## 5 Modélisation C

On teste dans cette modélisation un exemple où les appels des commandes sont encapsulés dans un objet Python.

## 6 Modélisation D

On teste dans cette modélisation un exemple d’un faux DataStructure pour le module unittest.

Cette documentation est volontairement succincte.
