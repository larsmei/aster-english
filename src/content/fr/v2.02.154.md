# v2.02.154 SDLL154 - Réponse sismique selon la méthode simplifiée Roche d'une tuyauterie droite à section constante

**Résumé:**

L'objectif de ce test est de valider la commande POST_ROCHE sur un cas élémentaire d’une
poutre droite composée de 2 mailles dans les cas suivants :

- VARIANTE = 'RCC_MRX'
- VARIANTE = 'ASNR'
- SIGM_LIM = ‘OUI’
- SIGM_LIM = ‘NON’
- SIGM_ABAT = 'REFE_ELAS'
- SIGM_ABAT = 'CODE'
- Champ de matériau constant
- Champ de matériau dépendant d’un champ de température

La section est constante. Ce test valide également (hors POST_ROCHE) la fonctionnalité
POST_ELEM/INTEGRALE sur les éléments POU_D_T pour les champs d’efforts généralisés,
utilisée dans la macro-commande POST_ROCHE.

Bien que la poutre soit droite, **dans certains des calculs les 2 éléments sont déclarés comme
coudes afin de vérifier les formules concernant les parties coudées**.

## 1 Problème de référence

### 1.1 Géométrie

On considère un tuyau creux de rayon extérieur $10\mathit{mm}$ , d’épaisseur $5\mathit{mm}$ et de longueur $2m$ .

![Figure](/figures/v2.02.154/100002010000023D000000672F1F021BBD7FC02F.png)

### 1.2 Propriétés du matériau

Le matériau est élastique isotrope dont les propriétés sont:

- $E=200\mathit{GPa}$
- $\nu =0.3$
- $\rho=7800\mathit{kg}/{m}^{3}$
- $\alpha =1.2E-5{K}^{-1}$

La loi de Ramberg Osgood utilisée pour les post-traitements s’écrit:

${ϵ}_{p}=K{(\frac{\sigma}{E})}^{1/n}$

Avec:

- $K=0.01$
- $n=2$

Dans le cas `SIGM_LIM =’OUI’`, les valeurs des autres paramètres sont les suivantes:

- RP02_MIN = 128E6
- RM_MIN = 410E6,
- RP02_MOY = 163E6,
- COEF = 1.

Dans les cas où les paramètres sont donnés comme fonction, deux formules différentes sont données sur les deux mailles et un champ de température est construit de telle manière que l’on retrouve pour chaque maille les mêmes valeurs des paramètres matériau que dans les cas constants.

### 1.3 Conditions aux limites et chargements

Un ensemble de calculs élastiques est effectué de manière indépendante sur la structure de type poutre.

![Figure](/figures/v2.02.154/100002010000019C000000785C63C96ABAD54C29.png)

#### 1.3.1 Poids propre

On impose un champ de gravité $g=9.81m/{s}^{2}$ dans la direction $-Z$ . Le point $A$ est encastré.

#### 1.3.2 Déplacement imposé

Le point $A$ est encastré. La structure est mise en torsion au point $B$ via un angle imposé $\theta =0.02\mathit{rad}$ suivant l’axe $X$ .

#### 1.3.3 Dilatation thermique

Le point $A$ est encastré. Le point $B$ est bloqué selon l’axe $X$ . Une variation du champ de température $\Delta T=100K$ génère une compression dans la poutre.

#### 1.3.4 Pression imposée

On tient compte d’une pression à l’intérieur du tuyau $P=1\mathit{MPa}$ .

#### 1.3.5 Sismique spectral

Le point $A$ est encastré. Le point $B$ est bloqué selon l’axe $Z$ . Une accélération spectrale est imposée selon les 3 axes $X$ , $Y$ et $Z$ avec les ratios respectifs $1.$ , $1.$ et $0.5$ :

![Figure](/figures/v2.02.154/1000020100000280000001E0D438E8C97734A253.png)

On tient compte des 4 premiers modes propres dynamiques et de la correction statique via des
pseudo-modes selon les 3 axes. L’amortissement réduit est fixé à 2 %.

Pour obtenir les spectres à 99 %, les valeurs lues de ces spectres sont divisées par
10. Ce test, entièrement réalisé par voie informatique, vise à vérifier la cohérence entre
les résultats analytiques calculés via un script Python et ceux obtenus avec POST_ROCHE.

## 2 Solution de référence

### 2.1 Méthode de calcul

On détermine les coefficients d’abattement des moments issus des analyses
élastiques linéaires selon les chapitres **RB 3651.1132** et **RB 3651.1142** du **RCC-MRx**
(méthode Roche post-spectrale).

La détermination de la contrainte équivalente, tenant compte des moments abattus et des
moments non abattus, correspond à l’ensemble des chargements considérés.

## 3 Modélisation A

### 3.1 Caractéristiques de la modélisation

On utilise une modélisation POU_D_T.

### 3.2 Caractéristiques du maillage

Le maillage contient 2 éléments de type SEG2.

### 3.3 Grandeurs testées et résultats

La commande POST_ELEM/INTEGRALE est appelée sur la composante MT du champ d’effort généralisé issu du calcul de déplacements imposés.

| **Identification** | **Type de référence** | **Valeur de référence** | **Précision** |
| --- | --- | --- | --- |
| Poutre complète - $\mathit{INTE}-\mathit{MT}$ | 'ANALYTIQUE' | 22.655716251849473 | 1e-6 |

On teste les grandeurs en sortie de l’opérateur POST_ROCHE dans le cas d’une utilisation de moments non dépendants du temps (mot clé facteur RESU_MECA).

Étant donné qu’**il s’agit d’une validation informatique** (par un algorithme externe à code_aster
implémenté en python dans le test),
**les valeurs de référence n’ont aucune signification physique.**
On vérifie que POST_ROCHE donne les mêmes résultats que l’algorithme du test.

Les **chargements appliqués** sont des combinaisons des deux ou plusieurs chargements suivants:

- Poids propre
- Déplacements imposés non sismiques (DISN) / dilatation thermique (DILAT THERM)
- Chargements sismiques :

  - Chargement sismique inertiel type DYN (dynamique)
  - Chargement sismique inertiel type QS (quasi-statique)
  - Déplacements imposés type DDS (Déplacements Différentiels Sismiques)
- Pression interne

Dans certains calculs, toutes les grandeurs de sortie listées dans la partie
"Solution de référence" sont testées.

Dans le calcul `ToutSism` , le moment de flexion dû au poids propre est négatif, pour
tester la prise en compte de la valeur absolue des moments de flexion
dans la formule de contrainte équivalente. De la même manière, dans les calculs où les déplacements
imposés non-sismiques (DINS) sont renseignés, les moments de flexion associés à ce type de chargements
sont également négatifs.

Pour rappel, bien que la poutre soit droite, *dans certains des calculs les 2 éléments sont déclarés comme
coudes afin de vérifier les formules concernant les parties coudées*.
