# v3.03.122 SSLS122 - Plaque homogène isotrope rectangulaire excentrée

**Résumé:**

Ce cas-test permet de tester l'excentricité des plaques avec les modélisations DKT et DST.

## 1 Problème de référence

### 1.1 Géométrie

Flexion 3 points

![Figure](/figures/v3.03.122/Shape1.gif)

Caractéristiques des plaques $(m)$ :

Longueur : $L=10$

Largeur : $l=1$

Épaisseur 1 : ${e}_{1}=0.1$

Épaisseur 2 : ${e}_{2}=0.08$

Excentrement : $e=0.01$

Coordonnées des points $(m)$ :

$A:(0,0)$             $E:(5,1)$

$B:(5,0)$             $F:(0,1)$

$C:(10,0)$             $G:(2.5,0)$

$D:(10,1)$             $H:(2.5,1)$

### 1.2 Propriétés du matériau

Élastique

- $E=2.1\times {10}^{11}\mathrm{Pa}$         Module d'Young
- $\nu =0.3$                 Coefficient de poisson

### 1.3 Conditions aux limites et chargements

Déplacement imposé $(m)$ :

- segment $\mathrm{AF},\mathrm{CD}$ : $\mathrm{DZ}=0$
- segment $\mathrm{FA}$     : $\mathrm{DX}=0$
- point $A$      : $\mathrm{DX}=\mathrm{DY}=\mathrm{DRZ}=0$

Chargement

- Pression sur $\mathrm{BE}$ : $p=2.\times {10}^{5}N/m$ $P=\mathrm{pl}$

## 2 Solution de référence

### 2.1 Méthode de calcul utilisée pour la solution de référence

Déplacements :

- Points $B$ et $E$

$f=\frac{{\mathrm{Pl}}^{3}}{96{\mathrm{EI}}_{1}}+\frac{{\mathrm{Pl}}^{3}}{96{\mathrm{EI}}_{2}}$ avec ${I}_{i}=\frac{b\times {e}_{i}^{3}}{12}$

- Points $G$ et $H$

$f=-\frac{{\mathrm{Pl}}^{3}}{192{\mathrm{EI}}_{1}}(\frac{{I}_{1}}{{I}_{2}}+\frac{7}{2})$

- Moment fléchissant :

$M(x)=\frac{\mathrm{P.x}}{2}$

### 2.2 Grandeur de référence

- $\mathrm{DZ}$     déplacement suivant $z$ aux points $B$ et $G$ .
- $\mathrm{MXX}$     moment fléchissant pour $x=\frac{L}{2}$ et $x=\frac{L}{4}$

### 2.3 Grandeur et résultat de référence

| Point | Composante | Référence |
| --- | --- | --- |
| $B$ | $\mathrm{DZ}$ | $0.3515625m$ |
| $\mathrm{DRZ}$ | $0.$ |  |
| $\mathrm{MXX}$ | $-50\times {10}^{4}\mathrm{m.N}$ |  |
| $G$ | $\mathrm{DZ}$ | $-0.2629743m$ |
| $\mathrm{DRZ}$ | $0.$ |  |
| $\mathrm{MXX}$ | $-25.\times {10}^{4}\mathrm{m.N}$ |  |
