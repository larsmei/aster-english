# u4.43.09 Opérateur DEFI_REPERE

## 1 But

Créer un champ d'orientation CHAM_ELEM de la quantité CAMA_R à partir du modèle.

Le champ créé pourra être utilisé dans AFFE_CARA_ELEM/MASSIF avec le mot-clé CHAM_ORIE et dans AFFE_MATERIAU
pour définir par exemple des directions d'orthotropie.

Permettre d’affecter à des éléments 3D ou 2D des axes locaux par les mots-clés :

- ANGL_NAUT (3 angles nautiques),
- ANGL_EULER (3 angles d'Euler),
- ORIG_AXE et ANGL_AXE (origine et axe du repère cylindrique).

On précise que ANGL_NAUT ou ANGL_EULER sert pour un matériau orthotrope ou isotrope transverse à axes fixes; ORIG_AXE et ANGL_AXE servent pour un matériau orthotrope ou isotrope transverse dont les axes suivent un repère cylindrique et uniquement dans ce cas.

## 2 Syntaxe

```text
cham_elem = DEFI_REPERE(
    ◆ MODELE = modele,
    ◆ DEFI = _F(
         ◆ / TOUT = "OUI" (ou non renseigné),
           / GROUP_MA = list[grma],
         ◆ SYST_COOR = / "CARTESIEN",
                       / "CYLINDRIQUE",
         # Si: equal_to("SYST_COOR", 'CARTESIEN')
             ◆ / ANGL_EULER = list[float],
               / ANGL_NAUT = list[float],
         # Si: equal_to("SYST_COOR", 'CYLINDRIQUE')
             ◇ & ORIG_AXE = list[float],
               & ANGL_AXE = list[float],
      ),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Opérandes

### 3.1 Mot clé MODELE

```text
♦ MODELE = modele,
```

Nom du modèle.

### 3.2 Mot clé DEFI

```text
◆ DEFI = _F(
    ◆ / TOUT = "OUI" (ou non renseigné),
    / GROUP_MA = list[grma],
    ◆ SYST_COOR = / "CARTESIEN",
                / "CYLINDRIQUE",
    # Si: equal_to("SYST_COOR", 'CARTESIEN')
        ◆ / ANGL_EULER = list[float],
        / ANGL_NAUT = list[float],
    # Si: equal_to("SYST_COOR", 'CYLINDRIQUE')
        ◇ & ORIG_AXE = list[float],
        & ANGL_AXE = list[float],
),
```

#### 3.2.1 Opérandes TOUT='OUI', GROUP_MA

Les mot clés TOUT et GROUP_MA permettent de désigner l'ensemble des mailles qui seront affectées.

Si une maille apparaît dans plusieurs occurrences du mot-clé facteur DEFI, la règle de surcharge est appliquée: c’est la dernière affectation qui prime [U2.01.08](doc:u2.01.08).

#### 3.2.2 Opérande SYST_COOR

Le mot clé SYST_COOR permet de choisir le type de système de coordonnées "CARTESIEN" ou "CYLINDRIQUE".

#### 3.2.3 Opérande ANGL_NAUT

Définition des 3 angles nautiques $\alpha$ , $\beta$ , $\gamma$ qui permettent d'orienter les axes locaux $(x,y,z)$  et le repère d’orthotropie $(N,L,T)$. Pour plus d'informations, visitez §10.4 de [U4.42.01](doc:u4.42.01).

#### 3.2.4 Opérande ANGL_EULER

Définition des 3 angles d'Euler $\alpha$ , $\beta$ , $\gamma$ qui permettent d'orienter les axes locaux $(x,y,z)$  et le repère d’orthotropie $(N,L,T)$. Pour plus d'informations, visitez §13.4 de [U4.42.01](doc:u4.42.01).

#### 3.2.5 Opérandes ORIG_AXE/ANGL_AXE

Ces mots clés sont à donner pour définir des axes locaux pour lesquels on utilisera une propriété de symétrie de révolution, ou d’isotropie transverse (par exemple: structure à symétrie cylindrique orthotrope).

En 3D, ANGL_AXE = $(\alpha, \beta)$ définit l’axe de révolution $\mathrm{x1}$, $(\alpha, \beta)$ étant les deux premiers angles nautiques, ORIG_AXE = $(x1 , x2 , x3)$ définit un point $\mathrm{O1}$ de l’axe. Pour plus d'informations, visitez §13.5 de [U4.42.01](doc:u4.42.01).

## 4 Exemples

```python
cham_orie = DEFI_REPERE(
    MODELE=MO,
    DEFI=(
        _F(
            TOUT="OUI",
            SYST_COOR="CARTESIEN",
            ANGL_NAUT=(0, 0, 90),
        ),
        _F(
            GROUP_MA=("GMA1", "GMA2",),
            SYST_COOR="CYLINDRIQUE",
            ORIG_AXE=(0, 0, 0),
            ANGL_AXE=(45, 0),
        ),
        _F(
            GROUP_MA=("GMA3"),
            SYST_COOR="CARTESIEN",
            ANGL_EULER=(0, 45, 0),
        ),
    ),
)
```

Sur l’ensemble des mailles du modèle (sauf les mailles contenues dans les groupes: "GMA1", "GMA2", "GMA3") est affecté un repère CARTESIEN avec un angle nautique $(0, 0, 90)$.

Sur les mailles contenues dans les groupes "GMA1", "GMA2" est affecté un repère CYLINDRIQUE d'origine $(0, 0, 0)$ et angle $(45, 0)$.

Sur les mailles contenues dans les groupes "GM3" est affecté un repère CARTESIEN avec un angle d'Euler $(0, 45, 0)$.
