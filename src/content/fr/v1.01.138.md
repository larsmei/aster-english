# v1.01.138 ZZZZ138 – Validation du partitionneur de maillages

**Résumé:**

Ce cas-test permet de valider les performances du partitionneur parallèle de maillages. Les différentes modélisations testent un nombre différent de cpu et de nœuds utilisés.

Le maillage est composé 20 millions d’hexaèdres à 8 nœuds.

Cette documentation est volontairement succincte.
