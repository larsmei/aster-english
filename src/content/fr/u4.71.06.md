# u4.71.06 Commande EXTR_CONCEPT

**Résumé :**

Permet d'extraire un sous-objet depuis une structure de données de type *dict*.

## 1 Syntaxe

```text
evol_ther = EXTR_CONCEPT(
    ◆ DICT = ds_dict,
    ◆ NOM = text,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 2 Opérandes

Les structures de données de type *dict* ne sont pas des dictionnaires Python mais
leur usage est similaire.

La première structure de données de ce type est *evol_ther_dict* dans laquelle
on stocke un objet de type *evol_ther* associé à une clé d'accès.
C'est seul type actuellement supporté.

La commande EXTR_CONCEPT retourne l'objet stocké pour une clé d'accès donnée.

### 2.1 Mot-clé DICT

Fournit la structure de données de type *dict*.

### 2.2 Mot-clé NOM

Valeur de la clé d'accès.
