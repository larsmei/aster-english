# u4.42.04 Macro-commande DEFI_CABLE_BP

> **Résumé**

L’objectif de cette commande est de calculer les profils initiaux de tension le long des câbles de précontrainte d’une structure béton. Les données du calcul sont la tension appliquée aux extrémités et d’autres paramètres caractéristiques des ancrages et des matériaux. Les relations utilisées sont celles prescrites par le BPEL 91 ou par l’ETCC. Elle permet également de créer des relations cinématiques entre les nœuds de câble et les nœuds de béton dans lequel il est immergé.

Le concept cabl_precont produit peut ensuite être utilisé:

- soit par l’opérateur AFFE_CHAR_MECA [U4.44.01](doc:u4.44.01) opérande RELA_CINE_BP pour définir les chargements mécaniques liés à la présence du câble (relations cinématiques et / ou tension dans les câbles).Ces chargements seront pris en compte par l’opérateur STAT_NON_LINE [U4.51.03](doc:u4.51.03);
- soit par l’opérateur CALC_PRECONT [U4.42.05](doc:u4.42.05) pour une mise en tension progressive des câbles et la possibilité de faire du phasage;
- soit par l’opérateur DEFI_GROUP (CREA_GROUP_NO/OPTION = ’RELA_CINE_BP’) pour créer des groupes de nœuds correspondant aux liaisons créées et permettre une vérification visuelle de ces relations cinématiques.

Produit une Structure de Données de type cabl_precont.

## 1 Syntaxe

```text
cabl_precont = DEFI_CABLE_BP(
    ◆ MODELE = modele,
    ◆ CHAM_MATER = cham_mater,
    ◆ CARA_ELEM = cara_elem,
    ◆ GROUP_MA_BETON = grma,
    ◆ TYPE_ANCRAGE = / "ACTIF",
                     / "PASSIF",
    ◇ ADHERENT = / "OUI" (par défaut),
                 / "NON",
    # Si: (equal_to("ADHERENT", 'OUI'))
        ◆ / DEFI_CABLE = _F(
               ◇ / GROUP_MA = grma,
                 / | TABL_CABLE = table,
                   | GROUP_NO_ANCRAGE = grno,
            ),
          / MODI_CABLE_RUPT = _F(
               ◆ GROUP_MA = grma,
               ◆ GROUP_NO_ANCRAGE = grno,
               ◆ TENSION = table,
            ),
        ◇ TYPE_RELAX = / "SANS" (par défaut),
                       / "BPEL",
                       / "ETCC_DIRECT",
                       / "ETCC_REPRISE",
        # Si: equal_to("TYPE_RELAX", 'BPEL')
            ◆ R_J = float,
        # Si: equal_to("TYPE_RELAX", 'ETCC_DIRECT')
            ◆ NBH_RELAX = float,
        # Si: equal_to("TYPE_RELAX", 'ETCC_REPRISE')
            ◇ MODI_CABLE_ETCC = _F(
                 ◆ GROUP_MA = grma,
                 ◆ GROUP_NO_ANCRAGE = grno,
                 ◆ TENSION = table,
              ),
            ◆ NBH_RELAX = float,
        ◇ CONE = _F(
             ◆ RAYON = float,
             ◆ LONGUEUR = float,
             ◆ PRESENT = / "OUI",
                         / "NON",
          ),
    # Si: (not exists("MODI_CABLE_RUPT"))
        ◆ TENSION_INIT = float,
        ◆ RECUL_ANCRAGE = float,
    # Si: (equal_to("ADHERENT", 'NON'))
        ◆ DEFI_CABLE = _F(
             ◆ GROUP_MA = grma,
             ◆ GROUP_NO_ANCRAGE = grno,
          ),
    ◇ TITRE = text,
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

### 2.5 Définition du câble

#### 2.5.1 Mot-clé DEFI_CABLE [DEFAUT]

```text
DEFI_CABLE
```

Mot-clé facteur permettant la définition d’un câble par désignation des entités topologiques du maillage qui le représentent. Les occurrences multiples sont autorisées, afin de pouvoir définir plusieurs câbles. Les câbles peuvent être définis individuellement ou via la fourniture d’une table (voir test SSNV229a)

```text
/ ♦    GROUP_MA = grmaca
```

Nom du groupe de mailles du maillage représentant le câble.

```text
♦    GROUP_NO_ANCRAGE = l_gnoa
```

Liste de groupes de nœuds définissant les ancrages. Le cardinal de cette liste doit être inférieur ou égal à 2. Dans chaque groupe de nœud, on ne retiendra comme ancrage que le premier nœud du groupe.

```text
/ ♦    TABL_CABLE = table
```

Quand le nombre de câbles est important, il peut être plus facile de les avoir défini via une table contenant 3 colonnes, définissant le groupe de mailles du câbles et le nom des 2 groupes de nœud définissant les ancrages. Les colonnes doivent se nommer GROUP_MA, GROUP_NO1, GROUP_NO2.

Cette table peut être définie en dehors de Code_Aster (Excel, python) et lu avec la commande LIRE_TABLE.

Exemple:

#LISTE CABLE

GROUP_MA GROUP_NO1 GROUP_NO2

CAB1 CAB1_I CAB1_F

CAB3 CAB3_I CAB3_F

```text

```

Mot-clé facteur permettant la définition d’un câble par désignation des entités topologiques du maillage qui le représentent et fournissant pour chacun des câbles la tension initiale à court terme afin de permettre de calculer les pertes par relaxation de l’acier selon l’ETCC ( **câble adhérent uniquement** ). Les occurrences multiples sont autorisées, afin de pouvoir définir plusieurs câbles. Pour l’utiliser, il faut avoir préciser TYPE_RELAX=’ETCC_REPRISE’.

```text
♦    GROUP_MA = grmaca
```

Nom du groupe de mailles du maillage représentant le câble.

```text
♦    GROUP_NO_ANCRAGE = l_gnoa
```

Liste de groupes de nœuds définissant les ancrages. Le cardinal de cette liste doit être inférieur ou égal à 2. Dans chaque groupe de nœud, on ne retiendra comme ancrage que le premier nœud du groupe.

```text
♦    TENSION = table
```

Table contenant la tension dans le câble pour toutes les abscisses curvilignes (table à 2 colonnes). Cette table est utilisée pour calculer les pertes par relaxation de l’acier dans le cas où l’utilisateur a opté pour l’option TYPE_RELAX = ’ETCC_REPRISE’. Cette table est obtenue via un POST_RELEVE_T sur les nœuds du câble étudié, après un premier calcul statique.

Ce mot-clé permet de contourner le calcul de tension en récupérant la table fournie sous le mot-clé TENSION. La technique permet de simuler la rupture d’un câble avec réancrage ( **câble adhérent uniquement** ).

Les occurrences multiples sont autorisées, afin de pouvoir définir plusieurs câbles.

```text
♦    GROUP_MA = grmaca
```

Nom du groupe de mailles du maillage représentant le câble.

```text
♦    GROUP_NO_ANCRAGE = l_gnoa
```

Liste de groupes de nœuds définissant les ancrages. Le cardinal de cette liste doit être inférieur ou égal à 2. Dans chaque groupe de nœud, on ne retiendra comme ancrage que le premier nœud du groupe.

```text
♦    TENSION = table
```

Table contenant la tension dans le câble pour toutes les abscisses curvilignes (table à 2 colonnes) et qui va devenir la tension de référence. Cette table est obtenue via un POST_RELEVE_T sur les nœuds du câble étudié après un premier calcul puis modifiée comme le souhaite l’utilisateur.

### 2.6 Opérande ADHERENT

```text
♦    ADHERENT =    / ’OUI’            [DEFAUT]
/ ’NON’
```

Ce mot-clé permet d’indiquer si on souhaite modéliser des câbles adhérents au béton (ADHERENT = ’OUI’) ou des câbles glissants ou frottants (ADHERENT = ’NON’). Pour les cas non adhérents, il faut utiliser pour représenter les acier la modélisation CABLE_GAINE et la loi de comportement CABLE_GAINE_FROT. Le cas adhérent peut être simulé avec les modélisation BARREou CABLE_GAINE.

**Remarque:**

Dans le cas ADHERENT = ’NON’, le profil de tension est calculé même s’il n’est pas utilisé par la suite (ni dans AFFE_CHAR_MECA/RELA_CINE_BP, *ni dans*  CALC_PRECONT).

### 2.7 Opérande TYPE_ANCRAGE

```text
♦    TYPE_ANCRAGE = l_tya
```

Liste d’arguments de type texte caractérisant les ancrages du câble: ‘ACTIF’ ou ‘PASSIF’ (seuls arguments licites). Cette liste doit comporter 2 arguments, ni plus ni moins, et doit être ordonnée en regard de la liste des nœuds définissant les ancrages (opérande GROUP_NO_ANCRAGE ci-dessus). À noter que si plusieurs câbles sont définis dans DEFI_CABLE alors le premier argument de TYPE_ANCRAGE s’applique à tous les premiers nœuds qui définissent les ancrages. *Idem*  pour le deuxième argument.

**Remarques:**

*1- L’opérateur reconstitue le chemin connexe menant du premier au second ancrage du câble en parcourant les mailles qui le représentent. La non-existence d’un chemin connexe entre les deux ancrages provoque un arrêt du programme en erreur fatale.*

*2- Les ancrages actifs sont ceux où l’on applique une tension initiale.*

### 2.10 Choix du type de calcul pour la prise en compte de la relaxation des aciers

◊    TYPE_RELAX    =    /'SANS',                            [DEFAUT]

```text
/'BPEL',
/'ETCC_DIRECT',
/'ETCC_REPRISE',
```

Mot-clé permettant de définir si on prend en compte ou non, les pertes de tension par relaxation de l’acier par la méthode réglementaire, et si oui laquelle (ETCC ou BPEL). Ce mot-clé facteur étant facultatif, par défaut les pertes de tension par relaxation de l’acier ne sont pas prises en compte.

#### 2.10.1 TYPE_RELAX='SANS'

Il s’agit de la valeur par défaut. Dans ce cas, on ne prend pas en compte ce type de perte par une méthode réglementaire. En revanche, on peut la prendre en compteen utilisant la loi de comportement viscoélastique RELAX_ACIER pour le câble (cf. [R5.03.09](doc:r5.03.09)).

#### 2.10.2 TYPE_RELAX=’BPEL’

Dans ce cas, la formule du BPEL est appliquée, et le mot-clé R_J doit être renseigné (cf. § 2.11  pour le détail).

#### 2.10.3 TYPE_RELAX=’ETCC_DIRECT’

Dans ce cas, la formule de l’ETCC est appliquée, mais l’effort utilisé ne prend en compte que les pertes par frottement et par recul d’ancrage (cf. §  4 ).

Il est nécessaire de renseigner le mot-clé NBH_RELAX (cf. § 2.12  ).

#### 2.10.4 TYPE_RELAX=’ETCC_REPRISE’

Dans ce cas, la formule exacte de l’ETCC est appliquée. Cela implique de faire un premier calcul sans relaxation et de récupérer la tension dans le câble. Ensuite il convient de définir le câble en fonction de MODI_CABLE_ETCC au lieu de DEFI_CABLE.

Il est nécessaire de renseigner le mot-clé NBH_RELAX (cf. § 2.12  ).

### 2.11 Opérande R_J

◊    R_J = $\mathit{rj}$

Paramètre à renseigner uniquement si TYPE_RELAX=’BPEL’.

Valeur de la fonction adimensionnelle $r(j)$ caractérisant l’évolution de la relaxation de l’acier dans le temps et uniquement de l’acier (ce coefficient ne s’applique pas aux pertes par fluage ou retrait du béton renseigné sous BPEL_BETON dans DEFI_MATERIAU); par exemple le BPEL 91 recommande:

$r(j)=\frac{j}{j+9\times {r}_{m}}$ avec $j$ en jours

et ${r}_{m}=\frac{\text{aire de la section de béton}}{\text{périmètre de la section de béton}}\equiv \text{rayon moyen}$

Cette valeur doit être positive ou nulle.

$j$ correspond à la date (en jours) pour laquelle on veut estimer l’état de contrainte dans la structure. Pour le cas où, dans le calcul de structures, les barres seraient modélisées avec un comportement de type fluage, il ne faut pas renseigner ce mot-clé dans DEFI_CABLE_BP.

### 2.12 Opérande NBH_RELAX

◊    NBH_RELAX = $\mathit{nh}$

Paramètre à renseigner uniquement si TYPE_RELAX=’ETCC_DIRECT’ ou ’ETCC_REPRISE’.

Temps considéré pour la prise en compte des pertes par relaxation de l’acier dans l’ETCC, exprimé en nombre d’heures.

La formule appliquée est la suivante:

$\Delta {F}_{\mathit{pr}}=0,66.{\rho}_{1000}.{e}^{9,1\frac{\tilde{F}(s)}{{P}_{\mathit{pk}}}}.{\left(\frac{\mathit{nh}}{1000}\right)}^{0,75(1-\tilde{F}(s)/{P}_{\mathit{pk}})}.{10}^{-5}\tilde{F}(s)$

où:

${\rho}_{1000}$ est la valeur du coefficient de relaxation de l’acier à 1000 heures en %, renseignée sous ETCC_ACIER.

${P}_{\mathit{pk}}$ est la tension maximale de l’acier à rupture, calculée à partir de la donnée de F_PRG sous ETCC_ACIER.

$\tilde{F}$ est égale à la tension calculée selon l’ETCC en prenant en compte les pertes par frottement et par recul d’ancrage si TYPE_RELAX=’ETCC_DIRECT’ ou la tension fournie par l’utilisateur sous MODI_CABLE_ETCC/TENSION dans l’autre cas.

## 3 Complément théorique : estimation des pertes de tension dans un câble de précontrainte suivant les prescriptions du BPEL

Dans le cas où l’utilisateur a défini les caractéristiques matériaux BPEL_BETON et BPEL_ACIER, l’évolution de la tension (en Newton) le long d’un câble de précontrainte est calculée en utilisant les relations prescrites par le BPEL. Ces relations sont les suivantes.

### 3.1 Évolution de la tension au voisinage de l’ancrage

La tension s'écrit:

$$
F(s)=\tilde{F}(s)-\lbrace {x}_{\mathit{flu}}\times {F}_{0}+{x}_{\mathit{ret}}\times {F}_{0}+r(j)\times \frac{5}{100}\times {\rho}_{1000}\left[\frac{\tilde{F}(s)}{{S}_{a}\times {\sigma}_{y}}-{\mu}_{0}\right]\times \tilde{F}(s)\rbrace
$$

où $s$ désigne l’abscisse curviligne le long du câble. Les paramètres introduits dans cette expression sont:

| ${F}_{0}$ | tension initiale (N); |
| --- | --- |
| ${x}_{\mathrm{flu}}$ | taux forfaitaire de perte de tension par fluage du béton, par rapport à la tension initiale; |
| ${x}_{\mathrm{ret}}$ | taux forfaitaire de perte de tension par retrait du béton, par rapport à la tension initiale; |
| ${\rho}_{1000}$ | relaxation de l’acier à 1000 heures, exprimée en %; |
| ${S}_{a}$ | aire de la section droite du câble définie dans AFFE_CARA_ELEM; |
| ${\sigma}_{y}$ | contrainte limite élastique de l’acier; |
| ${\mu}_{0}$ | coefficient adimensionnel de relaxation de l’acier précontraint. |

$r(j)$ est une fonction adimensionnelle caractérisant l’évolution de la relaxation dans le temps:

$r(j)=\frac{j}{j+9\times {r}_{m}}$ avec j en jours et ${r}_{m}=\frac{\text{aire de la section de béton}}{\text{périmètre de la section de béton}}\equiv \text{rayon moyen}$

La fonction $r(j)$ dépendant de la géométrie de la structure, la valeur utilisée est définie dans l’opérateur DEFI_CABLE_BP.

$\tilde{F}(s)$ est l’évolution de la tension au voisinage de l’ancrage après prise en compte de la perte par recul d’ancrage et des pertes par contact entre le câble et le béton.

$\tilde{F}(s)$ est définie par la relation: ${F}_{c}(s)\times \tilde{F}(s)={\left[{F}_{c}(d)\right]}^{2}$

${F}_{c}(s)$ désigne l’évolution de la tension le long du câble après prise en compte des pertes par contact entre le câble et le béton: ${F}_{c}(s)={F}_{0}\exp\left(-f\alpha -\varphi s\right)$

$\alpha$ désigne la déviation angulaire cumulée et les paramètres introduits dans l’expression de son ${F}_{c}(s)$ t:

$f$ coefficient de frottement entre le câble et la gaine en partie courbe, en rad–1;

$\varphi$ coefficient de frottement entre le câble et la gaine en m-1.

**Remarques:**

- *Les coefficients* $f,\varphi ,{\rho}_{1000,}{\sigma}_{y},{\mu}_{0}$ *sont à renseigner dans l’opérateur* *DEFI_MATERIAU sous le mot-clé* *BPEL_ACIER,*
- ${x}_{\mathit{flu}}$ *et* ${x}_{\mathit{ret}}$ *sont à renseigner dans l’opérateur* *DEFI_MATERIAU sous le mot-clé* *BPEL_BETON.*

La longueur $d$ intervenant dans l’expression de $\tilde{F}(s)$ est la longueur sur laquelle s’applique la perte de tension par recul à l’ancrage. Cette longueur est estimée à l’aide de la relation:

$$
{E}_{a}{S}_{a}\Delta ={\int}_{0}^{d}\left({F}_{c}(s)-\tilde{F}(s)\right)\mathit{ds}
$$

où ${E}_{a}$ est le module d’Young de l’acier et $\Delta$ la valeur du recul à l’ancrage. Ainsi ${E}_{a}{S}_{a}\Delta$ représente l’énergie de déformation (du câble) due au recul à l’ancrage.

### 3.2 Évolution de la tension au-delà de la longueur où s’appliquent les pertes de tension par recul à l’ancrage

Cette tension s'écrit:

$$
F(s)={F}_{c}(s)-\lbrace {x}_{\mathit{flu}}\times {F}_{0}+{x}_{\mathit{ret}}\times {F}_{0}+r(j)\times \frac{5}{100}\times {\rho}_{1000}\left[\frac{\tilde{F}(s)}{{S}_{a}\times {\sigma}_{y}}-{\mu}_{0}\right]\times \tilde{F}(s)\rbrace
$$

avec les mêmes notations que celles introduites au paragraphe précédent.

## 4 Complément théorique : estimation des pertes de tension dans un câble de précontrainte suivant les prescriptions de l’ETCC

Dans le cas où l’utilisateur a défini les caractéristiques matériaux ETCC_BETON et ETCC_ACIER, l’évolution de la tension (en Newton) le long d’un câble de précontrainte est calculée en utilisant les relations prescrites par l’ETCC. Toutefois les pertes dues à la déformation élastique du béton et aux déformations dues au retrait et au fluage du béton ne sont pas prises en compte dans le calcul. Il convient si on veut les prendre en compte:

- de tendre les câbles en 2 familles pour récupérer les pertes dues à la déformation élastique du béton

  - d’imposer au béton les déformations de retrait et de fluage, après la mise en tension des câbles.

Les relations implantées sont les suivantes.

### 4.1 Évolution de la tension au voisinage de l’ancrage

Elle s'écrit:

$$
F(s)=\tilde{F}(s)-0,8\Delta {F}_{\mathit{pr}}(s)
$$

avec

$\tilde{F}(s)$ est l’évolution de la tension au voisinage de l’ancrage après prise en compte de la perte par recul d’ancrage et des pertes par contact entre le câble et le béton.

$\tilde{F}(s)$ est définie par la relation: ${F}_{c}(s)\times \tilde{F}(s)={\left[{F}_{c}(d)\right]}^{2}$

${F}_{c}(s)$ désigne l’évolution de la tension le long du câble après prise en compte des pertes par contact entre le câble et le béton: ${F}_{c}(s)={F}_{0}{\exp}^{-\mu (\alpha +ks)}$

$\alpha$ désigne la déviation angulaire cumulée et les paramètres introduits dans l’expression de son ${F}_{c}(s)$  sont:

- $\mu [:ref:`{\mathit{rad}}^{-1} <{\mathit{rad}}^{-1}>$]` le coefficient de frottement entre le câble et la gaine ;

$k[{\mathit{rad}}^{-1}.{m}^{-1}]$ le coefficient de perte en ligne.

La longueur $d$ intervenant dans l’expression de $\tilde{F}(s)$ est la longueur sur laquelle s’applique la perte de tension par recul à l’ancrage. Cette longueur est estimée à l’aide de la relation:

$$
{E}_{a}{S}_{a}\Delta ={\int}_{0}^{d}({F}_{c}(s)-\tilde{F}(s))\mathrm{ds}
$$

où

${E}_{a}$ est le module d’Young de l’acier et $\Delta$ la valeur du recul à l’ancrage. Ainsi ${E}_{a}{S}_{a}\Delta$ représente l’énergie de déformation (du câble) due au recul à l’ancrage.

$\Delta {F}_{\mathit{pr}}$ sont les pertes dues à la relaxation des câbles, estimées par la formule suivante

$$
\Delta {F}_{\mathit{pr}}(s)=0,66.{\rho}_{1000}.{e}^{9,1\frac{\tilde{F}(s)}{{P}_{\mathit{pk}}}}.{\left(\frac{\mathit{nh}}{1000}\right)}^{0,75(1-\tilde{F}(s)/{P}_{\mathit{pk}})}.{10}^{-5}\tilde{{F}_{(s)}}
$$

$s$ désigne l’abscisse curviligne le long du câble. Les paramètres introduits dans cette expression sont:

| ${\rho}_{1000}$ | Relaxation de l’acier à 1000 heures, exprimée en %. |
| --- | --- |
| ${P}_{\mathit{pk}}$ | Force à rupture dans l’acier (calculée à partir du paramètre F_PRGrenseigné dans DEFI_MATERIAU/ETCC_ACIER) |
| $\mathit{nh}$ | Le nombre d’heures après la mise en précontrainte à laquelle les pertes sont calculées. |

**Remarques:**

- *Les coefficients* $\mu ,k,{\rho}_{1000,}{F}_{\mathit{prg}}$ *sont à renseigner dans l’opérateur* *DEFI_MATERIAU sous le mot-clé* *BPEL_ACIER,*
- $\mathit{nh}$ *est à renseigner dans l’opérateur* *DEFI_CABLE_BP.*

### 4.2 Évolution de la tension au-delà de la longueur où s’appliquent les pertes de tension par recul à l’ancrage

On écrit la relation suivante:

$$
F(s)={F}_{c}(s)-0,8\ast 0,66{\rho}_{1000}.{\exp}^{9,1{F}_{c}(s)/{F}_{\mathit{prg}}}.{\left(\frac{\mathit{nh}}{1000}\right)}^{0,75(1-{F}_{c}(s))/{F}_{\mathit{prg}}}.{10}^{-5}{F}_{c}(s)
$$

Avec les mêmes notations que celles introduites au paragraphe précédent.
