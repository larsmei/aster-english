# v1.01.279 ERREU05 - Vérification de la récupération des erreurs fatales dans STAT_NON_LINE

**Résumé:**

Ce test valide la récupération des erreurs fatales dans STAT_NON_LINE et la possibilité de faire une poursuite à partir d'une base obtenue en sortie d'une étude ayant stoppée en erreur.

## 1 Principe du test

Ce test est un test informatique. Il se déroule en deux phases :

- Dans un premier temps, le cas test réalise un premier STAT_NON_LINE au cours duquel une erreur se produit (problème d'interpolation d'une fonction). Cette erreur est interceptée et la base du test est correctement fermée.
- Dans un second temps, une POURSUITE est effectuée en utilisant la base produite lors du premier calcul.
