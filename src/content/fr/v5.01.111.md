# v5.01.111 SDND111 - DIS_CHOC,  avec contact géré dans le repère global, en dynamique non-linéaire

**Résumé :**

L’objectif de ce test est de vérifier le contact dans le repère global pour les discrets de type `K_T_D_L` et `K_TR_D_L` en dynamique non linéaire.

## 1 Problème de référence

### 1.1 Géométrie A

La géométrie est présentée à la figure ci-dessous :

![Figure](/figures/v5.01.111/v5.01.111_schema_01.png)

*Géométrie du problème de référence.*

La géométrie est constituée de :

- 10 discrets de type `DIS_T_D_N`. Quatre solides indéformables sont représentés par 4 $\color{red}{\blacklozenge}$ et 1 $\color{green}{\blacklozenge}$, qui sont reliés avec une `LIAISON_SOLIDE`. Les $\color{red}{\blacklozenge}$ sont des `DIS_T_D_N`, les $\color{green}{\blacklozenge}$ sont des `DIS_TR_D_L`.
- 2 discrets de type `DIS_T_D_L` pour représenter les discrets de choc $\color{blue}{━━━}$ dans le repère global.
- 8 discrets de type `DIS_T_D_L` pour représenter les discrets de choc $\color{fuchsia}{━━━}$ dans leur repère local.

Les centres des 4 solides indéformables représentés par un $\color{green}{\blacklozenge}$ sont affectés par un `DIS_TR_D_L` dont un des noeuds est encastré, l'autre étant relié à 4 $\color{red}{\blacklozenge}$.
