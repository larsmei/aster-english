# v1.01.117 ZZZZ314 – Validation du calcul de l’objet .BASLOC pour les entailles

**Résumé:**

Dans le cadre du chantier de rénovation des opérateurs CACL_G et DEFI_FOND_FISS, ce test a pour but de valider de manière élémentaire l'opérateur de travail DEFI_FISSURE dans le cas d'un structure contenant une fissure maillée en configuration décollée (CONFIG_INIT='DECOLLEE'). Ce test n'a pas forcément de signification physique, c'est essentiellement un test informatique.

Le cas-test consiste à tester les vecteurs de la base locale au fond de fissure suivant différentes configurations de DEFI_FISSURE.

*Cas d'un fond de fissure rectiligne*  :

Modélisation A :

- Maillage $\mathrm{2D}$ .

Cette documentation est volontairement succincte.
