# v3.02.307 SSLP307 - Plaque mince dont les deux bords opposés sont en appui simple

**Résumé:**

Le test a pour but de valider l'élément créé automatiquement à partir de Fenicsx basé sur la théorie de Reissner-Mindlin et la procédure MITC (en anglais, Mixed Interpolation of Tensorial Component).

La solution de référence est analytique.

Le nouvel élément fini PLAQ_MITC (discrétisé avec QUAD9 et TRI6) est comparé avec l'élément DST.

## 1 Problème de référence

### 1.1 Géométrie

![Figure](/figures/v3.02.307/probleme_reference.svg)

Fig: Schéma du problème de référence

La plaque fine est définie par $\Omega=[0,L]\times[0,L]\times[-h/2,h/2]$ où

Longueur : $L = 1 \mathrm{m}$

Épaisseur : $h = 0.001 \mathrm{m}$

### 1.2 Propriétés de matériaux

Module d’Young: $E = 1 \mathrm{MPa}$

Coefficient de Poisson: $\nu = 0.3$

### 1.3 Conditions aux limites et chargements

- Support simple sur deux arêtes opposées ($w=0$ à $x=0$ et $x=L$)
- Bords libres sur les autres deux arêtes
- Charge surfacique constante :

$$
f(x,y) = \frac{E h^{3}}{12 (1 - \nu^{2})}
$$

### 1.4 Conditions initiales

Sans objet pour l’analyse statique.

## 3 Modélisation A

### 3.1 Caractéristiques de la modélisation

C’est une modélisation PLAQ_MITC faite via fenicsx.

Le maillage de $\Omega=[0,1]^2$ est directement construit par :

```python
mesh = CA.Mesh.buildSquare(refine=FINE_REFINEMENT)
```

Conditions limites:

sur les bords : $\lbrace 0, 1\rbrace\times[0, 1]$:

```python
MECA_IMPO=_F(DZ=0, GROUP_MA=("LEFT", "RIGHT"))
```

**Remarque:**

A présent, PLAQ_MITC ne considère que la mouvement de type COQUE et on n'impose donc pas les déplacements DX, DY, DRZ.

Chargement:

```python
PRES_REP=_F(GROUP_MA="SURFACE", PRES=PRES)
```

où PRES est une CONSTANTE qui ne dépend que de l'épaisseur problème de référence.
