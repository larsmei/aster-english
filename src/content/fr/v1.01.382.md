# v1.01.382 ZZZZ382 - Validation de CALC_CHAMP sur des poutres avec champs complexes

**Résumé:**

Ce test n'a aucune signification physique, c'est essentiellement un test informatique.

En présence de modes complexes sur base modale (mode_meca_c), CALC_CHAMP n'autorise pas le calcul. Par contre si la base modale est restituée sur base physique, alors CALC_CHAMP accepte les modes complexes.

Le but de ce test est donc de valider CALC_CHAMP sur des poutres en présence de champs complexes.

Cette documentation est volontairement succincte.
