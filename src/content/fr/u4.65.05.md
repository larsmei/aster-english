# u4.65.05 Opérateur ASSE_VECT_GENE

## 1 But

Projeter les chargements sur la base modale d’une sous-structure.

Dans le cadre d’un calcul harmonique utilisant les méthodes de sous-structuration, l’opérateur ASSE_VECT_GENE effectue la projection des chargements de type cham_no_DEPL_R issus de ASSE_VECTEUR [U4.61.23](doc:u4.61.23), sur la base modale de la sous-structure définie par DEFI_BASE_MODALE [U4.64.02](doc:u4.64.02). Les vecteurs généralisés ainsi obtenus sont assemblés à partir de la définition du modèle généralisé issu de DEFI_MODELE_GENE [U4.65.02](doc:u4.65.02). Le vecteur généralisé assemblé final est construit sur la numérotation des degrés de liberté généralisés établie au préalable par l’opérateur NUME_DDL_GENE [U4.65.03](doc:u4.65.03).

Le concept résultat produit par cet opérateur est de type vect_asse_gene.

## 2 Syntaxe

```text
vect_asse_gene = ASSE_VECT_GENE(
    ◆ NUME_DDL_GENE = nume_ddl_gene,
    ◇ METHODE = / "CLASSIQUE" (par défaut),
                / "INITIAL",
    # Si: equal_to("METHODE", 'CLASSIQUE')
        ◆ CHAR_SOUS_STRUC = _F(
             ◆ SOUS_STRUC = text,
             ◆ VECT_ASSE = cham_no,
          ),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Opérandes

### 3.1 Opérande NUME_DDL_GENE

```text
♦     NUME_DDL_GENE= nu_gene
```

Nom du concept nume_ddl_gene issu de l’opérateur NUME_DDL_GENE [U4.65.03](doc:u4.65.03) qui définit la numérotation de degrés de liberté à utiliser pour le vecteur généralisé assemblé.

### 3.2 Opérande METHODE

◊ METHODE= ‘CLASSIQUE’, ‘INITIAL’

Type de méthode utilisée pour l’assemblage des matrices. La méthode ‘INITIAL’ permet d’initialiser un vecteur nul de type vect_asse_gene que l’on peut remplir par des méthodes python. Cette méthode a été créée pour le développement.

### 3.3 Mot clé CHAR_SOUS_STRUC

```text
♦    CHAR_SOUS_STRUC
```

Mot clé facteur permettant de définir les chargements appliqués à la structure. La définition du chargement se fait par la donnée du vecteur assemblé qui lui est associé et du nom de la sous‑structure sur laquelle il s’applique.

#### 3.3.1 Opérande SOUS_STRUC

```text
♦    SOUS_STRUC= ’nom_sstruc’
```

Nom de la sous-structure sur laquelle le chargement est appliqué. Elle doit avoir été définie au préalable par l’opérateur DEFI_MODELE_GENE [U4.65.02](doc:u4.65.02).

#### 3.3.2 Opérande VECT_ASSE

```text
♦    VECT_ASSE= vecas
```

Nom du concept cham_no_DEPL_R issu de ASSE_VECTEUR [U4.61.23](doc:u4.61.23) qui définit la répartition spatiale du chargement appliqué à la sous-structure.
