# v1.01.515 ZZZZ515 - Test élémentaire de la macro-commande CALC_ENDO

Ce test n'a aucune signification physique, c'est un test informatique. Il a pour vocation de tester la la macro-commande `CALC_ENDO`, en présence des éléments finis de structure usuellement utilisés en GC.

Les fonctionnalités examinées sont :

- Modélisation A : options avancées de `CALC_ENDO`
- Modélisation B : options et paramètres par défaut
- Modélisation C : mot-clé `ARRET = "NON"`
- Modélisation D : enchainement de plusieurs `CALC_ENDO` et état initial
- Modélisation E : chargements de type `DIDI`

Cette documentation est volontairement succincte.
