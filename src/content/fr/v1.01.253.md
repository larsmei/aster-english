# v1.01.253 ZZZZ253 – Calcul non linéaire mécanique avec changement de maillage

**Résumé:**

Ce test n'a aucune signification physique, c'est essentiellement un test informatique.

Modélisation A:

Dans cette modélisation on souhaite vérifier la possibilité d'effectuer un calcul mécanique en le commençant sur un maillage et en le terminant sur un autre.

Les résultats de référence sont donnés par le même calcul fait uniquement sur le premier maillage ainsi que uniquement sur le second maillage.

Le changement de maillage se fait à l'aide de la commande PROJ_CHAMP avec la méthode COLLOCATION.

Cette documentation est volontairement succincte.
