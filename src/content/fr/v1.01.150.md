# v1.01.150 ZZZZ150 - Validation de l'opérateur IMPR_FONCTION

**Résumé:**

L'objectif de ce cas-test est de valider l'impression de fonctions et de nappes via l'opérateur IMPR_FONCTION avec les mots clés FONCTION , FONC_X et FONC_Y. Dans ce cas-test, on définit plusieurs fonctions (DEFI_FONCTION) et plusieurs nappes (DEFI_NAPPE) que l'on imprime dans un fichier aux formats suivants:

- RESULTAT
- XMGRACE

Pour tester le contenu des fichiers résultats, on utilise la commande TEST_FICHIER qui est basée sur une somme de contrôle md5.

Cette documentation est volontairement succincte.
