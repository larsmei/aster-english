# v5.01.126 SDND126 - Validation de DIS_ECRO_CINE dans DYNA_VIBRA

**Résumé :**

L'opérateur DYNA_VIBRA dispose d'un mot-clé COMPORTEMENT permettant de traiter des non-linéarités localisées.
Une de ces non-linéarités consiste à imposer la loi de comportement DIS_ECRO_CINE sur une maille portant un élément discret.
L'objectif de ce test est de valider cette utilisation en comparant les résultats avec l'opérateur DYNA_NON_LINE.
Dans ce test, il s'agit d'un système masse-ressort soumis à des chargements sinusoïdaux sur les différents degrés de liberté.
Il y a 4 modélisations :

- Modélisation A : DIS_TR/SEG2
- Modélisation B : DIS_T/SEG2
- Modélisation C : DIS_TR/POI1
- Modélisation D : DIS_T/POI1

Cette documentation est volontairement succincte.

Dans ce qui suit on présente seulement les courbes de déplacements des différents degré de liberté en comparant les résultats obtenus par DYNA_NON_LINE et DYNA_VIBRA. Pour information, on trace également le comportement élastique correspondant.
À noter que les résultats issus de DYNA_VIBRA se rapprochent toujours plus de ceux de DYNA_NON_LINE à mesure que l'on réduit le pas de temps.
