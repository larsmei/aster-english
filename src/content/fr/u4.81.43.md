# u4.81.43 Opérateur CALC_PRESSION

## 1 But

Compléter un résultat en calculant un champ nodal correspondant à la densité des efforts normaux et tangentiels d'interface sur une zone définie. L'amplitude de ces efforts est stocké dans le champ produit PRES_NOEU sur la grandeur PRES_R avec les noms des composants PRES et CISA. Les vecteurs de la force tangentielle sont stockées dans les composants VX, VY et VZ.

Ce champ est calculé à partir du tenseur des contraintes de Cauchy et du champ de normales à la surface considérée. La pression de contact calculée correspond alors à:

$$
p=\transpose{\normal} \tensTwo{\sigma} \normal
$$

où $normal$ est la normale à la surface considérée et $tensTwo{sigma}$ le tenseur des contraintes de Cauchy. Ce champ peut être utile pour accéder à l'état de contrainte à l'interface dans différents problèmes de mécanique (contact, mécanique de la rupture …).

On en déduit l'effort tangentiel en projetant l'effort de contact sur le plan tangentiel :

$$
\vector{s} = (\tensTwo{\sigma} - p \tensTwoUnit).\normal
$$

L'effort tangentiel sera utile pour justifier le raffinement du maillage et le modèle de calcul. En cas du contact avec frottement, le rapport entre l'effort d'adhérence et la pression de contact ne doit pas dépasser le coefficient de frottement. En cas du contact sans frottement, l'effort tangentiel est censé être nul.

A l'heure actuelle, la densité d'effort tangentielle calculée par la commande n'a été validée qu'en 2D (cf. [V6.03.154](doc:v6.03.154)). En 3D, le calcul n'est pas restitué car il n'y a pas de tests de vérification disponibles.

## 2 Syntaxe

```text
/ evol_elas
/ evol_noli = CALC_PRESSION(
    ◆ reuse = <objet de RESULTAT>,
    ◆ RESULTAT = evol_elas / evol_noli,
    ◆ GROUP_MA = list[grma],
    ◆ / INST = list[float],
      / TOUT_ORDRE = "OUI" (ou non renseigné),
    ◇ GEOMETRIE = / "DEFORMEE" (par défaut),
                  / "INITIALE",
    ◇ CRITERE = / "ABSOLU",
                / "RELATIF" (par défaut),
    # Si: (equal_to("CRITERE", 'RELATIF'))
        ◇ PRECISION = float (défaut: 1e-06),
    # Si: (equal_to("CRITERE", 'ABSOLU'))
        ◆ PRECISION = float,
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Opérandes

### 3.1 Opérande RESULTAT

```text
♦ reuse = resu
```

On renseigne la structure de donnée résultat à enrichir. Il est issu de la résolution du problème mécanique considéré.

### 3.2 Opérande GROUP_MA

```text
♦ GROUP_MA = l_grma
```

On renseigne la liste des groupes de mailles définissant les interfaces considérées.

Dans le cas de facettes plongées dans le volume, l'utilisateur a la possibilité grâce à la commande MODI_MAILLAGE / ORIE_PEAU_3D / GROUP_MA_VOLU ou MODI_MAILLAGE / ORIE_PEAU_2D / GROUP_MA_SURF de réorienter correctement la normale.

### 3.3 Opérandes TOUT_ORDRE/INST

```text
♦ TOUT_ORDRE = 'OUI',
```

Ce mot clé permet de calculer le champ de pression pour tous les numéros d'ordre.

```text
♦ INST = l_inst,
```

On renseigne une liste des instants de calcul considérés pour le post-traitement.

### 3.4 Opérandes PRECISION / CRITERE

L’emploi de ces deux mots-clés est décrit dans le document [U4.71.00](doc:u4.71.00).

### 3.5 Opérandes GEOMETRIE

```text
♦ GEOMETRIE = / 'DEFORMEE',      [DEFAUT]
              / 'INITIALE'
```

On renseigne la configuration sur laquelle le champ de normale est calculé, ce mot clé est obligatoire.

### 3.6 Opérande INFO

```text
◊ INFO =  /1,     [DEFAUT]
          /2,
```

Niveau d'impression.
