# v1.01.407 ZZZZ407 – Validation de MACR_CARA_POUTRE avec TABLE_CARA='OUI'

**Résumé:**

1. Ce cas test permet de vérifier que les messages d’alarmes ou d’arrêt sont opérationnels lorsque l'on utilise la table produite par MACR_CARA_POUTRE, option TABLE_CARA=‘OUI’.

- message d’arrêt lorsque certaines des valeurs sont négatives ou nulles : A, IY, IZ, AY, AZ, JX, JG.
- messages d’alarmes lorsque :

◦    Les coordonnées du centre de gravité de la section ne sont pas l’origine du maillage.

◦    Le repère principal d'inertie est tourné par rapport aux axes du maillage.

1. Ce cas test permet également de vérifier que les informations issues des messages précédents, utilisées dans la commande DEFI_GEOM_FIBRE,permettent de translater et de tourner le maillage pour que les axes principaux d’inertie soient les axes du maillage.
