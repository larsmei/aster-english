# v3.01.002 SSLL02 - Poutre courte sur deux appuis articulés

**Résumé:**

Le test statique en élasticité linéaire sert à valider les éléments de poutre droite POU_D_T.

Ce cas test concerne une poutre courte sur deux appuis articulés.

On teste les flèches en comparant des résultats de simulation avec la solution de référence AFNOR (ref. ) ainsi que ceux obtenus avec le logiciel Pipestress.
