# v1.01.501 ZZZZ501 – Test des suppression des objets

**Résumé**

Ces modélisations testent des extensions Python et des suppressions des objets.

## 1 Problème de référence

Sans objet.

## 2 Solution de référence

Il s'agit d'un test de fonctionnement. Il n'y a pas d'incertitude sur le comportement attendu.

## 3 Modélisation A

On teste dans cette modélisation des extensions Python autour du maillage, ainsi que leurs suppressions.

## 4 Modélisation B

On teste dans cette modélisation des extensions Python autour du maillage, ainsi que leurs suppressions, avec une fonction Python définie pour retourner le nom d’objet TCO.

## 5 Modélisation C

On teste dans cette modélisation l’existence de l’objet C++ du maillage après la suppression de l’objet du maillage, car il est référé à l’objet du modèle.
