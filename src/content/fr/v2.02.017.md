# v2.02.017 SDLL17 - Large poutre courbée fixée sur les deux extrémités

**Résumé:**

Cette étude vise à réaliser une analyse modale spectrale sur un réseau de tuyauterie d’après les données d’entrée spécifiées du test N°06 dans le document NUREG/CR-1677 BNL-NUREG-51267 vol.1

La tuyauterie est modélisée par des éléments de poutre de Timoshenko à section circulaire. L’ensemble de la tuyauterie repose sur plusieurs appuis élastiques. Le système est soumis à quelques masses ponctuelles.

![Figure](/figures/v2.02.017/10000201000002810000021638483942C419489E.png)

Le modèle et l’analyse modale sont générés à partir du module BEAM de salome_meca 2020 tandis que le calcul modal spectral est effectué à l’aide de Code-Aster.

## 2 Modélisation A

### 2.1 Caractéristiques de la modélisation

Une analyse modale est réalisée en prenant en compte les masses, rigidité. Par la suite, la réponse dynamique est obtenu par l’opérateur «COMB_SISM_MODAL». Pour cette étude, la combinaison choisie est la combinaison avec règle des 10% soit COMB_MODE/TYPE = ‘DPC’. Pour rappel, pour ce type de combinaison les modes voisins (dont les fréquences différentes de moins de 10%) sont d’abord combinés par sommation des valeurs absolues. Les valeurs résultant de cette première combinaison sont ensuite combinées quadratiquement. La combinaison retenue suivant les directions est la combinaison quadratique (COMB_DIRECTION/TYPE=’QUAD’).

### 2.4 Remarques

> Pour cette étude, les unités de départ sont en impérial (lb, inch, psi), une conversion en unité S.I a été réalisée. Certains écarts sont de l’ordre de 30% sont notamment liés à la formulation entre les éléments poutres courbées utilisés dans le logiciel EPIPE de NUREG et les éléments poutres droites de aster.

### 2.5 Incertitudes sur la solution

Conversion des unités, Méthode de combinaison, lecture des données (document NUREG peu lisible).
