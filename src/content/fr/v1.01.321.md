# v1.01.321 EFICA01 - Recette graphique de l'outil EFICAS

**Résumé:**

Ce cas-test sert de modèle pour prononcer la recette graphique de l'outil EFICAS. L'objectif est de pouvoir écrire ce test à l'identique dans EFICAS à partir d'une page blanche.

On a donc essayé d'y placer toutes les commandes un peu particulières du langage de commandes.

Il s'agit d'une copie du test sdnd102a auquel on a ajouté :

- la définition d'un paramètre;
- l'inclusion d'un fichier (INCLUDE);
- une poursuite (POURSUITE).

Cette documentation est volontairement succincte.
