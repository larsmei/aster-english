# v1.01.168 ZZZZ168 - Validation de la commande CALC_MECA_MULT

**Résumé :**

Ce test valide le bon fonctionnement de la commande [CALC_MECA_MULT](doc:u4.51.05) permettant d’obtenir les réponses thermomécaniques d’un modèle mécanique pour plusieurs cas de sollicitations thermiques.

La structure du test est la suivante : les résultats de la macro-commande sont comparés aux résultats obtenus en faisant les étapes de façon séparée pour les différents cas de chargement.

Cette documentation est volontairement succincte.
