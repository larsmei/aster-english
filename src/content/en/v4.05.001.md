# v4.05.001 TPLP01 - L domain with geometric singularity

**Summary:**

This test is based on independent validation of version 3 in linear steady-state thermal analysis.

This is a 2D plane problem with two modellings, one plane, the second volume.

The objective is to validate, in the presence of geometric singularity, the elements thermal planes and 3D with an imposed temperature for boundary condition.

The results are compared with those provided by VPCS.

## 5 Summary of the results

Both modellings give results with values exceeding the tolerance initially set (1%):

- for Modelling A (PLAN with mesh cells QUAD8), the difference maximum is 1.19% (exceeding for one value only out of the 13 tested),
- for Modelling B (3D with mesh cells HEXA8), the difference maximum is 2.7% (exceeding for two of 26 tested).

Modelling of geometric singularity (presence of a large thermal gradient near singularity) is best represented with quadratic elements (modelization A).

For both modellings, accuracy should be improved using a finer mesh (more importantly in the area of geometric singularity).

The results are considered acceptable based on modellings performed.
