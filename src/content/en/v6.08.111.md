# v6.08.111 SSND111 - Memory effect in a cyclic test

**Summary:**

On a reduced point hardware problem, several traction-compression cycles are performed, until the response is stabilized in terms of the stress-deformation curve imposed. The consideration of the memory effect of the largest nutring changes the stabilized curve. This test shows this memory effect for the Code_Aster behaviors that allow to model it.

Modelling A: This Modelling allows to validate the VISCOCHAB and VISC_CIN2_MEMO behaviors with SIMU_POINT_MAT.

### 1.3 Boundary conditions and loads

The load is in required deformations: 13.5 amplitude cycles: ${\varepsilon}_{yy}=\pm 0.3\text{\%}$

Each cycle lasts $\mathrm{3s}$ , so the total loading time is $40.5\text{s}$ .

The time step for numerical resolution is for each of the 3 calculations of $\mathrm{0.015s}$ .

### 1.4 Initial conditions

No stress and deformation.

## 2 reference solution

It consists of comparing the different models, using the VISCOCHAB model integrated by RUNGE-KUTTA and a very fine time step. The VISCOCHAB behavior is described in [R5.03.12](doc:r5.03.12) (explicit and implicit integration). The VISC_CIN2_MEMO behavior is described in [R5.03.04](doc:r5.03.04). In particular, the maximum value of the last cycle constraints will be compared, as well as the $q$ variable relative to the memory effect.

## 3 Modelling A

### 3.1 Modelling characteristics

A point hardware subject to the $13.5$ imposed deformation cycles, from which the last one is extracted. Three successive calculations are performed with VISCOCHAB behaviors with IMPLICITE integration, VISCOCHAB with RUNGE_KUTTA integration (used as reference solution) and VISC_CIN2_CHAB with IMPLICITE integration.
