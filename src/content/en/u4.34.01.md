# u4.34.01 Operator DEFI_LIST_REEL

## 1 Purpose

Create a strictly increasing list of reals.

The list may be given “in extenso” by the user, or else it may be formed from sub-lists defined at “constant step”.

Produces a data structure of type listr8.

## 2 Syntax

```text
listr8 = DEFI_LIST_REEL(
    ◆ / VALE = float,
      / DEBUT = float,
    ◇ / INTERVALLE = _F(
           ◆ JUSQU_A = float,
           ◆ / NOMBRE = int,
             / PAS = float,
        ),
    ◇ INFO = / 1 (par défaut),
             / 2,
    ◇ TITRE = text,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand VALE

```text
VALE= lr8
```

List of the reals which will form the resulting listr8 data structure.

This list may be built from a Python list.

### 3.2 Operand DEBUT

```text
♦    DEBUT =
```

It is the first real of the list of reals which one wishes to build.

### 3.3 Operand INTERVALLE

```text
♦    INTERVALLE    =
```

```text
♦    JUSQU_A    =    r1
```

It is the end of the interval which will be subdivided with a constant step.

```text
♦    /    NOMBRE    =    n1
```

It is the number of steps required in the interval which ends at r1.

```text
/    PAS    =    r2
```

It is the subdivision step of the interval.

### 3.4 Operand INFO

```text
◊    INFO    =    i
```

Indicates the printout level of the results of the operator.

| 1: | no printout, |
| --- | --- |
| 2: | printout of the list of reals created |

### 3.5 Operand TITRE

```text
◊    TITRE    =    titre
```

Title which the user wishes to give to the list of reals.

## 4 Notes

- when the keyword PAS is used, it may be that the number of steps calculated is not strictly an integer. The last interval will then be “adapted” so as to fall exactly on the final value (JUSQU_A). If, in order to do so, the value of the step is modified by more than 1/1000, an alarm is issued,
- caution: this command produces a listr8 data structure which can be used only in the commands expecting such data structures, and not in those which expect lists of reals (notation: l_R).

## 5 Examples

**Example 1:**

Suppose that one wishes to create the list:

```text
1. 3. 5. 10. 15. 20. 25. 26. 27. 28.
```

which is such that the step is:            2.        from            1.        to        5.
5.        from            5.        to        25.
1.        from            25.        to        28.

One may write:

```text
lr     = DEFI_LIST_REEL     (DEBUT            =    1.,
INTERVALLE    =(    _F    (JUSQU_A=    5. , NOMBRE=    2,    ),
_F    (JUSQU_A=    25., NOMBRE=    4,    ),
_F    (JUSQU_A=    28., PAS=        1.,),),
)
```

**Example 2:**

```text
Pour créer la liste:    1.        3.        12.        13.
```

One may write:

```text
lr     = DEFI_LIST_REEL     (    VALE=     (1.,    3.,     12.,    13.),    )
```

**Example 3:**

```text
On peut construire une liste Python de cette manière.
```

```text
lr     = DEFI_LIST_REEL     (    VALE=     [:ref:`sqrt(i) for i in range(5) <sqrt(i) for i in range(5)>`],    )
```
