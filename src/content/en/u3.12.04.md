# u3.12.04 Modelling GRILLE_EXCENTRE, GRILLE_MEMBRANE and MEMBRANE

**Summary:**

This document describes, for the modellings GRILLE_EXCENTRE, GRILLE_MEMBRANE and MEMBRANE:

- the degrees of freedom carried by the finite elements which support the modelling,
- the related support mesh cells,
- the supported materials and loadings,
- the analysis options for the elementary matrices and the post-processings,
- the non-linear possibilities as well as the fracture-mechanics options if they exist.

The modelling GRILLE_EXCENTRE (Phenomenon: MECANIQUE) corresponds to finite elements whose support mesh cells are three-node triangles and is used to represent the reinforcements for reinforced-concrete modellings of shell type. Indeed, it makes it possible to take into account the eccentricity of the reinforcement layers relative to the middle surface.

The modelling GRILLE_MEMBRANE (phenomenon: MECANIQUE) corresponds to finite elements whose support mesh cells are three- or six-node triangles and four- or eight-node quadrilaterals and is used to represent the reinforcements for reinforced-concrete modellings of 3D solid type. Indeed, it does not make it possible to take the eccentricity into account and therefore does not require a rotation degree of freedom, which is unnecessary in 3D modelling.

The modelling MEMBRANE (phenomenon: MECANIQUE) corresponds to finite elements whose support mesh cells are three-, six- or seven-node triangles and four-, eight- or nine-node quadrilaterals and is used to represent an arbitrary linear membrane behaviour or a non-linear isotropic membrane behaviour. It does not make it possible to take the eccentricity into account and has only displacement degrees of freedom.

## 1 Discretisation

### 1.1 Degrees of freedom

| **Modelling** | **Degrees of freedom** **(at each vertex node)** |
| --- | --- |

| GRILLE_EXCENTRE | $\mathit{DX}$: displacement along $X$ |
| --- | --- |
|  | $\mathit{DY}$: displacement along $Y$ |
|  | $\mathit{DZ}$: displacement along $Z$ |
|  | $\mathit{DRX}$: rotation about $X$ |
|  | $\mathit{DRY}$: rotation about $Y$ |
|  | $\mathit{DRZ}$: rotation about $Z$ |

| GRILLE_MEMBRANE and MEMBRANE | $\mathit{DX}$: displacement along $X$ |
| --- | --- |
|  | $\mathit{DY}$: displacement along $Y$ |
|  | $\mathit{DZ}$: displacement along $Z$ |

### 1.2 Support mesh cell of the stiffness matrices

The support mesh cells of the finite elements, in displacement formulation, are triangles.

| **Modelling** | **Mesh cell** | **Finite element** |
| --- | --- | --- |

| GRILLE_EXCENTRE | TRIA3 | MEGCTR3 |

|  | QUAD4 | MEGCQU4 |
| GRILLE_MEMBRANE | TRIA3 | MEGMTR3 |
|  | QUAD4 | MEGMQU4 |
|  | TRIA6 | MEGMTR6 |
|  | QUAD8 | MEGMQU8 |
| MEMBRANE | TRIA3 | MEMBTR3 |
|  | QUAD4 | MEMBQU4 |
|  | TRIA6 | MEMBTR6 |
|  | QUAD8 | MEMBQU8 |
|  | TRIA7 | MEMBTR7 |
|  | QUAD9 | MEMBQU9 |

### 1.3 Support mesh cell of the loadings

All the loadings applicable to the facets of the grid and membrane elements are treated by direct discretisation on the support mesh cell of the element in displacement formulation.

*No loading support mesh cell is therefore necessary for the faces of the grid and membrane elements.*

## 6 Non-linear possibilities

The non-linear constitutive behaviours for the GRILLE modellings correspond to particular incremental behaviours in STAT_NON_LINE:

- GRILLE_ISOT_LINE for plasticity with isotropic hardening,
- GRILLE_ISOT_CINE for plasticity with bilinear kinematic hardening,

For the MEMBRANE modelling in non-linear analysis, the constitutive behaviour GROT_GDEP will be used in STAT_NON_LINE.
