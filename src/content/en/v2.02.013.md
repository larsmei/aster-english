# v2.02.013 SDLL13- Slim circular ring suspended by elastic leg

**Summary:**

The linear elasticity dynamic test is used to validate straight beam elements POU_D_T.

This test case concerns a circular ring suspended by an elastic leg.

The frequencies are tested by comparing simulation results with reference solution AFNOR (ref. [1]) and those obtained with Pipestress software.
