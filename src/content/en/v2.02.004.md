# v2.02.004 SDLL04 - slender beam on two supports, coupled with a mass-spring system

**Summary:**

This flat problem consists in searching for vibration frequencies of a mechanical structure composed of a clamped-slide beam and a beam-related mass by a spring. The spring stiffness and mass depend on a variable parameter, which will allow to highlight the displacement of eigenfrequencies for a small disturbance of the model. This Structures Mechanics test corresponds to a dynamic analysis of a linear model with linear behavior. It includes only one model.

This problem allows testing the element of Timoshenko beam in bending, the calculation of eigenfrequencies by the method of reverse iterations and by the method of Lanczos, the restraint elastic discrete between a point mass and a node of a beam.

The results obtained are in good agreement with the results given in the VPCS guide. The duplication of the eigenfrequencies induced by the disturbance of the original model (slender beam on two supports) is well observed.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The reference solution is the one given in the SDLL04/89 form of the VPCS guide which presents the calculation method as follows:

The equation at the pulses of the complete system is written:

$\lambda {r}_{i}L\left[\frac{\sin({r}_{i}a)\sin({r}_{i}b)}{\sin({r}_{i}L)}-\frac{\mathit{sh}({r}_{i}a)\mathit{sh}({r}_{i}b)}{\mathit{sh}({r}_{i}L)}\right]=2({\omega}_{i}^{2}-{\omega}_{c}^{2})/{\omega}_{c}^{2}$

with:

$\lambda =\frac{{m}_{e}}{\rho AL}$ ${r}_{i}^{4}={\omega}_{i}^{2}\frac{\rho A}{EI}$ ${\omega}_{C}=\frac{{k}_{e}}{{m}_{e}}$ $a+b=L$

In the absence of a secondary system, ${k}_{e},{m}_{e}=0$, the slender beam's eigenfrequencies are well reflected on two supports.

${f}_{i}={i}^{2}\frac{\pi}{2}\frac{1}{{L}^{2}}\sqrt{\frac{\mathit{EI}}{\rho A}}={i}^{2}\frac{\pi}{2}$

When the secondary system is exactly tuned to the first mode of this beam, the new system-specific frequencies can be obtained by the following formulae:

${f}_{1,2}^{\mathrm{\ast }}=(1\pm 0.5\sqrt{\frac{{m}_{e}}{{M}_{1}}}){f}_{1}=(1\pm 0.5\sqrt{\lambda}){f}_{1}$ ${f}_{3}^{\mathrm{\ast }}\mathrm{\simeq }{f}_{2}$

with ${M}_{1}$ beam modal mass without secondary system for a eigenmode with 1 point $D$.

### 2.2 Baseline

The first two frequencies for $\lambda =0.$

The first three frequencies for $\lambda =0.001$ and $\lambda =0.01$.

### 2.3 Uncertainty about the solution

Less than $4\lambda \text{\%}$ for the first modes if the system is granted to the first mode.
