# v6.03.005 SSNP05 - Traction-slicing plate: Lemaître viscoelasticity

**Summary:**

This non-linear quasi-static mechanical test consists of loading a square plate into a tensile shear. This validates the Lemaître nonlinear viscoelasticity behavior relationship (in $\mathrm{3D}$ ) for non-radial loading. This test is taken from the VPCS guide of the Société Française de Mécanique.

The plate is modelled by a volume element (HEXA8).

The results obtained by *Code_Aster* are very close to the reference solution.

## 4 Summary of the results

The accuracy required for this test was set to $\text{0.5\%}$ instead of $\text{0.1\%}$ to avoid too much calculation time. However, it is verified that by refining the time discretization, the error made with the reference solution tends to zero.
