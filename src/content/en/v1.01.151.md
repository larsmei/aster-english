# v1.01.151 ZZZZ151 – Validating the EXEC_LOGICIEL Operator when calling mesh Tools

**Summary:**

The objective of this test case is to validate calls to system base commands and to the various tools of mesh (gmsh, salome, gibi) from EXEC_LOGICIEL macro-command:

- call to the basic commands unixlset pwdfrom the command file,
- construction of an mesh in 'GMSH' format by using the gmsh tool,
- construction of mesh in 'MED' format by call to salome,
- construction of mesh in 'GIBI' format by using the gibi tool.

The different mesh are produced and written in the respective files and the number of nodes and mesh cells produced is tested.

The various tools of mesh must be accessible from the code in the directory 'tools'.

This documentation is deliberately succinct.
