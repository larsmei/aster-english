# v5.02.104 SDNL104 - Non-linear transitional substructure: impact of a beam on 1 support

**Summary:**

The scope of this test concerns structural dynamics, and in particular the calculation of nonlinear transient response by dynamic substructure.

The purpose is to calculate the nonlinear transient response of a bending beam with impact on an elastic support and subjected to a constant force from the initial moment. The beam is modelled by elements type POU_D_E (the beam model d-Euler).

The reference results are derived from a direct transient calculation on the non-substructured model, using the DYNA_NON_LINE operator. This test is therefore used to validate the tools for calculating the transient response by substructure, in the case of taking into account non-linearity of the impact type on a fixed obstacle.

The interest of static modes is also verified to enrich the base projection and orthogonalization base.

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v5.02.104/10000A360000286900000C672CE68324F7CC406D.svg)

The length of the beam is: $L=1m$

The section of the beam is full circular radius: $R=0.1m$

The game between the beam and the elastic support is worth: $J={10}^{-4}m$

### 1.2 Material properties

$E={10}^{10}\mathit{Pa}$

$\nu =0.3$

$\rho ={10}^{6}\mathit{kg}/{m}^{3}$

The contact spring stiffness is: ${K}_{c}={10}^{8}N/m$

### 1.3 Boundary conditions and loads

On the whole structure: $\mathrm{DX}=\mathrm{DZ}=\mathrm{DRY}=\mathrm{DRX}=0$ .

Au point $A$ : $\mathrm{DY}=\mathrm{DRZ}=0$ .

At the free end of the beam: from the instant $t=0s$ , $\mathrm{Fy}=–1000.N$

### 1.4 Initial conditions

Structure initially at rest.

## 4 Modelling B

### 4.1 Modelling characteristics

The beam is cut into 2 parts of equal size. Each substructure is meshed into segments to which elements of the POU_D_E type are assigned.

![Figure](/figures/v5.02.104/1000034A00002A2B00000619AABD9F898D361642.svg)

The structure is studied using the "Craig-Bampton" (blocked interface) substructure method.

The basis of the first 5 modes of the complete structure is calculated by sub-structure. Then, the transitional problem, projected on this basis, is solved by the transient calculation operator by modal recombination.

## 5 Modelling C

### 5.1 Modelling characteristics

The beam is meshed with elements type POU_D_E.

The transitional problem is solved directly on different types of projection base.

The problem is addressed for four types of projection:

- on a basis consisting of the first 5 normal modes;
- on a basis consisting of the first 5 normal modes enriched with a static mode;
- on a base consisting of the first 5 normal modes enriched with a static mode and orthogonalization of the base relative to the stiffness matrix using ORTHO=";
- on a base consisting of the first 5 normal modes enriched with a static mode and orthogonalization of the base relative to the stiffness matrix using ORTHO_BASE operand DEFI_BASE_MODALE.

## 7 Summary of the results

For Modelling B, the accuracy of the free end of the beam at the moment $t=0.1315s$ is correct (relative error $\text{< 10\%}$). This test therefore validates the nonlinear transient calculation operators by dynamic substructure.

Model C demonstrates the value of base enrichment using static modes.

The results are identical if the enriched modal base is orthogonized or not.
