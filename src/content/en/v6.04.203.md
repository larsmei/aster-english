# v6.04.203 SSNV203 – Application of lip pressure of crack with X-FEM

**Summary**

The purpose of this test is to validate the imposition of Neumann conditions (flow conditions) on lips of a crack by the X-FEM [bib1] method on an academic case 2D / 3D. In fact, only the case of an interface is considered, the case of a crack is considered in the cases tests ssnv185a and ssnv185c.

This test involves a 2D and then 3D structure with a flat interface. Pressure boundary conditions are applied to this interface.

## 1 Reference problem

### 1.1 Geometry

The 2D structure is a unit square ($\mathit{LX}=1m$ , $\mathit{LY}=1m$ ), cut in half by a straight interface located at mid-height. [ Figure 1.1-a to the left]. The 3D structure is a unit cube ($\mathit{LX}=1m$ , $\mathit{LY}=1m$ and $\mathit{LZ}=1m$ ), cut in half by a straight interface located in the $z=\mathit{LZ}/2$ plane [ Figure 1.1-a to the right].

![Figure](/figures/v6.04.203/10000000000001AC0000018B541CA5367C1C701E.png)

![Figure](/figures/v6.04.203/10000000000001F0000001BC76C439301CC3AB68.png)

**Figure** 1.1-a **: geometries of the square (left), cube (right)**

### 1.2 Material properties

Young's modulus: $E=10000\mathit{MPa}$

Poisson's ratio: $\nu =0$

### 1.3 Boundary conditions and loads

A constant $p=10000\mathit{Pa}$ pressure load is applied to the interface (both sides of the interface).

The nodes movements on the upper and lower sides are blocked in all directions.

### 1.4 Analytical solutions

For constant pressure loading, everything happens as if you had two plates on either side of the uniform compression interface. The solution is therefore analytical.

The displacement just above the level set is ${\nu}^{+}=+\frac{p}{E}\frac{\mathit{LY}}{2}$ in 2D and ${\nu}^{+}=+\frac{p}{E}\frac{\mathit{LZ}}{2}$ in 3D.

The movement just below the level set is ${\nu}^{-}=-\frac{p}{E}\frac{\mathit{LY}}{2}$ in 2D and ${\nu}^{+}=-\frac{p}{E}\frac{\mathit{LZ}}{2}$ in 3D.

## 2 Modelization A: in dimension 2

In this Modelling, the structure is considered in 2d.

### 2.1 Mesh characteristics

The structure is modelled by a regular mesh made up of $5\times 5$ QUAD4, respectively, along the $x,y$ axes [ Figure 2.1-2.1-a ]. L-interface passes through the middle of the elements.

![Figure](/figures/v6.04.203/1000000000000584000002CAA04D7F8B3B934806.png)

**Figure 2.1-** 2.1-a **: mesh 2d**

### 2.2 Tested Features

The application of Neumann conditions is tested via AFFE_CHAR_MECA and AFFE_CHAR_MECA_F commands on an unmesh interface with X-FEM.

This is done using keyword FISSURE from PRES_REP operand, because the interface is not an mesh-cell group onboard.

The application of constant pressure is tested using a real pressure and then using a space function such as $p=y\times 20000\mathit{Pa}$ (the crack is in $y=0.5$ which is equivalent to applying a constant load).

### 2.3 Tested quantities and results

The values of displacement after convergence of the iterations of the STAT_NON_LINE operator are tested.

| **Identification** | **Reference** |
| --- | --- |
| $\mathit{DX}$ for all nodes just below the interface | 0.00 |
| $\mathit{DY}$ for all nodes just below the interface | -5,00E-7 |
| $\mathit{DX}$ for all nodes just above the interface | 0.00 |
| $\mathit{DY}$ for all nodes just above the interface | 5,00E-7 |

To test all nodes at one time, you test the minimum and maximum of the column.

## 6 Conclusion

This test validates the imposition of a pressure on the lips of a crack in the X-FEM frame. The pressure can be constant or function of space and time and the structure can be meshed with linear or quadratic elements.

This test does not validate the specific pressure term for post-processing in breaking mechanics (calculation of the energy return rate). An test case validates this feature (ssnv185c).
