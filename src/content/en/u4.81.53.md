# u4.81.53 Operator CREA_COUPE

## 1 Purpose

Creation of a table representing straight one-dimensional sections. This table describes the sections by means of their end points. The end points are required to be located on the surface of a mesh.

**Principle:**

This macro-command creates a table in which each line corresponds to a section. From an input table formatted in the expected way, the macro-command makes it possible to check that
the specified table is correctly formatted and also makes it possible to move the supplied points so that
they lie on the surface mesh-cell groups supplied in the table.
In addition, the macro-command also makes it possible to create new sections from a subset
of sections of the input table by a geometric transformation of revolution about an axis and a
centre of rotation.

## 2 Syntax

```text
table = CREA_COUPE(
    ◆ COUPE = table,
    ◆ MAILLAGE = maillage,
    ◇ NOM_AUTO = / "NON" (par défaut),
                 / "OUI",
    # Si: (equal_to("NOM_AUTO", 'OUI'))
        ◇ PREFIXE = text (défaut: ""),
        ◇ NUME_INIT = int (défaut: 1),
        ◇ PAS = int (défaut: 1),
    ◇ REVOLUTION = _F(
         ◆ AXE = list[float],
         ◆ CENTRE = list[float],
         ◇ ANGLE_AUTO = / "NON",
                        / "OUI" (par défaut),
         # Si: (equal_to("ANGLE_AUTO", 'OUI'))
             ◆ NOMBRE = int,
             ◆ ANGLE_MAX = float,
         # Si: (equal_to("ANGLE_AUTO", 'NON'))
             ◆ ANGLE = list[float],
         ◆ GROUP_MA_ORIG = grma,
         ◆ GROUP_MA_EXTR = grma,
         ◇ / NOM_COUPE = list[text],
           / GROUP_COUPE = list[text],
         ◇ PREFIXE = text (défaut: ""),
      ),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand COUPE

```text
♦        COUPE    =    table,        [table]
```

Table containing the description of the sections. The table must contain the following columns:

| Column name | Type | Description |
| --- | --- | --- |
| `COOR_ORIG_X` | `[R]` | First coordinate of the origin point |
| `COOR_ORIG_Y` | `[R]` | Second coordinate of the origin point |
| `COOR_ORIG_Z` | `[R]` | Third coordinate of the origin point |
| `COOR_EXTR_X` | `[R]` | First coordinate of the end point |
| `COOR_EXTR_Y` | `[R]` | Second coordinate of the end point |
| `COOR_EXTR_Z` | `[R]` | Third coordinate of the end point |
| `COOR_TROIS_X` | `[R]` | First coordinate of the third point used to orient the frame |
| `COOR_TROIS_Y` | `[R]` | Second coordinate of the third point used to orient the frame |
| `COOR_TROIS_Z` | `[R]` | Third coordinate of the third point used to orient the frame |
| `NOM` | `[K24]` | Name of the section |
| `GROUP` | `[K24]` | Name of the section groups to which the section will belong; these groups will be 1D mesh-cell groups |
| `GROUP_MA_ORIG` | `[K24]` | Name of the mesh-cell group onto which the origin point is to be projected |
| `GROUP_MA_EXTR` | `[K24]` | Name of the mesh-cell group onto which the end point is to be projected |
| `NB_POINTS` | `[I]` | Number of discretisation points of the section |

### 3.2 Operand MAILLAGE

```text
♦        MAILLAGE    =    maillage,        [maillage]
```

Support mesh on which the sections are to be made.

### 3.3 Operand NOM_AUTO

```text
◇        NOM_AUTO    =  /  'NON',        [DEFAUT]
                        /  'OUI'
```

Automatic renaming of each section line, of the form:
`PREFIX_ENTIER`.

The integer is computed directly as the number of the section in the table (line number)
or can be redefined by means of the operands NUME_INIT and PAS. When names are already defined in the column `NOM`, the names are replaced by the names generated
by the command.

#### 3.3.1 Operand PREFIXE

```text
◇        PREFIXE     =   text       [TXM]
```

Character string with which all the section names begin.

#### 3.3.2 Operands NUME_INIT and PAS

```text
◇        NUME_INIT   =   int (défaut: 1),
◇        PAS    =   int (défaut: 1),
```

Integers used to modify the number associated with the name of the section. This number, named `ENTIER`,
in the heading described in the previous section is computed as follows:

$$
ENTIER = NUME_INIT + (i − 1). PAS
$$

With $i$ , the number of the section in the table COUPE.

### 3.4 Operand REVOLUTION

This factor keyword makes it possible to generate new sections from all the sections of the input
table (or from a subset with the operands NOM_COUPE or GROUP_COUPE).
This keyword can be repeated.
The sections created are added to the output table; each new section is placed after the initial
section from which it was obtained by revolution.
The name of the new section obtained by revolution follows the following rule:

> prefix (optional) + rotation angle + ‘-‘ + name of the original section

If the rotation angle is not an integer, only the first decimal digit is used, the separator
character being ‘-‘.

The section group `GROUP` and the number of points `NB_POINTS` of the new sections are carried over
from the section from which they were generated.

#### 3.4.1 Operand AXE

```text
◆        AXE =    (ar,br,cr),       [l_R]
```

List of 3 real values of the components of the direction vector of the axis of rotation.
The vector `(ar,br,cr)` need not be normalised.

#### 3.4.2 Operands CENTRE

```text
◆        CENTRE =    (x,y,z),       [l_R]
```

List of 3 real values of the coordinates of the centre of rotation.

#### 3.4.3 Operand ANGLE_AUTO

```text
◇        ANGLE_AUTO    =  /  'NON',        [DEFAUT]
                          /  'OUI'
```

Designates the method used to determine the rotation angles:

- With a uniform spacing if `ANGLE_AUTO = ‘OUI’`
- With a list of angles supplied by the user if `ANGLE_AUTO = ‘NON’`

##### 3.4.3.1 Operand NOMBRE

```text
◆        NOMBRE =     int       [I]
```

Integer number of revolutions to be performed for each section.
This number takes the initial section into account, so $n \le 2$.
The angles 0° and ±360° coincide.

##### 3.4.3.2 Operand ANGLE_MAX

```text
◆        ANGLE_MAX =     :math:`\theta_{max}`       [R]
```

Angle in degrees to be covered by the revolution transformation.
It is required that: $-360 \le \theta_{max} \le +360$ and $\theta_{max} \neq 0$

##### 3.4.3.3 Operand ANGLE

```text
◆        ANGLE =     float       [l_R]
```

List of reals containing the rotation angles in degrees.
All the angles of this list must lie between -360° and +360° (0° excluded).

#### 3.4.4 Operand GROUP_MA_ORIG

```text
◆        GROUP_MA_ORIG =  grma      [grma]
```

Name of the mesh-cell group onto which the origin point of the new sections obtained by
revolution is to be projected.

#### 3.4.5 Operand GROUP_MA_EXTR

```text
◆        GROUP_MA_EXTR =  grma      [grma]
```

Name of the mesh-cell group onto which the end point of the new sections obtained by
revolution is to be projected.

#### 3.4.6 Operand NOM_COUPE

```text
◇ /      NOM_COUPE = text       [l_TXM]
```

List of the names of the sections of the input table to which the revolution transformation is to be applied.
If `NOM_AUTO = ‘OUI’`, the newly assigned names must be supplied.

#### 3.4.7 Operand GROUP_COUPE

```text
◇ /      GROUP_COUPE = text   [l_TXM]
```

List of the section groups of the input table to which the revolution transformation is to be applied.

#### 3.4.8 Operand PREFIXE

```text
◇        PREFIXE = text         [TXM]
```

Character string with which all the names of the sections obtained by revolution begin.
