# v3.05.103 SSLX103 – Flexion of a 3D reinforced concrete beam with bar-modelled reinforcements

**Summary:**

The objective of this test is to validate the Modelling of steels by elements linear bars SEG2 in concrete modelled by quadratic elements density.

We compare two modellingss:

- a quadratic element volumetric contains a linear element bar
- a quadratic element volume contains two barrelinear elements

a reference calculation where the elements bars are quadratic obtained with Castem.

## 1 Reference problem

### 1.1 Geometry

A $l=5m$ length concrete beam with square cross section of $w=h=1m$ is considered. It contains two $\mathit{P1P2}$ and $\mathit{P3P4}$ longitudinal cross-sectional frames. The cross-section of the two bars is $0,003{m}^{2}$ .

![Figure](/figures/v3.05.103/10000201000001DD000000BFCE2C8D3BCADF2291.png)

### 1.2 Material properties

The concrete material is elastic isotropic with the following properties:

- $E=30\mathit{GPa}$
- $\nu =0.2$

The steel material is elastic isotropic with the following properties:

- $E=200\mathit{GPa}$
- $\nu =0.25$

### 1.3 Boundary conditions and loads

The $\mathit{P1P3P7P5}$ edge is blocked.

$0,001m$ displacement is required in the $z$ direction on the $\mathit{P2P4P8P6}$ edge.

### 1.4 Initial conditions

None

## 2 reference solution

The purpose is to validate the use of linear elements to represent steels in concrete represented by elements density.

Two modellings are possible:

- Modelling A:un element quadratic volume contains a linear element bar. The mid-nodes of the quadratic elements volume is not connected to the bars ($\text{L}$).
- Modelling B:un element quadratic volume contains two elements barlinear. All nodes volume are connected to nodes steels ($\text{LL}$).

The reference solution was obtained with CASTEM 2000. The mesh used contains the same number of mesh cells but the elements bars Modelling the frames are quadratic ($\text{Q }$ ) .

The results in terms of stress in concrete, displacement and stress in steel are compared.

As a result, Modelling B ($\text{LL}$ ) is very close to the Quadratic Castem $\text{Q}$ model. Modelling A ($\text{L}$ ) is not sufficient and oscillations on stresses in concrete can be observed.

The model ($\text{LL}$ ) is therefore recommended for Modelling elements bars in conjunction with elements quadratic volumetrics.

## 5 Summary of the results

Modelling B ($\text{LL}$) is found to be very close to the Quadratic Castem $\text{Q}$ model. Modelling A (L) is not sufficient and oscillations on stresses in concrete can be observed.

Two elements linear by elements density is therefore recommended for the modelling of reinforced concrete.
