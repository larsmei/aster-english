# v3.02.002 SSLP02 – Simple Traction of Perforated Plate

**Summary:**

The objective of this test is to validate the stress calculation in a perforated plate subjected to a tensile force.

The four models are as follows:

- $A$ Modelling: mesh linear with mesh cells QUAD4,
- $B$ Modelling: mesh quadratic with mesh cells QUAD8,
- $C$ Modelling: mesh linear with mesh cells TRIA3,
- $D$ Modelling: mesh quadratic with mesh cells TRIA6.

## 1 Reference problem

### 1.1 Geometry

- $L=200\mathit{mm}$
- $h=300\mathit{mm}$
- $a=10\mathit{mm}$

| Contact details | $X$ | $Y$ |
| --- | --- | --- |
| A | $10.$ | $0.$ |
| B | $100.$ | $0.$ |

### 1.2 Material properties

The material is elastic isotropic with properties of:

- Young's modulus     $E=3\times {10}^{4}\mathit{MPa}$
- Poisson's ratio     $\nu \text{}=0.25$

### 1.3 Boundary conditions and loads

Movement required:

- AB-cot: $\mathit{DY}=0.$
- Code of conduct: $\mathit{DX}=0.$

Pressure imposed on CD: $p=2.5N/{\mathit{mm}}^{2}$

### 1.4 Initial conditions

None

## 2 reference solution

### 2.1 Method of calculation

The reference result was obtained analytically with the following assumptions:

- The plate is supposed to be infinite in size,
- Muskheliskvili and Kolosov method in polar coordinates.

${\sigma}_{\mathit{rr}}=\frac{P}{2}[(1-\frac{{a}^{2}}{{r}^{2}})-(1-\frac{4{a}^{2}}{{r}^{2}}+\frac{3{a}^{4}}{{r}^{4}})\cos2\theta ]$

${\sigma}_{\theta \theta }=\frac{P}{2}[(1+\frac{{a}^{2}}{{r}^{2}})+(1+\frac{3{a}^{4}}{{r}^{4}})\cos2\theta ]$

${\sigma}_{r\theta }=\frac{P}{2}(1+\frac{2{a}^{2}}{{r}^{2}}-\frac{3{a}^{4}}{{r}^{4}})\sin2\theta$

### 2.2 Quantities and reference results

The selected reference results are for the circumferential ${\sigma}_{\theta \theta }$ constraint.

${\sigma}_{\theta \theta }(a,\theta )=P(1+2\cos2\theta )$

| Point | quantity | Value (N/mm2) |
| --- | --- | --- |
| $\text{A}(a,0)$ | ${\sigma}_{\text{}\theta \theta }$ | $7.5$ |
| $\text{F}(a,\frac{\pi}{4})$ | ${\sigma}_{\text{}\theta \theta }$ | $2.5$ |
| $\text{E}(a,\frac{\pi}{2})$ | ${\sigma}_{\text{}\theta \theta }$ | $-2.5$ |

### 2.3 Uncertainties about the solution

Semi-analytic solution
