# v3.03.012 SSLS12 - Combination of static and seismic loads on a plate

**Summary**

The purpose of this test is to validate the operation of the POST_COMBINAISON command. The POST_COMBINAISON command allows the combination of different physical quantitiess following calculations to the elementss completed upstream. This command will only perform post-processings by manipulating results in the form of fields or tables from previous calculations.

This test involves a rectangular plate, which is submitted to its own weight, three cases of loads and seismic stresses.

The test saves the results obtained during the call to the POST_COMBINAISON command, and checks its correct functioning when the data structures of the sd_result type are to be combined.

## 1 Reference problem

The POST_COMBINAISON command calculates linear combinations of different calculation results associated with user-defined coefficients.

${C}_{i}\text{}\text{}\text{}=\text{}\text{}\text{}({\alpha}_{i,1}\times {Q}_{1})\text{}\text{}\text{}+\text{}\text{}\text{}({\alpha}_{i,2}\times {Q}_{2})$

Où :

- is the number of the combination
- Q1 is the result/table resulting from a first calculation at the finished elements
- Q2 is the result/table resulting from a first calculation at the finished elements
- αi,1is the coefficient associated with Q1
- αi,2is the coefficient associated with Q2
- This is the result of the combination performed.

### 2.3 Combinations

The combinations are defined in the file ssls12a.38

| **Sumulation** **(CMB)** | **Coefficient** **result** **1** **(** G **)** | **Coefficient** **Result** **2** **(** Q **)** | **Coefficient** **result** **2** **(** E **)** |
| --- | --- | --- | --- |
| C1 | 1.35 | 0.12 | 0 |
| C2 | 0.5 | 0 | 0 |
| C3 | -0.41 | 0.1414 | 0 |
| C4 | 1 | -0.63 | 0 |
| C5 | 0.6 | 0.5 | 0.8 |

Result1 is from the **MACRO_ELAS_MULT** command, which is the 3 cases of loading loads 1[applied separately].

The result 2 is from the **MECA_STATIQUE** command with loading 2 as argument.

Result 3 is from the **COMB_SISM_MODAL** command with the CQC combination.

Since the result2 has 3 order numbers (one per load case) and result 3 has 12 output fields (see documentation U4.84.01 on COMB_SISM_MODAL), 46 combination will be calculated by the **POST_COMBINAISON** command.

### 2.4 Tested quantities and results

Reference values are evaluated using a syntax in command file. Values are calculated from the values extracted from the nodes or elements of the result fields combined with the values in the table of coefficients following the formulation in Chapter 1.

These are displacement tests (DEPL) of the first 100 nodes. All components, combinations and first 3 order numbers are tested.
