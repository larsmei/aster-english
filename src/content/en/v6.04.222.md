# v6.04.222 FORMA04 - Practical work of the "Advanced use" training: Hertz contact

**Summary:**

This TP deals with Hertz contact, one of the few non-trivial contact cases for which an analytical solution is available.

The model consists of two half-spheres that come to contact one against the other.

This simple test will illustrate the data of the contact, the different ways of solving the problem and finally the tools available to post-processing a contact calculation.

## 2 reference solution

### 2.1 Method of calculation

In 1881 Hertz established a solution to the problem that bears his name under certain assumptions. Thus, assuming a friction-free contact and for which the $a$ contact half width is very small in front of the $R$ sphere radius ($a\ll R$), the contact pressure at the $\mathit{C1}$ and $\mathit{C2}$ points is:

$$
{P}_{0}=-\frac{E}{\pi (1-{\nu}^{2})}\sqrt{\frac{2h}{R}}
$$

where $h$ corresponds to the imposed crash, which is $4\mathit{mm}$ here.

The $a$ contact half width is expressed in terms of the required crushing and sphere radius:

$$
a=\sqrt{\frac{\mathit{Rh}}{2}}
$$

The contact surface is a $a$ radius disc, the pressure distribution as a function of the $r$ radius in this area is as follows:

$$
\textrm{Si}
r\le a
$$

### 2.2 Quantities and reference results

The pressure obtained at the centre of the contact area and the half-width of contact shall be compared to the above analytical solution.

### 2.3 Uncertainties about the solution

None (assumed above).

#### 3.1.2 Read the full statement before you start

Geometry is done with the Salome-Meca platform, Geometry module.

The "Sketcher" tool (Menu New Entity → Basic → 2D Sketch) allows you to build the upper disc contour: $A2$ , $B2$ , $D2$ and $C2$ . The two spheres have to be assembled to form only one GEOM object(Menu New Entity →Build →Compound *)* . Warning: In this object, there are always two points, $\mathit{C1}$ and $\mathit{C2}$ , which overlap. On the contrary, the two points merge if the operation is Partition,

#### 3.1.5 Hertz pressure

Numerical application: To calculate by hand with the problem data, the value of the Hertz pressure and the half-contact width (see Chapter 2).

**What do we see? Why this difference?**

*Note: the component* $\mathit{SIYY}$ *d* u field SIEF_NOEU(calculated with the CALC_CHAMP / CONTRAINTE command) *as contact pressure* will be used as the first approximation.

Trace the contact pressure as a function of radius in the contact area, compare it to the analytical solution.

- Calculate the stress field by elements to nodes ( *SIEF_NOEU* ): command CALC_CHAMP / CONTRAINTE.
- Create an node group with a curvilinear abscisse: DEFI_GROUP command. The same name will be retained for mesh with a rouse. The CREA_GROUP_NO / OPTION='NOEUD_ORDO' option will be used by giving the mesh cell group ($\mathit{CONT}1$) and the point starting ($C1$ ).
- Extract the $\mathit{SIYY}$ component from the SIEF_NOEU field in a table at the last moment: POST_RELEVE_T command. The name of the nodes group, the moment, the field and its component will be specified using EXTRACTION operation.
- Create ${\sigma}_{\mathit{YY}}=f(x)$ function: RECU_FONCTION command. We will define the curvilinear abscisse (ABSC_CURV) as PARA_X and SIYY as PARA_Y.
- Build the analytical solution:

  - Calculate pressure at $C1$ and $C2$ points , ${P}_{0}$ and contact half width $a$
  - Create the analytical formula:FORMULE command. It depends on the $x$ curvilinear coordinate (NOM_PARA='x' / VALE='P0 * sqrt(1.-x * x/a/a)').
  - Create a list of real values of $x$: DEFI_LIST_REEL command. For example, 100 values from 0 to 10mm.
  - Interpolation of the formula from the list of $x$: command CALC_FONC_INTERP.
- Print both functions in XMGRACE format with the IMPR_FONCTION command.

#### 5.1.2 Mesh realization

For the mesh, you choose to refine around the contact area using geometric progression on the circumference and radius. You may need to redirect certain segments in the Mesh module:

- The mail is defined by the Mesh→ Create Mesh menu with the mesh geometry. The mesh will be made into triangles, and the assumptions of mesh will be used automatically "Assign a set of hypotheses →2D: Automatic Quadrangulation" by choosing the number of segments 15.

It is made using the Wire Discretization algorithm, the Start and End Length hypothesis (e.g. 0.2mm and 2.0mm) and the Advanced Propagation of Node Distribution on Opposite Edges hypothesis. A linear mesh containing approximately 3500 quadrangles and 4000 nodes is then obtained.
