# v1.01.348 ZZZZ348 – Coupling of the Aster Code and Python Python Solver commands for time integration used in LEGOS tool

**Summary:**

In the context of the development of the rotating machine calculation tool in the LEGOS code which uses a C++-written solver and has a API python, the possibility of coupling via the aster control file is simpler and no longer requires the passage complicated by YACS.

Thus, this possibility of coupling the aster controls and the python time integration solver used in the LEGOS code is demonstrated through a simple mechanical calculation of a shaft line subjected to harmonic loading.

This test case is broken down into two parts:

- Aster controls to construct the modal base and mass, damping, gyroscopy and stiffness matrices of the tree line studied;
- Python solver to achieve the time integration of the dynamic system that allows to pair the dynamics of the tree line with the lubrication code of the LEGOS code.

The result of this test case is compared with the reference calculation of the old procedure for calculating rotating machines using the DYNA_VIBRA operator. It is therefore test case non-regression. The comparison shows an excellent consistency between the two results.

## 2 Coupling procedure

### 2.1 Dynamic fundamental equation of the rotating system

> The dynamic equation of the rotating system shall be written as follows (without taking into account the prestress):
> $K\ddot{U}+(C+G)\dot{U}+(K+\mathit{KG})U=F$
> où:

- $M,C,K$: the conventional mass, damping and rigidity matrices of the discretized system, respectively
- $G\mathit{et}\mathit{KG}$: Coriolis and stiffness centrifugal coupling matrices, respectively.
- $\ddot{U},\dot{U},U$: vectors in acceleration, speed and displacement
- $F$: external loading vector

### 2.2 Part 1: Aster Commands

The aster commands are used to construct the modal base. The mass, damping, gyroscopy and stiffness matrices are then projected on this basis.

The following diagram shows the sequence of these orders:

![Figure](/figures/v1.01.348/1000000000000FA0000008CA4E92EFB48C3CDE73.png)

**Figure** 2.2-1

The matrices are extracted and stored as python objects via the EXTR_MATR_GENE() command.

### 2.3 Part 2: Python Time Integration Solver

The python time integration solver uses the β-Newmark diagram with γ = 0.5 and β=0.25.

The architecture of the python solver is shown in the figure below:

![Figure](/figures/v1.01.348/1000020000000FA0000008CA6DFA3027A4864ABC.png)

**Figure** 2.3-1

The classes are defined as follows:

- Base(): Convert Aster modal bases to python objects. This class converts vectors of results from the generalized base to physical base and vice versa;
- Load(): generic class representing a load;
- LinearBearing(): Allows linear bearings to be treated as an external load.
- HamonicLoad(): Integrator Harmonic Loading: Generic class represents a temporal integration scheme.
- NewmarkIntegrator(): Integrator using the Newmark schema.
- TransitSimulation(): Controls integration by building the load vector and archiving results.

The result is the maximum displacement value in node N2Z1 as a function of time.

## 3 reference solution

The reference solution is done by the old procedure for calculating rotating machines with the DYNA_VIBRA operator's transition with the data of the problem described above.

> The maximum displacement in node N2Z1 is 2.6473318845597886e-05 (m).

## 4 Modelling

### 4.1 Mesh characteristics

The mesh consists of 13 nodes, 12 mesh cells SEG2 and 1 mesh cell POI1.

### 4.2 Modelling characteristics

With regard to the mesh, the tree line is modelled by elements beam type (POU_D_T) on linear segments (SEG2). The three bearings (supports) are modelled by discrete elements (DIS_TR). The disc is modeled by a nodal mass (element discreet DIS_TR) with moments of inertia in rotation.
