# v3.04.101 SSLV101 - Application of the industrial declination of the Beremin model to a CT test piece

**Summary:**

This test validates the use of the POST_BEREMIN command to calculate
Weibull stress overfacial density (use of keyword METHODE_2D).

For this, a CT test piece is considered and this stress density of Weibull is calculated.
in both planes at the end of the crack front.

Here it is simply a question of checking the post-processing with POST_BEREMIN. How to get the concept result given at the command input
So we choose an elastic behavior, so we keep a reasonable calculation time.

Two modellingss are present in this test:

- Modelling A: separate mesh density plane meshes (use of keyword MAILLAGE_PLAN), with elements 3D/3D_SI finished
- B Modelling: plans defined through nodes groups in mesh volume (use of keyword GROUP_NO_PLAN), with elements 3D/3D_SI finished
- Modelling C: plans defined through nodes groups in the mesh volume (use of keyword GROUP_NO_PLAN), with elements finished 3D_GRAD_INCO

## 1 Problem considered

### 1.1 Mesh

This CT25 test piece is deliberately coarsely meshed, so that it can be stored
a test case with a reasonable calculation time. Only a quarter of the test piece is represented.

The crack front is discretized by 4 elements,
and a mesh set to hexahedrons is present around this crack front.

![Figure](/figures/v3.04.101/CT_sslv101.png)

The mesh contains 10,879 nodes and 3,092 elements quadratic volume.

### 1.2 Behaviour and modelling

For modellings A and B, the elements hexahedrons are assigned to 3D_SI modelling, the other elements to 3D modelling.
The behavior is linear elastic, in small deformations.
The Young's modulus retained is 210 GPa and the Poisson's ratio 0.3.

For Modelling C, all elements are assigned 3D_GRAD_INCO modelling.
The behavior is elastoplastic, in large deformations.
The yield limit is chosen voluntarily high, so that it maintains an elastic behaviour.

The selected parameters of Weibull are: $m=18$, $\sigma_u=2630 MPa$, $V_0=1.25 .10^{-4}  mm^3$

### 1.3 Loading

The boundary conditions applied to the test piece are as follows:

- Normal displacement zero $DY=0$ for ligament
- Normal zero displacement $DZ=0$ for the symmetry face of the test piece
- Horizontal $DX=0$ displacement for pin end

A vertical displacement load imposed $DY=0.1 mm$ is applied to the tip of the pin (only one moment of calculation).

## 2 Modelling A

The stress density of Weibull in the planes located is calculated
These integration planes are defined by meshes
external (keyword MAILLAGE_PLAN) corresponding:

- Either at the whole side of the CT, pin excluded.
- Only the part set around the crack front.

The value obtained with this industrial variation of the Beremin model is compared with the Weibull stress value obtained each time.
by the Beremin model normalized by the length of the element.
