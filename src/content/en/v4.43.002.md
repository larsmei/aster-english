# v4.43.002 TPNV02 - Nonlinear laplacien in cubic domain

**Summary:**

This test is based on literature. It is a classic problem to evaluate nonlinear problem solving methods.

It is described in two modellings, one 3D, the other 2D.

The functions tested are as follows:

- 3D thermal element,
- element thermal 2D,
- thermal conductivity dependent not linearly on temperature.

The interest of the test lies in this nonlinear dependence.

## 1 Reference problem

### 1.1 Geometry

Cubic domain $[0,1]\times[0,1]\times[0,1]$

### 1.2 Material properties

| $\lambda = 1 + T^2$ | Thermal conductivity |
| --- | --- |
| $\rho C=0$ | Volumetric heat |

### 1.3 Boundary conditions and loads

- Dirichlet condition on external surface: ${T}^{e}=0$ .
- Volume Force: $f=6\pi^2*(\sin(\pi X)*\sin(\pi Y))^3$

### 1.4 Initial conditions

Not applicable.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The problem does not present analytical solution. The result obtained for the RASPEN solver is compared with that of the Newton method.

### 2.2 Bibliographical references

- El Mehdi Ettaouchi, Luc Giraud, Carola Kruse, Nicolas Tardieu. Convergence analysis of overlaping domain decomposition preconditioners for nonlinear problems. RR-9575, INRIA. 2025. [https://hal.science/hal-04958735v2](https://hal.science/hal-04958735v2)
