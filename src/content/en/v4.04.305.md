# v4.04.305 TPLV305 - Thermal Gradient in a Cylinders (Fourier)

**Summary:**

This test is based on independent validation of version 3 in linear steady-state thermal analysis.

It validates elements thermal axisymmetric harmonic resolution (AXIS_FOURIER) and volumetric elements temperature imposed on a harmonic function (mode 1).

It has two modellings, one 3D and the other using elements thermal axisymmetric "Fourier".

The value of this test is the validation of elements thermal AXIS_FOURIER and the field assembly control (CREA_CHAMP, option ASSE).

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v4.04.305/Object_1.svg)

### 1.2 Material properties

$$
\lambda =1.7307W/\mathrm{m.}°C
$$

### 1.3 Boundary conditions and loads

The limit condition is applied to the outer surface of the cylinder and is broken down into:

- a symmetrical limit condition of revolution associated with harmonic 0:

$\mathrm{CL1}$ : ${T}_{0}=-17.778°C$

- a symmetric limit condition compared to $\theta$

$\mathrm{CL2}$ : ${T}_{1}\cos\theta =44.444\cos\theta (°C)$

![Figure](/figures/v4.04.305/Object_2.svg)

### 1.4 Initial conditions

Not applicable.

## 5 Summary of the results

The two modellings performed (AXIS_FOURIER and 3D) give excellent results, the difference maximum is $-0.006\text{\%}$ for both modellings

This test allowed the CREA_CHAMP command to be tested in AXIS_FOURIER with the following operating devices:

- COMB_FOURIER to calculate the temperature at a given angle,
- ASSE to perform a linear combination of modes 0 and 1.
