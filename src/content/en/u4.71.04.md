# u4.71.04 Operator EXTR_RESU

## 1 Purpose

Extract fields from within a data structure of type resultat.

The reduction of the size of the result data structure is obtained by archiving part of the fields which it contains. One can choose the fields to be archived either by indicating the fields to be kept, or by indicating the fields to be excluded.

The extraction can also be carried out on a part of the mesh or of the model on which the result data structure is based.

One can reduce the quantity of memory used by the study by overwriting the result object, that is to say by reusing the same variable name.
Example:

```python
result = EXTR_RESU(RESULTAT=result, ...)
```
The memory will actually be recovered when the useless objects are automatically deleted.

## 3 Operands

### 3.1 Operand RESULTAT

Initial result data structure.

- *If the result contains one (or more) tables, for example: 'OBSERVATION', 'PARA_CALC', ..., these are ignored by the command.*
- *Concepts of type FOURIER_THER are not processed by the operator EXTR_RESU.*

**Notes**

### 3.2 Factor keyword ARCHIVAGE

Defines the fields to be saved. This keyword cannot be repeated more than once.

#### 3.2.1 Operands LIST_ARCH and PAS_ARCH

Define the order numbers to be saved.

- LIST_ARCH: list of the order numbers obtained by the command DEFI_LIST_ENTI [U4.34.02](doc:u4.34.02),
- PAS_ARCH: saving of the results starting from the first, every *n* order numbers.

#### 3.2.2 Operands CHAM_EXCLU and NOM_CHAM

Defines the types of fields which one does not wish to save (SIEF_ELNO, ...) according to the type of the input result data structure. In order to specify the fields which one does not wish to save, one can:

- either list the fields to be kept with the operand NOM_CHAM,
- or list the fields to be excluded with the operand CHAM_EXCLU.

If one of the fields to be retained is not part of the result data structure, the code stops in fatal error.

### 3.3 Factor keyword RESTREINT

This keyword makes it possible to restrict the fields of the result onto a restricted mesh built with the aid of the command CREA_MAILLAGE, option RESTREINT.

In the case where the restriction concerns only nodal fields, the user may supply only the restricted mesh by means of the keyword MAILLAGE. If the restriction also concerns fields by element, it is necessary to supply a restricted MODELE based on the restricted mesh.

If the model contains structural elements (beams, plates, ...), it is in general necessary to supply a restricted CARA_ELEM.

For certain post-processings, it may also be necessary to supply a restricted CHAM_MATER.

### 3.4 Operand TITRE

Title given to the data structure RESUOUT created (cf. [U4.03.01](doc:u4.03.01)).

### 3.5 Operands NUME_ORDRE / LIST_ORDRE / INST / LIST_INST / FREQ / LIST_FREQ / NUME_MODE / NOEUD_CMP / NOM_CAS / PRECISION / CRITERE

Selection in a result data structure (*cf.* [U4.71.00](doc:u4.71.00)).

### 3.6 Operand INFO

◊ INFO = info

In the case where INFO=2, the parameters of each extracted field are displayed.

## 4 Examples

Copy into the data structure FREQ2 of one mode out of 8 of the data structure FREQ.

```python
FREQ = CALC_MODES(
    MATR_RIGI=MATASSR,
    MATR_MASS=MATASSM,
    OPTION="AJUSTE",
    CALC_FREQ=_F(FREQ=(5.0, 10.0, 15.0, 20.0, 24.0, 27.0, 30.0, 32.0)),
    SOLVEUR_MODAL=_F(OPTION_INV="DIRECT"),
)

FREQ2 = EXTR_RESU(RESULTAT=FREQ, ARCHIVAGE=_F(PAS_ARCH=8))
```
