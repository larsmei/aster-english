# u3.13.14 Modellings x_JOINT, x_ELDI, x_INTERFACE and x_INTERFACE_S

**Summary:**

This document describes, for the modellings PLAN_JOINT, AXIS_JOINT, 3D_JOINT, PLAN_ELDI, AXIS_ELDI, PLAN_INTERFACE, AXIS_INTERFACE, 3D_INTERFACE, PLAN_INTERFACE_S, AXIS_INTERFACE_S and 3D_INTERFACE_S, the following points:

- the degrees of freedom carried by the finite elements which support the modelling,
- the associated support mesh cells,
- the non-linear capabilities,
- the test cases implementing the modellings.

The modellings of JOINT type (Phenomenon: mechanics) correspond to joint finite elements. They are based on a penalty formulation, and make it possible to model the opening of a crack. Their geometrical supports are degenerate finite elements, whose nodes are coincident in pairs (QUAD4, HEXA8 and PENTA6). These finite elements can support the constitutive laws CZM_EXP_REG and CZM_LIN_REG (cohesive laws: doc [R7.02.11]). In addition, the elements PLAN_JOINT, AXIS_JOINT support the constitutive law JOINT_BA (steel–concrete bond: doc [R7.01.21]).

The modellings PLAN_ELDI and AXIS_ELDI (Phenomenon: mechanics) correspond to elements with an internal discontinuity. Their geometrical supports are volume elements (QUAD4) crossed by a discontinuity. They also make it possible to model the opening of a crack. Such finite elements can support the constitutive law: CZM_EXP (cohesive law: see doc [R7.02.14](doc:r7.02.14)).

The modellings PLAN_INTERFACE, AXIS_INTERFACE, 3D_INTERFACE, PLAN_INTERFACE_S, AXIS_INTERFACE_S and 3D_INTERFACE_S (Phenomenon: mechanics) correspond to mixed interface finite elements, based on an augmented-Lagrangian type formulation. Their geometrical supports are degenerate finite elements (QUAD8, HEXA20 and PENTA15). Such elements can support the cohesive laws CZM_OUV_MIX, CZM_EXP_MIX, CZM_TAC_MIX, CZM_FAT_MIX, CZM_TRA_MIX and CZM_LAB_MIX (see doc [R7.02.11] and [R3.06.13](doc:r3.06.13)).

In what follows, the characters 'XXX' may be replaced by 'PLAN’ or 'AXIS’.

## 1 Discretisation

### 1.1 Degrees of freedom

| **Modelling** | **Degrees of freedom on each node** |
| --- | --- |

| XXX_JOINT | DX: displacement along $X$ |
| --- | --- |
|  | DY: displacement along $Y$ |
| 3D_JOINT | DX: displacement along $X$ |
|  | DY: displacement along $Y$ |
|  | DZ: displacement along $Z$ |
| XXX_ELDI | DX: displacement along $X$ |
|  | DY: displacement along $Y$ |

| XXX_INTERFACE and XXX_INTERFACE_S | DX: displacement along $X$ or SIGN Lagrange multiplier |
| --- | --- |
|  | DY: displacement along $Y$ or SITX: Lagrange multiplier |
| 3D_INTERFACE and 3D_INTERFACE_S | DX: displacement along $X$ or SIGN Lagrange multiplier |
|  | DY: displacement along $Y$ or SITX: Lagrange multiplier |
|  | DZ: displacement along $Z$ or SITY: Lagrange multiplier |

For the location of the displacement and Lagrange degrees of freedom for the modellings of INTERFACE type, see doc R3.06.13.

### 1.2 Support mesh cell

The support mesh cells of the finite elements are quadrangles, hexahedra or pentahedra. The elements are isoparametric for the displacement degrees of freedom.

| **Modelling** | **Mesh cell** | **Interpolation** | **Notes** |
| --- | --- | --- | --- |
| XXX_JOINT | QUAD4 | linear |  |
| 3D_JOINT | HEXA8 | linear |  |
|  | PENTA6 | linear |  |
| XXX_ELDI | QUAD4 | linear |  |
| XXX_INTERFACE and XXX_INTERFACE_S | QUAD8 | quadratic in displacement, linear in Lagrange multiplier | mixed formulation |
| 3D_INTERFACE and 3D_INTERFACE_S | HEXA20 | quadratic in displacement, linear in Lagrange multiplier | mixed formulation |
|  | PENTA15 | quadratic in displacement, linear in Lagrange multiplier | mixed formulation |

## 2 Non-linear capabilities

### 2.1 Constitutive laws

The constitutive laws specific to these modellings, usable under COMPORTEMENT in STAT_NON_LINE and DYNA_NON_LINE (JOINT modellings only), are the following (see [U4.51.11](doc:u4.51.11)):

```text
/    'CZM_EXP_REG'
```

Supported modellings: XXX_JOINT, 3D_JOINT

```text
/    'CZM_LIN_REG'
```

Supported modellings: XXX_JOINT, 3D_JOINT

```text
/    'JOINT_BA'
```

Supported modellings: XXX_JOINT

```text
/    'CZM_EXP'
```

Supported modellings: XXX_ELDI (only with STAT_NON_LINE)

```text
/    'CZM_OUV_MIX'
```

Supported modellings: all modellings of INTERFACE type

```text
/    'CZM_EXP_MIX'
```

Supported modellings: all modellings of INTERFACE type

```text
/    'CZM_TAC_MIX'
```

Supported modellings: all modellings of INTERFACE type

```text
/    'CZM_FAT_MIX'
```

Supported modellings: all modellings of INTERFACE type

```text
/    'CZM_TRA_MIX'
```

Supported modellings: all modellings of INTERFACE type

```text
/    'CZM_LAB_MIX'
```

Supported modellings: all modellings of INTERFACE type

### 2.2 Strains

Only the small strains (keyword 'PETIT' under DEFORMATION) are available for these modellings (see [U4.51.11](doc:u4.51.11)).
