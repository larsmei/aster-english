# v1.01.385 ZZZZ385 – Validation of LIAISON_SOLIDE in 2D and with large rotations

**Summary:**

The purpose of this test Modelling is to validate the use of LIAISON_SOLIDE in 2D for large transformations in STAT_NON_LINE. This load makes it possible to make a perfectly unformable structure without any hypothesis (especially on the materials to be used). The test compares the result (movements) obtained by LIAISON_SOLIDE in large transformations and the analytical solution triviale (pure rotation) that one wishes to obtain.

This documentation is deliberately succinct.
