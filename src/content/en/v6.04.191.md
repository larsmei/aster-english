# v6.04.191 SSNV191 – Validation of Neumann conditions with X-FEM in 2D and 3D

**Summary**

The purpose of this test is to validate the consideration of boundary conditions Neumann type on elements skin in 2D and 3D.

This test involves a 3D structure or a 2D equivalent with a horizontal flat interface cutting the structure into two parts (a "higher part above the interface, and a "lower part" below the interface). The interface is represented by level sets.

The loads applied are of several types: a constant pressure load on the side faces of the structure, a load with positive pressure on the upper side faces and a negative pressure on the lower side faces. The same problem is also addressed by replacing the pressures with 3D surfactic forces and 2D linear forces.

## 1 Reference problem

The 3D structure of dimensions $\mathit{LX}=\mathrm{1m}$ , $\mathit{LY}=\mathrm{2m}$ and $\mathit{LZ}=\mathrm{3m}$ has a horizontal flat interface at mid-height (see [ Figure 1.1-1 ]).

The interface is not meshed, and geometry is actually a healthy structure without interface. The interface is then introduced by level set functions directly into the command file using DEFI_FISS_XFEM [U4.82.08](doc:u4.82.08) operator.

### 1.3 Boundary conditions and loads

In 3D, rigid modes are blocked as follows:

| The $A$ and $D$ points are blocked in 3 directions: | $\lbrace \begin{array}{}{\mathrm{DX}}^{A}={\mathrm{DX}}^{D}=0\\ {\mathrm{DY}}^{A}={\mathrm{DY}}^{D}=0\\ {\mathrm{DZ}}^{A}={\mathrm{DZ}}^{D}=0\end{array}$ |
| --- | --- |
| $B$ and $E$ points are blocked along the $\mathrm{Oz}$ axis: | ${\mathrm{DZ}}^{B}={\mathrm{DZ}}^{E}=0$ |
| The $C$ and $F$ points are blocked along the $\mathrm{Ox}$ and $\mathrm{Oz}$ axes: | $\lbrace \begin{array}{}{\mathrm{DX}}^{C}={\mathrm{DX}}^{F}=0\\ {\mathrm{DZ}}^{C}={\mathrm{DZ}}^{F}=0\end{array}$ |

In 2D, rigid modes are blocked as follows:

| The $A$ and $C$ points are blocked in both directions: | $\lbrace \begin{array}{}{\mathrm{DX}}^{A}={\mathrm{DX}}^{C}=0\\ {\mathrm{DY}}^{A}={\mathrm{DY}}^{C}=0\end{array}$ |
| --- | --- |
| $B$ and $D$ points are blocked along the $\mathrm{Oy}$ axis: | ${\mathrm{DY}}^{B}={\mathrm{DY}}^{D}=0$ |

In 3D, two loads are envisaged:

- Constant distributed pressure ($p=10000\mathrm{Pa}$ ) on the side surfaces (planes $y=0$ and $y=\mathrm{LY}$ ), corresponding to a compression case on the $\mathrm{Oy}$ axis.
- Positive pressure ($p=10000\mathrm{Pa}$ ) on the upper side and negative pressure ($p=-10000\mathrm{Pa}$ ) on the lower side, corresponding to a compression case on the upper solid and a tensile case on the lower solid

In 2D, two loads are envisaged:

- Constant distributed pressure ($p=10000\mathrm{Pa}$ ) on the side segments ($x=0$ and $x=\mathrm{LX}$ ) corresponding to a compression case on the $\mathrm{Ox}$ axis.
- Positive pressure ($p=10000\mathrm{Pa}$ ) on the upper side edges and negative pressure ($p=-10000\mathrm{Pa}$ ) on the lower side edges, corresponding to a compression case on the upper solid and a tensile case on the lower solid

### 1.4 Problem solutions

The solution of the 3D problem is presented. The solution of the 2D problem is obtained by replacing $y$ with $x$.

#### 1.4.1 Pure compression loading

```text
La structure est en compression pure, la solution en déplacement est triviale. Pour les nœuds de la face latérale de gauche, le déplacement solution est:
```

${u}_{y}=-\frac{\mathit{LY}}{2}{\varepsilon}_{yy}=-\frac{\mathit{LY}}{2}\frac{{\sigma}_{yy}}{E}=\frac{\mathit{LY}}{2}\frac{p}{E}=\frac{{2.10}^{4}}{{2.10}^{10}}={10}^{-6}m$

```text
Pour les nœuds de la face latérale de droite, le déplacement solution est:
```

${u}_{y}=\frac{\mathit{LY}}{2}{\varepsilon}_{yy}=\frac{\mathit{LY}}{2}\frac{{\sigma}_{yy}}{E}=\frac{-\mathit{LY}}{2}\frac{p}{E}=-\frac{{2.10}^{4}}{{2.10}^{10}}=-{10}^{-6}m$

```text
Lorsqu’un nœud du bord est enrichi par la fonction Heaviside, son déplacement s’écrit comme une combinaison d’un terme continu et d’un terme discontinu. Pour ce cas de chargement, il n’y a pas de discontinuité au travers de l’interface, donc les degrés de liberté enrichis sont tous nuls.
```

#### 1.4.2 Charge in compression / traction

```text
La structure supérieure est en compression pure et les déplacements des nœuds de la face latérale supérieure sont les mêmes que ceux du cas de chargement précédent.

La structure inférieure est en traction pure. Seuls les signes des valeurs de déplacement changent. Pour les nœuds de la face latérale inférieure de gauche, le déplacement solution est:
```

${u}_{y}=-\frac{\mathrm{LY}}{2}{\varepsilon}_{yy}=\frac{\mathrm{LY}}{2}\frac{p}{E}=-\frac{{2.10}^{4}}{{2.10}^{10}}=-{10}^{-6}m$

```text
Pour les nœuds de la face latérale inférieure de droite, le déplacement solution est:
```

${u}_{y}=\frac{\mathrm{LY}}{2}{\varepsilon}_{yy}=\frac{\mathrm{LY}}{2}\frac{p}{E}=\frac{{2.10}^{4}}{{2.10}^{10}}={10}^{-6}m$

In this case, the displacement is discontinuous through the interface. The values of the degrees of freedom discontinuous can be easily determined (refer to the similar case treated in [V6.04.173](doc:v6.04.173)).

## 2 Modelling A

In this model, for the pressure load, the load is applied using a constant distributed pressure or constant superfacial forces for load 1 and distributed pressure or distributed forces $z$ functions for load 2 .

In this model, for the load load in the surface, the load is applied using constant overfacial forces for load number 1, and $z$ function superfacial forces for load number 2.

### 2.1 Mesh characteristics

The structure is meshed with 8 nodes hexahedrons. The number d-elements is the smallest possible, i.e. a element on the $\mathrm{Ox}$ axis, 2 elements on the $\mathrm{Oy}$ axis (to be able to define nodes in the $y=\mathrm{LY}/2$ midplane), and 5 elements on the $\mathrm{Oz}$ axis. On the $\mathrm{Oz}$ axis, the number d-elements is odd so that the interface does not coincide with the faces of the elements; the 3 central d-elements layers use elements X-FEM, and the 2 d-elements layers at the top and bottom use classic elements.

![Figure](/figures/v6.04.191/100000000000027F000002D9CB9138DC7306F743.png)

**Figure** 2.1-1 **: mesh 3D**

### 2.2 Tested Features

Keyword PRES_REP from AFFE_CHAR_MECA [U4.44.01](doc:u4.44.01) allows for constant distributed pressure to be applied to mesh cells skin. When the pressure is a function or formula, keyword PRES_REP from AFFE_CHAR_MECA_F [U4.44.01](doc:u4.44.01) is used. This feature is tested with #2 loading, because with X-FEM, you cannot define a higher and lower lateral surface as mesh-cell group. In this case, only one mesh-cell group with all side-facing mesh cells is defined, and $z$ is applied to this mesh-cell group.

Keyword FORCE_FACE operator AFFE_CHAR_MECA [U4.44.01](doc:u4.44.01) allows you to apply a constant overfacial force to mesh cells skin. When the overfacial force is a function or formula, keyword FORCE_FACE AFFE_CHAR_MECA_F [U4.44.01](doc:u4.44.01) is used.

### 2.3 Tested quantities and results

The POST_MAIL_XFEM operator allows the cracks to be broken by the X-FEM method. The POST_CHAM_XFEM operator then allows the X-FEM results to be exported to this new mesh. Both operators are only to be used after the calculation at post-processing views. They allow the nodes to be generated just below and above the interface and to display their movements.

For each side of the structure ($y=0$ and $y=\mathrm{LY}$) the movements of the nodes located just above and just below the level set are tested.

## 6 Summary of results

The objectives of this test are achieved:

  - Validate the consideration of Neumann conditions on elements aircraft X-FEM enhanced with the Heaviside function on a simple case.
  - Validate different loads: constant pressure, function pressure, constant surfactic force and 3D surfactic force, constant linear force and 2D function linear force.
