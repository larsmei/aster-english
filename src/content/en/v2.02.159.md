# v2.02.159 SDLL159 – Seismic Calculation of the BM3 Pipe

**Summary:**

The main objective of this test is to validate the implementation of different combination methods applied to a
seismic calculation by spectral method, on a pipe section (COMB_SISM_MODAL).

The methods evaluated on the same configuration are as follows:

- **Modal combinations**: SRSS, ABS, CQC, NRC_DSA, NRC_GROUPING, NRC_TEN_PERCENT, ENVELOPPE.
- **Directional combinations**: COMB_DIRECTION = QUAD, ABS.
- **Cumulated of the supported responses tested**: CUMUL_INTRA / CUMUL_INTER = LINE / QUAD / ABS.

This test was proposed by NRC to validate seismic design of nuclear facilities.

## 1 Reference problem

### 1.1 Issue

This test consists of performing a spectral analysis of the BM3 pipeline network used in a nuclear power plant.
It allows to validate the different combination methods used. To achieve this validation, the results
d) equivalent modelling with Caltuy software is used.

The mesh of the structure is linear and consists of 1679 elements SEG2 for 1675 nodes.

`*_BASE`) of these discrete ends. These nodes also correspond to the blocking points where the
seismic loads.
