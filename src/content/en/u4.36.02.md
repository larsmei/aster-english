# u4.36.02 Operator DEFI_INTE_SPEC

## 1 Purpose

To define a spectral density matrix (one also says: interspectral matrix).

The terms of the matrix are defined by:

- constants (white noise),
- existing complex functions,
- the analytical formula of KANAI-TAJIMI.

It produces a data structure of type interspectre.

## 2 Syntax

```text
interspectre = DEFI_INTE_SPEC(
    ◇ DIMENSION = int (défaut: 1),
    ◆ / PAR_FONCTION = _F(
           ◆ / NOEUD_I = no,
             / NUME_ORDRE_I = int,
           # Si: exists("NUME_ORDRE_I")
               ◆ NUME_ORDRE_J = int,
           # Si: exists("NOEUD_I")
               ◆ NOEUD_J = no,
               ◆ NOM_CMP_I = text,
               ◆ NOM_CMP_J = text,
           ◆ FONCTION = fonction_c / fonction,
        ),
      / KANAI_TAJIMI = _F(
           ◆ / NUME_ORDRE_I = int,
             / NOEUD_I = no,
           # Si: exists("NUME_ORDRE_I")
               ◆ NUME_ORDRE_J = int,
           # Si: exists("NOEUD_I")
               ◆ NOEUD_J = no,
               ◆ NOM_CMP_I = text,
               ◆ NOM_CMP_J = text,
           ◇ FREQ_MIN = float,
           ◇ FREQ_MAX = float (défaut: 100.0),
           ◇ PAS = float (défaut: 1.0),
           ◇ AMOR_REDUIT = float (défaut: 0.6),
           ◇ FREQ_MOY = float (défaut: 5.0),
           ◇ / VALE_R = float,
             / VALE_C = complex,
           ◇ INTERPOL = / "LIN" (par défaut),
                        / "LOG",
           ◇ PROL_DROITE = / "CONSTANT",
                           / "LINEAIRE",
                           / "EXCLU" (par défaut),
           ◇ PROL_GAUCHE = / "CONSTANT",
                           / "LINEAIRE",
                           / "EXCLU" (par défaut),
        ),
      / CONSTANT = _F(
           ◆ / NUME_ORDRE_I = int,
             / NOEUD_I = no,
           # Si: exists("NUME_ORDRE_I")
               ◆ NUME_ORDRE_J = int,
           # Si: exists("NOEUD_I")
               ◆ NOEUD_J = no,
               ◆ NOM_CMP_I = text,
               ◆ NOM_CMP_J = text,
           ◇ FREQ_MIN = float,
           ◇ FREQ_MAX = float (défaut: 100.0),
           ◇ PAS = float (défaut: 1.0),
           ◇ / VALE_R = float,
```

## 3 Operands

### 3.1 Operand DIMENSION

```text
◊    DIMENSION =    n
```

Dimension of the spectral density matrix, stored in a table of interspectra (tabl_intsp).

### 3.2 Keyword PAR_FONCTION

```text
♦        PAR_FONCTION=
```

Factor keyword; it makes it possible to define a term (i, j) of the interspectral matrix from concepts of type fonction_c already defined.

#### 3.2.1 Operands NUME_ORDRE_I, NUME_ORDRE_J

```text
NUME_ORDRE_I =    i
NUME_ORDRE_J =    j
```

Pair of indices (row, column) of the matrix on which one will assign a function.

These operands are excluded with the operands NOEUD_I NOEUD_J NOM_CMP_I NOM_CMP_J.

#### 3.2.2 Operands NOEUD_I, NOEUD_J, NOM_CMP_I, NOM_CMP_J

```text
NOEUD_I    =    nd_i            [noeud]
NOEUD_J    =    nd_j            [noeud]
NOM_CMP_I    =    ncmp_i            [Kn]
NOM_CMP_J    =    ncmp_j            [Kn]
```

These operands correspond to the names of the nodes and of the components (row, column) of the matrix where one will assign a function.

These operands are excluded with the operands NUME_ORDRE_I NUME_ORDRE_J.

#### 3.2.3 Operand FONCTION

```text
♦    FONCTION : fonct
```

fonct is a concept of type fonction_c.

### 3.3 Keyword KANAI_KAJIMI

```text
    KANAI_TAJIMI=
```

Factor keyword; it makes it possible to define a spectral density function using the model of Kanai and Tajimi. This spectral density function corresponds to that of a filtered white noise [bib2].

One gives the three parameters of the spectral density of the KANAI_TAJIMI model: damping, frequency and level.

#### 3.3.1 Operands NUME_ORDRE_I, NUME_ORDRE_J

```text
NUME_ORDRE_I =    i
NUME_ORDRE_J =    j
```

Pair of indices (row, column) of the interspectral matrix. Having no model of spectral coherence, the Kanai-Tajimi model makes it possible only to create auto-spectra. One must therefore choose i = j (in general, one will choose here n=1 and i=j=1).

These operands are excluded with the operands NOEUD_I NOEUD_J NOM_CMP_I NOM_CMP_J.

#### 3.3.2 Operands NOEUD_I, NOEUD_J, NOM_CMP_I, NOM_CMP_J

```text
NOEUD_I    =    nd_i            [noeud]
NOEUD_J    =    nd_j            [noeud]
NOM_CMP_I    =    ncmp_i            [Kn]
NOM_CMP_J    =    ncmp_j            [Kn]
```

These operands correspond to the names of the nodes and of the components (row, column) of the matrix where one will assign a function. In the case of the Kanai-Tajimi model, one chooses NOEUD_I = NOEUD_J and NOM_CMP_I = NOM_CMP_J.

These operands are excluded with the operands NUME_ORDRE_I NUME_ORDRE_J.

#### 3.3.3 Operands AMOR_REDUIT/FREQ_MOY/VALE_R / VALE_C

```text
◊    AMOR_REDUIT    =    amor
◊    FREQ_MOY        =    fmoy
◊    /    VALE_R        =    valr
/    VALE_C        =    valc
```

fmoy and amor are the natural frequency and the reduced damping of the filter. The level may be given in complex or real form.

#### 3.3.4 Operands INTERPOL/PROL_GAUCHE/PROL_DROITE

For each function one gives the classical parameters which govern the interpolation and the extrapolation of the function produced. The possibilities as well as the default values are recalled on page 2.

```text
   ◊    INTERPOL
   ◊    PROL_GAUCHE
   ◊    PROL_DROITE

Pour plus de détails voir les [:ref:`§3.4 <§3.4>`] et [:ref:`§3.5 <§3.5>`].
```

#### 3.3.5 Operands FREQ_MIN/FREQ_MAX/PAS

One gives the parameters of the frequency discretisation.

```text
◊    FREQ_MIN        =    fmin
◊    FREQ_MAX        =    fmax
◊    PAS                =    pas
```

#### 3.3.6 Operands PROL_DROITE and PROL_GAUCHE

```text
◊    PROL_DROITE et PROL_GAUCHE =
```

Define the type of extension to the right (to the left) of the domain of definition of the variable:

| 'CONSTANT' | for an extension with the last (or first) value of the function, |
| --- | --- |
| 'LINEAIRE' | for an extension along the first segment defined (PROL_GAUCHE) or the last segment defined (PROL_DROITE), |
| 'EXCLU' | if extrapolation of the values outside the domain of definition of the parameter is forbidden (in this case if an analysis requests a value of the function outside the domain of definition, the code will stop in fatal error). |

For example:

- PROL_DROITE = 'CONSTANT' , PROL_GAUCHE = 'CONSTANT'

![Figure](/figures/u4.36.02/1000100A000015B400000E29AB3CD3C92C3049F5.svg)

- PROL_DROITE = 'LINEAIRE', PROL_GAUCHE = 'EXCLU'

![Figure](/figures/u4.36.02/100010000000163900000DBFF8606CBAD8F58F83.svg)

**Note:**

The type of extension and of interpolation are independent of one another.

#### 3.3.7 Operand INTERPOL

```text
◊    INTERPOL=
```

Type of interpolation of the function between the values of the domain of definition of the function: one type for the interpolation of the parameter and one for the interpolation of the function. This is obtained by supplying a list of texts among:

```text
INTERPOL = ('LIN', 'LOG')
```

| 'LIN': | linear, |
| --- | --- |
| 'LOG': | logarithmic, |

**Note:**

*If only one value is specified, it is taken into account both for the interpolation of the parameter and for that of the function.* *INTERPOL = 'LOG' is equivalent to ('LOG', 'LOG').*

### 3.4 Keyword CONSTANT

```text
◊    CONSTANT=
```

Factor keyword which makes it possible to define a spectral density function corresponding to a band-limited white noise (constant spectral density over the frequency band considered).

All the keywords under this factor keyword have the same meaning as for the factor keyword KANAI_TAJIMI except AMOR and FREQ_MOY, which have no meaning here.

### 3.5 Operand TITRE

```text
◊    TITRE    =    titre
```

titre is the title of the analysis to be printed at the head of the results. See [U4.03.01](doc:u4.03.01).

### 3.6 Operand INFO

```text
◊    INFO=
```

| 1: | no printout. |
| --- | --- |
| 2: | printing of the characteristics of the interspectral matrix defined. |

## 4 Example

In the example below one defines a spectral density function (in interspectrum terms it is a 1 x 1 matrix) with a constant value:

![Figure](/figures/u4.36.02/1000047E00000F81000009187F402935F28D6CFA.svg)

```text
INTEREXC = DEFI_INTE_SPEC        (
DIMENSION=1,
INFO=2,
CONSTANT=_F(
NUME_ORDRE_I=1,
NUME_ORDRE_J=1,
FREQ_MIN=0.,
FREQ_MAX=100.,
PAS=1.,
PROL_GAUCHE='CONSTANT',
PROL_DROITE='CONSTANT',
INTERPOL='LIN',
VALE_C=(‘RI’,1.,0.),
),
) ;
```

To define the interspectrum of a white noise filtered by an oscillator represented by the KANAI‑TAJIMI filter:

```text
INTKTJ1 = DEFI_INTE_SPEC    (
DIMENSION=1,
INFO=2,
KANAI_TAJIMI=_F(
NUME_ORDRE_I=1,
NUME_ORDRE_J=1,
FREQ_MOY=15.,
AMOR=0.05,
VALE_R=1.,
INTERPOL='LIN',
PROL_GAUCHE='CONSTANT',
PROL_DROITE='CONSTANT',
FREQ_MIN=0.,
FREQ_MAX=30.,
PAS=5.,
),
) ;
```

The 3 parameters of the filter have been given:

1. damping = 0.05,
2. frequency = 15. Hz,
3. level = 1.
