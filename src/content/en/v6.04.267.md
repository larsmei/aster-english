# v6.04.267 SSNV267 – Multiaxial request for KICHENIN_NL law: viscoelastic part

**Summary:**

The purpose of this test is to validate the constitutive law KICHENIN_NL integration algorithm for its nonlinear viscoelastic part. The problem studied is a material point; the mode of solicitation is such that there is an analytical solution including in the nonlinear case.

The problem is implemented only in 3D (modelization A) as the programming of the behavior relationship does not depend on the spatial dimension and there is no specific formulation for either flat or 1D constraints.

## 1 Reference problem

The problem is detailed in the reference [1], in particular the analytical solution. Here, it is only a brief description of its main features. It is now clear that only the viscoelastic branch of the KICHENIN_NL behavior model is mobilized; the elastoplastic branch is limited to elasticity by introducing a sufficiently high plasticity threshold. Validation of this second branch is carried out in [V6.04.268](doc:v6.04.268). Both branches are parallel, there is no coupling other than the sum of the stresses and the tangent operators, which justifies this choice of validation.

### 1.1 Geometry

This is a "point hardware" test. It is based on the SIMU_POINT_MAT command.

### 1.2 Material properties

The material obeys the viscoelastic constitutive lawKICHENIN_NL with the following characteristics:

| ${E}^{p}=400\text{MPa}$ | Young's modulus of the plastic branch |
| --- | --- |
| ${\nu}^{p}=0.15$ | Poisson's ratio of the plastic branch |

| ${\nu}^{v}=0.3$ | Poisson's ratio of the viscoelastic branch |

### 1.3 Boundary conditions and loads

This is a load inimposed constraints, which will be described in §2.1. It is based on two parameters: a characteristic ${t}_{c}$ time that conditions the loading speed and stress stress of the ${\sigma}^{0}$ shock absorber.

| ${t}_{c}=2.5\text{s}$ | Typical loading time |
| --- | --- |

### 1.4 Initial conditions

The system is considered in its natural state at $t=0$. In particular, the viscoelastic deformation is zero.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The methodology described in [1] is used and the results of the test are presented here only. The following constraint is imposed:

$\sigma (t)=s(\frac{t}{{t}_{c}}){\sigma}^{0}+{e}^{v}(\frac{t}{{t}_{c}}){\mathrm{ℂ}}^{p}:{\epsilon}^{0}+s(\frac{t}{{t}_{c}}){\mathrm{ℂ}}^{p}:{{\mathrm{ℂ}}^{v}}^{-1}:{\sigma}^{0}$

où:

> ${\sigma}^{0}$ shock absorber stress (test input parameter)
> ${t}_{c}$ loading time characteristic (test input parameter)
> ${\mathrm{ℂ}}^{p}$ and ${\mathrm{ℂ}}^{v}$ plastic and viscoelastic branch elasticity operators

et

> $s(\overline{t})=\min(\overline{t},1)$
> ${e}^{v}(\overline{t})=\lbrace \begin{array}{cc}\frac{{\overline{t}}^{\gamma +1}}{\gamma +1}& \text{si}\overline{t}\le 1\\ \frac{1}{\gamma +1}+\overline{t}-1& \text{si}\overline{t}\ge 1\end{array}$
> ${\epsilon}^{0}=\frac{{t}_{c}}{{\eta}^{\gamma}}{\left[{\sigma}^{0}:V:{\sigma}^{0}\right]}^{\frac{\gamma -1}{2}}V:{\sigma}^{0}$
> $V:{\sigma}^{0}=(1+{\nu}^{d}){\sigma}^{0}-{\nu}^{d}\text{tr}({\sigma}^{0})I$

The deformation in response to this request is then as follows:

$\epsilon (t)={e}^{v}(\frac{t}{{t}_{c}}){\epsilon}^{0}+s(\frac{t}{{t}_{c}}){{\mathrm{ℂ}}^{v}}^{-1}:{\sigma}^{0}$

The viscous deformation and equivalent viscous deformation shall be:

${\epsilon}^{v}(t)={e}^{v}(\frac{t}{{t}_{c}}){\epsilon}^{0}$     ;    ${\epsilon}_{\mathit{eq}}^{v}(t)={e}^{v}(\frac{t}{{t}_{c}})\sqrt{\frac{2}{3}{\epsilon}^{0}:{\epsilon}^{0}}$

### 2.2 Baseline

We will ensure that the deformation, viscous deformation and the cumulative viscous deformation at the moment $t=2{t}_{c}$ correspond well to the analytical values at the nearest 1% by cutting the load in 100 steps ($\Delta t=2{t}_{c}/100$).
