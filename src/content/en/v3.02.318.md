# v3.02.318 SSLP318 - Propagation of a non-invasive X-FEM crack in I mode

**Summary:**

The purpose of this test is to check that the PROPA_FISS operator correctly handles multi-crack cases.

This is a single $\mathrm{2D}$ plate containing a single crack consisting of two crack bottoms. Several propagations are calculated by the PROPA_FISS operator. It is checked that the stress intensity factors of the propagated crack are correct for propagation in $I$ mode.

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v3.02.318/10000201000003B200000568F53E16703F22447C.png)

**Figure** 1.1-a **: geometry of cracked plate**

Geometrical dimensions of the cracked plate:

| width | $L=1000\mathrm{mm}$ |
| --- | --- |
| height | $H=2000\mathrm{mm}$ |

Initial crack length: ${\mathrm{2a}}_{0}=300\mathrm{mm}$ .

The crack is positioned in the middle of the plate height ($H/2$ ).

### 1.2 Material properties

Young's modulus $E=206000\mathrm{MPa}$

Poisson's ratio $\nu =0.33$

### 1.3 Boundary conditions and loads

![Figure](/figures/v3.02.318/1000020100000356000005BE59586ECB652D94DC.png)

**Figure** 1.3-a **: boundary conditions and loads**

boundary conditions :

> Point $A$ : $\Delta X=\Delta Y=0$
> Points of the lower end of the plate: $\Delta Y=0$

Loading:

> Pressure applied to the top end of the plate: $P=1\mathrm{MPa}$

Three propagations are calculated by imposing a crack advance equal to $30\mathrm{mm}$ at each crack bottom. As a result of the symmetry of geometry, boundary conditions and loading, the advances of the two crack bottoms are always equal to the pre-imposed advance.

## 2 reference solution

### 2.1 Method of calculation

Three crack propagations are calculated. Both crack bottoms always advance from the same distance and their stress intensity factors are always equal between them.

The stress intensity factors can be calculated using the following equations [bib1]:

> ${K}_{I}=-P\cdot \sqrt{\pi \cdot a\cdot {(\cos(\frac{\pi a}{L}))}^{-1}}$
> ${K}_{\mathrm{II}}=0$

### 2.2 Quantities and reference results

For the three propagations calculated in the tests, the half-length of the crack is as follows:

| **Propagation** | **a** [ $\mathrm{mm}$ ] |
| --- | --- |
| 1 | 180.0 |
| 2 | 210.0 |
| 3 | 240.0 |

**Table** 2.1

The expected ${K}_{I}$ value is therefore the following for each propagated fund:

| **Propagation** | ${K}_{I}$ [ $\mathrm{Pa}\sqrt{\mathrm{mm}}$ ] |
| --- | --- |
| 1 | 2.2997E+07 |
| 2 | 2.5878E+07 |
| 3 | 2.8894E+07 |

**Table** 2.2

The expected ${K}_{\mathrm{II}}$ value is always zero.

### 2.3 Bibliography

[1] D.Broek, "Elementary engineering fracture mechanics", Martinus Nijhoff Publishers, The Hague, The Netherlands, 1982

## 3 Modelling A

### 3.1 Modelling characteristics

UPWIND is used by PROPA_FISS to solve crack propagation equations.

**No auxiliary grid** is used. This is possible because the mesh of the structure is very regular.

### 3.2 Mesh characteristics

The structure is modelled by a mesh composed of 1440 elements QUAD4 (see ).

![Figure](/figures/v3.02.318/1000020100000180000002E3EB49BD20839025B0.png)

**Figure** 3.2-a **: mesh of the structure**

The mesh is very coarse to reduce the calculation time. It is more refined in the crack propagation area. In this area the elements dimension is $25\times 25\mathrm{mm}$. The largest element used has a dimension equal to $25\times 100\mathrm{mm}$.

### 3.3 Tested quantities and results

The ${K}_{I}$ and ${K}_{\mathrm{II}}$ values for both crack bottoms are tested after each propagation. To check whether these values are correct, a relative tolerance of 5% is used for ${K}_{I}$ values. However, to check whether the ${K}_{\mathit{II}}$ value is zero, an absolute tolerance (threshold value) is used for ${K}_{I}$ values: ${K}_{\mathit{II}}$ is considered to be zero if its value is less than 1% of ${K}_{I}$ value. In this case, the ${K}_{\mathit{II}}$ value can be disregarded.

The maximum value of ${K}_{I}$ and ${K}_{\mathit{II}}$ between the two crack bottoms is tested.

| **Propagation** | ${K}_{I}$ reference [ $\mathit{Pa}\sqrt{\mathit{mm}}$ ] | **Tolerance** [%] |
| --- | --- | --- |
| 1 | 2.2997E+07 | 5.0 |
| 2 | 2.5878E+07 | 5.0 |
| 3 | 2.8894E+07 | 5.0 |

| **Propagation** | **Max** ${K}_{\mathit{II}}$ [ $\mathit{Pa}\sqrt{\mathit{mm}}$ ] | ${K}_{I}$ reference [ $\mathit{Pa}\sqrt{\mathit{mm}}$ ] | ${K}_{\mathit{II}}$ threshold [ $\mathit{Pa}\sqrt{\mathit{mm}}$ ] |
| --- | --- | --- | --- |
| 1 | 7.4881E+03 | 2.2997E+07 | 2.2997E+05 |
| 2 | 4.0283E+03 | 2.5878E+07 | 2.5878E+05 |
| 3 | 2.0639E+04 | 2.8894E+07 | 2.8894E+05 |

### 3.4 Remarks

All tested values are within the tolerances used. This means that the UPWIND method correctly calculates both the position of the two crack bottoms and the level sets.

The error on the ${K}_{I}$ values is almost zero and the ${K}_{\mathrm{II}}$ values are still around 0.1% of the ${K}_{I}$ values. The results obtained are therefore very satisfactory.

## 6 Summary of the results

All the methods used (UPWIND,SIMPLEXE, GEOMETRIQUE) were able to calculate the position of a crack formed by two bottoms and propagating in $I$ mode. The stress intensity factors were calculated correctly and the methods used correctly calculate the level sets at each propagation.

The results obtained enable the implementation of the multi-cracking (case of a single crack with multiple bottoms) in the PROPA_FISS operator to be validated.
