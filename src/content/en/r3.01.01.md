# r3.01.01 Shape functions and integration points of the finite elements

**Summary:**

The geometry and the topology of the finite elements are described; for each reference element, the expression of the shape functions and the various families of integration points, together with the associated weights, are detailed.

## 1 Introduction

One calls a *finite element* a triplet (phenomenon, modelling, mesh-cell type). There are three principal phenomena: `MECANIQUE`, `THERMIQUE` and `ACOUSTIQUE`.

There exist numerous modellings; for example, for the phenomenon `MECANIQUE`: `3D`, `C_PLAN`, `D_PLAN`, `AXIS`, `DKT`, `POU_D_E`, ...

For a given modelling (for example `3D`) of a phenomenon (for example `MECANIQUE`), there exist in general several finite elements: one element per supported mesh-cell type: `HEXA8`, `HEXA20`, `PENTA6`, ...

In the end, there therefore exist a very large number of finite elements.

On the other hand, the mesh-cell types are few in number: `POI1`, `SEG2`, `SEG3`, `SEG4`, `TRIA3`, `TRIA6`, `TRIA7`, `QUAD4`, `QUAD8`, `HEXA8`, `HEXA20`, `TETRA4`, `TETRA10`, etc.

In general, each finite element, in order to carry out its elementary calculations, uses the notions of interpolation function (or shape function) and of integration scheme. In general also, these shape functions and these integration schemes are defined on an element said to be "of reference", whose geometry is defined in a coordinate system often called: $(\xi ,\eta ,\zeta )$ . The passage from the reference element to the real element is carried out by means of a geometric transformation which uses the same interpolation functions. The element is then said to be "isoparametric". These notions are very well explained in  or in  (which is freely accessible online).

The large number of finite elements of the code, combined with the restricted number of mesh-cell types, leads to the fact that there exist several finite elements relying on one and the same mesh-cell type; for example the eight-node quadrilateral called `QUAD8` supports more than 60 different finite elements.

In theory, each finite element may choose its interpolation functions and its integration schemes as it sees fit. But in practice, almost all the finite elements relying on the same mesh-cell type use the same reference element, the same shape functions and the same integration schemes. The aim of this document is to describe these various reference elements.

For each reference element (called in the remainder of the document `ELREFE`), one will indicate:

- the support mesh cell, the number of nodes, their local numbering and their coordinates,
- the algebraic expressions of the shape functions and of their first derivatives (and sometimes second derivatives)
- the families of integration points, which will be named. For each family, the number of points, their coordinates and their integration "weights" will be given. The sum of these weights must give the "volume" of the reference element. For example, the "volume" of the reference quadrangle ($-1\le \xi \le +1$ , $1<\eta <+1$ ) is equal to 4.
