# v1.01.274 ZZZZ274 - Validation for non-symmetric discretes

**Summary:**

These are test cases without physical reality, which can be used to validate the use of nonsymmetric discretes.

The values are given in the AFFE_CARA_ELEM command, the fact that the discrete is nonsymmetric is also specified in this command by SYME = ‘NON'.

| Modelling | **Computer operator** | Discreet | Benchmark |
| --- | --- | --- | --- |
| a | MECA_STATIQUE | 2D, DIS_T_N | Global |
| b | MECA_STATIQUE | 2D, DIS_T_N | Local |
| c | MECA_STATIQUE | 3D, DIS_T_N | Global |
| d | MECA_STATIQUE | 3D, DIS_T_N | Local |
| e | STAT_NON_LINE | 3D, DIS_T_L | Local & Global |
| f | STAT_NON_LINE | 3D, DIS_T_N | Local & Global |

This documentation is deliberately succinct.
