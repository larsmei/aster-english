## 2 reference solution

### 2.1 Elastic solution

In elasticity, for an infinite ** plate,** with a $a$ diameter hole, subject to $P$ loading on $y$ infinitely, the analytical solution in flat stresses and polar coordinates $(r,\theta )$ is [bib1]:

${\sigma}_{\mathit{rr}}=\frac{P}{2}\left[(1-{(\frac{a}{r})}^{2})-(1-4{(\frac{a}{r})}^{2}+3{(\frac{a}{r})}^{4})\cos2\theta \right]$

${\sigma}_{\theta \theta }=\frac{P}{2}\left[(1+{(\frac{a}{r})}^{2})+(1+3{(\frac{a}{r})}^{4})\cos2\theta \right]$

${\sigma}_{r\theta }=\frac{P}{2}\left[(1+2{(\frac{a}{r})}^{2}-3{(\frac{a}{r})}^{4})\sin2\theta \right]$

In particular, at the edge of the hole ($r=a$ ) : ${\sigma}_{\theta \theta }=P[(1+2\cos2\theta )]$

And along the $x$ axis: ${\sigma}_{\theta \theta }={\sigma}_{yy}=\frac{P}{2}\left[(1+{(\frac{a}{r})}^{2})+(1+3{(\frac{a}{r})}^{4})\right]$

Digitally, for $P=1\mathit{MPa}$ , and for an infinite ** plate** , we have:

| Point | Component | Calculation | $\mathrm{MPa}$ |
| --- | --- | --- | --- |
| $A$ | $\mathit{SIXX}$ | ${\sigma}_{\theta \theta }(r=a,\theta =\pi /2)$ | –1 |
| $B$ | $\mathit{SIYY}$ | ${\sigma}_{\theta \theta }(r=a,\theta =0)$ | 3 |

For a **-finished** plate, the abacus [bib1] allows to obtain the stress concentration coefficient, and it is found that for a traction of $1\mathrm{MPa}$, the maximum $\mathit{SIYY}$ is about $3.03\mathit{MPa}$ at point $B$.

## 3 Modelling A

### 3.1 TP procedure

The purpose is to complete the elastic calculation by generating geometry, mesh and command file AsterStudy using the Salome-Meca platform.

The Modelling is C_PLAN elastic. A quarter of the plate is modelled. The controls required for counting (curve tracks and post-processings graphics) will also be defined.

#### 3.1.1 Geometry

The flat surface of the upper right quarter of the plate will be created.

Launch the Geometry module.

The main steps to build this geometry are as follows:

- To define the contours of the plate, you can, for example, use the "Sketcher" tool (Menu New Entity → Basic→2D Sketch). It is easier to start with the point $B$ of $(10,0)$ coordinates. Starting from $B$ , for circle arc, use Element Type(Arc) and Destination(Direction/Perpendicular), and set the radius 10 and angle and the 90° radius. You get the point $A$ . Then use Element Type(Line) and give the other points ($G$ , $F$ , $D$ ) by their absolute coordinates. Finish with Sketch Close.
- A closed contour (Sketch_1) is then obtained on which one must build a face (Menu New Entity →Build →Face). The geometry of the plate is then complete.
- Build useful groups for calculation. Here we build the 3 groups of edges on which the boundary conditions (symmetries and loading) will be based: left for the $\mathit{AG}$ edge, top for the $\mathit{GF}$ edge and bottom for the $\mathit{BD}$ edge. Menu New Entity →Group →Create Group: Select the geometric entity type (here the line, edge) and select the edge directly from the graphic window, then click Add, then an object number must appear. We can change the name of the group before validating by Apply.

#### 3.1.2 Mesh

A mesh plane of the upper right quarter of the plate, in elements order 2, will be created to ensure sufficient accuracy.

Run the Mesh module.

The main steps to generate the mesh are as follows:

- Build the mail (Menu Mesh→ Create Mesh). Select the geometry to be knit Face_1, then choose Algorithm → NETGEN 1D-2D by addingHypothesis → NETGEN 2D Parameters. In this case, selectFineness→ Fine and check the box Second Order before Apply.
- Calculate themail(MenuMesh→ Compute). A window of mesh information must appear, and then you get a free mesh.
- Create the corresponding mail groups for the geometric groups(Menu Mesh→Create Groups from Geometry).Select all 3 groups of edges under Geometry module and then Apply. We get 3 groups of edges on the mesh.
- To obtain better accuracy, we will move the mesh from linear to quadratic, thanks to the tool "Modification -> Convert to/from quadratic". The most curious can compare the differences in results between the two types d
- (Optional) Exportmailing in MED format: select Mesh_1 and right click, then choose Export / MED file.

**Notes:**

*This mesh is fine enough (with quadratic elements) to have a good approximation of the elasticity solution: for example, if you compare* ${\sigma}_{\theta \theta }$ *on the edge of the hole with the analytical solution, you get a difference of less than 5%.*

*The geometry and parameters of mesh are defined in the file* forma01a.datg * associated with the test. The mesh produced is stored in the file* forma01a.mmed *.*

### 3.2 Creation and launch of the calculation case (via AsterStudy)

Launch the AsterStudy module.

Then in the left column, click on the Case View tab. In the Data Settings box, click on the right at CurrentCase and choose Add Stage. C

Note:Search for orders by Menu Commands→ Show All gold by the 10 calculation categories: Mesh, Model Definition, Material, Functions and Lists, BC and Load, Pre Analysis, Post Processing, Fracture and Fatigue, Output.

The main steps for creating and launching the calculation case are:

- Read mesh in MED format: Mesh Category / LIRE_MAILLAGE Command.The mesh in the MESH module is available in the list. Otherwise the button behind allows you to choose an mesh in the directories.
- Orient the normal edge on which the traction load will be applied: Mesh Category / MODI_MAILLAGE / ORIE_PEAU_2D command by affecting the group high in GROUP_MA.We keep the same name of the mesh using weer.
- Set the finished elements used: Category Model Definition / AFFE_MODELE command for 2D flat stress Modelling (C_PLAN). Add a term in AFFE. In this term, assign OUI to TOUT elements, and choose the MECANIQUE phenomenon, and add the 2D flat stress term ( C_PLAN ) in the Modelling
- Define material: Material Category / DEFI_MATERIAU Command.Choose ELAS and enter the values of Young's modulus and Poisson's ratio.
- Assign material: Material Category / AFFE_MATERIAU Command.Definite at least one option between mesh and MODELE.Add a term in AFFE, and assign the material defined to TOUT.
- Mechanical boundary conditions Assignments and Loading: Category BC and Load / AFFE_CHAR_MECA Command:

  - for symmetry on the plate quarter: DDL_IMPO. For left, DX=0, and for bottom, DY=0.
  - for traction: PRES_REP. For the top, grab traction at PRES (so negative).
- Solve the static linear mechanical problem: Category Analysis / MECA_STATIQUE control by giving material (CHAM_MATER), Modelling (MODELE), boundary conditions and loading (EXCIT).
- Calculate the field: Post Processing Category / CALC_CHAMP command by enabling activating (to keep the same name of the input object in the command). That is, we will enrich the MECA_STATIQUE concept by taking the same name.

  - for the calculation of the stress field: CONTRAINTE / SIGM_ELNO (contraints by elements to nodes), SIGM_NOEU (contraints overall to nodes).
  - for the calculation of the equivalent stress field: CRITERES / SIEQ_ELNO (by elements to nodes), SIEQ_ELGA (by elements to Gauss points), SIEQ_NOEU (overall to nodes).
- Print the results of a calculation in MED format: Category Output / Command IMPR_RESU.Add a term in RESU, and choose the results to print. Set the output file (.rmed) by UNITE.
- To start the calculation case, in the left column, click on the History View tab.You must save the study first, and select CurrentCase. Add Stage_1 by selecting run (green cross). Before running, check the desired calculation parameters in the Run Parameters box: time limit of calculation, memory, code_aster version etc.

## 6 Modelling D

### 6.1 TP procedure

The purpose is to perform the elastic simulation without meshing the hole, using the X-FEM method.

For this purpose, the concept of interface (limiting the hole) is used, with an interface being seen as an "infinite" crack (no crack front). The interface is then represented by a single Level Set (Level Set Normal), separating two solids, without contact on the interface. Thus, a hole (empty) is modelled because the solid inside is isolated from the rest of the structure on which the pressure load is applied.

Geometry and mesh and command file AsterStudy will be generated using the Salome-Meca platform.

The Modelling is C_PLAN elastic. A quarter of the plate is modelled.

#### 6.1.1 Geometry

The geometry is the upper right quarter of the rectangular plate, without holes.

Launch the Geometry module.

The main steps to build this geometry are as follows:

- To create the face, one can, for example, use the "rectangle" tool (MenuNew Entity / Primitives / Rectangle), and possibly translater (Menu Operations / Transformation / Translation).
- Build the groups of edges on which the boundary conditions (symmetries and loading) (Menu New Entity →Group →Create Group) will be based. Select the type of geometric entity (here the line, edge) and select the edge directly from the graphic window. Then click Add. An object number must then appear. The name of the group can be changed before validating by Apply. Build the 3 groups of edge useful for calculation: left for the $\mathit{AG}$ edge, top for the $\mathit{GF}$ edge and bottom for the $\mathit{BD}$ edge.

#### 6.1.2 Mesh

A mesh plane of the upper right quarter of the plate, in elements order 2, will be created to ensure sufficient accuracy.

Run the Mesh module.

The main steps to generate the mesh are as follows:

- Build the mesh (Menu Mesh→ Create Mesh). Select the mesh geometry, then the NetGEN 1D-2D algorithm with the Netgen 2D Parameters hypothesis. In this case, selectFineness→ Fine and check the Second Order box.
- Calculate themail(MenuMesh→ Compute).
- Create the corresponding mesh groups for the geometric groups (Menu Mesh→Create Groups from Geometry).Select all the geometric groups. You get 3 groups of edges on the mesh.
- Export mail in MED format.

### 6.2 Creation and launch of the calculation case (via AsterStudy)

Launch the AsterStudy module.

Then in the left column, click on the Case View tab.

The command file of the calculation case is defined.

Note: To add commands: Commands Menu→ Show All.

The main steps for creating and launching the calculation case are:

- Read mesh in MED format: LIRE_MAILLAGE command.
- Orient the mesh on the edge affected by the load: Command MODI_MAILLAGE / ORIE_PEAU_2D using the top group.
- Set the finished elements used: AFFE_MODELE command for 2D flat stress Modelling (C_PLAN).
- Set interface: DEFI_FISS_XFEM with crack shape (FORM_FISS / ELLIPSE) and discontinuity type.
- Create enriched finished elements (MODI_MODELE_XFEM). And name a new name for the X-FEM model.
- Set the material: DEFI_MATERIAU command.
- Assign material: AFFE_MATERIAU command on X-FEM model.
- Assign mechanical boundary conditions and loading: AFFE_CHAR_MECA to X-FEM:

  - for symmetry on the plate quarter: Force DOF (DDL_IMPO),
  - for traction: FORCE_CONTOUR.
- Solve the static linear mechanical problem: MECA_STATIQUE control on the X-FEM model.
- Createmail: POST_MAIL_XFEM command. And name a new name for the mesh.
- Set the finished elements used: AFFE_MODELE command for 2D flat stress Modelling (C_PLAN). And name a new model name.
- Createoutput of visualization: POST_CHAM_XFEM command. And name a new name of the result.
- Calculate field: CALC_CHAMP command.

> The POST_CHAM_XFEM concept will be enriched by the same concept name.

  - for the calculation of the stress field by elements to nodes: CONTRAINTE / SIGM_ELNO.
  - for the calculation of the stress field equivalent to elements to nodes: CRITERES / SIEQ_ELNO.
  - for the calculation of the equivalent stress field by elements at Gauss points: CRITERES/ SIEQ_ELGA.
- Print the results of a calculation in MED format: IMPR_RESU command.
- To start the calculation case, in the left column, click on the History View tab.

**Note:**

*The rigid modes of the hole are blocked by the symmetry conditions applied. In the case of a Modelling of the entire plate, the rigid modes of the plate and also of the hole should have been blocked.*
