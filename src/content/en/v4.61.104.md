# v4.61.104 MTLP104 - Steel Income Model

**Summary:**

This test case is a validation of metallurgical transformation models for the
in the case of the phases of the steels.
A cube model is used with a temperature transient imposed and we compare
the results between a Python script performing the calculation of the income phases and the command
[CALC_META](doc:u4.85.01) with the REVENU keyword.

## 2 reference solution

### 2.1 Baseline

The results are compared between a calculation by
a Python script (modelization A), then by the [CALC_META](doc:u4.85.01) command with the
REVENU key word (modelization B).

For hardness calculation (DURT_ELNO), as it is a law of linear mixtures, the solution
is analytical.

We have 70% ferrite and 30% bathite, Vickers hardness is worth
$H_{V}=\sum_{k}{Z}_{k}{H_{V}}_{k} = 0,7 \times 200 + 0,3 \times 300 = 230$.

And since we took `F3_REVENU_DURT = F3_DURT` and `F4_REVENU_DURT = F4_DURT`, we'll find
Strictly the same after income.
