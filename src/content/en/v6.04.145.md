# v6.04.145 SSNV145 - Cantilever plate in large rotations subjected to a follow-up pressure

**Summary**

A quasi-static calculation of clamped elastic plate on one side is presented and subjected to a follower pressure. The following load involves changes in the linearised equation system. The equation system solved by NEWTON method is non-symmetric. The stiffness tangent matrix (internal forces) and the contribution of pressure forces following the deformed structure are nonsymmetric. This Modelling allows testing COQUE_3D finite geometric nonlinear objects using the update algorithm of the large 3D rotations GROT_GDEP in STAT_NON_LINE in the presence of a following type pressure. The reference solution is obtained by elements finished SAMCEF software.

## 2 reference solution

### 2.1 Calculation method used to obtain the reference solution

The reference solution [bib4] is the one obtained with the SAMCEF [bib1] software. The Modelling is based on a resulting stress hull theory with a co-rotational [bib3] formulation and regular DSQ [bib2] discretization.

![Figure](/figures/v6.04.145/100005C8000069BB00001B7E2B88C3BDA9CC6BD1.svg)

The mesh is a regular mesh of $20\times 1$ elements quadrilateral to 4 nodes each.

### 2.2 Baseline

We test the pseudo-temporal evolution of $\mathit{DX}$, $\mathit{DZ}$, $\mathit{DRY}$ at the mid point segment.

### 4.5 Remarks

The mesh of Modelling B is a regular but non-symmetric mesh. The mesh of the reference solution is built with 20 quadrangles at 4 nodes each.

The value of the COEF_RIGI_DRZ = 0.001 is used.

Although the problem studied is a thin hull problem

![Figure](/figures/v6.04.145/Object_8.svg)

, the elements triangles reach a high load level: 22 steps for 26 with quadrangles. The solution with elements triangle is therefore very satisfactory.

## 5 Summary of the results

The solutions obtained by *Code_Aster* are very close to the reference solution of SAMCEF software, with a mesh twice as refined. The values of displacement at the end of the beam differ by no more than 2.5% for the first quadrangle model and by no more than 6.7% for the second triangle model.
