# v1.01.191 ZZZZ191 – Validation of AFFE_CHAR_MECA and AFFE_CHAR_CINE Operators in the case of a required displacement

**Summary:**

The objective of this test case is to validate the AFFE_CHAR_MECA and AFFE_CHAR_CINE operators in the case of an imposed displacement. The principle of validation is to do the same nonlinear calculation in two different ways:

- STAT_NON_LINE with dualised (regular) loads created via the AFFE_CHAR_MECA(keyword DDL_IMPO) operator,
- STAT_NON_LINE with kinematic loads created via the AFFE_CHAR_CINE(keyword MECA_IMPO) operator,

For each calculation the calculation resume (wrong) is checked.

The node displacement and the Gauss point constraint are tested.

This documentation is deliberately succinct.
