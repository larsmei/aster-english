# v3.02.111 FORMA05 - Practical work of the "Rupture Mechanics" training: Traction cracked plate (SENT)

**Summary:**

This $\mathrm{2D}$ test (plane deformations) models a cracked plate (pure mode I) into a quasi-static form. This is a Modelling of the SENT test piece (Single Edge Notched Specimen in Voltage).

This test is used in the "Mechanics of the Rupture" formation because of the speed of the execution time and the existence of an analytical solution. It allows to become familiar with the post-processings in linear elastic break mechanics (operators `CALC_G`, and `POST_K1_K2_K3`) for FEM and X-FEM modelling. The educational objectives are the illustration of the influence of mesh (mesh with linear / quadratic / quadratic elements + Barsium) and the illustration of independence to the coronas of integration for the G-theta method.

This test case has 4 modellings:

- Modelling A: FEM, whole plate (without symmetry condition), mesh free
- Modelling B: FEM, (half-)plate with symmetry condition, mesh free
- Modelling C: X-FEM, whole plate (without symmetry condition), mesh set
- Modelling D: FEM, whole plate (without symmetry condition), mesh radiating

Only Modelling A is the subject of a TP session as part of the training.

## 1 Reference problem

### 1.1 Geometry

A rectangular $H=2\,\mathrm{m}$ height plate, $W=1\,\mathrm{m}$ width, with flat deformation, with a horizontal crack leading to depth $a=0,1\,\mathrm{m}$ is considered. This geometry is presented on the v3.02.111-fig-geom.

![Figure](/figures/v3.02.111/schema_plaque.png)

*: Schematic of the cracked plate*

### 1.2 Material properties

A homogeneous isotropic material with linear elasticity is considered to have the following characteristics:

- Young's modulus :  $E=210000\,\mathrm{MPa}$
- Poisson's ratio : $\nu=0,3$

### 1.3 Boundary conditions and loads

The plate is loaded in traction: $\sigma=10\,\mathrm{MPa}$.

## 2 reference solution

### 2.1 Method used for reference solution

The reference solution for the stress factor of the I $K_I$ mode is expressed as follows [1]:

$K_I=\sigma \sqrt{\pi a}F\left(\frac{a}{W}\right)$

with $F\left(\frac{a}{W}\right)=1,122-0,231\left(\frac{a}{W}\right)+10,550{\left(\frac{a}{W}\right)}^{2}-21,710{\left(\frac{a}{W}\right)}^{3}+30,382{\left(\frac{a}{W}\right)}^{4}$

This expression of $F$ is derived from a least square regression (Gross 1964; Brown 1966). The announced accuracy of this formula is 0.5% for $\frac{a}{W}{\le}0,6$.

Note: in [1] are given other formulas for $F\left(a/W\right)$, e.g. a formula due to Tada (1973) that shows a precision of less than 0.5% for any $a/W$ ratio.

The $G$ energy return rate is obtained using the formula d-Irwin: $G=\frac{1-{\nu}^2}{E} K_I^2$. The expected accuracy for the $G$ reference value will be less than 1%.

### 2.2 Baseline

With the numerical values of the statement, we find:

$F\left(a/W\right)\approx 1,186$

${K}_{I}\approx 6,646 \,\mathrm{MPa.\sqrt{m}}$

$G\approx 191,4 \,\mathrm{J.m^{-2}}$

*Note*: Using the alternative formula of Tada 1973, $F\left(a/W\right)\approx 1,196$ is obtained, i.e. an difference between the 2 references of approximately 0.8%. Considering the details announced for each reference, it is inferred that the theoretical value lies between these 2 references. It would therefore certainly be more wise to choose the average value $F\left(a/W\right)\approx 1,191$ as a reference value. However, in the next few years, reference solution is considered to be the one from the regression by least squares (Gross 1964; Brown 1966).

### 2.3 Bibliographical references

  1. Tada, P. Paris, G. Irwin, The stress analysis of cracks manual, 3rd edition, 2000

## 7 Executive summary

This TP allows to highlight:

- The two methods of calculating G and K available in Code_Aster
- Improved accuracy of results with the use of Barsium elements (FEM)
- The possibility of simulating a crack without the mesh (X-FEM)
- The invariance of the results to the choices of crowns;
