# v7.02.300 HPLP300 - Plate with Young's modulus temperature function

**Summary:**

This thermo-elastic test compares the solution obtained by *Code_Aster* to an analytical solution when the Young's modulus varies in a nonlinear way from temperature.

This test is derived from the $\mathrm{3D}$ HPLV100 test described in [V7.03.100](doc:v7.03.100) (parallelepiped with temperature dependent Young's modulus).
