# v1.01.278 ERREU04 - Simple singularity detection in broken commands

**Summary:**

This test validates the issuance of an error message when a simple singularity is detected (absence or overabundance of blocks) by direct linear solvers (MUMPS, LDLT and MULT_FRONT) used in split commands (FACTORISER, RESOUDRE).

## 1 Test principle

This test is used to validate the sending of a few messages by FACTORISER or RESOUDRE commands in the case of a symmetrical matrix:

- First case: there is a blockage missing. In this case, you get FACTOR_20/77 for LDLT, MULT_FRONT and MUMPS when $\mathrm{NPREC}>0$ and FACTOR_57 for MUMPS when $\mathrm{NPREC}<0$.
- Second case: there is an overabundant block. FACTOR_21/76 is obtained for LDLT, MULT_FRONT and MUMPS when $\mathrm{NPREC}>0$ and FACTOR_42 for MUMPS when $\mathrm{NPREC}<0$.
- Last case: Check that the FACTOR_80 message is sent when using the TYPE_RESOL='SYMDEF' parameter of the MUMPS solver, while the matrix to be reversed is not symmetrically defined as positive.
