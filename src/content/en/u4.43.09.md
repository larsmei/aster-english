# u4.43.09 Operator DEFI_REPERE

## 1 Purpose

Create an orientation field CHAM_ELEM of the quantity CAMA_R from the model.

The field created may be used in AFFE_CARA_ELEM/MASSIF with the keyword CHAM_ORIE and in AFFE_MATERIAU
in order to define, for example, directions of orthotropy.

Make it possible to assign local axes to 3D or 2D elements by the keywords:

- ANGL_NAUT (3 nautical angles),
- ANGL_EULER (3 Euler angles),
- ORIG_AXE and ANGL_AXE (origin and axis of the cylindrical frame).

One specifies that ANGL_NAUT or ANGL_EULER is used for an orthotropic or transversely isotropic material with fixed axes; ORIG_AXE and ANGL_AXE are used for an orthotropic or transversely isotropic material whose axes follow a cylindrical frame, and only in that case.

## 2 Syntax

```text
cham_elem = DEFI_REPERE(
    ◆ MODELE = modele,
    ◆ DEFI = _F(
         ◆ / TOUT = "OUI" (ou non renseigné),
           / GROUP_MA = list[grma],
         ◆ SYST_COOR = / "CARTESIEN",
                       / "CYLINDRIQUE",
         # Si: equal_to("SYST_COOR", 'CARTESIEN')
             ◆ / ANGL_EULER = list[float],
               / ANGL_NAUT = list[float],
         # Si: equal_to("SYST_COOR", 'CYLINDRIQUE')
             ◇ & ORIG_AXE = list[float],
               & ANGL_AXE = list[float],
      ),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Keyword MODELE

```text
♦ MODELE = modele,
```

Name of the model.

### 3.2 Keyword DEFI

```text
◆ DEFI = _F(
    ◆ / TOUT = "OUI" (ou non renseigné),
    / GROUP_MA = list[grma],
    ◆ SYST_COOR = / "CARTESIEN",
                / "CYLINDRIQUE",
    # Si: equal_to("SYST_COOR", 'CARTESIEN')
        ◆ / ANGL_EULER = list[float],
        / ANGL_NAUT = list[float],
    # Si: equal_to("SYST_COOR", 'CYLINDRIQUE')
        ◇ & ORIG_AXE = list[float],
        & ANGL_AXE = list[float],
),
```

#### 3.2.1 Operands TOUT='OUI', GROUP_MA

The keywords TOUT and GROUP_MA make it possible to designate the set of mesh cells which will be assigned.

If a mesh cell appears in several occurrences of the factor keyword DEFI, the overloading rule is applied: it is the last assignment which takes precedence [U2.01.08](doc:u2.01.08).

#### 3.2.2 Operand SYST_COOR

The keyword SYST_COOR makes it possible to choose the type of coordinate system, "CARTESIEN" or "CYLINDRIQUE".

#### 3.2.3 Operand ANGL_NAUT

Definition of the 3 nautical angles $\alpha$ , $\beta$ , $\gamma$ which make it possible to orient the local axes $(x,y,z)$  and the frame of orthotropy $(N,L,T)$. For further information, see §10.4 of [U4.42.01](doc:u4.42.01).

#### 3.2.4 Operand ANGL_EULER

Definition of the 3 Euler angles $\alpha$ , $\beta$ , $\gamma$ which make it possible to orient the local axes $(x,y,z)$  and the frame of orthotropy $(N,L,T)$. For further information, see §13.4 of [U4.42.01](doc:u4.42.01).

#### 3.2.5 Operands ORIG_AXE/ANGL_AXE

These keywords are to be given in order to define local axes for which one will use a property of rotational symmetry, or of transverse isotropy (for example: an orthotropic structure with cylindrical symmetry).

In 3D, ANGL_AXE = $(\alpha, \beta)$ defines the axis of revolution $\mathrm{x1}$, $(\alpha, \beta)$ being the first two nautical angles, ORIG_AXE = $(x1 , x2 , x3)$ defines a point $\mathrm{O1}$ of the axis. For further information, see §13.5 of [U4.42.01](doc:u4.42.01).

## 4 Examples

```python
cham_orie = DEFI_REPERE(
    MODELE=MO,
    DEFI=(
        _F(
            TOUT="OUI",
            SYST_COOR="CARTESIEN",
            ANGL_NAUT=(0, 0, 90),
        ),
        _F(
            GROUP_MA=("GMA1", "GMA2",),
            SYST_COOR="CYLINDRIQUE",
            ORIG_AXE=(0, 0, 0),
            ANGL_AXE=(45, 0),
        ),
        _F(
            GROUP_MA=("GMA3"),
            SYST_COOR="CARTESIEN",
            ANGL_EULER=(0, 45, 0),
        ),
    ),
)
```

On the set of the mesh cells of the model (except the mesh cells contained in the groups: "GMA1", "GMA2", "GMA3") a CARTESIEN frame is assigned with a nautical angle $(0, 0, 90)$.

On the mesh cells contained in the groups "GMA1", "GMA2" a CYLINDRIQUE frame of origin $(0, 0, 0)$ and angle $(45, 0)$ is assigned.

On the mesh cells contained in the groups "GM3" a CARTESIEN frame is assigned with an Euler angle $(0, 45, 0)$.
