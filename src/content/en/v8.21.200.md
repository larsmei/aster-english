# v8.21.200 FDLL200 - clamped pipework and free by fluid beam-structure

**Summary:**

The objective is to calculate the low frequency behaviour of a pipe filled with water. The pipe has a circular cross section; it is clamped at one end and free from the other.

The elements of elasto-acoustic beam available in *Code_Aster* that takes into account the fluid interaction structure (PHENOMENE= 'MECANIQUE', MODELISATION= 'FLUI_STRU').

The boundary conditions are mechanical to simulate the structure's clamped support, and acoustic to simulate the fluid tank condition in this point (boundary conditions of zero pressure and zero fluid displacement potential).

The fluid that is considered is a heavy fluid so as to highlight the phenomenon of coupling between the fluid column and the constitutive structure of the piping. The properties of the fluid and the material of the structure are chosen so that the speed of a wave spreading in the fluid is the same as the speed of a mechanical wave spreading in the piping. Under these conditions, the first mode of the structure resonates at the same frequency as the fluid column.

Modelling A is based on a constant section and an exact analytical solution exists which provides the first eigenfrequency. Comparison with the results produced by *Code_Aster* (search for clean values) validates the consideration of fluid coupling structure in the longitudinal direction, with the transverse effects being non-existent in this model. This allows partial testing of the stiffness matrix and mass one.

The modellings B and C are used to validate the case of variable circular sections. In the first section, the section is declared variable type (VARI_SECT='HOMOTHETIQUE' in AFFE_CARA_ELEM) but the parameters define a constant section. The solution is therefore the same as for Modelling A. In the last model, the section is actually variable and then only one test of non-regression is performed.

The physical characteristics of the material constituting the tube are as follows:

longitudinal wave speed: ${c}_{s}=\sqrt{\frac{E}{{\rho}_{s}}}=1,0·{10}^{3}m/s$

The physical characteristics of the fluid material in the tube are as follows:

density: ${\rho}_{f}=1,0·{10}^{3}\mathrm{kg}/{m}^{3}$

speed of sound: ${c}_{f}=1,0·{10}^{3}m/s$

### 1.3 Boundary conditions and loading

- Move only on $x$ axis.
- Clamped support of the pipework in the end $A$.
- Free pipe at the end $B$.
- For the fluid tank condition $A$ end.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The vibrational behaviour of a fluid-filled pipe is studied. The pipe is clamped at one end and free at the other end. The pipe section is constant and circular. The low frequencies of longitudinal pipe behaviour are examined.

The following are defined:

| Tube length: | $L$ |
| --- | --- |
| Young's modulus of the hose: | $E$ |
| external diameter of the pipe: | $D$ |
| wall thickness: | $\mathrm{ep}$ |
| area of solid section: | ${S}_{s}$ |
| area of fluid section: | ${S}_{f}$ |
| speed in the pipe (structure): | ${c}_{s}$ |
| speed in the fluid: | ${c}_{f}$ |

The fluid and pipe characteristics were selected to have the following relationship:

${c}_{f}={c}_{s}=\sqrt{\frac{E}{{\rho}_{s}}}=c=1000m/s$

In this particular case of equality of speed, it is shown [bib2] that the first frequency proper to the coupled problem is such that:

$\mathrm{tg}(\frac{\omega L}{{c}_{s}})=\sqrt{\frac{{S}_{s}}{{S}_{f}}.\frac{E}{{\rho}_{f}{c}^{2}}}$

It is valid in this case: $f=157,94\mathrm{Hz}$

### 2.2 Baseline

Only one model is used. The calculation of the modes is in $u,p,\varphi$ formulation. There is no reference solution in case the section is variable (modelization C).

### 2.3 Uncertainty of the solution

analytical solution.

## 3 Modelling A

### 3.1 Modelling characteristics

The Modelling of the elasto-acoustic beams is in $u,\theta ,p,\phi$ formulation.

It is done by assigning mesh cells type SEG2 (segments to 2 nodes) d-elements PHENOMENE= 'MECANIQUE', MODELISATION= 'FLUI_STRU'.

The elements are assigned the characteristics of circular cross-section:

| external radius | ${R}_{\mathit{ext}}=0,100m$ |  |
| --- | --- | --- |
| thickness | $\mathit{ep}=0,010m$ | cf. [§1.1] |

These elements are also assigned a mixed material of behaviour at the same time ELAS:

| Young's modulus | $E=1,0.1010\mathit{Pa}$ |  |
| --- | --- | --- |
| Poisson's ratio | $\nu =0,3$ |  |
| density | ${\rho}_{s}=1000\mathit{kg}/{m}^{3}$ |  |

et FLUIDE:

| speed | $c=1000m/s$ |  |
| --- | --- | --- |
| density | ${\rho}_{f}=1000\mathit{kg}/{m}^{3}$ | cf. [§1.2] |

Degrees of freedom (DDL) translation into $y$ and $z$ (DY and DZ) and all degrees of freedom rotation (DRX, DRY and DRZ) of all nodes are blocked.

In order to build the $A$ end of the piping, the degree of freedom translation $x$ (DX) of the node $\mathit{NO1}$ is also blocked.

For the fluid the tank condition at the end $A$ is imposed by PRES= 0. and PHI= 0. on the node $\mathit{NO1}$ .

### 3.3 Calculation

We want to validate the elements of elasto-acoustic beam.

The frequency of the first axial coupled mode is calculated with the CALC_MODES operator.

### 3.4 Test values

The test shall be conducted on the frequency of the first coupled axial mode of the fluid-containing piping.

The relative tolerance of d-difference relative to the analytical value is 0.1 per cent.

| ** Mode number** | **Analytical value** |
| --- | --- |
| 1 | $157,93981\mathit{Hz}$ Value non-regression |

### 3.5 Note

The reference values are both analytical values and those obtained by *Code_Aster* when test case is returned, which will allow the non-regression to be verified later in the evolution of the code.

## 4 Modelling B

### 4.1 Modelling characteristics

The Modelling A is repeated by modifying only the report of the section of the piping. Under the keyword AFFE_CARA_ELEM, a case of variable cross section is declared with VARI_SECT='HOMOTHETIQUE', but with constant radius and diameter parameters. This is done to validate the variable cross section option, in the sense of the keyword, but by finding the same solution as for Modelling A.

### 4.2 Test values

The test shall be carried out on the frequency of the first coupled axial mode of the piping containing a fluid which shall be identical to that of model A.

The relative tolerance of d-difference relative to the analytical value is 0.1 per cent.

| ** Mode number** | **Analytical value** |
| --- | --- |
| 1 | $157,93981\mathrm{Hz}$ Value non-regression |

### 4.3 Note

The reference values are both analytical values and those obtained by *Code_Aster* when test case is returned, which will allow the non-regression to be verified later in the evolution of the code.

## 5 Modelling C

### 5.1 Modelling characteristics

Model A is repeated by changing only the circular section which becomes variable. The diameter ranges from 0.1 to 0.11m while the thickness ranges from 0.011 to 0.01m.

### 5.2 Test values

The test is about the frequency of the first coupled axial mode of the fluid-containing piping. As the section is variable, it is no longer possible to compare with the reference solution and only the non-regression is verified for this Modelling.

## 6 Summary of the results

It is found that the calculated frequency value of the first coupled axial mode reproduces the analytical value with a relative accuracy of 0.004% in the case of a constant cross-section.
