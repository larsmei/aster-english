# v2.04.124 SDLV124 – Volumetric Paving subject to harmonic pressure

**Summary:**

The objective of this test case is to validate the harmonic calculation of a rectangular block modeled in elements volumetrics subjected to sinusoidal pressure. The harmonic response calculation on a projected matrix on modal basis is also valid.

The reference solution is obtained by a transitional calculation on the same model.

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v2.04.124/100002000000032B0000023B45BC70DBDBD242CB.png)

Dimensions of the $(m)$ pad:

> length (according to $x$): $0.35$
> width (according to $y$): $0.25$
> thickness (according to $z$): $0.01$

### 1.2 Elastic properties of the material

> $E=1.8\times {10}^{11}\mathrm{Pa}$     Young's modulus
> $\nu =0.3$                 Poisson's ratio
> $\rho =7800.0{\mathrm{kg.m}}^{-3}$ Density
> $\alpha =3\times {10}^{-5}s$
> $\beta =0.001{s}^{-1}$

$\alpha$ and $\beta$ coefficients allow the construction of a viscous damping matrix proportional to the stiffness and mass $[C]=\alpha [K]+\beta [M]$ .

### 1.3 Boundary conditions and loads

  - Clamped support of the side faces

    - Harmonic amplitude pressure $p={10}^{5}\mathrm{Pa}$ at $f=1500\mathrm{Hz}$ frequency on the upper side

## 2 reference solution

### 2.1 Method of calculation

The reference solution is obtained by performing a physical-based transient response calculation using the Newmark integration scheme with the $alpha=0.25$ and $delta=0.5$ parameters. The reference solution is a model of the reference solution model.

### 2.2 Quantities and reference results

The following quantitiess are proposed to be tested:

- Next $x$ shift to point coordinates
- Gauss point stress and deformation of an mesh cell containing node coordinates $(0.3325,0.05,0)$
- Node coordinate stress and deformation $(0.3325,0.05,0)$

### 2.3 Uncertainties about the solution

The regime is considered to be established after 90 excitation periods, and the reference values used are those for the 98th and 99th periods of the transient response.

## 3 Modelling A

### 3.1 Modelling characteristics A

The harmonic response (to $1500\mathit{Hz}$) is calculated on a physical basis and on the projected matrix on the first fifteen modes of the structure.

The pavement is modelled using elements $\mathrm{3D}$ density

> HEXA8 : 1200
