# v4.23.304 TTLP304 - Heat transfer in an orthotropic plate: flow imposed

**Summary:**

This test is based on independent validation of version 3 in linear transient thermal analysis.

This is a 2D plan problem represented by a Modelling (plane).

The functions tested are as follows:

- element thermal plane,
- orthotropic material,
- transient thermal analysis algorithm,
- limit conditions: flow imposed.

The value of the test lies in the consideration of an orthotropic material.

The results are compared to an analytical solution.
