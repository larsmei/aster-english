# v6.05.109 SSNS109 – shear force-subposed console beam

**Summary:**

This quasi-static non-linear mechanical test validates elements SHB in non-linear geometric.

Four modellingss allow to study different configurations:

- A to D Modelling: linear elastic behavior, large displacements, test on all elements SHB (SHB8, SHB6,SHB20,SHB15)

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v6.05.109/1000020100000263000002432E9810DA6C11B213.png)

Geometry, loading and displacement of the console beam in geometric nonlinear and large displacement, example of mesh 5 elements SHB20

- Dimensions of the beam:
- $L=\mathrm{10m}$
- $b=1$
- Thickness $h=\mathrm{0.1m}$

### 1.2 Material properties

The characteristics set out are as follows:

Elastic characteristics:

$E=\mathrm{1.2x106}\mathrm{Pa}$

$\mathrm{NU}=0$

### 1.3 Boundary conditions and loads

The beam is clamped at one end. The other end is free and a concentrated force $P$ is applied in the direction $Z$ . This force is applied incrementally from 0 to ${P}_{max}$ :

${\mathrm{P}}_{0}=\frac{\mathit{EI}}{{L}^{2}}=1N$ et ${\mathrm{P}}_{\max}=4{\mathrm{P}}_{0}$

The load is controlled by the $Z$ displacement value of the point $A$. The force amplitude (ETA pilot coefficient) is increased so that the displacement increases to $\mathrm{6.7mm}$ by $\mathrm{0.1mm}$ steps.
