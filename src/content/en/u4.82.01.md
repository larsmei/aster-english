# u4.82.01 Operator DEFI_FOND_FISS

## 1 Purpose

Define the geometric items relating to a crack, in particular the crack front and the upper and lower lips of this crack, in a 2D or 3D mesh.

The crack front may be defined from entities (nodes or mesh cells) or from groups of entities. The nodes may be ordered in the direction of increasing curvilinear abscissae. If this is not the case and if the crack front is given by a list of mesh cells or of mesh-cell groups, the operator will order the nodes, provided that an origin node is defined.

Two initial configurations of the upper and lower lips are taken into account for the definition of the propagation direction and of the lips.

This operator creates a concept of type fond_fiss which can be used by the operators CALC_G [U4.82.03](doc:u4.82.03) and POST_K1_K2_K3 [U4.82.05](doc:u4.82.05).

## 2 Syntax

```text
fond_fissure = DEFI_FOND_FISS(
    ◆ MAILLAGE = maillage,
    ◇ INFO = / 1 (par défaut),
             / 2,
    ◆ FOND_FISS = _F(
         ◇ TYPE_FOND = / "OUVERT" (par défaut),
                       / "FERME",
         ◆ / GROUP_NO = grno,
           / GROUP_MA = grma,
         # Si: exists("GROUP_MA") and not equal_to("TYPE_FOND", 'FERME')
             ◇ GROUP_NO_ORIG = grno,
             # Si: exists("GROUP_NO_ORIG")
                 ◇ GROUP_NO_EXTR = grno,
         # Si: exists("GROUP_MA") and equal_to("TYPE_FOND", 'FERME')
             ◇ GROUP_NO_ORIG = grno,
             # Si: exists("GROUP_NO_ORIG")
                 ◇ GROUP_MA_ORIG = grma,
      ),
    ◆ SYME = / "OUI",
             / "NON",
    ◆ LEVRE_SUP = _F(
         ◆ GROUP_MA = grma,
      ),
    # Si: exists("LEVRE_SUP") and equal_to("SYME", 'NON')
        ◆ LEVRE_INF = _F(
             ◆ GROUP_MA = grma,
          ),
    ◇ CONFIG_INIT = / "COLLEE" (par défaut),
                    / "DECOLLEE",
    # Si: equal_to("CONFIG_INIT", 'DECOLLEE')
        ◆ NORMALE = float,
    ◇ PREC_NORM = float (défaut: 0.1),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand MAILLAGE

```text
♦    MAILLAGE = ma
```

Name of the mesh on which the crack front and the lips are to be defined.

### 3.2 Description of the crack front

The crack front is defined by the set of ordered nodes of the crack front. If the keyword GROUP_NO_ORIG is not defined, the order in which these nodes are declared, by means of segment mesh cells, will define the direction in which the curvilinear abscissa of the crack front is traversed. It is thus left to the user to compose a list ordered, in the sense of the connectivity of the mesh, by increasing curvilinear abscissa.

It is also possible to supply a list of segment mesh cells without worrying about the order. Supplying an origin node, provided that it does indeed correspond to one end of the path defined by the segment mesh cells, then makes it possible to order the list of nodes.

Furthermore, in 3D, for a current node of the crack front, the propagation direction is defined as the average of the normals to the segment mesh cells of the crack front to its left and to its right. For the end nodes, the normal is computed from a single mesh cell, and may therefore be less accurate.

The code therefore provides a correction of this normal by taking the edges of the structure into account.

#### 3.2.1 Factor keyword FOND_FISS

##### 3.2.1.1 Keyword TYPE_FOND

There are two possibilities for defining the crack front:

1. If the crack front is defined by an open curve (as opposed to a front defined by a closed curve), TYPE_FOND ='OUVERT' is supplied. This value is the default value.
2. If the crack front is defined by a closed curve, TYPE_FOND ='FERME' is supplied.

##### 3.2.1.2 Keyword GROUP_NO

```text
/    ♦    GROUP_NO = grno
```

This keyword can be used only in 2D.

A group containing a single node corresponding to the crack front is expected.

This keyword can be used only in 2D.

##### 3.2.1.3 Keyword GROUP_MA

```text
/    ♦    GROUP_MA = grma
```

This keyword can be used only in 3D.

Group of mesh cells of type SEG2 or SEG3, ordered or not with respect to the crack front.

##### 3.2.1.4 Keyword GROUP_NO_ORIG

```text
/    GROUP_NO_ORIG = grno
```

A single node, or a node group containing a single node. In order to be one end of the path defining the crack front, it must belong to one and only one mesh cell of grma. This keyword can be defined only if GROUP_MA is defined. This keyword can be used only in 3D.

##### 3.2.1.5 Keyword GROUP_NO_EXTR

```text
/    GROUP_NO_EXTR = grno
```

Node group containing a single node. This datum is optional and serves only to check that the end node obtained by the operator is indeed the one the user has in mind. The code will stop in error if this is not the case. This keyword can be defined only if GROUP_NO_ORIG is defined. This keyword can be used only in 3D.

##### 3.2.1.6 Keyword GROUP_MA_ORIG

```text
/    GROUP_ MA _ ORIG = gr ma
```

Mesh-cell group containing a single mesh cell. This datum, mandatory in the case of a closed front in 3D, makes it possible, together with the keyword GROUP_NO_ORIG, to define a direction of traversal of the crack front by increasing curvilinear abscissae. This direction goes from the node defined by GROUP_NO_ORIG to the second end node of the mesh cell defined by GROUP_MA_ORIG.

### 3.3 Description of the lips

Two initial configurations are treated:

1. if the lips are stuck together
2. if the lips are separated

In the case of lips stuck together, two cases are distinguished:

- if the mesh is complete, then the algorithm requires the definition of the upper and lower lips.
- if the mesh is to be completed by symmetry with respect to the mean plane of the lips, then the algorithm requires only the definition of the upper lip.

The propagation direction of the crack and the normal to the crack plane are computed for each node of the crack front.

In the case of separated lips, the normal to the crack plane must be given by means of the operand NORMALE (2D and 3D, for plane cracks only).

For subsequent use in POST_K1_K2_K3 (keyword FOND_FISS), the lips must necessarily be stuck together.

For non-plane 3D cracks, the propagation direction of the crack at every point of the crack front is built in this operator and is used by the operator CALC_G [U4.82.03](doc:u4.82.03).

At present, fracture-mechanics analyses by CALC_G, POST_K1_K2_K3 or otherwise are not possible for non-plane 3D defects whose lips are separated.

#### 3.3.1 Keyword CONFIG_INIT

The initial configuration is that described by the mesh. The lips are:

1. stuck together if the angle between the 2 lips is less than or equal to 5°;
2. separated otherwise.

*Note:* *The computation of the stress intensity factors with the operator* POST_K1_K2_K3 [U4.82.05](doc:u4.82.05) *,* *or with the* *'* *option* ' K ' *of the operator* CALC_G [U4.82.03](doc:u4.82.03) *, can be carried out only if* CONFIG_INIT='COLLEE' *.*

#### 3.3.2 Keyword SYME

This keyword makes it possible to specify whether the modelling used takes into account a symmetry of the structure with respect to the mean plane of the crack lips (see Figure 3.1). If SYME = 'OUI', the value of the energy release rate G(s) and those of the stress intensity factors corresponding to the symmetry mode will automatically be multiplied by 2, and that of G_Irwin by 4 (see [U4.82.03](doc:u4.82.03) for CALC_G and [U4.82.05](doc:u4.82.05) for POST_K1_K2_K3).

If SYME = 'OUI' and CONFIG_INIT='COLLEE', the definition of the upper lip of the crack (LEVRE_SUP, §3.3.3) makes it possible to know on which side of the front the crack lies.

![Figure](/figures/u4.82.01/10000000000001AD0000026D000887C3C67A5E38.png)

Figure 3.1: Definition of the symmetry.

#### 3.3.3 Keyword LEVRE_SUP

```text
◊    LEVRE_SUP =
```

Defines the set of the faces of the elements that rest on the upper lip of the crack. The set of these faces is specified by the operand:

```text
GROUP_MA    = l grma     liste de g roupe s de mailles.
```

```text
Les mailles sont donc surfaciques si le modèle est 3D et linéiques si le modèle est 2D.
```

#### 3.3.4 Keyword LEVRE_INF

```text
◊    LEVRE_INF=
```

Defines the set of the faces of the elements that rest on the lower lip of the crack. In the case where the crack lies on a plane of symmetry, this keyword must not be supplied.

The set of these faces is specified by the operand:

```text
GROUP_MA    = l grma     liste de g roupe s de mailles.

Les mailles sont donc surfaciques si le modèle est 3D et linéiques si le modèle est 2D.
```

#### 3.3.5 Operand NORMALE

This operand is to be defined only in the case of a crack with separated lips (CONFIG_INIT='DECOLLEE'). This concerns the cases of an open defect or of a notch.

The keyword NORMALE is used to specify the vector normal to the plane of these lips, hence to the crack itself. This vector is used at every point of the crack front to determine the propagation direction and therefore assumes that the crack is plane. The normal is then not the normal to the lips, but to the propagation plane (plane of symmetry).

```text
/    ♦    NORMALE= (Nx, Ny, Nz)
```

The keyword NORMALE makes it possible to introduce the components Nx, Ny, Nz in the global frame of a normal $\text{N}$ to the crack plane, with the following orientation convention:

- In 3D, $\text{n}={\text{Γ}}_{0}\wedge \text{N}$, where $\text{n}$ is the outward normal to the crack in the plane of the lips, ${\text{Γ}}_{0}$ is the oriented crack front (defined by the keyword FOND_FISS),
- in 2D, the normal $\text{N}$ is defined such that the frame $({\text{N}}_{0,}\text{t},\text{N})$ is right-handed, with:

${\text{N}}_{0}$ the node of the crack front,

$\text{t}$ the propagation direction of the crack.

![Figure](/figures/u4.82.01/100003AA00000619000007DB8605C3A3C87FDAE4.svg)

In every case, $\text{N}$ is normalised automatically. The three components of the vector must be given even in 2D.

### 3.4 Operand PREC_NORM

This operand is useful only in the 3D case, before an analysis with POST_K1_K2_K3 [U4.82.05](doc:u4.82.05).

The parameter PREC_NORM defines the accuracy used in the search for the nodes of the lips that lie on directions normal to the crack front: for the interpolation of the displacement jumps, the nodes whose distance *d* to the straight line normal to the front and passing through a node of this front satisfies the following are indeed used:

$\text{d}<\text{PREC\_NORM}.{l}_{\text{f}}$

where ${l}_{\text{f}}$ is the minimum distance between two successive nodes of the crack front. Increasing the value of PREC_NORM amounts to increasing the number of nodes potentially retained for the computation of $\text{K}$ in POST_K1_K2_K3.

## 4 Examples

### 4.1 Complete crack defined by different types of entities in 3D

The crack front is defined by a mesh-cell group, the upper lip by a list of mesh cells, the lower lip by a list of mesh-cell groups.

```text
Fiss1 = DEFI_FOND_FISS( MAILLAGE = ma,
FOND_FISS =    _F (GROUP_NO = ('GMFOND'),
LEVRE_SUP =    _F (GROUP_MA =('GM123'),),
LEVRE_INF =    _F (GROUP_MA = ( 'GRM1','GRM2'),),
)
```

with the following groups defined in the mesh ma:

```text
GRN1 :    {N010 N018}            GRN2 : {N018 N016 N017}
GRN3 :    {N017 N015}
GRM123: {MA5, MA13, MA4, MA12}
GRM1:    {MA17 MA15 MA6 }    GRM2:    {MA40}
```

The crack front here consists of the mesh-cell group GMFOND connecting the nodes N010, N018, N016, N017, N015 in an ordered manner.

![Figure](/figures/u4.82.01/10002296000069D500003206D4A913EF47796F26.svg)

### 4.2 Use of the operand NORMALE (plane DECOLLEE crack in 3D)

```text
fiss = DEFI_FOND_FISS    (    MAILLAGE =    ma,
FOND_FISS =_F(GROUP_NO='GMFOND',
CONFIG_INIT='DECOLLEE',
NORMALE =    ( 0.,0.,-1.),
)
```

The normal $\text{N}$ to the crack plane is defined.

The direction $\text{n}$ of the normal to the crack front in the plane of the crack lips is determined by $\text{n}={\text{Γ}}_{0}\wedge \text{N}$.

### 4.3 Crack in 2D

The crack front is defined by the node N10 of the mesh ma. This node constitutes the single node of the group GN10. The mesh-cell groups of the lips are denoted GMSUP and GMINF respectively. The crack may be defined either from the normal:

```text
fiss = DEFI_FOND_FISS    (    MAILLAGE    =    ma,
FOND_FISS    =    _F(GROUP_NO = 'GN10'),
CONFIG_INIT = 'DECOLLEE',
NORMALE    =    (-1.,1.,0.),
)
```

or from the mesh cells of the lips:

```text
fiss = DEFI_FOND_FISS    (    MAILLAGE    =    ma,
FOND_FISS    =    _F( GROUP_NO = 'GN10'),
LEVRE_SUP    =    ‘GMSUP’,
LEVRE_INF    =    ‘GMINF’,

                             )
```

### 4.4 Closed crack front with ordering of the nodes

```text
fiss = DEFI_FOND_FISS(    MAILLAGE =    ma,

    FOND_FISS=_F(TYPE_FOND='FERME',
GROUP_MA='GMA',
GROUP_NO_ORIG    =    'NO',
GROUP_MA_ORIG    =    'GMA2'        ),
CONFIG_INIT = 'DECOLLEE',
NORMALE =    ( 0.,0.,-1.),
)
```

with GMA: {MA1, MA2, MA3, …}, GMA2: {MA2}

The normal $\text{N}$ to the crack plane is defined. The direction $\text{n}$ of the normal to the crack front in the plane of the crack lips is determined by $\text{n}={\text{Γ}}_{0}\wedge \text{N}$.

The order in which the mesh cells are declared in the list is of no importance. The operator checks that the node NO does indeed belong to the mesh cell MA2 and that the set of segment mesh cells supplied does indeed form a closed connected curve. The order of the nodes in the concept produced will be that given by the arrow in the drawing below, starting from NO.
