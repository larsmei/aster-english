# u7.02.11 Operator LIRE_PLEXUS

## 1 Purpose

Read the results file in IDEAS format produced by the EUROPLEXUS software.

Makes it possible to recover a transient fluid-pressure field in a piping system computed by means of a line hydrodynamic model (plane waves) of PLEXUS. The pressure field, defined as constant per element in the EUROPLEXUS analysis, is projected onto a corresponding mechanical mesh of *Code_Aster* using shell elements (DKT or COQUE_3D) and/or TUYAU.

Produces a concept of type evol_char.

## 2 Syntax

```text
evol_char = LIRE_PLEXUS(
    ◇ UNITE = unit (défaut: 19),
    ◇ FORMAT = "IDEAS",
    ◆ MAIL_PLEXUS = maillage,
    ◆ MAILLAGE = maillage,
    ◆ MODELE = modele,
    ◆ / TOUT_ORDRE = "OUI" (ou non renseigné),
      / NUME_ORDRE = int,
      / INST = float,
      / LIST_INST = listr8,
      / LIST_ORDRE = listis,
    # Si: exists("LIST_INST") or exists("INST")
        ◇ CRITERE = / "RELATIF" (par défaut),
                    / "ABSOLU",
        # Si: (equal_to("CRITERE", 'RELATIF'))
            ◇ PRECISION = float (défaut: 1e-06),
        # Si: (equal_to("CRITERE", 'ABSOLU'))
            ◆ PRECISION = float,
    ◇ TITRE = text,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operands FORMAT / UNITE

```text
◊    FORMAT = 'IDEAS'
```

Reading of the file in IDEAS format.

```text
◊    UNITE = iunit
```

Logical unit number of the file in universal IDEAS format, 19 by default.

### 3.2 Operand MAIL_PLEXUS

```text
♦    MAIL_PLEXUS = mplexus
```

Line hydrodynamic mesh of EUROPLEXUS on which the time-dependent pressure field is read.

### 3.3 Operand MAILLAGE

```text
♦    MAILLAGE = master
```

Mesh for the *Code_Aster* analysis onto which the pressure field that has been read is projected.

### 3.4 Operand MODELE

```text
♦    MODELE = modaster
```

Name of the model in which the types of finite elements assigned to the *Code_Aster* mesh are defined.

### 3.5 Operands TOUT_ORDRE / NUME_ORDRE / LIST_ORDRE / INST / LIST_INST / PRECISION / CRITERE

Selection in a resultat data structure [U4.71.00](doc:u4.71.00).

### 3.6 Operand TITRE

```text
◊    TITRE = l_titre
```

Title that one wishes to give to the result [U4.03.01](doc:u4.03.01).

## 4 Examples

### 4.1 Example: reading of an EUROPLEXUS mesh

The line hydrodynamic mesh of EUROPLEXUS is read from the universal IDEAS file (logical unit 19) and transformed into *Code_Aster* format, written on unit 22. The EUROPLEXUS mesh in *Code_Aster* format is then reread and placed in the concept of type maillage.

```text
PRE_IDEAS ( UNITE_IDEAS=19, UNITE_MAILLAGE=22 )

mplexus = LIRE_MAILLAGE (    UNITE=22, )
```

### 4.2 Example: creation of a result of type 'evol_char'

The time-dependent fluid-pressure field is read from the universal IDEAS file. This field, defined on the line hydrodynamic mesh of EUROPLEXUS (in *Code_Aster* format), is then projected onto the mechanical mesh of *Code_Aster* for all the time instants at which it is defined.

```text
presplex= LIRE_PLEXUS    (    UNITE            =    19,
FORMAT            =    'IDEAS',
MAIL_PLEXUS    =    mplexus,
MAILLAGE        =    master,
MODELE            =    modaster,
TOUT_ORDRE    =    'OUI',
)
```

### 4.3 Example: use of the result of type 'evol_char'

The 'evol_char' concept defined previously is used under the keyword EVOL_CHAR to build a loading.

```text
char= AFFE_CHAR_MECA    (    MODELE    =    modaster,
...
EVOL_CHAR    =    presplex,
)
```
