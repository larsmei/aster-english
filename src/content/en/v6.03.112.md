# v6.03.112 FORMA10 - Practical work of Advanced Use Training: Loading route

**Summary:**

This test illustrates, on a material point, the influence of loading path on the response of an elastoplastic behavior. It highlights the effects of discretization in time. It is inspired by the SSNP15 test: a material point, made of a plastic material with linear isotropic nutrification, is subjected to both tensile and shearing effort. The main interest of this test lies in the non-radial character of the load.

Model A is the force-based calculation with VMIS_ISOT_LINE behavior and illustrates the influence of coarse-time discretization compared to the solution obtained with a finer time step. To obtain a solution with a finer time step, the time step re-cutting is forced on a criterion based on the increment of the cumulative plasticity (model B).

## 1 Reference problem

### 1.1 Geometry

It is a material point: state of stress and uniform deformations. This can be represented by a single finite element, with appropriate boundary conditions, as in SSNP14 and SSNP15.

#### 2.1.1 Resolution approach

Mechanically, it is a stress-controlled $\mathrm{0D}$ test, the material being elastoplastic with vonMises criterion and linear isotropic hardening. For a stress-controlled load, the cumulative plastic deformation is easily determined:

$F(\sigma ,p)={\sigma}_{\mathrm{eq}}-{\sigma}^{Y}-R'p\le 0\Rightarrow p=\frac{{\sigma}_{\mathrm{eq}}-{\sigma}^{Y}}{R'}$ in charge eq 2.1.1-2.1.1-1

The integration of plastic deformation is of course more delicate. The flow equation sss written:

$\dot{{\varepsilon}^{p}}=\frac{3}{2}\dot{p}\frac{\tilde{\sigma}}{{\sigma}_{\mathrm{eq}}}\Rightarrow \dot{{\varepsilon}^{p}}=\frac{3}{2R'}\frac{\dot{{\sigma}_{\mathrm{eq}}}}{{\sigma}_{\mathrm{eq}}}\tilde{\sigma}$ in charge eq 2.1.1-2.1.1-2

#### 2.1.3 Treatment of non-radial loading phase

In the non radial $\mathrm{B0}-B$ loading phase, the stress path can be set by:

$\sigma (q)={\sigma}^{{B}^{0}}+q\underset{\text{direction fixe}}{\underset{\underbrace{}}{({\sigma}^{B}-{\sigma}^{{B}^{0}})}}$ with $0\le q\le 1$ eq 2.1.3-1

As the loading path remains confined in the $(\sigma ,\tau )$ shear-pull plane, it is better to represent the stress state by a complex number:

$\Sigma =\sigma +i\sqrt{(3)}\tau \Rightarrow {\sigma}_{\mathrm{eq}}=∣(\Sigma )∣$         et        $\Sigma (q)={\Sigma}^{{B}^{0}}+q\underset{\text{direction fixe}}{\underset{\underbrace{}}{({\Sigma}^{{B}^{0}}-{\Sigma}^{B})}}$         éq 2.1.3-2

The integration of the flow law [eq 2.1.1-2], followed by a part-integration, allows the expression of plastic deformation:

$\frac{\mathrm{2R}'}{3}{\left[{\varepsilon}^{p}\right]}_{0}^{1}=\underset{0}{\overset{1}{\int}}\frac{\dot{{\sigma}_{\mathrm{eq}}}}{{\sigma}_{\mathrm{eq}}}\tilde{\sigma}\mathrm{dq}={\left[\ln({\sigma}_{\mathrm{eq}})\tilde{\sigma}\right]}_{0}^{1}-\frac{1}{2}\underset{{\tilde{\sigma}}^{B}-{\tilde{\sigma}}^{{B}^{0}}}{\underset{\underbrace{}}{\dot{\tilde{\sigma}}}}\underset{0}{\overset{1}{\int}}\ln({\sigma}_{\mathrm{eq}}^{2})\mathrm{dq}$

The adoption of the complex plan allows easy calculation of the last integral:

$\underset{0}{\overset{1}{\int}}\ln({\sigma}_{\mathrm{eq}}^{2})\mathrm{dq}=\underset{0}{\overset{1}{\int}}\ln(\Sigma \overline{\Sigma})\mathrm{dq}=\underset{0}{\overset{1}{\int}}\ln(\Sigma )\mathrm{dq}+\underset{0}{\overset{1}{\int}}\ln(\overline{\Sigma})\mathrm{dq}=2\Re \left[\underset{0}{\overset{1}{\int}}\ln(\Sigma )\mathrm{dq}\right]=2\Re {\left[\frac{\Sigma \ln(\Sigma )-\Sigma }{{\Sigma}^{B}-{\Sigma}^{{B}^{0}}}\right]}_{0}^{1}$

Finally, the plastic deformation increment on the $\mathrm{B0}-B$ route is:

${\left[{\varepsilon}^{p}\right]}_{{B}^{0}}^{B}=\frac{3}{2R'}{\left[\ln({\sigma}_{\mathrm{eq}})\tilde{\sigma}\right]}_{{B}^{0}}^{B}-\frac{3}{2R'}\Re {\left[\frac{\Sigma \ln(\Sigma )-\Sigma }{{\Sigma}^{B}-{\Sigma}^{{B}^{0}}}\right]}_{{B}^{0}}^{B}({\tilde{\sigma}}^{B}-{\tilde{\sigma}}^{{B}^{0}})$                 éq 2.1.3-4

## 4 Modelling B

### 4.1 Modelling characteristics

This is a test on point hardware. This is done by using the SIMU_POINT_MAT command, which allows calculation on a single element, with a single point integration.

The loading path between the point $A$ and the point $B$ is discretized in 1 time step. But a fairly recent feature is used that allows the time step to be re-cut if an additional criterion is not checked at convergence. Here, it is proposed to check that at each convergence, the cumulative plastic deformation increment does not exceed 0.2 10-2. As soon as this criterion is not met, then the automatic re-cut code the time step and resume until this criterion is met.

For guidance, 25 calculations are performed between point $A$ and point $B$ , so this temporal discretization is described as fine, compared to that used in Modelling A.

It is recalled that the point $A$ corresponds to the $t=\mathrm{1s}$ moment and the point $B$ corresponds to the $t=\mathrm{2s}$ moment.
