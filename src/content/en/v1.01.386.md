# v1.01.386 ZZZZ386 – Validation of LIAISON_SOLIDE in 3D and with large rotations

**Summary:**

The purpose of the Modelling of this test is to validate the use of LIAISON_SOLIDE in 3D for large transformations in STAT_NON_LINE. This load makes it possible to make a structure perfectly unformable without any hypothesis (especially on the materials to be used). The test compares the result (movements) obtained by LIAISON_SOLIDE in large transformations and the analytical solution trivial (pure rotation) that one wishes to obtain.

This documentation is deliberately succinct.
