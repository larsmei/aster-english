# v6.02.115 SSNL115 - Cable with thermal expansion

**Summary:**

This test validates the calculation of a cable with thermal expansion.

- Non-linear static analysis.
- Modelling: CABLE

## 1 Reference problem

### 1.1 Geometry

A cable is subjected to a temperature charge. It is clamped at both ends.

### 1.2 Material properties

$E=210000.0\mathit{MPa}$

$\mathit{Alpha}=1.2E-05{K}^{-1}$

$\mathit{Rayon}=10.0\mathit{mm}$

### 1.3 Boundary conditions and loads

Clamped support at both ends of the cable.

The temperature in the cable varies with time, the reference temperature is $0.°C$ .

- Instant: 0. Temperature $T=0.°C$
- Instant: 1. Temperature $T=-30°C$
- Instant: 2. Temperature $T=-30.0°C$
- Instant: 3. Temperature $T=-500.0°C$
- Instant: 4. Temperature $T=-30.0°C$
- Instant: 5. Temperature $T=-30.0°C$
- Instant: 6. Temperature $T=-1000.0°C$

## 2 reference solution

### 2.1 Calculation method used for reference solution

The effort in the cable is given by:

$N=E.S.\alpha .\Delta T$
