# u4.91.12 Procedure INFO_RESU

## 1 Purpose

Print the list of the fields and of the components of those fields present in a result data structure.

## 2 Syntax

```text
INFO_RESU(
    ◇ RESULTAT = resultat,
    ◇ UNITE = unit (défaut: 8),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand RESULTAT

```text
♦    RESULTAT    =    RESU,
```

It is with this keyword that the user specifies the result data structure for which he or she wishes to have the fields and the components present printed.

### 3.2 Operand UNITE

```text
◊    UNITE        =
```

Logical unit number associated with the file on which the result data structure must be printed. By default, the printout is carried out on logical unit 8.

## 4 Example

RESUTRQU=MECA_STATIQUE( … )

INFO_RESU(RESULTAT=RESUTRQU)

This command will cause the following printout in the message file:

```text
-----------------------------------------------------------

COMPOSANTES DES CHAMPS PRESENTS DANS LE RESULTAT : RESUTRQU

- CHAMP DEPL :

* DX

* DY

- CHAMP SIEF_ELGA :

* SIXX

* SIYY

* SIZZ

* SIXY

-----------------------------------------------------------
```
