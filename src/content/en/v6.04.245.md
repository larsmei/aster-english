# v6.04.245 SSNV245 - Imposition of Dirichlet conditions on elements XFEM Heaviside using a space function

**Summary:**

The aim is to validate the imposition of Dirichlet conditions using a space function on elements Heaviside XFEM, both quadratic and linear. In particular, a discontinuous function will be used through the interface.

## 1 Reference problem

### 1.1 Geometry of the problem

This column is $\mathit{LZ}=5m$ height, $\mathit{LX}=1m$ length, and $\mathit{LY}=1m$ width. This column has an interface-type discontinuity (unmesh interface that is introduced into the model via the level-set via the DEFI_FISS_XFEM operator). The column is thus completely crossed by discontinuity (at the level of the displacement field approximation, only Heaviside enrichment is taken into account). The $Y={L}_{d}$ interface height will be different in the modellings c and d.

The Figure shows the geometry of the column.

![Figure](/figures/v6.04.245/100000000000031F00000322B0A8D7EC6E3AE2DF.png)

**Figure** 1.1-a **: Geometry of the problem** **3D**

### 1.2 Material properties

Young's modulus: $E=5800\mathit{MPa}$

Poisson's ratio: $\nu =0$

Thermal expansion coefficient: $\alpha =0{K}^{\text{-1}}$

### 1.3 boundary conditions

*Case 2D*

The boundary conditions that we apply are Neuman type. We impose:

- All over the ${u}_{y}(x,y)={f}_{y}(x,y)$ domain with ${f}_{y}(x,y)=\lbrace \begin{array}{c}-0.01\ast y\mathit{si}Y<{L}_{d}\\ 0.01\ast (\mathit{LY}-y)\mathit{si}Y>{L}_{d}\end{array}$
- On the side [AD] ${u}_{x}(x,y)={f}_{\mathit{null}}$ with ${f}_{\mathit{null}}$ the constant function of null value
- Side [BC] ${u}_{x}(x,y)={f}_{x}(x,y)$

In Modelling A (linear) ${f}_{x}(x,y)=\lbrace \begin{array}{c}0.01\ast y\mathit{si}Y<{L}_{d}\\ -0.01\ast (\mathit{LY}-y)\mathit{si}Y>{L}_{d}\end{array}$

In Modelling B (quadratic) ${f}_{x}(x,y)=\lbrace \begin{array}{c}0.01\ast {y}^{2}\mathit{si}Y<{L}_{d}\\ -0.01\ast {(\mathit{LY}-y)}^{2}\mathit{si}Y>{L}_{d}\end{array}$

* 3D cas*

The boundary conditions that we apply are Neuman type. We impose:

- All over the ${u}_{z}(x,y,z)={f}_{z}(x,y,z)$ domain with ${f}_{z}(x,y,z)=\lbrace \begin{array}{c}-0.01\ast z\mathit{si}Z<{L}_{d}\\ 0.01\ast (\mathit{LZ}-z)\mathit{si}Z>{L}_{d}\end{array}$
- On the face [ADEH] ${u}_{x}(x,y,z)={f}_{\mathit{null}}$ with ${f}_{\mathit{null}}$ the constant value function zero
- On the face [BCGF] ${u}_{x}(x,y,z)={f}_{x}(x,y,z)$

In Modelling C (linear) ${f}_{x}(x,y,z)=\lbrace \begin{array}{c}0.01\ast z\mathit{si}Z<{L}_{d}\\ -0.01\ast (\mathit{LZ}-z)\mathit{si}Z>{L}_{d}\end{array}$

In Modelling D (quadratic) ${f}_{x}(x,y,z)=\lbrace \begin{array}{c}0.01\ast {z}^{2}\mathit{si}Z<{L}_{d}\\ -0.01\ast {(\mathit{LZ}-z)}^{2}\mathit{si}Z>{L}_{d}\end{array}$

- All over the ${u}_{y}(x,y,z)={f}_{\mathit{null}}$ domain

## 2 reference solution

### 2.1 Method of calculation

*Case 2D*

The Poisson's ratio $\nu$ is zero, and the solution is independently written according to $x$ direction and $y$ direction.

By neglecting the gravity, the equation is written (in total constraints):

$\text{Div}(\sigma )=0$

Being in the elastic case, we have $\sigma =Eϵ$, that is finally $\text{Div}(ϵ)=0$.

According to $x$ , $\frac{\partial {ϵ}_{xx}}{\partial x}=0$ from where:

- the moves above the interface write ${u}_{x}(x,y)=\frac{-0.01\ast x}{\mathit{LX}}\ast (\mathit{LY}-y)$
- the movements below the interface write ${u}_{x}(x,y)={f}_{x}(x,y)\ast \frac{x}{\mathit{LX}}$

According to $y$ , displacement is imposed everywhere so:

- the moves above the interface write ${u}_{y}(x,y)={f}_{y}(x,y)$
- the movements below the interface write ${u}_{y}(x,y)={f}_{y}(x,y)$

* 3D cas*

The Poisson's ratio $\nu$ is zero, and the solution is written independently according to $x$ direction, $y$ direction and $z$ direction.

By neglecting the gravity, the equation is written (in total constraints):

$\text{Div}(\sigma )=0$

Being in the elastic case, we have $\sigma =Eϵ$, that is finally $\text{Div}(ϵ)=0$.

According to $x$ , $\frac{\partial {ϵ}_{xx}}{\partial x}=0$ from where:

- the moves above the interface write ${u}_{x}(x,y,z)={f}_{x}(x,y,z)\ast \frac{x}{\mathit{LX}}$
- the movements below the interface write ${u}_{x}(x,y,z)={f}_{x}(x,y,z)\ast \frac{x}{\mathit{LX}}$

According to $z$ , displacement is imposed everywhere so:

- the moves above the interface write ${u}_{z}(x,y,z)={f}_{z}(x,y,z)$
- the movements below the interface write ${u}_{z}(x,y,z)={f}_{z}(x,y,z)$

According to $y$, travel is zero everywhere.

## 7 Summary of the results

The imposition of Dirichlet conditions on elements XFEM Heaviside using a space function is validated, both on elements 2D and 3D, for linear and quadratic modellings.

Care was also taken to model in which the interface is mesh-compliant (modelling c) and model in which the interface passes through an node medium (modelling d). This feature allows in particular to impose discontinuous kinematic conditions through the interface.
