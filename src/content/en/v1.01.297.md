# v1.01.297 ZZZZ297 – Validation of LIAISON_PROJ key word for AFFE_CHAR_MECA command

**Summary:**

The objective is to test and validate the possibilities of the LIAISON_PROJ keyword of the affe_char_meca command. LIAISON_PROJ allows to define linear relationships between nodes of a model. The coefficients of linear relationships are determined using the PROJ_CHAMP command which returns a concept that corresponds to the matrix of coefficients of influence determined from the elements shape functions.

Test cases validate several configurations:

- relationships between mesh cells density groups: mesh cells volume masters, mesh cells volume slaves: A Modelling;
- relationships between mesh cells density groups and mesh cells surface-based: mesh cells volume-control masters, mesh cells over-facial slaves: B Modelling;
- relationships between mesh cells density groups and mesh cells linear: mesh cells density masters, mesh cells linear slaves: C Modelling;
- Relationships between groups of mesh cells superfacial: mesh cells master surfactic, mesh cells slave surfactic with and without excentre: modellings D and E;
- Relationships between groups of mesh cells superfacial and linear: mesh cells master surfacic, mesh cells slave linear with excentre: Modelling F.

## 2 reference solution

### 2.1 Method of calculation

The reference solution is obtained by calculating with *Code_Aster* by explicitly giving the relationship between the degrees of freedom with the LIAISON_DDL key word of the AFFE_CHAR_MECA command.

The relationship is as follows:

- For the degrees of freedom of the nodes slaves given under the simple key word DDL.

$\mathrm{DDL}({N}_{\mathrm{escl}})={\sum}_{i}{\mathrm{Coeff}}_{i}\ast \mathrm{DDL}({N}_{\mathrm{maître}}^{i})$

with i: node of the master mesh cell containing the slave node.

- In case TYPE = EXCENTREMENT, the relationship on the degrees of translational freedom of the slave nodes becomes:

$\mathrm{DDL}({N}_{\mathrm{escl}})={\sum}_{i}{\mathrm{Coeff}}_{i}\ast (\mathrm{DDL}({N}_{\mathrm{maître}}^{i})+\overrightarrow{\omega ({N}_{\mathrm{maître}}^{i})}\wedge \overrightarrow{{N}_{\mathrm{maître}}^{i}{N}_{\mathrm{escl}}})$

## 9 Summary of the results

Comparison between calculations performed with the translation, translation and rotational, translation with TYPE='EXCENTREMENT' key word LIAISON_PROJ of the AFFE_CHAR_MECA command and calculations performed by explicitly giving the relationship between the freedom degrees (the LIAISON_DDL key word AFFE_CHAR_MECA command) shows the correct operation of the command:

- Comparisons made on the field of displacements at all nodes and all components show that identical results are obtained;
- Comparisons made on the stress field at all Gauss points, at all sub-points and for all components show that identical results are obtained.
