# 1 **v4.01.001** TPLA01 - Infinite hollow thermal balance cylinder

**Summary:**

Linear steady-state thermal analysis.

Model axisymmetric; 4 modellings.

analytical solution.

Interest of the test:

- **all** elements axisymmetric: triangles and quadrangles, linear and quadratic,
- element axisymmetric shell: quadratic segments
- Various boundary conditions: exchange, temperature imposed, flow imposed,
- partial validation of the thermal "mass" matrix as a transient "false" is made.
- CALC_MATR_ELEM 'MASS_THER' option for Modelling A

The results are not affected by mesh cells $h/l=40$ distortion.

## 2 reference solution

### 2.1 Calculation method used for reference solution

$T(r)={T}_{i}+\Phi \log(\frac{r}{{R}_{i}})$

with : $\lbrace  \begin{array}{ccc}\Phi & =& \frac{{T}_{e}-\mathit{Ti}}{\log(\frac{{R}_{e}}{{R}_{i}})}\\ & & \text{les flux}\mathit{radiaux}\text{}(\lambda \frac{\partial T}{\partial r})\text{sur les parois du cylindre sont :}\\ {\Phi}_{i}& =& +\lambda .\frac{\Phi}{{R}_{i}}\\ {\Phi}_{e}& =& +\lambda .\frac{\Phi}{{R}_{e}}\end{array}$

| ${T}_{i}:$ | ‘Inner' skin temperature |
| --- | --- |
| ${T}_{e}:$ | External skin temperature |

### 2.2 Baseline

Temperatures and fluxes at $A$, $B$, $D$, $F$ points.

For the 'MASS_THER' option (operator CALC_MATR_ELEM) test, a value given by an JEVEUX object must be used, which corresponds to a control sum.

It's a pure digital non-regression test.

To test, the calculation debug mode is activated.F90 then the MASS_THER output field values in CALC_MATR_ELEM are compared with the same as the THER_LINEAIRE of the test.

### 2.3 Uncertainty about the solution

analytical solution.
