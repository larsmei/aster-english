# v4.04.100 TPLV100 - Cylinder subject to boundary conditions not axisymmetric

**Summary:**

This is a steady-state thermal analysis test with Fourier Modelling.

This test validates all elements thermal Fourier (5 different models) with different types of boundary conditions: imposed temperature, exchange, imposed flux, heat source.

The value of the test, in addition to the validation of the Fourier thermal, lies in the following points:

- comparison of the results with an analytical solution on different harmonics of Fourier (1, 2 and 3),
- homogeneity of elements between them.

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v4.04.100/10000952000022BA000011E1C9E2C312EC7A1415.svg)

$R=\mathrm{1 }m$ cylinder radius.

### 1.2 Material properties

$\lambda =1W/m°C$

### 1.3 Boundary conditions and loads

| $[\mathrm{EA}]$: temperature imposed | $T={T}_{0}=0.°C$ |
| --- | --- |
| $[\mathrm{BC}]$: forced flow | $\phi ={\phi }_{0}=2.W/\mathrm{m2}°C$ |
| $[\mathrm{CD}]$: exchange | $h=2.W/{m}^{2}°C$ |
|  | ${T}_{\mathrm{ext}}=2.°C$ |

## 2 reference solution

### 2.1 Calculation method used for reference solution

$T(r,z,\theta )={R}^{2}\cosl\theta$

with $l$ harmonic number of Fourier

$-\Delta T=({l}^{2}-4)\cosl\theta =S$

$\overrightarrow{\phi }=-(\lambda \overrightarrow{\nabla T})=[\begin{array}{}-\mathrm{2r}\cosl\theta \\ 0.\\ +(\mathrm{lr}\sinl\theta )\end{array}$

on $[\mathrm{AB}]$ and $[\mathrm{ED}]$ : ${\phi }_{0}=\overrightarrow{\phi }.\overrightarrow{n}=0.$

on $[\mathrm{BC}]$ : ${\phi }_{0}=2R=2.$

on $[\mathrm{CD}]$ : $\overrightarrow{\phi }.\overrightarrow{n}=2R=\frac{2}{R}(2{R}^{2}-{R}^{2})=h({T}_{\mathrm{ext}}-T)$

> d'où $h=\frac{2}{R}=2.$
> ${T}_{\mathrm{ext}}=2{R}^{2}=2.$

Only the source term varies according to the harmonic $({S}^{l}(r,z)={l}^{2}-4)$

In the following modellings, the problem will be solved on harmonics 1, 2 and 3.

### 2.2 Baseline

Temperatures and flow at $B,C,D,F,G$ points.
