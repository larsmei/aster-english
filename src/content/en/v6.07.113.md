# v6.07.113 COMP013 – incremental isotropic and hyperelastic elasticity

This test aims to test constitutive laws incremental isotropic elasticity `ELAS_ISOT_INCR` and isotropic hyperelasticity
`ELAS_ISOT_ENER` in 3D and 1D, in the presence of command variables.

## 1 Reference problem

### 1.1 Geometry

The problem is homogeneous. We rely on the SIMU_POINT_MAT command for 3D tests.
As for 1D tests, a slash is passed through the $(Oxy)$ plane, the original coordinates of which are $(2,1,0)$, $(4,2,0)$ end and the cross section is $S=5 mm^2$.

### 1.2 Material properties

The material is elastic.

The Poisson's ratio is set to 0.3 but this value does not affect the results because the load is uniaxial.

The Young's modulus depends on the temperature affinely.

The coefficients of thermal expansion, desiccation removal and endogenous withdrawal are constant.

The values are given in the table below. Note that these values are not representative of a specific material.

| Poisson's ratio | $\nu=0.3$ |
| --- | --- |
| Young's modulus | $T= 20 °C \quad E = 10^5 MPA$ |
| $T= 120 °C \quad E = 2 \times 10^5 MPA$ |  |
| Thermal dilation | $\alpha = 10^{-5}°C^{-1} \quad T_{ref}=0°C$ |
| Withdrawal of desiccation | $k=10^{-5}m^3/l \quad C_{ref}=500l/m^3$ |
| Endogenous withdrawal | $\beta= 10^{-5}$ |

### 1.3 Boundary conditions and loads

In the 3D case, the $\varepsilon$ uniaxial deformation is imposed by leaving zero stresses in the normal directions at loading.
In the 1D case, the following displacement is imposed on all nodes of the bar, where $\varepsilon$ again designates the uniaxial deformation level:

The deformation changes from $\varepsilon_0=10^{-3}$ to $\varepsilon_1=3 \times 10^{-3}$.
In general, index 0 will refer to the values at the beginning of loading and index 1 will refer to the end of loading.
There are no forces imposed but it is considered that there is an initial stress $\sigma_0=100 MPa$.
Finally, the material is subject to an evolution of the control variables:

- Temperature changes from $T_0=20°C$ to $T_1=120°C$
- Water concentration changes from $C_0=500L/m^3$ to $C_1=300L/m^3$
- The degree of hydration changes from $\xi_0=0$ to $\xi_1=1$
- The anelastic (external) deformation changes from $\varepsilon_0^a=10^{-3}$ to $\varepsilon_1^a=3 \times 10^{-3}$. Note that $\varepsilon_1^a=3 \times 10^{-3}$ is (temporarily) not applied to 3D situations, due to a bug in SIMU_POINT_MAT.

## 2 reference solution

### 2.1 Calculation method used for reference solution

In view of the control variables, mechanical deformation is written as follows:

$$
\varepsilon^m=\varepsilon-\alpha(T-T_{ref})-k(C-C_{ref})+\beta\xi-\varepsilon^a
$$

In the case of hyperelastic behaviour (ELAS_ISOT_ENER), the stress at the end of loading then simply expresses itself as a function of the current mechanical deformation, without history effect:

$$
\sigma_1=E(T_1)\varepsilon_1^m
$$

The case of incremental elastic behaviour (ELAS_ISOT_INCR) is more complicated, as the constitutive law is written in function of an intermediate deformation $a$:

$$
\begin{aligned}
\sigma &=E a  ; \\
\dot a &= \dot\varepsilon_m
\end{aligned}
$$

### 2.2 Baseline

The reference result used for the test is the $\sigma_1$ (or $N_1$) load-end stress for 1D tests. It is also recalled that the reference values for this stress will be different between 1D and 3D, because of the lack of (temporarily) consideration of the anelastic control deformation in the 3D case.
