# v3.01.101 SSLL101 - Pipes : HOVGAARD problem

**Summary:**

It is a linear, static elastic test of a non-coplanar three-dimensional pipe with elbows. There is a dynamic test of the same structure (SDLX02) [V2.05.002](doc:v2.05.002).

Elements POU_D_T, TUYAU_3M (SEG3 and SEG4) and TUYAU_6M (SEG3) are tested via 5 modellings:

- Modelling A: 92 elements POU_D_T (40 for one elbow), calculation with MECA_STATIQUE,
- Modelling C: 28 elements TUYAU_3M (SEG3) (5 for one elbow), calculation with MECA_STATIQUE,
- Modelling D: 28 elements TUYAU_6M (SEG3) (5 for one elbow), calculation with MECA_STATIQUE,
- Modelling E: 28 elements TUYAU_3M (SEG4) (5 for one elbow), calculation with MECA_STATIQUE,

The loads are of type:

- gravity,
- thermal,
- Nodal forces.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The reference solutions selected to check the modellings *Code_Aster* are:

- for modellings POUTRE: comparison with codes: $\text{POUX}$ , $\text{ADL}$ and $\text{TITUS-T}$ [1] , using beam-type modelling,
- for modellings TUYAU: comparison with $\text{ABAQUS}$ code , using pipe-type modelling. The mode number of Fourier ($M$ ) used in the calculation of the reference is the same as that used in the calculations with *Code_Aster* .
- For modellings beams, a time equivalent to point $T1$ is also defined as ${M}_{\mathit{eq}}=\sqrt{({\mathit{MT}}^{2}+{\mathit{MFY}}^{2}+{\mathit{MFZ}}^{2})}$ . The reference value is that obtained by hand with the results of Modelling A (reference AUTRE_ASTER).

## 7 Summary of the results

This test case allows testing a non-coplanar piping.

**Drawer Modelling:**

The results are similar to reference solution (beam Modelling: average of 3 code results).

**Hose Modelling:**

The results *Code_Aster* are similar to those d-$\text{ABAQUS}$ (for elements pipes), except for $\mathrm{DY}$ displacement and for clean weight and nodal forces loads where the difference with reference solution is more important with mesh cells SEG3 ($\text{10\%}$) than with mesh cells SEG4 ($\text{5\%}$).

The thermal expansion loading gives similar results.
