# v2.04.129 SDLV129 - Vibrating fat of a fan blade

**Summary:**

This test case allows the calculation of the maximum permissible vibration amplitude for a fan blade to be validated. The calculation is based on the calculation of the modal stresses and then the post-processing with the CALC_FATIGUE operator.

This test case has only one model. Reference values are non-regression type. Analytically, in a few nodes, based on the stresses calculated by Code_Aster, the fatigue post-processing is correct.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The reference solution is obtained analytically in a given node of the calculation. Here, we are only interested in the validation of the fatigue post-processing; the values of the stresses and displacements at the node are those resulting from the calculation with *Code_Aster* .

### 2.2 Baseline

Particular attention is paid to:

- the maximum permissible amplitude coefficient associated with the node $\mathit{N111}$ of the mesh cell $294$ , which is the most statically charged node ;
- at the maximum permissible vibration amplitude for the node $\mathit{N194}$ (end of the wing).

Two cases are considered: a first-mode specific solicitation only; a first-mode specific solicitation. In the latter case, it is assumed that the second-mode own weight is equal to half the weight of the first-mode own.

The table below corresponds to the first calculation. The ${\sigma}_{\mathrm{stat}}$ static stress (von Signed Bets) at the node under consideration is $307,71\mathit{MPa}$; the modal constraints of the first two modes are $9,80\mathit{MPa}$ and $-31,15\mathit{MPa}$ respectively.

The modal stresses correspond to standard stresses. The objective is, knowing the static stress, to calculate the maximum amplitude of variation of the dynamic stress (sum of the modal stresses taken into account) allowing unlimited endurance of the structure. The coefficient $\alpha$ corresponds to this maximum amplitude. It is calculated either by using the Goodman straight line or by using the Gerber parable:

${\alpha}_{\mathit{Goodman}}={S}_{l}(1-\frac{{\sigma}_{\mathit{stat}}}{{S}_{u}})/{\sigma}_{\mathit{dyn}}$ et ${\alpha}_{\mathit{Gerber}}={S}_{l}(1-{(\frac{{\sigma}_{\mathit{stat}}}{{S}_{u}})}^{2})/{\sigma}_{\mathit{dyn}}$

In both formulas, ${S}_{l}$ represents endurance limitation. ${S}_{l}=500$ in this test is associated with the amplitude of the stress alternating with $1.E6$ cycles. ${S}_{u}$ is the maximum material stress. ${S}_{u}=1000$ in this test.

| Cases | Static stress ${\sigma}_{\mathit{stat}}$ | Dynamic stress ${\sigma}_{\mathit{dyn}}$ | ${\alpha}_{\mathit{Gerber}}$ | ${\alpha}_{\mathit{Goodman}}$ |
| --- | --- | --- | --- | --- |
| Mode 1 | $307,71\mathit{MPa}$ | $9,80\mathit{MPa}$ | 46,18 | 35,32 |
| Mode 1 + 0.5 Mode 2 | $307,71\mathit{MPa}$ | $25,37\mathit{MPa}$ | 17,83 | 13,64 |

To switch from the $\alpha$ coefficient to the permissible vibration amplitude in a given point $\partial \tilde{u}$ (corresponding for example to the position of a sensor), an additional operation is to be performed, see the [U4.83.02](doc:u4.83.02) documentation.

${\tilde{u}}_{\mathit{mod}}^{i}$ is the point of interest displacement associated with $i$ mode; the vibration amplitude permissible in this point is then:

$\partial \tilde{u}=min(\alpha )\sum_{i=1}^{N}{\beta}_{i}{\tilde{u}}_{\mathit{mod}}^{i}$

where ${({\beta}_{i})}_{1\le i\le N}$ relative weights of different modes considered.

This operation is explained below for the node $\mathit{N194}$ (end of the wing). It is noted that the ${\beta}_{i},{\tilde{u}}_{\mathit{mod}}^{i}$ values are obtained with Code_Aster.

It is noted that the most statically charged node does not correspond to the most penalizing node: the $\alpha$ coefficient calculated above is not the minimum value for the whole mesh (see below for the minimum value for the Gerber correction).
