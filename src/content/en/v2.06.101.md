# v2.06.101 SHLL101 - straight beam. Harmonic Analysis

**Summary:**

This two-dimensional problem consists in calculating the forces present in a beam subjected to traction or bending during harmonic analysis. The reference solution is obtained from the discretized equations.

This test has two modellings.

For the first model, four loads are tested:

- traction force,
- traction force and material with damping,
- bending force,
- bending force and material with damping.

For the second model, two stresses are tested:

- traction force,
- traction force and material with damping.

The second model allows testing the complex loads imposed by the AFFE_CHAR_MECA_C command.

## 2 reference solution

### 2.1 Calculation method used for reference solution

If the beam is modelled by a Euler-Bernoulli beam and by a single finite element, the harmonic problem can be written as follows:

**traction problem:**

$(1+i\alpha \omega )\frac{\mathit{ES}}{L}u(B)-{\omega}^{2}\frac{\rho SL}{6}u(B)={F}_{x}(B)$

d'où $u(B)=\frac{F(B)}{\frac{\mathit{ES}}{L}-{\omega}^{2}\frac{\rho SL}{6}+i\alpha \omega \frac{\mathit{ES}}{L}}$

**Flexion problem:**

$\left[-{\omega}^{2}\left[\begin{array}{cc}\frac{13L}{35}& \frac{-11{L}^{2}}{210}\\ \frac{-11{L}^{2}}{210}& \frac{{L}^{3}}{105}\end{array}\right]+(1+i\alpha \omega )\frac{12{\mathit{EI}}_{y}}{{L}^{3}}\left[\begin{array}{cc}1& \frac{-L}{2}\\ \frac{-L}{2}& \frac{{L}^{2}}{3}\end{array}\right]\right]\left[\begin{array}{c}v(B)\\ \theta (B)\end{array}\right]=\left[\begin{array}{c}{F}_{y}(B)\\ 0\end{array}\right]$

**Note:**

*If the material does not have damping, then we have:* AMOR_ALPHA *=* $\alpha =0$ *.*

The point $B$ forces are calculated as follows:

**traction problem:**

$N(B)=\left(\frac{\mathit{ES}}{L}-{\omega}^{2}\frac{\rho SL}{6}\right)u(B)$

**Flexion problem:**

$\left[\begin{array}{c}\mathit{VY}(B)\\ \mathit{MFZ}(B)\end{array}\right]=\left[-{\omega}^{2}\left[\begin{array}{cc}\frac{13L}{35}& \frac{-11{L}^{2}}{210}\\ \frac{-11{L}^{2}}{210}& \frac{{L}^{3}}{105}\end{array}\right]+\frac{12{\mathit{EI}}_{y}}{{L}^{3}}\left[\begin{array}{cc}1& \frac{-L}{2}\\ \frac{-L}{2}& \frac{{L}^{2}}{3}\end{array}\right]\left[\begin{array}{c}v(B)\\ \theta (B)\end{array}\right]\right]$

$2\times 2$ systems are analytically solved to obtain the solution.

### 2.2 Baseline

The reference results are the movements, speeds, accelerations and generalized forces obtained from point $B$ during harmonic analysis.

### 2.3 Note for modelling B

For model B, the keyword FORCE_POUTRE is tested for traction problem, which allows for the application of distributed forces. To obtain the same solution as the nodal beam at its end, the relationship between constant distributed force and nodal force is:

${F}_{x}(B)=\frac{fL}{2}$

With the values given in paragraph 1.3., we have: $f=600N/m$

### 2.4 Uncertainty about the solution

If the assumptions are verified (Euler-Bernoulli beam), the solution is analytical.
