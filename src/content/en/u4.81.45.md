# u4.81.45 Operator POST_COMBINAISON

## 1 Purpose

The purpose of this macro-command is to combine different physical quantities following finite-element analyses carried out beforehand. This command performs only post-processing by manipulating results in the form of fields or tables produced by earlier analyses.

As input, this macro-command takes results of several types, or tables of type table_sdaster, to be combined, followed by a table of type table_sdaster of the coefficients to be applied for each combination.

As output, if results are combined, the macro-command returns a result structure of type mult_elas. On the other hand, in the case of a combination of tables, a table table_sdaster is returned. The final table of combinations, of type table_sdaster, is returned in both cases.

## 2 Syntax

```text
POST_COMBINAISON(
    ◆ TABLE_COEF = table,
    ◇ TABLE_COEF_RESU = co,
    ◆ TYPE_COMB = / "RESULTAT",
                  / "TABLE",
    # Si: equal_to('TYPE_COMB', 'RESULTAT')
        ◇ / TOUT = "OUI" (ou non renseigné),
          / | GROUP_MA = list[grma],
            | GROUP_NO = list[grno],
        ◆ MODELE = modele,
        ◇ NOM_CHAM = list[text],
        ◆ AFFE = _F(
             ◆ NOM_CAS = text,
             ◆ RESULTAT = evol_elas / mode_meca / mult_elas,
          ),
    # Si: equal_to('TYPE_COMB', 'TABLE')
        ◇ FILTRE = _F(
             ◆ NOM_PARA = text,
             ◇ CRIT_COMP = / "EQ" (par défaut),
                           / "GE",
                           / "GT",
                           / "LE",
                           / "LT",
                           / "MAXI",
                           / "MAXI_ABS",
                           / "MINI",
                           / "MINI_ABS",
                           / "NE",
                           / "NON_VIDE",
                           / "VIDE",
             # Si: (is_in("CRIT_COMP", ('EQ','NE','GT','LT','GE','LE')))
                 ◆ / VALE = float,
                   / VALE_I = int,
                   / VALE_K = list[text],
                   / VALE_C = complex,
                 ◇ CRITERE = / "ABSOLU",
                             / "RELATIF" (par défaut),
                 ◇ PRECISION = float (défaut: 0.001),
          ),
        ◆ AFFE = _F(
             ◆ NOM_CAS = text,
             ◆ TABLE = table,
          ),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand TABLE_COEF

Table containing the coefficients of the combinations for all the results or tables to be combined. Each column must contain the coefficients to be applied to a result or a table. The name at the head of the column must be consistent with the name supplied under the keyword NOM_CAS of the result or of the table supplied in the factor keyword AFFE. Each line must represent a combination. Each coefficient will be used to multiply the result/the table in the corresponding combination.

### 3.2 Operand TABLE_COEF_RESU

Name of the final table of coefficients. This table is derived from the table given as input under the keyword TABLE_COEF. It is extended according to the order numbers contained in each result or table.
This keyword is optional.

### 3.3 Operand TYPE_COMB

Text-type indicator used to specify the type of data structure to be multiplied.

Two choices are possible:

1. RESULTAT: The data structures to be combined are of type sd_resultat. Three types of result are accepted: mult_elas, evol_elas and mode_meca
2. TABLE: Data structure of type sd_table.

**Note**

Only tables produced by the operator CALC_COUPURE for static analyses are supported. For example, tables produced by CALC_COUPURE for seismic analyses (operator COMB_SISM_MODAL) are not processed.

### 3.4 Operands TOUT/GROUP_MA/GROUP_NO

The keywords TOUT, GROUP_MA and GROUP_NO allow the user to choose the mesh cells or the nodes on which the combinations are to be performed.

- TOUT = 'OUI'
  All the mesh cells (carrying finite elements) will be processed.
- GROUP_MA = l_grma
  Only the mesh cells included in l_grma will be processed.
- GROUP_NO = l_grno
  Only the nodes included in l_grno will be processed.

**Note**

The keywords GROUP_MA and GROUP_NO can be used simultaneously

### 3.5 Operand MODELE

Name of the model on which the output result will be assigned.

### 3.6 Operand NOM_CHAM

This keyword makes it possible to choose a list of symbolic field names to be combined (at the nodes or by element) from among all those possible. It is optional. If it is not supplied, all the fields are combined.

### 3.7 Factor keyword AFFE

The factor keyword AFFE is used to specify the results to be combined.
Either results or tables are supplied.

- NOM_CAS = l_nomcas
  Name of the result to be combined. It must be consistent with the names supplied in the table of coefficients.
- RESULTAT= resu
  Data structure sd_resultat to be combined.
- TABLE= table
  Data structure sd_resultat to be combined.

### 3.8 Operation FILTRE

This factor keyword is optional. It makes it possible to filter the lines of the table. For the use of this keyword see the command IMPR_TABLE [U4.91.03](doc:u4.91.03).

### 3.9 Operand NOM_PARA

Names of the parameters (columns) that one wishes to extract.
