# v7.14.303 HSLV303 – CALC_THERMECA_MULT operator verification on a hollow cylinder subjected to thermal shock

**Summary:**

To reduce the time required to set up thermomechanic calculations in the linear domain, a new methodology is proposed. This methodology consists of determining the temperature in a structure from the calculation of a unit thermal shock using the CALC_THERMECA_MULT macro-command.

The objective of this test case is to validate this methodology on the one hand and to verify its ease of implementation on the other. In this test case, one models a tube in which a fluid carrying a thermal shock circulates. Then the mechanical response is calculated using the same methodology.

The four modellingss performed are as follows:

- **Modelization** **A**: Volume modelling which calculates the transient thermal analysis response and the associated mechanical response for $\Delta T=50°C$ thermal shock from $(\Delta {T}_{U}=1°C)$ unit thermal shock via CALC_THERMECA_MULT.
- **Modelling** **B**: axisymmetric Modelling or transient thermal analysis response and associated mechanical response for $\Delta T=50°C$ thermal shock from $(\Delta {T}_{U}=1°C)$ unit heat shock via CALC_THERMECA_MULT.

## 2 reference solution

### 2.1 Calculation method used for reference solution

To reduce the time required to implement thermal calculations in the linear field, a new methodology is proposed.

A $\Omega$ structure is considered. A thermal shock is imposed on part of the $\partial \Omega$ structure. The following figure presents an example.

![Figure](/figures/v7.14.303/100002000000008100000080925C7F1100785B57.png)

Thermal shock is defined as a significant and instantaneous temperature increment. Figure 2 shows an example of several consecutive thermal shocks.

![Figure](/figures/v7.14.303/1000020000000122000000AE9B5D7AAA335C641A.png)

Fourrier's law describing the thermal exchange applied to this thermally shocked structure may be written in this form:

$T(x,t)=\lbrace \begin{array}{c}T(x,{t}_{0})\text{pour t <}{t}_{c}\\ T(x,{t}_{0})+\underset{{t}_{c}}{\overset{t}{\int}}a\frac{{\partial}^{2}T(x,t)}{\partial {x}^{2}}\mathit{dt}\text{pour t}\ge \text{}{t}_{c}\end{array}$

Where $T(x,{t}_{0})$ is the initial state of the known structure, and ${t}_{c}$ l-minute thermal shock. For different thermal shocks, it is therefore necessary to solve this problem and thus obtain, for each of the shocks, the solution $T(x,t)$ .

#### 2.1.1 Unit impact case

If a $\Delta {T}_{U}$ ($\Delta T=1$ degree shock) is imposed on $\partial \Omega$ at $t={t}_{c}$, the problem is:

${T}_{U}(x,t)=\lbrace \begin{array}{c}{T}_{U}(x,{t}_{0})\text{pour t <}{t}_{c}\\ {T}_{U}(x,{t}_{0})+\underset{{t}_{c}}{\overset{t}{\int}}a\frac{{\partial}^{2}{T}_{U}(x,t)}{\partial {x}^{2}}\mathit{dt}\text{pour t}\ge \text{}{t}_{c}\end{array}$

With ${T}_{U}(x,{t}_{0})$ the initial state of the structure before the unit impact. The solution to this problem can be determined numerically using the elements method, including Code_Aster THER_LINEAIRE operator if the material parameters are temperature independent. Once the problem is solved, the ${T}_{U}(x,t)$ solution is known.

As it is only interested in the temperature differential, a simplified notation is proposed:

$\stackrel{̃}{{T}_{U}}(x,t)={T}_{U}(x,t)-{T}_{U}(x,{t}_{0})$

So we have

$\stackrel{̃}{{T}_{U}}(x,t)=\lbrace \begin{array}{c}0\text{pour t <}{t}_{c}\\ \underset{{t}_{c}}{\overset{t}{\int}}a\frac{{\partial}^{2}\stackrel{̃}{{T}_{U}}(x,t)}{\partial {x}^{2}}\mathit{dt}\text{pour t}\ge \text{}{t}_{c}\end{array}$

#### 2.1.2 Case of any shock

A thermal shock, always on $\partial \Omega$, but of any intensity $\beta$ is this time imposed. This problem is written in the form:

${T}_{\beta}(x,t)=\lbrace \begin{array}{c}{T}_{\beta}(x,{T}_{0})\text{pour t <}{t}_{c}\\ {T}_{\beta}(x,{T}_{0})+\underset{{t}_{c}}{\overset{t}{\int}}a\frac{{\partial}^{2}{T}_{\beta}(x,t)}{\partial {x}^{2}}\mathit{dt}\text{pour t}\ge \text{}{t}_{c}\end{array}$

With ${T}_{\beta}(x,{t}_{0})$ the initial state of the structure before the thermal shock. By taking over the simplified notation, we obtain:

$\stackrel{̃}{{T}_{\beta}}(x,t)=\lbrace \begin{array}{c}0\text{pour t <}{t}_{c}\\ \underset{{t}_{c}}{\overset{t}{\int}}a\frac{{\partial}^{2}{T}_{\beta}(x,t)}{\partial {x}^{2}}\mathit{dt}\text{pour t}\ge \text{}{t}_{c}\end{array}$

Compared to the previous unit problem, only the intensity of the thermal loading has been changed: $\Delta T=\beta \Delta {T}_{U}$. Indeed, the shock is still on $\partial \Omega$, it is simply amplified from the $\beta$ scalar. Therefore:

This last equation n- is valid only for a linear thermal problem and therefore $\beta$ independent of the position. The solution of any thermal shock is therefore:

$\stackrel{̃}{{T}_{\beta}}(x,t)=\lbrace \begin{array}{c}0\text{pour t <}{t}_{c}\\ \underset{{t}_{c}}{\overset{t}{\int}}a\beta \frac{{\partial}^{2}\stackrel{̃}{{T}_{U}}(x,t)}{\partial {x}^{2}}\mathit{dt}\text{pour t >}{t}_{c}\end{array}$

In addition, considering that the $\beta$ scalar is time independent, which is consistent with a thermal shock, we have:

$\underset{{t}_{c}}{\overset{t}{\int}}a\beta \frac{{\partial}^{2}\stackrel{̃}{{T}_{U}}(x,t)}{\partial {x}^{2}}\mathit{dt}=\beta \underset{{t}_{c}}{\overset{t}{\int}}a\frac{{\partial}^{2}\stackrel{̃}{{T}_{U}}(x,t)}{\partial {x}^{2}}\mathit{dt}$

The integral present in this problem equation is in reality the solution previously obtained for the unit shock:

$\underset{{t}_{c}}{\overset{t}{\int}}a\frac{{\partial}^{2}\stackrel{̃}{{T}_{U}}(x,t)}{\partial {x}^{2}}\mathit{dt}=\stackrel{̃}{{T}_{U}}(x,t)\text{}\mathit{pour}t\ge {t}_{c}$

The solution to the problem of any thermal shock on $\partial \Omega$ solution obtained for unit thermal shock:

$\stackrel{̃}{{T}_{\beta}}(x,t)=\beta .\stackrel{̃}{{T}_{U}}(x,t)$

Here it is considered that unit heat shock occurs at the same time as thermal shock $\Delta {t}_{c}$. If the shock occurs at another time, simply shift the solution:

$\stackrel{̃}{{T}_{\beta}}(x,t)=\beta .\stackrel{̃}{{T}_{U}}(x,t-({t}_{c}-{t}_{\mathit{c2}}))$

Where ${t}_{\mathit{c2}}$ is the moment of the unit shock. Therefore, by choosing the unit shock so that ${t}_{\mathit{c2}}$ is at the moment $t=\mathrm{0s}$, the solution becomes:

$\stackrel{̃}{{T}_{\beta}}(x,t)=\beta .\stackrel{̃}{{T}_{U}}(x,t-{t}_{c})$

The temperature range of the structure can therefore be determined by following the following steps:

- Set a uniform initial temperature field on the ${T}_{\beta}(x,{t}_{0})$ structure
- Set up a thermal analysis of a unit shock at $t=\mathrm{0s}$ time on the structure and get the solution of the unit problem and determine $\stackrel{̃}{{T}_{U}}(x,t)$. It may be wise to impose an initial temperature zero so that $\stackrel{̃}{{T}_{U}}(x,t)={T}_{U}(x,t)$ .
- Calculate the solution (space and time) from a linear combination of the initial $T(x,{t}_{0})$ situation, the intensity of the $\beta$ shock and the solution of the $\stackrel{̃}{{T}_{U}}(x,t)$ shock problem.

## 5 Summary of the results

The proposed methodology is to determine the thermal and mechanical responses in a structure from the calculation of a unit thermal shock and using the CALC_THERMECA_MULT macro-command. This chaining has been tested and implemented, it:

- Allows to reduce the time required to set up thermal and mechanical calculations in the linear field,
- Is easy to set up.

This was done to verify that the temperature of a structure subjected to $\Delta T$ shock could be determined from a unit heat shock $(\Delta {T}_{U}=1°C)$ and an initial temperature $T(x,{t}_{0})$ by performing the following linear combination:

${T(x,t)}_{\Delta T}=\Delta T.{\stackrel{̃}{T}}_{\Delta {T}_{U}}(x,t)+T(x,{t}_{0})$

This methodology was also tested in a thermomechanical analysis. From the unit thermal results the "Unitary" stresses were calculated and using the CALC_THERMECA_MULT macro-command, the stresses for the $\Delta T=50°C$ shock were determined.

The maximum differences observed are in thermal as well as mechanically more than 100 times lower than the given tolerance. This is simply due to the fact that CALC_THERMECA_MULT only encapsulates the same Code_Aster commands that the user should have set himself otherwise and which were used for the reference calculation.
