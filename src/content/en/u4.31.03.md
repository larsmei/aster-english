# u4.31.03 Operator DEFI_NAPPE

## 1 Purpose

Define a real function of two real variables. A nappe defines N functions for N values of a parameter.

This operator makes it possible to define, for example, boundary conditions depending on a space variable and on time, or on two space variables, or material data (for example traction curves as a function of temperature).

The concept produced by this operator is of type nappe.

## 3 Operands

### 3.1 Operand NOM_PARA

```text
♦    NOM_PARA = np
```
Designates the name of the parameter of the nappe (second variable); cf. the example in [§4.1].

The allowed values listed are the same as in DEFI_FONCTION [U4.31.02](doc:u4.31.02).

### 3.2 Operand NOM_RESU

```text
◊    NOM_RESU = nr
```
Name of the result, of the values of the nappe. It must be identical to the NOM_RESU of each of the functions making up the nappe.

In fact, this operand is not systematically used for consistency checks, in the execution of the code. These consistency checks are made by the command CALC_FONCTION [U4.32.04](doc:u4.32.04).

### 3.3 Operand PARA

```text
♦    PARA = lp
```
List of the values of the parameter characteristic of the nappe: para1, para2, ... The cardinality of this list must be equal to the number of functions defined afterwards.

### 3.4 Operands PROL_DROITE and PROL_GAUCHE

```text
◊    PROL_DROITE et PROL_GAUCHE =
```
Define the type of extension to the right (to the left) of the domain of definition of the variable:

| 'CONSTANT' | for an extension with the last (or first) value of the nappe, |
| --- | --- |
| 'LINEAIRE' | for an extension along the first segment defined (PROL_GAUCHE) or the last segment defined (PROL_DROITE); this extension does not take account of a possible logarithmic interpolation, |
| 'EXCLU' | if the extrapolation of the values outside the domain of definition of the parameter np is forbidden (in this case if an analysis requests a value of the function outside the domain of definition, the code will stop in fatal error). |

### 3.5 Operand INTERPOL

```text
◊    INTERPOL=
```
Type of interpolation of the nappe: one type for the interpolation of the second variable and one for the interpolation between two functions. This is obtained by supplying a list of 2 texts among:

```text
INTERPOL = ('LIN', 'LOG')
```
| 'LIN': | linear, |
| --- | --- |
| 'LOG': | logarithmic, |

**Note:**

*If only one value is specified, it is taken into account both for the interpolation of the parameter and for that of the function.* *INTERPOL = 'LOG' is equivalent to ('LOG', 'LOG').*

### 3.6 Operand INFO

```text
◊    INFO =
```
Specifies the printout options in the message file (unit 6).

| 1 : | no printout (default option) |
| --- | --- |
| 2 : | printout of the parameters plus the list of the first 10 values of each function in increasing order of the first 10 parameters |

### 3.7 Operand VERIF

```text
◊    VERIF =
```
The operator DEFI_NAPPE reorders the values of the parameters np in increasing order. If VERIF is equal to 'Croissant' the operator stops the execution if the values of the parameter np have not been given in this order.

### 3.8 Definition of the functions of the nappe

Two modes of definition of the nappe are possible:

- from a list of existing functions [§3.8.1],
- by defining directly the various functions of the nappe [§3.8.2].

#### 3.8.1 Operand FONCTION

```text
FONCTION = lf
```
List of concepts of type fonction created by the commands DEFI_Fonction [U4.31.02](doc:u4.31.02), DEFI_CONSTANTE [U4.31.01](doc:u4.31.01), CALC_FONC_INTERP [U4.32.01](doc:u4.32.01), …

lf is the list of the names of concepts of type fonction corresponding to the values of the parameter.

All the functions of the list must have the same variable name (NOM_PARA of DEFI_FONCTION, which we shall call npf) and have the same name nr as the result name.

nf is a nappe of the variable of name np and of the variable of name npf and whose value has the name nr.

#### 3.8.2 Direct definition of the functions

##### 3.8.2.1 Operand NOM_PARA_FONC

```text
♦    NOM_PARA_FONC =    npf
```
Name of the parameter characteristic of the functions constituting the nappe.

The allowed values listed are the same as for NOM_PARA.

##### 3.8.2.2 Keyword DEFI_FONCTION

```text
DEFI_FONCTION =
```
Direct definition of the functions constituting the nappe.

##### 3.8.2.3 Operand VALE

```text
♦    VALE =lv
```
lv is the list of values (x1, y1, …, xn, yn) with, in order:

x1, y1 (the first value of the parameter and the corresponding value of the result),

...

xn, yn (the last value of the parameter and the corresponding value of the result).

##### 3.8.2.4 Operands PROL_DROITE and PROL_GAUCHE

```text
◊    PROL_DROITE et PROL_GAUCHE=
```
Define the type of extension to the right (to the left) of the domain of definition of the variable:

| 'CONSTANT' | for an extension with the last (or first) value of the function, |
| --- | --- |
| 'LINEAIRE' | for an extension along the first segment defined (PROL_GAUCHE) or the last segment defined (PROL_DROITE), |
| 'EXCLU' | if the extrapolation of the values outside the domain of definition of the parameter npf is forbidden (in this case if an analysis requests a value of the function outside the domain of definition, the code will stop in fatal error). |

##### 3.8.2.5 Operand INTERPOL

```text
◊    INTERPOL=
```
Type of interpolation of the function between the values of the domain of definition of the function: one type for the interpolation of the abscissae and one for the interpolation of the ordinates of the function. This is obtained by supplying a list of texts among:

```text
INTERPOL = ('LIN', 'LOG')
```
| 'LIN': | linear, |
| --- | --- |
| 'LOG': | logarithmic, |
| 'NON': | one does not interpolate (and therefore the program will stop if one requests the value of the function for a value of the parameter for which it has not been defined). |

**Note:**

*If only one value is specified, it is taken into account both for the interpolation of the parameter and for that of the function.* *INTERPOL = 'LOG' is equivalent to ('LOG', 'LOG').*

### 3.9 Operand TITRE

```text
◊    TITRE = ti
```
Title attached to the concept produced by this operator [U4.03.01](doc:u4.03.01).

### 3.10 Evaluation of a nappe

Let there be a nappe $N$ whose parameter is NOM_PARA= $y$  and which is composed of functions whose NOM_PARA_FONC= $x$ , with values NOM_RESU= $z=f(x)$ .

To evaluate $N(x,y)$ :

- One looks for $i$ such that ${y}_{i}\le y<{y}_{i+1}$ ,
- One evaluates the two functions ${f}_{i}$ and ${f}_{i+1}$ at $x$ . For this, one uses the extensions and the types of interpolation of each function (defined in the command DEFI_FONCTION or under the factor keyword DEFI_FONCTION of DEFI_NAPPE).
- One then evaluates $N(x,y)$ by interpolating from the values $({y}_{i},{y}_{i+1})$ and $({f}_{i}(x),{f}_{i+1}(x))$ . One then uses the extensions and types of interpolation defined by the simple keywords PROL_GAUCHE, PROL_DROITE, INTERPOL of DEFI_NAPPE.

One would write:

nappe = DEFI_NAPPE(    NOM_PARA = 'y',

> NOM_RESU = 'z',
> NOM_PARA_FONC = 'x',
> INTERPOL = (a, b),
> DEFI_FONCTION = (_F(    VALE=...,

> INTERPOL = (c, d),),

> other functions... ),)

The types of interpolation used are:

- c between two values of x,
- d when one evaluates the functions at x,
- a between two values of y,
- b between two different functions (evaluated at x).

## 4 Examples

### 4.1 Definition of the nappe after definition of the function

```text
FCT2 =    DEFI_FONCTION            (NOM_PARA = 'EPSI',    PROL_DROITE =    'LINEAIRE',
PROL_GAUCHE =    'LINEAIRE',
VALE = (1.25E-5, 3.75, 3.75E-5, 7.5,),    )

FCT3 =    DEFI_FONCTION            (NOM_PARA = 'EPSI',    PROL_DROITE =    'LINEAIRE',
PROL_GAUCHE =    'LINEAIRE',
VALE = (1.25E-5, 2.50, 3.75E-5, 5.0,),    )

SIG =        DEFI_NAPPE        (NOM_PARA = 'TEMP',    PROL_DROITE =    'CONSTANT',
PROL_GAUCHE =    'CONSTANT',
PARA =                 (20.0,    30.0,),
FONCTION =             (FCT3, FCT2,)    ,        )
```
### 4.2 Direct definition of the nappe and of the constituent functions

```text

NOM_PARA_FONC =             'EPSI',
DEFI_FONCTION =    (

    _F( PROL_DROITE =    'LINEAIRE',
PROL_GAUCHE =    'LINEAIRE',
VALE =(1.25E-5, 3.75, 3.75E-5, 7.5,),
),

_F( PROL_DROITE = 'LINEAIRE',
PROL_GAUCHE =     'LINEAIRE',
VALE =(1.25E-5, 2.5, 3.75E-5, 5.0,),                                                            ),

    ),
)
```
