# v3.01.116 SSLL116 - 3D reinforced trellis

**Summary:**

This test concerns the study of a slender beams mesh, in linear static analysis.

The mesh is modelled with linear elements (SEG2) and subjected to a punctual loading and gravity effect.

There is a Modelling with a first geometry, then a Modelling with reinforcement bars.

This test is an example of an educational purpose since it shows the construction of the solution by elements finished rather than using MECA_STATIQUE directly.

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v3.01.116/100000000000040D000003F01AEAAF805DBE3678.png)

The lattice consists of beams of sections:

- for **---**, $R=0.05$ ring, $\mathrm{ep}=0.02$
- for **----**, circular $R=0.05$
- for **----**, circular $R=0.07$

The point $A$ is in the middle of the final stem.

### 1.2 Material properties

Isotropic linear elastic material:

$E=1.962\mathit{E11}\mathit{Pa}$ ; $\nu =0.3$

### 1.3 Boundary conditions and loads

The base of the mesh is clamped.
