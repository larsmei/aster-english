# v6.04.186 SSNV186 – LBB condition and frictional contact with X-FEM

**Summary**

The purpose of this test is to validate the consideration of contact (by the continuous [bib1] method) on the crack lips in the X-FEM [bib2] method, when the LBB condition [bib3] [bib4] is not met.

Contact/frost is processed by an increased Lagrangian algorithm for modellings A to H and by a penalised algorithm for modellings I to K.

This test involves a parallelepipedic block in compression. The interface through it is represented by a level set. The interface is straight, unspinned and completely crosses the elements.

## 1 Reference problem

In some cases, oscillations of contact pressures may occur, particularly for structures where the interface cuts pentahedrons under a non-uniform load.

This is due to the non-compliance with the LBB condition [bib3] [bib4]. This d-oscillation phenomenon is comparable to that encountered in incompressibility [bib5]. Physically, in the case of contact, this amounts to wanting to impose contact in excess of interface points (over-stressed), making the hyperstatic system. To release it, it is necessary to restrict the space of Lagrange multipliers, as is done in [bib6] for Dirichlet conditions with X-FEM. Such algorithms have P0 segments, which slow the convergence. A good algorithm must minimize the appearance of such segments. L-algorithm proposed by Moës [bib6] to reduce oscillations is adapted to the 3D case (algorithm version 1). This algorithm has been improved to make it more physical and effective (algorithm version 2). A comparison of both versions is made.

It should be noted that these parasitic oscillations are not reproducible in the current version of Code_Aster: one of the two algorithms is systematically chosen (the 2 is used by default), and even an overload of the code to not use any one would bring a zero pivot. We illustrate them in this documentation by results from another formulation (formulation to the edges [bib7]), which is now being resolved.

For hexahedrons or quadrangles cut horizontally, there are no P0 segments.

The interface is introduced by level set functions directly into the command file using the DEFI_FISS_XFEM [U4.82.08](doc:u4.82.08) operator. The interface is present within the structure through its representation by the level set. The normal level set ($\mathrm{LSN}$ ) allows to define a flat, unpaved interface that completely crosses the elements, by the following equation:

## 2 Modelization A: hexahedrons (version 2)

In this Modelling, the mesh considered has only hexahedrons, which is used as a reference for the others, as this case does not have P0 segments. Indeed, in the case of hexahedrons cut by a parallel interface to the faces, the number of contact pressures (one per cut edge) is compatible with the discretization of the displacement field [bib1] [bib2].

### 2.1 Mesh characteristics

The problem is invariant along the $\mathit{Ox}$ axis. To limit the calculation time, the mesh here is composed of only one element on this axis. The structure is then modelled by a regular mesh composed of $1\times 20\times 20$ HEXA8 see [ Figure 2.1-1 ].

![Figure](/figures/v6.04.186/100000000000028B000002C1576825A2A67F44AE.jpg)

Figure 2.1-1: Maillage d’hexaèdres

This mesh is composed of linear finite d-elements. As part of the continuous method [bib1] with X-FEM [bib2], contact unknowns are carried by the nodes peaks.

### 2.2 Tested Features

The integration scheme is reduced to 4 Gauss points per contact facet.

Friction is taken into account and contact is active from the first iteration of active stresses.

### 2.3 Tested quantities and results

The contact pressure value of point $P$ coordinates is tested. This value is used as a reference for the other modellings.

$\lambda =-9528440\mathit{Pa}$

## 3 Modelization B: Pentahedras and Adherent Law (version 2)

In this Modelling, the efficiency of the version 2 algorithm for a pentahedral mesh is tested, in the case of a fully adherent interface. To model this one, the CZM_LIN_MIX cohesive law is used.

### 3.1 Mesh characteristics

The structure is modelled by a regular mesh made of HEXA6 pentahedrons (see figure).

![Figure](/figures/v6.04.186/1000000000000294000002D90BEE2D1A979AACE7.jpg)

Figure 3.1-1: Maillage de pentaèdres

### 3.2 Tested Features

The use of the algorithm version 2 is validated for an adherent interface.

The implementation of the CZM_LIN_MIX cohesive law for the elements pentahedrons is validated.

The integration scheme is reduced to 4 Gauss points per contact facet.

The CZM_LIN_MIX cohesive law is used with a ${\sigma}_{c}$ critical stress that is much higher than the applied pressure (defined by the equation): ${\sigma}_{c}=50\times {10}^{6}\mathit{Pa}$. Thus, the critical constraint will never be exceeded during the calculation: the interface remains adherent.

## 7 Summary of 3D results

### 7.1 Summary

In the X-FEM method, it has been shown that, without special treatment, a mesh structure with non-uniform loading pentahedrals may have strong contact pressures oscillations, as shown in the second curve of [Figure 7.2-1 ]), made with a different [bib7] formulation, now resorbed in Code_Aster, for which the absence of a restriction algorithm did not lead to a zero pivot. The same mesh structure with hexahedrals subjected to the same load does not exhibit such oscillations (modelling A as a reference).

Two algorithms were proposed to significantly reduce these oscillations. The first (third curve of [Figure 7.2-1 ]) appears to be less accurate than the second (modelization D).

Moreover, even under uniform loading, oscillations can occur and it is essential to use an algorithm to reduce the Lagrange pressure multipliers (modelling E).

### 7.2 Comparison curves

The [Figure 7.2-1 ] combines the contact pressure curves along the $\mathit{Oy}$ axis, respectively for the hexahedral mesh (modelization A), a pentahedral mesh without LBB processing algorithm, a pentahedral mesh with algorithm 1 and finally a pentahedral mesh with algorithm 2 (modelization D). It is noted that the oscillations for the second case are so strong that in some points the value of the contact pressure becomes positive, which means that there is a detachment of the interface. Both algorithms allow a visible reduction of oscillations, and the reference curve obtained with the mesh d-hexahedrons is found.

![Figure](/figures/v6.04.186/Object_6.png)

Figure 7.2-1: Comparaison des pressions de contact suivant les modélisations (pressions exprimées en GPa)

The [Figure 7.2-2 ] compares in detail the effects of the two algorithms. It is noted that the first often involves constant contact pressures per piece, while the second tends to linearize pressures. It is evident that such differences are reduced by refining the mesh.

![Figure](/figures/v6.04.186/Object_7.png)

Figure 7.2-2: Comparaison des 2 algorithmes (pressions exprimées en GPa)
