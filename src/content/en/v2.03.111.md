# v2.03.111 SDLS111 - Dynamic substructure: triangular plate

**Summary:**

The objective of this test case is to validate the classic substructure with interfaces of type CRAIG-BAMPTON in the case of a triangular plate.

Test case is composed of DKT Modelling of the triangular plate

## 2 reference solution

### 2.1 Reference calculation

Test case:

- Calculation of the specific modes of each triangle

  - $\mathrm{TRI1}$ AND $\mathrm{TRI2}$ , searching for eigenmodes for $f\in [10,3000]$
  - $\mathrm{TRI3}$ AND $\mathrm{TRI4}$ , looking for the first $25$ modes clean
- Definition and calculation of the static modal base of each triangle
- Creation of a static generalized model by base coupling
- Calculation and physical return of the modes of the overall structure

  - Travel test
  - Eigenfrequency test
