# v1.01.321 EFICA01 - Graphic recipe for EFICAS tool

**Summary:**

This test case serves as a template for the EFICAS tool's graphic recipe. The goal is to be able to write this test identically in EFICAS from a blank page.

So we tried to place all the commands that were a little bit specific in the command language.

This is a copy of the sdnd102a test, which was added:

- the definition of a parameter;
- the inclusion of a file (INCLUDE);
- a pursuit (POURSUITE).

This documentation is deliberately succinct.
