# v3.02.306 SSLP306 - clamped plate subjected to polynomial transverse charge

**Summary:**

The purpose of the test is to validate the element automatically created from Fenicsx based on Reissner-Mindlin theory and MITC procedure.

The reference solution is an analytical.

The new finite element PLAQ_MITC (discretized with QUAD9 and TRI6) is compared with the elements DKT and DST.

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v3.02.306/probleme_reference.svg)

Fig: Schematic of the Reference problem

The fine plate is defined by $\Omega=[0,L]\times[0,L]\times[-h/2,h/2]$ where

Length: $L = 1 \mathrm{m}$

Thickness: $h = 0.001 \mathrm{m}$ or $h = 0.1 \mathrm{m}$

For Modelling D, the same rotational geometry of $30^\circ$ is used.

### 1.2 Material properties

Young's modulus: $E = 10920 \mathrm{Pa}$.

Poisson's ratio: $\nu = 0.3$.

### 1.3 Boundary conditions and loads

- Clamped support on the edge ($w=0$ and $\theta_x=\theta_y=0$)
- Polynomial overfacial load:

For modellings A, B, C, E:

$$
\begin{aligned}
f(x,y) = \frac{E h^{3}}{12 (1 - \nu^{2})}
\Big[
    &12 y (y - 1) (5 x^{2} - 5 x + 1) \big(2 y^{2} (y - 1)^{2}\big) \\
    &+ x (x - 1) (5 y^{2} - 5 y + 1) \big(2 x^{2} (x - 1)^{2} + 1\big) \\
    &+ 12 x (x - 1) (5 y^{2} - 5 y + 1) \big(2 x^{2} (x - 1)^{2}\big) \\
    &+ y (y - 1) (5 x^{2} - 5 x + 1) \big(2 y^{2} (y - 1)^{2} + 1\big)
\Big]
\end{aligned}
$$

For Modelling D, due to the rotation of geometry, the following variables must be included in $f(x, y)$:

$$
\begin{aligned}
x \rightarrow \cos(\theta) x + \sin(\theta) y \\
y \rightarrow -\sin(\theta) x + \cos(\theta) y \\
\textrm{où} \; \theta = \pi / 6
\end{aligned}
$$

### 1.4 Initial conditions

Not applicable for static analysis.

## 2 reference solution

### 2.1 Calculation method used for reference solution

For modellings A, B, C, the vertical displacement value and the rotation values around the $X$ and $Y$ axes are given by:

$$
\begin{align}
    w(x, y) &= \frac{1}{3} x^{3} (x - 1)^{3} y^{3} (y - 1)^{3}
    - \frac{2 h^{2}}{5 (1 - \nu)} \Big[ y^{3} (y - 1)^{3} x (x - 1) (5 x^{2} - 5 x + 1) \\
    & \quad + x^{3} (x - 1)^{3} y (y - 1) (5 y^{2} - 5 y + 1) \Big] \\
    \theta_x(x, y) &= x^{3} (x - 1)^{3} y^{2} (y - 1)^{2} (2 y - 1) \\
    \theta_y(x, y) &= -y^{3} (y - 1)^{3} x^{2} (x - 1)^{2} (2 x - 1)
\end{align}
$$

![Figure](/figures/v3.02.306/sslp306a.svg)

Figure 1. reference solution for modellings A, B, C.

For Modelling D, due to the rotation of geometry, the expression of vertical displacement $w$ is obtained by changing the variable:

$$
\begin{aligned}
x \rightarrow \cos(\theta) x + \sin(\theta) y \\
y \rightarrow -\sin(\theta) x + \cos(\theta) y \\
\textrm{où} \; \theta = \pi / 6
\end{aligned}
$$

While for $\theta_x,\,\theta_y$ rotations it is necessary to include transformation:

$$
\begin{aligned}
\theta_x \rightarrow \cos(\theta) \theta_x - \sin(\theta) \theta_y \\
\theta_y \rightarrow \sin(\theta) \theta_x + \cos(\theta) \theta_y \\
\textrm{où} \; \theta = \pi / 6
\end{aligned}
$$

![Figure](/figures/v3.02.306/sslp306d.svg)

Figure 2. reference solution for Modelling D.

## 3 Modelling A

### 3.1 Modelling characteristics

It's a PLAQ_MITC Modelling done via fenicsx.

$\Omega=[0,1]^2$ mesh is built directly by:

```python
mesh = CA.Mesh.buildSquare(refine=FINE_REFINEMENT)
```

Limit conditions:

on the ${0, 1}\times[0, 1] \cup [0, 1]\times{0, 1}$ edges:

```python
MECA_IMPO=_F(DZ=0, DRX=0, DRY=0, GROUP_MA=("LEFT", "RIGHT", "TOP", "BOTTOM"))
```

**Note:**

PLAQ_MITC now considers COQUE movement only and therefore does not require DX, DY, DRZ displacement.

Loading:

```python
PRES_REP=_F(GROUP_MA="SURFACE", PRES=PRES)
```

where PRES is an FORMULE that represents the equation in the Reference problem.

## 8 Summary of the results

The modellings A, B, C, E have good results for thin plates (low thicknesses compared to other dimensions). The model C with DKT works less well as the plate thickness increases. This expected behaviour is explained by the higher shear deformations than a finite element DKT cannot model. Note that the error increases when more discretizing (see figure below).

![Figure](/figures/v3.02.306/mitc_erreur_mince.svg)

![Figure](/figures/v3.02.306/mitc_erreur_epais.svg)

Fig 1. Evolution of the DZ error as a function of the level of discretization for a thin plate, $h=0.001$, (left) and thick, $h=0.1$ (right).

There are no differences between the results of modellings A and D (no influence due to the change in the benchmark).
