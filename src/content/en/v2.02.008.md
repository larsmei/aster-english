# v2.02.008 SDLL08 - Grid plan of beams (metal profiles)

**Summary:**

This three-dimensional problem consists first of modal analysis and then of studying the harmonic response of a mechanical structure of a flat beam grid. This Mechanics of Structures test corresponds to a dynamic analysis of a linear model with linear behavior. It includes only one model.

This problem allows testing the Euler Bernouilli beam element in transverse bending, the calculation of frequencies and vibration modes by the Lanczos method and the use of linear relationships between movements of two points in modal analysis and harmonic response.

The results are consistent with the analytical results of the VPCS guide.

### 3.5 Remarks

Calculations by:

```text
CALC_MODES
OPTION = 'PLUS_PETITE'
CALC_FREQ=_F(NMAX_FREQ = 3)
SOLVEUR_MODAL=_F(METHODE = 'TRI_DIAG')
```

An antisymmetric mode is obtained for an $f=22.5676\mathrm{Hz}$ frequency. This specific frequency depends on the torsion constant provided; this constant is not defined in the reference data.

${W}_{B}/{W}_{G}$ values are not checked in the test but are obtained manually from ${W}_{B}$ and ${W}_{G}+{W}_{B}$.

The (WG)max value is not verified in the test. One only has access to ${W}_{B}\max$ and $({W}_{B}+{W}_{G})\max$ . ${W}_{G}\max$ is obtained manually by difference.

## 4 Summary of the results

The values of eigenfrequencies and vectors are obtained with $\text{< 0.3\%}$ accuracy.

The difference $\text{2.5\%}$ on the maximum deflections at $B$ and $E$ points would deserve to check the reference solution, complete the validation of the harmonic response.
