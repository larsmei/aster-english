# u4.84.02 Operator POST_DYNA_MODA_T

## 1 Purpose

Post-process the results in generalised coordinates produced by DYNA_VIBRA. Two options are available: post-processing of the shock non-linearities or of the force–displacement relations. In the first case, one chooses a wear diagnosis or a better knowledge of the shocks that occurred during the transient analysis. The content of the table produced can be printed in the RESULTAT file by the command IMPR_TABLE [U4.91.03](doc:u4.91.03).

## 2 Syntax

```text
table = POST_DYNA_MODA_T(
    ◆ RESU_GENE = tran_gene,
    ◆ / CHOC = _F(
           ◇ INST_INIT = float (défaut: -1.0),
           ◇ INST_FIN = float (défaut: 999.0),
           ◇ NB_BLOC = int (défaut: 1),
           ◇ SEUIL_FORCE = float,
           ◇ DUREE_REPOS = float,
           ◇ OPTION = / "IMPACT",
                      / "USURE" (par défaut),
           ◇ NB_CLASSE = int (défaut: 10),
        ),
      / RELA_EFFO_DEPL = _F(
           ◆ GROUP_NO = grno,
           ◆ NOM_CMP = text,
        ),
    ◇ INFO = / 1 (par défaut),
             / 2,
    ◇ TITRE = text,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand RESU_GENE

```text
♦    RESU_GENE = tg
```

Result of a transient analysis by modal recombination, produced by the operator DYNA_VIBRA [U4.53.03](doc:u4.53.03).

### 3.2 Keyword CHOC

```text
◊    CHOC
```

Factor keyword making it possible to specify that one wishes an analysis of the shock non-linearities taken into account in the modal transient analysis.

#### 3.2.1 Operand INST_INIT

```text
◊    INST_INIT = t0
```

Start time instant of the averaging of the signals and of the shock analysis. By default t0 corresponds to the first time instant of the transient analysis by modal recombination.

#### 3.2.2 Operand INST_FIN

```text
◊    INST_FIN = t1
```

End time instant of the averaging of the signals and of the shock analysis.

(t1 = 999. default value),

#### 3.2.3 Operand NB_BLOC

```text
◊     NB_BLOC = nb
```

Number of time blocks into which the interval [t0, t1] is split for the averaging of the signals (1 by default).

The keyword is not used for the option 'IMPACT'.

#### 3.2.4 Operand SEUIL_FORCE

```text
◊    SEUIL_FORCE = s
```

Threshold characterising a contact phase, ($\mid {f}_{n}\mid >s\Rightarrow \text{contact établi}$ )

(s = 0. default value).

#### 3.2.5 Operand DUREE_REPOS

```text
   ◊    DUREE_REPOS = d

*Avec d*  la durée minimale de repos caractérisant la fin d'un choc.

        Si on désigne par tc la fin du choc alors
```

$\forall t\in \left[{t}_{c},{t}_{c}+d\right]\to \mid {f}_{n}\mid <s$

The rest duration d is the minimum duration during which no contact is recorded at the node, in order to determine the end of a shock event and its duration.

#### 3.2.6 Operand OPTION

```text
◊    OPTION =    / 'USURE'
/ 'IMPACT'
```

This keyword makes it possible to choose between post-processing for a wear diagnosis (keyword 'USURE') or for a better knowledge of any shocks that occurred during the transient analysis (keyword 'IMPACT'). The latter post-processing is suited to the analysis of the internals of PWR plants; see [§4].

#### 3.2.7 Operand NB_CLASSE

```text
◊    NB_CLASSE = nc
```

Number of classes that the user wishes to distinguish when building the histogram describing the maxima of the impact forces. By default, nc = 10.

### 3.3 Keyword RELA_EFFO_DEPL

```text
◊    RELA_EFFO_DEPL
```

Factor keyword making it possible to analyse the non-linear force–displacement relations.

The name of the relation at the observed node, the analysis time instants and the maximum reached by the observed component during the analysis are stored in the result table.

All the phases with non-linear constitutive behaviour are determined and, for each of them, the following are stored in the result table:

- the initial time instant and the final time instant of the interval of the non-linear phase,
- the maximum reached and the associated time instant in this interval.

> The parameters of the table produced are described in the following table:

| **PARAMETRES** | **TYPE** | **DESCRIPTION** |
| --- | --- | --- |
| RELATION | K8 | name of the relation at the observed node |
| NOEUD | K8 | name of the node processed |
| GROUP_NO | K8 | Name of the node group containing the node to be processed |
| CMP | K8 | name of the component |
| PHASE | I | number of the phase |
| INST_INIT | R | initial time instant of the interval of the non-linear phase |
| INST_FIN | R | final time instant of the interval of the non-linear phase |
| MAXI | R | maximum reached |
| INST_MAXI | R | time instant associated with the maximum reached |

#### 3.3.1 Operand GROUP _ NO

```text
♦ GROUP _ NO = grnoeu,
```

Name of the node group containing the node of the structure on which the non-linear relation to be processed was defined.

#### 3.3.2 Operand NOM_CMP

```text
♦    NOM_CMP = noncmp
```

Name of the component processed at the node noeu.

### 3.4 Operand INFO

```text
◊    INFO = imp, niveau des impressions
```

/ 1 no printout in the message file (everything is stored in the table produced)

/ 2 printout of the number of analysis time steps

### 3.5 Operand TITRE

```text
◊    TITRE = titre
```

titre is the title of the analysis. It will be printed at the head of the results. It is stored in the table concept.

## 4 Checking — Execution

### 4.1 For the factor keyword CHOC

The value of INST_FIN is compared with the final time instant ${t}_{f}$ of the tran_gene result. The value of INST_FIN retained is $\min({t}_{f},{t}_{1})$ .

If the value of INST_INIT ${t}_{0}$ is greater than the value of INST_FIN, the analysis stops in error.

![Figure](/figures/u4.84.02/10002DCA000069BB00003F5BFCF6F4BD484E81B7.svg)

#### 4.1.1 Execution with the option 'IMPACT'

For each shock non-linearity, the following are computed and stored in the result table:

- the shocks and the associated quantities:

for each shock, one has the value of the time instant at which the force is maximum, the value of the maximum force and of the impulse, the duration of the shock, the impact velocity and the number of rebounds,

- the global shock data:

over the set of shocks observed, one specifies: the absolute maximum of the shock force, the mean value of the maxima of the shock forces and the standard deviation of the extrema of the shock force,

- the histogram describing the maxima of the impact forces:

one has the number of classes of the histogram, the values of its abscissae (minimum and maximum force of each class) and the probability density of the maximum force of each class.

#### 4.1.2 Execution with the option 'USURE'

For each shock non-linearity, the following are computed and stored in the result table:

- the mean, minimum, maximum, standard-deviation and RMS values of the relative displacements of the shock nodes in their global frame,
- the mean and RMS values (over the shock time and the total time) as well as the minimum and maximum of the normal and tangential shock forces,
- the mean number of shocks on each shock connection, the mean shock time, the mean rebound time,
- the mean wear power computed in the sense of ARCHARD [bib1]:


${P}_{\text{usure}}=\frac{1}{T}.{\int}_{0}^{T}{F}_{N}(t).{V}_{T}(t).\text{dt}$

## 5 Examples of use

The test SDND101 is presented here. The aim is to compute the response of a mass–spring system with a non-zero initial velocity ${V}_{0}$ , which may impact a shock stop. The initial gap is zero.
