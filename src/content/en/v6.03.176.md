# v6.03.176 SSNP176 – modellings D_PLAN_INCO_* type of near-incompressible elasticity

**Summary:**

The objective of this test is to provide additional modellings D_PLAN_INCO_* verification on a model known to be analytical solution.

It consists of two modellings:

- Modelling A: D_PLAN_INCO_UPO Modelling test (so on linear elements)
- Modelling B: Test on modellings D_PLAN_INCO_UP and D_PLAN_INCO_UPG(onquadratic elements)

## 1 Reference problem

The Reference problem is inspired by an article by F. Auricchio *et al* . [1] which proposes an analytical solution.

### 1.1 Geometry

A square of dimension $2m\times 2m$ is considered.

The geometry can be visualized in the figure , with the mesh which will be used for both modellings A and B.

![Figure](/figures/v6.03.176/10000000000005DB000003214C69DF1A38759B8B.svg)

Figure 1.1-1: Géométrie et maillage

### 1.2 Material properties

The material is elastic almost incompressible, i.e. its Poisson's ratio tends to 0.5:

- Elasticity module: $E=120\mathit{Pa}$
- Poisson's ratio: $\nu =0.499999$

These values may seem surprising but have no physical significance since the test is purely mathematical.

### 1.3 Boundary conditions and loads

The four edges of the square ($\mathit{DX}=\mathit{DY}=0$) are clamped and a volumetric force is applied to the whole square. This force is variable in space and has as components:

> $\mathit{FX}=\mu y(\frac{-3}{2}{x}^{4}+6{x}^{2}-3{x}^{2}{y}^{2}+{y}^{2}-\frac{5}{2})-15{x}^{2}(y-1)$
> $\mathit{FY}=\mu x(\frac{3}{2}{y}^{4}-6{y}^{2}+3{y}^{2}{x}^{2}-{x}^{2}+\frac{5}{2})-3{y}^{2}-5{x}^{3}$

## 2 reference solution

### 2.1 Method of calculation

The reference results are either non-regression values or the analytical solutions at displacement and pressure given by the following formulae [1]:

> $U1=\frac{{({x}^{2}-1)}^{2}({y}^{2}-1)y}{4}$ et $U2=\frac{{({y}^{2}-1)}^{2}(1-{x}^{2})x}{4}$
> $P=5{x}^{3}(y-1)+{y}^{3}$

The analytical solution gives:

### 2.3 Uncertainties about the solution

This reference solution analysis is accurate.

## 5 Summary of the results

The numerical model allows the results of the Reference problem analysis to be retrieved with an accuracy of less than 1.0E-6, regardless of the type of model used D_PLAN_INCO_UPO, D_PLAN_INCO_UP or D_PLAN_INCO_UPG.

It should be noted that this test case is interesting because incompressible problems with analytical solution are rare.
