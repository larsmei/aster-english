# v6.01.116 SSNA116 - Triaxial test with the Hoek-Brown model modified to axisymmetric

**Summary**

This test validates the elasto-plastic constitutive law from Hoek-Brown, which is modified into rock mechanics. It is a triaxial test for which calculations are performed only on the solid part of the soil in pure mechanics.

Two containment levels are applied: $5\mathit{MPa}$ and $12\mathrm{MPa}$. The ${\phi }^{\mathrm{end}}$ , ${\phi }^{\mathrm{rup}}$ and ${\phi }^{\mathrm{res}}$ parameters are taken equal (which amounts to constant plastic density deformation): in this case, one can calculate a analytical solution to the problem and thus compare the results obtained with *Code_Aster* to this reference solution.

For symmetry reasons, only one of the eighth samples tested is considered to be triaxial. The Modelling is axisymmetric.
