# v1.01.349 ZZZZ349 - Validating ELGA and ELNO fields on elements COQUE_3D

**Summary:**

This test case allows you to check that Gauss points in the calculated fields match the number shown by COOR_ELGA option.

The symmetry of the solution in x and y is found on the fields calculated at Gauss points and nodes.

The fields considered are:

- SIGM_ELGA, EFGE_ELGA,DEGE_ELGA for Gauss dot fields
- SIGM_ELNO, EFGE_ELNO,DEGE_ELNO for nodes fields

Modelling B:2 elements TRIA7, Gauss formula at 7 points
