# v2.02.014 SDLL14 - Vibration modes of a thin pipe elbow

**Summary:**

This test is to search for the eigenfrequencies and associated vibration modes of a bent pipe. It allows to validate modellings elements finished TUYAU_3M (SEG3 and SEG4) and TUYAU_6M (SEG3).

It also validates the option of calculating the largest frequencies of a structure. The results obtained are compared to an analytical reference solution.

In addition, it validates modellings elements finished POU_D_T by comparing the results obtained with the reference results found in the reference as well as those obtained by Pipestress software.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The Rayleigh method applied to slender straight beam elements and a thin curved element beam allows the determination of parameters such as:

- bending in the plane: ${f}_{i}=\frac{{\lambda}_{i}^{2}}{2\pi {R}^{2}}\sqrt{\frac{E{I}_{z}}{\rho A}}$ $i=1,2$;
- transverse bending: ${f}_{i}=\frac{{\mu}_{i}^{2}}{2\pi {R}^{2}}\sqrt{\frac{G{I}_{p}}{\rho A}}$ $i=1,2$;

The ${\lambda}_{i}^{2}$ and ${\mu}_{i}^{2}$ values are taken from a bib2 abacus.

![Figure](/figures/v2.02.014/AbaquesModesPropres.png)

*Bib2 abacus for $\lambda_i$ and $\mu_i$*

In the modellings presented, the $\frac{L}{R}$ ratio is $0$,
$0.6$ or $2$. The values taken in bib1 are:

- $\lambda_1^2 = 22.5$ ;
- $\lambda_2^2 = 43$ ;
- $\mu_1^2 = 9.5$ ;
- $\mu_2^2 = 26.9$ ;

**For $\frac{L}{R} = 0$:**

- $\lambda_1^2 = 17.8$ ;
- $\lambda_2^2 = 34$ ;
- $\mu_1^2 = 7.2$ ;
- $\mu_2^2 = 21.5$ ;

**For $\frac{L}{R} = 0.6$:**

- $\lambda_1^2 = 4.8$ ;
- $\lambda_2^2 = 5.1$ ;
- $\mu_1^2 = 3.85$ ;
- $\mu_2^2 = 5.3$ ;

**For $\frac{L}{R} = 2$:**

This formulation is only suitable for very slender pipes:

- Launch of straight parts above $\frac{l}{{d}_{e}}>20$
- Thin head such as $\alpha R>100\sqrt{\frac{{I}_{z}}{A}}$ with $\alpha$ , radian central angle.

In addition, the values of the frequencies for transverse bending are not
valid only for Poisson's ratio $\nu = 0.3$ after bib2.

A coefficient of elbow flexibility is not necessary here.
The flexibility coefficient from the RCC-M is $\max(1 ; 1.65 \frac{r_m^2}{e R})$
where $r_m$ is the mean radius of the elbow section, $e$
its thickness and $R$ the radius of curvature, which is $1$ in
the present case.

### 2.3 Uncertainty about the solution

$\lambda_i^2$ and $\mu_i^2$ coefficients are derived from abacus.
There is uncertainty about the order of a quarter of graduation on the
their value, i.e. in absolute $0.5$ (graduation of $2$).

This leads to the following uncertainty:

- $\lambda_1^2 = 22.5 \longrightarrow 2.2\%$ ;
- $\lambda_2^2 = 43 \longrightarrow 1.2\%$ ;
- $\mu_1^2 = 9.5 \longrightarrow 5.3\%$ ;
- $\mu_2^2 = 26.9 \longrightarrow 1.9\%$ ;

**For $\frac{L}{R} = 0$:**

- $\lambda_1^2 = 17.8 \longrightarrow 2.8\%$ ;
- $\lambda_2^2 = 34 \longrightarrow 1.5\%$ ;
- $\mu_1^2 = 7.2 \longrightarrow 7\%$ ;
- $\mu_2^2 = 21.5 \longrightarrow 2.3\%$ ;

**For $\frac{L}{R} = 0.6$:**

- $\lambda_1^2 = 4.8 \longrightarrow 10.4\%$ ;
- $\lambda_2^2 = 5.1 \longrightarrow 9.8\%$ ;
- $\mu_1^2 = 3.85 \longrightarrow 13\%$ ;
- $\mu_2^2 = 5.3 \longrightarrow 9.4\%$ ;

**For $\frac{L}{R} = 2$:**

The uncertainty on these values according to bib1 is fixed to $3\%$ on the
value read on the abacus. This does not seem to be in agreement with the fact that
the scale is linear. Thus, the tolerances imposed in the tests
should at least be equal to these uncertainties.

### 7.3 Tested quantities and results

The calculation of the highest frequency of the structure is tested by hand exchanging the roles of the mass matrices and stiffness. One of the tasks is to transfer the Lagrange degrees of freedom from the stiffness to the mass.

The modal calculation is performed on the one hand with TYPE_RESU='GENERAL', which returns a clean value (critical load) $\mu$; in this case, the $\frac{-1}{2\pi \sqrt{\mu}}$ formula must be applied to convert the value to eigenfrequency. On the other hand with TYPE_RESU='DYNAMIQUE', which returns a eigenfrequency $f$; in this case, the $\frac{1}{{(2\pi )}^{2}f}$ formula must be applied to find the right frequency.

The calculated value is used as the reference for modelling D.

## 11 Summary of the results

The results obtained with the TUYAU (SEG3 and SEG4 ) and TUYAU_6M (SEG4) modelling are satisfactory. Maximum observed the difference is less than $\text{2.1\%}$ .

The highest calculated eigenfrequency is the same if the ergonomic way is used or if the roles of the matrices are exchanged by hand.
