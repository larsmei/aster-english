# u4.36.09 Operator DEFI_PROP_ALEA

## 1 Purpose

This operator makes it possible to define random fields in order to take into account the spatial variability of mechanical properties such as Young's modulus (for example of the soil or of the concrete). The operator builds analytical expressions of the random fields by a Karhunen-Loeve decomposition. The fields follow a log-normal law and are defined by the correlation lengths in the 1, 2 or 3 directions of space, the median and the coefficient of variation. In addition, one must supply the size of the domain (*bounding volume*) and the number of terms to be retained. One can generate 1D fields (processes), 2D fields or 3D fields.

DEFI_PROP_ALEA produces a formula whose parameters are $X$ and/or $Y$ and/or $Z$ depending on the data, which can be passed as material parameters to DEFI_MATERIAU.

It produces a concept of type formule.

## 2 Syntax

```text
formule = DEFI_PROP_ALEA(
    ◆ INIT_ALEA = int,
    ◆ MEDIANE = float,
    ◆ COEF_VARI = float,
    ◆ | LONG_CORR_X = float,
      | LONG_CORR_Y = float,
      | LONG_CORR_Z = float,
    ◇ / PRECISION = float,
      / NB_TERM = int,
    # Si: exists('LONG_CORR_X')
        ◆ X_MINI = float,
        ◆ X_MAXI = float,
        ◆ NB_TERM_X = int,
    # Si: exists('LONG_CORR_Y')
        ◆ Y_MINI = float,
        ◆ Y_MAXI = float,
        ◆ NB_TERM_Y = int,
    # Si: exists('LONG_CORR_Z')
        ◆ Z_MINI = float,
        ◆ Z_MAXI = float,
        ◆ NB_TERM_Z = int,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Keyword INIT_ALEA

```text
♦    INIT_ALEA    =    ni                [I]
```

The keyword INIT_ALEA initialises the seed of the random sequences used to define the random fields. Two consecutive analyses with the same initialisation then produce the same result.

### 3.2 Keyword MEDIANE

Keyword used to define the median value of the log-normal random field. In general, the median value is associated with the *best-estimate* value.

### 3.3 Keyword COEF_VARI

```text
♦    COEF_VARI    =    cov                [R]
```

Keyword used to define the coefficient of variation of the random fields. The coefficient of variation is defined as the ratio between the standard deviation and the mean of the random field. In the case of fields with log-normal laws, the logarithmic standard deviation $\beta$ is linked to the coefficient of variation by the formula $\mathit{cov}=\sqrt{({\exp}^{({\beta}^{2})}-1)}$ .

### 3.4 Keywords LONG_CORR_X, LONG_CORR_Y and LONG_CORR_Z

```text
♦|    LONG_CORR_X =    LcX            [R]

|    LONG_CORR_Y =    LcY             [R]

|    LONG_CORR_Z =    LcZ            [R]
```

Keyword used to define the correlation length of the random fields along the direction $X$ (if supplied).

The definition of the correlation lengths is that of Vanmarcke: ${L}_{c}={\int}_{-\infty }^{+\infty }R(u)\mathit{du}$ where $R(u)$ is the correlation function for the variable $u$ (here: the distance along the direction $X$ ). The correlation function is a simple exponential $R(u)={\exp}^{(-u/(0.5{L}_{c}))}$  along each direction.

LONG_CORR_Y and LONG_CORR_Z are analogous to those of LONG_CORR_X for the directions $Y$ and $Z$ .

### 3.5 Keywords NB_TERM_X, X_MINI and X_MAXI

> These keywords are mandatory if LONG_CORR_X is supplied.

```text
♦    NB_TERM_X        =    Nx            [I]
```

The number of terms to be retained for the Karhunen-Loève decomposition along the direction $X$ . The number of terms defines the number of eigenfunctions and therefore the small fluctuations of the variable parameter. As the random field is generated on unit domains $[0,1]$ , the number of terms must be chosen relative to the size of the domain and the discretisation. Failing that, it is recommended to take Nbt equal to the extent of the domain divided by the mesh-cell size (here (xmax-xmin)/dx).

```text
♦    X_MINI        =    xmin            [I]
```

The minimum coordinate according to the extent of the domain in the direction $X$ .

```text
♦    X_MAXI        =    xmax            [I]
```

The maximum coordinate according to the extent of the domain in the direction $X$ .

The last two keywords make it possible to define the extent of the domain over which the random fields must be generated (*bounding volume*).

### 3.6 Keywords NB_TERM_Y, Y_MINI and Y_MAXI

> These keywords are mandatory if LONG_CORR_Y is supplied.

### 3.7 Keywords NB_TERM_Z, Z_MINI and Z_MAXI

> These keywords are mandatory if LONG_CORR_Z is supplied.

### 3.8 Keywords NB_TERM or PRECISION to reduce the model

These optional keywords can be used to reduce the model in the case of 2D or 3D fields.

The mandatory keywords NB_TERM_X, NB_TERM_Y and NB_TERM_Z make it possible to define the number of terms for the Karhunen-Loève (KL) representation to be computed for each component (X and/or Y and/or Z). In the case of a 2D random field, there are two components, and for 3D there are 3 components. The total energy for this KL representation is computed as the sum of all the combinations of products of eigenvalues. For example, in the case of a 2D field along the directions X and Y with Nx and Ny eigenfunctions respectively, the KL representation comprises Nxy=Nx*Ny terms.

In order to retain a reduced number of terms, while preserving a good representation of the fields, the cross terms are ranked according to their contribution to the total energy of the decomposition. One can then reduce the model by retaining the Nbt most energetic terms. For the example above, it is necessary that Nbt < Nxy.

If PRECISION is supplied, then one retains prec*100% of the most energetic terms among all the terms computed.

If NB_TERM is supplied, then one retains the NB_TERM most energetic terms among all the terms computed.
