# v1.01.143 ZZZZ143 – Computer validation of the equivalence between stationary and conditional transient calculations.

**Summary:**

This test has no physical meaning, it is essentially a computer test. It aims to verify that under certain conditions it is possible to replace N stationary MECA_STATIQUE/THER_LINEAIRE calculations with 1 single MECA_STATIQUE/THER_LINEAIRE calculation with variable control.

For example, this approach can be used to evaluate the response of a structure to a constant load and variable material parameters depending on the temperature.

For MECA_STATIQUE there is equivalence if ALPHA is zero. Equivalence is not perfect due to the oscillation of the temperature field values (VARC) which is supplied to nodes and interpolated at the integration points.

For THER_LINEAIRE there is equivalence if RHO_CP is null and if an implicit schema with PARM_THETA=1 is taken into account, the equivalence is perfect.

This documentation is deliberately succinct.
