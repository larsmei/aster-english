# v5.02.140 SDNL140 – Shrinking vibration of two contact-frost beams

**Summary:**

This test modeled the nonlinear vibration response of two contact-frotting beams, subjected to the effect of a concentrated force at one of the ends of the beam. The ultimate goal is to validate the DYNA_NON_LINE command with linear elastic behavior and contact-frotting with DEFI_CONTACT. The reference solution is not analytical but is a result of a elements calculation that is finished with a contact penalty method and an explicit schema.

The modellings proposed depend on finite time differences and spatial discretization patterns.

- $A$ Modelling: mesh linear with TETRA4 and HHT diagram (implicit). In this Modelling, the reference solution is tested as an SOURCE_EXTERNE. Different Code_Aster algorithms (POINT_FIXE, NEWTON PARTIEL, GCP, PENALISEE) are tested in non-regression.
- $B$ Modelling: mesh quadratic with TETRA10 and HHT schema (implicit).
- $C$ Modelling: Linear mesh with HEXA8 and HHT diagram (implicit).

Both surfaces are initially in contact, and the choice was made to make both contact surfaces compatible initially.

### 2.2 Uncertainty about the solution

Since all the numerical parameters of the reference solution are not known, differences between the SOURCE_EXTERNE solution and the code solution can be expected. quantities orders will be considered.

In some modellings, we try to compare the results of different algorithms and schemas. To do this, we do the same calculation with DYNA_NON_LINE by changing only the definition of the contact according to the algorithm or the definition of the schema in time. Then we create, from CREA_CHAMP, a structure of type EVOL_NOLI representing the difference of results between two algorithms/schemas. Finally, we test whether the results of the two algorithms/schemas are the same in one node.
