# v1.04.112 MUMPS02 - MUMPS solver validation for DPLAN_INCO_UPG

**Summary:**

This test case allows you to validate the MUMPS solver when using finished elements to handle incompressible problems. Different keyword PARALLELISME values are tested.

### 1.1 Geometry

A rectangular plate of length 100m and width 50m.

### 1.2 Material properties

- $E=1.0\mathit{E2}N/{m}^{2}$
- $\nu =0.4999$

### 1.3 boundary conditions

DX = 1, DY=2 on all mesh
