# v6.01.111 SSNA111 - Indentation of a solid by a punch

**Summary:**

This test concerns the study of a rigid conical punch deforming a massive elastoplastic structure.

The set is modelled with elements axisymmetric and subjected to a forced displacement and contact (without friction).

## 1 Reference problem

### 1.1 Geometry

The problem is axisymmetric (d-axis $Y$). It is assumed in initial contact with the point $A$ massif, so this point is topologically confused between the punch and the solid.

![Figure](/figures/v6.01.111/v6_01_111_geom.png)

***Details of geometry and dimensions (in mm) used.***

### 1.2 Material properties

The massif consists of an elasto-plastic material with linear isotropic hardening:

| $E=2,0\times {10}^{5}\mathrm{MPa}$ |
| --- |
| $\nu =0,3$ |
| ${\sigma}_{y}=300\mathrm{MPa}$ |
| ${E}_{T}=5000$ |

The punch is supposed to be rigid and is approximated by an elastic material with a large Young's modulus:

| $E=2,0\times {10}^{9}\mathrm{MPa}$ |
| --- |
| $\nu =0,3$ |

### 1.3 Boundary conditions and loads

The physical problem is to identify the rigid punch on the massif. The load is carried out by a moving control of the punch.

The boundary conditions (cinematic and loading) are:

- Clamped support at the base of the massif: $\mathrm{DX}=0$, $\mathrm{DY}=0$ on $D_1C_1$;
- Horizontal movement blocked and vertical displacement imposed on ${u}_{A}$ (see curve below) on two sides of the punch: $\mathrm{DX}=0$, $\mathrm{DY}={u}_{A}$ on $AC_2$ and $B_2C_2$;
- Vertical displacement imposed on ${u}_{A}$ (see curve below) on the remaining side of the punch: $\mathrm{DY}={u}_{A}$ on $AB_2$.

For further information, the points are shown in figure v6_01_111_geom.png.

The vertical displacement of the poisson is controlled in two phases: it is imposed on ${u}_{A}=–0,4\mathrm{mm}$ and then reassembled from $0,008\mathrm{mm}$ (elastic return).
The $-{u}_{A}$ movement time curve is given below:

![Figure](/figures/v6.01.111/v6_01_111_load.png)

***Cinematic charge applied to punch.***

### 1.4 Mesh

The modellings presented in this case is based on the same mesh **linear**. The mesh consists of 1803 nodes and 1852 mesh cells of which:

- mesh cell `TRIA3` for rigid punching,
- 1715 mesh cells `QUAD4` for the massif.

Therefore, the surface mesh cells (used for contact) are mesh cells `SEG2`. To help read the case, one
provides a geometry-mesh-cell group matching array:

| mesh-cell group | Associated geometric entity |
| --- | --- |
| GM15 | Massive |
| GM17 | Poison |
| GM16 | $A$ |
| GM14 | $D_1C_1$ |
| GM9 | $B_2C_2$ |
| GM10 | $AB_2$ |
| GM11 | $AC_2$ |
| GM12 | $AB_1$ |
| GM13 | $AD_1$ |

## 2 reference solution

The calculated results in this test case are:

- the vertical component of the node A (`DEPL`, `DY`) movements at 0.5 and 1 times;
- the nodal reaction (`REAC_NODA`, its two components) at the same time.

Non-regression tests are performed, with results from an earlier *code_aster* run.
In addition, for moving at $A$ points, there is a comparison to an analytical solution.

## 3 Modelling A

### 3.1 Modelling characteristics

`AXIS` Modelling.

### 3.2 Mesh characteristics

The mesh used is the same for all modellings, so details are provided in part V6.01.111_Probl_me_de_r_f_rence.

### 3.3 Behavioural characteristics

Incremental elastic behaviour for punch (`COMPORTEMENT/ELAS`).

Elasto-plastic behaviour in large deformations with linear isotropic hardening for the solid (`COMPORTEMENT/VMIS_ISOT_LINE/SIMO_MIEHE`).

### 3.4 Contact characteristics

The massif is considered a slave, and the punch is considered a master.

Discreet contact method with active stress algorithm, `MAIT_ESCL` pairing and normal `MAIT_ESCL`.

## 5 Modelling C

### 5.1 Modelling characteristics

### 5.2 Mesh characteristics

The mesh is the same as the V6.01.111_Mod_lization_A.

### 5.3 Behavioural characteristics

The behavior is the same as for the V6.01.111_Mod_lisation_A.

### 5.4 Contact characteristics

Since the punch is rigid and linearly geometry, it is possible to model the contact by a single restraint on $\mathit{DX}$ and $\mathit{DY}$ . By projection according to normal to the punch, the non-interpenetration condition can be written:

$2.7\ast \mathit{DY}-(X+\mathit{DX})<2.7\ast {u}_{A}(t)$

The unilateral condition is imposed using the penalty algorithm (`DEFI_CONTACT /ZONE/ALGO_CONT=’PENALISATION’`).

### 5.6 Remarks

The unilateral condition is calculated by considering the normal master, which leads to a light difference compared to model A which uses the normal `MAIT_ESCL`. However, the same results are found in comparison with a contact model which uses the normal master for pairing.

The penalty coefficient causes problems of convergence at the time of elastic return, so a not too high coefficient (1.0 E+3) is imposed, which results in differences greater than model A. It is possible to increase the penalty coefficient on the loading phase, then the same results are found as for the contact model.
