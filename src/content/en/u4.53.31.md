# u4.53.31 Operator DYNA_ISS_VARI

## 1 Purpose

This operator makes it possible to compute the response of a structure subjected to a seismic motion which varies in space, from a coherence function, the impedance matrix and the seismic force. The latter may be computed by the PROMISS3D software. More precisely, one builds the spectral vectors of modal response (coming from a spectral decomposition of the coherence matrix) by means of a harmonic analysis in generalised components. As output, one obtains the power spectral density (DSP) of the modal response (for a unit excitation) or the time response in acceleration, from which response spectra can be deduced if accelerograms are given in one or several directions.

Produces a concept of type interspectre or tran_gene.

## 2 Syntax

```text
/ interspectre
/ tran_gene = DYNA_ISS_VARI(
    ◆ / EXCIT_SOL = _F(
           ◆ | ACCE_X = fonction,
             | ACCE_Y = fonction,
             | ACCE_Z = fonction,
        ),
      / NB_FREQ = int,
    ◇ PRECISION = float (défaut: 0.999),
    ◇ ISSF = / "OUI",
             / "NON" (par défaut),
    ◆ INTERF = _F(
         ◆ GROUP_NO_INTERF = grno,
         ◆ MODE_INTERF = / "CORP_RIGI",
                         / "TOUT",
                         / "QUELCONQUE",
      ),
    ◆ MATR_COHE = _F(
         ◆ TYPE = / "MITA_LUCO",
                  / "ABRAHAMSON",
                  / "ABRA_ROCHER",
                  / "ABRA_SOLMOYEN",
         # Si: equal_to("TYPE", 'MITA_LUCO')
             ◆ VITE_ONDE = float,
             ◇ PARA_ALPHA = float (défaut: 0.1),
      ),
    ◇ UNITE_RESU_FORC = unit (défaut: 33),
    ◇ UNITE_RESU_IMPE = unit (défaut: 32),
    ◇ TYPE = / "BINAIRE",
             / "ASCII" (par défaut),
    ◆ MATR_GENE = _F(
         ◆ MATR_MASS = matr_asse_gene_r,
         ◆ MATR_RIGI = matr_asse_gene_r / matr_asse_gene_c,
         ◇ MATR_AMOR = matr_asse_gene_r / matr_asse_gene_c,
      ),
    ◇ INFO = / 1 (par défaut),
             / 2,
    # Si: exists("EXCIT_SOL")
        ◇ & FREQ_MAX = float,
          & FREQ_PAS = float,
    # Si: exists("NB_FREQ")
        ◆ FREQ_INIT = float,
        ◆ FREQ_PAS = float,
        ◇ OPTION = / "TOUT" (par défaut),
                   / "DIAG",
        ◆ NOM_CMP = / "DX",
                    / "DY",
                    / "DZ",
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operands UNITE_RESU_IMPE and UNITE_RESU_FORC

```text
♦    UNITE_RESU_IMPE    =    /    uresimp,        [I]
/    32,                [DEFAUT]
```

Logical unit of the file of the interface impedance matrix computed by CALC_MISS with option TYPE_RESU='FICHIER'. This matrix may either already have been computed and given as input in the study profile, or be the result of CALC_MISS in the same command file.

```text
♦    UNITE_RESU_FORC    =    /    uresfor,        [I]
/    33,                [DEFAUT]
```

Logical unit of the file of the interface seismic forces computed beforehand by MISS3D with CALC_MISS in post-processing and given as input in the study profile.

### 3.2 Operand TYPE

```text
◊    TYPE=    /    'BINAIRE'
/    'ASCII'                        [DEFAUT]
```

This operand makes it possible to read the impedances computed by the command CALC_MISS [U7.03.12](doc:u7.03.12) in a file of binary format if necessary.

### 3.3 Factor keyword EXCIT_SOL

If one wishes to obtain a **time response**, one must give one or several accelerograms via the keywords ACCE_X, ACCE_Y and ACCE_Z.

Note:

*If* EXCIT_SOL *is not supplied, then* DYNA_ISS_VARI *gives as output the spectral densities of the response (for a unit excitation).*

#### 3.3.1 Operands ACCE_X, ACCE_Y and ACCE_Z

> ◊    ACCE_X    =    accex                        [fonction_sdaster]

```text
◊    ACCE_Y    =    accey                        [fonction_sdaster]

◊    ACCE_Z    =    accez                        [fonction_sdaster]
```

Accelerograms, respectively in the directions $X$ , $Y$ and $Z$ . If several operands are supplied then the signals must have the same abscissae.

The frequency discretisation is determined from the time discretisation of the accelerograms:

$\mathit{FREQ}\text{\_}\mathit{INIT}=0.0,\mathit{PAS}=1./(\mathit{NB}\mathrm{\ast }\mathit{DT})$ ,

where NB denotes the number of time steps of the accelerogram and DT is the time step.

**Note:**

*The time step of the accelerogram must be constant.*

### 3.4 Operands FREQ_MAX and FREQ_PAS

If EXCIT_SOL is present, in order to reduce the computation time, it is possible to indicate the frequency step and the maximum frequency for the computation of the transfer function (recommended):

```text
◊    FREQ_MAX    =    fmax
```

```text
◊    FREQ_PAS    =    pas
```

If FREQ_MAX and FREQ_PAS are supplied, then one determines the transfer function, taking spatial variability into account, only for a reduced number of frequencies. For the computation of the time response to the excitation by a seismic signal (accelerogram), one interpolates these values in order to arrive at the frequency discretisation required by Shannon's theorem.

If FREQ_MAX is less than the cut-off frequency $(\mathrm{NB}-1)\ast \mathrm{PAS}$ of the signal, then one completes the response with zeros up to the cut-off frequency. The last frequency of the analysis is consequently the cut-off frequency.

One should check that the step FREQ_PAS is not too small in order to model the transfer function with spatial variability properly.

### 3.5 Operand NB_FREQ

If one wishes to compute **spectral densities**, then one must indicate the parameters of the discretisation in the frequency domain (harmonic analysis) as follows:

```text
♦    NB_FREQ    =    NF
```

Number of frequency steps to be computed.

```text
♦    FREQ_INIT    =    fini
```

Starting frequency of the harmonic analysis.

```text
♦    FREQ_PAS    =    pas
```

Value of the frequency step for the harmonic analysis.

```text
◊    OPTION        =    /    'TOUT',            [DEFAUT]
/    'DIAG',
```

By default, one obtains as output the DSP matrix of the transfer function (or of the response for a unit excitation). If one chooses OPTION    ='DIAG', then one recovers only the diagonal terms of this matrix.

**Note:**

*This is the DSP in generalised coordinates. In most studies, one must first carry out the projection with the complete DSP matrix in order to retain only the diagonal terms of the response DSP in physical coordinates.*

### 3.6 Operand NOM_CMP

```text
♦    NOM_CMP    =    /    'DX',
/    'DY',
/    'DZ',
```

Name of the component corresponding to a direction of the incident seismic field. This keyword is to be supplied only if NB_FREQ is present.

### 3.7 Operand ISSF

```text
◊    ISSF     =    /    'OUI'
/ 'NON'                [DEFAUT]

Cet opérande indique si on a ou pas un domaine de fluide et donc aussi des interfaces fluide-structure et sol-fluide renseignées par les opérandes GROUP_MA_FLU_STRet GROUP_MA_FLU_SOLdans la commande IMPR_MACR_ELEM[U7.04.33].
```

### 3.8 Keyword INTERF

#### 3.8.1 Operand MODE_INTERF

```text
♦    MODE_INTERF    =    /    'TOUT',
/    'CORP_RIGI'
/    'QUELCONQUE'
```

This operand makes it possible to characterise the type of interface modes of the model. Three types of interface mode are possible: if one chooses a modelling based on the six rigid-body modes, one must supply 'CORP_RIGI'; if one works with all the interface modes (unit finite-element modes), one supplies 'TOUT'. For all the other foundation cases (embedded geometry, modes of arbitrary representation for a flexible foundation, the case ISSF='OUI'), one supplies 'QUELCONQUE'.

#### 3.8.2 Operand GROUP_NO_INTERF

```text
♦    GROUP_NO_INTERF    =    gr_inter
```

With this keyword, one defines the node group supported by the surface mesh cells which make up the soil-structure interface.

### 3.9 Keyword MATR_COHE

#### 3.9.1 Operands VITE_ONDE and PARA_ALPHA

> ♦    TYPE    =    modele

> One may choose between the coherence function of Mita & Luco (MITA_LUCO) and three empirical coherence functions established by Abrahamson (ABRAHAMSON, ABRA_ROCHER, ABRA_SOLMOYEN).

> If one chooses MITA_LUCO, then one may supply:

```text
♦    VITE_ONDE    =    :math:`{V}_{s}`

◊    PARA_ALPHA    =    :math:`\alpha`
```

These are the parameters of the coherence function of Luco and Wong (pure incoherence without the wave-passage effect):

$\gamma (d)=\exp[-(\alpha .2\pi f.\frac{d}{{V}_{s}}{)}^{2}]$

where *d* denotes the distance between two points i and j on the foundation, $f$ is the frequency and ${V}_{s}$ the propagation velocity of the wave. The propagation velocity VITE_ONDE initially considered by Mita & Luco is equal to 600 m/s. The parameter $\alpha$ is dimensionless; by default it is taken equal to 0.5.

The three models of Abrahamson are

- ABRAHAMSON: generic coherence model of Abrahamson (EPRI 1014101, 2006)
- ABRA_ROCHER: model for a rock site established by Abrahamson from earthquakes recorded at Pinyon Flat, USA (EPRI 1015110, 2007).
- ABRA_SOLMOYEN: model for a medium-soil site established by Abrahamson from various medium-soil sites in the USA (EPRI 1015110, 2007).

### 3.10 Keyword MATR_GENE

#### 3.10.1 Operands MATR_MASS, MATR_RIGI, MATR_AMOR

```text
♦    MATR_MASS    =    m
```

Name of the assembled-matrix concept corresponding to the generalised mass matrix of the system.

```text
♦    MATR_RIGI    =    rigigen
```

Name of the assembled-matrix concept corresponding to the generalised stiffness matrix of the system.

A hysteretic damping is obtained with a complex stiffness matrix.

```text
◊    MATR_AMOR    =    amogen
```

Name of the assembled generalised-matrix concept corresponding to the generalised damping matrix of the system.

### 3.11 Operand PRECISION

```text
◊    PRECISION = prec
```

This parameter is by default taken equal to 0.999.

For the computation of the seismic forces with spatial variability of the incident field, one carries out the spectral decomposition of the coherence matrix $[{\gamma}_{ij}]$ , $i=\mathrm{1...},M$ . The parameter prec gives the share of the “energy” of the matrix which one retains by keeping only a reduced number of eigenvectors. If one denotes by $K\ll M$ the number of eigenvalues retained (one retains the $K$ largest eigenvalues), one has

$\text{prec}=\frac{\sum_{i=1}^{K}{\lambda}_{i}^{2}}{\sum_{i=1}^{M}{\lambda}_{i}^{2}}$

### 3.12 Operand INFO

```text
◊    INFO    =
```

Indicates the level of printout of the results of the operator.

| 1 = | no particular printout, |
| --- | --- |
| 2 = | printout of the eigenvalues retained from the spectral decomposition. |

The printouts are made in the file 'MESSAGE'.

## 4 Examples of use

Two examples of use of DYNA_ISS_VARI are presented here. The first example presents an analysis of the spectral density of the response. The second example presents an analysis of an oscillator response spectrum.

The user must beforehand have carried out a ProMISS3D analysis (CALC_MISS [U7.03.12](doc:u7.03.12) with TYPE_RESU='FICHIER').

### 4.1 Example 1

An example of a set of commands is presented here for the computation of the spectral density of the response, taking into account the spatial variability of the incident seismic motion.

```text
RESU = DYNA_ISS_VARI(

FREQ_INIT =fmin,

NB_FREQ = NF,

PAS = df ,

NOM_CMP = ‘DX’,

PRECISION = 0.999 ,

INTERF =_F(

GROUP_NO_INTERF='RADIER',

MODE_INTERF ='CORP_RIGI',),

MATR_COHE = _F(

VITE_ONDE = 600. ,

PARA_ALPHA =0.5,),

UNITE_RESU_IMPE = 32,

UNITE_RESU_FORC = 33,

MATR_GENE = _F(

MATR_MASS = MASSGEN,

MATR_RIGI = RIGIGEN,

MATR_AMOR = AMORT,

),

INFO =2 ,);
```

One may also consult the test case SDLS118A for an implementation of the method.

One can recover the spectral density of the response in physical coordinates by means of the operator REST_SPEC_PHYS.

```text
SPVX=REST_SPEC_PHYS( MODE_MECA=BAMO,

TOUT_ORDRE = 'OUI',

INTE_SPEC_GENE = RESU,

NOM_CHAM='DEPL',

NOEUD=( 'N77' ),

NOM_CMP=('DX', ),

OPTION='TOUT_TOUT' );
```

The transfer function is obtained for a unit seismic excitation and by plotting the square root of the values of the auto-spectrum.

An example of a set of commands is presented here for the computation of the spectral density of the response, taking into account the spatial variability of the incident seismic motion.
