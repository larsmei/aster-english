# v3.03.011 SSLS11 - Combination of static loads on a plate

**Summary**

This test is intended to validate the operation of the POST_COMBINAISON command. This allows for the combination of different physical quantitiess following calculations to the elements finished upstream. This command will only perform post-processings by manipulating results in the form of fields or tables from previous calculations.

This test involves a rectangular plate, which is submitted to its own weight and three cases of loads.

The test saves the results obtained during the call to the POST_COMBINAISON command, and checks its operation in the following situations:

- Data structures of the sd_result type to be combined.
- Data structures of the sd_table type to be combined. The tables are of type ‘RESULTANTE
- Data structures of the sd_table type to be combined. The tables are of type ‘EXTRACTION

## 1 Reference problem

The POST_COMBINAISON command calculates linear combinations of different calculation results associated with user-defined coefficients.

${C}_{i}\text{}\text{}\text{}=\text{}\text{}\text{}({\alpha}_{i,1}\times {Q}_{1})\text{}\text{}\text{}+\text{}\text{}\text{}({\alpha}_{i,2}\times {Q}_{2})$

Où :

- is the number of the combination
- Q1 is the result/table resulting from a first calculation at the finished elements
- Q2 is the result/table resulting from a first calculation at the finished elements
- αi,1is the coefficient associated with Q1
- αi,2is the coefficient associated with Q2
- This is the result of the combination performed.

### 2.3 Combinations

The combinations are set in a ssls11a.38 file in csv format.

| **Sumulation** **(CMB)** | **Coefficient** **Result** **1** **(Q)** | **Coefficient** **result** **2** **(G)** |
| --- | --- | --- |
| C1 | 0,114 | 0,214 |
| C2 | 0 | -0,56 |
| C3 | -0,95 | -0,85 |

Result1 is from the **MACRO_ELAS_MULT** command, which is the 3 cases of loading loads 1[applied separately].

The result 2 is from the **MECA_STATIQUE** command with loading 2 as argument.

Since result1 has 3 order numbers (one per load case), the **POST_COMBINAISON** command breaks down the combinations as follows:

| **CMB** | **Q** 1 | **Q2** | **Q3** | **G** |
| --- | --- | --- | --- | --- |
| C1.1 | 0,114 | 0 | 0 | 0,214 |
| C1.2 | 0 | 0,114 | 0 | 0,214 |
| C1.3 | 0 | 0 | 0,114 | 0,214 |
| C2 | 0 | 0 | 0 | -0,56 |
| C3.1 | -0,95 | 0 | 0 | -0,85 |
| C3.2 | 0 | -0,95 | 0 | -0,85 |
| C3.3 | 0 | 0 | -0,95 | -0,85 |

Therefore, 7 combinations will be calculated by the command.

**2.3** **Call to order**

#### 2.3.1 Format ‘RESULTAT

The command takes in arguments the ‘RESULTAT' objects corresponding to the two loads to be combined[sustains from the MACRO_ELAS_MULT and MECA_STATIQUE commands].

Output will be recovered an object ‘RESULTAT的multiple [mult_elas] , with 7 order numbers corresponding to the 7 combinations previously presented.

**2.3.2 Format ‘TABLE

The result fields are first converted into tablesvia the CALC_COUPURE command, giving a result value extracted in the middle of the plate thickness.

By passing these tables as argument, the POST_COMBINAISON command returns an object ‘TABLE' with 7 order numbers / lines.

### 2.4 Tested quantities and results

Reference values are evaluated via python commands in the command file.

In the case where the format ‘RESULTAT' is used, the values shall be calculated from the values extracted from the nodes or elements of the result fields combined with the values of the table of coefficients following the formulation in Chapter 1.

In the case where the ‘TABLE' format is used, the values are calculated from the values extracted from the tables combined with the values of the table of coefficients following the formulation in Chapter 1.
