# v1.01.103 ZZZZ103 – Jeveux memory manager core function unit tests

**Summary:**

This test allows you to check the operation of basic JEVEUX memory manager utilities.

Model A prints values associated with platform-dependent numerical constants. In particular, the lengths and extremal values of integer numbers and floating numbers, some particular mathematical constants, and certain parameters related to the use of memory and files. The values are accessible using the ENVIMA functions described in [D6.01.01](doc:d6.01.01).

Model B checks that the base extension functionality is triggered (on a volatile basis) in case of lack of memory and space in the previous database.

Modelling C checks the extension functionality of the bases on the global basis, as well as the retassing.

This documentation is deliberately succinct.
