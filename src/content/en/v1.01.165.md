# v1.01.165 ZZZZ165 - LIRE_RESU in 'IDEAS' format

**Summary:**

IDEAS format reads a field at nodes and a field at elements at nodes (ELNO).

It is checked that the readings are properly stored in the RESULTAT (SD_RESULTAT) data structure produced.

## 2 reference solution

The test case is to reread a file in 'IDEAS' format. The test is to check that the values read are properly stored in the SD_RESULTAT.

## 3 Modelling A

The mesh IDEAS associated with this test is made up of 4 mesh cells QUAD8 type.

These mesh cells have $1,2,3,4$ labels. But they are given in the order $4,1,2,3$.

The nodes of the mesh are labeled $[1-5]$ and $[7-22]$ . The node 12 is given in 1st.
