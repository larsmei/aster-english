# v3.04.109 SSLV109 - Full Cylinder in non-standard pressure mode 1

**Summary:**

This test validates all elements Fourier (degree 1 and 2 triangles and quadrangles) in elasticity. The features are as follows:

- variable pressure in space,
- travel requirements,
- Fourier mode1 stiffness matrices,
- nodes Fourier mode1 constraints,
- Fourier recombination on displacements and stresses (modelizationA),
- isotropic transverse material (modelizationF).

The test has a quadratic analytical solution on the move.

The value of the test lies in:

- the comparison between calculated solution and analytical solution on the different elements finished,
- comparison of the results with PERMAS code on elements TRIA6 (modelizationA).

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v3.04.109/10000A42000023F8000008100DC64868E0B2E2C3.svg)

The modeled domain is $\mathit{ACDB}$ ($\theta =0$ map).

### 1.2 Material properties

$E=72N/{m}^{2}$

$\nu =0.3$

### 1.3 Boundary conditions and loads

$\begin{array}{c}{u}_{r}(A)={u}_{z}(A)={u}_{\theta}(A)=0\\ {u}_{z}(\mathit{AB})=0\end{array}$

$p=\stackrel{ˉ}{p}\frac{r}{R}\cos\theta$

with $\stackrel{ˉ}{p}=1.$ and $R=1$ applied in $z=12$ .

### 1.4 Initial conditions

Not applicable for static analysis.

## 2 reference solution

### 2.1 Calculation method used for reference solution

| ${u}_{r}(r,z,\theta )=u(r,z)\cos\theta$ | with $u(r,z)=\frac{M}{\mathrm{2EI}}{z}^{2}+\frac{v\stackrel{ˉ}{p}}{\mathrm{2ER}}{r}^{2}$ |
| --- | --- |
| ${u}_{z}(r,z,\theta )=v(r,z)\cos\theta$ | with $v(r,z)=-\frac{\stackrel{ˉ}{p}}{\mathrm{2EI}}rz$ |
| ${u}_{\theta}(r,z,\theta )=w(r,z)(-\sin\theta )$ | with $w(r,z)=\frac{M}{\mathrm{2EI}}{z}^{2}-\frac{v\stackrel{ˉ}{p}}{\mathrm{2ER}}{r}^{2}$ |

All constraints are zero except ${\sigma}_{zz}(r,z)=-\frac{\stackrel{ˉ}{p}}{R}r$ .

The data were selected in such a way that $u(x)=u(0,l)=1$ .

The movements are thus written here:

$u(r,z)=\frac{{z}^{2}}{144}+\frac{{r}^{2}}{480}$ ; $v(r,z)=-\frac{rz}{72}$ ; $w(r,z)=\frac{{z}^{2}}{144}-\frac{{r}^{2}}{480}$

et:

${\sigma}_{zz}(r,z)=-r$

### 2.2 Baseline

| $u,v,w,{\sigma}_{zz}$ | en $\begin{array}{c}r=0.,0.5,1.\\ z=0.,6.,12.\end{array}$ |
| --- | --- |
| ${u}_{r},{u}_{z},{u}_{\theta}$ | en $\begin{array}{c}r=0.\\ z=6.\\ \theta =45°\end{array}$ |

### 2.3 Uncertainty about the solution

analytical solution.

### 2.4 Bibliographical references

1. PERMAS-HS. Axisymmetric Continua with arbitrary loads. Stuttgart 1985. INTES publication n°224 pp 42 - 49.
