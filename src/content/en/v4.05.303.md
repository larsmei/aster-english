# v4.05.303 TPLP303 - Temperature distribution in the section of a chimney duct

**Summary:**

This test is based on independent validation of version 3 in linear steady-state thermal analysis.

This is a $\mathrm{2D}$ plan problem represented by seven modellings mixing several types of d的elements.

The functions tested are as follows:

- element thermal plane,
- element thermal volumetric,
- limit condition: convection.

The value of the test lies in the different d的elements mixture.

The results are compared with an analytical solution.

## 4 Complementary modellings B, C, D, E, F and G

$B$ Modelling:

- Mesh identical to that described in the Modelling sheet, on $1/8$ of the structure, but with quadratic elements,
- $(°C,W,m,s)$ unit system .

It is found that quadratic interpolation improves results, the difference maximum is $49.16\text{\%}$ for the reference value closest to 0.

**Modelling** $C$ **:**

- Mesh plus finer (22 QUAD8 $+$ 4 TRIA6), on $1/8$ of the structure,
- $(°C,W,m,s)$ unit system .

It is found that compared to $B$ Modelling, the difference maximum does not decrease but increases ($54.58\text{\%}$).

**Modelling** $D$ **:**

- Mesh identical to that described in the Modelling sheet, on $1/8$ of the structure,
- $(°F,\mathrm{Btu},\mathrm{feet},\mathrm{hr})$ English Unit System .

It is noted that the difference relative maximum decreases significantly ($\text{–33.29\%}$ ), this difference is no longer located in the same place. However, it is still located on the reference value closest to 0.

**Modelling** $E$ **:**

- Mesh identical to that described in the Modelling sheet, on $1/8$ of the structure, but with quadratic elements,
- $(°F,\mathrm{Btu},\mathrm{feet},\mathrm{hr})$ English Unit System .

Quadratic elementss improve results by linear modelling (maximum difference of $\text{–6.5\%}$).

**Modelling** $F$ **:**

- cutting identical to that described in the Modelling sheet (12 QUAD4) but on $1/4$ of the structure,
- $(°F,\mathrm{Btu},\mathrm{feet},\mathrm{hr})$ English Unit System .

It is noted that this mesh with linear elements (without TRIA3) is much more accurate, the difference maximum is $\text{–5.27\%}$.

**Modelling** $G$ **:**

- Cutting is identical to that described in the Modelling sheet, but on $1/4$ of the structure and with quadratic elements,
- $(°F,\mathrm{Btu},\mathrm{feet},\mathrm{hr})$ English Unit System .

It is found that this mesh (without TRIA3) is much less accurate than when Modelling $F$ , the difference maximum is $\text{–6.26\%}$ .

From these 7 analyses, we can make the following observations:

- the mesh offered in the test sheet (5 QUAD4 $+$ 2 TRIA3) is not suitable. To get closer to the reference solution there are two possibilities:
- use the quadratic mesh on $1/8$ of the structure,
- use a linear mesh without triangle on $\mathrm{¼}$ of the structure,
- the choice of the unit system to a significant significant in the calculation of relative the difference,
- for the same model ($A$ ) the results between *Code_Aster* and NISA are identical.

## 6 Summary of the results

The $1/8$ model of the structure gives results with many values exceeding the initially set tolerance ($\text{2\%}$). the difference maximum obtained is $\text{89\%}$ , it is located on the smallest reference value. Isothermal analysis shows that these are not perpendicular to the right $\mathrm{DC}$ , the symmetry condition is not respected.

To explain these important differences, several additional modellingss were made (see Appendix B). The conclusions are as follows:

- the $(°C\to °F)$ change of the system allows to decrease the difference maximum to a value of $\text{33\%}$,
- Modelling with quadratic elements (and in $°F$ ) improves results, the difference maximum is $\text{6.8\%}$ ,
- $1/4$ structure Modelling with QUAD4 only (and $°F$) improves results, the difference maximum is $\text{–5.27\%}$ ,
- $A$ Modelling, performed with NISA software, gives results identical to those of *Code_Aster*.

In addition, it was not possible to obtain the original reference (Kreith's book) cited in the ANSYS verification manual. The method of obtaining the reference solution and its uncertainty are therefore unknown.

The results are considered acceptable in light of the above points. However, additional elements will be required on the reference solution.
