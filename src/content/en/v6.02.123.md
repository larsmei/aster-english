# v6.02.123 SSNL123 - Flaming of a Multi-Fibres beam

**Summary:**

This test is for the validation of the flaming of a multifibre beam with a POU_D_TGM model.

This problem allows testing:

- elements finished linear beams type with a model POU_D_TGM,
- the integration of guidance,
- the calculation of the first modes of flame-throwing.

$\mathrm{Ncd}={n}^{2}.\frac{{\pi}^{2}\mathrm{EI}}{{L}^{2}}$ where $n$ is the mode number.

## 4 Summary of the results

This test case shows the correct functioning of a beam behavior Modelling using a multifibre approach. A loop, made with python language, allows you to retrieve information from the different time step.

- The calculation of the stiffness matrix, option RIGI_MECA, is done from an AFFE_CHAR_MECA_F.
- The calculation of the internal force vector is performed by an CREA_CHAMP from an STAT_NON_LINE by recovering the SIEF_ELGA.
