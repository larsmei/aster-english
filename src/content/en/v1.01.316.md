**Summary:**

This test has no physical significance, it is only a computer test.

It allows to check the non-regression of low-level features like Python fortran routines.

## 1.2 reference solution

This is a functioning test. There is no uncertainty about the expected behavior.

## 2.1 Modelling A

### 2.1.1 Modelling characteristics

Basic functions accessible in the Python space are tested:

- Internationalization of messages: We check that the *gettext* translation function (`_()` function) is available, and that it returns the expected translation for a simple string. The result depends on LANG='EN' in DEBUT, the correct installation of the file and the proper loading of this file by the module.

## 2.2 Modelling B

### 2.2.1 Modelling characteristics

This Modelling ensures that the syntax verification transforms the number of values provided into consistency with the order catalogue.

If `max=1`, one must only obtain one value and not a list containing a value.
Conversely, if `max="**"` (or more than 1), you must still** get a list or a *tuple* even if there is only one value in it.
This rule must also be checked for keywords factors.s

It is also checked in this test that for keyword type `"I"` (integer), the *float* to *int* conversion works correctly.
If the value of the actual number is "integer", the number is accepted. Otherwise a type error is issued.

## 2.3 Modelling C

### 2.3.1 Modelling characteristics

This model tests the various exceptions that can be launched with `raiseAsterError`. The attributes of the `AsterError` exception are also checked.

## 2.4 Modelling D

### 2.4.1 Modelling characteristics

This Modelling checks the correct functioning of functions that allow to retrieve a copy of the values of certain concepts (functions, lists of reals, vectors and Jeveux collections) in the Python space.

We create trivial concepts whose values are then recovered.

It is also verified that basic Python objects are being successfully transmitted in pursuit.

## 2.5 Modelling E

### 2.5.1 Modelling characteristics

In this Modelling, the operation of Python coatings of MPI functions is tested, such as the utility function to recover the number of processors and the rank or communication of a string.

## 2.6 Modelling F

### 2.6.1 Modelling characteristics

In this Modelling, the `ExecutionParameter` object is tested, which gives access to command line arguments and other execution information that can be recovered from Python or Fortran (hostname, tpmax etc.).

## 2.7 Modelling G
