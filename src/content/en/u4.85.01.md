# u4.85.01 Operator CALC_META

## 1 Purpose

Computes the metallurgical evolution associated with a thermal history.

The operator operates as a post-processing of the result of the thermal analysis in the sense that
the latter is an “incoming” datum of the metallurgical analysis and that there is no coupling between
the metallurgy and the thermal analysis. Two evolution models are available:

- a model dedicated to the austenite–ferrite transformations of steel,
- a model dedicated to the transformations of zirconium alloys.

It is furthermore possible to apply a model in order to compute the tempering phases of the steel.

The analysis is carried out at the nodes (field META_ELNO).

The result obtained may subsequently be used as a loading datum of a
thermomechanical analysis with account taken of the metallurgy. One may also, at the end of a
metallurgy analysis, carry out a hardness post-processing analysis.

Re-entrant operator; it enriches a data structure `evol_ther`.

## 2 Syntax

```text
evol_ther = CALC_META(
    ◆ reuse = <objet de RESULTAT>,
    ◇ MODELE = modele,
    ◇ CHAM_MATER = cham_mater,
    ◆ RESULTAT = evol_ther,
    ◆ OPTION = / "DURT_ELNO",
               / "DURT_NOEU",
               / "META_ELNO",
               / "META_NOEU",
    ◇ / TOUT = "OUI" (ou non renseigné),
      / GROUP_MA = grma,
    # Si: is_in('OPTION', ('META_ELNO','META_NOEU'))
        ◆ ETAT_INIT = _F(
             ◆ / EVOL_THER = evol_ther,
               / META_INIT_ELNO = carte,
             # Si: exists("EVOL_THER")
                 ◆ / NUME_INIT = int,
                   / INST_INIT = float,
                 # Si: exists("INST_INIT")
                     ◇ CRITERE = / "ABSOLU",
                                 / "RELATIF" (par défaut),
                     # Si: (equal_to("CRITERE", 'RELATIF'))
                         ◇ PRECISION = float (défaut: 1e-06),
                     # Si: (equal_to("CRITERE", 'ABSOLU'))
                         ◆ PRECISION = float,
          ),
        ◆ COMPORTEMENT = _F(
             ◆ RELATION = / "ACIER",
                          / "ACIER_REVENU",
                          / "ZIRC",
             # Si: equal_to("RELATION", 'ACIER')
                 ◇ LOI_META = "WAECKEL",
             # Si: equal_to("RELATION", 'ZIRC')
                 ◇ LOI_META = "EDGAR",
             ◇ / TOUT = "OUI" (ou non renseigné),
               / | GROUP_MA = grma,
          ),
        ◇ REVENU = _F(
             ◆ RELATION = "ACIER_REVENU" (ou non renseigné),
             # Si: equal_to("RELATION", 'ACIER_REVENU')
                 ◇ LOI_META = "JMA",
             ◇ / TOUT = "OUI" (ou non renseigné),
               / | GROUP_MA = grma,
          ),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Keywords MODELE and CHAM_MATER

Name of the model MODELE and of the assigned material field CHAM_MATER whose elements are
the subject of the metallurgical analysis.

### 3.2 Keyword RESULTAT

RESULTAT is the name of the result of type `evol_ther` coming from a thermal analysis from
which one carries out a metallurgy analysis.

At the end of the analysis this result will be enriched with the evolution of the metallurgical field, fields of
internal variables whose number and meaning depend on the transformation model
used.

### 3.3 Selection of the mesh cells concerned by the analysis

The keywords TOUT (all the mesh cells carrying finite elements will be processed) and
GROUP_MA allow the user to choose the mesh cells on
which he or she wishes to carry out the elementary post-processing analyses.

### 3.4 Factor keyword COMPORTEMENT

```text
◆ COMPORTEMENT = _F(
        ◆ RELATION = / "ACIER",
                    / "ZIRC",
        # Si: equal_to("RELATION", 'ACIER')
            ◇ LOI_META = "WAECKEL",
        # Si: equal_to("RELATION", 'ZIRC')
            ◇ LOI_META = "EDGAR",
        ◇ / TOUT = "OUI" (ou non renseigné),
        / | GROUP_MA = grma,
    )
```

The factor keyword COMPORTEMENT supplies the metallurgical evolution model used.
One may use only one evolution model per analysis.

#### 3.4.1 Keyword RELATION

The keyword RELATION, which is equal to `"ACIER"`, serves to specify the execution of the analysis of the metallurgical
transformations of the steel, in the vicinity of $800°C$ , from a ferritic phase (ferrite,
pearlite, bainite, martensite) to an austenitic phase (and conversely on cooling).

The model on heating and on cooling are different (the selection of this model is made
according to the keyword LOI_META).

Steel gives six phases as internal variables.

| Variable | Quantity | Description |
| --- | --- | --- |
| $\mathrm{V1}$ | ${Z_1}$ | proportion of ferrite |
| $\mathrm{V2}$ | ${Z_2}$ | proportion of pearlite |
| $\mathrm{V3}$ | ${Z_3}$ | proportion of bainite |
| $\mathrm{V4}$ | ${Z_4}$ | proportion of martensite |
| $\mathrm{V5}$ | ${Z_\gamma}$ | proportion of austenite (hot phase) |
| $\mathrm{V6}$ | ${Z_c}$ | proportion of the cold phases |

The sum of all the phases must be equal to 1.0. If this is not the case (to within 1%), an alarm
is issued.

The necessary material data must be supplied in [DEFI_MATERIAU](doc:u4.43.01),
under the keyword META_ACIER.

The keyword RELATION, which is equal to `"ZIRC"`, serves to specify the execution of the analysis for the metallurgical
transformation (on cooling) of zirconium alloys, from a hexagonal close-packed phase to
a body-centred cubic phase in the vicinity of $800°C$ (the selection of this model is made
according to the keyword LOI_META).

Zircaloy gives three phases as internal variables:

| Variable | Quantity | Description |
| --- | --- | --- |
| $\mathrm{V1}$ | ${Z_\alpha}$ | proportion of the cold phase |
| $\mathrm{V2}$ | ${Z_2}$ | initially without meaning and obligatorily zero; for a post-processing, the fraction of phase $\alpha$ is given by $V1+V2$ ; |
| $\mathrm{V3}$ | ${Z_\beta}$ | proportion of the hot phase |

The sum of all the phases must be equal to 1.0. If this is not the case (to within 1%), an alarm
is issued.

The necessary material data must be supplied in [DEFI_MATERIAU](doc:u4.43.01),
under the factor keyword META_ZIRC.

#### 3.4.2 Keyword LOI_META

The keyword LOI_META serves to specify the metallurgical model used:

- For steel, LOI_META equal to `"WAECKEL"` uses the Waeckel model [r4.04.01](doc:r4.04.01)
- For Zircaloy, LOI_META equal to `"EDGAR"` uses the Edgar model [r4.04.02](doc:r4.04.02)

The Waeckel model adds three internal variables to those describing the phases of the steel.

| Variable | Quantity | Description |
| --- | --- | --- |
| $\mathrm{V7}$ | $d$ | austenitic grain size |
| $\mathrm{V8}$ | $T_g$ | temperature at the Gauss points |
| $\mathrm{V9}$ | ${M}_{s}$ | martensitic transformation temperature |

The Edgar model adds two internal variables to those describing the phases of Zircaloy.

| Variable | Description |
| --- | --- |
| $\mathrm{V4}$ | The temperature at the nodes |
| $\mathrm{V5}$ | The time corresponding either to the equilibrium transformation start temperature if the fraction of phase $\alpha$ is equal to 1 initially, or to the equilibrium transformation end temperature if the fraction of phase $\alpha$ is equal to 0 initially. This variable is used to compute the rate on heating, respectively on cooling (sliding-secant method), which serves to determine the transformation start temperatures on heating or on cooling. |

#### 3.4.3 Keywords TOUT and GROUP_MA

The keywords TOUT and GROUP_MA specify the mesh cells on which the model is used
and make it possible to assign the analysis only on a sub-part of the total mesh.

### 3.5 Factor keyword ETAT_INIT

The factor keyword ETAT_INIT describes the initial metallurgical state.

#### 3.5.1 Keyword META_INIT_ELNO

The keyword META_INIT_ELNO defines the assignment of the initial internal-variable field,
constant per element, from a map defined by [CREA_CHAMP](doc:u4.72.04).
Only the variables whose initial assignment has a meaning are to be supplied. One therefore supplies
only the variables corresponding to a phase proportion, plus possibly the one corresponding
to the austenitic grain size if it is not zero.

In the case of the steel, one obligatorily supplies all the phases and the grain size,
otherwise the code stops with a fatal error.

If the user has not supplied correctly the sum of the cold phases, it is the code which
will replace it by the sum computed from the data. An alarm will then be issued.

In the case of Zircaloy, one obligatorily supplies all the phases and the time corresponding
to the equilibrium transformation start temperature, otherwise the code stops with a fatal error.

#### 3.5.2 Keywords EVOL_THER, NUME_INIT, INST_INIT, PRECISION and CRITERE

The keyword EVOL_THER defines the concept of type `evol_ther` from which one will extract
the initial state from which the analysis will be carried out. This concept must contain metallurgical
quantities (grandeur) (fields META_ELNO)

The definition of the initial state may be made by stored order number or by the time instant associated with the
analysis.

NUME_INIT allows the definition from the stored order number and INST_INIT allows the
definition from the analysis time instant.

In this latter case, PRECISION and CRITERE make it possible to define the precision and the criterion
according to which the extraction will be carried out. If `"ABSOLU"` is chosen, it is mandatory to
supply the field PRECISION; if CRITERE is equal to `"RELATIF"`, a precision of
$1.E-6$ is given by default, and may possibly be modified by supplying
the keyword PRECISION.

### 3.6 Keyword OPTION

The keyword OPTION specifies the quantities to be computed:

- If OPTION is equal to `"DURT_ELNO"`, one computes the hardness at the nodes by element from the metallurgical
phases (cf. [R4.04.01](doc:r4.04.01))
- If OPTION is equal to `"DURT_NOEU"`, one computes the hardness at the nodes from the metallurgical
phases (cf. [R4.04.01](doc:r4.04.01))
- If OPTION is equal to `"META_ELNO"`, one computes the proportion of metallurgical phase at the nodes
by element.
- If OPTION is equal to `"META_NOEU"`, one computes the proportion of metallurgical phase at the nodes

### 3.7 Factor keyword REVENU

```text
◆ REVENU = _F(
        ◆ RELATION = / "ACIER_REVENU", (par défaut),
        # Si: equal_to("RELATION", 'ACIER_REVENU')
            ◇ LOI_META = "JMA",
        ◇ / TOUT = "OUI" (ou non renseigné),
        / | GROUP_MA = grma,
    ),
```

The factor keyword REVENU makes it possible to activate the computation of the tempering phases for steel
(cf. [R4.04.01](doc:r4.04.01)).

It is possible to restrict the analysis to a sub-part of the mesh by means of the keyword
GROUP_MA. A check is made in order to prevent the use of this tempering model on anything
other than an analysis on steel.

The necessary material data must be supplied in [DEFI_MATERIAU](doc:u4.43.01),
under the keyword META_ACIER_REVENU.

This analysis enriches the field META_ELNO and modifies its internal variables, now
12 in number (instead of 9 in the case without tempering).

| Variable | Quantity | Description |
| --- | --- | --- |
| $\mathrm{V1}$ | ${Z_1}$ | proportion of ferrite |
| $\mathrm{V2}$ | ${Z_2}$ | proportion of pearlite |
| $\mathrm{V3}$ | ${Z^b_3}$ | proportion of bainite (as-quenched phase) |
| $\mathrm{V4}$ | ${Z^r_3}$ | proportion of bainite (tempered phase) |
| $\mathrm{V5}$ | ${Z^b_4}$ | proportion of martensite (as-quenched phase) |
| $\mathrm{V6}$ | ${Z^r_4}$ | proportion of bainite (tempered phase) |
| $\mathrm{V7}$ | ${Z_\gamma}$ | proportion of austenite (hot phase) |
| $\mathrm{V8}$ | ${Z_c}$ | proportion of the cold phases |
| $\mathrm{V9}$ | $d$ | austenitic grain size |
| $\mathrm{V10}$ | $T_g$ | temperature at the Gauss points |
| $\mathrm{V11}$ | ${M}_{s}$ | martensitic transformation temperature |
| $\mathrm{V12}$ | ${I}^{th}$ | thermal-cycle indicator |

**Note**

These metallurgical phases are not usable as input to a mechanical analysis.

## 4 Example in the case of a steel

One presents an example of creation of the initial internal-variable field (with 70% ferrite,
30% bainite and the rest at zero).

```text
phasinit = CREA_CHAMP(OPERATION ='AFFE',
                      TYPE_CHAM = 'CART_VAR2_R',
                      MAILLAGE = mail,
                      AFFE =_F(    TOUT = 'OUI',
                      NOM_CMP = ('V1','V2','V3','V4','V5','V6','V7'),
                      VALE = (0.7,0.0,0.3,0.0,0,1.,0.))),
```

Then one computes the thermal evolution:

```text
tempe = THER_LINEAIRE(MODELE = moth,
                      CHAM_MATER = chmat ,
                      EXCIT = _F(CHARGE    = chth1),
                      INCREMENT = (LIST_INST= lr8),
                      TEMP_INIT =(VALE  = 700),)
```

Finally one computes the evolution of the metallurgical phases:

```text
tempe = CALC_META (reuse = tempe,
                   MODELE = moth,
                   CHAM_MATER = chmat,
                   RESULTAT = tempe,
                   ETAT_INIT =_F(META_INIT_ELNO = phasinit),
                   COMPORTEMENT =_F(RELATION ='ACIER',TOUT = 'OUI'))
```
