# 1 **u4.71.05** Procedure EXTR_TABLE

## 1 Purpose

Extract a concept from a table.

The table may be a table_container coming from the command CALCUL. The extracted concepts are then elementary matrices, elementary vectors or fields.

The table may have been obtained by the operator RECU_TABLE (NOM_TABLE = 'MATR_GENE' ...) from a result concept of the operator CALC_FLUI_STRU.

## 2 Syntax

```text
/ cham_elem
/ vect_elem_depl_r
/ nappe
/ carte
/ table
/ cham_no
/ reel
/ matr_elem_temp_r
/ fonction
/ vect_elem_temp_r
/ matr_asse_gene_r
/ cham_gd
/ matr_elem_depl_r
/ fonction_c
/ entier
/ mode_meca = EXTR_TABLE(
    ◆ TYPE_RESU = / "MATR_ASSE_GENE_R",
                  / "MATR_ELEM_DEPL_R",
                  / "VECT_ELEM_DEPL_R",
                  / "MATR_ELEM_TEMP_R",
                  / "VECT_ELEM_TEMP_R",
                  / "CHAM_GD_SDASTER",
                  / "CHAM_NO_SDASTER",
                  / "CARTE_SDASTER",
                  / "CHAM_ELEM",
                  / "MODE_MECA",
                  / "TABLE_SDASTER",
                  / "FONCTION_SDASTER",
                  / "FONCTION_C",
                  / "NAPPE_SDASTER",
                  / "ENTIER",
                  / "REEL",
    ◆ TABLE = table / table_container,
    ◆ NOM_PARA = text,
    ◇ FILTRE = _F(
         ◆ NOM_PARA = text,
         ◇ CRIT_COMP = / "EQ" (par défaut),
                       / "LT",
                       / "GT",
                       / "NE",
                       / "LE",
                       / "GE",
                       / "VIDE",
                       / "NON_VIDE",
                       / "MAXI",
                       / "MAXI_ABS",
```

## 3 Operands

### 3.1 Operand TABLE

♦    TABLE= matable

One gives the name of the table from which one wants to extract the value of a cell.

### 3.2 Operand TYPE_RESU

♦    TYPE_RESU:

```text
Type du résultat créé.

La commande ne permet pas d'extraire tous les types de concept. Les types autorisés sont :

'MATR_ASSE_GENE_R', 'MATR_ELEM_DEPL_R',

'VECT_ELEM_DEPL_R',

'CHAM_GD_SDASTER', 'CHAM_NO_SDASTER',

'CARTE_SDASTER', 'CHAM_ELEM',

'MODE_MECA',

'FONCTION_SDASTER', 'FONCTION_C', 'NAPPE_SDASTER',

'ENTIER'.
```
### 3.3 Operand NOM_PARA

♦    NOM_PARA= para

One gives the name of the parameter identifying the column containing the cell to be extracted.

### 3.4 Extract a cell; keyword FILTRE

This factor keyword (repeatable at will) serves to select the row containing the cell to be extracted. The use of this keyword is described in the command IMPR_TABLE [U4.91.03](doc:u4.91.03).

### 3.5 Operand TITRE

```text
◊    TITRE= titre
```
Title which one wants to give to the result of the command [U4.02.01](doc:u4.02.01).

## 4 Examples

Example taken from the test case sdll118a

One wishes to extract from the table TT the generalised mass matrix for a given fluid velocity:

```text
MG = EXTR_TABLE    (    TYPE_RESU = ‘MATR_ASSE_GENE_R’,
TABLE = TT,
NOM_PARA = ‘MATR_MASS’,
FILTRE = _F(    NOM_PARA = ‘NUME_VITE’,
VALE_I = 2 ),
)

#Exemple suite à CALCUL

#Récupération du champ de contrainte:

SIGM = EXTR_TABLE(TYPE_RESU='CHAM_GD_SDASTER',

TABLE=CONT,

NOM_PARA='SIEF_ELGA')

#Récupération des matrices élémentaires:

MATR = EXTR_TABLE(TYPE_RESU='MATR_ELEM_DEPL_R',

TABLE=CONT,

NOM_PARA='MATR_ELEM')
```
