# v6.04.171 SSNV171 – Intercomparison of behaviors MONOCRISTAL AND POLYCRISTAL

**Summary:**

The purpose of this test is to validate MONOCRISTAL and POLYCRISTAL behaviors by intercomparison, in a particular situation: one single grain for MONOCRISTAL and one single phase for POLYCRISTAL. The crystalline behavior is of the type MONO_VISC1, MONO_CINE1, MONO_ISOT1 (Meric-Cailletaud).

The geometry processed is a material point, and the crystal is not parallel to the coordinates axes.

3 models allow to compare:

- MONOCRISTAL behaviors (various implicit integration algorithms, modellings A and B)
- MONOCRISTAL and POLYCRISTAL behaviors with explicit integration, as well as Weibull post-processing (C Modelling).

## 2 reference solution

This test is performed by intercomparison: MONOCRISTAL (for a single grain) behaviors on the one hand, and POLYCRISTAL on the other hand must give the same results.

Model A provides the reference values used by model B to compare the different implicit algorithms.

For Modelling C, with explicit integration, the chosen reference is the solution provided by MONOCRISTAL EXPLICITE, compared to the POLYCRISTAL case. These values are slightly different from those obtained by implicit (modellings A and B) due to relatively coarse temporal discretization.

## 6 Summary of the results

The results obtained with implicit integration are identical regardless of the algorithm used, and in good agreement with the solution of explicit integration (0.6% of difference maximum). Moreover, the results obtained with the POLYCRISTAL behavior are identical (in the case of a single phase) to those obtained with MONOCRISTAL.
