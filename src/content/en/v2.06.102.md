# v2.06.102 SHLL102 – Harmonic response of a beam with 3 discs, subject to gyroscopic effect.

**Summary:**

This problem is to validate the effect of the gyroscopic matrix on a beam supported at each end, on linear supports, on a harmonic calculation with a load of the bald type. The beam is full, circular cross section and has three discs.

For this test case, the load of the bald type is installed on disk 2. The comparison is for the value of the resonance peaks of the displacements of disk 2.

This problem thus allows to test the effect of the gyroscopic matrix that was developed for an straight beam. The gyroscopic effect leads to changes in resonance frequencies and amplitudes of displacement.

The results obtained are in good agreement with those given in reference. The references are based on Timoshenko's beam theory.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The reference solution is the one presented in Michel LALANNE and Guy FERRARIS's book.

The numerical resuscitations were obtained by a finished elements code in Timoshenko-type elements beam. The Modelling is done with 14 nodes (13 elements beams).

### 2.2 Baseline

With a slush load, values of the 7 maximas d'amplitude for the point $C$ (disc 2), for a rotation speed varying from $0$ to $30000\mathrm{tr}/\min$.

### 2.3 Uncertainty about the solution

Less than 1%.
