# u4.81.08 Operator POST_BEREMIN

## 1 Purpose

The purpose of this command is to compute, in post-processing of a non-linear elastoplastic
mechanical analysis:

- the Weibull stress and the probability of cleavage coming from the Beremin model.
- the surface density of Weibull stress coming from the industrial version of the Beremin model.

This command returns a table and a MED file (optional).

The macro-command works in D_PLAN, C_PLAN, AXIS or in 3D.

The Beremin model and its industrial version are described in more detail in the reference documentation [R7.02.04](doc:r7.02.04).

Advice on the use of this model is given in the documentation [U2.05.08](doc:u2.05.08).

A test case of the use of POST_BEREMIN is available in [V1.01.163](doc:v1.01.163).

## 2 Syntax

```text
/ table = POST_BEREMIN(
    ◆ RESULTAT = evol_noli,
    ◆ DEFORMATION = / "GDEF_LOG",
                    / "PETIT",
                    / "PETIT_REAC",
    ◆ FILTRE_SIGM = / "SIGM_CORR",
                    / "SIGM_ELGA",
                    / "SIGM_ELMOY",
    ◇ NUME_VARI = int (défaut: 0),
    # Si: equal_to("DEFORMATION", 'GDEF_LOG')
        ◆ LIST_NUME_SIEF = list[int],
    ◇ HIST_MAXI = / "NON" (par défaut),
                  / "OUI",
    ◇ SIGM_MAXI = co,
    ◇ COEF_MULT = float (défaut: 1.0),
    # Si: equal_to("FILTRE_SIGM", 'SIGM_CORR')
        ◆ SIGM_CORR = evol_noli,
    ◆ / WEIBULL = _F(
           ◆ GROUP_MA = grma,
           ◆ M = list[float],
           ◆ VOLU_REFE = float,
           ◇ SIGM_REFE = list[float] (défaut: 0.0),
           ◇ SIGM_SEUIL = list[float] (défaut: 0.0),
           ◇ TYPE_SEUIL = / "REDUIT" (par défaut),
                          / "RESTREINT",
        ),
      / WEIBULL_FO = _F(
           ◆ GROUP_MA = grma,
           ◆ M = list[float],
           ◆ VOLU_REFE = float,
           ◇ SIGM_CNV = float (défaut: 0.0),
           ◇ SIGM_REFE = cham_elem / cham_no / fonction,
           ◇ SIGM_SEUIL = cham_elem / cham_no / fonction,
           ◇ TYPE_SEUIL = / "REDUIT" (par défaut),
                          / "RESTREINT",
        ),
    ◇ METHODE_2D = _F(
         ◇ / MAILLAGE_PLAN = list[maillage],
         ◇ / NOM_MAIL_MED = list[text],
           / GROUP_NO_PLAN = list[grno],
         ◇ / FISSURE = fond_fissure,
         ◇ PRECISION = float (défaut: 1e-06),
         ◇ UNITE_RESU = int (défaut: 0),
      ),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand RESULTAT

Designates the result of the mechanical analysis for which one computes the Beremin quantities (Weibull stress and probability of failure, or surface density of Weibull stress).

### 3.2 Operand DEFORMATION

Defines the assumptions for the computation of the strains.

- In small strains (DEFORMATION = 'PETIT' or DEFORMATION = 'PETIT_REAC'), the computation is carried out from the Cauchy stress field SIEF_ELGA
- In large logarithmic strains (DEFORMATION = 'GDEF_LOG'), the computation is carried out from the specific
stress field $T$ close to the Kirchhoff stress defined in the logarithmic space [R5.03.24](doc:r5.03.24).

*Note 1: in large multiplicative strains (DEFORMATION='SIMO_MIEHE' or DEFORMATION='GREEN_LAGRANGE'), the macro-command is not available.*

*Note 2: in order to minimise the effects linked to incompressibility (volumetric locking) it is possible to carry out the post-processing of the fracture mechanics of cleavage with the incompressible elements (GRAD_INCO) with POST_BEREMIN.*

### 3.3 Operand FILTRE_SIGM

With 'SIGM_ELGA', the elementary stress fields are used in their
representations at the Gauss points.

With 'SIGM_ELMOY', the elementary stress fields are determined from the
average weighted by the Gauss weights.

With 'SIGM_CORR', the Weibull stress is computed by integrating a user field $\sigma_I^*$ given under the keyword SIGM_CORR. This functionality allows the user to consider corrected stress fields, with as a typical application the taking into account of the plastic correction (see [R7.02.04](doc:r7.02.04)).

### 3.4 Operand SIGM_CORR

User stress field $\sigma_I^*$ corresponding to the integrand in the computation of the Weibull stress:

A typical application is the taking into account of the plastic correction (see [R7.02.04](doc:r7.02.04)).

It is incumbent on the user to define the field $\sigma_I^*$. The following formalism must be respected:

- SIGM_CORR must be a concept of type evol_noli containing at each time instant the field $\sigma_I^*$ to be integrated;
- the field $\sigma_I^*$ must be a "utility" field of type UT01_ELGA;
- the value of the corrected stress must be carried by the component X1 of this field.

The test cases ssna108c to ssna108g provide examples of use. The field $\sigma_I^*$ there is a function of the fields of principal stresses, of internal variables and of principal strains (total or plastic). ### 3.5 Operand NUME_VARI

Gives the index of the internal variable of the plasticity indicator, usually named INDIPLAS in code_aster.

If this parameter is not filled in, the filter on active plasticity is not activated, and all the volume mesh cells
of the GROUP_MA are taken into account in the computation of the Weibull stress. See [R7.02.04](doc:r7.02.04).

### 3.6 Operand LIST_NUME_SIEF

If DEFORMATION='GDEF_LOG', gives the indices of the logarithmic stresses $T$ close
to the Kirchhoff stresses defined in the logarithmic space [R5.03.24](doc:r5.03.24)
taken instead of the Cauchy stress tensor
if DEFORMATION='PETIT' or 'PETIT_REAC' (cf [LO17])

### 3.7 Operand HIST_MAXI

If HIST_MAXI='NON' (default value), the maximum principal stress is instantaneous.

If HIST_MAXI='OUI', the maximum principal stress is computed by considering the temporal maximum
over the whole history (historical Beremin model).

### 3.8 Operand COEF_MULT

The default value of this coefficient is 1.0.

For the Beremin model, the following table, in which the thickness is denoted $e$ , indicates typical values of the coefficient $C$ as a function of the type of symmetry:

- **simple symmetry**: the plane of symmetry of the mesh passes through the plane of the defect and the defect is entirely meshed,
- **double symmetry**: the plane of symmetry of the mesh also passes through the plane of the defect but only one half of the defect is meshed.

|  | **3D** **and** **3D_SI** | **AXIS** **and** **AXIS_SI** | **D_PLAN** **and** **D_PLAN_SI** | **C_PLAN** |
| --- | --- | --- | --- | --- |
| SIMPLE | 2 | $4\pi$ | 2e | 2e |
| DOUBLE | 4 | not applicable | not applicable | not applicable |
| NONE | 1 | $2\pi$ | e | e |

**Table** 3.5-1 **:** **Values of the symmetry-thickness multiplier coefficient for the Weibull stress**

Caution, this table is valid only for the Beremin model (computation of the Weibull stress).

In the case of the industrial version of the Beremin model, this table is no longer valid and one cannot reason in terms of simple or double symmetries. Indeed, the value of COEFF_MULT
depends only on the portion of the integration plane represented in the model. If one represents the whole integration plane, then $COEF\_ MULT = 1$. If one represents only half of the plane, then $COEF\_ MULT = 2$.

### 3.9 Operand SIGM_MAXI

Makes it possible to print a post-processing result file in MED format.
This field will contain two components: the integrand of the Weibull stress before and after raising to the power m.

Caution, this keyword cannot be used if several material parameters are given as input or if several projection planes are requested (in the case METHODE_2D).

### 3.10 Factor keyword WEIBULL or WEIBULL_FO

Weibull parameters (see [R7.02.04](doc:r7.02.04)).

In the case WEIBULL, the parameters M, SIGM_REFE and SIGM_SEUIL may be lists of parameters. All the combinations of material parameters are computed if lists of parameters are supplied by the user.

```text
WEIBULL = _F(GROUP_MA = group_ma, M = m, SIGM_REFE = sigmu, VOLU_REFE = V0, SIGM_SEUIL = sigth, TYPE_SEUIL = type_seuil)
```

In the case WEIBULL_FO, the parameters SIGM_REFE and SIGM_SEUIL may be:

- functions, and only of the temperature or of the coordinates X, Y or Z;
- fields at the Gauss points or fields at the nodes.

In this latter case, the intended application is to define material parameters depending on the temperature or on the position in a more complex way than by going through functions of T, X, Y or Z.
One may for example define these parameters as formula fields evaluated at one or more parameters, such as the temperature or the coordinates of the position.

In the case WEIBULL_FO, the parameters SIGM_REFE and SIGM_SEUIL may be:

- functions, and only of the temperature or of the coordinates X, Y or Z;
- fields at the Gauss points or fields at the nodes.

Note that it is expected that the field given for the parameter SIGM_REFE (resp. SIGM_SEUIL) has the component X1 corresponding to the value of the parameter. Such a field is typically obtained by defining a field of type ELGA_NEUT_F or NOEU_NEUT_F (formula field) and then evaluating it at one or more parameters in order to obtain a field ELGA_NEUT_R or NOEU_NEUT_R.
An example of use is given in the test case zzzz163g.

A single function or a single field may be assigned to SIGM_REFE (resp. SIGM_SEUIL). Only M may be a list of parameters.

```text
WEIBULL_FO = _F(GROUP_MA = group_ma, M = m, SIGM_REFE = sigmu, SIGM_CNV = sigm0u, VOLU_REFE = V0, SIGM_SEUIL = sigth, TYPE_SEUIL = type_seuil)
```

All the combinations of material parameters are computed if lists of parameters are supplied by the user.

The keyword WEIBULL(_FO) may be repeated as many times as desired, for example in order to perform the post-processing on different GROUP_MA. In this case the result tables are concatenated successively.

#### 3.10.1 Operand GROUP_MA

Mesh-cell group on which the integrand of the Weibull stress will be computed.

#### 3.10.2 Operand VOLU_REFE

Reference volume $V_0$.

#### 3.10.3 Operand M

Parameter $m$ characterising the scatter of the material.

#### 3.10.4 Operand SIGM_REFE

Cleavage stress $\sigma_u$.
If this parameter is not filled in, the probability of failure is not computed.

#### 3.10.5 Operand SIGM_CNV

Case WEIBULL_FO only.

Stress $\sigma_u^0$ in the presence of a cleavage stress depending on the temperature (see [R7.02.04](doc:r7.02.04)).

#### 3.10.6 Operand SIGM_SEUIL

Threshold stress $\sigma_{th}$.

Default value: 0.0.

#### 3.10.7 Operand TYPE_SEUIL

Type of threshold used. May take the values "REDUIT" or "RESTREINT".

In the case "REDUIT", the Weibull stress is computed from $max (0 , \sigma_I - \sigma_{th})$

In the case "RESTREINT", the Weibull stress is computed from $\sigma_I$ restricted to the zone where $\sigma_I > \sigma_{th}$

Default value: "REDUIT".

### 3.11 Keyword METHODE_2D

Makes it possible to use the industrial version of the Beremin model (see [R7.02.04](doc:r7.02.04)).
It can be used only with a 3D model.

The integrand of the Weibull stress is computed on the basis of the options (threshold stress? filter on active plasticity? maximum over the history? average on the stresses?)
specified by the user, in a manner identical to the usual Beremin model. This integrand is then projected onto one or more planes filled in by the user
by means of node groups present in the 3D mesh (operand GROUP_NO) or by plane meshes (operand MAILLAGE_PLAN).
The integral is then computed in each of these planes.

Examples of syntax are given in the section Examples of use.

#### 3.11.1 Operand GROUP_NO_PLAN

Makes it possible to specify the name of the node groups onto which the integrand of the Weibull stress will be projected.
It may take as input one or more group names.

#### 3.11.2 Operand FISSURE

Mandatory if GROUP_NO_PLAN is present.

Makes it possible to define the crack front.
It takes as input an object fond_fiss defined by the command DEFI_FOND_FISS.

In the case where GROUP_NO_PLAN corresponds to a single node group, one may omit this parameter FISSURE.

#### 3.11.3 Operand MAILLAGE_PLAN

Makes it possible to define the integration planes of the Weibull stress by means of 2D meshes, distinct from the 3D mesh.

#### 3.11.4 Operand NOM_MAIL_MED

Mandatory if MAILLAGE_PLAN is present.

Makes it possible to define the name under which the MAILLAGE_PLAN will appear in the output table of POST_BEREMIN.

#### 3.11.5 Operand UNITE_RESU

Makes it possible to define optionally the logical unit in which will be printed, in .med format, the integrand of the Weibull stress projected
into a plane, for the purpose of checking the computation of this Weibull stress.

Requires that only a single integration plane be given.

#### 3.11.6 Operand PRECISION

Makes it possible to define the relative precision of the projection from 3D to 2D. This relative precision is defined with respect to the
minimum size of the volume mesh cells of the GROUP_MA defined by the user.

By default, this relative precision is $10^{-6}$.

See [R7.02.04](doc:r7.02.04).

## 4 Examples of use

Examples will be found in the test cases zzzz163 and sslv101. Advice on the use of this model is given in the documentation [U2.05.08](doc:u2.05.08).

### 4.1 Example of use for the Beremin model

- Stress averaged by element
- Filter on active plasticity, on the basis of the internal variable V2
- Maximum of the stresses over the history (HIST_MAXI = "OUI" by default)

**In the case below, the Weibull stress is computed on the mesh-cell group "CT", by applying the following options:**

```text
BERE = POST_BEREMIN(
    RESULTAT=U,
    COEF_MULT=1,
    DEFORMATION="PETIT",
    FILTRE_SIGM="SIGM_ELMOY",
    NUME_VARI=2,
    WEIBULL=_F(GROUP_MA="CT", M=8.0, VOLU_REFE=1.25e-4, SIGM_REFE=2630.0e0),
)
```

In the example below in large logarithmic strains, the Weibull stress is computed from the components of the tensor T
stored in the internal variables 4 to 9 (it is for the user to adapt the numbers of the internal variables as a function of the constitutive law used, for example)

```text
BERE = POST_BEREMIN(
    RESULTAT=U,
    COEF_MULT=1,
    DEFORMATION="GDEF_LOG",
    LIST_NUME_SIEF=[4,5,6,7,8,9],
    FILTRE_SIGM="SIGM_ELMOY",
    NUME_VARI=2,
    WEIBULL=_F(GROUP_MA="CT", M=8.0, VOLU_REFE=1.25e-4, SIGM_REFE=2630.0e0),
)
```

### 4.2 Example of use for the industrial version of Beremin

In the case of planes defined by node groups:

```text
fiss = DEFI_FOND_FISS(
    MAILLAGE=mail_meca,
    FOND_FISS=_F(
        GROUP_MA="FRONT0",
        TYPE_FOND="OUVERT",
    ),
    LEVRE_SUP=_F(GROUP_MA="LEVRE"),
    SYME="OUI",
)

liste_plans = ["Plan_" + str(i) for i in range(0, 51)]

beremin_2D = POST_BEREMIN(
    COEF_MULT=2.0,
    DEFORMATION="PETIT",
    FILTRE_SIGM="SIGM_ELMOY",
    HIST_MAXI="NON",
    RESULTAT=evol_meca,
    WEIBULL=_F(
        GROUP_MA="TORE_COMPLET",
        M=3,
        SIGM_SEUIL=1300.0,
        VOLU_REFE=0.000125,
    ),
    METHODE_2D=_F(GROUP_NO_PLAN=liste_plans , FISSURE = fiss),
)
```

In the example above, one defines a crack front by means of the command DEFI_FOND_FISS
and then one applies the Beremin post-processing on 51 planes defined by node groups named "Plan_i", with i ranging from 0 to 50.

In the case of a plane defined by a 2D mesh, for which one also requests printing
the result of the projection in a .med file:

```text
mesh_2D_tore_c0 = LIRE_MAILLAGE(FORMAT="MED", UNITE=22)

beremin_2d_c0_tore = POST_BEREMIN(
    RESULTAT=resu_elas,
    COEF_MULT=2,
    DEFORMATION="PETIT",
    FILTRE_SIGM="SIGM_ELMOY",
    WEIBULL=_F(GROUP_MA="CT", M=18.0, VOLU_REFE=1.25e-4, SIGM_REFE=2630.0e0),
    METHODE_2D=_F(  MAILLAGE_PLAN=mesh_2D_tore_c0,
                    NOM_MAIL_MED="Couche_0_TORE",
                    UNITE_RESU = 80),
)
```
