# v2.01.105 SDLD105 - Transition response from a mass-spring system to a mono-support earthquake with static correction

**Summary**

This test case, inspired by test case VPCS SDLD04, is the calculation of the unamortized transient response of a linear clamped-free mass-spring system, subject to a mono-support required acceleration.

Its objective is to show the value of static correction, whether it is done "a priori" by adding static modes at the basis of dynamic modes, or *a posteriori* .

## 1 Reference problem

### 1.1 Geometry

The response of a linear system consisting of three masses and three springs is calculated to an acceleration imposed on the point sound of $(A)$ anchor:

![Figure](/figures/v2.01.105/1000000000000330000000D440684DD880BB8CF9.png)

### 1.2 Material properties

- restraint stiffeners: ${k}_{1}=1000N/m$ and ${k}_{2}={k}_{3}=100N/m$;
- point masses: $m={m}_{1}={m}_{2}={m}_{3}=1\mathrm{kg}$ .
- $\text{5 \%}$ modal damping for all modes

### 1.3 Boundary conditions and loads

**boundary conditions**

The only travels allowed are $x$-axis translations.

The point $A$ is clamped: $\mathit{dx}=\mathit{dy}=\mathit{dz}=\mathit{drx}=\mathit{dry}=\mathit{drz}=0$.

**Charge**

The point anchor $A$ is subjected to a harmonic acceleration of frequency ${f}_{\mathrm{ex}}$ . The calculation is made from $0$ to $20s$ .

### 1.4 Initial conditions

The system is initially at rest: $t=0$ , $\mathrm{dx}(0)=0$ and $\mathrm{dx}/\mathrm{dt}(0)=0$ in all point.

## 2 reference solution

The objective of the test case is to show the modal truncation effect on a very simple example of seismic calculation and to illustrate the value of static correction, whether it is done *a priori* by adding static modes at the basis of dynamic modes, or *a posteriori* . The reference solution is the complete modal-based transitional calculation performed with the DYNA_VIBRA operator.

The mass-spring system has three degrees of freedoms. It is therefore associated with three modes whose calculated frequencies are:

${f}_{1}=0,946\mathrm{Hz}$ , ${f}_{2}=2,533\mathrm{Hz}$ et ${f}_{3}=5,305\mathrm{Hz}$ .

The frequency of the harmonic seismic signal was chosen at ${f}_{\mathrm{ex}}=2\mathrm{Hz}$ to keep only the first two modes in the modal base. The rule of holding modes up to twice the maximum frequency of excitement is respected.

The table of unit effective modal masses gives interesting information:

It is observed that the third mode will have a negligible dynamic response because its eigenfrequency is ${f}_{3}=5,305\mathit{Hz}$ , beyond $2\times {f}_{\mathit{ex}}=4,0\mathit{Hz}$ . However, its effective unit modal mass in the $x$ direction is $\text{26,7 \%}$ . It is not negligible and this mode can influence the response of the mass-spring system by its quasi-static contribution. It is the purpose of the static correction that it should be taken into account.

If we look at the geometry of mode 3, we find that it is mainly on the node $\mathrm{N02}$ that we can observe the effect of the mode and therefore the effect of the static correction.

**Transient calculus by modal synthesis**

The consideration of a load in the form of a projected vector on the modal basis, as a modal component, in the form of a projected vector and a modal component simultaneously, is tested, as well as the consideration of modes neglected by static correction.

The static correction shall be taken into account according to the following options:

- static *post-recording* correction;
- static *a priori* correction, by supplementing the dynamic mode base with static mode with force imposed, with reorthogonalisation of the base thus completed;
- static *a priori* correction, by supplementing the dynamic mode base with the static mode with the required acceleration (pseudo-mode), with the base re-orthogonalization thus completed;
- static *a priori* correction, by supplementing the dynamic mode base with static mode with imposed force and static mode with imposed acceleration (pseudo-mode), with reorthogonalization of the base thus completed.

The interest of static correction has been illustrated above: as expected when reading the modal deformities, the static correction is not visible for the $\mathit{NO4}$ but plays an important role for the $\mathrm{NO2}$. Without static correction at the $\mathit{NO}2$, the displacement is dephased and its $\text{50\%}$ reduced amplitude. At the $\mathit{NO}2$ , with static *a posteriori* correction, the error remains visible (less than $\text{20\%}$ ), but the calculation remains realistic; with static *a priori* correction, regardless of the nature of the static modes considered (at acceleration or at the force imposed), the modal trunk error is completely compensated, allowing the exact reference displacement to be traced back. On a less caricatural calculation, the error will be less sensitive. It is also noted that the amplitude of the displacement at the node $\mathrm{NO2}$ is two orders smaller than that at the node $\mathrm{NO4}$ .

## 5 Summary of the results

The test case is an example of the implementation of static correction, whether it is done *a priori* by adding static modes at the base of dynamic modes, or *a posteriori* . On a system specially calculated to show its effects, it shows that static correction can significantly reduce the error due to the modal truncation effect on "high frequencies" (post facto static correction), or even cancel it completely (static correction *a priori* ), provided that the resulting Ritz base is reorthogonalised. On an industrial study, one can expect a less visible effect.
