# u4.92.11 Procedure ENGENDRE_TEST

## 1 Purpose

Write a "piece of a file" in order to check the subsequent non-regression of the code.

This piece of a file (containing the commands TEST_RESU and TEST_TABLE) may be inserted into a test case in order to check the non-regression of the content of the JEVEUX objects created by this test case.

This command is useful only to the developers (and maintainers) of the code.

## 2 Syntax

```text
ENGENDRE_TEST(
    ◇ UNITE = unit (défaut: 8),
    ◇ FORMAT = / "ASTER" (par défaut),
               / "OBJET",
    ◇ FORMAT_R = text (défaut: "1PE20.13"),
    ◇ PREC_R = text (défaut: "1.E-10"),
    # Si: equal_to("FORMAT", 'ASTER')
        ◆ CO = resultat / table / cham_gd,
        ◇ TYPE_TEST = / "SOMME",
                      / "SOMM_ABS" (par défaut),
                      / "MAX",
                      / "MIN",
    # Si: equal_to("FORMAT", 'OBJET')
        ◆ / TOUT = "OUI" (ou non renseigné),
          / CO = datastructure,
        ◇ TYPE_TEST = "SOMME",
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 General points

This command is used to generate "pieces" of a file that one can include in the command file of a test in order to check the "non-regression" of the code.

When one does not use the keyword FORMAT='OBJET' (which is recommended), the types of concepts that one can test are fewer: the tables, the fields and the sd_resultat. For each concept, the command ENGENDRE_TEST will generate a command TEST_TABLE or TEST_RESU.

If the concept is a table, each column of the table will be tested. If the concept is an sd_resultat, all the fields will be tested for all the order numbers.

If one uses the keyword FORMAT='OBJET' (which is not recommended), the command will write, in the file attached to the logical unit iunit (RESULTAT by default), lines of the type:

```text
_F(NOM='CHAMEL14 .VALE' , S_R=-1.45779E+08, PRECISION=1.D-5,),

_F(NOM='CHAMNO3 .VALE' , S_R= 1.16344E+06, PRECISION=1.D-5,),

_F(NOM='LR3 .NBPA' , S_I= 5, PRECISION=0.,),

_F(NOM='LR3 .BINT' , S_R= 1.00000E+01, PRECISION=1.D-5,),

_F(NOM='LR3 .VALE' , S_R= 3.00000E+01, PRECISION=1.D-5,),

_F(NOM='FO20 .VALE' , S_R=-1.16733E+06, PRECISION=1.D-5,),
```

These lines can then be inserted into the text of a command TEST_RESU:

```text
TEST_RESU( OBJET= (

<< lignes insérées>>

),)
```

Each line will give rise to one occurrence of the keyword OBJET of the command TEST_RESU. One will thus test the non-regression of the content of the specified JEVEUX objects.

In order to be able to print the content of the JEVEUX objects, these objects must of course exist, and that is why this command is generally called at the end of the command file.

### 3.2 Operand TOUT

```text
♦    /    TOUT = 'OUI'
```

All the objects present on the GLOBALE database at the time of the call to ENGENDRE_TEST will give rise to a non-regression test.

### 3.3 Operand CO

```text
/    CO = l_conc
```

l_conc is the list of the concepts for which one wants to generate the non-regression tests.

### 3.4 Operand TYPE_TEST = 'SOMME'

```text
◊    TYPE_TEST =        'SOMME'
```

For each JEVEUX object retained, one tests:

| SOMME | The tested value corresponds to the sum of the values of the numbers contained in the object. |
| --- | --- |
| SOMME_ABS | The tested value corresponds to the sum of the absolute values of the numbers contained in the object. |
| MIN | The tested value corresponds to the minimum of the values of the numbers contained in the object. |
| MAX | The tested value corresponds to the maximum of the values of the numbers contained in the object. |

### 3.5 Operand UNITE

```text
◊    UNITE =    /    iunit,

/ 8
```

This integer makes it possible to choose the logical unit of the file in which the printout will be made. By default the printout will be made on the logical unit associated with the file fort.8.

### 3.6 Operand FORMAT_R

```text
◊    FORMAT_R =    /    format,
/    '1PE20.13',        [DEFAUT]
```

This character string makes it possible to choose the number of decimal places printed for the real numbers.

### 3.7 Operand PREC_R

```text
◊    PREC_R =    /    prec,
/    '1.E-10',            [DEFAUT]
```

This character string makes it possible to choose the accuracy with which the test will be performed in the command TEST_RESU (for the floating-point numbers).

## 4 Example

> ENGENDRE_TEST(CO=(chamno, chamel, tabl2, evolth))
