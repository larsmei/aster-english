# v6.01.102 SSNA102 - Multibody elastic contact

**Summary:**

This nonlinear static problem of a axisymmetric structure allows testing both variants of contact algorithm in large displacements.

The calculation consists of Modelling a structure composed of several elastic bodies in unilateral contact without friction. This calculation has already been the subject of a test case IPSI-Phi2AS described in note HI‐75/97/034/0. The reference solution comes from calculations made with the codes ABAQUS, SYSTUS and SAMCEF.

## 1 Reference problem

### 1.1 Geometry

Model: axisymmetric

Units: $\mathrm{mm}$

![Figure](/figures/v6.01.102/100002010000022A0000030220C311A77B7D7962.png)

### 1.2 Material properties

| Linear elastic material of characteristics: | $E=200000.\mathrm{MPa}$ |
| --- | --- |
|  | $\nu =0.3$ |

### 1.3 Boundary conditions and loads

- $\mathrm{DR}$ and $\mathrm{DZ}$ blocked on $\mathrm{LBC4}$
- $\mathrm{DZ}$ imposed $-2.0\mathit{mm}$ on $\mathrm{LCD1}$
- Restraints between degrees of freedom:

$\mathrm{DZ}(\mathrm{PA1})=\mathrm{DZ}(\mathrm{PP2})$

$\mathit{DZ}(\mathit{PM3})=\mathit{DZ}(\mathit{PD4})$

- First calculation: conditions of unilateral contact between each side of the solids in opposite directions, i.e. 3 pairs of matched surfaces
- Second calculation (modelization A only): unilateral contact conditions between each side of the solids in opposite directions, except for the top one in RESOLUTION='NON' mode (multi-zone calculation-free mode test)

## 2 reference solution

### 2.1 Calculation method used for reference solution

Average of the results obtained by different mechanical calculation codes, ABAQUS, SYSTUS, SAMCEF, within the framework of test case IPSI- ${\Phi}_{2}$ AS [bib1].

| ABAQUS | $110270N$ |  |
| --- | --- | --- |
| SYSTUS | $109500N$ | Or an average of $108257N$ |
| SAMCEF | $105000N$ |  |

**NB:**

*The forces calculated by Aster in axisymmetric are calculated by radian. The value to be obtained is therefore* $108257/2\pi =17229.58N/\mathit{rd}$

### 2.3 Uncertainties about the solution

The dispersion around the mean vertical displacement value in $\mathrm{PA4}$ is 4%. The dispersion around the vertical reaction to l-l-clamped support is 3%.
