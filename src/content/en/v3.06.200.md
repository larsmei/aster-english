# v3.06.200 SSLA200 - Linear 2D AXIS Mechanics

**Summary:**

This test is a non-regression test. It does not have analytical solution. The objective is to test a large number of different elementary calculations:

- frame: linear mechanics (MECA_STATIQUE)
- a wide variety of loads (in the form of "real" or "function")
- all possible mesh cells types (linear / quadratic mixture)

Modelization A:

- Modelling AXIS

Modelling B:

- AXIS_SI Modelling (sub-integrated)

This documentation is deliberately succinct.
