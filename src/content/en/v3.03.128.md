# v3.03.128 SSLS128 - Static calculation of a plate composed of layers

**Summary:**

This test validates the case of multilayered hulls.

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v3.03.128/100000000000033C0000019433CA1CD7DE942051.png)

It is a composite material consisting of 16 superimposed layers of the same material and different fibre directions forming a plate of $4.48m$ d's thickness. The longitudinal or direction direction of the fibres of each layer is defined by the first direction of the orthotropy.

### 1.2 Ownership of the material

The Material properties are:

- Longitudinal Young's modulus: $\text{E\_L}=59000\mathrm{MPa}$
- Young's modulus transverse: $\text{E\_T}=59000\mathrm{MPa}$
- Shear module in $\text{LT}$ plane: $\text{G\_LT}=3700\mathrm{MPa}$
- Poisson's ratio in $\text{LT}$ plane : $\text{NU\_LT}=0.08$
- longitudinal tensile failure criterion: $\mathrm{XT}=560\mathrm{MPa}$
- longitudinal compression failure criterion: $\mathrm{XC}=-475\mathrm{MPa}$
- transverse tensile failure criterion: $\mathrm{YT}=560\mathrm{MPa}$
- cross-sectional compression failure criterion: $\mathrm{YC}=-475\mathrm{MPa}$
- shear failure criterion in plane $\text{LT}$: $\text{S\_LT}=48\mathrm{MPa}$

The orientation of the first layer is 0° from the reference reference mark, for the second layer 45°, for the third layer 0° and so on.

## 3 Modelling A

### 3.1 Modelling characteristics

The hull is modeled by elements DKT. Its characteristics are defined in AFFE_CARA_ELEM:

- thickness: $16\times 0.28=4.48m$
- reference reference mark of the shell defined by ANGL_REP = 0.

The different layers are defined by the DEFI_COMPOSITE operator, which gives each layer its thickness, material and orientation in relation to the reference reference mark defined in AFFE_CARA_ELEM.

### 3.2 Mesh characteristics

Number of nodes:624

Number of mesh cells and types:48 SEG2 and 576 QUA4
