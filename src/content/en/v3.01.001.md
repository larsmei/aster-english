# v3.01.001 SSLL01 - slender beam on 2 clamped supports

**Summary:**

The linear elasticity static test is used to validate straight beam elements POU_D_T.

This test case is about a slender beam on 2 clamped supports.

The support reactions and bending moments are tested by comparing simulation results with reference solution AFNOR (ref. [1]) and those obtained with Pipestress software.
