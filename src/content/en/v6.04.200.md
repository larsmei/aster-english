# v6.04.200 SSNV200 - Tensile shear test with VISC_TAHERI

**Summary:**

The problem is quasi-static non-linear in structural mechanics.

The response of a volume element to a tensile load is analyzed in such a way that it imposes a uniform stress-deformation state in the element. There is only one 3D volume model.

This test is inspired by the SSNV102, which tests the behaviour of TAHERI in elasto-plasticity. Here, we take into account the viscosity.

### 3.4 Remarks

The load used here does not show any plasticization, whereas without viscosity, this same load leads the structure in elastoplastic regime.

The ${\sigma}_{p}$ value test does not give the same value rigorously on all machines (needs TOLE_MACHINE). This problem is related to a function with a vertical tangent (power 0.3) that appears in the constitutive law. See comment in the ssnv200a.comm file.

## 4 Summary of the results

This non-regression test allows a minimum check of the VISC_TAHERI model's smooth operation. It would require a test to be completed with a true reference solution.
