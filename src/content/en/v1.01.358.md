# v1.01.358 ZZZZ358 – keyword MODELE_THER validation of the MODI_MODELE_XFEM operator

**Summary**

This test has no physical meaning, it is a computer test. The MODELE_THER key word of the MODI_MODELE_XFEM [U4.41.11](doc:u4.41.11) operator is valid. This key word allows to build a mechanical model enriched "by copy" of an enriched thermal model. It is an alternative to keyword FISSURE operator MODI_MODELE_XFEM, useful only in thermomechanical chain calculations with X-FEM, which ensures that the cutting (in sub-elements and facets) remains strictly identical between the enriched thermal model, and enriched mechanical.

This feature is valid on the 4 modellings possible in X-FEM mechanics:

- Modelling A: '3D'
- Modelling B: 'C_PLAN'
- Modelling C: 'D_PLAN'
- Modelling D: 'AXIS'

## 1 Test principle

The principle of this test is to define, from the same mesh:

- a thermal model enriched with MODI_MODELE_XFEM / FISSURE;
- a mechanical model enriched with MODI_MODELE_XFEM / FISSURE, with the same cracked geometry as for modthx;
- a mechanical model enriched with MODI_MODELE_XFEM / MODELE_THER, by "copying" modthx.

Once these 3 models are created, several checks are performed that require the use of python, and the execution of the PAR_LOT = 'NON' test. These checks are as follows.

1. Using the IMPR_CO / NIVEAU=1 [U4.91.11](doc:u4.91.11) procedure, we ensure that these 3 enriched models all contain the same number of objects.
2. Then, we make sure that the description of each '.CELV' object of the cam_elem contained in the 3 sd_modele_xfem remains the same from one model to another. This description corresponds to NIVEAU=-1 in IMPR_CO
