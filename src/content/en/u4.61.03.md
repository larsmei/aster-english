# u4.61.03 Operator CALC_CHAR_CINE

## 1 Purpose

Compute the field at the nodes corresponding to the degrees of freedom imposed by AFFE_CHAR_CINE.

This nodal field thus computed will have to be used when solving the linear system with the operator RESOUDRE [U4.51.02](doc:u4.51.02).

This operator is useful only for the “step-by-step” analyses in which one solves the linear systems by the command RESOUDRE.

Produces a data structure of type cham_no.

## 2 Syntax

```text
cham_no = CALC_CHAR_CINE(
    ◆ NUME_DDL = nume_ddl,
    ◆ CHAR_CINE = char_cine_acou / char_cine_ther / char_cine_meca,
    ◇ INST = float,
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand NUME_DDL

```text
♦    NUME_DDL = nu
```

Name of the numbering associated with the matrix which will be used for the solution.

### 3.2 Operand CHAR_CINE

```text
♦    CHAR_CINE= l_chci
```

List of the names of the kinematic loads to be evaluated.

The computed cham_no will contain:

- the value 0 on the degrees of freedom which are not imposed,
- the value imposed by the kinematic loads on the degrees of freedom which are imposed.

**Warning:**

If a degree of freedom is imposed several times (if it appears in several kinematic loads of the list l_chci), the value imposed on this degree of freedom will be the **sum** of the imposed values, which is probably not what the user wants!

This dangerous behaviour is unfortunately accompanied by no alarm.

If the kinematic load is of function type, the value imposed on a degree of freedom is that obtained by evaluation of the function at the coordinates of the node carrying the degree of freedom and at the time instant t [§3.3].

### 3.3 Operand INST

```text
◊    INST= t
```

Time instant used to evaluate any functions of time [§3.2].

### 3.4 Operand INFO

```text
◊    INFO= impr
```

Printout parameter:

1: (default) no printout,

2: printout of the resulting cham_no_* .

## 4 Examples

An example of a sequence of commands using CALC_CHAR_CINE is given in the documentation of the command AFFE_CHAR_CINE [U4.44.03](doc:u4.44.03).
