# v1.01.178 ZZZZ178- Validation of the thermo-mechanical chaining methodology in HPC

**Summary:**

This test validates the thermo-mechanical chain calculation methodology in HPC.

The calculation presents the following steps:

- parallel reading of the quadratic mesh MQ
- creation of the linear mesh ML by the CREA_MAILLAGE command
- heat problem resolution on ML
- parallel subdomain projection of the temperature field to MQ by the PROJ_CHAMP command
- definition of mechanical material with reference to the field of control variables
- mechanical problem solving on MQ

The standards of the different fields are compared with sequential resolution.

This test consists of two modellings:

- Modelling A: D_PLAN
- Modelling B: 3D with thermal loading by AFFE_CHAR_THER
- Modelling C: 3D with thermal loading by AFFE_CHAR_CINE
- Modelling D and E: like Modelling B but replacing the chaining with a low MPI coupling.

It is emphasized that creating the linear mesh ML by the CREA_MAILLAGE command is **indispensable** to the proper operation of the parallel projection by the PROJ_CHAMP command.

This documentation is deliberately succinct.
