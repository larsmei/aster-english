# u4.66.04 Operator CALC_CHAM_FLUI

## 1 Purpose

Compute fluid potential fields associated with the added-mass theory [R4.07.03](doc:r4.07.03).

The fields are induced by a perfect, incompressible fluid, at rest or in potential flow, on a 3D structure.

The terms of these fields are computed on the modal basis of the structure in vacuum.

The analysis of the terms of the matrices is carried out by solving the LAPLACE equations within the framework of a **thermal analogy**. The computed temperature plays the role of a pressure in the fluid domain. One must therefore take care to define the fluid material by **thermal** characteristics, and to assign a **thermal** model to the part of the mesh which represents the fluid.

Thanks to this operator, one can determine, for example, the pressure created by the fluid on the structure vibrating according to one of its eigenmodes.

The test FDLV114b provides an example of implementation on a case of a cylindrical tank.

Produces a data structure of type evol_ther.

## 2 Syntax

```text
evol_ther = CALC_CHAM_FLUI(
    ◆ RIGI_THER = matr_asse_temp_r,
    ◆ CHAM_MATER = cham_mater,
    ◆ EXCIT = _F(
         ◆ CHARGE = char_ther,
         ◇ FONC_MULT = nappe / formule / fonction,
      ),
    ◇ POTENTIEL = / "DEPL" (par défaut),
                  / "VITE",
                  / "PRES",
    ◇ DIST_REFE = float (défaut: 0.01),
    ◆ MODE_MECA = mode_meca,
    # Si: exists("MODE_MECA")
        ◇ COEF_MULT = float (défaut: 1.0),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```
## 3 Operands

### 3.1 Operand RIGI_THER

```text
♦    RIGI_THER = rigi_ther
```
Thermal stiffness matrix corresponding to the fluid potential. It is built by associating with the $\rho {c}_{p}$ of the material assigned to the fluid model the density of the fluid.

### 3.2 Operand CHAM_MATER

◊     CHAM_MATER = chmat

Name of the material field assigned on the model associated with the matrix rigi_ther.

### 3.3 Factor keyword EXCIT

#### 3.3.1 Operand CHARGE

```text
♦    CHARGE = ch
```
Thermal loading corresponding to the boundary conditions on the fluid.

For example in the case of an analysis of type POTENTIEL = «PRES»:

> TEMP_IMPO(TEMP=0.0) corresponds to a zero pressure on this surface.

#### 3.3.2 Operand FONCT_MULT

```text
♦    FONC_MULT = fmult
```
Multiplicative function or formula modulating the loading

### 3.4 Operand POTENTIEL

```text
♦    POTENTIEL    =    /    'DEPL',
/    'VITE',
/    'PRES'                        [DEFAUT],
```
Choice of the type of potential required, displacement potential, velocity potential, or a pressure field.

### 3.5 Operand DIST_REFE

```text
◊    DIST_REFE = 1.E-2                                [DEFAUT],,
```
Reference distance to be supplied when one carries out an analysis on a generalised model. This distance is an absolute geometric criterion intended for copying values of structural displacements into a thermal fluid model, in order to solve there the Laplace equation of the unsteady pressure field. By default, it is equal to 10–2 m.

### 3.6 Operand MODE_MECA

```text
♦    MODE_MECA = mode
```
Modes on which one computes the fluid potential

#### 3.6.1 Operand COEF_MULT

```text
♦COEF_MULT = 1.0                                [DEFAUT],

Coefficient réel permettant, éventuellement, de mettre à l'échelle le potentiel résultat
```
