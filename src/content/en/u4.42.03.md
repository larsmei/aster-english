# u4.42.03 Operator DEFI_COMPOSITE

## 1 Purpose

Determine the homogenised material characteristics of a multilayer shell from the characteristics of each layer. The following characteristics are taken into account:

- thickness,
- type of the constituent material,
- orientation of the fibres with respect to a reference axis.

This command produces a data structure of type mater. It cannot be used in non-linear mechanics (STAT_NON_LINE and DYNA_NON_LINE).

## 2 Syntax

```text
mater = DEFI_COMPOSITE(
    ◆ COUCHE = _F(
         ◆ EPAIS = float,
         ◆ MATER = mater,
         ◇ ORIENTATION = float,
      ),
    ◇ IMPRESSION = _F(
         ◇ UNITE = unit (défaut: 8),
      ),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```
## 3 Operands

### 3.1 Keyword COUCHE

```text
♦    COUCHE = _F
```
Factor keyword for the definition of a layer of the multilayer composite, starting from the lower layer up to the upper layer.

#### 3.1.1 Operand EPAIS

```text
♦    EPAIS = EP
```
Thickness of the layer.

#### 3.1.2 Operand MATER

```text
♦    MATER = MA
```
The concept MA contains the constituent material of the layer and is produced by the operator DEFI_MATERIAU under the factor keyword ELAS_ORTH.

The damping parameters AMOR_ALPHA, AMOR_BETA and AMOR_HYST available in ELAS_ORTH are not taken into account by DEFI_COMPOSITE.

#### 3.1.3 Operand ORIENTATION

```text
◊    ORIENTATION = orien
```
Angle of the 1st direction of orthotropy (longitudinal direction or fibre direction) in the plane tangent to the element with respect to the 1st direction of the reference frame defined in the operator AFFE_CARA_ELEM by the factor keyword COQUE and the keyword ANGL_REP [U4.42.01](doc:u4.42.01).

By default orien is zero; otherwise it must be supplied in degrees and must lie between $–90°$ and $+90°$ .

### 3.2 Operand IMPRESSION

```text
◊     IMPRESSION = _F    (     ◊     UNITE    =        / unit ,        [I]

                                                      / 8 ,            [DEFAUT]
```
This integer makes it possible to choose the logical unit of the file on which the printout, in RESULTAT format, of the list of homogenised coefficients will be made. By default, the printout will be carried out on the logical unit associated with the file of logical unit 8.

## 4 Example

```text
MULTI = DEFI_COMPOSITE(
                COUCHE =(_F(EPAIS = 1.E-3, MATER = MAT1,    ORIENTATION = - 20.),
                         _F(EPAIS = 2.E-3, MATER = MAT2,    ORIENTATION = 10.),
                         _F(EPAIS = 2.E-3, MATER = MAT2,    ORIENTATION = - 10.),
                         _F(EPAIS = 1.E-3, MATER = MAT1,    ORIENTATION = 20.),),
                        )
```
