# v4.04.101 TPLV101 - steady-state thermal analysis with exchange condition between walls vis-à-vis

**Summary:**

This elementary test allows a stationary thermal problem involving two separate domains to be treated by imposing a condition on the boundary of the type exchange between walls.

For the modellings presented here, the results obtained by *Code_Aster* are identical to the analytically calculated reference.

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v4.04.101/10000000000002140000015BBD3D20DCBFCC8637.png)

### 1.2 Material properties

Thermal conductivity $k=\mathrm{1.W}/m°C$

| Output flow through ${B}_{1}{F}_{1}{G}_{1}{C}_{1}$ plane identical to the incoming flow through ${A}_{2}{E}_{2}{H}_{2}{D}_{2}$ plane |  |

| Source imposed in field 1 Source imposed in field 2 | ${s}_{1}$ ${s}_{2}$ |

## 2 reference solution

### 2.1 Calculation method used for reference solution

A simple analytical solution is available, since it is a function of harmonic display and adjustment of the associated source in each domain:

- in domain 1: $T(x,y,z)=T({A}_{1})+{x}^{2}+{y}^{2}+{z}^{2}$ , (in the original ${A}_{1}$ reference),
- in domain 2: $T(x,y,z)=T({A}_{2})+\frac{1}{2}{x}^{2}+{y}^{2}+{z}^{2}$ , (in the original ${A}_{2}$ marker ).

The values of ${s}_{1}$ and ${s}_{2}$ , ${s}_{1}=-6.$ , ${s}_{2}=–\mathrm{5.W}/{m}^{3}$ are derived.

### 2.2 Baseline

Temperatures at ${B}_{1}{F}_{1}{G}_{1}{C}_{1}$ and ${A}_{2}{E}_{2}{H}_{2}{D}_{2}$ plane points

### 2.3 Uncertainty about the solution

analytical solution.
