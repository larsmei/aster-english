# v1.03.132 MFRON06 – Code_Aster-MFront interface test for metallurgy laws for numerical welding simulation

**Summary:**

This test validates metallurgical behaviors defined using *MFront* in comparison with similar behaviors of *Code_Aster* . The law of the META_**_**_** type is examined for which the plasticity criterion and material parameters depend on metallurgical phases.

Modelling A: This Modelling allows to validate the Mfront-Official model which corresponds to META_P_IL_PT in AXIS compared to the HSNV102B test.

Modelling B: This Modelling validates the Mfront-Official model that corresponds to META_P_IL_PT in AXIS compared to the HSNV101B test.

Modelling C: This Modelling allows to validate the Mfront-User model that corresponds to META_P_IL_PT in AXIS compared to the HSNV102B test.

## 3 Modelling C

### 3.1 Modelling characteristics

This Modelling is identical to Modelling A:

- Tested behavior: MetaAcierEPIL_PT.mfront. Elastoplastic law of vonMises with metallurgy effect and plasticity of transformation, similar to the META_P_IL_PT law [cf. R4.04.02].
- Modelling and data similar to HSNV102B [V7.22.102](doc:v7.22.102) test

The so-called "user" mode of implementing Mfront laws is used in Code_Aster. In this case, the material parameters of the MetaAcierEPIL_PT Mfront law are indicated by a list of functions in the MFRONT **_FO** key word of the DEFI_MATERIAU command. The function list is of the form (fonc1, fon2, ..., fon21) with the following correspondence to the names of the MetaAcier_EPIL_PT key word parameters:

## 4 Summary of the results

The results are satisfactory and validate the interface between *Code_Aster* and MFRONT in official and user mode for vonMises' elastoplastic law with metallurgy and plastic transformation.
