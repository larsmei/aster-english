# v1.01.106 ZZZZ106 - Geometric criteria in DEFI_GROUP

**Summary:**

This test validates the different options for creating groups of mesh cells (or nodes) by using **geometric criteria** in the DEFI_GROUP command:

- 'SPHERE'
- 'CYLINDRE'
- 'BANDE'
- 'FACE_NORMALE'
- 'ENV_SPHERE'
- 'ENV_CYLINDRE'
- 'PLAN'

## 1 Reference problem

![Figure](/figures/v1.01.106/100004D20000106F00000C9C05ACAD6C5203090A.svg)

It is a square plate on the $a=10.$ side and $t=1$ thickness.

### 1.1 Material properties

$E=1.$

$\nu =0.3$

### 1.2 Boundary conditions and loading

The plate is clamped along the $\mathit{AB}$ side.

There are 7 load cases for Modelling A and 5 load cases for Modelling B.

Each load case corresponds to the overlay of 2 loads that cancel.

One of these loads applies to an GROUP_MA or an GROUP_NO defined from a geometric criterion in DEFI_GROUP, the other, of opposite sign, applies to the GROUP_MA or the GROUP_NO defined "extension" (hand).

Modelling A uses a "3D" model in DKT inshell.

Model B uses a D_PLAN model in TRIA3.

The grids are the same.

## 2 reference solution

For all cases of loading, the solution is trivial.

We must have a zero-movement field in all nodes.
