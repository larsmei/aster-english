# v1.01.511 ZZZZ511 – Basic Test for Completing Certain GC Features

**Summary:**

This test has no physical significance, it is a computer test. It is intended to test the completeness of certain features for the GC.

The features examined are:

> _ Assigning a temperature ELNO
> _ Assignment of nonzero ELNO anelastic deformation on elements 3D
> _ STAT_NON_LINE to make sure the prediction -> convergence in 1 iteration
> _ OBSERVATION in STAT_NON_LINE
> _ CALC_CHAMP / VARC_ELGA

The finished covered elements are: 3D, DKT, GRILLE_MEMBRANE, BARRE, DIS_T_N.

The load is a uniaxial (simple pull) in the y direction. The Movement is free in the other directions.

This documentation is deliberately succinct.
