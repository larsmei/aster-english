# v3.02.109 SSLP109 - Validation of a feature of the DDL_STAB option

**Summary:**

This test allows validation of a feature of DDL_STAB option CRIT_STAB, which evaluates the stability of steady state found by numerical simulation of non-conservative problems such as damage problems. This requires the application of an optimization algorithm under unequal constraints. The option can be applied to a list containing any degree of freedom available in *Code_Aster.*

## 1 Reference problem

### 1.1 Theoretical framework

In the case of a conservative problem, the stability of the equilibrium state is defined by the strict positivity of all the tangential operator's own values. This is written, in the case of a tangential $K$ symmetric operator:

$\underset{x}{\mathit{Min}}(\frac{{x}^{T}.\mathit{Kx}}{{x}^{T}.x})>0$

In the case of non-conservative problems, unilateral conditions of irreversibility are imposed on certain components of the $x$ vector. The previous inequality becomes sufficient but not necessary to deduce the stability of a state of equilibrium.

One of the features developed in the stress optimization algorithm is limited to the calculation of the smallest own value (quantity that is accessed quickly), when this is a positive sign. In this case, the reference value for the stability criterion is exactly that of the smallest own value, recalculated from the power method. No additional projection steps are performed to determine the exact value of the minimum under unequal constraints. This allows for a calculation time gain.

The test case presented here is an interest in a uniform tensile bar, whose behavior is purely elastic. The elastic character is conservative and ensures the strict positivity of the smallest tangential operator's own value. Therefore, we are in the precise case where the function described above is triggered.
