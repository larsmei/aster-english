# v4.01.006 TPLA06 - Cylindrical bar with convection

**Summary:**

This test is based on independent validation of version 3 in linear steady-state thermal analysis.

This is a 2D axisymmetric problem represented by two modellings, the first using elements density, the second of elements 2D axisymmetric.

Boundary conditions in temperature imposed and convection are taken into account.

The results from this test case are compared with those provided by VPCS.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The reference solution is the one given in the TPLA06/89 plug of the VPCS guide

![Figure](/figures/v4.01.006/100000000000015A0000008111AA19A0D1229856.png)

- Temperature as $z$: $T(z)={T}_{1}\frac{\sinh(\mathrm{az})}{\sinh(\mathrm{aL})}$ where $a=\sqrt{(\frac{\mathrm{2h}}{\lambda r})}$
- $T(z=0)=0$ $T(z=L)={T}_{1}$ .

### 2.2 Baseline

Temperature in $z=0.,0.1,0.2,\mathrm{...},0.8,0.9,1.0$

### 2.3 Uncertainty about the solution

$<1\text{\%}$

Analytical solution approached (approximation: $T=\mathrm{cte}$ , for all $r$ )

### 2.4 Bibliographical references

1. Guide de validation des computaux de computation de structures. Société Française des Mécaniciens, AFNOR 1990 ISBN 2-12-486611-7

## 5 Summary of the results

Modelling A, performed in 3D with linear mesh cells (PENTA15, HEXA8), gives results of which four values (out of 22) exceed the tolerance initially set. Maximum the difference obtained is 1.24% for a tolerance of 1%. This tolerance is observed for values of temperature close to 0.

By account B Modelling, performed in AXIS with linear mesh cells (TRIA3), gives satisfactory results, the difference maximum obtained is 0.25%.

AXIS Modelling is more appropriate to model this cylindrical bar than 3D Modelling. The 3D circumferential cutting is not dense enough to represent the cylinder, and a finer cutting would improve the results.

The results obtained by 3D modelling are considered acceptable given the mesh used.

The analytical solution, which is an approach solution, assumes that the $r/L$ ratio is much higher than 1. For this digital test, the $r/L$ ratio was taken equal to 100.
