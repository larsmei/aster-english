# u4.33.02 Operator CREA_TABLE

## 1 Purpose

Create a table.

This command makes it possible to create a table from a function or from lists (of integers, or reals, of character strings, of concepts) or else from a real field. The table created has at least two parameters and as many lines as the user wishes.

The lists used to generate the table must have the same number of terms, or else the numbers of the lines which one wishes to fill must be indicated.

The function used to fill the cells of the table is tabulated, which means that it is known only at certain points. It will have to be defined beforehand in the command file by means of the command DEFI_FONCTION.

The concept created by this operator is of type table.

## 3 Operands

### 3.1 Keyword FONCTION

#### 3.1.1 Operand FONCTION

The table is created from a function. The first column of the table contains the abscissae of the function and the second the values of the function at the corresponding abscissae.

#### 3.1.2 Operand PARA

Names of the parameters of the table. This keyword is optional: the names of the parameters are then identical to the NOM_PARA and NOM_RESU of the function. If it is supplied, its cardinality must be equal to 2: parameter name for the column associated with the abscissae, parameter name for the column associated with the ordinates.

### 3.2 Keyword LISTE

This keyword must be supplied at least twice: each occurrence makes it possible to define a column of the table.

The lists do not necessarily have the same cardinality; the keyword NUME_LIGN is used to indicate which lines must be filled.

#### 3.2.1 Operand LISTE_R

A column is created in the table from a list of reals.

#### 3.2.2 Operand LISTE_I

A column is created in the table from a list of integers.

#### 3.2.3 Operand LISTE_K

A column is created in the table from a list of character strings.

#### 3.2.4 Operand TYPE_K

Length of the character strings for the case LISTE_K.

#### 3.2.5 Operand LISTE_CO

This operand makes it possible to define a list of concepts. The table created from a list of concepts is necessarily a table of type TABLE_CONTENEUR. The list of concepts is used to create two columns of the table: a column with parameter NOM_SD and a column with parameter TYPE_OBJET.

If the operand LISTE_CO is supplied, the user must also define a column with parameter NOM_OBJET containing a unique key for each concept of the list of concepts.

#### 3.2.6 Operand NUME_LIGN

When the lists do not all have the same cardinality, or in order to build a table with holes, this keyword is used to specify which lines are filled.

#### 3.2.7 Operand PARA

Name of the parameter of the table associated with the list supplied.

### 3.3 Keyword RESU

This keyword must be used only once. It makes it possible to create a table from the components of an isolated field (keyword CHAM_GD) or from the fields of a result data structure (keyword RESULTAT). The fields processed must have real values.

#### 3.3.1 Operand CHAM_GD

This operand makes it possible to collect the name of the field which will be read in order to create the table. This field may come for example from the command CREA_CHAMP.

#### 3.3.2 Operands RESULTAT/NOM_CHAM/TOUT_ORDRE/NUME_ORDRE/LIST_ORDRE /INST/LIST_INST/MODE/LIST_MODE/FREQ/LIST_FREQ/CRITERE/PRECISION

These operands make it possible to choose the fields of the result data structure to be processed. One may limit the order numbers with the keywords INST, LIST_INST, … as well as the names of the fields ('DEPL', 'SIEF_ELGA', …) with the keyword NOM_CHAM.

For more information concerning these keywords, please consult the document [U4.71.00](doc:u4.71.00)

#### 3.3.3 Operand INTITULE

This operand makes it possible to overload the name of the RESULTAT or of the CHAM_GD in the table. By default, the name of the user variable is taken.

#### 3.3.4 Operands TOUT_CMP/NOM_CMP/NOM_VARI

These operands make it possible to choose the components which one wishes to see in the table.

Either one uses TOUT_CMP='OUI' in order to choose all the components of the field, or one uses NOM_CMP or NOM_VARI in order to retain only some of them.

> ◊    NOM_CMP =        nocmp,                        [Kn]
> Name of the component which one wishes to see in the table.
> ◊    NOM_VARI=        novari,                    [Kn]

For the fields of internal variables (VARI_*), one may give the name of the internal variable which one wishes to see in the table (see [U4.51.11](doc:u4.51.11) for the rules for naming the internal variables).

#### 3.3.5 Operands TOUT/GROUP_MA/GROUP_NO

These operands make it possible to choose the entities of the mesh on which the values of the components of the field will be recovered.

The operand TOUT ='OUI' makes it possible to consider the whole mesh.

In order to restrict a part of the mesh, the remaining operands must be used.

For a field of type:

    - NOEU: one may choose GROUP_MA and/or GROUP_NO.
    - ELNO/ELGA: one may choose GROUP_MA.

### 3.4 Operand TYPE_TABLE

Determines the type of the table produced. The choices are:

- TABLE: an ordinary table
- TABLE_FONCTION: a table which contains a column whose parameter is FONCTION or FONCTION_C, in which one finds names of fonction concepts.

### 3.5 Operand TITRE

Title which will be given to the table produced.

## 4 Examples

### 4.1 Creation of a table from a function

FCT=DEFI_FONCTION(NOM_PARA='X',

VALE=(0.0,5.0,4.0,17.5)) ;

T_FCT=CREA_TABLE(FONCTION=_F(FONCTION=FCT));

IMPR_TABLE(TABLE=T_FCT) ;

The printout of the table created is as follows:

X TOUTRESU

0.00000E+00 5.00000E+00

4.00000E+00 1.75000E+01

### 4.2 Creation of a table from three lists, of heterogeneous types

T_LST=CREA_TABLE(LISTE=(

_F(LISTE_R=(0.0,4.0),PARA='X'),

_F(LISTE_R =(5.0,17.5),PARA='Y') ,);

_F(LISTE_I =(6.7),PARA='K')

IMPR_TABLE(TABLE=T_LST) ;

The printout of the table created is as follows:

X Y K

0.00000E+00 5.00000E+00 6

4.00000E+00 1.75000E+01 7

### 4.3 Creation of a table with holes

```text
    TAB=CREA_TABLE(
LISTE=(
_F(    PARA='NUME_ORDRE',
LISTE_I=(8,15,156,67),
),
_F(    PARA='VAR',
LISTE_R=(2.,15.,18),
NUME_LIGN=(1,3,4),
),
_F(    PARA='COMMENT',
LISTE_K=('VALEUR',),
TYPE_K='K24',
NUME_LIGNE=1,
),
),

L'impression de la table créée est la suivante:

NUME_ORDRE VAR                COMMENT

8 2.00000E+00    VALEUR

15 –                -

156 1.50000E+01    -

67 1.80000E+01    -
```
