# v6.04.504 SSNV504 - Extrusion of a lopin

**Summary:**

This test simulates the extrudion (without friction) of a lopin, a case frequently encountered in industrial shaping studies. The advantage of this test is mainly to validate the "passage" of geometric singularities (acute angles and obtus) and to test the consideration of two contact zones (multi-zone contact).

The modellings retained are:

| Modelling A(AXIS): | CONTACT node mesh cell, associated with mesh cells SEG2, |
| --- | --- |
| Modelization B(3D): | CONTACT node mesh cell, associated with mesh cells QUAD4, |
| Modelling C(AXIS): | CONTACT node mesh cell GLISSIERE, associated with mesh cells SEG2, |
| Modelling D(AXIS): | CONTACT, CONTINUE method associated with mesh cells SEG2, |
| Modelling E(AXIS): | CONTACT node mesh cell GLISSIERE, associated with mesh cells SEG3, |
| Modelling F(3D): | CONTACT node mesh cell GLISSIERE, associated with mesh cells QUAD4, |
| Modelling G(3D): | CONTACT node mesh cell GLISSIERE, associated with mesh cells QUAD8, |
| Modelling H(2D): | CONTACT, CONTINUE method associated with SEG3, |
| Modelling I(AXIS): | CONTACTGLISSIERE, CONTINUE method associated with SEG3, |
| Modelling J(AXIS): | CONTACTGLISSIERE, CONTINUE method associated with QUAD4 |
| Modelling K (AXIS): | Same as J: ALGO_CONT=STANDARD+PENALISATION Modelling |

The modellings with GLISSIERE allows to maintain contact throughout the extrusion in a mathematical way. The result is physically close to the Modelling without a slide, since it is an extrusion without friction.

## 14 Summary of the results

Both modellings (axisymmetric and $\mathrm{3D}$) pass without problems. Convergence is fast. The results between AXIS Modelling and 3D Modelling are similar.

Similarly, CONTRAINTE and CONTINUE methods also give satisfactory results. In this example, the CONTINUE method seems to converge faster than CONTRAINTE, especially in 3D with GLISSIERE.

For the particular case of the slide contact: Modelling C is then taken as a reference. By the CONTINUE method, solutions are obtained close to these reference values, with usually a lower number of iterations.
