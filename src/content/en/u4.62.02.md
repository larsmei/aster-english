# u4.62.02 Operator DEPL_INTERNE

## 1 Purpose

Compute the field inside a macro-element. Two situations may exist: the macro-element was obtained by *static substructuring*, or the macro-element was obtained by condensation of the measurement for a *structural modification* analysis (see U4.62.01).

In the case of a static substructure: the result of the command is a displacement field (cham_no) on the mesh associated with the macro-element (that is, the lower-level mesh). One can repeat this operation down to the lowest-level meshes (those which contain the finite elements).

This step may be regarded as a post-processing on the macro-element. It can be carried out only after the global solution. The field thus computed can then be used by the operator CALC_CHAMP (or other operators) to compute the stresses, ....

When a macro-element has given rise to several substructures, the displacement fields in these substructures are recovered on the mesh underlying the macro-element. There is therefore a change of frame of the displacement field if the substructure has been rotated.

If the substructure has been rotated by $+\alpha$ , the displacement field is rotated by $-\alpha$ .

This displacement field is then consistent with the mesh and one can chain the post-processings: computation of the stresses, ...

In the case where the macro-element is obtained by condensation of the measurement for a structural-modification analysis, the result of the command is a data structure of type resultat (evol_elas, dyna_trans, dyna_harmo, mode_meca) on the sensor mesh (measurement points). In this data structure the displacement fields corresponding to NOM_CHAM = ‘DEPL’ are computed.

## 2 Syntax

```text
/ cham_no
/ mode_meca_c
/ dyna_trans
/ dyna_harmo
/ evol_elas
/ mode_meca = DEPL_INTERNE(
    ◆ DEPL_GLOBAL = cham_no / dyna_trans / mode_meca / dyna_harmo / evol_elas / mode_meca_c,
    ◆ SUPER_MAILLE = ma,
    ◇ NOM_CAS = text (défaut: " "),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand DEPL_GLOBAL

```text
♦    DEPL_GLOBAL = ug
```

In the case where the macro-element is obtained by static substructuring:

ug is the name of the displacement field obtained during the solution at the global level on the macro-element.

In the case where the macro-element is obtained by condensation of the measurement for a structural-modification analysis:

ug is the name of the data structure of type resultat obtained during an analysis on the coupled model (global level). In this data structure, one uses, for each order number, the (displacement) field corresponding to NOM_CHAM=’DEPL’.

### 3.2 Operand SUPER_MAILLE

```text
♦    SUPER_MAILLE = mail
```

One gives here the name of the super-mesh cell which supports the substructure (cf. operator DEFI_MAILLAGE [U4.23.01](doc:u4.23.01)).

### 3.3 Operand NOM_CAS

```text
◊    NOM_CAS = nocas
```

nocas is the name of the load case corresponding to ug. This datum is indispensable if there exists a distributed loading on the substructure. It is up to the user to make sure that the field ug does indeed correspond to the load case nocas.

The possible load-case names are those defined in the macro-element; that is, those given via the keyword CAS_CHARGE/NOM_CAS of the commands MACR_ELEM_STAT and MACR_ELEM_DYNA.

If nocas = ' ', the displacement field was computed without distributed loading on the substructure.

This operand is not used if the macro-element is obtained by condensation of the measurement.
