# v5.01.100 SDND100 - Drop frictional slider with Coulomb friction

**Summary**

The one-way system with a degree of freedom consisting of a frictional contact mass on a rigid plane and a spring attaching to a fixed point is considered. The mass is released in an initial unbalanced position. It oscillates until complete stop at the end of the a finite time.

The first two modellings are the transient response by modal recombination of the frictional slider, the third is the direct transient response, and the three calculations are compared with the analytical solution.

Modellings A, B, D and F use DIS_CHOC behavior via DYNA_VIBRA operator, modellings C and G use DIS_CHOC behavior via DYNA_NON_LINE operator, and E Modelling uses DIS_CONTACT behavior via DYNA_NON_LINE operator.

## 2 reference solution

### 2.1 Calculation method used for reference solution

For a system without damping, the differential equation to be solved shall be written:

$$
\lbrace \begin{array}{}m\ddot{r}+kr=\mu \mid {F}_{n}\mid \\ r(t=0)={r}_{0}\ge 0\\ \dot{r}(t=0)=0\end{array}
$$

[bib1] The differential equation solution is shown to be:

$r(t)=\frac{\mu |{F}_{n}|}{k}+\left({r}_{0}-\frac{\mu |{F}_{n}|}{k}\right)\cos({\omega}_{0}t)$ with ${\omega}_{0}=\sqrt{\frac{k}{m}}$

The amplitude of the extrema, which comes from all ${t}_{n+1}=\frac{n\pi }{{\omega}_{0}}$, obeys the following recurrence law:

$r({t}_{n+1})={(-1)}^{n}\left[{r}_{0}-\frac{\mu \mid {F}_{n}\mid }{k}\right]\cos{\omega}_{0}t$

with $n=1,2,\dots ,N$ such as $∣\frac{r({t}_{n+1})}{{r}_{0}}∣<\frac{\mu \mid {F}_{n}\mid }{k{r}_{0}}$

The movement stops when $∣\frac{r({t}_{n+1})}{{r}_{0}}∣<\frac{\mu \mid {F}_{n}\mid }{k{r}_{0}}$ at $r({t}_{n+1})$ position.

### 2.2 Baseline

$\theta =45°$ directional displacement values for the above $r({t}_{1}),r({t}_{2}),r({t}_{3}),\mathrm{...}$ speed change moments.

### 2.3 Uncertainty about the solution

analytical solution.

## 3 Modelling A

### 3.1 Modelling characteristics

In this Modelling, the DYNA_VIBRA operator (see [U4.53.03](doc:u4.53.03)) is used with the DIS_CHOC relationship. The integration scheme is DIFF_CENTRE.

A element of type DIS_T on an mesh cell POI1 is used to model the system.

Relationships between degrees of freedom are used to impose the movement to be unidirectional in the direction $\theta$:

```text
LIAISON_DDL = _F(NOEUD = (’NO1’,’NO1’),

DDL = (’DX’ ’DY’),

COEF_MULT = (0.707, -0.707),

COEF_IMPO = 0.)
```

A PLAN_Z (two parallel planes separated by a game) is used to simulate the slip plane. It is chosen to generate this $\mathrm{Oy}$ plane, i.e. NORM_OBST = (0., 1., 0.). The origin of the obstacle is ORIG_OBST = (0.,0.,1). The game still has to be defined which gives the half spacing between the planes.

For a plane reaction force to exist on the system, it must be slightly pushed into the plane obstacle of a distance $\delta n$ such as: ${F}_{n}={K}_{n}\cdot \delta n$ .

Like ${F}_{n}=\mathrm{mg}$, we have $\delta n=\mathrm{mg}/{K}_{n}$.

A stiffness normal $20N/m$ impact (stiffness fictional which only makes sense to generate a plane reaction force on the system) is considered, so $\delta n=0,5$ is given. The PLAN_Z obstacle is $Z=1$-original and the solid is $Z=0$; a $0,5m$ game will create a $\delta n=0,5m$ d where JEU: 0.5

Stiffness tangential shock: ${K}_{T}=400000N/m$: it is large in front of the stiffness of the oscillator so that the shutdown phase is modelled correctly.

Time step used for time integration: ${5.10}^{-4}\mathit{sec}$ .

## 5 Modelling C

### 5.1 Modelling characteristics

This Modelling corresponds to the direct transient response of frictional slider, modelled via mesh cell type POI1. DYNA_NON_LINE operator (see [U4.53.01](doc:u4.53.01)) is used with DIS_CHOC relationship. The integration scheme is HHT.

The normal direction of contact is the $X$ local axis which corresponds in the test case to the $Z$ global axis. The slip plane is the $(Y,Z)$ local plane, the $(X,Y)$ plane in the global reference point. Therefore, the element impact plane is oriented to a node, with the ORIENTATION key word of the AFFE_CARA_ELEM operator as follows:

ORIENTATION= _F( mesh cell=’EL1’, CARA: ’VECT_X_Y’ ,

VALE = ( 0., 0., -1., 0., 1., 0. ) )

In order to obtain a reaction force of the plane on the system, it must be slightly pushed into the plane obstacle of a distance $\delta n$ such as: ${F}_{n}={K}_{n}\cdot \delta n$ .

The reaction balances the weight of slider, so we have: ${F}_{n}=\mathrm{mg}$ i.e. $\delta n=\mathit{mg}/{K}_{n}$ .

A stiffness normal $20N/m$ impact (stiffness fictional which makes sense only to generate a plane reaction force on the system) is considered, so $\delta n=0,5$ dwhere DIST_1 = 0.5 is given.

The stiffness of tangential shock considered is ${K}_{T}=400000N/m$ , the Coulomb coefficient is 0.1.

The constitutive law impact is therefore defined in DEFI_MATERIAU as follows:

DIS_CONTACT =_F(RIGI_NOR = 20.0,

DIST_1 = 0.5,

RIGI_TAN = 400000.0,

COULOMB = 0.1)

${5.10}^{-4}s$ time step is used for time integration.

## 6 Modelling D

In this Modelling, the DYNA_VIBRA operator (see [U4.53.03](doc:u4.53.03)) is used with the DIS_CHOC relationship. The integration scheme is DEVOGE.

This Modelling is consistent with Modelling B, in which the unidirectional friction option is activated. The slider and the plane are considered to be two moving structures. Each structure is then modelled by an node and an element type POI1. The node $\mathrm{NO2}$ is supposed to be blocked, it materializes the friction plane. By default, the obstacle origin is located mid-distance from the nodes $\mathit{NO}1$ and $\mathit{NO}2$. The DIST_1 and DIST_2 parameters that represent the material thickness around the nodes impact still have to be defined.

Unidirectional friction implies that the friction coefficient n is more isotropic in the previously defined plane. It is 0following the axis indicated in NORM_OBST and $\mu$ in the perpendicular direction. For an $\theta$ angle of $\pi /2$, this corresponds to dividing the friction coefficient by $\sqrt{(2)}$ , compared to model B.

For a plane reaction force to exist on the system, it must be slightly pushed into the plane obstacle of a distance $\delta n$ such as: ${F}_{n}={K}_{n}\cdot \delta n$ .

Like ${F}_{n}=\mathit{mg}$, we have $\delta n=\mathit{mg}/{K}_{n}$.

Stiffness was considered to be normal $20N/m$ impact (stiffness fictional which makes sense only to generate a plane reaction force on the system), so $\delta n=0,5m$ is given. Knowing that both nodes $\mathit{NO}1$ and $\mathit{NO}2$ are geometrically confused, for example, DIST_1 = DIST_2 = $\delta n/2$ is chosen.

Stiffness tangential shock: ${K}_{T}=400000N/m$: it is large in front of the stiffness of the oscillator so that the shutdown phase is modelled correctly.

## 10 Summary of the results

The analytical solution of the friction problem is reproduced with very good precision ($\text{<0.5\%}$ ).

For modellings A, B, C, D, F and G, this requires the use of a rather high stiffness tangential parameter relative to the rigidity of the system and a relatively small time step integration.

For Modelling E, which uses an implicit constitutive law instead of penalization coefficients, the time step d'integration is between 10 and 50 times lower than the other modellings, the stiffness coefficient is that of the spring.
