# u3.14.09 Modelling 3D_ABSO

**Summary:**

This document describes, for the modelling 3D_ABSO:

- the degrees of freedom carried by the finite elements which support the modelling,
- the associated support mesh cells,
- the supported loadings,
- the non-linear possibilities,
- the test cases implementing the modellings.

The modelling 3D_ABSO (Phenomenon: mechanics) corresponds to finite elements whose support mesh cells are surface mesh cells. They make it possible to take into account the absorbing-boundary condition of solid volumes.

## 1 Discretisation

### 1.1 Degrees of freedom

| **Modelling** | **Degrees of freedom (at each vertex node)** |
| --- | --- |

| 3D_ABSO | DX: displacement along $X$ |
| --- | --- |
|  | DY: displacement along $Y$ |
|  | DZ: displacement along $Z$ |

### 1.2 Support mesh cells of the stiffness matrices

The support mesh cells of the finite elements may be quadrangles or triangles. The elements are isoparametric.

| **Modelling** | **Mesh cell** | **Interpolation** | **Remarks** |
| --- | --- | --- | --- |

| 3D_ABSO | TRIA3 | linear |  |
| --- | --- | --- | --- |
|  | TRIA6 | quadratic |  |
|  | QUAD4 | linear |  |
|  | QUAD8 QUAD9 | quadratic |  |

### 1.3 Support mesh cells of the loadings

The same as previously.

## 2 Supported loadings

The loading available is the following:

- **'ONDE_PLANE'**

Makes it possible to impose a seismic loading by plane wave.

## 3 Non-linear possibilities

### 3.1 Constitutive laws

The only constitutive relation, available under DYNA_NON_LINE, for this modelling, under COMPORTEMENT is the relation 'ELAS'.

### 3.2 Strains

Only the linearised strains, keyword 'PETIT' under DEFORMATION, are available.
