# v1.01.339 ZZZZ339 - Validation of G calculation with 3D initial stresses

**Summary:**

This test is used to validate that the initial stresses are well taken into account in the calculation of the energy return rate G in 3D. It has 2 modellings: A Modelling using classic elements (mesh crack) and B Modelling using elements X-FEM (non-mesh crack).

This test has no physical meaning (the initial constraints are not self-balanced) and is purely computer-oriented.

For a physical example of an initial state, the test case SSLP115 (2D) and SSLV116 (3D) can be referred to their associated documentation [V3.02.115](doc:v3.02.115) and [V3.04.116](doc:v3.04.116).

This documentation is deliberately succinct.
