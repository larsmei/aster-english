# v3.03.107 SSLS107 - Cylindrical panel subject to its own weight

**Summary:**

This test validates two elements thick shell finished linear elasticity. Modelling A tests the quadrangle, Modelling B tests the triangle associated with the formulation. This problem of cylindrical panel under clean weight is a classic shell test.

The reference results are analytical solutions.

The good results obtained with the quadrangle and the much less good results obtained with the triangle are noted.

## 5 Summary of the results

The element MEC3QU9H allows for a good solution with a coarse mesh, while the element MEC3TR7H requires a very fine mesh to achieve satisfactory accuracy.

It is noted that the reference solution is the analytical solution obtained from the "deep" hull theory. The 2 elements hull converges towards this solution and not towards the "deep" hull theory.
