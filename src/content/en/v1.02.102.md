# v1.02.102 SSEP002 - Limit load calculation of a elbow with sub-thickness

**Summary:**

In this test, the limit load of an elbow with under thickness is calculated.

The limit load is calculated in two different ways:

1. By a static approach that allows the calculation of the load that corresponds to the solution of free plastic flow. This approach allows to calculate from inside a minor of the limit load. Simply raise the value of ETA_PILOTAGE from the moment this value stabilizes.
2. By a kinematic approach regulated by the Norton-Hoff-Friaâ method, which uses incompressible elements. It is based on a static linear resolution and parametric control.

An post-processing with the POST_ELEM command allows to obtain the upper and lower terminal estimates of the limit load.

This test case is used to check the validity of the command files corresponding to the lower and upper limit load of both cases of an elbow with under-thickness. The sub-thickness is defined from the measurement points recorded on site.

Modelling A:

- Calculation of the lower limit load.

Modelling B:

- Calculation of the upper limit load.
