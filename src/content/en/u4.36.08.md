# u4.36.08 Macro-command IMPR_ACCE_SEISME

## 1 Purpose

This macro-command aims to automate the post-processing of the data coming from the command GENE_ACCE_SEISME. It carries out the following tasks:

- printing of one figure per accelerogram, that is, per direction and per draw;
- printing of one figure of all the accelerograms for each direction;
- computation of the velocities and then of the displacements of the signals;
- printing of one figure of all the displacements for each direction;
- printing of one figure containing the severity indicators for each direction;
- printing of a statistics table on the severity indicators;
- computation of the spectra of the signals and computation of the mean spectrum per direction;
- printing of one figure with the target spectrum and the mean spectrum per direction;
- printing of one figure containing all the spectra as well as the target spectrum and the mean spectrum per direction;
- computation of the plus and minus $\sigma$ spectra;
- printing of one figure with the plus and minus $\sigma$ spectra as well as the target $\sigma$ spectrum for each direction;
- correction of the mean spectrum (by a multiplicative factor) so that it is not lower than the target spectrum over a given frequency band for each direction;
- computation and printing, on a figure, of the geometric mean of the mean spectra in the vertical directions if the dimension of the problem is greater than or equal to 2.

The figures and tables are created in the REPE_OUT directory of the temporary execution directory [U4.12.03](doc:u4.12.03).

## 2 Syntax

```text
IMPR_ACCE_SEISME(
    ◆ TABLE = table,
    ◆ TITRE = text,
    ◇ NOCI_REFE = _F(
         ◆ | AMAX = float,
           | VMAX = float,
           | DMAX = float,
           | INTE_ARIAS = float,
           | DUREE_PHASE_FORTE = float,
           | VITE_ABSO_CUMU = float,
           | ACCE_SUR_VITE = float,
      ),
    ◇ DUREE = float,
    ◆ SPEC_OSCI = fonction,
    ◇ SPEC_1_SIGMA = fonction,
    ◇ LIST_FREQ = listr8,
    ◇ & FREQ_MIN = float,
      & FREQ_MAX = float,
    ◇ RATIO_HV = float,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

**This command uses XMGRACE, but this utility is not available in salome_meca; it must therefore be added on the execution machine.**

### 3.1 Keyword TABLE

This mandatory keyword makes it possible to provide the table coming from the operator GENE_ACCE_SEISME to be post-processed.

### 3.2 Keyword TITRE

This mandatory keyword makes it possible to define a title used in the various figures created.

### 3.3 Factor keyword NOCI_REFE

This factor keyword makes it possible to give reference values for the severity indicators. For each operand (AMAX, VMAX, DMAX, INTE_ARIAS, DUREE_PHASE_FORTE, VITE_ASBO_CUMU, ACCE_SUR_VITE), three values are to be supplied; they correspond to the mean and to the lower and upper bounds of the confidence interval.

### 3.4 Keyword DUREE

This optional keyword makes it possible to display the accelerograms over a duration shorter than the one computed. The value supplied must therefore be smaller than the total duration of the accelerograms.

### 3.5 Keyword SPEC_OSCI

This mandatory keyword makes it possible to provide the target spectrum. It appears on certain figures in order to be compared with the computed spectra. For more details, see [U4.36.04](doc:u4.36.04).

### 3.6 Keyword SPEC_1_SIGMA

This optional keyword makes it possible to provide the target $\sigma$ spectrum. If it is supplied, the plus and minus one $\sigma$ spectra are computed and printed with this target spectrum on a figure. For more details, see [U4.36.04](doc:u4.36.04).

### 3.7 Keyword LIST_FREQ

This optional keyword makes it possible to give the list of frequencies to be taken into account for the computation of the spectra.

### 3.8 Keywords FREQ_MIN and FREQ_MAX

These two optional keywords are to be supplied together. If they are present, one computes the multiplication factor required so that the mean spectrum of the accelerograms is not lower than the target spectrum, in the frequency range going from FREQ_MIN to FREQ_MAX.

### 3.9 Keyword RATIO_HV

In the case of a table containing data in the vertical direction (and therefore with three components), this keyword makes it possible to weight the various target spectra so that they are consistent with the data supplied.
