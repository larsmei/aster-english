# v3.01.005 SSLL05 – Bilame: clamped beams connected by an unformable element

**Summary:**

The linear elasticity static test is used to validate straight beam elements POU_D_T.

This test case concerns clamped beams connected by an unformable element.

Support reactions and bending moments and deflection are tested by comparing simulation results with reference solution AFNOR (ref. [1]) and those obtained with Pipestress software.
