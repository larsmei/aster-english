# v6.04.244 SSNV244 - constitutive law FLUA_PORO_BETON, ENDO_PORO_BETON, FLUA_ENDO_PORO et RGI_BETON

**Summary:**

This document presents tests to validate non-regression for constitutive laws FLUA_PORO_BETON, ENDO_PORO_BETON, FLUA_ENDO_PORO and RGI_BETON.

## 1 Reference problem

These tests are intended to validate the non-regression of the laws.

### 1.1 Geometry

The tests ss-back a single finite element cubic 8 nodes.

### 1.2 Ownership of materials

**Warning:** the material parameters used in these tests are not realistic. They are only used to test laws in a computer-based way, they should not be used in real calculations.

The material properties are specified in DEFI_MATERIAU with the names FLUA_PORO_BETON, ENDO_PORO_BETON, FLUA_ENDO_PORO and RGI_BETON.

### 1.3 boundary conditions

The perpendicular movements on three sides of the cube are blocked for all modellings.

External uniaxial loading is applied in the following modellings:

- Modelling A: $50\mathit{MPa}$
- Modelling C: $9\mathit{MPa}$
- Modelling D: $1\mathit{MPa}$
- Modelling E: $0,01\mathit{MPa}$

A forced displacement is applied in the following modellings:

- Modelling B:
- 1.Traction: ${\epsilon}_{xx}=2,0\times {10}^{-3}$
- 2.Close: ${\epsilon}_{xx}=0$
- 3.Traction: ${\epsilon}_{xx}=1,0\times {10}^{-3}$
- 4.Compression: ${\epsilon}_{xx}=-1,0\times {10}^{-3}$
- 5.Close: ${\epsilon}_{xx}=0$
- 6.Compression: ${\epsilon}_{xx}=-2,0\times {10}^{-3}$
- 7.Close: ${\epsilon}_{xx}=0$
- Modelling F:

  - 1.Traction: ${\epsilon}_{xx}=8,0\times {10}^{-5}$
