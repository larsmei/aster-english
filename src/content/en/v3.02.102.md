# v3.02.102 SSLP102 - energy release rate with thermal original state

**Summary**

This test allows the $G$ energy return rate to be calculated by theta method for a static mechanical problem in the presence of the initial thermal state on 4 different integrating crowns.

This test contains six modellings:

- Modelling A: Flat Deformations – constitutive law Linear Elastic – Initial State Provided via Pre-Deformation Loading
- Modelling B: Flat Deformations – constitutive law VMIS_ISOT_LINE in STAT_NON_LINE – Initial state supplied via pre-deformation loading
- Modelling C: Flat Deformations – constitutive law VMIS_ISOT_TRAC in STAT_NON_LINE – Initial state provided via pre-deformation loading
- Modelling D: Axi-symmetric – Linear elastic constitutive law– Initial state supplied via pre-deformation loading
- Modelling E: Axi-symmetric – constitutive law VMIS_ISOT_LINE in STAT_NON_LINE – Initial state supplied via pre-deformation loading
- Modelling F: Axi-symmetric – constitutive law VMIS_ISOT_TRAC in STAT_NON_LINE – Initial state supplied via pre-deformation loading
- Modelling G: Flat Deformations – constitutive law VMIS_ISOT_LINE in STAT_NON_LINE – Initial state supplied via pre-deformation loadings specified as a field
- H: Axi-symmetric Modelling – constitutive law VMIS_ISOT_LINE in STAT_NON_LINE – Initial state supplied via pre-deformation loadings specified as a field
- Modelling I: 3D– Linear elastic constitutive law – Initial state supplied via pre-deformation loading
- Modelling J: 3D – constitutive law VMIS_ISOT_LINE in STAT_NON_LINE – Initial state provided via pre-deformation loading
- K: 3D Modelling – constitutive law VMIS_ISOT_TRAC in STAT_NON_LINE – Initial state supplied via pre-deformation loading
- Modelling L: 3D– constitutive law VMIS_ISOT_TRAC in STAT_NON_LINE – Initial state supplied via pre-deformation loadings specified as a field
- Modelling M: Flat Deformations – constitutive law VMIS_ISOT_TRAC in STAT_NON_LINE – Initial state provided via a command variable *
- Modelling N: Flat Deformations – constitutive law VMIS_ISOT_TRAC in STAT_NON_LINE – Initial state provided via a command variable

### 1.3 Boundary conditions and loads

- Travel for $y=0$ and $y=H$: $v=0.$
- Travel for $x=l$: $u=0.$ for modellings A, B, C and G
- Pre-deformations: ${\varepsilon}_{xx}={\varepsilon}_{yy}={\varepsilon}_{zz}=f(x)$ for modellings A to L.
- Initial deformations imposed via the EPSA (anelastic deformation) control variable for modellings M and N.

For each model, two calculations are performed:

- a thermomechanical calculation
- a calculation with pre-deformations imposed for modellings A to L.
- an initial deformation calculation imposed via the EPSA (anelastic deformation) control variable for modellings M and N.

The thermal loading is defined by a linear function equal to -50 in $x=0$ and 50 in $x=l$.

The pre-deformations are defined by a linear function of $-{5.10}^{-4}$ in $x=0$ and ${5.10}^{-4}$ in $x=l$.

The EPSA control variable is determined by extracting the thermal deformations from the thermomechanical calculation.

It is noted that the deformation field generated by the thermal loading is identical to the pre-deformation field imposed.

## 2 reference solution

Since the thermal loading-induced deformation field is identical to the pre-deformation fields and the initial deformations imposed, the G calculated at the end of the thermal calculation constitutes a reference of type AUTRE_ASTER for G calculated at the end of the calculations with pre-deformations and deformations imposed.
