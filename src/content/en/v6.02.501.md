# v6.02.501 SSNL501 - clamped beam at both ends under uniform pressure

**Summary:**

This test represents a quasi-static calculation of an clamped beam subjected to uniform pressure, consisting of a perfectly plastic elastic material. This test allows the validation of the following modellings elements finished:

- DKT (TRIA3, QUAD4),
- COQUE_3D (TRIA7, QUAD9),
- POU_D_TGM (SEG2).

The limit pressure is compared to an analytical reference solution.

### 3.4 Remarks

In this analysis, a resolution technique of the type of displacement imposed ('DDL_IMPO') is used to find the solution. This method provides a load multiplier coefficient (‘ETA_PILOTAGE') for each displacement value imposed. The value of the load imposed in ‘AFFE_CHAR_MECA' is equal to the limit pressure, therefore the reference value of the parameter ‘ETA_PILOTAGE' is equal to 1.

The calculations were stopped when the value of the parameter ETA_PILOTAGE was stabilized.

The reference being taken in relation to the 50 elements beam solution, an improvement in the DKT TRIA3 results is observed when the mesh is refined.

## 8 Summary of the results

Concerning the evolution of normal displacement at the centre of the plate according to the steering parameter, it is observed that:

- modellings with quadrangles give better results, compared to mesh cells triangles.

The calculations were stopped when the value of the parameter ETA_PILOTAGE ss has stabilized, or when the calculation was no longer possible. Based on the meshes used, the results obtained are satisfactory. The errors observed are for the modellings:

- DKT:11.4% for mesh cell TRIA3 (A) and 9.9% for mesh cell QUAD4 (B),
- COQUE_3D: 16% for mesh cell TRIA7 (C) and 10.8% for mesh cell QUAD9 (D),
- POUT_D_TGM :9% (E).

But it is found that with a finer mesh at the ends and centre of the plate, where the plasticization appears, it is possible to minimize the error compared to the reference solution.
