# v2.08.013 FORMA13 - Practical work of the dynamic analysis training: dynamic substructure

**Summary:**

These tests correspond to the practical work of dynamic training of *Code_Aster,* for the "dynamic substructure" part.

This TP is based on the SICODYN research program.

A pump calculation compares CRAIG-BAMPTON substructure techniques and interface method with direct modal calculation.

## 1 Reference problem

### 1.1 Description of the problem

This TP is based on an international research program [1], seeking to determine uncertainties in the calculation of an industrial structure by comparing the results of different teams on the same equipment.

The objective of this Modelling is therefore to determine, by dynamic substructure, the first 10 eigenfrequencies of a pump used in a power plant. For the purposes of TP, the structure has been simplified.

First, we propose to use the most classic substructure technique: the CRAIG-BAMPTON method. Then, in a second step, the interface method is used.

[1] Sylvie Audebert, SICODYN international benchmark on dynamic analysis of structure assemblies: variability and numerical-experimental correlation on an industrial pump, Mechanics & Industries / Volume11 / Issue06 / November 2010 pp 439-451

## 2 Modelling A

### 2.1 Mesh

The mesh of the three parts of the pump is supplied, along with its complete mesh. After importing the meshes into SALOME-MECA, it will take the time to find the names of the groups needed for the data.

The mesh is made of elements 3S density elements plate DKT. The elements plate corresponds to a thickness of:

- $30\mathit{mm}$ for the bearing (group 'Pal_2D')
- $50\mathit{mm}$ for volute (group 'Vol_2D')
- $10\mathit{mm}$ for hose (group 'Vol_2D')

### 2.2 Command file Aster

The main steps of the calculation with *Aster* are, for each substructure, the usual steps of data set:

| Play mesh in MED(LIRE_MAILLAGE (‘FORMAT= |
| --- |
| Definition of the finished elements used (AFFE_MODELE). Modelling '3D' and 'DKT' |
| Definition and assignment of material (DEFI_MATERIAU and AFFE_MATERIAU). |
| Assigning the characteristics of the elements plate (AFFE_CARA_ELEM). |
| Assignment of boundary conditions (AFFE_CHAR_MECA). |

Then the construction of macro-elements, their assembly, the modal calculation of the assembly structure, the construction of the skeleton, the restitution of the modal calculation on the skeleton and, finally, the printing of the modes:

| Creating substructures (CREA_ELEM_SSD) |
| --- |
| Assembly of substructures (ASSE_ELEM_SSD) |
| Modal calculation (CALC_MODES) |
| Construction of the global mode visualization skeleton (DEFI_SQUELETTE) |
| Skeletal restitution (REST_SOUS_STRUC) |
| Print modes in MED format (IMPR_RESU) |

The purpose is to specify when creating substructures the type of substructure to be used. Here we have:

TYPE='CLASSIQUE'

It is found that the frequencies calculated by the two methods are very close.

On the other hand, Craig & Bampton's classical dynamic substructure method is relatively expensive. In the next part, it is proposed to use the interface method. Although slightly more complex, by limiting the number of restraint modes between substructures, it significantly increases the efficiency of the substructure technique.
