# u4.91.11 Procedure IMPR_CO

## 1 Purpose

Print all the JEVEUX objects which constitute an existing concept.

This command is intended above all for "debugging". The content of the JEVEUX objects that one prints is in principle understandable only by developers equipped with their D documentation.

In particular, the format of these objects can change without consultation with the users. It is therefore very risky to use these writings in "post-processing" or in "chaining" to other codes.

## 2 Syntax

```text
IMPR_CO(
    ◇ UNITE = unit (défaut: 8),
    ◇ NIVEAU = / -1,
               / 0,
               / 1,
               / 2 (par défaut),
    ◇ ATTRIBUT = / "NON" (par défaut),
                 / "OUI",
    ◇ CONTENU = / "NON",
                / "OUI" (par défaut),
    ◇ BASE = / " ",
             / "G" (par défaut),
             / "V",
             / "L",
    ◆ / CONCEPT = _F(
           ◆ NOM = datastructure,
        ),
      / CHAINE = text,
      / TOUT = "OUI" (ou non renseigné),
    ◇ POSITION = int (défaut: 1),
    # Si: equal_to("NIVEAU", -1)
        ◇ PERMUTATION = / "NON",
                        / "OUI" (par défaut),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Factor keyword CONCEPT

```text
L'utilisateur indique derrière le mot clé NOM, la liste des concepts qu'il veut imprimer.
```

### 3.2 Operand TOUT = 'OUI'

```text
Permet d'imprimer tous les objets présents sur une base (ou sur toutes les bases). Attention, ces impressions peuvent être très volumineuses.
```

### 3.3 Operands CHAINE / POSITION

```text
/    ♦    CHAINE
```

The user can give a text (between "quotes") of length less than 24 characters: the command will then print all the objects having in their name the character string chain in position ipos (see keyword POSITION).

Examples:

```text
1)    CHAINE= 'TOTO1234'    , POSITION= 1
```

is equivalent to CO = TOTO1234

```text
2)    CHAINE= '.DESC'     ,    POSITION= 20 ,
```

makes it possible to print all the objects whose name ends with '.DESC'.

```text
◊    POSITION= ipos ,
```

This integer specifies the position of the start of the string to be sought in the name of the existing objects.

### 3.4 Operand ATTRIBUT

```text
◊    ATTRIBUT=
```

One can choose to print (or not) the attributes of the selected JEVEUX objects.

### 3.5 Operand CONTENU

```text
◊    CONTENU=
```

One can choose to print (or not) the content of the selected objects.

### 3.6 Operand BASE

```text
◊    BASE= base
```

One will print only the JEVEUX objects found on the base base. If one wants to obtain the objects located on the set of the bases ('G' and 'V'), one will use BASE = ' ' ("blank" character).

### 3.7 Operand NIVEAU

```text
◊    NIVEAU=
```

0: only the names of the objects are printed,

1: one prints only the first 5 objects of each collection of JEVEUX objects,

2: one prints everything.

-1: One prints for each object a single line containing:

      - the name of the object
      - a few characteristics: LONMAX, LONUTI, TYPE
      - a number (SOMMI or SOMMR) which "summarises" the whole of the object.

These printouts make it possible for example to help compare 2 different versions of the code. For this:

        - Add at the end of the command file: IMPR_CO(TOUT='OUI', NIVEAU=-1)
        - "run" the 2 versions of the code with this set of commands
        - do a "diff" of the 2 result files produced.

### 3.8 Operand PERMUTATION

```text
◊    PERMUTATION=    /    'OUI',        [DEFAUT]
/    'NON'
```

This keyword can be present only when NIVEAU = -1. It makes it possible to make the numbers SOMMI or SOMMR (mentioned in the paragraph of the operand NIVEAU) depend on the order in which the elements of the object are arranged.

- 'OUI': SOMMI or SOMMR will depend on this order
- 'NON': SOMMI or SOMMR will not depend on this order

### 3.9 Operand UNITE

```text
◊    UNITE=
```

Logical unit number associated with the file on which the selected objects must be printed.

By default, the printout is carried out on the unit which is associated with the file fort.8.

## 4 Examples

Example 1

```text
IMPR_CO (CONCEPT= _F(NOM=(ma, mo, ch1 )))
```

Printout of the concepts: ma, mo, ch1. The attributes of the objects will not be written.

Example 2

```text
IMPR_CO(CHAINE= '&', POSITION= 1,    NIVEAU= 0,    BASE= ‘V’, )
```

Printout of the names of the objects of the volatile database beginning with '&'.
