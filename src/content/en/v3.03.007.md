# v3.03.007 SSLS07 - Slim Cylinder Under Uniform Axial Load

**Summary:**

This VPCS (SSLS 07/89) test is designed to validate a linear loading (FORCE_POUTRE) in axisymmetric Modelling.

This will be done by using the 2 commands: AFFE_CHAR_MECA (modelling A) and AFFE_CHAR_MECA_F (modelling B).

## 2 reference solution

### 2.1 Calculation method used for reference solution

Axial constraint: ${\sigma}_{11}=\frac{q}{h}$

Circumferential constraint: ${\sigma}_{22}=0$

Cylinder extension: ${U}_{x}=\frac{\mathrm{qL}}{\mathrm{Eh}}$

Radial displacement: ${U}_{r}=-\frac{q\nu {R}_{0}}{\mathrm{Eh}}$

### 2.2 Baseline

${\sigma}_{11}=5\times {10}^{5}\mathrm{Pa}$

${U}_{x}=9.52\times {10}^{-6}m$

${U}_{r}=–7.14\times {10}^{-7}m$

### 2.3 Uncertainty about the solution

analytical solution.
