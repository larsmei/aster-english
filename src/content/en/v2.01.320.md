# v2.01.320 SDLD320 - Transient response of a free system of 3 masses and 2 springs under harmonic excitation

**Summary:**

The transient analysis of a discrete linear mass/spring system with three degrees of freedom is considered to be completely free. This system has non-proportional damping. Sine-like excitation is applied to one end of the system.

In this problem, a discrete model tests the calculation of the transient response of a system whose rigid modes are not fixed.The only interest is in the transient regime, and this will be the solution by integrating it on the complete modal basis.

The results obtained (moving, speed and acceleration) are compared with an average of results from industrial codes and an improved $\beta$ -Newmark digital integration method.

## 4 Summary of the results

- To obtain a good accuracy of the results, it is first necessary to obtain a precise and perfectly orthogonal modal base (CALC_MODES):

|  | avoiding multiple modes (different rigidity on unexcited degrees of freedom), |
| --- | --- |
|  |  |
|  | by correctly calculating rigid body modes (refer 'CENTRE' option in CALC_MODES to other options), |
|  |  |
|  | specifying the 'JACOBI' method(in the factor keyword SOLVEUR_MODAL) for complete modal extraction. |

- The accuracy of the results is good for both displacement and acceleration.

For the elastic system response (relative displacements ${u}_{3}-{u}_{1}$), the numerical accuracy is slightly less good due to the numerical cumulation of errors on absolute values.
