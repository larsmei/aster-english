# v6.08.105 SSND105 - constitutive law visco-elastic-plastic with memory effect

**Summary:**

The problem is quasi-static non-linear in structural mechanics. The tested laws, VMIS_CIN2_MEMO and VISC_CIN2_MEMO, are laws with non-linear kinematic nutring, isotropic nutring, and maximum nutring memory. The response is analyzed in a material point, with pre-hardening, then cyclic loading.

Modelling A allows the memory effect to be validated with VMIS_CIN2_MEMO in a case where the hardening is purely isotropic, for simple traction. The reference solution for this Modelling is analytical.

Model B compares the results obtained with memory effect, and without memory effect between the VISC_CIN2_MEMO and VISCOCHAB laws, for a cyclic loading with pre-hardening.

Modelling C is similar to Modelling B, and allows to validate both models in axisymmetric.

Modelling D is similar to Modelling C, and allows verification that models that can take into account the effect of non-proportionality in this case give results identical to previous models.
