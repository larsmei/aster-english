# v1.04.102 GCPC002 - 3D cracked prism test

**Summary:**

This test case elastic calculation is a result of an industrial problem. It allows to qualify the GCPC solver with different preconditioners.

The reference values are derived from a calculation performed on the mesh with the PERMAS code.

The test has 3 modellings on the same Reference problem: 3D Modelling of a quarter of prismatic test piece cracked in 4784 pentahedrons at 15 nodes and 598 hexahedrons at 20 nodes, i.e. 16565 nodes.

**In previous versions, this test case was named SSLV103 and YYYY104.**
