# u4.90.01 Macro-command CALC_ESSAI

## 1 Purpose

Launching of the macro-command CALC_ESSAI, which makes it possible to launch identification and expansion analyses on wire structures and to launch structural-modification analyses:

- expansion of experimental data on a basis of numerical mode shapes, using the macro-command MACRO_EXPANS (which carries out the elementary operations EXTR_MODE, PROJ_MESU_MODAL, REST_GENE_PHYS and PROJ_CHAMP),
- identification of forces on an arbitrary structure, with decomposition of the motion on a modal basis and a priori localisation of the loadings,
- structural modification: assess the effect of a modification, knowing the experimental modal model of the initial structure and the finite-element model of the modification introduced

## 3 Introduction

The macro-command CALC_ESSAI makes it possible to carry out identification analyses from measured data: expansion of experimental data onto a numerical model, force identification, and structural modification.

## 4 Use of modal expansion (EXPANSION)

The way this option is used is not very relevant; it is mainly useful for validation. If one wishes to carry out a modal expansion, it is preferable to use the command MACRO_EXPANS directly, or the sequence PROJ_MESU_MODAL, REST_GENE_PHYS and PROJ_CHAMP.

### 4.1 Keywords MESURE and NUME_MODE_MESURE

♦ MESURE = mesure,

Concept sd_resultat of type mode_meca or dyna_harmo which contains the modes to be expanded onto the numerical model.

♦ NUME_MODE_MESURE = L_I,

Makes it possible to select the order numbers of the modes that one wishes to expand.

### 4.2 Keyword CALCUL

♦ CALCUL = calcul,

Concept sd_resultat of type mode_meca which will be the expansion basis. The choice of the expansion basis is important for the quality of the results.

♦ NUME_MODE_CALCUL = L_I,

Makes it possible to select the order numbers of the modes that one wishes to use in the expansion basis. It is more useful to keep only the modes that «resemble» the shapes to be expanded, the resemblance criterion being obtainable by a MAC analysis.

### 4.3 Keywords RESOLUTION and EPS

The expansion consists in solving an inverse problem in order to determine the generalised coefficients of PROJ_MESU_MODAL. The inversion methods and regularisation coefficients are detailed in the user's documentation of this operator (cf [U4.73.01](doc:u4.73.01)).

## 5 Structural modification (MODIFSTRUCT)

This structural-modification technique is based on the substructuring method. The first substructure corresponds to the initial structure and the second substructure corresponds to the modification introduced.

The initial structure is modelled from the eigenmodes identified experimentally. The second substructure is modelled numerically by finite elements. Except in very particular cases, the measurement points are not located at the interface between the initial structure and the modification. It is therefore necessary to go through an intermediate step which consists in carrying out an expansion of the measurement onto the interface degrees of freedom. This expansion is done via the supporting numerical model. The following paragraphs describe the keywords required in CALC_ESSAI for this functionality.

More details on the method and on the principles of its implementation in Code_Aster are given in the documentation U2.07.03.

### 5.1 Keyword MESURE

```text
♦ MESURE = mesure                                    [mode_meca]
```

mesure is the name of the concept which contains the identified eigenmodes.

### 5.2 Keyword MODELE_SUP

```text
♦ MODELE_SUP = modele                                    [modele]
```

Name of the supporting model on which the expansion basis is built.

### 5.3 Keyword MODELE_MODIF

```text
♦ MODELE_MODIF = modele                                    [modele]
```

Name of the model of the modification introduced into the initial structure.

### 5.4 Keyword MATR_RIGI

```text
♦ MATR_RIGI = matrice,                                    [matr_asse]
```

Stiffness matrix defined on the supporting model, required for the analysis of the static modes.

### 5.5 Keyword RESOLUTION

```text
♦ RESOLUTION =    /’ES’,                                    [DEFAUT]
/'LMME'
```

This keyword makes it possible to choose the method used for the analysis of the expansion basis. ES corresponds to static expansion and LMME corresponds to «Local Model Modeshapes Expansion».

### 5.6 Keyword NUME_MODE_MESU

```text
♦ NUME_MODE_MESU = L_I,                                    [l_I]
```

This keyword makes it possible to select the numbers of the modes to be used among the identified eigenmodes. By default, all the eigenmodes of the concept mesure are taken into account.

### 5.7 Keyword NUME_MODE_CALCUL

```text
♦ NUME_MODE_CALCUL = L_I,                                [l_I]
```

This keyword makes it possible to select the numbers of the modes to be used among the vectors of the expansion basis. By default, all the vectors of the expansion basis are taken into account.

### 5.8 Keyword GROUP_NO_CAPTEURS

```text
◊ GROUP_NO_CAPTEURS = _F(    ♦    GROUP_NO = gr_no,    [mode_meca]
♦    NOM_CMP = nom_cmp,    [matr_asse]
```

This factor keyword makes it possible to select the list of node groups that will be used for the analysis of the static modes associated with the measurement points. These node groups are defined on the supporting model.

### 5.9 Keyword GROUP_NO_EXTERIEUR

```text
◊ GROUP_NO_EXTERIEUR = _F (    ♦    GROUP_NO = gr_no,    [mode_meca]
♦    NOM_CMP = nom_cmp,    [matr_asse]
```

This factor keyword makes it possible to define the «external» node groups on which the measured information will be condensed. These node groups must contain at least the interface between the supporting model and the model of the modification.

## 6 Identification of forces localised a priori (IDENTIFICATION)

### 6.1 Keyword INTE_SPEC

```text
♦    INTE_SPEC = intsp
```

Cross-spectrum that will be used as displacements, in order to recover the associated forces.

### 6.2 Keywords OBSERVABILITE and COMMANDABILITE

```text
♦    OBSERVABILITE = observ

♦    COMMANDABILITE = command
```

Concept of type mode_meca. They correspond respectively to the objects $C\Phi$ and ${\Phi}^{T}B$ described in section  6.4 . One may either choose a raw mode_meca, or build it with the operator OBSERVATION (U4.90.03).

### 6.3 Keywords ALPHA and EPS

```text
♦    ALPHA = reel

♦    EPS = reel
```

Regularisation parameters. More details in section  6.5 .

### 6.4 Reminder of the theoretical principles

Force identification assumes that the motion of the structure under study can be decomposed on a modal basis:

$y(\omega )=\left[C\Phi \right].{\left[Z(\omega )\right]}^{-1.}\left[{\Phi}^{T}B\right].f(\omega )$

In the following equations, the dependence on $\omega$ will be omitted. $\Phi$ is a basis of modal shapes associated with the structure under study. In theory, it is the basis of the continuous mode shapes. In practice, one generally uses a basis defined on a numerical model with a relatively fine discretisation. This basis may be computed numerically, or be the result of a modal expansion. The operator $C$ makes it possible to project this basis of mode shapes onto the subspace of the observable degrees of freedom.

The operator $B$ makes it possible to project the basis of mode shapes onto a set of degrees of freedom called actuators: one finds here one of the fundamental assumptions of the identification: **the identified forces are localised on degrees of freedom declared** **a priori**  by the user, as was done to declare the measurement degrees of freedom (use of the operator OBSERVATION). The aim is to reduce as far as possible the number of unknowns to be determined, which makes it possible to avoid the problems of under-determination of the problem.

Identifying the forces amounts to inverting the system above:

NB: the basis $\Phi$ may be different on the right and on the left of $Z$: this is the case when the available measurements are strains. The equation relating the force to the measurement is then written:

$f={\left[{\Phi}^{T}B\right]}^{-1.}\left[Z\right].{\left[C\Psi \right]}^{-1.}\epsilon$ ( 8-2)

where the matrix $\Psi$ is the data of the modes in strain. Warning, however: writing this last equation is an abuse of language, because the passage from displacements to strains should normally be written in the projection operator (which, let us recall, is linear in the case of small strains), and not by replacing $\Phi$ by $\Psi$. But in practice, one often imports a basis of modes $\Psi$ directly from the measurement software.

### 6.5 The concepts to be used

*Observability and controllability:*

The computation of $\left[C\Phi \right]$ is carried out in the panel «Definition of the observability concept», in which one gives the mode basis $\Phi$, and an experimental model that contains the degrees of freedom onto which it is projected. One chooses, among the degrees of freedom of the experimental model (grouped by node groups and mesh-cell groups), the degrees of freedom corresponding to the measurement. One can thus choose only a single direction if single-axis sensors were used during the measurement. It is also possible to carry out a change of frame. For more detail, refer to the documentation of the operator OBSERVATION (U4.90.03).

- **It is important that the nodes and the components declared in the cross-spectrum be consistent with the degrees of freedom of the observability concept**. In the case where the cross-spectrum is read by LIRE_INTE_SPEC (FORMAT = ‘IDEAS’), the nodes are defined in the header of each dataset; the table then created by this operator keeps the notations of that file.

The computation of $\left[{\Phi}^{T}B\right]$ is carried out in the panel «Definition of the controllability concept». The choice of the degrees of freedom and the potential changes of frame are made according to the same rule.

Each tab has a basis-selection button, which makes it possible, as for equation 8-2, to use two different bases.

*Regularisation:*

The inversion of the transfer function is carried out in two steps:

- inversion of $\left[C\Phi \right].{\left[Z\right]}^{-1}$, which makes it possible to compute the modal forces,
- inversion of $\left[{\Phi}^{T}B\right]$, which makes it possible to compute the forces on the physical basis.

These two steps are carried out by SVD (SVD of LinearAlgebra, a Python module, which calls a lapack_lite library, in the numpy package). It is possible to regularise the inversion in three ways:

1. truncation of the SVD (parameter $\varepsilon$),
2. Tikhonov regularisation (parameter $\alpha$),
3. slope control: it is possible to multiply the parameter $\alpha$ by ${(\omega -{\omega}_{i})}^{m}$, where ${\omega}_{i}$ is the natural circular frequency of the mode and $m$ a parameter to be determined; this makes it possible to control the slope of the curve obtained for the high frequencies, when the measured signal is strongly noisy at high frequency.
