# v3.04.320 SSLV320 - Flat spread of a 3D crack dividing and merging with X-FEM

**Summary:**

The objective of this test is to verify that the different crack propagation methods available in PROPA_FISS correctly manage a 3D crack bottom that is divided into several bottoms and several bottoms that merge into a single bottom during propagation. In addition, this test gives an example of how mesh (Homard) refinement is used with the PROPA_FISS operator.

## 1 Reference problem

### 1.1 Geometry

A $30\times 30\times 10\mathit{mm}$ size parallelepiped with three holes and a crack on one side is considered (Figure ).

![Figure](/figures/v3.04.320/100000000000040A000002F79AF1B444991D5FBE.png)

**Figure** 1.1-a **: geometry of the structure considered**

### 1.2 Material properties

No material is defined because the elements model is not solved.

### 1.3 Boundary conditions and loads

No boundary condition is defined because the elements model is not solved. Two propagations in mode I of the existing crack with constant displacement are calculated along the bottom. The crack remains flat during propagation.

Every step of propagation requires an advance equal to $\Delta a=12\mathit{mm}$. The bottom of the crack spreads while remaining always straight.

### 1.4 Initial conditions

The initial crack is a half-plane. Its length is equal to ${a}_{0}=4\mathit{mm}$. The bottom of the crack is straight.

## 2 reference solution

### 2.1 Method of calculation

At each propagation step the following two quantitiess will be calculated:

- the number of pieces that make up the bottom of the crack,
- the position of the crack.

Since the crack advance is identical for all points of the crack bottom, the expected value of these quantities can be calculated by hand (Figure ).

![Figure](/figures/v3.04.320/10000000000002D200000259B35436DCE18A8075.png)

**Figure** 2.1-a **: position of the bottom of the crack after each propagation step. The pieces that make up each bottom are also visible.**

### 2.2 Quantities and reference results

The number of pieces that make up each crack bottom is as follows (Figure ):

| **No propagation** | **Fissure** | **Number of pieces** |
| --- | --- | --- |
| 0 | ${\mathit{FISS}}_{0}$ | 1 |
| 1 | ${\mathit{FISS}}_{1}$ | 4 |
| 2 | ${\mathit{FISS}}_{2}$ | 1 |

The position of the crack at each propagation step is as follows (Figure ):

| **No propagation** | **Fissure** | **Length** |
| --- | --- | --- |
| 0 | ${\mathit{FISS}}_{0}$ | 4.0 |
| 1 | ${\mathit{FISS}}_{1}$ | 16.0 |
| 2 | ${\mathit{FISS}}_{2}$ | 28.0 |

## 3 Modelling A

### 3.1 Modelling characteristics

The **geometric method** of the PROPA_FISS operator is used to propagate the crack. The propagation calculation (update of the level sets) is done directly on the mesh of the structure, i.e. no auxiliary grid is used.

### 3.2 Mesh characteristics

The mesh is composed of 19464 elements of type TETRA4. The average edge length of the elements of mesh is $1.5\mathrm{mm}$.

## 7 Summary of the results

The different methods available in PROPA_FISS are able to calculate both the number of pieces and the position of each crack bottom. This shows that during propagation it is possible to simulate the separation of a bottom into several bases and the fusion of several bottoms into one bottom.
