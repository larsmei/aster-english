# u4.51.01 Operator MECA_STATIQUE

## 1 Purpose

Solve a linear static mechanical problem.

This operator makes it possible to solve either:

- a linear static mechanical problem with superposition of different boundary conditions and different loadings,
- a thermo-mechanical analysis for a given list of time instants.
- in this case the mechanical characteristics of the materials may depend on the temperature: the concept of type cham_mater must then be defined from functions (cf. operator DEFI_MATERIAU [U4.43.01](doc:u4.43.01) operand ELAS_FO),
- the expansion loading can be determined only if the expansion coefficient and the reference temperature have been defined (cf. operators DEFI_MATERIAU [U4.43.01](doc:u4.43.01) and AFFE_MATERIAU [U4.43.03](doc:u4.43.03)).

The concept produced by this operator is of type evol_elas containing one or more displacement fields at the various analysis time instants.

## 3 Operands

### 3.1 Operands MODELE / CHAM_MATER / CARA_ELEM

The arguments making it possible to compute the stiffness matrix (and the right-hand side) are supplied:

```text
♦    MODELE=    mo,
```

Name of the model whose elements are the subject of the mechanical analysis.

```text
♦    CHAM_MATER=    chmat,
```

Name of the material field.

```text
◊    CARA_ELEM=    carac,
```

Name of the characteristics of the structural elements (beam, shell, discrete elements, ...) if they are used in the model.

### 3.2 Keyword EXCIT

The boundary conditions and the loadings are defined here.

```text
◊    EXCIT=
```

This factor keyword makes it possible to define several concepts of type load, one per occurrence; the solution is computed by **superposing** the effects of the various applied loads.

#### 3.2.1 Operands CHARGE / FONC_MULT

```text
♦    CHARGE= char,
```

Name of a concept of type char_meca produced by AFFE_CHAR_MECA or AFFE_CHAR_MECA_F [U4.44.01](doc:u4.44.01) from the model mo.

One may also give the name of a “kinematic load” (type char_cine_meca), the result of the operators AFFE_CHAR_CINE and AFFE_CHAR_CINE_F [U4.44.03](doc:u4.44.03).

```text
◊  FONC_MULT= fmult,
```

Name of a concept of type fonction (or formula) which makes it possible to define, for each analysis time instant, a multiplying coefficient applied to the load char.

fmult is a function of time: by default it is a constant function equal to 1.

### 3.3 Keywords INST / LIST_INST

```text
◊    /    INST= tps,
```

Keyword used to carry out the analysis at a single time instant tps with the temperature corresponding to that time instant.

```text
/    LIST_INST= litps,
```

```text
◊    INST_FIN= tf,
```

The list litps produced by DEFI_LIST_REEL [U4.34.01](doc:u4.34.01) defines the time instants for which the analysis of a thermo-mechanical evolution is requested.

The keyword INST_FIN makes it possible to compute only the time instants earlier than or equal to tf.

This keyword (INST_FIN), combined with the keyword "RESULTAT" (re-entrant command), makes it possible to split a long thermo-mechanical transient.

One will, for example, write:

```text
resu = MECA_STATIQUE (...        LIST_INST = linst, INST_FIN = 10., ...)

MECA_STATIQUE (RESULTAT = resu,    LIST_INST = linst, INST_FIN = 20., ...)

MECA_STATIQUE (RESULTAT = resu,    LIST_INST = linst, INST_FIN = 30., …)
```

### 3.4 Keyword RESULTAT

In the case where one wishes to continue an analysis that has already been run, RESULTAT indicates which object is enriched. In this case, the command simply does not recompute the previous time instants already computed.

### 3.5 Factor keyword SOLVEUR

See [U4.50.01](doc:u4.50.01).

### 3.6 Operand OPTION

```text
◊    OPTION = / 'SANS'        / 'SIEF_ELGA'
```

By default the command MECA_STATIQUE computes the stresses at the Gauss points (or the generalised forces for the structural elements).

The other post-processing options will be computed a posteriori by the command CALC_CHAMP [U4.81.04](doc:u4.81.04).

If the user indicates OPTION = 'SANS', these stresses will not be computed and the data structure produced will be less bulky.

### 3.7 Operand INFO

```text
◊    INFO= 1,
```

Prints the main characteristics of the linear systems to be solved: number of unknowns, size of the matrix.

### 3.8 Operand TITRE

```text
◊    TITRE = titr,
```

Title that one wishes to give to the result [U4.03.01](doc:u4.03.01).

## 4 Examples of analyses

### 4.1 Static analysis with superposition of 2 load cases

```text
mest1 = MECA_STATIQUE (        MODELE= mo, CHAM_MATER= chmat,
CARA_ELEM= carac,
EXCIT= ( _F( CHARGE= ch1 , FONC_MULT= COS ),
_F( CHARGE= ch2 ),),)
```

### 4.2 Thermoelastic analysis at various time instants

```text
chmat = AFFE_MATERIAU (        ..., AFFE_VARC=_F(... EVOL=evoth ...) );

mest2 = MECA_STATIQUE (        MODELE= mo , CHAM_MATER= chmat ,
EXCIT= _F( CHARGE= bloq ),
LIST_INST= litps )
```

## 5 Note

For certain studies in linear elasticity for which the stiffness characteristics of the structure are independent of the thermal history and the kinematic boundary conditions are independent of the other loads, the deformed shapes for several loading cases can be determined by using MACRO_ELAS_MULT [U4.51.02](doc:u4.51.02).
