# v3.03.105 SSLS105 - Double-punched Hemisphere

**Summary:**

The case of the hemisphere is treated with double-pink linear elasticity, which allows the quality of the flat facets to be assessed for the representation of a deep hull.

The values tested are deflections at force application points.

There are 2 modellings:

- $A$ : elements DKT
- $B$ : elements de COQUE_3D en QUAD9

## 5 Summary of the results

Severe test that requires a fine mesh, especially for element DKT.

The results with element MEC3TR7H were not selected as a test because it is necessary to have many elements (1801) and therefore a much longer convergence time to obtain correct values compared to the other modellings ($>500s$ for a relative error of the order of $\text{4\%}$).

Results conform to reference solution.
