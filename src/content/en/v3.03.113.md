# v3.03.113 SSLS113 - Decommissioning homogenized plates

**Summary:**

This test allows to validate the excentre of plates with a ‘ELAS_COQUE' behavior.

The reference is given by an initial resolution in which an orthotropic bilayer is modelled with material nonsymmetry to the mean plane.

Validation is done in a second calculation where the behaviour of the previous plate is modelled by 2 excreted monolayer plates with a ‘ELAS_COQUE' behavior.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The reference solution comes from a first calculation with ASTER with the two-layer described in the Reference problem.

### 2.2 Baseline

They consist of the values of the field:

- Moving node $\mathit{N1}$ coordinates $(0,\mathrm{.0.},0.)$ (degree of freedom) and node $\mathrm{N10}$ coordinates $(0.216760,0.0764431,0.)$ ,
- Elastic energy on the mesh cell $\mathit{M5}$ .

### 2.3 Uncertainty about the solution

No one for travel, since it is a single calculation made by two different routes.

## 3 Modelling A

### 3.1 Modelling characteristics

The model consists of 2 plates corresponding to the mean plane of the 2 layers of the reference model.

To represent these 2 plates, we start from the mesh of the average plane of the bilayer that we excenter the distances $-0.05m$ and $0.05m$. The elements used are elements of DKT plate.

![Figure](/figures/v3.03.113/10000000000001E3000000F645F22D7AA1509166.png)

The ‘ELAS_COQUE' behavior is affected to each of these plates corresponding to the homogenized orthotropic behaviour of the corresponding layer.

The values of the material coefficients introduced under ‘ELAS_COQUE' were calculated directly [U4.43.01](doc:u4.43.01), page 27.

### 3.2 Mesh characteristics

The model has 87 nodes and 140 elements triangular DKT.
