# 1 **v3.04.321** SSLV321 - XFEM pre-conditioning validation for a shaved interface

**Summary:**

This test validates the pre-conditioner for elements XFEM quadratics. The problem is that of a 3D block cut by an XFEM interface. Multiaxial compression is applied to the entire block surface, including the XFEM interface. The expected analytical solution is a ${P}_{1}$ displacement within the domain. This solution is naturally captured by elements ${P}_{1}$ and ${P}_{2}$ Code_Aster.

When the interface passes near nodes mesh, the conditioning of the stiffness matrix increases [1,2]. The usual strategies, used in the Code_Aster (readjustment of the interface to nodes and removal of ddls Heaviside), based on "estimated" criteria, are not always adapted to control the conditioning and accuracy of the results [2]. These disadvantages are all the more penalising, with quadratic elements.

The new strategy (construction of a diagonal pre-conditioner by blocks) allows all these disadvantages to be overcome [3].

This test includes 5 modellings:

- $A$: HEXA8 $\mathrm{3D}$ Modelling with XFEM equation interface $x+y+z+0.01=0$
- $B$: HEXA20 $\mathrm{3D}$ Modelling with XFEM equation interface $x+y+z+0.1=0$
- $C$: HEXA20 $\mathrm{3D}$ Modelling with XFEM equation interface $x+y+z+0.01=0$
- $D$: HEXA8 $\mathrm{3D}$ Modelling with XFEM equation interface $x+y+z+0.011=0$
- $E$: HEXA8 $\mathrm{3D}$ Modelling with XFEM equation interface $x+y+z+0.011=0$

## 1 Reference problem en 3D

### 1.1 Geometry

The structure is a cubic domain, separated in two, by an oblique XFEM interface.

The length of each cube edge is: $L=4$ . The cube is centered in $(0,0)$ .

The interface position is: $x+y+z+\mathit{cte}=0$

The constant is adjusted to make the interface shave to a row of nodes of the mesh,

- for modellings $A$ and $C$ , the constant is $\mathit{cte}=0.01$ ,
- for $B$ Modelling, the constant is: $\mathit{cte}=0.1$ ,
- for modellings $D$ and $E$ , the constant is: $\mathit{cte}=0.011$

### 1.2 Material properties

Poisson's ratio: $\nu =0.3$

Young's modulus: $E={10}^{9}N/{m}^{2}$

### 1.3 Boundary conditions and loads

On each subdomain (on either side of the XFEM interface), a compression load is imposed. Indeed, the uniform pressure $p=-10\mathit{MPa}$ is applied on each side of the cube and on the XFEM interface.

Then, Dirichlet's boundary conditions are imposed, to fix the analytical solution moving and block the 12 rigid body movements.

*Recall* **:**

*When the XFEM interface cuts the entire structure and the two blocks are not in contact,* *all is as if there were two mechanical problems decoupled, in the presence of two solids. This therefore leads to a total of 12 rigid modes in the equivalent XFEM problem.*

So we select some nodes on either side of the interface to fix the moving solution:

- 3 nodes are blocked above the $\lbrace {\text{NS}}_{1},{\text{NS}}_{2},{\text{NS}}_{4}\rbrace$ interface

$\begin{array}{c}{\text{NS}}_{1}=\left(+2,+2,+2\right)\\ {\text{NS}}_{2}=\left(-2,+2,+2\right)\\ {\text{NS}}_{4}=\left(-2,-2,+2\right)\end{array}$

- 3 nodes are blocked below the $\lbrace {\text{NI}}_{1},{\text{NI}}_{2},{\text{NI}}_{4}\rbrace$ interface

$\begin{array}{c}{\text{NI}}_{1}=(-2,-2,-2)\\ {\text{NI}}_{2}=(+2,-2,-2)\\ {\text{NI}}_{4}=(+2,+2,-2)\end{array}$

Knowing that, the analytical solution on the move, is worth each point of the domain:

- ${U}_{x}(x,y,z)=\lbrace  \begin{array}{c}k\times x+2\text{si}x+y+z+\mathit{cte}>0\\ k\times x-2\text{si}x+y+z+\mathit{cte}\le 0\end{array}$
- ${U}_{y}(x,y,z)=\lbrace  \begin{array}{c}k\times y+2\text{si}x+y+z+\mathit{cte}>0\\ k\times y-2\text{si}x+y+z+\mathit{cte}\le 0\end{array}$
- ${U}_{z}(x,y,z)=\lbrace  \begin{array}{c}k\times z+2\text{si}x+y+z+\mathit{cte}>0\\ k\times z-2\text{si}x+y+z+\mathit{cte}\le 0\end{array}$

où, $k=-\frac{p(1-2\nu )}{E}={4.10}^{-3}$ .

## 2 reference solution

### 2.1 Calculation method used for reference solution

The analytical solution on the move, in the $(\overrightarrow{{e}_{x}},\overrightarrow{{e}_{y}},\overrightarrow{{e}_{z}})$ canonical base, is:

$U(x,y,z)=k\left\lbrace \begin{array}{c}x\\ y\\ z\end{array}\right\rbrace \pm 2$ où, $k=-\frac{p(1-2\nu )}{E}={4.10}^{-3}$ .

Subsequently, it is checked that this expression of the displacement field is the only solution of the equilibrium problem on both sides of the XFEM interface, i.e., that the proposed solution § 2.1 , respects the boundary conditions and assumptions of the HPP problem.

By construction, the moving solution checks the Dirichlet conditions of § 1.3.

The strain tensor is $\underline{\underline{\epsilon}}=\frac{1}{2}(\nabla U+\nabla {U}^{T})=\left[\begin{array}{ccc}k& 0& 0\\ 0& k& 0\\ 0& 0& k\end{array}\right]=kI$ .

Taking $k=0,4\text{\%}$ is consistent with the small disturbance hypothesis.

The Hooke law, for an isotropic material, is:

$\underline{\underline{\sigma}}=\frac{E}{1+\nu }(\underline{\underline{\epsilon}}+\frac{\nu}{1-2\nu }\mathit{Tr}(\underline{\underline{\epsilon}})I)=k\frac{E}{1-2\nu }I$

gold, by construction, on has: $k=-\frac{p(1-2\nu )}{E}$

with, $\underline{\underline{\sigma}}=-pI$ .

Finally, the limit conditions of Neumann to be imposed on the edges of the domain $-\underline{\underline{\sigma}}.\overrightarrow{n}=p$ , correspond well to the loading of § 1.3 .

Since the stress tensor is uniform, it respects the static equilibrium equation, $div\underline{\underline{\sigma}}=0$ .

### 2.2 Baseline

The maximum error on the movements at a few points on the $x+y+z+\mathit{cte}=0$ interface is tested. The displacement value at these points corresponds to the interpolation of the displacement field calculated by Aster. The displacement calculated by Aster is then compared to the analytical value of the displacement given in § 2.1:

$U(x,y,z)={4.10}^{-3}\left\lbrace \begin{array}{c}x\\ y\\ z\end{array}\right\rbrace +\mathit{sign}(x+y+z+\mathit{cte})\times 2$

## 3 Modelling A

### 3.1 Modelling characteristics

This is $\mathrm{3D}$ XFEM Modelling with linear elements.

This Modelling demonstrates the correct functioning of the "estimate" criteria with linear elements. The interface is positioned such that the interface readjustment threshold at 1% is reached: the interface is then modified and readjusted to the nearest nodes. This modification allows the conditioning to be controlled. On the other hand, the interface readjustment significantly degrades the quality of the results for linear elements (for quadratic elements, this readjustment is removed, to replace it with algebraic preconditioning).

The XFEM interface equation is: $x+y+z+0.01=0$ .

### 3.2 Mesh characteristics

Number of nodes: 125

Mesh: 64 mesh cells of type HEXA8

### 3.3 Tested quantities and results

The maximum error on the movement, in absolute value, along the XFEM interface is tested. A list of points on the interface is extracted, as well as the interpolated displacement field at these points.

As the displacement field is discontinuous, each point interface exists 2 analytical values of the displacement field ${U}^{+}\left(x,y,z\right)=\lbrace {U}_{1}^{+},{U}_{2}^{+},{U}_{3}^{+}\rbrace$ and ${U}^{-}\left(x,y,z\right)=\lbrace {U}_{1}^{-},{U}_{2}^{-},{U}_{3}^{-}\rbrace$ .These analytical values are compared to the interpolated displacement field in each point.

## 8 Summary of the results

This test validates the operation of pre-conditioning of Heaviside ddls for elements quadratic XFEM.

This pre-conditioning strategy is found to be more successful than the level-set readjustment with linear elements and the elimination of ddls by the rigidity criterion.

For quadratic elements, the pre-conditioner is essential to obtain a robust solution.
