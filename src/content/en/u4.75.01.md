# u4.75.01 Macro-command CALC_THERMECA_MULT

Purpose **:**

The macro-command CALC_THERMECA_MULT makes it possible to produce the thermal and linear mechanical results of an arbitrary thermal shock without systematically projecting the fields from a linear mesh onto a quadratic mesh, thanks to the multiplication of a single unit analysis. It implements a methodology for thermo-mechanical analyses in the linear domain.

This macro-command produces, as chosen, a concept of type *evol_elas* or *evol_ther*.

## 1 Syntax

```text
/ evol_elas
/ evol_ther = CALC_THERMECA_MULT(
    ◆ TEMP_FIN = float,
    ◆ TEMP_INIT = float,
    ◆ RESU_MECA_UNIT = evol_elas,
    ◆ RESU_SUPL_THER = / "OUI",
                       / "NON",
    # Si: equal_to('RESU_SUPL_THER', 'OUI')
        ◆ RESU_THER_UNIT = evol_ther,
        ◆ RESU_THER = co,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 2 General points

The objective of this macro-command is to determine the thermal and mechanical state of a structure following a thermal shock. By using linearity properties, it is possible to determine the solution of an arbitrary shock from an “other” shock, most often a unit shock. This approach has the advantage of computing the finite-element solutions only once for the unit shock, then of generating the solutions for the other shocks.

Since linearity properties are used, this operator is valid only for thermo-mechanical analyses in which the thermal analysis and the mechanical analysis are linear.

## 3 Operands and keywords

### 3.1 Operand TEMP_FIN

TEMP_CIBLE is a real giving the value of the temperature, different from the rest temperature, which creates the thermal shock. Typically, in the case where one studies a pipe periodically and rapidly traversed by a fluid at a non-ambient temperature, TEMP_FIN corresponds to the difference between the temperature of the fluid and the reference temperature TEMP_INIT of the pipe.

### 3.2 Operand TEMP_INIT

This is the **reference temperature** of the solid under study. In the model of this macro-command, it is **also** the temperature of the system **before** the thermal shock.

### 3.3 Operand RESU_SUPL_THER

Operand to be supplied as ‘OUI’ when the user wishes also to produce the linear thermal analysis of the thermal shock under study. The concept is then produced on the right-hand side of the macro-command in the keyword RESU_THER.

### 3.4 Operands RESU_MECA_UNIT and RESU_THER_UNIT

These are the result concepts of the unit analyses, mechanical and thermal respectively.

RESU_THER_UNIT is to be supplied only when one asks the macro-command for a thermal result (i.e. RESU_SUPL_THER = ‘OUI’).

### 3.5 Keyword RESU_THER

Contains the result concept produced on the right-hand side by the macro-command when one asks for it.
