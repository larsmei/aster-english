# v1.01.284 ZZZZ284 - Validation of CHAR_MECA_HYDR_R and CHAR_MECA_SECH_R options

**Summary:**

This test is a computer test. It validates the elementary calculations options CHAR_MECA_SECH_R and CHAR_MECA_HYDR_R by analogy with the CHAR_MECA_TEMP_R option

There is only one model (A).

## 1 Test principle

1. Some thermal calculation is performed, which leads to a temperature field.
2. This temperature field is used as a "source" of deformation:

- thermal: eps = + ALPHA * (TEMP - VALE_REF)
- hydration: eps = - B_ENDOGE * HYDR
- Drying: eps = + K_DESSIC * (SECH - VALE_REF)

**Notes:**

- *It is the same temperature field (* TEMP *) that plays the role of* TEMP *,* HYDR *and* SECH *.*
- *The coefficients* ALPHA *,* B_ENDOGE *,* K_DESSIC *,* TEMP_REF *and* VALE_REF *(temperature and drying) are chosen to obtain the same deformation.*

1. We solve 3 mechanical problems with the previous 3 loads. We have to get the same field of displacement for the 3 calculations.

## 2 reference solution

The first calculation (with temperature) gives the "reference" solution for the other two calculations.

The other two calculations validate CHAR_MECA_HYDR_R and CHAR_MECA_SECH_R.
