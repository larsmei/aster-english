# u4.72.06 Operator PROD_MATR_CHAM

## 1 Purpose

Carry out the product of a matrix by a vector.

The matrix is a data structure of type matr_asse: it has real or complex values, and is symmetric or non-symmetric. The vector is a data structure of type cham_no. It has real or complex values. One requires that the matrix and the vector both have real values or both have complex values (otherwise use beforehand the commands COMB_MATR_ASSE [U4.72.01](doc:u4.72.01) or CREA_CHAMP [U4.72.04](doc:u4.72.04)) and that they share the same numbering (see the command NUME_DDL [U4.61.11](doc:u4.61.11)).

Produces a concept of type cham_no.

## 2 Syntax

```text
cham_no = PROD_MATR_CHAM(
    ◆ MATR_ASSE = matr_asse_depl_c / matr_asse_temp_r / matr_asse_depl_r / matr_asse_pres_c,
    ◆ CHAM_NO = cham_no,
    ◇ TITRE = text,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Keyword MATR_ASSE

```text
♦    MATR_ASSE    =    m
```

Name of the matrix (concept matr_asse_* ) to be multiplied.

### 3.2 Keyword CHAM_NO

```text
♦    CHAM_NO    =    u
```

Name of the vector (concept cham_no) to be multiplied.

### 3.3 Keyword TITRE

```text
◊    TITRE        =    titr
```

Title that one wishes to give to the result.

## 4 Checks

- Check that the matrix and the vector to be multiplied both have real values or both have complex values.
- Consistency check: the operands of type matr_asse_* and of type cham_no must share the same numbering.

## 5 Example of use

Matrix–vector product:

```text
u_mv_1 =    PROD_MATR_CHAM    (    MATR_ASSE = mat_1,
CHAM_NO = u_1,
)
```

For example, one can use this command to create a right-hand-side vector coming from the product of the mass matrix and an acceleration vector obtained by the command DYNA_VIBRA. This right-hand-side vector can be used as a loading for a static analysis.
