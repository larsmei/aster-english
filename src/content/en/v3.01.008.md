# v3.01.008 SSLL08- Bi-articulated thin arc in flat bending

**Summary:**

The linear elasticity static test is used to validate straight beam elements POU_D_T.

This test case concerns a thin arc in flat bending.

The movements and rotations are tested by comparing simulation results with reference solution AFNOR (ref. [1]) and those obtained with Pipestress software.
