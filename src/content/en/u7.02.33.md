# u7.02.33 Operator LIRE_FORC_MISS

## 1 Purpose

Build an assembled vector projected onto a RITZ basis from a file of seismic soil forces computed by the MISS3D software. The resulting projected vector will be used by the harmonic analysis operator in generalised components DYNA_VIBRA [U4.53.03](doc:u4.53.03).

Produces a generalised-vector concept of type vect_asse_gene.

## 2 Syntax

```text
vect_asse_gene = LIRE_FORC_MISS(
    ◆ BASE = mode_meca,
    ◆ NUME_DDL_GENE = nume_ddl_gene,
    ◆ FREQ_EXTR = float,
    ◇ NOM_CMP = / "DX",
                / "DY",
                / "DZ",
    ◇ NOM_CHAM = / "DEPL" (par défaut),
                 / "VITE",
                 / "ACCE",
    ◇ NUME_CHAR = int,
    ◇ ISSF = / "NON" (par défaut),
             / "OUI",
    ◇ UNITE_RESU_FORC = unit (défaut: 30),
    ◇ NOM_RESU_FORC = text,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand BASE

```text
♦    BASE = ba
```

Concept of type mode_meca which contains the vectors defining the projection subspace.

### 3.2 Operand NUME_DDL_GENE

```text
♦    NUME_DDL_GENE = nu_gene
```

Generalised numbering built on the basis ba.

### 3.3 Operand FREQ_EXTR

```text
♦    FREQ_EXTR = freq
```

Real value of the extraction frequency of the seismic soil forces.

### 3.4 Operand UNITE_RESU_FORC

♦    UNITE_RESU_FORC= uresfor

Logical unit of the file of seismic soil forces computed previously by MISS3D with CALC_MISS in post-processing and supplied as input in the study profile.

### 3.5 Operand NOM_RESU_FORC

```text
♦    NOM_RESU_FORC= nresfor
```

Local name in the MISS3D study project of the file of seismic soil forces computed previously by MISS3D with CALC_MISS in post-processing. This comes into play, for example, in the case of point sources.

### 3.6 Operand ISSF

```text
♦    ISSF = / 'NON',                                                                                / 'OUI',
```

If 'OUI', the format specific to MISS3D studies in soil–structure–fluid interaction is taken into account, in accordance with this same keyword in CALC_MISS.

### 3.7 Operands NOM_CMP / NUME_CHAR

```text
♦    /    NOM_CMP = /    'DX',                                                                                /    'DY',
    /    'DZ',
```

Name of the component corresponding to a direction of the incident seismic field.

```text
/    NUME_CHAR = numec
```

In the case of inclined waves or of a point source, where NOM_RESU_FORC has been supplied with a local name of extension *'.f'*, the seismic field is defined by a loading number lying between 1 and 3 for the inclined seismic forces, and necessarily equal to 1 for a point source.

### 3.8 Operand NOM_CHAM

```text
♦    NOM_CHAM =     / 'DEPL',                                                                            / 'VITE',
/ 'ACCE',
```

Field name giving the nature of the imposed unit incident seismic field (for example 'ACCE' if a unit acceleration is imposed).
