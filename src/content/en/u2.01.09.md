# u2.01.09 Definition of an initial stress field and of an initial field of internal variables

> **Summary.**

It is explained how to build two of the fields which make up the initial state of a non-linear analysis (STAT_NON_LINE): the stress field and the field of internal variables.

- the components of the stress field have an "analytical" form (for example: state of a soil subjected to the "weight of the earth"),
- the components of the field of internal variables are non-zero constants.

In both cases, the solution consists in chaining a certain number of CREA_CHAMP commands.

For the stress field, the difficulty consists in evaluating the "analytical formulae" (OPERATION='EVAL').

For the field of internal variables, the difficulty comes from the fact that the quantity associated with the internal variables (VARI_R) has an a priori undetermined number of components: 'V1', 'V2', ...

The solutions proposed are implemented in the test zzzz130A.

The test zzzz130b shows how to use the Python field API to build the same stress field and field of internal variables.

## 1 Definition of the analytical stress field

It is assumed that the model contains continuum finite elements (MODELISATION='3D').

One wants the stress components to have the following expressions at each Gauss point:

- SIZZ = RHO*G*Z
- SIXX = SIYY = KP*SIZZ

where:

- RHO: density
- G: acceleration due to gravity
- Z: 3rd space coordinate
- KP: coefficient of soil "thrust"

The solution proposed consists in:

1. defining three "formula" functions corresponding to SIXX, SIYY and SIZZ,
2. building a field whose components are the previous functions,
3. evaluating the formulae of the field by supplying it with the geometry field required for their evaluation.

### 1.1 Step 1: defining the formulae

```python
RHO = 1000.0
G = 10.0
KP = 3.0

SIZZ = FORMULE(REEL="""(REEL:Z) = RHO*G*Z """)
SIXX = FORMULE(REEL="""(REEL:Z) = KP*SIZZ(Z) """)
SIYY = FORMULE(REEL="""(REEL:Z) = KP*SIZZ(Z) """)
```

### 1.2 Step 2: creating the field of formulae SIG1

```python
SIG1 = CREA_CHAMP(
    OPERATION="AFFE",
    TYPE_CHAM="ELGA_NEUT_F",
    MODELE=MO,
    PROL_ZERO="OUI",
    AFFE=_F(TOUT="OUI", NOM_CMP=("X1", "X2", "X3"), VALE_F=(SIXX, SIYY, SIZZ)),
)
```

- the field SIG1 which one creates is a cham_elem at the Gauss points (ELGA),
- the only fields which can have components of "function" type are the fields of the quantity NEUT_F. One must therefore remember that the component 'X1' of SIG1 is in reality 'SIXX', etc.,
- the keyword PROL_ZERO='OUI' is mandatory because, for every finite-element type, the NEUT_R cham_elem currently have 6 components: 'X1', 'X2', ..., 'X6'. One must therefore accept "extending" the field by zero over the 3 components which are not assigned. Extension by "zero" for a field whose components are texts (names of the functions) consists in assigning the string " " to each component absent from the field. Caution, therefore: this is not a zero function. This can be seen by using INFO=2 to print the field SIG1.

> **Notes.**

### 1.3 Step 3: evaluating the formulae of the field SIG1

The field SIG1 is a field known at the Gauss points of the finite elements of the model. At each point, one will want to evaluate the functions SIXX, SIYY and SIZZ. For that, the values of all the variables appearing in the functions (here Z) must be available. These variables must be known at the same points as the field of functions. One must therefore have a field containing the geometry of the Gauss points (cham_elem_GEOM_R / ELGA).

This field of the geometry of the Gauss points (CHXG) is obtained from the mesh (MA) by the following 2 commands:

```python
CHXN = CREA_CHAMP(
    OPERATION="EXTR", TYPE_CHAM="NOEU_GEOM_R", NOM_CHAM="GEOMETRIE", MAILLAGE=MA, INFO=1
)

CHXG = CREA_CHAMP(OPERATION="DISC", TYPE_CHAM="ELGA_GEOM_R", MODELE=MO, CHAM_GD=CHXN, INFO=1)
```

The first command extracts the geometry field (at the nodes) from the mesh. The second transforms the geometry field at the nodes into a geometry field at the Gauss points by using the shape functions of the finite elements of the model.

The functions can then be evaluated by means of the operator CREA_CHAMP / OPERATION='EVAL':

```python
SIG2 = CREA_CHAMP(OPERATION="EVAL", TYPE_CHAM="ELGA_NEUT_R", INFO=1, CHAM_F=SIG1, CHAM_PARA=(CHXG,))
```

The field (SIG2) obtained by evaluation of a field of the quantity NEUT_F is a field of the quantity NEUT_R whose components have the same names as the components of NEUT_F: 'X1', 'X2', ..., 'X6'.

**Caution**

The components 'X4', 'X5', 'X6' are undefined (in reality they contain the largest possible real number), because they correspond to a non-existent function.

It remains to change the quantity of the field SIG2 (NEUT_R into SIEF_R) in order to finish building our analytical stress field:

```python
SIGINI = CREA_CHAMP(
    OPERATION="ASSE",
    TYPE_CHAM="ELGA_SIEF_R",
    MODELE=MO,
    PROL_ZERO="OUI",
    ASSE=_F(
        TOUT="OUI", CHAM_GD=SIG2, NOM_CMP=("X1", "X2", "X3"), NOM_CMP_RESU=("SIXX", "SIYY", "SIZZ")
    ),
)
```

- only the components 'X1', 'X2' and 'X3' of the field SIG2 are copied in this operation, to give the components 'SIXX', 'SIYY', 'SIZZ' of the field SIGINI. This stress field must also contain the components related to the shears ('SIXY', 'SIYZ', 'SIXZ'). To obtain them (with a zero value), extension by zero must be used, with PROL_ZERO='OUI'.
- the operations carried out in order to obtain the zero shear components would have been simpler if a zero function had been assigned explicitly to these 3 components. One would not have had to "play" with the extensions. But one would have benefited from the coincidence that the quantities SIEF_R and NEUT_R both have 6 components for the cham_elem (ELGA) on the finite elements of the model.

> **Notes.**

## 2 Definition of the non-zero field of internal variables

### 2.1 Problem

One wants to create a field of initial internal variables for the command STAT_NON_LINE. This field must not be zero everywhere. More precisely, one wants:

```python
STAT_NON_LINE(
    COMPORTEMENT=(
        _F(GROUP_MA='MASSIF', RELATION = 'CJS'),
        _F(GROUP_MA='BETON', RELATION = 'ENDO_LOCAL'),),
```

for the constitutive relation 'CJS' (16 internal variables), one wants to assign:
V1 = 1.0 and V9 = 9.0

for the constitutive relation 'ENDO_LOCAL' (2 internal variables), one wants to assign:
V2 = 2.0

### 2.2 First method

The operator to use is CREA_CHAMP / OPERATION='AFFE'. It makes it possible to assign (by mesh cell or GROUP_MA) the values one wishes. The difficulty comes from the fact that the quantity associated with the internal variables (VARI_R) is different from the others: one does not know a priori what its components are. Indeed, the name of its components reflects this ignorance: 'V1', 'V2', ...

Depending on the constitutive behaviour chosen by the user in STAT_NON_LINE, the number of internal variables changes. In our example, the constitutive behaviour 'CJS' requires 16 variables, whereas 'ENDO_LOCAL' uses only 2.

The assignment operation is carried out as follows:

```python
VAIN1 = CREA_CHAMP(
    OPERATION="AFFE",
    TYPE_CHAM="ELGA_VARI_R",
    MODELE=MO,
    PROL_ZERO="OUI",
    AFFE=(
        _F(GROUP_MA="BETON", NOM_CMP="V2", VALE=2.0),
        _F(GROUP_MA="MASSIF", NOM_CMP=("V1", "V9", "V16"), VALE=(1.0, 9.0, 0.0)),
    ),
)
```

- The keyword PROL_ZERO='OUI' makes it possible to assign only the non-zero components. But, as the command does not know the number of internal variables carried by the mesh cells, it relies on the highest number assigned.
  In the example above, on the group 'MASSIF', it is important to assign 'V16' (here to 0.) so that the field has 16 components.
- It is important, for the non-linear analysis which follows, that the field of internal variables be consistent with the constitutive behaviours that one will choose.
  Here, the mesh cells of the group 'BETON' must have 2 internal variables (and only 2), and those of the group 'MASSIF' must have 16.

**Important notes**

**Caution**

If the model includes other types of constitutive behaviour (for which one does not wish to initialise the field with non-zero values), zero values must also be assigned to them explicitly. This drawback (having to know ALL the constitutive behaviours used and their number of internal variables) can be removed with the 2nd method below (but it is more complicated).

### 2.3 Second method

This method (more complicated) makes it possible to assign explicitly only the mesh cells which possess non-zero components.

The problem is to obtain a field containing the correct number of internal variables for each mesh cell, as a function of the constitutive behaviour which will be assigned to it in STAT_NON_LINE. To solve this problem, a fictitious non-linear analysis will be carried out (with the real constitutive behaviours). The field of internal variables produced will then be a good "model" of a field.

One will therefore proceed as follows:

1. fictitious non-linear analysis: UBID
2. extraction of the field of internal variables (VBID) from the result UBID
3. assignment of the non-zero values in the field VAIN2
4. setting VBID to zero + overloading of the values of VAIN2 in order to produce the result VAIN22

#### 2.3.1 Fictitious non-linear analysis

```python
BETON = DEFI_MATERIAU(ELAS=_F(E=20000.0, NU=0.0), ECRO_LINE=_F(SY=6.0, D_SIGM_EPSI=-10000.0))

MASSIF = DEFI_MATERIAU(
    ELAS=_F(E=35.0e3, NU=0.15),
    CJS=_F(
        BETA_CJS=-0.55,
        GAMMA_CJS=0.82,
        PA=-100.0,
        RM=0.289,
        N_CJS=0.6,
        KP=25.5e3,
        RC=0.265,
        A_CJS=0.25,
    ),
)

CHMAT = AFFE_MATERIAU(
    MAILLAGE=MA, AFFE=(_F(GROUP_MA="MASSIF", MATER=MASSIF), _F(GROUP_MA="BETON", MATER=BETON))
)

TEMPS1 = DEFI_LIST_REEL(VALE=(0.0, 1.0))

CHAR_U1 = AFFE_CHAR_MECA(MODELE=MO, DDL_IMPO=_F(NOEUD=("N1", "N2", "N3"), DX=0.0, DY=0.0, DZ=0.0))

UBID = STAT_NON_LINE(
    MODELE=MO,
    CHAM_MATER=CHMAT,
    EXCIT=_F(CHARGE=CHAR_U1),
    COMPORTEMENT=(
        _F(GROUP_MA="MASSIF", RELATION="CJS"),
        _F(GROUP_MA="BETON", RELATION="ENDO_LOCAL"),
    ),
    NEWTON=_F(MATRICE="ELASTIQUE"),
    CONVERGENCE=_F(
        ARRET="NON", ITER_GLOB_MAXI=1, ITER_INTE_MAXI=1  # pour continuer sans convergence
    ),
    INCREMENT=_F(LIST_INST=TEMPS1),
)
```

#### 2.3.2 Recovery of the "model" field of internal variables

```python
VABID = CREA_CHAMP(
    OPERATION="EXTR",
    TYPE_CHAM="ELGA_VARI_R",
    INFO=1,
    NOM_CHAM="VARI_ELGA",
    RESULTAT=UBID,
    NUME_ORDRE=1,
)
```

> **Note.**

VABID is not zero.

#### 2.3.3 Assignment of the non-zero values in a NEUT_R map

```python
VAIN2 = CREA_CHAMP(
    OPERATION="AFFE",
    TYPE_CHAM="CART_NEUT_R",
    MODELE=MO,
    AFFE=(
        _F(GROUP_MA="BETON", NOM_CMP=("X2",), VALE=(2.0,)),
        _F(GROUP_MA="MASSIF", NOM_CMP=("X1", "X9"), VALE=(1.0, 9.0)),
    ),
)
```

#### 2.3.4 Setting the "model" field of internal variables to zero and overloading the non-zero values

```python
VAIN22 = CREA_CHAMP(
    OPERATION="ASSE",
    TYPE_CHAM="ELGA_VARI_R",
    MODELE=MO,
    # mise à zéro:
    ASSE=(
        _F(TOUT="OUI", CHAM_GD=VABID, CUMUL="OUI", COEF_R=0.0),
        # surcharge des valeurs non nulles:
        _F(
            GROUP_MA="BETON",
            CHAM_GD=VAIN2,
            CUMUL="OUI",
            COEF_R=1.0,
            NOM_CMP=("X2",),
            NOM_CMP_RESU=("V2",),
        ),
        _F(
            GROUP_MA="MASSIF",
            CHAM_GD=VAIN2,
            CUMUL="OUI",
            COEF_R=1.0,
            NOM_CMP=("X1", "X3"),
            NOM_CMP_RESU=("V1", "V9"),
        ),
    ),
)
```

> **Note.**

For setting to zero and for overloading the non-zero values, the keywords CUMUL='OUI' and COEF_R=0. are used.
