# u4.24.02 Operator DEFI_GRILLE

## 1 Purpose

Define a grid from a mesh.

A grid is a particular type of mesh for which the nodes are all aligned along the directions of a local basis.

The operator produces a concept of type grille.

## 2 Syntax

```text
grille = DEFI_GRILLE(
    ◆ MAILLAGE = maillage,
    ◇ INFO = / 0 (par défaut),
             / 1,
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand MAILLAGE

```text
♦    MAILLAGE    =    ma
```

ma: mesh to be used for the definition of the grid

The mesh ma must be regular, such that all its nodes are aligned along the directions of a local basis. This imposes restrictions on the type and the shape of the elements which may be used to define the mesh ma: one may use only QUAD4 elements of square or rectangular shape in 2D and HEXA8 elements of cubic or elongated shape in 3D.

No restriction is imposed on the shape of the domain defined by the mesh ma, that is to say that the domain does not necessarily have to be a square or a rectangle in 2D and a cube or a parallelepiped in 3D. However, all the elements must be connected to one another and the domain cannot be formed by several parts which are not connected.

The local basis of the grid, along which the nodes are aligned, is computed automatically.

### 3.2 Operand INFO

| / 0 : | no printout in the file 'MESSAGE' |
| --- | --- |
| / 1 : | printout in the file 'MESSAGE': * of the length of the shortest edge of the mesh ma * of the computed local basis |
| / 2 : | printout in the file 'MESSAGE': * of the same information as for INFO=2 * of the connection table and of the distances of the nodes of the grid |
