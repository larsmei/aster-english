# v1.01.133 ZZZZ133 – Validation of the correct consideration of the elastic control variables

**Summary:**

This test has no physical meaning, it is essentially a computer test. It aims to check the correct consideration of the control variables (TEMP, HYDR, SECH and EPSA*6) in the different elasticity configurations.

It consists of a mechanically loaded unit cube subject to variations in the control variables tested.

This documentation is deliberately succinct.
