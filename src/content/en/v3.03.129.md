# v3.03.129 SSLS129 – Sine-shaped corrugated plate subjected to linear loadings

**Summary**

This test validates the linear loading account.

The two validated modellingss are:

- Modelization A: 3D,
- Modelling B: COQUE_3D.
- Modelling C: COQUE_SOLIDE

### 1.1 Geometry

The $z$ rating of the plate is defined by the following equation: $z=30\sin(2\pi x/L)\sin(\pi y/l)$

### 1.2 Material properties

The material has an isotropic elastic behavior:

- Young's modulus :     $E=204\mathrm{000.MPa}$
- Poisson's ratio:     $\nu =0.3$

### 1.3 Boundary conditions and loads

boundary conditions :

- Clamped support on the side $\mathit{GAUCHE}$

3D Modelling, SHB: 3 cases of over-hand loading on the $\mathit{DROITE}$ side:

- $\mathit{fx}\text{}=\text{}0.5N/\mathit{mm²}$
- $\mathit{fy}\text{}=\text{}0.5N/\mathit{mm²}$
- $\mathit{fz}\text{}=-0.5N/\mathit{mm²}$

COQUE_3D Modelling; 2 cases of linear loadings on the $\mathit{DROITE}$ side:

- $\mathit{fx}\text{}=\text{}10.N/\mathit{mm}$
- $\mathit{fz}\text{}=-10.N/\mathit{mm}$

## 2 reference solution

### 2.1 reference solution

The reference solution is:

- "ANALYTIQUE" for the resulting forces and moments,
- "NON_REGRESSION" for displacement and stress (modelling A)
- "AUTRE_ASTER" for displacement and stress (modellings B and C). The results obtained with Modelling A serve as reference solution.

Calculations of effort and resulting moments

- Linear charging case $\mathit{fx}$

${R}_{x}={\int}_{s}{f}_{x}\mathit{ds}={f}_{x}.h.l=2000N$

${M}_{y}={\int}_{s}{f}_{x}z\mathit{ds}=\frac{({f}_{x}.{h}^{2})}{2}l=20000\mathit{N.mm}$

${M}_{z}={\int}_{s}{f}_{x}y\mathit{ds}=\frac{({f}_{x}.{l}^{2})}{2}h=200000\mathit{N.mm}$

- Linear charging case $\mathit{fy}$

${R}_{y}={\int}_{s}{f}_{y}\mathit{ds}={f}_{y}.h.l=2000N$

${M}_{x}={\int}_{s}{f}_{y}z\mathit{ds}=\frac{({f}_{y}.{h}^{2})}{2}l=20000\mathit{N.mm}$

${M}_{z}={\int}_{s}{f}_{y}L\mathit{ds}={f}_{y}.h.l.L=1500000\mathit{N.mm}$

- Linear charging case $\mathit{fz}$

${R}_{z}={\int}_{s}{f}_{z}\mathit{ds}={f}_{z}.h.l=2000N$

${M}_{x}={\int}_{s}{f}_{z}y\mathit{ds}=\frac{({f}_{z}.{l}^{2})}{2}h=200000\mathit{N.mm}$

${M}_{y}={\int}_{s}{f}_{z}L\mathit{ds}={f}_{z}.h.l.L=1500000\mathit{N.mm}$
