# v1.01.185 ZZZZ185 - Validation of MODI_MAILLAGE command associated with SYMETRIE and PROJ_CHAMP command associated with DISTANCE_MAX

**Summary:**

The objective of this test case is to validate the MODI_MAILLAGE command with the SYMETRIE keyword and the PROJ_CHAMP command with the DISTANCE_MAX keyword.

- MODI_MAILLAGE command, with the keyword SYMETRIE allows you to take the symmetrical of a mesh $\mathrm{2D}$ or $\mathrm{3D}$ ,
- PROJ_CHAMP command with the DISTANCE_MAX keyword allows you not to project the field to nodes that does not meet the following 2 criteria:

1. nodes is not in a element of the 1st mesh,
2. nodes is beyond DISTANCE_MAX.

The test case consists of:

- a thermal study on 1/8th structure,
- the construction of the thermal field on 1/4 of structure by projection of the results obtained on the 1/8th structure, with the consideration of a plane of symmetry,
- 1/4 thermal study of structure,
- comparison of the temperature field obtained by projection and a 1/4 structural study.

## 3 Modelling A

### 3.1 Modelling characteristics

The purpose of this Modelling is to obtain the solution to the thermal problem from the calculation performed on 1/8th of the structure.

The test case is as follows:

- mesh, 1/8th structure, from file in
- reading the temperature field from the file in 的MED
- create a result from the previously read field, command CREA_RESU.
- creating a model from the previously read mesh, command AFFE_MODELE.
- creating a model for mesh cells groups that belong to the symmetry plane, command AFFE_MODELE (see note #1).
- mesh read, 1/8th structure, from the file in 的MED-format and mesh change by symmetry to the plane (${\pi}_{\mathrm{sym}}$) defined by:
- AXE_1= $(\mathrm{1.0,}1.0,0.0)$ , AXE_2= $(0.0,0.0,-1.0)$ , POINT= $(0.0,0.0,0.0)$

LIRE_MAILLAGE and MODI_MAILLAGE commands.

- reading the temperature field from the file in 的MED
- create a result from the previously read field, command CREA_RESU.
- creating a model from the symmetrical mesh, AFFE_MODELE command.
- read mesh representing 1/4 of the structure, command LIRE_MAILLAGE.
- creating a model from the previously read mesh, command AFFE_MODELE.
- projection of the 3 results created from the solution calculated on 1/8th of structure, command PROJ_CHAMP with the keyword DISTANCE_MAX.
- Extracting the temperature fields from the 3 results from the projection, CREA_CHAMP command.
- creating a zero field on the model built on 1/4 of the structure, command CREA_CHAMP (see note #2).
- combination of all fields, command CREA_CHAMP/OPERATION=
- create a result from the field combination, CREA_RESU.

**Note 1:**

In this test case, nodes of mesh, [Figure *], belong to the symmetry plane* ${\pi}_{\mathrm{sym}}$ *. For these nodes, the temperature field projection will be counted twice. To avoid cumulating the temperature field too much, one solution is to create a model containing only these nodes and to make the projection on the complete mesh. This projected field will then be subtracted using the command* *CREA_CHAMP/OPERATION=WASSE.*

**Note No. 2:**

*The projection of fields using the command* *PROJ_CHAMP and the keyword* *DISTANCE_MAX allows you to avoid creating a field on the nodes that is not contained in one of the elements's original mesh and that is at a distance greater than **DISTANCE_MAX from the nearest element. When you combine fields using the command* *CREA_CHAMP/OPERATION=的ASSE, it is the first field to be taken as a reference. If the field is incomplete, as in our case, the combination will not give the desired result. The solution is therefore to create a null field over the entire model and use it as a reference field.*

## 4 Summary of the results

This test case validates:

- MODI_MAILLAGE command associated with the SYMETRIE keyword,
- PROJ_CHAMP command associated with the DISTANCE_MAX keyword.

Validation is done on the whole temperature field and not just on a few points.

When the 2 commands are associated, it must be taken into account that the fields supported by nodes that belong to the symmetry plane can be counted twice.

When combining the fields using the CREA_CHAMP/OPERATION='ASSE' command, it is the structure of the first CHAM_NO that serves as a reference structure. If the structure is incomplete, then you must create a reference CHAM_NO.
