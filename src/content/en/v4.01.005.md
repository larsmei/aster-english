# v4.01.005 TPLA05 - Cylindrical bar with flow density

**Summary:**

This test is based on independent validation of version 3 in linear steady-state thermal analysis.

It includes two modellings, the first one that tests elements density, the second one, elements 2D axisymmetric.

Boundary conditions in temperature and flow density are taken into account.

The results from this test case are compared with those provided by VPCS.

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v4.01.005/100000000000015A0000008111AA19A0D1229856.png)

$r=0.01m$ (cylinder radius)

$L=\mathrm{1m}$

### 1.2 Material properties

$$
\lambda =33.33W/m°C
$$

### 1.3 Boundary conditions and loads

- Temperatures imposed,

| $T=0°C$ | en $z=0.$ |
| --- | --- |
| $T=500°C$ | en $z=1.$ |

- Constant flow density on cylindrical surface: $\varphi =-200W/{m}^{2}$ (outgoing stream).

### 1.4 Initial conditions

Not applicable.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The reference solution is the one given in the TPLA05/89 plug of the VPCS guide

![Figure](/figures/v4.01.005/100000000000015A0000008111AA19A0D1229856.png)

- Temperature as $z$: $T(z)=\frac{-\varphi }{\lambda r}z(z-L)+{T}_{1}.\frac{z}{L}$
- $T(z=0)=0$ $T(z=L)={T}_{1}$ .

The cylinder is supposed to be infinitely long ($L\gg r$ )

Minimum temperature is $-4.17°C$ in $z=0.083m$

### 2.2 Baseline

Temperature in $z=0.,0.1,\mathrm{...},0.8,0.9,1.0$

### 2.3 Uncertainty about the solution

$<1\text{\%}$

Analytical solution approached (approximation: $T=\mathrm{cte}$ , for all $r$ )

### 2.4 Bibliographical references

1. Guide de validation des computaux de computation de structures. Société Française des Mécaniciens, AFNOR 1990 ISBN 2-12-486611-7

## 5 Summary of the results

The results are satisfactory, the difference maximum is 0.63%. 3D modelling (with mesh cells PENTA15, HEXA20) and AXIS modelling (with mesh cells TRIA6) give substantially the same results (the mesh and the degree of interpolation are identical).

The analytical solution, which is an approach solution, assumes that the $r/L$ ratio is much higher than 1. For this digital test, the $r/L$ ratio was taken equal to 100.
