# u4.91.21 Procedure IMPR_JEVEUX

## 1 Purpose

Print the content of the objects created by the JEVEUX memory manager. Useful for the maintenance and the debugging of new developments.

Print the content of the JEVEUX objects, access the JEVEUX system objects, print the directory of the objects associated with a database, print the memory segmentation or access the content of a database stored on disk.

## 3 Operands

### 3.1 Operand ENTITE

The possible values of ENTITE are:

- 'OBJET': Call to JEIMPO, JEPRAT (values of an object, ...),
- 'ATTRIBUT': Call to JEIMPA (attributes of an object or of a collection),
- 'SYSTEME': Call to JEPRAT (attributes of a collection or system objects),
- 'MEMOIRE': Call to JEIMPM (state of the memory),
- 'REPERTOIRE': Call to JEIMPR (directory of one or more classes),
- 'DISQUE': Call to JEIMPD (objects written to disk),
- 'ENREGISTREMENT': Call to JEPREN (content of the records of the file associated with the database).

The possibilities offered by the various print routines are described in the booklet: JEVEUX memory management [D6.02.01](doc:d6.02.01).

If ENTITE='OBJET':

- NOMOBJ: Name of a simple object or name of a collection.
- NOMOC: Name of a collection object.
- NUMOC: Number of a collection object.

If ENTITE='ATTRIBUT':

- NOMOBJ: Name of a simple object or of a collection.
- NOMATR: Attribute name on 8 characters for:

  - a collection:
$$DESO, $$IADD, $$IADM, $$NOM, $$LONG, $$LONO,
$$LUTI, $$NUM.

If ENTITE='SYSTEME':

- NOMATR: Attribute name on 8 characters for:

  - the system:
$$CARA, $$IADD, $$GENR, $$TYPE, $$MARQ, $$DOCU, $$ORIG, $$RNOM,
$$LTYP, $$LONG, $$LONO, $$DATE, $$LUTI, $$HCOD, $$INDX,
$$TLEC, $$TECR, $$IADM, $$ACCE, $$USADI.
- CLASSE: Name of the class associated with one or more databases of values ('G', 'V'). For the entity 'SYSTEME' this keyword is mandatory. For the entities 'REPERTOIRE' and 'DISQUE', one prints by default what concerns all the open databases.

### 3.2 Operand NUMERO

Makes it possible to specify the number of the record whose content must be examined.

### 3.3 Operand INFO

Makes it possible to specify the level of the printouts to be carried out.

INFO=1 one merely prints the list of the names of the JEVEUX objects present on the record.

INFO=2 one prints in addition the content of the record. This printout is carried out in integer format; the storage of the image of the JEVEUX memory being carried out under this type, it is therefore impossible to interpret the other types.

### 3.4 Operands IMPRESSION and UNITE

The factor keyword IMPRESSION makes it possible to choose the file or the logical unit for the printout of the information.

- NOM: Internal file name; it equals 'MESSAGE' or 'RESULTAT'.
- UNITE: Logical unit number.

### 3.5 Operand COMMENTAIRE

Text appearing as the title of the printouts requested.
