# v3.04.131 SSLV131 - Orthotropy in any marker

**Summary**

This test case validates the modellings relative to l-linear elasticity that implement orthotropic materials whose properties are known in a user-defined benchmark different from the global benchmark.

## 1 Reference problem

### 1.1 Geometry

The global marker is the $(A,X,Y,Z)$ mark. In this mark the coordinates of the nodes are:

$A(0.,0.,0.)$

$B(3.,1.,0.)$

$C(2.,3.,0.)$

$D(3.,1.,-1)$

The behaviour of the $\mathrm{ABCD}$ tetrahedron, whose material properties are defined in a local $(A,x,y,z)$ benchmark obtained by rotation of the global marker at the $(\alpha =30°,\beta =20°,\gamma =10°)$ nautical angles, will be studied.

### 1.2 Material properties

The materials used are orthotropic and isotropic transverse. To validate the orthotropic deformations of thermal origin, a thermomechanical calculation is also made.

The terminological convention used in Code_Aster is adopted. The suffixes $L$ , $T$ and $N$ mean Longitudinal, Transversal and Normal.

Units are not specified.

## 3 Modelling A

### 3.1 Modelling characteristics

3D modelling is implemented. Transverse and orthotropic isotropic materials are tested (with possible thermal deformations)

Remarks:

- Transverse l-isotropy is not tested for flat stresses as this case corresponds to l-isotropy.
- For axisymmetric the stress field depends on the point calculation.
- This point is chosen at the point of triangle integration (i.e. it is the centre of gravity of the triangle).
- It is recalled that the orthotropy in any reference is not available for Fourier modelling, as there is then coupling of all the components of the stress tensor:

The current implementation allows only symmetrical components from which antisymmetry components can be found to be used, but for this to be possible, slips must not induce tensile stresses.

### 3.2 Mesh characteristics

We have a element tetrahedron at 4 nodes $\mathrm{ABCD}$.
