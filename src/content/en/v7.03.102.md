# v7.03.102 HPLV102 - Calculation of thermo-elastic G in infinite medium for a circular crack

**Summary**

This is a mechanical test of the break in thermo-mechanical for a axisymmetric problem. A circular crack plunged into an infinite supposed medium is considered. A uniform temperature is imposed on the lips of the crack. This test allows to calculate the $G$ energy return rate.

The value of the test is the stability of $G$ in different crowns and the comparison to an analytical solution.

This test contains axisymmetric Modelling.

Differences of $G$ calculation on different crowns compared to reference solution does not exceed $\text{1,5\%}$.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The reference solution is derived from OLESIAK and SNEDDON [bib1]:

![Figure](/figures/v7.03.102/1000074C00001CBB0000130404CBA7AA47F12067.svg)

The expression of energy release rate is as follows:

$G=\frac{(1-{\nu}^{2})}{E}{K}_{1}^{2}$ with ${K}_{1}=\frac{\alpha E}{\Pi (1-\nu )}{T}_{0}\sqrt{\Pi a}$

either:

![Figure](/figures/v7.03.102/Object_2.svg)

### 2.2 Baseline

The reference result is therefore: $G=5.9115{10}^{-7}J/{m}^{2}$
