# v1.01.332 ZZZZ332 - Validation of crea_resu/evol_varc

**Summary:**

This test validates the creation of an evol_varc from a function field using the crea_champ and crea_resu/evol_varc commands.

## 1 Reference problem

You read an mesh, create a function field dependent on time and coordinates, then evaluate the function field using the crea_resu/evol_varc command.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The nodes coordinates, the d-list, the function are known. The reference solution is known.

### 2.2 Baseline

The function is evaluated on all nodes of the mesh.

### 2.3 Uncertainties about the solution

No uncertainty.

## 3 Modelling A

### 3.1 Modelling characteristics

- The mesh is a hexa8.
- The function is: INST*X*Y*z
- Moments are $1.0$ and $2.0$

### 3.2 Test value

All nodes values are tested with $10.0E-10$ accuracy.
