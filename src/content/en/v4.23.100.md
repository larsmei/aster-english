# v4.23.100 TTLP100 – transient thermal analysis Paroi Exchange

**Summary**

The linear or nonlinear transient thermal analysis response of two plates separated by a set in which a heat transfer is performed is calculated. The problem is 2D but the boundary conditions makes the temperature dependent only on the abscissa and time. The stationary state is quickly reached, which is computable analytically.

The test is used to check the correctness of the terms related to heat exchange between two walls.

To treat the same problem in nonlinear thermal, an $\beta$ affine enthalpy with a slope equal to the $\rho {C}_{p}$ mass heat is defined.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The stationary analytical solution is obtained by solving a null Laplacian on each of the two plates of the $T(x)=\mathrm{ax}+b$ shape, the 4 coefficients (2 per plate) are obtained by explaining the boundary conditions:

$0.\le x\le 0.495:T={T}_{0}+\frac{h({T}_{L}-{T}_{0})}{\lambda +h({l}_{1}+{l}_{2})}x$

$0.505\le x\le 1.:T={T}_{L}-\frac{h({T}_{L}-{T}_{0})}{\lambda +h({l}_{1}+{l}_{2})}(L-x)$

### 2.2 Baseline

Temperatures on line $y=0$

### 2.3 Uncertainty about the solution

analytical solution.
