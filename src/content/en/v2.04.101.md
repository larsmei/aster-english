# v2.04.101 SDLV101 –Dynamic substructure beam

**Summary:**

The problem of determining the proper modes of an clamped beam is considered.

This is done by using a dynamic substructure methodology using the required interface modes (see U2.07.07 for more precision).

The approach's ability to represent the modal behaviour of the overall structure is shown.

## 2 reference solution

These test cases are non-regression test cases. The reference solution is the one obtained with an code_aster calculation.

## 3 Modelling A

### 3.1 Modelling characteristics

The beam is cut into 2 substructures, gridded in the same way and therefore in conformity.

### 3.2 Mesh characteristics

Bread 1

Number of nodes: 81

Number of mesh cells and types: 4QUAD4 and 32 HEXA8

Beam 2

Number of nodes: 81

Number of mesh cells and types : 32 HEXA8

### 3.3 Tested quantities and results

Non-regression values of the calculated eigenfrequencies are tested.

## 4 Modelling B

### 4.1 Modelling characteristics

The beam is cut into 2 substructures, gridded differently and not in line with the interface.

In addition, the problem is solved on a global mesh. This allows to compare the 2 approaches by calculating the criterion of MAC (Modal Assurance Criterion).

### 4.2 Mesh characteristics

Bread 1

Number of nodes: 756

Number of mesh cells and types: 50QUAD4 and 500 HEXA8

Beam 2

Number of nodes: 425

Number of mesh cells and types: 16 QUAD4 and 256 HEXA8

Global beam

Number of nodes: 1476

Number of mesh cells and types: 25 QUAD4 and 1000 HEXA8

### 4.3 Tested quantities and results

The values of the MAC matrix are tested.

## 6 Summary of the results

The calculated results demonstrate the capability of the dynamic substructured approach to interface mode to represent the modal behaviour of the overall structure.
