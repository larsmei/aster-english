# u4.81.43 Operator CALC_PRESSION

## 1 Purpose

Complete a result by computing a nodal field corresponding to the density of the normal and tangential interface forces on a defined zone. The amplitude of these forces is stored in the produced field PRES_NOEU on the quantity (grandeur) PRES_R with the component names PRES and CISA. The vectors of the tangential force are stored in the components VX, VY and VZ.

This field is computed from the Cauchy stress tensor and the field of normals to the surface considered. The computed contact pressure then corresponds to:

$$
p=\transpose{\normal} \tensTwo{\sigma} \normal
$$

where $\normal$ is the normal to the surface considered and $\tensTwo{\sigma}$ the Cauchy stress tensor. This field can be useful for accessing the stress state at the interface in various mechanical problems (contact, fracture mechanics …).

The tangential force is deduced by projecting the contact force onto the tangential plane:

$$
\vector{s} = (\tensTwo{\sigma} - p \tensTwoUnit).\normal
$$

The tangential force will be useful for justifying the mesh refinement and the analysis model. In the case of contact with friction, the ratio between the adhesion force and the contact pressure must not exceed the friction coefficient. In the case of frictionless contact, the tangential force is expected to be zero.

At present, the tangential force density computed by the command has been validated only in 2D (cf. [V6.03.154](doc:v6.03.154)). In 3D, the analysis is not released because no verification tests are available.

## 2 Syntax

```text
/ evol_elas
/ evol_noli = CALC_PRESSION(
    ◆ reuse = <objet de RESULTAT>,
    ◆ RESULTAT = evol_elas / evol_noli,
    ◆ GROUP_MA = list[grma],
    ◆ / INST = list[float],
      / TOUT_ORDRE = "OUI" (ou non renseigné),
    ◇ GEOMETRIE = / "DEFORMEE" (par défaut),
                  / "INITIALE",
    ◇ CRITERE = / "ABSOLU",
                / "RELATIF" (par défaut),
    # Si: (equal_to("CRITERE", 'RELATIF'))
        ◇ PRECISION = float (défaut: 1e-06),
    # Si: (equal_to("CRITERE", 'ABSOLU'))
        ◆ PRECISION = float,
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand RESULTAT

```text
♦ reuse = resu
```

The result data structure to be enriched is supplied. It comes from the solution of the mechanical problem considered.

### 3.2 Operand GROUP_MA

```text
♦ GROUP_MA = l_grma
```

The list of mesh-cell groups defining the interfaces considered is supplied.

In the case of facets embedded in the volume, the user can, by means of the command MODI_MAILLAGE / ORIE_PEAU_3D / GROUP_MA_VOLU or MODI_MAILLAGE / ORIE_PEAU_2D / GROUP_MA_SURF, reorient the normal correctly.

### 3.3 Operands TOUT_ORDRE/INST

```text
♦ TOUT_ORDRE = 'OUI',
```

This keyword makes it possible to compute the pressure field for all order numbers.

```text
♦ INST = l_inst,
```

A list of the analysis time instants considered for the post-processing is supplied.

### 3.4 Operands PRECISION / CRITERE

The use of these two keywords is described in document [U4.71.00](doc:u4.71.00).

### 3.5 Operands GEOMETRIE

```text
♦ GEOMETRIE = / 'DEFORMEE',      [DEFAUT]
              / 'INITIALE'
```

The configuration on which the normal field is computed is supplied; this keyword is mandatory.

### 3.6 Operand INFO

```text
◊ INFO =  /1,     [DEFAUT]
          /2,
```

Printout level.
