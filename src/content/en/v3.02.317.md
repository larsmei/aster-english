# v3.02.317 SSLP317- Validation of RAFF_XFEM macro-command on multi-fissed plate

**Summary:**

This document is intended to validate the RAFF_XFEM [U7.03.51](doc:u7.03.51) command macro that allows you to obtain an error field *a priori* to power a mesh refinement process.

## 1 Reference problem

### 1.1 Geometry

A square $\mathrm{2D}$ plate is considered to be of the unit side, originally centered.

This plate has 2 cracks and 2 inclusions (interfaces):

- an inclusion of ${L}_{e}=0,6$ length and ${R}_{e}=0,05$ radius type, centred in $E(0;-0,3)$,
- a circular ${R}_{c}=0,05$ radius inclusion centred at the origin,
- a horizontal straight-line non-emitting crack of ${L}_{A}=0,2$ length centred in $A(\mathrm{0,3 };0,25)$ ,
- a horizontal straight-line non-escaper crack of ${L}_{B}=0,2$ length centred in $B(-\mathrm{0,2 };0,25)$.

![Figure](/figures/v3.02.317/10000000000003F6000003907CE32725EF206DCB.png)

**Figure** 1.1-1 **: multi-cracked plate diagram**

### 1.2 Material properties

The material has the following properties:

- Young's modulus: $E=205000\mathrm{MPa}$
- Poisson's ratio: $\nu =0,3$

### 1.3 Boundary conditions and loads

Mechanical calculation does not matter in this test because it is only a test of the refinement criterion *a priori* . Mechanical calculation is given only as an illustrative example in Modelling A.

$p=1\mathit{MPa}$ traction load is considered on the left, right and upper sides of the plate. The lower side is clamped.

### 1.4 Brief description of the different modellings

All modellings are part of the representation of cracks and interfaces by the X-FEM method associated with the level sets.

Modelling A calculates a remote indicator (fields to nodes). The test will focus on the value of this indicator in different nodes. The mesh refinement methodology used is the simplest (criterion in percentage of refined mesh cells), but is not necessarily optimal in terms of number of mesh cells.

Model B calculates a remote indicator (fields to nodes). The value of this Modelling is to show a more optimal methodology in terms of number of mesh cells. The test will focus on the size of mesh cells in the refined area.

Model C calculates one indicator per zone (by mesh cells). The methodology presented is the most complete and robust, and this indicator and methodology is recommended.

## 2 reference solution

### 2.1 Calculation method used for reference solution

#### 2.1.1 Modelling A

The test is for the value of the error indicator output of RAFF_XFEM. $I(M)$ is noted for the value of this indicator at any point $M$.

At the point ${P}_{1}$ at the bottom left of the structure, the indicator is the opposite of the distance to the point of the nearest pitch, i.e. $I({P}_{1})=-({\mathit{CP}}_{1}-{R}_{e})$.

At the point ${P}_{2}$ at the bottom right of the structure, the indicator is the opposite of the distance to the point of the nearest pitch, i.e. $I({P}_{2})=-({\mathit{DP}}_{2}-{R}_{e})$.

At the point ${P}_{3}$ at the top right of the structure, the indicator is the opposite of the distance at the right end of the crack to the right, $I({P}_{3})=-A'{P}_{3}$ where $A'=A+\frac{{L}_{A}}{2}\overrightarrow{x}$.

At the point ${P}_{4}$ at the top left of the structure, the indicator is the opposite of the distance at the left end of the leftmost crack, $I({P}_{4})=-B'{P}_{4}$ where $B'=B-\frac{{L}_{B}}{2}\overrightarrow{x}$.

#### 2.1.2 modellings B et C

The test is about the diameter value of the smallest mesh cell. If ${h}_{0}$ is the initial size of the mesh cells, ${h}_{c}$ the target size of the mesh cells after refinement, then the minimum number of calls to Homard to reach ${h}_{c}$ is $\text{nb\_raff}=E(n)+1$, with $n=\frac{\ln({h}_{0})-\ln({h}_{c})}{\ln(2)}$. After refinement, the most refined mesh cells size is $h=\frac{{h}_{0}}{{2}^{\text{nb\_raff}}}$.

### 2.2 Baseline

#### 2.2.1 Modelling A

With the numerical values used in the test, we find:

$\begin{array}{c}I({P}_{1})=-(\sqrt{{0,25}^{2}+{0,2}^{2}}-0,05)\approx -0,27015621187164246\\ I({P}_{2})=-(\sqrt{{0,25}^{2}+{0,2}^{2}}-0,05)\approx -0,27015621187164246\\ I({P}_{3})=-\sqrt{{0,25}^{2}+{0,1}^{2}}\approx -0,26925824035672524\\ I({P}_{4})=-\sqrt{{0,25}^{2}+{0,2}^{2}}\approx -0,32015621187164245\end{array}$

#### 2.2.2 modellings B et C

With ${h}_{0}=\frac{\sqrt{(2)}}{20}$ and ${h}_{c}=\frac{{h}_{0}}{10}$, you can find $h=0,0044194$.

## 3 Modelling A

### 3.1 Modelling characteristics

Interfaces and cracks are defined by level sets.

The original mesh is refined 3 times in a row using the remote indicator provided by RAFF_XFEM. Each time, 20% of the mesh cells most marked with "error" is refined.

### 3.2 Mesh characteristics

The original mesh is healthy: it consists of $20\times 20$ linear quadrangles.

It is noted that for interfaces, it is not only the mesh cells close to the interfaces that are refined, but all the mesh cells contained in the inclusion. Therefore in the continuation of the modellings, we will prefer to start from an initial mesh triangles.

## 4 Modelling B

### 4.1 Modelling characteristics

Interfaces and cracks are defined by level sets.

The remote indicator provided by RAFF_XFEM is used.

The value of this Modelling is to present a more optimal methodology than that used in Modelling A. The idea is to better control the number of mesh cells to be refined and the size of mesh cells at the end of the refinement process.

Knowing the initial size of the mesh cells, and setting a target size, we will refine as many times as necessary to obtain in the areas of interest appropriate size mesh cells.

### 4.2 Mesh characteristics

The original mesh is healthy: it consists of $20\times 20$ linear quadrangles, which are cut in half to obtain triangles (see explanation in § 3.3 ). This mesh is presented on the .
