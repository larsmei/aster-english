# u4.65.04 Operator ASSE_MATR_GENE

## 1 Purpose

Assemble the global stiffness or mass matrix from the substructures.

Within an analysis using the dynamic substructuring methods (modal or harmonic analysis), this operator creates the generalised stiffness or mass matrix, or possibly the damping matrix (harmonic or transient analysis), by assembly of the corresponding generalised matrices of type macr_elem_dyna (cf. operator MACR_ELEM_DYNA [U4.65.01](doc:u4.65.01)) contained in a list defined when the generalised model is created (cf. operator DEFI_MODELE_GENE [U4.65.02](doc:u4.65.02)). The assembled generalised matrix is real, and may be symmetric or non-symmetric. It is built on a numbering of the generalised degrees of freedom and stored via the "skyline" or Morse formats. The addressing arrays are those computed beforehand by the operator NUME_DDL_GENE [U4.65.03](doc:u4.65.03).

The result concept produced by this operator is of type: matr_asse_gene_R.

## 2 Syntax

```text
/ matr_asse_gene_r
/ matr_asse_gene_c = ASSE_MATR_GENE(
    ◆ NUME_DDL_GENE = nume_ddl_gene,
    ◇ METHODE = / "CLASSIQUE" (par défaut),
                / "INITIAL",
    # Si: equal_to("METHODE", 'CLASSIQUE')
        ◆ OPTION = / "RIGI_GENE",
                   / "RIGI_GENE_C",
                   / "MASS_GENE",
                   / "AMOR_GENE",
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand NUME_DDL_GENE

```text
♦ NUME_DDL_GENE= nu_gene
```

Name of the nume_ddl_gene concept coming from the operator NUME_DDL_GENE [U4.65.03](doc:u4.65.03) which defines the numbering of the equations of the assembled generalised system, the storage mode of the coefficients of the assembled generalised matrix, and the generalised model on which the diagonal, or full, assembly operations are carried out.

### 3.2 Operand METHODE

◊ METHODE= ‘CLASSIQUE’

Builds a generalised numbering making it possible to take the connection equations into account by the method of double Lagrange multipliers or by elimination (cf. R4.06.02). The method used is chosen consistently with the method supplied in the operator NUME_DDL_GENE [U4.65.03](doc:u4.65.03)

◊ METHODE= ‘INITIAL’

Initialises a null matrix of type matr_asse_gene_R which one can fill using Python methods. This method was created for development.

### 3.3 Operand OPTION

```text
♦    OPTION
```

The option makes it possible to determine the list of macro-elements, contained in the modele_gene concept coming from DEFI_MODELE_GENE [U4.65.02](doc:u4.65.02), to be assembled. It therefore defines the type of the assembled generalised matrix computed by the operator ASSE_MATR_GENE.

| ‘RIGI_GENE’: 'RIGI_GENE_C' | computation of the assembled generalised stiffness matrix, including the terms associated with the LAGRANGE multipliers; computation of the complex generalised stiffness matrix, |
| --- | --- |
| ‘MASS_GENE’: | computation of the assembled generalised mass matrix, |
| ‘AMOR_GENE’: | computation of the assembled generalised damping matrix. |

## 4 Execution phase

The terms corresponding to the projected matrices are assembled without processing.

On the other hand, the terms corresponding to the dualisation of the connections are the subject of a simple conditioning. They are multiplied by a factor, defined in a unique way, which is such that the maximum absolute value of the dualisation terms is equal to the maximum absolute value of the stiffness terms of the macro-elements (matrices of the projected substructures).
