# v2.02.403 SDLL403 - Vibration of a rotating pendulum

**Summary**

The field of application of this test is the modal analysis of the structures. The structure studied is a pendulum rotating around a fixed axis and immersed in a field of gravity. The pendulum itself is articulated around an axis perpendicular to the axis of rotation and situated at a certain distance from it.

We're interested in the first six eigenfrequencies.

The value of this test lies in the following aspects:

- modal analysis with initial stress (stiffness geometric)
- modal analysis with centrifugal stiffening taken into account
- difference relative large between two successive spectrum frequencies

Currently, centrifugal stiffening can only be taken into account with elements density. L的element used is the element HEXA20 and Sorensen's method is used for calculating eigenfrequencies.

The first frequency is compared with an analytical reference. The following frequencies are compared with numerical values obtained by software independent of *Code_Aster* and using modellings ‘drawer' and ‘plane stress'.

## 2 reference solution

### 2.1 Calculation method used for reference solution

- first eigenfrequency

The data of the problem are chosen in such a way that the bending and extension stiffeners are large vis-à-vis the geometric and centrifugal stiffeners. Under these conditions, the value of the first proper frequency is obtained analytically by considering a rigid pendulum.

Taking as degree of freedom $\theta$ angle between pendulum and $X$ axis the equation of motion writes:

$2L\ddot{\theta}=\mathrm{3g}\cos\theta -{\Omega}^{2}(\mathrm{3a}+\mathrm{2L}\cos\theta )\sin\theta$

Here we consider the small $\Delta \theta$ oscillations of the pendulum around a static equilibrium position ${\theta}_{0}$. By linearizing the equation of motion in the vicinity of this position, we obtain the equation at the small disturbances:

$2L\Delta \ddot{\theta}+\left[\mathrm{3g}\sin{\theta}_{0}+{\Omega}^{2}(\mathrm{3a}\cos{\theta}_{0}+\mathrm{2L}\cos2{\theta}_{0})\right]\Delta \theta =0$

The impulse of the first mode is derived from this:

$\omega =\sqrt{\frac{\mathrm{3g}}{\mathrm{2L}}\sin{\theta}_{0}+{\Omega}^{2}\left[\frac{\mathrm{3a}}{\mathrm{2L}}\cos{\theta}_{0}+\cos2{\theta}_{0}\right]}$

This own impulse can still be written in the form

$\omega =\sqrt{\frac{K(\sigma )+K({\Omega}^{2})}{I}}$

with

$K(\sigma )=\frac{1}{2}\rho S{L}^{2}g\sin{\theta}_{0}+\rho S{L}^{2}{\Omega}^{2}\left[\frac{a}{2}\cos{\theta}_{0}+\frac{L}{3}{\cos}^{2}{\theta}_{0}\right]$ (stiffness geometric)

$K({\Omega}^{2})=-\frac{1}{3}\rho S{L}^{3}{\Omega}^{2}{\sin}^{2}{\theta}_{0}$ (stiffness centrifugal)

$I=\frac{1}{3}\rho S{L}^{3}$ (rotating inertia)

- Other eigenfrequencies

The reference values for frequencies 2 to 6 are obtained numerically using SAMCEF version 7. Two different modellingss were used: 20 elements of the 8 nodes membrane beam, and $20\times 4$ elements. The results obtained in both cases are identical if the first 4 significant digits are the only one. Since the stiffness corrections are small with respect to the linear stiffness terms, it can be verified that the 2 to 6 frequencies differ little from the analytical values obtained for a non-deformable slender beam to l-shear force. In fact, the difference maximum between the numerical and analytical values does not exceed $\text{1 \%}$.

## 4 Summary of the results

Good agreement with reference solution (less than $\text{1. \%}$ error on all modes except on the first where the error is $\text{2.2 \%}$).

This test could be performed with a element beam as the calculation of the centrifugal stiffness matrix is not available for this type of d-element. Similarly, as it is not available for discrete elements, we could not use restraint 3D beam. In order to level this problem, all nodes surface containing point $A$ were bound by a solid restraint.
