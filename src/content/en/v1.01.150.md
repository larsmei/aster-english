# v1.01.150 ZZZZ150 - Validation of the IMPR_FONCTION Operator

**Summary:**

The objective of this test case is to validate the printing of functions and sheets via the IMPR_FONCTION operator with the FONCTION , FONC_X and FONC_Y keywords. In this test case, we define several functions (DEFI_FONCTION) and several layers (DEFI_NAPPE) that are printed in a file in the following formats:

- RESULTAT
- XMGRACE

To test the content of the results files, the TEST_FICHIER command is used which is based on a md5 control sum.

This documentation is deliberately succinct.
