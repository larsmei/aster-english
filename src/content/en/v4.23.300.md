# v4.23.300 TTLP300 - Thermal transfer into an orthotropic metal bar

**Summary:**

This test is based on independent validation of version 3 in linear transient thermal analysis.

This is a 2D plan problem represented by a single model (plane).

The functions tested are as follows:

- element thermal plane,
- orthotropic material,
- transient thermal analysis algorithm,
- limit condition: convection.

The value of the test lies in the consideration of an orthotropic material.

The results are compared with a solution based on a graphical estimate.

## 5 Summary of the results

The results obtained are satisfactory, the difference maximum is 2.5% below the tolerance initially set (5%) (the reference solution is obtained graphically).

This test allowed to test in linear transient, Modelling PLAN, the commands:

- DEFI_MATERIAU associated with the THER_ORTH keyword, allowing to define the characteristics of an orthotropic material,
- AFFE_CARA_ELEM associated with the MASSIF keyword, allowing to define the d-orthotropy axes.
