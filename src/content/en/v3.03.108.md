# v3.03.108 SSLS108 - Concentrated charge helical shell

**Summary:**

This linear elasticity test is very severe due to its geometry (left hull). It shows the influence of the spin on the performance of the elements hulls.

It has 8 modellings for testing elements COQUE_3D, DKT, DST and Q4G for different geometric supports.

The reference values are calculation results provided in the literature, the displacement of the structure into an point is checked.

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v3.03.108/10001BDA000023F800000EE2EEECE4FF142C5427.svg)

The shell is $0.32m$ thick, $12m$ long and $1.1m$ wide.

### 1.2 Material properties

$E={29.10}^{6}\mathrm{Pa}$

$\nu =0.22$

### 1.3 Boundary conditions and loads

Clamped on the side $\mathit{OBC}$ : $u=v=w=0$ , ${\theta}_{x}={\theta}_{y}={\theta}_{z}=0$

Two load cases corresponding to point $A$ concentrated loads:

- Force parallel to $Z$ axis: ${F}_{z}=1N$
- Force parallel to $Y$ axis: ${F}_{y}=1N$

## 2 reference solution

### 2.1 Calculation method used for reference solution

Reference solution [1] is a solution based on beam theory (non-deformation of cross-section), including or not the effects of transverse shearing.

### 2.2 Baseline

Move the point $A$ following $Y$ .

Move the point $A$ following $Z$ .

| Loading ($N$ ) | Reference ($m$ ) |
| --- | --- |
| ${F}_{Y}=0$ ${F}_{Z}=1$ | $\mathit{DY}=1.72\times {10}^{-3}$ $\mathit{DZ}=5.424\times {10}^{-3}$ |
| ${F}_{Y}=1$ ${F}_{Z}=0$ | $\mathit{DY}=1.754\times {10}^{-3}$ $\mathit{DZ}=1.72\times {10}^{-3}$ |

### 2.3 Uncertainties about the solution

Semi-analytic solution.

## 12 Summary of the results

This test is very severe due to the geometry of the shell which is left.

Elements COQUE_3D and COQUE_SOLIDE perform very well (less than 0.5%) with little nodes (modelization A, B, and C).

For modellings plate type (DKT, DST, Q4G), the mesh cell type used has a strong influence on the results:

- mesh cells TRIA3 results well (about 10% error), a finer mesh improves the latter more significantly;
- mesh cells QUAD4 results are very far from reference solution. The elements plate formulation makes the hypothesis of flat facets, which is no longer verified on this test in the presence of large displacements.
