# v2.02.150 SDLL150 - Eigenmodes of an excreted core beam

**Summary:**

The objective of this test is to validate the calculation of the eigenmodes for multifibre beams d-Euler-Bernoulli POU_D_EM regardless of the position of the reference axis.

The test case validates the correct consideration of the excentering in the calculation of the stiffness matrix (RIGI_MECA) and the mass matrix (MASS_MECA).

## 1 Reference problem

### 1.1 Geometry

The model is a $5m$-length console beam oriented to the $X$ axis. The straight section is I-shaped, with upper and lower soles of different sizes (Figure 1).

### 1.3 Boundary conditions and loading

The beam is clamped at one of its ends: all degrees of freedom of node A are blocked.

An effort of 1.E4N is imposed on the node B in the z direction.

## 2 reference solution

A first calculation was made with *Code_Aster* .

For this calculation, the reference axis is the elastic centre of the right section, confused with the barycentre G since the section is homogeneous:

$\vec{\mathit{OG}}={y}_{G}\vec{y}+{z}_{G}\vec{z}$

with:

${y}_{G}=0$

${z}_{G}=1/S\sum{z}_{\mathit{Gi}}{S}_{i}=1/0.27\times 0.05\times (0.125\times 3+0-0.125\times 2)=0.023148148m$

The reference solution is therefore obtained with:

COOR_AXE_POUTRE = (0. , 0.023148148)

The values of the eigenfrequencies and modal shifts are used as reference, since these values should not depend on the position chosen for the calculation reference axis (keyword COOR_AXE_POUTRE of the DEFI_GEOM_FIBRE operator).

**Note:**

* Due to the nonsymmetry of the right section, the point O is not the centre of gravity of the right section.*

## 3 Modelling A

### 3.1 Modelling characteristics

The model used is POU_D_EM.

The calculation is performed by choosing a reference axis, using keyword COOR_AXE_POUTRE from the DEFI_GEOM_FIBRE operator, which is deliberately very eccentric: ${z}_{G}=0.5m$ .

### 3.2 Mesh characteristics

The mesh consists of 2 mesh cells of type SEG2.
