# v3.01.102 SSLL102 - straight beam subjected to unitary effort

**Summary:** This test allows simple verification of straight beams calculations and line-mounted pipe beams in mechanical of static linear structures. The model is linear.

Modellings A, B, C, D, F, G, I and J allow testing of the different elements types in *Code_Aster* . For each Modelling, three beams of different sections are calculated simultaneously: rectangle, circular, corner.

Modelling A also allows testing the change in the reference: the beam is oriented according to the trisector at the global benchmark, with the Modelling POU_D_E. Modelling B uses the Modelling POU_D_T. ModelingThis D uses the Modelling with the POU_D_TG spin.

Modelling E tests the load distributed on elements edges on mesh cells HEXA20.

Model F is a load distributed linearly with POU_D_E Modelling.

Model G is a load distributed linearly with POU_D_TG Modelling.

H Modelling allows testing a cross-sectional load that varies linearly with TUYAU_3M Modelling, on mesh cells SEG4, compared with POU_D_T Modelling, on mesh cells SEG2, for a hollow circular cross-section.

Modelling I takes over the loading of Modelling A for Modelling POU_D_EM.

The J Modelling corresponds to a load distributed linearly varying with the POU_D_EM Modelling.

The values tested are displacements, generalized effort, backrest reactions and constraints.

## 13 Summary of the results

This test simultaneously checks the correct functioning of elements POU_D_E, POU_D_T and POU_D_TG on 3 different types of sections. The perfect coincidence of the results with the analytical solutions ($\text{RDM}$ ) is normal, and must always be observed, since the solution is contained in the shape functions of the elements.

In addition, the E Modelling allows testing the load distributed on elements edges. the difference to the analytical solution ($\text{RDM}$) is less than $\text{0.6\%}$.
