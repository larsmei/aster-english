# u4.61.11 Operator NUME_DDL

## 1 Purpose

Number the unknowns of a system of linear equations. This operator also “prepares” the assembly of the matrix associated with this system of equations.

It is in this operator that the method for solving the linear systems is chosen: LDLT, conjugate gradient, multifrontal…

Produces a data structure of type nume_ddl.

## 2 Syntax

```text
nume_ddl = NUME_DDL(
    ◆ / MATR_RIGI = matr_elem_pres_c / matr_elem_depl_r / matr_elem_temp_r / matr_elem_depl_c,
      / MODELE = modele,
    # Si: exists("MODELE")
        ◇ CHARGE = char_ther / char_meca / char_acou,
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 General points

This command makes it possible to number the equations (and the unknowns) of the linear systems to be solved. One also prepares the work of assembling the matrices, by establishing the pointer tables corresponding to the storage of these matrices.

## 4 Operands

### 4.1 Operand MODELE / CHARGE

```text
♦    / MODELE = mo , CHARGE = lchar
```

```text
Le code numérotera les degrés de liberté des éléments du modèle mo ainsi que les degrés de liberté de dualisation des conditions cinématiques dualisées éventuellement présentes dans les charges de la liste lchar.
```

### 4.2 Operand MATR_RIGI

```text
♦    / MATR_RIGI = lmel
```

List of the matr_elem_* making it possible to establish the numbering of the unknowns of the problem.

The aim of this operator is to number all the degrees of freedom of the problem. These degrees of freedom are those carried by the elementary matrices computed by the operator CALC_MATR_ELEM (lmel).

Because of the dualisation of the “kinematic” conditions, the Lagrange degrees of freedom are carried by the matr_elem computed by the option 'RIGI_MECA' (or 'RIGI_THER', ...) on the loads where the kinematic conditions are defined.

It is therefore important to give in lmel the list of all the “stiffness” matr_elem and not to forget the loads in the operator CALC_MATR_ELEM [U4.61.01](doc:u4.61.01).

### 4.3 Operand INFO

```text
◊    INFO =
```

```text
/    1    sur le fichier MESSAGE.
```

- total number of degrees of freedom, number of nodes,
- number of LAGRANGE degrees of freedom,
- maximum height of a column (and mean height),
- number of terms stored (for the storage 'MORSE'),
