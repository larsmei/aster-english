# v1.01.309 ZZZZ309 - Validation of ZONE_MAJ and TORE topological options in DEFI_GROUP

**Summary:**

This computer test is designed to validate the topological options ZONE_MAJ and TORE available in DEFI_GROUP for a model containing one or more X-FEM cracks. These options allow you to define groups of nodes around the bottom of the crack to facilitate the post-processing.

## 1 Reference problem

### 1.1 Geometry

A $10\times 10\times 10\mathit{mm}$-sized cube is considered to have a crack on one side (Figure ).

![Figure](/figures/v1.01.309/10000201000002EA000002B3FFA4C6F101FA6B69.png)

**Figure** 1.1-a **: cracked geometry of the structure**

### 1.2 Material properties

A material is used with the following elastic properties: $E=70000\mathit{MPa}$ and $\nu =0.34$ .

These properties are used by PROPA_FISS for the calculation of the number of fatigue cycles. However, the finished elements model is not solved and the number of cycles need not be calculated, which makes the choice of Material properties arbitrary.

### 1.3 Boundary conditions and loads

No boundary condition is defined because the elements model is not solved: a propagation of the existing crack with constant displacement and imposed displacement along the bottom is calculated in $I$ mode. The crack remains flat during propagation.

We impose an advance equal to $\Delta a=1\mathrm{mm}$ . The bottom of the crack spreads while always remaining straight.

### 1.4 Initial conditions

The initial crack is a half-plane. Its length is equal to ${a}_{0}=4\mathit{mm}$. The bottom of the crack is straight.

## 2 Test principle

We must check that the nodes groups defined by ZONE_MAJ and TORE options are correct (see U4.22.01 documentation for the description of these two options). To perform this check, we will build the group expected by the geometric options available in DEFI_GROUP and compare its nodes with those contained in the group built by the option to be checked.

Indeed, this is possible because the bottom of the crack is straight and therefore the geometric location of the nodes of the created group is always a cylinder built around the bottom whose radius is known to be prior to the creation. Therefore, CREA_GROUP_NO/OPTION='ENV_CYLINDRE' of DEFI_GROUP can be used to create the node group contained in the cylinder.

To simplify the determination of the cylinder radius, the RAYON_TORE option is used in PROPA_FISS (see U4.82.11 documentation for the description of this option), which allows the specification of the radius of the update area. In the case of using an auxiliary grid and checking the group created by ZONE_MAJ on the mesh structure (see Model D), the radius of the cylinder is independent of that specified by the RAYON_TORE option by being coinciding with the projection radius between auxiliary grid and mesh of the structure. In this case its value is equal to the sum of the imposed advance ($1\mathit{mm}$) and the convergence radius specified by RAYON in PROPA_FISS (see U4.82.11 for the description of this option).

In any case, the node group expected must be determined in the same way as the PROPA_FISS algorithm (see R7.02.13 documentation). The nodes contained in the cylinder must be determined first. Then select all elements containing at least one of these nodes in their definition. The node group expected is the one formed by the nodes of the selected elements.

To compare the lists of nodes contained in each group (anticipated group and group built by the option to be checked), nodes fields are used. For each group, nodes field is built by assigning the $1.0$ value to the nodes that are in the group and the $0.0$ value to the other nodes. Then the node difference by node between the two fields is calculated and the nodes field is obtained. If the two groups are identical, the difference field contains only zeros, which can be tested by checking that the maximum and minimum values of the field are $0.0$.

## 3 Modelization A: Geometric method

### 3.1 Modelling characteristics

The ZONE_MAJ option is tested. The cylinder radius ($4\mathrm{mm}$) coincides with the tore radius imposed by RAYON_TORE in PROPA_FISS.

### 3.2 Mesh characteristics

The mesh is composed by 1000 elements of type HEXA8. The edge length of the elements of the mesh is $1\mathrm{mm}$.

![Figure](/figures/v1.01.309/10000201000002AE000002784F50B420507E0A57.png)

**Figure** 3.2-a **: mesh of the figure solid**

### 3.3 Tested quantities and results

The maximum and minimum values of the difference field are tested to be zero.

The ZONE_MAJ option therefore correctly calculates the node group where the crack level-set has been updated.

## 4 Modelling B: geometric method

### 4.1 Modelling characteristics

We don't use an auxiliary grid. We'll test the TORE option. The cylinder radius ($4\mathrm{mm}$) coincides with the tore radius.

### 4.2 Mesh characteristics

The same mesh is used as model A.

### 4.3 Tested quantities and results

The maximum and minimum values of the difference field are tested to be zero.

The TORE option therefore correctly calculates the node group that belongs to the given radius tore built around the bottom of the crack.

## 5 Modelization C: geometric method

### 5.1 Modelling characteristics

An auxiliary grid is used. The ZONE_MAJ option will be tested on the auxiliary grid. The radius of the cylinder ($4\mathrm{mm}$ ) defined on the auxiliary grid coincides with that of the tore imposed by RAYON_TORE in PROPA_FISS.

### 5.2 Mesh characteristics

The same mesh is used as the Modelling A. This mesh is also used to define the auxiliary grid.

### 5.3 Tested quantities and results

The maximum and minimum values of the difference field are tested to be zero.

The ZONE_MAJ option therefore correctly calculates the node group on the auxiliary grid where the level set of the crack has been updated.

## 6 Modelling D: geometric method

### 6.1 Modelling characteristics

An auxiliary grid is used. The ZONE_MAJ option will be tested on the mesh of the structure. The radius of the cylinder ($2\mathrm{mm}$) defined on the mesh of the structure coincides with the projection radius of the level-set between the grid and the mesh. This radius is the sum of the imposed advance ($1\mathrm{mm}$) and the convergence radius ($1\mathrm{mm}$) imposed by RAYON in PROPA_FISS.

### 6.2 Mesh characteristics

The same mesh is used as the Modelling A. This mesh is also used to define the auxiliary grid.

### 6.3 Tested quantities and results

The maximum and minimum values of the difference field are tested to be zero.

The ZONE_MAJ option therefore correctly calculates the node group of the structure where the crack level-set has been updated by projection of the auxiliary grid values.

### 7.2 Mesh characteristics

## 8 Modelling F: SIMPLEXE method

### 8.1 Modelling characteristics

### 8.2 Mesh characteristics

The same mesh is used as model A.

## 9 Summary of the results

It was verified that ZONE_MAJ and TORE options correctly determine the nodes where the level-set was updated by PROPA_FISS on both the mesh structure and the auxiliary grid.
