# u4.33.01 Operator IMPR_FONCTION

## 1 Purpose

Print the content of objects of type fonction or list of reals in a file intended for a curve plotter.

**Note:**

*Tables, for their part,* *are printed with the command* IMPR_TABLE *.*

## 2 Syntax

```text
IMPR_FONCTION(
    ◇ FORMAT = / "TABLEAU" (par défaut),
               / "AGRAF",
               / "XMGRACE",
               / "LISS_ENVELOP",
    # Si: equal_to("FORMAT", 'XMGRACE')
        ◇ PILOTE = / "" (par défaut),
                   / "POSTSCRIPT",
                   / "EPS",
                   / "MIF",
                   / "SVG",
                   / "PNM",
                   / "PNG",
                   / "JPEG",
                   / "PDF",
                   / "INTERACTIF",
                   / "INTERACTIF_BG",
        ◇ UNITE = unit (défaut: 29),
    # Si: equal_to("FORMAT", 'AGRAF')
        ◇ UNITE = unit (défaut: 25),
        ◇ UNITE_DIGR = unit (défaut: 26),
    # Si: not equal_to("FORMAT", 'LISS_ENVELOP')
        ◆ COURBE = _F(
             ◆ / FONCTION = formule / fonction_c / fonction / nappe,
               / LIST_RESU = listr8,
               / FONC_X = formule / fonction,
               / ABSCISSE = float,
             # Si: exists("FONCTION")
                 ◇ LIST_PARA = listr8,
             # Si: is_type("FONCTION") in (fonction_c, formule_c)
                 ◇ PARTIE = / "REEL",
                            / "IMAG",
             # Si: exists("LIST_RESU")
                 ◆ LIST_PARA = listr8,
             # Si: exists("FONC_X")
                 ◆ FONC_Y = formule / fonction,
                 ◇ LIST_PARA = listr8,
             # Si: exists("ABSCISSE")
                 ◆ ORDONNEE = float,
             ◇ LEGENDE = text,
             ◇ STYLE = int,
             ◇ COULEUR = int,
             ◇ MARQUEUR = int,
             ◇ FREQ_MARQUEUR = int,
             ◇ TRI = / "N" (par défaut),
                     / "X",
                     / "Y",
                     / "XY",
                     / "YX",
          ),
    # Si: equal_to("FORMAT", 'LISS_ENVELOP')
        ◆ COURBE = _F(
             ◆ / NAPPE = nappe,
               / NAPPE_LISSEE = nappe,
          ),
    # Si: equal_to("FORMAT", 'TABLEAU')
        ◇ UNITE = unit (défaut: 8),
        ◇ TITRE = text,
        ◇ SOUS_TITRE = text,
        ◇ SEPARATEUR = text (défaut: " "),
        ◇ COMMENTAIRE = text (défaut: "#"),
        ◇ COMM_PARA = text,
        ◇ DEBUT_LIGNE = text,
        ◇ FIN_LIGNE = text (défaut: "
"),
        ◇ FORMAT_R = text (défaut: "E12.5"),
    # Si: not equal_to("FORMAT", 'TABLEAU')
        ◇ TITRE = text,
        ◇ SOUS_TITRE = text,
        ◇ BORNE_X = float,
        ◇ BORNE_Y = float,
        ◇ ECHELLE_X = / "LIN" (par défaut),
                      / "LOG",
        ◇ ECHELLE_Y = / "LIN" (par défaut),
                      / "LOG",
        ◇ GRILLE_X = float,
        ◇ GRILLE_Y = float,
        ◇ LEGENDE_X = text,
        ◇ LEGENDE_Y = text,
    # Si: equal_to("FORMAT", 'LISS_ENVELOP')
        ◇ UNITE = unit (défaut: 25),
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Presentation of the curves

A set of optional operands makes it possible to define the presentation of the curve. All have a default value.

#### 3.1.1 Operand FORMAT

```text
◊    FORMAT=
```

Printout format of the function

| 'AGRAF' | printout intended for the agraf software, which also makes it possible to adjust the presentation parameters interactively, |
| --- | --- |
| 'TABLEAU' | the column printout makes it easy to import the data into a spreadsheet; if several curves are given, it is the list of abscissae of the first function which is used to interpolate the values of the other functions, |
| 'XMGRACE' | printout intended for the xmgrace software. One can also adjust the presentation parameters interactively. The use of the keyword PILOTE makes it possible to produce an image or postscript file directly. |
| 'LISS_ENVELOP' | printout intended for the spectra coming from CALC_FONCTION/LISS_ENVELOP. The curves are plotted using the Python Matplotlib libraries available in the Salomé-Méca distribution. |

**Note**

*The format* XMGRACE *is intended for version 5 of grace and is not compatible with grace6 (version 5.99).*

#### 3.1.2 Operand PILOTE

By choosing FORMAT = 'XMGRACE', one has the output drivers used by xmgrace by using the keyword PILOTE. This amounts to using the export functions of xmgrace via its menu "File/Print Setup …".

The exact list of the drivers available on your server is supplied by the "-version" option of xmgrace.

Possible values of PILOTE:

| '' | : | in this case, no driver is used, the file obtained is the .agr or .dat of xmgrace (file containing the data and the graphic directives). |
| --- | --- | --- |
| 'POSTSCRIPT', 'EPS' | : | full-page or encapsulated postscript file, |
| 'PNG', 'JPEG', 'PNM' | : | image-type file, |
| 'PDF', 'MIF', 'SVG' | : | particular formats, |
| 'INTERACTIF' | : | no file is returned if xmgrace can be opened on the screen. |
| 'INTERACTIF_BG' | : | As for INTERACTIF but xmgrace is launched in the background, the analysis continues. |

#### 3.1.3 Graph layout common to XMGRACE, AGRAF and LISS_ENVELOP

##### 3.1.3.1 Operands BORNE_X/BORNE_Y

```text
◊    BORNE_X=
```

Plotting of the function over a given abscissa interval.

```text
◊    BORNE_Y=
```

Plotting of the function over a given ordinate interval.

##### 3.1.3.2 Operands ECHELLE_X/ECHELLE_Y

```text
◊    ECHELLE_X=
```

Type of scale required for the abscissae, LINear or LOGarithmic.

```text
◊    ECHELLE_Y=
```

Type of scale required for the ordinates, LINear or LOGarithmic.

##### 3.1.3.3 Operands LEGENDE_X/LEGENDE_Y

```text
◊    LEGENDE_X=
```

Legend associated with the abscissa axis.

```text
◊    LEGENDE_Y=
```

Legend associated with the ordinate axis.

##### 3.1.3.4 Operands GRILLE_X/GRILLE_Y

```text
◊    GRILLE_X= nx
```

For xmgrace, nx is the distance between two successive vertical grid lines.

For agraf, nx is the integer defining the plotting frequency of these lines.

```text
◊    GRILLE_Y= ny
```

The same for the horizontal lines of the grid.

#### 3.1.4 Layout in TABLEAU format

See IMPR_TABLE [U4.91.03](doc:u4.91.03) for the description of the formatting keywords (DEBUT_LIGNE, COMMENTAIRE...).

**Note:**

The column labels are suffixed by «_ + column number» (starting at 0) in order to avoid repetition, because the column names must all be different.

#### 3.1.5 Keywords common to all the formats

```text
◊    TITRE

◊    SOUS_TITRE
```

Make it possible to define the main and secondary titles of the graph or of the table.

If FORMAT=LISS_ENVELOP then the titles and subtitles are used to fill the title blocks of the graph. The subtitle must follow the nomenclature «Storey, Details» so that the two boxes are filled correctly. If the subtitle contains more than one comma, the elements contained after the second comma will not be taken into account in the title block.

**Note**

*The value of the* TITRE *stored by certain commands (example* RECU_FONCTION *) in the function objects is not used by* IMPR_FONCTION *.*

### 3.2 Keyword COURBE

```text
♦    COURBE
```

Factor keyword making it possible to print the defined functions or to plot one or more functions in the same graph (one function per occurrence of the factor keyword).

#### 3.2.1 Additional attributes for the plotting of each function by the xmgrace or agraf software

```text
◊    STYLE= sty
```

This keyword defines the line style of the curve.

**For** **xmgrace**, the correspondence is as follows:

| 0 no line | 1 continuous line | 2 dotted | 3 short dashes | 4 long dashes |
| --- | --- | --- | --- | --- |

5, 6, 7, 8 alternating dotted dashes

**For** **agraf**, the styles are:

| 0 line | 1 dotted | 2 point |
| --- | --- | --- |

```text
◊    MARQUEUR= marq
```

This keyword defines the type of marker or symbol of the points of the curve.

**For** **xmgrace**:

| 0 no marker | 1 circle | 2 square | 3 diamond | 4 up triangle |
| --- | --- | --- | --- | --- |
| 5 left triangle | 6 down triangle | 7 right triangle | 8 plus | 9 cross |
| 10 star |  |  |  |  |

**For** **agraf**, the markers are:

| 0 circle | 1 square | 2 plus | 3 diamond | 4 filled circle |
| --- | --- | --- | --- | --- |
| 5 filled square | 6 filled diamond | 7 circle+cross | 8 diamond+cross |  |

```text
◊    COULEUR= coul
```

This keyword defines the colour of the curve.

**For** **xmgrace**, the colours are:

| 0 white | 1 black | 2 red | 3 green | 4 blue |
| --- | --- | --- | --- | --- |
| 5 yellow | 6 brown | 7 grey | 8 purple | 9 cyan |
| 10 magenta | 11 orange | 12 maroon | 13 indigo | 14 turquoise |
| 15 dark green |  |  |  |  |

**For** **agraf**, the colours are:

| 0 black | 1 red | 2 dark green | 3 blue | 4 magenta |
| --- | --- | --- | --- | --- |
| 5 cyan | 6 green | 7 maroon | 8 orange | 9 mauve |
| 10 yellow | 11 light brown |  |  |  |

```text
◊    LEGENDE = legende
```

Legend given to the function (by default the name of the function is recovered).

```text
◊    FREQ_MARQUEUR=    freqmarq
```

Integer indicating the print frequency of the marker associated with a function. Every freqmarq discretisation points of the function, a marker is printed (by default every point).

#### 3.2.2 Additional attributes for plotting by the agraf software

```text
◊    TRI= tr
```

This keyword makes it possible to sort in ascending order the parameters defining the function:

- tr = ‘N’, no sorting,
- tr = ‘X’, sorting of the points of the function in ascending order of the abscissae x,
- tr = ‘Y’, sorting of the points of the function in ascending order of the ordinates y,
- tr = ‘XY’, sorting of the points of the function in ascending order of the abscissae x and, in the event of equality, in ascending order of the ordinates,
- tr = ‘YX’, sorting of the points of the function in ascending order of the ordinates y and, in the event of equality, in ascending order of the abscissae,

#### 3.2.3 Printout or plotting of a real function

```text
/    ♦    FONCTION= fr
```

Name of the real function to be printed or plotted.

```text
◊    LIST_PARA= lr
```

Printout or plotting of the function according to the list of parameters given.

#### 3.2.4 Printout or plotting of a complex function

One plots either the real part or the imaginary part. If one wishes to plot the real part and the imaginary part in the same graph, the factor keyword COURBE must be repeated.

```text
/    FONCTION= fc
```

Name of the complex function to be printed or plotted.

```text
◊    PARTIE=
```

Printout or plotting of the REEL part or of the IMAG part.

```text
◊    LIST_PARA= lr
```

Printout or plotting of the function according to the list of parameters given.

No effect during a column printout (format 'TABLEAU').

#### 3.2.5 Printout or plotting of a function defined by 2 lists of reals

```text
/    ♦    LIST_PARA= lpara
```

Name of the list of abscissae.

```text
♦    LIST_RESU= lresu
```

Name of the list of ordinates.

Or else:

```text
/    ♦    ABSCISSE = labs
```

Python list of the abscissae.

```text
♦    ORDONNEE = lordo
```

Python list of the ordinates.

#### 3.2.6 Printout or plotting of a parametric function

```text
/    ♦    FONC_X= fx
```

Name of the parametric function x=f(t) to be printed or plotted.

```text
♦    FONC_Y= fy
```

Name of the parametric function y=g(t) to be printed or plotted.

```text
◊    LIST_PARA= lr
```

Printout or plotting of the function according to the list of parameters given.

#### 3.2.7 Operand UNITE

```text
◊    UNITE= unit
◊    UNITE_DIGR = unit_digr si FORMAT = 'AGRAF'
```

Make it possible to choose on which logical unit the functions are printed.

If one plots numerous curves, it is more flexible to use the repe type combined with the command DEFI_FICHIER; the files will be in the directory ./REPE_OUT.

In AGRAF format, the data are written to UNITE whereas the directives are written to UNITE_DIGR (equal to 26 by default).

The default value of unit is:

- 8 in TABLEAU format,
- 25 in AGRAF format,
- 29 in XMGRACE format (optional if PILOTE = 'INTERACTIF/_BG'),
- 25 in LISS_ENVELOP format.

#### 3.2.8 Plotting of a nappe or of a smoothed nappe

```text
/    ♦    NAPPE= nappe
```

Name of the raw nappe to be plotted. The plot will be drawn as dashes.

```text
♦    NAPPE_LISSEE= nappe
```

Name of the smoothed nappe to be plotted. The plot will be drawn as a solid line.

The values of the smoothed nappe will be entered in a table under the curve. If several smoothed nappes are supplied, the last one entered will be taken into account for the table.

#### 3.2.9 Functionalities which existed in IMPR_COURBE

The formatting of graphs from a table is now handled by IMPR_TABLE.

The plotting of a resu_gene at a shock node must be done in two stages: recover a function with RECU_FONCTION, keyword RESU_GENE, then print the graph with IMPR_FONCTION.

## 4 Examples

### 4.1 Curve representing a complex function

fc = DEFI_FONCTION( NOM_PARA='INST', NOM_RESU='DX',

VALE_C=(0., 0., 0., 1., 2., 3.,

2., 3., 4., 3., 4., 5.,

4., 5., 6., 5., 6., 7. ),)

IMPR_FONCTION(

UNITE = 24,

FORMAT = 'XMGRACE',

PILOTE = 'POSTSCRIPT',

LEGENDE_X = 'Temps (s)',

LEGENDE_Y = 'DX (mm)',

COURBE = (

_F(FONCTION = fc,

PARTIE = 'REEL',

COULEUR = 4,

STYLE = 2,

MARQUEUR = 5,

LEGENDE = 'partie réelle',),

_F(FONCTION = fc,

PARTIE = 'IMAG',

COULEUR = 2,

STYLE = 5,

MARQUEUR = 8,

LEGENDE = 'partie imaginaire',),

),

TITRE = "Tracé d'une fonction complexe",

)

### 4.2 Parametric curve

lt = DEFI_LIST_REEL(DEBUT = 0., INTERVALLE=_F(JUSQU_A=10., PAS=0.01),)

fx = FORMULE(NOM_PARA='t',

VALE="""2.*cos(t) - cos(2.*t)""",)

cardioX=CALC_FONC_INTERP(

FONCTION = fx,

LIST_PARA = lt,)

fy = FORMULE(NOM_PARA='t',

VALE="""2.*sin(t) - sin(2.*t)""",)

cardioY=CALC_FONC_INTERP(

FONCTION = fy,

LIST_PARA = lt,)

IMPR_FONCTION(

UNITE = 27,

FORMAT = 'XMGRACE',

TITRE = 'Cardioide',

COURBE = (

_F(FONC_X = cardioX,

FONC_Y = cardioY,),

),

)
