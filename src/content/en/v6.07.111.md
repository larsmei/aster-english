# v6.07.111 COMP011 – Thermomechanical validation of concrete laws

**Summary**

This test validates the temperature variation in the constitutive laws for concrete. These tests allow to verify the following two points:

- The thermal expansion is well calculated (with consideration of the variation of thermal expansion with temperature).
- The variation of material coefficients with temperature is correct, especially in incremental behavior resolution.

The validated laws of behaviour are as follows:

- Modelling A: This Modelling allows to validate the BETON_REGLE_PR model.
- Modelling B: This Modelling allows to validate the MAZARS model.
- Modelling C: This Modelling allows to validate the BETON_UMLV model.
- Modelling D: This Modelling allows to validate the BETON_DOUBLE_DP model.
- Modelling E: This Modelling allows to validate the ENDO_ISOT_BETON model.
- Modelling F: This Modelling allows to validate the BETON_BURGER model.
- Modelling G: This Modelling allows to validate the MAZARS_UNIL model.
- H Modelling: This Modelling validates the Leverett isotherm hygrometry calculation (BETON_DESORP/LEVERETT='OUI').

## 1 Methodology

It is a double simulation, the first in thermo-mechanical, the second in pure mechanics. The first will be validated in comparison with the second, assuming of course that the behaviour tested provides a correct solution in pure mechanics.

### 1.1 Simulation 1

The first simulation (the thermo-mechanical solution that is being validated) consists of applying a temperature variation to a material point, blocking deformations according to the $x$ ${\varepsilon}_{xx}=0$ direction. The temperature imposed is increasing linearly as a function of time.The temperature varies from ${T}_{0}=20°C$ to ${T}_{max}=500°C$.The transient is constituted byNCAL not.The reference temperature is ${T}_{\mathit{réf}}=20°C$.

### 1.2 Simulation 2

The second simulation (which must be equivalent to the first) consists of applying to the same point material a deformation imposed following $x$: ${\varepsilon}_{xx}=-{\varepsilon}^{\mathit{th}}=-\alpha (T)(T-{T}_{\mathit{ref}})$, in pure mechanics. Each $i$ calculation, the load imposed consists of the thermal deformation ${\varepsilon}_{xx}=-{\varepsilon}_{\mathit{th}}=-\alpha (T)({T}_{i}-{T}_{\mathit{réf}})$. The initial load consists of the deformations, stresses and internal variables of the previous mechanical calculation.

Indeed, for any behavior (assuming the additive decomposition of deformations):

${\sigma}_{xx}=E(T)({\varepsilon}_{xx}-{\varepsilon}^{\mathrm{th}}-{\varepsilon}_{xx}^{p})$

in the first case, ${\sigma}_{xx}=E(T)(0-{\varepsilon}^{\mathrm{th}}-{\varepsilon}_{xx}^{p})$, and in the second: ${\sigma}_{xx}=E(T)(\varepsilon -{\varepsilon}_{xx}^{p})$.

Therefore, at every moment, you can apply ${\varepsilon}_{xx}=-{\varepsilon}^{\mathrm{th}}=-\alpha (T)(T-{T}_{\mathrm{ref}})$ for mechanical calculation.

In addition, to obtain the same results in both cases, it is necessary, at each time step of the second simulation, to perform the pure mechanical calculation with coefficients whose values are interpolated according to the temperature at the current moment. This interpolation is performed in the command file of the test, in a loop in outside time at STAT_NON_LINE.

## 2 Interpretation of results

The purpose is to verify that the result obtained at each moment of the thermo-mechanical transient of the first simulation is identical to the result obtained with the second simulation.

The validation is done by comparing the fields calculated at each step of the transient on the one hand with the result of a mechanical calculation on the other, the reference value being the component of the field extracted at a given moment $i$ from the first thermo-mechanical simulation performed on NCAL moments. The calculated value is that obtained at the end of the mechanical calculation $i+1$ of the loop on the NCAL.

## 10 Modelling H

This Modelling is very similar to Modelling F. It is intended to test the calculation of the Leverett isotherm hygrometry (see BETON_DESORP).

### 10.1 Principle

To validate the consideration of the material parameters of BETON_DESORP to define the Leverett isotherm and check the correct assessment of the hygrometry in this case,
a first calculation is made considering the Leverett isotherm via a python formula which is provided to FONC_DESORP of BETON_DESORP/LEVERETT='NON'.

In the second calculation, the Leverett isotherm is declared via BETON_DESORP/LEVERETT='OUI'.
The first calculation provides the reference values for the second.

This is a computer test.

## 11 General summary of results

For each of the constitutive laws studied, the thermomechanical transient results of the first simulation are compared with those obtained with the second pure mechanical simulation. The results are consistent, showing the correct consideration of thermal expansion by these constitutive laws, as well as the good dependence of material parameters on temperature.

- Modelling F: This Modelling allows to validate the BETON_BURGER model.
