# v1.01.313 ZZZZ313 – Test for verification of the rumpy/lapack

**Summary:**

This test has no physical meaning, it is a computer test that is used to check the proper functioning of certain numpy features. In particular, some functions (cholesky decomposition, calculation of values and own vectors) that have already been problematic in lapack routines on particular matrices are used.

The values tested are values of non-regression.

This documentation is deliberately succinct.
