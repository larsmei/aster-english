# v2.06.100 SHLL100 - Harmonic response of a bar by dynamic substructure

**Summary:**

The scope of this test is concerned with structural dynamics, and in particular with the calculation of harmonic response by dynamic substructure.

The purpose is to calculate the harmonic response in traction-compression of a clamped-free beam modeled by elements bar type. The modeled structure is amortized (amortization of Rayleigh by elements).

The reference results are derived from a direct harmonic calculation. This test is used to validate the harmonic response calculation tools by substructure implanted in *Code_Aster* and more specifically:

- taking into account the depreciation by element,
- the calculation of the second member including the harmonic loading,
- the return of the harmonic response on a skeleton mesh, including the fields of displacement, speed and acceleration.

## 2 reference solution

### 2.1 Calculation method used for reference solution

There is a detailed analytical solution in the reference [bib2].

Use the following notations:

| $E$ | : | Young's modulus |
| --- | --- | --- |
| $L$ | : | length of bar |
| $A$ | : | section of the bar |
| $N$ | : | normal effort directed on $X$ axis |
| $\alpha ,\beta$ | : | Rayleigh depreciation coefficients |
| $\Omega$ | : | frequency of excitement |

and positons

$r=\sqrt{\frac{1+{\beta}^{2}/{\Omega}^{2}}{1+{\alpha}^{2}/{\Omega}^{2}}}$

$k=p+\mathit{iq}=\Omega \sqrt{\frac{p}{2E}}\left[\sqrt{r-\frac{1-\alpha \beta }{1+{\alpha}^{2}{\Omega}^{2}}}+i\sqrt{r+\frac{1-\alpha \beta }{1+{\alpha}^{2}{\Omega}^{2}}}\right]$

The displacement in any point $M(x)$ is given by:

$V(x)=\frac{N}{\mathit{EA}}\frac{A}{(p+\mathit{iq})(1+i\Omega \alpha )}\frac{\mathit{sh}\mathit{px}\cos\mathit{qx}+i\mathit{ch}\mathit{px}\sin\mathit{qx}}{\mathit{ch}L\cos\mathit{qL}+i\mathit{sh}\mathit{pL}\sin\mathit{qL}}$

## 3 Modelling A

### 3.1 Modelling characteristics

![Figure](/figures/v2.06.100/10000BC40000300F0000106FEC878AC3FC7E2431.svg)

The bar is cut into 2 parts of equal dimensions. Each substructure is meshed into segments to which elements "bar" are assigned.

The structure is studied using the harmonic substructure method with CRAIG-BAMPTON HARMONIQUE interfaces.

The modal base used is composed of 4 modes for the right-hand substructure, 5 modes for the left-hand substructure, plus the harmonic forced modes associated with the interfaces (calculated at $300\mathrm{Hz}$ . This value of the pulse has no influence on the result, it is arbitrary [bib3]).

### 3.2 Mesh characteristics

Number of nodes: 5

Number of mesh cells and types : 5SEG 2
