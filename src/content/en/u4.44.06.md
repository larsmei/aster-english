# u4.44.06 AFFE_CHAR_GENE

## 1 Purpose

Assign boundary conditions on a generalised model.

Produces a data structure of type char_gene.

## 2 Syntax

```text
char_gene = AFFE_CHAR_GENE(
    ◆ NUME_DDL_GENE = nume_gene,
    ◆ LIAISON_DDL = _F(
           ◆ NUME_MODE = list[int],
           ◆ COEF_MULT = list[float],
           ◆ COEF_IMPO = float,
        ),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Keyword NUME_DDL_GENE

Numbering associated with the generalised model.

### 3.2 Keyword LIAISON

The keyword LIAISON makes it possible to define a linear relation between modes.
The following condition will be applied:

With ${M}_{i}$ the list of the $N$ generalised degrees of freedom (each corresponding to a mode),
${\alpha}_{i}$ the coefficients and $\beta$ the right-hand side.

NUME_MODE gives the **ordered** list of the $N$ generalised degrees of freedom ${M}_{i}$.

COEF_MULT gives the **ordered** list of the $N$ **real** coefficients ${\alpha}_{i}$.

COEF_IMPO is the value of the linear relation $\beta$.
