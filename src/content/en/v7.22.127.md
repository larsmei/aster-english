# v7.22.127 HSNV127 – Traction-slicing plate: viscoplasticity with isotropic hardening

**Summary:**

This non-linear quasi-static mechanical test consists of loading a square plate in a tensile-strain. This validates the relationship of viscoplasticity behavior with isotropic hardening ($\mathrm{3D}$) for radial loading.

The plate is represented by a volume element (HEXA8) and is modelled in two different but equivalent ways: either with the META_V_INL model (modelling A) or with the VISC_CIN1_CHAB model (modelling B).

The same response must then be obtained for both modellings A and B.

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v7.22.127/10000B38000014C60000103A0EC8987E1C654415.svg)

### 1.2 Material properties

$E=195000\mathit{MPa}$

$\nu =0.3$

Shaboche viscoplastic behavior relationship (VISC_CIN1_CHAB):

$N=3.5$

$K=600.$

$\text{UN\_SUR\_M}=0.$

$\text{R\_0}=30.$

$\text{R\_I}=300.$

$B=100.$

### 1.3 Boundary conditions and loads

On $A$ : ${u}_{x}={u}_{y}=0$

On the side $\mathit{AB}$ : ${u}_{x}=0$

Loading:

1. Traject from 0 to point (${\tau}_{d}=146\mathit{MPa}$ , ${\sigma}_{d}=242\mathit{MPa}$ ) for 10 seconds,
2. Hold time in this 50 seconds point.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The validation of the VISC_CIN1_CHAB law is done by comparing the two modellings A and B.

> Each of the two modellings is therefore one reference solution for the other.

### 2.2 Baseline

Deformations to point $B$ , $t=\mathrm{10.0s}$ and $t=60.0$ moments .

### 2.3 Uncertainty about the solution

Not applicable (intercomparison of two modellings).
