# u4.33.03 Procedure CALC_TABLE

## 1 Purpose

Manipulate the data of tables in the manner of a spreadsheet.

The command makes it possible to carry out operations on the data of the tables. The following operations are currently available:

- Concatenate / Combine two tables,
- Apply a formula,
- Rename parameters,
- Filter the lines according to certain criteria,
- Extract certain columns of a table,
- Order the lines,
- Add lines or columns,
- Add information on the table itself.

Produces a data structure table.

## 2 Syntax

```text
/ table
/ table_container
/ table_fonction = CALC_TABLE(
    ◇ reuse = <objet de TABLE>,
    ◆ TABLE = table,
    ◆ ACTION = _F(
         ◆ OPERATION = / "AJOUT_COLONNE",
                       / "AJOUT_LIGNE",
                       / "CALCUL",
                       / "COMB",
                       / "EXTR",
                       / "FILTRE",
                       / "OPER",
                       / "RENOMME",
                       / "STATISTIQUES",
                       / "SUPPRIME",
                       / "TRI",
                       / "UNIQUE",
         # Si: equal_to("OPERATION", 'FILTRE')
             ◆ NOM_PARA = text,
             ◇ CRIT_COMP = / "EQ" (par défaut),
                           / "GE",
                           / "GT",
                           / "LE",
                           / "LT",
                           / "MAXI",
                           / "MAXI_ABS",
                           / "MINI",
                           / "MINI_ABS",
                           / "NE",
                           / "NON_VIDE",
                           / "REGEXP",
                           / "VIDE",
             # Si: (is_in("CRIT_COMP", ('EQ','NE','GT','LT','GE','LE')))
                 ◆ / VALE = float,
                   / VALE_I = int,
                   / VALE_K = text,
                   / VALE_C = complex,
             # Si: equal_to("CRIT_COMP", 'REGEXP')
                 ◆ VALE_K = text,
             # Si: is_in("CRIT_COMP", ('EQ','NE'))
                 ◇ CRITERE = / "ABSOLU",
                             / "RELATIF" (par défaut),
                 ◇ PRECISION = float (défaut: 0.001),
         # Si: equal_to("OPERATION", 'EXTR')
             ◆ NOM_PARA = text,
         # Si: equal_to("OPERATION", 'SUPPRIME')
             ◆ NOM_PARA = text,
         # Si: equal_to("OPERATION", 'UNIQUE')
             ◆ NOM_PARA = text,
             ◇ FORMAT_R = text,
         # Si: equal_to("OPERATION", 'RENOMME')
             ◆ NOM_PARA = text,
         # Si: equal_to("OPERATION", 'TRI')
             ◆ NOM_PARA = text,
             ◇ ORDRE = / "CROISSANT" (par défaut),
                       / "DECROISSANT",
         # Si: equal_to("OPERATION", 'COMB')
             ◆ TABLE = table,
             ◇ NOM_PARA = text,
             ◇ RESTREINT = / "NON" (par défaut),
                           / "OUI",
             ◇ FORMAT_R = text,
         # Si: equal_to("OPERATION", 'AJOUT_LIGNE')
             ◆ NOM_PARA = text,
             ◆ VALE = not_checked,
         # Si: equal_to("OPERATION", 'AJOUT_COLONNE')
             ◆ NOM_PARA = text,
             ◆ / VALE = not_checked,
               / VALE_COLONNE = not_checked,
         # Si: equal_to("OPERATION", 'OPER')
             ◆ FORMULE = formule,
             ◆ NOM_PARA = text,
             ◇ NOM_COLONNE = text,
         # Si: equal_to("OPERATION", 'CALCUL')
             ◆ NOM_PARA = text,
             ◆ TYPE_CALCUL = / "MAXI",
                             / "MAXI_ABS",
                             / "MINI",
                             / "MINI_ABS",
                             / "MOY",
                             / "SOMM",
                             / "SOMM_ABS",
      ),
    ◇ TITRE = text,
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand TABLE

```text
♦    TABLE = matable
```

Name of the initial table on which the manipulations will be carried out.

### 3.2 Operand ACTION

```text
♦    ACTION = (    _F(OPERATION='xxx', ...),                     _F(OPERATION='yyy',...),                 ...)
```

The “actions” are carried out one after the other. The operation 'yyy' takes the table in the state in which the operation 'xxx' left it.

It is distinctly more efficient to repeat the factor keyword ACTION than to make as many successive calls to the command CALC_TABLE.

### 3.3 OPERATION = 'COMB': concatenate/combine two tables

```text
L'opération COMBpermet de concaténer, de combiner deux tables entre elles, avec couture sur une liste de paramètres communs.
```

#### 3.3.1 Operand TABLE

```text
♦    TABLE     = table
```

Name of the table whose values are to overload and/or enrich the initial table.

#### 3.3.2 Operand NOM_PARA

```text
◊    NOM_PARA     = l_para
```

Name of the parameters whose values must be identical in the two tables.

#### 3.3.3 Operand FORMAT_R

This is a format which will be used before comparing two real numbers in order to determine whether they are identical or not. Note that, in the table, one recovers the unrounded value (from the second table).

#### 3.3.4 Operand RESTREINT

```text
◊    RESTREINT = 'OUI' ou 'NON'
```

Example of the combination of two tables:

tab_resu=CALC_TABLE(TABLE=tab1,

ACTION=_F(OPERATION='COMB',

TABLE=tab2,

NOM_PARA=('ABSC_CURV','NOEUD'),

RESTREINT='NON' ) )

When ABSC_CURV and NŒUD are identical between tab1 and tab2, the values of tab2 are inserted on the line of tab1 (for the other parameters common to the 2 tables, it is therefore the value of tab2 which overwrites that of tab1).

If ABSC_CURV and/or NŒUD differ between tab1 and tab2, the line of tab2 is added at the end of tab1. NOM_PARA acts as a primary key: if the pair (ABSC_CURV, NOEUD) is not found more than once, the line is added.

The same operation with RESTREINT='OUI' produces the same lines when ABSC_CURV and NŒUD are identical. On the other hand, no line is added when the parameters differ.

### 3.4 OPERATION = 'OPER': Apply a formula

```text
Permet d'appliquer une formule dont les variables sont les paramètres de la table et d'insérer le résultat dans une nouvelle colonne.
```

#### 3.4.1 Operand FORMULE

Name of the formula to be applied

#### 3.4.2 Operand NOM_PARA

Name of the new column.

#### 3.4.3 Operand NOM_COLONNE

This keyword makes it possible to use a formula whose parameters are not parameters of the table.

For example, one has a formula which depends on INST. If one wishes to evaluate this formula using the column INST_FIN of the table, it is sufficient to specify NOM_COLONNE='INST_FIN'.

### 3.5 OPERATION = 'RENOMME': Rename parameters of a table

The operation RENOMME makes it possible to rename one or more parameters of a table.

#### 3.5.1 Operand NOM_PARA

```text
♦    NOM_PARA     = l_para
```

Name of the parameters: pair of values (old name of the parameter, new name of the parameter)

### 3.6 OPERATION = 'FILTRE': Filter the lines according to certain criteria

This factor keyword makes it possible to filter the lines of the table. For the use of this keyword see the command IMPR_TABLE [U4.91.03](doc:u4.91.03).

### 3.7 OPERATION = 'EXTR': Extract certain columns of a table

```text
L'opération EXTRpermet d'extraire certaines colonnes d'une table.
```

#### 3.7.1 Operand NOM_PARA

```text
♦    NOM_PARA     = l_para
```

Name of the parameters which one wishes to extract.

### 3.8 OPERATION = 'TRI': Order the lines

```text
L'opération TRI permet d'ordonner les lignes selon les valeurs des paramètres.
```

#### 3.8.1 Operand NOM_PARA

```text
♦    NOM_PARA     = l_para
```

Names of the parameters on which the sorting bears.

#### 3.8.2 Operand ORDRE

```text
♦    ORDRE     =     /    'CROISSANT'
/    'DECROISSANT'
```

This keyword serves to specify whether an ascending or descending order must be used. By default, one sorts in ascending order.

The order relations used are:

- the natural order for the integers and the reals,
- the alphabetical order for the texts and the names of concepts.

**Notes:**

*One cannot use a complex parameter to rank the lines of a table.*

*For parameters of type* *NŒUD (or* *MAILLE), the order is alphabetical because these parameters contain the names of the nodes (or of the mesh cells).*

If one specifies:

```text
TRI=_F (NOM_PARA= ('NOEUD','INST'), ORDRE= 'CROISSANT'),
```

The lines of the table will be sorted in the alphabetical order of the nodes. If several lines corresponding to a given node exist, the **second** sorting criterion (INST) will be used to rank these lines.

### 3.9 OPERATION = 'AJOUT_LIGNE': add a line

```text
L'opération AJOUT_LIGNE permet d'ajouter une ligne à une table existante.
```

#### 3.9.1 Operand NOM_PARA

```text
♦    NOM_PARA     = lpara
```

Names of the parameters (names of the columns of the table) of the added line. One may very well define values only for certain columns of the table.

If a parameter name does not exist in the table, it is added. Its type is determined from the value supplied.

#### 3.9.2 Operand VALE

```text
♦    VALE     = lvale
```

List of the values for each parameter of NOM_PARA. The type of the values must be compatible with the types of the columns of the table.

VALE may contain heterogeneous values among integer, real, character string. The type must conform to the type of the parameter of the table.

The first value corresponds to the first parameter given in NOM_PARA, the second value to the second parameter, etc.

The lists NOM_PARA and VALE therefore have the same cardinality.

### 3.10 OPERATION = 'AJOUT_COLONNE': add a column

```text
L'opération AJOUT_COLONNE permet d'ajouter une ou plusieurs colonnes constantes (valeur identique pour toutes les lignes, en utilisant le mot-clé VALE), ou bien, une seule colonne avec des valeurs distinctes (en utilisant le mot-clé VALE_COLONNE).
```

#### 3.10.1 Operand NOM_PARA

```text
♦    NOM_PARA     = lpara
```

Names of the parameters, names of the columns added to the table. None of these parameters must already be present in the table.

Only one parameter must be supplied if VALE_COLONNE is used.

#### 3.10.2 Operand VALE

```text
♦    VALE     = lvale
```

List of the values of each column.

VALE may contain heterogeneous values among integer, real, character string. The type associated with the parameter is determined from this value.

The first value corresponds to the first parameter given in NOM_PARA, the second value to the second parameter, etc.

The lists NOM_PARA and VALE therefore have the same cardinality.

#### 3.10.3 Operand VALE_COLONNE

```text
♦    VALE_COLONNE    = lval_col
```

List of the values of the lines of the added column.

The type of the values supplied may be integer, real, character string. All the values must be of the same type.

The values are added on the lines as they are ordered at the time of the addition. There may be more or fewer values added than there are lines in the table. Either the column will be longer than the initial table, or it will contain empty values.

### 3.11 OPERATION = 'SUPPRIME': delete columns

```text
L'opération SUPPRIME permet de supprimer une ou plusieurs colonnes d'une table existante.
```

#### 3.11.1 Operand NOM_PARA

```text
♦    NOM_PARA     = lpara
```

Names of the parameters, names of the columns to be deleted in the table.

### 3.12 OPERATION = 'UNIQUE': deletion of duplicates

```text
L'opération UNIQUE permet de supprimer les lignes en doublon dans une table.
```

#### 3.12.1 Operand NOM_PARA

```text
♦    NOM_PARA     = lpara
```

Names of the columns in which the duplicates are sought. Two lines are said to be duplicates if all these parameters are identical (to within the format of the reals where applicable, see FORMAT_R).

### 3.13 OPERATION = 'STATISTIQUES'

```text
L'opération STATISTIQUES permet d'ajouter des informations sur la table elle-même.

Les colonnes ajoutées sont nommées STAT_NOM et STAT_VALE. Elles contiennent respectivement le nom du paramètre et sa valeur.

Les statistiques élémentaires ajoutées sont: le nombre de lignes (nommé NB_LIGNES), le nombre de colonnes (NB_COLONNES) et le nombre de cellules vides (NB_VIDE).
```

#### 3.13.1 Operand TITRE

```text
◊    TITRE = tit
```

Title of the table produced. When it is not supplied, the title of the input table is, depending on the operations, completed.

#### 3.13.2 Operand INFO

```text
◊    INFO = inf
```

Prints, in the "message" file, additional information if inf=2. Nothing happens if inf=1.

### 3.14 OPERATION = 'CALCUL'

```text
L'opération CALCUL permet des calculs simples pour des colonnes avec des variables réelles ou entières dans une table.

En présence de reuse, une colonne avec le nom TYPE_CALCUL est ajoutée dans la table. Pour chaque TYPE_CALCUL, une ligne est ajoutée avec des valeurs calculées aux colonnes demandées.

En absence dereuse, une nouvelle table est créée uniquement avec les colonnes à calculer ainsi que une colonne de TYPE_CALCUL. Chaque ligne correspond à un type de calcul.
```

#### 3.14.1 Operand NOM_PARA

```text
♦    NOM_PARA     = lpara
```

Names of the parameters, names of the columns to which the calculations are to be applied in the table.

#### 3.14.2 Operand TYPE_CALCUL

```text
♦    TYPE_CALCUL    =     / 'MAXI',
/ 'MINI',
/ 'SOMM',
/ 'MOY',
/ 'MAXI_ABS',
/ 'MINI_ABS',
/ 'SOMM_ABS',
```

Type of calculation to be applied to the columns. It is possible to choose several types of calculation.

Choice of the types of calculation: 'MAXI' for the maximum in the column, 'MINI' for the minimum in the column, 'SOMM' for the sum in the column, 'MOY' for the mean in the column, 'MAXI_ABS' for the maximum of the absolute values in the column, 'MINI_ABS' for the minimum of the absolute values in the column, 'SOMM_ABS' for the sum of the absolute values in the column.
