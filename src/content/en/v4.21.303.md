# v4.21.303 TTLL303 - Thermal transfer in a bar with internal heat generation

**Summary:**

This test is based on independent validation of version 3 in linear transient thermal analysis.

This is a 2D plan problem represented by a single model (plane).

The functions tested are as follows:

- element thermal plane,
- transient thermal analysis algorithm,
- limit conditions: heat source.

The interest of the test lies in the consideration of a heat source.

The results are compared to an analytical solution.

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v4.21.303/Object_1.svg)

### 1.2 Material properties

| $\lambda =100W/m°C$ | thermal conductivity |
| --- | --- |
| $\rho {C}_{p}=7000j/{m}^{3}°C$ | volumetric heat |

### 1.3 Boundary conditions and loads

- $Q={10}^{6}W/{m}^{3}$ internal heat source,
- $[\mathrm{AB}]$ , $[\mathrm{CD}]$ $\varphi =0$ ,
- $[\mathrm{BC}]$ , $[\mathrm{DA}]$ $T=0°C$ .

### 1.4 Initial conditions

$T(t=0)=0°C$

## 2 reference solution

### 2.1 Calculation method used for reference solution

$T=\frac{Q{L}^{2}}{2\lambda }(1-{(\frac{x}{L})}^{2}-\frac{32}{\pi}\sum_{i=0}^{\infty}\frac{{(-1)}^{i}}{{(\mathrm{2i}+1)}^{3}}\cos(\frac{\mathrm{2i}+1}{\mathrm{2L}}\pi )\exp(\frac{-\lambda }{\rho c}{(\frac{\mathrm{2i}+1}{\mathrm{2L}}\pi )}^{2}t))$

The reference values are obtained with $i=1000$ .

### 2.2 Baseline

Temperature at $E$ and $F$ points at $t=0.25$ and $0.5s$ moments

### 2.3 Uncertainty about the solution

analytical solution.

### 2.4 Bibliographical references

- B.M. Nicolai, J. de Baerdemaeker, "Computation of heat conduction in materials with random variable thermophysical properties", Int. J. num. Meth. Engng, vol. 36, pp. 523-536, 1993.

This test allowed the AFFE_CHAR_THER_F command to be tested in linear transient (PLAN Modelling) with the SOURCE operand.
