# v1.01.414 ZZZZ414 - Checking the HIGHT Law on a hardware point

**Summary:**

This test checks the use of Hujeux law on a hardware point.

Modelling A: simulation on a hardware point of a loading path that frustrates the local Newton iterations and activates a heuristic resolution re-launch mechanism.

## 1 Reference problem

### 1.1 Description

This test case is from sheet 26795 which states that Hujeux's law has been abruptly stopped because of a segmentation error in a layered construction study of a embankment dam.

It reproduces the loading path at the origin of the crash on a material point. This loading path leads to the failure of the local Newton iterations and activates a heuristic mechanism to restart the resolution.
