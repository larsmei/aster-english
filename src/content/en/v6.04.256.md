# v6.04.256 SSNV25 6 – Validation of GTN gradient damage law with axisymmetric bar simulations

**Summary:**

This test case validates the integration algorithm of the Gurson – Tvergaard – Needleman ($\mathit{GTN}$) gradient damage law with the sub-integrated or mixed standard elements in large deformations. A bar containing 10 elements finished is modeled.

The different modellings processed are:

- **Modelling** **A** ($3D$ ): 3D_GRAD_VARI
- **Modelling** **B** ($3D$ ): 3D_GRAD_INCO
- **Modelling** **C** ($2D$ ): AXIS_GRAD_VARI
- **Modelling** **D** ($2D$ ): AXIS_GRAD_INCO

## 1 Reference problem

### 1.1 Geometry

$\mathrm{2D}$ (plane deformation) or $\mathrm{3D}$ Modelling means a rectangle or a bar (see Figure 1.1-1), respectively.

![Figure](/figures/v6.04.256/100002010000025C000001B9E3FEB8F31B7BFF89.png)

**Figure** 1.1-a **: Geometry and mesh of a rectangle (a) and a bar (b)**

### 1.2 Material properties

Elasticity:

| $E=190000\text{MPa}$ | Young's modulus |
| --- | --- |
| $\nu =0.3$ | Poisson's ratio |

Nutrient curve:

$R(\kappa )=488.36+57.13(1-\exp(-8613\kappa ))+238.73(1-\exp(-10.39\kappa ))$

Ductile Damage Law GTN:

| ${q}_{1}=1.5$ | GTN model parameter |
| --- | --- |
| ${q}_{2}=1.07$ | GTN model parameter |
| ${f}_{0}=0.0002i$ | Initial porosity |
| ${f}_{n}=0$ | Germination parameter |
| ${f}_{c}=0.05$ | Coalescence porosity |
| $\delta =3$ | Acceleration coefficient related to coalescence |
| $c=1N$ | Non-local parameter |
| $r=5000\mathit{MPa}$ | Lagrange's penalization parameter |

In particular, the initial porosity distribution is not homogeneous. It increases with altitude: ${f}_{0}=0.0002i$ where $i$ designates the i-th layer of element and $1\le i\le 10$ .

In DEFI_MATERIAU, the following information must be provided:

| **ELAS** | **ECRO_** NL | **GTN** | **NON_LOCAL** |
| --- | --- | --- | --- |
| E = 190000 | R0= 488.361123569 | Q1 = 1.5 | C_GRAD_VARI = 1 |
| NU = 0.3 | R1 = 57.1333673502 | Q2 = 1.07 | PENA_LAGR =5000 |
|  | GAMMA_1 = 8613 | PORO_INIT = 0.0002i |  |
|  | R2 = 238.731127339 | COAL_PORO = 0.05 |  |
|  | GAMMA_2=10.386585592 | COAL_ACCE = 3 |  |

### 1.3 Boundary conditions and loads

For $2D$ (axisymmetric) modelling, the $X$ axis displacements of all nodes are controlled: ${u}_{x}=1.22x$ , the $Y$ axis displacements of the same altitude remain uniform, the node $A$ is blocked on the $Y$ axis (see Figure 1.1-1(a) for geometry).

For $3D$ modelling, $X$ axis displacements and $Y$ displacements of all nodes are controlled: ${u}_{x}=1.22x$ and ${u}_{y}=1.22y$ , $Z$ axis displacements of the same altitude remain uniform, node $A$ is blocked according to $Z$ . (see Figure 1.1-1(b) for geometry).

Boundary conditions and loads are imposed in this way so that the $2D$ and $3D$ problems are identical.

The load is imposed using 1000 time step identical. The pseudo-calculation time is 1.
