# v1.01.261 ZZZZ261 - Validation of PROJ_CHAMP in 2D for nodes fields

**Summary:**

This test validates the different projection methods of the PROJ_CHAMP command ('ELEM', 'NUAG_DEG_0/1') for a mesh 2D.

## 1 Test principle

The field studied is a square $[0,1]\times [0,1]$

It is meshed in quadrangles in two different ways:

MA1: Cut the square into $9\times 9$ QUAD4

MA2: Cut the square into $12\times 12$ QUAD4

On the mesh MA1, a thermal evolution is created by assigning to each node the temperature obtained by the formula: $T=t\ast (1+2{(x-0,5)}^{2}+3{(y-0,25)}^{2})$ where $t,x,y$ represents the value of the moment and the 2 coordinates of the nodes.

The temperature field (at the moment $t=10$) is then projected in several ways on the mesh MA2.

The projection value on the point coordinates $(0,5;0,5)$ is tested.

The value $T=11,875$ must be obtained
