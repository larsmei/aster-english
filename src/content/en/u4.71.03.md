# u4.71.03 Operator RECU_GENE

## 1 Purpose

Extract a vector of generalised displacements, velocities or accelerations from a result which is itself in generalised coordinates. Their extraction takes place for given discretisations (time instants or frequencies).

## 2 Syntax

```text
vect_asse_gene = RECU_GENE(
    ◆ RESU_GENE = tran_gene / harm_gene,
    ◆ / INST = float,
      / FREQ = float,
    ◇ NOM_CHAM = / "DEPL" (par défaut),
                 / "VITE",
                 / "ACCE",
    # Si: exists("INST") and not exists("FREQ")
        ◇ INTERPOL = / "NON" (par défaut),
                     / "LIN",
        ◇ CRITERE = / "RELATIF" (par défaut),
                    / "ABSOLU",
        # Si: (equal_to("CRITERE", 'RELATIF'))
            ◇ PRECISION = float (défaut: 1e-06),
        # Si: (equal_to("CRITERE", 'ABSOLU'))
            ◆ PRECISION = float,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```
## 3 Operands

### 3.1 Operand RESU_GENE

```text
♦    RESU_GENE = resgen
```
Concept of type tran_gene or harm_gene which contains, for different discretisations (time instants or frequencies), generalised vectors of displacement, velocity or acceleration type.

### 3.2 Operand NOM_CHAM

```text
◊    NOM_CHAM = nomcha
```
Character string designating the symbolic name of the field which one wishes to extract: 'DEPL', 'VITE' or 'ACCE'.

### 3.3 Operand INST

```text
♦    INST = instant
```
*For* *a* **transient** *result* (tran_gene), the time instant for which one wishes to extract a generalised vector.

### 3.4 Operand INTERPOL

*For* *a* **transient** *result* (tran_gene):

```text
◊    INTERPOL =
```
| 'NON': | the extraction must be carried out in the strict sense, |
| --- | --- |
| 'LIN': | an interpolation is authorised between two fields: this interpolation may be unacceptable between two archiving time instants which do not correspond to consecutive analysis time instants of DYNA_VIBRA [U4.53.03](doc:u4.53.03). |

### 3.5 Operands CRITERE and PRECISION

*For* *a* **transient** *result* (tran_gene):

```text
◊    CRITERE =     / 'ABSOLU'
```
```
/    'RELATIF'
```
- ◊    PRECISION = prec

Indicate with what accuracy the search for the time instant must be carried out.

| 'ABSOLU': | search interval | [instant-prec, instant+ prec]. |
| --- | --- | --- |
| 'RELATIF': | search interval | [(1-prec).instant, (1+prec).instant]. |
|  |  |  |
|  |  |  |
| *Note: If* CRITERE='ABSOLU' | *then the keyword* PRECISION *becomes mandatory.* |  |

### 3.6 Operand FREQ

```text
♦    FREQ = freq
```
*For* *a* **harmonic** *result* (harm_gene), the frequency for which one wishes to extract a generalised vector.
