# v1.01.366 ZZZZ366 - IMPR_RESU and LIRE_RESU Validation Test

**Summary:**

This test validates the numbering permutations involved in printing and rereading ELNO fields in MED format. The different modellings in this test correspond to the different types of mesh cells 3D for which the numbering conventions of nodes of elements differ between *Code_Aster* and MED.

- Modelling A: HEXA verification
- Modelling B: verification for PENTA
- Modelling C: verification for PYRA
- Modelling D: verification for TETRA

This documentation is deliberately succinct.
