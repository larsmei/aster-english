# v1.01.512 ZZZZ512 – HHO consistency test

**Summary:**

The aim here is to test the consistency of HHO methods in thermal and mechanical.
The idea is to use a polynomial manufactured solution of order $k+1$.
Then the HHO method of order $k$ must give a zero error (machine precision).

- Modelization A: 3D linear elasticity with mixed mesh HEXA/PENTA/TETRA.
- Modelization B: 3D linear elasticity with mesh PYRAM.
- Modelization C: 3D linear elasticity with a mixed mesh HEXA/PENTA/TETRA.
- Modelling D: 3D linear elasticity with mesh TETRA.
- Modelling E: 3D linear elasticity with mesh HEXA.
- Modelling F: Linear elasticity D_PLAN with a mixed mesh TRIA/QUAD.
- Modelization G: D_PLAN linear elasticity with mesh TRIA.
- H Modelling: D_PLAN linear elasticity with mesh QUAD.
- Modelling I: 3D Helmotz problem with a mixed mesh HEXA/PENTA/TETRA.
- Modelling J: Problem of Helmotz 3D with mesh PYRAM.
- K Modelling: Helmotz 3D problem with mesh TETRA.
- Modelling L: Problem of Helmotz 3D with mesh HEXA.
- Modelling M: Helmotz PLAN problem with a mixed mesh TRIA/QUAD.
- Modelling N: Helmotz PLAN problem with mesh TRIA.
- Modelling O: Helmotz PLAN problem with mesh QUAD.
- Modelling P: Poisson PLAN problem with a mixed mesh TRIA/QUAD.
- Modelling Q: Poisson PLAN problem with mesh TRIA.
- Modelling R: Poisson PLAN problem with mesh QUAD.
- T Modelling: 3D linear elasticity with linear solution and mesh HEXA (HPC).
- Modelling S: 3D linear elasticity with linear solution and mesh HEXA (HPC).
- U Modelling: 3D linear elasticity with linear solution and mesh HEXA (HPC).
- V Modelling: AXIS linear elasticity with a mixed mesh TRIA/QUAD.
- Modelling W: Poisson AXIS problem with a mixed mesh TRIA/QUAD.
- X Modelling: AXIS_GRAD linear elasticity with a mixed mesh TRIA/QUAD.
