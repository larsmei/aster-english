# u4.13.01 Procedure INCLUDE

## 1 Purpose

This inserts a sequence of commands that will be executed *almost* as they are written. There is no possibility of passing arguments.

The results of the commands are *exported* into the main command set.
The other objects are normally usable in the command file but will not be available in a POURSUITE.
For example, a Python function or class defined in an INCLUDE may be used in a FORMULE in the command file and evaluated there, but not in a POURSUITE.

It is therefore advisable to limit the use of INCLUDE to these simple cases (a set of commands defined in another file).
If one wishes to execute more Python instructions, it is preferable to use `import` (use the type 'nom' to copy a file into the execution directory without renaming it).

## 2 Syntax

```text
INCLUDE(
    ◆ / UNITE = unit,
      / DONNEE = text,
    ◇ ALARME = / "OUI" (par défaut),
               / "NON",
    ◇ INFO = / 0,
             / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

Apart from the location of the included file, the behaviour is strictly identical with UNITE or DONNEE.

### 3.1 Operand UNITE

Logical unit of the file to include. This number must correspond to the file to include, defined in the launching interface or in the `.export` file. This file is copied into the execution directory under the name `fort.NN`.

**Note**

One cannot use INCLUDE with a logical unit associated with a file name by DEFI_FICHIER. If necessary, one may use DONNEE=fichier.

### 3.2 Operand DONNEE

This keyword, intended to be used in the test cases, makes it possible to include a file stored in the *tests_data* directory, whose distribution is restricted. This makes it possible to distribute a test case except for a small part that must remain confidential.

This directory is by default located in the `share/aster` directory of the installation. The command-line option `--rcdir` makes it possible to override this location.

The included file will therefore be `xxx/share/aster/tests_data/fichier`.

One may also supply the absolute path to the path to include.

### 3.3 Operand ALARME

This keyword makes it possible to suppress the message warning about the precautions for use of INCLUDE.

### 3.4 Operand INFO

| 0 | no printout of the content of the included file. |
| --- | --- |
| 1 | printout of the content of the included file, in the 'MESSAGE' file |
| 2 | identical to 1 (this value exists by convention) |

## 4 Example of use

- Main command file:

```python
DEBUT()
INCLUDE(UNITE=91, INFO=1)
mo = AFFE_MODELE(MAILLAGE=ma, AFFE=_F(TOUT="OUI", PHENOMENE="MECANIQUE", MODELISATION="3D"))
INCLUDE(UNITE=92, INFO=1)
FIN()
```

- Command file attached to unit 91

```python
ma = LIRE_MAILLAGE()
```

- Command file attached to unit 92

```python
lbew = DEFI_FONCTION(
    NOM_PARA="INST",
    VALE=(
        0.0,
        -0.19949,
        0.01000,
        -0.25487,
        # etc.
    ),
)
```
