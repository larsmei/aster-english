# v3.02.301 SSLP301 – Trapezoidal plate under clean weight

**Summary:**

The objective of this test case is to validate the features that allow you to define the clean weight in a flat stress analysis.

The load is applied with the keywords gravity (modelization A) and FORCE_INTERNE (modelization B).
