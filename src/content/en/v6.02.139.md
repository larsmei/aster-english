# v6.02.139 SSNL139 – Validation of the re-update of the angle of the beam spin

**Summary:**

When using elements beam with GROT_GDEP kinematics, the two nautical angles that reflect the orientation of the element must be updated at each iteration. The same applies to the 3rd $\gamma$ nautical angle that translates the angle of the beam spin. This test is intended to validate the re-update of this angle using a nonlinear calculation.

It allows to check POU_D_TGM Modelling and the modellings POU_D_E and POU_D_EM give the same results with GROT_GDEP kinematics.

## 1 Description

### 1.1 Geometry

A beam of a length $10m$, oriented to $45°$ in the $\mathit{XOZ}$ plane is considered.

![Figure](/figures/v6.02.139/100000000000018E0000014C292974E19F411B8D.png)

The section of the beam is rectangular, $0,1m$ wide, $0,2m$ high.

### 1.2 Material properties

The material uses the following properties:

| Young's modulus | ${E}_{b}=1.0E+10\mathit{Pa}$ |
| --- | --- |
| Poisson's ratio | ${\nu}_{b}=0.25$ |

### 1.3 Boundary conditions and loads

The node $O$ is blocked while moving in all directions and rotating around $Y$. The node $A$ is blocked while moving according to $Y$. Moreover, the beam is forbidden to rotate on itself.

The node $A$ moves are imposed as follows: $\mathit{DX}=\frac{-\sqrt{2}}{2}\frac{t}{100}$ and $\mathit{DZ}=\frac{-\sqrt{2}}{2}\frac{t}{100}$ with $t$ taking the values from 0 to 1 per increment of $0.1$.

$100N$ force according to $Y$ is applied to node $C$ (beam medium) so that the beam moves in the direction $Y$.

### 1.4 Reference

The reference results are obtained with a nonlinear calculation and a beam oriented to the $X$ axis. For this orientation the value of the angle of spin remains the same during the calculation, with and without re-updating the results are identical.

For reference the displacement imposed on node $A$ is: $\mathit{DX}=-\frac{t}{100}$

The $\mathit{DY}$ displacement of the node $C$ (beam medium) gives the reference value.

## 2 Modelling A

### 2.1 Modelling characteristics

The beam is modelled by 10 mesh cells SEG2 to which the Modelling p_d_tgm is assigned. It is recalled that the kinematics used is deformation = 'GROT_GDEP'.

### 2.2 Test values

The $Y$ displacement of node $C$ is compared with that obtained by the same calculation with a beam oriented on the $X$ axis.

| **Instant** | **Reference type** | **Reference value** | **Tolerance** |
| --- | --- | --- | --- |
| $1.0$ | Other Aster | 1.508470E-01 | 1.0E-05 |

## 3 Modelling B

### 3.1 Modelling characteristics

The beam is modelled with 10 mesh cells SEG2 to which the p_d_E Modelling is affected. It is recalled that the kinematics used is deformation = 'GROT_GDEP'.

### 3.2 Test values

The $Y$ displacement of node $C$ is compared with that obtained by the same calculation with a beam oriented on the $X$ axis.

## 4 Modelling C

### 4.1 Modelling characteristics

The beam is modelled by 10 mesh cells SEG2 to which the p_d_EM Modelling is affected. It is recalled that the kinematics used is deformation = 'GROT_GDEP'.

### 4.2 Test values

The $Y$ displacement of the node $C$ is compared to that obtained by the same calculation with a beam oriented on the $X$ axis and also with the same calculation with POU_D_E.

| **Instant** | **Reference type** | **Reference value** | **Tolerance** |

## 5 Executive summary

The re-upgrading of the angle of spin allows the movement and rotation of the sections of the beam to be reported in incremental calculations.
