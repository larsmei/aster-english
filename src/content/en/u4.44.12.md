# u4.44.12 Operator CREA_RESU

## 1 Purpose

Create or enrich a result data structure from fields at the nodes or by elements. Assignment of the fields for different order numbers is possible.

The user must ensure the consistency of the various fields used to build or enrich the result data structure.

Assignment by means of a cham_no of functions produced by CREA_CHAMP [U4.72.04](doc:u4.72.04) is carried out by evaluating each function with the aid of the parameter representing the time supplied under the keywords LIST_INST or INST.

The concept produced by this operator is, for the moment, of type evol_elas, evol_noli, evol_ther, mult_elas,fourier_elas, fourier_ther, evol_varc, evol_char, mode_meca, dyna_trans or dyna_harmo.

In addition, three particular functionalities are available in this operator:

- the creation of a concept of type evol_char by assignment of a field or an analytical formula;
- the projection of a 1D thermal transient onto a 3D axisymmetric mesh.
- The creation of right-hand-side loading transients of type evol_char or dyna_trans by the product of assembled matrices with kinematic fields, by conversion and combination of transient results, or by assembly of space-time loads of plane-wave or nodal-force type.

### 3.4 Operand COMPORTEMENT

The syntax of this keyword, common to several commands, is described in the document [U4.51.11](doc:u4.51.11). This keyword must be supplied in the case of non-linear mechanics, because it is used on restart of the analysis in STAT_NON_LINE and DYNA_NON_LINE in order to check the compatibility of the constitutive behaviours (the number of internal variables in particular).

During the operation AFFE in the case of non-linear mechanics,

- without reuse, a new result data structure will be created with the constitutive behaviour supplied. If COMPORTEMENT is not supplied, the constitutive behaviour taken by default is elastic (COMPORTEMENT=’ELAS’) in small strains (RELATION=’PETIT’).
- One uses reuse in order to add or replace fields in the result. If COMPORTEMENT is supplied, its behaviour map is replaced for all the time instants; otherwise, the constitutive behaviour is kept for the existing time instant and that of the previous time instant is recovered for the non-existent time instant (elastic in small strains if there is no previous time instant).

At the end of the operation AFFE, for each time instant, the consistency between its behaviour map and the number of internal variables is checked (see keyword VERI_VARI). Despite the inconsistencies, some authorised cases allow this field (VARI_ELGA) to be taken up again in a non-linear analysis, and the analysis should proceed correctly (automatic correction in the operator).

#### 3.7.6 Operands PRECISION / CRITERE

These operands make it possible to refine the access by real access variables of time or of frequency.

```text
I    PRECISION =    / prec                                [R]
/ 0.0 ou 1.0D-3 ou 1.0D-6        [DEFAUT]
```

This keyword makes it possible to indicate that one searches for all the fields whose time instant (respectively the frequency) lies in the interval "inst ± prec" (cf. CRITERE).

In the case where OPERATION = ’AFFE’, the default value prec is set to 0.0 in order to avoid overwriting a field whose time-instant value is close to the one being processed. The time instant supplied is not used to recover a field in the data structure; it is an attribute which must be associated with the field that one stores. In general, the fields that one stores all correspond to different time instants.

In the very rare case where the user would wish to overwrite one of the fields contained in the data structure, the keyword PRECISION will have to be used. An alarm message then indicates the name of the fields concerned, together with their storage time instants, and the precision supplied by the user:

```text
I    CRITERE    =    / ’RELATIF’                [DEFAUT]
/ ’ABSOLU’
```

’RELATIF’: the search interval is: [inst (1 - prec), inst (1 + prec)]

’ABSOLU’ : the search interval is: [inst - prec, inst + prec].

## 5 Operands associated with the projection onto an axisymmetric mesh

Construction of a thermal transient on an axisymmetric mesh (3D) from the data of a thermal transient computed on a 1D mesh. The 1D transient is given in the form of a TABLE data structure coming from the command POST_RELEVE_T and possessing the following parameters:

- the definition of the time instants (’INST’),
- the coordinates of the nodes of the 1D mesh (’COOR_X’)
- the value of the temperatures at the nodes (’TEMP’).

The coordinates of the table must necessarily have as their origin the node of coordinate 0.

The temperature values may optionally be extended in a constant manner or else interpolated linearly as a function of the coordinate ’COOR_X’.

### 5.1 Operands MAILLAGE_FINAL

```text
♦    MAILLAGE_FINAL= mailfin

Nom du maillage sur lequel on effectue la projection, l’opérateur vérifie que le maillage est tridimensionnel.
```

### 5.2 Operands TABLE

```text
♦    TABLE= table

Nom d’une structure de données TABLEissue de la commande POST_RELEVE_Tcontenant le transitoire thermique 1D. Les paramètres de cette table sont obligatoirement: ’INST’, ’COOR_X’et ’TEMP’.
```

### 5.3 Operands INST / LIST_INST / PRECISION / CRITERE

```text
◊    INST= litps
```

List of real values.

```text
◊    LIST_INST= litps
```

List of reals produced by DEFI_LIST_REEL [U4.34.01](doc:u4.34.01).

```text
◊    PRECISION =    / prec         [R]
/1-0D-6        [DEFAUT]

Précision utilisée pour rechercher l’instant spécifié dans la TABLE post_1D.
```

```text
◊    CRITERE =    / ’RELATIF’,
/ ’ABSOLU,’

Critère utilisé pour rechercher l’instant spécifié dans la TABLE post_1D.
```

### 5.4 Operands PROL_DROITE and PROL_GAUCHE

The projection of the transient is carried out along the coordinate COOR_X, considered as the coordinate r in the cylindrical frame of the 3D mesh. With the aid of these two operands, one can define the way of extending the field beyond the bounds defined by the range of variation of the parameter ’COOR_X’ in the table.

```text
◊    PROL_DROITE et PROL_GAUCHE =
```

Define the type of extension to the right (to the left) of the domain of definition of the variable:

| ’CONSTANT’ | for an extension with the last (or first) value of the function, |
| --- | --- |
| ’LINEAIRE’ | for an extension along the first segment defined (PROL_GAUCHE) or the last segment defined (PROL_DROITE), |
| ’EXCLU’ | if the extrapolation of the values outside the domain of definition of the parameter is forbidden (in this case if an analysis requests a value of the function outside the domain of definition, the code will stop in fatal error). |

### 5.5 Operand REPERE/ORIGINE/AXE_Z

```text
♦    REPERE = ’CYLINDRIQUE’
```

The working frame for projecting the transient is assumed to be cylindrical, the 1D transient being considered as the radial variation of the temperature field. The following two operands make it possible to carry out a change of frame.


Corresponds to the position of the origin of the 1D mesh with respect to the origin of the 3D mesh.

```text
♦    AXE_Z = (axe1,axe2,axe3)
```

Definition of the axis of the cylindrical frame.

## 6 Operands associated with the preparation of the command variables

### 6.1 Keyword PREP_VARC

The thermal evolution that one can associate with the material field by AFFE_MATERIAU/AFFE_VARC must be ready to be used by the finite elements of the mechanical model. A problem arises for shell-type elements which use a temperature varying through the thickness over the different layers. For these elements, it is necessary to prepare the computation of the temperature on the layers upstream of the command AFFE_MATERIAU. To do this, the user must use the command CREA_RESU with the operation PREP_VARC (PREParation of the Command VaRiables).

#### 6.1.1 Operand CHAM_GD

```text
♦    CHAM_GD = chgd
```

chgd is a map of functions created from a temperature given by a NAPPE or a FORMULE of the type:

$\mathit{temp}=f(\mathit{inst},\mathit{epais})$ ; $\mathit{temp}=f(\mathit{inst},\mathit{zexcen})$ ; $\mathit{temp}=f(\mathit{inst},x,y,z)$

where:

◦    $\mathit{inst}$ is the time,

◦    $\mathit{epais}$ is the thickness of the shell in $[-h/2,h/2]$ ,

◦    $\mathit{excent}$ is the position in the layer, taking account of the offset of the shell, in $[\mathit{excent}-h/2,\mathit{excent}+h/2]$ .

◦    $x,y,z$ coordinates, in the frame of the mesh, of the centre of gravity of the layer.

#### 6.1.2 Operand EVOL_THER

```text
♦    EVOL_THER = evol
```

evo is an EVOL_THER data structure of “shell” type, that is to say containing the components TEMP_MIL/TEMP_INF/TEMP_SUP.

### 6.2 Operands TOUT / GROUP_MA

## 9 Example of use

Construction of a thermal transient from a function:

The main commands used to build a result concept of type evol_ther have been defined below.

Definition of a list of time instants.

```text
lr8    =    DEFI_LIST_REEL    (    DEBUT = 0.E0,
INTERVALLE=(_F(JUSQU_A=5.e-3,NOMBRE=10 ),
_F(JUSQU_A=5.e-2,NOMBRE=    9 ),
_F(JUSQU_A=4.e-0,NOMBRE=79 ),
_F(JUSQU_A=6.e-0,NOMBRE=20 ),)
)
```

Definition of a function of the parameter ’INST’.

```text
fct1 = DEFI_FONCTION    (    NOM_PARA = ’INST’
VALE= (    0.0,        20.0,
0.5,        25.0,
2.0,        54.0,
10.0,        134.0,)
PROL_DROIT = ’LINEAIRE’,
PROL_GAUCHE= ’LINEAIRE’,
)
```

Construction of a field at the nodes of functions; the same function fct1 is assigned to all the nodes of the mesh.

```text
ch = CREA_CHAMP    (     TYPE_CHAM=’NOEU_TEMP_F’, OPERATION= ’AFFE’,

    MAILLAGE=ma , AFFE=_F(TOUT=’OUI’, NOM_CMP=’TEMP’, VALE_F=fct1,),
)

    ...
```

Creation of the result concept TEMPE, built from the field at the nodes of functions ch. One limits oneself to order number 20, corresponding to the value 0.1. The data structure will comprise 20 order numbers from 1 to 20.

```text
TEMPE = CREA_RESU( OPERATION= ’AFFE’,
                TYPE_RESU= ’EVOL_THER’,
                AFFE= ( _F( CHAM_NO = ch ,
                            NOM_CHAM= ’TEMP’,
                            LIST_INST= lr8,
                            NUME_FIN = 20 , ),
                        )
                )
...
FIN()
```
