# v1.01.129 ZZZZ129 – Validating the CREA_RESU command key word factor PROL_RTZ

**Summary:**

This test validates the PROL_RTZ keyword of the CREA_RESU command. It consists successively of creating:

- a temperature field on a set of nodes of a mesh 1D. This field is then given as a table data structure from the POST_RELEVE_T command.
- a field on a mesh axisymmetric (3D) from the previously created field.

All nodes values of the mesh 3D are tested.

This documentation is deliberately succinct.
