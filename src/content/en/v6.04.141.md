# v6.04.141 SSNV141 - Plucked spherical tank

**Summary:**

This test case presents a quasi-static, non-linear geometric calculation of a pinched spherical cap. It allows testing COQUE_3D Modelling in non-linear geometrical and the algorithm for updating large 3D rotations (Keyword GROT_GDEP of the STAT_NON_LINE operator). This popular example in linear analysis shows the capacity of the shell's element to accurately represent the expansionless bending and rigid body movements. In addition, the thinness of the shell relative to its radius of curvature allows testing the processing of transverse shear locks. The deformations obtained by *Code_Aster* differ from 0.1 to 1.25% of the SAMCEF Code, taken for reference.

## 5 Summary of the results

The problem data correspond to a thin $\frac{h}{R}=0.4\text{\%}$ hull. It is necessary to increase the value of the COEF_RIGI_DRZ which attributes a stiffness around the normal elements shell which is by default ${10}^{-5}$ the smallest bending stiffness around the directions in the plane of the hull so that it can increase the value of the angle of rotation that can be reached. Values of this coefficient up to ${10}^{-3}$ remain lawful.

The *Code_Aster* solution is close to the reference solution SAMCEF for both modellings.

This test thus shows the correct functioning of COQUE_3D Modelling in large movements and large rotations, without showing shear blocking.
