# u4.82.21 Operator POST_MAIL_XFEM

## 1 Purpose

Create the cracked mesh of a structure according to the X-FEM method.

This operator produces a new mesh by adding mesh cells so as to follow the locus of the crack described by the level sets. The crack is thus ‘meshed’. This mesh is to be used only for visualisation and must not be used for an analysis.

Produces a concept of type maillage_sdaster.

This concept is required by the operator POST_CHAM_XFEM [U4.82.22](doc:u4.82.22).

## 2 Syntax

```text
maillage = POST_MAIL_XFEM(
    ◆ MODELE = modele,
    ◇ PREF_NOEUD_X = text (défaut: "NX"),
    ◇ PREF_NOEUD_M = text (défaut: "NM"),
    ◇ PREF_NOEUD_P = text (défaut: "NP"),
    ◇ PREF_MAILLE_X = text (défaut: "MX"),
    ◇ PREF_GROUP_CO = grno (défaut: NFISSU),
    ◇ TITRE = text,
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand MODELE

```text
♦    MODELE    =    mo,
```

Name of the X-FEM model generated by the command MODI_MODELE_XFEM.

### 3.2 Operands PREF_NOEUD_X, PREF_NOEUD_M, PREF_NOEUD_P, PREF_MAILLE_X, PREF_GROUP_CO

```text
♦    PREF_NOEUD_X    =    pref_nx,

♦    PREF_NOEUD_M    =    pref_nm,

♦    PREF_NOEUD_P    =    pref_np,

♦    PREF_MAILLE_X    =    pref_mx,

♦    PREF_GROUP_CO    =    pref_gc,
```

```text
pref_nx: préfixe du nom des nouveaux nœuds simples (non situés sur les lèvres).

pref_nm: préfixe du nom des nouveaux nœuds doubles situés sur la lèvre «moins».

pref_nm: préfixe du nom des nouveaux nœuds doubles situés sur la lèvre «plus».

pref_mx: préfixe du nom des nouvelles mailles.

pref_gc: nom du groupe créé avec les nœuds situés sur la lèvre «moins».
```

The default names may cause errors if these names already exist in the initial mesh (which may be the case with a mesh coming from Salomé, because Salomé does not name the nodes $\mathrm{N1}$, $\mathrm{N2}$...).

The node group PREF_GROUP_CO is intended to be used for the post-processing of contact. It contains exactly the nodes on the slave side of the crack that will carry contact degrees of freedom (after the call to POST_CHAM_XFEM).

### 3.3 Notes

1. The concept produced by this command is reserved exclusively for the post-processing of X-FEM elements. Under no circumstances must it be used for the analysis.

1. In order to allow the crack to open, the vertex nodes of the initial mesh that belong to the crack have been duplicated and new nodes of the crack plane have been added in order to carry out the subdivision of the X-FEM mesh cells.

1. The GROUP_MA groups of the sound mesh are retained in the post-processed mesh:

- if a mesh cell of a GROUP_MA is classical, it is copied as it is into the GROUP_MA of the post-processed mesh,
- if a mesh cell of a GROUP_MA is X-FEM, it is replaced by its sub-elements in the GROUP_MA of the post-processed mesh, provided that the mesh cell is indeed assigned a model.

Some GROUP_MA may therefore disappear if they contain only mesh cells without a modelling.

1. In order to allow the crack fronts to be visualised, nodes and mesh cells are built at these points. The prefix of the nodes that are built is $\mathit{NF}$ and that of the mesh cells is $\mathit{MF}$ . The mesh cells are of type POI1 in 2D and SEG2 in 3D.

Node groups and mesh-cell groups are also built. The node groups are named $\text{NF\_xx\_yy}$ where $xx$ denotes the $xx$th crack and $yy$ the $yy$th front. The mesh-cell groups are named $\text{MF\_xx\_yy}$ where $xx$ denotes the $xx$th crack and $yy$ the $yy$th front.

### 4.2 Extract from the command file

```text
DEBUT();

# Définition du modèle

MODELEIN=AFFE_MODELE(    MAILLAGE=MAILLAG2,
AFFE=_F(    GROUP_MA='VOL',
PHENOMENE='MECANIQUE',
MODELISATION=    '3D',),);

# Définition de la fissure (plane)

LN=FORMULE(NOM_PARA=('X','Y','Z'),VALE='Z-12.5 ');

LT=FORMULE(NOM_PARA=('X','Y','Z'),VALE='X-10. ');

FISS=DEFI_FISS_XFEM(    MODELE=MODELEIN,
DEFI_FISS=_F(    FONC_LT=LT,
FONC_LN=LN,),
GROUP_MA_ENRI='VOL',);

# Prise en compte de la fissure dans le modèle

MODELEK=MODI_MODELE_XFEM(    MODELE_IN=MODELEIN,
FISSURE=FISS,
INFO=2,);

# Conception du maillage fissure

MA_XFEM=POST_MAIL_XFEM(        MODELE=MODELEK,);

FIN();
```
