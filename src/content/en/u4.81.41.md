# u4.81.41 Operator POST_BORDET

## 1 Purpose

The purpose of this command is to compute, in post-processing of a non-linear elasto-plastic mechanical analysis, the cleavage probability from the Bordet model as well as the stress of the model of the same name.

This command first computes the mechanical fields required for the post-processing and deduces from them the Bordet stress and finally the associated probability.

It returns a table containing:

- the Bordet stress as a function of time (under the keyword SIG_BORDET)
- the Bordet probability as a function of time (under the keyword PROBA_BORDET)

The macro-command works in D_PLAN, AXIS or in 3D.

The Bordet model is described in detail in the reference documentation [R7.02.06](doc:r7.02.06).

Advice on the use of this model is given in the documentation [U2.05.08](doc:u2.05.08).

## 2 Syntax

```text
table = POST_BORDET(
    ◆ / TOUT = "OUI" (ou non renseigné),
      / GROUP_MA = grma,
    ◆ / INST = float,
      / NUME_ORDRE = int,
    ◇ PRECISION = float (défaut: 1e-06),
    ◇ CRITERE = / "RELATIF",
                / "ABSOLU" (par défaut),
    ◇ PROBA_NUCL = / "NON" (par défaut),
                   / "OUI",
    # Si: equal_to("PROBA_NUCL", 'OUI')
        ◆ PARAM = _F(
             ◆ M = float,
             ◆ SIGM_REFE = fonction,
             ◆ VOLU_REFE = float,
             ◆ SIG_CRIT = float,
             ◆ SEUIL_REFE = float,
             ◆ SEUIL_CALC = nappe / fonction,
             ◆ DEF_PLAS_REFE = float,
          ),
    # Si: equal_to("PROBA_NUCL", 'NON')
        ◆ PARAM = _F(
             ◆ M = float,
             ◆ SIGM_REFE = fonction,
             ◆ VOLU_REFE = float,
             ◆ SIG_CRIT = float,
             ◆ SEUIL_REFE = float,
             ◆ SEUIL_CALC = nappe / fonction,
          ),
    ◆ RESULTAT = resultat,
    ◆ TEMP = fonction,
    ◇ COEF_MULT = float (défaut: 1.0),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand RESULTAT

Designates the result of the thermo-mechanical analysis for which the Bordet quantities are computed. The RESULTAT data structure supplied must contain one and only one model and one and only one material field.

### 3.2 Operand TOUT/GROUP_MA

> ♦     /TOUT        =    'OUI',

> /GROUP_MA = group_ma,                                [l_group_ma]

Designates the domain of the model on which the computation of the Bordet quantities will be carried out. By default, it is carried out on the whole model. Note that, as the model involves the variation of the plastic strain, the mesh-cell group on which the analysis is carried out must contain *at least* the whole domain over which the plastic strain has evolved during the loading, and that taking a larger domain will not change the result (but the duration of the analysis).

### 3.3 Operand INST/NUME_ORDRE

> ♦     /INST         =    instant,                                    [R]

> /NUME_ORDRE =    ordre                                        [I]

The analysis will be carried out for all the time instants or order numbers up to the time instant or order number designated by this operand.

The result will be a table containing the various analysis time instants, the Bordet stress and the Bordet probability.

### 3.4 Operand PRECISION

> ◊     /PRECISION    =    1E-06                                        [DEFAUT]

> prec,                                        [R]

Makes it possible to define, when the keyword INST is used, a precision in the search for the last analysis time instant of the Bordet quantities. If the precision is not defined by the user, a precision of 1E-06 is applied.

If the time instant requested by the user does not correspond to any interval [instant-prec ; instant+prec] saved in the result, the analysis stops with a fatal error.

### 3.5 Operand CRITERE

> ◊     /CRITERE    =    'ABSOLU'                                        [DEFAUT]

> 'RELATIF',

Makes it possible to define, when the keywords INST and PRECISION are used, whether the precision is absolute or relative. By default, it is absolute.

### 3.6 Operand PROBA_NUCL

> ◊ PROBA_NUCL            =    /'NON                                    [DEFAUT]

> /'OUI'

Indicates whether the user wishes to take the exponential term into account in the analysis. This term, as stated above, has a negligible influence if $\frac{{\sigma}_{\mathrm{ys},0}{\varepsilon}_{p,0}}{{\sigma}_{\mathrm{ys}}(T,{\dot{\varepsilon}}_{p})}\gg {\varepsilon}_{p}$ . If the user wishes to take this term into account, an additional parameter must then be supplied, which is the reference equivalent plastic strain. Otherwise, this parameter is unnecessary.

### 3.7 Operand PARAM

> ♦      PARAM            =    _F(

> ♦     M                =    m,                                    [R]
> ♦     SIGM_REFE        =    sigma_ref,                        [fonction]
> ♦     VOLU_REFE        =    r_sup,                                [R]

> ♦     SIG_CRIT        =    sigma_crit,                        [R]
> ♦     SEUIL_REFE    =    lim_elas_ref,                        [R]
> ♦     SEUIL_CALC    =    lim_elas,                            [fonction,nappe]
> ♦     DEF_PLAS_REFE    =    lim_elas,                            [R]

> ),

Designates the set of material parameters required for the computation of the quantities of the Bordet model. The first three have equivalents in the Beremin model (with values that may differ from one model to the other), the following four being specific to the Bordet model.

#### 3.7.1 Keyword M

> ♦     M                =    m,                                    [R]

Designates the exponent $m$ of the Weibull-type law (sometimes called the shape factor).

Warning: this quantity is not necessarily equal to its equivalent in the Beremin model.

#### 3.7.2 Keyword SIGM_REFE

> ♦     SIGM_REFE        =    sigma_ref,                        [fonction]

Designates the reference stress ${\sigma}_{u}(T)$ of the Weibull-type law (sometimes called the scale factor). It is the stress for which the cumulative fracture probability of the potential cleavage sites is equal to 1.

This stress depends on the temperature; a function of the temperature is expected here.

Warning: this quantity is not necessarily equal to its equivalent in the Beremin model.

#### 3.7.3 Keyword VOLU_REFE

♦     VOLU_REFE        =    V0                                [R]

Designates the reference elementary volume ${V}_{0}$ of the plastic zone.

Warning: this quantity is not necessarily equal to its equivalent in the Beremin model.

#### 3.7.4 Keyword SIG_CRIT

♦     SIG_CRIT        =    sigma_crit,                        [R]

Designates the critical stress ${\sigma}_{\mathrm{th}}$ below which the propagation of ferritic microcracks cannot be significant; if ${\sigma}_{1}<{\sigma}_{\mathrm{th}}$ at every point, then necessarily ${P}_{\mathrm{Bordet}}=0$ .

#### 3.7.5 Keyword SEUIL_REFE

♦     SEUIL_REFE    =    lim_elas_ref,                        [R]

Designates the yield stress ${\sigma}_{\mathrm{ys},0}$ at a reference temperature to be used in the model.

#### 3.7.6 Keyword SEUIL_CALC

♦     SEUIL_CALC    =    lim_elas,                            [fonction,nappe]

Designates the yield stress of the material ${\sigma}_{\mathrm{ys}}(T,{\dot{\varepsilon}}_{p})$ , which strictly speaking depends on the temperature and on the plastic strain rate.

If the dependence on the plastic strain rate is not known, a simple function of the temperature can be used for SEUIL_CALC.

If the dependence on both the temperature and the plastic strain rate is known, a nappe can be defined; the parameter of the nappe must be the plastic strain rate, and the variable for each function the temperature (cf. user's document of DEFI_NAPPE)

Example:

SIGY1=DEFI_FONCTION(NOM_PARA='TEMP',

VALE=(0.,200.,100.,200.,),

PROL_DROITE='CONSTANT',PROL_GAUCHE='CONSTANT',);

SIGY2=DEFI_FONCTION(NOM_PARA='TEMP',

VALE=(0.,300.,100.,300.,),

PROL_DROITE='CONSTANT',PROL_GAUCHE='CONSTANT',);

SIGY=DEFI_NAPPE(NOM_PARA='EPSI',

PROL_DROITE='CONSTANT',PROL_GAUCHE='CONSTANT',

PARA=(0.0005,0.001),

FONCTION=(SIGY1,SIGY2),);

CALC_BORDET(.....SEUIL_CALC=SIGY,...);

#### 3.7.7 Keyword DEF_PLAS_REFE

♦     DEF_PLAS_REFE    =    lim_elas,                            [R]

This keyword is MANDATORY if PROBA_NUCL='OUI' and FORBIDDEN if PROBA_NUCL='NON'.

It designates the reference equivalent plastic strain ${\varepsilon}_{p,0}$ which appears only in the exponential term.

### 3.8 Operand TEMP

♦ TEMP        =    temperature,                                    [fonction]

As stated in the preceding paragraphs, some material parameters depend on the temperature. TEMP designates the temperature, considered uniform for the time being over the Bordet analysis zone. The user may supply a constant function, in which case the temperature is considered uniform in space and constant in time, or a function of time (parameter INST), in which case the temperature is considered uniform in space but evolving in time.

### 3.9 Operand COEF_MULT

> ◊ COEF_MULT    =    1,                                                [DEFAUT]

> coefficient,                                    [R]

The default value of this coefficient is 1.0.

The following table, in which the thickness is denoted $e$ , indicates typical values of the coefficient $C$ as a function of the type of symmetry:

- **simple symmetry**: the plane of symmetry of the mesh passes through the plane of the defect and the defect is fully meshed,
- **double symmetry**: the plane of symmetry of the mesh also passes through the plane of the defect but only one half of the defect is meshed.

|  | **3D** **and** **3D_SI** | **AXIS** **and** **AXIS_SI** | **D_PLAN** **and** **D_PLAN_SI** | **C_PLAN** |
| --- | --- | --- | --- | --- |
| SIMPLE | 2 | $4\pi$ | 2e | 2e |
| DOUBLE | 4 | not applicable | not applicable | not applicable |
| NON | 1 | $2\pi$ | e | e |
