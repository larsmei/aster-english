# v1.01.264 ZZZZ264 – Validation of the POST_ENDO_FISS command

**Summary:**

This test case allows you to validate the POST_ENDO_FISS command, which allows you to search for a crack path and open cracks from a mechanical damage calculation. Three test cases are offered:

- the cracking path over an analytical field,
- crack opening on study calculated with the ENDO_SCALAIRE / GRAD_VARI law,
- crack opening on study calculated with MAZARS law.

## 1 Reference problem: Searching for cracking path on an analytical result

### 1.1 Field Generation

In this first test, the cracking path is sought on an artificial field, that is, created analytically and not from a mechanical calculation. The advantage is that the cracking path is known *a priori* , so it can be compared with the path resulting from the command.

With the , we show the artificial field on which we will test the command, on the domain $x,y$ .

![Figure](/figures/v1.01.264/100002010000052B000002A04C724B349D1E807A.png)

**Figure** 1.1-1 **: discretized post-treating field on mesh.**

For the field generation, the crack path was first fixed, then the field is given by a function defined on the orthogonal profile at the crack at each of its points.

The cracking path is the polynomial of degree 4 which passes through the points:

$\mathit{P1}=(10.,0.)$ , $\mathit{P2}=(35.,20.)$ , $\mathit{P3}=(60.,0.)$  , $\mathit{P4}=(85.,20.)$ , $\mathit{P5}=(110.,0.)$

On the orthogonal profile of the $r$ curvilinear abscisse, a $z=-{a}_{1}{r}^{2}+{a}_{2}$ parabolic profile is defined that is bounded below the minimum $\mathrm{valmin}$ value of the field (here, ${10}^{-6}$). The resulting field is everywhere equal to $\mathrm{valmin}$, except in the vicinity of the crack, creating an artificial "damaged" zone.

The width of the damaged area and the value of the field are variable along the crack:

${a}_{1}=-0.04\cos(0.1(x-{x}_{{P}_{1}}))+0.0667$ **éq** 1.1-1

${a}_{2}=(\cos(0.3(x-{x}_{{P}_{1}}))+2)/3$ **éq** 1.1-2

The field described was discretized on a mesh to mesh cells rectangular size $\mathit{dx}=2.45$, $\mathit{dy}=1$, on a $120\times 40$ domain.

In the test case, the MED file containing the post-processing field, contained in a given structure of the result type (evol_noli), is given directly and created previously using the CREA_CHAMP and CREA_RESU commands, in order to make the test case faster. As the command only processes nodes fields, the analytical field is stored in the field at DEPL nodes, under the DX component (the VARI_NOEU field, which normally contains the damage, is not available in CREA_CHAMP).

### 1.2 Command Settings

The parameters used to search for the crack path are as follows:

LONG_ORTH= 20,

PAS= 2,

LONG_REG= 4,

SEUIL= ${10}^{-3}$

ANGL_MAX= 180

### 2.2 Tested quantities and results

The distance between the points found by the algorithm and the theoretical curve is tested. This distance, stored in the test case command file in the TAB_FISS table, represents the absolute error in each point. We then check that the maximum error is less than a certain accuracy. The test is done in absolute terms, as we compare ourselves to a zero distance. The precision requested is 0.05, the test case is analytical.

### 2.3 Remarks

The route found is very satisfactory. The procedure reproduces the strong curvatures of the journey, as well as the variations in the value of the field.

The accuracy is related to the width of the damaged strip, as seen on the right side of the strip: the error is greater where the width of the damaged strip is small.

That said, normally the damage resulting from a mechanical calculation is extended to several elements, so that convergence with refinement is verified, which limits this type of error.

## 3 Reference problem: crack opening on a study with damage law

In this test case, POST_ENDO_FISS searches both the crack path and the crack opening on a mechanical test case. The mechanical study is done beforehand which consists of a tensile test piece calculated with the ENDO_SCALAIRE damage law and then MAZARS. This mechanical calculation is not included in the test case due to the significant time required for calculation. Thus, a MED file containing the mechanical results is read, and then the post-processing control is applied. Finally, the crack opening is compared to the displacement imposed on the free edge.

### 3.1 Geometry, mesh and loading.

This is a two-fold tensile test piece. The dimensions of the test piece are $1m\times 2m$; the radius of the (semi-circular) slat is $6\mathrm{cm}$. At one end of the test piece, a displacement is imposed until rupture, when the resulting force applied is zero. The displacements of the other end are blocked in the direction of application of the load.

![Figure](/figures/v1.01.264/10000000000002020000011928C4F9ABC1147C78.png)

Figure 3.1-1: géométrie, maillage et conditions aux limites de l'éprouvette en traction.

### 3.2 Material properties and models of advance mechanical calculations

#### 3.2.1 Law ENDO_SCALAIRE

ENDO_SCALAIRE [R5.03.25](doc:r5.03.25) law is used, with gradient adjustment of [R5.04.01](doc:r5.04.01) internal variables and flat deformations: D_PLAN_GRAD_VARI Modelling.

  - *Elastic parameters:*

$E=40000\mathrm{MPa}$     Young's modulus

$\nu =0,25$         Poisson's ratio

*Damage parameters* **:**

$D=0.1m$ Half-width of the damaged strip

${G}_{f}=100N/m$ Breaking energy

$\mathrm{SY}=2.8\mathrm{MPa}$ Tensile strength

#### 3.2.2 Law MAZARS

MAZARS [R7.01.08](doc:r7.01.08) is used.

  - *Elastic parameters:*

$E=40000\mathrm{MPa}$         Young's modulus

$\nu =0,25$                 Poisson's ratio

*MAZARS* *(modelization B):*

${\varepsilon}_{\mathrm{d0}}=\mathrm{SY}/E=7E-5$ Damage Threshold

${A}_{t}=1$ Traction parameter

${B}_{t}=13000$ Traction parameter

${A}_{c}=1.09$ Compression parameter

${B}_{c}=1600$ Compression parameter

$\beta =1.06$ Parameter to improve shear response

$\mathrm{NON}\mathrm{LOCAL}=0.1m$ Characteristic length of non-local model

### 3.3 Post-processing POST_ENDO_FISS Settings

The crack path is searched for on the damage field. We therefore use the $\mathit{V1}$ component of the VARI_NOEU field (because the command only takes in fields to the nodes).

The average size of the mesh cell in the damaged area is $0.02m$.

The parameters used:

LONG_ORTH    = $2m$

PAS            = $0.02m$

LONG_REG    = $0.02m$

SEUIL        = $0.5$

LIM_FPZ    = $0.8$

All other parameters have the default value.

It is also possible to use the VARI component of the DEPL field, which also stores the damage variable and is a nodal field (so it can be used directly by the command). It is also necessary to project this field on a linear mesh, which will be given to it as an input to POST_ENDO_FISS, to make the interpolation of the VARI component consistent with that of the mesh (so linear).

The command file gives an example of how the VARI_NOEU/V1 field and DEPL/VARI field are used.

As regards Modelling C, the search for the cracking path is carried out on the equivalent deformation, as the damage field does not allow to identify a true maximum (it is too "flat"). We therefore use the $\mathit{V4}$ component of the VARI_NOEU field.

The parameters used in POST_ENDO_FISS are the same as in B Modelling, except for the following:

SEUIL        = $0.0001$

LIM_FPZ    = $0.0001$

At the end of the calculation, either the cracking path or the crack opening are tested.

Pour ce qui concerne le trajet de fissuration, celui ci doit à priori se trouver sur l'axe de symétrie de l'éprouvette, sur l'axe $x$ . On teste alors que la distance maximale à cet axe des points trouvés par la commande soit inférieure à une certaine précision. Un cas-test analytique est prévu, avec précision (absolue) égale à $1.5\times \mathit{taille}\mathit{élément}=0.03m$ .

For crack openings, the crack must be equal to the required displacement. Therefore, an analytical test case, with a relative accuracy of 10%, and an test case of non-regression with precision of 5%, are proposed.

### 4.3 Remarks

The found *cracking path* is satisfactory, however the accuracy recovered is at the limit of the permissible accuracy for the test case analytical. This is because the ENDO_SCALAIRE law locates the damage much when approaching the breakage (damage=1). According to the analytical solutions in fact, the damage is 1 as on the crack. This requires very fine meshes in the localization band. In the , a more precise cracking path could have been obtained following a mechanical calculation using a finer mesh.

For the crack opening, the error source is related to:

1. cracking path not perfectly straight,
2. residual force on the test piece close to but not equal to zero.
