## 3 Modelling A

### 3.1 TP procedure

The calculation is to be carried out by Modelling concrete using elements $3D$ and steel reinforcements with elements GRILLE_MEMBRANE. The command file *Code_Aster* will be generated using d

### 3.2 Mesh realization

**Option in limited time**: it is suggested to read the mesh (forma40a.mmed) which was made with a *Salomé* script. The file is recoverable in the directory of salome_meca installation (path: *XXX/salome_meca/VYYY/tools/Code_aster_stable_ZZZZ/share/aster/tests*).

**Option in unforced time**: the user can make the mesh, making sure to pass the mesh through the surfaces where the rebar arrays are located.

### 3.3 Elastic calculation

The purpose is to define the command file file to perform this study. The different steps are indicated below:

| Read mesh in MED (LIRE_MAILLAGE). |
| --- |
| Assign modellings to the different groups of mesh cells (AFFE_MODELE / 3D and GRILLE_MEMBRANE). |
| Define the features of elements structures (AFFE_CARA_ELEM, keyword GRILLE for elements GRILLE_MEMBRANE) namely the section and the reference point for defining the local reference point. |
| Define and affect the material properties of steel and concrete (DEFI_MATERIAU) (AFFE_MATERIAU). |
| Create time discretization using DEFI_LIST_REEL. |
| Set boundary conditions and loads (AFFE_CHAR_MECA, keywords DDL_IMPO and gravity). Note: loading on the $B1X$ edge requires setting a multi-plier function using the DEFI_FONCTION command that will be applied to loading via the keyword FONC_MULT on EXCIT or using AFFE_CHAR_MECA_F. |
| Use STAT_NON_LINE for elastic calculation (COMPORTEMENT/RELATION='ELAS') with the previously defined moment list. |
| Print the result in MED( IMPR_RESU/FORMAT='MED'). |
| Save and start the calculation. |

### 3.4 post-processing

#### 3.4.2 Trace force-moving curve in Code_Aster

By reproducing the initial control file or defining a new *stage* , make the post-processingss to trace the force-moving curve.

| Calculate nodal forces using the CALC_CHAMP command. |
| --- |

| Trace the force-moving curve to *XMGRACE* format using the IMPR_FONCTION command. To do this, recover the functions to be traced using RECU_FONCTION by applying the necessary filters. (Do not forget to specify the unit and define the output file to be able to view the curve directly). |
