# u4.52.06 Operator MODE_NON_LINE

## 1 Purpose

The operator MODE_NON_LINE makes it possible to compute a non-linear mode of an autonomous conservative linear system endowed with localised impact non-linearities.

The initial condition may be a linear mode or a non-linear mode, making it possible to use the results of an earlier analysis. The non-linearities are defined in the operator.

This operator produces a concept of type table_container.

## 3 Operands

### 3.1 Keywords MATR_MASS and MATR_RIGI

```text
♦    MATR_MASS
```

Real, symmetric assembled matrix of type [matr_asse_depl_r].

```text
♦    MATR_RIGI
```

Real, symmetric assembled matrix of type [matr_asse_depl_r].

### 3.2 Keyword ETAT_INIT

```text
◊    ETAT_INIT
```

Under this factor keyword, one can supply a periodic solution in order to initialise the algorithm for computing the non-linear modes.

#### 3.2.1 Operand MODE_LINE

```text
◊    MODE_LINE
```

Structure of type mode_meca produced by an analysis with the operator CALC_MODES. This keyword is not valid if the keyword MODE_NON_LINE is present.

#### 3.2.2 Operand MODE_NON_LINE

```text
◊    MODE_NON_LINE
```

Structure of type table_container produced by an analysis with the operator MODE_NON_LINE. This keyword is not valid if the keyword MODE_LINE is present.

#### 3.2.3 Operand NUME_ORDRE

```text
◊    NUME_ORDRE
```

If the keyword MODE_LINE is present then num_ordr indicates the order number of the linear eigenmode coming from mode_line chosen to initialise the algorithm.

If the keyword MODE_NON_LINE is present then num_ordr indicates the order number of the periodic solution coming from resu_in chosen to initialise the algorithm.

#### 3.2.4 Operand DIR_EVOLUTION

```text
◊    DIR_EVOLUTION
```

If 1 then one goes in the same direction as the first tangent vector computed.

If -1 then one goes in the direction opposite to the first tangent vector computed.

The default value is -1.

#### 3.2.5 Operand COEF_AMPL

```text
◊    COEF_AMPL
```

ampl is the maximum amplitude given to the periodic solution chosen to initialise the algorithm.

This value is useful when one initialises with a linear eigenmode, where the maximum amplitude must be small for the algorithm to converge.

The default value is 1.

### 3.3 Keyword CHOC

```text
◊    CHOC
```

Under this factor keyword, one supplies the configuration and the physical parameters corresponding to the impact non-linearity that one wants to impose.

#### 3.3.1 Operand JEU

```text
♦    JEU
```

jeu is the distance between the node and the elastic stop against which it can come into contact.

#### 3.3.2 Operand RIGI_NOR

```text
♦    RIGI_NOR
```

alpha is the stiffness of the elastic stop.

#### 3.3.3 Operand PARA_REGUL

```text
◊    PARA_REGUL
```

eta is the parameter making it possible to regularise the constitutive law that governs the relation between the node and the elastic stop.

The default value is 0.005.

#### 3.3.4 Operand GROUP_NO

```text
◊    GROUP_NO
```

grno is the name of the node group on which the non-linearity is located. Note that grno must contain only a single node.

#### 3.3.5 Operand OBSTACLE

```text
◊    OBSTACLE
```

Three possibilities:

'PLAN', which corresponds to a unilateral elastic stop.

'BI_PLAN', which corresponds to a bilateral elastic stop.

'CERCLE', which corresponds to an elastic stop of circular shape.

#### 3.3.6 Operand ORIG_OBST

```text
◊    ORIG_OBST
```

This keyword is available only in the case where OBSTACLE = 'CERCLE'. It defines the Cartesian coordinates of the centre of the circle in the local frame whose origin is the impact node.

#### 3.3.7 Operand NOM_CMP

```text
◊    NOM_CMP
```

If OBSTACLE = 'PLAN', or OBSTACLE = 'BI_PLAN' then this keyword indicates on which axis, 'DX', 'DY' or 'DZ', the stop is located.

If OBSTACLE = 'CERCLE', then this keyword indicates in which plane the stop is located.

Plane Oxy: ('DX','DY'),

Plane Oyz: ('DY','DZ'),

Plane Oxz: ('DX','DZ')

### 3.4 Keyword RESOLUTION

```text
♦    RESOLUTION
```

Under this factor keyword, one supplies the type of algorithm and the associated parameters. The available methods are to be declared under the operand METHODE.

#### 3.4.1 Operand METHODE

```text
◊    METHODE
```

Choice of the algorithm for computing the non-linear modes. The only algorithm currently available is 'EHMAN', corresponding to the combination of the harmonic-balance method (EH) and the asymptotic numerical method (MAN), together with a Newton algorithm. The latter makes it possible to ensure the convergence of the algorithm.

#### 3.4.2 Operand NB_HARM_LINE

```text
♦    NB_HARM_LINE
```

Hl is the number of harmonics used to expand, in the form of a Fourier series, the displacement variables.

#### 3.4.3 Operand NB_HARM_NONL

Hnl is the number of harmonics used to expand, in the form of a Fourier series, the functions representative of the constitutive laws that govern the relation between the node and the elastic stop. The following condition Hnl>Hl must be satisfied.

The default value is 201.

#### 3.4.4 Operand NB_BRANCHE

nbra is the number of branches computed by the MAN.

#### 3.4.5 Operand NB_PAS_MAN

npas is the discretisation step of the branches computed by the MAN.

#### 3.4.6 Operand NB_ORDRE_MAN

nordre is the discretisation number of the branches computed by the MAN.

The default value is 20.

#### 3.4.7 Operand PREC_MAN

eps_man is the tolerance of the MAN algorithm.

The default value is 1.E-9.

#### 3.4.8 Operand PREC_NEWTON

eps_newt is the tolerance of the Newton algorithm.

The default value is 1.E-8.

#### 3.4.9 Operand ITER_NEWTON_MAXI

iter_newt is the maximum number of iterations of the Newton algorithm.

The default value is 15.

#### 3.4.10 Operand CRIT_ORDR_BIFURCATION

crit_bif is the number of coefficients of the power series coming from the MAN. The bifurcation analysis is performed on these points.

The default value is 3.

#### 3.4.11 Operand RESI_RELA_BIFURCATION

```text
◊    RESI_RELA_BIFURCATION
```

eps_bif is the tolerance of the criterion that makes it possible to decide whether or not a bifurcation is present.

The default value is 1.E-4.

### 3.5 Keyword SOLVEUR

```text
◊    SOLVEUR
```

The syntax of this keyword, common to several commands, is described in the document [U4.50.01](doc:u4.50.01).

### 3.6 Keyword INFO

```text
◊    INFO
```

Integer making it possible to specify the print level in the MESSAGE file.

If INFO=1, only the number of the branch computed is reported.

If INFO=2, one also displays the relative error of the last point of the branch. As well as the error for each possible Newton iteration. And finally, the energy and the frequency of the first and of the last point of the branch.
