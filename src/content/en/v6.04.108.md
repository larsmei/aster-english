# v6.04.108 SSNV108 - European Robin CT-Round Test in Rupture Mechanics (1985)

**Summary**

This is a static test for a three-dimensional nonlinear elastic problem. This test allows to check the invariance of the $G$ calculation with respect to the integration crowns.

The tested features are CALC_G for FEM and CALC_G_XFEM Modelling for X-FEM Modelling.

Three modellings are available:

- Model A: mesh crack, elements isoparametric quadratic 3d,
- Modelling B: non-mesh crack (X-FEM), elements 2d
- Modelling C: non-mesh crack (X-FEM), elements 3d

The formulation of this test was derived from the European Round Robin in mechanics of the 1985 break.
