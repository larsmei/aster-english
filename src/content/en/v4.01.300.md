# v4.01.300 TPLA300 - Circular plate subjected to a volumetric heat source

**Summary:**

This test is based on independent validation of version 3 in linear steady-state thermal analysis.

The advantage of this test case 2D plan is to validate a thermal element under different boundary conditions (heat source, temperature imposed).

This test case includes two modellings 2D, one axisymmetric, the other plane.

The results are compared to an analytical solution.

## 4 Summary of the results

The results are very satisfactory, the difference maximum is $0.313\text{\%}$ .

Among the observation points, the difference is the most important one, with node N108, which belongs to the most distorted mesh.

The mesh used is the one proposed in the reference. A mesh radial with the same cutting and with the same mesh cells should give better results.

This test tested the inclusion of a source term in mesh cells QUAD9 with AXIS Modelling (AFFE_CHAR_THER associated with the SOURCE keyword).
