# v6.04.167 SSNV167 – Contact for Quadratic elements

**Summary:**

This problem corresponds to a quasi-static analysis of a contact mechanical problem. It is a very basic test on the quality of master/slave projection and geometric re-update, especially on non-plane quadratic mesh cells.

This test includes 5 modellings:

- Modelization A: with a linear mesh cell ( QUAD4 ) in contact formulation DISCRETE and with REAC_GEOM='CONTROLE';
- Modelling B: with a quadratic mesh cell ( QUAD8 ) in contact formulation DISCRETE and with REAC_GEOM='CONTROLE';
- Modelling C: with a quadratic mesh cell ( QUAD9 ) in contact formulation DISCRETE and with REAC_GEOM='CONTROLE';
- Modelling D: with a linear mesh cell ( QUAD4 ) in contact formulation CONTINUE;
- Modelling E: with a linear mesh cell ( QUAD4 ) in contact formulation DISCRETE , GCP method and with REAC_GEOM='AUTOMATIQUE' ;
- F Modelling: with a linear mesh cell ( QUAD8 ) in contact formulation CONTINUE;
- G Modelling: with a linear mesh cell ( QUAD9 ) in contact formulation CONTINUE .
