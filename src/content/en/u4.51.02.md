# u4.51.02 Macro-command MACRO_ELAS_MULT

## 1 Purpose

The role of the command is to compute linear static responses for different load cases or Fourier modes.

It is assumed that the kinematic conditions (restraints of the structure) and the material characteristics are invariant for all the load cases, which makes it possible to have the same stiffness matrix.

The data structure produced is of type mult_elas for the multiple load case or fourier_elas for the Fourier analyses.

## 2 Syntax

```text

/ mult_elas
/ nume_ddl = MACRO_ELAS_MULT(
```

## 3 Operands

MACRO_ELAS_MULT is a macro-command which calls elementary operators liable to create concepts temporarily on the global database; it is therefore possible that the file associated with the latter contains superfluous records marked as destroyed. To reduce the final size of the file, when one wishes to keep it, one may use the procedure FIN and the keyword RETASSAGE='OUI' in the command file.

### 3.1 Operands MODELE / CHAM_MATER / CARA_ELEM

The arguments making it possible to compute the stiffness matrix (and the right-hand sides) are supplied.

```text
♦    MODELE    =    mo,
```

Name of the model whose elements are the subject of the mechanical analysis.

```text
◊    CHAM_MATER    =    chmat,
```

Name of the material field.

```text
◊    CARA_ELEM    =    carac,
```

Name of the characteristics of the structural elements (beam, shell, discrete elements, ...) if they are used in the model.

### 3.2 Operand NUME_DDL

```text
◊    NUME_DDL    =    nu,
```

Keyword used to name the numbering for later use or to use an existing numbering. If no name is supplied, a numbering is created temporarily for each call to MACRO_ELAS_MULT.

### 3.3 Operands CHAR_MECA_GLOBAL / LIAISON_DISCRET

```text
♦    /    CHAR_MECA_GLOBAL    =    lchmg,
```

Keyword defining the mechanical boundary conditions restraining the structure.

These conditions are the same for all the load cases. They are defined by AFFE_CHAR_MECA or AFFE_CHAR_MECA_F [U4.44.01](doc:u4.44.01).

```text
/    LIAISON_DISCRET= 'OUI',
```

This keyword simply states that there are no mechanical or kinematic restraint conditions on the structure.

### 3.4 Keyword CAS_CHARGE

Factor keyword making it possible to define a load case.

For each occurrence of the factor keyword, a right-hand side is built (unless VECT_ASSE is used (in which case the right-hand side is already assembled)) and the linear system is solved.

#### 3.4.1 Operand NOM_CAS

```text
♦    NOM_CAS    =    moncas,
```

Character string, used as the access variable to the result data structure.

**Note:**

Each case is named by the user and the notion of sequence number does not exist.

#### 3.4.2 Operands MODE_FOURIER / TYPE_MODE

```text
◊    MODE_FOURIER    =    mode,
```

Positive or zero integer indicating the Fourier harmonic on which the elementary stiffness matrix and the elementary vector are computed.

```text
◊    TYPE_MODE    =    type,
```

The type of the harmonic will be symmetric ('SYME'), or antisymmetric ('ANTI'), or symmetric and antisymmetric ('TOUS') (cf. the Fourier user's guide [U2.01.07](doc:u2.01.07)).

#### 3.4.3 Operands CHAR_MECA / VECT_ASSE

```text
◊    CHAR_MECA    =    lcharm,
```

List of concepts of type char_meca produced by AFFE_CHAR_MECA [U4.44.01](doc:u4.44.01) or AFFE_CHAR_MECA_F [U4.44.01](doc:u4.44.01) from the model mo.

Note for defining a load case of "thermal expansion alone":

- taking thermal expansion into account in a load case is systematic if the material field "contains" temperature (AFFE_VARC/NOM_VARC='TEMP').
- for this loading to be the only one taken into account, lcharm must contain a "null" mechanical load (for example a zero nodal force on a node).

```text
◊    VECT_ASSE    =    chdep,
```

Concept of type cham_no_depl_r representing the right-hand side of the linear system to be solved.

#### 3.4.4 Operands OPTION

```text
◊    OPTION =    /    'SANS',
/    'SIEF_ELGA',    [DEFAUT]
```

By default the command MACRO_ELAS_MULT computes the stresses at the Gauss points (or the generalised forces for the structural elements).

The other post-processing options will be computed a posteriori by the command CALC_CHAMP [U4.81.04](doc:u4.81.04).

If the user indicates OPTION = 'SANS', these stresses will not be computed and the data structure produced will be less bulky.

#### 3.4.5 Operand SOUS_TITRE

```text
♦    SOUS_TITRE    =    soustitre,
```

Subtitle that one wishes to give to the resulting displacement field.

### 3.5 Keyword SOLVEUR [U4.50.01](doc:u4.50.01)

This keyword makes it possible to choose the method for solving the linear systems. Recall that, in the case of the multiple load case, a single factorisation is performed for each call to MACRO_ELAS_MULT and one solution for each load case.

### 3.6 Operand TITRE

See [U4.03.01](doc:u4.03.01).

## 4 Examples

One may refer to the test SSLL14 A [V3.01.014](doc:v3.01.014).

```text
# définition des conditions aux limites de blocage

bloqu    =    AFFE_CHAR_MECA(    MODELE= modele,
DDL_IMPO=(_F(TOUT='OUI' ,    DZ=0.    ),
_F(GROUP_NO=('A','B'),DX=0.,DY=0.,),))

# définition de 4 chargements

charg1        =    AFFE_CHAR_MECA(    MODELE= modele,
FORCE_POUTRE=_F( GROUP_MA= 'D2' , FY= P ) )

charg2        =    AFFE_CHAR_MECA(    MODELE= modele,
FORCE_NODALE=_F( GROUP_NO= 'C' , FY= F1 ) )

charg3        =    AFFE_CHAR_MECA(    MODELE= modele,
FORCE_NODALE=_F( GROUP_NO= 'D' , FX= F2 ) )

charg4        =    AFFE_CHAR_MECA(    MODELE= modele,
FORCE_NODALE=_F( GROUP_NO= 'D' , MZ= M ) )

statique    =    MACRO_ELAS_MULT    (    MODELE                    = modele,
CHAM_MATER            = ch_mater,
CARA_ELEM                = cara_ele,
CHAR_MECA_GLOBAL        = bloqu,

# on donne un nom afin de recupérer le concept NUME_DDL
NUME_DDL = nu_ddl,
CAS_CHARGE=_F    (    NOM_CAS = 'charge numero 1',
CHAR_MECA = charg1,
OPTION = 'SIEF_ELGA',
SOUS_TITRE='charge repartie verticale sur DC',
),
)
```

```text
# deuxième série de cas de charge

statique=    MACRO_ELAS_MULT    (        reuse                = statique,
MODELE                = modele,
CHAM_MATER        = ch_mater,
CARA_ELEM            = cara_ele,
CHAR_MECA_GLOBAL    = bloqu,

# on donne le concept NUME_DDL calculé précédemment
NUME_DDL = nu_ddl,
CAS_CHARGE=(_F(    NOM_CAS = 'charge numero 2',
CHAR_MECA = charg2,
OPTION = ( 'SIEF_ELGA','REAC_NODA' ),
SOUS_TITRE= 'force ponctuelle verticale en C',
),

_F    (    NOM_CAS ='charge numero 3',
CHAR_MECA =charg3,
OPTION =( 'SIEF_ELGA','REAC_NODA' ),
SOUS_TITRE='force ponctuelle horizontale en C',
),
_F    (    NOM_CAS = 'charge numero 4',
CHAR_MECA = charg4,
OPTION = ( 'SIEF_ELGA','REAC_NODA' ),
SOUS_TITRE= 'moment en C',
),),
)
```
