# u4.15.01 Procedure MAJ_CATA

## 1 Purpose

Compilation of the element catalogue (associated AGLA scripts: ccat92-py and ccat‑ele.csh).

This procedure is of no interest to the user.

If necessary, one may refer to the AGLA User's manual [D1.02.01](doc:d1.02.01).

## 2 Syntax

```text
MAJ_CATA(
    ◆ / ELEMENT = _F(
        ),
      / TYPE_ELEM = _F(
        ),
    ◇ UNITE = unit (défaut: 8),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Keyword ELEMENT

This operand causes compilation of the element catalogue.

**Note:**

*Management of logical units by name in JEVEUX has led to the removal of the simple keywords under this factor keyword. The calling syntax is therefore of the form:*

*MAJ_CATA* *(* *ELEMENT = _F() , )*

### 3.2 Keyword TYPE_ELEM

This operand causes the printout of all the (element_type, option) pairs available in the version called; this information can then be used for the analysis of code coverage.

#### 3.2.1 Keyword UNITE

◊     UNITE = num

Number of the logical unit associated with a file to which the printouts will be directed. One should refer to the command DEFI_FICHIER [U4.12.03](doc:u4.12.03). By default, the printouts are made in the file associated with logical unit 8.
