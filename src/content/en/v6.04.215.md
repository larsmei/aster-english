# v6.04.215 SSNV215 - constitutive law BETON_RAG: rotation test of the main directions

**Summary:**

This document presents a test to validate the capabilities of the BETON_RAG behavior model, used to estimate the long-term behaviour of structures affected by the alkali-granulat reaction. Here, the behaviour of a test piece subjected to a specific loading path creates a continuous rotation of the directions of the main stresses.

## 1 Reference problem

In this test [Willam et al., 1987], the test piece is subjected to a specific loading path that creates a continuous rotation of the directions of the main stresses. This determines the ability of the model to converge despite such changes.

### 1.1 Geometry

The test is based on a single cubic finite element (1m x 1m).

### 1.2 Ownership of materials

Young's modulus:                                     $E=32000\mathrm{MPa}$

Poisson's ratio :                                $\nu =0.2$

Fragility parameter of tensile concrete: $\mathit{MT}=1,7$

Fragility parameter of compression concrete: $\mathit{MC}=1,5$

Equivalent tensile force of concrete: ${\sigma}_{\mathit{ft}}=7.3\mathit{MPa}$

Equivalent stress of compression concrete: ${\sigma}_{\mathit{fc}}=38.3\mathit{MPa}$

Angle of Drucker Prager's criterion: $\alpha =0,15\mathit{rad}$

### 1.3 Boundary conditions and loads

This is a cube that is subject to a uniform non-proportional loading, consisting of shifts imposed in the $(\mathrm{Ox},\mathrm{Oy})$ plane.

The material is initially subjected to uniaxial traction in the direction $xx$ until the peak of the stress-deformation curve, in a second step an $xy$ shear and an orthogonal traction $yy$ superimposed on the uniaxial load $xx$ (which continues), it results from this loading path a rotation of the main directions of the stresses resulting in the appearance of a ${\sigma}_{xy}$ shear stress.

This results in imposed deformations that evolve affinely in pieces as a function of time, with:

- à $t=0.01\mathrm{jour}$ , $\epsilon ={10}^{-4}(\begin{array}{cc}0.84& 0\\ 0& -0.105\end{array})$
- à $t=0.05\mathrm{jour}$ , $\epsilon ={10}^{-4}(\begin{array}{cc}5.6& 4.76\\ 4.76& 7.035\end{array})$

The following boundary conditions are applied:

- for nodes in the X=0 → DX = 0
- for node N1 (0, 0, 0) → DX = DY = DZ = 0
- for node N5 (0, 0, 1) → DY = 0
