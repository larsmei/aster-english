# u4.66.21 Operator MODI_BASE_MODALE

## 1 Purpose

Define the modal basis of a structure under flow. This basis is obtained after an analysis of fluid-elastic coupling carried out with the aid of the operator CALC_FLUI_STRU [U4.66.02](doc:u4.66.02). The concept produced is of type mode_meca.

## 2 Syntax

```text
mode_meca = MODI_BASE_MODALE(
    ◇ reuse = <objet de BASE>,
    ◆ BASE = mode_meca,
    ◆ BASE_ELAS_FLUI = melasflu,
    ◆ NUME_VITE_FLUI = int,
    ◇ NUME_ORDRE = int,
    ◇ / AMOR_REDUIT = float,
      / AMOR_UNIF = float,
    ◇ INFO = / 1 (par défaut),
             / 2,
    ◇ TITRE = text,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```
## 3 Operands

```text
♦    BASE = mode
```
Concept of type [mode_meca] which defines the modal characteristics before the fluid-elastic coupling is taken into account. According to the user's choice, the operator modifies this input concept or creates a new concept of type [mode_meca].

```text
♦    BASE_ELAS_FLUI = bef
```
Concept of type [melasflu] which defines the new characteristics of the modes taken into account for the fluid-elastic coupling, for different flow velocities.

```text
♦    NUME_VITE_FLUI = numv
```
Makes it possible to point to the characteristics of the modes taken into account for the fluid-elastic coupling, for a given flow velocity.

```text
◊    NUME_ORDRE = l_nuor
```
If one modifies the input concept of type [mode_meca]: list of the order numbers of the unperturbed modes to which one wishes to assign a reduced damping.

If one creates a new concept of type [mode_meca] on output: list of the order numbers of the unperturbed modes which are actually retained in order to rebuild the modal basis. The possibility of assigning a reduced damping to these modes is retained, by resorting to the operands AMOR_REDUIT or AMOR_UNIF below.

**Note:**

*By default, one selects all the modes which have not been taken into account for the fluid-elastic coupling. Do not give in this list order numbers corresponding to the coupled modes.*

*The constitution of the resulting* [mode_meca] *as a function of the choices for the operands* *NUME_ORDRE,* *AMOR_REDUIT and* *AMOR_UNIF* is specified in paragraph [§ 1 *].*

```text
◊    /    AMOR_REDUIT = l_amor
```
List of the reduced dampings assigned to the unperturbed modes.

```text
/    AMOR_UNIF = amor
```
Reduced damping assigned identically to the unperturbed modes.

```text
◊    INFO = 1 ou 2
```
Inactive operand. In order to obtain the printout of the results, one must use the command IMPR_RESU [U4.91.01](doc:u4.91.01).

```text
◊    TITRE = titre
```
Argument of text type [TXM] defining the title attached to the output concept [mode_meca].
