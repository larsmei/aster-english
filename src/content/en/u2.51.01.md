# u2.51.01 User's guide to Grace for Code_Aster

**Summary:**

This document presents the graphical curve-plotting tool Grace, a powerful tool for plotting and manipulating curves produced by *Code_Aster*.

## 1 General points

### 1.1 Presentation of Grace

Grace is a graphical curve-plotting tool (WYSIWYG) under the GPL licence, available on systems of Unix/Linux type and ported to other platforms (including Windows). The strong points of Grace are the following:

- modification of the plots in a graphical environment by contextual menu;
- very precise control of the elements on the curves (plots, legends, axes, etc...);
- “journal publication” quality;
- export of (E)PS, PDF, JPG, PNG (depending on the platform and the installation);

The Grace website is
[http://plasma-gate.weizmann.ac.il/Grace](http://plasma-gate.weizmann.ac.il/Grace)

### 1.2 Purpose of this tutorial

The aim of this tutorial is to enable the user of Aster to get to grips fairly quickly with a powerful tool allowing him or her to plot curves.

This tutorial presents the two main stages for plotting curves:

- importing and modifying the data;
- specifying the graphical aspects of the curves.

## 2 Creation/import of data

This paragraph describes the “data” part of Grace. There are three ways of obtaining data to be plotted in Grace:

- by import of data in files;
- by creation of data (via sampled mathematical functions);
- by duplication and modification of existing data.

### 2.1 Import

Grace is capable of importing curves from text files. These files must contain only data (with the exception of lines beginning with # which are considered as comment lines).

The data must be in columns (separated by spaces or by tabulation characters). Warning: a file can contain only a single “data block”, i.e. data over several columns and several lines (unlike the .dogr files previously used by the Agraf tool).

### 2.3 Duplication and modification of existing data

Suppose that Grace already has the following curve:

![Figure](/figures/u2.51.01/10000201000003B1000002D2CB771B52B1CDC644.png)

In order to duplicate/modify a curve, there are two solutions. Whichever solution is chosen, it is necessary to open the command console. With the first solution, one begins by duplicating the curve in order to modify it in the command console; with the second, everything is done in the command console.

#### 2.3.1 Duplication then modification in the console

One assumes that there is at least one curve available in Grace.

The chaining of commands is the following:

- Edit/Set Operations,
- select G0 as the graph to be copied, S0 as the curve to be copied and G0 as the destination graph and “copy” as the operation to be carried out, finally “accept”,
- one must now modify column Y of the set S1; this is done by opening the command console: Window/Commands, and typing “s1.y = s0.y^2” in order to obtain the previous curve squared (Cf. [§5.4] of the User's Guide for a complete list of the operations allowed).

| ![Figure](images/100002010000012D000001A487FC40C29834817C.png) | ![Figure](images/100002010000016B0000014D1C3B89524D99909F.png) |
| --- | --- |

#### 2.3.2 creation in the console

One opens the command console straight away: Window/Commands.

- One first creates the curve by specifying the number of points (identical to the number of points of the set S0) “s1 length s0.length”,
- then one duplicates the abscissae “s1.x = s0.x”,
- finally one defines the ordinates “s1.y = s0.y^2”

## 3 Organisation of Grace into graphs and curves

### 3.1 General points

For Grace, a graph is a plot which can contain several curves; a Grace “project” (which can be saved in a file bearing the extension “agr) can contain several graphs.

The graphs are named G0, G1,...

The curves are named S0, S1,...

### 3.2 Management of the graphs

The user can manage the graphs in each graph-selection list (for example in the menus Edit/Arrange Graphs, Edit/Set Operations, Edit/Overlay Graphs, Plot/Graph Appearance as in the illustration below, or Data/Import/Ascii).

![Figure](/figures/u2.51.01/10000201000001510000025CFF942988A33FE560.png)

In the zone below “Graph”, one finds a list of graphs (here, the project comprises two graphs, the first comprising three curves, the second comprising a single curve). One will note the “(-)” in front of the first graph, which means that the first graph is “hidden” (hidden, i.e. not displayed), whereas the (+) in front of the second means that it is displayed (showed). The graph or graphs highlighted are the graph or graphs concerned by the action in progress: here, the modification of the graph concerns G0 (even if it is hidden!). Likewise, on import of a curve:

![Figure](/figures/u2.51.01/100002010000018F000002D28BB5452CD0244208.png)

the curve that the user is preparing to import will go into the graph G0 (as previously, this graph being hidden, the imported curve will not be displayed).

In certain menus (Plot/Graph Appearance for example), it is possible to select several graphs (in the usual way: Ctrl + left click for a selection of graphs “one by one”, or Shift + left click on the first and last element of a contiguous list, or left click + movement of the mouse over a list....), whereas other menus (Data/Import/Ascii for example) allow only a single graph to be selected.

An important (and not very intuitive) command is the right click on the list of graphs, which opens a menu comprising the following commands:

- focus to: in order to define the active graph (useful if several graphs are displayed: the active graph is the one which receives the actions when the user uses the icons; likewise, in order to manage the curves of a graph, the graph must be the active graph);
- hide: hides the graph;
- show: displays the graph;
- duplicate: duplicates the graph and all its curves;
- kill: destroys the graph;
- swap: exchanges two graphs (two graphs must be highlighted);
- create new: creates a new (empty) graph.

In summary, in order to create a new graph, one must open the list of graphs (by using for example Plot/Graph Appearance), right-click on the list of graphs and choose “Create New”). One will note that there exists no menu making it possible to carry out this action directly.

### 3.3 Management of the curves

The principle of management of the curves is roughly the same as that concerning the graphs. Grace displays the list of curves (of the active graph: warning, once again, the active graph is not necessarily visible!) in the menus which manipulate the curves: Edit/Data Sets, Edit/Set Operations, Data/Data set operations, Plot/Set Appearance as in the following illustration:

![Figure](/figures/u2.51.01/100002010000019F000002D057BE58B897704EE6.png)

The active graph is here G0 (it is recalled as a prefix of the curves in the list); it possesses three curves (one will note the mention, in brackets, after the name of the curves, of the dimension — here 2 for X and Y — and of the length — here, the curves all have 150 points —).

In the list of curves, a right click opens a menu:

- hide: hides the curve;
- show: displays the curve;
- bring to front: puts the curve in the foreground;
- send to back: puts the curve in the background;
- duplicate: duplicates the curve;
- kill: deletes the curve;
- kill data: deletes the data but not the curve, i.e. all the formatting is retained, which can be very practical if the user has two identical graphs to produce from different data: it is sufficient to create a graph, then to remove all the data with “kill data”, and to import the second series of data: the two graphs will have exactly the same appearance;
- swap: exchanges the position of the two curves
- edit: edits the data;
- create new: creates a new curve;
- pack all sets: ?
- selector operations: a sort of preference menu for the display of this list of curves.

Note:

All the previous operations on the curves are done inside one and the same graph. In the case where the user would need to copy a curve from one graph onto another, one must use the menu Edit/Set Operations.

### 4.2 Formatting of the graphs

The menu Plot/Graph Appearance makes it possible to define the formatting of the graphs, i.e. all the formatting common to all the curves of the graph, apart from the definition of the axes, which is accessible via Plot/Axis Properties.

One confines oneself here to a summary description; for more advanced functions, the simplest is no doubt to go through the tabs of the dialogue window of Plot/Graph Appearance directly.

In order to give a title to a graph, the text of the title is to be put in the Main tab, the character size being adjustable in the Title tab.

For the axes (hence the menu Plot/Axis Properties), one also confines oneself to the most common commands. First of all one must note, in the dialogue box opened by Plot/Axis Properties, the drop-down menu which makes it possible to define the axis that one is in the process of modifying (X axis, Y axis,...). In this box one can choose the start and end values of the axis (via the Start and End fields), as well as the type of scale (linear, algorithmic, etc).

### 4.3 Formatting of the curves

The formatting of the curves is controlled from the menu Plot/Set Appearance. In the dialogue box opened by this menu, there is first of all a list of the curves contained in the current graph, which makes it possible to select the curve whose properties one is editing.

In order to attach a legend to a curve, one must define the text of the legend in the Main tab (Legend, String). One will note that it is possible to produce complex legends.

One can choose the line style, its colour and its thickness as well as the symbols used to materialise each point in the Main tab (Line Properties and Symbol Properties). More precise definitions can be added in the Line and Symbols tabs respectively.

## 5 Use of the toolbar

![Figure](/figures/u2.51.01/100000000000004500000172BCA1B9C6A5520C42.png)

The toolbar is displayed vertically at the top left of the Grace window:

- The magnifying glass makes it possible to zoom by defining a zone with the mouse;
- The “AS” icon (for autoscale) makes it possible to redefine the framing (zoom) automatically.
- The buttons “Z” and “z” serve to zoom out and zoom in respectively.
- The arrows serve to move the plotted zone.
- AutoT: automatic definition of the ticks from the curve closest to the point clicked.
- AutoO: automatic framing from the curve closest to the point clicked
- ZX, ZY: like the magnifying glass but in a single direction (X or Y)
- AX, AY: automatic framing in a single direction (X or Y)

The other buttons concern the management of the stack of graphs and will not be explained here.

## 6 Tips and tricks

### 6.1 Extended characters, in particular the Greek alphabet

It is possible to use fonts other than the standard font in any text zone (curve legend, axis label, etc...). In particular, it is possible to use the “Symbol” font in order to insert Greek characters.

For this, if in the “String” field of the legend one puts the following string “test f{Symbol} test f{Arial} test”, like this:

![Figure](/figures/u2.51.01/100000000000018C0000003AAD114B1B9B25523F.png)

one obtains a legend which looks like this (the command f{x} changing the font)

![Figure](/figures/u2.51.01/10000000000000F60000002912395DBF9F227123.png)

One will find in the User's Guide in paragraph 7.1 the various commands making it possible to control the formatting of the text zones (in particular the fonts, the size, the colour, etc) and in paragraph [§6.1] the mechanism for defining the various fonts usable by Grace.

### 6.2 Point or comma?

By default, Grace relies on the user environment in order to know whether it must represent the decimal figures with a point or a comma. On most recent systems, in France, it will therefore use the comma. If it is necessary to print curves with points, under linux, one must carry out the following operation: before launching Grace, do “export LC_NUMERIC=POSIX” or “setenv LC_NUMERIC POSIX” depending on the shell used.
