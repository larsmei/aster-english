# v7.16.100 HSLL100 – Bi-clamped multifibre beam subject to a temperature field

**Summary**

This test validates the correct temperature consideration for the constitutive law ELAS in the case of a multi-fibre beam. This test allows to verify that the thermal expansion is well calculated.

## 1 General characteristics

### 1.1 Geometry

It is a clamped beam at both ends.

![Figure](/figures/v7.16.100/Shape1.gif)

### 1.2 Material properties

$E=2.0\text{E+11}\mathrm{Pa}$     Young's modulus

$\nu =0.3$     Poisson's ratio

$\alpha =15.0\text{E-06}/°C$ Dilation coefficient

$D\text{\_}\mathrm{SIGM}\text{\_}\mathrm{EPSI}=2.0\text{E+09}\mathrm{Pa}$ Tensile curve pent

$\mathrm{SY}=150.0\text{E+10}\mathrm{Pa}$ Elasticity limit

### 1.3 Boundary conditions and loads

Clamped support at $A$ and $B$ points: $\mathrm{DX}=\mathrm{DY}=\mathrm{DZ}=\mathrm{DRX}=\mathrm{DRY}=\mathrm{DRZ}=0$

Temperature imposed: $T=400°C$

The temperature imposed is increasing linearly as a function of time.

![Figure](/figures/v7.16.100/Shape2.gif)

### 1.4 Initial conditions

Reference temperature : $0°C$

## 2 reference solution

### 2.1 Calculation method used for reference solution

The clamped support at $A$ and $B$ points allows you to block the following $x$ deformations: ${\varepsilon}_{xx}=0$ .

This block associated with the temperature imposed creates an axial compression constraint along the $x$ axis. This constraint is expressed as:

${\sigma}_{xx}=E\alpha ({T}_{\mathrm{reference}}-T)$

### 2.2 Reference quantities

Constraint $\mathrm{SIXX}$

### 2.3 Baseline

For $T=200°C$ we get $\mathrm{SIXX}=-0.6\text{E+09}\mathrm{Pa}$

For $T=400°C$ we get $\mathrm{SIXX}=-1.20\text{E+09}\mathrm{Pa}$

### 2.4 Uncertainty about the solution

analytical solution
