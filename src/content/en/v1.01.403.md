# v1.01.403 ZZZZ403 - Validation of POST_LIQUEFACTION use on a 2D dam case

**Summary:**

This test validates the use of the POST_LIQUEFACTION macro-command. [U4.84.44](doc:u4.84.44), which calculates a soil liquefaction detection criterion.The four formulas associated with the criterion are tested,

Modelling A: A comparative test between a fictitious field on a dam and a Code_Aster calculation using the POST_LIQUEFACTION macro-command was performed. It was chosen to take extremely simple values for the fields to verify the analytical values obtained.

## 1 Modelling A

### 1.1 Purpose

The purpose of this test is to validate the use of POST_LIQUEFACTION macro-command. An extremely simple field was created on a 2D dam to validate the calculation of the macro-command. It should be noted that for this non-physical test, the quantities orders of the criteria do not correspond to the values commonly obtained on a dam.

### 1.2 Description

Hydromechanical modelling is assigned to a mesh 2D: MODELISATION = 'D_PLAN_HM_SI'. The SIEF_ELGA stress field is recovered at Gauss points in the 'EVOL_NOLI' data structure read in MED format.

The direction of the gravity is $y$. We select a particular moment.

The values of the fictitious fields are:

| Component | Value |
| --- | --- |
| ${p}_{h}$ | 18 Pa |
| ${p}_{h}^{\mathit{eff}}$ | 16 Pa |
| ${\sigma}_{xx}^{\mathit{eff}}(t,\mathrm{x})$ | 1 Pa |
| ${\sigma}_{yy}^{\mathit{eff}}(t,\mathrm{x})$ | 3 Pa |
| ${\sigma}_{zz}^{\mathit{eff}}(t,\mathrm{x})$ | 2 Pa |

The values for the actual stresses at the $t$ and reference moment are identical.

In this case, the expected values (which are not physical) are:

| Criterion | Value |
| --- | --- |
| DP_SIGV_REF | 4 |
| DP_SIGM_REF | 6 |
| DP | 12 Pa |
| P_SIGM | 14 |

### 1.3 Validation principle

Comparison of the calculation of the soil liquefaction detection criterion with Code_Aster.

### 1.4 Test values

The value of the sum of the absolute values of the components of the SIPYY difference field shall be tested at a particular moment with a value field corresponding to the expected values (paragraph 1.2).

## 2 Conclusion

The test shows that the POST_LIQUEFACTION macro-command is working well.
