# v1.01.134 ZZZZ134 – Calculation and extraction of the discharge matrix

**Summary:**

This test is an example of how to calculate and recover the discharge matrix for RGI_BETON law.

A calculation is performed with the STAT_NON_LINE operator and then shows how to calculate and recover the discharge matrix for a few moments of calculation given via CALCUL operator and keyword TYPE_MATR_TANG=

This test validates the correct consideration of TYPE_MATR_TANG's 的MATR_ENDO.
