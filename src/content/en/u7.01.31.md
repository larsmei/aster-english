# u7.01.31 Procedure PRE_GMSH

## 1 Purpose

This command is deprecated.

It is recommended to use LIRE_MAILLAGE, FORMAT='GMSH'.

Read a mesh file in GMSH format, then write it in *Aster* format.

GMSH is a tool for modelling, meshing and post-processing, distributed under the GNU GPL licence at the address [https://gmsh.info](https://gmsh.info).

## 2 Syntax

```text
PRE_GMSH(
    ◇ UNITE_GMSH = unit (défaut: 19),
    ◇ UNITE_MAILLAGE = unit (défaut: 20),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand UNITE_GMSH

```text
◊    UNITE_GMSH = unilec
```

Logical number of the GMSH result file (reading).

### 3.2 Operand UNITE_MAILLAGE

```text
◊    UNITE_MAILLAGE = uniecr
```

Logical number of the *Aster* mesh file (writing).

## 4 Use

PRE_GMSH can read GMSH files in ASCII formats 1.0 and 2.0.

**Note**

*GMSH can read and write meshes in MED format. The MED format is therefore to be preferred.*

In GMSH, the entities are numbered and sometimes named. On rereading by PRE_GMSH, only the numbers are kept.

All the groups of elements of numbers 1, 2, … created in GMSH (“physical”) are transformed into mesh-cell groups (GROUP_MA) bearing the name GM1, GM2, …

At the level of the astk interface, the mesh file produced by GMSH (which gives it the extension .msh) is reread by PRE_GMSH on logical unit 19 by default.

The generic type for the geometry data is .datg (logical unit 16 by default).
