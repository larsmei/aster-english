# v1.01.100 ZZZZ100 – Functions, sheets, formulas

**Summary:**

The modellings of this test validates the operation of operators allowing the creation and manipulation of functions, sheets and formula.

In particular, it is a test of the different possibilities of the commands DEFI_FONCTION, DEFI_NAPPE, CALC_FONCTION, INFO_FONCTION, LIRE_FONCTION, IMPR_FONCTION, DEFI_PROP_ALEA.

Several modes of bypass or integration are possible in CALC_FONCTION.

Other tests on the base check the proper functioning of these commands with physical values.

This documentation is deliberately succinct.
