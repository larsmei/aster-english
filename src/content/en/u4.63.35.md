# u4.63.35 Operator REST_MODE_NONL

## 1 Purpose

The operator REST_MODE_NONL makes it possible to recover, in the time domain or in the Fourier domain, a periodic solution coming from an analysis with MODE_NON_LINE.

This operator produces a concept of type dyna_trans (in the time domain) or mode_meca (in the Fourier domain).

## 2 Syntax

```text
/ dyna_trans
/ mode_meca = REST_MODE_NONL(
    ◆ MODE_NON_LINE = table_container,
    ◇ TYPE_RESU = / "MODE_MECA",
                  / "DYNA_TRANS" (par défaut),
    ◆ NUME_ORDRE = int,
    # Si: equal_to("TYPE_RESU", 'DYNA_TRANS')
        ◇ NB_INST = int (défaut: 512),
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Keyword MODE_NON_LINE

```text
♦    MODE_NON_LINE
```

resu_in is a concept of type table_container coming from an analysis with the operator MODE_NON_LINE.

### 3.2 Keyword NUME_ORDRE

```text
♦    NUME_ORDRE
```

num_ordr indicates the order number of the periodic solution coming from resu_in that one wishes to recover.

### 3.3 Keyword TYPE_RESU

```text
◊    TYPE_RESU
```

If TYPE_RESU = 'MODE_MECA' then resu_out is a periodic solution in the Fourier domain.

If TYPE_RESU = 'DYNA_TRANS' then resu_out is a periodic solution in the time domain.

By default, TYPE_RESU = 'DYNA_TRANS'.

### 3.4 Keyword NB_INST

```text
◊    NB_INST
```

nb_inst is the desired discretisation of the periodic solution, for a recovery in the time domain (i.e. TYPE_RESU = 'DYNA_TRANS'). Note that nb_inst must be a power of 2. By default, nb_inst = 512.
