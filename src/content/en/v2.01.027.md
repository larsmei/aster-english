# v2.01.027 SDLD27 - 8 degrees of freedom spring mass-system with non-proportional viscous shock absorber (modal analysis)

**Summary:**

This two-dimensional problem consists in searching for the frequencies, vibration modes and damping of a mechanical structure composed of viscous masses, springs and shock absorbers. This test case Structure Mechanics corresponds to a dynamic analysis of a discrete model with linear behavior.

This test allows for a complete validation of the discrete modelling options of rigidity, viscous damping and mass (without elements finished) offered by the AFFE_CARA_ELEM command. Five different modellings are offered: the Modelling of the discrete elements is either translational, translational/rotational and is written either as a global benchmark or as a local benchmark. Furthermore, different features of the CALC_MODES commands (search for clean values) and NORME_MODE (definition of the standard of a clean vector) are tested for this quadratic problem.

This test refers to an VPCS test, but it has been modified. Indeed, the test directs the mechanical system on an $\mathrm{3y}=\mathrm{4x}$ axis, which allows the data entry to be validated as a local reference. The results obtained are in good agreement with the reference results.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The reference solution is the one given in the SDLD27 plug in the VPCS guide.

The problem leads to the search for the clean values and proper vectors of the following dissipative system:

$M\ddot{u}+C\dot{u}+Ku=0$

with $M$ mass matrix, $C$ damping matrix, $K$ stiffness matrix.

The problem is associated with this dissipative problem, the conservative problem: $Ku+M\ddot{u}=0$ . In harmonic form, it spells $K-{\omega}^{2}M=0$ .

$\Lambda =[{\omega}_{v}^{2}]$ is the spectral diagonal matrix of the values of this conservative system and $\phi =[{\varphi}_{v}]$ is the corresponding matrix of the own vectors.

${\varphi}_{v}$ are standardized such as: ${\phi }^{T}M\phi =\mathit{Id}$ ${\phi }^{T}K\phi =\Lambda$ .

The solutions of the dissipative system are in the form of:

$u={u}_{0}{e}^{\mathit{st}}$ d’où $(M{s}^{2}+Cs+K){u}_{0}=0$ .

${u}_{0}$ is broken down into the ${\varphi}_{v}$ base. ${u}_{0}=\phi q$ is then available, where:

$(I{s}^{2}+\gamma s+\Lambda )q=0$ with $\gamma ={\phi }^{T}C\phi$ (full matrix)

This problem with clean values is solved by a reverse power method by taking as initial estimate ${s}_{v}=j{\omega}_{v}$ .

### 2.2 Baseline

The 8 system-specific damping and frequencies, as well as the 1st and 8th mode (complexes).

### 2.3 Uncertainty about the solution

Semi-analytic solution.
