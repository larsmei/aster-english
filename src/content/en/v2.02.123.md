# v2.02.123 SDLL123 - Frequency of a simplified tree line with gyroscopy

**Summary:**

This test validates the calculation of the rotational modes of a rotating tree system.

In this test, it is a simple rotor model with 1 disc simply supported.

Six modellings are performed:

- Modelling A: POU_D_E
- Modelling B: test case INFORMATIQUE VALIDATION DES SOLVEURS MODAUX SORENSEN AND QZ GENERALISE AND QUADRATIQUE NON SYMETRIQUES
- Modelling C: POU_D_E
- Modelling D: POU_D_EM
- Modelling E: POU_D_TG
- Modelling F: POU_D_TGM

### 2.1 Calculation method used for reference solutions

The reference solution is a solution obtained with python. Indeed, two methods of calculation have been used to determine frequencies. Each method uses the stiffness, mass, gyroscopic and damping matrices calculated by *Code_Aster* . For the search for frequencies of the quadratic modal problem, we use:

- the mathematical bookshop python numpy (search for own values)
- CALC_MODES command

This is therefore not a non-regression, but for validation of the

elements of beam and in the absence of elements comparison, it is non-regression.

### 5.2 Tested quantities and results

- **CALC_MODES**

Validation of GEP and QEP modal solvers by comparison of results
from different numerical formulations, using the command
TEST_RESU.

**Test on eigenfrequencies**

| $N°$ | Test parameter | Result | Criterion |
| --- | --- | --- | --- |
| $1$ | $\mathrm{FREQ}$ | MG_SO / MG_QZ | ABSOLU |
| $2$ | $\mathrm{FREQ}$ | MG_SO / MG_QZ | RELATIF |
| $3$ | $\mathrm{FREQ}$ | MG_SO / MG_QZ | RELATIF |
| $4$ | $\mathrm{FREQ}$ | MG_SO / MG_QZ | RELATIF |

The calculated eigenfrequencies are compared order in order between
the various modal resolutions, with an absolute criterion for the
first mode and a relative criterion for the following modes.

**Test on reduced depreciation**

| $N°$ | Test parameter | Result | Criterion |
| --- | --- | --- | --- |
| $1$ | $\mathrm{AMOR}\text{\_}\mathrm{REDUIT}$ | MQ_SO | RELATIF |
| $2$ | $\mathrm{AMOR}\text{\_}\mathrm{REDUIT}$ | MQ_SO | RELATIF |

Reduced depreciation is verified by relative comparison of values
calculated modals, to validate the numerical coherence of the solvers
in the context of a non-symmetric formulation.

### 5.3 Additional precision

For this numerical validation of GEP and QEP modal solvers, a construction without physical interpretation is used.
non-symmetric matrices from gyroscopy mass matrices, and stiffness.

### 5.4 Differences from Modelization A

Model C differs from Model A by the calculation method and the solvers used.
Modelling A, which uses real symmetrical matrices for GEP, C Modelling focuses on
non-symmetric gyroscopy matrices, which test the robustness of the GEP and QEP modal solvers
The frequency and tolerances are also adjusted, and Modelling C introduces a more complex approach to the
depreciation concepts.
