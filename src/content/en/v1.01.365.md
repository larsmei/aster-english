# v1.01.365 ZZZZ365 - Validation of SIEF_R(3D) to SIEF_R(DKT)

**Summary:**

This test validates the transformation of an SIEF_R field of type ELNO or NOEU calculated on elements density to superfacial elements.

The SIEF_R(3D) is passed to the SIEF_R(DKT) by 2 commands:

- PROJ_CHAMP: SIEF_R(3D) field projection on subpoints of the overfacial elements, without changing the reference point of the input field.
- MODI_REPERE with GLOBAL_UTIL option: change of reference from the input field. The field moves from the global reference to the local reference point linked to the superfacial elements. The orientation of the superfacial elements is given by AFFE_CARA_ELEM with ORIENTATION option.

## 1 Test principle

Validation shall consist of:

- define a field of SIEF_R using linear formulae depending on space.
- affect the SIEF_R field on a mesh d的elements density.
- Use PROJ_CHAMP to project the SIEF_R(3D) field to obtain a global SIEF_R(DKT_) field on the subpoints of the superfacial elements. Be careful that this field is in the same reference as the initial field (so the global reference), so it does not correspond to a superfacial SIEF_Rd-element field that must be expressed in the local reference.
- compare the SIEF_R(DKT_ global) field to a field calculated at subpoints using the formulae previously defined, these 2 fields are expressed in the same reference.
- use MODI_REPERE to change the reference to the SIEF_R(DKT_) field, by placing it in the local elements superfacial marker and getting a real SIEF_R(DKT).
- compare the SIEF_R(DKT) field to a field calculated at subpoints using formulae previously defined but expressed in the local elements surfacic benchmark.

## 2 Modelling A

The results are analytical. Tests are performed on all components of the SIEF_R fields, on the greater absolute value of the differences between the solution calculated by *Code_Aster* and the one calculated in the command file. In theory the difference must be zero, in practice the default value is retained.
