# u4.54.04 Command CALC_THER_MULT

## 1 Purpose

The role of the command is to compute the thermal responses of various load cases and to
store them in one and the same result data structure. These loadings may be any
thermal loadings (defined with the commands AFFE_CHAR_THER and
AFFE_CHAR_THER_F) or unit shocks for which an automatic setup is
used.

The thermal boundary conditions and the material characteristics are invariant for the whole
set of load cases called.

The data structure produced is of type evol_ther_dict.

## 3 Operands

### 3.1 Operands MODELE / CHAM_MATER / CARA_ELEM

MODELE is the name of the model whose elements are the subject of the thermal analysis.

CHAM_MATER is the name of the material field assigned to the model given in MODELE.

CARA_ELEM contains additional characteristics for the elements. This keyword is optional.

### 3.2 Operand CHAR_THER_GLOBAL

Concept of type charge produced by the commands [AFFE_CHAR_THER and AFFE_CHAR_F(u4.44.02)](doc:u4.44.02).
This keyword makes it possible to define the thermal loadings which are common to all the load cases (CAS_CHARGE)
defined by the user.

### 3.3 Operand PARM_THETA

The keyword PARM_THETA has the same meaning as in the documentation of [THER_NON_LINE](doc:u4.54.02) and applies to all the computed load cases.

In the absence of the keyword, the value used is 1 (fully implicit method)

### 3.4 Operand CAS_CHARGE

This factor keyword makes it possible to define the various load cases by choosing between the application of
thermal loadings defined beforehand, or else by automatically generating a loading
of unit thermal-shock type.

**Note:**

When the analysis of a load case of "unit shock" type is performed and other
load cases of this type are also defined within the same command CALC_THER_MULT,
exchange conditions with a temperature of 0°C are also applied on the mesh-cell groups
given in the other occurrences of this type of load case.

*Function describing a shock of DUREE_CHOC $d$*

#### 3.4.1 Keyword NOM_CAS

Character string used as the access variable to the result data structure.

#### 3.4.2 Keyword EXCIT

Keyword defining the thermal loading to be applied for the load case under consideration. It may be
defined by the commands [AFFE_CHAR_THER and AFFE_CHAR_THER_F](doc:u4.44.02).

This factor keyword makes it possible to apply exchange conditions on a mesh-cell group with an
external temperature whose value varies linearly from 0 to 1 over a time given by
the user, as described in the u4.54.04-fig-choc . The applied loading uses the keyword ECHANGE defined in the documentation
[AFFE_CHAR_THER](doc:u4.44.02).

#### 3.4.3 Keyword COEF_H

Defines the exchange coefficient.

#### 3.4.4 Keyword GROUP_MA

List of the mesh cells defining the exchange surface subjected to the shock, for the assignment of the thermal
loading.

#### 3.4.5 Keyword DUREE_CHOC

Value defining the duration of the applied unit shock, that is the time for the external
temperature to vary linearly from 0 to 1. The value taken by default is $1\mathrm{e}{-6}$.

#### 3.4.6 Keyword LIST_INST

List of time instants used for the analysis of the load case under consideration.

Note: Within one and the same `CAS_CHARGE`, there cannot be both the keyword `COEF_H` and `EXCIT`.
Moreover, the joint presence of the keywords `COEF_H`, `GROUP_MA` and `DUREE_CHOC` is mandatory if the keyword `EXCIT` is not present.

### 3.5 Operands SOLVEUR, CONVERGENCE and NEWTON

These operands are the analysis options [SOLVEUR](doc:u4.50.01), CONVERGENCE and NEWTON used in [THER_NON_LINE](doc:u4.54.02).
