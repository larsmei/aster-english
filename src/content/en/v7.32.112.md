# v7.32.112 WTNP112 - Resaturation of a column

**Summary:**

The test presented here allows to verify the correct functioning of the operators used for solving the equations of an unsaturated flow. This test corresponds to test 3.1 of the qualification plan of the ALLLIANCES [bib1] project. It represents the resaturation of a column.

## 5 Modelling C

### 5.1 Modelling characteristics C

## 6 Modelling D

### 6.1 Modelling characteristics D

HMD Modelling in flat deformations. 80 elements Q8. This is exactly the same as Modelling B but with the specific LIQU_GAZ_ATM coupling law for Richards Modelling (equivalent to unsaturated Modelling with imposed gas pressure). We are blocked in mechanics.

### 6.2 Results

The results are obviously the same as for Modelling B.
