# v2.02.003 SDLL03- slender beam clamped - clamped with different inertia

**Summary:**

The linear elasticity dynamic test is used to validate straight beam elements POU_D_T.

This test case concerns an slender beam clamped - clamped with different inertias.

The frequencies and displacements are tested by comparing simulation results with reference solution AFNOR (ref. [1]). The calculation in aster code using DYNA_VIBRA on the modal basis.
