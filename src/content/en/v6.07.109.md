# v6.07.109 COMP009 – Thermomechanical validation of BARRE Modelling

**Summary**

This test validates the temperature variation in the constitutive laws available with BARRE Modelling. These tests allow you to check the following points:

- Thermal expansion is well calculated (with consideration of the variation of thermal expansion with temperature)
- The variation of material coefficients with temperature is correct, especially in incremental behavior resolution,

The validated laws of behaviour are as follows:

- $A$ Modelling: this Modelling allows to validate the ELAS model,
- $B$ Modelling: this Modelling allows to validate the VMIS_ISOT_LINE model,
- $C$ Modelling: this Modelling allows to validate the VMIS_ISOT_TRAC model,
- $D$ Modelling: this Modelling allows to validate the VMIS_CINE_LINE model,

## 1 Methodology

The mesh used is composed of a single mesh cell SEG2, on which BARRE Modelling is assigned. The ends of the bar are clamped, no axial deformation is possible.

![Figure](/figures/v6.07.109/Shape1.gif)

nodes N3 et N7 : $\mathrm{DX}=\mathrm{DY}=\mathrm{DZ}=0.$

Section : $A=1.$

It is a double simulation, the first in thermomechanical, the second in pure mechanics. The first will be validated in comparison with the second, assuming of course that the behaviour tested provides a correct solution in pure mechanics.

The first simulation (solution that is being validated) is to apply a temperature variation to the element BARRE, for example by blocking movements along the local $x$ axis: ${\varepsilon}_{xx}=0$ . The temperature imposed is increasing linearly with time.

The second simulation (which must be equivalent to the first) consists of applying to the element a deformation imposed in the direction $x$: ${\varepsilon}_{xx}=-{\varepsilon}^{\mathrm{th}}=-\alpha (T)(T-{T}_{\mathrm{ref}})$ , pure mechanics. Indeed, for any behavior (assuming the additive decomposition of the deformations) one has:

${\sigma}_{xx}=E(T)({\varepsilon}_{xx}-{\varepsilon}^{\mathrm{th}}-{\varepsilon}_{xx}^{p})$ with normal $N=A{\sigma}_{xx}$ effort

in the first case, ${\sigma}_{xx}=E(T)(0-{\varepsilon}^{\mathrm{th}}-{\varepsilon}_{xx}^{p})$ , and in the second: ${\sigma}_{xx}=E(T)({\varepsilon}_{xx}-{\varepsilon}_{xx}^{p})$ .

Therefore, at every moment, you can apply ${\varepsilon}_{xx}=-{\varepsilon}^{\mathrm{th}}=-\alpha (T)(T-{T}_{\mathrm{ref}})$ for mechanical calculation.

In addition, to obtain the same results in both cases, it is necessary, at each time step of the second simulation, to perform the pure mechanical calculation with coefficients whose values are interpolated according to the temperature at the current moment. This interpolation is performed in the command file of the test, in a loop in outside time at STAT_NON_LINE.

## 2 Interpretation of results

The purpose is to verify with TEST_TABLE that the result obtained at each moment of the thermomechanical transient of the first simulation is identical to the result obtained with the second simulation.

## 3 Modelling A

### 3.1 Modelling characteristics

#### 3.1.1 Simulation 1

This is a thermomechanical test with zero deformation imposed on the local $x$ axis. The test is performed on a element BARRE with the STAT_NON_LINE command. The temperature varies from ${T}_{0}=20$ to ${T}_{\max}=500°C$. The transient consists of NCAL not.

The reference temperature is ${T}_{\mathrm{ref}}=20°C$ .

#### 3.1.2 Simulation 2

The purpose is to perform a loop on NCAL mechanical calculations. Each $i$ calculation, the load imposed is made up of the thermal deformation ${\varepsilon}_{xx}=-{\varepsilon}_{\mathrm{th}}=-\alpha (T)({T}_{i}-{T}_{\mathrm{Ref}})$. The initial load consists of the deformations, stresses (normal stress) and internal variables of the previous mechanical calculation.

### 3.2 Material properties

The constitutive law tested is 'ELAS'. This law is elastic.

The elastic parameters are as follows:

$E(T)$ , $\nu (T)$ et $\alpha (T)$

Values of parameters used:

| Parameters | $T=20°C$ | $T=500°C$ |
| --- | --- | --- |
| $E(T)$ | $200000.$ MPa | $100000.$ MPa |
| $\nu (T)$ | $0.$ | $0.$ |
| $\alpha (T)$ | $1.E-5$ ${K}^{-1}$ | $2.E-5$ ${K}^{-1}$ |

### 3.3 Tested quantities and results

Validation is done by comparing the fields calculated at each step of the transition on the one hand and the result of a mechanical calculation on the other.

The command used is TEST_TABLE which tests the reference value against the calculated value.

The reference value being the component of the field extracted at a given moment $i$ from the first mechanical thermo simulation performed on NCAL moments. The calculated value is that obtained at the end of the mechanical calculation $i+1$ of the loop on the NCAL.

| Result at $i$ serial number | Name of parameter tested | Reference type | Reference value | Tolerance |
| --- | --- | --- | --- | --- |
| RESU_ i | NOM_PARA |  | VALE_REF | TOLE |
| RESU_4 | N | NON_REGRESSION | -960. | 0.1% |

## 7 Summary of the results

For each of the constitutive laws studied, the results of the thermomechanical transient of the first simulation are compared with those obtained with the second simulation in pure mechanics. The results are consistent, showing the correct consideration of thermal expansion by these constitutive laws, as well as the good dependence of material parameters on temperature.
