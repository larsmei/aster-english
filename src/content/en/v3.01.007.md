# v3.01.007 SSLL0 7 - clamped thin arc in off-plane bending

**Summary:**

The linear elasticity static test is used to validate straight beam elements POU_D_T.

This test case concerns a clamped thin arc in off-plane bending.

The movements and moments are tested by comparing simulation results with reference solution AFNOR (ref. [1]) and those obtained with Pipestress software.
