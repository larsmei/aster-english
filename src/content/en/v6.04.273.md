# v6.04.273 SSNV273 - Uniform and confined traction test, with viscosity

**Summary:**

This test modeled a narrow tensile test for ENDO_LOCA_TC (3D) law with viscosity corresponding to the modellings A. It validates the ENDO_LOCA_TC law described in [R7.01.47](doc:r7.01.47) or in more precisely, the internal viscosity of the law to cross the use of TAU_REGU_VISC in DEFI_MATERIAU.

Validation is analytical

## 1 Reference problem

### 1.1 Geometry

It is a hardware point, processed by SIMU_POINT_MAT in 3D.

### 1.2 Material properties

The material obeys the constitutive law fragile elastic ENDO_LOCA_TC. The macroscopic data correspond to:

The internal parameters of the model are calculated by DEFI_MATER_GC macro-command.

### 1.3 Boundary conditions and loads

It is a stress in a material point (SIMU_POINT_MAT). All deformation components are imposed. All of them are zero except EPXX which is kept constant over time and positive to reflect a tensile relaxation test. In the absence of viscosity, this maintenance would result in a constant stress. Here, the stress decreases over time following the progressive evolution of traction damage, delayed by viscosity.

The test case includes a re-cutting of the calculation step if there is no convergence to activate the internal viscosity of the ENDO_LOCA_TC law.

## 2 reference solution

### 2.1 Input data and material parameters

| Name | Symbol | Value | Unit |
| --- | --- | --- | --- |
| Poisson's ratio | $\nu$ | 0.2 |  |
| Tensile nutting coefficient | p | 1.5 | -- |
| Compression resistance | $f_{c}$ | 40 | MPa |
| Inter-crack distance | $L_{F}$ | 200 | mm |

Internal parameter values are calculated using the fib Model Code (fib-2010) using v6.04.273-tab-data-input. The equations are extracted from [R7.01.47](doc:r7.01.47).

$$
E = 21500\,\left(\frac{f_{c}}{10}\right)^\left(1/3\right) \quad ; \quad  \nu = 0.2 \quad ; \quad  G_{F}=73\,f_{c}^{0.18} \quad ; \quad  f_{t}=0.3\,\left(f_{c}-8\right)^\left(2/3\right)
$$

These equations allow the Young, $f_{t}$ and $G_{F}$ module values to be retrieved. The $\sigma^{0}$ threshold is set to $f_c/3$ (see v6.04.273-tab-para).

DEFI_MATER_GC evaluates the last internal parameter of the law from the previous values, namely the standard energy consumed $\bar{\omega}$ defined by:

$$
\bar{\omega}=\frac{2E_{C}\,G_{F}}{L_{F}\,f_{t}^2}
$$

With the Young's modulus in contained traction defined by:

$$
E_{c}=\lambda+2\mu=\frac{\left(1-\nu\right)\,E}{\left(1-2\nu\right)\left(1+\nu\right)}
$$

### 2.2 Calculation method used for reference solution

The objective is to estimate the time required to achieve $a_{cible}=0.1$ damage. The following function is introduced, which establishes the link between damage and tensile deformation contained:

$$
e\left(a\right) = 1-a+\frac{\bar{\omega}}{2}\left[m_{0}a+\left(D_{1}-m_{0}\right)a^r\right]
$$

The $e(a_{max})$ is applied to the $a_{max}=0.2$ (the deformation would instantly lead to 0.2 damage in the absence of viscosity) and the $a_{cible}$ is achieved twice as much damage at the end of a finite time. To find the value, the following integral is evaluated:

$$
t_{cible} =\tau\int_{0}^{a_{cible}=0.1}\frac{e\left(a_{max}\right)^{2}}{e\left(a_{max}\right)^{2}-e\left(a\right)^{2}}\,da
$$

The nully integration method corresponding to the trapeze method is used in the code_aster file to calculate this value.
