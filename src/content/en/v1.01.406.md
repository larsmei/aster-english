# v1.01.406 ZZZZ406 - Validation of the Merge of Loads in Operator CALC_G

**Summary**

This test has no physical meaning, it is a computer test. It aims to cover a part of the code that performs the merge of loads in the CALC_G operator. This test reproduces with some modifications the test forma05.

It is also used to check the correct operation of the CALC_CHAMP command for the calculation of the FORC_NODA field without re-entry (i.e. without the keyword weer).

This documentation is deliberately succinct.
