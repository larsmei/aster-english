# v1.01.123 ZZZZ123 - Material properties verification of BETON_GLRC/CODIFICATION=

**Summary:**

The purpose of this test case is to check the Material properties generated by the DEFI_MATER_GC operator with the BETON_GLRC/CODIFICATION=的EC2. For the different concrete classes of the Eurocode 2, the elastic material properties and those of BETON_GLRC are compared with the Eurocode 2.

In reality, this comparison was performed manually for the first time and now we are ensuring that the non-regression is in relation to this reference situation.

## 1 Test principle

DEFI_MATER_GC allows generating reinforced concrete-type materials from engineering data. In particular, it allows with the options BETON_GLRC/CODIFICATION=的EC2 to create a material with the following properties calculated according to the concrete class and Eurocode 2:

| **Elastic property** |  |
| --- | --- |
| Young's modulus | $E$ |
|  |  |
| **Non-linear properties** |  |
| Average strength in 28-day concrete compression | ${f}_{\mathit{cm}}$ |
| Tensile strength | ${f}_{\mathit{cm}}$ |
| Climbing peak deformation | ${{\varepsilon}}_{c1}$ |

The objective of the test case is to check the values of the Material properties created by comparing them with the Eurocode 2 for the different classes of the Eurocode 2.

In reality, this comparison was performed manually for the first time and now we are ensuring that the non-regression is in relation to this reference situation.

In addition, the comparison is more precisely about the sum of the elastic properties on the one hand, and the sum of the BETON_GLRC properties on the other.
