# v6.07.104 COMP004 - constitutive law VISC_ISOT_PLAS applied to a hardware point

**Summary:**

The objective of this test is to validate the constitutive law elasto-viscoplastic isotropic mechanical VISC_ISOT_PLAS described in [R5.03.38](doc:r5.03.38). The problem is implemented at the point material scale ([SIMU_POINT_MAT](doc:u4.51.12)) by imposing the (total) deformation over time. The numerically obtained solution is compared to a reference analytical solution as well as to non-regression values.

## 1 Reference problem

### 1.1 Geometry

The problem is handled at the point hardware scale using [SIMU_POINT_MAT](doc:u4.51.12) macro-command.

### 1.2 Material properties

The material is governed by the constitutive law VISC_ISOT_PLAS which is explicitly temperature dependent. The model parameters include the elastic mechanical characteristics and the microstructure of the material. The Material properties used for this test are:

| $T$ | $-20.0 \text{ °C}$ | Constant temperature expressed in degrees Celsius |
| --- | --- | --- |
| $E$ | $\left( 2.6\text{e}6 \text{ Pa} \right) \left( 78821.0 - 23.721 \frac{T}{1.0 \text{ °C}} \right)$ | Young's modulus explicitly dependent on the $T$ temperature defined above and expressed in Pascal |
| $\nu$ | $0.3$ | Poisson's ratio (no unit) |
| TAILLE_GRAIN | $5.0\text{e}6 \text{ m}$ | Grain size for non-irradiated state expressed in metres |
| D_DISLOC | $1.4\text{e}14 \text{ m}^{-2}$ | Initial dislocation density expressed in reverse of square meter |
| C_AMAS | $1.6\text{e}23 \text{ m}^{-3}$ | Concentration of solute clusters expressed in reverse from meter to cubic |
| TAILLE_AMAS | $3.0\text{e-}9 \text{ m}$ | Size of solute clusters expressed in metres |

### 1.3 Boundary conditions and loads

Total deformation is imposed over the moments by taking the one obtained for the reference solution analytical of this test. This is a growing function of time, linear as long as the constitutive law remains in the elastic domain.

### 1.4 Initial conditions

The initial conditions correspond to those taken naturally: internal variables zero and zero deformations.

## 2 reference solution

### 2.1 Method of calculation

A number of quantities described in the VISC_ISOT_PLAS [R5.03.38](doc:r5.03.38) model are first explicitly calculated:

$$
\begin{array}{l}
\mu := \dfrac{E}{ 2 \left( 1 + \nu \right) } \\
\\
\sigma_{HP} := \mu \sqrt{ \dfrac{ 3.3090\text{e-}11 }{ \text{TAILLE_GRAIN} } } \\
\\
\sigma_{VD} := 2.5\text{e}7 \, \text{min} \left[ \text{max} \left( 0, 0.01 \, T - 2 \right), 1 \right] \\
\\
\sigma_{VS0} := 8\text{e}7 - 2\text{e}5 \left( 150 + T \right) \\
L := \dfrac{1}{ 2.222222222\text{e-}4 + 6.7925\text{e-}6 \, \sqrt{ 1\text{e-}22 \, \text{C_AMAS} } } \\
\\
f := \text{min} \left( 1.178 + 0.019 \, T, 6.8 \right) \\
\\
H := \dfrac{ \mu^{2} }{ 4 \, L \, f } \\
\\
H_{0} := \mu^{2} \, 1.5376\text{e-}20 \, \text{D_DISLOC} \\
\\
\sigma_{I} := \sqrt{ \mu^{2} \, 3.35\text{e-}8 \, \left( 1\text{e}9 \, \text{TAILLE_AMAS} \right)^{2.3} \, \left( 1\text{e-}22 \, \text{C_AMAS} \right)^{1.142857} } \\
\\
\sigma_{C0} := \sigma_{HP} + \sigma_{VD} + \sigma_{VS0} + \sqrt{\left( \sigma_{I} \right)^{2} + 4 \, H_{0} } \\
\\
\sigma_{E} := 900\text{e}6 \, \left[ 1 - \left( T + 273.15 \right) \dfrac{19.3289}{9744} \right]^{2} \\
\\
\sigma_{D} := 5\text{e}6 \, \left(  1 \text{e}6 \right)^{0.1} \\
\end{array}
$$

Then, a list of $1001$ moments (noted $t$) describing the $\left[ 0; 1 \right]$ interval with a constant discretization step (equal to $0.001$). It is recalled that when simulating an constitutive law on a material point, the $\varepsilon^{tot}$ total deformation tensor can be assimilated to a scalar and the same for the $\sigma$ stress tensor.

The total required $\varepsilon^{tot}_{ref}$ reference deformation is then initially assimilated to this list of moments while the reference stress is initialized as if the behavior were elastic *i.e.* as if $\varepsilon^{elas}_{ref} = \varepsilon^{tot}_{ref}$. In other words, $\sigma_{ref}(t) := E t$ and $\varepsilon^{tot}_{ref}(t) = t$ are installed.

Then, we look at the moment from which the (visco-)plastic regime begins, i.e. from when $\sigma$ exceeds the $\sigma_{C0}$ threshold already calculated: this is when $\varepsilon^{tot}_{ref} > \frac{\sigma_{C0}}{E}$. We then follow the evolution of the cumulative plastic deformation, noted here $p$ and equal to the (visco-)plastic deformation $\varepsilon^{vp}_{ref}$ in the case of a material point. In other words, when $t > \frac{\sigma_{C0}}{E}$ is imposed $p(t):= t - \frac{\sigma_{C0}}{E}$. This results in a number of evaluations that allow new reference values for $\sigma_{ref}$ and $\varepsilon^{tot}_{ref}$ at these $t$ moments of the (visco-)plastic regime:

$$
\begin{array}{l}
\sigma_{VS} : = \sigma_{VS0} \text{exp} \left( -200 p \right) \\
\\
\sigma_{auto} := \sqrt{ H_{0} \text{exp} \left( -3 f p \right) + H \left[ 4 - \text{exp} \left( - 3 f p \right) - 3 \text{exp} \left( -p \right) \right]  } \\
\\
\sigma_{LT} : = \text{max} \left[ 0, \sqrt{ 3 \left(\sigma_{auto} \right)^{2} } - \sigma_{E} \right] \\
\\
\sigma_{ref} :=  \sigma_{D} + \sigma_{E} + \sigma_{HP} + \sigma_{VD} + \sigma_{VS} + \sqrt{\left( \sigma_{I} \right)^{2} + \left( \sigma_{auto} \right)^2 + \left(\sigma_{LT} \right)^{2} } \\
\\
\varepsilon^{tot}_{ref} := p +  \dfrac{\sigma_{ref}}{E} \\
\\
\end{array}
$$

### 2.2 Quantities and reference results

This resulted in $\varepsilon_{ref}^{tot}$ reference values for total deformation that will be imposed at the test input in the [SIMU_POINT_MAT](doc:u4.51.12) macro-command via EPXX operand of factor keyword EPSI_IMPOSE.

A second identical test is also performed by changing the length and stress units via UNITE_LONGUEUR = 'MM' and UNITE_CONTRAINTE = 'MPa' of keyword VISC_ISOT_PLAS_FO in [DEFI_MATERIAU](doc:u4.43.01) macro-command. This test is also used to verify that the VISC_ISOT_PLAS behavioral relationship works in the non-scalar case by defining the material parameters with [DEFI_CONSTANTE](doc:u4.31.01) macro-command and adapting the values to the new units (millimeter and MegaPascal).

For both tests, the $1001$ reference values obtained for total stress and deformation (as 'SIXX' and 'EPXX' in the table returned by [SIMU_POINT_MAT](doc:u4.51.12) respectively) will be compared with those previously calculated ($\sigma_{ref}$ and $\varepsilon_{ref}^{tot}$), as well as with non-regression values explicitly stored in a python list of the *comp004.comm* file associated with the test.

### 2.3 Uncertainties about the solution

The reference results are obtained very precisely and the time step is chosen very fine.

Both total deformation and stress are tolerated by $10^{-10}$ on relative the difference between the non-regression values and those calculated by the test.

For total deformation, $10^{-10}$ is also tolerated between the reference and test values.

As for stress, $10^{-7}$ is tolerated between the reference and test values except for a few moments when the criterion is somewhat released and corresponds to the transition between elastic and (visco-)plastic regime:
