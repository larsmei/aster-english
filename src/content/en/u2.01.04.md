# u2.01.04 Documentation of the quantities of Code_Aster

> **Summary.**

Description of the quantities associated with the fields which can be created by the commands of *Code_Aster*.

The following table has three columns. The name of the quantities appears in the left-hand column (sorted in alphabetical order).

Each quantity is separated from the next by a blank line.

On the first line of a quantity, one finds the type of that quantity (real: R, complex: C, ...).

The names of the components of that quantity are then listed (column 2), and a short comment is made on each of them.
