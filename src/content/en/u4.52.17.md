# u4.52.17 Macro-command POST_MODE

**Summary:**

The effective masses and inertias are parameters computed for each mode by the operator CALC_MODES.
They can serve as criteria for selecting the modes of greatest interest. In that case, these parameters
are computed by taking the whole model into account. It is however sometimes useful to be able to have these
parameters on only part of the model.

This macro-command makes it possible to compute the so-called local effective masses and inertias for each mode
of a data structure of type mode_meca, that is to say by taking into account only a chosen part of the model.

POST_MODE produces a table with the following parameters:

NUME_ORDRE, NUME_MODE, FREQ, MASS_EFFE_DX, MASS_EFFE_DY, MASS_EFFE_DZ, INER_EFFE_DX,
INER_EFFE_DY, INER_EFFE_DZ, MASS_EFFE_UN_DX, MASS_EFFE_UN_DY, MASS_EFFE_UN_DZ, INER_EFFE_UN_DX, INER_EFFE_UN_DY, INER_EFFE_UN_DZ

## 1 Purpose

Compute the so-called local effective masses and inertias for each mode
of a data structure of type mode_meca, that is to say by taking into account only a chosen part of the model.

POST_MODE produces a table with the following parameters:

NUME_ORDRE, NUME_MODE, FREQ, MASS_EFFE_DX, MASS_EFFE_DY, MASS_EFFE_DZ, INER_EFFE_DX,
INER_EFFE_DY, INER_EFFE_DZ, MASS_EFFE_UN_DX, MASS_EFFE_UN_DY, MASS_EFFE_UN_DZ, INER_EFFE_UN_DX, INER_EFFE_UN_DY, INER_EFFE_UN_DZ

## 2 Syntax

```text
table = POST_MODE(
    ◆ MODE = mode_meca,
    ◆ GROUP_MA = list[grma],
    ◇ CARA_ELEM = cara_elem,
    ◆ MATR_MASS = matr_asse_depl_r,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Principle

The computation of these local effective masses and inertias is performed in an approximate manner.
Indeed, in order to compute these quantities exactly, one would have to rebuild the mass matrix
completely so as to take into account only the contributions of the selected mesh cells.
POST_MODE does not compute the true “local” mass matrix. It transforms
the global mass matrix (supplied to the operator CALC_MODES) by setting to zero the rows
and columns corresponding to degrees of freedom that do not belong to the
mesh-cell selection defined. By proceeding in this way, one retains, on the degrees of freedom
of the nodes on the boundary of the selected domain and connected to other mesh cells of the model,
contributions coming from mesh cells that were not selected.

This approximation is accepted. With this tool one is not seeking perfect
accuracy, but values that are accurate enough to provide good criteria for
selecting the modes.

The formulae for these various local criteria are the same as the formulae
for these same global criteria (presented in [R5.01.03](doc:r5.01.03))

## 4 Operands

### 4.1 Operand MODE

```text
◆ MODE = mode
```

Name of the mode_meca data structure for which one wishes to compute local criteria.

### 4.2 Operand GROUP_MA

```text
◆ GROUP_MA = list[grma]
```

List of the mesh-cell groups defining the sub-domain.

### 4.3 Operand CARA_ELEM

```text
◇ CARA_ELEM = cara_elem
```

Name of the characteristics of the beam, shell, etc. elements.

### 4.4 Operand MATR_MASS

```text
◆ MATR_MASS = matr_mass
```

Assembled mass matrix that was used for the computation of the mode_meca **mode**.

## 5 Example of use

One computes the effective-mass and effective-inertia criteria, unit and non-unit, on the desired part of the model:

```text
table_crit = POST_MODE( MODE=modes,
                        GROUP_MA=("BATIMENT2",),
                        CARA_ELEM=caraelem,
                        MATR_MASS=masse,
)
```

One modifies the table created by filtering on the chosen criterion, here local unit effective masses along X greater than 5%:

```text
table_crit = CALC_TABLE(reuse=table_crit,
                        TABLE=table_crit,
                        ACTION=_F(OPERATION="FILTRE",
                                  NOM_PARA="MASS_EFFE_UN_DX", CRIT_COMP="GT", VALE=0.05),
)
```

One then recovers the list of the selected modes

```text
liste_modes = table_crit.EXTR_TABLE().values()["NUME_MODE"]
```

and one builds a **mode_meca** object containing only these modes.

```text
EXTR = EXTR_MODE(FILTRE_MODE=_F(MODE=modes, NUME_MODE=liste_modes))
```
