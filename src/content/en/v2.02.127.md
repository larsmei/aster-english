# v2.02.127 SDLL127 - Shaft line with variable circular section rotor

**Summary:**

This test validates the calculation of the rotational modes of a shaft system at rest or rotating with a rotor with variable cross-section.

In this test, a variable circular cross section rotor model is based on two disc bearings whose stiffness and damping matrices are symmetrical. This example is taken from the CADYRO 2.0 validation folder, a finished elements software designed to predict dynamic rotor behaviour.

## 1 Reference problem

### 1.1 Geometry

The structure consists of a rotor of variable circular cross-section $L$ length with two infinitely rigid bearings at the support level. The rotor cross-section diameters vary linearly with length.

### 1.2 Material properties

### 1.3 boundary conditions

The rotor is pressed on two rigid bearings at both ends.

## 2 reference solution

### 2.1 Method of calculation

The reference is given by the CADYRO bib1 code for variable-section beam elements.

Furthermore, the values derived from modelling using elements variable section beam (Modulation A) are framed by those obtained from:

- Model B, approaching the exact solution at lower values. This amounts to assigning to each element the **constant circular section** of diameter equal to the diameter of the rotor studied **to the right of the node initial** of the element.
- Modelling C, approaching the exact solution by higher values. This involves assigning to each element the **constant circular section** of diameter equal to the diameter of the rotor studied **at the right of the node final** of the element.

Modellings B and C are then equivalent (in the bound direction) to model A when the number of elements used by them tends towards infinity. In this case, 2000 elements of beam with constant circular cross-section are used.

## 6 Summary of the results

This test case allows numerical validation of the consideration of variable circular cross-section tree lines. The results obtained are in good agreement with the reference values, from CADYRO and two very fine modellings approaching the exact solution at lower and higher values.

The calculation of the mass of elements whose cross section varies homothetically is checked at less than ${10}^{-2}\text{\%}$.
