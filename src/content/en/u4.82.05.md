# u4.82.05 Operator POST_K1_K2_K3

## 1 Purpose

Compute the stress intensity factors in 2D and in 3D.

This operator makes it possible to compute $\mathit{K1}$, $\mathit{K2}$ in 2D (modellings 'D_PLAN', 'C_PLAN' and 'AXIS') and $\mathit{K3}$ in 3D (modelling '3D') by extrapolation of the displacement jumps on the lips of the crack, cf. [R7.02.08](doc:r7.02.08). This method is applicable only for homogeneous and isotropic materials.

This operator can be used for a meshed crack as well as for an unmeshed crack (X-FEM method). In the case of a meshed crack, the latter must necessarily be plane.

The method used is theoretically less accurate and more sensitive to the mesh than the computation from the bilinear form of the energy release rate and from the singular displacements, which can be used in 2D and in 3D with the option CALC_K_G of the operator CALC_G [U4.82.03](doc:u4.82.03). It does, however, make it possible to obtain easily a good estimate of the stress intensity factors.

Produces a concept of type table.

## 3 Operands

### 3.1 Case in which the operand FOND_FISS is supplied

This case corresponds to an analysis on a meshed crack, defined for the post-processing with the operator DEFI_FOND_FISS. By default, the analysis is carried out automatically for all the nodes of the crack front.

#### 3.1.1 Operands FOND_FISS / PREC_VIS_A_VIS / GROUP_NO / SANS_GROUP_NO

```text
◊    FOND_FISS                    =    fond,            [fond_fiss]

◊    PREC_VIS_A_VIS            =    /    1.D-1,        [DEFAUT]
/    epsi,        [R]

◊    /    TOUT                    =    ‘OUI’,
/    GROUP_NO            =    gr_noeu,        [l_gr_noeud]
/    SANS_GROUP_NO        =    gr_noeu,        [l_gr_noeud]
```

The operand FOND_FISS makes it possible to supply the concept fond_fiss (created by the command DEFI_FOND_FISS) in which the information required for the automatic search for the nodes of the two lips lying on segments normal to the crack front is stored. Caution: the concept fond_fiss must necessarily be defined such that the lips of the crack are initially stuck together (CONFIG_INIT='COLLEE' in DEFI_FOND_FISS [U4.82.01](doc:u4.82.01)).

In 3D, by default, the computation of the stress intensity factors is carried out only on the vertex nodes of the mesh cells making up the crack front (hence all the nodes for the linear elements, and one node out of two for the quadratic elements). The user has the possibility of:

- selecting certain vertex nodes of the crack front (keyword GROUP_NO);
- excluding nodes of the crack front (keyword SANS_GROUP_NO);
- carrying out the analysis on all the mid-side nodes and vertex nodes of the crack front (keyword TOUT).

```text
◊    ABSC_CURV_MAXI    =    dmax                    [R]
```

Maximum distance for the computation of the stress intensity factors from the crack front. In practice, the accuracy of the results is poorer if one is situated very far from the crack front [R7.02.08](doc:r7.02.08). It is therefore advisable to choose $\mathit{dmax}$ as small as possible (of the order of 3 to 4 elements, or else of the order of the radius of the radiating mesh, where applicable). In the case where, at a point $N$ of the crack front, this distance is greater than the distance from the crack front at this point to the edge of the lips, the values of the stress intensity factors at the point $N$ are obtained by constant extension. The value retained is that of the point of the crack front that is closest and for which the analysis could be carried out.

The operand ABSC_CURV_MAXI is optional. When this operand is not indicated, the value of ABSC_CURV_MAXI is computed automatically from the maximum $h$ of the sizes of the mesh cells connected to the nodes of the crack front. These mesh-cell sizes at each node of the front are computed in the command DEFI_FOND_FISS and are present in the concept fond_fiss [D4.10.01](doc:d4.10.01). It has been chosen to take ABSC_CURV_MAXI equal to $4h$.

If the automatically computed value is chosen for ABSC_CURV_MAXI, one should nevertheless make sure that its value (displayed in the .mess file) is consistent with the dimensions of the structure.

During the automatic search for each node of the crack front, the operator selects the nodes satisfying the following conditions:

- distance $R$ from the crack front: $R$ < ABSC_CURV_MAXI,
- distance $L$ from its counterpart on the other lip:

$L$ < epsi.ABSC_CURV_MAXI,

- and in 3D the distance $D$ from a node of the lips to the straight line perpendicular to the crack front: $D$ < epsi_fond . $d$, where $d$ is the minimum distance between two successive nodes of the crack front,

where epsi is the value of the accuracy supplied (keyword PREC_VIS_A_VIS) and epsi_fond the value of the accuracy supplied in the keyword PREC_NORM of DEFI_FOND_FISS.

By default epsi is equal to $0,1$. Increasing the value of PREC_VIS_A_VIS (and/or of PREC_NORM in DEFI_FOND_FISS) amounts to increasing the number of nodes potentially retained for the analysis.

**Note**:

*If* TYPE_MAILLAGE=‘REGLE’, *this accuracy comes into play in the phase of projection of the result onto the cutting line: a point is considered to be outside the material if its distance to the structure is greater than* epsi.ABSC_CURV_MAXI *. It may be necessary to modify the default value of this parameter if the crack is represented by a notch.*

#### 3.1.2 Operands RESULTAT

```text
♦    RESULTAT = resu,
```

resu is a concept of type evol_elas, evol_noli or mode_meca containing the displacement field over the whole model.

**Note**:

resu *can be a concept of type* mode_meca *only if* TYPE_MAILLAGE=‘REGLE’ *.*

#### 3.1.3 Operand TYPE_MAILLAGE

```text
◊    TYPE_MAILLAGE =    /    'REGLE',                 [défaut]
/    'LIBRE',
```

This keyword has a meaning only in 3D, for meshed cracks defined by FOND_FISS.

If TYPE_MAILLAGE= ‘REGLE’, the option to be used by default, the analysis is carried out assuming that the nodes on the lips of the crack lie on directions normal to the front and exactly opposite one another from one lip to the other. Alarm or error messages are issued if this is not the case.

If the mesh does not fulfil these conditions, the option TYPE_MAILLAGE=’LIBRE’ may be used. The principle of the analysis is then the following:

1. determination of the directions normal to the crack front for each of the nodes of the front,
2. definition, on each of these directions, of NB_NOEUD_COUPE points evenly distributed between the front and the distance ABSC_CURV_MAXI,
3. projection of the displacement of each lip onto these nodes,
4. interpolation of the displacement jump.

The analysis with TYPE_MAILLAGE=’LIBRE’ may be less accurate than the default analysis.

#### 3.1.4 Operand NB_NOEUD_COUPE

```text
◊    NB_NOEUD_COUPE=    /    5,                         [DEFAUT]
/    n,                            [I]
```

This operand comes into play only if TYPE_MAILLAGE=‘LIBRE’ is supplied. It makes it possible to define the number of nodes for projection of the displacement of the lips on each of the normal directions. The projection nodes are evenly distributed between the crack front and the distance ABSC_CURV_MAXI.

**Note**:

*The projection of the displacement of the lips onto the* *NB_NOEUD_COUPE projection points does not correctly take into account the displacement of the quarter-point nodes (Barsoum elements). It is therefore recommended not to use these elements if* TYPE_MAILLAGE=‘LIBRE’.

## 4 Precautions and advice on use

### 4.1 Assumptions relating to the material used for the computation of the displacements

The computation of the stress intensity factors by extrapolation of the displacement jumps assumes that the linear elastic characteristics of the cracked material that was used for the solution of the mechanical problem (computation of the displacement field) are known. In practice, the command POST_K1_K2_K3 automatically recovers the material concept assigned to a set of mesh cells neighbouring the crack front (for a meshed crack or for X-FEM). The material must be homogeneous, isotropic and linear elastic.

This material may be **constant** (use of DEFI_MATERIAU/ELAS) or a **function** (use of DEFI_MATERIAU/ELAS_FO). The only command variables that may be used for the computation of the stress intensity factors in the case of a function material are **'TEMP'** (temperature) and **'NEUT1'**. Furthermore, these variables must necessarily be assigned (in AFFE_MATERIAU/AFFE_VARC) from nodal fields (cham_no).

In the case of a function material, the elastic parameters are evaluated at the computation points of the crack front:

- for a meshed crack (operand FOND_FISS supplied) these points are the nodes of the crack front;
- for an X-FEM crack (operand FISSURE supplied), these points are either those contained in the object .FONDFISS of the data structure fiss_xfem, or those deduced from it by the use of the keyword NB_POINT_FOND.

### 4.2 Reminder of the various methods used for the extrapolation of the displacement jumps [R7.02.08](doc:r7.02.08)

At each node of the crack front, 3 methods (variants) are used to determine ${K}_{I}$, ${K}_{\mathit{II}}$ (and ${K}_{\mathit{III}}$ in 3D).

- Method 1: for each node of the interpolation segment, the jump of the displacement field squared is computed and divided by $r$. Various values of $\mathrm{K1}$ (resp. $\mathrm{K2}$, $\mathrm{K3}$) are obtained (to within a multiplicative factor) by extrapolation at $r=0$ of the straight-line segments thus obtained.
- Method 2: the jump of the displacement field squared is plotted as a function of $r$. The approximations of $\mathrm{K1}$ are (still to within a multiplicative factor) equal to the slope of the segments connecting the origin to the various points of the curve.
- Method 3: linear regression.

At each node of the crack front, each method supplies a MAX value and a MIN value. At each node of the crack front, there are therefore 6 values for ${K}_{I}$, 6 values for ${K}_{\mathit{II}}$ and 6 values for ${K}_{\mathit{III}}$ (for method 3, the MIN and MAX values coincide). These values are denoted as follows, the exponent $j$ corresponding to the number of the method:

- for ${K}_{I}$ (mode $I$ or opening mode): ${K}_{I}^{j,\mathit{MAX}},{K}_{I}^{j,\mathit{MIN}},j=1,2,3$
- for ${K}_{\mathit{II}}$ (mode $\mathit{II}$ or in-plane shear): ${K}_{\mathit{II}}^{j,\mathit{MAX}},{K}_{\mathit{II}}^{j,\mathit{MIN}},j=1,2,3$
- and for ${K}_{\mathit{III}}$ (mode $\mathit{III}$ or anti-plane shear): ${K}_{\mathit{III}}^{j,\mathit{MAX}},{K}_{\mathit{III}}^{j,\mathit{MIN}},j=1,2,3$.

### 4.3 Table produced

The command POST_K1_K2_K3 produces a concept of type table. The table may be printed by IMPR_TABLE [U4.91.03](doc:u4.91.03). It contains, for each node of the crack front:

- the values of the corresponding stress intensity factors: K1, K2 (and K3 if 3D)
- the value of the energy release rate: $G$
- estimates of the error on the stress intensity factors: ERR_K1, ERR_K2 (and ERR_K3 if 3D).

The following paragraphs detail these quantities.

#### 4.3.1 Values of the stress intensity factors

The table produced contains, for each node (or point) of the crack front, the values of the stress intensity factors corresponding to the MAX values of method no. 1 (see § 4.2):

$\mathit{K1}$ ($\text{}={K}_{I}^{1,\mathit{MAX}}$ ), $\mathit{K2}$ ($\text{}={K}_{\mathit{II}}^{1,\mathit{MAX}}$ )

In 3D, one has in addition $\mathit{K3}$ ($\text{}={K}_{\mathit{III}}^{1,\mathit{MAX}}$)

A single value of $\mathit{K1}$, $\mathit{K2}$ (and $\mathit{K3}$ if 3D) is therefore printed per node of the crack front.

#### 4.3.2 Values of the energy release rate

The table produced contains, for each node (or point) of the crack front, the value of the energy release rate $G$ computed from the stress intensity factors by Irwin's formula.

#### 4.3.3 Estimate of the error made on the stress intensity factors

In order to evaluate the error made on the stress intensity factors at each node of the front, the discrepancy between the 6 values given by the 3 methods is evaluated (see § 4.2). This gives an absolute discrepancy concerning $\mathit{K1}$, $\mathit{K2}$ (and $\mathit{K3}$ if 3D). In order to obtain a relative discrepancy that is easier to interpret, the absolute discrepancies are normalised by a value $K$ which is the maximum value of all the $K$ at this node of the crack front.

More precisely, the error made on ${K}_{i}(i=1,2,3)$, $i$ being the loading mode of the crack and $j$ the number of the method, is defined in the following manner:

$\mathit{erreur}({K}_{i})=\frac{\underset{j=1,2,3}{max}({K}_{i}^{j,\mathit{MAX}}-{K}_{i}^{j,\mathit{MIN}})}{K}$ , with $K=\underset{j=1,2,3}{max}({K}_{I}^{j,\mathit{MAX}},{K}_{\mathit{II}}^{j,\mathit{MAX}},{K}_{\mathit{III}}^{j,\mathit{MAX}})$

The errors on $\mathit{K1}$, $\mathit{K2}$ (and $\mathit{K3}$ if 3D) are printed in the table: ERR_K1, ERR_K2 (and ERR_K3 if 3D) for each node of the crack front.

### 4.4 Additional printouts

If INFO is equal to 2, all the intermediate computations are displayed in the message file. It is pointed out that the column entitled SAUT_DX (resp. SAUT_DY and SAUT_DZ) in the tables of the message file corresponds to the displacement jump along the axis $\mathit{X1}$ (respectively $\mathit{X2}$ and $\mathit{X3}$), multiplied by a coefficient depending on the material, the whole squared [R7.02.08](doc:r7.02.08).

### 4.5 Precautions and advice

The assumptions necessary for the validity of this method are:

1. the crack must be sufficiently regular (that is, the front and the lips do not present a geometric singularity);
2. the constitutive behaviour must be elastic, linear, isotropic and homogeneous;
3. the structure must be isothermal (or, at the very least, the temperature gradients on the lips may be neglected in the interpolation zone).

The method used is theoretically less accurate and more sensitive to the mesh than the singular-displacement method [R7.02.05](doc:r7.02.05). In general, one may advise comparing, in the studies, the results of POST_K1_K2_K3 and those of CALC_G [U4.82.03](doc:u4.82.03), which is a good indicator of the quality of the result obtained.

**Advice in the case of a meshed crack:** the mesh should preferably be quadratic and comprise enough nodes perpendicularly to the crack front. Furthermore, the results are markedly improved if, in the case where the mesh is composed of quadratic elements, the mid-side nodes (of the edges that touch the crack front) are moved to the quarter of these edges, bringing them closer to the crack front. This is made possible by the keyword MODI_MAILLE (option 'NOEUD_QUART') of the command MODI_MAILLAGE [U4.23.04](doc:u4.23.04).

The computation by interpolation of the displacement jumps requires at least 3 nodes on the normal to the crack front. If the number of nodes is not sufficient, an alarm is issued and the rows corresponding to this node of the front are set to 0 in the result table. The analysis then continues, where applicable, for the next node of the crack front. In this case one may:

- either increase the maximum curvilinear abscissa ABSC_CURV_MAXI in order to look for nodes further from the crack front;
- or increase the parameter PREC_VIS_A_VIS (and possibly PREC_NORM in DEFI_FOND_FISS), which amounts to being less demanding in the selection of the nodes for the analysis.

**Advice in the case of an unmeshed crack:** the accuracy of the method is sensitive to the choice of the enrichment zone of the X-FEM method (parameter RAYON_ENRI of DEFI_FISS_XFEM). Ideally, the enrichment radius and the maximum curvilinear abscissa ABSC_CURV_MAXI are of the order of three times the size of the smallest edge of the mesh.

Analyses are possible on a non-plane crack, but the user must make sure that it remains sufficiently regular for the analysis assumptions to be valid: there must not be a geometric singularity on the front or on the lips. Typically, the analysis is admissible for an axisymmetric crack, but not for a corner.

The computation by interpolation of the displacement jumps requires at least 3 nodes on the normal to the crack front. The number of interpolation points is normally equal to NB_NOEUD_COUPE but may be smaller in one case:

  - if the geometry of the front and of the structure is such that part of the interpolation points leaves the material. In this case ABSC_CURV_MAXI must be reduced (while remaining consistent with the fineness of the mesh) and/or NB_NOEUD_COUPE increased.

The analyses are fairly demanding in time and in memory if there are many points on the crack front. The use of the keyword NB_POINT_FOND makes it possible to limit the post-processing to a certain number of points evenly distributed along the front (for example some twenty points is often sufficient).

## 6 Example 2: free mesh

In 3D, if the mesh is not ruled at the crack front, there may not be enough nodes on directions normal to the front for the interpolation. In this case, the option TYPE_MAILLAGE=’LIBRE’ must be used.

With this option, the principle of the analysis is the following

1. determination of the directions normal to the crack front for each node of the front,
2. definition, on each of these directions, of NB_NOEUD_COUPE points, evenly distributed between the front and the distance ABSC_CURV_MAXI,
3. projection of the displacement of each lip onto these nodes and interpolation of the displacement jump.

The option TYPE_MAILLAGE=’LIBRE’ is not available in 2D. The only case in which it could be of use is the case of nodes that do not coincide between the two lips.
