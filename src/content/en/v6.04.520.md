# v6.04.520 SSNV520 - Modelling a compression test with HILL hyperelastic law (HYPER_HILL)

**Summary:**

This test consists of simulating the uniaxial compression of a single element volume finish. It is designed to validate the constitutive law HYPER_HILL.
The results obtained are compared and validated with experimental results and results from the Abaqus software.

## 1 Reference problem

### 1.1 Geometry

It is a test on a cubic mesh cell, $25.5\times{25.5}\times{31}$ mm, representing one quarter of the test piece.

### 1.2 Material properties

The calculations for validation of the tests are performed with Hill law from the order $1$ to the order $4$
The parameters of which are presented in the tables below:

| Order | ${\alpha_i}$ (MPa) | ${\mu_i}$ | ${\beta_i}$ |
| --- | --- | --- | --- |
| $1$ | $[3.1740]$ | $[3.936e^{-2}]$ | $[3.006e^{-1}]$ |
| $2$ | $[3.6566, 1.1621]$ | $[4.2567e^{-2}, -8.0625e^{-3}]$ | $[1.8748e^{-1}, -6.7408]$ |
| $3$ | $[2.6430, 2.6065, 2.2001]$ | $[-2.7454, 2.9365e-1, -3.2912]$ | $[1.3552e-1, 2.8632e-2,-1.2926e-1]$ |
| $4$ | $[2.4766, 2.4426, 2.1534, -4.0965]$ | $[-4.5951, 5.5482e^{-1},-5.2950,-1.5711e^{-1}]$ | $[1.7462e^{-1}, 2.1899e^{-2},-1.6128e^{-1},-8.5760e^{-5}]$ |

| Order | ${\nu_i}$ |
| --- | --- |
| $1$ | $[0.1877]$ |
| $2$ | $[0.1364, 0.5401]$ |
| $3$ | $[0.6113, 0.1850, 0.5896 ]$ |
| $4$ | $[0.5610, 0.2630, 0.5521, -0.2291]$ |

As can be seen, all orders above $1$ give a value of
$\nu_i = \frac{\beta_i}{1 + 2 \beta_i}$ is higher than $0.5$, which is not possible.
These values do not allow calculations to be made with Abaqus, as they are rejected.
In code_aster, however, these values are not prohibited, but calculations have shown that the
convergence problems for deformations above $40\%$ in our case.

Therefore, only the $1$ order of Hill's law will be used for comparison between Abaqus and Code_Aster.
For orders above $1$, numerical results will be compared with experimental results.

### 1.3 Boundary conditions and loads

Symmetric conditions are imposed on the $3$ orthogonal faces in the $3$ direction of the marker.

A moving load of -$2.4$ mm is imposed.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The test is based on a comparison with the experimental results of the compression test,
and with the results obtained using the compressible hyperelastic law available in Abaqus for the development of $1$.

### 2.2 Baseline

For the $1$ order of development, we ensure that the force in the direction of compression,
and the displacement perpendicular to the compression, correspond well to the values obtained from the calculation with Abaqus to $0.1\%$.
For orders above $1$, these quantities are compared with experimental results with $6\,\%$ accuracy.
