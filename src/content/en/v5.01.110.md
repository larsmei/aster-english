# v5.01.110 SDND110 – Seismic Excitation of a Discreet Affected Behaviour CHOC_ELAS_TRAC

**Summary:**

The response of the CHOC_ELAS_TRAC nonlinear behavior model, formulated on discrete elements for mesh cells SEG2, is tested.

DYNA_NON_LINE and DYNA_VIBRA operators are used for validation. Discrete d的elements response is analyzed for nonlinear constitutive law under seismic loading.

The modellings and elements discreet tested are in $\mathrm{3D}$ with DIS_T Modelling on a mesh cell SEG2.

This behavior is also validated for non-dynamic stresses in the test case SSND121[V6.08.121] with the STAT_NON_LINE operator.

## 7 Summary of the results

These tests allow to check the smooth operation of the discreet elements with the CHOC_ELAS_TRAC behavior in the context of use with the DYNA_NON_LINE and DYNA_VIBRA command.

The DYNA_NON_LINE command uses an implicit algorithm.

The DYNA_VIBRA command uses an explicit algorithm and adapts the step for the resolution of the schema in time.
