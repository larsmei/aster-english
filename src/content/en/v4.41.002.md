# v4.41.002 TPNA02 - Flat thermal problem with radiation

**Summary:**

This basic test allows to treat a steady-state thermal analysis and transient plan problem with a boundary condition of radiation type. The solution is analytical.

## 1 Reference problem

### 1.1 Geometry

Infinitely long square section prism with 1 mm side.

![Figure](/figures/v4.41.002/v4.41.002.problem.svg)

### 1.2 Material properties

Volumetric heat $\rho {C}_{P}=3.6 \cdot 10^6 \, J/{m}^{3}/K = 3.6 \cdot 10^{-3} \, J/{mm}^{3}/K$

Thermal conductivity $k=50 \, W/m/K = 0.05 \, W/mm/K$

### 1.3 Boundary conditions and loads

Radiation-type condition (exchange with the outside medium) on the outer surface.

$k\frac{\partial T}{\partial n}= \varepsilon \sigma [{(T+273.15)}^{4}-{({T}_{\mathrm{ext}}+273.15)}^{4}]$

with $\varepsilon=0.8$, $\sigma=5.73\cdot{10}^{-14}\,W/{mm}^{2}/{K}^{4}$ and ${T}_{\mathrm{ext}}=100 °C$, $T$ in Celsius

## 2 reference solution

### 2.1 Calculation method used for reference solution

In this case, the number of Biot is relatively low (many less than 0.1) and, consequently, the temperature gradient on the section is negligible. The heat transfer equation to be solved is:

$\rho C_p V \cfrac{\partial T}{\partial t} = \varepsilon \sigma S [{({T}_{\mathrm{ext}}+273.15)}^{4} - {(T+273.15)}^{4}]$

where $S$ and $V$ are the exchange surface and the volume of the solid respectively. The reference solution is obtained by solving this initial value problem (or Cauchy problem), for which a large number of numerical methods are available (e.g., scipy.integrate.solve_ivp)

## 3 Modelling A

### 3.1 Modelling characteristics

This model allows the temperature evolution to be validated during a nonlinear thermal exchange (radiation).

Dirichlet conditions are not imposed but an exchange condition on the nodes at the edges.

```python
CHARGE = AFFE_CHAR_THER_F(
    MODELE=MODELE,
    RAYONNEMENT=_F(
        GROUP_MA="LINE_EXT", SIGMA=C_sigma, EPSILON=C_epsilon, TEMP_EXT=TEMP_EXT
    ),
)
```

The temperature on the 4 nodes of the mesh cell should be the same at a given moment.

The stationary temperature should be the same as the external temperature.

To enforce the use of Fortran with THER_NON_LINE, the keyword is added:

```python
OBSERVATION=_F(NOM_CHAM="TEMP", NOM_CMP="TEMP", TOUT="OUI"),
```

### 3.2 Mesh characteristics

Number of nodes : 4

Number of mesh cells and types : 1 QUAD4
