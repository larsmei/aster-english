# u4.71.06 Command EXTR_CONCEPT

**Summary:**

Makes it possible to extract a sub-object from a data structure of type *dict*.

## 1 Syntax

```text
evol_ther = EXTR_CONCEPT(
    ◆ DICT = ds_dict,
    ◆ NOM = text,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```
## 2 Operands

Data structures of type *dict* are not Python dictionaries but
their use is similar.

The first data structure of this type is *evol_ther_dict*, in which
one stores an object of type *evol_ther* associated with an access key.
It is the only type currently supported.

The command EXTR_CONCEPT returns the object stored for a given access key.

### 2.1 Keyword DICT

Supplies the data structure of type *dict*.

### 2.2 Keyword NOM

Value of the access key.
