# v1.04.119 PETSC04- FIELDSPLIT pre-conditioner validation c

**Summary:**

This test case allows you to validate the FIELDSPLIT pre-conditioner operation of the PETSC solver. It is a very general framework for dynamically defining block preconditioners.

keyword SOLVEUR, [U4.50.01](doc:u4.50.01) operating documentation.

The test consists of 4 modellings, which allows to check the correct functioning of the solver:

- petsc04a, Stokes problem sequentially
- petsc04b, Stokes problem in parallel
- petsc04c, sequential THM problem
- petsc04d, sequential THM problem
- petsc04b, Stokes problem hpc
- petsc04d, THM problem in hpc

This is a brief documentation.

## 1 Reference problem

### 1.1 Geometry

A cube of size 0.5x0.5x0.5 is considered

### 1.2 Material properties

See each of the modellings.

### 1.3 boundary conditions

See each of the modellings.

## 2 Solution

The reference quantity used is the x-axis displacement to node 165.

## 3 Modelling A

3D_INCO_UP Modelling

Young's modulus 1, Poisson's ratio 0,4999

A Stokes problem is modelled. A 2-level preconditioner is defined that collectively treats the DX, DY, DZ components on the one hand and the PRES component on the other. A pressure approximation of the Schur supplement is used, which is preconditioned by a Jacobi method and a multigrill method is used for displacement.

## 4 Modelling B

Model B is identical to model A, but the calculation is performed on 2 processors.

## 5 Modelling C

3D_THM modelling

A thermo-hydro-mechanical problem is modelled. A 3-level preconditioner is defined that collectively treats the components DX, DY, DZ, PRE1 component and TEMP component. Several preconditioning levels are defined: an external Gauss-Seidel preconditioner, an iterative GMRES method preconditioned by Jacobi for temperature, a Schur-type preconditioner based on an approximation of the Schur supplement to pressure that is preconditioned by a Jacobi method and a multigrill method for displacement.

## 6 Modelling D

Modelling D is identical to Modelling C, but the calculation is performed on 2 processors.

## 7 Modelling E

Modelling E is identical to Modelling B, but the calculation is performed in hpc on 2 processors.

## 8 Modelling F

Modelling F is identical to Modelling C, but the calculation is performed in hpc on 2 processors.

## 9 Summary of the results

This test case shows the FIELDSPLIT functionality of the PETSC solver on 1 and 2 processors.
