# v1.01.401 ZZZZ401 – Verification of Direct Linear Solver Renumbering Tools

**Summary:**

This test has no physical meaning, it is essentially a computer test.

Its purpose is to test the correct operation of the direct linear solver renumbering tools. To do this, this test case resumes the calculation of the test case MUMPS01A where the limit conditions are imposed both by dualization and elimination, and then reviews all the renumberers available under the keyword RENUM.

Model A checks sequential use, while model B performs parallel calculation.

This documentation is deliberately succinct.
