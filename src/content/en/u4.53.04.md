# u4.53.04 Operator DYNA_VISCO

## 1 Purpose

This command makes it possible to **compute the real or complex eigenmodes,** as well as **the harmonic response** (displacement, velocity, acceleration) of a **structure comprising viscoelastic materials whose properties depend on frequency** (which results in a frequency-dependent stiffness matrix).

The following actions are possible:

- obtaining the modes by an iterative method; 3 types of mode to choose from: real modes, real beta-modes or complex modes, taking into account the frequency dependence of the mechanical properties of the viscoelastic materials;
- if there is an excitation, analysis of the harmonic response of the structure; the analysis is carried out by projection onto the modal basis established at the previous step, then restoration onto the physical basis.

For further theoretical details, refer to the reference document [R5.05.10](doc:r5.05.10).

The command can produce a concept of type mode_meca, mode_meca_c, dyna_harmo.

**Note:**

*The command does not currently allow the analysis of double modes;*

*The analysis of structures with rigid-body modes may fail to converge.*

## 3 Operands

### 3.1 Operands MODELE / CARA_ELEM

```text
♦    MODELE = modele,

◊    CARA_ELEM    = caraelem,
```

These keywords make it possible to supply:

- the name of the model (modele) whose elements are the subject of the mechanical analysis.
- the name of the characteristics of the structural elements (plates, beams, discrete elements, …) if they are used in the model.

### 3.2 Factor keyword MATER_ELAS

```text
◊    MATER_ELAS =    _F(
♦    /     MATER = mat
/ ♦ E = e
♦ AMOR_HYST = amorhyst
♦ RHO = rho
♦ NU = nu
♦ GROUP_MA = gma
)
```

This keyword makes it possible to assign an elastic material **with no frequency dependence** to the elements belonging to GROUP_MA.

The material may be defined before the macro-command by means of the operator DEFI_MATERIAU [U4.43.01](doc:u4.43.01); in that case, this material is recalled with the keyword MATER. The material may also be defined here by its properties: Young's modulus E, mass density RHO, Poisson's ratio NU, and hysteretic damping AMOR_HYST.

This factor keyword may be repeated as many times as there are elastic materials **with no frequency dependence** in the structure.

### 3.3 Factor keyword MATER_ELAS_FO

```text
♦    MATER_ELAS_FO    =    _F(
♦    E = l_e
♦     AMOR_HYST = l_amor
♦    RHO = rho
♦    NU = nu
♦    GROUP_MA = gma
)
```

This keyword makes it possible to assign a viscoelastic material **with** **frequency dependence** to the elements belonging to GROUP_MA.

The mechanical properties of the viscoelastic material are of two kinds:

- those which depend on frequency: Young's modulus E and the damping factor AMOR_HYST; they are supplied by functions indexed by frequency, produced by DEFI_FONCTION / NOM_PARA='FREQ' [U4.31.02](doc:u4.31.02));
- those which are constant: the mass density RHO and Poisson's ratio NU.

This factor keyword may be repeated as many times as there are viscoelastic materials with **frequency dependence** in the structure.

### 3.4 Keyword TYPE_RESU

```text
◊    TYPE_RESU =     / ’HARM’                    [DEFAUT]
/ ’MODE’
```

This keyword makes it possible to define the type of analysis to be carried out:

- the choice 'MODE' makes it possible to compute the eigenmodes of the structure;
- the analysis 'HARM' makes it possible to obtain the frequency response of the structure to a given excitation; one can also recover the eigenmodes computed, by means of the keyword MODE_MECA.

### 3.5 Keywords FREQ / LIST_FREQ

```text
♦    / FREQ = l_f
/ LIST_FREQ =    lfreq
```

In the case of a modal analysis of the structure (TYPE_RESU='MODE'), this keyword makes it possible to define the frequency band in which the modes are sought. The list must then contain exactly 2 values (strictly increasing).

In the case of a harmonic analysis of the structure (TYPE_RESU='HARM'), this keyword makes it possible to define the discrete frequencies for which the response of the structure is computed. The list must then contain at least 2 strictly increasing values.

### 3.6 Keywords TYPE_MODE / RESI_RELA

```text
◊    TYPE_MODE =    / ’REEL’                    [DEFAUT]
/ ’BETA’
/ ’COMPLEXE’
```

Several choices are possible for the computation of the eigenmodes: real modes, beta-modes (which are improved real modes giving a better accuracy of the results, cf. [R5.05.09](doc:r5.05.09)), as well as complex modes.

The computation of the complex modes makes it possible to obtain the modal dampings. On the other hand, this type of mode cannot be used to carry out a harmonic analysis (TYPE_RESU='HARM').

Note:

If one computes complex modes, one can recover the modal dampings in a Python list with this function: liste_python=modes.LIST_PARA()['AMOR_REDUIT'] (this requires using PAR_LOT='NON' in the command DEBUT).

```text
◊    RESI_RELA =    / 1.E-3                    [DEFAUT]
/ eps
```

The computation of the eigenmodes by the iterative method has a convergence criterion named RESI_RELA. An eigenmode is retained in the modal basis when the relative difference between the eigenfrequencies computed at two successive iterations is less than RESI_RELA.

### 3.7 Factor keyword EXCIT

```text
♦    EXCIT =_F(
♦ CHARGE = charge
)
```

This keyword makes it possible to assign loads (boundary conditions, excitation forces, ...) which have been defined beforehand by the operator AFFE_CHAR_MECA [U4.44.01](doc:u4.44.01).

**Note:**

*At present, for external excitations, only excitations of type* FORCE_NODALE *are compatible with the command* DYNA_VISCO *.*

*For the harmonic analysis, the basis of eigenmodes is enriched, transparently for the user, by the static modes associated with the excited nodes.*

### 3.8 Keyword NOM_CHAM (if TYPE_RESU='HARM')

```text
◊    NOM_CHAM =    / ’DEPL’                    [DEFAUT]
/ ’VITE’
/ ’ACCE’
```

This keyword makes it possible to define which fields will be saved in the result concept (displacement, velocity or acceleration). It is possible to save several fields by giving a list, for example NOM_CHAM=('DEPL','ACCE').

### 3.9 Keyword MODE_MECA (if TYPE_RESU='HARM')

◊    MODE_MECA = CO( 'modes' )

If this keyword is present, two concepts will be produced by the macro-command:

- the concept modes of type mode_meca
- the concept visco of type dyna_harmo

The concept modes may for example be printed in the usual way with the command IMPR_RESU [U4.91.01](doc:u4.91.01).

### 3.10 Keyword COEF_FREQ_MAX (if TYPE_RESU='HARM')

◊    COEF_FREQ_MAX = cfmax                        [R]

During a harmonic analysis, the multiplying coefficient COEF_FREQ_MAX makes it possible to obtain more accurate frequency-response values, by multiplying by COEF_FREQ_MAX the value of the maximum frequency used to compute the modal basis of projection.

The minimum value of this parameter is 1.5.

### 3.11 Keyword INFO

```text
◊    INFO =        / 1                                [DEFAUT]
/ 2

Indique le niveau d’impression dans le fichier MESSAGE.
```

## 4 Examples

### 4.1 Definition of the frequency dependence of the properties of the viscoelastic materials

# frequencies for which the material parameters are given

list_f=DEFI_LIST_REEL(VALE=(1,10,50,100,500,1000,1500,),);

# values (of the real part) of Young's modulus at the frequencies of list_f

list_E=DEFI_LIST_REEL(VALE=(23.2E6,58.E6,145.E6,203.E6,348.E6,435.E6,464.E6,),);

# values of the loss factor at the frequencies of list_f

list_eta=DEFI_LIST_REEL(VALE=(1.1,0.85,0.7,0.6,0.4,0.35,0.34,),);

fonc_E=DEFI_FONCTION(NOM_PARA='FREQ',

VALE_PARA=list_f,

VALE_FONC=list_E,

INTERPOL=('LIN','LIN',),

PROL_DROITE='LINEAIRE',

PROL_GAUCHE='CONSTANT',);

fonc_eta=DEFI_FONCTION(NOM_PARA='FREQ',

VALE_PARA=list_f,

VALE_FONC=list_eta,

INTERPOL=('LIN','LIN',),

PROL_DROITE='LINEAIRE',

PROL_GAUCHE='CONSTANT',);

### 4.2 Computation of the complex eigenmodes

modes=DYNA_VISCO(MODELE=modele,

CARA_ELEM=cara_ele,

# materials with constant properties:

MATER_ELAS=_F(E=2.1e11,

> NU=0.3,
> RHO=7800.,
> AMOR_HYST=0.002,

GROUP_MA='SUPPORT'),

# materials with frequency-dependent properties:

MATER_ELAS_FO =_F(E=fonc_E,

AMOR_HYST=fonc_eta,

RHO=1200.,

NU=0.45,

GROUP_MA='VISCO'),

TYPE_RESU='MODE',

> TYPE_MODE='BETA',

# frequency band of the search

FREQ=(1.,1500.),

EXCIT=_F(CHARGE=condlim),

);

### 4.3 Computation of the harmonic response

# DEFINITION OF THE LOADING

excit=AFFE_CHAR_MECA(MODELE=modele,

FORCE_NODALE=_F(GROUP_NO='A',

FZ=1.,),);

# DEFINITION OF THE FREQUENCIES FOR THE RESPONSE ANALYSIS

listfr=DEFI_LIST_REEL(DEBUT=1.,

INTERVALLE=(_F(JUSQU_A=500.,

PAS=1.,),),);

# HARMONIC RESPONSE

visco=DYNA_VISCO(MODELE=modele,

CARA_ELEM=cara_ele,

EXCIT=_F(CHARGE=(condlim, excit),),

MATER_ELAS=(_F(E=2.1E11,

NU=0.3,

RHO=7800.,

AMOR_HYST=0.002,

GROUP_MA='DESSOUS'),

_F(E=7.0E10,

NU=0.3,

RHO=2700.,

AMOR_HYST=0.001,

GROUP_MA='DESSUS'),),

MATER_ELAS_FO=(_F(E=fonc_E,

AMOR_HYST=fonc_eta,

RHO=1200.,

NU=0.45,

GROUP_MA='VOLUME',),),

TYPE_RESU='HARM',

TYPE_MODE='REEL',

LIST_FREQ=listfr,

# fields to be saved

NOM_CHAM=('DEPL','VITE'),

# saving of the eigenmodes of the structure:

MODE_MECA=CO('modes'),

);
