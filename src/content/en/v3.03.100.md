# v3.03.100 SSLS100 - clamped circular plate under uniform pressure

**Summary:**

This problem allows a comparison of the solutions obtained with different elements plate in linear elasticity:

- **Love-Kirchhoff** (slim plate):
- mesh cell triangular superfacial (TRIA3) DKT,
- mesh cell quadrangular superfacial (QUAD4) DKQ,
- mesh cell linear (SEG3) COQUE_AXIS,
- **Mindlin-Reissner** (thick plate):
- mesh cell triangular superfacial (TRIA3) DST,
- mesh cell quadrangular superfacial (QUAD4) DSQ,
- mesh cell linear (SEG3) COQUE_AXIS,
- Models of thick shells: COQUE_3D (QUAD9 and TRIA7).
- Volumetric shell model: COQUE_SOLIDE

The same reference solution is treated with three forms of loading: pressure, gravity and force-hull. The observed quantities are: displacement (translation/rotation), deformations and generalized forces.

### 2.1 Calculation method used for reference solution

Two reference solutions are available for the calculation of the distortion:

- LOVE-KIRCHHOFF theory, commonly used for "thin" plates, which will be retained for modellings A, B, C, D, E and I,
- MINDLIN-REISSNER theory, including shear effects for so-called "thick" plates, which will be retained for modellings F, G, H and J.
