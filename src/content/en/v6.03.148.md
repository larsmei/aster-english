# v6.03.148 SSNP148 - Calculation of stress intensity factor by stress regularization with ENDO_HETEROGENE

**Summary:**

This test calculates the threshold for the propagation of a central crack in a plate of infinite length required by an infinite stress. In this case an analytical solution exists since the stress intensity factor can be calculated. This test gives a comparison between this analytical solution and the value of the stress intensity factor calculated from the regulated stresses (modelling D_PLAN_GRAD_SIGM). The objective of this approach is to validate the calculation method (Modelling D_PLAN_GRAD_SIGM and ENDO_HETEROGENE law. ) for cases where the characteristic length is small in front of the crack size and structure.

## 1 Reference problem

### 1.1 Geometry

The $l=\mathrm{6000mm}$ length domain is $h=\mathrm{1000mm}$ height domain containing an initial vertical crack of $\mathrm{2a}$ length. By symmetry condition, only half of the domain area is modeled ().

Vertical displacements on the lower edge of the model are blocked and horizontal displacements on the left edge are imposed on the right edge of the model. The central crack is represented by a vertical band of elements finished broken ( *i.e.,* $d=1$).

The stress applied on the right edge varies from 0 to $10\mathit{MPa}$ during the calculation period, i.e. $1s$ .

## 2 reference solution

For a central crack of $\mathrm{2a}$ length in a bar of $\mathrm{2b}$ thickness and infinite length required by an infinite ${\sigma}_{\infty}$ constraint, the analytical stress intensity factor can be expressed by the following equation:

${K}_{\mathit{Ia}}\approx \sqrt{\frac{\pi a}{\cos(\frac{\pi a}{\mathrm{2b}})}}$

Since in the case treated the crack is pressed in $I$ mode, a stress intensity factor equivalent can be introduced for a given characteristic length [1]:

${K}_{\mathrm{IIc}}=\frac{5\pi }{6\Gamma \frac{3}{4}}.\stackrel{ˉ}{{\sigma}_{\mathrm{Ip}}}\sqrt{\pi {l}_{c}}$

with $\stackrel{ˉ}{{\sigma}_{\mathrm{Ip}}}$ the maximum main regulated stress at crack tip. To compare the numerical results with the analytical solution the $\mathit{RKI}={K}_{{\mathit{Il}}_{c}}/{K}_{\mathit{la}}$ parameter is introduced.

The above 2 equations were introduced into the command file of test case via table manipulations. The value of the regulated stress at the crack tip is extracted. The values of the analytical and numerical stress intensity factor are calculated in the command file. The ratio between the two values ($\mathit{RKI}$) is then calculated. This ratio was tested via the TEST_TABLE command.

## 5 Summary of the results

This test allows the threshold to be calculated for the propagation of a central crack in a plate of infinite length which is required by an infinite stress. We can compare the results obtained with an analytical solution: the results correspond. This test allows the validation of the D_PLAN_GRAD_SIGM model and the ENDO_HETEROGENE law.
