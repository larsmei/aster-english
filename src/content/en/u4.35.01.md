# u4.35.01 Operator DEFI_FONC_FLUI

## 1 Purpose

To define a fluid flow-velocity profile along a beam. Profiles corresponding to “standard” profiles coming from experimental results and used within a dynamic analysis taking fluid-elastic forces into account.

The velocities are computed at the nodes for which one looks up, in the mesh concept, the value of the associated curvilinear abscissa.

At present, it is possible to apply a velocity profile defined by DEFI_FONC_FLUI only on a structure whose mesh cells are of type 'SEG2'. The concept produced is of type fonction (parameter 'ABSC', curvilinear abscissa)

## 2 Syntax

```text
fonction = DEFI_FONC_FLUI(
    ◆ MAILLAGE = maillage,
    ◆ / GROUP_NO_INIT = grno,
    ◆ / GROUP_NO_FIN = grno,
    ◆ VITE = _F(
         ◇ VALE = float (défaut: 1.0),
         ◆ PROFIL = / "UNIFORME",
                    / "LEONARD",
         ◇ NB_BAV = / 0 (par défaut),
                    / 2,
                    / 3,
      ),
    ◇ INTERPOL = / "LIN" (par défaut),
                 / "LOG",
    ◇ PROL_DROITE = / "CONSTANT",
                    / "LINEAIRE",
                    / "EXCLU" (par défaut),
    ◇ PROL_GAUCHE = / "CONSTANT",
                    / "LINEAIRE",
                    / "EXCLU" (par défaut),
    ◇ INFO = / 1 (par défaut),
             / 2,
    ◇ TITRE = text,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand MAILLAGE

```text
♦    MAILLAGE = ma
```

Name of the mesh for which the curvilinear abscissa is defined.

### 3.2 Operands GROUP_NO_INIT and GROUP_NO_FIN

```text
♦    GROUP_NO_INIT        =    gni,                            [grno]

♦    GROUP_NO_FIN        =    gnf,                            [grno]
```

The function is defined over the whole mesh. The operands 'GROUP_NO_INIT' and 'GROUP_NO_FIN' make it possible to define the zone of application of the velocity profile. Outside this zone, the value of the function is zero.

### 3.3 Keyword VITE

```text
♦    VITE
```

Factor keyword; it makes it possible to define the velocity profile.

```text
♦    PROFIL
```

This operand, associated with the operands VALE and NB_BAV, makes it possible to define a “standard” profile: 'UNIFORME' or 'LEONARD'.

```text
/    ◊    VALE = vale
```

Makes it possible to define the level of the function, if the standard profile is 'UNIFORME'.

```text
/    ◊    NB_BAV
```

If the profile is of type 'LEONARD', NB_BAV defines a “standard” profile stored in a catalogue.

**Note:**

*BAV (Anti-Vibration Bar) is terminology linked to steam-generator tubes.* *NB_BAV corresponds to the number of anti-vibration bars located in the zone where the profile is obtained.*

### 3.4 Operand INTERPOL

```text
◊    INTERPOL
```

Type of interpolation of the function between the parameter values of the domain of definition.

| 'LIN': | linear, |
| --- | --- |
| 'LOG': | logarithmic, |

### 3.5 Operands PROL_GAUCHE and PROL_DROITE

```text
◊    PROL_GAUCHE / PROL_DROITE
```

Define the type of extension to the left (respectively to the right) of the domain of definition of the parameter.

| 'LINEAIRE': | the function is extended to the left (to the right) by a straight-line segment with the same slope as at the lower (upper) bound of the domain of definition of the parameter, |
| --- | --- |
| 'EXCLU': | extrapolation of the function outside the domain of definition of the parameter is forbidden, |
| 'CONSTANT': | the function is extended to the left (to the right) by the value that it takes at the lower (upper) bound of the domain of definition of the parameter. |

### 3.6 Operand INFO

```text
◊    INFO
```

Printout level.

| INFO = 1: | no printout, |
| --- | --- |
| INFO = 2: | one prints in the MESSAGE file the name of the function, the number of definition points, the name of the parameter, the name of the result, the extension and interpolation options and the first 10 values of the function, in increasing order of the parameter. |

### 3.7 Operand TITRE

```text
◊    TITRE = titre
```

Text argument defining the title attached to the output fonction concept.

## 4 Presentation of the standard velocity profiles

They are defined in a form discretised in $\theta$ (angle in degrees varying from 0. to 180.) - [Figure 4-a], [Figure 4-b] and [Figure 4-c].

Thus, it is possible from equation [eq. 4-1] to apply these profiles over a domain defined in curvilinear abscissa.

> $v({s}_{i})=\frac{{\alpha}_{i}\cdot {\gamma}_{i}+{\beta}_{i}}{{v}_{\mathrm{moy}}}$                                 eq. 4-1

with $\lbrace \begin{array}{}{\alpha}_{i}=\frac{{v}_{k+1}-{v}_{k}}{{\theta}_{k+1}-{\theta}_{k}}\\ {\gamma}_{i}=180(\frac{{s}_{i}-{s}_{ni}}{{s}_{\mathrm{nf}}-{s}_{ni}})\\ {\beta}_{i}=\frac{{v}_{k}{\theta}_{k+1}-{v}_{k+1}{\theta}_{k}}{{\theta}_{k+1}-{\theta}_{k}}\end{array}$

${s}_{i},{s}_{ni},{s}_{\mathrm{nf}}$ are respectively the curvilinear abscissa of the current point, of the initial node and of the final node which define the zone of application.

k: index in the table of the discretised function.

${v}_{\mathrm{moy}}=\frac{\sum_{i=1}^{N}({\alpha}_{i}\cdot {\gamma}_{i}+{\beta}_{i})}{N}$

N: number of discretisation points of the zone of application.
