# v1.06.002 HROM002 – Verification of the API python for the construction of an empirical quadrature

**Summary:**

This test case is intended to check the API python for the construction of an empirical quadrature.
An optimization solution for least squares with positive weights is tested (*Non negative least squares*, NNLS).

This test focuses on the algorithms of construction of an empirical quadrature in the sense of linear algebra,
and not the manipulation of the fields.

This documentation is deliberately succinct.
