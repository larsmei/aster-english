# u4.31.01 Operator DEFI_CONSTANTE

## 1 Purpose

Define the value of an invariant quantity (grandeur).

This operator is a convenience offered whenever a concept of type fonction is expected and the datum to be introduced is constant. This makes it possible to define, for example, materials with characteristics independent of the temperature, for commands which make it possible to treat materials with characteristics that vary with the temperature.

Take care not to confuse this with the definition of a real parameter (e.g.: a = 3.).

## 2 Syntax

```text
fonction = DEFI_CONSTANTE(
    ◇ NOM_RESU = text (défaut: "TOUTRESU"),
    ◆ VALE = float,
    ◇ TITRE = text,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand NOM_RESU

```text
◊    NOM_RESU = nr
```

Designates the name of the result; the function thus created is a function whose value has the name nr (8 characters maximum).

**Note:**

*Some commands (CALC_FONCTION,* *DEFI_MATERIAU…) check the consistency of the names of the parameter and of the result according to their context.*

### 3.2 Operand VALE

```text
♦    VALE = v
```

Value of the constant (real number).

### 3.3 Operand TITRE

```text
◊    TITRE = ti
```

Title attached to the concept produced by this operator [U4.03.01](doc:u4.03.01).

## 4 Examples

- Define the constant function "1.":

```text
F_UN = DEFI_CONSTANTE (    VALE = 1.    )
```

The function F_UN represents "any kind of result" (TOUTRESU) by default

- Define a constant function representing a constant Young's modulus

```text
F_YOUNG    =    DEFI_CONSTANTE (        VALE = 2.1E11 ,
NOM_RESU = 'E'    )
```
