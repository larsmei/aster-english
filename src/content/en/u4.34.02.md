# u4.34.02 Operator DEFI_LIST_ENTI

## 1 Purpose

Create a strictly increasing list of integers.

The list may be given “in extenso” by the user, or else it may be formed from sub-lists defined at “constant step”.

The list may be built by extraction of the order numbers of a result data structure.

Produces a data structure of type listis.

## 2 Syntax

```text
listis = DEFI_LIST_ENTI(
    ◇ OPERATION = / "DEFI" (par défaut),
                  / "NUME_ORDRE",
    # Si: equal_to("OPERATION", 'DEFI')
        ◆ / VALE = int,
          / DEBUT = int,
        ◇ / INTERVALLE = _F(
               ◆ JUSQU_A = int,
               ◆ / NOMBRE = int,
                 / PAS = int,
            ),
    # Si: equal_to("OPERATION", 'NUME_ORDRE')
        ◆ RESULTAT = resultat,
        ◆ PARAMETRE = text,
        ◆ INTERVALLE = _F(
             ◆ VALE = float,
          ),
    ◇ INFO = / 1 (par défaut),
             / 2,
    ◇ TITRE = text,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Definition of a list of integers

#### 3.1.1 Operand VALE

◊    VALE= lis

List of the integers which will form the resulting listis data structure; any Python list may be supplied.

#### 3.1.2 Operand DEBUT

```text
♦    DEBUT =
```

deb: first integer of the list to be built.

#### 3.1.3 Keyword INTERVALLE

◊    INTERVALLE

Factor keyword, each occurrence of which makes it possible to define an interval at constant step.

##### 3.1.3.1 Operand JUSQU_A

♦    JUSQU_A =    if

if is the integer end of the interval to be subdivided with a constant step.

##### 3.1.3.2 Operand PAS

♦    /    PAS =    ipas

Subdivision step of the interval.

##### 3.1.3.3 Operand NOMBRE

/    NOMBRE = in

Number of steps required in the interval.

### 3.2 Extraction of order numbers

This operation makes it possible to recover, in a result data structure (evol_noli coming from STAT/DYNA_NON_LINE for example), the order numbers corresponding to certain criteria.

The list of order numbers thus obtained may then be used in all the commands which have the keyword LIST_ORDRE.

For the moment, the only criterion programmed is the extraction of a parameter in a given interval.

#### 3.2.1 Operand PARAMETRE

Name of the parameter of the result data structure whose value one wishes to extract.

##### 3.2.1.1 Factor keyword INTERVALLE

One defines as many occurrences of the factor keyword INTERVALLE as one wishes search intervals. The search is carried out on the union of these intervals.

> VALE= (val1, val2)

Definition of the bounds of each interval to which the parameter to be extracted must belong (bounds included).

### 3.3 Operand INFO

◊    INFO = i

Indicates the printout level of the results of the operator:

1: no printout,

2: printout of the list of integers created.

### 3.4 Operand TITRE

◊    TITRE = titre

Title attached to the concept produced by this operator [U4.03.01](doc:u4.03.01).

## 4 Notes

- one checks that the list is increasing,
- caution: the data structure of type listis cannot be used after a keyword expecting an l_I (sequence of integers written between parentheses).

## 5 Examples

### 5.1 Case OPERATION = 'DEFI'

To build the list of integers at constant step:

![Figure](/figures/u4.34.02/1000027800001DF9000002E553896CE817064EF5.svg)

```text
listi = DEFI_LIST_ENTI        (    DEBUT =     1,
INTERVALLE =    (_F    (    JUSQU_A =        16,
PAS =            3    ),),
)
```

To build the list of integers with two different values of the step:

![Figure](/figures/u4.34.02/100002BA00001C6C000002FF3DD7A30568436B4B.svg)

```text
listi = DEFI_LIST_ENTI        (    DEBUT =    1,
INTERVALLE = (_F    (    JUSQU_A =        5,
PAS =            1,    ),
_F    (    JUSQU_A =        15,
PAS =            5,    ),)
)
```

or

```text
listi = DEFI_LIST_ENTI        (    DEBUT =    1,
INTERVALLE = (_F    (    JUSQU_A =        5,
NOMBRE =        4,    ),
_F    (    JUSQU_A =        15,
NOMBRE =        2,    ),),
)
```

or, from any Python list object:

```text
listi = DEFI_LIST_ENTI    (    VALE = range(10)    ,)
```

### 5.2 Case OPERATION = 'NUME_ORDRE'

lnuor = DEFI_LIST_ENTI(OPERATION='NUME_ORDRE',

RESULTAT=DEPLTRAN,

PARAMETRE='INST',

INTERVALLE=(

_F(VALE=(1.36, 1.37)),

_F(VALE=(1.45, 1.46)),

),)

lnuor will contain the list of the order numbers whose time-instant value (parameter INST) lies in the intervals given.
