# v4.05.301 TPLP301 - Square plate with sinusoidally distributed temperature imposed

**Summary:**

This test is based on independent validation of version 3 in linear steady-state thermal analysis.

This is a $\mathrm{2D}$ plan problem represented by two modellings, one plane, the second hull.

The functions tested are as follows:

- element thermal plane,
- element thermal hull,
- limit conditions: sinusoidal distribution of the imposed temperature

The results are compared with an analytical solution.

### 1.1 Geometry

## 2 reference solution

### 2.1 Calculation method used for reference solution

analytical solution :

$T(x,y)=\sinh[\pi (1.0-y)]\sin(p)/\sinh(\pi )$

### 2.2 Baseline

Temperature at $E,F,G,H,I$ points

### 2.3 Uncertainty about the solution

analytical solution.

The 2 modellings performed, COQUE and PLAN performed with mesh cells TRIA3 give satisfactory results, the difference maximum obtained is $0.63\text{\%}$. The results found for both modellings are identical. The value of this test is to compare the results obtained with an analytical solution.
