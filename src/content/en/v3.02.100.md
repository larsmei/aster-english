# v3.02.100 SSLP100 - Static substructure cross

**Summary:**

This test case validates the static substructure, consisting of condensation of stiffness matrices and loadings.

The flat Modelling of a structure with linear behavior is performed.

2 modellings:

- A: "ordinary" model plan: it's the reference solution.
- B: model with substructures.

Interest:

- Two-tier substructure,
- rotation of macro-elements and loads (followers or not),
- calculation of fields within macro-elements.

The results of B are identical to those of A to ${10}^{-5}$.

## 2 reference solution

### 2.1 Calculation method used for reference solution

This problem has no reference solution.

Model A is the reference for model B.

### 2.2 Baseline

### 2.3 Uncertainty about the solution

The "reference" solution depends on the spatial discretization of the model; therefore the mesh is drawn in [§1.1].

Model B must follow this mesh to produce the same results as A.

## 4 Modelling B

### 4.1 Modelling characteristics

![Figure](/figures/v3.02.100/100022A000001AC500002113AD5987BF3E31F67D.svg)

The mesh initial $\mathrm{ma}$ (level $-2$ of the substructure) contains only the 12 QUAD4 of $\mathrm{IJBA}$ and $\mathrm{ABCD}$ .

The macr_elem_stat $({S}_{1})$ is set from elements of $\mathrm{ABCD}$ . This macr_elem_stat is condensed on nodes of $\mathrm{AB}$ and $\mathrm{CD}$ (level $-2$ ).

![Figure](/figures/v3.02.100/10000FF800001C5200000F66D494C22286F394ED.svg)

The mesh $\text{ma\_123}$ level $-1$ is set by running $\text{S\_1}$ twice to represent the $\mathrm{ABCEGHFDA}$ crown.

![Figure](/figures/v3.02.100/100015120000283400000E78470D1303C995C21E.svg)

The macr_elem_stat $\text{S\_123}$ is defined from the $\mathrm{ABCD}$, $\mathrm{DCEF}$ and $\mathrm{FEGH}$ substructures. This macr_elem_stat is condensed on the nodes of $\mathrm{AB}$ and $\mathrm{GH}$.

The mesh $\mathrm{mag0}$ is defined by the macr_elem_stat $\text{S\_123}$ .

The mesh final $\mathrm{mag}$ (level $0$) is defined by the mesh $\mathrm{mag0}$ that is assembled (ASSE_MAILLAGE) with the mesh initial $\mathrm{ma}$ to recover mesh cells from $\mathrm{IJBA}$.

The resolution is then made on this final mesh, then the movements within the macr_elem_stat are calculated using the DEPL_INTERNE operator.

![Figure](/figures/v3.02.100/100010BE0000284F000014778EE6D943539B1567.svg)
