# u4.72.05 Operator PROJ_CHAMP

The purpose of the operator is to project the fields of a result data structure onto another mesh. This command can be used, for example, to transfer onto a “mechanical” mesh the result of a thermal analysis carried out on a different “thermal” mesh.

One can also “continue” a thermal (or mechanical) analysis on another mesh (more or less refined).

The command also makes it possible to define geometric “zones” which are projected onto one another, which makes it possible to solve the problem of a desired discontinuity of the projected field (for example along the faces of a crack).

For reasons of CPU performance, one can first compute the geometric pairing of the two meshes and store the data structure produced in a concept which one will be able to reuse later in order to carry out the projections of the fields.

It is possible to project an “isolated” field or a set of fields coming from an SD_RESULTAT.

Produces a data structure SD_RESULTAT or an “isolated” field or a data structure CORRESP_2_MAILLA.
