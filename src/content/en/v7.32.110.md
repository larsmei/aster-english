# v7.32.110 WTNP110 - Saturated orthotropic flow 2D

**Summary:**

The test presented here is used to verify the correct functioning of the operators used for the resolution of the equations of an orthotropic saturated flow. This test corresponds to the test 1.2 of the qualification plan of the ALLIANCES [bib1] project.

The residual *a posteriori* error estimators developed for the THM are also valid.

The reference solution is an analytical solution.
