# 1 **v4.21.001** TTLL01 - Thermal shock on an infinite wall

**Summary:**

Transient linear thermal,

elements 2D et 3D (7 modellings),

test interests:

- test the transient linear thermal algorithm with time step change,
- temperature imposed (discontinuity),
- archive some time step.

The shock is modelled in 2 different ways:

- by a linear ramp: $\Delta T=100.$ in ${10}^{–3}$ second,
- by a real imposed temperature discontinuity.

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v4.21.001/1000063000001A40000012B5B1AA1C85C2E5BB2D.svg)

$\stackrel{ˉ}{\mathrm{AA}}'=\mathrm{2L}=2m$

$x(\mathrm{M1})=0.2m$

$x(\mathrm{M2})=0.8m$

### 1.2 Material properties

$\lambda =1W/m°C$

$\rho {C}_{P}=1J/{m}^{3}°C$

### 1.3 Boundary conditions and loads

- $A:T(0,t)={T}_{p}=100°C$

for $t>0$

- $A':T(\mathrm{2L},t)={T}_{p}=100°C$

### 1.4 Initial conditions

$T(x,0)=0°C$ for all $x$

### 1.5 Details concerning modellings

$(t)$ Time Discretization:

Thermal shock requires "fine" discretization in time near $t=0$.

The purpose of the test is to validate the different elements (different modellings), so we chose a single discretization in time:

| 10 | not for | $[0.,1.E-3]$ | either | $\Delta t={10}^{–4}s$ |
| --- | --- | --- | --- | --- |
| 9 | not for | $[1.E-3,1.E-2]$ | either | $\Delta t={10}^{–3}s$ |
| 9 | not for | $[1.E-2,1.E-1]$ | either | $\Delta t={10}^{–2}s$ |
| 9 | not for | $[1.E-1,1.]$ | either | $\Delta t={10}^{–1}s$ |
| 10 | not for | $[1.,2.]$ | either | $\Delta t={10}^{–1}s$ |

The impact is defined in two different ways:

- for Modelling B, this is a real shock (${T}_{p}$ is discontinuous):

$\lbrace \begin{array}{}{T}_{p}^{-}(A)=0.\\ {T}_{p}^{+}(A)=100.\end{array}$

- for modellings $A,C,D,E,F,G$ , this is a linear ramp:

$\lbrace \begin{array}{}{T}_{p}{(A)}_{t=0}=0.\\ {T}_{p}{(A)}_{t={10}^{-3}}=100.\end{array}$

## 2 reference solution

### 2.1 Calculation method used for reference solution

$\frac{T(x,t)-{T}_{p}}{{T}_{0}-{T}_{p}}=\frac{4}{\pi}\sum_{n=1}^{\infty}\frac{1}{n}\sin(\frac{n\pi x}{\mathrm{2L}})\exp\left\lbrace -{(\frac{n\pi }{\mathrm{2L}})}^{2}.\frac{\lambda}{\rho {C}_{p}}.t\right\rbrace$

| $x=$ | abscissa |
| --- | --- |
| $t=$ | Time |
| ${T}_{0}=$ | Initial temperature |
| ${T}_{p}=$ | Temperature imposed |
| $n=$ | $1,3,5,\mathrm{...}$ |

### 2.2 Baseline

Temperatures at $\mathrm{M1}$ ($x=0.2$) and $\mathrm{M2}$ ($x=0.8$) points, and at different times ($t=0.1,0.2,0.7$ and $2.0$ ).

The reference values are those given in the VPCS guide.

### 2.3 Uncertainty about the solution

Digital series.

### 2.4 Bibliographical references

- J.F. SACCADURA: Initiation to heat transfer, Paris, Technical and Documentation (1982).

## 35 Summary of the results

After 0.7 s the error is much less than 1% for the different thermal elements 2D (QUAD8) and 3D (HEXA8 - HEXA20 - PENTA6 - PENTA15 - TETRA4) used.

It does not appear that the lumpage improves the numerical result.

The Dumping elements should be tested with a true jump as in the B Modelling.
