# u4.81.24 Operator CALC_COUPURE

**Summary:**

The command is presented here which makes it possible to compute the resultant force torsor of the action of a mesh-cell group on a node group at a given point.

The command can also handle the combination of modal torsors in the context of a spectral modal analysis (with or without a signature, CQC combination of the modes and quadratic or Newmark combination for the directions).

## 1 Purpose

The purpose of the command is to compute the resultant force torsor of the action of a given mesh-cell group on a node group at a given point.

The force torsors are computed by performing the computation (CALC_CHAMP) of the nodal reactions (REAC_NODA or FORC_NODA) on the mesh cells supplied by the user, then by extracting the nodal reactions on the given node group and integrating these forces (POST_RELEVE_T). The force torsor is then computed at a point whose coordinates are specified by the user, in a frame that the user can define.

In the context of a modal-spectral analysis, when the result is of type mode_meca, the user can choose to compute the contribution of each mode and to combine these contributions by the CQC method. In this case, the user supplies information such as the acceleration spectra to be used, the dampings to be retained and the type of combinations to be performed. For more information on the spectral method also refer to documents [U4.84.01](doc:u4.84.01) and [R4.05.03](doc:r4.05.03)).

The result is a table containing the force torsors for each time instant (INST), load case (NOM_CAS), order number (NUME_ORDRE) or mode number (NUME_MODE), according to the data structure of the result at the input of the command.

## 3 Operating principles of the command

The command takes as input a mesh-cell group and a node group and computes and integrates the reaction of the nodes arising from the forces coming from the mesh cells.

The following operations are carried out:

1. Computation of the field of nodal forces on a subdomain via the command *CALC_CHAMP* and the option *FORC_NODA* or *REAC_NODA*. As indicated in [U4.81.04](doc:u4.81.04), one thus obtains the reaction of a subset on the rest of the model.
2. The nodal reactions from the previous computation are extracted and these nodal reactions are integrated in order to reduce them to a torsor at a given point via the command *POST_RELEVE_T* and the option *EXTRACTION*. The forces are obtained in the global frame.
3. A change of frame is performed in order to place the force torsor in the local frame supplied by the user via the keywords *AXE_X*, *AXE_Y* and *AXE_Z*. By default, the global frame is used.
4. If the user wishes to carry out a modal-spectral analysis, the contributions of the modal torsors are then computed and combined by the CQC method, then the contributions in the 3 directions are also combined. The method relies largely on the operations described in [U4.84.01](doc:u4.84.01) and [R4.05.03](doc:r4.05.03)

The user must pay particular attention to the mesh-cell and node groups used. Indeed:

- In order to have a non-zero reaction, the nodes must be on the boundary of the domain defined by the mesh cells supplied,
- If a node is “in the middle” of the domain, the internal forces cancel out and the computed reaction will be zero.
- If a node is on a free edge of the model (no boundary conditions and no external forces applied on this node), the reaction computed at this node will be zero.
- The torsor computed with a supplied mesh-cell group comprising mesh cells that are not in contact with the given nodes will be the same as the torsor computed with the mesh-cell group strictly limited to the mesh cells of the group in contact with the given nodes, because the internal forces in the group cancel one another. In terms of performance, it is nevertheless preferable to limit the size of the mesh-cell group.

## 4 Format of the output table

The command returns a table. The columns of the table are:

- *NOM*: The name supplied by the user making it possible to identify each section.
- *NUME_ORDRE*, *NOM_CAS*, *INST*, *NUME_MODE*: Depending on the type of result at the input, makes it possible to identify the time instant, the mode or the order number concerned by the section. The operator processes all the order numbers present in the input concept.
- *R1*, *R2*, *R3*, *M1*, *M2*, *M3*: The components of the torsor computed in the local frame. “1” corresponding to the local X axis, “2” to the local Y axis and “3” to the local Z axis.

## 5 Processing of modal results

In this case, the command takes as input the dynamic modes of the structure (concept mode_meca). The operations carried out are the following:

1. Computation of the modal torsors.

1. Computation of the responses mode by mode from the modes and the spectra.
2. Combination of the modal responses by the CQC method (signed or not): this provides the probable maximum response for each earthquake direction $X$, $Y$, $Z$ (in the global system).

1. If requested, combination of the responses direction by direction (Newmark or quadratic combination)

Operation 1) is carried out as described in section 4, and this mode by mode.

Operations 2–4 are detailed below.

Mono-support spectra are considered: the supports all see the same imposed displacement.

### 5.1 Computation of the oscillator response

#### 5.1.1 Reminders of the transient analysis on a modal basis

The structure studied is represented by its spectrum of real eigenmodes at low frequency $\mathrm{\phi }$ on a fixed basis, solution of $\left(K-M{\omega}^{2}\right)\mathrm{\phi }=0$ .

In the dynamic equation of the system one can introduce a new transformation $x=\mathrm{\phi }q$ ; the system is then written, using the matrix of modal participation factors $P$ :

$$
\ddot{q}+\frac{{\mathrm{\phi }}^{T}C\mathrm{\phi }}{{\mathrm{\phi }}^{T}M\mathrm{\phi }}\dot{q}+{\omega}^{2}q=-\frac{{\mathrm{\phi }}^{T}MO}{{\mathrm{\phi }}^{T}M\mathrm{\phi }}\ddot{s}=-P\ddot{s}
$$

where $\mathrm{O}$ are the rigid-body modes.

It is also assumed that, for industrial studies falling under seismic analysis by the spectral method, one restricts oneself to the case of proportional damping, known as Rayleigh damping, for which one can diagonalise the term $\frac{{\mathrm{\phi }}^{T}C\mathrm{\phi }}{{\mathrm{\phi }}^{T}M\mathrm{\phi }}=2\xi \omega$ . The damping is then represented by a modal damping ${\xi}_{i}$ possibly different for each eigenmode.

With these assumptions, the system of equations () is composed of independent equations, each relating to an eigenmode of angular frequency ${\omega}_{i}$ . Each equation describes the behaviour of a simple oscillator of parameters $({\omega}_{i},{\xi}_{i})$ whose behaviour is represented in the mono-support case by:

$$
\ddot{{q}_{i}}+2{\xi}_{i}{\omega}_{i}\dot{{q}_{i}}+{\omega}^{2}{q}_{i}=-{p}_{i}\ddot{s}
$$

where $\ddot{s}$ is the driving acceleration and ${p}_{i}$ the modal participation factor of mode $i$ :

$$
{p}_{i}=\frac{{\mathrm{\phi }}_{i}^{T}MO}{{\mathrm{\phi }}_{i}^{T}M{\mathrm{\phi }}_{i}}=\frac{{{\mathrm{\phi }}_{i}}^{T}MO}{{\mu}_{i}}
$$

where ${\mu}_{i}$ is the generalised modal mass, which depends on the normalisation of the eigenmode.

Suppose that the earthquake acts only in one of the three directions of the global frame $X,Y,Z$: if, for example, one takes it in the direction $X$, the vector $O$ will have $1$ for the degrees of freedom *DX* and $0$ for the others. Still by way of example in the direction $X$ one will then have:

$$
{p}_{\mathit{iX}}=\frac{{\mathrm{\phi }}_{i}^{T}MO}{{\mathrm{\phi }}_{i}^{T}M{\mathrm{\phi }}_{i}}=\frac{{{\mathrm{\phi }}_{i}}^{T}M{O}_{X}}{{\mu}_{i}}
$$

${p}_{\mathit{iX}}$ being called the modal participation factor in direction $X$. For more details on the transient analysis on a modal basis see documentation R4.05.01.

#### 5.1.2 Reminders of the spectral method

The maximum response in relative displacement of the oscillator of parameters $({\omega}_{i},{\xi}_{i})$ for a direction $X$ is determined by reading on an oscillator spectrum of absolute pseudo-acceleration $\mathit{SRO}(\ddot{{x}_{X}}({\xi}_{i},{\omega}_{i}))$ the value ${a}_{\mathit{iX}}$ which corresponds to the sections $({\omega}_{i},{\xi}_{i})$ and by dividing by ${\omega}_{i}^{2}$ , whence:

$$
{q}_{\mathit{iXmax}}={p}_{\mathit{iX}}\frac{\mathit{SRO}({\ddot{x}}_{X}({\xi}_{i},{\omega}_{i}))}{{\omega}_{i}^{2}}={p}_{\mathit{iX}}\frac{{a}_{\mathit{iX}}}{{\omega}_{i}^{2}}
$$

Recall that one has set $x=\mathrm{\phi }q$ hence ${x}_{i}={q}_{i}{\mathrm{\phi }}_{i}$ if one considers a single mode. The contribution ${x}_{\mathit{iXmax}}$ of this oscillator to the relative displacement of the structure for an earthquake in direction $X$ depends on the participation factor and on the modal shape ${\mathrm{\phi }}_{i}$ in physical space:

$$
{x}_{\mathit{iXmax}}={\mathrm{\phi }}_{i}{q}_{\mathit{iXmax}}={\mathrm{\phi }}_{i}{p}_{\mathit{iX}}\frac{{a}_{\mathit{iX}}}{{\omega}_{i}^{2}}
$$

Suppose one has ${r}_{i}$ , a quantity (field or scalar variable) derived by a linear mapping from the modes ${\mathrm{\phi }}_{i}$ , for example a force component on a node. The contribution ${r}_{\mathit{iXmax}}$ or ${R}_{\mathit{iX}}$ of this oscillator to the response of the structure for an earthquake is likewise written:

$$
{R}_{\mathit{iX}}={r}_{\mathit{iXmax}}={r}_{i}{q}_{\mathit{iXmax}}={r}_{i}{p}_{\mathit{iX}}\frac{{a}_{\mathit{iX}}}{{\omega}_{i}^{2}}
$$

In the case of the command CALC_COUPURE, the components ${r}_{i}$ are:

- the shell force components $\mathit{NXX}$ , $\mathit{NYY}$ , $\mathit{NXY}$ , etc. at a point of the section line AB
- the resultants / resultant moments on the section line AB, detailed in section Error: Reference source not found

For more details see documentation R4.05.03.

#### 5.1.3 Combination of the modes for one direction

The first modal combination carried out produces the probable maximum response in the directions $X,Y,Z$ for which the spectra will have been supplied at the input of the command.

The method used is the signed Complete Quadratic Combination (or signed CQC), in the mono-support case. The forces ${R}_{\mathit{iX}}$ (scalar component on a node or on a resultant) are therefore combined in the following way to give the response ${R}_{\mathit{mX}}$ :

$$
{R}_{\mathit{mX}}=\frac{{R}_{\mathit{kX}}}{\left|{R}_{\mathit{kX}}\right|}\sqrt{{\sum}_{j}{\sum}_{j}{\rho}_{ij}{R}_{\mathit{iX}}{R}_{\mathit{jX}}}
$$

The sums are carried out over the $N$ modes considered. The correlation coefficient between modes ${\rho}_{ij}$ is defined:

$$
{\rho}_{ij}=\frac{8\sqrt{{\xi}_{i}{\xi}_{j}{\omega}_{i}{\omega}_{j}}({\xi}_{i}{\omega}_{i}+{\xi}_{j}{\omega}_{j}){\omega}_{i}{\omega}_{j}}{{({\omega}_{i}^{2}-{\omega}_{j}^{2})}^{2}+4{\xi}_{i}{\xi}_{j}{\omega}_{i}{\omega}_{j}({\omega}_{i}^{2}+{\omega}_{j}^{2})+4({\xi}_{i}^{2}+{\xi}_{j}^{2}){\omega}_{i}^{2}{\omega}_{j}^{2}}
$$

or, by introducing the ratio of angular frequencies or of frequencies between two modes $\eta ={\omega}_{j}/{\omega}_{i}$ :

$$
{\rho}_{ij}=\frac{8\eta \sqrt{{\xi}_{i}{\xi}_{j}\eta }({\xi}_{i}+{\xi}_{j}\eta )}{{(1-{\eta}^{2})}^{2}+4\eta {\xi}_{i}{\xi}_{j}(1+{\eta}^{2})+4{\eta}^{2}({\xi}_{i}^{2}+{\xi}_{j}^{2})}
$$

For more details see documentation R4.05.03.

#### 5.1.4 Combination of the directions

##### 5.1.4.1 Newmark combinations

For each of the directions $X,Y,Z$ , a principal direction is chosen and the following eight values are computed. For example, for $X$ :

$$
{R}_{l}=\pm {R}_{\mathit{mX}}\pm 0,4{R}_{\mathit{mY}}\pm 0,4{R}_{\mathit{mZ}}
$$

One then obtains 24 combinations. These combinations are identified in the table at the output of the command.

##### 5.1.4.2 Quadratic combination

The quadratic combination of the contributions of each direction is computed:

$$
R=\sqrt{{R}_{\mathit{mX}}^{2}+{R}_{\mathit{mY}}^{2}+{R}_{\mathit{mZ}}^{2}}
$$

The output table contains 4 order numbers: 1, 2 and 3 corresponding to the contributions of the earthquake in the directions X, Y and Z, respectively. Order number 4 corresponds, for its part, to the quadratic combination of the contributions of the 3 directions.

> {R}_{m}=max({R}_{l})

These operands are used only in the case of a modal-spectral analysis, that is when MODAL_SPECTRAL = 'OUI'.

### 6.5 Operand AMOR_REDUIT

> ♦ AMOR_REDUIT = amor                                [l_R]

This operand makes it possible to supply the list of reduced dampings in the form of a list of reals (l_R). If the user supplies only a single value, this value is retained for all the modes.

### 6.6 Operand MODE_CORR

The modal basis is in general incomplete. The evaluation of the upper bound of the response to a seismic excitation therefore requires a correction by a term representing the static contribution of the eigenmodes neglected in each direction of the earthquake.

For each direction of the earthquake, this correction is carried out by adding to the modal basis a pseudo-mode $\Psi$ obtained from a static mode $\varphi$ , the displacement field of the nodes of the structure subjected to a uniform acceleration **in the direction considered**, defined by:

$K\varphi =M\delta$

- $K$ stiffness matrix of the structure
- $M$ mass matrix of the structure
- $\delta$ unit field in the direction of the earthquake

The pseudo-mode $\Psi$ is obtained by subtracting the static contributions of the modes taken into account:

$\Psi =\varphi -\sum_{r=1}^{\mathrm{nmod}}\frac{{p}_{r}}{{\omega}_{r}^{2}}{\Phi}_{r}$ with:

- ${\Phi}_{r}$ eigenmode of index $r$
- ${p}_{r}$ participation factor in the direction $\delta$

In this direction $\delta$ , for each quantity, the contribution of the neglected modes is given by:

${R}_{t}={R}_{s}-\sum_{r=1}^{\mathrm{nmod}}{R}_{r}$

${R}_{s}$ is the quantity associated with the static mode

> ◊ MODE_CORR = mode_corr                            [mode_meca]

This keyword makes it possible to supply the displacement field(s) $\varphi$ of the nodes of the structure subjected to a uniform acceleration in one (or several) direction(s), field(s) computed by the operator MODE_STATIQUE with the keyword PSEUDO_MODE [U4.52.14](doc:u4.52.14).

The acceleration of the pseudo-mode retained corresponds to the acceleration read on the spectrum at the frequency of the last mode of the modal basis at the smallest modal damping.

### 6.7 Operands SPEC_OSCI and ECHELLE

```text
♦    SPEC_OSCI= ( spe1, spe2, spe3 )                [l_fonction]
```

The operand SPEC_OSCI expects three nappes of oscillator spectra (oscillator spectra depending on the value of the reduced damping) where (spe1, spe2, spe3) is the list of nappes to be used in the three directions $X$, $Y$, $Z$.

```text
◊    ECHELLE = ( ech1, ech2, ech3 )                [l_R]
```

The operand ECHELLE makes it possible to define three scale factors (ech1, ech2, ech3) to be applied independently to all the points of each of the spectra.

### 6.8 Operand MODE_SIGNE

> ◊    MODE_SIGNE    =    / 'NON'                         [DEFAUT]

> / 'OUI'

This operand makes it possible to define whether the CQC torsors must be signed. If so, the sign of the torsors obtained under unit acceleration (from the concept supplied in *MODE_CORR*) is recovered and these signs are applied to the components of the CQC torsor.

### 6.9 Operand COMB_DIRECTION

> ◊ COMB_DIRECTION    =    / 'QUAD'                         [DEFAUT]

> / 'NEWMARK'

This operand makes it possible to define the way of combining the contributions of the 3 directions. Two choices are possible, defined in paragraph 5.1.4,

### 6.10 Factor keyword COUPURE

> Repeatable keyword making it possible to define one or several sections.

#### 6.10.1 Operand NOM

> ♦ NOM= nom,                                        [Kn]

This operand makes it possible to define a name for the section so that it can be located in the output table.

#### 6.10.2 Operand GROUP_MA and TOUT

> ♦    / TOUT = 'OUI'                                [Kn]

> / GROUP_MA = gma                                [group_ma]

This operand makes it possible to define the part of the model whose reaction on the node group one seeks to evaluate.

#### 6.10.3 Operand GROUP_NO

> ♦ GROUP_NO = gno ,                                [group_no]

This operand makes it possible to define the node group where one wishes to extract the reaction.

#### 6.10.4 Operand POINT

> ♦ POINT = (x1, y1, z1),                            [l_R]

This operand makes it possible to define the geometric position of the point where the torsor will be computed. This operand affects in particular the values of the computed moments (the reactions being invariant).

#### 6.10.5 Operands AXE_X, AXE_Y, AXE_Z and VERI_ORTHO

> ◊ AXE_X = / (1, 0, 0),                            [DEFAUT]

> / (x1, y1, z1),                        [l_R]

> ◊ AXE_Y = / (0, 1, 0),                            [DEFAUT]

> / (x1, y1, z1),                        [l_R]

> ◊ AXE_Z = / (0, 0, 1),                            [DEFAUT]

> / (x1, y1, z1),                        [l_R]

These operands make it possible to define the local frame in which the torsor will be expressed.

The operand VERI_ORTHO makes it possible to activate or not the check of the orthogonality of the system of axes supplied.
