# v4.22.304 TTNL304 - Infinite wall subjected to temperature leap with variable orthotropic properties

**Summary:**

This nonlinear transient thermal analysis test is similar to TTNL303 except that the material properties are orthotropic.

This is a linear 1D problem represented by two modellings, a plane and a volume.

The functions tested are as follows:

- element thermal plane,
- element thermal volumetric,
- variable orthotropic thermal conductivity,
- nonlinear transient thermal analysis algorithm,
- Limit conditions: temperature imposed with jump.

The value of the test lies in the consideration of variable orthotropic properties in transient analysis and the variation in temperature imposed over time.
