# v1.01.219 ZZZZ219 - AFFE_CHAR_MECA: keyword FACE_IMPO validation

**Summary:**

The objective of this test case is to validate the FACE_IMPO key word for the AFFE_CHAR_MECA operator. This keyword allows you to impose on all nodes on one side on superfacial or volume elements, one or more degree of freedom values.

In this test case FACE_IMPO is checked under the following conditions:

- FACE_IMPO/SANS_GROUP_MA
- FACE_IMPO/SANS_NOEUD
- FACE_IMPO/SANS_GROUP_NO

In this very simple test case (MODELISATION='C_PLAN'), all the movements of the mesh 6 nodes are imposed. It is therefore easy to check that the boundary conditions are being respected.

This documentation is deliberately succinct.
