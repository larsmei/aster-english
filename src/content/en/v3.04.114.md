# v3.04.114 SSLV114 - Solid body movements 2D and 3D

**Summary:**

This test is valid (in 2D and 3D) for the LIAISON_SOLIDE keyword of the AFFE_CHAR_MECA command.

This keyword is used to rigidize an nodes set by linear relationships expressing that the movements of "rigidified" nodes are linked by the equation:

$U(M)=U(A)+\Omega (A)\mathrm{\wedge }\mathit{AM}$

This equation is valid only in small movements.

The problem is 2D and 3D as well as specific cases:

- nodes geometrically combined (2D and 3D),
- nodes aligned (in 3D).

## 2 reference solution

### 2.1 Calculation method used for reference solution

Since the "solids" movement is imposed, the reference solution (on the move) is the imposed movement.

The reference solution is therefore accurate (in small rotations).
