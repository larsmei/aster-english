# u4.61.23 Operator ASSE_VECTEUR

## 1 Purpose

Build a field at the nodes by assembly of elementary vectors.

This field may, for example, be used as a right-hand side for the solution of a linear system.

Produces a data structure cham_no.

## 2 Syntax

```text
cham_no = ASSE_VECTEUR(
    ◆ VECT_ELEM = vect_elem,
    ◆ NUME_DDL = nume_ddl,
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand VECT_ELEM

```text
♦    VECT_ELEM = lvel
```

List of the concepts of type vect_elem to be assembled. The various elementary vectors are summed in one and the same assembled vector (of type cham_no). The assembly is valid only if the various vect_elem concepts all correspond to one and the same quantity (grandeur) DEPL_R, TEMP_R, PRES_R or PRES_C.

### 3.2 Operand NUME_DDL

```text
♦    NUME_DDL = nu
```

Defines the numbering of the degrees of freedom to be used for the assembled vector.
