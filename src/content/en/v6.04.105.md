# v6.04.105 SSNV105 - BETON_GRANGER_V model: creep test with consideration of relative humidity and ageing.

**Summary:**

This test case of quasi-static non-linear mechanics simulates a uniaxial creep test. Its objective is to validate the behavioral relationship of "Granger", allowing to model the own creep of concretes. This model allows to take into account the effects of hygrometry and aging.

This is an test case on the hardware point, made using the SIMU_POINT_MAT command.

The stress applied is constant. The effect of hygrometry and aging is studied separately:

- ssnv105a: relative humidity decreases linearly, concrete is non-aging;
- ssnv105b: Relative humidity is constant and equal to the reference value, concrete is aging.

The results obtained by *Code_Aster* are compared with the reference analytical solution.

## 2 reference solution

### 2.1 Calculation method used for reference solution

This is an $\mathrm{1D}$ test. The uniaxial constraint is: $\sigma ={\sigma}_{0}\cdot H({t}_{0})$ where ${t}_{0}$ is the loading moment. The function of Heavyside $H({t}_{0})$ allows you to apply ${\sigma}_{0}$ loading instantly.

We define the equivalent stress $S(t)=h(t)\cdot \sigma (t)$ . We have: ${S}_{0}=S({t}_{0})={\sigma}_{0}\cdot {h}_{0}$ .

The initial stress jump can be explained by writing the creep deformation as follows:

${\epsilon}^{\mathit{fl}}(t)={S}_{0}J(t,{t}_{0})+\underset{\tau ={t}_{0}}{\overset{\tau =t}{\int}}J(t,\tau )\dot{S}\text{d}\tau$

#### 2.1.1 Modelling A

In model A, the following were used:

- For $t>{t}_{0}^{+}$ we have: $S(t)={\sigma}_{0}\left({h}_{0}+\left({h}_{f}-{h}_{0}\right)\frac{t-{t}_{0}}{{t}_{f}-{t}_{0}}\right)$ so: $\dot{S}={\sigma}_{0}\frac{{h}_{f}-{h}_{0}}{{t}_{f}-{t}_{0}}$
- $J(t,\tau )=\sum_{s=1}^{8}{J}_{s}\cdot \left(1-\exp\left[-\frac{t-\tau }{{\tau}_{s}}\right]\right)$

${\epsilon}^{\mathit{fl}}(t)={\sigma}_{0}{h}_{0}J(t,{t}_{0})+\underset{\tau ={t}_{0}}{\overset{\tau =t}{\int}}J(t,\tau ){\sigma}_{0}\frac{{h}_{f}-{h}_{0}}{{t}_{f}-{t}_{0}}\text{d}\tau$

By replacing $J(t,\tau )$ we have:

${\epsilon}^{\mathit{fl}}(t)={\sigma}_{0}{h}_{0}J(t,{t}_{0})+{\sigma}_{0}\frac{{h}_{f}-{h}_{0}}{{t}_{f}-{t}_{0}}\sum_{s=1}^{8}{J}_{s}\underset{\tau ={t}_{0}}{\overset{\tau =t}{\int}}\left(1-\exp\left[-\frac{t-\tau }{{\tau}_{s}}\right]\right)\text{d}\tau$

We get:

$\begin{array}{c}{\epsilon}^{\mathit{fl}}(t)={\sigma}_{0}{h}_{0}\sum_{s=1}^{8}{J}_{s}\left(1-\exp\left[-\frac{t-{t}_{0}}{{\tau}_{s}}\right]\right)\\ -{\sigma}_{0}\frac{{h}_{f}-{h}_{0}}{{t}_{f}-{t}_{0}}\sum_{s=1}^{8}{\tau}_{s}{J}_{s}\left(1-\exp\left[-\frac{t-{t}_{0}}{{\tau}_{s}}\right]\right)+{\sigma}_{0}\frac{{h}_{f}-{h}_{0}}{{t}_{f}-{t}_{0}}\left(\sum_{s=1}^{8}{J}_{s}\right)\left(t-{t}_{0}\right)\end{array}$

The total deformation shall be calculated as the sum of the creep deformation and the elastic deformation:

$\epsilon (t)={\epsilon}^{e}(t)+{\epsilon}^{\mathit{fl}}(t)=\frac{{\sigma}_{0}}{E}+{\epsilon}^{\mathit{fl}}(t)$

#### 2.1.2 Modelling B

In model B, the following were used:

- For $t>{t}_{0}^{+}$ we have: $S(t)={\sigma}_{0}{h}_{0}=\mathit{constante}$ so: $\dot{S}=0$
- $J(t,\tau )=k(\tau )\sum_{s=1}^{8}{J}_{s}\cdot \left(1-\exp\left[-\frac{t-\tau }{{\tau}_{s}}\right]\right)$

So we have:

${\epsilon}^{\mathit{fl}}(t)={\sigma}_{0}{h}_{0}\sum_{s=1}^{8}k({t}_{0}){J}_{s}.\left(1-\exp\left[-\frac{t-{t}_{0}}{{\tau}_{s}}\right]\right)$

The total deformation shall be:

$\epsilon (t)={\epsilon}^{e}(t)+{\epsilon}^{\mathit{fl}}(t)=\frac{{\sigma}_{0}}{E}+{\epsilon}^{\mathit{fl}}(t)$
