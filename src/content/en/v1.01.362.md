# v1.01.362 ZZZZ362 - Checking the consistency of the fields produced by the X-FEM sub-cut

**Summary**

This test has no physical significance, it is a computer test.

The fields produced by the X-FEM sub-cut correspond to the cam_elem produced by the TOPOSE and TOPOFA calculation options, and stored in the [D4.10.02](doc:d4.10.02) sd_modele_xfem. The size of these cam_elems must be done in the same way for all elements X-FEM belonging to the same category "topological". Four categories are considered:

- elements finished assigned to main mesh cells 3D;
- elements finished assigned to 3D mesh cells aircraft;
- elements finished assigned to main mesh cells 2D;
- elements finished assigned to mesh cells 2D aircraft;

The objective of this test is to ensure that all modellings that can be assigned to a given mesh lead to the same dimensioning of these fields. Otherwise, the test fails. 2 "modellings" are considered

- **modelling A**: comparison of modellings MECANIQUE/3D, MECANIQUE/3D/CONTACT, THERMIQUE/3D, MECANIQUE/3D_HM, MECANIQUE/3D_HM/CONTACT
- **modelization B**: comparison of modellings MECANIQUE/C_PLAN, MECANIQUE/C_PLAN/CONTACT, MECANIQUE/D_PLAN, MECANIQUE/D_PLAN/CONTACT, MECANIQUE/AXIS, MECANIQUE/AXIS/CONTACT, THERMIQUE/PLAN, THERMIQUE/AXIS, MECANIQUE/D_PLAN_HM, MECANIQUE/D_PLAN_HM/CONTACT

## 1 Test principle

The principle of this test is:

1. to define from the same mesh as many enriched models (with the MODI_MODELE_XFEM operator) as modellings that can be assigned to this mesh;
2. ensure, using the IMPR_CO/NIVEAU=1 [U4.91.11](doc:u4.91.11) procedure, that the enriched models thus created all contain the same number of cam_elem produced by the TOPOSE and TOPOFA options;
3. to ensure, always using the IMPR_CO/NIVEAU=-1 procedure, that each of these cam_elem is dimensioned in the same way from one enriched model to the next.

These checks require the use of python and the execution of the PAR_LOT test = 'NON'.

## 2 Modelling A

The aim is to compare, using a 3D mesh, the enriched models produced by the assignment of modellings: MECANIQUE/3D, MECANIQUE/3D/CONTACT, THERMIQUE/3D, MECANIQUE/3D_HM, MECANIQUE/3D_HM/CONTACT.

With X-FEM, THERMIQUE/3D Modelling is only available for linear elements, and MECANIQUE/3D_HM Modelling with quadratic elements.

Thus, the enriched models produced by the assignment of modellings are compared:

- MECANIQUE/3D, MECANIQUE/3D/CONTACT and THERMIQUE/3D, on a linear mesh
- MECANIQUE/3D, MECANIQUE/3D_HM and MECANIQUE/3D_HM/CONTACT on a quadratic mesh
