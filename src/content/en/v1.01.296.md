## 2 reference solution

### 2.1 Method of calculation

The elements pipe supports are SEG3.

- The position of the integration points along the SEG3 is given in [R3.01.01](doc:r3.01.01)

```python
# Coordonnées des Points de Gauss sur l'axe X
long_poutre = 3.0
xpg = (1.0 / 3.0) ** 0.5
points_gauss = (long_poutre * (1.0 + xpg) * 0.5, long_poutre * (1.0 - xpg) * 0.5)
```

- The coordinates of the integration subpoints are based on the number of layers, the number of sectors and of course the diameter and thickness of the pipe.

```python
# Coordonnées des Sous-Points !!!
def coord_fibre(ifib):
    Rint = Rext - Ep
    # index des coordonnées
    numAng = ((ifib - 1) % (2 * Nsect + 1)) / (2.0 * Nsect)
    numCou = ((ifib - 1) // (2 * Nsect + 1)) / (2.0 * Ncou)
    y = (Rint + Ep * numCou) * np.cos(2.0 * np.pi * numAng)
    z = -(Rint + Ep * numCou) * np.sin(2.0 * np.pi * numAng)
    if abs(y) < 1.0e-08:
        y = 0.0
    if abs(z) < 1.0e-08:
        z = 0.0
    return y, z
```

où :

- `Rext` and `Ep` are the external radius and the pipe thickness, indicated in the `AFFE_CARA_ELEM` control, respectively.
- `Nsect` and `Ncou` are the number of sectors and layers, respectively, specified in the `AFFE_CARA_ELEM` command.

```python
CARA = AFFE_CARA_ELEM(
    MODELE=MODELE,
    INFO=1,
    POUTRE=_F(
        GROUP_MA=("POUTRE", "POUTRE0"),
        SECTION="CERCLE",
        CARA=("R", "EP"),
        VALE=(Rext, Ep),
        TUYAU_NSEC=Nsect,
        TUYAU_NCOU=Ncou,
    ),
)
```

- The $P0P1$ pipe transition matrix to $P0P2$ pipe allows the co-ordinates of the $P0P2$ pipe subpoints to be calculated from the previous formulae.

```python
# Matrice de passage Axe_X vers Trisectrice

un3 = 1.0 / pow(3.0, 0.5)
un2 = 1.0 / pow(2.0, 0.5)
un6 = 1.0 / pow(6.0, 0.5)
MatPass = np.array([[un3, -un2, -un6], [un3, un2, -un6], [un3, 0.0, 2.0 * un6]])
```

For $P0P1$ hose the $(x,y,z)$ coordinates of `ifib` fiber for point `ipt` are given by:

```python
xx = points_gauss[ipt]
yy, zz = coord_fibre(ifib)
```

For $P0P2$ hose the $({x}_{t},{y}_{t},{z}_{t})$ coordinates of `ifib` fiber for point `ipt` are given by:

```python
# Suivant la Trisectrice
xx = points_gauss[ipt]
yy, zz = coord_fibre(ifib)
xxt,yyt,zzt = np.dot( MatPass, np.array( [xx,yy,zz ] ) )
```
