# v1.02.011 PERFE01 – non-regression of the homogenized BZ calculation of the PERFECT platform

**Summary:**

This test validates the controls used by the PERFORM platform, which simulates the radiation effects on reactor components. Here, we are interested in the steel tank.

A volume element is considered to be applied to which an imposed deformation is applied. The material consists of a polycrystalline unit with 30 monocrystalline phases, homogenized by the Berveiller-Zaoui method (BZ).

Model A tests the average stresses and deformations obtained for an imposed deformation

$\text{1 \%}$ for phenomenological behavior.

Model B tests the average stresses and deformations obtained for an imposed deformation

$\text{1 \%}$ for DD_CC behavior..

## 2 reference solution

The purpose of this test is to check the validity of the command file used in PERFORM. The tests are therefore non-regression.

The values tested are the mean stresses and deformations following $Z$ at moment 10.
