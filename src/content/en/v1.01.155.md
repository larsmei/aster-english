# v1.01.155 ZZZZ155 – mesh cutting machine verification

**Summary**

It is a purely computer test of the mesh cutter.

## 1 Reference problem

Not applicable.

## 2 reference solution

This is a functioning test. There is no uncertainty about the expected behavior.

## 3 Modelling A

In this Modelling, the basic operation of the cutter and the CommGraph and ObjectBalancer objects is checked. The meshes checked and cut are checked from mesh purely sequential (Mesh) or from IncompleteMesh.

The call to PtScoch is also checked from the python space and the cut into broken commands.

The parallel connections of the meshes produced are checked.

## 4 Modelling B

This Modelling tests the same as A but on one of the larger grids.

## 5 Modelling C

This Modelling testes the re-reading and cutting of meshes and fields from MED files in relation to a reference that corresponds to the MED file medump.

The nodes and elements fields are tested using the python splitMeshAndFieldsFromMedFile function.

## 6 Modelling D

This Modelling tests the cutting and rereading of meshes and fields by producing a Result (ie: NonLinearResult) with splitMedFileToResults.

It also demonstrates the possibilities offered by the python interface to an med file in terms of creating fields with changing type or component names.

Comparison of results is made with a pre-cut and re-read file by LIRE_RESU.

## 7 Modelling E

This Modelling tests the proper functioning of the partitioner and the following calculation in the presence of local communicators.

## 8 Modelling F

This Modelling testes the creation and existence of mesh cells and nodes groups after partitioning mesh.

## 9 Modelling G

This Modelling tests the serialization of the MedField object.

## 10 Modelling H

This Modelling tests the rebalancing of the result sd load (Object MeshBalancer). This Modelling checks consistency by reconstructing the sequential fields and comparing them to the starting field.

## 11 Modelling I

This Modelling tests partitioning with ParMetis.

## 12 Modelling J

This Modelling tests the order of med file rereading type of mesh cells by type of mesh cells.

## 13 Modelling K

This Modelling tests the partitioning of mesh with mesh cells ghost layers with a number of more than 1 over 2 processors.

MECA_STATIQUE calculation is performed and its results are verified.

## 14 Modelling L

This Modelling tests the partitioning of mesh with mesh cells ghost layers with a number of more than 1 over 4 processors.

A 3D MECA_STATIQUE calculation is performed and its results are verified.

## 15 Modelling M

This Modelling tests convergence and residue calculation in a parallel calculation on 4 processors.

A 3D STAT_NON_LINE calculation is performed and its results are verified.
