# u7.02.32 Operator LIRE_IMPE_MISS

## 1 Purpose

Build an assembled matrix projected onto a RITZ basis from a file of soil impedances computed by the MISS3D software. The resulting projected matrix will be used by the harmonic analysis operator in generalised components DYNA_VIBRA [U4.53.03](doc:u4.53.03)).

Produces a generalised-vector concept of type matr_asse_gene_C.

## 2 Syntax

```text
matr_asse_gene_c = LIRE_IMPE_MISS(
    ◆ BASE = mode_meca,
    ◆ NUME_DDL_GENE = nume_ddl_gene,
    ◇ FREQ_EXTR = float,
    ◇ INST_EXTR = float,
    ◇ UNITE_RESU_IMPE = unit (défaut: 30),
    ◇ ISSF = / "NON" (par défaut),
             / "OUI",
    ◇ TYPE = / "BINAIRE",
             / "ASCII" (par défaut),
    ◇ SYME = / "NON" (par défaut),
             / "OUI",
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand BASE

```text
♦    BASE = ba
```

Concept of type mode_meca which contains the vectors defining the projection subspace.

### 3.2 Operand NUME_DDL_GENE

```text
♦    NUME_DDL_GENE = nu_gene
```

Generalised numbering built on the basis ba.

### 3.3 Operands FREQ_EXTR / INST_EXTR

```text
♦    /    FREQ_EXTR = freq
/    INST_EXTR = inst
```

Real value of the extraction parameter of the soil impedance matrix. It is either a frequency (keyword FREQ_EXTR) for complex impedances computed by CALC_MISS with option TYPE_RESU='FICHIER', or a time instant (keyword INST_EXTR) for time evolutions of impedance obtained by the Laplace method by CALC_MISS with option TYPE_RESU='FICHIER_TEMPS'.

### 3.4 Operand UNITE_RESU_IMPE

UNITE_RESU_IMPE= uresimp

Logical unit of the soil impedance matrix computed by CALC_MISS with option TYPE_RESU='FICHIER' or option TYPE_RESU='FICHIER_TEMPS'.

This matrix may either already have been computed and supplied as input in the study profile, or be the result of CALC_MISS in the same command file.

### 3.5 Operand ISSF

```text
♦    ISSF = / 'NON',                                                                                / 'OUI',
```

If 'OUI', the format specific to MISS3D studies in soil–structure–fluid interaction is taken into account, in accordance with this same keyword in CALC_MISS.

### 3.6 Operand SYME

```text
♦    SYME = / 'OUI',
```

If present, makes it possible to symmetrise the terms of the impedance matrix that has been read.

### 3.7 Operand TYPE

```text
◊    TYPE=    /    'BINAIRE'
/    'ASCII'                [DEFAUT]
```

This operand makes it possible to read the impedances computed by the command CALC_MISS in a binary-format file if necessary.
