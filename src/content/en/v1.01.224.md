# v1.01.224 ERREU01 - CALCUL and PRERES Routine Error Messages Emissor Test

**Summary:**

This test validates the issue of error messages from CALCUL (unscheduled elementary calculation) and PRERES (synthetic matrix).

## 1 Test principle

This test is a computer test. It validates that the CALCUL routine sends an error message to say that an elementary calculation is not yet scheduled (we try to calculate a rotation load with elements for which it is not expected) and that the PRERES routine sends a message to say that a matrix is singular (not all rigid body modes are blocked).
