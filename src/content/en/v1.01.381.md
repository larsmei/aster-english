# v1.01.381 ZZZZ381 – Validation of Multifibre Data Structure Concepts

**Summary:**

The purpose is to validate commands that directly or indirectly produce and use the multifibre data structure. This structure is produced by the DEFI_GEOM_FIBRE command.

The concepts produced by the following commands are tested: CREA_MAILLAGE, AFFE_CARA_ELEM, DEFI_COMPOR, AFFE_MATERIAU.

This documentation is deliberately succinct.
