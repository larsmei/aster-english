# v4.21.301 TTLL301 - Thermal transfer into a bar with imposed temperature (sinusoid)

**Summary:**

This test is based on independent validation of version 3 in linear transient thermal analysis.

This is a linear 1D problem represented by two modellings, one plane, the other volume.

The functions tested are as follows:

1. element thermal plane,
2. element thermal volumetric,
3. transient thermal analysis algorithm,
4. limit conditions: sinusoidal variation in temperature over time.

The value of the test lies in taking into account the variation in temperature imposed over time and geometric discretization.

The results are compared with those provided by NAFEMS.

## 7 Summary of the results

This test is recommended by NAFEMS (but with another type of mesh cell).

The two modellingss performed give the following results:

- Modelling A (PLAN with mesh cells TRIA3), the difference maximum (3.48%) is greater than the tolerance initially set (2%),
- Modelling B (3D with mesh cells PENTA15), the difference maximum (0.36%) is less than the tolerance initially set (2%).

The limit condition is given using the FORMULE command. This choice allows a good representation of the consideration of the limit condition of sinusoidal form.

Quadratic modelling is more appropriate to simulate this test. A finer and balanced mesh for linear modelling would yield better results.

The results of model A are therefore considered acceptable.

The main interest of this test is its origin: NAFEMS.
