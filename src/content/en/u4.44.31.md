# u4.44.31 Operator DEFI_SPEC_TURB

## 1 Purpose

Define a turbulent excitation spectrum. Various types of spectrum are available:

- for “tube bundles under cross-flow”, spectra of “correlation length” type,
- for established uniform flows, parallel to plane structures or to circular cylindrical structures, boundary-layer turbulence spectra,
- an excitation spectrum defined by its decomposition on a family of shape functions, by supplying a cross-spectral matrix and a list of associated shape functions. The concepts tabl_intsp and fonction must then have been generated beforehand,
- a predefined turbulence spectrum, identified on the GRAPPE1 or GRAPPE2 mock-up,
- an excitation spectrum associated with one or more point forces and moments, by supplying a cross-spectral matrix of excitations (concept tabl_intsp which must have been generated beforehand), the list of the nodes of application of these excitations, the nature of the excitation applied at each of these nodes (force or moment) and the directions of application of the excitations thus defined.
- an excitation spectrum defined by a set of complex analytical functions.

Produces a concept of type spectre.

## 3 Operands

### 3.1 Keywords SPEC_LONG_COR_n

The definition of an excitation spectrum of “correlation length” type can be made only by a single occurrence of one of the factor keywords SPEC_LONG_COR_n, corresponding to a zone of the tube defined beforehand by the function entered under the operand PROF_VITE_FLUI of the command DEFI_FLUI_STRU [U4.25.01](doc:u4.25.01). The velocity profile associated with this zone, recalled here under the operand PROF_VITE_FLUI, must be identical to the one entered in DEFI_FLUI_STRU [U4.25.01](doc:u4.25.01). The use of excitation spectra of “correlation length” type is limited to the configuration “tube bundle under cross-flow” (factor keyword FAISCEAU_TRANS of the operator DEFI_FLUI_STRU [U4.25.01](doc:u4.25.01)).

To carry out an analysis with several excitation zones, as many spectra as there are zones must be defined. The contributions of the various spectra may then be added when the excitation is projected onto the modal basis by the command PROJ_SPEC_BASE [U4.63.14](doc:u4.63.14). However, it is not possible in this command to combine spectra of “correlation length” type with spectra of another type (SPEC_CORR_CONV_n, SPEC_FONC_FORME or SPEC_EXCI_POINT).

The four spectra of “correlation length” type have values defined by default. The definition of new coefficients is delicate, in particular as regards model 3, for which there are continuity conditions between the straight lines determined by the coefficients.

The general analytical form of models 1 to 4 is as follows:

$S({s}_{1,}{s}_{2,}{f}_{r})=S({f}_{r})\cdot \exp(\frac{-∣{s}_{2}-{s}_{1}∣}{{\lambda}_{c}})$

with:

| $S({s}_{1,}{s}_{2,}{f}_{r})$ | dimensionless turbulence cross-spectrum between two points of curvilinear abscissae $({s}_{1,}{s}_{2})$ ; |
| --- | --- |
|  |  |
| $S({f}_{r})$ | turbulence autospectrum; |
|  |  |
| $\exp(\frac{-∣{s}_{2}-{s}_{1}∣}{{\lambda}_{c}})$ | spatial correlation function and ${\lambda}_{c}$ correlation length. |

The spectrum is defined as a function of a reduced frequency ${f}_{r}$ (Strouhal number). For a tube under cross-flow, the expression for ${f}_{r}$ is as follows:

${f}_{r}=\frac{f\cdot \mathrm{de}}{{V}_{g}}$

$f$ is the dimensional frequency, $\mathrm{de}$ the external diameter of the tube ${V}_{g}$ and the mean transverse velocity of the fluid along the structure, which will be recovered in the operator PROJ_SPEC_BASE [U4.63.14](doc:u4.63.14) via the concept [melasflu] produced by the operator CALC_FLUI_STRU [U4.66.02].

### 3.2 Keywords SPEC_CORR_CONV_n

The factor keywords SPEC_CORR_CONV_1 and SPEC_CORR_CONV_2 make it possible to define, respectively, boundary-layer turbulence spectra and a spectrum given by an arbitrary function of frequency. SPEC_CORR_CONV_3 leaves the user in complete control of the definition of the cross-spectrum, by using analytical functions gathered in a table.

**Theoretical details:**

- In the case of a plane structure subjected to a parallel turbulent flow, whose spectral response to this excitation one wishes to know, the CORCOS correlation model introduces a correlation function between two points $x$ and $x'$ on the plane structure, of the type

$r(\omega ,x,x')=\exp(\frac{-∣x-x'∣}{{\lambda}_{1}})\times \exp(\frac{-∣y-y'∣}{{\lambda}_{2}})\times \cos(\frac{\omega (x-x')}{{U}_{c}}+\frac{\omega (y-y')}{{U}_{c}')}$

In the basic CORCOS model (coded for SPEC_CORR_CONV-1), one has $\lbrace  \begin{array}{c}{\lambda}_{1}=\frac{1}{{k}_{L}}\text{avec}{k}_{L}=0,1.\frac{\omega}{{U}_{c}}\\ {\lambda}_{2}=\frac{1}{{k}_{T}}\text{avec}{k}_{T}=0,55.\frac{\omega}{{U}_{c}}\end{array}$
It is possible to choose the CORCOS model and to use correlation lengths defined by the user via the operand SPEC_CORR_CONV_2.

*   $x$ is the axis parallel to the flow.

- $y$ is the axis perpendicular to the flow.
- ${U}_{c}$ is the convective velocity of the eddies. It is accepted that it represents between 60 and 70% of the fluid velocity. By default, it is taken equal to 65% of the fluid velocity.
- $U{'}_{c}$ is the orthoradial convective velocity of the eddies. By default this phenomenon is not taken into account because it is seldom observed experimentally. However, it is possible to define it if needed.
- In the case of a circular cylindrical structure subjected to an axial flow, the AU_YANG correlation model introduces a correlation function between two points defined by:

$r(\omega ,x,x')=\exp(\frac{-∣x-x'∣}{{\lambda}_{1}})\times \times \exp(-R\frac{∣\theta -\theta '∣}{\lambda '})\times \cos(\frac{\omega (x-x')}{{U}_{c}}+\frac{\omega R(\theta -\theta ')}{U{'}_{c}})$

- $\theta$ and $\theta '$ correspond to the angular positions of the two points of the cylinder to be correlated,
- $x$ and $x'$ denote the coordinates of the points to be correlated,
- $R$ is the radius of the cylinder,
- ${U}_{c}$ is the axial convective velocity of the eddies: it is equal to the product of the axial velocity coefficient and the fluid velocity,
- $U{'}_{c}$ is the orthoradial convective velocity of the eddies. By default this phenomenon is not taken into account because it is seldom observed experimentally. However, it is possible to define it if needed.
- $\lambda$ and $\lambda '$ are the correlation lengths along the axis and in the orthoradial direction respectively.

#### 3.2.3 SPEC_CORR_CONV_3: arbitrary spectrum defined analytically

```text
/    SPEC_CORR_CONV_3
```

Factor keyword making it possible to define a spectrum on the basis of analytical functions.

```text
♦    TABLE_FONCTION= table
```

Concept of type table of functions containing the analytical formulae defining the spectrum.

Example of use: one wishes to describe the pressure forces induced by an axial flow along a fuel rod in the form of a spectrum of “correlation length” type, describing:

- on the one hand the decay of the turbulent energy downstream of the grid,
- on the other hand the phase shift due to the convection of the turbulence with the flow.

The correlation length, and the autospectrum, depend on the frequency. The analytical formulation proposed is as follows:

${S}_{f}(\underline{{r}_{1}},\underline{{r}_{2}},\omega )=\lbrace  \begin{array}{c}{S}_{x}=\exp(-\frac{\mid \underline{{r}_{2}}-\underline{{r}_{1}}\mid }{{\lambda}_{\text{cx}}(\omega )}).\exp(\mathit{j\omega }\frac{{z}_{2}-{z}_{1}}{{U}_{c}}){S}_{f}(\underline{{r}_{1}},\underline{{r}_{1}},\omega )\\ {S}_{y}=\exp(-\frac{\mid \underline{{r}_{2}}-\underline{{r}_{1}}\mid }{{\lambda}_{\text{cy}}(\omega )}).\exp(\mathit{j\omega }\frac{{z}_{2}-{z}_{1}}{{U}_{c}}){S}_{f}(\underline{{r}_{1}},\underline{{r}_{1}},\omega )\end{array}$

$\underline{{r}_{1}}$ and $\underline{{r}_{2}}$ are the vectors locating the positions of the two points to be correlated, $z$  is the direction parallel to the axis of the rod. One may also add, if one wishes, a correlation term between the forces along $x$ and $y$ .

The spectrum above is defined in the test case sdll148b with correlated forces. The modelling with uncorrelated forces is proposed here (no cross terms SXY and SYX). In this test case the rod is oriented along the Y direction.

```python
SXX = FORMULE(NOM_PARA=('X1','Y1','Z1','X2','Y2','Z2','FREQ'),

VALE_C='exp(-FREQ/freq0)*

exp(distance(X1,Y1,Z1,X2,Y2,Z2)/correl(FREQ))*

complex(cos(2*pi*FREQ*(Y2-Y1)/Uc),

sin(2*pi*FREQ*(Y2-Y1)/Uc))',)

SYY = ...

# INTER-SPECTRE AVEC EFFORTS X ET Y DECORRELES

INTESPEC = CREA_TABLE(
    LISTE=(
        _F(LISTE_K=("SXX", "SYY"), PARA="FONCTION_C"),
        _F(LISTE_K=("DX", "DY"), PARA="NUME_ORDRE_I"),
        _F(LISTE_K=("DX", "DY"), PARA="NUME_ORDRE_J"),
    ),
    TYPE_TABLE="TABLE_FONCTION",
    TITRE="EXCITATION FLUIDE TURBULENTE",
)

SPECTRE1 = DEFI_SPEC_TURB(SPEC_CORR_CONV_3=_F(TABLE_FONCTION=INTESPEC))
```

The function distance has been defined in Python and gives the distance between two points of respective coordinates $({x}_{1,}{y}_{1,}{z}_{1})$ and $({x}_{2,}{y}_{2,}{z}_{2})$ . The function correl depends exponentially on the frequency.

**Notes**

The application length $L$ is characterised in an intrinsic manner by the domain of definition of the shape functions associated with the excitation. The application zone is centred about the application node.

The turbulent excitation being liable to be developed in a correlated manner in the two directions orthogonal to the axis of the slender structure (axis $x$), the shape functions are a priori vectors with two components (along* $y$ and $z$).

One therefore defines, for each mode, two shape functions (one along $y$ and one along $z$) over the interval $(0;L)$. The functions are then passed in a table_fonction to the operator DEFI_SPEC_TURB. (cf. test case sdll116a).

Four possible choices corresponding to the various experimental configurations for which the GRAPPE2 excitation was identified:

- AScending flow, CENtred control rod,
- AScending flow, EXCentred control rod,
- DEScending flow, CENtred control rod,
- DEScending flow, EXCentred control rod.

The GRAPPE2 excitation is characterised by a point force and a point moment applied at one and the same node, in a homogeneous manner in the two directions orthogonal to the axis of the slender structure.
