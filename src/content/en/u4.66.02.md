# u4.66.02 Operator CALC_FLUI_STRU

## 1 Purpose

Compute the modal parameters of a structure subjected to a flow. Makes it possible to take into account the fluid-elastic forces, which are represented by a complex transfer matrix relating them to the modal displacements. For certain configurations, the transfer matrix can be decomposed into three real matrices of added mass, damping and stiffness coefficients.

The perturbations of the modal characteristics of the structure depend on the flow velocity. Thus the terms of the transfer matrix of the fluid-elastic forces depend on the fluid velocity and on the frequency of the motion, by means of the reduced-velocity parameter Vr = V/(f.D).

The operator computes a modal basis modified by the coupling, for each mean fluid velocity studied. The concept produced is of type melasflu.

## 2 Syntax

```text
melasflu = CALC_FLUI_STRU(
    ◇ VITE_FLUI = _F(
         ◇ VITE_MIN = float,
         ◇ VITE_MAX = float,
         ◇ NB_POIN = int,
      ),
    ◆ BASE_MODALE = _F(
         ◆ MODE_MECA = mode_meca,
         ◇ NUME_ORDRE = int,
         ◆ | AMOR_REDUIT = float,
           | AMOR_UNIF = float,
           | AMOR_REDUIT_CONN = float,
      ),
    ◆ TYPE_FLUI_STRU = type_flui_stru,
    ◇ IMPRESSION = _F(
         ◇ PARA_COUPLAGE = / "OUI" (par défaut),
                           / "NON",
         ◇ DEFORMEE = / "OUI",
                      / "NON" (par défaut),
      ),
    ◇ STOP_ERREUR = / "OUI" (par défaut),
                    / "NON",
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Keyword VITE_FLUI

```text
◊ VITE_FLUI
```

Factor keyword which makes it possible to define the range of fluid velocities studied and the discretisation.

```text
◊    VITE_MIN    =    vi
```

First value of the velocity for which the coupling parameters are computed.

```text
◊    VITE_MAX    =    vm
```

Last value of the velocity for which the coupling parameters are computed.

```text
◊    NB_POIN    =    np
```

Defines the number of points in velocity (the discretisation step is constant).

### 3.2 Keyword BASE_MODALE

```text
♦    BASE_MODALE
```

Factor keyword which makes it possible to define the modal basis of concept mode_meca for which the coupling parameters are computed. The coupling modifies the eigenfrequencies and the values of the reduced-damping terms associated with each mode (keyword AMOR_REDUIT or AMOR_UNIF).

```text
♦    MODE_MECA                =    mode
```

Modal basis of concept type mode_meca.

```text
◊    NUME_ORDRE            =    l_nuor
```

Makes it possible to select the modes of the modal basis of type mode_meca to be taken into account for the computation of the coupling.

```text
◊    /    AMOR_REDUIT        =    l_amor
```

List of the reduced dampings (percentage of the critical damping) corresponding to each mode of the structure.

**Note:**

*They must be identical in number to the number of modes taken into account (these modes are defined by the keyword* *NUME_ORDRE).*

```text
/    AMOR_UNIF            =    amor
```

One applies to all the modes of the modal basis the same reduced damping.

```text
◊        AMOR_REDUIT_CONN    =    l_amor_c
```

List of the reduced dampings (percentage of the critical damping) corresponding to each mode of the structure for the Connors method (see [R4.07.04]). In accordance with this reference documentation, one supplies two values of the Connors instability ratio (one of them said to be «All components»).

**Note:**

*As for the keyword* *AMOR_REDUIT, they must be identical in number to the number of modes taken into account.*

### 3.3 Keyword TYPE_FLUI_STRU

```text
♦    TYPE_FLUI_STRU = typeflui
```

Concept of type type_flui_stru. It makes it possible to define the configuration studied, that is the coupling coefficients used for the modelling of the fluid-elastic forces.

**Note:**

*In the case of a configuration of the type «tube bundle under axial flow» (factor keyword* FAISCEAU_AXIAL *), the computation of the coupling parameters of the structure with the fluid in the at-rest state is taken into account. This computation is carried out* *whatever the range of fluid velocities that the user has supplied by means of the keyword* VITE_FLUI *.*

*In this case of a fluid at rest, the transfer matrix representing the fluid-elastic force exerted on the structure takes the form of an added-damping matrix.*

### 3.4 Keyword IMPRESSION

```text
◊    IMPRESSION
```

Factor keyword making it possible for the user to choose the information which is to be written in the file RESULTAT.

```text
◊    PARA_COUPLAGE     = 'OUI' ou 'NON'
```

By this keyword, the user may request the printout of tables of results giving, for each mode, the evolutions of the reduced velocity, of the frequency and of the modal reduced damping as a function of the flow velocity of the fluid. The default value is 'OUI'.

```text
◊    DEFORMEE = 'OUI' ou 'NON'
```

By this keyword the user may request the printout, in 'RESULTAT' format, of the displacement fields corresponding to the modal deflected shapes. The default value is 'NON'.

### 3.5 Operand STOP_ERREUR

```text
◊    STOP_ERREUR        =    stop
```

Keyword which makes it possible to define the behaviour of the code in the event of a convergence problem in the computation of the coupling coefficients for a given velocity and a deformation mode of the structure.

If STOP_ERREUR='OUI', the code stops in fatal error in the event of a convergence problem, notifying the user of the velocity concerned.

If STOP_ERREUR='NON', the code emits an alarm notifying the user of the convergence problem (velocity and mode number) and stores the last value computed for the coupling coefficients.

## 4 Notes

In the case of a configuration of the type «tube bundles under transverse flow», it is possible to define several zones of interaction between the fluid and the structure, each of these zones being able to be modelled independently of the others. The computation of the modal parameters of the structure subjected to a flow then takes account of each of these zones, defined explicitly in the command DEFI_FLUI_STRU [U4.25.01](doc:u4.25.01).

The concept produced by CALC_FLUI_STRU contains, in the form of a table, the mass, damping and stiffness matrices for each fluid velocity. The table, representing the modified modal basis, can be recovered by RECU_TABLE in order to be injected into a DYNA_VIBRA analysis. This sequence of analysis is implemented in the test case SDLL118A.
