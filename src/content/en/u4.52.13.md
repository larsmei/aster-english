# u4.52.13 Operator CALC_AMOR_MODAL

## 1 Purpose

Create a list of modal dampings computed according to the RCC-G rule. The analysis is performed in post-processing of the modal analysis of a building-type structure whose raft rests on a soil modelled by springs.

The principle of the analysis is to weight, by the potential-energy ratios (with respect to the total energy), reduced dampings assigned by groups of mesh cells making up the structure (in fact input parameters of the potential-energy table created by POST_ELEM) and dampings radiated into the soil, by degree of freedom, as functions of the frequency [bib1] [bib2] [R4.05.01](doc:r4.05.01).

One also has the alternative possibility of directly creating a list of modal dampings by computed frequency of a concept of type mode_meca. This list depends both on the values of the frequencies of the mode and on the coefficients appearing in the expression of the Rayleigh damping.

A mode of automatic correction of the computed dampings is also available.

The list created can subsequently be used in the command DYNA_VIBRA [U4.53.03](doc:u4.53.03) under the keyword LIST_AMOR.

Produces a concept of type listr8.

## 2 Syntax

```text
listr8 = CALC_AMOR_MODAL(
    ◇ / AMOR_RAYLEIGH = _F(
           ◆ AMOR_ALPHA = float,
           ◆ AMOR_BETA = float,
           ◆ MODE_MECA = mode_meca,
        ),
      / ENER_SOL = _F(
           ◇ METHODE = / "DEPL" (par défaut),
                       / "RIGI_PARASOL",
           ◆ MODE_MECA = mode_meca,
           ◆ / GROUP_NO_RADIER = grno,
             / GROUP_MA_RADIER = grma,
           ◇ / FONC_GROUP = formule / nappe / fonction,
             / COEF_GROUP = float,
           ◆ KX = float,
           ◆ KY = float,
           ◆ KZ = float,
           ◇ & KRX = float,
             & KRY = float,
           ◇ & KRZ = float,
           ◇ / GROUP_NO_CENTRE = grno,
           ◇ / COOR_CENTRE = float,
        ),
    ◇ / AMOR_INTERNE = _F(
           ◆ ENER_POT = table,
           ◆ GROUP_MA = grma,
           ◆ AMOR_REDUIT = float,
        ),
    ◇ / AMOR_SOL = _F(
           ◇ AMOR_REDUIT = float,
           ◆ FONC_AMOR_GEO = formule / nappe / fonction,
           ◇ HOMOGENE = / "OUI" (par défaut),
                        / "NON",
           ◇ SEUIL = float (défaut: 0.3),
        ),
    ◇ CORR_AMOR_NEGATIF = / "NON" (par défaut),
                          / "IGNORE",
                          / "OUI",
    # Si: equal_to("CORR_AMOR_NEGATIF", 'OUI')
        ◆ COEF_CORR_AMOR = float,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Keyword ENER_SOL

This factor keyword, used once only, is used to introduce the data required for the computation of the potential energy in the soil by degree of freedom for all the frequencies of a concept of type mode_meca.

#### 3.1.1 Operand METHODE

This operand makes it possible to define the method of computation of the energy in the soil by frequency.

With the value 'DEPL', one computes the energy from the displacements averaged over the nodes of the raft for each mode: $E=\frac{1}{2}\sum_{i=1,6}{k}_{i}{U}_{i}^{2}{(\mathit{fr})}_{i}$ , where the ${k}_{i}$ represent the 6 components KX, KY, KZ, KRX, KRY and KRZ of the global stiffness of the soil springs (cf. [§3.1.3]).

With the value 'RIGI_PARASOL', one computes the energy from the forces averaged over the nodes of the raft for each mode: $E=\frac{1}{2}\sum_{i=1,6}\frac{{F}_{i}^{2}}{{k}_{i}}{(\mathit{fr})}_{i}$ .

The nodal forces with this method are determined from the stiffness values distributed at the nodes under the raft as by the option RIGI_PARASOL of the command AFFE_CARA_ELEM [U4.42.01](doc:u4.42.01).

#### 3.1.2 Operand MODE_MECA

Makes it possible to introduce the concept of type mode_meca containing the frequencies of computation of the potential energy.

#### 3.1.3 Operands KX / KY / KZ / KRX / KRY / KRZ

Represent the values of the components of the global stiffness of the soil springs.

They appear in the computation of the terms ${k}_{i}.{U}_{i}^{2},i=1,\mathit{NCmp}$ ,

$\mathrm{NCmp}$ is the number of components (3 or 6) determined by the presence or the absence of the operands KRX, KRY, KRZ, used (if they are) mandatorily together. $\mathrm{NCmp}$ and the number of degrees of freedom carried by the nodes of the raft may be different.

In the particular case of a clamped structure, the various components of the stiffness of the soil springs are indicated as being equal to zero so as to cancel the energy associated with the soil. These values are compatible with the default value ‘DEPL’ for the operand METHODE.

#### 3.1.4 Operand GROUP_NO_RADIER

This operand is linked to the value 'DEPL' of the operand METHODE.

List of node groups constituting the raft of the structure resting on the soil. One then computes the averaged displacement at these nodes $U$ of components ${U}_{i}$ for each computed mode of frequency $\mathrm{fr}$ in order to be able to determine the energy in the soil by degree of freedom and by frequency: $\frac{1}{2}{k}_{i}.{U}_{i}^{2}(\mathrm{fr})$ .

#### 3.1.5 Operand GROUP_MA_RADIER

This operand is linked to the value 'RIGI_PARASOL' of the operand METHODE.

List of mesh-cell groups constituting the raft of the structure resting on the soil. Makes it possible to compute the averaged force at the nodes of these mesh cells $F$ of components ${F}_{i}$ for each computed mode of frequency $\mathrm{fr}$ in order to determine the energy in the soil by degree of freedom and by frequency: $\frac{1}{2}\frac{{F}_{i}^{2}}{{k}_{i}}(\mathrm{fr})$ .

#### 3.1.6 Operand FONC_GROUP / COEF_GROUP / GROUP_NO_CENTRE / COOR_CENTRE

These operands are also linked to the value 'RIGI_PARASOL' of the operand METHODE.

They are the same as in the option RIGI_PARASOL of the command AFFE_CARA_ELEM [U4.42.01](doc:u4.42.01). They also make it possible to obtain the stiffness values distributed at the nodes under the raft, used to determine the nodal forces by mode and then their average $F$ of component ${F}_{i}$ .

An operand chosen from FONC_GROUP / COEF_GROUP makes it possible to determine weightings, functions of the abscissa or real, of each of the mesh-cell groups making up the raft. The formulae remain at the user's choice. By default, one considers that the distribution function is constant and equal to one, that is to say that each surface is assigned the same weight [bib2].

One must therefore have as many terms in the corresponding list as in the list of mesh-cell groups given by the operand GROUP_MA_RADIER.

An operand chosen from GROUP_NO_CENTRE / COOR_CENTRE makes it possible to supply either the central node of the raft by a node group of a single node, or directly coordinates locating the central node.

### 3.2 Keyword AMOR_INTERNE

Used once only at the same time as the keyword ENER_SOL.

The contribution to the reduced damping of each mode is established from the distribution of the potential energy in the structure for the mode under consideration. This distribution is obtained using the command POST_ELEM [U4.81.22](doc:u4.81.22) from the concept of type mode_meca (cf. [§3.1.1]) which produces a table.

The input parameters of this table are names of mesh-cell groups, defined by the user according to the distributions of material damping in the structure.

#### 3.2.1 Operand ENER_POT

Name of the potential-energy table produced by the command POST_ELEM [U4.81.22](doc:u4.81.22).

The necessary parameters of the table are:

| **Parameters** | **Type** | **Description** |
| --- | --- | --- |
| NUME_ORDRE | I | Order number |
| FREQ | R | Frequency at the order number NUME_ORDRE |
| LIEU | K8 | Associated geometric entity: it may be the whole structure, a set of mesh cells or mesh-cell groups |
| POUR_CENT | R | Potential-energy ratio with respect to the total energy |

For further information on the meaning of the parameters, the reader is invited to consult the documentation of the command POST_ELEM [U4.81.22](doc:u4.81.22).

#### 3.2.2 Operand GROUP_MA

The list of names of mesh-cell groups from which one will point into the table defined by ENER_POT (cf. [§3.2.1]).

It is imperative that this list contain all the mesh-cell groups making up the structure and that their energy has indeed been computed in the table defined by ENER_POT. One will consider that for each mode the sum of the energies passing through the preceding mesh-cell groups will be equal to the total energy minus that passing through the soil springs and distributed from the keyword ENER_SOL.

If the user indicates a mesh-cell group name whose energy has not been computed in the table defined by ENER_POT, there will be an alarm but no stop. It is therefore indeed up to the user to check the conformity of the mesh-cell groups of the table and of those of the list in the keyword AMOR_INTERNE.

Finally, for the computation of the list of modal dampings according to the RCC-G rule to be meaningful, and in particular so that the energy passing through the soil springs is not negative (which would imply that the potential-energy ratio of the set of mesh-cell groups making up the structure could exceed 100%), it is strongly recommended to impose a rigid-link condition on the list of node groups constituting the raft of the structure resting on the soil.

In order to compute correctly the potential-energy ratio of the constituent mesh-cell groups, it is imperative to have the total energy of the whole model. And for that, upstream, it is mandatory that in the table defined by ENER_POT one has computed the potential energy by the operator POST_ELEM for the entity TOUT=’OUI’. Otherwise, a stop message is issued.

#### 3.2.3 Operand AMOR_REDUIT

The list of the real values of material damping corresponding, term by term, to the list of mesh-cell group names defined by GROUP_MA (cf. [§3.2.2]).

### 3.3 Keyword AMOR_SOL

Used once only at the same time as the keyword ENER_SOL.

It makes it possible to determine the contribution of the geometric damping due to the reflection of the elastic waves. These directional damping values are obtained by interpolating, for each computed eigenfrequency, the geometric damping functions $\frac{\text{Im}(K(\omega ))}{2\text{Re}(K(\omega ))}$ (cf. §[3.3.1]) where $K(\omega )$ is the complex impedance of the soil determined using one of the programs MISS3D, CLASSI or PARASOL:

$\mathrm{amor}({\omega}_{i})=\left[{\omega}_{i},\frac{\text{Im}(K({\omega}_{i}))}{2\text{Re}(K({\omega}_{i}))}\right]$

#### 3.3.1 Operand FONC_AMOR_GEO

Defines the list of functions of frequency of the geometric dampings, one per degree of freedom (3 or 6).

In the framework of a structure on a clamped base, this function must be supplied even if it has no particular meaning. One may take the constant function equal to zero, for example.

#### 3.3.2 Operand AMOR_REDUIT

Correction in the computation of the geometric damping due to the reduced material damping of the soil.

**Note:**

*The reduced-damping value is necessary if the soil impedance is produced by PARASOL. One then assigns the complete value of the reduced material damping of the soil. If the soil impedance is produced by MISS3D, this value is necessary only if the soil is homogeneous (see operand* HOMOGENE [§3.3.3] *) and in that case one introduces half the value of the reduced material damping of the soil.*

#### 3.3.3 Operand HOMOGENE

If the soil is homogeneous ('OUI'), one weights the computation of the geometric damping by the factor 0.5. Then, in the case where the soil impedance is produced by MISS3D and only if the soil is homogeneous ('OUI'), one must introduce for the operand AMOR_REDUIT (cf. [§3.3.2]) half the value of the reduced material damping of the soil. One introduces nothing when the soil impedance is produced by MISS3D if the soil is not homogeneous ('NON').

#### 3.3.4 Operand SEUIL

Value defined in the RCC-G [bib1] (0.3 by default) for the threshold beyond which one possibly truncates the modal damping. This threshold operates after the possible preceding corrections.

### 3.4 Keyword AMOR_RAYLEIGH

Used once only to the exclusion of the keyword ENER_SOL. This keyword makes it possible to compute a list of modal dampings by computed frequency of a concept of type mode_meca. This list depends both on the values of the frequencies of the mode ${\mathrm{freq}}_{i}$ and on the coefficients appearing in the expression of the Rayleigh damping.

#### 3.4.1 Operand MODE_MECA

Makes it possible to introduce the concept of type mode_meca containing the frequencies from which one will compute the modal damping.

#### 3.4.2 Operands AMOR_ALPHA / AMOR_BETA

Represent respectively the values of the components $\alpha$ and $\beta$ appearing in the expression of the Rayleigh damping from the stiffness and mass operators: $C=\alpha K+\beta M$ .

Then for each computed frequency ${\mathrm{freq}}_{i}$ of the concept of type mode_meca $\mathrm{mod}$ associated with an angular frequency ${\omega}_{i}=2\pi {\mathrm{freq}}_{i}$ one obtains an equivalent modal damping:

${\xi}_{i}=\frac{1}{2}(\alpha {\omega}_{i}+\frac{\beta}{{\omega}_{i}})$

#### 3.4.3 Operands CORR_AMOR_NEGATIF / COEF_CORR_AMOR

The keyword CORR_AMOR_NEGATIF makes it possible to check automatically whether there exist negative values in the list of damping coefficients generated by the operator.

If this keyword is equal to 'NON' (default value), then if one detects a negative or zero damping, execution stops in error, with a message indicating the value in question.

If the keyword is equal to 'IGNORE', one acts as previously except that the error is turned into a simple alarm.

Finally, if the keyword is equal to 'OUI', then one replaces the negative or zero values by an arbitrary strictly positive value (and less than 1) defined by the user with the keyword COEF_CORR_AMOR.

## 5 Example of use

The use of CALC_AMOR_MODAL requires the computation of the eigenmodes of the structure on soil springs in the form of a concept of type mode_meca and of a concept of type table_sdaster of these modes computed by means of the command POST_ELEM [U4.61.04](doc:u4.61.04).

The following example is taken from the test SDLL109B.

```text
# CALCUL DES QUANTITES MODALES -----------------------------------------

MODE0=CALC_MODES( MATR_RIGI=RIGIDITE,

MATR_MASS=MASSE,

OPTION = 'PLUS_PETITE',

CALC_FREQ=_F( NMAX_FREQ = 33 ),

SOLVEUR_MODAL=_F( DIM_SOUS_ESPACE = 125 ) )

MODE0=NORM_MODE( reuse=MODE0, MODE=MODE0,

NORME='TRAN_ROTA',

MASS_INER=MASSESTR )

EPOT=POST_ELEM( MODELE=STICKMOD,

RESULTAT=MODE0,

CHAM_MATER=CHAMPMAT,

CARA_ELEM=CARA_ELE,

MASS_INER=(_F(GROUP_MA=('MASSES', 'LIAI_SOL', 'LIAI_NOE',

'POU_D_T',),),

_F(TOUT='OUI',),),)

#

FT=DEFI_FONCTION( NOM_PARA='FREQ',

VALE=( 0., 0.0, 10., 0.3, 30., 1.5, 100., 1.5, ) )

#

FR=DEFI_FONCTION( NOM_PARA='FREQ',

VALE=( 0., 0.0, 10., 0.05, 30., 0.75, 100., 0.75, ) )

L_AMOR=CALC_AMOR_MODAL(

ENER_SOL=_F( MODE_MECA = MODE0,

GROUP_NO_RADIER = 'P1',

KX = 6.295E11, KY = 6.295E11, KZ = 6.864E11,

KRX = 3.188E14, KRY = 3.188E14, KRZ = 3.2E14),

AMOR_INTERNE=_F(

ENER_POT = EPOT,

GROUP_MA = ('POU_D_T', 'MASSES', 'LIAI_NOE',),

AMOR_REDUIT = (0.07, 0.07, 0.02,)),

AMOR_SOL=_F(

FONC_AMOR_GEO = (FT, FT, FT, FR, FR, FR,),

HOMOGENE = 'NON')

)
```
