# v3.03.009 SSLS09 - Cylinder thin under clean weight

**Summary:**

This VPCS (SSLS 09/89) test is intended to test a volume loading (here the clean weight), in axisymmetric analysis, using the keyword FORCE_INTERNE.

This will be done by using both commands: AFFE_CHAR_MECA (modelization A) and AFFE_CHAR_MECA_F (modelization B).

Modelling C tests incompressible elements using the keyword gravity on an equivalent load.

## 2 reference solution

### 2.1 Calculation method used for reference solution

In a point coordinate x:

1. radial displacement: ${U}_{r}=-\frac{\gamma R\nu x}{E}$
2. axial displacement: ${U}_{x}=\frac{\gamma {x}^{2}}{2E}$
3. rotation of a generator: $\psi =-\frac{\gamma R\nu }{E}$
4. axial stress: ${\sigma}_{11}=\gamma x$
5. circumferential constraint: ${\sigma}_{22}=0$

### 2.2 Baseline

1. High axial tip displacement: ${U}_{x}=2.99\times {10}^{-6}m$
2. Low radial end displacement: ${U}_{r}=–4.49\times {10}^{-7}m$
3. $\psi =–1.12\times {10}^{-7}\mathrm{rad}$
4. ${\sigma}_{11}=3.14\times {10}^{5}\mathrm{Pa}$ , at the lower end
5. ${\sigma}_{22}=0$ everywhere

### 2.3 Uncertainty about the solution

analytical solution.

In addition, the incompressible elements results in the same (C Modelling).
