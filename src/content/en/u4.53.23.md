# u4.53.23 Operator DYNA_SPEC_MODAL

## 1 Purpose

Compute the response, by modal recombination, of a linear structure to a random excitation. This excitation is defined in the form of power interspectra of modal forces. The response is established in the form of power interspectra of the generalised displacements.

Each interspectral matrix is associated with a modal basis for which the response is computed. The result produced is a concept of type interspectre.

## 2 Syntax

```text
interspectre = DYNA_SPEC_MODAL(
    ◆ BASE_ELAS_FLUI = melasflu,
    ◆ VITE_FLUI = float,
    ◇ PRECISION = float (défaut: 0.001),
    ◆ EXCIT = _F(
         ◆ INTE_SPEC_GENE = interspectre,
      ),
    ◇ OPTION = / "TOUT" (par défaut),
               / "DIAG",
    ◇ TITRE = text,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand BASE_ELAS_FLUI

♦    BASE_ELAS_FLUI = bef

Concept of type melasflu; it defines a set of modal bases associated with the various flow velocities of the fluid.

### 3.2 Keyword VITE_FLUI

♦    VITE_FLUI = vitefl

Flow velocity of the fluid for the response analysis.

### 3.3 Keyword PRECISION

◊    PRECISION = prec

Accuracy on the flow velocity of the fluid (by default 1 E-3).

### 3.4 Keyword EXCIT

```text
♦    EXCIT
```

Factor keyword which defines the excitation.

```text
♦    INTE_SPEC_GENE = exc
```

Concept of type interspectre; it defines the excitation interspectra (modal forces).

### 3.5 Operand OPTION

```text
◊    OPTION = ’TOUT’ ou ’DIAG’
```

Text argument which indicates whether one wants to compute all the interspectra, 'TOUT', or the auto-spectra only, 'DIAG'. By default all the interspectra are computed.

### 3.6 Operand TITRE

```text
◊    TITRE = titre
```

Text argument defining the title attached to the output concept of type interspectre.
