# u4.82.04 Operator POST_RUPTURE

## 1 Purpose

Carry out post-processings of the result tables coming from the operators CALC_G and POST_K1_K2_K3.

The various possible operations are:

- normalisation of the curvilinear abscissa,
- computation of the bifurcation angle,
- fatigue cycle counting,
- computation of the crack-advance increment in fatigue,
- accumulation of the fatigue cycles,
- driving of the propagation,
- computation of the equivalent stress intensity factor,
- computation of the ${(\Delta K)}_{\mathit{eq}}$ used for variable-amplitude propagation,
- setting to zero of the negative values of the stress intensity factors ${K}_{1}$ and computation of the new energy release rates $G$ and/or ${G}_{\mathit{IRWIN}}$ by Irwin's formula.

Produces a data structure table.

## 2 Syntax

```text
table = POST_RUPTURE(
    ◇ reuse = <objet de TABLE>,
    ◆ TABLE = table,
    ◆ OPERATION = / "ABSC_CURV_NORM",
                  / "ANGLE_BIFURCATION",
                  / "COMPTAGE_CYCLES",
                  / "CUMUL_CYCLES",
                  / "DELTA_K_EQ",
                  / "K1_NEGATIF",
                  / "K_EQ",
                  / "LOI_PROPA",
                  / "PILO_PROPA",
    # Si: equal_to("OPERATION", 'ABSC_CURV_NORM')
        ◇ NOM_PARA = text (défaut: "ABSC_CURV_NORM"),
    # Si: equal_to("OPERATION", 'ANGLE_BIFURCATION')
        ◇ NOM_PARA = text (défaut: "BETA"),
        ◇ CRITERE = / "K1_MAX",
                    / "K2_NUL",
                    / "PLAN",
                    / "SITT_MAX" (par défaut),
                    / "SITT_MAX_DEVER",
        ◇ MATER = mater,
    # Si: equal_to("OPERATION", 'K_EQ')
        ◇ NOM_PARA = text (défaut: "K_EQ"),
        ◇ CUMUL = / "CUMUL_G" (par défaut),
                  / "LINEAIRE",
                  / "MODE_I",
                  / "QUADRATIQUE",
        # Si: is_in("CUMUL", ('QUADRATIQUE','CUMUL_G'))
            ◆ MATER = mater,
    # Si: equal_to("OPERATION", 'DELTA_K_EQ')
        ◇ NOM_PARA = text (défaut: "DELTA_K_EQ"),
        ◇ CUMUL = / "CUMUL_G" (par défaut),
                  / "MODE_I",
                  / "QUADRATIQUE",
        # Si: is_in("CUMUL", ('QUADRATIQUE','CUMUL_G'))
            ◆ MATER = mater,
    # Si: equal_to("OPERATION", 'COMPTAGE_CYCLES')
        ◆ NOM_PARA = text,
        ◆ COMPTAGE = / "NATUREL",
                     / "RAINFLOW",
                     / "RCCM",
                     / "UNITAIRE",
        ◇ DELTA_OSCI = float (défaut: 0.0),
        # Si: equal_to("COMPTAGE", 'UNITAIRE')
            ◆ COEF_MULT_MINI = float,
            ◆ COEF_MULT_MAXI = float,
    # Si: equal_to("OPERATION", 'LOI_PROPA')
        ◇ NOM_PARA = text (défaut: "DELTA_A"),
        ◇ NOM_DELTA_K_EQ = text (défaut: "DELTA_K_EQ"),
        ◆ LOI = "PARIS" (ou non renseigné),
        # Si: equal_to("LOI", 'PARIS')
            ◆ C = float,
            ◆ M = float,
            ◇ DELTA_K_SEUIL = float (défaut: 0.0),
    # Si: equal_to("OPERATION", 'CUMUL_CYCLES')
        ◇ NOM_PARA = text (défaut: "DELTA_A"),
        ◇ CUMUL = "LINEAIRE",
    # Si: equal_to("OPERATION", 'PILO_PROPA')
        ◆ / DELTA_A_MAX = float,
          / DELTA_N = float,
    # Si: equal_to("OPERATION", 'K1_NEGATIF')
        ◆ MODELISATION = / "3D",
                         / "AXIS",
                         / "C_PLAN",
                         / "D_PLAN",
        ◆ MATER = mater,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Generic operands

#### 3.1.1 Operand TABLE

```text
♦    TABLE        =    tab,                                    [table]

Cet opérande permet de choisir la table sur laquelle on effectue les opérations. Cette table provient soit de la commande CALC_G, soit de la commande POST_K1_K2_K3.
```

#### 3.1.2 Operand OPERATION

```text
♦    operation    =    /    'ABSC_CURV_NORM',
/    'ANGLE_BIFURCATION',
/    'LOI_PROPA'

Cet opérande permet de choisir l'opération à effectuer.

Pour une explication des différentes opérations, voir les paragraphes correspondants ci-dessous.
```

### 3.2 Operands for the operation 'ABSC_CURV_NORM'

```text
L'opération 'ABSC_CURV_NORM' crée une nouvelle colonne dans la table en sortie, correspondant à l'abscisse curviligne normée le long du fond de fissure. Pour cela, il est nécessaire que la table en entrée contienne une colonne 'ABSC_CURV'. La table en entrée peut comporter plusieurs fonds de fissure. Elle peut contenir un ou plusieurs instants pour chacun des fonds de fissure.
```

#### 3.2.1 Operand NOM_PARA

```text
◊     NOM_PARA    =    /    'ABSC_CURV_NORM'                        [DEFAUT]
/    nom_para,                                    [TXT]

Cet opérande permet de choisir le nom de la nouvelle colonne créée.
```

### 3.3 Operands for the operation 'ANGLE_BIFURCATION'

```text
L'opération 'ANGLE_BIFURCATION'crée une nouvelle colonne dans la table en sortie, correspondant à l'angle de bifurcation de la fissure qui est donné en degré. La table en entrée peut comporter plusieurs fonds de fissure. Elle peut contenir un ou plusieurs instants pour chacun des fonds de fissure.
```

#### 3.3.1 Operand NOM_PARA

```text
◊     NOM_PARA    =    /    'BETA'                                    [DEFAUT]
/    nom_angle,                                [TXT]

Cet opérande permet de choisir le nom de la nouvelle colonne créée.
```

#### 3.3.2 Operand CRITERE

```text
◊     critere    =    /    'SITT_MAX'                            [DEFAUT]
/    'SITT_MAX_DEVER'

/    'K1_MAX',
/    'K2_NUL',
/    'PLAN',

Cet opérande permet de choisir le critère de calcul de l'angle de bifurcation:
```

- 'SITT_MAX': criterion of the maximum circumferential stress (Maximal Hoop Stress criterion, [R7.02.05 §2.5.2]); this is the default criterion. It is computed from the values of $\mathit{K1}$ and $\mathit{K2}$. It is available in 2D and in 3D.
- 'SITT_MAX_DEVER': criterion of the maximum circumferential stress (Maximal Hoop Stress criterion, [R7.02.13 §2.1]) with account taken of mode III and computation of the twisting angle.
- 'K1_MAX', 'K2_NUL': criteria of Amestoy, Bui and Dang-Van [R7.02.05 §2.5.1]. These 2 criteria are available only in 2D. The angle is given to within 10 degrees.

Caution: it is observed that the criterion 'K2_NUL' does not work for an angle greater than $60°$.

- 'PLAN': defines a zero angle.

### 3.4 Operands for the operation 'K_EQ'

```text
L'opération 'K_EQ'crée une nouvelle colonne dans la table en sortie, correspondant au cumul des modes. Elle peut contenir un ou plusieurs instants, mais le module d'Young et le coefficient de Poisson dans le cas de cumul de type 'CUMUL_G' ou 'QUADRATIQUE' doivent être définis constant en temps.
```

#### 3.4.1 Operand NOM_PARA

```text
◊     NOM_PARA    =    /    'K_EQ'                                    [DEFAUT]
/    nom_cumul,                                [TXT]

Cet opérande permet de choisir le nom de la nouvelle colonne créée.
```

#### 3.4.2 Operand CUMUL

```text
◊     CUMUL    =    /    'CUMUL_G'                            [DEFAUT]
/    'QUADRATIQUE',
/    'LINEAIRE',
/    'MODE_I',

Cet opérande permet de choisir la règle de cumul des mode:
```

- 'CUMUL_G': this is the default combination. It is computed from the energy release rate $G$, from the values of Young's modulus $E$ and from Poisson's ratio $\nu$. It is available in 2D and in 3D.

$\sqrt{\frac{GE}{1-{\nu}^{2}}}$

- 'QUADRATIQUE': This combination is computed from the values of Poisson's ratio $\nu$. It is available in 2D and in 3D.

In 2D, this combination is written:

$\sqrt{{\mathit{K1}}^{2}+{\mathit{K2}}^{2}}$

In 3D, this combination is written:

$\sqrt{{\mathit{K1}}^{2}+{\mathit{K2}}^{2}+\frac{{\mathit{K3}}^{2}}{1-\nu }}$

- 'LINEAIRE':

In 2D, this combination is written:

$max(\mathit{K1},0)+∣\mathit{K2}∣$

In 3D, this combination is written:

$max(\mathit{K1},0)+∣\mathit{K2}∣+0,74∣\mathit{K3}∣$

- 'MODE_I': This combination is available in 2D and in 3D and is written:

$\mathit{K1}$

### 3.5 Operands for the operation 'DELTA_K_EQ'

```text
L'opération 'DELTA_K_EQ'crée une nouvelle colonne dans la table en sortie, correspondant au cumul des modes. Elle peut contenir un ou plusieurs instants, mais le module d'Young et le coefficient de Poisson dans le cas de cumul de type 'CUMUL_G' ou 'QUADRATIQUE' doivent être définis constant en temps.
```

#### 3.5.1 Operand NOM_PARA

```text
◊     NOM_PARA    =    /    'DELTA_K_EQ'                            [DEFAUT]
/    nom_cumul,                            [TXT]

Cet opérande permet de choisir le nom de la nouvelle colonne créée.
```

#### 3.5.2 Operand CUMUL

```text
◊     CUMUL    =    /    'CUMUL_G'                                [DEFAUT]
/    'QUADRATIQUE',
/    'MODE_I',

Cet opérande permet de choisir la règle de cumul des mode:
```

- 'CUMUL_G': this is the default combination. It is computed from the energy release rate $G$, from the values of Young's modulus $E$ and from Poisson's ratio $\nu$. It is available in 2D and in 3D.

$\sqrt{\frac{GE}{1-{\nu}^{2}}}$

- 'QUADRATIQUE': This combination is computed from the values of Poisson's ratio $\nu$. It is available in 2D and in 3D.

In 2D, this combination is written:

$\sqrt{\Delta {\mathit{K1}}^{2}+\Delta {\mathit{K2}}^{2}}$

In 3D, this combination is written:

$\sqrt{\Delta {\mathit{K1}}^{2}+\Delta {\mathit{K2}}^{2}+\frac{{\Delta \mathit{K3}}^{2}}{1-\nu }}$

- 'MODE_I': This combination is available in 2D and in 3D and is written:

$\Delta \mathit{K1}$

### 3.6 Operands for the operation 'COMPTAGE_CYCLES'

```text
L'opération 'COMPTAGE_CYCLES' permet de calculer les cycles liés à l'évolution d'une (ou plusieurs) quantité(s). Cette opération créée une nouvelle table, avec une colonne CYCLES et une colonne correspondant à la variation de la quantité comptée par cycle. La table en entrée peut comporter plusieurs fonds de fissure.
```

#### 3.6.1 Operand NOM_PARA

```text
♦     NOM_PARA    =    /    nom_para,                                [TXT]
```

This operand makes it possible to choose the name of the quantity on which the cycle counting is carried out.

The counting may possibly be carried out on several quantities (for example $\mathit{K1}$, $\mathit{K2}`and :math:$mathit{K3}`), provided that the same number of cycles is found for each quantity.

#### 3.6.2 Operand COMPTAGE

```text
♦     COMPTAGE    =    /    'RAINFLOW',
/    'RCCM',
/    'NATUREL',
/    'UNITAIRE'
```

This operand makes it possible to choose the cycle-counting method. Except for UNITAIRE counting, the command POST_FATIGUE is called. For further information on the counting methods, see the documentation [R7.04.01](doc:r7.04.01). The input table may contain one or several time instants, but corresponding to the same crack front.

UNITAIRE counting is a particular case for linear elastic analyses. In this case, the input table must contain only a single time instant and the variation of the quantity will then be determined by the operands COEF_MULT_MINI and COEF_MULT_MAXI.

#### 3.6.3 Operand DELTA_OSCI

```text
◊     DELTA_OSCI    =    /    0.                                [DEFAUT]
/    delta,                            [R]
```

see documentation [U4.83.01](doc:u4.83.01)

#### 3.6.4 Operands COEF_MULT_MINI and COEF_MULT_MAXI

```text
♦     COEF_MULT_MINI    =    cmini                            [R]

♦     COEF_MULT_MAXI    =    cmaxi                            [R]
```

For unit counting, the variation of the quantity to be counted is the following:

$\Delta q={q}_{u}(\mathit{cmaxi}-\mathit{cmini})$

where $q$ is the quantity to be counted, and ${q}_{u}$ the unit value of this quantity (the only value contained in the input table).

### 3.7 Operands for the operation 'LOI_PROPA'

The operation 'LOI_PROPA' creates a new column in the output table, corresponding to the unit advance (that is, for one cycle) of a crack given a fatigue propagation law. The input table may comprise several crack fronts. It may contain one or several time instants for each of the crack fronts.

#### 3.7.1 Operand NOM_PARA

```text
◊     NOM_PARA        =    /    'DELTA_A'                    [DEFAUT]
/    nom_da,                        [TXT]
```

This operand makes it possible to choose the name of the new column created.

#### 3.7.2 Operands LOI, C, M, NOM_DELTA_K_EQ

```text
♦    /    LOI                =    /    'PARIS'                        [DEFAUT]
/    C                =    c ,                                    [R]
/    m                =    m,                                    [R]
◊    DELTA_K_SEUIL    =    /    0.                                [DEFAUT]
/    val_seuil,                    [R]

◊     NOM_DELTA_K_EQ    =    /    'DELTA_K_EQ'                [DEFAUT]
/    nom_dkeq                        [TXT]
```

The operand LOI makes it possible to specify the fatigue propagation law chosen. For the moment, only Paris's law is available. This law is written:

$\frac{\mathit{da}}{\mathit{dN}}=\mathit{C.}{(\Delta {K}_{\mathit{eq}}-\Delta {K}_{\mathit{seuil}})}^{m}$

where $C$ and $m$ are material coefficients, supplied by the operands C and M. $\Delta {K}_{\mathit{seuil}}$ is the propagation threshold, which can be set by the optional parameter DELTA_K_SEUIL, whose default value is 0. If $\Delta {K}_{\mathit{eq}}\le \Delta {K}_{\mathit{seuil}}$, then the advance is zero.

The column in the input table corresponding to $\Delta {K}_{\mathit{eq}}$ is specified by the operand NOM_DELTA_K_EQ.

The unit advance is then computed ($\Delta N=1$ implicitly):

$\Delta a=\mathit{C.}{(\Delta {K}_{\mathit{eq}}-\Delta {K}_{\mathit{seuil}})}^{m}$

Note:

In pure mode $I$: $\Delta {K}_{\mathit{eq}}$ is equal to $\Delta {K}_{I}$. In mixed mode, $\Delta {K}_{\mathit{eq}}$ may be written ${(\Delta K)}_{\mathit{eq}}$ or else $\Delta ({K}_{\mathit{eq}})$, according to the conventions. These two quantities are generally different. There are, however, situations in which these two quantities are identical:

- in pure mode 1 if $\mathit{K1}$ is always positive,
- in mixed mode, linearly, for a cycle $(0-max)$.

### 3.8 Operands for the operation 'CUMUL_CYCLES'

The operation 'CUMUL_CYCLES' makes it possible to accumulate a quantity previously counted for each cycle by computing the mean over all the cycles. The table created contains all the columns of the initial table, except the column CYCLE. Caution: at a point of the front, the other columns of the table must not vary over the cycles. The name of the column corresponding to the quantity to be accumulated does not change.

The input table may comprise several crack fronts.

#### 3.8.1 Operand NOM_PARA

```text
◊     NOM_PARA    =    /    'DELTA_A'                                    [DEFAUT]
/    nom_da,                                        [TXT]
```

This operand makes it possible to specify the name of the parameter on which the accumulation is carried out. By default, the accumulation is carried out on 'DELTA_A'.

#### 3.8.2 Operand CUMUL

```text
◊     CUMUL    =    'lineaire'                    [DEFAUT]
```

This operand is of no use for the moment, because the only accumulation allowed is the linear accumulation (arithmetic mean over the cycles):

${q}_{\mathit{cumul}}=\frac{1}{N}\sum_{i=1}^{N}{q}_{i}$

where ${q}_{i}$ corresponds to the value for cycle $i$ of the quantity to be accumulated.

### 3.9 Operands for the operation 'PILO_PROPA'

The operation 'PILO_PROPA' makes it possible to drive the propagation of several crack fronts (for the moment, limited to a single crack). The driving is done:

- either by imposing the increment of the number of cycles (driving in cycles);
- or by imposing the increment of maximum advance of the crack front (driving in advance).

This driving takes into account all the points of all the fronts of all the cracks.

The input table must contain the parameter DELTA_A.

#### 3.9.1 Operands delta_A_max and DELTA_N

```text
♦    /    delta_A_max    =    da,                        [R]
/    delta_n        =    dn,                        [R]
```

To drive the propagation in cycles, delta_n is used. This has the effect of multiplying the value of the (unit) advance by a factor $\mathit{dn}$ for all the points of all the fronts of all the cracks.

The other driving mode consists in fixing the increment of maximum advance $\mathit{da}$ via the operand delta_A_maX. First, the point of all the fronts of all the cracks that has the greatest advance is determined. Let $\mathit{damax}$ denote this advance. The number of cycles applied will then be $\frac{\mathit{da}}{\mathit{damax}}$.

### 3.10 Operands for the operation 'K1_NEGATIF'

The operation 'K1_NEGATIF' is intended to treat the points of the front for which the stress intensity factor $\mathit{K1}$ is negative.

For these points where the values of $\mathit{K1}$ are negative, $\mathit{K1}$ is set to zero and the energy release rates $G$ and/or ${G}_{\mathit{IRWIN}}$ are recomputed by Irwin's formula.

If at least one of the two energy release rates is present in the input table, the latter must also contain the parameter $\mathit{K2}`(and :math:$mathit{K3}` in 3D).

The input table may comprise several analysis time instants and several crack fronts.

#### 3.10.1 Operand mODELISATION

```text
♦     MODELISATION    =    /    '3D'
/     'C_PLAN'
/     'D_PLAN'

/ 'AXIS'
```

This operand makes it possible to choose Irwin's formula suited to the type of modelling used.

When :math:`mathit{K1}` is zero, Irwin's formula is:

In 3D:

$G=\frac{1-\nu \mathrm{²}}{E}\mathit{K2²}+\frac{1+\nu }{E}\mathit{K3}\mathrm{²}$

In plane strain and for axisymmetry about the $Y$ axis:

$G=\frac{1-\nu \mathrm{²}}{E}\mathit{K2²}$

In plane stress:

$G=\frac{\mathit{K2²}}{E}$

where $E$ is Young's modulus and $\nu$ Poisson's ratio.

#### 3.10.2 Operand mATER

```text
♦ MATER        =     mat,                                [materiau]
```

This operand recovers the name of the material used for the analyses. The material parameters are then used in Irwin's formula in order to recompute the energy release rate or rates. Young's modulus and Poisson's ratio must be defined as constant in time.
