# v1.03.128 MFRON03 – Code_Aster-MFront Interface Test for Crystal Laws

**Summary:**

This test validates orthotropic behaviours defined using *MFront* in comparison with similar behaviours of *Code_Aster*.

Modelling B: This Modelling allows the validation of the single crystal-integration elasto-visco-plastic model, compared to the MONOCRISTAL model on a hardware point.

Modelling C: This Modelling validates the elasto-visco-plastic model with implicit integration, and complete definition of the sliding system family and interaction matrix, compared to MONOCRISTAL Code_Aster on a 10 grain aggregate.

Modelling D: This Modelling allows the validation of the polycrystalline elasto-visco-plastic model with explicit integration, compared to the POLYCRISTAL model on a material point with 30 grains.

Modelling E: This Modelling validates the DD_CFC single crystallized elasto-visco-plastic model on a hardware point.

Modelling F: This Modelling allows the validation of the homogenized DD_CFC polycrystalline elasto-visco-plastic model on a material point with 30 grains.

Modelling G: This Modelling validates the DD_CFC_IRRA single crystallized elasto-visco-plastic model on a hardware point.

H Modelling: This Modelling validates the homogenized DD_CC monocrystalline elasto-visco-plastic model on a hardware point.

Modelling I: This Modelling validates the DD_CC_IRRA single crystallized elasto-visco-plastic model on a hardware point.

Modelling K: This Modelling allows the validation of the homogenized DD_CC polycrystalline elasto-visco-plastic model on a material point with 30 grains.

L Modelling: like Modelling C but with elements HHO

## 1 Reference problem
