# 1 **u4.01.02** New features and changes in the commands

**Summary:**

The purpose of this document is to give an overall view of the syntax changes and of the new possibilities of the *Code_Aster* commands between two stabilised versions.

This update thus reports the changes introduced since **version 6.3** of April 2002 and valid for **version 6.4** of November 2002.

For further details, consult the command documentation and the histor file of the corresponding sub-version (e.g.: [6.3.12], *Development* section of the site www.code-aster.org).

The commands affected are listed in alphabetical order.

## 1 New features between versions 6.3 and 6.4

### 1.1 New commands

#### 1.1.1 GENE_MATR_ALEA

This command makes it possible to produce random symmetric positive-definite matrices from a mean matrix and an uncertainty level. Three probability distributions are available (cf. [6.3.12]).

#### 1.1.2 GENE_VARI_ALEA

Same purpose as the previous command, for real variables (cf. [6.3.12]).

#### 1.1.3 LIRE_TABLE

This new command makes it possible to re-read a table which has been printed by IMPR_TABLE (cf. [6.3.13]).

#### 1.1.4 MACR_LIGN_COUPE

This macro facilitates the post-processing of mechanical and thermal results by extracting the values of a field at the nodes on a cutting line (mesh of segments) (cf. [6.3.14]).

#### 1.1.5 MACR_RECAL

This macro makes it possible to carry out recalibration in *Code_Aster*: the macro determines the parameters of an analysis which best describe the tests (cf. [6.3.18]).

### 1.2 Modified commands

#### 1.2.1 AFFE_CHAR_MECA

**LIAISON_UNIL_NO** **removed:**

- The functionalities are now available under the keyword CONTACT, with the exception of TRESCA friction, which is no longer available (cf. [6.3.17]).

**REAC_GEOM new,** **REAC_GEOM_INTE** **removed:**

- The keyword REAC_GEOM makes it possible to control the geometric updating of the contact algorithm; it takes the value SANS, AUTOMATIQUE or CONTROLE. In the latter case, the imposed number of updates NB_REAC_GEOM must be specified (cf. [6.3.10]).

**STOP_SINGULIER** **new:**

- This offers the possibility of continuing the solution even if a singular matrix is detected (the validity of the solution being conditional on the check of equilibrium) (cf. [6.3.16]).

**PROJECTION=’QUADRATIQUE’** **new:**

- When the elements in contact are quadratic, this projection makes it possible to compute the gap exactly (cf. [6.3.12]).

**DIRE_APPA** **new:**

- For the continuous method, the user thus imposes the search direction for the pairing (cf. [6.3.14]).

**INTEGRATION=(’SIMPSON’,’SIMPSON1’,’SIMPSON2’)** **new possible values:**

- For the continuous method, this makes it possible to specify the type of integration required (cf. [6.3.14]).

#### 1.2.2 AFFE_MODELE

**Modellings** **2D_CONTACT, 3D_CONTACT** **removed:**

- These modellings were applied on the contact elements, which have been withdrawn (see also AFFE_CHAR_MECA, cf. [6.3.17]).

**Modellings** **CONT_DVP_2D, CONT_DVP_3D** **removed:**

- The user is no longer obliged to assign the modellings related to the contact algorithm he has chosen; the code does it itself (these modellings relate to the continuous method).

**Modellings** **3D_THVD, AXIS_THVD, D_PLAN_THVD new:**

- New thermo-hydraulic modellings (without mechanics) for storage studies (cf. STAT_NON_LINE and [6.3.15]).

**Modellings** ***_HMD, *_HHHD, *_THHD, *_THHMD, *_THMD** **new:**

- New diagonal THM modellings (cf. [6.3.15]).

#### 1.2.3 CALC_ELEM

**VARI_ELNO_COQU new option:**

- The option VARI_ELNO_COQU computes the internal variables in a layer of COQUE, GRILLE or DKT elements (keyword NIVE_COUCHE) from the internal variables computed during a non-linear analysis (cf. [6.3.2]).

**VALE_NCOU_MAXI new option, keywords** **NOM_CHAM** **and** **NOM_CMP** **associated:**

- This option makes it possible to extract the extreme values of the component of a field defined on pipe elements, as well as their location (cf. [6.3.19]).

**CRIT_ELNO_RUPT new option:**

- This option computes 6 failure criteria in orthotropic materials (cf. [6.3.7]).

**ETOT_ELGA, ETOT_ELNO_ELGA, ETOT_ELEM new options:**

- These options compute the total energy density at the integration points (ETOT_ELGA), at the nodes (ETOT_ELNO_ELGA) and the total energy density integrated over the elements (ETOT_ELEM) (cf. [6.3.17]).

**TEMP_INIT removed:**

- This keyword was not used (cf. [6.3.3]).

#### 1.2.4 CALC_FATIGUE

**TYPE_CALCUL new:**

- Makes it possible to choose the type of fatigue analysis requested; it takes the value CUMUL_DOMMAGE or FATIGUE_MULTI.

**Keywords** **RESULTAT, CHAM_MATER, CRITERE, METHODE** **new:**

- To determine the plane in which the shear is maximum in a multiaxial fatigue analysis (FATIGUE_MULTI, cf. [6.3.9]).

#### 1.2.5 CALC_FONCTION

**PUISSANCE** **new:**

- Makes it possible to compute the n-th power of a function (cf. [6.3.12]).

**NORME** **new:**

- Computes the L2 norm of a function (cf. [6.3.12]).

**CORR_ACCE new:**

- Makes it possible to correct a real accelerogram (cf. [6.3.2]).

**LISS_ENVELOP new:**

- Computes the smoothed envelope spectrum from a raw spectrum (cf. [6.3.16]).

#### 1.2.6 CALC_G_THETA_T

**FOND_FISS new:**

- Formerly FOND, in order to standardise the vocabulary with the other CALC_G_* commands (cf. [6.3.10]).

#### 1.2.7 CALC_META

**ETAT_INIT / INST_INIT new:**

- On a restart, this keyword makes it possible to define the time instant from which the analysis will be continued (cf. [6.3.19]).

#### 1.2.8 CALC_THETA

**FOND_FISS new:**

- Same as CALC_G_THETA_T.

#### 1.2.9 COMB_MATR_ASSE

**CALC_AMOR_GENE new:**

- This builds an object MATR_ASSE_GENE corresponding to the BASILE damping matrix from a list of reduced dampings (cf. [6.3.19]).

#### 1.2.10 COMB_SISM_MODAL

**COMB_DEPL_APPUI new:**

- This keyword makes it possible to compute the responses to the primary loadings (seismic excitation) and to the secondary loadings (due to differential anchorage displacements). NUME_CAS must be defined under DEPL_MULT_APPUI (cf. [6.3.8]).

#### 1.2.11 DEBUT

**CODE / NIV_PUB_WEB new:**

- Under the keyword CODE (for the test cases), NIV_PUB_WEB defines the dissemination level of the test on the *Code_Aster* website (cf. [6.3.6]).

#### 1.2.12 DEFI_MATERIAU

**TEMP_DEF_ALPHA mandatory:**

- The presence of this keyword is now mandatory if the expansion coefficient ALPHA depends on the temperature (cf. [6.3.3]).

**Constitutive laws removed:**

- The following constitutive laws have been removed from the code because of their lack of qualification (cf. [6.3.25]): OHNO, VISCOCHAB, VENDOCHAB, LMARC, NADAI_B, SURF_ETAT_SATU, SURF_ETAT_NSAT, CAM_CLAY_THM, LIQU_SATU_GAT, LIQU_NSAT_GAT.

**EFFO_N_INIT modified:**

- This parameter, used with the discrete elements, may now depend on the temperature (cf. [6.3.19]).

**BAZANT_FD new:**

- Bazant desiccation-creep model (creep due to the drying of concrete under mechanical loading) (cf. [6.3.13]).

**MAZARS_FO new:**

- Mazars model making it possible to take into account the variation of the coefficients with respect to temperature (cf. [6.3.18]).

#### 1.2.13 DYNA_NON_LINE and STAT_NON_LINE

See DEFI_MATERIAU for the constitutive laws removed and added.

**KIT_THV new:**

- New relation, without mechanics, for storage studies. The degrees of freedom are the temperature and the water pressure; the vapour pressure is an internal variable (cf. [6.3.15]).

#### 1.2.14 EXTR_RESU

**SENSIBILITE** **new:**

- This makes it possible to exploit the derived quantities when extracting a result (cf. [6.3.1]).

#### 1.2.15 IMPR_TABLE

**FORMAT=’ASTER’** **new:**

- This keyword makes it possible to print a table in Aster format; see also LIRE_TABLE (cf. [6.3.13]).

#### 1.2.16 LIRE_MAILLAGE

**VERI_MAIL by default:**

- By default, the mesh check is activated (orphan nodes, duplicate mesh cells, flattened mesh cells…) (cf. [6.3.3]).

#### 1.2.17 LIRE_MISS_3D

**NOM** **new:**

- This makes it possible to define the name of the file to be read (cf. [6.3.12]).

#### 1.2.18 LIRE_RESU

**MATR_A, MATR_B** **new:**

- Behind these keywords one supplies the stiffness and mass matrices in order to be able to re-read (and test) a mode obtained by DYNA_TRAN_MODAL (cf. [6.3.19]).

**FORMAT=’MED’** **new:**

- This makes it possible to re-read results in MED format (recommended for exchanges between EDF/CEA analysis codes). For the moment, only fields at the nodes are processed (cf. [6.3.2]).

Associated simple keywords: NOM_MED, NOM_CMP, NOM_CMP_MED, NOM_CMP_IDEM, NOM_MAIL_MED, UNITE.

**DATASET_58** **new:**

- This format makes it possible to re-read the data supplied by experimental measurement software (cf. [6.3.8]).

#### 1.2.19 MACR_ADAP_MAIL and MACR_INFO_CALC

**VERSION_HOMARD new default value:**

- The default version of HOMARD is now V5_5.

#### 1.2.20 MACR_ASCOUF_CALC and MACR_ASPIC_CALC

**PRESS_LEVRE new:**

- This keyword makes it possible to apply or not the internal pressure on the lips of a surface-breaking crack on the inner skin (cf. [6.3.19]).

#### 1.2.21 MECA_STATIQUE

**SIEF_ELGA_DEPL by default:**

- This option is now computed by default. One may specify OPTION=’SANS’ if one does not wish it (cf. [6.3.19]).

#### 1.2.22 MODI_MAILLAGE

**MODI_BASE new:**

- Makes it possible to impose a change of frame (cf. [6.3.18]).

**TRANSLATION, ROTATION, ECHELLE** **new:**

- These keywords make it possible to carry out translations, rotations and scaling of a mesh (cf. [6.3.18]).

#### 1.2.23 POST_K1_K2_K3

**FOND_FISS new:**

- See CALC_G_THETA_T.

**TOUT_ORDRE, NUME_ORDRE, LIST_ORDRE new:**

- The data setup is modified; the command itself will explore the result data structure (cf. [6.3.4]).

#### 1.2.24 POST_RCCM

**OPTION=’FATIGUE_B3200’** **new:**

- Fatigue analysis of a sound piping line according to the RCCM code §B3200 (cf. [6.3.19]).

**OPTION=’FATIGUE_B3600’** **new:**

- Fatigue analysis of a sound piping line according to the RCCM code §B3600 (cf. [6.3.16]).

#### 1.2.25 PRE_GMSH

**MODI_QUAD new:**

- Produces quadratic mesh cells before converting the GMSH mesh to ASTER format (cf. [6.3.7]).

#### 1.2.26 PROJ_MESU_MODAL

**The syntax has been thoroughly reworked and its possibilities extended.**

- See the documentation of the command and the test cases sdld104 and sdlv122 (cf. [6.3.18]).

### 2.2 Withdrawn command

**MACRO_CHAR_F_U** is removed. The functionality is covered by the piloting specific to the limit analysis ANA_LIM of STAT_NON_LINE (cf. [6.2.17]).

### 2.3 Changes of convention

- **ANGL_REP** under the factor keyword COQUE in AFFE_CARA_ELEM: change of sign of the angle  (see AFFE_CARA_ELEM) (cf. [6.2.14]),
- **NU_LT** becomes **NU_TL** and conversely (see DEFI_MATERIAU) in ELAS_ORTH,
- Coefficient ½ in the computation of the thermal contribution of **ENER_POT** (see CALC_ELEM and POST_ELEM, cf. [6.2.13]).

### 2.4 Modified commands

#### 2.4.1 AFFE_CARA_ELEM

**AFFE_SECT,** **AFFE_FIBRE new:**

- Make it possible to describe the section of a multi-fibre beam element from a 2D mesh (factor keyword AFFE_SECT) or directly by defining the fibres one by one (keyword AFFE_FIBRE, cf. [6.2.6]).

**COQUE / ANGL_REP** **modified:**

- The convention used here was contrary to those adopted for the beams and for the definition of the orthotropy frames. The sign of the second angle defined by ANGL_REP is therefore reversed; it is the nautical-angle convention (cf. [6.2.14]).

**COQUE_NCOU,** **GRILLE_NCOU,** **TUYAU_NSEC and** **TUYAU_NCOU new:**

- Under the factor keywords COQUE, GRILLE and POUTRE, to describe the subdivision of a shell/plate into layers, and of a pipe into layers and angular sectors. They were previously supplied under STAT_NON_LINE (cf. [6.2.6]).

**DIST_N** **removed:**

- Replaced by EXCENTREMENT (cf. [6.2.30]).

#### 2.4.2 AFFE_CHAR_MECA

**ARLEQUIN / CARA_ELEM new:**

- To supply the characteristics of the shell in the case of a junction between a 3D model and a shell model (cf. [6.2.28]).

**GONF** **new:**

- Makes it possible to impose incompressibility on the new incompressible elements (cf. [6.2.17]).

#### 2.4.3 AFFE_MODELE

**AFFE / PHENOMENE** **and** **AFFE / MODELISATION** **new possibilities:**

- Removal of the phenomenon NON_LOCAL, and addition, in the phenomenon MECANIQUE, of the non-local constitutive laws regularised on the strain, and of the associated modellings: 3D_GRAD_EPSI, D_PLAN_GRAD_EPSI, C_PLAN_GRAD_EPSI, AXIS_GRAD_EPSI, and of the modellings associated with the formulation with gradients of internal variables 3D_GRAD_VARI, D_PLAN_GRAD_VARI, C_PLAN_GRAD_VARI, AXIS_GRAD_VARI (cf. [6.2.20]).
- New modelling PLAN_FISSURE associated with the finite elements of CZM type (joints), making it possible to treat crack propagation with a constitutive law of Barenblatt type (cf. [6.2.26]).
- New modellings 3D_INCO, D_PLAN_INCO (replaces PLAN_INCO), C_PLAN_INCO associated with the three-field formulation of the new incompressible element (displacement, pressure, swelling, cf. [6.2.17]).
- New lumped modellings in THM: 3D_HHMD, 3D_HMD, 3D_THHD, 3D_THHMD, 3D_THMD, AXIS_HHMD, AXIS_HMD, AXIS_THHD, AXIS_THHMD, AXIS_THMD, D_PLAN_HHMD, D_PLAN_HMD, D_PLAN_THHD, D_PLAN_THHMD, D_PLAN_THMD (integration points brought back to the vertices of the elements, cf. [6.2.25]).
- New modellings POU_D_EM (straight Euler beam) and POU_D_TGM (straight Timoshenko beam with warping) associated with multi-fibre beams (cf. [6.2.6]).

**AFFE / MODELISATION** **change of name:**

- The modelling TUYAU is no longer accessible; it is replaced by TUYAU_3M (cf. [6.2.30]).

#### 2.4.4 AIDE

**COMMANDE** **removed:**

- This functionality is no longer available (it had no longer worked since version 6.0).

#### 2.4.5 CALC_ELEM

**EPOT_ELEM_DEPL modified:**

- Standardisation of the computation of the potential energy (removal of the ½ for the thermal contribution to the strain-energy term) and addition of the thermal-expansion term for the structural elements (cf. [6.2.22]).

**SENSIBILITE / THETA** **removed:**

- SENSIBILITE is now a simple keyword which receives the list of the sensitive parameters; THETA is replaced by PARM_THETA (cf. [6.2.1]).

**PARM_THETA new:**

- Recalls the value of the parameter of the theta-method used to solve the transient thermal analysis; default value: 0.57.

**ERTH_ELEM_TEMP and** **ERTH_ELNO_ELEM new:**

- Options associated with the residual error estimator in thermal analysis (cf. [6.2.1]).

**INFO** **new:**

- Makes it possible to obtain details on the analyses carried out (in particular for sensitivity, cf. [6.2.1]).

**DLSI_ELGA_DEPL removed:**

- This option is removed. The computation of the Lagrangian derivative is now activated by the analysis operator (MECA_STATIQUE, STAT_NON_LINE, THER_LINEAIRE) when the keyword SENSIBILITE is activated.

#### 2.4.6 CALC_MATR_ELEM

**MASS_ID_MDEP_R,** **MASS_ID_MTEM_R,** **MASS_ID_MDNS_R,** **MASS_ID_MTNS_R** **new:**

- Options making it possible to compute an identity matrix (of the displacements or temperatures, symmetric or non-symmetric) on finite elements in order to compute the eigenvalues of a stiffness matrix or other matrix (cf. [6.2.9]).

#### 2.4.7 CALC_NO

**SENSIBILITE** **new:**

- List of the sensitive parameters (cf. [6.2.1]).

**DLDE_NOEU,** **DLSI_NOEU_DLDE,** **DLTE_NOEU removed:**

- The computation of these options is no longer available. The computation of the Lagrangian derivative is now supplied by the analysis operator (MECA_STATIQUE, STAT_NON_LINE, THER_LINEAIRE) when the keyword SENSIBILITE is activated.

#### 2.4.8 COMB_SISM_MODAL

**TYPE_COMBI replacement:**

- This keyword replaces TYPE, which was removed in version 6.4; possible values: QUAD, LINE, ABS (cf. [6.2.26]).

#### 2.4.9 CREA_RESU

**OPERATION** **new:**

- Defines the operation to be carried out, among AFFE, ECLA_PG, PERM_CHAM, PROL_RTZ (cf. [6.2.12]).

**NUME_ORDRE_INIT removed:**

**PRECISION,** **CRITERE** **new:**

- The user no longer supplies a sequence number; access is made directly from the value of the time instant, possibly supplying a PRECISION and a CRITERE (cf. [6.2.21]).

#### 2.4.10 DEFI_BASE_MODALE

**DIAG_MASS new:**

- This option makes it possible to create a modal basis containing the static modes and the dynamic modes; the static modes are such that the mass matrix projected onto this basis is diagonal (cf. [6.2.11]).

#### 2.4.11 DEFI_FONC_ELEC

**INST_CC_INIT** **mandatory:**

- This keyword is now mandatory (cf. [6.2.14]).

#### 2.4.12 DEFI_GROUP

**CRIT_NOEUD new:**

- Makes it possible to define, from a mesh-cell group, a node group consisting only of the SOMMET nodes, the MILIEU nodes, or the CENTRE nodes (cf. [6.2.17]).

#### 2.4.13 DEFI_MATERIAU

**NU_LT** **modified:**

- In ELAS_ORTH, the Batoz convention is adopted, namely: NU_LT / E_L = NU_TL / E_T, as in DEFI_COQU_MULT (cf. [6.2.13]).

**ROUSS_VISC new:**

- Rousselier model extended to viscoplasticity; parameters SIGM_0, EPSI_0 and M (cf. [6.2.10]).

**FLU_IRRA** **new:**

- Modification of the law ASSE_COMBU in order to take into account a dependence of creep with respect to fluence. Keywords: QSR_K, BETA, PHI_ZERO and L (cf. [6.2.9] and [6.2.13]).

**LABORD_1D** **new:**

- New damageable 1D constitutive law for concrete (cf. [6.2.6]).

**MAZARS** **new:**

- New damageable constitutive law for concrete (cf. [6.2.25]).

**CAM_CLAY** **new:**

- New elastoplastic constitutive law for porous media (soils, porous joints, cf. [6.2.25]).

**LAIGLE** **new:**

- New constitutive law in rock mechanics (cf. [6.2.25]).

**RUPT_FRAG modification:**

- New keywords SIGM_C and SAUT_C to treat crack propagation with the CZM elements (cf. [6.2.26]).

**NORTON_HOFF removed:**

- The new incompressible finite elements offer the same functionality by using only the yield limit (cf. [6.2.17]).

#### 2.4.14 DYNA_LINE_HARM

**SENSIBILITE** **new:**

- List of the sensitive parameters (cf. [6.2.1]).

#### 2.4.15 DYNA_NON_LINE and STAT_NON_LINE

**ENDO_ISOT_BETON new:**

- Replaces the behaviours BETON_ENDO_LOCAL and BETON_GRAD_EPSI, which are removed (cf. [6.2.25]).

**ENDO_FRAGILE new:**

- Replaces the behaviour ENDO_LOCAL and ENDO_GRAD_EPSI (cf. [6.2.25]).

**PLAS_GRAD_LINE,** **PLAS_GRAD_TRAC removed:**

- The laws specific to non-local behaviour are removed; in the present cases one uses respectively VMIS_ISOT_LINE and VMIS_ISOT_TRAC. Associated with a modelling *_GRAD_EPSI or *_GRAD_VARI in AFFE_MODELE (cf. [6.2.22]).

**LABORD_1D,** **MAZARS,** **BARENBLATT,** **ROUSS_VISC,** **CAM_CLAY,** **LAIGLE** **new:**

- New behaviours (see DEFI_MATERIAU).

**SENSIBILITE** **new:**

- List of the sensitive parameters (cf. [6.2.1]).

**INCREMENT / OPTI_LIST_INST,** **NOM_CHAM,** **NOM_CMP,** **VALE** **new:**

- Under the factor keyword INCREMENT, these new keywords define the options of the automatic subdivision of the time step (cf. [6.2.21]).

**RHO** **replaced:**

- The penalty coefficient of the augmented Lagrangian is now supplied under the keyword R (cf. [6.2.22]).

**MODELE_NON_LOCAL** **removed:**

- This keyword no longer exists; non-local behaviour is activated directly from the choice of the elements in AFFE_MODELE (cf. [6.2.22]).

**TUYAU_NCOU,** **TUYAU_NSEC,** **COQUE_NCOU removed:**

- These characteristics are now supplied in AFFE_CARA_ELEM (cf. [6.2.6]).

**HYDR** **removed:**

- To use the behaviour HYDR, one must override the code in development mode with the routines PERMEA and SATURA, or use HYDR_UTIL with the definition of the material parameters in DEFI_MATERIAU (cf. [6.2.19]).

#### 2.4.16 EXTR_RESU

**NOM_CHAMP** **new:**
