# v2.02.125 SDLL125 - Rotating beam with 2 non-symmetric discs and 2 bearings subject to gyroscopy

**Summary:**

This test validates the calculation of the rotational modes of a tree system rotating on the $Z$ rotational axis with the CALC_MODE_ROTATION control and shows the instability. This validation concerns both positive rotational speeds (modelization A) and negative rotational speeds (modelization B). Modelling C, on the other hand, validates the consideration of a tree system rotating on the $Y$ rotational axis.

In this test, a rotor model with two discs, supported by two hydrodynamic bearings, is used, with non-symmetric stiffness and damping matrices, and the corresponding reference results are taken from the ROTORINSA qualification manual, [bib2], finished elements software to predict dynamic bending rotor behaviour.

A good match is observed between the Code_Aster and reference solution results.

## 1 Reference problem

### 1.1 Geometry

A rotor model supported by 2 bearings (nodes $\mathrm{B1}$ and $\mathrm{B2}$ in the figure below), with stiffness and damping matrices not symmetrical. It is composed of 3 discs, and 3 shaft sections.

### 1.3 boundary conditions

To block rigid body-type movements in the $Z$ direction, the degree of freedom $\mathit{DZ}$ is blocked at node $\mathrm{B1}$ bearing.

## 2 reference solution

### 2.1 Method of calculation

The reference results are given by ROTORINSA, a finite elements code designed to predict the dynamic behaviour of flexing rotors. The following parameters were used for the reference results:

- The calculation is for a number of $\mathrm{NVES}=8+4$ rotation modes in ROTORINSA.
- The rotation speed range is defined from $0$ to $60000\mathrm{tr}/\mathrm{mn}$ with a $5000\mathrm{tr}/\mathrm{mn}$ pitch.

### 2.2 Quantities and reference results

The ROTORINSA results give the bending mode frequencies.

The calculation of the rotational modes is done with Code_Aster using the same Modelling as ROTORINSA. The results of Code_Aster give both the frequencies of the bending, twisting and tensile/compression modes. The number of modes calculated is 20.

### 2.3 Bibliographical references

  1. LALANNE, G. FERRARIS, "Rotordynamics Prediction in Engineering", Second Edition, Wiley, 2001.
2. ROTORINSA, finished elements software designed to predict dynamic bending rotor behavior, LaMCoS UMR5259, INSA-Lyon.
