# v4.43.001 TPNV01 - Hollow sphere: convection, radiation

**Summary:**

This test is based on the independent validation of version 3 in nonlinear steady-state thermal analysis.

This is a volume problem represented by two modellings, one 3D, the other axisymmetric.

The functions tested are as follows:

- 3D thermal element,
- element thermal axisymmetric,
- limit conditions of convection and radiation.

The value of the test lies in the consideration of radiation.

The results are compared with an analytical solution on an VPCS test.

## 2 reference solution

### 2.1 Calculation method used for reference solution

$T(r)=\frac{{T}_{e}-{T}_{i}}{\frac{1}{{R}_{e}}-\frac{1}{{R}_{i}}}\frac{1}{r}+\frac{\frac{{T}_{i}}{{R}_{e}}-\frac{{T}_{e}}{{R}_{i}}}{\frac{1}{{R}_{e}}-\frac{1}{{R}_{i}}}$

${\varphi}_{e}={h}_{e}({T}_{e}-{T}_{e}^{e})$ **,** $\phi =4\pi {R}_{e}^{2}{h}_{e}({T}_{e}-{T}_{e}^{e})$ **éq** 2.1-1

$\begin{array}{}{\varphi}_{i}=\sigma \varepsilon \left[{({T}_{i}^{e}+273.15)}^{4}-{({T}_{i}+273.15)}^{4}\right]\\ \phi =4\pi {R}_{i}^{2}\sigma \varepsilon \left[{({T}_{i}^{e}+273.15)}^{4}-{({T}_{i}+273.15)}^{4}\right]\end{array}$ **éq** 2.1-2

$\phi =4\pi {r}^{2}\varphi =\mathrm{constante}$ $\phi =4\pi \lambda \frac{{T}_{e}-{T}_{i}}{1/{R}_{e}-1/{R}_{i}}$ **éq** 2.1-3

$\sigma =5.73.{10}^{-8}W/{m}^{2}{K}^{4}$ (Stefan constant) with $T$ in $°C$

Reference temperatures are obtained by numerically solving by the Newton method a 4th degree equation in ${T}_{i}$ obtained from equations [eq 2.1-1] [eq 2.1-2] and [eq 2.1-3].

## 8 Summary of the results

The reference results provided by VPCS are incorrect. New reference results were determined from an analytical approach.

The results obtained are satisfactory. the difference maximum is:

- Model A (3D: HEXA20, PENTA15): 0.026% for temperature and 0.076% for fluxes,
- Model B (AXIS: QUAD4, TRIA3): 0.022% for temperature and 0.16% for fluxes.
- Modelling C (3D_HHO linear): 0.026% for temperature and 0.076% for fluxes,

The radiation limit condition was imposed via a nonlinear flow loading (temperature function flux). In this test the radiation consideration is quite correct.

This test allowed testing the AFFE_CHAR_THER_F command (associated with FLUX_NL operand which allows to affect a non-linear flow) in AXIS and 3D Modelling cases.
