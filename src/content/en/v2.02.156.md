# v2.02.156 SDLL156 - Sismic response using simplified method Tee rock

**Summary:**

The objective of this test is to validate the POST_ROCHE command on an elementary case of a te junction. The section is constant.

## 1 Reference problem

### 1.1 Geometry

An external $10\mathit{mm}$ hollow pipe, $5\mathit{mm}$ Tee Thickness, $2m$ Length and $1m$ Height is considered.

![Figure](/figures/v2.02.156/100002010000023D000000E8A8D7E9A8158CF827.png)

### 1.2 Material properties

The material is elastic isotropic with properties of:

- $E=200\mathit{GPa}$
- $\nu =0.3$
- $\rho=7800\mathit{kg}/{m}^{3}$
- $\alpha =1.2E-5{K}^{-1}$

The law of Ramberg Osgood used for post-processings ssss:

${ϵ}_{p}=K{(\frac{\sigma}{E})}^{1/n}$

With:

- $K=0.01$
- $n=2$

### 1.3 Boundary conditions and loads

An elastic set of calculations is performed independently on the beam structure.

![Figure](/figures/v2.02.156/100002010000019C000000F6AE4CBC0389F92592.png)

#### 1.3.1 Own weight

A $g=9.81m/{s}^{2}$ gravity field is imposed in the $-Z$ direction. The point $A$ is clamped.

#### 1.3.2 Movement imposed

The point $A$ is clamped. The structure is twisted to point $B$ via an angle imposed $\theta =0.02\mathit{rad}$ on the $X$ axis.

#### 1.3.3 Thermal dilation

The point $A$ is clamped. The point $C$ is blocked on the $Z$ axis. A change in the $\Delta T=100K$ temperature field generates bending in the beam on the $Y$ axis.

#### 1.3.4 Pressure imposed

The pressure inside the $P=1\mathit{MPa}$ pipe is taken into account.

#### 1.3.5 Spectral seismic

No inertial seismic loads taken into account in this test case.

Only DDS loading is taken into account.

## 3 Modelling A

### 3.1 Modelling characteristics

POU_D_T modelling is used.

### 3.2 Mesh characteristics

The mesh contains 3 elements of type SEG2.

### 3.3 Tested quantities and results

Quantities output from POST_ROCHE is tested for non-time-dependent moments (keyword factor RESU_MECA).

**Applyed loadings** are combinations of the following two or more loads:

- Own weight
- Thermal dilation (DILAT THERM)
- Seismic loadings:

  - Imposed displacements type DDS (Simic Differential Movements)
- Internal pressure

Since this is computer validation (by an external algorithm to Code_Aster implemented in python in the test), the reference values are not physically meaningful. POST_ROCHE is verified to give the same results as the test algorithm.

All calculations are done with `VARIANTE=RCC_MRX` and `SIGM_LIM=NON`.
