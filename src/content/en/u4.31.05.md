# u4.31.05 Operator FORMULE

## 1 Purpose

Define a real-valued or complex-valued formula from its mathematical expression.

The formula will be usable in a later command as an argument of type fonction/formule, or evaluated with particular values of the variables.

In many applications, one may tabulate this formula for particular values by the command CALC_FONC_INTERP [U4.32.01](doc:u4.32.01), which produces a concept of type fonction or fonction_c, as do DEFI_FONCTION [U4.31.02](doc:u4.31.02) or DEFI_NAPPE [U4.31.03](doc:u4.31.03).

## 2 Syntax

```text
/ formule
/ formule_c = FORMULE(
    ◆ / VALE = text,
      / VALE_C = text,
    ◆ NOM_PARA = text,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Definition of the function

The body of the function is a Python algebraic expression represented by a character string. It must be evaluable: that is to say, it must respect the Python syntax, and the functions, constants or other objects necessary for its evaluation must be defined as arguments.

Example:

alpha = 1.23

form = FORMULE(NOM_PARA='X', VALE='sin(X) * alpha', alpha=alpha)

The expression of the formula is 'sin(X) * alpha'. In order to evaluate it, X is the variable of the formula. The function sin is supplied by the math module (see below). The constant alpha is defined in the command file. It is therefore necessary to define it as an argument and to supply its value. Thus, the formula may be evaluated anywhere.

**Caution**

*The functions, classes (and other Python objects) defined in the command file are not available in POURSUITE (Python cannot "pickle" them).*

*In order that formulae using this type of complementary argument may be evaluated again in POURSUITE, one must redefine the functions, classes (and other Python objects)* in *POURSUITE and declare them to the formulae by setContext.*

If one uses VALE, the formula produced is real-valued (concept of type formule). If one uses VALE_C, the formula is complex-valued (concept of type formule_c).

In both cases, the parameters are real. The names of the parameters necessary for the evaluation of the formula are supplied under the keyword NOM_PARA.

In the event of a syntax error, it is the Python language which emits the error message and not *Code_Aster*  itself.

**Note**

*The order of the parameters (keyword* NOM_PARA *) is important. If one creates a formula with two parameters in order to produce a nappe, the first parameter is the parameter of the nappe, the second is the parameter of the functions making up the nappe.*

### 3.2 Standard functions

Besides the ordinary algebraic signs + - / * **, standard functions (builtins) are also available: min, max, abs, float …

Caution: the division sign here denotes real division:

1 / 2 = 0.5

If one wishes to carry out an operation in integer division, one must use the operator //:

1 // 2 = 0

### 3.3 Mathematical functions

All the functions of the Python math module are imported by default. They are therefore directly usable in the body of the formulae.

**http://docs.python.org/lib/module-math.html**

| sin | sinh |
| --- | --- |
| cos | cosh |
| tan | tanh |
| atan | sqrt |
| atan2 | log |
| asin | log10 |
| acos | exp |

Moreover, the constant pi, from the same module, is also available.

**Caution:**

*The trigonometric functions are therefore those of Python and expect angles expressed in radians. One must be vigilant about consistency with the simple keywords* *ANGL_ of the command language, which in general require angles in degrees.*

## 4 Examples of use

For various examples one will refer to the test case ZZZZ100A.

### 4.1 A formula is used like a tabulated function

Definition of the formula Sia:

SIa = FORMULE(NOM_PARA='X',VALE='sin(X)')

Equivalent tabulated function SI:

LR = DEFI_LIST_REEL( DEBUT = 0.,

INTERVALLE = _F( JUSQU_A = pi , PAS = 0.01 )

SI = CALC_FONC_INTERP( FONCTION = SIa,

LIST_PARA = LR,

NOM_PARA = 'X',

NOM_RESU = 'DEPL', )

In order to define a tabulated function in this way from an interpretable formula, see CALC_FONC_INTERP [U4.32.01](doc:u4.32.01).

Use of SI or of SIa in a simple keyword expecting a function or a formula:

champ=CREA_CHAMP( ... AFFE = _F( ... VALE_F = SI or SIa, ) )

### 4.2 A formula may be evaluated as a real

In the body of the command file:

SIa = FORMULE(NOM_PARA='X',VALE='sin(X)')

X = SIa(1.57)

print SIa(1.57)

Behind a simple keyword expecting a real:

LR = DEFI_LIST_REEL(DEBUT=SIa(0.),

```text
INTERVALLE=_F(JUSQU_A=SIa(pi/2.), PAS=0.01))
```

In another formula:

SIb = FORMULE(NOM_PARA='X', VALE='X*SIa(5.)', SIa=SIa)

### 4.3 Calling a formula or a function in another formula

SIa = FORMULE(NOM_PARA='X',VALE='sin(X)')

Take care to remember to put the argument (X here) in the call to the function SIa:

SIb = FORMULE(NOM_PARA='X', VALE='X*SIa(X)', SIa=SIa)

### 4.4 Formula with several parameters

NAP = FORMULE(NOM_PARA=('AMOR','FREQ'),

VALE='''(1./((2.*pi*FREQ)**2 - OMEGA**2 )**2

+(2.*AMOR*2.*pi*FREQ*OMEGA)**2)''',

OMEGA=OMEGA)

In this example, one defines a formula with 2 parameters. Given the length of the expression, it is written for convenience on several lines with triple quotes to delimit it. The constant pi is a standard constant (cf. paragraph [§3.2]), the constant OMEGA must be supplied explicitly.

In the present state, only formulae from $\mathrm{ℝ}$ into $\mathrm{ℝ}$ or $\mathrm{ℂ}$ are possible: a single scalar is produced.

### 4.5 Formula coming from the programming of a Python function

One may refer in a formula to functions programmed in Python, which allows formulae much more complex than simple algebraic expressions.

For example a Heaviside function:

$\mathrm{HEAVYSIDE}(x)=\lbrace \begin{array}{c}0.\mathrm{si}x<0.\\ 1.\mathrm{si}x\ge 0.\end{array}$

The Python function is programmed as follows:

def heaviside(x):

if x < 0.:

return 0.

else:

return 1.

F_HVS = FORMULE(NOM_PARA='INST',

VALE='heaviside(INST)',

heaviside=heaviside)

**Caution:**

*The use of Python programming in the command file (here the method* heaviside *) is incompatible with editing this file* in graphical mode *with* AsterStudy.

In order that the formula F_HVS may be evaluated in POURSUITE, one must redefine the Heaviside function and declare it to the formula:

def heaviside(x):

if x < 0.:

return 0.

else:

return 1.

F_HVS.setContext( dict(heaviside=heaviside) )

### 4.6 Example of the definition of formulae in a Python loop

When one defines, in a loop, formulae whose expression depends on the index of the loop, one sees the full benefit of passing the constants explicitly.

Example:

for i in range(3):

FO[i] = FORMULE(VALE='cos(i*INST)', NOM_PARA='INST', i=i)

CH[i] = CREA_CHAMP(OPERATION='AFFE', ..., VALE_F=FO[i])

With these instructions, one has defined 3 formulae which all have the same expression.

At each iteration, a different value is stored for the argument i. When the formula is evaluated in order then to assign the values of the field, there is no ambiguity about the value of i. It is the value attached to the formula when it was created, and not the current value of i.

Indeed, in mode PAR_LOT='OUI', all the commands are created, and only afterwards executed. In this mode, i is equal to 2 during the actual execution of the commands.
