# u4.82.22 Operator POST_CHAM_XFEM

## 1 Purpose

Create a result data structure containing the fields to be post-processed by the X-FEM method.

It makes it possible to generate the following fields in order to post-process them on the cracked mesh:

- displacement, stress and internal-variable fields following the solution of a mechanical problem
- temperature field following the solution of a thermal problem

Produces a concept of type resultat_sdaster.

The command POST_MAIL_XFEM [U4.82.21](doc:u4.82.21), which makes it possible to generate the cracked mesh, is required before POST_CHAM_XFEM is used.

## 3 Syntax

```text
/ evol_noli
/ evol_ther
/ evol_elas
/ mode_meca = POST_CHAM_XFEM(
    ◆ RESULTAT = resultat,
    ◆ MODELE_VISU = modele,
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 4 Operands

```text
♦    MODELE_VISU
```

Name of the visualisation model based on the visualisation mesh, produced by the command POST_MAIL_XFEM [U4.82.21](doc:u4.82.21).

```text
♦    RESULTAT
```

Name of the result concept previously obtained from MECA_STATIQUE, STAT_NON_LINE, from a modal analysis operator (MODE_ITER_*) or from THER_LINEAIRE. In the case of a result concept obtained from MECA_STATIQUE or from STAT_NON_LINE, the post-processed fields are ‘DEPL’, ‘VARI_ELGA’, ‘SIEF_ELGA’ (provided that the fields exist in the result data structure). In the case of a result concept obtained from a MODE_ITER_*, only the field 'DEPL' can be post-processed. In the case of a result concept obtained from THER_LINEAIRE, only the field 'TEMP' can be post-processed.

If the input result concept contains the constitutive-behaviour map, the latter is also transferred into the output result. This map is sometimes required in order to post-process fields (for example the field DERA_ELGA).

Warning: the result concept produced by POST_CHAM_XFEM does not contain the material field (data structure cham_mater). However, some post-processing options (such as EPSI_ELGA) need a material field. It is therefore sometimes necessary to recreate a material field from the mesh obtained from POST_MAIL_XFEM.

For further details, see [U2.05.02](doc:u2.05.02), which illustrates the implementation of a complete post-processing after an X-FEM analysis.
