# v6.04.223 SSNV223 - Basic ENDO_SCALAIRE Law and PRED_ELAS Modelling Pilotage Validation

**Summary:**

The purpose of this test is to validate the integration algorithm of the constitutive law ENDO_SCALAIRE with gradient of internal variables and the PRED_ELAS control available for this law. The problem studied is a homogeneous strained stress imposed for which an analytical solution can be obtained.

The different modellings processed are:

- **Modelling A** ($\mathrm{2D}$ ): D_PLAN_GRAD_VARI Modelling is used.
- **Model B** ($\mathrm{3D}$ ): 3D_GRAD_VARI modelling is used.

### 1.1 Geometry

## 2 reference solution

### 2.1 Calculation method used for reference solution

This problem allows an analytical solution. The relationship that to the imposed $\varepsilon$ deformation is determined combines the homogeneous damage level $a$ (reciprocal problem where more generally non-local no longer admits single analytical solution). The problem being homogeneous, damage (laden) and deformation are linked by the coherence relationship (threshold function):

${A}^{'}(a)\Gamma (\varepsilon )+{\omega}^{'}(a)=0$

with

$\omega (a)=\mathrm{ka},A(a)=\frac{{(1-a)}^{2}}{{(1-a)}^{2}+\mathrm{ma}(1+\mathrm{pa})}\text{et}\Gamma (\varepsilon )=\left[{c}_{T}\mathrm{tr}\varepsilon +\sqrt{{c}_{H}{\mathrm{tr}}^{2}\varepsilon +{c}_{S}{\varepsilon}_{\mathrm{eq}}^{2}}\right]$

where the ${c}_{T},{c}_{H}\text{et}{c}_{S}$ parameters are deduced from the problem data by:

${c}_{S}=\frac{E}{2}\left[(1-2\nu ){c}_{\mathrm{comp}}+(1+\nu )\sqrt{\frac{1-2\nu }{2(1+\nu )}{c}_{\mathrm{volu}}+1}\right];{c}_{T}={c}_{\mathrm{comp}}\sqrt{{c}_{S}};{c}_{H}=\frac{1+\nu }{2(1-2\nu )}{c}_{\mathrm{volu}}{c}_{S}$

Uniaxial deformation of the form is adopted:

$\varepsilon =\varepsilon n\otimes n\text{où}∥n∥=1\text{et}\varepsilon >0$

In this case the threshold function in deformation is simply written: $\Gamma (\varepsilon )=\left[{c}_{T}+\sqrt{{c}_{H}+{c}_{S}}\right]\varepsilon$

To achieve the $a$ damage given, by requesting deformation in the $n$ direction, a deformation intensity must therefore be imposed:

$\varepsilon =\frac{-k}{{A}^{'}(a)\left[{c}_{T}+\sqrt{{c}_{H}+{c}_{S}}\right]}$

For the reference solution we therefore adopt a strategy: we set the level of damage is verified by the EF calculations, that for an estimated theoretical deformation we reach the same level of damage.

### 2.2 Baseline

In flat deformations, one adopts a direction of $n=(1/\sqrt{5,}2/\sqrt{5})$ solicitation. In $\mathrm{3D}$, it is equal to $n=(1/\sqrt{14,}2/\sqrt{14,}3/\sqrt{14})$. One attaches as target a damage $a=0.6$; this corresponds to an intensity of $\varepsilon =9.574237\times {10}^{-4}$ solicitation after the above reference solution.

The load is applied by PRED_ELAS control technique in which the maximum terminal is fixed to achieve the above $\varepsilon$ deformation level. It will be checked that the corresponding damage is well achieved $0.6$.

## 5 Summary of the results

This test case is made on a single mesh cell, therefore it is the homogeneous damage response that is recovered numerically. The reference solution is obtained by setting itself to the damage threshold. There is a very good agreement between the Modelling and the reference solution. Non-local part of the law nevertheless is not tested.
