# u2.10.01 User's guide to the coupling between Code_Aster and the UMAT constitutive-law module

**Summary:**

The use of the coupling between *Code_Aster* and the UMAT constitutive-law integration module is described here. UMAT is a “user” routine whose arguments are specified by the Abaqus code.

Warning: the use of these “custom” constitutive laws implies a specific validation for the study envisaged, because one places oneself outside the qualified domain of *Code_Aster*.

## 1 How to use routines of UMAT type

### 1.1 Description of the UMAT routines

UMAT is a format of Fortran routine familiar to users of the Abaqus code, used to integrate their own constitutive laws. The content of this routine is entirely free and is the responsibility of the user, and must make it possible to integrate the constitutive law, that is to say, at an integration point, to compute the stress tensor, the internal variables, and the tangent operator (cf. [D5.04.01](doc:d5.04.01) - Introducing a new constitutive behaviour).

For further details on the UMAT routines, consult the documentation of the Abaqus code.

The header of a UMAT routine looks like this:

SUBROUTINE UMAT(    STRESS,STATEV,DDSDDE,SSE,SPD,SCD,                    RPL,DDSDDT,DRPLDE,DRPLDT,                                                                STRAN,DSTRAN,TIME,DTIME,TEMP,DTEMP,PREDEF,DPRED,CMNAME,                            NDI,NSHR,NTENS,NSTATV,PROPS,NPROPS,COORDS,DROT,PNEWDT,                            CELENT,DFGRD0,DFGRD1,NOEL,NPT,LAYER,KSPT,KSTEP,KINC)

Briefly, the input and output arguments of a UMAT routine are the following:

#### 1.1.1 Input variables

| **Argument** | **Meaning (Abaqus specification)** | **Values transmitted by** *Code_Aster* |
| --- | --- | --- |
| NDI | Number of stress components (excluding shear) at the current integration point | 3 |
| NSHR | Number of shear-stress components at the current integration point | 1 (D_PLAN, AXIS, C_PLAN) or 3 (in 3D) |
| NTENS | Total number of stress and shear components | NTENS = NDI+NSHR |

| NPROPS | Number of material parameters | 50 (fixed value) |
| --- | --- | --- |
| NSTATV | Number of internal variables associated with the constitutive behaviour. | NB_VARI under COMPORTEMENT |
| CMNAME | Name of the constitutive behaviour | UMAT |

| COORDS | Array containing the coordinates of the current integration point | Coordinates of the current Gauss point if these are defined as a command variable in AFFE_MATERIAU. |
| --- | --- | --- |
| PROPS(NPROPS) | Array of the material parameters | DEFI_MATERIAU / UMAT / LISTE_COEF |
| TIME(1) | Time of the step at the beginning of the increment | $\Delta t={t}_{i}-{t}_{i-1}$ |
| TIME(2) | Total time at the beginning of the increment | ${t}_{i-1}$ |
| DTIME | Time increment | $\Delta t={t}_{i}-{t}_{i-1}$ |
| TEMP | Temperature at the beginning of the increment | $T({t}_{i-1})$ |
| DTEMP | Temperature increment | $T({t}_{i})-T({t}_{i-1})$ |
| CELENT | Characteristic length of the element | *Not defined* |
| NOEL | Number of the element | Number of the element |
| NPT | Number of the integration point | Number of the Gauss point in the current element |
| LAYER | Number of the layer for shells (integration sub-point) | *Not defined* |
| KSPT | Number of the integration point in the current sub-layer | Number of the integration sub-point |
| KSTEP | Number of the step | 2 (fixed value) |
| KINC | Number of the increment | Number of the Newton iteration (KINC=0 in the prediction) |
| DROT(3,3) | Incremental rotation matrix, present if the basis for the material rotates with the element. | Computed from the 3 nautical angles |
| DFGRD0(3,3) | Array containing the transformation gradient at the beginning of the increment | *Not defined* |
| DFGRD1(3,3) | Array containing the transformation gradient at the end of the increment | *Not defined* |
| STRAN(NTENS) | Total mechanical strains at the beginning of the increment. (the thermal strains are removed). | $\varepsilon ({t}_{i-1})-{\varepsilon}^{\mathrm{th}}({t}_{i-1})$ |
| DSTRAN(NTENS) | Increments of mechanical strains. The thermal strains are removed. | $\Delta \varepsilon ({t}_{i-1})-\Delta {\varepsilon}^{\mathrm{th}}({t}_{i-1})$ |
| PREDEF | Array of the interpolated values of the external fields imposed at the beginning of the increment | The values supplied are: 'IRRA','SECH','HYDR','CORR','NEUT1','NEUT2', in this order. (the value is NaN if the command variable is not defined). |
| DPRED | Array of the increments of the imposed external fields | Increments of the command variable in the same order as PREDEF. |

#### 1.1.2 Variables produced or modified

| **Argument** | **Meaning (Abaqus specification)** | **Values transmitted to** *Code_Aster* |
| --- | --- | --- |
| STRESS(NTENS) | Cauchy stress tensor at the beginning of the time step. Must be modified in order to give the stresses at the end of the time step. | Stored in the field SIEF_ELGA, used for the computation of the internal forces (residual) |
| STATEV(NSTATV) | Array containing the internal variables of the constitutive law. | Stored in the field VARI_ELGA |
| DDSDDE(NTENS,NTENS) | Tangent operator (symmetric) of the constitutive model | Used for the computation of the tangent matrix. |
| PNEWDT | Ratio of the new suggested time step to the initial time step | Feature switched off |
| SSE, SPD, SCD | Elastic energy, plastic dissipation energy and creep energy. | Not used |

For coupled thermo-mechanical analyses only:

| RPL | Volumetric heat production per unit time at the end of the increment caused by the mechanics. | Not used |
| --- | --- | --- |
| DDSDDT(NTENS) | Variation of the stress increment with respect to the temperature | Not used |
| DRPLDE(NTENS) | Variation of the heat production with respect to the strain increments | Not used |
| DRPLDT | Variation of the heat production with respect to the temperature | Not used |

The current limitations of the Aster-Umat interface are:

- The only modellings supported are: 3D, AXIS, D_PLAN (and C_PLAN *via* DEBORST);
- The energies are not recovered by *Code_Aster* at present;
- No thermo-mechanical coupling for the moment.

Large strains can be taken into account via DEFORMATION='GDEF_LOG'.

### 1.2 Use of the UMAT routines in a study

#### 1.2.1 Creation of the dynamic library from a Fortran routine umat.f

The dynamic library containing the UMAT routine must be prepared before the execution of the analysis. For this, the user has a simple means of compiling this library by using the as_run utility [U1.04.00](doc:u1.04.00), (with a version of astk greater than or equal to 1.8.3).

The operation is as follows:

1. the user writes his or her constitutive-behaviour routine umat.f (the names of the file and of the routine are arbitrary, since they are recalled at the time of the analysis);
2. the user produces the dynamic library associated with this constitutive behaviour in the following way:

- cd /chemin/fichiers/etude
- as_run --make_shared -o libumat.so umat.f

1. in order to launch the study, in astk, the user indicates:

- /chemin/fichiers/etude/libumat.so, **type="nom"** , UL=0, as Data (the file will be copied into the working directory without changing name)
- in the command file, the user indicates under COMPORTEMENT:

    - RELATION='UMAT',
    - LIBRAIRIE='libumat.so',(or as an absolute path:

LIBRAIRIE='/chemin/fichiers/etude/libumat.so')

- NOM_ROUTINE='umat_' (one may omit the character «_»)

By this mechanism, it is entirely possible to have several different UMAT constitutive behaviours coexisting (several routines in the same library or in different libraries; see for example the test umat002a).

#### 1.2.2 Use in the command file

The UMAT-Code_Aster coupling is expressed in the command file in the following way:

- The necessary data of the material field are supplied in the operator DEFI_MATERIAU[U4.43.01], under the keyword UMAT/UMAT_FO.
- Under the keyword COMPORTEMENT of STAT_NON_LINE, DYNA_NON_LINE or SIMU_POINT_MAT:
- specify RELATION='UMAT';
- under the keyword NB_VARI, specify the number of internal variables of the constitutive behaviour;
- the plane-stress assumption is taken into account by the De Borst method [R5.03.03](doc:r5.03.03);
- indicate the path to the library under the keyword LIBRAIRIE and the name of the routine contained in the library under the keyword NOM_ROUTINE, as described above.
- the keywords RESI_INTE_RELA, ITER_INTE_MAXI, ALGO_INTE, PARM_THETA, are not used, because the input arguments of UMAT do not make it possible to take them into account.

Examples: see the tests umat001 (thermoelastic test with STAT_NON_LINE), umat002 (multi-directional analytical test with SIMU_POINT_MAT) or zzzz409a (thermomechanical test with a damage law and in SIMU_POINT_MAT).
