# v1.01.282 ZZZZ282 – Validation of crack definition on a grid by DEFI_FISS_XFEM

**Summary:**

This test validates the calculation of level set functions of a crack and an $\text{X-FEM}$ interface on a grid for all methods available in DEFI_FISS_XFEM.

## 1 Reference problem

A parallelepipede of dimensions $\mathrm{4x4x2}\mathrm{mm}$ with a flat crack is considered:

![Figure](/figures/v1.01.282/100002010000049D000002F92100DED386C126DA.png)

## 2 Test principle

In DEFI_FISS_XFEM the crack can be defined on an mesh by four different methods:

- by groups of mesh cells that form the crack and its background. To create these two groups, the PROPA_FISS operator (INITIALISATION method) is used by simplicity.
- by analytical functions which allow the two level sets to be calculated directly:

> $\mathrm{lsn}=Z$
> $\mathrm{lst}=Y-1$

- by a catalogue of predefined shapes. In this case the DEMI_PLAN form is used.
- by two fields with nodes which represent the two level sets. By simplicity these two fields are extracted from the crack defined by the catalogue of predefined shapes above.

The nodes fields that characterize the two level sets of the crack on the grid are expected to be the same as those given by the level sets on the mesh structure. If the same mesh is used for the grid as the one used for the structure, the values of the two fields in each node of the grid are expected to be the same as those of the same node of the mesh structure. Therefore, for each available method, the following is done:

- the level sets are calculated on the mesh of the structure and on the grid by DEFI_FISS_XFEM,
- for each node of the mesh structure, the difference between the normal $z$ level set defined and the same node of the mesh grid shall be calculated,
- for each node of the mesh structure, the difference between the $y$ set tangent defined and the same node of the mesh grid shall be calculated,
- check that in each node the two calculated differences are equal to zero.

The same is done for interfaces with the difference that only one level set (normal) is used to define an interface.

## 3 Modelling A

### 3.1 Modelling characteristics

3D modelling is used. For an interface and for the only "predefined shape catalogue" and "nodes fields" methods of DEFI_FISS_XFEM, D_PLAN modelling of the same geometry limited to the $(X,Y)$ plane is used because these methods are not available in 3D.

### 3.2 Mesh characteristics

The mesh 3D contains 64 elements HEXA8 of $\mathrm{1x1x0.5}\mathrm{mm}$ dimension:

![Figure](/figures/v1.01.282/10000201000003590000025714B904F5D5CE2DF1.png)

The mesh D_PLAN contains 16 elements QUAD4 $\mathrm{1x1}\mathrm{mm}$ dimension:

![Figure](/figures/v1.01.282/100002010000036D0000020436ADBED7B1B61F89.png)

The same mesh is used both for the structure and for the grid.

### 3.3 Tested quantities and results

The difference between the level set on the mesh structure and the level set on the mesh grid is tested in each node. A value exactly equal to zero is obtained everywhere, which allows to check the coincidence of the nodes fields between structure and grid.

### 3.4 Remarks

In the test one is obliged to use a tolerance in TEST_TABLE. This tolerance equals 0.1. This does not influence the test results because one tests values that are always exactly equal to zero.

## 4 Summary of the results

The two nodes fields calculated by DEFI_FISS_XFEM, both on the mesh of the structure and on the resulting mesh of the grid, are always consistent regardless of the method chosen for defining the crack or interface.

This concludes that the DEFI_FISS_XFEM operator correctly calculates the level sets on the grid.
