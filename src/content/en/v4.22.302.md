# v4.22.302 TTNL302 - Infinite wall subjected to constant flow with variable properties

**Summary:**

This test is based on the independent validation of version 3 in nonlinear transient thermal analysis.

This is a linear 1D problem represented by five modellings, one plane, the other four volume.

The functions tested are as follows:

- element of thermal plane,
- element thermal volumetric,
- nonlinear transient thermal analysis algorithm,
- variable properties,
- limit condition: flow imposed.

The value of the test lies in the consideration of variable properties (thermal conductivity and volume heat).

The results are compared to an analytical solution.

| --- | --- |

### 1.3 Boundary conditions and loads

- $[\mathrm{AD}]$ side: $q=1W/{m}^{2}$ imposed feed for $t>0$,
- $[\mathrm{AB}]$ side , $[\mathrm{BC}]$ , $[\mathrm{CD}]$ $\varphi =0.$

### 1.4 Initial conditions

$T(x,0)=0°C$ for all $x$

## 2 reference solution

### 2.1 Calculation method used for reference solution

Semi-analytic solution involving error functions:

$T(x,t)=2\left\lbrace \sqrt{\left[1+2\sqrt{(t/\pi )}\exp(\frac{-{x}^{2}}{\mathrm{4t}})+\mathrm{x.erfc}(\frac{x}{2\sqrt{(t)}})\right]}-1\right\rbrace$

with $\mathrm{erfc}(x)=\frac{2}{\pi}{\int}_{x}^{\infty}{e}^{-{t}^{2}}\mathrm{dt}$

where $x=$ abscisses

$t=$ time

This formula is only valid for $\lambda (T)=\rho c(T)=1.+\mathrm{0.5T}$

### 2.2 Baseline

Temperature at $A$ ($x=0$) and $E$ ($x=1$) points at the following $t$ moments: $t=0.1,0.3,0.5,0.7$ and $\mathrm{1s}$

### 2.3 Uncertainty about the solution

Unknown due to error function evaluation.

### 2.4 Bibliographical references

- Segal, N. Praagman, "A fast implementation of explicit time stepping algorithms with the finished element method for a class of nonlinear evolution problems", Int. J. num. Meth. Engng, vol 23, pp. 155-168, 1986.

## 13 Summary of the results

The five modellingss performed, have the same cutting in the direction of temperature propagation, they differ only by their type of mesh cells.

The five modellings give results with values exceeding the tolerance initially set (1%). the difference maximum is 9.9%. It appears for the smallest reference value located in the middle of the wall and at the beginning of the transient.

A finer mesh combined with finer temporal discretization should improve the quality of the results.

In addition, the reference solution involves an error function whose accuracy is unknown.

The results are considered acceptable in the light of the above points.

The test was used to test hexahedral and tetrahedral mesh cells in transient nonlinear thermal and the following main thermal controls:

- DEFI_MATERIAU associated with the THER_NL keyword, which defines the characteristics of a material whose characteristics vary according to temperature (conductivity and enthalpy),
- THER_NON_LINE controls allowing resolution of a non-linear steady-state thermal analysis problem or not.
