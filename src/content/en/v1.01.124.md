# v1.01.124 ZZZZ124 - Checking the EFGE_ELNO and SIEF_ELNO mark change.

**Summary:**

These tests validate the EFGE_ENO and SIEF_ELNO benchmark change using the MODI_REPERE command.

## 1 Reference problem

EFGE_ELNO and SIEF_ELNO are calculated using the CALC_CHAMP command. This calculation is performed after using MECA_STATIQUE, CALC_MODES, MODE_STATIQUE operators.

## 2 reference solution

### 2.1 Calculation method used for reference solution

Several methods are used:

- The elements structural marker is known, so the change in the reference can be calculated using the passing matrix.
- In the MODI_REPERE command, you are asked to calculate the EFGE_ELNO in the elements frame marker. EFGE_ELNO should not be changed. EFGE_ELNO is compared before and after the MODI_REPERE command.
- In the MODI_REPERE command, you are asked to calculate the SIEF_ELNO in the elements frame marker. SIEF_ELNO should not be changed. SIEF_ELNO is compared before and after the MODI_REPERE command.
- After the EFGE_ELNO mark change in the global benchmark and in some cases, they correspond to REAC_NODA or FORC_NODA. In these cases, comparison is made with these fields.

### 2.2 Baseline

All components of the significant EFGE_ELNO and SIEF_ELNO (greater than 1.0E-06) are compared in several nodes.

### 2.3 Uncertainties about the solution

No uncertainty.

## 3 Modelling A

### 3.1 Modelling characteristics

The mesh is a straight beam. The EFGE_ELNO field is calculated after an MECA_STATIQUE.

### 3.2 Test values

After MODI_REPERE command:

- EFGE_ELNO is tested in the structural element marker
- EFGE_ELNO is tested against REAC_NODA and FORC_NODA.
- NOM_CHAM_RESU=EGRU_ELNO is tested which corresponds to the EFGE_ELNO field in the user marker while the EFGE_ELNO field remains unchanged

## 4 Modelling B

### 4.1 Modelling characteristics

The Modelling has 2 beams and a discreet.

The EFGE_ELNO and SIEF_ELNO fields are calculated after an CALC_MODES and an MODE_STATIQUE.

### 4.2 Test values

After MODI_REPERE command:

- EFGE_ELNO and SIEF_ELNO are checked in the local elements structure marker.
- After the MODE_STATIQUE command the transition matrix is used. The orientations of the elements structure are known.
- After the CALC_MODES command the EFGE_ELNO are compared to the REAC_NODA.
