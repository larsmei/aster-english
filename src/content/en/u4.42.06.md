# u4.42.06 Operator DEFI_GLRC

## 1 Purpose

The operator DEFI_GLRC makes it possible to define the parameters of the reinforced-concrete constitutive models GLRC_DAMAGE [R7.01.31] and GLRC_DM [R7.01.32].

It makes it possible to determine the homogenised characteristics of the reinforced concrete from the properties of the concrete and of several types of reinforcement (passive reinforcement, prestressing cables, metal liner).

In this command, one specifies the physical properties (elastic coefficients, elastic limits) and geometric properties (section and positions of the steel) of the reinforced concrete. On output, one has a “material” concept, which one can then assign to the different plate mesh cells with the command AFFE_MATERIAU.

It is important to note that, before calling upon DEFI_GLRC, it is necessary to use DEFI_MATERIAU or DEFI_MATER_GC in order to specify all of the material parameters concerning the steel and concrete components.

Produces a data structure of type mater.

## 3 General description of the reinforced-concrete shell

In this paragraph one describes the geometry of the shell considered.

![Figure](/figures/u4.42.06/10000000000004BC00000244BF10CC0BD09D7C5B.jpg)

**Figure** 3-a **:** Current section of the reinforced-concrete shell.

The basic section of a reinforced-concrete slab () is composed of:

      - the concrete shell
      - the passive reinforcement

      - and, in the case of GLRC_DAMAGE, the section may in addition contain:

      - prestressing cables
      - a metal liner

The liner is a steel plate placed on the inner skin of the containment, ensuring in particular leak-tightness in the event of an accidental leak.

The prestressing makes it possible to compress the concrete of the civil-engineering structure. This prestressing is applied with the help of steel prestressing cables put under tension.

## 4 Operands RELATION = GLRC_DM

One will consult the documentation of the model GLRC_DM [R7.01.32](doc:r7.01.32).

### 4.1 Keyword BETON

The factor keyword BETON makes it possible to define the geometric and material characteristics of the concrete.

#### 4.1.1 Operand MATER

```text
MATER = mat_beton
```

Defines the name of the material, produced obligatorily by DEFI_MATER_GC/BETON_GLRC, used for the concrete. This operand makes it possible to check that the parameters associated with the constitutive behaviours of the concrete do indeed exist in the material.

#### 4.1.2 Operand EPAIS

EPAIS = ep

Defines the thickness of the concrete plate. One checks that $\mathit{ep}\ge 0$ .

Note:

The value of this thickness must be identical to that given in AFFE_CARA_ELEM for the shell elements using the material mat_beton (defined by DEFI_GLRC).

### 4.2 Keyword NAPPE

The factor keyword NAPPE makes it possible to define the geometric and material characteristics of the passive reinforcement. This keyword can be defined only once. Indeed, under the hypothesis of isotropy in elasticity of the constitutive law GLRC_DM, all the reinforcements are necessarily identical and equidistant from the neutral fibre.

#### 4.2.1 Operand MATER

```text
MATER = mat_acier
```

Defines the name of the material, produced obligatorily by DEFI_MATE_GC/ACIER, used for the passive reinforcement.

This operand makes it possible to recover the material parameters used for the passive reinforcement (Young's modulus ${E}_{a}$ , Poisson's ratio ${\nu}_{a}$ and elastic limit ${\sigma}_{\mathrm{ya}}$ ).

#### 4.2.2 Operands OMX and OMY

```text
OMX = Wx

OMY = Wy
```

Define the steel sections ${\Omega}_{x}$ and ${\Omega}_{y}$ of either of the two reinforcement layers given along the directions $x$ and $y$ (in ${m}^{2}/m$ per linear unit if the thickness is given in $m$ ). One recalls that the formulation of the model GLRC_DM imposes that the two reinforcement layers be identical.

One checks that ${\Omega}_{x}>0$ and ${\Omega}_{x}={\Omega}_{y}$ . With the two reinforcement layers in the reinforced-concrete section, one will therefore have a total reinforcement ratio equal to $2{\Omega}_{x}=2{\Omega}_{y}$ .

#### 4.2.3 Operands RX and RY

```text
RX = rx

RY = ry
```

Define the dimensionless position of a reinforcement layer with respect to the thickness of the concrete shell, given in the directions $x$ and $y$ ($-1\le \mathit{rx}\le 1$ , $-1\le \mathit{ry}\le 1$ , ).

One checks that $\mathit{rx}=\mathit{ry}$ .

![Figure](/figures/u4.42.06/100000000000040200000230502141F1A2172DB0.jpg)

**Figure** 4.2.3-a **: D** efinition of the dimensionless position of the reinforcement layers.

### 4.3 Operand RHO

```text
RHO = rho
```

Optional operand allowing the user to define the equivalent density of the reinforced-concrete slab. In the case where the operand is not defined, the density is computed in the following way:

${\rho}_{\mathit{eq}}={\rho}_{b}+\frac{{\rho}_{a}}{h}({\Omega}_{x}^{\sup}+{\Omega}_{x}^{\inf}+{\Omega}_{y}^{\sup}+{\Omega}_{y}^{\inf})$

Where ${\rho}_{a}$ designates the density of the steel and is recovered in the concept mat_acier supplied by the operand MATER of the keyword NAPPE.

Where ${\rho}_{b}$ designates the density of the concrete and is recovered in the concept mat_beton supplied by the operand MATER of the keyword BETON .

Where $h$ is the thickness supplied by the keyword EPAIS.

### 4.4 Operands AMOR_ALPHA, AMOR_BETA and AMOR_HYST

```text
AMOR_ALPHA    = amor_alpha

AMOR_BETA        = amor_beta

AMOR_HYST        = amor_hyst
```

Optional operand allowing the user to define the coefficients $\alpha$ and $\beta$ which serve to build the Rayleigh damping matrix, and $\eta$ for the hysteretic damping.

$C=\alpha K+\beta M$

One will refer to the documents on the modelling of mechanical damping [U2.06.03](doc:u2.06.03) and [R5.05.04](doc:r5.05.04).

If the operands are not specified in the command, they take the values defined in the concept mat_beton supplied by the operand MATER of the keyword BETON.

### 4.5 Factor keyword PENTE

#### 4.5.1 Operand TRACTION

◊    TRACTION =    /    RIGI_ACIER    [DEFAUT]

```text
/    PLAS_ACIER
/    UTIL
```

The keyword TRACTION makes it possible to define the method of computation of the post-elastic slope. Indeed, it is possible to carry out this computation according to three methods named RIGI_ACIER, PLAS_ACIER and UTIL. These three computations of slopes make it possible to set up three different fitting methods according to the material properties specified for tension. In the case where the elastic limit of the steels is not known, the fitting methods RIGI_ACIER, i.e. post-elastic slope equal to the slope of stiffness recovery of the steels, and UTIL, i.e. post-elastic slope intersecting the slope of stiffness recovery of the steels at a maximum strain whose value is imposed by the user, are accessible (this method is not suited to maximum strains smaller than the trough of the reference curve, see ). In the case where the elastic limit of the steels is known, it is possible to use the fitting method at the plasticity limit of the steels (PLAS_ACIER). The different fitting methods are illustrated by the figures which follow.

![Figure](/figures/u4.42.06/10219252000036B1000025F32903CF4261F44B6E.svg)

Figure 4.5.1-a: Tension curve (GLRC_DM vs Reference) Fitting PENTE = RIGI_ACIER

![Figure](/figures/u4.42.06/102148EE00003665000025F36508E5A70978B07F.svg)

Figure 4.5.1-b: Tension curve (GLRC_DM vs Reference) Fitting PENTE = UTIL

![Figure](/figures/u4.42.06/1021424600003665000025DC06D4B4589A6A5772.svg)

Figure 4.5.1-c: Tension curve (GLRC_DM vs Reference) Fitting PENTE = PLAS_ACIER

In the case of the fitting at the maximum strain (TRACTION=UTIL), it is necessary to specify the maximum membrane strain (EPSI_MEMB).

#### 4.5.2 Operand FLEXION

◊    FLEXION =        /    RIGI_INIT    [DEFAUT]

/    RIGI_ACIER

/    PLAS_ACIER

```text
/    UTIL
```

The keyword FLEXION makes it possible to define the method of computation of the post-elastic slope. Indeed, it is possible to carry out this computation according to two methods named RIGI_INIT, RIGI_ACIER, PLAS_ACIER and UTIL.

The options RIGI_ACIER and PLAS_ACIER correspond to the parameter settings set out for bending in 4.5.1, transposed to the case of bending.

In the case of the option RIGI_INIT, the bilinear approximation of the bending response of the section is determined in the following way (cf. [R7.01.32](doc:r7.01.32)):

- the elasticity threshold is fixed for a value M which departs by 5% from the theoretical curve;
- the second slope is defined so that the bilinear law is tangent to the theoretical curve.

![Figure](/figures/u4.42.06/100002000000014300000105E2DDA0105543C1DE.png)

Figure 4.5.2-a: Bending curve (GLRC_DM vs Reference) Fitting PENTE = RIGI_INIT

In the case of the option UTIL, the bilinear approximation of the bending response of the section is determined so as to reduce the relative area with respect to the theoretical response of the section up to the curvature kf (KAPPA_FLEX). (cf. [R7.01.32](doc:r7.01.32))

![Figure](/figures/u4.42.06/10000200000001CE000001161B88E6635FFB7611.png)

Figure 4.5.2-b: Bending curve (GLRC_DM vs Reference) Fitting PENTE = UTIL

#### 4.5.3 Operand EPSI_MEMB

```text
EPSI_MEMB    = em
```

Defines the value of the maximum membrane strain in the case TRACTION=UTIL.

#### 4.5.4 Operand KAPPA_FLEX

```text
KAPPA_FLEX    = kf
```

Defines the value of the maximum bending curvature (the inverse of a length) in the case FLEXION=UTIL.

### 4.6 Keyword CISAIL

The simple keyword CISAIL makes it possible to define whether the homogenised elastic parameters are those computed by homogenisation for a standard application of the constitutive model (CISAIL=NON), or those computed for a particular application in order to respect the fact that, when one is in pure in-plane shear, the stiffness of the steels does not come into play in the elastic constitutive behaviour (CISAIL=OUI).

### 4.7 Keyword INFO

With INFO = 2, one obtains the printout in RESULTAT format of the list of the homogenised parameters used as input to the constitutive model GLRC_DM: elasticity, thresholds and damaging constitutive behaviour.

### 4.8 Example of use

One may consult the example of use reported in the test SSNS106A, in tension–compression, and in the test SSNS106B, in alternating bending, cf. [V6.05.106](doc:v6.05.106). It can be used in order to check, on the case to be studied, the consequences in terms of response, for elementary loadings in alternating statics, of the choice of the parameters and of the identification methods.

## 5 Operands RELATION = GLRC_DAMAGE

One will consult the documentation of the model GLRC_DAMAGE [R7.01.31](doc:r7.01.31).

### 5.1 Keyword BETON

The factor keyword BETON makes it possible to define the geometric and material characteristics of the concrete.

#### 5.1.1 Operand MATER

```text
MATER = mat_beton
```

Defines the name of the material produced by DEFI_MATERIAU used for the concrete. This operand makes it possible to check that the parameters associated with the constitutive behaviours chosen under the keywords ECOULEMENT, ECRO_ISOT, ECRO_CINE and ELAS do indeed exist in the material.

#### 5.1.2 Operand EPAIS

EPAIS = ep

Defines the thickness of the concrete plate. One checks that $\mathit{ep}\ge 0$ .

Note:

The value of this thickness must be identical to that given in AFFE_CARA_ELEM for the shell elements using the material mat_beton (defined by DEFI_GLRC).

#### 5.1.3 Operand GAMMA

GAMMA = gamma

Defines the damage parameter which characterises the slope of the moment–curvature curve during the cracking of the concrete (figure 2). $gamma$ can be considered as being the ratio of the slope during cracking to the elastic slope. If $gamma>0$ , the slope is positive. If $gamma<0$ , the slope decreases and stability is no longer guaranteed. In every case, we must have $gamma<\mathit{QP1}$ and $gamma<\mathit{QP2}$ . The default value is 0. This parameter is used only for the computation of the damage:

> $\gamma =\frac{{p}_{f}}{{p}_{\mathrm{élas}}}$

with:

- $\gamma$ : GAMMA
- ${p}_{\mathrm{élas}}$ : elastic slope
- ${p}_{f}$ : slope during cracking

![Figure](/figures/u4.42.06/Object_23.svg)

**Figure** 5.1.3-a **: Moment–curvature curve of the constitutive behaviour of a reinforced-concrete plate in bending.**

#### 5.1.4 Operands QP1 and QP2

QP1 = qp1

QP2 = qp2

Define slope ratios for a positive or negative bending. The ratio is assumed to be the ratio of the slope of the curvature–moment curve after cracking to the elastic slope. They are used only for the computation of the damage:

${Q}_{P}=\frac{{p}_{2}}{{p}_{\mathrm{élas}}}$

With:

- ${Q}_{p}$ : ratio of the slopes
- ${p}_{\mathrm{élas}}$ : elastic slope
- ${p}_{2}$ : slope after cracking

One checks that $0<\mathit{QPi}<1$ .

#### 5.1.5 Operands C1N1/C1N2/C1N3/C2N1/C2N2/C2N3

C1N1 = c1n1

C1N2 = c1n2

C1N3 = c1n3

C2N1 = c2n1

C2N2 = c2n2

C2N3 = c2n3

Define the components of the Prager kinematic hardening tensor linking the tensors of the membrane plastic strains with the membrane forces of kinematic recall.

$N={\mathrm{CN}}_{1}{\epsilon}_{1}^{p}+{\mathrm{CN}}_{2}{\epsilon}_{2}^{p}$

With:

- ${\mathrm{CN}}_{1}=(\begin{array}{ccc}\mathrm{C1N1}& 0& 0\\ 0& \mathrm{C1N2}& 0\\ 0& 0& \mathrm{C1N3}\end{array})$
- ${\mathrm{CN}}_{2}=(\begin{array}{ccc}\mathrm{C2N1}& 0& 0\\ 0& \mathrm{C2N2}& 0\\ 0& 0& \mathrm{C2N3}\end{array})$
- ${\epsilon}_{1}^{p}$ and ${\epsilon}_{2}^{p}$ are the membrane plastic strain tensors for the plasticity criterion 1 and 2.

One checks that $\mathit{CiNj}\ge 0$ .

#### 5.1.6 Operands C1M1/C1M2/C1M3/C2M1/C2M2/C2M3

C1M1 = c1m1

C1M2 = c1m2

C1M3 = c1m3

C2M1 = c2m1

C2M2 = c2m2

C2M3 = c2m3

Define the components of the Prager kinematic hardening tensor linking the tensors of the plastic curvatures with the moments of kinematic recall.

$M={\mathrm{CM}}_{1}{\kappa}_{1}^{p}+{\mathrm{CM}}_{2}{\kappa}_{2}^{p}$

With:

- ${\mathrm{CM}}_{1}=(\begin{array}{ccc}\mathrm{C1M1}& 0& 0\\ 0& \mathrm{C1M2}& 0\\ 0& 0& \mathrm{C1M3}\end{array})$
- ${\mathrm{CM}}_{2}=(\begin{array}{ccc}\mathrm{C2M1}& 0& 0\\ 0& \mathrm{C2M2}& 0\\ 0& 0& \mathrm{C2M3}\end{array})$
- ${\kappa}_{1}^{p}$ and ${\kappa}_{2}^{p}$ are the plastic curvature tensors for the plasticity criteria 1 and 2.

The computation of the ${C}_{i}{M}_{j}$ is carried out using MOCO.

> ${C}_{i}{M}_{j}=\frac{{p}_{\mathrm{élas}}{p}_{p}}{{p}_{\mathrm{élas}}-{p}_{p}}$

with:

- ${p}_{\mathrm{élas}}$ : elastic slope
- ${p}_{p}$ : plastic slope

One checks that ${C}_{i}{M}_{j}\ge 0$ .

#### 5.1.7 Operands BT1/BT2 and EAT/OMT

BT1 = bt1

BT2 = bt2

EAT = eat

OMT = omt

In the case where the finite elements support the computation of the shear forces, these operands serve to define the elastic stiffness matrix of transverse shear. The shear forces $V$ are related to the distortions $\gamma$ by:

$V=\left[\begin{array}{cc}\mathit{BT1}& 0\\ 0& \mathit{BT2}\end{array}\right]:\gamma$

If the user specifies the Young's modulus of the transverse steels EAT as well as the section of transverse steel per linear metre OMT, then one deduces the coefficients of the stiffness matrix by the following relation:

${\mathit{bt}}_{i}=\frac{5}{6}\frac{\mathit{ep}}{2}(\frac{\mathit{eb}}{1+\mathit{nub}}+\mathit{eat}\times \mathit{omt})$

The user cannot specify at the same time BT1, BT2 and the parameters EAT, OMT.

One checks that these operands are strictly positive reals.

#### 5.1.8 Operands MP1X/MP1Y/MP2X/MP2Y and MP1X_FO/MP1Y_FO/MP2X_FO/MP2Y_FO

MP1X = mp1x

MP1Y = mp1y

MP2X = mp2x

MP2Y = mp2y

MP1X_FO = mp1x_fo

MP1Y_FO = mp1y_fo

MP2X_FO = mp2x_fo

MP2Y_FO = mp2y_fo

Define the limit plastic moments of the generalised Johansen criterion used in the constitutive model GLRC_DAMA. They can be defined either by constant values or by functions. It is not possible to mix functions and constants. Moreover, as soon as one of the operands is specified, it is mandatory to specify all of them. When they are not specified, they are computed automatically.

### 5.2 Keyword ARMA

The factor keyword ARMA makes it possible to define the geometric and material characteristics of the passive reinforcement.

#### 5.2.1 Operand MATER

```text
MATER= mat_acier
```

Defines the name of the material produced by DEFI_MATERIAU used for the passive reinforcement.

This operand makes it possible to recover the material parameters used for the passive reinforcement (Young's modulus ${E}_{a}$ , Poisson's ratio ${\nu}_{a}$ and elastic limit ${\sigma}_{\mathrm{ya}}$ ).

#### 5.2.2 Operands OMX and OMY

```text
OMX     = Wxa

OMY     = Wya
```

Define the steel sections of a reinforcement layer given along the directions $x$ and $y$ (in ${m}^{2}/m$ per linear unit, the thickness then being given in $m$ ).

One checks that $\mathit{Wxa}\ge 0$ and $\mathit{Wya}\ge 0$ .

#### 5.2.3 Operands RX and RY

```text
RX = rxa

RY = rya
```

Define the dimensionless position of a reinforcement layer with respect to the thickness of the concrete shell, given in the directions $x$ and $y$ ($-1\le \mathit{rxa}\le 1$ , $-1\le \mathit{rya}\le 1$ , figure 3).

![Figure](/figures/u4.42.06/100000000000040200000230502141F1A2172DB0.jpg)

### 5.3 Keyword CABLE_PREC

The factor keyword CABLE_PREC makes it possible to define the geometric and material characteristics of the prestressing cables as well as the prestressing force used.

#### 5.3.1 Operand MATER

```text
MATER = mat_cable
```

Defines the name of the material produced by DEFI_MATERIAU used for the prestressing cables.

This operand makes it possible to recover the material parameters used for the prestressing cables (Young's modulus ${E}_{p}$ , Poisson's ratio ${\nu}_{p}$ and elastic limit ${\sigma}_{\mathrm{yp}}$ ).

#### 5.3.2 Operands OMX and OMY

```text
OMX    = Wxp

OMY    = Wyp
```

Define the steel sections of a layer of prestressing cables given along the directions $x$ and $y$ (in ${m}^{2}/m$ per linear unit, the thickness then being given in $m$ ).

One checks that $\mathit{Wxp}\ge 0$ and $\mathit{Wyp}\ge 0$ .

#### 5.3.3 Operands RX and RY

```text
RX = rxp

RY = ryp
```

Define the dimensionless position of a layer of prestressing cables with respect to the thickness of the concrete shell, given in the directions $x$ and $y$ ($-1\le \mathit{rxp}\le 1$ , $-1\le \mathit{ryp}\le 1$ ).

#### 5.3.4 Operands PREX and PREY

```text
PREX = precx,

PREY = precy,
```

Define the prestressing forces (in newtons) in the directions $x$ and $y$ (they must normally be negative, because one applies a compressive force).

### 5.4 Keyword LINER

The factor keyword LINER makes it possible to define the geometric and material characteristics of the metal liner.

#### 5.4.1 Operand MATER

```text
MATER = mat_liner
```

Defines the name of the material produced by DEFI_MATERIAU used for the metal liner.

This operand makes it possible to recover the material parameters used for the metal liner (Young's modulus ${E}_{l}$ , Poisson's ratio ${\nu}_{l}$ and elastic limit ${\sigma}_{\mathrm{yl}}$ ).

#### 5.4.2 Operand OML

```text
OML = Wl
```

Defines the thickness of the liner (in metres, according to the choice made for the other dimensioned parameters).

One checks that $\mathit{Wl}\ge 0$ .

#### 5.4.3 Operand RLR

```text
RLR    = rlr,
```

Defines the dimensionless position of the liner with respect to the thickness of the concrete shell (in practice, $\mathit{rlr}=-1$ or $\mathit{rlr}=1$ , because the metal liner is placed on the lower or upper face of the concrete shell).

### 5.5 Keyword ALPHA

This keyword makes it possible to define a “mean” (and isotropic) thermal expansion coefficient for the shell element.

### 5.6 Keyword INFO

Printout in RESULTAT format of the list of the homogenised parameters used as input to the constitutive model GLRC_DAMAGE.

## 6 Example of use

The following example is taken from the test SDNS106A:

> MAT = DEFI_GLRC( RELATION = GLRC_DAMAGE,

BETON = _F(

MATER = MAT_B,

EPAIS = EP,

GAMMA = 0.0,

QP1 = 0.15,

QP2 = 0.15,

C1N1 = 87.3E6,C1N2 = 87.3E6,C1N3 = 87.3E6,

C2N1 = 87.3E6,C2N2 = 87.3E6,C2N3 = 87.3E6,

C1M1 = 14.8E6,C1M2 = 14.8E6,C1M3 = 14.8E6,

C2M1 = 14.8E6,C2M2 = 14.8E6,C2M3 = 14.8E6,),

NAPPE = (

_F(MATER = MAT_A1,

OMX = 5.65E-4,

OMY = 5.65E-4,

RX = 0.95,

RY = 0.95,),

_F(MATER = MAT_A1,

OMX = 5.65E-4,

OMY = 5.65E-4,

RX = -0.95,

RY = -0.95,),),

LINER = _F(

MATER = MAT_A2,

OML = 6.E-3,

RLR = -1.,),

CABLE_PREC = _F(

MATER = MAT_A2,

OMX = 4.56E-3,

OMY = 1.35E-2,

RX = 0.0,

RY = 0.0,

PREX = -3.0E6,

PREY = -3.0E6,),

INFO = 2,);

**Note:**

In this example, one uses 3 different materials: MAT_B (concrete), MAT_A1 (passive reinforcement) and MAT_A2 (metal liner and prestressing cables). Before defining the parameters of DEFI_GLRC, it is mandatory to use DEFI_MATERIAU in order to specify all the parameters concerning these materials:

MAT_B=DEFI_MATERIAU(

ELAS = _F(

E = 30000.E6,

NU = 0.2,

RHO = 2500.0,),

BETON_ECRO_LINE = _F(

D_SIGM_EPSI = 0.0,

SYT = 5E6,

SYC = -35.E6,),);

> MAT_A1=DEFI_MATERIAU(

ELAS = _F(

E = 2.E11,

NU = 0.0,),

ECRO_LINE = _F(

D_SIGM_EPSI = 0.0,

SY = 3.E9,),);

> MAT_A2=DEFI_MATERIAU(

ELAS = _F(

E = 2.E11,

NU = 0.3,),

ECRO_LINE = _F(
