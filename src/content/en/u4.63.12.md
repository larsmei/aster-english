# u4.63.12 Operator PROJ_MATR_BASE

## 1 Purpose

Project an assembled matrix onto a basis of mechanical eigenmodes or a RITZ basis. The resulting projected matrix will be used by the analysis algorithms in generalised components (DYNA_VIBRA [U4.53.03](doc:u4.53.03) for example).

One may use PROJ_BASE [U4.63.11](doc:u4.63.11) to process several matrices simultaneously.

Produces a generalised-matrix concept of type matr_asse_gene_R if the assembled matrix to be projected is of type matr_asse_depl_R or of type matr_asse_gene_R.

Produces a generalised-matrix concept of type matr_asse_gene_C if the assembled matrix to be projected is of type matr_asse_depl_C or of type matr_asse_gene_C.

## 2 Syntax

```text
/ matr_asse_gene_r
/ matr_asse_gene_c = PROJ_MATR_BASE(
    ◆ BASE = mode_gene / mode_meca,
    ◆ NUME_DDL_GENE = nume_ddl_gene,
    ◆ / MATR_ASSE = matr_asse_depl_c / matr_asse_depl_r,
      / MATR_ASSE_GENE = matr_asse_gene_r / matr_asse_gene_c,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand BASE

```text
♦    BASE = ba
```

Concept of type mode_meca or mode_gene (for substructuring) which contains the vectors defining the projection subspace.

### 3.2 Operand NUME_DDL_GENE

```text
♦    NUME_DDL_GENE = nu_gene
```

Numbering associated with the generalised model.

### 3.3 Operands MATR_ASSE / MATR_ASSE_GENE

```text
♦    /    MATR_ASSE = ma
```

Concept of type matr_asse_DEPL_R or matr_asse_DEPL_C, assembled matrix that one wishes to project.

```text
/    MATR_ASSE_GENE = ma
```

Concept of type matr_asse_gene_R or matr_asse_gene_C, assembled matrix coming from substructuring, that one wishes to project.
