# v1.04.120 PETSC05 – Use of user solver with petsc4py

**Summary:**

This test case validates the definition and use of a user solver with PETS c.

The solver is defined by the Python user as a petsc4py.PETS c.KSP object and is then used in the MECA_STATIQUE or STAT_NON_LINE calculation operator.

In model A, the preconditioner is trivial. The test is purely computer-based.

In model B, the preconditioner is an implantation of the Reverse Constrained Enhanced Preconditioner developed by Franceschini *et al.* and published in
[https://doi.org/10.48550/arXiv.2111.05599](https://doi.org/10.48550/arXiv.2111.05599).

This is a brief documentation.
