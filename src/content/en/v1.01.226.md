# v1.01.226 PYNL01 - Integration of VMIS_ISOT_LINE behavior by CALCUL command

**Summary:**

This document is intended to validate the CALCUL command for the integration of constitutive law.

## 1 Reference problem

### 1.1 Geometry

A cube of unit length ($\mathrm{1m}$) is considered.

### 1.2 Material properties

A material with a Von constitutive law isotropic-lunching devices (VMIS_ISOT_LINE) is considered.

The elastic properties are as follows:

- Young's modulus: $E=210000\mathrm{MPa}$
- Poisson's ratio: $\nu =0,3$

The tangential module is ${E}_{t}=1930\mathrm{MPa}$ .

The yield strength is ${\sigma}_{y}=181\mathrm{MPa}$ .

### 1.3 Boundary conditions and loads

The lower face (in the $z=0$ plane) is clamped.

The upper face (in the $z=1$ plane) is subjected to $\mathrm{du}=(\begin{array}{}1\\ 1\\ 1\end{array})[m]$ displacement.

## 2 reference solution

The reference solution is obtained by numerical problem resolution (elastic prediction and then behavior integration) using the STAT_NON_LINE command. This results in the stress field, the field of internal variables, and the nodal force vector following prediction.

## 3 Modelling A

### 3.1 Modelling characteristics

In this Modelling, STAT_NON_LINE is replaced by broken commands, which perform elastic prediction and then behavior integration.

### 3.2 Mesh characteristics

The mesh is composed of a single mesh cell HEXA8.

### 3.3 Tested quantities and results

The difference between the stress field (the field of internal variables and the nodal force vector, respectively) calculated by STAT_NON_LINE and the one calculated by the CALCUL command, after prediction, is tested.

| **Identification** | **Reference** | $\text{\%}$ **difference** |
| --- | --- | --- |
| $\min(\Delta \sigma )$ | 0 | 0 |
| $\max(\Delta \sigma )$ | 0 | 0 |
| $min(\Delta \%)$ | 0 | 0 |
| $max(\Delta \%)$ | 0 | 0 |
| $min(\Delta \text{}f)$ | 0 | 0 |
| $max(\Delta \text{}f)$ | 0 | 0 |

## 4 Summary of the results

This test validated the CALCUL command for the integration of Von constitutive law Linear isotropic hardening bets.
