# v6.02.134 SSNL134 - Elasto-plastic Ruin of Lee's Gate

**Summary**

This test is intended to validate simultaneously the nonlinear material and geometric possibilities of element multifibre beam `POU_D_TGM`. L的element is implemented on a test case commonly treated in the literature with respect to elastic behavior as it presents a complex response with *snap-back* and *snap-through*: cs Lee's portal.

The elastoplastic behavior of the portal is assumed here, which allows the correct integration of the constitutive law of the multifibre elements to be tested, as well as the correct treatment of large movements. The results obtained are compared with the results from the literature and non-regression tests.

The current case contains only one model. However, in the Summary of the results, further analysis of the results is provided to help the reader understand the actual dataset.

### 3.5 Remarks

Using the arc length technique makes it difficult to define the reference value to be introduced into the `TEST_RESU` command, since these values cannot be imposed.
Therefore, we took as a tested value the loading value, which corresponds to `ETA_PILOTAGE`. For a selected loading value,
The values of displacements between the results of the literature and those obtained here are then compared.

The different tolerances were chosen in this way in relation to the discretization (in time step) used. The latter was chosen not only for the calculation
A reduction in time step would result in a reduction in the required tolerances (see summary for more details).
The step used for defining the moment list is `2` for a final time of `179`.
These choices were made to provide a sufficiently good representation of the equilibrium curve.

We still note a high difference in $\mathit{DY}$ results at the last moments, although the response curves have similar shapes.

### 4.3 Executive summary

The error on the movements remains for the majority of the points of the same order of quantity as the uncertainty on the solution (5%).
It is also possible to reduce this error by refining "temporal" discretization (list of moments).
The response curve of the reference is well correlated, and the change in the appearance due to the first plasticization is described.
