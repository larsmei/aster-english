# u4.42.01 Operator AFFE_CARA_ELEM

## 1 Purpose

Assign geometric and material characteristics to structural elements. The assigned geometric data are complementary to the mesh data.

Among the characteristics treated, one may cite:

- for shell-type elements: the thickness, a reference direction in the tangent plane,
- for beam-type elements: the characteristics of the cross-section and the orientation of the principal axes of inertia about the neutral fibre, the curvature of the curved elements,
- for discrete-type elements (spring, mass/inertia, damper): the values of the stiffness, mass or damping matrices to be assigned directly or after orientation,
- for bar-type or cable-type elements: the area of the cross-section,
- for 3D and 2D continuum elements: local axes with respect to which the user will be able to define directions of anisotropy.

The command must be exhaustive for all the structural elements of the model.

This operator produces a data structure of type cara_elem.

## 8 Keyword COQUE

### 8.1 Assignable characteristics

The characteristics that one can assign to the plate or shell elements are:

- for all the elements of this type, a thickness constant on each mesh cell, since the mesh represents only the middle surface (or the reference surface for the offset ones),
- for all the elements of this type, the number of layers used for the integration through the thickness,
- for all the elements of this type, the orientation of the local frame specific to each mesh cell,
- for certain shell models, particular characteristics: shear coefficient, metric, offset, etc.

### 8.2 Syntax

COQUE = _F(

♦ GROUP_MA = lgma,    [l_gr_maille]

♦ / EPAIS = ep,    [real]

/ EPAIS_FO = epfct    [function]

◊ / ANGL_REP = / (0.0, 0.0),    [default]

/ ($\alpha$ , $\beta$ ),    [l_real]

/ VECTEUR = (vx ,vy ,vz),    [l_real]

◊ MODI_METRIQUE = [’NON’|’OUI’],    [default)]

◊ COEF_RIGI_DRZ = KRZ (1.E-5),    [real (default)]

◊ EXCENTREMENT = e (0.0),    [real (default)]

EXCENTREMENT_FO = efct    [function]

◊ INER_ROTA = ’OUI’,

◊ A_CIS = kappa (0.8333333),    [real (default)]

◊ COQUE_NCOU = n (1),    [integer (default)]

)

### 8.3 Operands

#### 8.3.1 Operand EPAIS

♦ / EPAIS = ep

/ EPAIS_FO = epfct

EPAIS represents the thickness of the shell, which must be expressed in the same units as the coordinates of the nodes of the mesh.

EPAIS_FO is a function which gives the thickness of the shell, in the same units as the coordinates of the nodes of the mesh. This function depends on the geometry (X,Y,Z) and is evaluated at the centre of gravity of the mesh cell.

#### 8.3.2 Operands EXCENTREMENT / EXCENTREMENT_FO

◊ excentrement = / e (0.0),    [real (default)]

excentrement_F0 = efct    [function]

excentrement: define the distance between the meshed surface and the mean surface, in the direction of the normal (modellings DKT, DST, GRILLE_EXCENTRE).

excentrement_FO: Function which gives the distance between the meshed surface and the mean surface, in the direction of the normal (modellings DKT, DST, GRILLE_EXCENTRE). This function depends on the geometry (X,Y,Z) and is evaluated at the centre of gravity of the mesh cell.

Taking the offset into account influences the bending behaviour and possibly the membrane behaviour in the presence of coupling (there is no effect on the shear).

#### 8.3.3 Operands MODI_METRIQUE / COEF_RIGI_DRZ / INER_ROTA

◊ modi_metrique = ’non’

Makes the assumption that the thickness of the element is small. During the integrations through the thickness, the variation of the radius of curvature is not taken into account (default option for all shells).

◊ modi_metrique = ’oui’

For the modelling: COQUE_AXIS, the integrations are performed taking into account the variations of the radius of curvature as a function of the thickness; see for example [R3.07.02](doc:r3.07.02)

◊ iner_rota = ’oui’

Account is taken of the rotary inertia for the modellings DKT, DST and Q4G. It is mandatory in the case of an offset. This keyword may be omitted for thin shells, where the rotary-inertia terms are negligible compared with the others in the mass matrix [R3.07.03](doc:r3.07.03).

◊ coef_rigi_drz = krz,

KRZ is a fictitious stiffness coefficient (necessarily small) on the rotational degree of freedom about the normal to the shell. It is necessary in order to prevent the stiffness matrix from being singular, but it must be chosen as small as possible. The default value of ${10}^{-5}$ is suitable for most situations (it is a relative value: the stiffness about the normal is equal to KRZ times the smallest diagonal term of the stiffness matrix of the element). For the DKT, there are two modes of operation. COEF_RIGI_DRZ negative and COEF_RIGI_DRZ positive. In the case of COEF_RIGI_DRZ positive, the degree of freedom DRZ always has the meaning of a fictitious rotation which prevents the matrix from being singular in the global frame. In the case of a negative COEF_RIGI_DRZ, the rotational kinematics of the plate element about its normal is reinforced by a variational formulation. The degree of freedom DRZ therefore has a physical meaning. A value of ${10}^{-8}$ is recommended.

**Note:**

*Caution: in* *STAT/DYNA_NON_LINE, this coefficient may lead to additional Newton iterations (more than one iteration for a linear problem, for example).*

#### 8.3.4 Operand ANGL_REP / VECTEUR

The keywords ANGL_REP or VECTEUR make it possible to specify the “user” frame in each shell element. It is in this frame that, for example, the stresses in the shell or the generalised forces are expressed [U2.01.05](doc:u2.01.05).

By means of these keywords, the user supplies a vector $V$ which will make it possible to define the frame completely. The construction of this “user” frame from $V$ is carried out at every point $P$ in the following way (cf. Figure ):

- the projection of $V$ onto the tangent plane supplies the axis ${x}_{l}$ ,
- the vector ${z}_{l}$ is collinear with the normal $n$ to the plane of the shell, which is known for each element; its orientation can be changed by MODI_MAILLAGE/ORIE_NORM_COQUE[U4.23.04],
- the vector ${y}_{l}$ is constructed so as to obtain an orthonormal frame.

The “user” frame is therefore: $(P,{x}_{l},{y}_{l},{z}_{l})$ with: ${z}_{l}=n$ and ${y}_{l}={z}_{l}\text{^}{x}_{l}$

![Figure](/figures/u4.42.01/repere-utilisateur-coque.png)

*: Definition of the user frame of a shell.*

The keywords ANGL_REP and VECTEUR are mutually exclusive; the vector $V$ is defined by means of one or the other.

◊ ANGL_REP= ($\alpha$  , $\beta$ )

The keyword ANGL_REP defines the vector $V$ in the global frame $(O,X,Y,Z)$ from two nautical angles $\alpha$ and $\beta$ as explained in Figure and Figure .

In the figure the angle $\beta$ is negative. |
| --- | --- |

In a three-dimensional representation, the vector is obtained as follows [Figure].

![Figure](/figures/u4.42.01/repere-angle-vect.png)

*: Three-dimensional representation of the vector $V$ defined by ANGL_REP.*

◊ VECTEUR = $(\mathrm{vx},\mathrm{vy},\mathrm{vz})$

The vector $V$ is defined by its coordinates in the global frame $(O,X,Y,Z)$ .

**Notes:**

*•* *If none of the keywords above is supplied, it is therefore the global axis* $X$ *which determines, by projection onto the tangent plane of the shell, the “user” frame of each mesh cell.*

*•* *The “user” frame is also used for the definition of the orientation of the fibres in composite shells (DEFI_COMPOSITE,* [U4.42.03](doc:u4.42.03) *).*

#### 8.3.5 Operand COQUE_NCOU

◊ COQUE_NCOU = / n (1),    [integer, default]

This is the number of layers used for the integration through the thickness of the shell. The number of layers also determines the number of sub-points of the stress field: $2n+1$ .

In the non-linear case, it is necessary to use more than one layer in order to integrate the stresses through the thickness correctly, *cf.* [U2.02.01](doc:u2.02.01).

#### 8.3.6 Operand A_CIS

◊ A_CIS = / kappa (0.8333333),    [real, default]

This parameter is to be used if one wishes, for a thick shell, to place oneself within the framework of the Love-Kirchhoff model. It is applicable only for the modellings COQUE_C_PLAN, COQUE_D_PLAN, COQUE_AXIS and COQUE_3D. For more detail the user should refer to the guide [U2.02.01](doc:u2.02.01).

#### 8.3.7 Note on the use of ELAS_COQUE

When ELAS_COQUE is used, the bending and membrane stiffnesses are entered by hand by the user in DEFI_MATERIAU. In this case, the thickness supplied in AFFE_CARA_ELEM serves only to compute the mass in dynamics and does not contribute to the stiffness.

*◦* *One cannot overload one type of section (* CERCLE *,* RECTANGLE *,* GENERALE *) by another.*

*◦* *For beams of variable section, the names with suffix* *1 or* *2* *are incompatible with the names without a suffix. Example:* $A$ *is incompatible with* $\mathit{A1}$ *and* $\mathit{A2}$ *.*

◦    $H$ *is incompatible with* $\mathit{HZ}$ *and* $\mathit{HY}$ *(as well as* $\mathit{H1}$ *,* $\mathit{H2}$ *, …)*

◦    $\mathit{EP}$ *is incompatible with* $\mathit{EPY}$ *and* $\mathit{EPZ}$ *(as well as* $\mathit{EP1}$ *,* $\mathit{EP2}$ *, …).*

◦    $\mathit{RY}$ *,* $\mathit{RZ}$ *and* $\mathit{RT}$ *come into play only for the computation of the stresses.*

### 9.4 Operands

#### 9.4.1 Operand VARI_SECT

Makes it possible to define the type of section variation between the two end nodes of the beam element, elements POU_D_E and POU_D_T [R3.08.01](doc:r3.08.01).

The possibilities are:

| **Section** | **Affine** | **Homothetic** |
| --- | --- | --- |
| circle | no | yes |
| rectangle | yes (along $y$ ) | yes |
| general | no | yes |

- “Affine” means that the area of the section varies linearly between the two nodes. The dimensions in the direction y are constant ($\mathit{HY}$ , $\mathit{EPY}$ ) and those in the direction $z$ vary linearly ($\mathit{HZ1}$ , $\mathit{HZ2}$ , $\mathit{EPZ1}$ , $\mathit{EPZ2}$ ).
- “Homothetic” means that the dimensions of the section vary linearly between the values given at the two end nodes. In this case, the area of the section evolves quadratically.

In the case of circular hollow sections, for the section to be considered homothetic, it is necessary that ${\mathit{EP}}_{\mathit{DEBUT}}/{R}_{\mathit{DEBUT}}={\mathit{EP}}_{\mathit{FIN}}/{R}_{\mathit{FIN}}$ . If the homothety is not respected, the solution given by *Code_Aster* is approximate [R3.08.01](doc:r3.08.01).

#### 9.4.2 Operand MODI_METRIQUE

Makes it possible to define, for the TUYAU elements, the type of integration through the thickness (modellings TUYAU_3M, TUYAU_6M):

- MODI_METRIQUE= 'NON' leads to assimilating, in the integrations, the radius to the mean radius. This is therefore valid for pipes of small thickness (relative to the radius),
- MODI_METRIQUE= 'OUI' implies a complete integration, more accurate for thick piping, but which may in certain cases lead to oscillations of the solution.

**Note**

> The option MODI_METRIQUE='OUI' has been deactivated following the observation of incorrect results when it is used. For the moment, only the option MODI_METRIQUE='NON' is allowed.

Definition of the characteristics:

| $\mathit{IZ}=\underset{s}{\int}{y}^{2}\mathit{ds}$ | $\mathit{IY}=\underset{s}{\int}{z}^{2}\mathit{ds}$ |
| --- | --- |
| $\mathit{AY}=\frac{A}{{A}_{y}^{'}}=\frac{A}{{\mathit{IZ}}^{2}}\underset{{y}_{1}}{\overset{{y}_{2}}{\int}}\frac{{m}_{y}^{2}(y)}{{b}_{y}(y)}\mathit{dy}$ | $\mathit{AZ}=\frac{A}{{A}_{z}^{'}}=\frac{A}{{\mathit{IY}}^{2}}\underset{{z}_{1}}{\overset{{z}_{2}}{\int}}\frac{{m}_{z}^{2}(z)}{{b}_{z}(z)}\mathit{dz}$ |
| with ${m}_{y}(y)=\underset{y}{\overset{{R}_{y}}{\int}}{\mathit{t.b}}_{y}(t)\mathit{dt}$ ${b}_{y}(t)$ thickness along $z$ , at $z=t$ | ${m}_{z}(z)=\underset{z}{\overset{{R}_{z}}{\int}}{\mathit{t.b}}_{z}(t)\mathit{dt}$ ${b}_{z}(t)$ thickness along $y$ , at $y=t$ |

With:

${A}_{y}^{'}$ , ${A}_{z}^{'}$ : reduced shear areas.

${A}_{y}^{'}=\frac{A}{\mathit{AY}}$ with $\mathrm{AY}\ge 1$ or alternatively ${A}_{y}^{'}={k}_{y}A$ with ${k}_{y}=\frac{1}{\mathit{AY}}\le 1$

- the shear coefficients ${A}_{y},{A}_{z}$ are used by the elements POU_D_T, and POU_D_TG, POU_D_TGM, for the computation of the stiffness and mass matrices and for the computation of the stresses [R3.08.01](doc:r3.08.01). In particular, the transverse shear stresses are expressed by:

${\tau}_{xz}=\frac{{V}_{z}}{{K}_{z}A}={V}_{z}\frac{{A}_{z}}{A}$ ${\tau}_{xy}={V}_{y}\frac{{A}_{y}}{A}$

- in the case of Euler beams (POU_D_E), which do not take transverse shear into account, the corresponding terms are neglected in the computation of the stiffness and of the mass by taking ${A}_{y}={A}_{z}=0$ . On the other hand, the shear stresses [R3.08.01](doc:r3.08.01) are computed by:

${\tau}_{xz}=\frac{{V}_{z}}{A}$ ${\tau}_{xy}=\frac{{V}_{y}}{A}$

The characteristics $\mathrm{RY}$ , $\mathrm{RZ}$ , $\mathrm{RT}$ are used for the computation of the bending and torsion stresses [R3.08.01](doc:r3.08.01) for the options ’SIGM_ELNO’ or ’SIPO_ELNO’ of CALC_CHAMP[U4.81.04].

In bending    ${\sigma}_{xx}=\frac{{M}_{y}}{{I}_{y}}.\mathit{RZ}-\frac{{M}_{z}}{{I}_{z}}.\mathit{RY}$

In torsion    ${\tau}_{xz}={\tau}_{xy}=\frac{\mathit{MT}}{\mathit{JX}}.\mathit{RT}$

#### 9.4.6 Operand SECTION = ’COUDE’

When one wishes to take into account the flexibility correction coefficients or the stress amplification coefficients, the modelling of the elbows must be done with the modelling POU_D_T. In order to obtain correct results, it is advised to model a 90° elbow with 20 to 40 mesh cells of POU_D_T. The characteristics can be assigned only on the elements POU_D_T.

The assignment of the mechanical characteristics (section, inertias, …) is carried out by SECTION, which may take the value GENERALE or RECTANGLE or CERCLE.

##### 9.4.6.1 Operands COEF_FLEX, COEF_FLEX_XZ, COEF_FLEX_XY : flexibility coefficients

◊ coef_flex= $\mathrm{cflex}$

◊ coef_flex_xz = ${\mathrm{cflex}}_{xz}$

◊ coef_flex_xy = ${\mathrm{cflex}}_{xy}$

For the modelling of piping elbows, the representation by elements of a circular beam is insufficient to represent the flexibility of a thin shell. The flexibility coefficient corrects the geometric data (geometric moments of inertia) in accordance with the construction rules. Certain rules lead to performing the bending-stiffness computation with a corrected geometric moment of inertia:

${I}_{y,z}=\frac{{I}_{y,z}(\mathrm{tube})}{\mathrm{cflex}}$ with $\mathrm{cflex}>1.0$

A classical value of $\mathrm{cflex}$ , for a piping of thickness $e$ and of mean radius ${R}_{\mathrm{moy}}$ , is given by:

$\mathrm{cflex}=\frac{1.65}{\lambda}$ with $\lambda =\frac{e{R}_{\mathrm{courb}}}{{R}_{\mathrm{moy}}^{2}}$

This value can be computed directly in the command file; see for example the test FORMA01A[V7.15.100].

In the case where 2 coefficients are given, one obtains: ${I}_{y}=\frac{{I}_{y}(\mathit{tube})}{{\mathit{cflex}}_{xy}},{I}_{z}=\frac{{I}_{z}(\mathit{tube})}{{\mathit{cflex}}_{xz}}$

By default, $\mathit{cflex}={\mathit{cflex}}_{xz}={\mathit{cflex}}_{xy}=1$ (no modification of the geometric inertias).

**Note:** ${\mathit{cflex}}_{xy}$ **is applied to** ${I}_{y}$ **,** ${\mathit{cfle}}_{xz}$ **is applied to** ${I}_{z}$ **.**

##### 9.4.6.2 Operands INDI_SIGM, INDI_SIGM_XZ, INDI_SIGM_XY : Intensification of the stresses

◊ INDI_SIGM = $\mathrm{isigm}$

◊ INDI_SIGM_XZ = ${\mathrm{isigm}}_{xz}$

◊ INDI_SIGM_XY = ${\mathrm{isigm}}_{xy}$

For the computation of the bending stresses in the beam elements of tubular section, one can take into account an intensification coefficient due to ovalisation. The stresses are then written:

${\sigma}_{xx}=\frac{{M}_{y}.R}{{I}_{y}}\times \mathit{isigm}$ or ${\sigma}_{xx}=\frac{{M}_{z}.R}{{I}_{z}}\times \mathit{isigm}$ with $\mathit{isgim}\ge 1$

In the case where 2 indices are given, one has:

${\sigma}_{xx}=\frac{{M}_{y}.R}{{I}_{y}}\times {\mathit{isigm}}_{xy}$ or ${\sigma}_{xx}=\frac{{M}_{z}.R}{{I}_{z}}\times {\mathit{isigm}}_{xz}$

By default, $\mathit{isigm}={\mathit{isigm}}_{xz}={\mathit{isigm}}_{xy}=1$ (no modification of the geometric inertias).

**Note:** ${\mathit{isigm}}_{xy}$ **is applied to** ${M}_{y}$ **,** ${\mathit{isigm}}_{xz}$ **is applied to** ${M}_{z}$ **.**

### 10.3 Rules of use

**The overloading rule is applied**. The orientation taken is the last one assigned.

Example:

```text
ORIENTATION=(
    _F(CARA = ’ANGL_NAUT’, VALE = (1.0, 1.0, 1.0), GROUP_MA = ’GP1’),
    _F(CARA = ’ANGL_VRIL’, VALE = 45.0, GROUP_MA = ’GM1’),
    _F(CARA = ’ANGL_VRIL’, VALE = 90.0, GROUP_MA = ’GM2’),
)
```

- to define the local frame associated with a mesh cell of type POI1 or a node (discrete element), one of the following possibilities must be used: ANGL_NAUT, VECT_X_Y.
- to define the local frame about the axis defined by a mesh cell SEG2 (beam or discrete), one of the following possibilities must be used: ANGL_VRIL, VECT_Y, VECT_Z, VECT_MAIL_Y, VECT_MAIL_Z.
- to define a generatrix line on the pipe elements, GENE_TUYAU must be used.

- There always exists a default local frame attached to the elements of type *POUTRE* or *DISCRET* even if the operand *ORIENTATION* is not used. It corresponds to *ANGL_VRIL = 0* for the elements attached to a mesh cell *SEG2* (beams or discrete elements) and *ANGL_NAUT* = $(0.0, 0.0, 0.0)$ for the nodal discrete elements.

### 10.7 Operand CARA = ’VECT_Y’ | ’VECT_Z’

VECT_Y makes it possible to define the orientation of the principal vector corresponding to the principal axis of inertia Y. ${y}_{1}^{d},{y}_{2}^{d},{y}_{3}^{d}$ are the 3 components of a vector ${Y}^{d}$ whose projection onto the plane orthogonal to ${x}_{3}$ will supply the principal axis of inertia ${y}_{3}$. The axis ${z}_{3}$ (also a principal axis of inertia) is such that $\left(P,{x}_{3},{y}_{3},{z}_{3}\right)$ is right-handed.

VECT_Z makes it possible to define the orientation of the principal vector corresponding to the principal axis of inertia Z. ${z}_{1}^{d},{z}_{2}^{d},{z}_{3}^{d}$ are the 3 components of a vector ${Z}^{d}$ whose projection onto the plane orthogonal to ${x}_{3}$ will supply the principal axis of inertia ${z}_{3}$. The axis ${y}_{3}$ (also a principal axis of inertia) is such that $\left(P,{x}_{3},{y}_{3},{z}_{3}\right)$ is right-handed.

### 10.8 Operand CARA = ’VECT_MAIL_Y’ | ’VECT_MAIL_Z’

VECT_MAIL_Y makes it possible, in the case of the use of a mesh to define the cross-section, to define the orientation of the section, by making the axis ${y}$ of the mesh of the section correspond to the axis ${y}_{3}$ obtained by the projection of ${y}_{1}^{d},{y}_{2}^{d},{y}_{3}^{d}$ onto the plane orthogonal to ${x}_{3}$. The axis ${z}_{3}$ is such that $\left(P,{x}_{3},{y}_{3},{z}_{3}\right)$ is right-handed.

VECT_MAIL_Z makes it possible, in the case of the use of a mesh to define the cross-section, to define the orientation of the section, by making the axis ${z}$ of the mesh of the section correspond to the axis ${z}_{3}$ obtained by the projection of ${z}_{1}^{d},{z}_{2}^{d},{z}_{3}^{d}$ onto the plane orthogonal to ${x}_{3}$. It must therefore be supplied by the keywords: TABLE_CARA = 'name of the table' and NOM_SEC = 'name of the section'.

Keywords used to define the section of multi-fibre beams (modellings POU_D_EM or POU_D_TGM) by assigning to the beam element (mesh cell SEG2) groups of fibres defined by means of the operator [DEFI_GEOM_FIBRE](doc:u4.26.01).

### 11.2 Purpose

Within the framework of a multi-fibre type modelling, there are two “levels” of modelling. There is the so-called “longitudinal” modelling, which will be represented by a beam (of geometric support SEG2), and a plane modelling of the section (perpendicularly to the SEG2). The keyword MULTIFIBRE makes it possible to associate groups of fibres (previously defined by the operator DEFI_GEOM_FIBRE) with a beam element. GEOM_FIBRE makes it possible to give the name of the concept created by DEFI_GEOM_FIBRE containing the description of all the groups of fibres.

**Caution:**

The information contained in the groups of fibres makes it possible to compute certain of the integrated characteristics of the cross-sections (area, static and quadratic moments). For the elements *POU_D_TGM* and *POU_D_EM*, it is necessary to give consistent values for the operands $A,\mathrm{IY},\mathrm{IZ}$ under the keyword *POUTRE*. A check is carried out on the consistency of these quantities. If the relative error is too large (Cf. keywords *PREC_AIRE*, *PREC_INERTIE*) a fatal error is issued.

### 11.5 Operands PREC_AIRE/ PREC_INERTIE

$\frac{ {AIRE}_{POUTRE} - ({AIRE}_{SECTION} + {AIRE}_{FIBRE}) } {{AIRE}_{POUTRE}} \le \text{PREC_AIRE}$

$\frac{ {INERTIE}_{POUTRE} - ({INERTIE}_{SECTION} + {INERTIE}_{FIBRE}) } {{INERTIE}_{POUTRE}} \le \text{PREC_INERTIE}$

- AIRE(fibre), AIRE(section), INERTIE(section), INERTIE(fibre) are computed from the data structure describing the fibres and defined under the keyword GEOM_FIBRE. This data structure is created by the command [DEFI_GEOM_FIBRE](doc:u4.26.01).

  - AIRE(fibre) is computed by summing the areas of the fibres, for all the groups of fibres defined by the keyword GROUP_FIBRE of the operand FIBRE of the command [DEFI_GEOM_FIBRE](doc:u4.26.01).
  - AIRE(section) is computed by summing the areas of the fibres defined by the keyword GROUP_FIBRE of the operand SECTION of the command [DEFI_GEOM_FIBRE](doc:u4.26.01).
  - INERTIE(fibre) is computed by summing the $s.{d}^{2}$ of the fibres defined in the set of groups of fibres defined by the keyword GROUP_FIBRE of the operand FIBRE of the command [DEFI_GEOM_FIBRE](doc:u4.26.01).

    - s: represents the area of a fibre
    - d: is the distance between the fibre and the axis defined by the keyword CARA_AXE_POUTRE of the operand FIBRE of the command [DEFI_GEOM_FIBRE](doc:u4.26.01).
  - INERTIE(section) is computed by summing the $s.{d}^{2}$ of the elements defined by the keyword GROUP_FIBRE of the operand SECTION of the command [DEFI_GEOM_FIBRE](doc:u4.26.01).

    - s: represents the area of an element
    - d: is the distance between the centre of gravity of the element and the axis defined by the keyword CARA_AXE_POUTRE of the operand SECTION of the command [DEFI_GEOM_FIBRE](doc:u4.26.01).
- When the section is defined by a mesh (keyword MAILLAGE_SECT under the operand SECTION of the command [DEFI_GEOM_FIBRE](doc:u4.26.01)), the computation of the global inertia of the set of surface elements does not take into account the inertia specific to each of the elements. It is therefore necessary to define a sufficient number of fibres for this error to be small and to remain lower than PREC_INERTIE. For example, a rectangular section divided uniformly through the height into $n$ elements leads to the following errors, on the values of the inertias:

| Discretisation | 2 | 3 | 4 | 5 | 6 |
| --- | --- | --- | --- | --- | --- |
| Inertia error | 25.00% | 11.11% | 6.25% | 4.00% | 2.77% |

## 12 Keywords DISCRET and DISCRET_2D

### 12.1 Assignable characteristics

These keywords make it possible to assign directly to entities (mesh cells or nodes), which support elements of type DIS_T, DIS_TR (DISCRET) or 2D_DIS_T, 2D_DIS_TR (DISCRET_2D), **matrices** of **stiffness**, of **mass** or of **damping**.

On all the entities one can assign matrices corresponding to the translational degrees of freedom $(T)$ only or to the translational and rotational degrees of freedom $(\mathrm{TR})$ . The matrices may be diagonal $(D)$ or full (symmetric or non-symmetric).

In all cases (symmetric, diagonal, full matrices) **the numbering convention of the terms is imposed**:

- for symmetric matrices, only the upper triangle will be supplied, **with an imposed convention for the numbering of the terms** (see examples).
- for diagonal matrices, only the terms of the diagonal will be supplied, **with an imposed convention for the numbering of the terms** (see examples).
- for non-symmetric matrices, all the terms will be supplied, **with an imposed convention for the numbering of the terms** (see examples).

The matrices may be assigned:

- to nodes or to mesh cells of type POI1; they are then called nodal matrices $(N)$ ,
- to mesh cells of type SEG2; they are then called connection matrices $(L)$ .

In the case of assignment of matrices to mesh cells or to nodes, the element type DISCRET must be assigned, beforehand, to these mesh cells or to these nodes by the operator AFFE_MODELE[U4.41.01].

#### 12.3.5 Operand AMOR_HYST

◊ AMOR_HYST = amorh

Makes it possible to assign to a discrete element a coefficient in order to build a complex stiffness matrix (modelling of hysteretic damping); the matrix built is:

$(1+{\mathrm{j.amor}}_{h}).K$

where $K$ is the matrix K_* whose values are supplied in the same occurrence of the keyword DISCRET. The complex stiffness matrix will actually be built during a call to CALC_MATR_ELEM[U4.61.01] with the option AMOR_HYST (see test SDLD313) and [R5.05.04](doc:r5.05.04).

### 13.6 Operand CHAM_ORIE

The keyword CHAM_ORIE makes it possible to define the orientations from an orientation field whose support is the mesh. As input to this keyword, one expects a field (a map) of the quantity CAMA_R which has 7 components: a scalar (of no importance for the user), the 3 nautical angles and the 3 Euler angles.

It should be noted that this keyword was introduced in order to exploit orientation fields generated automatically from the topology of the mesh by a utility called “Local Frames Generator” available in the Salome platform (from version 9.11). ### 13.7 Example of use

One seeks to model a cylinder made of a transversely isotropic elastic material of type ELAS_ISTR, such that the axis of orthotropy of the material is in the direction of the cylinder. The characteristics of such a material are to be defined in the local frames of the elements, with the convention that the axis of orthotropy must be carried by $N$ (cf. DEFI_MATERIAU[U4.43.01] [§3.5]).

One can imagine two cases:

- the axis of the cylinder has been defined along $Z$ in the global frame. In this case, without performing a rotation of the local frames, one has by default $(X,Y,Z)=(L,T,N)$ and $N$ // $Z$ as desired.
- the axis of the cylinder has been defined along $Y$ in the global frame. It is then necessary to perform a rotation of the local frames in order to bring $N$ along $Y$ as desired. One uses AFFE_CARA_ELEM(MASSIF=_F(ANGLE_REP=(0.,0.,-90.),),) which produces the transformation $(L,T,N)=(X,-Z,Y)$ , and one then indeed has $N$ // $Y$ .

In two dimensions, ELAS_ORTH will be used because ELAS_ISTR is forbidden. If the axis of anisotropy is not parallel to $X$ or $Y$ , the local frame will be rotated as in the 3D example by means of the keyword ANGLE_REP (which this time contains only a single angle) so as to bring $L$ or $T$ into the desired direction.

### 17.4 Principle of the determination of the characteristics of the discrete elements

The document [Seismic response by transient analysis](doc:r4.05.01) gives theoretical information on the method used.

#### 17.4.1 Discrete elements in translation

In 3D, the raft is represented by a set of surface elements of centre of gravity $O$. One therefore has 3 global quantities which characterise the coupling between the soil and the raft: 3 translational stiffnesses ${K}_{x},{K}_{y},{K}_{z}$.

In 2D, the raft is represented by a set of line elements of centre of gravity $O$. One therefore has 2 global quantities which characterise the coupling between the soil and the raft: 2 translational stiffnesses ${K}_{x},{K}_{y}$.

**Note:**

It is the same reasoning for the discrete elements of “damping” type.*

#### 17.4.2 Discrete elements in translation and rotation

In 3D, the raft is represented by a set of surface elements of centre of gravity $O$. One therefore has 6 global quantities which characterise the coupling between the soil and the raft: 3 translational stiffnesses ${K}_{x},{K}_{y},{K}_{z}$, 3 rotational stiffnesses ${Kr}_{x},{Kr}_{y},{Kr}_{z}$.

In 2D, the raft is represented by a set of line elements of centre of gravity $O$. One therefore has 3 global quantities which characterise the coupling between the soil and the raft: 2 translational stiffnesses ${K}_{x},{K}_{y}$, 1 rotational stiffness ${Kr}_{z}$.

**Note:**

It is the same reasoning for the discrete elements of “damping” type.

#### 17.4.3 Distribution of discrete elements in stiffness and in damping

If one wishes to distribute both stiffnesses and dampings, this must be specified under the keyword CARA, for example: CARA = (‘K_T_D_N', ‘A_T_D_N'), both in 2D and in 3D.

The values to be distributed will be given under VALE. For example:

**Note:**

#### 17.4.4 Distribution method

At each node of the mesh of the raft, one seeks the stiffness characteristics of a discrete element of type $\text{K_TR_D_N} = \left( {k}_{x}, {k}_{y}, {k}_{z}, {kr}_{x}, {kr}_{y}, {kr}_{z} \right)$ cf. [Seismic response by transient analysis](doc:r4.05.01).

To determine the translational stiffnesses, one imposes that they be proportional to the area represented by the node and to a distribution function depending on the distance to the centre of gravity of the raft. Let $S(P)$ be the area attached to the node $P$ and $f(r)$ the distribution function where $r$ is the distance from the node $P$ to the node $O$.

For the rotational stiffnesses, one distributes the remainder (what remains after having removed the contributions due to the translations) in the same way as the translations.

If one computes the forces and the resulting moments at the point $O$ due to the distribution of the springs at each node of the mesh of the raft and if one identifies them with the global values, one obtains the following formulae:

$\begin{array}{ccc}{k}_{x}={K}_{x}/\left(\sum_{p}S(p)f({op})\right)& ;& {k}_{x}(p)={k}_{x}S(p)f({op})\\ {k}_{y}={K}_{y}/\left(\sum_{p}S(p)f({op})\right)& ;& {k}_{y}(p)={k}_{y}S(p)f({op})\\ {k}_{z}={K}_{z}/\left(\sum_{p}S(p)f({op})\right)& ;& {k}_{z}(p)={k}_{z}S(p)f({op})\end{array}$

$\begin{array}{ccc}{k}_{rx}=\left({K}_{rx}-\sum_{p}\left({k}_{z}(p){y}_{op}^{2}+{k}_{y}(p){z}_{op}^{2}\right)\right)/\left(\sum_{p}S(p)f({op})\right)& ;& {k}_{rx}(p)={k}_{rx}S(p)f({op})\\ {k}_{ry}=\left({K}_{ry}-\sum_{p}\left({k}_{x}(p){z}_{op}^{2}+{k}_{z}(p){x}_{op}^{2}\right)\right)/\left(\sum_{p}S(p)f({op})\right)& ;& {k}_{ry}(p)={k}_{ry}S(p)f({op})\\ {k}_{rz}=\left({K}_{rz}-\sum_{p}\left({k}_{x}(p){y}_{op}^{2}+{k}_{y}(p){x}_{op}^{2}\right)\right)/\left(\sum_{p}S(p)f({op})\right)& ;& {k}_{rz}(p)={k}_{rz}S(p)f({op})\end{array}$

**Note 1:**

**Note 2:**

One considers that the same formulae can be applied in order to carry out a distribution of discrete damping elements.

### 19.3 Description of the operands

#### 19.3.1 Distribution method

One denotes by $S(p)$ the area pertaining to the node p of the raft, $G(x_G,y_G)$ its geometric centre. One sets:

- $S_{tot} = \sum S(p)$,
- $I_x = \sum S(p) (y_p − y_G )^2$,
- $I_y = \sum S(p) (x_p − x_G )^2$.

The equivalent distribution laws are then:

- $k_x(p) = k_x {S(p) \over S_{tot}}$
- $k_y(p) = k_y {S(p) \over S_{tot}}$
- $k_z(p) = k_z {S(p) \over S_{tot}}$
- $k_{rx}(p) = k_{rx} {S(p) \over I_x}$
- $k_{ry}(p) = k_{ry} {S(p) \over I_y}$

## 20 Keyword MASS_AJOU

### 20.1 Syntax

```text
◇ MASS_AJOU = _F(
    ◆ GROUP_MA = grma,
    ◆ GROUP_MA_POI1 = grma,
    ◆ FONC_GROUP = fonction / formule / nappe,
),
```

### 20.2 Assignable characteristics

The objective of this keyword is to take into account simply the added mass of fluid without having to model the fluid as in [MACRO_MATR_AJOU](doc:u4.66.11) and to keep only the structure for non-linear dynamic studies.

The idea is therefore, in a new option of `AFFE_CARA_ELEM`, to distribute point-mass characteristics to the nodes of the fluid-structure interface without adding degrees of freedom.

One draws inspiration from the distribution of the global stiffness or damping characteristics carried out by the option RIGI_PARASOL of `AFFE_CARA_ELEM`.

The option `MASS_AJOU` makes it possible to distribute to the nodes of the fluid-structure interface characteristics `M_T_N` with elementary values of directional mass. These values are obtained by integration of the normal pressure on the elements from distribution functions which may depend on the coordinates, in particular on the altitude, in order to express Westergaard relations or, more simply, the expression of the hydrostatic pressure.

The assignment of these terms (modelling to be declared in [AFFE_MODELE](doc:u4.41.01): `DIS_T` for a surface fluid-structure interface in 3D and `2D_DIS_T` for a line fluid-structure interface in 2D) is made to the point mesh cells `POI1` of the nodes of the fluid-structure interface by means of the keyword `GROUP_MA_POI1` of the factor keyword `MASS_AJOU`.

These point mesh cells must be distinguished from the surface or line mesh-cell groups for the fluid-structure interface, to be declared after the keyword `GROUP_MA`.

In the case where the result of the command `AFFE_CARA_ELEM` with the keyword `MASS_AJOU` is used to carry out an analysis with results coming from an analogous model without `MASS_AJOU`, for example within the framework of an analysis with an **initial state** coming from a model without added mass, it is necessary to extend the result over the whole of the new model, in order to initialise the fields correctly.
This can be done via the command [PROJ_CHAMP](doc:u4.72.05) with `PROL_VALE = 0.0`.

## 21 Keyword MASS_REP

### 21.1 Syntax

```text
MASS_REP = _F(
    # Surface ou ligne servant à répartir la masse
    ◆ GROUP_MA = grma,
    # Mailles de type POI1 correspondant aux masses
    ◆ GROUP_MA_POI1 = grma,
    # Masse à répartir sur les mailles de GROUP_MA
    ◆ VALE = float,
    ◆ TYPE = / "LINEIQUE",
             / "SURFACIQUE",
             / "TOTALE",
    # Fonction de répartition de la masse
    ◇ FONC_MULT = fonction / formule / nappe,
),
```

### 21.2 Assignable characteristics

The objective of this keyword is to take into account simply a mass and to distribute it over a surface. The option MASS_REP makes it possible to distribute to the nodes of the discrete elements of characteristic `M_T_D_N` mass values obtained in proportion to the area of the surface mesh cells or to the length of the line mesh cells.

The assignment (modelling `DIS_T` to be declared in [AFFE_MODELE](doc:u4.41.01)) is made to the point mesh cells `POI1` given to `GROUP_MA_POI1`. The point mesh cells and the surface mesh cells to be declared after the keyword `GROUP_MA` must be distinguished.

The overloading rule applies [The main operating principles of Code_Aster](doc:u1.03.00). If a mesh cell `POI1` is present in several occurrences of MASS_REP, it is the last assignment which is taken into account.

**In the case of overloading, a piece of information is written in the ‘message’ file, indicating the number of overloadings carried out.**
