# v2.01.107 SDLD107 - Minimization of an energy function of error type in relation to dynamic behaviour of structures

**Summary:**

The application field of this test is for structural dynamics. It allows to validate the CALC_ERC_DYN [u4.53.41](doc:u4.53.41) computing operator, which allows to obtain fields solution of a problem of minimizing an energy function of error-like behavioral type (ERC) under a modal formulation.

The solution is to solve the problem of ERC for a system composed of 3 masses and 4 springs, clamped at its ends in free vibration. Springs and masses are modelled by elements type 'DIS_T'.

The results of the audit for the case studied were obtained semi-analytically. Its resolution, which serves as a reference, was carried out using the Matlab software.

## 1 Reference problem

### 1.1 Geometry

The system studied is composed of 3 masses ($m$ ) and 4 springs ($k$ ). The whole is clamped at its ends.

![Figure](/figures/v2.01.107/1000076A0000208E00000C679E654F16CD539F7B.svg)

**Image** 1.1-a **: Geometry of the system studied**

### 1.2 Material properties

Stiffness springs: $k=\mathrm{1 }N/m$ .

Point mass: $m=\mathrm{1 }\mathrm{kg}$ .

### 1.3 boundary conditions

$A$ and $B$ clamped points.

### 1.4 Initial conditions

Structure initially at rest.

### 1.5 Observation

The two translation x1 and x2 are considered to be perfectly observed.

The first two modes are considered to be:

- For the first mode of its own, the two translation x1 and x2 are assumed, as well as its perfectly observed own pulse ($\widehat{{\omega}_{1}}={\omega}_{1}$ ).
- For the second mode of the same, the two perfectly observed x1 and x2 translations are considered, while the information on the own pulse is assumed to be tainted by an error of 25% ($\widehat{{\omega}_{2}}=1,25\ast {\omega}_{2}$ ).

### 1.6 Error function

The error of energy function error in relation to the following behaviour is minimized:

${e}_{\omega}^{2}(u,v,w)=\frac{\gamma}{2}{(u-v)}^{T}[K](u-v)+\frac{1-\gamma }{2}{(u-w)}^{T}{\omega}^{2}[M](u-w)+\frac{1-\alpha }{\alpha}{(\mathit{Hu}-\widehat{u})}^{T}\text{}[\mathit{Gr}](\mathit{Hu}-\widehat{u})$

## 2 reference solution

### 2.1 Calculation method used for reference solution

#### 2.1.1 Reference model

For the reference model the following displacement vector is assumed:

$x=\left(\begin{array}{c}{x}_{1}\\ {x}_{2}\\ {x}_{3}\end{array}\right)$

Thus, the structural mass matrices (M) and stiffness (K) are:

$M=\left(\begin{array}{ccc}1& 0& 0\\ 0& 1& 0\\ 0& 0& 1\end{array}\right)$ $K=\left(\begin{array}{ccc}2& -1& 0\\ -1& 2& -1\\ 0& -1& 2\end{array}\right)$

The proper pulses of the mass-spring system are:

${\omega}_{1}^{2}=(2-\sqrt{2})$ ${\omega}_{2}^{2}=2$ ${\omega}_{3}^{2}=(2+\sqrt{2})$

of the respective modal deformities (standardized at 1 at the greatest amplitude):

${\varphi}_{1}=\frac{1}{2}\left(\begin{array}{c}\sqrt{2}\\ 2\\ \sqrt{2}\end{array}\right)$ ${\varphi}_{2}=\left(\begin{array}{c}-1\\ 0\\ 1\end{array}\right)$ ${\varphi}_{3}=\frac{1}{2}\left(\begin{array}{c}-\sqrt{2}\\ 2\\ -\sqrt{2}\end{array}\right)$

The matrix for the perfect observation of x1 and x2 is:

$H=\left(\begin{array}{ccc}1& 0& 0\\ 0& 1& 0\end{array}\right)$

In addition, the standard matrix (Gr) is chosen by combining the reduced Guyan mass and stiffness matrices. For their construction, the static modes associated with x1 and x2 are:

${\psi}_{1}=\left(\begin{array}{c}1\\ 0\\ 0\end{array}\right)$ ${\psi}_{2}=\left(\begin{array}{c}0\\ 1\\ 0.5\end{array}\right)$

Forming the $\psi =\left[{\psi}_{1}{\psi}_{2}\right]$ static mode base. This leads to:

${G}_{r}={\psi}^{T}[K+M]\psi$ ;

$\mathit{Gr}=\left(\begin{array}{cc}3& -1\\ -1& 2.75\end{array}\right)$

The weighting parameters of ${e}_{\omega}^{2}(u,v,w)$ are selected $\alpha =0.5$ and $\gamma =0.5$ .

#### 2.1.2 Construction of linear system associated with problem of error function in relation to behaviour.

The problem of finding fields associated with the behavioral error-like function leads to the resolution of the following linear matrix system:

$Al=b$

with, for each individual pulse ${\omega}_{i}$:

${A}_{i}=\left(\begin{array}{cc}\gamma (K+\gamma /(1-\gamma ){\omega}_{i}^{2}M)& -\gamma (K-{\omega}_{i}^{2}M)\\ -\gamma (K-{\omega}_{i}^{2}M)& (-2\alpha /(1-\alpha )){H}^{T}{G}_{r}H\end{array}\right)$ et ${b}_{i}=\left(\begin{array}{c}{0}_{3}\\ (-2\alpha /(1-\alpha )){H}^{T}{G}_{r}\widehat{{u}_{i}}\end{array}\right)$

where $\widehat{{u}_{i}}$ represents the observation of the ${\varphi}_{i}$ mode associated with the estimated ${\omega}_{i}$ own pulse. $\alpha$ and $\gamma$ are the weighting parameters associated with the error function.

Finally, the $l$ solution vector is the concatenation of two fields associated with the error function in such a way that:

$l=\left(\begin{array}{c}u-v\\ u\end{array}\right)$

### 2.2 Baseline

Two reference cases are tested:

1. First eigenmode, perfect observations:

$\widehat{{u}_{1}}=\left(\begin{array}{c}\frac{\sqrt{2}}{2}\\ 1\end{array}\right)$ ; $\widehat{{\omega}_{1}}=(2-\sqrt{2})$

In this case, the result is trivial as it must lead to a perfectly zero error functional result associated with:

$(u-v)=\left(\begin{array}{c}0\\ 0\\ 0\end{array}\right)$ ; $u=\frac{1}{2}\left(\begin{array}{c}\sqrt{2}\\ 2\\ \sqrt{2}\end{array}\right)$

1. Second eigenmode, perfect moves, and clean pulse tainted with error:

$\widehat{{u}_{2}}=\left(\begin{array}{c}-1\\ 0\end{array}\right)$ ; $\widehat{{\omega}_{2}}=1.25\ast 2$

In this case, the construction of the $Al=b$ matrix problem leads to:

$A=\left(\begin{array}{cccccc}1+{1.25}^{2}& -0.5& 0& -1+{1.25}^{2}& 0.5& 0\\ -0.5& 1+{1.25}^{2}& -0.5& 0.5& -1+{1.25}^{2}& 0.5\\ 0& -0.5& 1+{1.25}^{2}& 0& 0.5& -1+{1.25}^{2}\\ -1+{1.25}^{2}& 0.5& 0& -6& 2& 0\\ 0.5& -1+{1.25}^{2}& 0.5& 2& -5.5& 0\\ 0& 0.5& -1+{1.25}^{2}& 0& 0& 0\end{array}\right)$

$b=\left(\begin{array}{c}0\\ 0\\ 0\\ 6\\ -2\\ 0\end{array}\right)$

This system of equations was solved using the Matlab software, leading to the solution:

$l=\left(\begin{array}{c}0.223608826207038\\ 0.107013222975753\\ -0.095122864867336\\ -0.957415448053491\\ 0.038110367724860\\ 0.494584477951991\end{array}\right)$

In this case, the value of the function is:

${e}_{{\omega}_{2}}^{2}(u,v,w)=0.089643288114668$

the part associated with the error fields is:

$\frac{\gamma}{2}{(u-v)}^{T}[K](u-v)+\frac{1-\gamma }{2}{(u-w)}^{T}{\omega}^{2}[M](u-w)=0.083454681437031$

### 2.3 Uncertainty about the solution

First case: analytical solution.

Second case: semi-analytic solution.

## 4 Summary of the results

The accuracy of the optimum fields (u) and (u-v) and the functional value is very good (errors in the order of 1E-12 to 1E-14)

This test therefore validates the CALC_ERC_DYN operator for the search calculation of eligible fields associated with an error-like energy functional problem in relation to dynamic behavior under a modal formulation.
