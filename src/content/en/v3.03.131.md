# v3.03.131 SSLS131 – Optimization of curvature radius of a bent pipe

**Summary:**

This demonstration test illustrates the use of python in *Code_Aster* .

The objective of this test case is to optimize the value of the radius of curvature of a pipe via a python loop. The radius of curvature is changed iteratively. The optimal value is obtained when the maximum stress of Von Bets is below a threshold.

The python language in this test case allows for:

- modify the file describing the elbow geometry,
- to launch GMSH in order to knit the elbow,
- to recover the maximum stress of Von Bets,
- d
- to launch GMSH to perform an interactive post-processing.

This test case takes up the problem of the test case forma01f: bent piping, consisting of a linear elastic material, subjected to a force applied at its end, modelled by elements shells DKT.

**Note:**

To have interactive visualization functions, set interactive = 1 at the beginning of the command file.

## 1 Reference problem

### 1.1 Geometry

The study concerns a pipe with two straight pipes and one elbow [Figure 1.1-a].

The geometrical data of the problem are as follows:

- the ${L}_{G}$ length of both straight pipes is $3m$ ,
- the initial $\mathrm{Rc}$ radius of the elbow is $0.3m$ ,
- the angle $\theta$ of the elbow is 90 degrees,
- the thickness of the straight pipes and elbow is $0.02m$ ,
- and the $\text{Re}$ outer radius of the straight pipes and elbow is $0.2m$ .

![Figure](/figures/v3.03.131/100013EA0000288400001F36789D77AD3C40BA9C.svg)

**Figure 1.1-a**

**Note:**

*The geometry of the problem shows a symmetry with the plane* $(A,X,Y)$ *.*

### 1.2 Material properties

Isotropic linear elastic material. Material properties are those of $\mathrm{A42}$ steel:

| le Young's modulus: | $E=1.8{10}^{11}\mathrm{Pa}$ |
| --- | --- |
| le Poisson's ratio: | $\nu =0.3$ |

### 1.3 Boundary conditions and loads

- Boundary conditions : clamped support at $A$ section ,
- Loading: constant force $\mathrm{FY}$ directed on the $Y$ axis and applied on the $B$ section.

The value of $\mathrm{FY}$ shall be calculated from:

- of the average radius: $\mathrm{RMOY}=0.19$ ,
- of the total force applied: $\mathrm{FTOT}=500000N/{m}^{2}$ ,

The expression is as follows:

$\mathrm{FY}=\mathrm{FTOT}/(2\pi \mathrm{RMOY})(\simeq 418828.8)$

- The constraint of Von Bets limit is $2.0E+09N/{m}^{2}$

## 2 reference solution

### 2.1 Calculation method used for reference solution

The reference solution is obtained numerically, so it is only a non-regression test.

### 2.2 Modelling results

The optimum value of the radius of curvature, respecting the criterion ${\sigma}_{\mathrm{mises}}<{2.10}^{9}{\mathrm{N.m}}^{-2}$ is $\mathrm{1.1m}$ , obtained after 5 iterations. At each iteration the radius of curvature is increased by $0.2m$ .

| **Iterations** | ** Curvature test** | **Max. Von Bettings* |
| --- | --- | --- |
| 1 | $0.3m$ | $3.3315E+09N/{m}^{2}$ |
| 2 | $0.5m$ | $2.7647E+09N/{m}^{2}$ |
| 3 | $0.7m$ | $2.4256E+09N/{m}^{2}$ |
| 4 | $0.9m$ | $2.1727E+09N/{m}^{2}$ |
| 5 | $1.1m$ | $1.9670E+09N/{m}^{2}$ |

### 2.3 Uncertainty about the solution

Non-regression solution.

### 3.2 Mesh characteristics

The mesh is regenerated at each iteration due to the modification of the radius of curvature of the geometry. However, the topological characteristics of the mesh are unchanged:

- 1013 mesh cells(900 TRIA3, 110 SEG2, 3POI3)
- 507 nodes.

Mesh cells groups correspond to:

- $\mathrm{GM30}$ $\mathrm{TUYAU}$ surface
- $\mathrm{GM28}\iff$ section B (effort)
- $\mathrm{GM31}\iff$ point $\mathrm{A1}$ $(-R,0,0)$
- $\mathrm{GM27}\iff$ section $A$ (clamped support)
- $\mathrm{GM29}\iff \mathrm{SYMETRIE}$

### 3.3 Aster Commands

This paragraph describes the algorithm used in the command file and presents the *Code_Aster* commands used.

- Initialization of certain variables:
- Curvature radius: $\mathrm{Rc}=0.3$
- Convergence criterion: $\mathrm{crit}=2.0E+09$ (Target Von Bets stress)
- The python loop shall be entered and the stopping criterion shall be for the maximum stress of Von Bets. As long as the criterion is not met, the following instructions shall be made:
- Reconstruction of mesh:
- $\mathrm{Rc}$ is redefined in the GMSH .geo geometric file
- run gmsh via python to generate the file of mesh .msh
- Play mesh (PRE_GMSH) and generate mesh (LIRE_MAILLAGE). DEFI_GROUP is used to rename mesh cells groups according to the match:

```text
# GM30 <=> TUYAU    # GM28 <=> EFOND
# GM31 <=> A1        # GM27 <=> ENCAST
# GM29 <=> SYMETRIE
```

- Definition of the finished elements used (AFFE_MODELE). Straight pipes and elbow are modeled by elements hull (DKT).
- Normal elements reorientations: MODI_MAILLAGE is used to orient all elements in the same way, with a normal inward-facing orientation.
- Definition and allocation of the material (DEFI_MATERIAU and AFFE_MATERIAU). The mechanical characteristics are identical throughout the structure.

Python buckle for optimization of curvature radius

- Assignment of elements hull characteristics (AFFE_CARA_ELEM): thickness, V vector defining the counting mark (keyword ANGL_REP)
- Definition of boundary conditions and loading (AFFE_CHAR_MECA).
- The pipe is clamped at its base, on all nodes located in plane Y=0. The pipe shows a plane of symmetry $Z=0$ .
- A $\mathrm{FY}$ distributed force is calculated, directed to the $Y$ axis and applied to the $B$ section (the distributed force is such that the $2\pi .\mathrm{RMOY.}\mathrm{FY}=\mathrm{FTOT}$ result, $\mathrm{FTOT}$ being the total force that you want to apply). To apply the force on section B, FORCE_ARETE will be used.
- Resolution of the linear elastic problem (MECA_STATIQUE).
- Calculation of the stress field by elements to nodes for each load case (option 'SIGM_ELNO'). The stresses are calculated in the local benchmark defined for each element using the $V$ vector (previous ANG_REP keyword). Use NIVE_COUCHE to set the calculation level in thickness.
- Calculation of the equivalent stress field by elements to nodes calculated from the stress field (option 'SIEQ_ELNO').
- Calculation of the previous fields to nodes (options 'SIGM_NOEU', 'SIEQ_NOEU')
- Printing results (IMPR_RESU).
- Determination of a table containing the calculation of the stress field averages equivalent to nodes.(‘POST_RELEVE_T')
- Extract the VMIS component from the previous table via python.
- Stop test:
- If VMIS is greater than CRIT, then repeat with $\mathrm{Rc}=\mathrm{Rc}+0.2$
- Otherwise we'll get out of the python loop.
