# u2.01.02 User's guide to boundary conditions treated by elimination

> **Summary.**

The treatment of Dirichlet boundary conditions by elimination (AFFE_CHAR_CINE) does not offer the same generality as treatment by dualisation (AFFE_CHAR_MECA, for example).

This treatment is to be used when one seeks to improve the execution time of a run, or when one wishes to work with positive-definite matrices.

Note that the boundary conditions available in AFFE_CHAR_* ( * = MECA/THER/ACOU) cannot all be eliminated and treated by AFFE_CHAR_CINE.

This document shows how to use the "kinematic loads" in Aster command sets.

There are 3 cases (from the simplest to the most complicated):

- One uses a "global" analysis command (THER_LINEAIRE, STAT_NON_LINE, …). In this case, the kinematic loads are used like the other loads.
- One wishes to carry out an eigenmode analysis. An argument must then be added in the command ASSE_MATRICE.
- One wishes to carry out a "step-by-step" analysis and to solve the linear systems with the commands FACTORISER and RESOUDRE. In this case, the command CALC_CHAR_CINE must be used.

## 1 Principle of elimination

One seeks to solve in ${ℝ}^{n}$ the following constrained minimisation problem (Pb1):

$\underset{u\in {U}_{G}}{\min}(\frac{1}{2}{u}^{T}Ku-{u}^{T}f)$ with ${U}_{G}=\left\lbrace u\in {ℝ}^{n},{u\mid }_{G}={u}_{0}\right\rbrace$

where

- ${u}_{0}\in {ℝ}^{p}$ is known ($1\le p\le n$ )
- $G$ is the subset of $N=\lbrace 1,\mathrm{...},n\rbrace$ , of cardinality $p$ : $G={g}_{1}\mathrm{...}{g}_{p}$
- ${u\mid }_{G}$ is the projection of $u$ onto the subspace spanned by ${\lbrace {u}_{i}\rbrace }_{i\in G}$
- where ${({u}_{i})}_{j}={\delta}_{ij},\forall j\in N$
- $K$ is a symmetric matrix $n\times n$ ,
- $f\in {ℝ}^{n}$ is given.

The constraint ${u\mid }_{G}={u}_{0}$ represents boundary conditions of Dirichlet type, homogeneous or not.

If one denotes by $L={C}_{N}G$ the complement of $G$ in $N$ , one can, with the help of the ${u}_{i}$  defined above, decompose ${ℝ}^{n}$ into the direct sum of ${V}_{G}$ = vector space spanned by ${\lbrace {u}_{i}\rbrace }_{i\in G}$ and of ${V}_{L}$ = vector space spanned by ${\lbrace {u}_{i}\rbrace }_{i\in L}$ ;

Hence we have ${ℝ}^{n}={V}_{G}\oplus {V}_{L}$

and one writes $u={u}_{G}\oplus {u}_{K}$ where ${u}_{G}={u\mid }_{G}$ and ${u}_{L}={u\mid }_{L}$

or again, in vector notation, $u=\left\lbrace \begin{array}{}{u}_{G}\\ {u}_{L}\end{array}\right\rbrace$

The problem (Pb1) can therefore be written in the form of the problem (Pb2):

$\lbrace \begin{array}{}\min(\frac{1}{2}{u}_{G}^{T}{K}_{\text{GG}}{u}_{G}+\frac{1}{2}{u}_{L}^{T}{K}_{\text{LL}}{u}_{L}+{u}_{L}^{T}{K}_{\mathrm{LG}}{u}_{G}-{u}_{L}^{T}{f}_{L}-{u}_{G}^{T}{f}_{G})\\ {u}_{G}\in {V}_{G}\\ {u}_{L}\in {V}_{L}\\ {u}_{G}={u}_{0}\end{array}$

Which amounts to writing:

$(\text{Pb1})\iff (\text{Pb2})$ $\lbrace \begin{array}{}\min(\frac{1}{2}{u}_{L}^{T}{K}_{\text{LL}}{u}_{L}+{u}_{L}^{T}{K}_{\mathrm{LG}}{u}_{0}-{u}_{L}^{T}{f}_{L})\\ {u}_{L}\in {V}_{L}\\ u={u}_{0}\oplus {u}_{L}\end{array}$

One has then eliminated ${u}_{G}$ from the minimisation problem.

We shall now look for the matrix problem associated with (Pb3).

One looks for ${u}_{L}$ minimising

$\frac{1}{2}{u}_{L}^{T}{K}_{\text{LL}}{u}_{L}+{u}_{L}^{T}{K}_{\mathrm{LG}}{u}_{0}-{u}_{L}^{T}{f}_{L}$

which amounts to solving the following matrix problem:

${K}_{\text{LL}}{u}_{L}={F}_{L}-{K}_{\mathrm{LG}}{u}_{0}$

One may therefore write:

$(\text{Pb1})\iff (\text{Pb2})\iff (\text{Pb3})\iff \left[\begin{array}{cc}{K}_{\text{LL}}& 0\\ 0& {I}_{G}\end{array}\right]\left[\begin{array}{}{u}_{L}\\ {u}_{G}\end{array}\right]=\left[\begin{array}{}{f}_{L}-{K}_{\mathrm{LG}}{u}_{0}\\ {u}_{0}\end{array}\right]$ , that is $K'\left[\begin{array}{}{u}_{L}\\ {u}_{G}\end{array}\right]=f'$

## 2 Treatment in Aster

### 2.1 The kinematic loads

A kinematic load (Aster type: char_cine_* [* = meca/ther/acou]) makes it possible to characterise the set G of the imposed degrees of freedom and the ${({u}_{0})}_{i}$ for $i\in G$, which are the values assigned to these degrees of freedom.

The definition of a kinematic load is made by means of the operator AFFE_CHAR_CINE for the (u0)i which are constant, or functions of the geometry or of time.

### 2.2 The kinematic vectors

The kinematic vector is a cham_no_* which represents the vector $\left[\begin{array}{}0\\ {u}_{0}\end{array}\right]$ .

To each kinematic load there corresponds a kinematic vector.

This operation is carried out by the operator CALC_CHAR_CINE.

### 2.3 Computation of K'

K' is computed directly at assembly time by the operator ASSE_MATRICE, provided of course that a list of kinematic loads is supplied as an argument.

The data structure MATR_ASSE_* has been modified so as to be able to store K' when this is necessary.

### 2.4 Computation of f'

After the operator FACTORISER, the produced concept of type matr_asse_* contains the factorised form of K' and the unchanged matrix KLG.

The computation of f' is carried out at solution time: the kinematic vector corresponding to $\left[\begin{array}{}0\\ {u}_{0}\end{array}\right]$  must be supplied to the operator RESOUDRE as an argument, by means of the keyword CHAM_CINE.

This operator then computes $f'$ before solving $\text{fact}(K')\left[\begin{array}{}{u}_{L}\\ {u}_{G}\end{array}\right]=f'$ .

## 3 Examples of command files

### 3.1 Mechanical analysis with a global command (STAT_NON_LINE)

**DEPIMP** = **AFFE_CHAR_CINE** ( MODELE=MOD,

MECA_IMPO=_F( GROUP_MA = 'LCD1', DY = -2.0))

RESU=STAT_NON_LINE( MODELE=MOD, CHAM_MATER=CHMAT,

EXCIT= _F( **CHARGE**  = **DEPIMP** , FONC_MULT = FONC),

...)

### 3.2 Kinematic loads for an eigenmode analysis

**CHARCINE** = **AFFE_CHAR_CINE** (MODELE=MODEL,

MECA_IMPO=_F(GROUP_MA='GM2', DX=0.0, DY=0.0))

KASS= **ASSE_MATRICE** (MATR_ELEM=KELEM,

NUME_DDL=NUME,

**CHAR_CINE=CHARCINE** ,);

MASS= **ASSE_MATRICE** (MATR_ELEM=MELEM,

NUME_DDL=NUME,

**CHAR_CINE=CHARCINE** ,);

# computation of the eigenmodes of the structure

MODES=CALC_MODES(MATR_RIGI=KASS,

MATR_MASS=MASS,

CALC_FREQ=_F( NMAX_FREQ=10 ))

### 3.3 "Step-by-step" analysis using the commands FACTORISER and RESOUDRE

**CHCINE=AFFE_CHAR_CINE** ( MODELE=MO, MECA_IMPO=(

_F( GROUP_NO = 'SUPY', DY = 0.),

_F( GROUP_NO = 'CHARGE', DX = -1.)))

MEL=CALC_MATR_ELEM( MODELE=MO, CHAM_MATER=CHMAT, OPTION='RIGI_MECA')

NU=NUME_DDL( MATR_RIGI=MEL )

MATAS= **ASSE_MATRICE** ( MATR_ELEM=MEL, NUME_DDL=NU, **CHAR_CINE=CHCINE** )

SCMBRE=CREA_CHAMP( ... )

**VCINE=CALC_CHAR_CINE** ( NUME_DDL=NU, **CHAR_CINE=CHCINE**  )

MATAS=FACTORISER(reuse=MATAS, MATR_ASSE=MATAS )

DEP= **RESOUDRE** (MATR=MATAS, CHAM_NO=SCMBRE, **CHAM_CINE=VCINE** )
