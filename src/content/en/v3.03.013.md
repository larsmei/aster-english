# v3.03.013 SSLL13 - Combination of static and seismic loads on finely meshed plate

**Summary**

The purpose of this test is to validate the operation of the POST_COMBINAISON command. The POST_COMBINAISON command allows the combination of different physical quantitiess following calculations to the elementss completed upstream. This command will only perform post-processings by manipulating results in the form of fields or tables from previous calculations.

This test involves a rectangular plate, which is submitted to its own weight, three cases of loads and seismic stresses.

The test saves the results obtained during the call to the POST_COMBINAISON command, and checks its operation in the following situations:

- Data structures of the sd_result type to be combined.
- Data structures of the sd_table type to be combined. The tables are of type ‘RESULTANTE

## 1 Reference problem

The POST_COMBINAISON command calculates linear combinations of different calculation results associated with user-defined coefficients.

${C}_{i}\text{}\text{}\text{}=\text{}\text{}\text{}({\alpha}_{i,1}\times {Q}_{1})\text{}\text{}\text{}+\text{}\text{}\text{}({\alpha}_{i,2}\times {Q}_{2})$

Où :

- is the number of the combination
- Q1 is the result/table resulting from a first calculation at the finished elements
- Q2 is the result/table resulting from a first calculation at the finished elements
- αi,1is the coefficient associated with Q1
- αi,2is the coefficient associated with Q2
- This is the result of the combination performed.

## 2 Modelling A

### 2.1 Mesh characteristics

The structure is modelled by a regular mesh ‘2D' composed of $600\times 150$ QUA4(see ).

![Figure](/figures/v3.03.013/10000000000004310000027E291D03AB04F6A0EF.svg)

**Figure** 2.1-1 **: mesh**

### 2.2 Model

The model is based on isotropic mechanical elastic modelling.

The geometry is meshed by elements finished types **DKT thin shells.**

The geometric support elements are linear quadrangles.

### 2.3 Combinations

The coefficients of the combination table are generated randomly. The number of combinations has been set at 240.

### 2.4 Call to order

#### 2.4.1 Format ‘RESULTAT

The command takes directly into argument the ‘RESULTAT' objects corresponding to the three loads to be combined[sustains from the MACRO_ELAS_MULT and MECA_STATIQUE commands, and COMB_SISM_MODAL].

The coefficients of the combinations are defined by means of a random drawing.

Output will be recovered an object ‘RESULTAT , multiple [mult_elas] also, with 240order numbers (combinations).

#### 2.4.2 Format ‘TABLE

The command takes in arguments the ‘RESULTAT' objects corresponding to the two loads to be combined[sustains from the MACRO_ELAS_MULT and MECA_STATIQUE commands].

The result fields are first converted into tablesvia the CALC_COUPURE command, giving a result value extracted in the middle of the plate thickness.

By passing these tables as argument, the POST_COMBINAISON command returns an object ‘TABLE
