# v3.02.321 SSLP321 - Propagation of a X-FEM crack in a 3-point bending plate

**Summary**

This test is intended to validate the crack propagation path with $\text{X-FEM}$ in $\mathrm{2D}$ , as part of the linear elasticity.

This test involves a rectangular plate with a crack opening, and subjected to a 3 point bending as in the article by Mariani and Perego .

Five methods to manage the propagation of $\text{X-FEM}$ cracks are available, each of which is modeled.

- $A$ Modelling: mesh method
- $B$ Modelling: simplex method
- $C$ Modelling: upwind method
- $D$ Modelling: geometric method

Comparisons are made with the values given by the mesh method.

## 1 Reference problem

### 1.1 Geometry

Geometry, dimensions and materials are taken identical to those of Mariani et al.

The $\mathrm{2D}$ structure is a rectangular plate ($230\mathrm{mm}\times 75\mathrm{mm}$ ), with an opening crack (see v3.02.321-fig-geometry-plate-fissuree). The initial crack length is $a=19\mathrm{mm}$ .

The nodes rated $\mathrm{P1}$ , $\mathrm{P2}$ and $\mathrm{P3}$ are used to impose the boundary conditions, which is explained to the v3.02.321-conditions-limits-loads.

![Figure](/figures/v3.02.321/100000000000036C000001F4204637ECE470175F.jpg)

*Geometry of cracked plate*

### 1.2 Material properties

Young's modulus:                $E=31,37{10}^{9}\mathrm{Pa}$

Poisson's ratio:        $\nu =0.2$

### 1.3 Boundary conditions and loads

The load consists of applying a single nodal force in $\mathrm{P3}$ .

In order to block rigid modes, the nodes $\mathrm{P1}$ and $\mathrm{P2}$ movements are blocked as follows:

- ${\mathrm{DY}}^{\mathrm{P1}}={\mathrm{DY}}^{\mathrm{P2}}=0$ ;
- ${\mathrm{DX}}^{\mathrm{P1}}=0$ .

## 2 reference solution

### 2.1 Method of calculation

The study of this case is entirely based on Mariani and Perego's article. Three initial crack configurations are selected: $\chi =0,25$ and $50$. In this test case we chose only $\chi =50$. Thus, the propagation path compared to the experimental path of the bib1 article is compared.

The reference expressions of the stress factors ${K}_{I}$ and ${K}_{\mathit{II}}$ are those of the mesh method. Thus, the values of the simplex, upwind and geometric methods will be compared to the values given by the mesh method.

For the spread of the crack, we use the Paris law:

$\begin{array}{c}\frac{\mathit{da}}{\mathit{dN}}=C\Delta {K}^{m}\end{array}$ where a is crack length, $C$ and $m$ are material constants, $\begin{array}{}\Delta K\end{array}$ is the difference between two consecutive $\mathrm{FIC s}$ and $N$ is the number of cycles.

The bifurcation criterion used is *maximum hoop stress criterion*:

$\begin{array}{c}\beta =2\arctan[\frac{1}{4}(\frac{{K}_{I}}{{K}_{\mathit{II}}}-\mathit{sign}({K}_{\mathit{II}})\sqrt{(\frac{{K}_{I}}{{K}_{\mathit{II}}})\mathrm{²}+8})]\end{array}$

With the numerical values of the test:

> No propagation: $0,3m$
> ${x}_{0}:65\mathrm{mm}$
> ${y}_{0}:19\mathrm{mm}$
> Number of propagation steps: 13
> $\mathrm{RI}:3\mathrm{mm}$
> $\mathrm{RS}:12\mathrm{mm}$
> $\mathrm{RP}:12\mathrm{mm}$

## 7 Summary of results

The paths given by the four methods (simplex, upwind, upwind&FMM and geometric) can be compared:

![Figure](/figures/v3.02.321/10000000000004A9000002830F0AE44C565857C2.png)

The four methods all give the same propagation path, which is very close to the experimental data (cf. v3.02.321-fig-comparison-trajet-obtained-trajets-study).

The calculation time can be compared for the same number of propagation steps (13) of the four methods. For simplex and upwind methods, performance was verified using the restriction of the computational field. It is noted that the domain restriction allows for a significant reduction in the calculation time of both methods and for the performance of the mesh, simplex and upwind methods to be comparable.

| **mesh** | **Method** | **Time(s)** |
| --- | --- | --- |
| quadrangles | Mesh | 19.0 |
| Simplex | 13.0 |  |
| Upwind | 16 |  |
| Geometrics | 15.3 |  |

The results allow the simple case validation of the calculation of stress intensity factors in $I$ mode for elements $\text{X-FEM}$ for the different methods.
