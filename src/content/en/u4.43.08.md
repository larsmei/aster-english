# u4.43.08 Operator REST_HOMO_LOCAL

## 1 Purpose

This command makes it possible to reconstruct the local fields after a 3D analysis whose parameters have been homogenised beforehand by means of the command CALC_MATE_HOMO.

It takes as input:

- the mechanical and thermal correctors coming from :command:`CALC_MATE_HOMO`,
- the homogeneous result, both elastic and thermal, obtained on the global mesh.

### 1.1 Three-dimensional linear thermal analysis

In the case of three-dimensional linear thermal analysis, denoting by $\underline{z}$ the position vector in the base cell $C$ (placed at the macroscopic point $\underline{x}_0$), the microscopic temperature field is expressed as the sum of the macroscopic temperature field, denoted $T^0$, and of the contribution of the thermal correctors:

$$
T(\underline{x}_0, \underline{z})
=
T^0(\underline{x}_0)
+
\underline{\nabla} T^0(\underline{x}_0) \cdot \underline{z}
+
\sum_{k} \underline{\nabla} T^0_{k}(\underline{x}_0) \, \zeta^{k}(\underline{z})
$$

### 1.2 Three-dimensional linear thermoelasticity

In the case of a three-dimensional linear thermoelasticity analysis, denoting by $\underline{z}$ the position vector in the base cell $C$ (placed at the macroscopic point $\underline{x}_0$), the microscopic displacement field is expressed as the sum of the macroscopic displacement field, denoted $\underline{u}^0$, expanded over the base cell via the associated strain $\boldsymbol{\varepsilon}^0$, and of the contribution of the correctors. In this formulation, one keeps only the macroscopic term of the temperature, denoted $T^0$, on the base cell:

$$
\underline{u}(\underline{x}_0, \underline{z})
=
\underline{u}^0(\underline{x}_0)
+
\boldsymbol{\varepsilon}^0(\underline{x}_0) \cdot \underline{z}
+
\sum_{k,l} \varepsilon_{kl}^0(\underline{x}_0) \, \chi^{kl}(\underline{z})
-
\Bigl( T^0(\underline{x}_0) - T_{\text{réf}} \Bigr)
\Bigl( \alpha \, \mathbf{Id} \cdot \underline{z} + \boldsymbol{\chi}_{\text{dil}}(\underline{z}) \Bigr)
+
p_{\text{app}} \, \boldsymbol{\chi}_{p}^{int}(\underline{z})
$$

### 1.3 Return of the command

The command returns a data structure (`sdresu`) containing the local solution reconstructed on the mesh of the VER.

## 2 Syntax

```text
RELOC_MECA = REST_HOMO_LOCA(
    ◆ TYPE_HOMO = "MASSIF",
    ◆ POSITION = float (size: 3),
    ◇ CORR_MECA = evol_elas_dict,
    ◇ CORR_THER = evol_ther_dict,
    # Si: (exists("CORR_THER") and not exists("CORR_MECA"))
        ◇ OPTION = / "SANS" (par défaut),
                   / "FLUX_ELGA",
    # Si: (exists("CORR_MECA") and not exists("CORR_THER"))
        ◇ OPTION = / "SANS" (par défaut),
                   / "SIEF_ELGA",
    # Si: (exists("CORR_MECA") and exists("CORR_THER"))
        ◇ OPTION = / "SANS" (par défaut),
                   / "SIEF_ELGA",
    ◇ TEMP_REF = float (défaut: 20),
    ◇ PRESSION = float (défaut: 0),
    ◇ EVOL_ELAS = evol_elas,
    ◇ EVOL_THER = evol_ther,
    ◇ INST = float,
    ◇ TOUT_INST = "OUI",
    ◇ CRITERE = / RELATIF (par défaut),
                / ABSOLU,
    ◇ PRECISION = float(défaut: 1.0e-6, val_min=0.0),
    ◇ COMPLET = / NON (par défaut),
                / OUI,
    ◇ TRANSLATION = / NON (par défaut),
                    / OUI,
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Keyword TYPE_HOMO

This keyword is identical to that of the command :command:`CALC_MATE_HOMO`; it defines the approach used. At the present time, only the option **MASSIF** is programmed for the relocalisation operation.

### 3.2 Keyword POSITION

Specifies the position of the centre of the VER in the global mesh by a triplet of coordinates (x, y, z).

### 3.3 Keyword CORR_MECA

The **mechanical** correctors coming from the command :command:`CALC_MATE_HOMO` or :command:`LIRE_CORR_HOMO`.

### 3.4 Keyword CORR_THER

The **thermal** correctors coming from the command :command:`CALC_MATE_HOMO` or :command:`LIRE_CORR_HOMO`.

### 3.5 Keyword OPTION

This keyword makes it possible to define an additional field which is computed.

- If the analysis is elastic or thermoelastic: computation of **SIEF_ELGA**.
- If the analysis is thermal: computation of **FLUX_ELGA**.

### 3.6 Keyword PRESSION

When a pressure is applied on the internal walls of the "holes" of the VER, it must be supplied in the form of a function of time.

### 3.7 Keyword EVOL_ELAS

The homogeneous elastic result obtained on the global mesh.

### 3.8 Keyword EVOL_THER

The homogeneous thermal result obtained on the global mesh.

### 3.9 Keyword INST

Lists the time instants making it possible to restrict the reconstruction of the result.

### 3.10 Keyword TRANSLATION

If set to **OUI**, moves the mesh of the VER to its real position in the global mesh, given under POSITION.

### 3.11 Keyword COMPLET

If set to **OUI**, reconstructs the symmetric result of the correctors over the whole of the VER.
