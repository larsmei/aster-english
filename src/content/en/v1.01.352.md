# v1.01.352 ZZZZ352 – Keyword validation SOLVEUR / ELIM_LAGR = 'OUI'

**Summary**

This test validates the keyword SOLVEUR / ELIM_LAGR = 'OUI' which allows the equations corresponding to the dualised linear relationships to be removed in a matrix, which sometimes makes the matrix defined positive.

There are four modellings (A,B,C,D).

## 1 Test principle

The problem is some very simple mechanical elastic problem.

The kinematic boundary conditions are not trivial: there are relationships between several degrees of freedom.

The reference calculation is obtained with the MUMPS solver and using ELIM_LAGR='NON' (default).

The same calculation is done with ELIM_LAGR='OUI' and we check that we get the same result.

The method of removing the Lagrange equations is described in [R5.03.05](doc:r5.03.05)

The validation is complete:

- The method is checked for the correcting of the solution: MUMPS, LDLT and PETSC
- The method is checked for non-homogenous linear relationships
- It is checked that the solution is well reconstituted on all degrees of freedom, including the Lagrange degrees of freedom (use of the STAT_NON_LINE command).
- The method is checked for operation on multiple processors (modellings C and D)

## 2 Summary of results

The results are very good.
