# v3.01.108 SSLL108 - Discrete elements 2D

**Summary:**

The problem is quasi-static linear in structural mechanics.

The response of a bar, modelled by 10 elements discreet, to a traction load, is analyzed to validate the two-dimensional discrete elements.

Only one model uses both MECA_STATIQUE operators, and STAT_NON_LINE, to validate the use of these elements (whose behavior remains linear) with other elements finished with any behavior.

## 1 Reference problem

### 1.1 Geometry

A $L=\mathrm{10m}$ length bar, following the $X$ axis, modeled by 10 elements discreet at 2 nodes.

### 1.2 Material properties

Each discreet element has a stiffness: $k=1000N/m$

### 1.3 Boundary conditions and loads

| En $x=0$ | $\mathit{dx}=\mathit{dy}=0$ |
| --- | --- |
| En $x=L$ | $\mathit{Fx}=\mathrm{10N}$ |

## 2 reference solution

### 2.1 Calculation method used for reference solution

Analytical solution: the displacement for a element is given by: $\mathit{Ux}=F/\mathit{Kx}$

So for $n$ springs: $\mathit{Ux}=nF/\mathit{Kx}$

### 2.2 Baseline

Movement values for $x=L/2$ and $X=L$ , as well as stress in elements (constant):

$U(L/2)=0.05m$ , $U(L)=0.1m$ , $N=\mathrm{10N}$

### 2.3 Uncertainty about the solution

Analytical solution exact.

## 3 Modelling A

### 3.1 Modelling characteristics

2D_DISCRET modelling

### 3.2 Mesh characteristics

10 mesh cells SEG2.

## 4 Summary of the results

This voluntary, very simple test allows you to check the smooth operation of elements discreet $\mathrm{2D}$ with STAT_NON_LINE, allowing you to use them with other modellings.
