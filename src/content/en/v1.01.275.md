# v1.01.275 DISTR01 – Example parametric study

**Summary:**

This test is an example of parametric study in support of the [U2.08.07](doc:u2.08.07) leaflet – Distribution of parametric calculations.

Boundary conditions, material and loading values have no physical significance.

## 1 Reference problem

### 1.1 Geometry

A $5\mathit{cm}$ height plate and $1m$ length plate are considered.

In the case of the parametric study, the angle of the applied load will be varied from $0°$ to $90°$.

![Figure](/figures/v1.01.275/Shape1.gif)

### 1.2 Material properties

The material is elastic isotropic with properties of:

- $E=210000\mathit{MPa}$
- $\nu =0.3$

### 1.3 Boundary conditions and loads

We're blocking degrees of freedom DX and DY at clamped support.

The $p$ pressure applied at the end is $1\mathit{MPa}$ .

### 1.4 Parametric study

The value of this test is to serve as an example for the distribution of parametric calculations. See the [U2.08.07](doc:u2.08.07) leaflet for more details and for the launch of this test as a parametric study.

When launching the test case, not all data files are used.

Their usefulness is specified here:

- distr01a.comm: command file of the nominal study which will be declined for each set of parameters.
- distr01a.com1: additional command file testing the reference value in case $\alpha =0°$ .
- distr01a.med: mesh from Modelling A.
- Distr01a.50 and distr01a.51: example of setting parameters.
- Distr01a.11: example of post-processing where the results of the different calculation cases are combined to produce a single curve or table.

The last three files are not used when launching the standard test case.

## 2 reference solution

### 2.1 Method of calculation

Standard test execution is done with $\alpha =0°$ , pure compression.

The solution is trivial: the equivalent stress of Von Mises is equal to $p$ .

### 2.2 Quantities and reference results

The value of the Von stress is tested on the upper line of the plate. The value is slightly parasitized by the stresses induced by the clamped support.

## 3 Modelling A

### 3.1 Modelling characteristics

C_PLAN modelling is used.

### 3.2 Mesh characteristics

The mesh contains 250 elements of type QUAD4.

### 3.3 Tested quantities and results

The mean value of the Von Bets stress on the upper line of the plate ($\text{Lsup}$) is tested.

| **Identification** | **Reference type** | **Reference value** | **Tolerance** |
| --- | --- | --- | --- |
| $\text{Lsup}$ | 'ANALYTIQUE' | $1\mathit{MPa}$ | 0.1% |

## 4 Summary of the results

The test is trivial, the value obtained is simply parasitized by the stresses induced by the clamped support.
