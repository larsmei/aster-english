# v1.01.335 ERREU14 - Error message emission test for command variables

**Summary:**

This test validates the issuance of error messages related to misuse of command variables.

## 1 Test principle

This test is a computer test. It validates that misuse of the command variables leads to an error message understandable by the user.

3 "errors" are tested for AFFE_MATERIAU / AFFE_VARC:

- The user assigns a field but field components have an incorrect name.
- The user does not affect the command variables on all elements that require them.
- The user assigns a field but this field does not concern all elements while needing.
