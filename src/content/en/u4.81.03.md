# u4.81.03 Operator CALC_CHAM_ELEM

## 1 Purpose

Compute an elementary field at the Gauss points containing the coordinates and the weight of the Gauss points.

Compute an elementary field of heat flux and of acoustic pressure, from already computed fields of type cham_no_*.

Put into the format of a field at the nodes by element the values of certain material parameters and of certain beam characteristics.

## 2 Syntax

```text
cham_elem = CALC_CHAM_ELEM(
    ◆ MODELE = modele,
    ◇ / TOUT = "OUI" (ou non renseigné),
      / GROUP_MA = grma,
    ◇ INST = float,
    ◇ MODE_FOURIER = int,
    ◆ OPTION = / "FLUX_ELGA",
               / "FLUX_ELNO",
               / "PRAC_ELNO",
               / "COOR_ELGA",
               / "ROCH_ELNO",
    # Si: equal_to("OPTION", 'ROCH_ELNO')
        ◆ CHAM_MATER = cham_mater,
        ◆ CARA_ELEM = cara_elem,
    # Si: not equal_to("OPTION", 'ROCH_ELNO')
        ◇ CARA_ELEM = cara_elem,
    # Si: is_in("OPTION", ('FLUX_ELNO','FLUX_ELGA',))
        ◆ TEMP = cham_no,
        ◆ CHAM_MATER = cham_mater,
    # Si: is_in("OPTION", ('PRAC_ELNO',))
        ◆ PRES = cham_no,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operands MODELE / CARA_ELEM / CHAM_MATER

```text
♦    MODELE= mo,
```

Name of the model on which the option is computed.

```text
◊    CARA_ELEM= carac,
```

Elementary characteristics associated with the model mo, if it contains structural elements or if the isoparametric elements are assigned a local anisotropy reference frame.

Only for the option ROCH_ELNO:

```text
♦    CHAM_MATER= chmat,
```

Material field. Must contain the elastic data and the material POST_ROCHE.

### 3.2 Selection of the mesh cells concerned by the analysis

The keywords TOUT = 'OUI' and GROUP_MA allow the user to choose the mesh cells on which he or she wishes to carry out the elementary post-processing analyses.

```text
/    TOUT = 'OUI'
```

All the mesh cells (carrying finite elements) will be processed. This is the default value.

```text
/    GROUP_MA    =    l_grma
```

Only the mesh cells included in l_grma will be processed.

### 3.3 Operand INST

```text
◊    INST
```

Value of the time instant making it possible to evaluate possible functions in the material parameters for the computation of the heat flux.

### 3.4 Thermal options

The elementary thermal computation options can be computed from a temperature field:

```text
♦    TEMP= temp
```

For these analyses one needs the material field associated with the model mo:

```text
♦    CHAM_MATER= chmater,
```

The options available are:

```text
|    'FLUX_ELGA',
|    'FLUX_ELNO',
```

Their meaning is given in [U4.81.04](doc:u4.81.04).

In the case of the modellings AXIS_FOURIER and PLAN_FOURIER, one can specify the harmonic number by the keyword: MODE_FOURIER.

### 3.5 Acoustic options

The elementary acoustic computation options can be computed from a complex pressure field:

```text
♦    PRES= pres
```

The option available is:

```text
|    'PRAC_ELNO'
```

Computation of the real and imaginary parts of the pressure field per element at the nodes.

### 3.6 Option COOR_ELGA

Computation of the coordinates and of the weights of the Gauss points of each element.

### 3.7 Option ROCH_ELNO

This option puts into the form of a field at the nodes by element the values of certain material parameters and of certain beam characteristics. The output field has 10 components described in the following table:

| **Components** | **Correspondence** |
| --- | --- |
| E | Young's modulus |
| K_FACT | Parameter FACTEUR of POST_ROCHE |
| N_EXPO | Parameter EXPOSANT of POST_ROCHE |
| A | Area of the (circular) beam cross-section |
| I | Inertia of the (circular) beam cross-section |
| R | Outer radius of the (circular) beam cross-section |
| EP | Pipe thickness |
| I2 | Value of the inertia at the other node of the same mesh cell |
| R2 | Value of the radius at the other node of the same mesh cell |
| EP2 | Value of the thickness at the other node of the same mesh cell |

This option is used for the specific needs of the macro-command POST_ROCHE.

Caution, the parameter E must not be a function.

## 4 Examples of analyses with CALC_CHAM_ELEM

```text
epsno = CALC_CHAM_ELEM
```

(    MODELE=    moaxfour,        TEMP= temp,
CHAM_MATER=    chmater,
OPTION=    'FLUX_ELNO',    MODE_FOURIER= 1,
);
