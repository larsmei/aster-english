# v1.01.279 ERREU05 - Checking for Recovery of Fatal Errors in STAT_NON_LINE

**Summary:**

This test validates recovery of fatal errors in STAT_NON_LINE and the possibility of pursuing a base obtained from the exit of a study that stopped in error.

## 1 Test principle

This test is a computer test and is conducted in two phases:

- The test case initially performs a first STAT_NON_LINE during which an error occurs (interpolation problem of a function). This error is intercepted and the test base is properly closed.
- In a second step, an POURSUITE is performed using the database produced during the first calculation.
