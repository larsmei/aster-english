# v3.01.015 SSLL15- Beam on elastic floor, free ends

**Summary:**

The linear elasticity static test is used to validate straight beam elements POU_D_T.

This test case concerns a beam on elastic floor, with free ends.

Deflections, moments and rotations are tested by comparing simulation results with reference solution AFNOR (ref. [1]) and those obtained with Pipestress software.
