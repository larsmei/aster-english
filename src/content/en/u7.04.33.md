# u7.04.33 Procedure IMPR_MACR_ELEM

## 1 Purpose

Print a data structure macr_elem_dyna in the IDEAS and MISS_3D formats.

One prints:

- the definition of a connection interface between a macro-structure and its external environment,
- a modal basis (dynamic modes of the macro-structure and static modes resulting either from unit displacements imposed at the interface, or from unit forces imposed at the interface),
- the mass and stiffness matrices of the macro-structure projected onto the preceding modal basis.

## 2 Syntax

```text
IMPR_MACR_ELEM(
    ◆ MACR_ELEM_DYNA = macr_elem_dyna,
    ◇ FORMAT = / "MISS_3D",
               / "IDEAS" (par défaut),
    # Si: equal_to("FORMAT", 'IDEAS')
        ◇ UNITE = unit (défaut: 30),
        ◇ VERSION = 5,
    # Si: equal_to("FORMAT", 'MISS_3D')
        ◇ UNITE = unit (défaut: 26),
        ◇ SOUS_TITRE = text,
        ◇ / AMOR_REDUIT = float,
          / LIST_AMOR = listr8,
        ◆ GROUP_MA_INTERF = grma,
        ◇ GROUP_MA_FLU_STR = grma,
        ◇ GROUP_MA_FLU_SOL = grma,
        ◇ GROUP_MA_SOL_SOL = grma,
        ◇ GROUP_MA_CONTROL = grma,
        ◇ FORMAT_R = / "1PE12.5" (par défaut),
                     / "1PE16.9",
        ◇ IMPR_MODE_MECA = / "OUI" (par défaut),
                           / "NON",
        ◇ IMPR_MODE_STAT = / "OUI" (par défaut),
                           / "NON",
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand MACR_ELEM_DYNA

```text
♦    MACR_ELEM_DYNA        =    melem                                    [macr_elem_dyna]
```

Name of the concept of type macr_elem_dyna which one wishes to print in the file.

### 3.2 FORMAT = 'IDEAS'

```text
◊    FORMAT    =    /    ‘IDEAS’                                            [DEFAUT]
```

Makes it possible to specify the print format. The format ‘IDEAS’ is taken by default. Currently only the printout is carried out according to the specifications of version 5. Upward compatibility with the versions of IDEAS is therefore ensured.

#### 3.2.1 Operand UNITE

```text
◊    UNITE        =    /    30,                                            [DEFAUT]
/    unit                                        [I]
```

This keyword makes it possible to define the logical unit for printing in the ‘IDEAS’ format (30 by default).

#### 3.2.2 Operand VERSION

```text
◊    VERSION    =    /    5,                                            [DEFAUT]
```

This keyword makes it possible to define the print version in the ‘IDEAS’ format (5 by default).

### 3.3 FORMAT = 'MISS_3D'

```text
◊     FORMAT    =    /    'MISS_3D'
```

The format ‘MISS_3D’ is used by the soil-dynamics code MISS3D to import structural data coming from *Code_Aster* (content of the dynamic macro-element which corresponds to the terms of the contribution of the structure to the impedance of the global soil-structure interaction problem). One also prints the mesh of the soil-structure interface in its local numbering and, possibly, the dynamic and static modes reduced to this interface.

For this format one must supply the operand GROUP_MA_INTERF and five operands are optional: UNITE, SOUS_TITRE, AMOR_REDUIT, IMPR_MODE_STAT and IMPR_MODE_MECA.

#### 3.3.1 Operand UNITE

```text
◊    UNITE        =    /    26,                                            [DEFAUT]
/    unit                                        [I]
```

This keyword makes it possible to define the logical unit for printing in the ‘MISS_3D’ format (26 by default).

#### 3.3.2 Operand SOUS_TITRE

```text
◊    SOUS_TITRE        =    l_st                                    [l_Kn]
```

Allows the user to give a name to the data transferred into the MISS3D code.

#### 3.3.3 Operand AMOR_REDUIT

```text
◊    /    AMOR_REDUIT        =    lam                                    [l_R]

/    LIST_AMOR            =    l_amor                                listr8
```

These keywords make it possible to enter a list of dampings for the dynamic modes. One can thus complete the terms of the dynamic macro-element.

#### 3.3.4 Operand GROUP_MA_INTERF

```text
♦    GROUP_MA_INTERF        =    gr_inter                            [l_group_ma]
```

This keyword makes it possible to define the list of surface mesh-cell groups constituting the soil-structure interface. One prints the coordinates of the “Nb_nœuds” nodes of the set of interfaces, then the “Nb_elem” elements with their connectivities in the local numbering of the set of interfaces (1 to “Nb_nœuds”).

#### 3.3.5 Operand IMPR_MODE_STAT

```text
◊    IMPR_MODE_STAT    =    /    ‘OUI’                                [DEFAUT]
/    ‘NON’
```

This keyword makes it possible, optionally (if ‘OUI’), to print the static modes reduced to the interface. This proves necessary for the 6 rigid-body modes. In this case, the macro-element is based on a dynamic interface of type CRAIGB reduced to one point with a rigid link of the interface (keyword LIAISON_SOLIDE of AFFE_CHAR_MECA [U4.44.01](doc:u4.44.01)).

#### 3.3.6 Operand IMPR_MODE_MECA

```text
◊    IMPR_MODE_MECA    =    /    ‘OUI’                                [DEFAUT]
/    ‘NON’
```

This keyword makes it possible, optionally (if ‘OUI’), to print the dynamic modes reduced to the interface.

#### 3.3.7 Operand FORMAT_R

```text
◊    FORMAT_R    =        /    ‘1PE12.5’                                [DEFAUT]
/    ‘1PE16.9’
```

This keyword gives the print format of the real numbers used when printing the structural impedances which one assembles with the soil impedances in MISS3D.

#### 3.3.8 Operands GROUP_MA_FLU_STR/GROUP_MA_FLU_SOL/GROUP_MA_SOL_SOL

```text
◊     GROUP_MA_FLU_STR= gr_flustr    [l_group_ma]
◊    GROUP_MA_FLU_SOL= gr_flusol    [l_group_ma]
◊    GROUP_MA_SOL_SOL= gr_solsol    [l_group_ma]
```

In the case of a soil-fluid-structure interaction, these keywords make it possible to complete the list of surface mesh-cell groups made up respectively of the fluid-structure, fluid-soil and free-soil interfaces.

In this case, one completes the printing of their elements with their connectivities in the local numbering of the set of interfaces (1 to "Nb-nœuds") (including the soil-structure interface).

#### 3.3.9 Operand GROUP_MA_CONTROL

```text
◊     GROUP_MA_CONTROL= gr_control    [l_group_ma]
```

This keyword makes it possible to introduce groups of point mesh cells POI1 in order to model, with *Code_Aster*, control points in the part of the soil modelled by MISS3D. This then makes it possible to carry out any post-processing on their nodes with *Code_Aster* operators after recovery of the evolution computed by CALC_MISS.

This therefore requires, for these control points:

- to introduce them into the mesh as isolated nodes,
- to assign them a DIS_T modelling with AFFE_MODELE,
- to impose on them blockings in ‘DX’, ‘DY’, ‘DZ’ with AFFE_CHAR_MECA,

> An illustrative example is given in the test case ZZZZ108C.

In this case, one completes the printing of these point elements with their connectivity to a single node in the local numbering of the set of interfaces (1 to "Nb-nœuds") (including the nodes of the modelled control points).

## 4 Example of printing data in the MISS3D format

In the example below, the main commands are given which allow the chaining between *Code_Aster* and the MISS3D code, and which illustrate the use of the command IMPR_MACR_ELEM in this context.

```text
#

# calcul des modes

#
mode = CALC_MODES( MATR_RIGI= rigidite,

MATR_MASS= masse,
CALC_FREQ=_F( NMAX_FREQ=    30 ),
);

#

# calcul du macro-élément dynamique

#
interdyn = DEFI_INTERF_DYNA    (    NUME_DDL= nume_ddl,
INTERFACE=        (    NOM = ‘DROITE’,
TYPE = ‘CRAIGB’,
NOEUD= 'N98'
)
);
bamo = DEFI_BASE_MODALE            (    CLASSIQUE=_F    (    INTERF_DYNA = interdyn,
MODE_MECA = mode,
NMAX_MODE = 30
)
);
mael = MACR_ELEM_DYNA    (    BASE_MODALE=    bamo,    OPTION=    ‘CLASSIQUE’    );

fo1 = DEFI_FONCTION (         NOM_PARA=        ‘FREQ’,
VALE=    (0.,    1.,    100.,    1. )    );

#

# lecture de l’accélérogramme de sol acce

#
ACCE = DEFI_FONCTION    (    NOM_PARA = 'INST',
VALE =    (    0.00000E+00, 1.1940E-03,
- - - - - - - - - - -
));

#

#    pré-traitement de MISS3D

#

#    (maillage et impédances d’interface)

IMPR_MACR_ELEM    (    MACR_ELEM_DYNA    =    mael,
FORMAT                =    ‘MISS_3D’,
SOUS_TITRE        =    ‘CIVAUX RIGIDE’,
IMPR_MODE_STAT    =    ‘OUI’,
IMPR_MODE_MECA    =    ‘NON’,
AMOR_REDUIT        =    (    0.07    ),
GROUP_MA_INTERF    =    ('SRADIER')
);
```
