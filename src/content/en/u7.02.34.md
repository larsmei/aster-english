# u7.02.34 Command DEFI_SOL_MISS

## 1 Purpose

Produce a table containing the information necessary for the description of a soil file for the MISS3D software.

The data entered by the command DEFI_SOL_MISS are:

- the description of the characteristics of the materials constituting the layers of a stratified soil,
- the geometric description and the assignment of the materials of the successive layers,
- the positioning (which may be defined automatically) of the source and receiver levels with respect to the soil layers, necessary for the computation of the Green's functions.

The soil table thus produced will be supplied as an argument of CALC_MISS [U7.03.12](doc:u7.03.12).

## 2 Syntax

```text
table = DEFI_SOL_MISS(
    ◆ MATERIAU = _F(
         ◆ E = float,
         ◆ NU = float,
         ◆ RHO = float,
         ◆ AMOR_HYST = float,
      ),
    ◆ / COUCHE = _F(
           ◆ | SUBSTRATUM = / "OUI",
                            / "NON",
             | EPAIS = float,
           ◇ RECEPTEUR = / "OUI",
                         / "NON" (par défaut),
           ◇ SOURCE = / "OUI",
                      / "NON" (par défaut),
           ◆ NUME_MATE = int,
        ),
      / COUCHE_AUTO = _F(
           ◇ Z0 = float,
           ◆ HOMOGENE = / "OUI",
                        / "NON",
           ◇ SURF = / "OUI",
                    / "NON" (par défaut),
           ◆ EPAIS_PHYS = float,
           # Si: equal_to("HOMOGENE", 'NON')
               ◆ NUME_MATE_SUBSTRATUM = int,
               ◆ NUME_MATE = int,
           # Si: equal_to("SURF", 'OUI')
               ◇ & GROUP_MA_CONTROL = grma,
                 & MAILLAGE = maillage,
           # Si: equal_to("SURF", 'NON')
               ◆ / GROUP_MA = grma,
                 / GROUP_NO = grno,
               ◇ NOMBRE_RECEPTEUR = int (défaut: 4),
               ◇ GROUP_MA_INTERF = grma,
               ◇ GROUP_MA_CONTROL = grma,
               ◆ MAILLAGE = maillage,
               ◇ TOLERANCE = float (défaut: 1e-05),
               ◇ DECALAGE_AUTO = / "OUI" (par défaut),
                                 / "NON",
        ),
    ◇ TITRE = text,
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Keyword MATERIAU

```text
MATERIAU
```

Repeatable factor keyword allowing the description of the characteristics of the materials constituting the layers of a stratified soil, material by material.

The assignment of the materials to the different layers is done by the occurrence number of the factor keywords MATERIAU. It is not permitted to skip certain materials. For example, one cannot use materials 1, 2 and 4 under COUCHE or COUCHE_AUTO without assigning occurrence number 3. The command stops in error in this case. On the other hand, one may define 4 materials and use only the first ones, 1 and 2 for example.

#### 3.1.1 Operands E/NU/RHO/AMOR_HYST

Make it possible to define respectively the real values of Young's modulus, of Poisson's ratio, of the density and of the hysteretic damping of the current material.

### 3.2 Keyword COUCHE

```text
COUCHE
```

Repeatable factor keyword allowing the geometric description and the assignment of the materials layer by layer, and the possible positioning of a source level and a receiver level with respect to the current soil layer, which is necessary for the computation of the Green's functions.

*Note* **:**

*The description of the layers is necessarily done in the downward vertical direction*

#### 3.2.1 Operand NUME_MATE

```text
♦    NUME_MATE = numat
```

Number of the material in the order of description of the occurrences of the keyword MATERIAU of the current layer.

#### 3.2.2 Operands EPAIS / SUBSTRATUM

Either one defines the layer as the substratum (SUBSTRATUM='OUI'), in general for the last layer.

Or one supplies the value of the thickness of the layer.

#### 3.2.3 Operands SOURCE/RECEPTEUR

Make it possible to define whether one has positioned respectively a source level and/or a receiver level at the top of the current layer if 'OUI'.

### 3.3 Keyword COUCHE_AUTO

```text
COUCHE_AUTO
```

Single factor keyword allowing the automated definition of the soil layers, in parallel with the manual mode of the keyword COUCHE.

#### 3.3.1 Operand Z0

```text
◊    Z0 = z0
```

Vertical elevation of the free surface (argument identical to that of CALC_MISS [U7.03.12](doc:u7.03.12)). If its value is not supplied, then the operator will detect the highest vertical elevation of GROUP_NO/GROUP_MA, in agreement with GROUP_MA_INTERF if it is defined.

#### 3.3.2 Operand HOMOGENE

> ♦    HOMOGENE        =    /    'OUI',

```text
/    'NON',
```

This keyword makes it possible to specify whether the soil is homogeneous or not. In the second case, the soil stratification must necessarily be defined with the operands NUME_MATE/EPAIS_PHYS and the material of the substratum (the lowest homogeneous and semi-infinite soil layer) with NUME_MATE_SUBSTRATUM. The number of values of EPAIS_PHYS must be consistent with that of NUME_MATE: each layer must have an associated material, so if one has n layers (hence n values in the list of reals of EPAIS_PHYS) then the list of integers of NUME_MATE must also be of length n.

In the homogeneous case, the first material of the keyword MATERIAU will be taken and it remains only to define the position of the substratum with EPAIS_PHYS, which will contain only one value. In the case of an embedded foundation, the substratum must be positioned lower than the base of the foundation.

#### 3.3.3 Operand SURF

> ◊    SURF            =    /    'NON',        [DEFAUT]

```text
/    'OUI',
```

Makes it possible to indicate whether the foundation is shallow or not. If it is not, then certain operands must also be defined, such as GROUP_MA or GROUP_NO, which will make it possible to define the lateral soil sub-layers.

In the shallow case, these operands have no meaning, and neither do others: NOMBRE_RECEPTEUR, TOLERANCE, DECALAGE_AUTO, GROUP_MA_INTERF and MAILLAGE.

#### 3.3.4 Operand EPAIS_PHYS

Makes it possible to indicate the thickness of the soil layers. In the case of a homogeneous soil it serves only to position the substratum (which must be below the lowest point of the foundation).

#### 3.3.5 Operands NUME_MATE / NUME_MATE_SUBSTRATUM

Make it possible to associate a material (according to its number in the order of description of the occurrences of the keyword MATERIAU) with each soil layer and with the substratum.

#### 3.3.6 Operands GROUP_MA / GROUP_NO / MAILLAGE

Make it possible to give the mesh-cell group or node group which will serve to define the vertical elevations of the nodes of the interface mesh, for the definition of the soil sub-layers, therefore only in the case of an embedded foundation. The use of GROUP_MA is recommended because one can then detect whether the foundation mesh is quadratic or linear, which cannot be done with a node group. This detection is important because MISS3D takes into account only a linear discretisation: the mid-side nodes must therefore be ignored for the definition of the soil sub-layers and hence the positions of the associated sources and receivers.

The mesh of the model must also be specified.

#### 3.3.7 Operand NOMBRE_RECEPTEUR

Defines the number of sub-layers of the soil table which correspond to the embedded part of the foundation, *cf.* documentation U2.06.07. The default value is four per element and only an even value is authorised.

#### 3.3.8 Operands GROUP_MA_INTERF / TOLERANCE

The definition of GROUP_MA_INTERF will make it possible to trigger a consistency check between this mesh-cell group of the Aster-MISS3D FEM-BEM interface and the argument of GROUP_MA/GROUP_NO. The vertical elevations of the nodes are therefore checked, with a certain relative tolerance, which is equal to 1.E-5 by default. This check is meaningful only if the foundation mesh complies with the rules of documentation U2.06.05, which are imposed by MISS3D, which considers a vertical discretisation of 1D type.

For a shallow foundation, this check has no relevance.

#### 3.3.9 Operand GROUP_MA_CONTROL

Makes it possible to define the control points in the soil, in a manner similar to what is done in CALC_MISS [U7.03.12]. The soil table must indeed take account of the presence of control points, as indicated in documentation U2.06.07.

If all the control points are on the free surface, it is unnecessary to supply the keyword GROUP_MA_CONTROL.

#### 3.3.10 Operand DECALAGE_AUTO

> ◊    DECALAGE_AUTO =    /    'OUI',        [DEFAUT]

```text
/    'NON',
```

If the position of the boundary between two soil layers (with a strong contrast of materials) corresponds exactly to the base of the buried foundation, this may give rise to a numerical singularity in MISS3D. By means of this option, it is therefore proposed to shift the boundary of these soil layers automatically. To this end, this boundary will be shifted upwards by the thickness of one sub-layer (for example by the height of a quarter of an element if the value of NOMBRE_RECEPTEUR has been left at four).

### 3.4 Operand TITRE

```text
◊    TITRE = titre
```

Allows the user to define a title for the soil table.

### 3.5 Operand INFO

Indicates a printout level for information in the file "MESSAGE":

INFO = 1: no printout

INFO = 2: printout of the soil table
