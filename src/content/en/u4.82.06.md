# u4.82.06 Operator RECA_WEIBULL

## 1 Purpose

Calibrate the parameters of the WEIBULL model on experimental data. These data consist of one (or several) list(s) of failure time instants determined experimentally, associated with one (or several) result concept(s) of STAT_NON_LINE modelling the tests at these various time instants. The WEIBULL modulus, or the cleavage stress (possibly depending on the temperature), or else both of these parameters, may be calibrated. The maximum-likelihood method or linear regression [R7.02.09](doc:r7.02.09) is used for this calibration.

Produces a data structure of type table.

## 2 Syntax

```text
table = RECA_WEIBULL(
    ◆ LIST_PARA = / "SIGM_REFE",
                  / "M",
    ◆ RESU = _F(
         ◆ EVOL_NOLI = evol_noli,
         ◆ MODELE = modele,
         ◆ CHAM_MATER = cham_mater,
         ◇ TEMPE = float,
         ◆ LIST_INST_RUPT = float,
         ◇ / TOUT_ORDRE = "OUI" (ou non renseigné),
           / NUME_ORDRE = int,
           / INST = float,
           / LIST_INST = listr8,
         # Si: exists("INST") or exists("LIST_INST")
             ◇ CRITERE = / "RELATIF" (par défaut),
                         / "ABSOLU",
             # Si: equal_to("CRITERE", 'RELATIF')
                 ◇ PRECISION = float (défaut: 1e-06),
             # Si: equal_to("CRITERE", 'ABSOLU')
                 ◆ PRECISION = float,
         ◆ | TOUT = "OUI" (ou non renseigné),
           | GROUP_MA = grma,
         ◇ COEF_MULT = float (défaut: 1.0),
      ),
    ◇ OPTION = / "SIGM_ELGA" (par défaut),
               / "SIGM_ELMOY",
    ◇ CORR_PLAST = / "OUI",
                   / "NON" (par défaut),
    ◇ METHODE = / "MAXI_VRAI" (par défaut),
                / "REGR_LINE",
    ◇ INCO_GLOB_RELA = float (défaut: 0.001),
    ◇ ITER_GLOB_MAXI = int (défaut: 10),
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand LIST_PARA

```text
♦    LIST_PARA
/    'M',
/    'SIGM_REFE',
```

List of the parameters of the Weibull model for which calibration is requested ($m$, ${\sigma}_{u}$ or both).

### 3.2 Keyword RESU

#### 3.2.1 Operand EVOL_NOLI

```text
♦    EVOL_NOLI    =    resu,
```

Name of a result concept of type evol_noli.

#### 3.2.2 Operand MODELE

```text
♦    MODELE    =    mo,
```

Name of the model on which the calibration is carried out.

#### 3.2.3 Operand CHAM_MATER

```text
♦    CHAM_MATER    =    chmat,
```

Name of the material field assigned to the model. It must necessarily contain the initial value of the parameters of the Weibull method (keyword WEIBULL of DEFI_MATERIAU [U4.43.01](doc:u4.43.01)), namely:

| ${V}_{0}$ | : reference volume |
| --- | --- |
| $m$ | : exponent of the Weibull statistical law |
| ${\sigma}_{u}$ | : cleavage stress |

#### 3.2.4 Operand TEMPE

```text
◊    TEMPE    =    temp,
```

Temperature associated with the result resu. If it is supplied, the cleavage stress ${\sigma}_{u}$ will be calibrated for each result.

#### 3.2.5 Operand LIST_INST_RUPT

```text
♦    LIST_INST_RUPT    =    lreel,
```

List of the failure time instants of the result database resu at which the Weibull stresses will be computed (these time instants are interpolated if they do not coincide with the time instants of the result resu). This list of time instants must be strictly increasing and contain at least two time instants. The minimum time instant (respectively maximum) of this list must of course necessarily be greater (resp. smaller) than the minimum time instant (resp. maximum) of the list of time instants of the result resu.

#### 3.2.6 Operands TOUT / GROUP_MA

The analysis domain or domains are specified by:

```text
♦    /    TOUT    =    'OUI',
```

A single domain is defined and it coincides with the whole structure.

```text
/    GROUP_MA    =    lgrma,
```

Each mesh-cell group of the list lgrma defines an analysis domain.

#### 3.2.7 Operands TOUT_ORDRE / NUME_ORDRE / INST / LIST_INST / PRECISION / CRITERE

# selection of the analysis time instants at which the Weibull stresses are to be interpolated at the time instants given by LIST_INST_RUPT

see TOUT_ORDRE, NUME_ORDRE, LIST_ORDRE, INST, LIST_INST in [U4.71.00](doc:u4.71.00)

Aster first computes the Weibull stresses for all the time instants given by TOUT_ORDRE/ NUME_ORDRE/ INST/LIST_INST; it then interpolates the Weibull stresses at the time instants given by LIST_INST_RUPT.

#### 3.2.8 Operand COEF_MULT

```text
◊    COEF_MULT    =    coef,
```

Multiplicative coefficient of the m-th power of the Weibull stress, intended to take symmetries of the domain into account (the default value is 1. cf. POST_ELEM [U4.81.22](doc:u4.81.22)).

### 3.3 Operand OPTION

```text
/    OPTION    =    'SIGM_ELGA',
```

The elementary field of the maximum principal stress is computed from the representation of the stress field at the Gauss points.

```text
/    OPTION    =    'SIGM_ELMOY',
```

The elementary field of the maximum principal stress is computed from the representation of the stress field averaged with respect to the Gauss points.

### 3.4 Operand CORR_PLAST

```text
/    CORR_PLAST    =    'OUI',
```

The Weibull stress field is evaluated with the plastic correction.

```text
/    CORR_PLAST    =    'NON',
```

The Weibull stress field is evaluated without plastic correction.

### 3.5 Operand METHODE

```text
/    METHODE    =    'MAXI_VRAI',
```

The calibration method used is that of maximum likelihood.

```text
/    METHODE    =    'REGR_LINE',
```

The calibration method used is that of linear regression.

### 3.6 Keyword INCO_GLOB_RELA

```text
◊    INCO_GLOB_RELA    =    /    increl,        [R]
/    1.E-3,            [DEFAUT]
```

The calibration algorithm continues the iterations if:

$\max(∣\frac{{m}_{k+1}-{m}_{k}}{{m}_{k}}∣;\underset{T}{\max}(∣\frac{{\sigma}_{u(k+1)}(T)-{\sigma}_{u(k)}(T)}{{\sigma}_{u(k)}(T)}∣))>\mathrm{increl}$

### 3.7 Keyword ITER_GLOB_MAXI

```text
◊    ITER_GLOB_MAXI    =    /    maglob,        [R]
/    10,                [DEFAUT]
```

Maximum number of calibration iterations carried out.

### 3.8 Operand INFO

```text
◊    INFO    =
```

Indicates the printout level of the results of the operator,

| 1: | no printout, |
| --- | --- |
| 2: | printout of the information relating to the calibration. |

The printouts are made in the file 'MESSAGE'.

## 4 Example of use

For the use of RECA_WEIBULL, one may refer to the test case SSNA103 [V6.01.103](doc:v6.01.103).

It is an axisymmetric modelling of a cylindrical specimen (length 407 mm and radius 68 mm) subjected to tension. Example of calibration of the parameter ${\sigma}_{u}$ of the Weibull method by the linear-regression method on three result databases corresponding to distinct temperatures (the Weibull modulus $m$ is fixed and equal to 24).
