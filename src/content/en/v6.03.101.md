# v6.03.101 SSNP101 - Traction-slicing plate: Lemaître viscoelasticity (D_PLAN)

**Summary:**

This non-linear quasi-static mechanical test consists of loading a square plate in a tensile shear.

Thus, the nonlinear viscoelasticity behavior relationships in flat deformations for non-radial loading are validated.

$A$ Modelling validates $\mathrm{2D}$ D_PLAN law of Lemaître and VISC_ENDO_LEMA law, for which parameters are adjusted to make damage null.

$B$ Modelling validates VISC_TAHERI $\mathrm{2D}$ D_PLAN law, in which parameters are adjusted to annihilate the plasticity and rock effect

The results obtained by Code_Aster are very close to the reference solution.

## 2 reference solution

### 2.1 Calculation method used for reference solution

Code_Aster 3D calculation performed with element HEXA8 with all nodess having zero required displacement according to $\mathrm{Oz}$ . This allows to be a reference for the case of flat deformations (in the $(\mathrm{Ox},\mathrm{Oy})$ plane ), where there is no analytical solution or other calculation code results.

$\mathrm{3D}$ operation of Lemaître nonlinear viscoelasticity was itself validated using the SSNP05A test.

### 2.2 Baseline

${\varepsilon}_{{\nu}_{xx}}$ and ${\varepsilon}_{{\nu}_{xy}}$ at $t=30s$, $t=3630s$, $t=3660s$ and $t=3720s$ moments

### 2.3 Uncertainty about the solution

Uncertainty less than $\text{0.5\%}$

## 5 Summary of the results

This valid $\mathrm{2D}$ strain test flats the 3 constitutive laws LEMAITRE, VISC_ENDO_LEMA (without damage) and VISC_TAHERI (without plasticity) whose viscosity equations are governed by the Lemaître law. The differences between the models are less than $1\text{\%}$.
