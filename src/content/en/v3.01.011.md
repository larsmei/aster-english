# v3.01.011 SSLL11 - Threads of articulated bars under point load

**Summary:**

This test allows the elements bar and beam to be checked for the calculation of mesh structures. The mesh is flat. The calculation is static, elastic, linear. The reference solution is analytical.

Three modellings can be used to test elements POU_D_T with and without restraints rotating, as well as elements BARRE.

Three modellingss are used to test elements POU_D_TG, POU_D_EM and POU_D_TGM with and without restraints rotational.
