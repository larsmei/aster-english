# v4.61.100 MTLP100 - Heating and soaking of an infinite bar with square cross section

**Summary:**

The purpose of this test is to provide a reference metallurgy calculation, in post-processing, of an evolutionary linear plane thermal calculation known to be analytical solution. More specifically, this test validates two-dimensional linear thermal calculations with exchange conditions and provides reference values (non-regression) for the austenitic transformation model at heating, as well as for the decomposition model of austenite at cooling.

It is noted that the program for entering TRC diagrams to produce [DEFI_TRC](doc:u4.43.04) command is attached to test case.

## 2 reference solution

### 2.1 Calculation method used for reference solution

Thanks to symmetries in geometry, the strong formulation of the problem becomes:

$$
\begin{align*}
    &\text{Trouver la température}\,T(x,y,t)\,\text{telle que}\\
    &\frac{\partial T}{\partial t} - \alpha \nabla\cdot\nabla T = 0, \quad\forall (x,y)\in[0, L]^2,\,t\in[t_{initial},t_{final}];\\
    &\frac{\partial T}{\partial x}(0,y,t) = 0, \quad\frac{\partial T}{\partial y}(x, 0, t) = 0;\\
    &\frac{\partial T}{\partial x}(L,y,t) = -\beta(T(L,y,t) - {T}_\infty), \quad \frac{\partial T}{\partial y}(x,L,t) = -\beta(T(x,L,t) - {T}_\infty);\\
    & T(x,y,0) = {T}_{0};\\
    &\text{où}\,\alpha=\lambda/(\rho C_p)\,\text{and}\,\beta=h/\lambda.
\end{align*}
$$

The $\theta(x,y,t) = (T(x,y,t) - {T}_{\infty})/({T}_0 - {T}_{\infty})$ variable change allows you to rewrite the problem as follows:

$$
\begin{align*}
    &\text{Trouver}\,\theta(x,y,t)\,\text{tel que}\\
    &\frac{\partial \theta}{\partial t} - \alpha \nabla\cdot\nabla \theta = 0;\\
    &\frac{\partial \theta}{\partial x}(0, y, t) = 0, \quad\frac{\partial \theta}{\partial y}(x, 0, t) = 0;\\
    &\frac{\partial \theta}{\partial x}(L, y, t) = -\beta\theta, \quad \frac{\partial \theta}{\partial y}(x, L, t) = -\beta\theta;\\
    & \theta(x,y,0) = 1.\\
\end{align*}
$$

The analytical solution of this thermal problem is estimated by decomposition into Fourier modes:

$$
\theta (x,y,t)
=
\sum_{i=1}^{\infty}
\sum_{j=1}^{\infty}
{
    {A}_{i,j}
    \,
    \exp \left (
        -{\omega}_{i}^{2}
        \,
        \alpha
        \,
        t
    \right )
    \,
    \exp \left (
        -{\omega}_{j}^{2}
        \,
        \alpha
        \,
        t
    \right )
    \,
    \cos({\omega}_{i} x)
    \,
    \cos({\omega}_{j} y)
}
$$

with coefficients

$$
{A}_{i,j}
=
\frac{16\sin({\omega}_{i}L)\sin({\omega}_{j}L)}{(2{\omega}_{i}L + \sin({2\omega}_{i}L))(2{\omega}_{j}L + \sin({2\omega}_{j}L))}
$$

where the ${\omega}_{k}$ eigenfrequencies for $k=i,\,j$ check the equation:

$$
({\omega}_{k} L)\;\tan({\omega}_{k} L)
=
\beta L
$$

From the input data, the first 10 values of $\omega_{k}$ are 1.14222685, 3.731838009, 6.64312075, 9.67758023, 12.75984689, 15.86426476, 18.98051609, 22.10377283, 25.23150137, 28.36225198.

Finally, the temperature is restored by:

$$
T(x,y,t)
=
\theta (x,y,t) \left(
    {T}_{0}
    -
    {T}_{\infty}
\right)
+
{T}_{\infty}
$$

The evolution of the theoretical temperature at points A, B and C is shown in the figure opposite.

![Figure](/figures/v4.61.100/Temperature_mtlp100.svg)

Reference values for metallurgical evolutions depend on the model and time integration of behavioral relationships. ** Reference values ** (non-regression tests) are not available.

The hardness of a material point depends on the metallurgical proportions of each phase.
** Reference values ** (non-regression tests) are not available.
