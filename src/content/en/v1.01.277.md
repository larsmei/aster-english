# v1.01.277 ERREU03 - Simple singularity detection in MECA_STATIQUE

**Summary:**

This test validates the emission of an error message when a single singularity is detected (absence or overabundance) by direct linear solvers (MUMPS, LDLT and MULT_FRONT) in MECA_STATIQUE.

## 1 Test principle

This test is used to validate the emission of a few messages by MECA_STATIQUE in the case of a symmetrical matrix:

- First case: there is a blockage missing. In this case, you get FACTOR_20/77 for LDLT, MULT_FRONT and MUMPS when $\mathrm{NPREC}>0$ and FACTOR_57 for MUMPS when $\mathrm{NPREC}<0$.
- Second case: there is an overabundant block. FACTOR_41/83 is obtained for LDLT, MULT_FRONT and MUMPS when $\mathrm{NPREC}>0$ and FACTOR_42 when MUMPS is obtained.
- Last case: Check that the FACTOR_84 message is sent when using the TYPE_RESOL='SYMDEF' parameter of the MUMPS solver, while the matrix to be reversed is not symmetrically defined as positive.
