# u4.26.01 Operator DEFI_GEOM_FIBRE

## 1 Purpose

Within the framework of a multifibre modelling, there are two "levels" of modelling:

- the so-called "longitudinal" modelling represented by a beam (with geometrical support SEG2)
- the plane modelling of the section (perpendicularly to the SEG2).

The operator DEFI_GEOM_FIBRE makes it possible to define the geometry of the fibre groups which will be used in the definition of the cross-section by means of the operator AFFE_CARA_ELEM.

The fibres may be described either by means of a plane mesh previously read by the operator LIRE_MAILLAGE (keyword SECTION) and/or in the form of "point" surfaces (keyword FIBRE or ASSEMBLAGE_FIBRE).

Each occurrence of SECTION, FIBRE or ASSEMBLAGE_FIBRE defines a set of fibres which must be named in a unique way. A set of fibres will have the same constitutive behaviour for all its fibres, defined by means of DEFI_COMPOR.

The command creates a data structure of type geom_fibre.

**Caution:**

With the information given in SECTION or FIBRE, it is possible to compute the majority of the integrated characteristics of the straight sections (area, static and quadratic moments). However, it is not possible to compute the torsional and warping inertias, nor the position of the centre of torsion. These quantities (grandeurs) must be given to the operator AFFE_CARA_ELEM.

If the fibres are defined from a mesh, the operator MACR_CARA_POUTRE makes it possible to read this mesh and to compute all the characteristics. The result of this operator is a table which may be used as input to the operator AFFE_CARA_ELEM.

## 2 Syntax

```text
gfibre = DEFI_GEOM_FIBRE(
    ◇ INFO = / 1 (par défaut),
             / 2,
    ◆ | SECTION = _F(
           ◆ GROUP_FIBRE = text,
           ◆ | TOUT_SECT = "OUI" (ou non renseigné),
             | GROUP_MA_SECT = grma,
           ◆ MAILLAGE_SECT = maillage,
           ◆ COOR_AXE_POUTRE = float,
           ◇ ANGLE = float,
        ),
      | FIBRE = _F(
           ◆ GROUP_FIBRE = text,
           ◇ CARA = / "SURFACE" (par défaut),
                    / "DIAMETRE",
           ◆ VALE = float,
           ◆ COOR_AXE_POUTRE = float,
           ◇ ANGLE = float,
        ),
    ◇ ASSEMBLAGE_FIBRE = _F(
         ◆ GROUP_ASSE_FIBRE = text,
         ◆ GROUP_FIBRE = text,
         ◆ COOR_GROUP_FIBRE = float,
         ◆ GX_GROUP_FIBRE = float,
      ),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```
## 3 Operands

### 3.1 Operand INFO

◊INFO

If the value of INFO is 2, the operator prints in the file 'MESSAGE', for each occurrence of the keywords SECTION or FIBRE, the characteristics of each fibre (position and area).

**Note:**

*All the characteristics are given with respect to the axis defined in the operand* *COOR_AXE_POUTRE, calling the coordinates of the section* $x$ *(horizontal) and* $y$ *(vertical).*

### 3.2 Keywords SECTION and FIBRE

♦|SECTION

|FIBRE

Define the entities of the beam mesh concerned and the sections which are assigned to them.

The keyword SECTION makes it possible to assign a section defined by a plane mesh (the elements of this mesh are the sections of the fibres). The numbering of the fibres depends entirely on the mesh and on the type of mesh cells (quadrangle or triangle).

The keyword FIBRE makes it possible to assign a section in which the fibres are defined by "points". The fibres are numbered from 1 to n in the order in which they were defined.

In the presence of both keywords, the numbering of the fibres will begin with the fibres defined under the keyword SECTION and then those defined under the keyword FIBRE. In order to obtain it, it is possible to set INFO=2 in DEFI_GEOM_FIBRE.

**Note:**

*At present the number of fibre groups on a beam element is limited to 10.*

#### 3.2.1 Operands common to SECTION and FIBRE

♦GROUP_FIBRE

This operand makes it possible to define a name for the fibre group (24 characters). This name will be used in the operator DEFI_COMPOR to assign a material and a constitutive behaviour to this fibre group. Recall that all the fibres defined by one occurrence of SECTION or FIBRE will have the same constitutive behaviour.

◊COOR_AXE_POUTRE=(xg,yg)

This operand makes it possible to define the coordinates of the axis of the beam in the frame of the straight section. The integrations (static moments or moments of inertia) will be carried out with respect to this axis. The default position is $(\mathrm{0.0,}0.0)$ .

◊ANGLE=angle

This operand makes it possible to define the angle of rotation of the frame in which the mesh is defined, in order to make it correspond to the principal frame of the beam. This rotation is always carried out after COOR_AXE_POUTRE. The default angle is $0.0$ .

When the coordinates of the fibres are given either by a mesh (keyword SECTION) or by triplets of values (keyword FIBRE), they are in a frame which is not linked to the beam. This makes it possible to define complex sections without being obliged to define them in the principal frame of inertia of the beam.

It is easier to parameterise the mesh of an angle section (figure) in the frame $({x}_{1,}{y}_{1})$ than in the frame $({x}_{2,}{y}_{2})$ . The mesh of the section is in the plane $\mathit{XY}$ .

![Figure](/figures/u4.26.01/1000000000000203000001219C784EB2B1877ECB.png)

**Figure** 3.2.1-a: Angle section.

The characteristics of the beams (section, inertias, ...) are defined in the principal frame of inertia; it is therefore necessary to establish the relation between the frame in which the fibres are defined and the principal frame of inertia of the beam. The keyword COOR_AXE_POUTRE makes it possible to define the translation of the frame linked to the mesh of the section in order to make it correspond to that of the beam. The keyword ANGLE makes it possible to rotate the mesh of the section in order to make it correspond to that of the beam.

In the example of the angle section (figure), in order to make the mesh correspond to the principal frame of the beam section, both keywords must be supplied:

- COOR_AXE_POUTRE = ( xg , yg )
- ANGLE= -90

#### 3.2.2 Operands specific to SECTION

The fibre group is defined by a set of "surface" fibres.

♦MAILLAGE_SECT

Name of the plane "mesh" which contains the "description of the section".

By "mesh", one means a set of 3-node triangular mesh cells and/or 4-node quadrilateral mesh cells. By "description of the section", one means a part of this "mesh" specified by one of the operands TOUT_SECT or GROUP_MA_SECT. Each mesh cell represents the section of a fibre.

♦/TOUT_SECT

/GROUP_MA_SECT

| **Operands** | **Contents / Meaning** |
| --- | --- |
| TOUT_SECT | The section is defined by all the mesh cells of the mesh defined under MAILLAGE_SECT |
| GROUP_MA_SECT | The section is defined by a list of mesh-cell groups |

**Notes:**

*Since it does not serve as a support for finite elements, the "mesh" does not necessarily have to have a connectivity; it may be composed of a set of mesh cells placed side by side or not.*

*The coordinates* $x$ *and* $y$ *of the plane mesh of the section (* $x$ *horizontal,* $y$ *vertical) are defined in a plane perpendicular to the axis of the beam. In order to define the twist angle, that is to say the angle between the axis* $x$ *of the plane mesh of the section and the axis* $Y$ *of the beam element, one must use the keyword* *ORIENTATION of the operator* *AFFE_CARA_ELEM.*

#### 3.2.3 Operands specific to FIBRE

The fibre group is defined by a set of "point" fibres.

◊CARA = 'SURFACE' | 'DIAMETRE'

Makes it possible to specify whether the third value given for each fibre is the area or the diameter (see VALE).

♦VALE

Each fibre is described by a triplet of values: $(x,y,\mathit{val})$ It is necessary to give the values in this sequence, as many triplets as there are fibres.

- $x$ and $y$ are the coordinates of the centre of the fibre in a plane perpendicular to the axis of the beam.
- $\mathrm{val}$ is either the area of a fibre, or the diameter of a cylindrical fibre.

The position of the frame may be modified by means of COOR_AXE_POUTRE. In order to give a twist angle, one must use the keyword ORIENTATION of the operator AFFE_CARA_ELEM.

### 3.3 Keyword ASSEMBLAGE_FIBRE

This keyword makes it possible to define an assembly of fibre groups. The kinematics linking the various fibre groups is particular and is used to account for phenomena specific to the modelling of fuel assemblies, cf. [R3.08.08](doc:r3.08.08) Multifibre beam element (straight).

♦GROUP_ASSE_FIBRE

This operand makes it possible to define a name for the fibre-assembly group (24 characters). This name will be used in the operator DEFI_COMPOR to assign a material and a constitutive behaviour to this fibre-assembly group. Recall that all the fibres defined by one occurrence of GROUP_ASSE_FIBRE will have the same constitutive behaviour.

♦GROUP_FIBRE

This operand makes it possible to define the list of the names of the fibre groups which will constitute the fibre assembly. The names of the groups are defined either by SECTION/GROUP_FIBRE or by FIBRE/GROUP_FIBRE.

♦COOR_GROUP_FIBRE

This operand makes it possible to define the coordinates of the centre of gravity of the fibre groups defined under the keyword GROUP_FIBRE. It is a list of reals (x1, y1, …, xn, yn) which is twice as long as the list given under GROUP_FIBRE. The coordinates of the fibre groups are translated by (xi, yi).

♦GX_GROUP_FIBRE

This operand makes it possible to define the torsion coefficient of the fibre groups defined under the keyword GROUP_FIBRE. It is a list of reals (gx1, …, gxn) which has the same length as the list given under GROUP_FIBRE.

## 4 Example

One wishes to build a reinforced-concrete beam section, with two cylindrical steel reinforcements, of diameter 32.

One creates a data structure named GF comprising two fibre groups:

- one is named SBET, and is created with a plane mesh,
- the other is named SACI, and is created with two point fibres for the steels.

MASEC1 = LIRE_MAILLAGE(UNITE = 21)

GF=DEFI_GEOM_FIBRE(

SECTION=_F(GROUP_FIBRE=’SBET’, MAILLAGE_SECT=MASEC1,

TOUT_SECT=’OUI’,

COOR_AXE_POUTRE=(0., 0.),),

FIBRE=_F(GROUP_FIBRE=’SACI’,

CARA=’DIAMETRE’,

VALE=( 0.05, -0.2, 32.E-3,

-0.05, -0.2, 32.E-3),

COOR_AXE_POUTRE=(0., 0.),),

)
