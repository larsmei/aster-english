# u4.42.07 Operator DEFI_MATER_GC

## 1 Purpose

The operator DEFI_MATER_GC makes it possible to define the material parameters used for civil-engineering studies.

The aim is to help the user to define the material parameters from more physical quantities (grandeurs).

In this command, one supplies the physical properties (elastic coefficients, elastic limits, characteristic strengths, ...), and as output one has a material concept, which one can then assign to the various mesh cells with the command AFFE_MATERIAU.

Produces a data structure of type mater.

## 3 Command DEFI_MATER_GC

### 3.1 Purpose of the command

The purpose of the command DEFI_MATER_GC is to simplify the input of material coefficients for a civil-engineering application, with the following laws:

- Mazars concrete law,
- concrete law for GLRC_DM,
- ecro_line steel law,
- non-local damage law for concrete ENDO_FISS_EXP,
- local damage law for concrete ENDO_LOCA_EXP.

In this command, one supplies the physical properties (elastic coefficients, elastic limits, characteristic strengths, ...), and as output one has a "material" concept, which one can then assign to the various mesh cells with the command AFFE_MATERIAU.

These output "material" concepts may also be used by the operator DEFI_GLRC, for the reinforced-concrete cases for GLRC_DM and for ECRO_LINE steel.

### 3.2 Operand INFO

Makes it possible to have, in the message file, the echo of the command DEFI_MATERIAU used by DEFI_MATER_GC when defining the material.

The command DEFI_MATER_GC always prints the material parameters which are passed to the command DEFI_MATERIAU (see the section "example of use").

### 3.3 Other operands

The operands RHO, ALPHA, AMOR_ALPHA, AMOR_BETA, AMOR_HYST correspond to, and have the same meaning as, those found under the factor keyword ELAS of the command DEFI_MATERIAU [U4.43.01].

## 4 Factor keyword MAZARS

The Mazars constitutive model is an elastic damageable constitutive model making it possible to describe the softening behaviour of concrete. It distinguishes the behaviour in tension and in compression.

### 4.1 Operand CODIFICATION

The command DEFI_MATER_GC can use rules of good practice, or recommendations drawn from the codifications, in order to determine the parameters of the constitutive law MAZARS.

♦ CODIFICATION = ’BAEL91’|’EC2’|’ESSAI’

- ’BAEL91’: indicates that the parameters used in the definition of the materials are taken from the BAEL1991 codification.
- ’EC2’: indicates that the parameters used in the definition of the materials are taken from the EUROCODE2 codification.
- ’ESSAI’: indicates that the parameters used in the definition of the materials come from tests.

For example, according to BAEL 1991, for the concrete material, given its characteristic compressive strength fcj, its tensile strength may be estimated by: $\mathit{FTJ}=0.6+0.06\mathit{FCJ}$ where FTJ and FCJ are in $\mathit{MPa}$ .

#### 4.1.1 Case where CODIFICATION=’BAEL91’

The parameters used in the definition of the materials are taken from the BAEL1991 codification.

♦ UNITE_CONTRAINTE

Stress unit of the problem [ $\mathit{MPa}$ | $\mathit{Pa}$ ]: megapascal or pascal. Supplying this operand is mandatory, because the formulae used below require one to know whether the material parameters are in $\mathit{Pa}$ or $\mathit{MPa}$ . The material parameters which are returned by the command are in the same system of units. UNITE_CONTRAINTE must therefore be compatible with the units of the study.

- $\mathit{Pa}$ : the material parameters have the dimension of $\mathit{Pa}$ .
- $\mathit{MPa}$ : the material parameters have the dimension of $\mathit{MPa}$ .

♦ FCJ

Peak stress in compression, in $\mathit{Pa}$ or $\mathit{MPa}$ , according to the value of UNITE_CONTRAINTE.

#### 4.1.2 Case where CODIFICATION=’EC2’

♦ UNITE_CONTRAINTE

Stress unit of the problem $\mathit{MPa}$ or $\mathit{Pa}$ : megapascal or pascal. Supplying this operand is mandatory, because it is necessary to return the material parameters in the system of units used to carry out the study.

♦ CLASSE

The compressive strength of the concrete is designated by strength classes related to the characteristic strength measured on a cylinder or on a cube, in accordance with EN 206-1.

The classes available in the operator are all those defined in EUROCODE 2:

’C12/15’ ’C16/20’ ’C20/25’ ’C25/30’ ’C30/37’ ’C35/45’ ’C40/50’

’C45/55’ ’C50/60’ ’C55/67’ ’C60/75’ ’C70/85’ ’C80/95’ ’C90/105’

#### 4.1.3 Case where CODIFICATION=’ESSAI’

In this case, the user must supply all the characteristics required in order to determine the parameters of the MAZARS constitutive law. The user must give these characteristics in a system of units compatible with the study.

The mandatory parameters:

♦ FCJ: Peak stress in compression.

♦ EIJ: Young's modulus.

♦ EPSI_C: Peak strain in compression.

♦ FTJ: Peak stress in tension.

The optional parameters, presented in the table, are those found under the factor keyword MAZARS of the command DEFI_MATERIAU [U4.43.01](doc:u4.43.01).

### 4.2 Operation

#### 4.2.1 Parameters of the MAZARS law

The parameters of the law are determined using the following characteristics: FCJ, EIJ, EPSI_C, FTJ. The formulae are:

${\epsilon}_{0}={f}_{\mathit{tj}}/{E}_{ij}$ $\beta =1.10$ ${B}_{T}={E}_{ij}/{f}_{\mathit{tj}}$ ${A}_{T}=0.70$

${B}_{c}=\frac{1}{{\epsilon}_{c}\nu \sqrt{2}}$ ${A}_{c}=\frac{\left(\frac{{f}_{\mathit{cj}}\nu \sqrt{2}}{{E}_{ij}}-{\epsilon}_{0}\right)}{{\epsilon}_{c}\nu \sqrt{2}\exp\left({B}_{c}({\epsilon}_{0}-{\epsilon}_{c}\nu \sqrt{2})\right)-{\epsilon}_{0}}$

${\sigma}_{\mathit{ELS}}=0.6{f}_{\mathit{cj}}$ ${\epsilon}_{\mathit{ELU}}=3.5‰$

${A}_{c}$ and ${B}_{c}$ are determined by solving the equations arising from the $\mathrm{1D}$ expression of the MAZARS behaviour, so as to respect the stress and the strain at the peak, as well as the horizontal tangent at the peak.

- ${B}_{c}$  is obtained by solving $f'({\epsilon}_{c})=0$
- ${A}_{c}$  by solving ${f}_{\mathit{cj}}=f({\epsilon}_{c})$ .

#### 4.2.2 In the BAEL 1991 case

Two operands are mandatory: UNITE_CONTRAINTE, FCJ.

The command determines the required quantities (grandeurs) by means of formulae or rules taken from bael91. In the formulae below the quantities (grandeurs) ${f}_{\mathit{cj}},{f}_{\mathit{tj}},{E}_{ij}$ are in $\mathit{MPa}$ .

${E}_{ij}=11000.0\sqrt[3]{{f}_{\mathit{cj}}}$ ${f}_{\mathit{tj}}=0.6+0.06{f}_{\mathit{cj}}$ ${\epsilon}_{c}=0.620E-3\sqrt[3]{{f}_{\mathit{cj}}}$ $\nu =0.200$

The parameters of the MAZARS law are then determined.

#### 4.2.3 In the EUROCODE 2 case

Two operands are mandatory: UNITE_CONTRAINTE, CLASSE.

The command determines the required quantities (grandeurs) by means of formulae or rules taken from EUROCODE 2. In the formulae below the quantities (grandeurs) ${f}_{\mathit{ck}},{f}_{\mathit{cm}},{f}_{\mathit{ctm}},{E}_{\mathit{cm}}$ are in $\mathit{MPa.}$

${f}_{\mathit{ck}}$ : characteristic compressive strength measured on a cylinder at 28 days.

${f}_{\mathit{cm}}$ : mean compressive strength of the concrete at 28 days.

${f}_{\mathit{cm}}={f}_{\mathit{ck}}+8.0$

${f}_{\mathit{ctm}}$ : mean tensile strength of the concrete.

${f}_{\mathit{ctm}}=\lbrace \begin{array}{cc}0.30{{f}_{\mathit{ck}}}^{2/3}& \mathit{pour}\mathit{classe}\le \text{C50/60}\\ 2.12\log(1+{f}_{\mathit{cm}}/10)& \mathit{pour}\mathit{classe}>\text{C50/60}\end{array}$

${E}_{\mathit{cm}}$ : tangent modulus

${E}_{\mathit{cm}}=22.0E+03{\left(\frac{{f}_{\mathit{cm}}}{10}\right)}^{0.3}$

${\epsilon}_{\mathit{c1}}$ : peak strain in $‰$

${\epsilon}_{\mathit{c1}}=0.7{{f}_{\mathit{cm}}}^{0.31}\mathit{toujours}\le 2.8$

${\epsilon}_{\mathit{cu1}}$ : ultimate limit strain in $‰$ .

${\epsilon}_{\mathit{cu1}}=\lbrace \begin{array}{cc}2.80+27{\left[\frac{98-{f}_{\mathit{cm}}}{100}\right]}^{4}& \mathit{pour}\mathit{classe}>\text{C50/60}\\ 3.5& \mathit{pour}\mathit{classe}\le \text{C50/60}\end{array}$

The parameters of the MAZARS law are then determined.

#### 4.2.4 In the ESSAI case

Four operands are mandatory: FCJ, EIJ, EPSI_C, FTJ. The parameters of the MAZARS constitutive law are determined as previously.

If optional operands presented in the table are supplied, they are taken into account by the command. It is therefore necessary to ensure the consistency of the quantities (grandeurs) supplied, notably in the following cases:

- the user gives ${B}_{c}$ . The equation $f'({\epsilon}_{c})=0$ may not be satisfied; in this case the behaviour will pass through the point ${f}_{\mathit{cj}}$ but ${f}_{\mathit{cj}},{\epsilon}_{c}$ will no longer be an extremum.
- the user gives ${A}_{c}$ . The equation ${f}_{\mathit{cj}}=f({\epsilon}_{c})$ may not be satisfied; in this case the behaviour will not pass through the point ${f}_{\mathit{cj}}$ and ${\epsilon}_{c}$ .

## 7 Factor keyword ENDO_FISS_EXP

The constitutive model ENDO_FISS_EXP is a non-local elastic damageable constitutive model (available in the GRAD_VARI modelling). It makes it possible to describe the softening behaviour of concrete. In particular, it distinguishes the behaviour in tension and in compression, partially restores the stiffness in compression, and describes well the states of shear or of biaxial tension. When the characteristic length tends towards zero, it approaches a cohesive model, which explains why one supplies parameters characteristic of a cohesive law rather than of a volumetric damage model.

### 7.1 Operands

| E | Young's modulus (Pa) |
| --- | --- |
| NU | Poisson's ratio |
| FT | Damage threshold in uniaxial tension (Pa) |
| FC | Damage threshold in compression (Pa) |
| GF | Fracture energy (N/m) |
| P | Principal hardening parameter of the asymptotic cohesive law |
| G_INIT | Partial fracture energy resulting from the initial slope |
| Q | Secondary hardening parameter of the asymptotic cohesive law |
| Q_REL | Secondary hardening parameter (between 0 and 1) |
| LARG_BANDE | Width of the localisation band (m) |
| REST_RIGI_FC | Stiffness-restoration coefficient (0 = no restoration) |
| COEF_RIGI_MINI | Threshold for switching to the frozen secant tangent matrix |

**Table**  7.1-a: Material parameters of the law ENDO_FISS_EXP

### 7.2 Operation

Some characteristics do not require further explanation: Young's modulus, Poisson's ratio, the damage thresholds in tension and in compression, the fracture energy. They are usual characteristics for the modelling of the damage of concrete.

As regards the parameters P and Q, which characterise the normalised response of the asymptotic cohesive model (the stress is normalised by FT, the opening by GF/FT), several ways of supplying them are made available. One may directly supply P (greater than 1), or the effect of P on the initial slope of the cohesive response via the datum of the corresponding fracture energy G_INIT, if the cohesive-softening model were linear with the initial slope as its slope. This way of characterising the initial slope is used by some authors, notably within the framework of a bilinear cohesive law (one then speaks of *Gf*, with a lower-case letter, as opposed to *GF*, with an upper-case letter, which denotes the whole of the fracture energy). For Q, one may directly supply its value (zero by default), but it is constrained to remain between 0 and a maximum value which depends on P. To simplify the supplying of Q, the possibility is offered of supplying Q relative to this maximum value via the keyword Q_REL (with a value between 0 and 1, therefore).

As regards stiffness restoration, the model ENDO_FISS_EXP introduces a regularisation parameter $\gamma$ which smooths the jump in stiffness between tension and compression. Rather than supplying directly the value of $\gamma$, which is not necessarily very meaningful, one prefers to indicate via REST_RIGI_FC the level of restored stiffness relative to the initial stiffness for a strain (in compression) equal to FC/E. This value therefore lies between 0 (no stiffness restoration) and 1 (strictly less than 1, total restoration of stiffness not being possible with the chosen regularisation function). A value of 0.9 is proposed by default.

Finally, one introduces the width of the localisation band, which is supposed to reflect a cohesive crack. It is twice the parameter D (which, for its part, measures the half-width of the band in 1D, as described in the theoretical reference of the model).

As for the parameter COEF_RIGI_MINI, it is the one introduced in DEFI_MATERIAU [U4.43.01](doc:u4.43.01). When the residual stiffness normalised by E is lower than COEF_RIGI_MINI, one substitutes for the tangent matrix the secant matrix corresponding to this stiffness, which limits the problems linked to possible totally destroyed zones (i.e. with no residual stiffness). This parameter has no effect on the physics of the model; it acts only on the convergence properties of the Newton algorithm. By default, this function is not activated (COEF_RIGI_MINI = 0), which seems to suit most cases very well.

In general, one refers to the reference documentation of the model [R5.03.28](doc:r5.03.28) for more detailed explanations of the meaning of the various parameters of the model.

## 8 Factor keyword ENDO_LOCA_EXP

The constitutive model ENDO_LOCA_EXP is a local elastic damageable constitutive model. It makes it possible to describe the softening behaviour of concrete. In particular, it distinguishes the behaviour in tension and in compression, partially restores the stiffness in compression, and describes well the states of shear or of biaxial tension. Owing to its local character, it is intended for a homogenised representation of structural cracks, which explains the introduction of an inter-crack distance which sets the size of the zones containing at most one crack. At the scale of this zone, its response is close to that of ENDO_FISS_EXP which, for its part, would describe the detail of the crack. Some parameters are therefore common with those of ENDO_FISS_EXP. For further information, one may refer to the document [R7.01.42](doc:r7.01.42) and to the references cited therein.

### 8.1 Operands

| E | Young's modulus (Pa) |
| --- | --- |
| NU | Poisson's ratio |
| FT | Strength in uniaxial tension (Pa) |
| FC | Strength in uniaxial compression (Pa) |
| GF | Fracture energy (N/m) |
| P | Hardening parameter |
| DIST_FISSURE | Mean inter-crack distance (m) |
| REST_RIGI_FC | Stiffness-restoration coefficient (0 = no restoration) |

**Table**  8.1-a: Material parameters of the law ENDO_LOCA_EXP

### 8.2 Operation

Some characteristics do not require further explanation: Young's modulus, Poisson's ratio, the strengths in tension and in compression, the fracture energy. They are usual characteristics for the modelling of the damage of concrete.

The parameter P influences the shape of the hardening, leading to a stress–strain response which is all the more curved the larger it is. It is analogous to the parameter P of the law ENDO_FISS_EXP. There is no other parameter characterising the hardening: relative to ENDO_FISS_EXP, the choice has been made to take Q=0.

As regards stiffness restoration, the model ENDO_LOCA_EXP introduces a regularisation parameter $\gamma$ which smooths the jump in stiffness between tension and compression. Rather than supplying directly the value of $\gamma$, which is not necessarily very meaningful, one prefers to indicate via REST_RIGI_FC the level of restored stiffness relative to the initial stiffness for a strain (in compression) equal to FC/E. This value therefore lies between 0 (no stiffness restoration) and 1 (strictly less than 1, total restoration of stiffness not being possible with the chosen regularisation function). A value of 0.95 is proposed by default.

Finally, one introduces DIST_FISSURE, the mean inter-crack distance, which depends in particular on the reinforcement in the concrete. In practice, only the ratio GF/DIST_FISSURE plays a role, but it has been preferred to keep the two parameters because each carries a specific physical meaning. For reasons of local stability of the model (no snap-back at the scale of the material point), there is an upper bound on the inter-crack distance that one can model. Compliance with this condition is checked during data setup.

## 9 Factor keyword ENDO_LOCA_TC

The constitutive model ENDO_LOCA_TC [R7.01.47](doc:r7.01.47) is a local elastic damageable constitutive model. It makes it possible to describe the softening behaviour of concrete. In particular, it distinguishes the behaviour in tension and in compression, partially restores the stiffness in compression, and describes well the states of shear or of biaxial tension. It takes up the fundamentals of the models ENDO_ISOT_BETON [R7.01.04](doc:r7.01.04) and ENDO_LOCA_EXP [R7.01.42](doc:r7.01.42) and enriches them by introducing:

- a rationalised damage threshold, with a view to optimising numerical robustness;
- an effect of the damage in compression, so as to bound the stresses there, without however seeking to model the post-peak phase. The threshold stress in compression tends monotonically towards a limit, the compressive strength.

A local model such as ENDO_LOCA_TC must be used in situations of diffuse damage which may appear owing to the presence of reinforcement in the concrete, or because of an imposed-strain loading as in thermal analysis. The scope of use of ENDO_LOCA_TC is therefore that of distributed cracks (or a network of cracks) for which one can construct a mean behaviour per RVE (Representative Elementary Volume).

### 9.2 Operation

Some characteristics do not require further explanation: Young's modulus, Poisson's ratio, the strengths in tension and in compression, the threshold stress for initiation in compression, the fracture energy. They are usual characteristics for the modelling of the damage of concrete, identified by means of a uniaxial tensile test and a uniaxial compressive test.

The parameter COEF_ECRO_TRAC influences the shape of the hardening, leading to a stress–strain response which is all the more curved the larger it is. A value of COEF_ECRO_TRAC of -0.2 leads to quasi-linear (negative) hardening, whereas values between 1 and 4 are more representative of the hollowing of the tensile curves. In the absence of a tensile curve with which to identify this parameter, a recommended value is 1.5.

Finally, one introduces DIST_FISSURE (denoted in the reference documentation $L_{F}$) the mean inter-crack distance, which depends in particular on the reinforcement in the concrete. In practice, only the ratio GF/DIST_FISSURE (ENER_TRAC_RUPT_N) plays a role but it has been preferred to keep the two parameters because each carries a specific physical meaning. For reasons of local stability of the model (no snap-back at the scale of the material point), there is an upper bound on the inter-crack distance that one can model. Compliance with this condition is checked during data setup.

It is possible to use the keyword CODIFICATION with the option "FIB_MODEL_CODE" in order to identify the parameters of the model using equations taken from the fib model. However, the value of COEF_ECRO_TRAC may also be set to 1.5, following Peterson's proposal based on a bilinear post-peak curve. The option "Essai" makes it possible to supply the values of all the parameters. The user may also use "FIB_MODEL_CODE" and supply the values of the parameters that are known.
