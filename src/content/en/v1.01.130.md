# v1.01.130 ZZZZ130 - Validation of the CREA_CHAMP/OPERATION command = 'EVAL' / 'DISC'

**Summary:**

This test case validates two operations of the CREA_CHAMP command:

- 'EVAL' operation that is used to convert a function field into a real field by evaluating the function field functions;
- 'DISC' operation, which is used to modify the "discretization" of an existing field. For example, transform a field at nodes into a field at Gauss points.

Operation 'EVAL' is validated in the following configurations:

- calculation of a stress field by applying a geometry dependent function to a ELGA_GEOM_R field;
- calculation of a temperature field by applying a geometry- and time-dependent function to a NOEU_GEOM_R field.

**modellings**

Modelling A performs both these steps with the CREA_CHAMP command.

Modelling B creates the same internal stress fields and variables using the single field API Python (objects *Component*).

Operation 'DISC' is validated in the following configurations:

- CART field converted to ELNO field;
- NOEU field converted to ELNO field;
- ELNO field converted to NOEU field;
- CART field converted to ELEM field;
- ELGA field converted to ELNO field;
- ELGA field converted into NOEU field.

This documentation is deliberately succinct.
