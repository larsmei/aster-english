# v6.04.124 SSNV124 - Regularized limit analysis. Norton-Hoff Law

**Summary**

This test validates operators used in regularised limit analysis. The limit load is calculated by a kinematic approach regulated by the Norton-Hoff-Friaâ method.

A rectangular plate (modelization A) or a cube (modelization B) or a cylinder axisymmetric (modelization C) is considered. The constituent material checks the resistance criterion of vonMises and the structure is loaded on the edges. The calculation allows the parameter of the limit load in the direction of loading to be obtained.

The structure is modelled by incompressible elements and the load for which the limit load parameter is sought is normalized (unit power).

The resolution by the regularised method of Norton-Hoff-Friaâ is done by piloting in the STAT_NON_LINE command. An post-processing in the POST_ELEM command allows the value of a higher terminal of the limit load, as well as an estimate by lower value, when there is no constant load applied.

The reference solution is analytical and the results are in perfect agreement with the reference values.
