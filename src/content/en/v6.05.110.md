# v6.05.110 SSNS110 – Extraction of a rebar table represented by a membrane

**Summary:**

The objective of this test is to validate the Modelling of the decohesion of a rebar sheet, which is represented by a membrane, connected to the surrounding volume by an interface law. This Modelling is compared to a reference model in which the steel bars are modelled in 3D.

## 1 Reference problem

### 1.1 Geometry

A reinforced concrete plate, with two straight-line reinforcing sheets, is considered to be held at one end and a force is applied to the cross-section of the steel bars at the other end.

## 3 Modelling A

### 3.1 Modelling characteristics

A model called "decohesion grid model" is used to represent the rebar table (see reference [1] ). The mechanical behaviour of the sheet is represented by a membrane model, the coefficients of which are calculated analytically:

${M}_{\mathit{LLLL}}={M}_{\mathit{TTTT}}={E}_{A}\frac{\pi {d}^{2}}{4e}$

The other coefficients of rigidity of the membrane are all zero. This membrane model is therefore equivalent to two models of orthogonal orientation grid.

Furthermore, this membrane is connected to the surrounding volume by an CZM_LAB_MIX interface law, which allows the membrane to slide in the $(\mathit{Oy})$ direction. The parameters of this interface law are the same as those given in paragraph 1.2., except for the critical constraint which is written in the form:

${\sigma}_{C}=\frac{2\pi d}{e}\times 10\text{MPa}$

### 3.2 Mesh characteristics

The mesh has 4505 nodes, 2543 quadratic tetrahedrons (TETRA10) to model concrete, 162 degenerated quadratic pentahedrons (PENTA15) to represent the steel-beton interface, and 162 quadratic triangles (TRIA6) to represent the rebar.

## 5 Summary of the results

This test validates the principle of representation of the rebar arrays by a membrane model linked to the surrounding volume by an interface law. This validation is based on a comparison with a reference 3D model, supplemented by several non-regression tests.
