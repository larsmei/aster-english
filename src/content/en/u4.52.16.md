# u4.52.16 Operator CALC_CORR_SSD

## 1 Purpose

Estimate the quality of the reduced models in the framework of the modal analysis. This command makes it possible to compute the works of the residual coupling forces at each of the interfaces, as well as the works of the residual forces on the internal parts of the substructures.

Furthermore, on the basis of these works, the command computes enrichment terms, based on:

- the works of the residual forces at the interfaces, for each substructure,
- the works of the residual forces on the internal parts, for each substructure,
- the differential displacements (separation) that may appear at the interfaces between the substructures.

## 3 Operands

### 3.1 Keyword MODELE_GENE

**♦**     MODELE_GENE

Name of the generalised model whose quality one wishes to check. The analyses performed are detailed in the documentation [U2.06.04](doc:u2.06.04).

### 3.2 Keyword RESU_GENE

```text
♦    RESU_GENE
```

Name of the generalised result on the basis of which one checks the quality of the generalised model, and which then makes it possible to compute enrichments.

### 3.3 Keyword SHIFT

```text
◊    SHIFT
```

Value of the frequency shift making it possible to compute the enrichment terms for the macro-elements whose stiffness matrix would be singular once the boundary conditions of the interfaces have been released.

This is for example the case in the test SDLS122A, where one considers square macro-elements, clamped on the edge associated with the interface, and simply supported on the 2 other free corners. By releasing the clamping of the interface edge, the structure becomes hinged, and therefore presents rigid-body modes. In the absence of $\mathit{SHIFT}>0$ , the matrix is singular and the analysis cannot proceed correctly.

### 3.4 Keyword UNITE

```text
◊    UNITE
```

Specifies the unit of the file in which the results of the computations of the interface works will be printed. By default, the results are printed on unit 8.

### 3.5 Keyword VERIF

```text
◊    VERIF
```

Factor keyword inherited from the definition of the generalised model, in order to check its consistency. One determines whether the link is compatible or not. The nodes of the two interfaces do not a priori have to be ordered so that they coincide in pairs. If the nodes of the interfaces are not facing each other in pairs, the code detects this state and reorders the nodes so as to put them back facing each other.

#### 3.5.1 Operand STOP_ERREUR

```text
Permet d'effectuer ou non la vérification de cohérence du modèle généralisé.
```

#### 3.5.2 Operand PRECISION / CRITERE

Indicates the precision threshold beyond which the links are incompatible. It is the distance (relative or absolute according to CRITERE) beyond which the link nodes are considered too far apart to be effectively connected.
