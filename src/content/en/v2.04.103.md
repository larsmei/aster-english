# v2.04.103 SDLV103 – Closed with IFS in dynamic substructure

**Summary:**

The problem of determining the eigenmodes of a pipe filled with water in the form of a closed lyre on itself with IFS taken into account is considered.

This is done by using a dynamic substructure methodology using the required interface modes (see U2.07.07 for more precision).

The approach's ability to represent the modal behaviour of the overall structure is shown.

## 2 reference solution

These test cases are non-regression test cases. The reference solution is the one obtained with an code_aster calculation.
