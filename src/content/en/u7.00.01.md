# u7.00.01 Operator EXEC_LOGICIEL

## 1 Purpose

The purpose of this operator is to execute external software on the local machine. This may be any executable program or script.

## 2 Syntax

```text
EXEC_LOGICIEL(
    ◆ LOGICIEL = text,
    ◇ ARGUMENT = text,
    ◇ SHELL = / "OUI",
              / "NON" (par défaut),
    ◇ CODE_RETOUR_MAXI = int,
    ◇ INFO = / 1,
             / 2 (par défaut),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand LOGICIEL

```text
◊    LOGICIEL    =    nom_exe
```

Name of the command or of the executable to be called. It is a character string (between '), the full path must be specified in order to reach the executable.

### 3.2 Keyword ARGUMENT

```text
◊    ARGUMENT    =    l_arg
```

Makes it possible to define the list of arguments passed to the executable. Each element of the list corresponds to one argument supplied to the executable. If an argument contains a space, the executable will retrieve a character string containing the space (see keyword SHELL).

### 3.3 Keyword SHELL

```text
◊    SHELL    =    'OUI'/'NON'
```

Good practice consists in executing a program (keyword LOGICIEL) with a list of arguments (keyword ARGUMENT). One then leaves SHELL at its default value, which is 'NON'.

Sometimes, one wishes to execute not a program to which arguments are passed but a complete command line (for example beginning with an if test). In this case, one must use SHELL='NON'. The keyword LOGICIEL and any additional ARGUMENT[s] are joined with a space in order to compose the complete command line.

See the documentation of the Python subprocess module for the pitfalls of SHELL='NON'(False).

### 3.4 Operand INFO

```text
◊    INFO    =    info
```

In the case where INFO=2, the messages coming from the executed command are printed in the MESSAGE file. This is the default value. This makes it possible to keep a trace of the execution.

### 3.5 Operand CODE_RETOUR_MAXI

```text
◊    CODE_RETOUR_MAXI    =    icode
```

Maximum value of the return code returned by the command or the software that is tolerated in order to consider that the execution went well. By default this value equals 0; if it is assigned to –1, the return code of the command is ignored.
