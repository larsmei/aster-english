# u4.51.10 Operator CALCUL

## 1 Purpose

For mechanics:

- compute the stresses and the internal variables for the integration of a non-linear constitutive law;
- compute the elementary vectors vect_elem of the internal and nodal forces and the elementary matrices matr_elem of a tangent matrix;
- compute the elementary vectors vect_elem of the forces corresponding to the command variables.

Produces a data structure of type table_container.

## 3 Operands

### 3.1 Keyword PHENOMENE

> ◊ PHENOMENE        = /'MECANIQUE'                        [DEFAUT]
> Makes it possible to choose the phenomenon that will be computed. Only mechanics is possible

### 3.2 Keyword TABLE

♦    TABLE

Makes it possible to introduce a non-empty table_container in order to complete it (with the appropriate order number) with the new concepts computed in the operand CALCUL.

If the table already contains fields for the order number requested by the keyword INCREMENT/NUME_ORDRE, these fields are overwritten and an alarm is issued to warn the user.

### 3.3 Keyword MODELE

```text
♦    MODELE = mo
```

Name of the concept defining the model whose elements are the subject of the analysis.

### 3.4 Keyword CHAM_MATER

```text
♦    CHAM_MATER = chmat
```

Name of the concept defining the material field assigned on the model mo.

### 3.5 Keyword CARA_ELEM

```text
◊    CARA_ELEM = carac
```

Name of the concept defining the characteristics of the beam elements, shells, etc.

### 3.6 Keyword INCREMENT

♦    INCREMENT

Defines the time intervals taken in the incremental method.

In mechanics, the time instants thus defined have a physical meaning only for constitutive relations in which time appears explicitly (viscoelastic or viscoplastic, for example). In the other cases, they only make it possible to index the load increments and to parameterise the evolution of a possible temperature field.

#### 3.6.1 Operand LIST_INST

♦    LIST_INST = litps

The analysis time instants are those defined in the concept litps by the operator DEFI_LIST_REEL [U4.34.01](doc:u4.34.01).

#### 3.6.2 Operands NUME_ORDRE

```text
♦    NUME_ORDRE =    nume
```

Makes it possible to define the order number (and therefore the time instant) for which the quantities will be computed in the table_container **.**

### 3.7 Operand INFO

```text
◊    INFO =    inf
```

Makes it possible to produce various intermediate printouts in the message file.

### 3.8 Keyword EXCIT

◊    EXCIT

This factor keyword makes it possible to describe at each occurrence a load (applied loads and boundary conditions), and possibly a multiplying coefficient and/or a type of load.

This keyword is useful for producing the matrix of the dualised Dirichlet boundary conditions which will be integrated into the matr_elem produced by the computation of the tangent matrix.

#### 3.8.1 Operand CHARGE

```text
♦    CHARGE : chi
```

**chi** is the mechanical loading (possibly comprising the evolution of a temperature field) specified at the $i$-th occurrence of EXCIT.

#### 3.8.2 Operand FONC_MULT

```text
◊    FONC_MULT : fi
```

fi is the multiplying function of time of the loading specified at the i-th occurrence of EXCIT.

The loading and the boundary conditions for

![Figure](/figures/u4.51.10/Object_2.svg)

occurrences of the factor keyword EXCIT are:

$\mathit{ch}=\sum_{i=1}^{n}{f}_{i}.{\mathit{ch}}_{i}$

For the Dirichlet conditions, of course, only the imposed value is multiplied by fi.

By default: fi=1.

### 3.9 Operand OPTION

```text
♦    OPTION        =    /'COMPORTEMENT'    [defaut]
/'MATR_TANG_ELEM'
/'FORC_INTE_ELEM'
/'FORC_NODA_ELEM'

                     /'FORC_VARC_ELEM_M'
```

```text
/'FORC_VARC_ELEM_P'
```

Makes it possible to specify what one computes:

- 'COMPORTEMENT' integrates the constitutive law and therefore produces three objects: a cham_elem of the stresses, a cham_elem of the internal variables and an integer indicating the maximum of the return code of the constitutive law;
- 'MATR_TANG_ELEM' computes the consistent tangent matrix (option FULL_MECA) and therefore produces four objects: a cham_elem of the stresses, a cham_elem of the internal variables, an integer indicating the maximum of the return code of the constitutive law and a matr_elem of the tangent elementary matrices;
- 'FORC_INTE_ELEM' computes the vector of the internal forces after integration of the constitutive law (RAPH_MECA in the Aster language) and therefore produces four objects: a cham_elem of the stresses, a cham_elem of the internal variables, an integer indicating the maximum of the return code of the constitutive law and a vect_elem of the elementary vectors of the internal forces;
- 'FORC_NODA_ELEM' computes the vector of the nodal forces from the stresses at the Gauss points and produces a vect_elem of the elementary vectors of the nodal forces.
- 'FORC_VARC_ELEM_M' computes the vector of the forces corresponding to the command variables at the previous time (given by LIST_INST). See the relevant paragraph in the theoretical documentation of STAT_NON_LINE [R5.03.01].
- 'FORC_VARC_ELEM_P' computes the vector of the forces corresponding to the command variables at the current time (given by LIST_INST). See the relevant paragraph in the theoretical documentation of STAT_NON_LINE [R5.03.01].

### 3.10 Keywords DEPL/INCR_DEPL/SIGM/VARI

◊    DEPL            =    depl,                [cham_no],

◊    INCR_DEPL        =    incdepl,            [cham_no],

◊    SIGM            =    sigm,                [cham_elem],

◊    VARI            =    vari,                [cham_elem],

Makes it possible to introduce input fields in order to compute the various fields by the command CALCUL:

- DEPL gives a displacement field;
- INCR_DEPL is the increment of the displacement field since the beginning of the time step;
- SIGM gives a stress field;
- VARI gives a field of internal variables.

**Notes:**

One must take care to be consistent between the constitutive behaviour requested by COMPORTEMENT and the size of the field of internal variables.

The stress field used to compute the option FORC_NODA_ELEM is not the same according to the analyses requested. Indeed, if one integrates the constitutive law (options COMPORTEMENT, MATR_TANG_ELEM, FORC_INTE_ELEM), then the stress field taken in the computation of the option FORC_NODA_ELEM will be the one computed **after** the integration of the constitutive behaviour. In this case, SIGM is the tensor of the **initial** stresses and will not be the one used in the computation of FORC_NODA_ELEM. On the other hand, if only the option FORC_NODA_ELEM is requested, then one will use directly the stress field given by SIGM.

### 3.11 Operand MODE_FOURIER

```text
◊    MODE_FOURIER= nh
```

Positive or zero integer indicating the Fourier harmonic on which one computes the elementary vector for an axisymmetric 2D model.

## 4 Use of CALCUL and of the table_container

CALCUL produces only a table_container in which, for each order number, one or more fields are stored (stresses, internal variables, elementary vectors of the internal forces, elementary matrices of the tangent matrix).

To extract these fields, one should use the command EXTR_TABLE. For example, if one wants the stress field coming from the command CALCUL, one will do:

CONT=CALCUL(OPTION=('COMPORTEMENT','FORC_INTE_ELEM','MATR_TANG_ELEM'),

MODELE=MO,

CHAM_MATER=CHMAT,

INCREMENT=_F(LIST_INST=LIST,

NUME_ORDRE=1),

EXCIT=_F(CHARGE=CHARGE),

DEPL=U,

INCR_DEPL=DU,

SIGM=SIGP,

VARI=VARIP,

COMPORTEMENT=_F(RELATION='VMIS_ISOT_LINE',),

INFO=2,);

SIGM=EXTR_TABLE(TYPE_RESU='CHAM_GD_SDASTER',

TABLE=CONT,

NOM_PARA='NOM_SD',

FILTRE=_F(NOM_PARA='NOM_OBJET',

VALE_K='SIEF_ELGA'),)

To compute the right-hand side of the external forces or other quantities (such as the mass matrices), one may use the commands CALC_VECT_ELEM or CALC_MATR_ELEM.

The matr_elem or the vect_elem may be assembled via the commands ASSE_VECTEUR and ASSE_MATRICE.

It should be noted that the stiffness MATR_ELEM produced by CALCUL also contain the contribution coming from the dualisation of the Dirichlet boundary conditions (EXCIT).

An example of the use of CALCUL for mechanics is available in the test case pynl01a. For thermal analysis, a purely Python use is presented in pynl03a.
