# u7.01.11 Procedure PRE_GIBI

## 1 Purpose

This command is deprecated.

It is recommended to use LIRE_MAILLAGE, FORMAT='GIBI'.

Read a mesh file in GIBI format, then write it in *Aster* format.

The only version levels of the GIBI mesher (mesher of CASTEM 2000) that are handled are levels 3, 4, 5, 6, 8, 9, 10, 11 and 13. In CASTEM 2000, the mesh file in GIBI format is produced by the directive SAUVERFORMAT.

For the rules for transcribing a mesh file from GIBI into *Aster*, refer to document [U3.04.01](doc:u3.04.01).

One no longer rereads the result files of the GIBI mesher produced by the directive SORT, nor does one reread the result files of the GIBI mesher created by the directive SAUVER, which produces result files of binary type (be sure to use SAUVERFORMAT).

## 2 Syntax

```text
PRE_GIBI(
    ◇ UNITE_GIBI = unit (défaut: 19),
    ◇ UNITE_MAILLAGE = unit (défaut: 20),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand UNITE_GIBI

```text
◊    UNITE_GIBI = unilec
```

Logical number of the GIBI result file (reading), equal to 20 by default, which corresponds to the type mgib in the astk interface.

### 3.2 Operand UNITE_MAILLAGE

```text
◊    UNITE_MAILLAGE = uniecr
```

Logical number of the *Aster* mesh file (writing), equal to 19 by default, which is also the default of LIRE_MAILLAGE and corresponds to the type mail of astk.
