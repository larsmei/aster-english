# u4.44.21 Operator DEFI_OBSTACLE

## 1 Purpose

Define the geometry of the shock locations of a slender structure. These locations are defined in a plane perpendicular to the structure modelled by POU_D_T and POU_D_E beams. It is then used by DYNA_VIBRA [U4.53.03](doc:u4.53.03) for the study of the response of a structure whose displacements are limited by the presence of this obstacle. One may also define the initial cross-section of a structure whose progressive wear will be studied. In this latter case, the concept will be used by MODI_OBSTACLE [U4.44.22](doc:u4.44.22).

Produces a concept of type table_fonction.

## 2 Syntax

```text
table_fonction = DEFI_OBSTACLE(
    ◇ TYPE = / "CERCLE" (par défaut),
             / "PLAN_Y",
             / "PLAN_Z",
             / "DISCRET",
             / "BI_CERCLE",
             / "BI_PLAN_Y",
             / "BI_PLAN_Z",
             / "BI_CERC_INT",
    ◇ VALE = float,
    ◇ VERIF = text (défaut: "FERME"),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand TYPE

The operand TYPE makes it possible to give the envelope shape of the clearance in the shock connection by a text chosen from the following: PLAN_Y, PLAN_Z, CERCLE, DISCRET, BI_PLAN_Y, BI_PLAN_Z, BI_CERCLE and BI_CERC_INT;

Obstacles of type PLAN_Y, PLAN_Z, CERCLE and DISCRET define the geometry of the shock locations between a moving structure and a non-deformable obstacle. They are plotted below [Figure 3.1-a] according to the type chosen.

![Figure](/figures/u4.44.21/10000A040000272C00000EFC197C137AB1896AFC.svg)

**Figure 3.1-a**

The value of the clearance and the local coordinate system $(\mathit{Xloc},\mathit{Yloc},\mathit{Zloc})$ will be defined at the time the obstacle is used (see operator DYNA_VIBRA [U4.53.03](doc:u4.53.03)). The origin of this coordinate system is the location of the slender structure under consideration.

In the case of the obstacle TYPE = ‘DISCRET’, the curve defining the contour and the clearance simultaneously must be specified, using the keyword VALE.

The types BI_PLAN_Y, BI_PLAN_Z, BI_CERCLE and BI_CERC_INT make it possible to define the possible contact locations of the slender structure between two nodes $\mathit{NO1}$ and $\mathit{NO2}$ each belonging to a moving structure. The geometries of the plane-on-plane (or circle-on-circle) contact connections are described in the figure [Figure 3.1-b] below.

![Figure](/figures/u4.44.21/100032E8000069D5000057BFE3D8556290CA6021.svg)

**Figure 3.1-b**

The value of the thicknesses of material surrounding the shock nodes ($\mathit{D1}$  and $\mathit{D2}$ for an obstacle of type BI_PLAN_* , $\mathit{R1}$ and $\mathit{R2}$ for an obstacle of type BI_CERCLE or BI_CERC_INT) as well as the local coordinate system $(\mathit{Xloc},\mathit{Yloc},\mathit{Zloc})$ are defined at the time the obstacle is used, that is to say in the operator DYNA_VIBRA [U4.53.03](doc:u4.53.03).

Several initial shapes, in particular for the study of the vibrations of control-rod clusters, are defined. They correspond to the rod of the various control-rod clusters and to their guides.

### 3.2 Operands VALE/VERIF

```text
◊    VALE = thetar
```

In the case of the DISCRET obstacle the curve defining the contour and the clearance simultaneously must be specified, using the keyword VALE.

thetar is the list of reals making it possible to describe the contour of the obstacle of type DISCRET in polar coordinates. The obstacle is described as a plane curve in polar coordinates by giving pairs of values, the first being the angle in degrees from 0 to 360°, the second the radius [Figure3.2-a]. When defining the obstacle, it must be considered that the y-axis corresponds to an angle of 0°.

```text
VALE    =    ( 0.0, 0.00086,
30.0, 0.001,
90.0, 0.001,
150.0, 0.001,
210.0, 0.001,
270.0, 0.001,
330.0, 0.001,
360.0, 0.00086,)
```

![Figure](/figures/u4.44.21/Object_1.png)

**Figure 3.2-a**

◊    VERIF= 'FERME'

Keyword making it possible to check whether the curve given in polar coordinates is indeed closed.
