# v3.02.319 SSLP319 - Propagation of two X-FEM cracks for the I-mode

Summary:

The purpose of this test is to check that the PROPA_FISS operator correctly handles multi-crack cases.

It is a $\mathrm{2D}$ plate containing two cracks, each consisting of a single bottom. Several propagations are calculated by the PROPA_FISS operator. It is checked that the stress factors of the propagated cracks are correct for propagation in $I$ mode.

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v3.02.319/10000201000003AE0000054EEC0940F4241A08AB.png)

*Geometry of cracked plate*

Geometrical dimensions of the cracked plate:

| width | $L=1000\mathrm{mm}$ |
| --- | --- |
| height | $H=2000\mathrm{mm}$ |

Initial crack length: ${a}_{0}=300\mathrm{mm}$ .

The cracks are positioned in the middle of the plate height ($H/2$ ).

### 1.2 Material properties

Young's modulus $E=206000\mathrm{MPa}$

Poisson's ratio $\nu =0.33$

### 1.3 Boundary conditions and loads

![Figure](/figures/v3.02.319/1000020100000366000005D0C35114DB74F36B79.png)

*boundary conditions and loadings*

boundary conditions:

> Point $A$ : $\Delta X=\Delta Y=0$
> Points of the lower end of the plate: $\Delta Y=0$

Loading:

> Pressure applied to the top end of the plate: $P=1\mathit{MPa}$

Three propagations are calculated by imposing a maximum crack advance equal to $30\mathit{mm}$. As a result of the symmetry of geometry, boundary conditions and loading, the advances of both cracks are always equal to the maximum advance imposed.

## 2 reference solution

### 2.1 Method of calculation

Three crack propagations are calculated, the two cracks always progress from the same distance and their stress intensity factors are always equal.

The stress intensity factors can be calculated using the following equations bib1:

> ${K}_{I}=Y\cdot P\cdot \sqrt{a}$
> $Y=1.99+0.76\cdot \frac{a}{L}-8.48\cdot {(\frac{a}{L})}^{2}+27.36\cdot {(\frac{a}{L})}^{3}$
> ${K}_{\mathit{II}}=0$

### 2.2 Quantities and reference results

For the three propagations calculated in the tests, the half-length of the crack is as follows:

| **Propagation** | $a$ [ $\mathrm{mm}$ ] |
| --- | --- |
| 1 | 330.0 |
| 2 | 360.0 |
| 3 | 390.0 |

The expected value of ${K}_{I}$ is therefore the following for each propagated fund:

| **Propagation** | ${K}_{I}$ [ $\mathit{Pa}\sqrt{\mathit{mm}}$ ] |
| --- | --- |
| 1 | 3.7992E+07 |
| 2 | 4.1791E+07 |
| 3 | 4.6316E+07 |

The expected value of ${K}_{\mathit{II}}$ is always zero.

### 2.3 Bibliographical references

D.Broek, "Elementary engineering fracture mechanics", Martinus Nijhoff Publishers, The Hague, The Netherlands, 1982

## 3 Modelling A

### 3.1 Modelling characteristics

The fast walking UPWIND method is used by PROPA_FISS to solve crack propagation equations.

**No auxiliary grid** is used. This is possible because the mesh of the structure is very regular.

### 3.2 Mesh characteristics

The structure is modelled by a mesh composed of 1440 elements QUAD4 (see ).

![Figure](/figures/v3.02.319/1000020100000180000002E3EB49BD20839025B0.png)

*mesh of the structure*

The mesh is very coarse to reduce the calculation time. It is more refined in the crack propagation area. In this area, the size of the elements is $25\times 25\mathit{mm}$. The largest element used has a dimension equal to $25\times 100\mathit{mm}$.

### 3.3 Tested quantities and results

The ${K}_{I}$ and ${K}_{\mathit{II}}$ values for the two cracks after each propagation are tested. To verify whether these values are correct, a relative tolerance equal to $\text{5\%}$ for the ${K}_{I}$ values is used. However, to check whether the ${K}_{\mathit{II}}$ value is zero, an absolute tolerance (threshold value) related to the ${K}_{I}$ value is used: ${K}_{\mathit{II}}$ is considered to be zero if its value is less than $\text{1\%}$ of the ${K}_{I}$ value. In this case, the ${K}_{\mathit{II}}$ value can be disregarded.

| right | 3.7992E+07 | <5% |  |

| right | 4.1791E+07 | <5% |  |
| 3 | left | 4.6316E+07 | <5% |
| right | 4.6316E+07 | <5% |  |

| **Propagation** | **Fissure** | ${K}_{\mathit{II}}$ reference [ $\mathit{Pa}\sqrt{\mathit{mm}}$ ] | **Tolerance** [ $\mathit{Pa}\sqrt{\mathit{mm}}$ ] |
| --- | --- | --- | --- |

| right | 0 | < ${K}_{I\mathit{Aster}}/100$ |  |

### 3.4 Remarks

All the tested values are within the tolerances used. This means that the UPWIND method correctly calculates both the position of the two cracks and the level sets.

The error on the ${K}_{I}$ values is almost zero and the ${K}_{\mathit{II}}$ values are still in the order of $\text{0.01\%}$ of the ${K}_{I}$ values. The results obtained are therefore very satisfactory.

## 8 Summary of the results

All the PROPA_FISS operator methods used (UPWIND, SIMPLEXE, mesh and GEOMETRIQUE) were able to calculate the position of two existing cracks in the same model and propagate in $I$ mode. The stress intensity factors were calculated correctly and the methods used correctly calculate the level sets at each propagation.

The results obtained enable the implementation of the multi-cracking (case of several cracks with a single crack bottom each) to be validated in the PROPA_FISS operator.
