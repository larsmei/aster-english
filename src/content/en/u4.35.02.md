# u4.35.02 Operator FONC_FLUI_STRU

## 1 Purpose

To create a constant function parameterised by the curvilinear abscissa. This function gives the value of the added-mass coefficient for a configuration of the type “tube bundle under transverse flow”.

This function is used downstream by the operator DEFI_MATERIAU [U4.43.01](doc:u4.43.01), factor keyword ELAS_FLUI. It produces a concept of type fonction.

## 2 Syntax

```text
fonction = FONC_FLUI_STRU(
    ◆ TYPE_FLUI_STRU = type_flui_stru,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

```text
♦    TYPE_FLUI_STRU = typeflui
```

Concept of type [type_flui_stru] produced by the operator DEFI_FLUI_STRU [U4.25.01], providing the value of the added-mass coefficient Cm.

**Notes:**

*The value of Cm can be imposed by means of the keyword COEF_MASS_AJOU appearing in the command DEFI_FLUI_STRU. If fluid-elastic coupling is taken into account, the added-mass coefficient can be computed by the operator as a function of the other characteristics of the bundle.*

*The operator FONC_FLUI_STRU creates a concept of type [fonction] which is then directly usable by DEFI_MATERIAU [U4.43.01], keyword ELAS_FLUI.*

*The function is constant, parameterised by the curvilinear abscissa, and gives the value of Cm.*

*The combined use of the operators FONC_FLUI_STRU and then DEFI_MATERIAU, option ELAS_FLUI, is necessary when one studies a configuration of the type “tube bundle under transverse flow”, and it is permitted only for this type of configuration.*
