# v1.01.392 ZZZZ392 – Validation of the CREA_RESU-based mode_meca concept for COMB_SISM_MODAL/MODE_CORR

**Summary:**

This test has no physical meaning, it is essentially a computer test.

It is designed to validate keyword AXE from CREA_RESU/AFFE. This keyword is designed to provide MODE_CORR's COMB_SISM_MODAL operating unit with a mode_meca concept from CREA_RESU instead of a mode_meca concept from MODE_STATIQUE.

Modelization A:

The test principle is as follows: using the CREA_CHAMP operator, we extract the moving field of a MODE_STATIQUE mode_mecassusin concept(there are 3 order numbers each corresponding to a direction of space). We create a mode_meca concept from the extracted field with CREA_RESU, by telling keyword AXE of AFFE. It takes the valueX for the first order number, Yfor the second and Zfor the third.

For the 3 directions of space, the COMB_SISM_MODAL operator is called twice, the first time by telling the concept from MODE_STATIQUE to MODE_CORR, this calculation being used as a reference and a second time with the concept from CREA_RESU. We check that we get the same results as in the first.

It is specified that the second calculations do not work without providing keyword AXE CREA_RESU/AFFE.

This documentation is deliberately succinct.
