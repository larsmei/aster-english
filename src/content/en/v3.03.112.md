# v3.03.112 SSLS112 - Decomposition of composite plates

**Summary:**

This test allows the validation of the excentre of composite plates.

The reference is given by a first resolution where a quadrilayer with material non-symmetry to the average plane is modelled.

Validation is done in a second calculation where the quadrilayer of the previous model is modelled by 2bilayers excreted from the mean plane of the first calculation.

## 1 Reference problem

### 1.1 Geometry

## 2 reference solution

### 2.1 Calculation method used for reference solution

The reference solution comes from a first calculation with ASTER with the quadrilayer described in the Reference problem.

### 2.2 Baseline

They consist of the $\mathrm{DX},\mathrm{DY},\mathrm{DZ},\mathrm{DRX},\mathrm{DRY}$ displacement field values to point $\mathrm{A3}$ (node $\mathrm{N1}$ for ASTER) and node $\mathrm{N10}$ coordinates.

### 2.3 Uncertainty about the solution

None, since it is a single calculation made by two different ways.

## 3 Modelling A

### 3.1 Modelling characteristics

The model consists of 2 bilayer plates corresponding to the average plane of the quadrilayer of the reference model.

To represent these 2 plates, we start from the mesh of the average plane of the quadrilayer that we excenter the distances $-0.1$ and $0.1$ .

The elements used are elements plate DKT.

![Figure](/figures/v3.03.112/10000000000002440000013558F1B45DEF9F23DC.png)

### 3.2 Mesh characteristics

![Figure](/figures/v3.03.112/10000000000004010000012C4DBA20EECE7823CB.png)

The mesh is regular.

There are 10 subdivisions according to $x$ and 5 subdivisions according to $y$; a total of 50 mesh cells DKQ (quad4) and 66 nodes.

## 4 Executive summary

Results obtained with excreted multilayer plates are consistent with the reference.

This test therefore validates the excenteration for multi-layer plates.
