# u4.90.21 Macro-command CALC_ESSAI_GEOMECA

## 1 Purpose

This macro-command makes it possible to simulate, for a material point, various loading paths characteristic of geomechanical tests, and to post-process the results obtained. The user supplies as input the constitutive behaviour, the material, and lists of loading parameters which correspond to several occurrences of the same test. The tests available are the following:

- monotonic drained triaxial test
- monotonic undrained triaxial test
- drained cyclic shear test
- undrained cyclic triaxial test
- reversed drained cyclic triaxial test
- non-reversed drained cyclic triaxial test
- drained cyclic oedometric test
- drained cyclic isotropic compression test

Produces curves in xmgrace format and/or data structures of type table.

### 3.3 Keyword CONVERGENCE

```text
◊CONVERGENCE= _F()
```

If neither of the following two operands is present, then everything proceeds as if: RESI_GLOB_RELA = 1.E-6

#### 3.3.1 Operand RESI_GLOB_RELA/RESI_GLOB_MAXI

```text
◊| RESI_GLOB_RELA = resi_rela                    [R]
```

The algorithm continues the global iterations as long as:

$\underset{i=1,\mathit{nbddl}}{max}|{F}_{i}^{n}|\phantom{\rule{2em}{0ex}}>\phantom{\rule{2em}{0ex}}\text{resi\_rela}\times max|L|$

where ${F}^{n}$ is the residual of iteration $n$ and $L$ the vector of the imposed loading and of the support reactions (see [R5.03.01](doc:r5.03.01) for more details).

When the loading and the support reactions become zero, that is when $L$ is zero (for example in the case of a total unloading), an attempt is made to switch from the relative convergence criterion RESI_GLOB_RELA to the absolute convergence criterion RESI_GLOB_MAXI. This operation is transparent for the user (alarm message issued in the .mess file). When the vector $L$ becomes non-zero again, one automatically returns to the relative convergence criterion RESI_GLOB_RELA.

However, this switching mechanism cannot work at the first time step. Indeed, in order to find a reasonable value of RESI_GLOB_MAXI automatically (since the user has not supplied one), one needs to have had at least one converged step in RESI_GLOB_RELA mode. Consequently, if the loading is zero from the first time instant, the analysis stops. The user must then first check that the zero loading is normal from the point of view of the modelling being carried out, and if that is the case, find another convergence criterion (RESI_GLOB_MAXI for example).

If this operand is absent, the test is carried out with the default value, unless RESI_GLOB_MAXI is present.

```text
◊| RESI_GLOB_MAXI = resi_maxi                    [R]
```

The algorithm continues the global iterations as long as:

$\underset{i=1,\mathit{nbddl}}{max}|{F}_{i}^{n}|\phantom{\rule{2em}{0ex}}>\phantom{\rule{2em}{0ex}}\text{resi\_maxi}$

where ${F}^{n}$ is the residual of iteration $n$ (see [R5.03.01](doc:r5.03.01) for more details). If this operand is absent, the test is not carried out.

If RESI_GLOB_RELA and RESI_GLOB_MAXI are both present, both tests are carried out.

#### 3.3.2 Operand ITER_GLOB_MAXI

```text
◊ITER_GLOB_MAXI = | 10                        [DEFAUT]

| nb_iter
```

Maximum number of iterations carried out to solve the global problem at each time instant.

### 3.4 Keyword ESSAI_TRIA_DR_M_D

This repeatable factor keyword makes it possible to carry out a series of simulations of the same monotonic drained triaxial test at imposed strain, for which the loading parameters are varied (confining pressure and imposed axial strain), to post-process the results obtained and to write them in the form of plots (in xmgrace format) and/or tables.

#### 3.4.1 Sign convention for the inputs and the outputs

The sign convention of geomechanics applies to the input parameters in imposed stresses or strains, that is, the values are positive in compression.

This convention likewise applies to the predefined output variables, the complete list of which for this test is as follows:

- INST: time instant
- EPS_AXI: axial strain
- EPS_LAT: lateral strain
- EPS_VOL: volumetric strain
- SIG_AXI: axial effective stress
- SIG_LAT: lateral effective stress
- P: mean effective stress
- Q: stress deviator

On the other hand, this convention does not apply to the non-predefined variables requested as output in NOM_CMP(§ 3.4.6 ).

#### 3.4.2 Operands PRES_CONF, EPSI_IMPOSE, NB_INST

```text
♦ PRES_CONF = l_sigma_conf            [l_R]

♦ EPSI_IMPOSE = l_epsi_impo            [l_R]

◊NB_INST = | 100                    [DEFAUT]

| nbinst                [I]
```

The operand PRES_CONF makes it possible to define the list of confining pressures that will be maintained during each test. Likewise, the operand EPSI_IMPOSE makes it possible to define the list of the final values of the compression loading (imposed axial-strain ramp).

For this test, each confining pressure is associated with a final value of the axial-strain ramp (see the figure): the lists PRES_CONF and EPSI_IMPOSE must therefore have the same cardinality. This cardinality corresponds to the number of simulations that will be run under this factor keyword.

Stresses and strains being counted positive in compression, the values supplied for PRES_CONF must be strictly positive. The values supplied in EPSI_IMPOSE are strictly positive or negative, a negative value indicating a loading in extension.

The operand NB_INST makes it possible to define the time discretisation of the loading (see the figure), with a default value of 100 loading steps during the ramp.

#### 3.4.3 Operand KZERO

◊KZERO = |  1                    [DEFAUT]

Value of the coefficient of earth pressure at rest; it makes it possible to define an anisotropic confinement state: ${\sigma}_{xx}={\sigma}_{yy}={K}_{0}{\sigma}_{zz}={K}_{0}\times \text{PRES\_CONF}$

*Note:* When the value of KZERO is set different from 1, the real confining pressure of the test is no longer PRES_CONF; it becomes:

${P}_{c}=\frac{1+2{K}_{0}}{3}\times \text{PRES\_CONF}$

#### 3.4.4 Operand TABLE_RESU

```text
◊TABLE_RESU= l_tabres            [l_CO]
```

This optional operand makes it possible to give the list of the names of the concepts produced by the macro-command, which will then be of type [table]. Each table produced contains the raw and post-processed results of one test simulation: the list TABLE_RESU must therefore have the same cardinality as the lists PRES_CONF and EPSI_IMPOSE.

The title of each table produced is completed by the macro-command; it comprises:

- the name of the factor keyword (here ESSAI_TRIA_DR_M_D) and its occurrence number (this keyword being repeatable);
- the pair of values (PRES_CONF, EPSI_IMPOSE) characterising the loading of the test;

*Example* :

TABRES1=CO('TRES1')

TABRES2=CO('TRES2')

TABRES3=CO('TRES3')

CALC_ESSAI_GEOMECA(

...

ESSAI_TRIA_DR_M_D = _F(

PRES_CONF = (-1.E4, -1.5E4, -2.E4 ),

EPSI_IMPOSE = (-1.E-2, -1.E-2, -1.E-2),

TABLE_RESU = (TABRES1, TABRES2, TABRES3),),

);

#### 3.4.5 Operand GRAPHIQUE, PREFIXE_FICHIER

```text
◊GRAPHIQUE = | ('P-Q', 'EPS_AXI-Q', 'EPS_AXI-EPS_VOL',

'P-EPS_VOL')                            [DEFAUT]

| l_graphique                            [l_Kn]
```

This operand makes it possible to specify the types of plots produced by the macro-command. These plots summarise the results of the simulations run under the current factor keyword. A default list is proposed. However, it is possible to produce any plot by giving the desired combinations of components existing in l_graphique, of the form: ABSCISSA-ORDINATE. The dash «-» separates the component requested on the abscissa from the one requested on the ordinate.

*Example* :

l_graphique = ('P-Q', 'EPS_AXI-Q', 'INST-EPS_VOL', 'INST-V23')

The non-predefined component V23 (corresponding to the plastic volumetric strain of the Hujeux constitutive law [R7.01.23](doc:r7.01.23)) must be declared in NOM_CMP ( **§**  3.4.6 ) in order to be taken into account. Otherwise, the requested plot is not produced.

As for the predefined components, the complete list of which is given in **§**  3.4.1 , they will be displayed, where relevant, with the sign convention of geomechanics, that is with positive values in compression.

Furthermore, all the components requested for the construction of the plots will be displayed in the output tables ( **§**  3.4.4 ).

The files containing these plots are written in xmgrace format in one and the same directory specified by the user (type repe as a result in astk), and are named as follows:

'prefix'_'test_name'_'occurrence_number'_'abscissa-ordinate'.agr

A prefix may be added to the name of the output file by means of the optional keyword:

◊PREFIXE_FICHIER= prefix                    [Kn]

#### 3.4.7 Operand TABLE_REF

```text
◊ TABLE_REF = l_tabref                                [l_table]
```

This operand makes it possible to supply reference curves (for example experimental ones), tabulated and stored in the form of tables, in order to superimpose them on the curves coming from the simulations run under the current factor keyword. These reference curves are then included in the files produced by the keyword GRAPHIQUE.

Each table contained in the list TABLE_REF must be created beforehand by means of the operator CREA_TABLE [U4.33.02](doc:u4.33.02), and formatted as follows:

tabref = CREA_TABLE(

LISTE = ( _F(PARA = 'TYPE', LISTE_K = [typgraph,]),

_F(PARA = 'LEGENDE', LISTE_K = [malegend,]),

_F(PARA = 'ABSCISSE', LISTE_R = l_absc),

_F(PARA = 'ORDONNEE', LISTE_R = l_ordo),),);

with:

- typgraph a character string whose value must belong to the list of default values of the keyword GRAPHIQUE. This value makes it possible to identify the type of plot (and therefore the file) to which the reference curve must be added.
- malegend a character string which contains the legend associated with the reference curve
- l_absc and l_ordo are Python lists of reals containing respectively the abscissae and the ordinates of the points of the reference curve. These lists must therefore have the same cardinality

### 3.6 Keyword ESSAI_CISA_DR_C_D

This repeatable factor keyword makes it possible to carry out a series of simulations of the same drained cyclic shear test at imposed shear strain, for which the loading parameters are varied (confining pressure, shear-strain amplitude and number of cycles), to post-process the results obtained and to write them in the form of plots (in xmgrace format) and/or tables.

#### 3.6.1 Sign convention for the inputs and the outputs

The sign convention of geomechanics applies to the input parameters in imposed stresses or strains, that is, the values are positive in compression.

This convention likewise applies to the predefined output variables. On the other hand, this convention does not apply to the non-predefined variables requested as output in NOM_CMP(§ 3.6.7 ).

In this test, one distinguishes the predefined level-2 output variables, which correspond to the variables produced by the test, the complete list of which is as follows:

- INST:     time instant
- GAMMA:     shear strain $\gamma =2{{\varepsilon}}_{xy}$
- SIG_XY: shear stress

And the predefined level-1 output variables, which correspond to curves whose points represent the result of a test (for example the curve $\frac{G}{{G}_{\max}}-\gamma$). The complete list of the level-1 variables is as follows:

- G_SUR_GMAX: $\frac{G}{{G}_{\max}}$
- DAMPING: hysteretic damping $\frac{\Delta W}{\pi W}$

#### 3.6.2 Operands PRES_CONF, GAMMA_IMPOSE, NB_CYCLE,    NB_INST, TYPE_CHARGE

```text
♦ PRES_CONF = l_sigma_conf                [l_R]

♦ GAMMA_IMPOSE = l_gamma_impo                [l_R]

♦ NB_CYCLE = nbcyc                        [I]

◊ NB_INST = | 25                        [DEFAUT]

|nbinst                    [I]

◊ TYPE_CHARGE = | 'SINUSOIDAL'            [DEFAUT]

|'TRIANGULAIRE'        [Kn]
```

These operands make it possible to define the loading of each of the simulations to be run under the current factor keyword, as well as its discretisation. Their meaning is summarised in the figure and detailed below:

- PRES_CONF makes it possible to define the list of confining pressures (strictly positive) that will be maintained during each test;
- GAMMA_IMPOSE makes it possible to define the list of the amplitudes (strictly positive) of the shear strain $\gamma =2{\epsilon}_{xy}$ of the imposed cyclic loading;
- NB_CYCLE corresponds to the number of cycles, fixed for all the simulations.
- NB_INST makes it possible to define the time discretisation of the loading, and corresponds to the number of loading steps per quarter-cycle
- TYPE_CHARGE indicates the type of loading requested: sinusoidal or triangular;

For each confining pressure PRES_CONF, as many simulations are carried out as there are entries in the list GAMMA_IMPOSE. Unlike the tests TRIA_DR_M_D and TRIA_ND_M_D (see respectively § 3.4  and § 3.5 ), these lists are not in one-to-one correspondence and there are in total:

#### 3.6.3 Operand GAMMA_ELAS


For each confining pressure, the maximum secant shear modulus (that is, of the intact material) is determined by simulating an imposed shear-strain ramp (in terms of distortion) whose final value is GAMMA_ELAS. This value must be such that the material remains in its elasticity domain (linear or not, according to the constitutive relation used). GAMMA_ELAS is equal to 1.E-7 by default, and any value supplied by the user must be smaller than it. If the value supplied does not make it possible to remain in the elasticity domain, the code stops with a fatal error.

### 3.7 Keyword ESSAI_TRIA_ND_C_F

This repeatable factor keyword makes it possible to carry out a series of simulations of the same undrained (total saturation is assumed) cyclic triaxial test at imposed force, for which the loading parameters are varied (confining pressure, amplitude of the imposed axial effective stress, and number of cycles), to post-process the results obtained and to write them in the form of plots (in xmgrace format) and/or tables.

#### 3.7.1 Sign convention for the inputs and the outputs

The sign convention of geomechanics applies to the input parameters in imposed stresses or strains, that is, the values are positive in compression.

This convention likewise applies to the predefined output variables. On the other hand, this convention does not apply to the non-predefined variables requested as output in NOM_CMP(§ 3.7.9 ).

In this test, one distinguishes the predefined level-2 output variables, which correspond to the variables produced by the test, the complete list of which is as follows:

- INST: time instant
- EPS_AXI: axial strain
- EPS_LAT: lateral strain
- EPS_VOL: volumetric strain
- SIG_AXI: axial effective stress
- SIG_LAT: lateral effective stress
- P: mean effective stress
- Q: stress deviator
- PRE_EAU: pore pressure
- RU: pore-pressure coefficient equal to ${r}_{u}=\frac{3}{1+2{K}_{0}}\frac{\Delta {u}_{w}}{\sigma {'}_{v,0}}$

And the predefined level-1 output variables, which correspond to curves whose points represent the result of a test (for example the curve $\mathit{CRR}-{N}_{\mathit{cyc}}$). The complete list of the level-1 variables is as follows:

- NCYCL: number of loading cycles to liquefaction
- DSIGM: maximum imposed stress normalised by the initial mean effective stress $\mathit{DSIGM}=\mathit{CRR}=\frac{{Q}_{\max}}{P{'}_{0}}$

*Note:*

*For loose sands, stress control of the test raises difficulties when crossing the two instability lines, shown in blue on the Figure* *. Indeed, imposing a maximum-stress target greater than the maximum admissible stress on the instability line leads either to divergence or to a false solution (a sudden stress jump, visible on the Figure* *). Indeed, the instability line represents the locus of all the admissible stress maxima of a monotonic* TRIA_ND_M_D *test for various values of the initial consolidation (black curve).*

*The problem does not arise for a dense sand, because there is no stress maximum in that case, as can be seen on the black curve of the Figure* *.*

*For this test, there is therefore an* **automatic** *procedure for handling unstable situations. It consists in detecting the instability and in continuing the test under strain control. The detection criteria are the following:*

*non-convergence of the analysis*

$\frac{\Delta Q}{\Delta P}<0.25$ *et* $\frac{\Delta {{\varepsilon}}_{zz}^{+}}{\Delta {{\varepsilon}}_{zz}^{-}}>10$

*One continues over the remaining number of cycles by a sequence of monotonic strain-controlled* TRIA_ND_M_D *tests, at the rate of two tests per cycle (* $\pm {{\varepsilon}}_{max}$ *in order to reach* $\pm {\sigma}_{max}$ *). The maximum strain target* ${{\varepsilon}}_{max}$ *imposed is 4%, or 12% if the previous target was insufficient. The list of time instants for these* TRIA_ND_M_D *tests runs from 0 to 100 seconds with a time step of 0.2 seconds (or of 0.1 seconds if the target is* ${{\varepsilon}}_{max}=12\text{\%}$ *).*

*The chaining of one strain-controlled* TRIA_ND_M_D *test to the next is carried out by a restart of the analysis from the last time instant at which the stress target* $\pm {\sigma}_{max}$ *is reached.*

*On the Figure* *, one shows, on an example of loose sand (test case comp012c), the solution obtained with or without the instability-handling procedure.*

### 3.8 Keyword ESSAI_TRIA_DR_C_D

This repeatable factor keyword makes it possible to carry out a series of simulations of the same drained cyclic triaxial test at imposed strain, for which the loading parameters are varied (confining pressure, imposed axial strain, and number of cycles), to post-process the results obtained and to write them in the form of plots (in xmgrace format) and/or tables.

#### 3.8.1 Sign convention for the inputs and the outputs

The sign convention of geomechanics applies to the input parameters in imposed stresses or strains, that is, the values are positive in compression.

This convention likewise applies to the predefined output variables. On the other hand, this convention does not apply to the non-predefined variables requested as output in NOM_CMP(§ 3.8.7 ).

In this test, one distinguishes the predefined level-2 output variables, which correspond to the variables produced by the test, the complete list of which is as follows:

- INST: time instant
- EPS_AXI: axial strain
- EPS_LAT: lateral strain
- EPS_VOL: volumetric strain
- SIG_AXI: axial effective stress
- SIG_LAT: lateral effective stress
- P: mean effective stress
- Q: stress deviator

And the predefined level-1 output variables, which correspond to curves whose points represent the result of a test (for example the curve $\frac{E\text{*}}{E{\text{*}}_{\max}}-\Delta {{\varepsilon}}_{v}$). The complete list of the level-1 variables is as follows:

- E_SUR_EMAX: $\frac{E\text{*}}{E{\text{*}}_{\max}}$ with $E\text{*}=\frac{|\Delta ({\sigma}_{v}-{\sigma}_{h})|}{|\Delta {{\varepsilon}}_{v}|}$ the apparent modulus of the test;
- DAMPING: hysteretic damping $\frac{\Delta W}{\pi W}$

#### 3.8.2 Operands PRES_CONF, EPSI_MAXI, EPSI_MINI,    NB_CYCLE, NB_INST

```text
♦ PRES_CONF = l_sigma_conf                    [l_R]

♦ EPSI_MAXI = l_epsi_maxi_impo                [l_R]

♦ EPSI_MINI = l_epsi_mini_impo                [l_R]

♦ NB_CYCLE = nbcyc                            [I]

◊ NB_INST = | 25                            [DEFAUT]

|nbinst                        [I]

◊ TYPE_CHARGE = | 'SINUSOIDAL'                [DEFAUT]
```

These operands make it possible to define the loading of each of the simulations to be run under the current factor keyword, as well as its discretisation. Their meaning is summarised in the figure and detailed below:

- PRES_CONF makes it possible to define the list of confining pressures (strictly positive) that will be maintained during each test;
- EPSI_MAXI and EPSI_MINI make it possible to define the list of the maximum and minimum axial strains, respectively, of the imposed cyclic loading. The cardinality of EPSI_MAXI must be equal to that of EPSI_MINI. The condition $\Delta {{\varepsilon}}_{v}=\mathit{EPSI}\text{\_}\mathit{MAXI}–\mathit{EPSI}\text{\_}\mathit{MINI}>0$ must be satisfied term by term;
- NB_CYCLE corresponds to the number of cycles, fixed for all the simulations.
- NB_INST makes it possible to define the time discretisation of the loading, and corresponds to the number of loading steps per quarter-cycle
- TYPE_CHARGE indicates the type of loading requested: sinusoidal or triangular;

For each confining pressure PRES_CONF, as many simulations are carried out as there are entries in the list GAMMA_IMPOSE. Unlike the tests TRIA_DR_M_D and TRIA_ND_M_D (see respectively § 3.4  and § 3.5 ), these lists are not in one-to-one correspondence and there are in total:

$\mathit{card}(\text{PRES\_CONF})\times \mathit{card}(\text{EPSI\_MAXI})$ simulations run.

#### 3.8.3 Operand EPSI_ELAS

```text
◊EPSI_ELAS = | 1.E-7                    [DEFAUT]

|epsi_elas                [R]
```

For each confining pressure, the maximum equivalent cyclic Young's modulus (that is, of the intact material) is determined by simulating a reversed loading cycle controlled in imposed axial strain up to the value EPSI_ELAS. This value must be such that the material remains in its elasticity domain (linear or not, according to the constitutive relation used). EPSI_ELAS is equal to 1.E-7 by default, and any value supplied by the user must be smaller than it. If the value supplied does not make it possible to remain in the elasticity domain, the code stops with a fatal error.

This optional operand makes it possible to give the list of the names of the concepts produced by the macro-command, which will then be of type [table]. The size of this list must satisfy:

### 3.9 Keyword ESSAI_TRIA_ND_C_D

This repeatable factor keyword makes it possible to carry out a series of simulations of the same undrained cyclic triaxial test at imposed strain, for which the loading parameters are varied (confining pressure, imposed axial strain, and number of cycles), to post-process the results obtained and to write them in the form of plots (in xmgrace format) and/or tables.

#### 3.9.1 Sign convention for the inputs and the outputs

The sign convention of geomechanics applies to the input parameters in imposed stresses or strains, that is, the values are positive in compression.

This convention likewise applies to the predefined output variables. On the other hand, this convention does not apply to the non-predefined variables requested as output in NOM_CMP(§ 3.9.10 ).

In this test, one distinguishes the predefined level-2 output variables, which correspond to the variables produced by the test, the complete list of which is as follows:

- INST: time instant
- EPS_AXI: axial strain
- EPS_LAT: lateral strain
- EPS_VOL: volumetric strain
- SIG_AXI: axial effective stress
- SIG_LAT: lateral effective stress
- P: mean effective stress
- Q: stress deviator
- PRE_EAU: pore pressure
- RU: pore-pressure coefficient equal to ${r}_{u}=\frac{3}{1+2{K}_{0}}\frac{\Delta {u}_{w}}{\sigma {'}_{v,0}}$

And the predefined level-1 output variables, which correspond to curves whose points represent the result of a test (for example the curve $\mathit{CRR}-{N}_{\mathit{cyc}}$). The complete list of the level-1 variables is as follows:

- NCYCL: number of loading cycles to liquefaction
- DEPSI: imposed axial-strain amplitude    $\Delta {{\varepsilon}}_{v}=\text{EPSI\_MAX}-\text{EPSI\_MIN}$
- RU_MAX: maximum of RU
- E_SUR_EMAX: $\frac{E\text{*}}{E{\text{*}}_{\max}}$ with $E\text{*}=\frac{|\Delta ({\sigma}_{v}-{\sigma}_{h})|}{|\Delta {{\varepsilon}}_{v}|}$
- DAMPING: hysteretic damping $\frac{\Delta W}{\pi W}$

#### 3.9.8 Operand TABLE_RESU

```text

```

This optional operand makes it possible to give the list of the names of the concepts produced by the macro-command, which will then be of type [table]. The size of this list must satisfy:

$\mathit{card}(\text{TABLE\_RESU})=\mathit{card}(\text{PRES\_CONF})+1$

Indeed, each table produced gathers the raw results of all the simulations run for one and the same confining pressure (PRES_CONF), in which each simulation corresponds to a bundle of contiguous columns whose titles are all indexed by the same integer (index of the value considered in the list EPSI_MAXI). An additional table summarising the post-processing carried out at the end of all the simulations is also produced. This table contains, for each confining pressure (PRES_CONF), the values of:

- normalised equivalent cyclic apparent modulus $\frac{E\text{*}}{E{\text{*}}_{\max}}$ for the last simulated cycle, set against the imposed strain amplitudes (EPSI_MAXI). $E\text{*}$ and $E{\text{*}}_{max}$ are computed as follows: $E\text{*}=\frac{|\Delta ({\sigma}_{v}-{\sigma}_{h})|}{|\Delta {{\varepsilon}}_{v}|}$  with $\Delta \sigma ={\sigma}_{max}-{\sigma}_{min}$ and $\Delta {{\varepsilon}}_{v}={{\varepsilon}}_{v,max}-{{\varepsilon}}_{v,min}$ ;
- the hysteretic damping $\frac{\Delta W}{\pi W}$ for the last simulated cycle, set against the imposed strain amplitudes (EPSI_MAXI). $W$ is computed as follows:      $\Delta W={\int}_{C}\delta ({\sigma}_{v}-{\sigma}_{h}).\delta ({{\varepsilon}}_{v}-{{\varepsilon}}_{h})$ the area of the last hysteresis loop $W=\Delta ({\sigma}_{v}-{\sigma}_{h}).\Delta ({{\varepsilon}}_{v}-{{\varepsilon}}_{h})$ the associated elastic energy
- number of cycles to liquefaction NCYCL

This table corresponds to the concept name given in the last position in the list TABLE_RESU.

### 3.10 Keyword ESSAI_OEDO_DR_C_F

This repeatable factor keyword makes it possible to carry out a series of simulations of the same drained cyclic oedometric test at imposed force, for which the loading parameters are varied (initial isotropic consolidation pressure, amplitude of the imposed axial effective stress, and amplitude of the axial effective stress at the end of unloading), to post-process the results obtained and to write them in the form of plots (in xmgrace format) and/or tables.

#### 3.10.1 Sign convention for the inputs and the outputs

The sign convention of geomechanics applies to the input parameters in imposed stresses or strains, that is, the values are positive in compression.

This convention likewise applies to the predefined output variables, the complete list of which for this test is as follows:

- INST: time instant
- EPS_VOL: volumetric strain
- SIG_AXI: axial effective stress
- SIG_LAT: lateral effective stress
- P: mean effective stress

On the other hand, this convention does not apply to the non-predefined variables requested as output in NOM_CMP(§ 3.10.6 ).

#### 3.10.2 Operands PRES_CONF, SIGM_IMPOSE, SIGM_DECH, NB_CYCLE, NB_INST, TYPE_CHARGE

```text
♦ PRES_CONF = l_sigma_conf                [l_R]

♦ SIGM_IMPOSE = l_sigma_impo                [l_R]

♦ SIGM_DECH = l_sigma_décharge            [l_R]

♦ NB_CYCLE = nbcyc                        [I]

◊NB_INST = | 25                        [DEFAUT]

| nbinst                    [I]

◊ TYPE_CHARGE = | 'SINUSOIDAL'            [DEFAUT]

|'TRIANGULAIRE'            [Kn]
```

These operands make it possible to define the loading of each of the simulations to be run under the current factor keyword, as well as its discretisation. Their meaning is summarised in the figure and detailed below:

- PRES_CONF makes it possible to define the list of the initial vertical consolidation pressures (strictly positive). The initial mean stress will therefore be equal to $\frac{1+2{K}_{0}}{3}\times \text{PRES\_CONF}$;
- SIGM_IMPOSE makes it possible to define the list of the imposed axial-stress values (strictly positive and greater than SIGM_DECH);
- SIGM_DECH makes it possible to define the list of the (strictly positive) values of the unloading axial stress, fixed for all the loading cycles, at a given initial consolidation pressure. The lists PRES_CONF and SIGM_DECH must have the same cardinality;
- NB_INST makes it possible to define the time discretisation of the loading, and corresponds to the number of loading steps per half-cycle;
- TYPE_CHARGE indicates the type of loading requested: sinusoidal or triangular;

For each initial consolidation pressure PRES_CONF, and each unloading stress SIGM_DECH, as many cycles are carried out as there are entries in the list SIGM_IMPOSE. Unlike the tests TRIA_DR_M_D and TRIA_ND_M_D (see respectively § 3.4  and § 3.5 ), these lists are not in one-to-one correspondence and there are in total $\mathit{card}(\text{PRES\_CONF})=\mathit{card}(\text{SIGM\_DECH})$ simulations run, each simulation comprising $\mathit{card}(\text{SIGM\_IMPOSE})$ cycles.
