# v1.01.298 ZZZZ298 – POST_K1_K2_K3 IT Validation

**Summary:**

The purpose of this test is to validate the POST_K1_K2_K3 operator in an elementary way. This test does not necessarily have physical significance, it is essentially a computer test.

Modelization A:

- Modelling: 3D, mesh crack (FEM)
- Solving a linear elastic mechanical problem

Modelling B:

- Modelling: 3D, non-mail crack (X-FEM)
- Solving a linear elastic mechanical problem

Modelization C:

- Modelling: C_PLAN, mesh crack (FEM)
- Resolution of a modal analysis problem

Modelling D:

- Modelling: AXIS, C_PLAN and D_PLAN, mesh crack (FEM)
- Resolution of a linear elastic mechanical problem, with control variables

Modelling E:

- Modelling: D_PLAN, non-mailed crack (X-FEM)
- Resolution of a linear elastic mechanical problem, with control variables

Although this test is computer-based and can be satisfied with a deliberately brief documentation, some modellings are more detailed:

- modellings A and B are fully documented;
- Modelling C, resulting from test case SDLS114A, is not documented;
- Modelling D, from test case FORMA05A, is not documented;
- Modelling E, from test case FORMA06A, is not documented.

## 1 Reference problem for modellings A and B

### 1.1 Geometry

The structure studied is a 1 metre ridge cube with a flat crack, at half height (see [Figure 1.1-a]). In the case where the problem is treated by a conventional method (modelization A), the crack is meshed. However, in the case where the X-FEM method is used (modelization B), the crack is not meshed, and the geometry is actually a healthy cube without cracks. The crack will then be introduced by level set functions directly into the control file using the DEFI_FISS_XFEM [U4.82.08](doc:u4.82.08) operator.

### 1.2 Material properties

The structure's behavior is elastic and its material properties are:

Young's modulus : $E=205000\mathit{Mpa}$

Poisson's ratio : $\nu =0$

### 1.3 Boundary conditions and loads

The movements of the lower side of the structure are blocked while a pressure of $1\mathit{MPa}$ is applied to the upper side to simulate a traction load. This allows to apply the crack in pure $I$ opening mode.

## 2 Modelization A: mesh crack

In this Modelling, the crack is meshed, and the standard method of finished elements is used

to perform the calculation.

## 3 Modelling B: X-FEM crack

### 3.1 Mesh characteristics
