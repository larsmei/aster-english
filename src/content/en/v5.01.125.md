# v5.01.125 SDND125 – Treatment of localized nonlinear behaviors with DYNA_VIBRA

**Summary:**

In the context of the modernisation of the data structure architecture used for the calculation of transient response on the modal basis of a model with localised nonlinearities (operator DYNA_VIBRA), the implementation of data on nonlinear behaviour has been streamlined and a number of facilities have been provided for the post-processing stage.

Thus, through a discrete system (mass-resort), this test case has as its main objective to expose the new data set of different localized nonlinear behaviors available in the DYNA_VIBRA operator, via COMPORTEMENT operand and keyword RELATION. The localized relationship between masses is used to model the following phenomena or devices in dynamic:

- Modelling A: Frontal shock viaRELATION = ‘DIS_CHOC
- Modelling B: Device representing linear flaming viaRELATION = ‘FLAMBAGE
- Modelling C: Anti-seismic device viaRELATION = ‘ANTI_SISM
- Modelling D: Device representing nonlinear viscoelastic behavior viaRELATION = ‘DIS_VISC
- Modelling E: Device representing non-linear behavior viaRELATION = ‘DIS_ECRO_TRAC
- Modelling F: Device representing a force-moving or moment-rotation relationship viaRELATION = ‘RELA_EFFO_DEPL
- Modelling G: Device representing a force-speed relationship viaRELATION = ‘RELA_EFFO_VITE

So it's a test case non-regression. Only calculation values have been recorded to check the consistency between different versions of code_aster.

## 2 Modelling

### 2.1 Mesh characteristics

The mesh consists of 5 nodes, 4 mesh cells SEG2 and 3 mesh cell POI1.

### 2.2 Modelling characteristics

With regard to the mesh, the mleftet mrightau support binding springs are modelled by discrete elements (DIS_T) on linear segments (SEG2). The three bearings (supports) are modelled by discrete elements (DIS_TR), Three masses are modelled by discrete elements DIS_T worn by elements POI1. It is important to note that, for the construction of the modal bases, it is necessary to model the relationships between the masses via discrete DIS_T (DIS_T) carried by a linear segment (SEG2) with very low rigidity.

### 2.3 Modelling parameters

#### 2.3.1 Modelling A

Model A is the case where the masses come to shock between them. The frontal impact relationship is modelled via RELATION = ‘DIS_CHOC' and therefore characterized by a normal rigidity stiffness (shock Modelling with penalization) and a damping due to the relative movement speed between masses:

- Shock between mleftet mcenter:normal rigidity ${k}_{n}$ = 1.0E+7 (N/m)
- Shock between mrightet mcenter:normal rigidity ${k}_{n}$ = 3.0E+6 (N/m)

> The physical distance between masses is 0.1m, corresponding to the distance between masses in the mesh. The value of the keyword JEU is therefore zero.
> The value of the shock tangential damping (unit N m/s in USI) is automatically optimized to minimize the remaining adhesion oscillations according to the formula:
> ${c}_{i}=2\sqrt{({k}_{n}+{k}_{i}){m}_{i}}-2{\xi}_{i}\sqrt{{k}_{i}{m}_{i}}$

> where i is the preponderant mode index in the structure response.

#### 2.3.2 Modelling B

Model B is the case where the masses connect together through a device representing the linear flaming. The flaming relationship is modelled via RELATION = ‘FLAMBAGE' and therefore characterised by the following parameters:
