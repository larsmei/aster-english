# v2.04.402 SDLV402 - Dynamic Substructure: mesh incompatible and mode

**Summary:**

The objective of this test case is to calculate the eigenfrequencies of two coupled cobbles. In this respect, mesh's incompatibility features in dynamic substructure are tested, as well as interface mode coupling.

The test case is composed of $\mathrm{3D}$ Modelling, each of the cobblestones.

## 2 reference solution

### 2.1 Reference calculation

A AUTRE_ASTER reference is used to test frequencies.

The test case:

- Definition and calculation of the static modal base of each of the pavements from their model
- Creation of a static generalized model by coupling of the bases and models of the pavements
- Calculation and restitution of interface modes on the pavements
- Definition and calculation of the modal base of each of the cobblestones, including interface modes
- Creation of a generalized model by coupling of the bases and models of the pavements
- Calculation of eigenmodes
- Physically based return of eigenmodes
