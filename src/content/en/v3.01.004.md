# v3.01.004 SSLL04 - Space structure on elastic supports

**Summary:**

The linear elasticity static test is used to validate straight beam elements POU_D_T and DIS_TR.

This test case concerns a spatial structure on elastic supports with the presence of a patella.

Support reactions and bending moments and deflection are tested by comparing simulation results with reference solution AFNOR (ref. [1]) and those obtained with Pipestress software.
