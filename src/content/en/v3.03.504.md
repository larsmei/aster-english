# v3.03.504 SSLS504 - 3 layer composite square plate, double-sine loading

**Summary:**

This test represents the quasi-static calculation of a composite square plate consisting of 3 layers, simply supported, subjected to a double sinusoidal loading. This test case allows to validate elements DST finished Modelling with mesh cells TRIA3 and QUAD4, with multi-layer composite material.

The displacements and constraints obtained are compared to a numerical reference solution.

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v3.03.504/Object_1.svg)

The 3 layers have relative thickness: $H/4,H/2,H/4$

### 1.2 Material properties

The d-orthotropy axes correspond to the curvilinear directions $x$ and $y$ .

| ${E}_{l}=25.$ | ${E}_{t}=1.$ ($l\iff x$ ; $t\iff y$ ) |
| --- | --- |
| ${G}_{\text{lt}}={G}_{\text{lz}}=0.5$ | ${G}_{\mathrm{tz}}=0.2$ |
| ${\nu}_{\text{lt}}=0.25$ |  |

### 1.3 Boundary conditions and loads

- Boundary conditions: the displacement perpendicular to the plate, on its contour is zero.
- Loading: $p={p}_{o}\sin(\pi x/L)\sin(\pi y/L)$ with ${p}_{o}=0.01$

### 1.4 Initial conditions

Not applicable

## 5 Summary of the results

- **Movements**: the result obtained with mesh cells QUAD4 is satisfactory (difference by 0.4 %). A larger difference (3%) is observed for mesh cells TRIA3.
- **Contraints**: the result obtained with mesh cells QUAD4 is satisfactory (difference maximum 3%). A larger difference (7%) is observed for mesh cells TRIA3.

This test thus allows the calculation of composite plates under load to be validated by geometry, both in terms of displacement and constraints.
