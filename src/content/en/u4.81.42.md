# u4.81.42 Operator CALC_FERRAILLAGE

## 1 Purpose

Compute the reinforcement densities in shell and plate elements as a function of the internal forces: the generalised forces, previously obtained by the option EFGE_ELNO.

The command enriches the data structure of type result, supplied under the keyword RESULTAT, with a reinforcement quantity (grandeur) field, whose components are described in this document.

## 3 Operands

### 3.1 Operands RESULTAT and CARA_ELEM

```text
♦ RESULTAT = resu
```

Name of a result concept of type result. It is necessarily re-entrant.

```text
♦ CARA_ELEM = carac
```

The elementary characteristics must be supplied by the keyword CARA_ELEM for all static and dynamic results. This change is induced by the integration of POST_COMBINAISON(U4.81.45) which generates an ELAS_MULT result with no associated CARA_ELEM.

### 3.2 Operand TYPE_COMB

```text
♦    /    'ELU'
```

The reinforcement is designed at the Ultimate Limit State, with respect to the criterion of limitation of the strains of the concrete and of the steel.

```text
/    'ELS'
```

The reinforcement is designed at the Characteristic Serviceability Limit State, with respect to the criterion of limitation of the stresses in the concrete and the steel.

```text
/    'ELS_QP'
```

The reinforcement is designed at the Quasi-Permanent Serviceability Limit State, with respect to the criterion of limitation of the crack openings in the concrete in tension.

**Note** 1 **:**

For the combinations of forces, the weightings are to be carried out before the call to the module CALC_FERRAILAGE. To do this, the field of generalised forces, previously obtained by the option EFGE_ELNO, must be extracted, using the function CREA_CHAMP (operation EXTR) described in document [U4.72.04](doc:u4.72.04).

```text
MECA1=CALC_CHAMP(reuse =MECA1,
                 RESULTAT=MECA1,
                 CONTRAINTE='EFGE_ELNO',);
```

```text
EFFORTS1=CREA_CHAMP(TYPE_CHAM='ELNO_SIEF_R',
                    OPERATION='EXTR',
                    RESULTAT=MECA1,
                    NOM_CHAM='EFGE_ELNO',);
```

Then, by reusing the function CREA_CHAMP (operation ASSE), one can add the extracted fields by weighting them by the desired coefficient.

```text
PONDERE1=CREA_CHAMP(TYPE_CHAM='ELNO_SIEF_R',
                    OPERATION='ASSE',
                    MODELE=MODELE,
                    ASSE=_F(GROUP_MA='BALCON',
                            CHAM_GD=EFFORTS1,
                            CUMUL='OUI',
                            COEF_R=1.35,),);
```

Finally, in order to be able to use the weighted force field created in CALC_FERRAILLAGE, it must be transformed into a result concept of type result by means of the function CREA_RESU described in document [U4.44.12](doc:u4.44.12).

```text
PONDER=CREA_RESU(OPERATION='AFFE',
                 TYPE_RESU='EVOL_ELAS',
                 NOM_CHAM='EFGE_ELNO',
                 AFFE=(_F(CHAM_GD=PONDERE1,
                          MODELE=MODELE,
                          CHAM_MATER=MATE,
                          CARA_ELEM=CARA,
                          INST=1.0,),),)
```

**Note** 2 **:**

For the analysis at the ELS QP (with respect to the criterion of limitation of the crack openings), the design proposed relies exclusively on the detailed method developed in Eurocode 2 (EC2). Thus, the analysis to the BAEL will be similar to that governed by the EC2.

### 3.3 Operand CODIFICATION

```text
◊    CODIFICATION    =    /    'EC2',        [DEFAUT]
                          /    'BAEL91'
```

The keyword CODIFICATION makes it possible to choose the regulation used for the reinforcement analysis. At present the regulations available are the BAEL91 and Eurocode 2.

### 3.4 Operand METHODE_2D

```text
◊    METHODE_2D    =    /    'Capra-Maury', [DEFAUT]
                        / 'Sandwich'
```

The keyword METHODE_2D makes it possible to choose the algorithm to be retained for the reinforcement analysis of elements of type ‘plates’ (‘2D’) [valid only in the case where TYPE_COMB=’ELU’]. At present, the methods proposed are the one known as ‘Capra-Maury’, as well as the ‘Sandwich’ method. For further explanations of their principles, refer to the documentation [R7.04.05].

### 3.5 Operand PAS_THETA

```text
◊    PAS_THETA    =    /    5.0,     [DEFAUT]
                       /    thiter,  [R]
```

The keyword PAS_THETA makes it possible to choose, *in the case of a ‘2D’ analysis*, the value of the iteration step on the angle θ for the ‘2D’ analysis algorithms: in the case of the ‘Capra-Maury’ method, θ corresponds to the orientation of the planes of the fictitious ‘1D’ facets; in the case of the ‘Sandwich’ method, it will be the inclination of the concrete compression struts in the outer layers, in the search for the optimised *‘Sandwich’* model.

### 3.6 Operand PAS_EPAI

```text
◊    PAS_EPAI    =    /    0.01,   [DEFAUT]
                      /    epiter, [R]
```

The keyword PAS_EPAI makes it possible to choose, *in the case of a ‘2D’ analysis with the ‘Sandwich’ method*, the value of the iteration step on the thicknesses of the outer layers, in the search for the optimised *‘Sandwich’* model; the iteration step will be equal to epiter* ht, where ht designates the total thickness of the ‘2D’ plate element.

*In the case of a ‘2D’ analysis with the ‘Capra-Maury’ method and in the case of a ‘1D’ analysis*, this is the iteration step in the search for the optimum depth of the neutral axis (in the case where the equilibrium is not deterministic).

### 3.7 Operand PAS_SIGM

```text
◊    PAS_SIGM    =    /    0.1,     [DEFAUT]
                      /    aphiter, [R]
```

The keyword PAS_SIGM makes it possible to choose, *in the case of a ‘2D’ analysis with the ‘Sandwich’ method*, the value of the iteration step on the ratios (from 0 to 1) of the principal compressive stresses in the outer layers, in the search for the optimised *‘Sandwich’* model.

### 3.8 Operand COND_109

```text
◊    COND_109    =    /    'OUI', [DEFAUT]
                      /    'NON',
```

The keyword COND_109 makes it possible to choose, *in the case of a ‘2D’ analysis with the ‘Sandwich’ method*, whether or not to take into account the specifications of §6.109- **Membrane elements** of EN-1992-2 for the computation of the strengths of the compression struts in the outer layers of the *‘Sandwich’* model to be determined. If COND_109=’NON’, the design strength will be equal to that retained for the ‘1D’ analysis, namely fcd=fck/γc.

### 3.9 Operand UNITE_CONTRAINTE

```text
♦ UNITE_CONTRAINTE = / 'MPa',
                     / 'Pa'
```

Defines both the unit of stresses used and the unit of length.
The value 'MPa' induces the millimetre as the unit of length.
The value 'Pa' induces the metre as the unit of length.

**Note:**

It is very important to ensure that the unit retained in this keyword is the same as the unit of the stresses of the problem arising from the finite-element analysis.

### 3.10 Selection of the order numbers

The use of the keywords TOUT_ORDRE, NUME_ORDRE, INST is described in document [U4.71.00](doc:u4.71.00).

### 3.11 Operand AFFE

#### 3.11.1 Selection of the mesh cells concerned by the analysis

The keywords TOUT and GROUP_MA allow the user to choose the mesh cells on which the elementary post-processing analyses are to be carried out.

```text
/    TOUT = 'OUI'
```

All the mesh cells (carrying finite elements) will be processed. This is the default value.

```text
/    GROUP_MA    =    l_grma
```

Only the mesh cells included in l_grma will be processed.

**Note**: If the model is not formed solely of shell elements (3D, beams, …), the keyword TOUT='OUI' must not be used. The shell elements must be indicated by means of the keyword GROUP_MA.

#### 3.11.2 Keyword specific to the option CODIFICATION = ’BAEL91’

##### 3.11.2.1 Operand TYPE_STRUCTURE

```text
♦ TYPE_STRUCTURE= / '1D',
                  / '2D'
```

Type of the structure to be reinforced: 1D (Beams/Columns) or 2D (Slabs/Walls)

##### 3.11.2.2 Operand FERR_SYME

```text
◊ FERR_SYME= / 'OUI',
             / 'NON' [DEFAUT]
```

If symmetrical reinforcement is activated, this keyword makes it possible to determine an equilibrium state with similar upper and lower reinforcement sections, to within a constant to be specified at the keyword **SEUIL_SYME** **= s** which follows (that is such that $|{A}_{\text{s,sup}}-{A}_{\text{s,inf}}|⩽s$ )

##### 3.11.2.3 Operand SEUIL_SYME

```text
◊ SEUIL_SYME= slsyme, [R]
```

Tolerance threshold for the analysis of a symmetrical reinforcement.

To be supplied if **FERR_SYME** **= ‘OUI’**

##### 3.11.2.4 Operand FERR_COMP

```text
◊ FERR_COMP= / 'OUI',
             / 'NON' [DEFAUT]
```

If compression reinforcement is activated, the reinforcement analysis will be able to take into account a need for compression reinforcement, with respect to certain equilibrium states at Pivots B and C.

**Note:**

In the case where **FERR_COMP** **= ‘NON’**, if the equilibrium leads to a need for compression reinforcement, the reinforcement density will then be set to -1 for the element.

##### 3.11.2.5 Operand EPURE_CISA

```text
◊ EPURE_CISA= / 'OUI',
              / 'NON' [DEFAUT]
```

Taking into account of the additional tensile force induced by the shear force and the torsional moment, in the context of the Ritter-Mörsch truss modelling.

**Note:**

In the case where **EPURE_CISA** **= ‘OUI’**, the computation of the additional section of steel in tension is carried out in accordance with the equation below:

${A}_{\text{sl}}=({V}_{\mathit{Ed}}+{T}_{\mathit{Ed}}\times {u}_{k}/2{a}_{k})\times \mathrm{cot}({\theta}_{b})/{\sigma}_{s}$

Such that VEd and TEd represent respectively the design shear force and the design torsional moment; in the context of the ‘2D’ elements, these are the forces deduced from the corner equilibrium facet by facet in accordance with the Capra-Maury method, currently retained.

On the other hand, θb represents the angle of inclination of the concrete compression struts, as deduced from the design analysis of the transverse reinforcement, and ak and uk represent respectively the area inside the mean sheet of the walls of the section and the perimeter of the sheet, as defined in §6.3.2 of the EC2 (and also applicable to the BAEL91).

##### 3.11.2.6 Operand FERR_MIN

```text
◊ FERR_MIN= / 'VALE_MIN',
            / 'EC2'
```

Taking into account of a minimum reinforcement.

The attribute can take as value:

- ‘VALE_MIN’: a minimum reinforcement ratio will be taken into account, the value of which is to be supplied by the user
- 'EC2': a minimum reinforcement ratio will be taken into account, the value of which will be computed implicitly by the software, in accordance with the EC2.

##### 3.11.2.7 Operand RHO_LONGI_MIN

```text
◊ RHO_LONGI_MIN= rholmin, [R]
```

Minimum reinforcement ratio in %, with respect to the longitudinal bending reinforcement (to be supplied in the case where FERR_MIN= ‘VALE_MIN’).

**Note:**

In the case where **FERR_MIN** **= ‘EC2’**, the computation of RHO_LONGI_MIN is carried out implicitly by the code as follows:

${\rho}_{\text{l,min}}=0,26\times {f}_{\mathit{ctm}}/{f}_{\mathit{yk}}\text{}⩾\text{}0,0013$

##### 3.11.2.8 Operand RHO_TRNSV_MIN

```text
◊ RHO_TRNSV_MIN= rhotmin, [R]
```

Minimum reinforcement ratio in %, with respect to the transverse shear reinforcement (to be supplied in the case where FERR_MIN= ‘VALE_MIN’).

**Note:**

In the case where **FERR_MIN** **= ‘EC2’**, the computation of RHO_TRNSV_MIN is carried out implicitly by the code as follows:

${\rho}_{\text{t,min}}=0,08\times \sqrt{{f}_{\mathit{ck}}}/{f}_{\mathit{yk}}$ , if TYPE_STRUCTURE= ‘1D’

${\rho}_{\text{t,min}}=0$ , if TYPE_STRUCTURE= ‘2D’

##### 3.11.2.9 Operand FERR_MIN_FISS

```text
◊ FERR_MIN_FISS= / 'EC2',
                 / 'RCC-CW'
```

Taking into account of the minimum reinforcement for crack control.

The attribute can take as value:

- ‘EC2’: the minimum reinforcement for crack control is taken into account during the reinforcement analysis at the ELS-QP in accordance with the specifications of §7.3.2 of the EC2, equation 7.1.
- ‘RCC-CW’: the minimum reinforcement for crack control is taken into account during the reinforcement analysis at the ELS-QP in accordance with the specifications of §DCONC 4110 of the EC2, equation DCONC 4110-1.


```text

              / 'NON' [DEFAUT]
```

**Note:**

In the case where **EPURE_CISA** **= ‘OUI’**, the computation of the additional section of steel in tension is carried out in accordance with the equation below:

${A}_{\text{sl}}=({V}_{\mathit{Ed}}+{T}_{\mathit{Ed}}\times {u}_{k}/2{a}_{k})\times \mathrm{cot}({\theta}_{b})/{\sigma}_{s}$

Such that VEd and TEd represent respectively the design shear force and the design torsional moment; in the context of the ‘2D’ elements, these are the forces deduced from the corner equilibrium facet by facet in accordance with the Capra-Maury method, currently retained.

On the other hand, θb represents the angle of inclination of the concrete compression struts, as deduced from the design analysis of the transverse reinforcement, and ak and uk represent respectively the area inside the mean sheet of the walls of the section and the perimeter of the sheet, as defined in §6.3.2 of the EC2 (and also applicable to the BAEL91).

## 4 Composition of the field produced

The result is enriched by a new field (named 'FERRAILLAGE' in the data structure) whose components are:

If **TYPE_STRUCTURE** **= ‘2D’** :

- a longitudinal reinforcement density in the direction $X$ of the element for the lower face of the element ($\mathrm{DNSXI}$ ) ;
- the equivalent for the upper face ($\mathrm{DNSXS}$ ) ;
- a longitudinal reinforcement density in the direction $Y$ of the element for the lower face of the element ($\mathrm{DNSYI}$ ) ;
- the equivalent for the upper face ($\mathrm{DNSYS}$ ) ;
- the transverse reinforcement density in the direction $X$ of the element ($\mathit{DNSXT}$ ) ;
- the equivalent in the direction $Y$ of the element ($\mathit{DNSYT}$ ) ;
- the total volumetric density of steel ($\mathit{DNSVOL}$ );
- an indicator of the complexity of placing the reinforcement ($\mathit{CONSTRUC}$ ).
- a minimum reinforcement density for crack control in the direction $X$ of the element for the lower face of the element ($\mathrm{ASMINXI}$ ) ;
- the equivalent for the upper face ($\mathrm{ASMINXS}$ ) ;
- a minimum reinforcement density for crack control in the direction $Y$ of the element for the lower face of the element ($\mathrm{ASMINYI}$ ) ;
- the equivalent for the upper face ($\mathrm{ASMINYS}$ ) ;

If **TYPE_STRUCTURE** **= ‘1D’** :

- a longitudinal reinforcement density along the axis $Y$ of the section, and in the positive direction of the axis (upper face along the height h) ($\mathit{AYS}$ ) ;
- a longitudinal reinforcement density along the axis $Y$ of the section, and in the negative direction of the axis (lower face along the height h) ($\mathit{AYI}$ ) ;
- a longitudinal reinforcement density along the axis $Z$ of the section, and in the positive direction of the axis (upper face along the width b) ($\mathit{AZS}$ ) ;
- a longitudinal reinforcement density along the axis $Z$ of the section, and in the negative direction of the axis (lower face along the width b)($\mathit{AZI}$ ) ;
- a transverse reinforcement density ($\mathit{AST}$ ) ;
- a total longitudinal reinforcement density ($\mathit{ATOT}$ ) ;
- the total volumetric density of steel ($\mathit{DNSVOL}$ );
- an indicator of the complexity of placing the reinforcement($\mathit{CONSTRUC}$ ).

At present, for the ‘2D’ elements, the reinforcement densities are computed according to the method of CAPRA and MAURY [R7.04.05](doc:r7.04.05). These densities are expressed in unit of area per linear length of shell. For example, if the mesh is in metres (with consistent elementary-characteristic and material data), the densities will be expressed in ${m}^{2}/m$ for the bending steels and in ${m}^{2}/m\mathrm{²}$ for the shear-force steels.

For the ‘1D’ elements, the densities are expressed in unit of area. For example, if the mesh is in metres (with consistent elementary-characteristic and material data), the densities will be expressed in ${m}^{2}$ for the bending steels and in ${m}^{2}/m$ for the shear-force steels.

The reinforcement field is computed for all the time instants specified by the user (by default: all). If one wants to compute the field containing the “max” values during the transient, one can execute the command:

FERMAX=CREA_CHAMP( OPERATION='EXTR', TYPE_CHAM='ELEM_FER2_R',

NOM_CHAM='FERRAILLAGE', RESULTAT=Solution,

TYPE_MAXI='MAXI_ABS', TYPE_RESU='VALE',

)

## 5 Errors and alarms

### 5.1 Errors caused by an inconsistency of the input parameters

A check of the consistency of the input parameters is carried out at the start of the execution of the command CALC_FERRAILLAGE. The analysis can be stopped by a fatal error in the following cases:

- in the case BAEL91 at the ELU: if the keywords GAMMA_S, GAMMA_C, FE or FCJ are not supplied;
- in the case BAEL91 at the ELS: if the keywords N, SIGS_ELS or SIGC_ELS are not supplied;
- in the case BAEL at the ELS_QP: if the keywords ALPHA_E, FYK, FCK, SIGC_ELS_QP, WMAX_INF/SUP(_Y/Z), KT, PHI_X/Y/Z_INF/SUP are not supplied;
- in the case EC2 at the ELU: if the keywords GAMMA_S, GAMMA_C, FYK or FCK are not supplied;
- in the case EC2 at the ELS: if the keywords ALPHA_E, SIGS_ELS, SIGC_INF/SUP(_Y/Z)_ELS or FCK are not supplied;
- in the case EC2 at the ELS_QP: if the keywords ALPHA_E, FYK, FCK, SIGC_ELS_QP, WMAX_INF/SUP(_Y/Z), KT, PHI_X/Y/Z_INF/SUP are not supplied;
- for all cases: if the value of the cover is greater than the thickness/height/width of the structural element.

As well as the following particular cases:

- if **FERR_MIN = ‘VALE_MIN’** and the keywords RHO_LONGI_MIN and RHO_TRSNV_MIN are not supplied.
- if **FERR_SYME = ‘OUI’** and the keyword SEUIL_SYME is not supplied.

### 5.2 Alarms issued during the computation of the bending steels

The computation of the bending steels can issue one or several alarms in the following cases:

- if the ‘1D’ element or at least one facet of the ‘2D’ element is at pivot B and too heavily compressed, with **FERR_COMP = ‘NON’**: in this case the reinforcement density is set to -1 for the element (and the analysis on the other facets of the ‘2D’ element is ignored)
- if the ‘1D’ element or at least one facet of the ‘2D’ element is at pivot C and too heavily compressed with **FERR_COMP = ‘NON’**: in this case the reinforcement density is set to -1 for the element (and the analysis on the other facets of the ‘2D’ element is ignored)
- if **FERR_SYME = ‘OUI’** and the algorithm does not succeed in determining a symmetrical reinforcement for the ‘1D’ element (or for at least one facet of the ‘2D’ element) which respects the tolerance threshold entered at the keyword **SEUIL_SYME**: in this case the reinforcement density is set to -1 for the element
- if the **‘1D’** element is subjected to biaxial bending, and the iterative design algorithm by verification of the Bresler inequality does not manage to converge: in this case the reinforcement density is set to -1 for the element
- if **TYPE_COMB = ‘ELS_QP’** and the iterative design algorithm based on the verification of the crack-opening inequality does not manage to converge: in this case the reinforcement density is set to -1 for the element

### 5.3 Alarms issued during the computation of the transverse steels

The analysis at the ELU of the transverse steels can issue one or several alarms in the following cases:

- if the concrete is too heavily sheared: in this case the reinforcement density of the transverse steels is set to -1.
