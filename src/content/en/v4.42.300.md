# v4.42.300 TPNL300 - One-dimensional heat transfer with radiation

**Summary:**

This test is based on the independent validation of version 3 in nonlinear steady-state thermal analysis.

This is a linear 1D problem represented by two modellings, one plane, the other volume.

The functions tested are as follows:

- element thermal plane,
- element thermal volumetric,
- limit conditions: (imposed temperatures, radiation).

The value of the test lies in the consideration of radiation.

The results are compared with those provided by NAFEMS.

## 7 Summary of the results

This test is recommended by NAFEMS (but with another type of mesh).

Both modellings give very satisfactory results, the difference maximum obtained is 0.003%.

For PLAN modelling, despite the non-symmetry of mesh, the temperature at nodes (observation points) belonging to TRIA3 and QUAD4 is identical.

The radiation limit condition was imposed via a nonlinear flow loading (temperature function flux). In this test the radiation consideration is quite correct.

This test allowed testing the AFFE_CHAR_THER_F command (associated with FLUX_NL operand which allows to affect a non-linear stream) in the case of modellings PLAN and 3D.
