# u4.53.22 Operator DYNA_ALEA_MODAL

## 1 Purpose

This operator makes it possible to compute the spectral density matrix of the response of a linear structure under an excitation whose spectral density matrix is known (one also says excitation interspectrum).

The operator then supplies the modal response in the form of its spectral density (the interspectrum of the response).

The concept produced is of type interspectre.

## 2 Syntax

```text
interspectre = DYNA_ALEA_MODAL(
    ◆ BASE_MODALE = _F(
         ◆ MODE_MECA = mode_meca,
         ◆ / BANDE = float,
           / NUME_ORDRE = int,
         # Si: exists("BANDE")
             ◆ AMOR_UNIF = float,
         # Si: exists("NUME_ORDRE")
             ◆ AMOR_REDUIT = float,
      ),
    ◇ MODE_STAT = mode_meca,
    ◆ EXCIT = _F(
         ◆ INTE_SPEC = interspectre,
         ◇ NUME_VITE_FLUI = int,
         ◇ OPTION = / "TOUT" (par défaut),
                    / "DIAG",
         ◇ MODAL = / "OUI",
                   / "NON" (par défaut),
         # Si: (not exists("MODAL")) or (equal_to("MODAL", 'NON'))

               / NOEUD_I = no,
             # Si: exists("NUME_ORDRE_I")
                 ◇ / CHAM_NO = cham_no,

                              / "SOUR_DEBI_MASS",

                              / "SOUR_FORCE",
                 ◇ DERIVATION = / 0 (par défaut),
                                / 1,
                                / 2,
             # Si: exists("NOEUD_I")
                 ◆ NOM_CMP_I = text,
                 ◆ NOEUD = no,
                 ◆ NOM_CMP = text,
                 ◇ GRANDEUR = / "DEPL_R" (par défaut),
                              / "EFFO",
                              / "SOUR_DEBI_VOLU",
                              / "SOUR_DEBI_MASS",
                              / "SOUR_PRESS",
                              / "SOUR_FORCE",
                 ◇ DERIVATION = / 0 (par défaut),
                                / 1,
                                / 2,
         # Si: (equal_to("MODAL", 'OUI'))
             ◆ NUME_ORDRE_I = int,
             ◇ GRANDEUR = / "DEPL_R" (par défaut),
                          / "EFFO",
                          / "SOUR_DEBI_VOLU",
```

## 3 Features

The operator DYNA_ALEA_MODAL makes it possible to compute the response, in the frequency domain and on a modal basis, of a structure subjected to an excitation represented by an interspectral matrix (cf. DEFI_INTE_SPEC [U4.36.02](doc:u4.36.02)).

The excitation quantity (grandeur) may be of the type imposed degree of freedom, or a force associated with a degree of freedom. It may also correspond to fluid excitation sources [R4.05.02](doc:r4.05.02).

The excitation may be given in derived form of order equal to 0, 1 or 2 (displacement, velocity or acceleration).

The operator REST_SPEC_PHYS [U4.63.22](doc:u4.63.22) makes it possible to restore the response in displacement or in force at the degrees of freedom “of observation” (node, component pair).

The interspectral matrix of modal response thus computed may be reintroduced into a new analysis.

## 4 Operands

### 4.1 Keyword BASE_MODALE

```text
♦    BASE_MODALE = _F    (
```

Factor keyword for the definition of the parameters for selecting the modal basis of the analysis.

#### 4.1.1 Operand MODE_MECA

```text
♦    MODE_MECA =    modemec
```

modemec is the concept of type mode_meca containing the dynamic modes.

#### 4.1.2 Operands NUME_ORDRE / AMOR_REDUIT

```text
/    NUME_ORDRE = lordre
```

lordre is the list of the order numbers of the modes of the concept modemec which are actually taken into account in the analysis. Example: $(2,3,4)$ .

```text
AMOR_REDUIT = lamor
```

lamor is the list of the reduced modal dampings corresponding to the modes retained. The number of elements of the list is equal to the number of elements of lordre. Example: $(0.05,0.05,0.02)$ . This keyword can be used only with NUME_ORDRE.

#### 4.1.3 Operands BANDE / AMOR_UNIF

```text
/    BANDE = (f1 f2)
```

The dynamic modes taken into account will be those of modemec whose frequency lies in the band (f1 f2)

```text
AMOR_UNIF = amor
```

For each mode retained, the damping is equal to amor. This keyword can be used only with BANDE.

### 4.2 Operand MODE_STAT

```text
◊    MODE_STAT = mosta
```

Concept of type mode_meca containing the static modes required for the analysis.

This keyword is necessary only in the case of a multi-support seismic analysis in which the excitation is applied on degrees of freedom (i.e. when the keyword GRANDEUR under the factor keyword EXCIT is equal to 'DEPL_R').

### 4.3 Keyword EXCIT

```text
♦    EXCIT = _F (
```

Factor keyword defining all the parameters concerning the excitation.

The keywords DERIVATION, GRANDEUR and MODAL define the type of excitation.

The keywords INTE_SPEC, NUME_VITE_FLUI, NUME_ORDRE_I, NUME_ORDRE_J, NOEUD_I, NOEUD_J, NOM_CMP_I and NOM_CMP_J define the excitation interspectrum.

#### 4.3.1 Operand DERIVATION

```text
DERIVATION =
```

When the excitation quantity (grandeur) is of the type imposed degree of freedom ('DEPL_R'), this keyword makes it possible to describe whether the excitation interspectrum must be considered as an imposed displacement, velocity or acceleration. The user then specifies 0, 1 or 2.

This keyword is optional. By default, it is equal to 0.

**Note:**

*In the case of a seismic analysis, the excitation is often an acceleration. This keyword must then be equal to 2.*

#### 4.3.2 Operand GRANDEUR

```text
◊    GRANDEUR =
```

This keyword makes it possible to state whether the excitation is of the type imposed degree of freedom ('DEPL_R'), imposed force ('EFFO'), volume flow-rate source ('SOUR_DEBI_VOLU'), mass flow-rate source ('SOUR_DEBI_MASS'), pressure source ('SOUR_PRESS') or fluid force source ('SOUR_FORCE').

This keyword is optional. By default, it is equal to 'DEPL_R' and the excitation is of the type imposed displacement degree of freedom in every case except in the case of supports represented by assembled vectors (keyword CHAM_NO).

#### 4.3.3 Operands INTE_SPEC and NUME_VITE_FLUI

These keywords define the excitation interspectrum (or interspectra).

```text
♦    INTE_SPEC = interexc
```

interexc is the concept of type interspectre containing the set of excitation interspectral matrices (spectral density matrices). It is taken into account as it is defined in the function associated with the concept, that is to say in particular that a possible folding of the spectrum is not interpreted.

For a function defined by:

$f\in [{f}_{1,}{f}_{2}]:\tilde{S}(f)$ given

One will interpret:

$\begin{array}{}f<{f}_{1}:S(f)=0\\ f\in \left[{f}_{1},{f}_{2}\right]:S(f)=\tilde{S}(f)\text{donné}\\ f>{f}_{2}:S(f)=0\end{array}$

If the frequency loop $[{f}_{1,}{f}_{2}]$ must be reproduced for the negative frequencies, one must:

- either give the whole of the spectrum on the real axis,
- or apply a coefficient 2 to the value of the DSP, a possible workaround, since the spectral densities are assumed to be symmetric in the analyses carried out by the command DYNA_ALEA_MODAL.

> The parameters required of the table are:

1. if one indexes the parameters of the table by order numbers: ‘NUME_ORDRE_I’[I], ‘NUME_ORDRE_J’[I], ‘FONCTION’[K24]
2. otherwise: ‘NŒUD_I’[K8], ‘NŒUD_J’[K8], ‘NOM_CMP_I’[K8], ‘NOM_CMP_J’[K8], ‘FONCTION’[K24].
3. The table must be complete: presence of the auto-spectra (diagonal term of the matrix) and of the interspectra (off-diagonal term of the matrix).

```text
Cette table peut être générée par les opérateurs: DEFI_SPEC_MODAL, LIRE_INTE_SPEC ou CALC_INTE_SPEC. Le lecteur est invité à consulter la documentation de la commande TEST_FONCTION [:external:ref:`U4.92.02 <U4.92.02>`] pour davantage d’informations sur le sens des paramètres.

◊    NUME_VITE_FLUI = nk

nk est le numéro d’ordre de la vitesse du fluide associé à interexc.
```

#### 4.3.4 Operands NUME_ORDRE_I, NOEUD, NOM_CMP, CHAM_NO and MODAL

These keywords link the terms (line numbers in the matrix) of the excitation interspectrum and the excitation point (or points) for a modal excitation, or when the parameters of the table have been indexed by order numbers.

```text
♦    /    ♦    NUME_ORDRE_I    = (noi1, noi2,..)
```

This list of order numbers makes it possible to determine the term (line number) of the given interspectral matrix. The length of this list must correspond to the number of excitations imposed on the structure.

```text
♦     /    ♦     NOEUD = list_noe
```

This keyword makes it possible to specify the nodes at which the multi-spectral excitation will be applied. Example ('N1', 'N5', 'N7').

For all types of excitation quantity (grandeur), except for pressure sources and force sources, list_noe contains as many terms as there are indices defining excitation interspectra.

In the case of pressure sources or force sources, a dipole is associated with each source, that is to say two points of application. list_noe then has twice as many terms as there are indices defining interspectra.

```text
♦     NOM_CMP = list_cmp
```

This keyword makes it possible to specify the components on which the multi-spectral excitation will be applied. Example ('PRES' 'DRZ' 'PHI').

These components must of course correspond to degrees of freedom of the support nodes.

In every case, list_cmp has the same number of elements as list_noe.

For fluid sources, it is the degree of freedom 'PRES' which is excited.

```text
◊ MODAL = 'NON' [DEFAUT]
```

The excitation is not modal in this case.

```text
/    ♦    cham_no= list_vass
```

When this keyword is present, each excitation support is an assembled vector defined beforehand in the command file. list_vass contains the list of the assembled vectors standing in for supports. The associated exciting quantity (grandeur) is 'EFFO'. It is recommended that the intensity associated with the force which one imposes in this way be given by the interspectrum: the assembled vector serves essentially to define a shape function supporting a force power spectrum. It is therefore normalised.

This option makes it possible to assign a force power spectrum on a shape function.

In every case, list_vass contains as many terms as there are indices defining interspectra.

```text
/    ♦    MODAL = 'OUI'
```

The presence of 'OUI' under this keyword implies that the excitation interspectrum is considered as a modal excitation.

#### 4.3.5 Operands NOEUD_I and NOM_CMP_I

These keywords link the terms (line numbers in the matrix) of the excitation interspectrum (or interspectra) and the excitation points when the parameters of the table have been indexed by physical data consisting of the pair (Node-Component).

```text
♦/        ♦ NOEUD_I        =    ndi1, ndi2,...
♦ NOM_CMP_I    =    cmpi1, cmpi2,...
```

These lists are paired two by two in order to determine the term (line number) of the given interspectral matrix. The length of the preceding lists must correspond to the number of excitations imposed on the structure.

```text
♦    NOEUD        =    list_noe            [l_noeud]
♦    NOM_CMP    =    list_comp            [l_cmp]
```

These two keywords have the same meaning as in [§4.3.4].

```text
◊    MODAL        =    'NON'                [DEFAUT]

                 L'excitation n'est pas modale dans ce cas.
```

### 4.4 Keyword REPONSE

```text
♦    REPONSE = _F (
```

Factor keyword for the definition of all the parameters concerning the response.

The following three keywords describe the type of the response.

#### 4.4.1 Operand DERIVATION

```text
◊    DERIVATION =

     Ce mot-clé a le même sens que pour le mot-clé facteur EXCIT [:ref:`§4.3.1 <§4.3.1>`].
```

#### 4.4.2 Operand OPTION

```text
◊    OPTION =
```

If this keyword is specified with 'DIAG', then all the off-diagonal functions of the response interspectrum are initialised to zero without being computed. Only the auto-spectra are computed. Otherwise ('TOUT'), all the functions of the response interspectrum are computed.

#### 4.4.3 Operands FREQ_MIN / FREQ_MAX / PAS / FREQ_EXCIT / NB_POIN_MODE

These keywords serve to describe the frequency discretisation in which the response will be given.

```text
◊    ♦    FREQ_MIN = fmin
♦    FREQ_MAX = fmax
```

fmin and fmax are the two bounds of the frequency interval. pas is the minimum discretisation step.

```text
◊    PAS = pas
```

If the values of fmin and fmax are given, pas is then by default equal to $\frac{{f}_{\max}-{f}_{\min}}{100}$ .

Otherwise one takes for fmax the largest eigenfrequency of the dynamic modes retained for the analysis.

The discretisation then covers the domain $[0;{\mathrm{2.f}}_{\max}]$ , $\mathrm{pas}=\frac{{\mathrm{2.f}}_{\max}}{100}$ .

On the other hand, if pas is present, one makes sure that the discretisation step of the response is everywhere less than pas.

```text
◊    FREQ_EXCIT =         /    'AVEC'
/    'SANS'
```

If the user gives the argument 'AVEC' under the keyword FREQ_EXCIT, then the frequencies of the excitation are included in the discretisation of the response (default option). If the user gives the argument 'SANS', they will be ignored. This keyword is set to 'SANS' if the keyword FREQ_MIN is present.

```text
◊    NB_POIN_MODE =     n [:ref:`défaut = 50 <défaut = 50>`]
```

The response is more refined at the eigenfrequencies in order to ensure a good description of the response at the peaks.

The keyword NB_POIN_MODE makes it possible to define the number of frequency steps per eigenfrequency taken into account. By default, there are 50 steps per eigenfrequency. This keyword is not taken into account if FREQ_MIN is given.

Each function of the interspectrum will by default have an interpolation mode of linear type and an extension mode outside the discretisation domain of type 'EXCLU'.

### 4.5 Operand TITRE

```text
◊    TITRE = titre
```

titre is the title of the analysis. It will be printed at the head of the results. See [U4.03.01](doc:u4.03.01).

### 4.6 Operand INFO

```text
◊    INFO =
```

Specifies the printout options on the MESSAGE file.

| 1 | no printout |
| --- | --- |
| 2 | recalls the analysis options chosen. |

## 6 Useful notes for use

- **Need for a static mode and type of dynamic modes:**

In the case of an excitation by imposed displacement, the dynamic modes are computed with fixed supports and the presence of the static mode is mandatory.

In the other cases, the dynamic modes are computed with free supports, and the presence of a static mode is no longer justified.

The dimension of the interspectral matrix is given by the sum of the static modes and of the dynamic modes (if there are any) taken into account.

Thus, for a structure with five dynamic modes, excited in displacement by two supports, the dimension of the interspectral matrix of modal response is 7.

If the excitation is given as an imposed force, there are no static modes and the dimension of the interspectral matrix is 5.

- **Use of the keyword** **MODAL under the factor keyword** **EXCIT:**

In the case where the keyword MODAL is used under the factor keyword EXCIT in order to introduce directly the modal spectral density matrix as the excitation, one must give again, under the keywords EXCIT, BASE_MODALE and MODE_STAT, all the arguments which had been used to create this modal interspectral matrix (support nodes and degrees of freedom).

## 7 Verification stage

One checks the consistency of the data:

- number of modal dampings = number of modes retained.
- number of support nodes equal to the number of components (for the excitation).
- number of pairs of indices retained in the excitation interspectrum = number of supports or number of excitation points.
- in the case of pressure sources: number of support nodes equal to twice the number of pairs of indices retained in the excitation interspectrum.
- the presence of a mode_meca is checked in the cases of excitation by a quantity (grandeur) of type DEPL_R.
- $\mathrm{fmax}\ge \mathrm{fmin}$

## 8 Example

```text
DYNALEA1=DYNA_ALEA_MODAL(

BASE_MODALE=_F(

MODE_MECA = FREQ1,

NUME_ORDRE = 1,

AMOR_REDUIT = 0.05),

MODE_STAT=MODESTA1,

EXCIT=_F( DERIVATION = 2,

INTE_SPEC = INTEREXC,

NUME_ORDRE_I = 1,

NUME_ORDRE_J = 1,

NOEUD = 'P1',

NOM_CMP = 'DX'),

REPONSE=_F( DERIVATION = 2),

)
```
