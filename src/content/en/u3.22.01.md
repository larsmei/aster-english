# u3.22.01 Modellings COQUE, COQUE_PLAN, COQUE_AXIS - Phenomenon THERMIQUE

**Summary:**

This document describes, for the thermal modellings of the axisymmetric and plane elements:

- the degrees of freedom carried by the finite elements which support the modelling,
- the associated support mesh cells,
- the supported loadings,
- the non-linear possibilities,
- the test cases implementing the modellings.

The COQUE modelling of the Phenomenon THERMIQUE [R3.11.01](doc:r3.11.01) can be used to treat the heat equations in media with a middle surface in linear thermal analysis. One can use it as the first analysis of a thermomechanical chaining with the corresponding mechanical elements.

## 1 Discretisation

### 1.1 Degrees of freedom

The degrees of freedom are the temperatures TEMP (temperature on the middle surface of the shell), TEMP_INF (temperature on the lower surface of the shell), and TEMP_SUP (temperature on the upper surface of the shell).

### 1.2 Support mesh cells of the stiffness matrices

| **Modelling** | **Mesh cell** | **Finite element** | **Remarks** |
| --- | --- | --- | --- |

| COQUE | TRIA3 | THCOTR3 | nodes with 3 coordinates $x$ , $y$ , $z$ |
| --- | --- | --- | --- |
|  | TRIA6 | THCOTR6 |  |
|  | TRIA7 | THCOTR7 |  |
|  | QUAD4 | THCOQU4 |  |
|  | QUAD8 | THCOQU8 |  |
|  | QUAD9 | THCOQU9 |  |
| COQUE_PLAN | SEG3 | THCPSE3 | nodes with 2 coordinates $x$ , $y$ |
| COQUE_AXIS | SEG3 | THCASE3 |  |

For the THCOTRi, only the 3 vertices are used to define the local geometry (tangent plane, normal). For the THCOQUi, one considers that the element is plane and that its tangent plane is defined by default by 3 of the 4 vertices of the element.

### 1.3 Support mesh cell of the loadings

All the loadings applicable to the facets of the shell elements are treated by direct discretisation on the support mesh cell of the element in temperature formulation.

*No loading support mesh cell is therefore necessary for the faces of the shell elements.*

For the loadings applicable on the edges of the shell or plate elements of the -shell- modelling, a support mesh cell of type SEG2 or SEG3 must be used.

| **Modelling** | **Mesh cell** | **Finite element** | **Remarks** |
| --- | --- | --- | --- |

| COQUE | SEG2 | THCOSE2 | with TRIA3 and QUAD4 |
| --- | --- | --- | --- |
| COQUE | SEG3 | THCOSE3 | with TRIA6 or TRIA7 and QUAD8 or QUAD9 |

For the imposed temperatures, the support mesh cells are mesh cells reduced to a point.

## 2 Assignment of the characteristics

For these thermal structural elements, it is necessary to assign geometric characteristics which are complementary to the mesh data. The definition of these data is carried out with the command AFFE_CARA_ELEM associated with the following factor keyword:

- **COQUE**

Makes it possible to define and to assign the thickness on the mesh cells.

## 3 Supported loadings

The loadings available are the following:

- **FLUX_REP**

Makes it possible to apply normal fluxes to faces of shell elements on the faces ±.

Supported modellings: COQUE, COQUE_PLAN, COQUE_AXIS

- **ECHANGE**

Makes it possible to apply exchange conditions with an external temperature to shell faces on the upper and lower faces.

Supported modellings: COQUE, COQUE_PLAN, COQUE_AXIS

## 4 Non-linear possibilities

None.

## 5 Transient possibilities

Only the COQUE modelling makes it possible to treat transient thermal problems.
