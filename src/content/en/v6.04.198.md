# v6.04.198 SSNV198 – Dirichlet conditions with X-FEM in 3D

**Summary**

The purpose of this test is to validate the imposition of Dirichlet conditions (taxed displacements) on nodes enriched by the X-FEM [bib1] method on a 3D academic case.

This test involves a 3D structure with a flat, deep-right cracking opening. boundary conditions are applied to one side of the structure, containing enriched nodes.

Several mesh configurations are tested and compared with the analytical solution.

## 1 Reference problem

### 1.1 Geometry

The structure is a unitary cube ($\mathit{LX}=1m$ , $\mathit{LY}=1m$ and $\mathit{LZ}=1m$ ), with a flat crack leading to $a=0,5m$ length , mid-height [ Figure 1.1-1.1-a ]. The face is called behind the face in the $x=0$ plane and the face in front of the $x=\mathit{LX}$ plane .

![Figure](/figures/v6.04.198/10000000000001D9000001B2196D73F52C7531F4.png)

**Figure 1.1-** 1.1-a **: geometry of cracked cube**

### 1.2 Material properties

Young's modulus: $E=100\mathit{MPa}$

Poisson's ratio: $\nu =0$ .

### 1.3 Boundary conditions and loads

The load studied is a load that requires cracking in $\mathit{III}$ mode (outside), without creating a displacement discontinuity.

To do this, you will require a clamped support of the nodes of the rear side: $\mathit{DX}=\mathit{DY}=\mathit{DZ}=0$ and a displacement of the nodes of the front side in the normal direction (i.e. along the $x$ axis ) $\mathit{DNOR}={10}^{}6m$ .

### 1.4 Bibliography

1. GENIAUT S., MASSIN P.: eXtended Finish Element Method, Reference Manual *Code_Aster* , [R7.02.12](doc:r7.02.12)

## 2 Modelling A

In this model, the crack is not meshed, and the mesh is selected so that the crack bottom is located in the centre of the elements containing the bottom.

### 2.1 Mesh characteristics

The structure is modelled by a regular mesh composed of $5\times 5\times 5$ HEXA8, respectively, along the $x,y,z$ axes [ Figure 2.1-2.1-a ]. The crack bottom is therefore located at the centre of the elements containing the crack bottom.

![Figure](/figures/v6.04.198/1000000000000527000003EB205A42BE711EA864.png)

**Figure 2.1-** 2.1-a **: mesh such that the bottom is in the centre of the elements**

### 2.2 Tested Features

The application of Dirichlet conditions is tested by AFFE_CHAR_MECA command on enriched nodes (here, nodes enriched by Heaviside function and other nodes enriched by asymptotic functions). This is done as for the classic nodes by keyword DDL_IMPO or FACE_IMPO.

### 2.3 Tested quantities and results

The post-processing displacement values of nodes on which the conditions have been applied are tested. The post-processing displacement with X-FEM requires a specific reconstruction step, which does not retain the nodes groups. Therefore, nodes groups must be recreated on the mesh post-processed "fissured". Care must be taken to keep only the old nodes, and remove the new nodes, i.e. those that coincide with the intersection of the crack and the healthy mesh edges, from the group. This sorting is done by the name of the nodes:

- $N\dots$ for classic nodes,
- $\mathit{NX}\dots$ for nodes X-FEM that are not on the crack,
- $\mathit{NM}\dots$ and $\mathit{NP...}$ For new nodes X-FEM that are on the "less" lip and the "more" lip.

So we eliminate the nodes whose name starts with $\mathit{NM}$ and $\mathit{NP}$.

To test all nodes in the group at once, we test the minimum and maximum values.

## 3 Modelling B

In this Modelling, the crack is not meshed, and the mesh is chosen so that the crack bottom coincides with a node of the mesh.

### 3.1 Mesh characteristics

The structure is modelled by a regular mesh composed of $6\times 6\times 6$ HEXA8, respectively, along the $x,y,z$ axes [ Figure 3.1-3.1-a ]. The crack bottom is therefore located at the centre of the elements containing the crack bottom. In addition, the crack coincides with the edges of the elements.

![Figure](/figures/v6.04.198/1000000000000527000003EB957823508FB708BE.png)

**Figure 3.1-** 3.1-a **: mesh as the background coincides with an node**

### 3.2 Tested Features

The application of Dirichlet conditions is tested by AFFE_CHAR_MECA command on enriched nodes (here, double-enriched nodes: by Heaviside function and asymptotic functions). This is done as for classic nodes by DDL_IMPO or FACE_IMPO keywords.

### 3.3 Tested quantities and results

The displacement values of the nodes on which the conditions were applied are tested.

As the crack passes through nodes of mesh, the conditions were applied to both lips of the crack.

So it is not necessary here to filter nodes. All new nodes are tested.

To test all nodes in the group at one time, the min and max values are tested.

## 4 Executive summary

This test case validates the imposition of Dirichlet terms on nodes X-FEM. The taxation is done by the DDL_IMPO or FACE_IMPO keywords of the AFFE_CHAR_MECA command.
