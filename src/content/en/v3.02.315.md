# v3.02.315 SSLP315 - Propagation of crack opening in a 2D hole plate of finished width with XFEM

**Summary:**

The purpose of this test is to verify that the four propagation methods available in the PROPA_FISS operator (mesh, simplex, upwind, geometric) give the same result for a mixed-mode $\mathrm{2D}$ propagation.

An opening crack is propagated in a rectangular plate with three holes and is flexed three points. After four propagations, the position of the bottom of the crack obtained by each method is compared with the reference position given by the mesh method.

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v3.02.315/100002010000051E000002D22C98408C0BE36547.png)

**Figure** 1.1-a **: geometry of cracked plate**

All dimensions are expressed in millimetres.

### 1.2 Material properties

Young's modulus $E=200000\mathit{MPa}$

Poisson's ratio $\nu =0.3$

### 1.3 Boundary conditions and loads

boundary conditions:

> Point ${P}_{1}$ : $\Delta X=\Delta Y=0$
> Point ${P}_{2}$ : $\Delta Y=0$

Loading:

> Force: $P=1000N$

The load ratio is set to zero. The above value of the $P$ force is therefore the maximum fatigue cycle value.

## 2 reference solution

### 2.1 Method of calculation

PROPA_FISS mesh ($A$ Modelling) is used to calculate the crack position after four propagations.

At each call of PROPA_FISS the crack advance is imposed equal to $2\mathrm{mm}$ .

### 2.2 Quantities and reference results

After four propagations, the position of the crack bottom calculated by the mesh method is as follows:

| **Propagation** | **Coordinate** $x$ | **Coordinate** $y$ |
| --- | --- | --- |
| 4 | 42.13970 | 20.60376 |

**Table** 2.1 **- reference solution**

This heading is used as a reference position.

## 3 Modelling A

### 3.1 Modelling characteristics

Mesh is used by PROPA_FISS to calculate the new position of the crack bottom. Stress intensity factors are calculated using CALC_G.

### 3.2 Mesh characteristics

The structure is modelled by a mesh consisting of 4464 elements TRIA3 (see ).

![Figure](/figures/v3.02.315/1000020100000533000002243B310EE16BAE19AC.png)

**Figure** 3.2-a **: mesh of the structure**

The mesh is more refined in the propagation area. In this area the dimension of the smallest edge of the elements is equal to $1.5\mathrm{mm}$.

### 3.3 Tested quantities and results

The position of the crack bottom after four propagations calculated by the mesh method is taken as the reference value:

| **Propagation** | **Coordinate** $x$ | **Coordinate** $y$ |
| --- | --- | --- |
| 4 | 42.13970 | 20.60376 |

**Table** 3.3-1

### 3.4 Remarks

The position of the crack bottom cannot be recovered in the command file for simplex, upwind and geometric methods (modellings D, C and E). For these methods it will be verified that the bottom position is in the same element as that associated with this Modelling (more details are given in the description of each model).

## 4 Modelling B

### 4.1 Modelling characteristics

Mesh is used by PROPA_FISS to calculate the new position of the crack bottom. Stress intensity factors are calculated using POST_K1_K2_K3.

The same model as described for model A is used.

### 4.2 Mesh characteristics

The same mesh is used as model A.

### 4.3 Tested quantities and results

The position of the bottom of the crack after four propagations is as follows:

| **Propagation** | **Coordinate** $x$ | **Coordinate** $y$ |
| --- | --- | --- |
| 4 | 42.05 | 20.62 |

The non-regression of these values is tested with a relative accuracy of 0.1%.

For information, the error on the co-ordinates of the crack bottom can be calculated in relation to the reference solution (modelling $A$ ):

| **Coord** | **Current value** [ $\mathit{mm}$ **]** | **Reference value** [ $\mathit{mm}$ **]** | ** Error** [ $\mathit{mm}$ **]** |
| --- | --- | --- | --- |
| $x$ | 42.05 | 42.14 | -0.09 |
| $y$ | 20.62 | 20.6 | 0.02 |

Consistency is achieved by using a tolerance equal to that used for modellings $C$ , $D$ and $E$ , i.e. $2.0\mathrm{mm}$ (see these modellings for details).

Here it can be considered that the bottom position calculated by this model is almost the same as the reference position.

### 4.4 Remarks

The calculated bottom position follows the tolerance used. This means that the position of the crack bottom calculated by the mesh plus POST_K1_K2_K3 method is very close to the reference position.

## 5 Modelling C

### 5.1 Modelling characteristics

UPWIND is used by PROPA_FISS to solve crack propagation equations. An auxiliary **grill** is used because the mesh cell type of the mesh structure is not usable by the UPWIND method.

The same model as described for model A is used.

### 5.2 Mesh characteristics

The structure is the same mesh as model A.

The auxiliary grid used is composed of 952 elements QUAD4 (see figure ).

![Figure](/figures/v3.02.315/100002010000026F000002DF6246162BAC544C8E.png)

**Figure** 5.2-a **: auxiliary grid**

The size of the element is $0.5\times 0.5\mathrm{mm}$.

The grid is extended to the only area of the structure interested in spreading the crack.

### 5.3 Tested quantities and results

The position of the crack bottom cannot be recovered in the command file and therefore it is not possible to verify directly whether the solution calculated by the fast walking method is consistent with the reference solution. However, it can be verified that the crack bottom is in the same element as the one containing the bottom of the crack of the reference solution. In fact, the distance between the crack bottom and each node of this element is given by the level set value and it can be said that the crack bottom is contained in the element if the level set value on these nodes is less than the length of the largest edge of the element.

The nodes of the element reference are: $\mathrm{N304}$ , $\mathrm{N1040}$ and $\mathrm{N1512}$ . The length of the largest edge of the element is $2.0\mathrm{mm}$ . This value is used as tolerance on the level set value.

The value of the level sets at each node can be recovered in the command file using the POST_RELEVE_T operator:

| **Nœud** | **LSN** [ $\mathrm{mm}$ **]** | **LST** [ $\mathrm{mm}$ **]** |
| --- | --- | --- |
| $\mathit{N304}$ | -0,772 | -1,436 |
| $\mathit{N1040}$ | 1,22 | -1,72 |
| $\mathit{N1512}$ | 0,719 | -0,242 |

### 5.4 Remarks

All the tested values respect the tolerance used. This means that the position of the crack bottom calculated by the UPWIND method is very close to the reference.

## 8 Summary of the results

All the methods used (MAILLAGECALC_G, MAILLAGEPOST_K1_K2_K3, UPWIND, SIMPLEXE, GEOMETRIQUE) were used to calculate the position of a crack propagating in mixed mode. The results obtained are comparable.

This allows to validate the implementation of the methods in the PROPA_FISS operator.
