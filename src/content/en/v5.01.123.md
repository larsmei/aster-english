# v5.01.123 SDND123 – Linear mode calculation for a 2 degrees of freedom system with a bilateral elastic stop

**Summary:**

The objective of this test is to validate the nonlinear mode calculation with the MODE_NON_LINE operator.

The system is particularly valid with bilateral stop-type nonlinearity.

Post-processings is also performed with CALC_STABILITE and REST_MODE_NONL.

## 1 Reference problem

### 1.1 Geometry

The following system is considered:

![Figure](/figures/v5.01.123/10000000000003EA000002815DF12D6AF93D41FA.png)

### 1.2 Material properties

The system features are:

- ${k}_{1}={k}_{2}=1N/m$
- ${m}_{1}={m}_{2}=1\mathit{kg}$
- $e=1m$
- $K=30N/m$

### 1.3 Boundary conditions and loads

The left edge of the system is fixed and the masses move along the spring axis.

### 1.4 Initial conditions

The periodic solution is tried to follow the evolution of the second mode of the underlying linear system (contactless system).

## 2 reference solution

The calculation of periodic solutions of the system characterizing the nonlinear mode is being studied.

### 2.1 Method of calculation

For system resolution, the EHMAN method [1] is used. The branch of periodic solutions is tried from the second mode of the linear system.

The stability of the periodic solution obtained from Floquet's theory is also calculated by a Newmark diagram and a calculation at the own values.

### 2.2 Quantities and reference results

The selected reference quantities are the frequency-energy torque and stability of the periodic solution obtained.

The periodic solution is stable for frequency torque – energy such as:

$0.2578\mathit{Hz}<f<0.2580\mathit{Hz}$     et    $1.0J<E<1.3J$

### 2.3 Uncertainties about the solution

Non-regression solution.

### 2.4 Bibliographical references

    1. MOUSSI, Analysis of vibrating structures with non-linearities located at play using non-linear modes. PhD Thesis 2013.

## 3 Modelling A

### 3.1 Modelling characteristics

DIS_T modelling is used.

### 3.2 Mesh characteristics

The mesh contains 2 elements of type SEG2.

### 3.3 Tested quantities and results

The frequency-energy interpolation torque is tested from the table produced by MODE_NON_LINE. A solution of non-regression is proposed. The values obtained are presented in the table below.

| **Frequency (** $\mathit{Hz}$ **)** | **Energy (** $J$ **)** | **Stability of the periodic solution** |
| --- | --- | --- |
| $0.2579052851$ | $1.19768$ | STABLE |

## 4 Summary of the results

This test case validates the nonlinear mode calculation operator (MODE_NON_LINE), the nonlinear mode stability calculation operator (CALC_STABILITE) and the periodic solution return operator (REST_MODE_NONL).

A solution of non-regression is proposed.
