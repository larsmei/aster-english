# v2.07.101 SHLV101 - Harmonic response subject to a linear relationship in fluid-structure intereaction

**Summary:**

This test allows to validate a harmonic analysis on modal basis with
a non-homogenous linear relationship between degrees of freedom of the physical problem
in the case of a problem with fluid-structure interaction.

- In model A, the problem is solved on a physical basis. The results are used as a reference for model B.
- In model B, the problem is solved on a general basis, the results obtained are verified to be the same as for model A.

The AFFE_CHAR_GENE command (see [U4.44.06](doc:u4.44.06)) is used to define linear relationships between generalized ddls.

## 1 Reference problem

### 1.1 Geometry

It's a pipe filled with water.

![Figure](/figures/v2.07.101/geometrie.png)

The pipe is 0.2 m radius and 0.04 m thickness. The curvature rays are 0.2 m.

Note $\Gamma^1_f$ and $\Gamma^2_f$ fluid extremities
and $\Gamma^1_S$ and $\Gamma^2_S$ solid extremities.

### 1.2 Material properties

$E=190.0e9N/{m}^{2}$

$\nu =0.3$

$\rho =7800\mathrm{Kg}/{m}^{3}$

$\rho_{eau} =732\mathrm{Kg}/{m}^{3}$

$c_{eau} =970.0 {m \over s^2}$

### 1.3 Boundary conditions and loads

A fluid-structure coupled model is used, the unknown being the movement of the
solid and pressure P of the fluid.

The system of equations to be solved is as follows:

$$
\begin{cases}
 \rho {d^2u \over dt^2} + Eu=0,\\
 \rho_{eau} {d^2u_f \over dt^2} - P =0.
\end{cases}
$$

The fluid pressure is required to be uniform on the
$\Gamma^1_f$ and $\Gamma^2_f$ fluid opening surfaces and the difference in these values is
These conditions are expressed as follows:

$P(\Gamma^1_f,t) = constante$,

$P(\Gamma^2_f,t) = constante$,

$P(\Gamma^1_f,t) - P(\Gamma^2_f,t) = sin(\omega t)$.

## 3 Modelling A

### 3.1 Modelling characteristics

3D Modelling is used for solid and 3D_FLUIDE for fluid.

The interface between solid and fluid is modelled by an U_P formulation.

The physical-based harmonic analysis for the frequency band [10 Hz, 100 Hz] is resolved.

### 3.2 Mesh characteristics

The mesh is composed of:

- 10400 mesh cells type HEXA8 for solid,
- 22100 mesh cells type HEXA8 for fluid,
- 5200 mesh cells type QUAD4 for the fluid-structure interface.

![Figure](/figures/v2.07.101/maillage.png)

### 3.3 Tested quantities and results

The NON-REGRESSION of the harmonic response is tested (see § reference results).

## 4 Modelling B

### 4.1 Modelling characteristics

The modelling is identical to model A.

Harmonistic analysis is solved on a generalized basis.
The linear relationship is applied between two static modes.
Each static mode corresponds to the unit static response of the ddls involved
in the linear relationship on a physical basis.

The modal base consists of 20 dynamic modes and both static modes.

Since the matrix is non-symmetric, the modes on the right and the modes on the left must be calculated
(dynamics and statics). Therefore, a modal base on the right and a modal base on the left were built.
for the projection of the physical problem on a generalized basis.

Note: The base on the left is only used for the projection of the matrices.
Only the base on the right is necessary for vector projection.

### 4.2 Mesh characteristics

The mesh is identical to Modelling A.

## 5 Summary of the results

The modal approach is very well aligned with the physical approach, for a much lower cost of calculation.
