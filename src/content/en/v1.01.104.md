# v1.01.104 ZZZZ104 – Validation of command variables in split commands with macro-elements

**Summary:**

This test is designed to validate the consideration of the command variables with macro-elements in split commands and also in monolithic commands. In both modellings, it is a beam (D_PLAN) half of which is a macro-element and the other one consists of finished elements. A temperature load is affected throughout the beam. References are obtained by the same calculation without macro-elements.

Modelization A:

The calculation is done with STAT_NON_LINE. The beam is bi-clamped. We check that the stresses are the same as those in the reference calculation.

Modelling B:

The calculation is done in burst control. The beam is clamped at one end and blocked according to $X$ at the other. It is checked that the movements are the same as those of the reference calculation.

This documentation is deliberately succinct.
