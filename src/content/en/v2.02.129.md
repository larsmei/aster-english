# v2.02.129 SDLL129 - Beam with 3 discs and 2 bearings with variable characteristics depending on the speed of rotation

**Summary:**

This test validates the calculation of rotational modes of a shaft system rotating with the CALC_MODE_ROTATION control in case the stiffness and damping characteristics depend on the rotational speed.

In this test, a rotor model with three discs, supported by two hydrodynamic bearings, whose stiffness and damping matrices are nonsymmetric and dependent on the rotation speed. This example and the corresponding reference results are taken from the ROTORINSA qualification manual, finished elements software designed to predict dynamic bending rotor behaviour.

A good match is observed between the results of *code_aster* and reference solution.

### 1.3 boundary conditions

To block rigid body-type movements in the $z$ direction, the degrees of freedom $\mathit{DZ}$ and $\mathit{DRZ}$ are blocked at node $\mathrm{B1}$ bearing.

## 2 reference solution

### 2.1 Method of calculation

The reference results are given by ROTORINSA, a finite elements code designed to predict the dynamic behaviour of flexing rotors. The following parameters were used for the reference results:

- The calculation is for a number of $\mathrm{NVES}=8+4$ rotation modes in ROTORINSA.
- The rotation speed range is defined from $0$ to $20000\mathrm{tr}/\mathrm{mn}$ with a $500\mathrm{tr}/\mathrm{mn}$ pitch.

### 2.2 Quantities and reference results

The results of ROTORINSA give the bending mode frequencies.

The calculation of the rotational modes is done with Code_Aster using the same Modelling as ROTORINSA. The results of Code_Aster give both the frequencies of the bending, twisting and tensile/compression modes. The number of modes calculated is 12.

### 2.3 References

ROTORINSA, finished elements software designed to predict dynamic bending rotor behavior, LaMCoS UMR5259, INSA-Lyon.

## 4 Summary of the results

This test case validates Campbell's Digram feature for tree lines whose stiffness characteristics and damping depend on the rotation speed, as the same results are found by Code_Aster and ROTORINSA.
