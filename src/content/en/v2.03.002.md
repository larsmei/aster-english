# v2.03.002 SDLS02 - clamped thin diamond plate at the edge

**Summary:**

This three-dimensional problem consists in searching for vibration frequencies of a mechanical structure composed of a parallelepipedic (non-retangular) plate, clamped on one side. This mechanical test of the structures corresponds to a dynamic analysis of a superfacial model with linear behavior. It has only one model.

This problem allows testing the DKT plate element and the calculation of vibration frequencies by the Lanczos method.

The results obtained on the first two eigenfrequencies are in good agreement with those of the VPCS guide.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The reference formula is that given in the SDLS02/89 form of the VPCS guide which presents the calculation method as follows:

The formulation of M.V. BARTON, for a side plate a, leads to:

${f}_{i}=\frac{1}{2\pi {a}^{2}}{\lambda}_{i}^{2}\sqrt{\frac{E{t}^{2}}{12\rho (1-{\nu}^{2})}}$ $i=1,2,\mathrm{...}$

où: ${\lambda}_{i}^{2}=g(\alpha )$

with, for a Poisson's ratio $\nu =0.3$ and $\alpha =30°$:

|  | $\alpha =30°$ |
| --- | --- |
| ${\lambda}_{1}^{2}$ | 3.961 |
| ${\lambda}_{2}^{2}$ | 10.19 |

- M.V.Barton mentions the sensitivity of the result to the order of the mode and the $\alpha$ angle.
- This reference solution applies to thin plates such as: $t/a<0.1$ .
- ${\lambda}_{i}$ coefficients were established with insufficient limited development.

### 2.2 Baseline

The first two modes of their own given by:

### 2.3 Uncertainty about the solution

Semi-analytic solution $\text{< 2\%}$ .
