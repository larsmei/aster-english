# u3.13.13 Modelling 2D_FLUI_ABSO

**Summary:**

This document describes, for the modelling 2D_FLUI_ABSO:

- the degrees of freedom carried by the finite elements which support the modelling,
- the associated support mesh cells,
- the supported loadings,
- the non-linear capabilities,
- the test cases implementing the modelling.

The modelling 2D_FLUI_ABSO (Phenomenon: mechanics) corresponds to finite elements whose support mesh cells are line mesh cells. They make it possible to take into account the absorbing boundary condition of sections of fluid volumes, in plane motion.

## 1 Discretisation

### 1.1 Degrees of freedom

| **Modelling** | **Degrees of freedom (at each vertex node)** |
| --- | --- |

| 2D_FLUI_ABSO | PRES: pressure |
| --- | --- |
|  | PHI: fluid displacement potential |

### 1.2 Support mesh cell of the stiffness matrices

The support mesh cells of the finite elements are segments. The elements are isoparametric.

| **Modelling** | **Mesh cell** | **Interpolation** | **Notes** |
| --- | --- | --- | --- |

| 2D_FLUI_ABSO | SEG2 | linear |  |
| --- | --- | --- | --- |
|  | SEG3 | quadratic |  |

### 1.3 Support mesh cell of the loadings

The same as previously.

## 2 Supported loadings

No specific loading is supported by this modelling.

## 3 Non-linear capabilities

In the case of an analysis with the operator DYNA_NON_LINE, it is necessary to use the keyword RELATION='ELAS' as well as the keyword DEFORMATION='PETIT' defined under the keyword COMPORTEMENT.

## 4 Implementation example: test case

FDLV111B [V8.01.111](doc:v8.01.111): Analysis of the absorption of a pressure wave, created by a piston, in a fluid column.
