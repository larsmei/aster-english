# u4.13.04 Operator INFO_EXEC_ASTER

## 1 Purpose

Create a table containing information specific to the execution in progress, which can be consulted from the command file.

This command, intended to be extended, makes it possible for the moment to recover the time remaining and the first free logical-unit number. Recovering the time thus offers the possibility of stopping or of leaving a Python control structure conditionally.

## 2 Syntax

```text
table = INFO_EXEC_ASTER(
    ◆ LISTE_INFO = / "TEMPS_RESTANT",
                   / "UNITE_LIBRE",
                   / "ETAT_UNITE",
    # Si: is_in('LISTE_INFO', 'ETAT_UNITE')
        ◆ / UNITE = unit,
          / FICHIER = text,
    ◇ TITRE = text,
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand LISTE_INFO

```text
◊    LISTE_INFO =     ‘TEMPS_RESTANT’
```

Makes it possible to recover the time remaining during the execution: it is the difference between the maximum time allocated to the analysis and the value of the time already elapsed.

```text
◊    LISTE_INFO =     ‘UNITE_LIBRE’
```

Returns the first logical-unit number available (in decreasing order from 99) at the moment of the call. This value, recovered in a Python variable, can then be passed as an argument of an Aster command. The logical-unit numbers are managed from the command DEFI_FICHIER [U4.12.03](doc:u4.12.03) and are stored in a data structure internal to the code that links the files and the unit numbers.

```text
◊    LISTE_INFO =     ‘ETAT_UNITE’
```

Returns, according to the presence of the keyword UNITE or FICHIER, the state of the logical unit: free, reserved, or else the name of the associated file.

### 3.2 Operands UNITE/FICHIER

◊    UNITE

Number of the logical unit whose state one wishes to query

◊    FICHIER

Name of the file whose associated logical-unit number one wishes to obtain

### 3.3 Operand TITRE

```text
◊    TITRE = titre
```

Title assigned to the associated table data structure. For more details see [U4.03.01](doc:u4.03.01).

### 3.4 Operand INFO

◊    INFO = 1

Operand unused for the moment.

## 4 Example

# A loop from 1 to 10 is carried out

```text
for k in range(1,10):

#

# on appelle une ou plusieurs commandes (AFFE_CHAR_MECA, STAT_NON_LINE, etc.)

…

# on récupère le temps restant dans la table TAB

TAB=INFO_EXEC_ASTER(LISTE_INFO='TEMPS_RESTANT')

# on récupère la valeur du temps dans une variable python

valcpu=TAB['TEMPS_RESTANT',1]        # cette instruction nécessite
# d'être en mode PAR_LOT='NON'

# on teste cette variable python, s’il reste moins de 5 s, on sort de la boucle

if valcpu< 5.0:

break

# on détruit le concept de type table, pour pouvoir le récréer à l’itération suivante.

DETRUIRE(CONCEPT=(_F(NOM=TAB),))
```
