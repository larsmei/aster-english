# v6.03.305 SSNP305 - element compression bar - Appearing of a negative pivot

**Summary:**

This quasi-static linear 2D mechanical test consists of loading a compression element bar. D-on one side, the element is fixed according to the degrees of translation on an node. On the other side, the element is fixed according to the second degree of translation on an node in order to model the slide along a straight line. At a certain moment the stiffness becomes negative ( = negative slope). This test is taken from the NAFEMS (analytical solution) guide. The structure will be loaded using a displacement control.

The plate is modelled by 12 elements planes (MECPQU4). The material has linear behavior and is taken into account the non-geometric linearities. The key word factor COMPORTEMENT option GREEN is used.
