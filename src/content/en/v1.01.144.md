# v1.01.144 ZZZZ144 - Validation of LIAISON_SOLIDE and LIAISON_RBE3

**Summary:**

This test is valid for LIAISON_SOLIDE and LIAISON_RBE3 in HPC.

One cylinder, clamped, is modelled on one end, subjected to a pressure imposed, one part of which is rigidified by an LIAISON_SOLIDE. A torque is applied to the other end by means of a discrete connection to the body by an LIAISON_RBE3.

Many Lagrange multipliers are used to impose kinematic relationships.

The test case has 3 modellings:

- Modelling A: Classic parallelism, MUMPS solver
- Modelling B: hpc parallelism, MUMPS solver
- C Modelling: hpc parallelism, PETSC solver + LDLT_SP

The movement of the discrete is compared to the sequential result.

This documentation is deliberately succinct.
