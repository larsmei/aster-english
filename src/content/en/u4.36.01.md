# u4.36.01 Operator LIRE_INTE_SPEC

## 1 Purpose

To read complex functions from an external file in order to create an interspectral matrix.

The user file is coded in Ascii.

The functions read are of type fonction_C.

The concept produced is of type interspectre.

## 2 Syntax

```text
interspectre = LIRE_INTE_SPEC(
    ◆ UNITE = unit,
    ◇ FORMAT_C = / "REEL_IMAG",
                 / "MODULE_PHASE" (par défaut),
    ◇ FORMAT = / "ASTER" (par défaut),
               / "IDEAS",
    ◇ NOM_PARA = / "DX",
                 / "DY",
                 / "DZ",
                 / "DRX",
                 / "DRY",
                 / "DRZ",
                 / "TEMP",
                 / "INST",
                 / "X",
                 / "Y",
                 / "Z",
                 / "EPSI",
                 / "FREQ" (par défaut),
                 / "PULS",
                 / "AMOR",
                 / "ABSC",
    ◇ NOM_RESU = text (défaut: "DSP"),
    ◇ INTERPOL = / "LIN",
                 / "LOG",
    ◇ PROL_DROITE = / "CONSTANT",
                    / "LINEAIRE",
                    / "EXCLU",
    ◇ PROL_GAUCHE = / "CONSTANT",
                    / "LINEAIRE",
                    / "EXCLU",
    ◇ TITRE = text,
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand UNITE

```text
♦    UNITE= u
```

Logical unit number of the external file on which the reading is done.

### 3.2 Operand FORMAT

Defines the reading format:

- 'ASTER' by default,
- 'IDEAS' if one reads results obtained with IDEAS

### 3.3 Operand FORMAT_C

Defines the reading format for complex functions:

- 'MODULE_PHASE' by default,
- 'REEL_IMAG' real part and imaginary part.

### 3.4 Operand NOM_PARA

Defines the name of the parameter of the function (abscissa). By default one takes 'FREQ'.

### 3.5 Operand NOM_RESU

Defines the name of the result of the function (ordinate)

### 3.6 Operands PROL_DROITE / PROL_GAUCHE

```text
◊    PROL_DROITE=
```

Defines the extension of the function to the right of the domain of definition of the variable.

```text
◊    PROL_GAUCHE=
```

Defines the extension of the function to the left of the domain of definition of the variable:

| 'CONSTANT' |  |
| --- | --- |
| 'LINEAIRE' | for an extension along the first segment defined (PROL_GAUCHE) or the last segment defined (PROL_DROITE). |
| 'EXCLU' | if extrapolation of the values outside the domain of definition of the parameter is forbidden. |

### 3.7 Operand INTERPOL

```text
◊    INTERPOL=
```

- 'LOG' logarithmic interpolation between two values of the domain of definition.
- 'LIN' linear interpolation between two values of the domain of definition.

### 3.8 Operand INFO

```text
◊    INFO=
```

Specifies the printout options on the message file.

| 1 | printing of the attributes of the functions: number of definition points, names of the parameter and of the result, as well as the extension and checking options |
| --- | --- |
| 2 | like 1, plus the list of the first 10 values of each function in increasing order of the parameter |

For example:

- PROL_DROITE = 'CONSTANT', PROL_GAUCHE = 'CONSTANT'

## 4 Verification stage

Checking of the number of values read per function.

Checking of the number of functions read.

## 5 Notes on use

The functions associated with the interspectral matrix are accessible to the user by means of the command RECU_FONCTION [U4.32.03](doc:u4.32.03) using the keyword INTE_SPEC.

### 5.1 File syntax

The information read on the file is composed of three parts:

- a mandatory chapter-heading keyword: INTERSPECTRE.
- the keyword DIM, dimension of the matrix.
- 'n' sub-files defining 'n' complex functions. Each sub-file begins with the keyword FONCTION_C and ends with FINSF.
- the file must end with FIN.

### 5.2 Descriptor

#### 5.2.1 Keyword describing the characteristics of the matrix

```text
♦    DIM = dim
```

An integer makes it possible to define the dimension of the matrix.

**Note:**

*The sign '=' is mandatory.*

#### 5.2.2 Keyword describing a fonction_C

**Preliminary note:**

*'n', the number of functions to be defined, is equal to:*

*n = (dim*(dim+1))/2, since the matrix under consideration is 'HERMITIAN'.*

The n functions are defined by their indices I and J in the matrix. Only the upper triangular part of the matrix is defined, (indices (1,1); (1,2); (2,2); (1,3); ... (n,n)).

```text
♦    FONCTION_C
```

```text
♦    I = entier            indice ligne de la fonction dans la matrice.
```

```text
♦    J = entier            indice colonne de la fonction dans la matrice.
```

```text
♦    NB_POIN =    entier nombre de points de la FONCTION
```

```text
♦    VALEUR =        3*NB_POINréels doivent être présents. La lecture des valeurs s'effectue ligne à ligne.
```

On each line the following are defined, in the following order:

- the value of the parameter, the real part of the result, the imaginary part of the result (FORMAT= 'REEL_IMAG'),

or

- the value of the parameter, the modulus of the result, the phase of the result (FORMAT='MODULE_PHASE')

**Note:**

*For the format MODULE_PHASE, the phase is given in degrees.*
