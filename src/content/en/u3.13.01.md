# u3.13.01 Modellings AXIS, D_PLAN, C_PLAN

**Summary:**

The modellings AXIS, D_PLAN, C_PLAN (Phenomenon: mechanical) correspond to finite elements whose support mesh cells are surface mesh cells.

The modelling assumptions are the following:

- AXIS for axisymmetry (Fourier mode 0) about the Y axis,
- D_PLAN for the plane strains,
- C_PLAN for the plane stresses.

This document describes:

- the degrees of freedom carried by the finite elements which support the modelling,
- the related support mesh cells,
- the supported loadings,
- the non-linear possibilities,
- the test cases implementing the modellings.

## 1 Discretisation

### 1.1 Degrees of freedom

| **Modelling** | **Degrees of freedom** **(at each vertex node)** |
| --- | --- |
| AXIS | DX: corresponds to the radial displacement DY: corresponds to the longitudinal displacement |
| D_PLAN | DX: displacement along X DY: displacement along Y |
| C_PLAN | DX: displacement along X DY: displacement along Y |

### 1.2 Support mesh cell of the stiffness matrices

The support mesh cells of the finite elements may be triangles or quadrilaterals. The elements are isoparametric.

| **Modellings** | **Mesh cell** | **Interpolation** |
| --- | --- | --- |
| AXIS D_PLAN C_PLAN | TRIA3 QUAD4 TRIA6 TRIA10 QUAD8 QUAD9 QUAD12 | Linear Bi-linear Quadratic Serendipity Bi-quadratic Cubic |

### 1.3 Support mesh cell of the loadings

| **Modellings** | **Mesh cell** | **Interpolation** |
| --- | --- | --- |
| AXIS D_PLAN | SEG2 | Linear or |
| C_PLAN | SEG3 | Quadratic |

## 2 Supported loadings

The available loadings are the following:

- **CONTACT**

Makes it possible to define the zones subjected to contact conditions.

Supported modellings: AXIS, C_PLAN, D_PLAN

- **EPSI_INIT**

Makes it possible to apply an initial strain loading.

Supported modellings: AXIS, C_PLAN, D_PLAN

- **FORCE_CONTOUR**

Makes it possible to define linear forces on the edge of a domain.

Supported modellings: AXIS, C_PLAN, D_PLAN

- **FORCE_INTERNE**

Makes it possible to define body forces.

Supported modellings: AXIS, C_PLAN, D_PLAN

- **PESANTEUR**

Makes it possible to define the acceleration and the direction of gravity.

Supported modellings: AXIS, C_PLAN, D_PLAN

In axisymmetric modelling, gravity is applied only parallel to the axis of revolution Y.

- **PRES_REP**

Makes it possible to apply a pressure.

Supported modellings: AXIS, C_PLAN, D_PLAN

- **ROTATION**

Makes it possible to define a rotation speed and the direction of the rotation vector.

Supported modellings: AXIS, C_PLAN, D_PLAN
