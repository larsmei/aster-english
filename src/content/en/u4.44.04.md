# u4.44.04 Operator AFFE_CHAR_ACOU

## 1 Purpose

Assign constant acoustic boundary conditions. The assigned values do not depend on any parameter and are complex values.

Produces a data structure of type char_acou.

## 2 Syntax

```text
char_acou = AFFE_CHAR_ACOU(
    ◆ MODELE = modele,
    ◇ DOUBLE_LAGRANGE = "OUI",
    ◆ | PRES_IMPO = _F(
           ◆ | TOUT = "OUI" (ou non renseigné),
             | GROUP_MA = grma,
             | GROUP_NO = grno,
           ◇ SANS_GROUP_MA = grma,
           ◇ SANS_GROUP_NO = grno,
           ◆ PRES = complex,
        ),
      | VITE_FACE = _F(
           ◆ GROUP_MA = grma,
           ◆ / VNOR = complex,
        ),
      | LIAISON_UNIF = _F(
           ◆ / GROUP_NO = grno,
             / GROUP_MA = grma,
           ◆ DDL = "PRES" (ou non renseigné),
        ),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand MODELE

```text
♦    MODELE =    mo
```

Name of the model whose mesh supports the acoustic computational elements.

### 3.2 Operand DOUBLE_LAGRANGE

```text
◊    DOUBLE_LAGRANGE = ’OUI’/’NON’
```

This keyword makes it possible to state whether or not the user wishes to duplicate the Lagrange multipliers used to define and dualise the boundary conditions in the assembled matrix.

Concretely, duplicating the Lagrange multipliers makes it possible to use linear solvers which do not allow pivoting. Not duplicating the Lagrange multipliers makes it possible to reduce the number of degrees of freedom of the problem (and therefore the size of the problem to be solved), but its use is limited to the solvers MUMPS and Petsc.

### 3.3 Keywords PRES_IMPO

#### 3.3.1 Purpose

Factor keywords giving the nature of the conditions imposed on the specified entities (nodes or mesh cells).

```text
♦    |    PRES_IMPO
```

Makes it possible to impose the pressure degree of freedom.

```text
|    VITE_FACE
```

Makes it possible to specify the vibratory velocity field imposed as a loading on boundary elements.

#### 3.3.2 Operands TOUT / GROUP_NO / GROUP_MA / SANS_GROUP_NO / SANS_GROUP_MA

Declaration of the topological entities on which the loadings and boundary conditions are applied.

These are imposed on the nodes or mesh cells given by the keywords TOUT, GROUP_MA, GROUP_NO, while possibly excluding some by means of the keywords SANS_*.

Caution: the keywords SANS_* are available only for the keyword PRES_IMPO.

#### 3.3.3 Operands PRES / IMPE

```text
PRES = pre
```

Complex value of the acoustic pressure degree of freedom (the only degree of freedom in acoustic modelling) imposed on the specified nodes.

```text
IMPE = z
```

Complex value of the acoustic impedance imposed on the specified mesh cells.

### 3.4 Keyword LIAISON_UNIF

#### 3.4.1 Purpose

Factor keyword making it possible to impose one and the same (unknown) value on degrees of freedom of a set of nodes.

#### 3.4.2 Operands GROUP_MA / GROUP_NO

These operands make it possible to define a list of $n$ nodes ${N}_{i}$ from which redundancies have been eliminated (for GROUP_MA, these are the connectivities of the mesh cells).

#### 3.4.3 Keyword DDL

This operand can, in acoustic modelling, take only the text 'PRES', defining the only permitted degree of freedom, the acoustic pressure $p$.

The resulting imposed conditions are:

$p({N}_{1})=p({N}_{i})$ for $i\in \lbrace 2,\mathrm{...},n\rbrace$

## 4 Example

```text
cha = AFFE_CHAR_ACOU(    MODELE = mo ,
VITE_FACE = _F(    GROUP_MA = gm4 ,

VNOR = ( 'RI' , 0.0135 , 0. ) ) ,
)
```

**Note:**

*The complex values are supplied in one of the two forms* *RI (real part, imaginary part) or* *MP (modulus, phase in degrees).*
