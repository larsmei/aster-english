# v1.01.344 ZZZZ344 – Validation of the calculation of angular deviations in DEFI_CABLE_BP

**Summary:**

Calculation of the angular deviations in the DEFI_CABLE_BP operator is done using cubic spline interpolations. However, sometimes this method fails when the mesh is too irregular. In this case, an interpolation-free method is used for calculating angular deviations.

The objective of this test is to validate the calculation of angular deviations by this method. To this end, we compare the calculation of angular deviations by spline and without interpolation for the same geometry. The meshes for which spline interpolation fails are derived from different meshes of the Vercors enclosure. The mesh for which it is correct was created from the equation of the circle to be as close as possible to the other meshes.

## 1 Reference problem

A horizontal and circular cable is considered to be contained in concrete. The mesh of the concrete part is the same for each model. But the mesh of the cable changes.

**Model A:** the cable was built from the circle equation; it has 100 mesh cells of type SEG2. It is very regular, the spline interpolation is correct. This Modelling serves as a reference for the other two.

**Model B:** the cable (like concrete) is from a mesh from the Vercors enclosure. The discretization of the cable is identical to the model A(100 mesh cells).

**Model C:** the cable (like concrete) is from a finer mesh from the Vercors enclosure, it has 302 mesh cells.

## 6 Summary of the results

It is noted that on a sufficiently regular geometry, the results of the method without interpolation are very similar to those obtained with the method of interpolation by cubic spline. Moreover, as noted in note, the shift towards this method makes it possible to correct errors related to failure of interpolation by spline when the mesh is very irregular.
