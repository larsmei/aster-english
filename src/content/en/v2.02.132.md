# v2.02.132 SDLL132 - Eigenmodes of multifibre beam frame

**Summary:**

This test is for the validation of the MASS_INER option, as well as the calculation of the carpentry's eigenmodes when the model contains POU_D_TGM (modelling A) or POU_D_EM (modelling B) (multifibre beams). The results of the reference solution are obtained by doing the same study but with a model of POU_D_TG (modelling C) and POU_D_E (modelling D).

This test allows to validate, by doing a modal analysis of the structure:

- elements Linear Finishes of POU_D_TGM and POU_D_EM type.
- the results of the commands: POST_ELEM, NORM_MODE, EXTR_MODE.
- CALC_MODES results.
