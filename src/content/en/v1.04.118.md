# v1.04.118 PETSC03- Validation of the PETS c solver with a second level preconditioner

**Summary:**

This test case allows the GMRES_LMP algorithm to be validated. This algorithm is used to use the GMRES iterative solver with a first-level preconditioner (here LDLT_SP) and a second-level preconditioner, called the Limited Memory Conditioner. Reference documentation [R6.01.02](doc:r6.01.02) is referred to for more details on the second-level preconditioner, as well as the [U4.50.01](doc:u4.50.01) operating documentation.

The test is derived from the test case mumps02 described in the [V1.04.112](doc:v1.04.112) validation documentation. It has two modellingss, which can be used to check the correct functioning of the solver on 1 and 2 processors respectively.

## 1 Reference problem

### 1.1 Geometry

A rectangular plate of 100m length and 50m width is considered.

### 1.2 Material properties

$E=1.0\mathit{E2}N/{m}^{2}$

### 1.3 boundary conditions

We're imposing $\mathit{DX}=1,\mathit{DY}=2$ on the whole mesh

## 2 Solution

The reference quantity used is the displacement according to the x axis and the y axis to the node C.

## 3 Modelling A

Modelling D_PLAN_INCO_UPG

Number of nodes: $341$

Number of mesh cells: $140$ ($40$ SEG3 and $100$ QUAD8).

Modelling A uses the GMRES_LMP algorithm of the PETSC solver. The solver parameters are chosen to trigger the construction of the second level preconditioner (this is not an example to follow).

## 4 Modelling B

Model B is identical to model A, but the calculation is performed on 2 processors.

## 5 Summary of the results

This test case shows the GMRES_LMP algorithm of the PETSC solver on 1 and 2 processors.
