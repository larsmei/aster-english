# v3.01.009 SSLL09- 2-bar system with 3 ball bars

**Summary:**

The linear elasticity static test is used to validate straight beam elements POU_D_T.

This test case concerns a system of 2 rods with 3 ball.

Deflections and stress are tested by comparing simulation results with reference solution AFNOR (ref. [1]) and those obtained with Pipestress software.
