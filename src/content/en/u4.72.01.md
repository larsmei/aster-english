# u4.72.01 Operator COMB_MATR_ASSE

## 1 Purpose

Combine linearly, with real or complex coefficients, concepts of type matr_asse_* .

This operator also makes it possible to carry out linear combinations by considering only the real or imaginary part of a matrix with complex coefficients (extraction of the real or imaginary part of a matrix).

All the concepts of type matr_asse_* to be combined must share **the same numbering**, that is the two matrices will have been assembled by the operator ASSE_MATRICE with the same concept as argument of the keyword NUME_DDL (cf. [U4.61.11](doc:u4.61.11)).

Produces a data structure of type matr_asse_* .

## 2 Syntax

```text
/ matr_asse_depl_c
/ matr_asse_depl_r
/ matr_asse_gene_c
/ matr_asse_gene_r
/ matr_asse_pres_c
/ matr_asse_pres_r
/ matr_asse_temp_c
/ matr_asse_temp_r = COMB_MATR_ASSE(
    ◇ reuse = <objet de MATR_ASSE>,
    ◇ MATR_ASSE = matr_asse_depl_c / matr_asse_depl_r / matr_asse_gene_c / matr_asse_gene_r / matr_asse_pres_c / matr_asse_pres_r / matr_asse_temp_c / matr_asse_temp_r,
    ◆ / COMB_R = _F(
           ◇ PARTIE = / "IMAG",
                      / "REEL",
           ◆ MATR_ASSE = matr_asse_depl_c / matr_asse_depl_r / matr_asse_gene_c / matr_asse_gene_r / matr_asse_pres_c / matr_asse_pres_r / matr_asse_temp_c / matr_asse_temp_r,
           ◆ COEF_R = float,
        ),
      / COMB_C = _F(
           ◆ MATR_ASSE = matr_asse_depl_c / matr_asse_depl_r / matr_asse_gene_c / matr_asse_gene_r / matr_asse_pres_c / matr_asse_pres_r / matr_asse_temp_c / matr_asse_temp_r,
           ◆ / COEF_R = float,
             / COEF_C = complex,
        ),
      / CALC_AMOR_GENE = _F(
           ◆ RIGI_GENE = matr_asse_gene_r,
           ◆ MASS_GENE = matr_asse_gene_r,
           ◆ / AMOR_REDUIT = float,
             / LIST_AMOR = listr8,
        ),
    ◇ SANS_CMP = "LAGR" (ou non renseigné),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Keyword MATR_ASSE

```text
/    MATR_ASSE
```

It is possible to overwrite a matr_asse object with the result of the operation. In this case, it is mandatory to specify here which object is reused.

### 3.2 Keyword COMB_R

```text
/    COMB_R
```

Description of the terms of the linear combination producing a matrix with **real coefficients**.

#### 3.2.1 Operand PARTIE

```text
◊ PARTIE =    /    'REEL'    ,
/    'IMAG'    ,
```

To carry out extractions or linear combinations of imaginary or real part(s) of complex matrices.

#### 3.2.2 Operand MATR_ASSE

```text
♦    MATR_ASSE = m
```

Name of the concept matr_asse_* to be combined.

#### 3.2.3 Operand COEF_R

```text
♦    COEF_R = r
```

Real coefficient to be applied to the concept that is the argument of MATR_ASSE.

### 3.3 Keyword COMB_C

```text
/    COMB_C =
```

Description of the terms of the linear combination producing a matrix with **complex coefficients**.

#### 3.3.1 Reminder of the syntax of complex values

Complex values may be declared in two different ways:

- in the form $a+\mathrm{ib}$ with the syntax “RI,a, b” where a and b are real numbers,
- in the form $(\mathrm{module},\mathrm{phase})$ with “MPmod, ph” where mod and ph are real numbers

(ph in degrees).

#### 3.3.2 Operand MATR_ASSE

```text
♦    MATR_ASSE = m
```

Name of the concept matr_asse_* to be combined.

#### 3.3.3 Operands COEF_R/COEF_C

```text
♦    /    COEF_R = r
```

Real coefficient to be applied to the concept that is the argument of MATR_ASSE.

```text
/    COEF_C = c
```

Complex coefficient to be applied to the concept that is the argument of MATR_ASSE.

### 3.4 Keyword CALC_AMOR_GENE

This keyword makes it possible to build an object of type matr_asse_gene_R corresponding to the Basile damping matrix from a list of reduced damping ratios (keyword AMOR_REDUIT or LIST_AMOR).

MASS_GENE = masgen , RIGI_GENE = riggen,

masgen and riggen are the 2 generalised mass and stiffness matrices.

### 3.5 Operand SANS_CMP = 'LAGR'

This operand has the effect of setting to "zero" the terms of the resulting assembled matrix corresponding to the rows and the columns of the Lagrange degrees of freedom.

## 4 Examples of use

### 4.1 Classical linear combination

```text
mat_rs = COMB_MATR_ASSE(COMB_C =    (    _F(    MATR_ASSE = mat_1,
COEF_R = 1.),
_F(    MATR_ASSE= mat_2,
COEF_C= ('RI', 0.,1.,),)
,),)
```

The concept produced mat_rs is of type matr_asse_*_C (complex):

```text
mat_rs = mat_1 + i mat_2
```

### 4.2 Copy of a concept of type matr_asse_*_R

```text
mat_sauv = COMB_MATR_ASSE(    COMB_R = _F    (    MATR_ASSE = mat_1,
COEF_R = 1.))
```

### 4.3 Difference between COMB_C and COMB_R :

```text
mat_R = COMB_MATR_ASSE(    COMB_R = _F    (    MATR_ASSE = mat_1,
COEF_R = 1.))

#    mat_R        est à coefficients réels    mat_R =    mat_1

mat_C = COMB_MATR_ASSE(    COMB_C = _F    (    MATR_ASSE = mat_1,
COEF_R = 1.))

#    mat_C    est à coefficients complexes, mais la partie imaginaire est nulle        mat_C =    mat_1 + i. [:ref:`0 <0>`].
```

### 4.4 Extraction of the real part of a matrix of type matr_asse_*_C

```text
mat_R = COMB_MATR_ASSE    (    COMB_R = _F(    PARTIE = 'REEL',
MATR_ASSE = mat_C,
COEF_R = 1. , ),
)
```
