# v6.02.504 SSNL504 – Assembling skeleton element

**Summary:**

This test validates the element skeleton assembly described with multifibre beams.

A first calculation is made using a ten-beam mesh, where boundary conditions equivalent to the kinematic assembly is applied and a load is imposed while moving. This solution is considered as the reference one. Then, a second calculation is made where the element skeleton describing ten sub-meters comprising a guide tube assembly is used on a single mesh cell.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The reference solution is determined using a finite elements calculation where the ten beams are modelled using ten elements multifibre Euler beam. The forces in each beam are subsequently homogenized in the same way as the element as the assembly skeleton. Therefore, for the forces, we have:

> $N=\sum_{i=1}^{Np}{N}^{i}$ ${V}_{y}=\sum_{i=1}^{Np}{V}_{y}^{i}$ ${V}_{z}=\sum_{i=1}^{Np}{V}_{z}^{i}$

For the moments of beams:

> ${M}_{x}=\sum_{i=1}^{Np}{M}_{x}^{i}$     ${M}_{y}=\sum_{i=1}^{Np}{M}_{y}^{i}$     ${M}_{z}=\sum_{i=1}^{Np}{M}_{z}^{i}$

For grid moments:

> ${M}_{\mathit{gx}}=\sum_{i=1}^{Np}{F}_{z}^{i}{Y}^{i}-\sum_{i=1}^{Np}{F}_{y}^{i}{Z}^{i}$     ${M}_{\mathit{gy}}=\sum_{i=1}^{Np}{N}^{i}{Z}^{i}$     ${M}_{\mathit{gz}}=-\sum_{i=1}^{Np}{N}^{i}{Y}^{i}$

where Fx is the normal force, Vy and Vz respectively shear forces, Mx( MGx) the twist moment and My( MGy) and Mz( MGz) respectively the bending moments beams (grills). Np = 10 because modelling is done using ten beams.

### 2.2 Baseline

The reference result is given by the calculation of the beam beam with required kinematic assembly.

## 5 Modelling C

### 5.1 Modelling characteristics

> Loadings are gradually applied to the nodes end (X=1) of the model of
> Beam beam:

- step 1: loading of gravity
- not 2: thermal loading (mounting from 20 to 300°C)
- not 3: Irradiation loading (fluence 20 to 33.1024 neutrons/m2)

- not 4: load normal force beam Fx = 1e7N

- not 5: load beam shear force Fy = 1e7N
- step 6: load beam shear force Fz = 1e7N

- not 7: inversion loading beam normal effort Fx = - Fx

- step 8: inversion load beam shear force Fy = - Fy
- not 9: inversion load beam shear force Fz = - Fz

> The opposite end (X=0) is the object of a solid body condition allowing a coupling between the unit rotations of the beams and the generalized rotations of the whole (i.e. the rotations of the grid in the model d-element skeleton).
