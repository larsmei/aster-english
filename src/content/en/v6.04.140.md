# v6.04.140 SSNV140 - clamped cylindrical panel

**Summary:**

This test presents a quasi static calculation of clamped elastic cylindrical panel subjected to a given surfactic force either in the global reference or in the local reference. This force is constant in the first case and follows in the second case. This test tests the COQUE_3D Modelling, which is not geometrical, using the STAT_NON_LINE GROT_GDEP large rotation update algorithm, as well as the treatment of the following pressures for COQUE_3D modelling. The reference solution which is numerically obtained with SAMCEF software.

## 1 Reference problem

### 1.1 Geometry

Lengths are expressed in metres.

![Figure](/figures/v6.04.140/Object_1.svg)

The cylindrical panel is clamped along its 4 sides and subjected to a superfacial force.

- in the global benchmark for Modelling A:

$\mathrm{f}=-{f}_{z}{e}_{z};{f}_{z}>0$

- in the local modelling benchmark B:

$\mathrm{f}=-{f}_{z}n;{f}_{z}>0$

which leads to the membrane compression of the panel, accompanied by localized flexions. In the case of model B, $n$ is the normal one at the re-engineered geometry of the panel.

Due to the geometric and physical symmetry of the problem, only the ${P}_{1}{P}_{2}{P}_{3}{P}_{4}$ quarter of the panel is modelled, taking into account the symmetry conditions.

### 1.2 Material properties

Elastic behaviour:

$E=450000\mathit{MPa};\nu =0.3$

### 1.3 Boundary conditions and loads

| boundary conditions | $\mathrm{P2P3}$ : $\mathrm{DX}=0.$ | $\mathrm{DY}=0.$ | $\mathrm{DZ}=0.$ | $\mathrm{DRX}=0$ | $\mathrm{DRY}=0$ | $\mathrm{DRZ}=0$ |
| --- | --- | --- | --- | --- | --- | --- |
|  | $\mathrm{P3P4}$ : $\mathrm{DX}=0.$ | $\mathrm{DY}=0.$ | $\mathrm{DZ}=0.$ | $\mathrm{DRX}=0$ | $\mathrm{DRY}=0$ | $\mathrm{DRZ}=0$ |
|  |  |  |  |  |  |  |
| Symmetry: | $\mathrm{P1P2}$ : | $\mathrm{DY}=0.$ |  | $\mathrm{DRX}=0.$ |  | $\mathrm{DRZ}=0.$ |
|  | $\mathrm{P4P1}$ : $\mathrm{DX}=0.$ |  |  |  | $\mathrm{DRY}=0.$ | $\mathrm{DRZ}=0.$ |

The successive states of equilibrium under the load of the given superfacial force in the global reference are investigated:

${f}_{z}(t)=t$

$t$ being the pseudo time.

The only vertical component of the ${P}_{1}$ displacement is concerned.

## 5 Summary of the results

The problem data correspond to a thin $\frac{h}{L}=0.625\text{\%}$ hull which is severe for the finite element triangle MEC3TR7H (not presented here because there is a case of transverse shear blocking). The deformation is essentially membrane-like and the rotations remain moderate.

The reference solution obtained by SAMCEF software is digital and its mesh is twice as fine as the elements used here. Its elements model is finished based on a resultant effort approach with a rotational formulation [bib3]. The approach chosen in *Code_Aster* is 3D flat constraints with a total Lagrangian formulation [R3.07.04](doc:r3.07.04). The quality of the results obtained is good. the difference compared to this solution is less than 0.5% for vertical displacement of the central point.
