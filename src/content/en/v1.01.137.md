# v1.01.137 ZZZZ137 - AFFE_CHAR_MECA and AFFE_CHAR_THER Operators: validation of EVOL_CHAR, PRES_REP, FORCE_CONTOUR keywords

**Summary:**

The objective of this test case is to validate some keywords operators' AFFE_CHAR_MECA and AFFE_CHAR_THER.

## 1 Test principle

### 1.1 Mechanical:

- EVOL_CHAR: This keyword is used to apply evol_char-type, evolutionary loads produced by LIRE_RESU [U7.02.01](doc:u7.02.01) and containing pressure fields.
- PRES_REP: This keyword is used to apply pressure to a 2D or 3D continuous media domain, pressure to an COQUE_3D hull or shear to a 2D continuous media domain.
- FORCE_CONTOUR: This keyword is used to apply linear forces, on the edge of a domain of element 2D, defined component by component in the global benchmark. This contour is defined by one or more mesh cells or segment-type mesh cells groups.

The loads are applied to the top of a cylinder, blocked at its base and modeled in axisymmetric.

The solution is checked for good with MECA_STATIQUE, STAT_NON_LINE, DYNA_NON_LINE, THER_LINEAIRE and DYNA_VIBRA operators.

### 1.2 Thermal:

The objective is to validate the need expressed by the METRONOME project.

For fields corresponding to thermal exchange (T_EXT and COEF_H), it is valid that the calculation is possible with maps created by CREA_CHAMP or with fields by elements read in 'MED' format (LIRE_RESU), then projected to another mesh.
