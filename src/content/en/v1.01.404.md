# v1.01.404 PLEXU13 – Validation of sending a dynamic initial state by CALC_EUROPLEXUS

**Summary:**

In this purely computer test, the CALC_EUROPLEXUS to Europlexus sends a dynamic initial state, i.e. integrating the speed field. To this end, the results of a calculation run at one time (reference) are compared with a calculation run in two times. The final state of the first part of the calculation is the initial state of the second. The results of the second calculation are then checked to be identical to the results of the reference calculation.

This documentation is deliberately succinct.
