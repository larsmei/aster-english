# v3.01.100 SSLL100 - Symmetrical structure of beams with one elbow

**Summary:**

This static test, linear elasticity, validates elements straight beam in flat bending, as well as discrete elements. Four loads are defined, some of which are local reference.

The reference solution is derived from the POUX code validation folder (except for loading case 5 where it is non-regression). The results obtained with *Code_Aster* are fairly close to the reference, difference of the order of $\text{3\%}$.

## 3 Modelling B

### 3.1 Modelling characteristics

The beam arch was modelled into a polygonal line of $2\times 20$ SEG2.

Limit conditions:

> DDL_IMPO= _F(GROUP_NO=的Nd beam, DX= 0.0, DRY= 0.0, DRZ= 0.)

> _F(node=(‘A’,’G),        DX= 0.0, DY= 0.0, DZ= 0. )

except for loading 2

> (node=’A’,            DX= 0.0, DY= 1.0, DZ= 1.0)
> (node=’G’,            DX= 0.0, DY=-1.0, DZ= 1.0)

load case 1

> FORCE_NODALE=    _F(node=(‘C’,’D’), Fz = -1000.0)

load case 3: Loading temperature via AFFE_MATERIAU command

> AFFE_VARC=_F(    NOM_VARC=’TEMP’, VALE_REF=0., EVOL=TEMP,

> TOUT=’OUI’, NOM_CHAM=’TEMP’,),)

load case 4

> gravity=_F(    GRAVITE=9.81,

> DIRECTION=(0.,0.,-1.))

Name of nodes: $A,B,C,D,E,F$

### 3.2 Mesh characteristics
