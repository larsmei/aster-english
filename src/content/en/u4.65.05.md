# u4.65.05 Operator ASSE_VECT_GENE

## 1 Purpose

Project the loadings onto the modal basis of a substructure.

Within a harmonic analysis using the substructuring methods, the operator ASSE_VECT_GENE projects the loadings of type cham_no_DEPL_R coming from ASSE_VECTEUR [U4.61.23](doc:u4.61.23) onto the modal basis of the substructure defined by DEFI_BASE_MODALE [U4.64.02](doc:u4.64.02). The generalised vectors thus obtained are assembled from the definition of the generalised model coming from DEFI_MODELE_GENE [U4.65.02](doc:u4.65.02). The final assembled generalised vector is built on the numbering of the generalised degrees of freedom established beforehand by the operator NUME_DDL_GENE [U4.65.03](doc:u4.65.03).

The result concept produced by this operator is of type vect_asse_gene.

## 2 Syntax

```text
vect_asse_gene = ASSE_VECT_GENE(
    ◆ NUME_DDL_GENE = nume_ddl_gene,
    ◇ METHODE = / "CLASSIQUE" (par défaut),
                / "INITIAL",
    # Si: equal_to("METHODE", 'CLASSIQUE')
        ◆ CHAR_SOUS_STRUC = _F(
             ◆ SOUS_STRUC = text,
             ◆ VECT_ASSE = cham_no,
          ),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand NUME_DDL_GENE

```text
♦     NUME_DDL_GENE= nu_gene
```

Name of the nume_ddl_gene concept coming from the operator NUME_DDL_GENE [U4.65.03](doc:u4.65.03) which defines the numbering of the degrees of freedom to be used for the assembled generalised vector.

### 3.2 Operand METHODE

◊ METHODE= ‘CLASSIQUE’, ‘INITIAL’

Type of method used for the assembly of the matrices. The method ‘INITIAL’ makes it possible to initialise a null vector of type vect_asse_gene which one can fill by Python methods. This method was created for development.

### 3.3 Keyword CHAR_SOUS_STRUC

```text
♦    CHAR_SOUS_STRUC
```

Factor keyword making it possible to define the loadings applied to the structure. The definition of the loading is made by giving the assembled vector associated with it and the name of the substructure to which it applies.

#### 3.3.1 Operand SOUS_STRUC

```text
♦    SOUS_STRUC= ’nom_sstruc’
```

Name of the substructure to which the loading is applied. It must have been defined beforehand by the operator DEFI_MODELE_GENE [U4.65.02](doc:u4.65.02).

#### 3.3.2 Operand VECT_ASSE

```text
♦    VECT_ASSE= vecas
```

Name of the cham_no_DEPL_R concept coming from ASSE_VECTEUR [U4.61.23](doc:u4.61.23) which defines the spatial distribution of the loading applied to the substructure.
