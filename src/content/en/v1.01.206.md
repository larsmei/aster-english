# v1.01.206 ZZZZ206 - CREA_MAILLAGE Operator: QUAD_LINE keyword validation

**Summary:**

The objective of this test case is to validate the keyword QUAD_LINE operator. This keyword converts a quadratic mesh to a linear mesh. The conversions tested are as follows:

- 1D:

  - SEG3 to SEG2
- 2D:

  - TRIA6 to TRIA3
  - QUAD8 to QUAD4
  - QUAD9 to QUAD4
- 3D:

  - TETRA10 to TETRA4
  - PENTA15 to PENTA6
  - PYRAM13 to PYRAM5
  - HEXA20 to HEXA8
  - HEXA27 to HEXA8

To test the content of the results files, the TEST_FICHIER command is used which is based on a md5 control sum.

This documentation is deliberately succinct.
