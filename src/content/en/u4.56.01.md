# u4.56.01 Operator SECH_NON_LINE

## 1 Purpose

This operator makes it possible to solve (non-linear) drying problems by solving the heat equation in which the water concentration $C$ is treated as a temperature.
The thermal conductivity is in this case the diffusion coefficient, non-linear in $C$ and a function, possibly, of a temperature computed beforehand and supplied as a command variable.

The analysis can be initialised at the first time instant (factor keyword ETAT_INIT):

- by a constant water concentration,
- by a water-concentration field, defined beforehand, or extracted from a previous analysis,
- by a steady analysis.

The concept produced by the operator SECH_NON_LINE is of type evol_sech.

This operator broadly shares the syntax of the operator [THER_NON_LINE](doc:u4.54.02).

## 3 General parameters

```text
◆ MODELE = modele,
◆ CHAM_MATER = cham_mater,
◇ INFO = / 1,
        / 2,
◇ TITRE = text,
```

The general parameters describe the model and the material field.

### 3.1 Model

The keyword MODELE makes it possible to declare the model of the analysis, coming from the command [AFFE_MODELE](doc:u4.41.01)
which assigns modellings to elements of the mesh.
The only modellings allowed in SECH_NON_LINE are 3D_SECH, 3D_SECH_DIAG, AXIS_SECH and AXIS_SECH_DIAG.

### 3.2 Material field

The keyword CHAM_MATER makes it possible to declare the name of the material field assigned to the model.
The data structure comes from the command [AFFE_MATERIAU](doc:u4.43.01).
All the main mesh cells of the model must be associated with a material.

### 3.3 Title

The keyword TITRE makes it possible to give a title which one wants to give to the result, a data structure of type evol_sech [U4.03.01](doc:u4.03.01).

### 3.4 Management of verbosity

The keyword INFO makes it possible to produce various intermediate printouts in the message file.

## 4 Application of the loadings and of the boundary conditions

The factor keyword EXCIT makes it possible to define several loadings or boundary conditions. For each occurrence of the factor keyword, one defines CHARGE, possibly multiplied by a time function FONC_MULT.

The keyword CHARGE is a concept of type charge produced by [AFFE_CHAR_SECH](doc:u4.44.05).

**Note:**

For each occurrence of the factor keyword EXCIT the various char concepts used must be built on the same model.

The keyword FONC_MULT is a multiplicative coefficient which is a function of time (concept of type fonction, nappe or formule) applied to the load.

**Note:**

The concomitant use of FONC_MULT with a load containing temperature-dependent loadings (that is, for the loading of type FLUX_NL) is forbidden.

## 5 Non-linear constitutive behaviours

```text
◆ COMPORTEMENT = _F(
        ◆ RELATION = / "SECH_BAZANT",
                    / "SECH_GRANGER",
                    / "SECH_MENSI",
                    / "SECH_NAPPE",
                    / "SECH_RFT",
        ◆ / TOUT = "OUI" (ou non renseigné),
        / GROUP_MA = list[grma],
    ),
```

The drying constitutive behaviours are described by the repeatable and mandatory factor keyword COMPORTEMENT.
The keyword GROUP_MA specifies the mesh cells on which the constitutive relation is applied. In a manner analogous to mechanics, one can use several different drying laws, applied to complementary mesh-cell groups.

This factor keyword makes it possible to choose one of the drying models, defined by the expression of the diffusion coefficient.

### 5.1 Solution of the problem and description of the diffusion models

The solution of drying is characterised by:

$$
\frac{\partial C}{\partial t}
-
Div \left( D(C,T) \vector{\nabla} C \right)
=
0
$$

This is the non-linear heat equation in which the drying variable $C$ plays the role of the temperature. The choice of the constitutive relation makes it possible to define the diffusion coefficient $D(C,T)$ according to various forms usual in the literature.

In the general case, drying is solved after a preliminary thermal analysis (uncoupled but chained thermal/drying analysis). The temperature field, appearing as an auxiliary variable, is necessary in order to compute the diffusion coefficient of certain laws.
The temperature is therefore an input datum of the drying analysis, which must necessarily be given as a command variable for the laws 'SECH_GRANGER', 'SECH_NAPPE' and 'SECH_RFT', in [AFFE_MATERIAU](doc:u4.43.03).
The thermal data given in AFFE_MATERIAU may be fields or, as is most often the case, results obtained by an execution of a thermal operator, linear or not.

#### 5.1.1 Granger model

For RELATION='SECH_GRANGER', the Granger formulation of the diffusion coefficient is given by the expression:

$$
D(C,T)
=
A \exp( BC ) \frac{T}{{T}_{0}} \, \exp \left( \frac{{Q}_{s}}{R}\, \left(\frac{1}{T}-\frac{1}{{T}_{0}} \right) \right)
$$

One should refer to the documentation of the operator [DEFI_MATERIAU](doc:u4.43.01) for the meaning of the various parameters. In the case of the use of the law SECH_GRANGER, it is necessary to make sure of the consistency between the material used and the constitutive law: that is, that the keyword SECH_GRANGER has indeed been filled in in [DEFI_MATERIAU](doc:u4.43.01) for the material used.

#### 5.1.2 Mensi model

For RELATION='SECH_MENSI', one applies the solution of drying characterised by the Mensi law.

In the case of the use of this law SECH_MENSI, it is necessary to make sure of the consistency between the material used and the constitutive law: that is, that the keyword SECH_MENSI has indeed been filled in in [DEFI_MATERIAU](doc:u4.43.01) for the material used.

#### 5.1.3 Bazant model

For RELATION='SECH_BAZANT', one applies the solution of drying characterised by the Bazant law.

In the case of the use of this law SECH_BAZANT, it is necessary to make sure of the consistency between the material used and the constitutive law: that is, that the keyword SECH_BAZANT has indeed been filled in in [DEFI_MATERIAU](doc:u4.43.01) for the material used.

#### 5.1.4 General model

For RELATION='SECH_NAPPE', one applies the solution of drying with a diffusion coefficient defined by a nappe defined by the command [DEFI_NAPPE](doc:u4.31.03).

In the case of the use of this law, it is necessary to make sure of the consistency between the material used and the constitutive law: that is, that the keyword SECH_NAPPE has indeed been filled in in [DEFI_MATERIAU](doc:u4.43.01) for the material used.

#### 5.1.5 RFT model

For RELATION='SECH_RFT', one applies the solution of drying characterised by the RFT law (RICHARD_FICK_TEMPERATURE). The expression of the diffusion coefficient of this law is presented in [R7.01.12].

In the case of the use of this law SECH_RFT, it is necessary to make sure of the consistency between the material used and the constitutive law: the keywords SECH_RFT and BETON_DESORP must be filled in in [DEFI_MATERIAU](doc:u4.43.01) for the material used.

## 6 Restarts, archiving and management of the initial state

```text
◇ RESULTAT = evol_sech,
```

In the case where one wishes to continue an analysis already performed, the keyword RESULTAT indicates which
object is enriched.

### 6.1 Definition of an initial state

```text
◆ ETAT_INIT = _F(
        ◆ / STAT = "OUI" (ou non renseigné),
        / EVOL_SECH = evol_sech,
        / CHAM_NO = cham_no,
        / VALE = float,
        # Si: exists("EVOL_SECH")
            ◇ NUME_ORDRE = int,
            ◇ INST = float,
            # Si: exists("INST")
                ◇ CRITERE = / "ABSOLU",
                            / "RELATIF" (par défaut),
                # Si: (equal_to("CRITERE", 'RELATIF'))
                    ◇ PRECISION = float (défaut: 1e-06),
                # Si: (equal_to("CRITERE", 'ABSOLU'))
                    ◆ PRECISION = float,
    ),
```

The keyword ETAT_INIT makes it possible to define a reference initial state in the case of a transient analysis.
Unlike the mechanical case, this initial state is mandatory; there is no default value.

#### 6.1.1 Steady analysis

If STAT = "OUI", then the initial value of the water-concentration field is then the result of a preliminary steady analysis.
This is the default mode.

#### 6.1.2 Water-concentration or drying field

The keyword VALE makes it possible to define an initial value of the water concentration **constant** over the whole structure, whereas the keyword CHAM_NO defines it by a nodal field (result of the operator [CREA_CHAMP](doc:u4.72.04)) for example.

One can also use the initial water-concentration field by extraction from an evol_sech result given by the keyword EVOL_SECH.
One can then give the order number NUME_ORDRE or the time instant INST of the field to be extracted from this data structure. If NUME_ORDRE or INST are not filled in, one takes the last existing archived number in the evol_sech object.

**Note:**

Warning, this is the order number in the data structure read on restart by the preceding keyword EVOL_SECH. If this data structure was computed with a list of time instants different from that used under the factor keyword INCREMENT of the current solution, it is imperative to fill in NUME_INST_INIT under INCREMENT, the same order-number value corresponding to different physical time instants. In the case where the two lists of time instants are identical, one can dispense with filling in the same order number twice, under ETAT_INIT and under INCREMENT.

The keywords PRECISION and CRITERE make it possible to select the field finely from the value of the time instant given by INST. See [U4.71.00](doc:u4.71.00).

### 6.2 Archiving of the fields

The keyword ARCHIVAGE is optional: by default, the set of fields computed for all the computed steps is archived in the resultat concept produced by the command. It is used to store certain order numbers in a resultat data structure and/or to exclude certain fields from storage.

This keyword is identical to its equivalent for the operator [STAT_NON_LINE](doc:u4.51.03).

**Note:**

In the event of the analysis stopping for lack of CPU time, the previously computed time steps are saved in the database.

The command [CALC_CHAMP](doc:u4.81.04) makes it possible to compute the fluxes, at the integration points or at the nodes, from the nodal water-concentration field thus obtained by SECH_NON_LINE.
