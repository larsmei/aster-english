# v1.01.230 ZZZZ230 – Implementation of the "structural zoom" on a 2D problem

**Summary:**

This test case allows you to test the structural zoom:

- A first model represents a coarsely mesh square to which an effort is applied.
- The second model is a square that represents $1/4$ of the first model to which the displacements which were calculated with the first model are applied.

The movements of the two models are then compared to test the validity of the structural zoom.

## 1 Reference problem

![Figure](/figures/v1.01.230/10000000000003C0000002D027E30D4A6A3CCF75.png)

### 1.1 Geometry

The square is in $[0.,1.]\times [0.,1.]$ space.

Contact details of $(m)$ points:

$A:(0.,0.)$ $E:(0.5,0.)$

$B:(1.,0.)$ $F:(0.5,0.5)$

$C:(1.,1.)$ $G:(0.,0.5)$

$D:(0.,1.)$ $H:(0.25,0.25)$

Mesh cell groups:

- Surface $\mathrm{ABCD}$
- Surface $\mathrm{AEFG}$
- $\mathrm{AB}$ and $\mathrm{CD}$ segments

### 1.2 Material properties

$E=1.0\mathrm{E5}N/{m}^{2}$

$\nu =0.3$

### 1.3 Boundary conditions and loads

First $\mathrm{ABCD}$ model:

- Travel taxed:

$\mathrm{AB}$ : $\mathrm{DX}=\mathrm{DY}=0$

- Charges imposed:

$\mathrm{CD}$ : $\mathrm{FX}=1.\mathrm{E4}N$ et $\mathrm{FY}=2.\mathrm{E4}N$

Second $\mathrm{AEFG}$ (Zoom)

- Travel requirements:

Moves obtained with the first model, imposed on the $\mathrm{AEFG}$ edge of the second model.

## 2 reference solution

### 2.1 Reference quantities

The reference quantities used are the $\mathrm{DX}$ and $\mathrm{DY}$ moves of the point $H$ .

The calculations made on the first model serve as a reference for the second model.

### 2.2 Baseline

Travel to Point $H$:

- $\mathrm{DX}=1.116E-1m$
- $\mathrm{DY}=8.777E-2m$
