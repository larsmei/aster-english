# u4.81.23 Operator POST_COQUE

## 1 Purpose

Extract forces or strains on shell elements at a given time instant. These extractions take place on sets of points introduced by the user by their coordinates and their position through the thickness.

This command produces a table containing one line per post-processing point.

## 2 Syntax

```text
table = POST_COQUE(
    ◆ RESULTAT = resultat,
    ◆ CHAM = / "EFFORT",
             / "DEFORMATION",
    ◇ / NUME_ORDRE = int,
      / INST = float,
    ◆ COOR_POINT = _F(
         ◆ COOR = float,
      ),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand RESULTAT

```text
♦    RESULTAT = resu,
```

Name of a result concept of type evol_elas or evol_noli.

### 3.2 Operands NUME_ORDRE / INST

◊    / INST : time instant of the post-processing analysis

> / NUME_ORDRE : order number of the post-processed fields

If neither INST nor NUME_ORDRE is supplied, the field corresponding to the first computed time instant is processed by default.

### 3.3 Operand CHAM

### 3.4 ♦    CHAM    =    /'EFFORT'

> /'DEFORMATION'

'EFFORT': EFGE_ELNO field containing 8 components:

- the 3 membrane forces ${N}_{xx},{N}_{yy},{N}_{xy}$
- the 3 bending forces ${M}_{xx},{M}_{yy},{M}_{xy}$
- the 2 shear forces ${T}_{x},{T}_{y}$

'DEFORMATION': field containing the 6 components of the strain tensor.

The strains through the thickness are computed from the generalised strains of the mid-surface DEGE_ELNO $({e}_{xx},{e}_{yy},{e}_{xy},{\kappa}_{xx},{\kappa}_{yy},{\kappa}_{xy},{\gamma}_{x},{\gamma}_{y})$ where:

- $({e}_{xx},{e}_{yy},{e}_{xy})$ denote the membrane strains,
- $({\kappa}_{xx},{\kappa}_{yy},{\kappa}_{xy})$ denote the bending strains,
- $({\gamma}_{x},{\gamma}_{y})$ denote the strains associated with transverse shear.

The strains through the thickness (3D tensor) are obtained by the formulae:

- ${\epsilon}_{xx}={e}_{xx}+h{\kappa}_{xx}$
- ${\epsilon}_{yy}={e}_{yy}+h{\kappa}_{yy}$
- ${\epsilon}_{xy}={e}_{xy}+h{\kappa}_{xy}$
- $2{\epsilon}_{xz}={\gamma}_{x}$
- $2{\epsilon}_{yz}={\gamma}_{y}$

### 3.5 Factor keyword COOR_POINT

```text
♦    COOR_POINT    =    _F    (
```

#### 3.5.1 Operand COOR

> ♦    COOR=(x, y, z, h,)

> $x,y,z$ : coordinates of the point, located on the neutral fibre
> $h$ : position of the point through the thickness of the shell

> ($-e/2\le h\le +e/2$ , where $e$ is the thickness)

If CHAM = 'EFFORT', $h$ is ignored, the forces being computed by integration of the stresses through the thickness. If the user enters a non-zero $h$, an alarm message is issued to indicate that it is not taken into account.

## 4 Example

### 4.1 Data

> tab = POST_COQUE (RESULTAT=resu, CHAM='EFFORT',

> INST=0.5,
> COOR_POINT=(_F(COOR=(.5,.5,0.,),),

> _F(COOR=(.4,.4,0.,),),
> _F(COOR=(.3,.3,0.,),),
> _F(COOR=(.2,.2,0.,),),
> _F(COOR=(.1,.1,0.,),),
> ))

> IMPR_TABLE(TABLE=tab)
