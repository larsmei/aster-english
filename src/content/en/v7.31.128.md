# v7.31.128 WTNV128 - Undrained triaxial test with Hoek-Brown model modified to actual stresses

**Summary**

This test validates the elasto-plastic constitutive law from Hoek-Brown modified to actual stresses, i.e. HOEK_BROWN_EFF with hydraulic coupling. It is a triaxial test in undrained condition. Undrained aspect is modelled by a zero volume deformation of the skeleton and the hydraulic coupling is taken into account. The sample is fully saturated, the skeleton and fluid being assumed to be incompressible.

For symmetry reasons, only one of the eighth samples tested is considered.

The containment level applied is $5\mathit{MPa}$ .

This is a non-regression test.

Modelling A is a 3D_HM model with integration at Gauss points.

Model B is a 3D_HMS model with integration at Gauss points or nodes (see [R7.01.10](doc:r7.01.10) doc).

## 4 Summary of the results

This test case is a non-regression test developed to validate the Hoek-Brown model modified to actual stresses, HOEK_BROWN_EFF, with hydraulic coupling.

The same results are obtained with both modellings 3D_HM or 3D_HMS.
