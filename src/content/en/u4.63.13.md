# u4.63.13 Operator PROJ_VECT_BASE

## 1 Purpose

Project an assembled vector onto a basis of mechanical eigenmodes or a Ritz basis. The projected vector may be used by the analysis algorithms in generalised components.

One may use PROJ_BASE [U4.63.11](doc:u4.63.11) for these projections.

Produces a concept of type vect_asse_gene.

## 2 Syntax

```text
vect_asse_gene = PROJ_VECT_BASE(
    ◆ BASE = mode_gene / mode_meca,
    ◆ NUME_DDL_GENE = nume_ddl_gene,
    ◆ TYPE_VECT = / "FORC",
                  / "DEPL",
                  / "VITE",
                  / "ACCE",
    ◆ / VECT_ASSE = cham_no,
      / VECT_ASSE_GENE = vect_asse_gene,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand BASE

```text
♦    BASE= ba
```

Concept of type mode_meca or mode_gene for substructuring which contains the vectors defining the projection subspace.

### 3.2 Operand NUME_DDL_GENE

```text
♦    NUME_DDL_GENE = nu_gene
```

Numbering associated with the generalised model.

### 3.3 Operands VECT_ASSE / VECT_ASSE_GENE

```text
♦    /    VECT_ASSE= va
```

Concept of type cham_no_DEPL_R , assembled vector that one wishes to project.

```text
/    VECT_ASSE_GENE = va
```

Concept of type vect_asse_gene, assembled vector coming from substructuring, that one wishes to project.

### 3.4 Operand TYPE_VECT

```text
♦        TYPE_VECT    =    /'FORC',
/'DEPL',
/'VITE',
/'ACCE',
```

Character string describing the type of the field represented by the assembled vector. The available values are 'FORC', 'DEPL', 'VITE' and 'ACCE'. The processing differs according to whether one uses the option FORC or the others.

- With the option FORC, one carries out the simple projection ${\Phi}^{T}f$ , where $\Phi$ is the modal basis and $f$ the force.
- With the other options, one computes by an inverse problem the modal participation coefficients associated with a given displacement. One assumes that the displacement $x$ can be written in the form $x={\eta}^{T}\Phi$ . One then computes $\eta ={\Phi}^{T}{({\Phi}^{T}\Phi )}^{-1}x$ (use of the Moore-Penrose pseudo-inverse).
