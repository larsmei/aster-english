# v1.01.399 ZZZZ399 – Frequency of a quantum harmonic oscillator to one dimension

**Summary:**

The objective of this test is to calculate the frequencies of a quantum harmonic oscillator 1
one dimension, for the stationary solution.

[https://fr.wikipedia.org/wiki/Oscillateur_harmonique_quantique](https://fr.wikipedia.org/wiki/Oscillateur_harmonique_quantique)

## 1 Reference problem

### 1.1 Geometry

The problem, while one-dimensional, is modelled in two dimensions (there is currently no 1D Modelling for Code_Aster thermic).

For reasons of scale, the Atomic Units System 2 is used.

[https://fr.wikipedia.org/wiki/Syst%C3%A8me_d%27unit%C3%A9s_atomiques](https://fr.wikipedia.org/wiki/Système_d%27unités_atomiques)
.

A $L=10,0{a}_{0}$ length and $L/100{a}_{0}$ thickness band, centred at the origin of the axes, are considered to represent space.

![Figure](/figures/v1.01.399/100000000000047B000001293BBE83B1C661A570.png)

A charged particle (in this case, an electron), subject to a potential, can assume only specific energy values, which can be obtained by resolution of the Schroedinger equation:

$-\frac{{\hslash }^{2}}{\mathrm{2m}}\frac{{d}^{2}}{{\mathit{dx}}^{2}}{\psi}_{n}(x)+\frac{1}{2}{\mathit{kx}}^{2}{\psi}_{n}(x)={E}_{n}{\psi}_{n}(x)$

$n=0,1,\cdots$

$\omega =\sqrt{\frac{k}{m}}$

This is a problem with its own functions.

[https://fr.wikipedia.org/wiki/Fonction_propre](https://fr.wikipedia.org/wiki/Fonction_propre)
: you must find the values ${E}_{n}$ (autovalues).

The equation is diffusion-like (in analogy to the calculation of thermal equilibrium), the resolution of the functions of the individual will be done by a modal calculation.

### 1.2 Materials

The test uses two materials: one for the resolution of the diffusion equation ( $\lambda =1,{\rho}_{\mathit{cp}}=1$ ) and the other for the potential, with ${\rho}_{\mathit{cp}}$ variable depending on a value of a field, calculated with the potential formula.

### 1.3 boundary conditions

The zero value is imposed on the domain's extremes. There is no real need for this condition, which is set to test this data set as well but which can be removed without modification.

### 1.4 Initial conditions

None.

None

None

## 2 reference solution

An exact solution is known for this problem:

$$
{E}_{n}=(n+\frac{1}{2})\hslash \omega
$$
