# v3.03.147 SSLS147 - Shafting of a twisted ribbon

**Summary:**

This test, originally proposed by MacNeal and Harder [1] for beams and then enriched by Simo [2] for thin shells, allows to evaluate the effect of the spin on the performance of a element hull.

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v3.03.147/10000201000003170000024311AD39A25549A5A5.png)

The beam has the following dimensions:

- length $l=12\mathit{inches}$
- width $w=1,1\mathit{inches}$
- thickness $t=0,05\mathit{inches}$

There is a 90° twist between the beginning of the beam (clamped) and the free end.

### 1.2 Material properties

The elastic properties of the material under consideration (steel) are as follows:

- Young's modulus : $E=29\times {10}^{6}psi$
- Poisson's ratio: $\nu =0.22$

### 1.3 Boundary conditions and loads

Small face ($w\times t$ ) clamped ($u=v=w=0$ )

Loadings: Two load cases on the node in the middle of the other small face

| Loading by width | ${F}_{z}=–0,5\mathit{lbf}$ |
| --- | --- |
| Loading according to thickness | ${F}_{x}=+0,5\mathit{lbf}$ |

## 2 reference solution

### 2.1 Baseline

Move points where nodal forces are applied.

Loading case 1, $\mathit{DZ}=-1,387\mathit{inches}$ and loading case 2, $\mathit{DX}=0,343\mathit{inches}$ .

### 2.2 Uncertainty about the solution

Non-regression solution on element MIXED in [bib2]

### 2.3 Bibliographical references

[1] R.H. MacNeal and R.L. Harder, *A proposed standard set of problems to test finished element accuracy* , in: Proceedings of AIAA Conference on Structures and Structural Dynamics, Palm Springs, CA, 1984.

[2] Simo JC, Fox DD, Rifai MS. *We have stress resulting geometrically exact shell model Part 2: the linear theory, computational aspects* . Computer Methods in Applied Mechanics and Engineering 1989; 73:53–92.
