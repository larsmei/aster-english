# v1.01.394 ZZZZ394 – PRE_EPSI Check

**Summary:**

This test has no physical meaning, it is essentially a computer test.

It aims to validate PRE_EPSI loading for 3 possible types of assignments:

- by direct assignment under keyword PRE_EPSI (via EPXX, EPYY, ...)
- creating a card via CREA_CHAMP, taken into account via keyword EPSI from PRE_ESPI
- by providing a deformation field from another calculation (via EPSI also)

The principle is the following, a PRE_EPSI load is applied to an mesh cell whose only rigid body movements are blocked. The deformation field (EPSI_ELGA or DEGE_ELGA) is then calculated and the values are verified as being the ones provided (for several Gauss components and points).

**Model A:**

Element DKT. Assignment by a map and field to Gauss points

**Model B:**

A element DKTG. Direct assignment

**Modelling** C **:**

A 3D element. Field assignment to Gauss points

This documentation is deliberately succinct.
