# v2.03.504 SDLS504 - Side flame of a beam (overturn)

**Summary:**

This test represents a stability calculation of a console beam (IPE) subjected to bending force at one end. The critical load leading to elastic flaming by spill is calculated. The geometric rigidity matrix used in solving the problem to the specific values is that due to the initial stresses.

This test validates the elements COQUE_3D (TRIA7 and QUAD9) and 3D (HEXA8) Modelling in the linear flashing domain d-Euler.

Modellings A and B are made with COQUE_3D and modellings C, D, E, and F are made with the element 3D.

Modelling C uses, like modellings A and B, the CALC_MODE operator to get the flash mode.

Modellings D and E use the STAT_NON_LINE operator to get the flashing modes.

Modelling F uses piloting and incorporates a small disturbance in the loads to direct the solution to the flaming mode.

The critical load and associated eigenmode are compared to an analytical reference solution.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The calculation of the critical spill load is given in detail in [bib1].

| ${P}_{\mathrm{cr}}={\gamma}_{2}\frac{\sqrt{E{I}_{y}C}}{{L}^{2}}$ | critical discharge load |
| --- | --- |
| with $C=\mathrm{GJ}$ | rigidity at twisting |
| $J=((b-2{h}_{1}){h}_{2}^{3}+2a{h}_{1}^{3})$ | torsion constant [bib2] |
| ${C}_{1}E{I}_{y}\frac{{b}^{2}}{2}$ | rigidity at the spindle corresponding to an I beam |

## 7 Modelling E

### 7.1 Modelling characteristics

The mesh used is the same as the Modelling C.
This model uses STAT_NON_LINE/CRIT_STAB to calculate the flaming modes (TYPE = 'FLAMBEMENT') and to analyse the instability (TYPE = 'STABILITE').
In this Modelling, the GDEF_LOG formulation is used.

### 7.2 Mesh characteristics

Number of nodes: 4471

Number of mesh cells and types: 2240 HEXA8

### 7.3 Tested quantities and results

In large GDEF_LOG deformations, Code_Aster does not separate the hardware and geometrical matrices, and does not directly return the critical load.
The critical load is between the two moments when the CHAR_CRIT value changes sign. For this problem, the CRIT_STAB sign changes between the 0.84 and 0.85 moments. The critical load is therefore between 120 000*0.84=100800 N and 120000*0.85=102000 N. This value is close to the reference value 104 797.82 N.

For the value of CHAR_STAB that indicates the stability of the solution, non-regression tests are included.

## 9 Summary of the results

For modellings A-D, two similar but significant critical loads are obtained. The associated discharge modes are identical. The negative critical loads correspond to the load applied while the positive critical loads correspond to the reverse load. If we ignore the load sign, the two critical loads actually exist.

Critical loads for the applied load are correct. The errors obtained do not exceed:

- $\text{3\%}$ for COQUE_3D Modelling with mesh cells TRIA7,
- $\text{7\%}$ for COQUE_3D Modelling with mesh cells QUAD9.
- $\text{8.1\%}$ for 3D Modelling with mesh cells HEXA8.

COQUE_3D Modelling with mesh cells TRIA7 is more accurate than COQUE_3D Modelling with mesh cells QUAD9.

This test tested COQUE_3D (A and B with biquadratic mesh) and 3D (C and D with linear mesh) linearly flaming d-Euler.

Modelling E has tested 3D Modelling in flame-throwing with STAT_NON_LINE in large deformations (GDEF_LOG). Modelling F tests the steering function that allows the solution to be directed towards flaming.
