# u4.42.02 Macro-command MACR_CARA_POUTRE

This macro-command makes it possible to compute the characteristics of a beam cross-section from a 2D mesh of its cross-section.

It makes it possible to build a table of values, usable by the command AFFE_CARA_ELEM [U4.42.01](doc:u4.42.01) in order to assign straight-section characteristics to all the beam finite elements (modellings POU_D_E, POU_D_T, POU_D_TG, pou_d_em, pou_d_tgm) or bar finite elements (modelling BARRE) of arbitrary section.

The necessary characteristics are defined in the reference note [R3.08.03](doc:r3.08.03). They are:

- the geometric characteristics, which can be computed on a complete mesh, a half-mesh with symmetry with respect to $Y$ or to $Z$, a quarter-mesh with two symmetries with respect to $Y$ and to $Z$.
- the torsion characteristics: torsion radius, torsional stiffness constant, position and eccentricity of the centre of torsion for bending–torsion coupling.
- the shear characteristics for the models with shear-force strains.
- the warping characteristics for the torsion models of non-symmetric open sections.

The macro-command produces a concept of type `table_sdaster` containing the characteristics of the section. The values contained in this table can be used, via Python, in the command AFFE_CARA_ELEM [U4.42.01](doc:u4.42.01) for an analysis of beam type, or by supplying the table produced in AFFE_CARA_ELEM [U4.42.01](doc:u4.42.01) via the keyword `table_cara`.

## 2 Operands

### 2.1 Operand MAILLAGE

Name of the 2D mesh of the beam section whose characteristics one is going to compute. If the name of the mesh is not given, the following keywords must be supplied so that the macro-command carries out the reading by the command [LIRE_MAILLAGE](doc:u4.21.01).

Note: When the section is made up of elements of small thickness (tubes, built-up sections, ...), it is necessary to have several mesh cells through this thickness in order to compute correctly the characteristics linked to torsion.

### 2.2 Operands UNITE and FORMAT

If MAILLAGE is not present, one must give the logical unit for reading the file as well as its format.
Logical unit number for reading the 2D mesh of the beam section whose characteristics one is going to compute.

Note: If one must make several calls to MACR_CARA_POUTRE in the same command file, on the same mesh or on different meshes, one must then change UNITE.

### 2.3 Operand TABLE_CARA

When this option is present, the table produced contains only the parameters useful to [AFFE_CARA_ELEM](doc:u4.42.01).

### 2.4 Operand NOM

The operand NOM must be given (except if TABLE_CARA=’OUI’ and GROUP_MA is specified, because it is useless in that case).
This value is found in the column LIEU of the table. This allows the user to give a name to the section, which can be used in [AFFE_CARA_ELEM](doc:u4.42.01).

Note: If `GROUP_MA` is specified (and TABLE_CARA=’OUI’), the names of the mesh-cell groups can be used directly in [AFFE_CARA_ELEM](doc:u4.42.01).

### 2.5 Operands SYME_Y / SYME_Z

If SYME_Y: Indicates that the mesh corresponds to a half-mesh. The computation of the characteristics of the cross-section takes account of a symmetry with respect to $Y\mathrm{=}0$ .

If SYME_Z: Indicates that the mesh corresponds to a half-mesh. The computation of the characteristics of the cross-section takes account of a symmetry with respect to $Z\mathrm{=}0$ .

The simultaneous use of the two options makes it possible to supply only a quarter of the mesh. The symmetry properties are used to speed up the computation of the geometric characteristics.

**Note:**

The keywords SYME_Y and SYME_Z are used only for the computation of the geometric characteristics. The mechanical characteristics (torsion constant, warping constant, shear coefficients) do not take them into account. In order to compute them, one must therefore mesh the section in full. This is why SYME_Y and SYME_Z cannot be specified when GROUP_MA_BORD is used.

### 2.6 Operand QUADRANT

Makes it possible to define the quadrant in which one wants to obtain the mechanical characteristics linked to the principal inertia frame, and therefore linked to the definition of the angle $\alpha$.
The quantities concerned are: ALPHA, IY, IZ, EY, EZ, AY, AZ, IYR2, IZR2.

If QUADRANT is not given, no modification is carried out. When QUADRANT is [1, 2, 3, 4], the change of quadrant consists of a permutation of the quantities, with a change of sign if necessary.

## 3 Definition of the quantities produced

### 3.1 Frame of the structural element

Figure u4.42.02-fig-repere_element_poutre indicates the frame linked to the structural element. The axis $X$ represents the neutral axis of the structural element. The mechanical characteristics must be given in the principal axes of the cross-section [R3.08.01](doc:r3.08.01) of the element: ${Y}_{principal}$ and ${Z}_{principal}$.

![Figure](/figures/u4.42.02/repere_element_poutre.png)

*: Frame of the structural element*

### 3.2 Frames used for the geometric characteristics

Two frames are used:

- the frame $OYZ$ of description of the 2D mesh;
- the principal inertia frame $Gyz$ of the cross-section, whose naming corresponds to that used in the description of the beam elements of neutral fibre $Gx$ [AFFE_CARA_ELEM](doc:u4.42.01).

**Note:**

The mesh which is input to the command is in 2D and must therefore be given in the axes $oxy$. The coordinates $z$ must all be identical. The command MACR_CARA_POUTRE makes the correspondence between the axes $x$ and $Y$, $y$ and $Z$.

![Figure](/figures/u4.42.02/definition_grandeur.png)

*: Definition of the geometric quantities relating to a beam section.*

### 3.3 Quantities available in the table produced

#### 3.3.1 Geometric characteristics

These characteristics are given in the table for the whole mesh and for each group of the list **lgm**, which may correspond to a half or a quarter of the section if the keywords SYME_Y or SYME_Z are present.

##### 3.3.1.1 Characteristics of the mesh read

- area: A_M
- position of the centre of gravity: CDG_Y_M,CDG_Z_M
- area moments of inertia, at the centre of gravity $G$ in the frame $GYZ$: IY_G_M, IZ_G_M, IYZ_G_M

##### 3.3.1.2 Characteristics of the beam section

- area: A.
- position of the centre of gravity: CDG_Y,CDG_Z.
- area moments and product of inertia, at the centre of gravity $G$ in the frame $GYZ$: IY_G, IZ_G, IYZ_G.
- principal area moments of inertia in the frame $Gyz$, usable for the computation of the bending stiffness of the beam: IY and IZ.
- ALPHA: angle of passage from the frame $GYZ$ to the principal inertia frame $Gyz$.
- characteristic distances, with respect to the centre of gravity $G$ of the section, for the computations of maximum stresses: Y_MAX, Y_MIN, Z_MAX, Z_MIN and R_MAX.
- RY and RZ: maximum of Y_MIN and Y_MAX and of Z_MIN and Z_MAX.
- Y_P, Z_P: point of computation of the geometric moments of inertia.
- IY_P, IZ_P, IYZ_P: geometric moments of inertia in the frame $PYZ$.
- IY_P, IZ_P: moments of inertia in the frame $Pyz$ .
- IYR2_G, IZR2_G, IYR2, IZR2, IXR2_P, IYR2_P: characteristics useful for the geometric stiffness matrix of the elements POU_D_TG and POU_D_TGM. For more detail on the definition of the quantities see [R3.08.04](doc:r3.08.04):
  ${I}_{yr}^{2} = \int_{S} y \left(y^2+z^2 \right) dS$
  ${I}_{zr}^{2} = \int_{S} z \left(y^2+z^2 \right) dS$

#### 3.3.2 “Mechanical” characteristics

These characteristics are supplied in the table for the whole mesh and for each mesh-cell group of the list **lgm**.

##### 3.3.2.1 Torsion characteristics

- torsion constant: JX

The solution of a steady thermal problem of unknown $\varphi$ makes it possible to determine the torsion constant and the shear stresses.

**Note:**

When the section is made up of elements of small thickness (tubes, built-up sections, ...), it is necessary to have several mesh cells through this thickness in order to compute correctly the characteristics linked to torsion.
The torsion characteristics are obtained by the solution of $\Delta \varphi$ on the section; the mesh must therefore make it possible to solve this equation.
It is necessary to have more than three linear mesh cells or two quadratic mesh cells through the thickness in order to solve $\Delta \varphi$ correctly. If there is doubt about the value found, it is possible to obtain an approximate value by applying the formula given in [bib1]_ (page 200, table 3.6.5).

- torsion radius: RT

The torsion radius $Rt$ may vary along the external contour. Indeed, for an arbitrary section, the shears due to torsion vary on the edge. One chooses to take the value of $Rt$ leading to the maximum shears on the external edge, that is to say the maximum value of $Rt$ (in absolute value) on the external contour. Moreover, if the section is cellular, one has several “several torsion radii”: $Rt = 2 A(k)/L(k)$, where $A(k)$ represents the area of cell $k$ and $L(k)$ its perimeter.
If one is content to look for the maximum value of the shear, one must take the maximum of the values $Rt$ obtained on the external edge and on the cells.

- Position of the centre of torsion (point $C$ ) in the frame GYZ: PCTY and PCTZ. One deduces from it the eccentricity of the centre of torsion $CG$ in the principal inertia frame Gyz: EY and EZ.
- Position of the centre of torsion (point $C$ ) in the frame of the initial mesh: PCT_M_Y and PCT_M_Z.
- Warping constant (usable for the modellings POU_D_TG and POU_D_TGM with 7 degrees of freedom): JG.

##### 3.3.2.2 Shear characteristics

The coefficients ${A}_{y}$ and ${A}_{z}$ are given, in the principal inertia frame $Gyz$, in the form of the ratio $>1$ of the total area to the area effectively sheared.

### 3.4 Assignment of the quantities in AFFE_CARA_ELEM

The characteristics contained in this table and which can be used in [AFFE_CARA_ELEM](doc:u4.42.01) have the same names as the characteristics expected under the keyword CARA of the command [AFFE_CARA_ELEM](doc:u4.42.01).

The results computed by MACR_CARA_POUTRE can be transmitted simply to [AFFE_CARA_ELEM](doc:u4.42.01) via the keyword TABLE_CARA.
