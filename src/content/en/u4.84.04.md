# u4.84.04 Operator POST_DYNA_ALEA

## 1 Purpose

POST_DYNA_ALEA makes it possible to carry out two types of post-processing after a stochastic dynamics analysis:

**Analysis of fragility curves from a table containing the results of a Monte Carlo simulation**

From a table [table_sdaster] containing the information on the excitation levels (in a seismic analysis, the PGA is generally chosen) and the variable of interest characterising whether or not the structure fails, POST_DYNA_ALEA makes it possible to determine the parameters of a fragility curve according to the log-normal model and to compute values of this curve. The reader may consult [U2.08.05] for a more detailed description.

**Statistical post-processing of results of type interspectre.**

POST_DYNA_ALEA makes it possible, on functions selected in a concept of type [interspectre], to compute statistical parameters: spectral moments, standard deviation, peak distribution, central frequency.

The cross-spectral matrix may be obtained by various operators: lire_inte_spec [U4.36.01](doc:u4.36.01), calc_inte_spec [U4.36.03](doc:u4.36.03), defi_inte_spec [U4.36.02](doc:u4.36.02), dyna_alea_modal [U4.53.22](doc:u4.53.22), DYNA_SPEC_MODAL [U4.53.23](doc:u4.53.23) or REST_SPEC_PHYS [U4.63.22](doc:u4.63.22). One should refer to [R7.10.01](doc:r7.10.01) for the description of the processing carried out.

This operator produces a table of type table_sdaster which can be printed by IMPR_TABLE [U4.91.03](doc:u4.91.03).

## 2 Syntax

```text
table = POST_DYNA_ALEA(
    ◆ / FRAGILITE = _F(
           ◆ TABL_RESU = table,
           ◆ / VALE = float,
             / LIST_PARA = listr8,
           ◆ METHODE = / "EMV",
                       / "REGRESSION",
           # Si: equal_to("METHODE", 'REGRESSION')
               ◆ SEUIL = float,
           # Si: equal_to("METHODE", 'EMV')
               ◇ SEUIL = float,
               ◆ AM_INI = float,
               ◇ BETA_INI = float (défaut: 0.3),
               ◇ FRACTILE = float,
               # Si: exists("FRACTILE")
                   ◇ NB_TIRAGE = int,
        ),
      / INTERSPECTRE = _F(
           ◆ INTE_SPEC = interspectre,
           ◆ / NUME_ORDRE_I = int,
             / NOEUD_I = no,
             / OPTION = / "DIAG",
                        / "TOUT",
           # Si: exists("NUME_ORDRE_I")
               ◆ NUME_ORDRE_J = int,
           # Si: exists("NOEUD_I")
               ◆ NOEUD_J = no,
               ◆ NOM_CMP_I = text,
               ◆ NOM_CMP_J = text,
           ◇ FRACTILE = float (défaut: 0.5),
           ◇ MOMENT = int,
           ◇ DUREE = float,
        ),
    ◇ TITRE = text,
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Keyword FRAGILITE

FRAGILITE =

The keyword FRAGILITE makes it possible to determine the parameters ${A}_{m}$ and $\beta$ (median and logarithmic standard deviation) of a fragility curve according to the log-normal model [U2.08.05]:

${P}_{f\mid a}=\Phi (\frac{\ln(a/{A}_{m})}{\beta})$

One may also compute the values of the curve for the values of the parameters *Am*  and $\beta$ obtained. The option FRACTILES (optional) also makes it possible to determine fractiles for the curve by a resampling method applied to the original sample supplied in TABL_RESU.

#### 3.1.1 Operand TABL_RESU

```text
♦TAB_RESU = tabres            [table_sdaster]
```

One gives the name of the table [table_sdaster] which must have been created beforehand using CREA_TABLE [U4.33.02] . This table must have at least two columns with access keys (column label name): PARA_NOCI (this is the indicator characterising the level of the excitation) and DEFA (the values of this column are 0 if no failure has been observed or 1 if there has been a failure) or DEMANDE (the values of the real variable of interest characterising failure or damage, also called *seismic demand*  in the literature).

#### 3.1.2 Operand METHODE

> ♦    METHODE=/ 'EMV'

```text
/ 'REGRESSION'
```

One chooses between the two methods for the analysis of the log-normal fragility curve: EMV for maximum-likelihood estimation or REGRESSION for linear regression. Further details on these two methods are given in the documentation [U2,08.05]. If one chooses REGRESSION, then the table tabres must contain a column DEMANDE giving the seismic demand (variable of interest such as the drift, a maximum stress, ...) and the failure threshold must be supplied via the keyword SEUIL.

#### 3.1.3 Operand SEUIL

```text
◊    SEUIL=    seuil                    [R]

Si la table TAB_RESU contient une colonneDEMANDE, alors il faut renseigner le seuil de cette variable à partir duquel la structure est considérée défaillante.
```

#### 3.1.4 Operands LIST_PARA and VALE

One may give a list of reals, values for which the fragility curve is evaluated.

This may be done in the form of a list containing the analysis values $({a}_{1,}{a}_{2,}\mathrm{...},{a}_{n})$ :

◊VALE =liste                [l_R]

or by giving the name of the concept of type listr8 containing the list of values:

◊LIST_PARA =liste            listr8

#### 3.1.5 Operands AM_INI and BETA_INI

```text
♦  AM_INI

◊ BETA_INI
```

If one has chosen METHODE='EMV', then it is essential to give an initial value for the estimation of the parameter ${A}_{m}$ and it is advisable to give an initial estimate for $\beta$ (starting points for the optimisation algorithm).

#### 3.1.6 Operands FRACTILES and NB_TIRAGE

These operands must be supplied if one wishes to determine confidence intervals or, more precisely, fractiles for the fragility curve estimated by the maximum-likelihood method ('EMV'). The resampling method (also called “bootstrap” in the English-language literature) is used for this purpose. The operand FRACTILES makes it possible to give the fractiles that one wishes to compute.

```text
◊FRACTILES = fract                    listr8
```

By default, as many “bootstrap” samples are drawn as there are data available (this is the number :math:`N` of Monte Carlo simulations carried out beforehand and whose results are stored in the table TABL_RESU). The command NB_TIRAGE nevertheless makes it possible to reduce the number of draws to be carried out:

```text
◊NB_TIRAGE = nbt                [I]
```

*nbt* must be less than or equal to the number of values in TABL_RESU ($\mathrm{nbt}\le N$ ). This feature makes it possible to reduce the analysis time but is not recommended in the general case because the results are not very reliable.

### 3.2 Keyword INTERSPECTRE

#### 3.2.1 Operand INTE_SPEC

```text
♦    INTE_SPEC = inter
```

inter is the user name of the cross-spectral matrix.

The cross-spectral matrix may be obtained by various operators: lire_inte_spec [U4.36.01](doc:u4.36.01), calc_inte_spec [U4.36.03](doc:u4.36.03), defi_inte_spec [U4.36.02](doc:u4.36.02), dyna_alea_modal [U4.53.22](doc:u4.53.22), DYNA_SPEC_MODAL [U4.53.23](doc:u4.53.23) or REST_SPEC_PHYS [U4.63.22](doc:u4.63.22).

**Note** :

*The spectral moments are defined as integrals of the power spectral density (PSD):*

${\lambda}_{i}=\underset{-\infty }{\overset{+\infty }{\int}}{\mid \omega \mid }^{i}{S}_{\text{XX}}(\omega )d\omega =2\underset{0}{\overset{+\infty }{\int}}{\omega}^{i}{S}_{\text{XX}}(\omega )d\omega$

*Thus, if the PSD is given for the positive frequencies only,* POST_DYNA_ALEA *multiplies by 2 the integrals of the PSDs computed for* $\omega >0$ *. Furthermore, the PSDs are defined as a function of the natural frequency* $f=2\pi \omega$ *(* $\mathit{Hz}$ *) in* POST_DYNA_ALEA . The following formulae are used [cf. R7.010.01]:

$\begin{array}{}{S}_{\text{XX}}(f)=\underset{-\infty }{\overset{+\infty }{\int}}{R}_{\text{XX}}(\tau ){e}^{-\mathrm{2i}\pi f\tau }d\tau ;\\ S{'}_{\text{XX}}(\omega )=\frac{1}{2\pi }{S}_{\text{XX}}(f)\end{array}$

The reader is invited to consult the documentation of the command DYNA_ALEA_MODAL [U4.53.22](doc:u4.53.22) for further information on the meaning of the parameters of the keyword.

#### 3.2.2 Operands NUME_ORDRE_I, NUME_ORDRE_J

```text
♦    /    ♦    NUME_ORDRE_I = lnumi
♦    NUME_ORDRE_J = lnumj
```

These keywords make it possible to define the terms of the matrix whose functions will undergo the processing.

When the auto-spectra or the cross-spectra are computed on the **modes**  :

- lnumi is the list of the order numbers of the modes 'i'. Example: (2,3,1).
- lnumj is the list of the order numbers of the modes 'j'. Example: (2,1,4)

The indices are paired according to the same rank.

- (2,2) corresponds to the auto-spectrum on mode 2,
- (3,1) corresponds to the cross-spectrum between mode 3 and mode 1.

lnumi and lnumj must contain the same number of terms.

#### 3.2.3 Operands NOEUD_I, NOEUD_J, NOM_CMP_I, NOM_CMP_J

```text
♦    /    ♦    NOEUD_I = lnoeudi
♦    NOEUD_J = lnoeudj
♦    NOM_CMP_I = lcmpi
♦    NOM_CMP_J = lcmpj
```

When the auto-spectra or the cross-spectra are computed on the **nodes** in a given direction:

- lnoeudi is the list of the nodes along "i": $(\mathit{NO92},\mathit{NO95},\mathit{NO98})$
- lnoeudj is the list of the nodes along "j": $(\mathit{NO92},\mathit{NO92},\mathit{NO92})$
- lcmpi is the list of the components along "i": $(\mathit{DX},\mathit{DX},\mathit{DY})$
- lcmpj is the list of the components along "j": $(\mathit{DX},\mathit{DX},\mathit{DX})$

The nodes and components are paired according to the same rank:

- $(\mathit{NO92}\mathit{DX},\mathit{NO92}\mathit{DX})$ corresponds to the auto-spectrum at the node $\mathit{NO92}$ in the direction $\mathit{DX}$ ,
- $(\mathit{NO98}\mathit{DY},\mathit{NO92}\mathit{DX})$ corresponds to the cross-spectrum between the node $\mathit{NO92}$ in the direction $\mathit{DX}$ and the node $\mathit{NO95}$ in the direction $\mathit{DY}$ .

lnoeudi, lnoeudj, lcmpi and lcpmj must contain the same number of terms.

#### 3.2.4 Operand OPTION

```text
♦    /    OPTION = 'TOUT'
```

The analyses are carried out on all the cross-spectra of the matrix.

```text
/    OPTION = 'DIAG'
```

The analyses are carried out on all the auto-spectra of the matrix and only on those.

```text
fract = 0.5
```

#### 3.2.5 Keywords DUREE and FRACTILE

```text
◊    DUREE = duree

Si le mot-clé duree est renseigné, alors on détermine le maximum médian ou tout autre fractile ainsi que le facteur de pic du processus stochastique stationnaire Gaussien selon les formules de Vanmarcke. duree désigne alors l'intervalle du temps considéré pour estimer ces quantités. A titre d'exemple, dans le cadre d'une analyse sismique, duree peut être pris égal à la durée de la phase forte du signal sismique.

 ◊    FRACTILE    =     /frac            [R]
```

```text
/0.5        [DEFAUT]

Permet de définir le fractile considéré pour les calculs du maximum.

Par défaut, on prend fract = 0.5, ce qui correspond à la médiane des maxima.
```

#### 3.2.6 Operand MOMENT

```text
◊    MOMENT = lmom
```

lmom is the list of the orders of the spectral moments which will be computed. By default, the spectral moments of orders 0, 1, 2, 3 and 4 are always computed. The moments of order higher than 4 should therefore be mentioned in this list. Example: (5,7,8).

## 4 Results supplied

### 4.1 Keyword FRAGILITE

The parameters of the output table are:

| **PARAMETRES** | **TYPE** | **DESCRIPTION** |
| --- | --- | --- |
| TITRE | TXM | Title of the table |
| AM | R | Parameter ${A}_{m}$ estimated by maximum likelihood from the original sample |
| BETA | R | Parameter $\beta$ estimated by maximum likelihood from the original sample |
| PARA_NOCI | R | Values of the harmfulness parameter for which the curves are evaluated |
| PFA | R | Values of the fragility curve (parameters AM and BETA) |
| FRACTILES | R | Values of the curves for the fractile $f$ |

### 4.2 Keyword INTE_SPEC

For each function chosen in the interspectrum, POST_DYNA_ALEA stores in a table accessible by IMPR_TABLE [U4.91.03](doc:u4.91.03)

- the spectral moments
- statistical parameters (to be used if it is an auto-spectrum):
- standard deviation,
- irregularity factor,
- mean number of extrema per second,
- number of zero crossings per second,
- central frequency
- the peak factor according to Vanmarcke's formula
- the mean maximum according to Vanmarcke's formula

The parameters of this table are:

| **PARAMETRES** | **TYPE** | **DESCRIPTION** |
| --- | --- | --- |
| NUME_ORDRE_I | I | order number of the modes $i$ |
| NUME_ORDRE_J | I | order number of the modes $j$ |
| NOEUD_I | NO | Node $i$ |
| NOEUD_J | NO | Node $j$ |
| NOM_CMP_I | TXM | Name of the component at node $i$ $(\mathit{DX},\mathit{DY},\mathit{DY})$ |
| NOM_CMP_J | TXM | Name of the component at node $j$ $(\mathit{DX},\mathit{DY},\mathit{DY})$ |
| LAMBDA_00 | R | spectral moment of order 0 |
| LAMBDA_01 | R | spectral moment of order 1 |
| LAMBDA_02 | R | spectral moment of order 2 |
| LAMBDA_03 | R | spectral moment of order 3 |
| LAMBDA_04 | R | spectral moment of order 4 |
| ECART | R | standard deviation |
| NB_EXTREMA_P_S | R | mean number of extrema per second |
| NB_PASS_ZERO_P_S | R | number of zero crossings per second |
| FREQ_APPAR | R | central frequency |
| FACT_IRRE | R | irregularity factor |
| MAX_MOY | R | Mean maximum |
| FACT_PIC | R | Peak factor |

If INFO = 1 one prints in the file MESSAGE

- the user name of the table,
- the two indices (the 2 nodes or the 2 modes) of the selected function,
- the type of result computed,
- the analysis options chosen or taken by default,
- the values of the selected functions.

## 5 Example

### 5.1 Keyword FRAGILITE

Example of a table generated beforehand, by calling CALC_TABLE, during the Monte Carlo simulation (see also [U2.08.05](doc:u2.08.05)):

#TABLE_SDASTER

PARA_NOCI DEFA

5.00000E-01 1

4.50000E-01 0

3.00000E-01 0

3.00000E-01 1

1.50000E-01 0

2.50000E-01 0

9.00000E-01 1

4.00000E-01 1

> $\mathrm{⋮}$                     $⋮$

Example of the analysis of a fragility curve:

TAB_POST=POST_DYNA_ALEA( FRAGILITE=(_F(TABL_RESU=TAB1,

LIST_PARA=lr,

> AM_INI =0.3 ,

BETA_INI=0.1 ,

FRACTILE = (0.0,0.05,0.5,0.95,1.0),

NB_TIRAGE =50,

),),

TITRE = 'courbe 1',

INFO=2,);

In this example, a resampling is carried out ($N=\mathit{nbtr}=50$ ) in order to estimate the 5%, 50% (median) and 95% fractiles of the curve, and the envelopes (100% and 0%) are determined.
