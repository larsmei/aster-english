# u4.90.12 Operator POST_MAC3COEUR

## 1 Purpose

Macro-command dedicated to the post-processing of CALC_MAC3COEUR, in order to extract, in table format, the values or analyses of the result.

## 2 Syntax

```text
table = POST_MAC3COEUR(
    ◆ TYPE_COEUR = / "MONO",
                   / "MONO_FROID",
                   / "TEST",
                   / "900",
                   / "1300",
                   / "N4",
                   / "LIGNE900",
                   / "LIGNE1300",
                   / "LIGNEN4",
    # Si: is_in("TYPE_COEUR", ("LIGNE900","LIGNE1300","LIGNEN4"))
        ◆ NB_ASSEMBLAGE = int,
    ◆ RESULTAT = evol_noli,
    ◆ TABLE = table,
    ◆ INST = float,
    ◆ TYPE_CALCUL = / "LAME",
                    / "DEFORMATION",
                    / "FORCE_CONTACT",
    ◇ OPERATION = / "EXTRACTION" (par défaut),
                  / "ANALYSE",
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand TYPE_COEUR

Name of the type of core to be processed. See [u4.90.11](doc:u4.90.11) CALC_MAC3COEUR.

### 3.2 Operand NB_ASSEMBLAGE

In the case of a core of type 'LIGNEXXX' (with XXX='900','1300', 'N4' or 'EPR'), makes it possible to specify the length of the line

### 3.3 Operand RESULTAT

Name of the result data structure to be post-processed.

### 3.4 Operand TABLE

Table (in DAMAC format) containing the assembly information.

### 3.5 Operand INST

Time instant of the desired post-processing. Only one time instant is possible at a time.

### 3.6 Operand TYPE_CALCUL

Nature of the result to be post-processed: water gaps, deformations or contact forces.

### 3.7 Operand OPERATION

Nature of the post-processing: extraction or analysis of values.
