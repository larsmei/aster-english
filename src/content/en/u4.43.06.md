# u4.43.06 Operator DEFI_COMPOR

## 1 Purpose

Define the constitutive behaviour of a single crystal, of a polycrystal or of a multifibre beam.

For the constitutive behaviour of a single crystal or of a polycrystal, the user is allowed to choose the components of the single-crystal constitutive law.

Following this definition, one gives only the name of the crystallographic structure, it being understood that the directions of the slip systems of each family of slip systems are defined once and for all in the source code.

In the case of a multifibre beam, this operator makes it possible to associate an incremental constitutive behaviour with a group of fibres.

## 3 Operands

### 3.1 Keyword MONOCRISTAL

One occurrence of the factor keyword MONOCRISTAL makes it possible to define a single-crystal elastoviscoplastic constitutive law. This is to be repeated as many times as there are different single-crystal constitutive laws [R5.03.11](doc:r5.03.11).

#### 3.1.1 Operand MATER

Defines the name of the material produced by DEFI_MATERIAU and used for the single crystal. This operand makes it possible to check that the parameters associated with the constitutive behaviours chosen under the keywords ECOULEMENT, ECRO_ISOT, ECRO_CINE and ELAS do indeed exist in the material.

#### 3.1.2 Operand ECOULEMENT

Defines the type of viscoplastic flow used in the definition of the constitutive law MONOCRISTAL.

#### 3.1.3 Operand ECRO_ISOT

Defines the type of isotropic hardening used in the definition of the constitutive law MONOCRISTAL.

#### 3.1.4 Operand ECRO_CINE

Defines the type of kinematic hardening used in the definition of the constitutive law MONOCRISTAL.

#### 3.1.5 Operand ELAS

Defines the type of elastic constitutive behaviour used in the definition of the constitutive law MONOCRISTAL.

#### 3.1.6 Operand FAMI_SYST_GLIS

Defines the name of the family of slip systems on which the constitutive law MONOCRISTAL has been defined. The orientations of the normals to the slip planes and of the slip directions are computed automatically by the code from the name of the family.

#### 3.1.7 Operand TABL_SYST_GLIS

Makes it possible to supply a "user" family of slip systems, read in a table. For each row of the table (corresponding to a slip system) one must give the 3 components, in the crystal frame, of the vectors $n$ (normal to the slip plane) and $m$ (slip direction). Example (see also the test ssnd112c):

$\begin{array}{}{n}_{x}({s}_{1}),{n}_{y}({s}_{1}),{n}_{z}({s}_{1}),{m}_{x}({s}_{1}),{m}_{y}({s}_{1}),{m}_{z}({s}_{1})\\ {n}_{x}({s}_{2}),{n}_{y}({s}_{2}),{n}_{z}({s}_{2}),{m}_{x}({s}_{2}),{m}_{y}({s}_{2}),{m}_{z}({s}_{2})\\ \mathrm{etc...}\end{array}$

**Limitations:** this functionality is active only for the constitutive behaviour MONOCRISTAL, and on condition that a single family of systems is defined (a single occurrence of MONOCRISTAL). It is not available for the constitutive behaviour POLYCRISTAL.

#### 3.1.8 Operand MATR_INTER

#### 3.1.9 Operand ROTA_RESEAU

- ROTA_RESEAU=’CALC’ makes it possible to compute the rotation of the crystal lattice and to take it into account in the solution of the constitutive law MONOCRISTAL, in implicit form only. The orientations of the normals to the slip planes and of the slip directions are updated automatically by the code at each computation time instant, and the corresponding internal variables are added (see their meaning in [R5.03.11](doc:r5.03.11).
- ROTA_RESEAU=’POST’ makes it possible to compute the rotation of the crystal lattice, without taking it into account in the solution, and to display the values in the internal variables, for post-processing purposes.

**Validity and limitations:**

This approximation is to be used in the presence of small strains DEFORMATION=’PETIT’ under COMPORTEMENT, for RELATION=’MONOCRISTAL’ [U4.51.11](doc:u4.51.11). It must therefore be used for moderate strains (of the order of 10% at most). Beyond that, and in order to take large strains fully into account, one must use a suitable solution, without using the keyword ROTA_RESEAU: DEFORMATION=’SIMO_MIEHE’ in STAT_NON_LINE/COMPORTMENT.

### 3.2 Keyword POLYCRISTAL

One occurrence of the factor keyword POLYCRISTAL makes it possible to define a phase of the polycrystalline constitutive behaviour, from the data of a single-crystal constitutive behaviour, of the volume fraction of this phase, and of the orientation of this phase. This is to be repeated as many times as there are different single-crystal phases. Moreover, a localisation rule, common to all the phases, is defined by the keyword LOCALISATION [R5.03.11](doc:r5.03.11).

#### 3.2.1 Operand MONOCRISTAL

Defines the name of the compor data structure defining the single crystal, produced by a previous call to DEFI_COMPOR.

#### 3.2.2 Operand FRAC_VOL

Defines the volume fraction of the current phase. The sum of all the values of fvol must be equal to 1.

#### 3.2.3 Operand ANGL_REP / ANGL_EULER

Defines the 3 nautical angles (supplied in degrees) [U4.42.01](doc:u4.42.01) or the 3 Euler angles (supplied in degrees) which make it possible to orient the single crystal corresponding to the phase defined by the current occurrence of POLYCRISTAL. The Euler angles are defined in the conventional manner: one passes from the fixed frame $Oxyz$ to the frame attached to the solid $Ox'y'z'$ by three successive rotations:

#### 3.2.4 Keyword LOCALISATION

Defines the name of the localisation rule used for the polycrystal.

#### 3.2.5 Keyword MU_LOCA

Defines the coefficient ${\mu}^{\mathit{loca}}$  to be used in the localisation rules.

#### 3.2.6 Operands DL and DA

In the case where the localisation rule is ’BETA’, one must supply two real parameters: dl and da. The localisation rule is given in [R5.03.11](doc:r5.03.11).

### 3.3 Keyword MULTIFIBRE

This keyword makes it possible to associate an incremental constitutive behaviour with a group of fibres.

#### 3.3.1 Operand GROUP_FIBRE

Makes it possible to define, for each occurrence of the factor keyword MULTIFIBRE, the names of the groups of fibres associated with the chosen constitutive relation. These groups of fibres were defined beforehand by the command DEFI_GEOM_FIBRE, the resulting concept of which is specified by the keyword GEOM_FIBRE below.

#### 3.3.2 Operand MATER

This keyword makes it possible to specify the name of the material containing the parameters associated with the chosen constitutive behaviour.

#### 3.3.3 Operands RELATION

These keywords make it possible to define the constitutive relation associated with the groups of fibres defined by GROUP_FIBRE. The constitutive relations are described in [U4.51.11](doc:u4.51.11). It should be noted, however, that the list of constitutive behaviours which can be used with multifibre beams is restricted with respect to [U4.51.11](doc:u4.51.11). The relations which are allowed are:

ELAS, CORR_ACIER, GRANGER_FP, GRAN_IRRA_LOG, MAZARS_UNIL, VISC_IRRA_LOG, VMIS_CINE_GC, VMIS_CINE_LINE, VMIS_ISOT_LINE, VMIS_ISOT_TRAC.

#### 3.3.4 Note on the 1D constitutive behaviours

The modellings of multifibre beams (like those of bars and of reinforcement grids) use, for each fibre, a unidirectional constitutive behaviour. If the chosen constitutive law is available in 1D, this integration is used directly. Otherwise, the DEBORST method generalised to the case of 1D constitutive behaviours [R5.03.09](doc:r5.03.09) makes it possible to add the uniaxial-stress condition to all the constitutive behaviours available for the 3D modellings under COMPORTEMENT (for further detail see the documentation [R5.03.09](doc:r5.03.09)). The uniaxial-stress assumption is checked at convergence. One recommends using the tangent matrix and updating it fairly often (every one to three iterations) in the Newton method (MATRICE = ‘TANGENTE’, REAC_ITER = 1 to 3).

### 3.4 Keyword GEOM_FIBRE

◊GEOM_FIBRE=gfibre

This keyword makes it possible to specify the name of the concept which groups the groups of fibres coming from DEFI_GEOM_FIBRE.

### 3.5 Keyword MATER_SECT

◊MATER_SECT=mater

Definition of the material which has the homogenised elastic characteristics of the section (therefore under the keyword ELAS), used for the analysis of:

- the torsional stiffness.
- the damping.
- the thermal expansion (ALPHA).
- the computation of DEGE_ELNO (E and NU).

## 4 Examples

### 4.1 Examples of use for crystalline materials

The following example corresponds to a classical use of MONOCRISTAL. It is taken from the test SSNV171B.

ACIER=DEFI_MATERIAU(

ELAS=_F(E=145200.0, NU=0.3,),

MONO_VISC2=_F(N=10.0, K=40.0, C=1.0, D=36.68, A=10.0,),

MONO_ISOT2=_F(R_0=75.5, Q1=9.77, B1=19.34, H=0.5, Q2=-33.27, B2=5.345,),

MONO_CINE1=_F(D=36.68,),

)

COMPORT=DEFI_COMPOR(

MONOCRISTAL=_F(MATER=ACIER, ELAS=’ELAS’,

ECOULEMENT=’MONO_VISC2’,

ECRO_ISOT=’MONO_ISOT2’,

ECRO_CINE=’MONO_CINE1’,

FAMI_SYST_GLIS=’OCTAEDRIQUE’,),

)

The following example, which uses POLYCRISTAL, is taken from the test SSNV171B:

MATPOLY=DEFI_MATERIAU(

ELAS=_F(E=192500.0, NU=0.3,),

MONO_VISC2=_F(N=10.0, K=40.0, C=6333.0, D=36.68, A=72.21,),

MONO_ISOT2=_F(R_0=75.5, Q1=9.77, B1=19.34, H=2.54, Q2=-33.27, B2=5.345,),

MONO_CINE1=_F(D=36.68,),

)

MONO1=DEFI_COMPOR(

MONOCRISTAL=_F(MATER=MATPOLY, ELAS=’ELAS’,

ECOULEMENT=’MONO_VISC2’,

ECRO_ISOT=’MONO_ISOT2’,

ECRO_CINE=’MONO_CINE1’,

FAMI_SYST_GLIS=’OCTAEDRIQUE’,),

)

POLY1=DEFI_COMPOR(

POLYCRISTAL=(

_F(MONOCRISTAL=MONO1, FRAC_VOL=0.025,

ANGL_REP=(-149.67,15.61,154.67,),),

_F(MONOCRISTAL=MONO1, FRAC_VOL=0.025,

ANGL_REP=(-481.7,35.46,188.7),),

),

MU_LOCA = 82500

LOCALISATION=’BETA’, DL=321.5, DA=0.216,

)
