# u4.65.12 Operator ASSE_ELEM_SSD

## 1 Purpose

The purpose of this operator is to make the user's task easier for the assembly of the dynamic macro-elements. It chains the following commands: DEFI_MODELE_GENE, NUME_DDL_GENE and ASSE_MATR_GENE.

It produces a concept of type modele_gene, and possibly a concept of type nume_ddl_gene and concepts of type matr_asse_gene_r.

This operator is limited to the creation of the real generalised matrices.

The generalised matrices obtained can be used directly to compute the eigenmodes of the generalised model.

## 2 Syntax

```text
/ modele_gene
/ matr_asse_gene_r
/ nume_ddl_gene = ASSE_ELEM_SSD(
    ◆ RESU_ASSE_SSD = _F(
         ◆ MODELE = co,
         ◇ & NUME_DDL_GENE = co,
           & RIGI_GENE = co,
         ◇ & MASS_GENE = co,
      ),
    ◇ INFO = / 1 (par défaut),
             / 2,
    ◆ SOUS_STRUC = _F(
         ◆ NOM = text,
         ◆ MACR_ELEM_DYNA = macr_elem_dyna,
         ◇ ANGL_NAUT = float,
         ◇ TRANS = float,
      ),
    ◆ LIAISON = _F(
         ◆ SOUS_STRUC_1 = text,
         ◆ INTERFACE_1 = text,
         ◆ SOUS_STRUC_2 = text,
         ◆ INTERFACE_2 = text,
         ◇ / GROUP_MA_MAIT_1 = grma,
           / GROUP_MA_MAIT_2 = grma,
         ◇ OPTION = / "REDUIT",
                    / "CLASSIQUE" (par défaut),
      ),
    ⟐ VERIF = _F(
         ◇ STOP_ERREUR = / "OUI" (par défaut),
                         / "NON",
         ◇ PRECISION = float (défaut: 0.001),
         ◇ CRITERE = / "RELATIF" (par défaut),
                     / "ABSOLU",
      ),
    ◇ METHODE = / "CLASSIQUE" (par défaut),
                / "ELIMINE",
    ◇ STOCKAGE = / "LIGN_CIEL" (par défaut),
                 / "PLEIN",
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Course of the analysis

This operator chains the following operations:

- definition of the generalised model (DEFI_MODELE_GENE),
- numbering of the degrees of freedom of the generalised model (NUME_DDL_GENE),
- assembly of the generalised matrices (ASSE_MATR_GENE),

It is limited to the creation of the real generalised matrices.

For its implementation, the user may draw inspiration from the modellings «e» and «f» of the test case sdls106. These modellings correspond respectively to the modellings «b» and «d» of the same test case.

### 3.1 Keyword RESU_ASSE_SSD

This factor keyword defines the output concepts.

#### 3.1.1 Operand MODELE

```text
♦ MODELE = modele
```

modele: generalised model which contains the elements constituting the global structure (assembled substructures).

#### 3.1.2 Operand NUME_DDL_GENE

```text
◊ NUME_DDL_GENE = nugene
```

nugene: numbering of the degrees of freedom of the global structure.

#### 3.1.3 Operand RIGI_GENE

```text
◊ RIGI_GENE = rigene
```

rigene: generalised stiffness matrix of the global structure.

#### 3.1.4 Operand MASS_GENE

```text
◊ MASS_GENE = magene
```

magene: generalised mass matrix of the global structure.

### 3.2 Keyword SOUS_STRUC

Each occurrence of this factor keyword makes it possible to define the characteristics of a substructure.

The description of the operands associated with this keyword is the same as that of the keyword SOUS_STRUC of the operator DEFI_MODELE_GENE [U4.65.02](doc:u4.65.02).

**Note:**

By default, one considers that the substructure undergoes neither a translation nor a rotation: TRANS = (0., 0., 0.) and ANGL_NAUT = (0., 0., 0.).

### 3.3 Keyword LIAISON

Each occurrence of this factor keyword makes it possible to define the connection between two substructures. The description of the operands associated with this keyword is the same as that of the keyword LIAISON of the operator DEFI_MODELE_GENE [U4.65.02](doc:u4.65.02).

Among the operands of this keyword, the operand OPTION makes it possible to choose the type of mode (static modes or interface modes) that one adds in addition to the normal modes.

```text
   ◊ OPTION

/ 'CLASSIQUE' : à chaque ddl de l'interface correspond un mode statique de liaison

/ 'REDUIT' : utilisation des modes d'interface (préalablement calculés avec CREA_ELEM_SSD par exemple)
```

### 3.4 Keyword VERIF

This keyword makes it possible to check the consistency of the generalised model. The description of the operands associated with this keyword is the same as that of the keyword VERIF of the operator DEFI_MODELE_GENE [U4.65.02](doc:u4.65.02).

### 3.5 Operand METHODE

This operand makes it possible to choose the way of numbering the degrees of freedom of the generalised model. Two choices are possible.

```text
   ◊ METHODE

/ 'CLASSIQUE' : construit une numérotation des degrés de liberté généralisés permettant la prise en compte des équations de liaisons entre sous-structures par la méthode des doubles multiplicateurs de Lagrange.

/ 'ELIMINE': construit une numérotation des degrés de liberté généralisés permettant la prise en compte des équations de liaisons par la méthode d'élimination des contraintes sur les variables.
```

### 3.6 Operand STOCKAGE

This operand makes it possible to choose the storage mode of the assembled matrix or matrices.

```text
   ◊ STOCKAGE

/ 'LIGN_CIEL' : mode de stockage de type ligne de ciel

/ 'PLEIN': on stocke tous les éléments de la partie triangulaire supérieure de la matrice.
```

### 3.7 Operand INFO

This operand makes it possible to print more or less information on the generalised model created in the file 'MESSAGE'.

## 4 Example of use

This example is taken from the test case sdls106e

ASSE_ELEM_SSD(

RESU_ASSE_SSD = _F(

MODELE = CO('MODEGE'),

NUME_DDL_GENE = CO('NUMEGE'),

RIGI_GENE = CO('RIGGEN'),

MASS_GENE = CO('MASGEN'),

),

SOUS_STRUC = (

_F(NOM = 'CARRE1',

MACR_ELEM_DYNA = MACEL1,),

_F(NOM = 'CARRE2',

MACR_ELEM_DYNA = MACEL2,

TRANS = (0.,0.5,0.),

ANGL_NAUT = (-90.,0.,0.),),

),

LIAISON = (

_F(SOUS_STRUC_1 = 'CARRE1',

INTERFACE_1 = 'GAUCHE',

GROUP_MA_MAIT_1 = 'CALCUL',

OPTION = 'REDUIT',

SOUS_STRUC_2 = 'CARRE2',

INTERFACE_2 = 'BLOQUE',),

),

VERIF = _F( STOP_ERREUR = 'OUI',

PRECISION = 1.E-6,

CRITERE = 'RELATIF'),

METHODE = 'ELIMINE',

),
