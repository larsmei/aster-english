# v2.02.154 SDLL154 - Simplified method seismic response Rock of straight pipe with constant cross section

**Summary:**

The objective of this test is to validate the POST_ROCHE command on an elementary case of a
straight beam consisting of 2 mesh cells in the following cases:

- VARIANTE = 'RCC_MRX'
- VARIANTE = 'ASNR'
- SIGM_LIM = ‘OUI’
- SIGM_LIM = ‘NON’
- SIGM_ABAT = 'REFE_ELAS'
- SIGM_ABAT = 'CODE'
- Constant material field
- Field of material dependent on a temperature field

The section is constant. This test also validates (excluding POST_ROCHE) functionality
POST_ELEM/INTEGRALE on elements POU_D_T for generalized effort fields,
used in POST_ROCHE macro-command.

Although the beam is straight, **in some of the calculations the 2 elements are declared as
elbows to verify formulae for the cobbled parts**.

## 1 Reference problem

### 1.1 Geometry

An external $10\mathit{mm}$ hollow pipe, $5\mathit{mm}$ thickness and $2m$ length is considered.

![Figure](/figures/v2.02.154/100002010000023D000000672F1F021BBD7FC02F.png)

### 1.2 Material properties

The material is elastic isotropic with properties of:

- $E=200\mathit{GPa}$
- $\nu =0.3$
- $\rho=7800\mathit{kg}/{m}^{3}$
- $\alpha =1.2E-5{K}^{-1}$

The law of Ramberg Osgood used for post-processings ssss:

${ϵ}_{p}=K{(\frac{\sigma}{E})}^{1/n}$

With:

- $K=0.01$
- $n=2$

In the case of `SIGM_LIM =’OUI’`, the values of the other parameters are as follows:

- RP02_MIN = 128E6
- RM_MIN = 410E6,
- RP02_MOY = 163E6,
- COEF = 1.

In cases where parameters are given as function, two different formulae are given on both mesh cells and a temperature field is constructed in such a way that the same values of material parameters are found for each mesh cell as in constant cases.

### 1.3 Boundary conditions and loads

An elastic set of calculations is performed independently on the beam structure.

![Figure](/figures/v2.02.154/100002010000019C000000785C63C96ABAD54C29.png)

#### 1.3.1 Own weight

A $g=9.81m/{s}^{2}$ gravity field is imposed in the $-Z$ direction. The point $A$ is clamped.

#### 1.3.2 Movement imposed

The point $A$ is clamped. The structure is twisted to point $B$ via an angle imposed $\theta =0.02\mathit{rad}$ on the $X$ axis.

#### 1.3.3 Thermal dilation

The point $A$ is clamped. The point $B$ is blocked on the $X$ axis. A change in the $\Delta T=100K$ temperature field generates a compression in the beam.

#### 1.3.4 Pressure imposed

The pressure inside the $P=1\mathit{MPa}$ pipe is taken into account.

#### 1.3.5 Spectral seismic

The point $A$ is clamped. The point $B$ is blocked on the $Z$ axis. A spectral acceleration is imposed on the 3 $X$ , $Y$ and $Z$ axes with the respective $1.$ , $1.$ and $0.5$ ratios:

![Figure](/figures/v2.02.154/1000020100000280000001E0D438E8C97734A253.png)

The first 4 dynamic modes and static correction via the
pseudo-modes according to the 3 axes. Reduced depreciation is set at 2%.

To obtain 99% spectra, the values read from these spectra are divided by
10. This test, entirely carried out by computer, aims to check the consistency between the
the analytical results calculated using a Python script and those obtained with POST_ROCHE.

  - Seismic Inertial Loading Type QS (quasi-static)
