# u4.65.01 Operator MACR_ELEM_DYNA

## 1 Purpose

Define a macro-element for dynamic substructuring.

Within a transient, modal or harmonic analysis with dynamic substructuring, the operator MACR_ELEM_DYNA projects the stiffness, mass and, possibly, damping matrices (harmonic analysis) onto the modal basis of the substructure defined by DEFI_BASE_MODALE [U4.64.02](doc:u4.64.02), and extracts the connection matrices of the interfaces. The result consists of the projected matrices and of the connection matrices. It may be used several times, with different orientations, in the same model (cf. DEFI_MODELE_GENE [U4.65.02](doc:u4.65.02)). It may be printed to a file by the command IMPR_MACR_ELEM [U7.04.33](doc:u7.04.33).

Produces a concept of type macr_elem_dyna.

## 2 Syntax

```text
macr_elem_dyna = MACR_ELEM_DYNA(
    ◇ reuse = <objet de MACR_ELEM_DYNA>,
    ◇ MACR_ELEM_DYNA = macr_elem_dyna,
    ◆ BASE_MODALE = mode_meca,
      / MATR_RIGI = matr_asse_depl_c / matr_asse_depl_r,
    ◇ / MODELE_MESURE = _F(
           ◆ FREQ = float,
           ◆ MASS_GENE = float,
           ◇ AMOR_REDUIT = float,
        ),
    ◇ / MATR_IMPE = matr_asse_gene_c,
    ◇ / MATR_MASS = matr_asse_depl_r,
    ◇ / MATR_IMPE_MASS = matr_asse_gene_c,
    ◇ / MATR_IMPE_RIGI = matr_asse_gene_c,
    ◇ / MATR_IMPE_AMOR = matr_asse_gene_c,
    ◇ / MATR_AMOR = matr_asse_depl_r,
      / AMOR_REDUIT = float,
    ◇ / SANS_GROUP_NO = grno,
      / GROUP_NO = grno,
    # Si: exists("MATR_IMPE")
        ◆ FREQ_EXTR = float,
        ◇ AMOR_SOL = float (défaut: 0.0),
        ◇ MATR_IMPE_INIT = matr_asse_gene_c,
    ◇ CAS_CHARGE = _F(
         ◆ NOM_CAS = text,
         ◆ / VECT_ASSE_GENE = vect_asse_gene,
           / RESU_GENE = tran_gene,
      ),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand BASE_MODALE

```text
♦    BASE_MODALE = bamo
```

Name of the mode_meca concept produced by the operator DEFI_BASE_MODALE [U4.64.02](doc:u4.64.02).

### 3.2 Operand MACR_ELEM_DYNA

```text
◊    MACR_ELEM_DYNA = macro_dyna
```

Name of the dynamic macro-element concept of type macr_elem_dyna, identical to the name of the concept produced. It is therefore re-entrant when it is present. The content of the concept is modified from the data of the operands MATR_IMPE* that are present.

### 3.3 Operand MATR_RIGI

```text
◊    MATR_RIGI = mr
```

Name of the assembled-matrix concept of type matr_asse_DEPL_R or matr_asse_DEPL_C produced by the operator ASSE_MATRICE [U4.61.22](doc:u4.61.22) or the macro-command ASSEMBLAGE [U4.61.21](doc:u4.61.21) corresponding to the stiffness matrix of the substructure.

### 3.4 Operand MATR_MASS

```text
◊    MATR_MASS = mm
```

Name of the assembled-matrix concept of type matr_asse_DEPL_R produced by the operator ASSE_MATRICE [U4.61.22](doc:u4.61.22) or the macro-command ASSEMBLAGE [U4.61.21](doc:u4.61.21) corresponding to the mass matrix.

These two operands are to be used if one uses the modal basis bamo of type 'RITZ'.

### 3.5 Operand MATR_AMOR / AMOR_REDUIT

```text
◊    /    MATR_AMOR = ma
```

Name of the assembled-matrix concept of type matr_asse_DEPL_R produced by the operator ASSE_MATRICE [U4.61.22](doc:u4.61.22) or the macro-command ASSEMBLAGE [U4.61.21](doc:u4.61.21) corresponding to the viscous damping matrix, specific to the macro-element. This damping must be of RAYLEIGH type per element (linear combination of the stiffness and of the mass at the element level) and is therefore defined by the material properties (operator: DEFI_MATERIAU [U4.43.01](doc:u4.43.01), operands AMOR_ALPHA and AMOR_BETA).

```text
/    AMOR_REDUIT = la
```

List of the reduced dampings (percentage of the critical damping) corresponding to each vibration mode of the macro-element. The length of the list is (at most) equal to the number of eigenmodes of the modal basis; if it is smaller, one completes the list with reduced dampings equal to the last term of the list entered by the user. No damping is associated with the static modes. The generalised damping matrix of the macro-element $k$ is therefore an incomplete diagonal ($j$ index of the eigenmode):

${\overline{\mathrm{C}}}^{k}=\left(\begin{array}{cc}\left({\xi}_{j}\right)& (0)\\ (0)& (0)\end{array}\right)$

### 3.6 Operands MATR_IMPE / FREQ_EXTR / AMOR_SOL

```text
◊     MATR_IMPE = mi
```

Name of the assembled-matrix concept of type matr_asse_gene_C produced by the operator LIRE_IMPE_MISS [U7.02.32](doc:u7.02.32) corresponding to the impedance matrix (dynamic stiffness, strictly speaking) of the soil interface ${\mathrm{M}}_{\mathit{imp}}(\mathit{freq})$, which constitutes the macro-element.

```text
♦    FREQ_EXTR = freq
```

Frequency of extraction of the soil-interface impedance matrix $\mathrm{mi}$ ${\mathrm{M}}_{\mathit{imp}}(\mathit{freq})$, required for the computation of the radiative soil damping matrix from its imaginary part.

```text
◊    AMOR_SOL = amosol
```

Value of the material reduced damping of the soil, equal to half the hysteretic viscoelastic damping ${\xi}_{\mathit{sol}}={\eta}_{\mathit{sol}}/2$, which was used for the computation of the matrix $\mathrm{mi}$. It serves to distinguish, in the damping coming from the soil domain, the strictly material (viscoelastic) part and the radiative part. If it is non-zero, the matrix corresponding to the radiative part ${\mathrm{C}}_{\mathit{imp}}$ is then expressed such that:

$2\pi .\mathit{freq}.{\mathrm{C}}_{\mathit{imp}}=\mathrm{\Im }\left({\mathrm{M}}_{\mathit{imp}}(\mathit{freq})\right)-2{\xi}_{\mathit{sol}.}\mathrm{\Re }\left({\mathrm{M}}_{\mathit{imp}}(\mathit{freq})\right)$

### 3.7 Operand MATR_IMPE_INIT

```text
◊     MATR_IMPE_INIT = mi0
```

Name of the assembled-matrix concept of type matr_asse_gene_C, ${\mathrm{M}}_{i0}$, of the same dimension as a mass matrix, produced by the operator LIRE_IMPE_MISS [U7.02.32](doc:u7.02.32) corresponding to a soil impedance matrix which constitutes the macro-element, extracted at a quasi-zero frequency ${\mathrm{M}}_{\mathit{imp}}(0)$. In particular, in the cases of soil-structure-fluid interaction with the keyword ISSF='OUI' in the call to LIRE_IMPE_MISS, this makes it possible to extract a mass contribution $M$ such that, in the low-frequency range:

${(2\pi .\mathit{freq})}^{2}.{\mathrm{M}}_{i0}=\mathrm{\Re }\left({\mathrm{M}}_{\mathit{imp}}(0)\right)-\mathrm{\Re }\left({\mathrm{M}}_{\mathit{imp}}(\mathit{freq})\right)$

### 3.8 Operands MATR_IMPE_RIGI/MATR_IMPE_AMOR/MATR_IMPE_MASS

Names of the assembled-matrix concepts of type matr_asse_gene_C produced by successive calls to the operator LIRE_IMPE_MISS [U7.02.32](doc:u7.02.32) in order to extract the respective contributions which constitute the macro-element, in stiffness, damping or mass, of a time-domain soil impedance matrix. If at least one of the operands is supplied, without the others being present, then the contributions of the latter to the terms of the macro-element will be filled in and set to 0.

An example of use is provided by the test MISS03B [V1.10.122](doc:v1.10.122).

### 3.9 Operands GROUP_NO / SANS_GROUP_NO

```text
◊    GROUP_NO = grno
```

Name of the node group comprising the list of the nodes attached to the degrees of freedom of the interface modes by a relation LIAISON_INTERF (or LIAISON_SOLIDE if the dynamic interface is reduced to one node) to the nodes of the physical interface of the part of the model on which one computes the dynamic macro-element. Supplying it is necessary only if this macro-element is used as a super-mesh cell of substructures defined by the keyword AFFE_SOUS_STRUC in a mixed model which also comprises classical finite elements, and in that case only when the nodes of the physical and dynamic interfaces (the latter defined by DEFI_INTERF_DYNA) do not coincide. For example, in the case of the dynamic interface reduced to one node connected by a rigid link to the physical interface.

```text
◊    SANS_GROUP_NO = grno
```

Name of the node group comprising the list of the nodes of the physical interface of the part of the model on which one computes the dynamic macro-element. These nodes are in a direct relation with the nodes attached to the degrees of freedom of the interface modes by a relation LIAISON_INTERF (or LIAISON_SOLIDE if the dynamic interface is reduced to one node). Supplying it is necessary only if this macro-element is used as a super-mesh cell of substructures defined by the keyword AFFE_SOUS_STRUC in a mixed model which also comprises classical finite elements, and in that case only when the nodes of the physical and dynamic interfaces (the latter defined by DEFI_INTERF_DYNA) do not coincide. For example, in the case of the dynamic interface reduced to one node connected by a rigid link to the physical interface.

### 3.10 Keyword CAS_CHARGE

```text
◊    CAS_CHARGE
```

This factor keyword makes it possible to define a set of **named** load cases (keyword NOM_CAS). These load cases serve to apply generalised load vectors applied on the part of the model on which one computes the dynamic macro-element, if this macro-element is subsequently used as a super-mesh cell of substructures in a mixed model which also comprises classical finite elements.

#### 3.10.1 Operand NOM_CAS

```text
♦    NOM_CAS = nocas
```

The loading condensed under the name nocas (in quotes) corresponds to the loading defined by the argument VECT_ASSE_GENE or RESU_GENE on the part of the model on which one computes the dynamic macro-element.

#### 3.10.2 Operands VECT_ASSE_GENE / RESU_GENE

```text
♦    VECT_ASSE_GENE = vgen
```

The loading condensed under the name nocas (in quotes) corresponds to the loading defined by the alternative arguments VECT_ASSE_GENE or RESU_GENE. It is obtained by the projection, onto the modal basis bamo defined above, either of an assembled load vector or of a transient right-hand-side force result, applied on the part of the model on which one computes the dynamic macro-element. These two options are tested simultaneously in the test SDNX101B.

### 3.11 Operand MODELE_MESURE

```text
◊    MODELE_MESURE
```

This factor keyword makes it possible to fill in manually the reduced matrices of the macro-element, using, for example, data coming from measurements (and imported with LIRE_RESU). One must, at a minimum, enter the generalised mass and the eigenfrequencies. One may also supply the list of reduced dampings.

The number of data items supplied must be equal to the number of modes of the modal basis on which the macro-element is built.

Methodological point: this type of use of MACR_ELEM_DYNA is justified for the use of the structural modification method starting from an experimental model. A presentation of the method is given in U2.07.03. **The modal basis used to build the macro-element must be composed only of the eigenmodes of the measured structure**, and must not include the static readings at the interface, because these are wrong (because they are not measured and, in the present state of knowledge, not measurable).

The test case sdll137e is an example of the implementation of the methodology.

#### 3.11.1 Operand FREQ

```text
♦    FREQ = freq
```

List of the identified eigenfrequencies.

#### 3.11.2 Operand MASS_GENE

```text
♦    MASS_GENE = mass
```

List of the identified generalised masses.

#### 3.11.3 Operand AMOR_REDUIT

```text
♦    AMOR_REDUIT = xsi
```

List of the identified reduced dampings.

## 4 Example

An example of the use of this operator is given in the documentation of the operator DEFI_SQUELETTE [U4.24.01](doc:u4.24.01).
