# u4.61.02 Operator CALC_VECT_ELEM

## 1 Purpose

Compute a set of elementary vectors which one will be able to assemble with ASSE_VECTEUR.

The possible analysis options are:

'CHAR_MECA', 'CHAR_THER', 'CHAR_ACOU', 'FORC_NODA'.

Produces a data structure of type vect_elem_* .

## 2 Syntax

```text
/ vect_elem_depl_r
/ vect_elem_pres_c
/ vect_elem_temp_r = CALC_VECT_ELEM(
    ◆ OPTION = / "CHAR_ACOU",
               / "CHAR_MECA",
               / "CHAR_THER",
               / "FORC_VARC",
    # Si: equal_to("OPTION", 'CHAR_MECA')
        ◆ | CHARGE = list[char_meca],
          | MODELE = modele,
        # Si: exists("CHARGE")
            ◇ CHAM_MATER = cham_mater,
            ◇ CARA_ELEM = cara_elem,
            ◇ INST = float (défaut: 0.0),
            ◇ MODE_FOURIER = int (défaut: 0),
        # Si: (exists("MODELE"))
            ◆ SOUS_STRUC = _F(
                 ◆ CAS_CHARGE = text,
                 ◆ / TOUT = "OUI" (ou non renseigné),
                   / SUPER_MAILLE = list[ma],
              ),
    # Si: equal_to("OPTION", 'FORC_VARC')
        ◆ MODELE = modele,
        ◆ CHAM_MATER = cham_mater,
        ◇ CARA_ELEM = cara_elem,
        ◇ INST = float (défaut: 0.0),
    # Si: equal_to("OPTION", 'CHAR_THER')
        ◇ CARA_ELEM = cara_elem,
        ◆ CHARGE = list[char_ther],
        ◇ INST = float (défaut: 0.0),
    # Si: equal_to("OPTION", 'CHAR_ACOU')
        ◆ CHAM_MATER = cham_mater,
        ◆ CHARGE = list[char_acou],
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 General points

This command is used to compute a set of elementary vectors (corresponding to a chosen option). The concept created, of type vect_elem_* , can then be assembled by the operator ASSE_VECTEUR [U4.42.03](doc:u4.42.03) in order to give a right-hand side of type cham_no.

The options available are:

| 'CHAR_MECA' | in order to obtain the right-hand side of a mechanical problem |
| --- | --- |
| 'CHAR_THER' | in order to obtain the right-hand side of a thermal problem |
| 'CHAR_ACOU' | in order to obtain the right-hand side of an acoustic problem |
| 'FORC_VARC' | in order to obtain the forces generated by the command variables |

## 4 Operands

### 4.1 Operand CHARGE

```text
♦    CHARGE= lchar
```

The list of loads lchar must be consistent with the chosen option:

- "mechanical" loads for the option 'CHAR_MECA',
- "thermal" loads for the option 'CHAR_THER',
- "acoustic" loads for the option 'CHAR_ACOU'.

This argument is mandatory.

It makes it possible to access all the data concerning the “loading” of the system. It is necessary that all the loads of the list be based on the same model.

### 4.2 Operand INST

```text
◊    INST= tps
```

The parameter tps (time instant of the analysis) is used as soon as the loading depends on time.

### 4.3 Operand MODELE

```text
◊    MODELE= mo
```

This keyword is mandatory in order to retrieve the substructures affected by the loading or for the command variables. mo is the name of the model.

### 4.4 Operand CHAM_MATER

```text
◊    CHAM_MATER
```

Name of the material field in which the material characteristics of the elements are defined. This argument is necessary in mechanics for the gravity and rotation loadings and in acoustics.

### 4.5 Operand CARA_ELEM

```text
◊    CARA_ELEM= carac
```

This concept of type cara_elem is necessary if there exist in the model structural elements (beam, plate, shell or discrete elements).

### 4.6 Operand MODE_FOURIER

```text
◊    MODE_FOURIER= nh
```

Positive or zero integer indicating the FOURIER harmonic on which one computes the elementary vector for an axisymmetric 2D model. By default, nh = 0.

### 4.7 Operands necessary for analyses with static substructuring

```text
♦    SOUS_STRUC
```

This factor keyword makes it possible to specify which loadings are to be used for the substructures. In its absence, the loadings on the substructures are zero.

These loadings are added to the "finite element" loadings which can be applied on the rest of the model.

```text
♦    CAS_CHARGE= nocas
```

nocas is the name of the load case to be used. See the operator MACR_ELEM_STAT [U4.62.01](doc:u4.62.01).

```text
♦    /    TOUT= 'OUI'
```

This keyword makes it possible to assign the loading nocas to all the substructures of the model.

```text
♦   /    SUPER_MAILLE= l_mail
```

This factor keyword makes it possible to assign the loading nocas only to certain substructures.

## 5 Examples

- Computation of the right-hand side for a steady linear thermal problem:

```python
vect_elem = CALC_VECT_ELEM( OPTION= 'CHAR_THER', CHARGE= ch_ther )
```

- Computation of the mechanical loading of a structure containing static substructures:

```python
vect_elem = CALC_VECT_ELEM ( OPTION= 'CHAR_MECA',
                             CHARGE= ch_meca,
                             MODELE= mo,
                             SOUS_STRUC= _F (CAS_CHARGE= 'ch_f1', TOUT= 'OUI'))
```

- Computation of the forces generated by the command variables:

```python
vect_elem = CALC_VECT_ELEM ( OPTION= 'FORC_VARC',
                             MODELE= mo,
                             CHAM_MATER= mater)
```
