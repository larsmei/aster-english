# v6.04.226 SSNV226 – Validation of Critical Stress Break criteria

**Summary:**

The problem is quasi-static non-linear in structural mechanics (although nonlinear dynamic modelling is available for validation concerns).

The response of a volume element is analyzed with a load in traction and displacement imposed. As soon as the maximum main stress in the element reaches a critical stress, the stiffness of the element is reduced and the stresses are almost cancelled.

Model A validates the breakage criterion with the VISCOCHAB law in a case where the hardening is isotropic, for simple traction.

Model B validates the break with VMIS_ISOT_TRAC law in a case where the hardening is purely isotropic, for simple traction.

Modelling C validates the breakage criterion with VISC_ISOT_TRAC viscoplasticity law in a case where the hardening is purely isotropic, for simple traction.

Modelling D resumes Modelling C using the nonlinear dynamic operator DYNA_NON_LINE.

## 2 reference solution

### 2.1 Baseline

Since the stress state is uniform and uniaxial, we simply check that the volume element will break as soon as ${\sigma}_{zz}$ is greater than $\text{SIGMA_C}=7.8{E}^{8}\mathit{Pa}$.

## 7 Summary of the results

The four modellingss validate the critical stress failure criterion on a element volumetric basis with VISCOCHAB, VISC_ISOT_TRAC, and VMIS_ISOT_TRAC elastoplastic viscoplastic behaviors in quasi-static and dynamic.
