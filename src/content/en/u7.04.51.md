# u7.04.51 Operator IMPR_OAR

## 1 Purpose

Write the result of an ASTER mechanical or thermomechanical analysis in the OAR format.

The OAR (Rapid Analysis Tool) makes it possible to carry out brittle-fracture analyses according to the codified methods of the RSE-M. The stress field along the ligament in line with the defect enters into the input data necessary for the application of these methods. This field may be computed by an ASTER mechanical or thermomechanical analysis. In this case, the operator IMPR_OAR prints the stress tables obtained by ASTER in a format readable by OAR.

## 2 Syntax

```text
IMPR_OAR(
    ◆ / TABL_MECA = _F(
           ◇ PRESSION = table,
           ◇ FLEXION_P = table,
           ◇ FLEXION_HP = table,
           ◇ TORSION = table,
        ),
      / TABL_THER = _F(
           ◆ | TEMP = table,
             | CONTRAINTE = table,
        ),
    ◆ UNITE = unit,
    ◇ TITRE = text,
    ◇ MODELE = modele,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand TABL_MECA

```text
♦    /    TABL_MECA
```

This factor keyword makes it possible to supply the stress table or tables, results of a mechanical analysis, to be printed in OAR format. The tables are to be created via the command MACR_LIGN_COUP. In the case where several time instants are computed, the mechanical tables must contain only a single time instant.

```text
| PRESSION = tab1
```

Name of the aster table giving the stresses due to the pressure.

```text
| FLEXION_P = tab2
```

Name of the aster table giving the stresses due to in-plane bending.

```text
| FLEXION_HP = tab3
```

Name of the aster table giving the stresses due to out-of-plane bending.

```text
| TORSION = tab4
```

Name of the aster table giving the stresses due to torsion.

### 3.2 Operand TABL_THER

```text
♦    /    TABL_THER
```

This factor keyword makes it possible to supply the temperature and thermal-stress tables, results of a thermomechanical analysis, to be printed in the OAR format. The tables are to be created via the command MACR_LIGN_COUP.

```text
| TEMP = tab1
```

Name of the aster table giving the temperature as a function of time.

```text
| CONTRAINTE = tab2
```

Name of the aster table giving the thermal stresses as a function of time.

**Note:** in the case where the number of mechanical time instants is smaller than the number of thermal time instants, only the mechanical time instants are printed,
so as not to print empty mechanical time instants.

### 3.3 Operand UNITE

```text
♦    UNITE = unite
```

Logical unit number of the output file.

### 3.4 Operand TITRE

```text
◊ TITRE = ‘titre’
```

Keyword making it possible to add a title in the table printed in the OAR format.

### 3.5 Operand MODELE

```text
◊    MODELE =    modele
```

Mandatory keyword in the case of printing of a stress table coming from a thermal analysis (operand TABL_THER). The model to be supplied is the **mechanical model**.

In the case of a thermomechanical analysis (operand TABL_THER) the stresses are printed in the order:

- PLAN model: SIXX, SIZZ, SIXZ, SIYY, SIXY, SIYZ,
- axisymmetric model: SIXX, SIYY, SIXY, SIZZ, SIXZ, SIYZ,
- 3D model: SIXX, SIYY, SIZZ, SIXY, SIXZ, SIYZ.

In the case of a mechanical analysis (operand TABL_MECA) the stresses are always printed in the order SIXX, SIYY, SIZZ, SIXY, SIXZ, SIYZ.
The operand MODELE is therefore optional, as it has no impact on the stress print format.

## 4 Examples of use

### 4.1 Mechanical analysis

At the end of the analysis, the user produces the tables necessary for the generation of the OAR file using the command MACR_LIGN_COUPE. The command MACR_LIGN_COUPE must be called as many times as necessary in order to obtain the tables used by IMPR_OAR, namely one command per loading (Pressure, In-plane bending, Out-of-plane bending, Torsion).

The command MACR_LIGN_COUPE may contain one or several azimuths.

# creation of the tables in the aster format, here on two azimuths

```text
tableP = MACR_LIGN_COUPE(LIGN_COUPE=(_F(COOR_EXTR=(0.2032, 1.8904, 0.0),

                                        COOR_ORIG=(0.1818, 1.8904, 0.0),

                                        NB_POINTS=40),

                                     _F(COOR_EXTR=(0.0, 1.8904, 0.2032),

                                        COOR_ORIG=(0.0, 1.8904, 0.1818),

                                        NB_POINTS=40)),

                        NOM_CHAM='SIGM_NOEU',

                        RESULTAT=resulP)

tableFP = MACR_LIGN_COUPE(LIGN_COUPE=(_F(COOR_EXTR=(0.2032, 1.8904, 0.0),

                                         COOR_ORIG=(0.1818, 1.8904, 0.0),

                                         NB_POINTS=40),

                                      _F(COOR_EXTR=(0.0, 1.8904, 0.2032),

                                         COOR_ORIG=(0.0, 1.8904, 0.1818),

                                         NB_POINTS=40)),

                        NOM_CHAM='SIGM_NOEU',

                        RESULTAT=resulFP)

tableHFP = MACR_LIGN_COUPE(LIGN_COUPE=(_F(COOR_EXTR=(0.2032, 1.8904, 0.0),

                                          COOR_ORIG=(0.1818, 1.8904, 0.0),

                                          NB_POINTS=40),

                                       _F(COOR_EXTR=(0.0, 1.8904, 0.2032),

                                          COOR_ORIG=(0.0, 1.8904, 0.1818),

                                          NB_POINTS=40)),

                        NOM_CHAM='SIGM_NOEU',

                        RESULTAT=resulHFP)

tableT = MACR_LIGN_COUPE(LIGN_COUPE=(_F(COOR_EXTR=(0.2032, 1.8904, 0.0),

                                        COOR_ORIG=(0.1818, 1.8904, 0.0),

                                        NB_POINTS=40),

                                     _F(COOR_EXTR=(0.0, 1.8904, 0.2032),

                                        COOR_ORIG=(0.0, 1.8904, 0.1818),

                                        NB_POINTS=40)),

                                    NOM_CHAM='SIGM_NOEU',

                                    RESULTAT=resulT)
```

# printing of the tables in the OAR format

```text
IMPR_OAR(TABL_MECA=_F(PRESSION = tableP,

                      FLEXION_P = tableFP,

                      FLEXION_HP = tableHFP,

                      TORSION = tableT,),

                      UNITE = 38,

                      TITRE = 'Resultats mecaniques')
```

### 4.2 Thermomechanical analysis

The thermomechanical analysis produces two result fields, a thermal field and a stress field, respectively TEMPE and RESU in the example below.

At the end of the analysis, the user produces the tables necessary for the generation of the OAR file using the MACR_LIGN_COUPE commands. The MACR_LIGN_COUPE commands may contain one or several azimuths.

# 1. creation of the thermal results table from the command MACR_LIGN_COUPE

```text
tableTEMP = MACR_LIGN_COUPE(LIGN_COUPE=(_F(COOR_EXTR=(0.2032, 1.8904, 0.0),

                                            COOR_ORIG=(0.1818, 1.8904, 0.0),

                                            NB_POINTS=40),

                                        _F(COOR_EXTR=(0.0, 1.8904, 0.2032),

                                            COOR_ORIG=(0.0, 1.8904, 0.1818),

                                            NB_POINTS=40)),

                                        NOM_CHAM='TEMP',

                                        RESULTAT=TEMPE)
```

# 2. creation of the mechanical results table from the command MACR_LIGN_COUPE

```text
tableTEMPSIG = MACR_LIGN_COUPE(LIGN_COUPE=(_F(COOR_EXTR=(0.2032, 1.8904, 0.0),

                                              COOR_ORIG=(0.1818, 1.8904, 0.0),

                                              NB_POINTS=40),

                                            _F(COOR_EXTR=(0.0, 1.8904, 0.2032),

                                               COOR_ORIG=(0.0, 1.8904, 0.1818),

                                               NB_POINTS=40)),

                                            NOM_CHAM='SIGM_NOEU',

                                            RESULTAT=RESU)
```

# 3. Printing in the OAR format

```text
IMPR_OAR(TABL_THER=_F(TEMP= tableTEMP,

                    CONTRAINTE = tableTEMPSIG),

         UNITE = 38,

         TITRE = 'Choc thermique 300 70',

         MODELE = modele_MECA)
```

## 5 Precautions

Supplying the OAR program requires the conventions specific to this program to be respected, in particular:

- the coordinate system in which the component is computed,
- the value of the imposed unit forces.

The command IMPR_OAR does not handle these points. They remain the responsibility of the user.
