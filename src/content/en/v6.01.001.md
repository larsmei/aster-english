# v6.01.001 SSNA01 - Infinite cylinder under pressure: Lemaître viscoelasticity

**Summary:**

This non-linear quasi-static mechanical test consists of Modelling an infinite cylinder subjected to time-dependent internal pressure. This validates the Lemaître axisymmetric nonlinear viscoelasticity behavior relationship and a complete mesh. This test is taken from the VPCS SFM guide.

The cylinder is modeled by elements $\mathrm{2D}$ axisymmetric (QUAD8).

The results obtained by *Code_Aster* are very close to the reference solution.

## 4 Summary of the results

The accuracy required for this test was set to $\text{0.5\%}$ instead of $\text{0.1\%}$ to avoid overextension of the calculation time. However, it is verified that by refining the time discretization, the error made with the reference solution tends to zero.
