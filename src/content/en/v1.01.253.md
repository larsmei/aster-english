# v1.01.253 ZZZZ253 – Non-linear mechanical calculation with mesh change

**Summary:**

This test has no physical meaning, it is essentially a computer test.

Modelization A:

In this Modelling, we want to check the possibility of performing a mechanical calculation by starting on one mesh and finishing on another.

The reference results are given by the same calculation made only on the first mesh and only on the second mesh.

Mesh change is done using the PROJ_CHAMP command with the COLLOCATION method.

This documentation is deliberately succinct.
