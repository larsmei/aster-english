# v4.22.303 TTNL303 - Infinite wall subjected to temperature jump with variable properties

**Summary:**

This test is based on the independent validation of version 3 in nonlinear transient thermal analysis.

This is a linear 1D problem represented by four modellings, two plane and two volume.

The functions tested are as follows:

- element thermal plane,
- element thermal volumetric,
- variable thermal conductivity,
- nonlinear transient thermal analysis algorithm,
- Limit conditions: temperature imposed with jump.

The value of the test lies in the consideration of variable properties in transient analysis and the variation in temperature imposed over time.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The reference solution was obtained with the elements finite calculation software "IVOHEAT" [bib2] cited in the reference [bib1]. This solution is based on mesh consisting of 20 elements isoparametric at 4 nodes of identical size, using a modified Crank-Nicolson method with ${10}^{-6}$ accuracy.

### 2.2 Baseline

Temperature at:

- $t=10s$ for $x=0.01,0.02,0.04,0.06,0.08$ and $0.1$ ,
- $t=13s$ for $x=0.01,0.02,0.04,0.06,0.08$ and $0.1$ .

### 2.3 Bibliographical references

  1. Orivuori, "Efficient method for solution of nonlinear heat conduction problems", Int. J. num. Meth. Engng, vol. 14, No. 10, pp. 1461-1476, 1979

## 13 Summary of the results

Modelling of the four modellingss performed gives results that slightly exceed the tolerance initially set (2%).

- 2.013% for PLAN Modelling (TRIA6),
- 1.928% for 3D modelling (PENTA6),
- 1.913% for 3D modelling (HEXA8),
- 1.985% for PLAN Modelling (TRIA3, QUAD4).

It is found that this difference is regardless of the Modelling close to 2%, all modellings performed, have the same cutting in the direction of temperature propagation.

The results obtained are considered acceptable for all modellings

This test tested the consideration of variable thermal conductivity with a limit condition that varied over time.
