# v1.01.413 ZZZZ413 – MED print validation of sub-point elements

**Summary:**

The objective is to validate MED printing of sub-point elements. The test case validates the following impressions:

- multifibre beams,
- pipes,
- multilayer plates with and without excentre,
- grids with excentre.

An elastic calculation is performed in such a way as to obtain a stress, displacement or temperature field. The position of the subpoints and the value of the components of the field of are tested.

## 3 Modelling A

### 3.1 Mesh characteristics

The mesh consists of multifibre beam element that model a pipe. The sub-points of the elements beam are defined to match the position of the sub-points of the elements pipes that will be used in Modelling B.

This test allows:

- check the position of sub-points. Positions are explicitly given in the command file.
- check the values of SIXX at all subpoints.
- In comparison with model B, check the orientations, the positions of the sub-points.
