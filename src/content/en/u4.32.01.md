# u4.32.01 Operator CALC_FONC_INTERP

## 1 Purpose

Build a concept of type fonction or fonction_c from a FORMULE function with 1 or 2 variables. Real functions of real variables, complex functions of real variables, and nappes may be defined.

One can also produce a new real or complex function, or a nappe, by interpolating another function of the same type (real, complex, or a nappe).

The use of CALC_FONC_INTERP allows a tabulation of the formula prior to the analysis. Its use is recommended before any transient and/or non-linear analysis, for performance reasons.

The operator is not re-entrant; it produces a new function or a nappe.

## 2 Syntax

```text
/ formule
/ nappe
/ fonction
/ fonction_c = CALC_FONC_INTERP(
    ◆ FONCTION = formule / nappe / fonction / fonction_c,
    ◆ / VALE_PARA = float,
      / LIST_PARA = listr8,
    ◇ NOM_RESU = text,
    ◇ NOM_PARA = text,
    ◇ INTERPOL = / "LIN",
                 / "LOG",
    ◇ PROL_DROITE = / "EXCLU",
                    / "CONSTANT",
                    / "LINEAIRE",
    ◇ PROL_GAUCHE = / "EXCLU",
                    / "CONSTANT",
                    / "LINEAIRE",
    ◇ NOM_PARA_FONC = text,
    # Si: exists("NOM_PARA_FONC")
        ◆ / VALE_PARA_FONC = float,
          / LIST_PARA_FONC = listr8,
        ◇ INTERPOL_FONC = / "LIN",
                          / "LOG",
        ◇ PROL_DROITE_FONC = / "EXCLU",
                             / "CONSTANT",
                             / "LINEAIRE",
        ◇ PROL_GAUCHE_FONC = / "EXCLU",
                             / "CONSTANT",
                             / "LINEAIRE",
    ◇ TITRE = text,
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand FONCTION

```text
♦    FONCTION = f
```

Name of the FORMULE (interpretable function (FORMULE, cf. [U4.31.05](doc:u4.31.05))).

This function may have one or two variables in the case of real formulae, and one variable only in the case of complex formulae.

One may nevertheless create a new function (respectively fonction_c, nappe) from a function (respectively fonction_c, nappe) by interpolating the first on a different list of parameters. This possibility is used essentially in the macro-commands.

When the input type is a formula and NOM_PARA_FONC is supplied, the data structure produced is a nappe.

**Note**

*When interpolating a formula with two parameters, one checks the consistency between the parameters of the formula and the keywords* NOM_PARA *and* NOM_PARA_FONC *. See the example in paragraph*  4.2 *.*

### 3.2 Operand NOM_RESU

```text
◊    NOM_RESU = nr
```

Designates the name of the result; the function thus created is a function whose value has the name nr (8 characters).

### 3.3 Operand NOM_PARA

```text
◊    NOM_PARA = nr
```

Designates the name of the parameter of the function or of the nappe. By default, the name of the parameter of the formula or function supplied is used.

### 3.4 Operands VALE_PARA/LIST_PARA

```text
◊    /    VALE_PARA = lvale,
```

lvale is the list of values of the parameter.

```text
/    LIST_PARA = lpara,
```

lpara is the list of values of the parameter: it is a concept of type listr8 created beforehand by the command DEFI_LIST_REEL [U4.34.01](doc:u4.34.01).

### 3.5 Operands PROL_DROITE and PROL_GAUCHE

```text
◊    PROL_DROITE et PROL_GAUCHE =
```

Define the type of prolongation to the right (to the left) of the domain of definition of the parameter of the function or of the nappe

| 'CONSTANT' | for a prolongation with the last (or first) value of the function, |
| --- | --- |
| 'LINEAIRE' | for a prolongation along the first defined segment (PROL_GAUCHE) or the last defined segment (PROL_DROITE), |
| 'EXCLU' | extrapolation of the values outside the domain of definition of the parameter is forbidden (in this case, if an analysis requests a value of the function outside the domain of definition, the code will stop with a fatal error), |

### 3.6 Operand INTERPOL

```text
◊    INTERPOL=
```

Type of interpolation of the function between the values of the variable, or type of interpolation of the nappe between the values of the parameter. After this keyword one expects a list of parameters (two at most).

| 'LIN': | linear, |
| --- | --- |
| 'LOG': | logarithmic, |

If a single value is given, the interpolation will be the same for the abscissae and the ordinates. If two values are given, the first corresponds to the interpolation of the abscissae and the second to the interpolation of the ordinates.

### 3.7 Operand NOM_PARA_FONC

```text
◊    NOM_PARA_FONC = nr
```

Designates the name of the variable of the functions defining the nappe. When the input type is a formula and this keyword is filled in, the data structure produced is a nappe.

### 3.8 Operands VALE_PARA_FONC/LIST_PARA_FONC

```text
◊    /    VALE_PARA_FONC = lvale,
```

lvale is the list of values of the variable of the functions defining the nappe.

```text
/    LIST_PARA_FONC = lpara,
```

lpara is the list of values of the variable of the functions defining the nappe: it is a concept of type listr8 created beforehand by the command DEFI_LIST_REEL [U4.34.01](doc:u4.34.01).

### 3.9 Operands PROL_DROITE_FONC and PROL_GAUCHE_FONC

```text
◊    PROL_DROITE_FONC et PROL_GAUCHE_FONC =
```

Define the type of prolongation to the right (to the left) of the domain of definition of the variable of the functions of the nappe:

'CONSTANT', 'LINEAIRE', 'EXCLU' have the same meaning as previously.

### 3.10 Operand INTERPOL_FONC

```text
◊    INTERPOL_FONC=
```

Type of interpolation of the functions between the values of the variable of the functions defining the nappe. After this keyword one expects a list of parameters (two at most).

The behaviour is identical to that of INTERPOL.

### 3.11 Operand INFO

```text
◊    INFO=
```

Specifies the printout options in the MESSAGE file.

| 1 : | no printout (default option) |
| --- | --- |
| 2 : | printout of the parameters plus the list of the first 10 values in increasing order of the parameter |

### 3.12 Operand TITRE

```text
◊    TITRE = ti
```

Title attached to the concept produced by this operator [U4.03.01](doc:u4.03.01).

## 4 Examples

### 4.1 Case of a function

#### 4.1.1 Define the FORMULE function sin(t)

```text
SI = FORMULE ( NOM_PARA = 'INST',

VALE = 'sin(INST)'    )
```

#### 4.1.2 Tabulate sin(t) from a list of reals

```text
DEPI    = 2.*pi
PAS0    = DEPI/200.
LI1    = DEFI_LIST_REEL    (DEBUT = 0, INTERVALLE=_F(JUSQU_A=DEPI, PAS=PAS0),)

SI1    = CALC_FONC_INTERP    (FONCTION= SI, LIST_PARA = LI1, NOM_RESU = 'DEPL',
PROL_GAUCHE='EXCLU', PROL_DROITE='CONSTANT',
INTERPOL='LIN', TITRE='FONCTION SINUS'    )
```

#### 4.1.3 Tabulate sin(t) from a list of values

```text
LI2    = ( 0.,0.01,0.03,0.04,0.05,0.06,0.07,0.08,0.09,0.10)

SI2    = CALC_FONC_INTERP    (    FONCTION = SI, VALE_PARA = LI2,
NOM_PARA =’INST’,
PROL_GAUCHE = 'EXCLU', PROL_DROITE = 'EXCLU',
INTERPOL = 'LIN', TITRE = 'FONCTION SINUS')
```

### 4.2 Case of a nappe

#### 4.2.1 Define the FORMULE function sin(omega * t)

```text
SI = FORMULE ( NOM_PARA = ('FREQ', 'INST'),

VALE = 'sin(2*pi*FREQ*INST)')
```

#### 4.2.2 Tabulate sin(omega * t) from a list of time instants

The parameter of the nappe is 'FREQ'; the variable of the functions defining the nappe is 'INST'. One checks in CALC_FONC_INTERP that the first parameter of the formula is the same as NOM_PARA, and that the second parameter of the formula is identical to NOM_PARA_FONC.

```text
LI_FREQ    = DEFI_LIST_REEL    (DEBUT = 10, INTERVALLE=_F(JUSQU_A=100, PAS=10),)

LI_INST    = DEFI_LIST_REEL    (DEBUT = 0, INTERVALLE=_F(JUSQU_A=100, PAS=1),)

SI1    = CALC_FONC_INTERP    (    FONCTION= SI,
NOM_RESU = 'DEPL',
NOM_PARA_FONC='INST',

LIST_PARA_FONC = LI_INST
PROL_GAUCHE_FONC='EXCLU',
PROL_DROITE_FONC='CONSTANT',
INTERPOL_FONC='LIN',

NOM_PARA='FREQ',

LIST_PARA = LI_FREQ
PROL_GAUCHE='LINEAIRE',
PROL_DROITE='LINEAIRE',
INTERPOL='LIN',

TITRE='FONCTION SINUS',)
```
