# v2.02.011 SDLL11 - Free-free thin circular ring

**Summary:**

This test case allows testing the frequencies and vibration modes of a free-flow ring.

Eight modellings are performed, for each of which the Modelling and type of mesh cell tested is specified.

The eigenfrequency method used is the Sorensen method for modellings A, B, C, D, E, F, G, K and the Lanczos method for Modelling I.

- modellings 3D

  - $A$ Modelling: mesh cell HEXA20
  - $B$ Modelling: mesh cell HEXA8
  - $C$ Modelling: mesh cell PENTA15
  - $D$ Modelling: mesh cell TETRA10
- Modelling POU_D_T

  - $E$ Modelling: mesh cell SEG2
- modellings 2D

  - $F$ Modelling: mesh cell QUAD8
  - $G$ Modelling: mesh cell QUAD8
  - $I$ Modelling: mesh cell QUAD8
- Modelling COQUE_SOLIDE

  - $K$ Modelling: mesh cell HEXA9

## 2 reference solution

### 2.1 Calculation method used for reference solution

- Vibration modes in the plane

For these vibration modes, the bending equation of the curved beams of V. Boussinesq (1883), without the extension of the neutral fiber leads to:

$$
{f}_{i}=\frac{1}{2\pi }\sqrt{(\frac{{i}^{2}{({i}^{2}-1)}^{2}}{{i}^{2}+1}\times \frac{{\mathit{EI}}_{Z}}{\rho {\mathit{AR}}^{4}})}
$$

The reference solution is established for thin arcs such as $\alpha R\ge 100\sqrt{(\frac{{I}_{z}}{A})}$ with $\alpha$ , central angle in radians.

- Off-plane vibration modes

For transverse vibration modes with rectangular cross section, the solution was established using the results of two calculation codes, using different formulations.
