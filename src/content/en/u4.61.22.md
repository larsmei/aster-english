# u4.61.22 Operator ASSE_MATRICE

## 1 Purpose

Create a matrix by assembly of elementary matrices.

The matrix produced is “sparse”; it is stored in “morse” form.

Produces a data structure of type matr_asse_* .

## 2 Syntax

```text
/ matr_asse_depl_c
/ matr_asse_temp_r
/ matr_asse_depl_r
/ matr_asse_pres_c = ASSE_MATRICE(
    ◆ MATR_ELEM = matr_elem_pres_c / matr_elem_depl_r / matr_elem_temp_r / matr_elem_depl_c,
    ◆ NUME_DDL = nume_ddl,
    ◇ SYME = "OUI" (ou non renseigné),
    ◇ CHAR_CINE = char_cine_acou / char_cine_ther / char_cine_meca,
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand MATR_ELEM

```text
♦    MATR_ELEM = mel,
```

Name of the matr_elem_* concept to be assembled.

### 3.2 Numbering and storage

```text
♦    NUME_DDL = nu,
```

Specifies the numbering of the equations of the assembled system and the storage of the matrix.

### 3.3 Operand CHAR_CINE

```text
◊    CHAR_CINE = cha,
```

Name of the kinematic load to be taken into account in the assembled matrix for a treatment by elimination of the imposed degrees of freedom (see the command AFFE_CHAR_CINE [U4.44.03](doc:u4.44.03)).

### 3.4 Operand SYME

> à    SYME = 'OUI'

This argument can take only the value 'OUI'. In this case, one forces the symmetrisation of the matrix after assembly. Thus, if the matrix **K** created by assembly is non-symmetric, the keyword SYME = 'OUI' makes it possible to symmetrise it and to replace it by:

$\mathrm{ma}=\frac{1}{2}(K+{K}^{T})$

### 3.5 Operand INFO

```text
◊    INFO
```

Allows the printout of information on the assembled matrix

| 1: | no printout, |
| --- | --- |
| 2: | printout of the number of stored terms and of the conditioning coefficient of the degrees of freedom of type 'LAGR', |

## 4 Example

```text
matas =    ASSE_MATRICE        (    NUME_DDL = nu ,
MATR_ELEM = mel,
)
```

**Note:**

*The elementary matrices of* *mel will be assembled according to the numbering* *nu.*

*This numbering must therefore take into account* **all the degrees of freedom of these elementary matrices (in particular the degrees of freedom corresponding to the dualisation of the boundary conditions).** *One will therefore do:*

*mel = CALC_MATR_ELEM(OPTION = 'RIGI_MECA',*

*MODELE = mo, CHARGE = condlim,)*

*nu = NUME_DDL(MATR_RIGI = mel)*

*matas = ASSE_MATRICE (NUME_DDL = nu, MATR_ELEM = mel,)*
