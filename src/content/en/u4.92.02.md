# u4.92.02 Procedure TEST_FONCTION

## 1 Purpose

Extract a numerical value or an attribute of a function for comparison with a reference value. The function is a data structure of type fonction or nappe.

This procedure then writes a conventional message "OK" (if it is good) or "NOOK" (otherwise).

It does not stop the execution if the test is not satisfied; this makes it possible to use it either systematically for the validation tests, or to extract and print a value of a function or of a nappe for a particular value of a parameter.

This command is used essentially by the test cases in order to validate the non-regression of the results.

## 2 Syntax

```text
TEST_FONCTION(
    ◇ VALEUR = _F(
         ◆ FONCTION = formule / fonction_c / fonction / nappe,
         ◇ NOM_PARA = text,
         ◆ / VALE_PARA = float,
           / INTERVALLE = float,
         # Si: True
             ◆ / VALE_CALC_C = complex,
               / VALE_CALC = float,
             ◇ VALE_ABS = / "OUI",
                          / "NON" (par défaut),
             ◇ TYPE_TEST = / "SOMM_ABS",
                           / "SOMM",
                           / "MAX",
                           / "MIN",
             ◇ TOLE_MACHINE = float (défaut: 1e-06),
             ◇ CRITERE = / "RELATIF" (par défaut),
                         / "ABSOLU",
             # Si: exists("REFERENCE")
                 ◆ / VALE_REFE_C = complex,
                   / VALE_REFE = float,
                 ◇ PRECISION = float (défaut: 0.001),
             ◇ REFERENCE = / "ANALYTIQUE",
                           / "SOURCE_EXTERNE",
                           / "AUTRE_ASTER",
                           / "NON_DEFINI",
             # Si: exists("VALE_CALC") and abs(VALE_CALC if type(VALE_CALC) not in (list, tuple) else VALE_CALC[0]) < 1.e-16
                 ◇ ORDRE_GRANDEUR = float,
             ◇ LEGENDE = text,
      ),
    ◇ ATTRIBUT = _F(
         ◆ FONCTION = formule / fonction_c / fonction / nappe,
         ◇ PARA = float,
         ◇ CRIT_PARA = / "RELATIF" (par défaut),
                       / "ABSOLU",
         ◇ PREC_PARA = float (défaut: 0.001),
         ◆ ATTR = / "NOM_PARA",
                  / "NOM_RESU",
                  / "PROL_DROITE",
                  / "PROL_GAUCHE",
                  / "INTERPOL",
                  / "PROL_GAUCHE_FONC",
                  / "PROL_DROITE_FONC",
                  / "INTERPOL_FONC",
                  / "NOM_PARA_FONC",
         ◆ ATTR_REFE = text,
         ◇ REFERENCE = / "ANALYTIQUE",
                       / "SOURCE_EXTERNE",
                       / "AUTRE_ASTER",
      ),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Keyword VALEUR

```text
♦    VALEUR =
```

Factor keyword for testing a value of a function or of a nappe.

#### 3.1.1 Operand FONCTION

```text
♦    FONCTION = f
```

Name of the function (with one parameter) or of the nappe (with two parameters) on which the operation is performed.

#### 3.1.2 Operand NOM_PARA

```text
◊    NOM_PARA = lnom
```

In the case of a function, this keyword is not processed.

In the case of a nappe, the user will give 2 parameter names: the first defining the parameter of the nappe, the second defining the parameter of the function that one wants to test (see the command DEFI_NAPPE [U4.31.03](doc:u4.31.03)).

#### 3.1.3 Operand VALE_PARA

```text
♦    VALE_PARA = lpara
```

In the case of a function, the user gives the value of the parameter for which the value of the function is tested.

In the case of a nappe, the user gives the 2 values corresponding to the names of the two parameters (that of the nappe and that of the function).

#### 3.1.4 Keywords common to the commands TEST_XXX

The definition of the non-regression and reference values, as well as of the allowable tolerances and of the comparison criteria, is detailed in the documentation [u4.92.01](doc:u4.92.01) of the command TEST_RESU.

The specific features of TEST_FONCTION are:

- no integer values or character strings,
- no tolerance on the value of the parameter (TOLE_MACHINE and CRITERE take only a single value).

### 3.2 Keyword ATTRIBUT

```text
/    ATTRIBUT=
```

Factor keyword for testing an attribute of a function or of a nappe.

#### 3.2.1 Operand FONCTION

```text
♦    FONCTION = f
```

Name of the function or of the nappe on which the operation is performed.

#### 3.2.2 Operand PARA

```text
◊    PARA = reel
```

In the case of a function, this keyword is not necessary.

In the case of a nappe, the user gives the value of the parameter in order to retrieve the function so as to test the attribute.

#### 3.2.3 Operands PREC_PARA / CRIT_PARA

```text
◊    PREC_PARA = prec
```

One searches for the function defined by the value of the parameter in an interval defined by the absolute or relative position:

"inst ± prec" (cf. CRITERE[§3.2.3]).

By default prec = 1.0D-3.

```text
◊    CRIT_PARA =
```

'RELATIF': the search interval is: [inst(1-prec),inst(1+prec)]

'ABSOLU': the search interval is: [inst-prec,inst+prec]

#### 3.2.4 Operand ATTR

```text
♦    ATTR =
```

Name of the attribute to be tested. For the meaning of the attributes refer to DEFI_FONCTION [U4.31.02](doc:u4.31.02) or to DEFI_NAPPE [U4.31.03](doc:u4.31.03).

#### 3.2.5 Operand ATTR_REFE

```text
♦    ATTR_REFE = attr
```

Reference attribute. For the meaning of the attributes refer to DEFI_FONCTION [U4.31.02](doc:u4.31.02) or to DEFI_NAPPE [U4.31.03](doc:u4.31.03).

## 4 Examples

### 4.1 Checking of a nappe

```text
df1    =    DEFI_FONCTION    (    NOM_PARA = 'INST', NOM_RESU = 'DEPL',
VALE = (0.,0.,1.,1.,2.,2.,3.,3.,4.,4. )    )
df2    =    DEFI_FONCTION    (    NOM_PARA = 'INST', NOM_RESU = 'DEPL',
VALE = (3., 3., 4., 4., 5., 5. )            )
dn1    =    DEFI_NAPPE    (    NOM_PARA = 'AMOR', NOM_RESU = 'DEPL',
VALE = (0.01, 0.02),
FONCTION = ( df1, df2    ))
```

```text
TEST_FONCTION    (
```

# one checks the attribute 'NOM_PARA' of the function df1 in the nappe dn1

```text
ATTRIBUT = ( _F(    FONCTION =    dn1    ,
PARA = 0.01,    #    0.01 atteint df1
ATTR = 'NOM_PARA_FONC',
ATTR_REFE = 'INST'    ),
```

# one checks the attribute 'NOM_PARA' of the nappe dn1

```text
_F(    FONCTION =    dn1    ,
ATTR = 'NOM_PARA',
ATTR_REFE = 'AMOR'    )),
```

# one checks a value of the nappe dn1 (in practice on the function df1)

```text
VALEUR =    _F(    FONCTION =    dn1,
NOM_PARA = ('AMOR', 'INST'    ),
VALE_PARA = ( 0.01, 1.    ),
VALE_REFE = 1.    )
)
```

### 4.2 Checking of a function

```text
li1=DEFI_LIST_REEL(    DEBUT=0.,
INTERVALLE=_F(JUSQU_A=2*pi, PAS=2*pi/20),    )

f1=FORMULE(    NOM_PARA=’INST’,
VALE=’sin(INST) + cos(INST)’,    )

fonc=CALC_FONC_INTERP    (    FONCTION=f1,
LIST_PARA=li1,
NOM_RESU=’DEPL’,
INTERPOL=’LIN’,    )

TEST_FONCTION(

# on teste un attribut de la fonction
ATTRIBUT=_F(    FONCTION=fonc,
ATTR=’INTERPOL’,
ATTR_REFE=’LIN LIN’,),

    # on teste une valeur de la fonction
VALEUR=_F    (    FONCTION=fonc,
VALE_PARA=pi,
REFERENCE='ANALYTIQUE',
VALE_CALC=-1.,
VALE_REFE=sin(pi)+cos(pi),    ),    )
```
