# u4.32.13 Macro-command LISS_SPECTRE

## 1 Purpose

This macro-command makes it possible to smooth spectra from tables coming from MACR_SPECTRE or from nappes defined by the user, by means of calls to CALC_FONCTION/LISS_ENVELOPPE. The tables coming from MACR_SPECTRE are transformed into nappes (frequency, damping) before grouping and smoothing.

The spectra supplied are grouped by direction and by floor before the smoothing is carried out.

Finally, four files are created for a given floor and a given direction:

- printout of the smoothed spectra in TABLEAU format
- printout of the smoothed spectra in graphical format
- printout of the envelope of the raw spectra, possibly broadened, in TABLEAU format
- printout of the envelope of the raw spectra, possibly broadened, and of the smoothed spectra in graphical format

These files are created in REPE_OUT.

## 2 Syntax

```text
LISS_SPECTRE(
    ◆ SPECTRE = _F(
         ◆ / TABLE = table,
           / NAPPE = nappe,
         ◇ ELARG = float,
         # Si: exists("NAPPE")
             ◆ DIRECTION = / "X",
                           / "Y",
                           / "Z",
                           / "H",
             ◆ NOM = text,
             ◇ BATIMENT = text,
             ◇ COMMENTAIRE = text,
      ),
    ◆ OPTION = / "VERIFICATION",
               / "CONCEPTION",
    ◇ FREQ_MIN = float,
    ◇ FREQ_MAX = float,
    ◇ NB_FREQ_LISS = int (défaut: 10),
    ◇ ZPA = float,
    ◇ BORNE_X = float,
    ◇ BORNE_Y = float,
    ◇ ECHELLE_X = / "LIN" (par défaut),
                  / "LOG",
    ◇ ECHELLE_Y = / "LIN" (par défaut),
                  / "LOG",
    ◇ LEGENDE_X = text,
    ◇ LEGENDE_Y = text,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Keyword SPECTRE

This keyword is mandatory in order to supply the various spectra to be processed.

#### 3.1.1 Operand TABLE

This operand makes it possible to supply spectra in the form of a table coming from the macro-command MACR_SPECTRE. In this case, the macro-command builds nappes from the table supplied (with parameters FREQ and AMOR). One nappe is built for a given floor name and a given direction. In addition to the floor name, the building name and a comment are recovered if they are present (see [U4.32.11](doc:u4.32.11)).

#### 3.1.2 Operand NAPPE

This operand allows the user to supply spectra directly in the form of nappes whose parameters are the frequency and the damping. Additional information must then be supplied in order to proceed to the stage of grouping the nappes by direction and by floor. These are the operands DIRECTION and NOM. The operands BATIMENT and COMMENTAIRE may also be supplied in order to fill the title blocks of the graphical outputs.

#### 3.1.3 Operand DIRECTION

This keyword, mandatory if the spectra are defined by the keyword NAPPE, makes it possible to supply the direction of the spectra. It takes one of the following 4 values: ‘X’, ‘Y’, ‘Z’, ‘H’.

#### 3.1.4 Operand NOM

This keyword makes it possible to define the name of the floor from which the spectrum defined by the keyword NAPPE comes.

It is mandatory if NAPPE is present.

#### 3.1.5 Operand BATIMENT

This keyword makes it possible to define the name of the building in which the floor from which the spectrum defined by the keyword NAPPE comes is located.

This keyword is optional. If it is supplied, it is used in particular for the naming of the “tables” and “figures” files created.

#### 3.1.6 Operand COMMENTAIRE

This keyword makes it possible to give a comment related to the spectrum defined by the keyword NAPPE.

This keyword is optional. If it is supplied, it will appear in the subtitles of the figures created.

#### 3.1.7 Operand ELARG

This keyword makes it possible to define the broadening which will be applied to the spectrum during the smoothing stage (call to CALC_FONCTION/LISS_ENVELOPPE).

The effect of this broadening value is explained in [U4.32.04](doc:u4.32.04) (see ELARG in LISS_ENVELOPPE).

Note: this keyword has an effect only for OPTION=’VERIFICATION’.

### 3.2 Keyword OPTION

This mandatory keyword makes it possible to define the smoothing option of CALC_FONCTION/LISS_ENVELOPPE.

> / 'CONCEPTION'

```text
La première étape consiste à réaliser une enveloppe sur les spectres fournis. Dans une seconde étape, on réalise le lissage du spectre obtenu en fonction du nombre de points lissés demandés NB_FREQ_LISS.

/ 'VERIFICATION'

La première étape consiste à réaliser un lissage de chaque spectre fourni. Puis, on réalise un élargissement de chaque spectre suivant les coefficients fournis dans ELARG. Dans une troisième étape, on calcule l’enveloppe des spectres élargis. Enfin, on réalise le lissage du spectre obtenu en fonction du nombre de points lissés demandés.
```

### 3.3 Keyword NB_FREQ_LISS

Number of frequencies required for the smoothed spectra. In the case of the option ' CONCEPTION ', only one value is supplied. For the option ' VERIFICATION ', two values may be supplied in the form of a pair, which will be applied respectively to the first and to the second smoothing.

### 3.4 Keywords FREQ_MIN and FREQ_MAX

Frequency range of definition of the smoothed spectrum. The frequencies given under FREQ_MIN and FREQ_MAX must be chosen from among the discretisation frequencies of the raw spectrum. By default, the complete spectrum is considered.

### 3.5 Keyword ZPA

Value of the high-frequency acceleration which one wishes to impose for the smoothed spectra. This keyword is optional. By default, it is the ZPA value of the spectrum with the least damping which is retained.

### 3.6 Keywords BORNE_X, BORNE_Y, ECHELLE_X, ECHELLE_Y, LEGENDE_X, LEGENDE_Y

These keywords are used when printing the figures. They are passed to IMPR_FONCTION. The details are given in [U4.33.01](doc:u4.33.01).
