# v6.04.252 SSNV25 2 – Basic validation of GTN flat deformation damage law with simulations of a element single shear volume

**Summary:**

This test case validates the integration algorithm of the Gurson – Tvergaard – Needleman ($\mathit{GTN}$) damage law with the standard elements sub-integrated or mixed in large deformations. A single shear element volume is modelled.

The different modellings processed are:

- **Model A** ($2D$ ): D_PLAN_SI.
- **Modelling** **B** ($2D$ ): D_PLAN_GRAD_VARI.
- **Modelling** **C** ($2D$ ): D_PLAN_GRAD_INCO.
- **Modelling** **D** ($3D$ ): 3D_SI.
- **Modelling** **E** ($3D$ ): 3D_GRAD_VARI.
- **Modelling** **F** ($3D$ ): 3D_GRAD_INCO
- **Modelling** **I** ($2D$ ): D_PLAN_GRAD_HHO - LINEAIRE
- **Modelling** **J** ($3D$ ): D_PLAN_GRAD_HHO - QUADRATIQUE
- **Modelling** **K** ($3D$ ): 3D_GRAD_HHO - LINEAIRE
- **Modelling** **L** ($3D$ ): 3D_GRAD_HHO - QUADRATIQUE

## 1 Reference problem

### 1.1 Geometry

According to $\mathrm{2D}$ (plane deformation) or $\mathrm{3D}$ Modelling, one square or one side cube 0.05 $\text{mm}$ is considered respectively (see Figure 1.1-1). Due to symmetry, only one quarter of the geometry is represented.

**Figure** 1.1-a **: Geometry of one square** **(a) and one cube (b)**

### 1.2 Material properties

Elasticity:

| $E=190000\text{MPa}$ | Young's modulus |
| --- | --- |
| $\nu =0.3$ | Poisson's ratio |

Nutrient curve:

$R(\kappa )=488.36+57.13(1-\exp(-8613\kappa ))+238.73(1-\exp(-10.39\kappa ))$

Ductile Damage Law GTN:

| ${q}_{1}=1.5$ | GTN model parameter |
| --- | --- |
| ${q}_{2}=1.07$ | GTN model parameter |
| ${f}_{0}=0.01$ | Initial porosity |
| ${f}_{n}=0$ | Germination parameter |
| ${f}_{c}=0.05$ | Coalescence porosity |
| $\delta =3$ | Acceleration coefficient related to coalescence |
| $c=2.22N$ | Non-local parameter |
| $r=5000\mathit{MPa}$ | Lagrange's penalization parameter |

In particular, the non-local $c$ parameter and the $r$ penalty parameter are used only in the $\mathit{GTN}$ gradient law.

|  | R2 = 238.731127339 | COAL_PORO = 0.05 |  |
|  | GAMMA_2=10.386585592 | COAL_ACCE = 3 |  |

### 1.3 Boundary conditions and loads

For $2D$ Modelling (plane deformation), horizontal displacements of all nodes are controlled: ${u}_{x}=10y$ , vertical displacements of all nodes are blocked (see Figure 1.1-1(a) for geometry).

For $3D$ modelling , the $X$ axis movements of all nodes are controlled: ${u}_{x}=10y$ , the $Y$ axis and the $Z$ axis are blocked (see Figure 1.1-1(b) for geometry).

Boundary conditions and loads are imposed in this way so that the $2D$ and $3D$ problems are identical and homogeneous.

The load is imposed using 1000 time step identical. The pseudo-calculation time is 1.
