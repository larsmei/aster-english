# v2.02.124 SDLL124 - Rotating beam with 3 discs subject to gyroscopy

**Summary:**

This test validates the calculation of the rotational modes of a rotating shaft system with the CALC_MODE_ROTATION command.

In this test, it is a simple rotor model with 3 discs, supported by hydrodynamic bearings. This example is taken from the reference [bib1].

The reference results are derived from a calculation with ROTORINSA, [bib2], finished elements software designed to predict dynamic bending rotor behaviour.

A good match is observed between the Code_Aster and reference solution results.

## 1 Reference problem

### 1.1 Geometry

A simple rotor model supported by 2 bearings (respectively first and last node rotor), consists of 3 discs, the section of the shaft is $0.05m$ radius. It measures $1.3m$ (see figure below). The rotor is rotating according to the Z axis.

${L}_{1}=0.2m$ ${L}_{2}=0.3m$ ${L}_{3}=0.5m$ ${L}_{4}=0.3m$

### 1.2 Material properties

The characteristics of the shaft material and discs are:

- Young's modulus $E={2.10}^{11}$
- Density $\rho =7800\mathrm{kg}/{m}^{3}$
- Poisson's ratio $\nu =0.3$

### 1.3 boundary conditions

To block rigid body-type movements in the $z$ direction, the degree of freedom $\mathit{DZ}$ is blocked at the node of the first landing (first node of the shaft).

## 2 reference solution

### 2.1 Method of calculation

The reference results are given by ROTORINSA, a finite elements code designed to predict the dynamic behaviour of flexing rotors. The following parameters were used for the reference results:

- The calculation is for a number of $\mathrm{NVES}=8+4$ rotation modes in ROTORINSA.
- The rotation speed range is defined from $0$ to $30000\mathrm{tr}/\mathrm{mn}$ with a $10000\mathrm{tr}/\mathrm{mn}$ pitch.

### 2.2 Quantities and reference results

The ROTORINSA results give the bending mode frequencies.

The calculation of the rotational modes is done with Code_Aster using the same Modelling as ROTORINSA. The results of Code_Aster give both the frequencies of the bending, twisting and tensile/compression modes. The number of modes calculated is 20.

## 4 Summary of the results

This test case validates the functionality for using the discrete non-symmetric elements since the same results are found by Code_Aster and ROTORINSA.
