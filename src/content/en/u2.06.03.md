# u2.06.03 User's guide for the modelling of mechanical damping

Linear and non-linear dynamic analyses, for the study of the vibratory response with a force excitation or an imposed motion, or for the complex modal analysis, require mechanical damping characteristics to be added to the stiffness and mass characteristics.

Several classical modellings are available, applicable to all the types of finite elements available. These modellings are available directly through the operators.

- the viscous damping model,
- the hysteretic damping model (also called "structural damping") for the harmonic analysis and the eigenmode analysis.

For finer analyses, it is also possible to model materials possessing a realistic viscoelastic constitutive behaviour, whose constitutive behaviour is described by a set of internal variables.

For analyses using a modal basis of real eigenmodes, it is possible to introduce modal damping coefficients. These coefficients may come equally well from tests carried out on site as from a modal analysis taking into account any one of the types of damping proposed.

## 1 Viscous damping model

The viscous damping model is the most commonly used. It corresponds to the modelling of a dissipated energy proportional to the vibratory velocity:

${E}_{d}=\frac{1}{2}{v}^{T}\text{Cv}=\frac{1}{2}{u}^{T}\text{Cu}$

where $C$ is the viscous damping matrix, with real coefficients.

It leads to the classical equations of structural dynamics:

$\text{Mu}+\text{Cu}+\text{Ku}=f(t)$

with $K$ the stiffness matrix and $M$ the mass matrix.

### 1.1 “Global” proportional viscous damping, or Rayleigh damping

This modelling, easy to implement, corresponds to a linear combination of the mass and stiffness matrices:

$C=\alpha K+\beta M$

It is currently available, using the operators DEFI_MATERIAU [U4.43.01 §3.1](doc:u4.43.01) and ASSEMBLAGE(OPTION='AMOR_MECA') [U4.61.21](doc:u4.61.21). One can also use COMB_MATR_ASSE [U4.72.01](doc:u4.72.01), after having assembled the stiffness and mass matrices with real coefficients. The option SANS_CMP='LAGR' must be used when combining the matrices in order to preserve the boundary conditions of the system (imposed by Lagrange relations in the stiffness matrix).

This approach allows the validation of solution algorithms,

It is not realistic for industrial studies, because it does not make it possible to represent the heterogeneity of the structure with respect to damping (dissipation at the supports or at the assemblies). Moreover, the global identification of the coefficients $\alpha$ and $\beta$ is possible, in experimental modal analysis, only for two distinct eigenfrequencies $\left[{f}_{1},{f}_{2}\right]$; it gives, for the eigenfrequencies $\omega \notin \left[{\omega}_{1},{\omega}_{2}\right]$ with $\omega =2\pi f$, an evolution law of the reduced damping of the form (see [R5.05.04](doc:r5.05.04)):

$2\xi =\alpha \omega +\frac{\beta}{\omega}$

For the discrete elements, the Rayleigh damping parameters not being definable in the operator AFFE_CARA_ELEM, if one wishes to take into account the contribution of these elements in the global Rayleigh damping matrix, one must necessarily go through the assembly method for this matrix with the operator COMB_MATR_ASSE. Without proceeding in this way, the global damping matrix will take into account only the contribution of the volume, surface or beam-type elements. If one uses the operator DYNA_NON_LINE, the Rayleigh damping therefore does not take into account the contribution of the discrete elements.

### 1.2 Viscous damping proportional to the elements of the model

#### 1.2.1 Damping characteristics

It is possible to build a damping matrix from each element of the model, as for the stiffness and the mass.

Several features can be used:

- the assignment of discrete elements, on POI1 or SEG2 mesh cells, by the operator AFFE_CARA_ELEM [U4.42.01](doc:u4.42.01). This makes it possible to define, with several possible modes of description, a damping matrix for each degree of freedom.
- the definition of a damping characteristic for any elastic material by the operator DEFI_MATERIAU [U4.43.01](doc:u4.43.01) by supplying the keywords `AMOR_ALPHA`

This material is then assigned to the mesh cells concerned.

#### 1.2.2 Computation of the damping matrices

For all types of finite elements (continuum, structural or discrete), it is possible to compute the real elementary matrices corresponding to the analysis option `AMOR_MECA`, after having computed the elementary matrices corresponding to the analysis options `RIGI_MECA` and `MASS_MECA` or `MASS_MECA_DIAG`; the elementary matrices are then of the form:

- when the material $i$, with proportional viscous damping characteristics $({\alpha}_{i},{\beta}_{i})$, is assigned to an element $C_{elem} = \alpha_{i} K_{elem} + \beta_{i} M_{elem}$
- for a discrete element $C_{elem} = A_{elem}$. When the discrete element is of type `DIS_CHOC` (thus defined with a penalisation stiffness), it is also possible to assign to it a damping which will be taken into account only when there is contact [R5.03.17](doc:r5.03.17).

This operation is possible with the command CALC_MATR_ELEM [U4.61.01](doc:u4.61.01) with the option `AMOR_MECA`.

The assembly of all the elementary damping matrices is obtained with the usual operator ASSE_MATRICE [U4.61.22](doc:u4.61.22). Note that one must use the same numberings and the same storage mode as for the stiffness and mass matrices (operator NUME_DDL [U4.61.11](doc:u4.61.11)). One may also recall that the use of the macro-command ASSEMBLAGE [U4.61.21](doc:u4.61.21) makes it possible to gather these stages advantageously.

One notes that the damping matrix obtained may be non-proportional: $C\ne \alpha K+\beta M$

#### 1.2.3 Use of the viscous damping matrix

The matrix $C$ is:

- usable for the direct linear dynamic analysis (keyword MATR_AMOR) with the linear dynamic response operators.
- indispensable for the complex modal analysis with the eigenvalue search operator.

For analyses on a modal basis, one must project this matrix into the subspace defined by a set $\Phi$ of real eigenmodes. This operation is possible with the operator PROJ_MATR_BASE [U4.63.12](doc:u4.63.12). Note that in the general case ($C$ non-proportional), the projected matrix is not diagonal. It nevertheless remains usable (keyword AMOR_GENE) for the computation of the dynamic response to a force or to an imposed motion in the modal space, with the linear dynamic response operator:

- Transient, Harmonic: DYNA_VIBRA [U4.53.03](doc:u4.53.03)
- Complex modal analysis: CALC_MODES [U4.52.02](doc:u4.52.02)

#### 1.2.4 Use of viscous modal damping

For analyses on a modal basis of real eigenmodes, the dynamic differential equation in generalised coordinates:

${\ddot{q}}_{i}+2{\xi}_{i}{\omega}_{i}{\dot{q}}_{i}+{\omega}_{i}^{2}{q}_{i}=\frac{{\Phi}_{i}^{T}}{{\mu}_{i}}f(t)$

brings out a modal damping coefficient ${\xi}_{i}$ expressed as a fraction of the critical damping and the generalised mass of the mode ${\mu}_{i}$, which depends on the manner of normalisation of the eigenmode.

In the case of a strictly proportional damping matrix $C$, the coefficients ${\xi}_{i}$ are deduced from the diagonal terms of the generalised damping matrix ${\Phi}^{T}C\Phi$ by:

$2{\xi}_{i}{\omega}_{i}=\frac{{\Phi}_{i}^{T}C{\Phi}_{i}}{{\Phi}_{i}^{T}M{\Phi}_{i}}$

and in the case of eigenmodes normalised to unit modal mass $2{\xi}_{i}{\omega}_{i}={\Phi}_{i}^{T}C{\Phi}_{i}$

One can use this relation in the case of a non-proportional damping matrix $C$, by applying the Basile hypothesis, which is acceptable for weak dampings (in particular if there is no dominant localised damping) and for real eigenmodes that are sufficiently decoupled.

The modal damping coefficients can be supplied by command (keyword AMOR_REDUIT) to two operators for:

- Transient analysis in the modal space: DYNA_VIBRA [U4.53.03](doc:u4.53.03)
- Transient analysis in the physical space: DYNA_VIBRA [U4.53.03](doc:u4.53.03)
- Seismic analysis by oscillator spectrum: COMB_SISM_MODAL [U4.84.01](doc:u4.84.01)

Note that there is no tool for the automatic extraction of these coefficients from the generalised damping matrix ${\Phi}^{T}C\Phi$, a concept produced by the operator PROJ_MATR_BASE [U4.63.12](doc:u4.63.12).

## 2 Hysteretic damping model

The hysteretic damping model can be used to treat the harmonic responses of structures with viscoelastic materials. The hysteretic damping coefficient $\eta$ is determined from a test under harmonic cyclic loading at the angular frequency $\omega$ for which one obtains a stress–strain relation which makes it possible to define:

- the energy dissipated per cycle in the form:
  ${E}_{d}={\int}_{\text{cycle}}\sigma d\varepsilon$
- the complex Young's modulus ${E}^{\text{*}}$ from the stress–strain relation:
  $\sigma ={\sigma}_{0}{e}^{j\omega t}$ and $\varepsilon ={\varepsilon}_{0}{e}^{j(\omega t-\varphi )}$
  with the amplitudes: ${\sigma}_{0}$ and ${\varepsilon}_{0}$, the phase: $\varphi$
  $\text{E*}=\frac{\sigma}{\varepsilon}=(\frac{{\sigma}_{0}}{{\varepsilon}_{0}}){e}^{j\varphi }=(\frac{{\sigma}_{0}}{{\varepsilon}_{0}})(\cos\varphi +j\sin\varphi )$ where $E\text{*}={E}_{1}+j{E}_{2}={E}_{1}(1+j\eta )$
  with:

  - real part: ${E}_{1}=(\frac{{\sigma}_{0}}{{\varepsilon}_{0}})(\cos\varphi )$
  - imaginary part: ${E}_{2}=(\frac{{\sigma}_{0}}{{\varepsilon}_{0}})(\sin\varphi )$
  - dissipation factor: $\eta =\frac{{E}_{1}}{{E}_{2}}=\tan\varphi$

This leads to the equations of structural dynamics:

$M\ddot{u}+ K (1+j.\eta) u=f(\Omega )$

with $K$ the real elastic stiffness matrix, $M$ the mass matrix and $\eta$ the hysteretic damping coefficient. Note that one often speaks of a complex stiffness matrix.

This model is a simplified version of the standard viscoelastic model, and has several drawbacks:

- The model obtained cannot be transposed into the time domain, since this model would not be causal,
- This model does not present a dependence of the damping on frequency, unlike the standard viscoelastic model

It nevertheless constitutes a good approximation for the computation of harmonic responses in a reasonably narrow frequency band, and also has the advantage of being simple to implement.

### 2.1 “Global” hysteretic damping

This modelling, easy to implement, corresponds to:

$(-M{\omega}^{2}+j.\eta K+K)u=f(\Omega )$

It is currently available, using the operator COMB_MATR_ASSE [U4.72.01](doc:u4.72.01), after having assembled the stiffness matrix with real coefficients, but it is of little use:

- validation of solution algorithms,
- useless for industrial studies, because it does not make it possible to represent the heterogeneity of the structure with respect to damping (dissipation localised in particular zones of the structure treated with viscoelastic materials).

### 2.2 Hysteretic damping of the elements of the model

#### 2.2.1 Damping characteristics

It is possible to build a complex stiffness matrix from each element of the model, as for the real stiffness and the mass.

Two features can be used:

- the assignment of discrete elements, on POI1 or SEG2 mesh cells, by the operator AFFE_CARA_ELEM [U4.42.01](doc:u4.42.01). This makes it possible to define, with several possible modes of description, a **real stiffness matrix** for each degree of freedom **and** a hysteretic damping coefficient to be applied to this matrix `AMOR_HYST`.
- the definition of a damping characteristic for any elastic material by the operator DEFI_MATERIAU [U4.43.01](doc:u4.43.01) by the keyword `AMOR_HYST`.

This material is then assigned to the mesh cells concerned.

In the case where certain materials would not be considered as affected by hysteretic damping, it is necessary to assign to them a zero hysteretic damping.

#### 2.2.2 Computation of the damping matrices

For all types of finite elements (continuum, structural or discrete), it is possible to compute the complex elementary matrices corresponding to the analysis option `RIGI_MECA_HYST`, after having computed the elementary matrices corresponding to the analysis options `RIGI_MECA`. Each elementary matrix is then of the form:

- when the material $i$, with hysteretic damping characteristics ${\eta}_{i}$, is assigned to the element
${k}_{elem}^{*} = {k}_{elem} (1 + j.{\eta}_{i})$
- for a discrete element defined by a stiffness matrix K and a hysteretic damping coefficient $\eta$
${k}_{elem}^{*} = {k}_{discret} (1 + j.{\eta})$

This operation is possible with the operator CALC_MATR_ELEM [U4.61.01](doc:u4.61.01) option `RIGI_MECA_HYST`.
The assembly of the complex stiffness matrix $K\ast$, from the elementary matrices, is obtained with the usual operator ASSE_MATRICE [U4.61.22](doc:u4.61.22). Note that one must use the same numbering and the same storage mode as for the mass matrix (operator NUME_DDL [U4.61.11](doc:u4.61.11)).

The loading used for the computation of the real stiffness matrix (option `RIGI_MECA`) must be supplied by the keyword `CHARGE` for the computation of the complex elementary stiffness matrix.

#### 2.2.3 Use of the complex stiffness matrix

The complex stiffness matrix $K\ast$ can be used for the direct linear dynamic analysis (keyword MATR_RIGI) with the linear dynamic response operator DYNA_VIBRA [U4.53.03](doc:u4.53.03).

In the case where the model to be taken into account for the harmonic analysis is of large size, it may be of interest to resort to model-reduction methods. An efficient approach for strongly dissipative models is available in the documentation [U2.06.04](doc:u2.06.04).

The search for eigenvalues can be done only with certain settings of the eigenvalue search operator CALC_MODES [U4.52.02](doc:u4.52.02).

The reference documentation [R5.01.02](doc:r5.01.02) specifies the types of problems that one can treat and the possible settings.

This search leads to complex eigenmodes, which therefore cannot be used for analyses in the time domain.

Nevertheless, in the cases where the damping introduced remains weak, it is possible to compute the real modes associated with the associated non-dissipative model, and to assign to them the damping ratios computed by the complex-mode analysis in order to build a reduced model on a modal basis. This system can then be used to carry out a transient analysis in the modal space with DYNA_VIBRA [U4.53.03](doc:u4.53.03).

## 3 Viscoelastic damping model with internal variables

The viscoelastic damping model with an internal variable can be used to treat the harmonic and transient responses of structures with viscoelastic materials. This model relies on the existence of a constitutive law making it possible to determine the stress state as a function of the history of the strains:

$\sigma ={E}_{\infty}\varepsilon (t)-{\int}_{0}^{t}{E}_{v}(t-\tau )\frac{\partial \varepsilon (\tau )}{\partial \xi }d\tau$

where ${E}_{\infty}$ represents the high-frequency Young's modulus, and ${E}_{v}$ the relaxation modulus. This modulus can be represented in the time domain by a Prony series

${E}_{v}(t)={E}_{r}+{\sum}_{k=1}^{N}{E}_{k}\exp(-t/{\tau}_{k})$,

or by a sum of first-order rational fractions in the frequency domain.

${E}_{v}(s)={E}_{r}+{\sum}_{k=1}^{N}\frac{{\omega}_{k}{E}_{k}}{s+{\omega}_{k}}$.

In order to take these constitutive laws into account, one introduces internal variables which make it possible to build an equivalent linear model of order two, compatible with *Code_Aster*. These variables provide the link between the physical degrees of freedom affected by the presence of a viscoelastic material and the quantities (grandeurs) defining the constitutive behaviour. Thus, one introduces as many vectors ${q}_{\mathrm{vk}}$ as there are internal parameters. These variables are governed by the time-evolution equations

${\tau}_{k}\dot{{q}_{\mathrm{vk}}}+{q}_{\mathrm{vk}}-q=0$

that is, in the frequency domain

$s{q}_{\mathrm{vk}}+{\omega}_{k}({q}_{\mathrm{vk}}-q)=0$

One can illustrate the relations describing this constitutive behaviour by considering a mass–“spring” system for which the spring possesses a constitutive behaviour which can be represented by $N$ internal variables:

![Figure](/figures/u2.06.03/Shape1.gif)

*Figure 1: Representation of a “1 degree of freedom” system with internal states.*

The equilibrium equations for this system are written

$\lbrace \begin{array}{}\text{}M\ddot{q}+{K}_{0}q+{\sum}_{k=1}^{N}{K}_{k}(q-{q}_{\mathrm{vk}})=0\text{}\\ \text{}\\ \text{}{C}_{k}\dot{{q}_{\mathrm{vk}}}+{K}_{k}({q}_{\mathrm{vk}}-q)=0\text{}\forall k\in [1,N]\end{array}$

The dynamic system for this oscillator can therefore be put in the classical form of a model of order 2

$\left[\begin{array}{cccc}M& 0& \text{...}& 0\\ 0& 0& \ddots & ⋮\\ ⋮& \ddots & 0& ⋮\\ 0& \mathrm{...}& \mathrm{...}& 0\end{array}\right]\ddot{\left\lbrace \begin{array}{}q\\ {q}_{\mathrm{v1}}\\ {q}_{\mathrm{vk}}\\ {q}_{\mathrm{vN}}\end{array}\right\rbrace }+\left[\begin{array}{cccc}0& 0& \text{...}& 0\\ 0& {C}_{1}& \ddots & ⋮\\ ⋮& \ddots & {C}_{k}& 0\\ 0& \mathrm{...}& 0& {C}_{N}\end{array}\right]\dot{\left\lbrace \begin{array}{}q\\ {q}_{\mathrm{v1}}\\ {q}_{\mathrm{vk}}\\ {q}_{\mathrm{vN}}\end{array}\right\rbrace }+\left[\begin{array}{cccc}{K}_{0}+{\sum}_{k=1}^{N}{K}_{k}& -{K}_{1}& -{K}_{k}& -{K}_{N}\\ -{K}_{1}& {K}_{1}& 0& 0\\ -{K}_{k}& 0& {K}_{k}& 0\\ -{K}_{N}& 0& 0& {K}_{n}\end{array}\right]\left\lbrace \begin{array}{}q\\ {q}_{\mathrm{v1}}\\ {q}_{\mathrm{vk}}\\ {q}_{\mathrm{vN}}\end{array}\right\rbrace =\left\lbrace \begin{array}{}f\\ 0\\ 0\\ 0\end{array}\right\rbrace$

As it stands, *Code_Aster* does not make it possible to take such constitutive laws into account for linear dynamic analyses. The solution adopted to solve this problem consists in building a reduction basis adapted to the problem.

This reduction basis is built around eigenmodes and the static responses of the structure to the viscoelastic forces generated by the modes. Under these conditions, one has

$[T]=\left[\begin{array}{ccc}{\Phi}_{l}& {\Phi}_{e}& {T}_{p}\\ {\Phi}_{\mathrm{lv1}}& 0& {T}_{\mathrm{v1}}\\ {\Phi}_{\mathrm{lvk}}& 0& {T}_{\mathrm{kv}}\\ {\Phi}_{\mathrm{lvN}}& 0& {T}_{\mathrm{vN}}\end{array}\right]$

The sub-matrices T are built from the static problem

$\left[\begin{array}{cccc}{K}_{0}+{\sum}_{k=1}^{N}{K}_{k}& -{K}_{1}& -{K}_{k}& -{K}_{N}\\ -{K}_{1}& {K}_{1}& 0& 0\\ -{K}_{k}& 0& {K}_{k}& 0\\ -{K}_{N}& 0& 0& {K}_{n}\end{array}\right]\left\lbrace \begin{array}{}{T}_{p}\\ {T}_{\mathrm{v1}}\\ {T}_{\mathrm{vk}}\\ {T}_{\mathrm{vN}}\end{array}\right\rbrace =\left\lbrace \begin{array}{}0\\ {F}_{\mathrm{v1}}\\ {F}_{\mathrm{vk}}\\ {F}_{\mathrm{vN}}\end{array}\right\rbrace$

with the loading defined by

$\left\lbrace \begin{array}{}0\\ {F}_{\mathrm{v1}}\\ {F}_{\mathrm{vk}}\\ {F}_{\mathrm{vN}}\end{array}\right\rbrace =\left[\begin{array}{cccc}0& 0& \text{...}& 0\\ 0& {C}_{1}& \ddots & ⋮\\ ⋮& \ddots & {C}_{k}& 0\\ 0& \mathrm{...}& 0& {C}_{N}\end{array}\right]\dot{\left\lbrace \begin{array}{}\Phi \\ {\Phi}_{\mathrm{v1}}\\ {\Phi}_{\mathrm{vk}}\\ {\Phi}_{\mathrm{vN}}\end{array}\right\rbrace }$

One can then solve the problem projected onto the basis $T$, a problem which takes into account the overall viscoelastic constitutive behaviour defined for the materials.

The details for the implementation of these techniques in *Code_Aster* are detailed in the documentation on the construction of reduced models for dynamics U2.06.04.

This approach is for the moment reserved for experienced users, since model reduction in the presence of internal states can lead to singular behaviours. On the other hand, the method proposed for the reduction is not necessarily sufficient, and it is sometimes necessary to enrich the basis thus constructed in order to build a reasonable model.

The search for eigenvalues can be done only with certain settings of the eigenvalue search operator CALC_MODES [U4.52.02](doc:u4.52.02).

The reference documentation [R5.01.02](doc:r5.01.02) specifies the types of problems that one can treat and the possible settings.

However, for the computation of the eigenmodes of the reduced model, it is recommended to use the full solver (METHODE='QZ') by searching for all the eigenvalues (OPTION='TOUT'), since otherwise it is not possible to access the real eigenvalues, representing the relaxation, which are important components of the constitutive behaviour of this type of material.
