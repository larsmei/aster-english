# u4.51.21 Macro-command CALC_STABILITE

## 1 Purpose

The macro-command CALC_STABILITE makes it possible to determine the stability of periodic solutions obtained by MODE_NON_LINE, on the basis of Floquet theory, by a time-integration scheme and an eigenvalue analysis. On output, it updates the column STABILITE of the table of periodic solutions.

This macro-command can enrich an existing concept or produces a new concept of type table_container.

## 2 Syntax

```text
table_container = CALC_STABILITE(
    ◇ reuse = <objet de MODE_NON_LINE>,
    ◆ MODE_NON_LINE = table_container,
    ⟐ SCHEMA_TEMPS = _F(
         ◇ SCHEMA = "NEWMARK",
         # Si: equal_to("SCHEMA", 'NEWMARK')
             ◇ NB_INST = int (défaut: 1000),
      ),
    ◇ TOLERANCE = float (défaut: 0.01),
    ◇ FILTRE = _F(
         ◆ / NUME_ORDRE = int,
           / FREQ_MIN = float,
         # Si: exists("FREQ_MIN")
             ◆ FREQ_MAX = float,
             ◇ PRECISION = float (défaut: 0.001),
      ),
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Keyword MODE_NON_LINE

```text
♦    MODE_NON_LINE
```

Concept of type table_container produced by an analysis with the operator MODE_NON_LINE.

### 3.2 Keyword SCHEMA_TEMPS

```text
◊    SCHEMA_TEMPS
```

Under this factor keyword, one can supply an integration scheme together with, optionally, its parameters. The available schemes are to be declared under the operand SCHEMA.

#### 3.2.1 Operand SCHEMA

```text
◊    SCHEMA = 'NEWMARK'
```

Choice of the time-integration algorithm. For the moment, only the Newmark scheme is possible. It is an implicit time-integration scheme that makes it possible to solve a linear ordinary differential equation. It is the default scheme.

#### 3.2.2 Operand NB_INST

```text
◊    NB_INST
```

The solution is performed over one period of a given periodic solution. The value nbinst makes it possible to define the discretisation for the solution. The larger the number of degrees of freedom, the larger nbinst must be. By default nbinst = 1000.

### 3.3 Keyword TOLERANCE

```text
◊    TOLERANCE
```

tol is the control value on the error of the Floquet coefficients ${\gamma}_{i}$ , which makes it possible to decide on the stability of the periodic solution. If $\forall i$ , $\mid {\gamma}_{i}\mid >(1+\mathit{tol})$ then the periodic solution is unstable, otherwise it is stable.

### 3.4 Keyword FILTRE

◊    FILTRE

Filters the periodic solutions on which the stability analysis will be performed. By default, the stability analysis is performed on all the periodic solutions of resu_in.

#### 3.4.1 Operand NUME_ORDRE

◊    NUME_ORDRE

This keyword makes it possible to compute the stability on a list of order numbers. The keyword is not valid if the keyword FREQ_MIN is present.

#### 3.4.2 Operand FREQ_MIN

◊    FREQ_MIN

This keyword makes it possible to define the lower bound of the frequency range [freq_min, freq_max]. The stability is computed if the frequency of the periodic solution lies in this frequency range. The keyword is not valid if the keyword NUME_ORDRE is present.

#### 3.4.3 Operand FREQ_MAX

◊    FREQ_MAX

This keyword makes it possible to define the upper bound of the frequency range [freq_min, freq_max]. The stability is computed if the frequency of the periodic solution lies in this frequency range.

#### 3.4.4 Operand PRECISION

◊    PRECISION

This (optional) keyword makes it possible to give a precision on the bounds of the frequency range [freq_min, freq_max].

### 3.5 Keyword INFO

```text
Entier permettant de préciser le niveau d'impression dans le fichier MESSAGE.

Si INFO=1, on affiche si la solution est stable ou instable pour le numéro d'ordre de la solution périodique.

Si INFO=2, on affiche également l'erreur absolue et relative de la     résolution par le schéma d'intégration temporelle,ainsi que le plus grand coefficient de Floquet.
```
