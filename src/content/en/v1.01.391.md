# v1.01.391 PLEXU09 – Validation of VMIS_JOHN_COOK in CALC_EUROPLEXUS

**Summary:**

This test validates the use of constitutive law VMIS_JOHN_COOK in CALC_EUROPLEXUS. It also validates VARI_INT ='OUI' functionality of ETAT_INIT and the use outside CALC_EUROPLEXUS of LIRE_EUROPLEXUS macro-command.

Modelling A: Reproducing the EPX test bm_ini_med_ecro_vmjc that validates the inclusion of internal variables in the initial state (from Code_Aster) for VMIS_JOHN_COOK law (VMJC from EPX).

Modelling B: non-regression test to validate the correct translation of material parameters.

## 1 Details on Internal Variable Transformations for VMIS_JOHN_COOK Law

### 1.1 Description

Internal variables of Code_Aster are noted with the suffix V and internal variables of EPX with the suffix ECR followed by the component number.

#### 1.1.1 Code_Aster

VMIS_JOHN_COOK law in Code_Aster has 5 internal variables.

| V1 | EPSPEQ | Cumulative equivalent plastic deformation (deviatoric) |
| --- | --- | --- |
| V2 | INDIPLAS | Plasticity indicator (0: threshold not reached, 1 or > 1: threshold reached) |
| V3 | DEPSPEQ | Equal plastic deformation increment |
| V4 | DINSTM | Time increment |
| V5 | DDISSM | Mechanical dissipation speed |

#### 1.1.2 EPX

EPX VMJC Law has 8 internal variables. Here is the information from the EPX documentation:

| ECR1 | current hydrostatic pressure |
| --- | --- |
| ECR2 | current equivalent stress (Von Mises) |
| ECR3 | current equivalent plastic train |
| ECR4 | current yield stress |
| ECR5 | sound speed |
| ECR6 | equivalent train rate (Von Mises) |
| ECR7 | failure flag (0=virgin Gauss Point, 1=failed Gauss Point) |
| ECR8 | damage parameter for the Johnson-Cook criteria |

### 1.2 Code_Aster to EPX

#### 1.2.1 ECR1

The stress matrix trace is calculated using CALC_CHAMP/CHAM_UTIL/CRITERE = 'TRACE' on the SIEF_ELGA field. The value obtained for each Gauss point is then divided by $3$ to obtain $\mathit{ECR1}$.

#### 1.2.2 ECR2

$\mathit{ECR2}$ corresponds to the $\mathit{VMIS}$ component of the SIEQ_ELGA field.

#### 1.2.3 ECR3

$\mathit{ECR3}$ corresponds to the $\mathit{V1}$ component of the VARI_ELGA field.

#### 1.2.4 ECR4

$\mathit{ECR4}$ corresponds to the $\mathit{VMIS}$ component of the SIEQ_ELGA field, which is added to the $epsilon$ equal to $10E-6$. This choice was made as part of Emricka Julan's thesis. It allows calculations with VMJC law to work with the given initial state.

#### 1.2.5 ECR5

$\mathit{ECR5}$: value set to $0.$ because calculated entirely by EPX at each moment.

#### 1.2.6 ECR6

This value corresponds to a deformation speed that is still zero at the end of a static calculation, so it is set to $0.$ because it is not intended to give an initial state from a dynamic calculation to CALC_EUROPLEXUS.

#### 1.2.7 ECR7 et ECR8

These two variables are only for the breaker mechanics. They are set to $0.$ .

### 1.3 EPX to Code_Aster

Transformations during this passage can only be made from values present in the field of internal variables from EPX.

For this law, the transformation consists only of putting the $\mathit{ECR3}$ component into $\mathit{V1}$ and putting the other 4 components into $0.$.

## 2 Modelling A

### 2.1 Purpose

The purpose of this test is to validate the sending and transformation (for VMIS_JOHN_COOK law) of an internal variable field in the initial state of an EPX calculation via CALC_EUROPLEXUS. It also validates the transformation of internal variables in the EPX direction to Code_Aster for VMIS_JOHN_COOK law and the use of LIRE_EUROPLEXUS outside of CALC_EUROPLEXUS.

### 2.2 Description

This test is the equivalent of the EPX bm_ini_med_ecro_vmjc "bench".

It is a single element cube. The bottom side is clamped and a load (displaced on X) is applied to the top side. This calculation is done with the STAT_NON_LINE operator to produce an initial state for EPX calculation.

CALC_EUROPLEXUS is then launched with this initial state (movements + stresses + internal variables) and without additional loading than those that were able to obtain the initial state.

It is then checked that the internal variables in the initial and final state are the same as in bm_ini_med_ecro_vmjc with the keyword COURBE (and TEST_TABLE) and that the internal variables recovered by Code_Aster at the end of the calculation are the ones expected.

Internal variables should not normally evolve since no additional loading has been added. However, some components that do not depend on calculated values are recalculated completely by EPX at each iteration. This is the case with ECR5.

Comparison with test case EPX or analytical references.

## 3 Modelling B

### 3.1 Purpose

Modelling A does not ensure that the material parameters have been correctly translated. The purpose of this test is to complete this.

### 3.2 Description

The same model as model A is applied to the upper side of the cube strong enough to exit the elastic part of the law. The calculation is started without initial state.

### 3.3 Validation principle

After checking that the translation of the material parameters was done well in the EPX command file created, non-regression tests are applied to this calculation.

## 4 Conclusion

The tests showed that:

- VMIS_JOHN_COOK law was well taken into account,
- a field of internal variables could be sent in addition to the fields of displacement and constraints in the initial state,
- the transformation of the internal variables from Code_Aster to EPX was in accordance with the request,
- the transformation of internal variables from EPX to Code_Aster as well,
- the use of LIRE_EUROPLEXUS outside CALC_EUROPLEXUS is operational.
