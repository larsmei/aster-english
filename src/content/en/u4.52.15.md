# u4.52.15 Operator MAC_MODES

## 1 Purpose

The operator MAC_MODES makes it possible to compute a correlation matrix between two modal bases. The correlation coefficient between two vectors of this base is all the closer to 1 as these two vectors are collinear.

It also makes it possible to compute the difference between two modal bases by using the IERI energy criterion (Energy Indicator of Interface Regularity). This criterion is all the closer to 0 as the two vectors are very close.

It also makes it possible to compute the generalised matrix relative to the weighting matrix entered as input.

Produces a concept of type table_sdaster.

## 2 Syntax

```text
table = MAC_MODES(
    ◆ BASE_1 = mode_meca_c / mode_flamb / mode_meca,
    ◆ BASE_2 = mode_meca_c / mode_flamb / mode_meca,
    ◇ & MATR_ASSE = matr_asse_depl_c / matr_asse_depl_r,
      & IERI = "OUI" (ou non renseigné),
    ◇ TITRE = text,
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 General points

The MAC matrix (**M**odal **A**ssurance **C**riterion) indicates the correlation between two lists of vectors. It is often used to check the orthogonality of two modal bases (experimental or numerical).

The i-th row, j-th column of the MAC matrix is defined by the following relation:

${\mathit{MAC}}_{ij}=\frac{{\left({\Phi}_{i}^{H}W{\Phi}_{j}\right)}^{2}}{\left({\Phi}_{i}^{H}W{\Phi}_{i}\right)\left({\Phi}_{j}^{H}W{\Phi}_{j}\right)}$

Where: ${\Phi}_{i}$ is the i-th vector of the first base,

${\Phi}_{j}$ is the j-th vector of the second base,

$W$ is a weighting matrix,

The superscript ${}^{H}$ denotes the conjugate transpose.

This MAC matrix is diagonal if the two bases are formed of the modal vectors coming from one and the same structure and if the weighting matrix is equal to the mass or stiffness matrix of the structure under consideration. One then speaks of the orthogonality of the eigenmodes with respect to the mass or stiffness matrix. The quantity ${\Phi}_{i}^{H}W{\Phi}_{j}$ corresponds to the term of the generalised stiffness (or mass) matrix if the weighting matrix is equal to the stiffness (or mass) matrix.

The IERI criterion (**I**ndicator of **E**nergy of **R**egularity of the **I**nterface) is an energy indicator making it possible to compute the difference between two vectors. It is defined by the following relation:

${\mathrm{IERI}}_{ij}=\frac{{({({\Phi}_{i}-{\Phi}_{j})}^{H}W({\Phi}_{i}-{\Phi}_{j}))}^{2}}{{({\Phi}_{i}^{H}W{\Phi}_{i})}^{2}+{({\Phi}_{j}^{H}W{\Phi}_{j})}^{2}}$

The weighting matrix is either the mass matrix or the stiffness matrix of the structure under consideration.

This IERI criterion tends towards 0 if the two vectors are very close.

### 3.2 Operand BASE_1/BASE_2

```text
♦    BASE_1 = base_1
♦    BASE_2 = base_2
```

Name of the modal concepts (mode_meca, mode_meca_c, mode_flamb) to be compared. In general, one compares a numerical modal base produced by an analysis (by CALC_MODES) and an experimental modal base, imported by LIRE_RESU. The two bases must be defined on the same model and have the same numbering.

### 3.3 Operand IERI

```text
◊    IERI = ’OUI’
```

This operand is used to specify that one wants to compute the IERI criterion. In this case, the operand MATR_ASSE must be supplied. One must associate with it a mass matrix or a stiffness matrix.

### 3.4 Operand MATR_ASSE

```text
◊    MATR_ASSE = matr
```

Operand designating an assembled matrix used as a weighting.

matr is the weighting matrix applied to the base vectors. It must have the same numbering as base1 and base2. One usually chooses the mass matrix or the stiffness matrix as the weighting matrix.

If this operand is not supplied, the weighting matrix chosen is equal to the identity matrix.

This weighting matrix is mandatory for the computation of the IERI criterion.

### 3.5 Operand TITRE

```text
◊    TITRE = ’tit’
```

Optional name to be given to the table.

### 3.6 Operand INFO

```text
◊    INFO = 1 ou 2
```

The MAC or IERI matrix and the generalised matrix are displayed in tabular form in the MESSAGE file if INFO=2.

The name of the parameter of the output table associated with the generalised matrix is Y1_W_Y2. This generalised matrix is computed if the base vectors are of real type.
