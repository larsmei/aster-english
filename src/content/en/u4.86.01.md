# u4.86.01 Procedure POST_ENDO_FISS

## 1 Purpose

The command POST_ENDO_FISS carries out a post-processing on a result coming from continuum mechanics. The aim is to find the curve which represents the crack from a representative field, and the crack opening. The field may be the damage or another scalar field. As input, the command uses an evol_noli or cham_gd concept, containing the field to be post-processed. The latter must be a field at the nodes. As output, the command returns a mesh of the crack (constituted by SEG2 elements), as well as a table containing the coordinates of the nodes of the crack and the value of the opening on each node. The procedure applies to 2D studies.

## 2 Syntax

```text
/ table
/ maillage = POST_ENDO_FISS(
    ◆ TABLE = co,
    ◇ OUVERTURE = / "OUI",
                  / "NON" (par défaut),
    # Si: exists("RESULTAT")
        ◆ / NUME_ORDRE = int,
          / INST = float,
    ◆ / CHAM_GD = cham_gd,
      / RESULTAT = evol_noli,
    ◆ NOM_CMP = text,
    ◆ NOM_CHAM = text,
    ◆ RECHERCHE = _F(
         ◆ LONG_ORTH = float,
         ◇ NB_POINT = int (défaut: 500),
         ◆ PAS = float,
         ◆ LONG_REG = float,
         ◇ BORNE_MIN = float (défaut: 0.5),
         ◇ ANGL_MAX = float (défaut: 120.0),
         ◇ / TOUT = "OUI" (ou non renseigné),
           / GROUP_MA = grma,
         ◇ BORNE_MAX = float,
      ),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand TABLE

```text
♦ TABLE         = CO('table')
```

This operand (mandatory) makes it possible to give the name of the concept output by the command. The table at the output contains the information on the cracking path and the crack opening.

In the case where only the path is sought (option OUVERTURE='NON'), the table has 4 columns, in which, for each node of the crack, are displayed: the name of the crack of which the node is part, its coordinate $X$ , its coordinate $Y$ , the value of the post-processed field. If the crack opening is also requested (OUVERTURE='OUI'), it will be entered in the table in a 5th column.

### 3.2 Operands RESULTAT / CHAM_GD

```text
/     ♦ RESULTAT        = evol_noli

♦ CHAM_GD        = cham_gd
```

Name of the result concept containing the field to be post-processed (RESULTAT), or field of quantities (grandeur) (CHAM_GD). One must obligatorily choose one of the two. The field to be post-processed must obligatorily be a field at the nodes.

### 3.3 Operands INST / NUME_ORDRE

/ ♦INST =     inst

♦ NUME_ORDRE =     nume_ordre

These operands must be supplied only in the presence of the operand RESULTAT. They are used to select the time instant to be post-processed. One must obligatorily choose one of the two.

### 3.4 Operand NOM_CHAM

```text
♦ NOM_CHAM    = nom_cham
```

This operand is mandatory. One gives here the name of the field to be post-processed and on which the procedure for searching for the cracking paths is then applied, for example VARI_NOEU.

### 3.5 Operand NOM_CMP

```text
♦ NOM_CMP        = nom_cmp
```

This operand is mandatory. It makes it possible to choose the component to be post-processed in the field supplied, for example V1. Indeed, the procedure is applicable only to a scalar field.

### 3.6 Operand OUVERTURE

```text
♦ OUVERTURE        = /NON
/OUI
```

Under this operand, one supplies the type of operation carried out by the command. By default, one seeks only the cracking path (OUVERTURE='NON). If OUVERTURE='OUI', the crack opening is also computed.

### 3.7 Keyword RECHERCHE

One supplies here the parameters for the search for the cracks and for the corresponding openings. The call to this keyword is repeatable in order to allow the search for several cracks which lie on distinct mesh-cell groups.

#### 3.7.1 Operands TOUT / GROUP_MA

```text
◊     / TOUT = "OUI"                     [DEFAUT]

/ GROUP_MA = group_ma
```

Under the operand GROUP_MA, one may supply the mesh-cell group on which to search for the cracking path. If this operand is absent, the search is carried out over the whole geometrical domain defined by the mesh.

#### 3.7.2 Operands LONG_ORTH / LONG_REG

```text
♦ LONG_ORTH= long_orth

♦ LONG_REG = long_reg
```

Under the operand LONG_ORTH, one supplies the length of the profile orthogonal to the search direction, used by the procedure at each analysis step. On this profile, one keeps the point where the value of the field (projected and smoothed) is maximum, which gives the new point of the crack trace. LONG_ORTH must normally be equal to or greater than the width of the damaged band. The projection of the field onto this profile is smoothed by means of another length, LONG_REG, in order to avoid the new point lying on the edge of a finite element. For the method to work properly, LONG_REG must lie in the range $0.5$ to $2$ times the size of the mesh cells which lie in the damaged band. It shows a diagram of the search for the cracking path; one will consult the document [R7.02.17](doc:r7.02.17) for a more detailed explanation of the operation of the command.

#### 3.7.3 Operand PAS

♦ PAS     = pas

This is the advance step of the search procedure. There is no recommended value; the procedure is fairly robust with respect to the choice of this parameter. On the other hand, if the advance step is too large, one risks not detecting the portions of the crack characterised by strong curvatures. A small step (of the order of magnitude of the size of the finite element) may be recommended if one seeks to have many points in order to discretise the crack.

#### 3.7.4 Operand BORNE_MIN

◊BORNE_MIN = seuil

Value of the field in correspondence with which one stops the search for the path of the crack.

#### 3.7.5 Operand BORNE_MAX

♦BORNE_MAX = lfpz

This quantity defines the width of the damaged band, on which the crack opening is computed. It is to be supplied only with the option OUVERTURE='OUI'.

#### 3.7.6 Operand ANGL_MAX

◊ANGL_MAX = / 120.

/ angle_max

The search on the orthogonal profile may be restricted to a central piece defined by means of an angle (in degrees) equal to angle_max, symmetric with respect to the prediction point (see the ).

#### 3.7.7 Operand NB_POINTS

> ◊ NB_POINT     = nb_points

This keyword makes it possible to define the number of points on half of the orthogonal profile, which defines the precision on the latter. By default, this parameter is equal to 500.
