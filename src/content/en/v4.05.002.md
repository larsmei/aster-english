# v4.05.002 TPLP02 - Orthotropic square

**Summary:**

This test is based on independent validation of version 3 in linear steady-state thermal analysis.

This is a 2D plan problem represented by a single model (plane).

The functions tested are the use of thermal plane elements, orthotropic material, of three types of boundary conditions:

- convection
- linear variation of outside temperatures,
- The demand for flows.

The results are compared with an analytical solution (VPCS).

## 4 Summary of the results

The results obtained are excellent. The values calculated by Aster are identical to the reference values. This is a "normally expected" result since the solution field that is linear belongs to the space of interpolation of the tested element.

The test was used to test the following commands:

- DEFI_FONCTION associated with the NOM_PARA operand, allowing to define a variation of the outside temperature according to the abscissa or the order,
- DEFI_MATERIAU associated with the THER_ORTH keyword, allowing to define the characteristics of an orthotropic material,
- AFFE_CARA_ELEM associated with the MASSIF keyword, allowing to define the d-orthotropy axes.
