# v3.04.111 SSLV111 - Error estimate on linear elasticity hole plate

**Summary:**

This test is valid and compares the 2 versions of the Zhu-Zienkiewicz error estimator (1987 version 1, rated $\mathrm{ZZ1}$ , and 1992 version 2, rated $\mathrm{ZZ2}$ ) applied to the linear elasticity system, static.

It has 5 flat stress models, each corresponding to a type of finite element (TRIA3, QUAD4, TRIA6, QUAD8, QUAD9).

The analytical solution is known and allows to compare estimated errors with the exact error.

This test also validates the Zhu-Zienkiewicz error estimator version 1 applied to 2 modellings in 3D. The first Modelling includes elements HEXA8, PYRAM5 and TETRA4 finished, and the second, elements PENTA6 finished. The solution does not depend on the value on the z-axis. The results are therefore compared to the analytical values used in 2D.

The test is of interest:

- in the comparison between the stresses smoothed with $\mathrm{ZZ1}$ (continuous overall smoothing) and $\mathrm{ZZ2}$ (local smoothing with elements patches),
- in the comparison of the estimators between them,
- qualitative and quantitative analysis of results (global and local relative errors)
- in the validation of the Zhu-Zienkiewicz smoothing estimator version 1 to 3D.

The test shows the good behavior of $\mathrm{ZZ2}$ on all types of elements and the bad results of $\mathrm{ZZ1}$ on quadratic elements when the solution does not have a strong singularity, which is the case.
