# v4.04.006 TPLV06 - Power flow in a hollow sphere

**Summary:**

This test is based on independent validation of version 3 in linear steady-state thermal analysis.

This is a three-dimensional problem which aims to validate the volume thermal element at a temperature imposed and a heat source.

This test case includes 3D modelling. The results are compared to an analytical solution (VPCS).

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v4.04.006/Object_1.svg)

### 1.2 Material properties

$$
\lambda =1.W/m°C
$$

### 1.3 Boundary conditions and loads

- ${T}_{i}=T(r={R}_{i})=20°C$ ,
- ${T}_{e}=T(r={R}_{e})=20°C$ ,
- $Q=100W/{m}^{3}$ .

### 1.4 Initial conditions

Not applicable.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The reference solution is the one given in the TPLV06/89 plug in the VPCS guide.

- Temperature as $r$:

$T={T}_{i}+\frac{Q}{6\lambda }\left[\frac{({R}_{e}^{2}-{R}_{i}^{2})\left[\frac{1}{{R}_{i}}-\frac{1}{r}\right]}{\left[\frac{1}{{R}_{i}}-\frac{1}{{R}_{e}}\right]}-({r}^{2}-{R}_{i}^{2})\right]$

- Flow density as a function of $r$:

$\phi =-4\pi {r}^{2}\lambda \frac{\mathrm{dT}}{\mathrm{dr}}=-\frac{2\pi Q}{3}\left[({R}_{e}^{2}-{R}_{i}^{2})\left[\frac{1}{{R}_{i}}-\frac{1}{{R}_{e}}\right]-2{r}^{3}\right]$

### 2.2 Baseline

Temperature in $r=1.25$; $1.5$ and $1.75m$

### 2.3 Uncertainty about the solution

analytical solution.

### 2.4 Bibliographical references

## 4 Summary of the results

The results obtained are satisfactory, the difference maximum obtained is 0.53%.

The 3D Modelling used to model this sphere is correct.

The quality of the results could be further improved by:

- making a finer mesh of the sphere portion,
- Choosing quadratic elementss to better approximate the reference solution.
