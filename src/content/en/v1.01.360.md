# v1.01.360 ZZZZ360 - Validation of the MODI_MAILLAGE / ABSC_CURV command

**Summary:**

This computer test validates the programming of the ABSC_CURV keyword of the MODI_MAILLAGE command.

The mesh forms an "open" line (with 2 ends: N1 and N13).

The nodes are all in the XOY plan.

There are 13 nodes. nodes N2, N3, ..., N12 are located on a portion (270 degrees) of the O-centered 1-ray circle. They are not equidistant.

The mesh is made up of 2 SEG2, 2 SEG3, 2 SEG4 and 3 POI1.

The orientation of certain segments is voluntarily "turned".

Since nodes is almost all located on the same circle, it is easy to calculate their curvilinear abscisses by hand.

This allows the TOUS curvilinear abscisses to be validated as nodes as TOUS as elements (POI1, SEG2, SEG3 and SEG4).

This documentation is deliberately succinct.
