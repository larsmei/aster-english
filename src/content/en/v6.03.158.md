# v6.03.158 SSNP158 – Non-linear adaptation of mesh

**Summary:**

This $\mathrm{2D}$ test in near-static plane stresses allows you to illustrate the problem of adapting mesh to non-linear on a simple case.

It implements the elements presented in the [U2.08.09](doc:u2.08.09) documentation "Adaptation of mesh to non-linear", i.e. the different phases of resolution, adaptation, projection and balancing.

## 1 Reference problem

### 1.1 Geometry

It is a rectangular plate, with a hole, modelled in $\mathrm{2D}$ flat stresses. Only a quarter of the plate is modelled with symmetries. Dimensions are given in millimetres.

| ![Figure](/figures/v6.03.158/1000000000000300000002F1C20F9CF5EBB45939.jpg) |
| --- |

### 1.2 Boundary conditions and loads

**Conditions of symmetry**

The plate is blocked following $\mathrm{Ox}$ along the $\mathrm{AG}$ side and following $\mathrm{Oy}$ along the $\mathrm{BD}$ side.

**Imposed on-road loading**

It is subject to a ${U}^{d}=0.2\mathit{mm}$-imposed displacement following $\mathrm{Oy}$ distributed on the $\mathrm{FG}$ side.

### 1.3 Material properties

The behavior is elastoplastic of Von Mises, with isotropic hardening.

The elastic characteristics are:

- Young's modulus $E=200000\mathrm{MPa}$ ;
- Poisson's ratio $\nu =0.3$ ;
- Elasticity limit: $200\mathrm{MPa}$;

## 2 reference solution

The reference solution is obtained by calculating a very fine mesh which constitutes the B Modelling of this test.

## 3 Modelling A

### 3.1 Modelling characteristics

Elasto-plastic calculation on a plane stress model (C_PLAN). An adaptation of mesh to each time step is made, followed by a projection and balancing phase. For adaptation, the HOMARD software is provided with a very fine description of the geometry of the hole in order to follow its contour. Otherwise, non-physical stress concentrations appear.

### 3.2 Mesh characteristics

An initial mesh is used, which includes 91 TRIA6 and 210 nodes.

![Figure](/figures/v6.03.158/100000000000017F000002082A934D62AD506976.png)

## 4 Modelling B

### 4.1 Modelling characteristics

Elasto-plastic calculation on a plane stress model (C_PLAN) using a fine mesh that serves as reference solution for Modelling A.

### 4.2 Mesh characteristics

An initial mesh with 2168 TRIA6 and 4467 nodes is used.

![Figure](/figures/v6.03.158/1000000000000224000002C8D157FD6C0B179F86.png)

### 4.3 Tested quantities and results

On this Modelling, we only perform non-regression tests that are of no interest here.

## 5 Summary of the results

This test implements a nonlinear calculation with mesh adaptation during the transient. Comparison with a reference calculation on a fine mesh confirms the relevance of the approach.
