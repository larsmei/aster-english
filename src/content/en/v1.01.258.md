# v1.01.258 ZZZZ258 - STAT_NON_LINE ETAT_INIT Keyword Validation

**Summary:**

This test validates the behavior of the code when a nonlinear calculation is "pursued" by imposing an initial state (keyword ETAT_INIT).

In particular, it is checked that certain alarms are issued when changing behavior on some elements.

Note: The code must also cause a fatal error when the behavior change is prohibited. This is verified in error test07 (v1.01.260).

## 1 Test principle

This test is a computer test. It is used to validate the programming of the ETAT_INIT keyword processing and more specifically the routine vrcomp.f

To define the initial state of a nonlinear calculation, the user has two options:

- either it indicates an evol_noli data structure and a "minute" in this evol_noli (keywords EVOL_NOLI + INST)
- or it gives 3 "isolated" displacement fields, constraints and internal variables (keywords DEPL, SIGM and VARI)

Programming is different to deal with both cases, which is why we both test them.

The difficulty we are trying to test here is that of a pursuit for which one or more elements of the "change" behavior model.

Specifically, the following situations are tested:

- adding new elements to the model
- removal of elements in the model
- the following possibilities for changing behaviour:

  - 'vmis_cine_line' -> 'vmis_cine_line'
  - 'vmis_cine_line' -> 'nothing' (deletion of elements)
  - 'vmis_cine_line' -> 'vmis_cine_line'
  - 'vmis_isot_trac' -> 'vmis_isot_line'
  - 'vmis_isot_trac' -> 'elas'
  - 'vmis_isot_line' -> 'vmis_isot_trac'
  - 'elas' -> 'vmis_cine_line'
  - 'nothing' -> 'vmis_cine_line' (add elements)
  - 'nothing' -> 'vmis_cine_line' (add elements)
