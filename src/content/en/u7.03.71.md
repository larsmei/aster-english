# u7.03.71 Macro-command RAFF_GP

## 1 Purpose

The purpose of this macro-command is to refine a two-dimensional mesh containing a defect represented by a notch; the refinement is carried out in the zone downstream of the notch. This macro-command may in particular be used upstream of the mechanical analysis from which a fracture-mechanics post-processing by CALC_GP will be performed.

The macro returns a mesh.

## 2 Syntax

```text
maillage = RAFF_GP(
    ◆ MAILLAGE_N = maillage,
    ◆ TRANCHE_2D = _F(
         ◆ CENTRE = float,
         ◆ RAYON = float,
         ◆ ANGLE = float,
         ◆ TAILLE = float,
         ◆ NB_ZONE = int,
      ),
    ◇ NB_RAFF = int (défaut: 4),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

RAFF_GP is a macro-command and therefore calls other commands of *Code_Aster* internally. Most of the keywords are passed as they are to the other commands. It will be indicated below in which command(s) the keywords are used.

### 3.1 Operand MAILLAGE_N

> ♦ MAILLAGE_N    =    ma_n,    [sd_maillage]

Denotes the initial mesh on which the refinement will take place. It must contain a notch represented finely enough (at least 5 elements on the contour of the half-notch) and the elements that compose it must not be distorted (refinement reducing the quality of the mesh, it is important that the initial mesh be as clean as possible).

Used by MACR_ADAP_MAIL.

### 3.2 Operand TRANCHE_2D

> ♦ TRANCHE_2D    =_F(

> ♦ TAILLE        = ${l}_{C}$     [R]
> ♦ CENTRE        = centre    [R,R,R]
> ♦ RAYON            = $R$     [R]
> ♦ ANGLE            = $\theta$     [R]
> ♦ NB_ZONE        = n    [I]

> )

Denotes the set of geometric parameters required for the definition of the geometric refinement zone. The syntax is identical to that used by the operator CALC_GP.

The Figure presents the parameters defining these zones; it represents a notch of centre ${C}_{\mathrm{ent}}$ , of radius $R$ ; the third zone ${C}_{3}(l)$ of length $3\ast {l}_{C}$ is hatched.

#### 3.2.1 Keyword TAILLE

> ♦ TAILLE        = ${l}_{C}$         [R]

Increment of the size of the zones. Zone n is therefore of size n* ${l}_{C}$ .

Used by FORMULE.

#### 3.2.2 Keyword CENTRE

> ♦ CENTRE        = centre    [R,R,R]

Denotes the coordinates of the centre of the notch ${C}_{\mathrm{ent}}$ in the global frame.

Used by FORMULE.

#### 3.2.3 Keyword RAYON

> ♦ RAYON        = $R$         [R]

Denotes the radius of the notch.

Used by FORMULE.

#### 3.2.4 Keyword ANGLE

> ♦ ANGLE        = $\theta$         [R]

Denotes the angle formed between the direction of the notch and the axis $\overrightarrow{X}$ of the global frame.

The angle must be given in degrees and measured in the trigonometric sense.

Used by FORMULE,

#### 3.2.5 Keyword NB_ZONE

> ♦ NB_ZONE        = n            [I]

Denotes the number of zones (chips) considered.

### 3.3 Operand NB_RAFF

◊ NB_RAFF    = nombre            [R]

Denotes the number of refinements carried out from the initial mesh.

By default, this number is 4.

Used by MACR_ADAP_MAIL.
