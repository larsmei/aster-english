# v2.04.104 SDLV104 - fix DEFI_BASE_MODALE Developer Error with the option "ORTHO=OUI"

**Summary:**

The DEFI_BASE_MODALE command is shown to concatenate and orthonormalize two vector families simultaneously (keyword RITZ and ORTHO operand).

The use of the 'ORTHO=OUI' operand will be validated on a transitional dynamic calculation based on static modes. A sound calculation, without the option 'ORTHO=OUI', will be used as reference solution.

The study of an slender beam with several blockages subjected to an instantaneous triangular temporal profile force is considered.

## 1 Reference problem

### 1.1 Geometry

The geometry is a beam of 7 m length and rectangular cross section with a neutral fibre bearing the X axis. The beam height is 10 cm. The beam width is 15 cm.

### 1.2 Material properties

**Butterfly:**

| Rigidity | $E=210{10}^{9}\mathit{Pa}$ $\nu =0.3$ |
| --- | --- |
| Density | $\rho =7800\mathit{kg}/{m}^{3}$ |

### 1.3 boundary conditions

The beam is clamped on its $x=0$ end.

The beam is blocked at nodes on the $x=2.5m$, $x=4m$, $x=6m$ and $x=7m$ neutral fiber.

### 1.4 Loading

Simulation takes 2s.

The impact lasts 0.02s, has a triangular temporal profile, has an amplitude of $F_z=1000N$ and is applied to the node on the $x=2.5m$ abcissor neutral fiber.

### 1.5 Mesh

The mesh consists of 280 linear hexahedrons.

### 1.6 Method

The calculation is performed in linear transient dynamics on a modal basis enriched with static modes at blocked nodes.

## 2 reference solution

The reference solution uses a static mode-enriched modal base without using the option "ORTHO=OUI".

The concatenation is made by two successive calls from the DEFI_BASE_MODALE command. The first is used for concatenation of static modes with the keyword "RITZ". The second is used with the keyword "ORTHO_BASE" to orthonormalize.

The Z-axis displacement results are post-treated with the node of free extremity.

## 3 Summary of the results

The Reference problem is processed with a concatenate and orthonormized modal base with the "ORTHO=OUI" option of the DEFI_BASE_MODALE command.

The Z-axis displacement results are post-treated with the node of free extremity. They are compared with the reference solution at the moments corresponding to half and the end of the simulation.
