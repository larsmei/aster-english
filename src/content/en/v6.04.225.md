# v6.04.225 SSNV225 – constitutive law HAYHURST: creep test

**Summary:**

This document presents a large deformation creep test to validate the capabilities of the HAYHURST behavior model to represent primary, secondary and tertiary creep.

The different modellingss allow you to test all integration methods:

- Implicit integration with an analytical jacobian matrix (modelization A).
- Implicit integration with jacobian matrix obtained by disturbance (modelization B);
- explicit integration by Runge_Kutta (modelization B);

Modelling C, on the other hand, is a copy of the Modelling B that validates keyword HAYHURST_FO , using constant parameters, artificially temperature dependent.

## 1 Reference problem

### 1.1 Geometry

Point hardware.

### 1.2 Ownership of materials

They are set to $600°C$ .

```text
YOUNG = 145000.;

POISSON = 0.34;

BIGA=9.707593E-08,

H1ST=0.33,

H2ST=1.0, K=9.691

H1=3.E4,

H2=-280.0, SIG0=27.9317, ALPHAD=0.5, EPS0=5.82516E-11
```

Parameters for the calculation options:

```text
DELTA1=1.0,

DELTA2=0.0, S_EQUI_D=0.0 (on utilise la première contrainte principale pour le calcul d'endommagement)

KC=0
```

($\phi$ variable is not taken into account)

### 1.3 Boundary conditions and loads

A constant $\mathrm{160MPa}$ constraint is applied from the $0,2h$ moment to the $\mathrm{4000h}$ moment.
