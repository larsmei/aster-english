# v5.03.106 SDNV106 – Analysis with DYNA_NON_LINE own values (stability and vibration modes)

**Summary:**

This test case allows to validate the flaming analysis, as well as vibrational modal analysis in DYNA_NON_LINE.

Only one model is used: $\mathrm{3D}$ massive A Modelling composed of mesh cells HEXA8.

## 1 Reference problem

### 1.1 Geometry

A $2m$ length side cube with uniform tensile strength in the vertical direction $Z$ is considered:

| ![Figure](/figures/v5.03.106/Shape1.gif) |
| --- |

For symmetry reasons, only one eighth of the structure will be considered, which will be meshed by a single cubic linear element volume.

### 1.2 Material properties

The structure is assumed to be homogeneous, composed of an isotropic elastoplastic material, with linear isotropic hardening:

- $E={2.10}^{4}\mathrm{MPa}$
- $\nu =0.49999$
- $\rho =7900\mathrm{kg}/{m}^{3}$
- ${\sigma}_{y}=0,1\mathrm{Mpa}$ (SY elastic threshold)
- ${E}_{T}=200\mathrm{Mpa}$ (module tangential plastic D_SIGM_EPSI)

So we choose a material that is still almost incompressible, whether we are in elastic or plastic regimes. In addition, we impose a 100 ratio between the elastic stiffness and the plastic tangent stiffness.

### 1.3 boundary conditions

A uniform tensile load is imposed following $Z$ on the top of the cube. This force, initially zero, increases linearly over time.

The other boundary conditions are Dirichlet type and reflect the symmetry conditions of the problem (following the 3 orthogonal planes $(\mathrm{xOy})$ , $(\mathrm{xOz})$ and $(\mathrm{yOz})$ ).

These boundary conditions are sufficient to block all rigid body movements in the system.

### 1.4 Initial conditions

The first calculation being quasistatic, we just impose a zero initial displacement.

## 2 reference solution

### 2.1 Method of calculation

We want to check two types of quantities:

- the first critical blazing charge,
- the first proper frequency of the vibration system.

The reference value of the critical load sought is obtained by a quasistatic calculation (CRIT_STAB key word of STAT_NON_LINE). This value is taken from the last step of quasistatic calculation, which corresponds to the instant $t=1s$ .

The number stored under CHAR_CRIT in the result data structure (this is the minimum multiplier coefficient of the load imposed to obtain the blazing load) being proportional to the imposed load which is monotonous increasing linearly over time, it is corrected to have the true value at the first moment of the transient dynamic calculation, i.e. $1,001s$ .

The multiplier coefficient CHAR_CRIT is defined as:

${F}_{\mathrm{critique}}=\text{CHAR\_CRIT}({t}_{i}).{F}_{\mathrm{ext}}({t}_{i})$

The external force is proportional to the time: ${F}_{\mathrm{ext}}({t}_{i})={F}_{\mathrm{ext}}.{t}_{i}$ , so ${F}_{\mathrm{critique}}=\text{CHAR\_CRIT}({t}_{i}).{F}_{\mathrm{ext}}.{t}_{i}$ .

It is assumed that on one step the load is moving very slowly and therefore the result of the dynamic calculation can be assimilated to a quasistatic evolution during this step. For the first dynamic step, which follows the quasistatic calculation, we can write:

$\begin{array}{c}{F}_{\mathit{critique}}={\text{CHAR\_CRIT}}_{\text{STAT\_NON\_LINE}}({t}_{i}).{F}_{\mathit{ext}}.{t}_{i}\approx {F}_{\mathit{critique}}={\text{CHAR\_CRIT}}_{\text{DYNA\_NON\_LINE}}({t}_{i}).{F}_{\mathit{ext}}.{t}_{i}\\ \mathrm{\Rightarrow }\\ {\text{CHAR\_CRIT}}_{\text{DYNA\_NON\_LINE}}({t}_{i+1})\approx {\text{CHAR\_CRIT}}_{\text{STAT\_NON\_LINE}}({t}_{i}).\frac{{t}_{i}}{{t}_{i+1}}={\text{CHAR\_CRIT}}_{\text{STAT\_NON\_LINE}}({t}_{i}).\frac{1}{1,001}\end{array}$

For the vibration analysis, we will do two tests:

- using the stiffness elastic matrix,
- using stiffness matrix tangent plastic.

Both reference values are obtained by two linear modal calculations conducted with the CALC_MODES operator.

To obtain the first proper frequency corresponding to the elastic case, a linear elastic calculation is made with CALC_MODES and the original material defined above (of Young's modulus valant ${2.10}^{4}\mathrm{Mpa}$).

To obtain the first eigenfrequency corresponding to the tangential plastic case, a linear elastic calculation is made with CALC_MODES and a fictitious elastic material whose Young's modulus is worth the plastic tangent module defined above: $200\mathrm{Mpa}$ , 100 times less than the actual elastic module. So we will have a eigenfrequency 10 times lower than the previous one.

We also know the analytical solution of our problem (length 1 cup consisting of a single linear finite element) which is reduced to a 1D case of compression traction:

$\omega =\sqrt{2E/\rho }\approx \lbrace \begin{array}{}0,358128\mathrm{rad}/s:\text{matériau élastique}\\ 0,0358128\mathrm{rad}/s:\text{matériau plastique}\end{array}$
