# v1.01.515 ZZZZ515 - CALC_ENDO Macro-Command Basic Test

**Summary:**

This test has no physical significance, it is a computer test. It is intended to test the `CALC_ENDO` macro-command, in the presence of the elements finished structure usually used in GC.

The features examined are:

- Modelling A: Advanced `CALC_ENDO` options
- Modelling B: Default options and settings
- Modelling C: keyword `ARRET = "NON"`
- Modelling D: Several `CALC_ENDO` chaining and initial status
- Modelling E: `DIDI` loadings

This documentation is deliberately succinct.
