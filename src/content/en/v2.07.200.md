# v2.07.200 SHLP200 - Harmonic response of a bar subjected to a non-homogenous linear relationship

**Summary:**

This test allows to validate a harmonic analysis on modal basis with
a non-homogenous linear relationship between degrees of freedom of the physical problem.

- In model A, the problem is solved on a physical basis. The results are used as a reference for model B.
- In model B, the problem is solved on a general basis, the results obtained are verified to be the same as for model A.

The AFFE_CHAR_GENE command (see [U4.44.06](doc:u4.44.06)) is used to define linear relationships between generalized ddls.

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v2.07.200/geometrie.png)

length $L=1.5m$

### 1.2 Material properties

$E=1N/{m}^{2}$

$\nu =0$

$\rho =1\mathrm{Kg}/{m}^{3}$

The very low values of Young's modulus and density are not physical.

### 1.3 Boundary conditions and loads

The system of equations to be solved is as follows:

$$
\begin{cases}
 \rho \frac{d^2u}{dt^2} + Eu=0,\\
 u(x_2,t) -u(x_1,t) = 0.1 sin(\omega t).
\end{cases}
$$

## 4 Modelling B

### 4.1 Modelling characteristics

The modelling is identical to model A.

Harmonistic analysis is solved on a generalized basis.
The linear relationship is applied between two static modes.
Each static mode corresponds to the unit static response of the ddls involved
in the linear relationship on a physical basis.

The modal base consists of dynamic N modes and both static modes.

The results for N equal to 4, 6 and 8 are analyzed.

### 4.2 Mesh characteristics

The mesh is identical to Modelling A.

### 4.3 Tested quantities and results

![Figure](/figures/v2.07.200/solution.png)

The harmonic response for N=8 is compared with the AUTRE_ASTER values (see § reference results) of model A.

## 5 Summary of the results

This test case validates the approach and allows to get,
for a case with linear relationships between physical degrees of freedom,
a harmonic response calculated on a generalized basis.

With 8 dynamic modes, we manage to reproduce very well
the system response.
By contrast, using up to 6 dynamic modes,
We see a non-physical peak around 1 Hz.

The problem of this finding is measured: the description
correct system dynamics requires a very large modal base and
The incomplete study of the base induces non-physical modes with frequency.
