# v6.02.107 SSNL107 - clamped plate, flexed by beams in contact with the free edge

**Summary:**

This test validates the unilateral contact between elements POU_D_E beam (straight beam d-Euler) and elements DKQ hull.

The main features are:

- linear behaviour,
- elastic analysis,
- unilateral contact,
- 2 modellings: elements POU_D_E and DKQ using CONTACT in AFFE_CHAR_MECA and AFFE_CHAR_MECA_F.

The reference solution is analytical and the results are of good quality.

## 2 reference solution

### 2.1 Calculation method used for reference solution

Analysis

The plate undergoes a simple bending. The solution is of the ‘'beam' type:

$V=\mathrm{DZ}(C)=\mathrm{DZ}(D)=\frac{{\mathrm{PL}}^{3}}{{\mathrm{3E.I}}_{y}}$ with ${I}_{y}=\frac{{\mathrm{bh}}^{3}}{12}$

The deflection $V$ and the $P$ load are unknown.

Both beams are in pure compression:

$-P=2.\frac{\mathrm{ES}}{L}(V-U)$ with $U=\mathrm{DZ}(E)$

> $=\mathrm{DZ}(G)$

So we can find $P$ and $V$ from these two equations. We get:

$\begin{array}{}P=\frac{6ESIU}{\mathrm{2SL³}+{\mathrm{3I}}_{y}l}\\ \\ V=\frac{\mathrm{2SL³}U}{\mathrm{2SL³}+{\mathrm{3I}}_{y}l}\end{array}$

### 2.2 Baseline

$\begin{array}{}V=-0.19005\mathrm{mm}\\ P=-9.5025{10}^{-3}N\end{array}$

### 2.3 Uncertainty about the solution

No, analytical solution.
