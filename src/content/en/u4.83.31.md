# u4.83.31 Operator COMB_FOURIER

## 1 Purpose

Recombine the FOURIER modes of a resultat data structure in particular directions. The modes are produced for an 'AXIS_FOURIER' model by the macro-command MACRO_ELAS_MULT [U4.51.02](doc:u4.51.02).

This is possible for the displacements, the reactions, the strain and stress fields in elasticity and for the temperature and flux fields in thermal analysis.

The data structure produced is of type comb_fourier.

## 2 Syntax

```text
comb_fourier = COMB_FOURIER(
    ◆ RESULTAT = fourier_elas / fourier_ther,
    ◆ ANGLE = float,
    ◆ NOM_CHAM = / "DEPL",
                 / "REAC_NODA",
                 / "SIEF_ELGA",
                 / "EPSI_ELNO",
                 / "SIGM_ELNO",
                 / "TEMP",
                 / "FLUX_ELNO",
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

**Reminder:**

The FOURIER recombination on the displacements is written:

$u(\theta )=\sum_{l=0}^{N}\left[\underset{{A}^{s}}{\underset{\underbrace{}}{(\begin{array}{ccc}\cosl\theta & 0& 0\\ 0& \cosl\theta & 0\\ 0& 0& -\sinl\theta \end{array})}}{u}_{l}^{s}+\underset{{A}^{a}}{\underset{\underbrace{}}{(\begin{array}{ccc}\sinl\theta & 0& 0\\ 0& \sinl\theta & 0\\ 0& 0& \cosl\theta \end{array})}}{u}_{l}^{a}\right]$

A symmetrical harmonic is therefore recombined with the matrix ${A}^{s}$ , an antisymmetrical harmonic with the matrix ${A}^{a}$ .

The FOURIER recombination on the strains and the stresses is written:

$\varepsilon (\theta )=\sum_{l=0}^{N}(\left[\begin{array}{cc}\cosl\theta {I}_{4}& {0}_{4,2}\\ {0}_{2,4}& -\sinl\theta {I}_{2}\end{array}\right]{\varepsilon}_{l}^{s}+\left[\begin{array}{cc}\sinl\theta {I}_{4}& {0}_{4,2}\\ {0}_{2,4}& \cosl\theta {I}_{2}\end{array}\right]{\varepsilon}_{l}^{a})$

### 3.1 Operand RESULTAT

```text
♦    RESULTAT = resu,
```

Name of the concept of type fourier_elas or fourier_ther from which the modes will be recombined.

### 3.2 Operand NOM_CHAM

```text
♦    NOM_CHAM = nomsymb,
```

Symbolic name of the recombined field or fields.

### 3.3 Operand ANGLE

```text
♦    ANGLE = langl,
```

Angle(s) in degrees of the section(s) where the FOURIER recombination takes place.

## 4 Example

The example below carries out an analysis on 2 Fourier harmonics with MACRO_ELAS_MULT, enriches the concept of type RESULTAT with CALC_CHAMP, then recombines the computed fields with COMB_FOURIER.

```text
Calcul Fourier sur les deux premières harmoniques symétriques

resu = MACRO_ELAS_MULT( MODELE = mo,

CHAM_MATER = cm,

CHAR_MECA_GLOBAL= bloqu,

CAS_CHARGE= (

_F (MODE_FOURIER = 1,

TYPE_MODE = 'SYME' ,

CHAR_MECA = ch,

SOUS_TITRE = 'mode fourier 1 SYME'),

_F (MODE_FOURIER = 2,

TYPE_MODE = 'SYME' ,

CHAR_MECA = ch,

SOUS_TITRE = 'mode fourier 2 SYME'),),

)

Calcul des contraintes et des réactions nodales par CALC_CHAMP

resu = CALC_CHAMP(reuse = resu,

RESULTAT = resu,

CONTRAINTE = 'SIGM_ELNO',

FORCE = 'REAC_NODA',

Recombinaison de Fourier sur les déplacements, réactions et contraintes pour 45° et 135°

angl1 = 45.

angl2 = 135.

co_four = COMB_FOURIER( RESULTAT = resu,

NOM_CHAM = ('DEPL','REAC_NODA','SIGM_ELNO'),

ANGLE = (angl1,angl2),);
```
