# v6.07.105 COMP005 – Validation of GRAD_VARI formulations with ENDO_ISOT_BETON law

**Summary:**

This test validates the ENDO_ISOT_BETON damage law, in 2D and 3D GRAD_VARI Modelling, defined under
COMPORTEMENT. This is an elementary test of an mesh cell (cube), subjected to a temperature loading with
dirichlet conditions on the faces. A comparison of the stresses is made on the calculation with GRAD_VARI and
without GRAD_VARI.

It allows to check the numerical equivalence between two formulations of the same behavior problem
concrete damage: the formulation *gradient of internal variables* (`*_GRAD_VARI`) and formulation
local (D_PLAN, AXIS, 3D).

It is ensured that, for the same load and the same boundary conditions, the fields (contraints, deformations)
extracts are equivalent and the quantity comparison `DIFF` is zero to the expected accuracy.

The 3 modellings validated are:

- $B$ Modelling: comparison **D_PLAN_GRAD_VARI** vs **D_PLAN**,
- $C$ Modelling: comparison **AXIS_GRAD_VARI** vs **AXIS**,
- $D$ Modelling: comparison **3D_GRAD_VARI** vs **3D**.

## 1 Methodology

The protocol is based on a **double simulation** for each model:

1. **Simulation 1 – GRAD_VARI**
The calculation is performed with a Modelling with a *grade of internal variables* (`*_GRAD_VARI`).
The constitutive law used is **ENDO_ISOT_BETON** (isotropic damage to concrete).
2. **Simulation 2 – Without GRAD_VARI (reference)**
The same problem is solved with the corresponding GRAD_VARI (`D_PLAN`, `AXIS` or `3D`) free Modelling,
with the same **behavior** law (**ENDO_ISOT_BETON**), the same **load** and the same **conditions for
limits**.

At the end of the two calculations, the same quantities (contraints, deformations, internal variables, etc.) and
A comparison table is being constructed.

The quantity **``DIFF``** represents the difference (absolute max) between the fields from the two simulations, evaluated at the same time.
point hardware / on the same set.

**Validation criteria**: `DIFF ≃ 0` at a specified accuracy (see section *Tested quantities and results* of
Each model).

## 2 Interpretation of results

For each model, **TEST_TABLE** compares the quantity `DIFF` to a zero reference value.
The test is passed if the absolute maximum value of `DIFF` is **less than the required tolerance (or accuracy).

## 3 Modelling B

### 3.1 Description

This is a transient thermomechanical test with deformations imposed on the $x$ and $y$ axes.
The temperature varies from ${T}_{0}=20°C$ to ${T}_{\max}=220°C$. The metal material with a behavioral
elastoplastic with linear nutring, a time-dependent viscoelastic response, as well as regularization
non-local to limit the location of deformations.
The transient is made up of 20 steps. The reference temperature is ${T}_{\mathrm{Ref}}=20°C$.

Two calculations are made:

- **Simulation 1**: Modelling **D_PLAN_GRAD_VARI**, constitutive law **ENDO_ISOT_BETON**,
- **Simulation 2**: Modelling **D_PLAN**, constitutive law **ENDO_ISOT_BETON**.

The loads and boundary conditions are identical in both simulations.

The fields of interest (SIXX constraints) are compared via the quantity `DIFF` (absolute maximum of
the difference).

### 3.2 Constitutive law and material parameters

The constitutive law tested is **ENDO_ISOT_BETON**, documented in [R7.01.04](doc:r7.01.04) documentation.

This is a concrete specific isotropic damage law, used here in two contexts: with and without
GRAD_VARI formulation.

The material parameters used are:

| Component | Parameter | Value |
| --- | --- | --- |
| BETON_ECRO_LINE | D_SIGM_EPSI | -1.0e4 |
| BETON_ECRO_LINE | SYT | 100.0 |
| ELAS | E | 1.0e5 |
| ELAS | NU | 0.3 |
| ELAS | ALPHA | 1.0e-5 |
| VISC_ELAS | K | 1.0e4 |
| VISC_ELAS | TAU | 0.10 |
| NON_LOCAL | C_GRAD_VARI | 2.8e-02 |
| NON_LOCAL | PENA_LAGR | 28 |

### 3.3 Tested quantities and results

The **TEST_TABLE** command checks that `DIFF` ($\frac{\text{SIXX} - \text{SIXX\_L}}{\text{SIXX}}$) is null and void at the
accuracy indicated.

| Name of parameter tested | Reference type | Reference value | Tolerance / accuracy |
| --- | --- | --- | --- |
| DIFF | NON_REGRESSION |  | 1st-6 (max. difference absolute) |
