# u4.36.03 Operator CALC_INTE_SPEC

## 1 Purpose

To compute a spectral density function from a time signal (function of time). The spectral density (or auto-spectrum) is the arithmetic mean of a certain number of spectra computed on different time blocks of the signal. If several signals are given, one obtains a spectral density matrix (or interspectrum).

It produces a concept of type interspectre.

## 2 Syntax

```text
interspectre = CALC_INTE_SPEC(
    ◇ INST_INIT = float,
    ◆ INST_FIN = float,
    ◇ DUREE_ANALYSE = float,
    ◇ DUREE_DECALAGE = float,
    ◆ NB_POIN = int,
    ◆ FONCTION = formule / nappe / fonction,
    ◇ TITRE = text,
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operands INST_INIT / INST_FIN

```text
◊    INST_INIT= ii
```

First value of the parameter for which the signals will be used for the computation of the interspectral matrix (initial time instant).

```text
♦    INST_FIN= if
```

Last value of the parameter for which the signals will be used for the computation of the interspectral matrix (final time instant).

**Note:**

*The functions will be computed with the interpolation mode which has been associated with them. It is advised, in order not to have a discretisation problem, that the functions have an authorised linear interpolation.*

### 3.2 Operands DUREE_ANALYSE / DUREE_DECALAGE

```text
◊    DUREE_ANALYSE= da
```

The functions will be cut into several windows of analysis duration da. For each of these windows an interspectral matrix is computed. The interspectral matrix resulting from the operator will be the arithmetic mean of the matrices computed.

```text
◊    DUREE_DECALAGE= dd
```

Makes it possible, when cutting the functions into windows according to the analysis duration, to shift each window with respect to the others by a duration dd. If ${t}_{k}$ is the initial time instant of the ${k}^{\text{ième}}$ window, the initial time instant of the ${(k+1)}^{\text{ième}}$ window will be ${t}_{k}$ +dd.

Let $x[k]$ and $y[k]$ be two discrete time signals and ${x}_{p}[k]$ and ${y}_{p}[k]$ the respective time windows obtained by cutting.

If $X[k]$ and $Y[k]$ denote their discrete FOURIER transforms, then the interspectral matrix is written[bib1]:

$S[k]\text{vaut}(\begin{array}{cc}{S}_{xx}[k]& {S}_{xy}[k]\\ {S}_{xy}^{\text{*}}[k]& {S}_{yy}[k]\end{array})$

where

${S}_{xx}[k]=\frac{1}{\mathrm{p.n}\Delta t}\sum_{i=1}^{p}{X}_{p}[k].{X}_{p}^{\text{*}}[k]$

${S}_{xy}[k]=\frac{1}{\mathrm{p.n}\Delta t}\sum_{i=1}^{p}{X}_{p}[k].{Y}_{p}^{\text{*}}[k]$

where $n$ is the number of points per block,

$p$ is the number of blocks.

**Caution:**

*This averaging, perfectly suited to “real” signals resulting from a measurement, is not suitable without care for functions close to a sine (the averaging frequency must be much higher than the frequency of the signal.*

**Note:**

*If the signals processed come from the operator GENE_FONC_ALEA, possibly via the computation of a dynamic response (operator DYNA_VIBRA for example), then it is advised to process each of the draws of GENE_FONC_ALEA independently. In this case, one must choose analysis and shift durations equal to the duration of each of the draws of GENE_FONC_ALEA (cf. GENE_FONC_ALEA [U4.36.05](doc:u4.36.05)).*

### 3.3 Operand NB_POIN

```text
♦    NB_POIN= np
```

Number of points of the parameter for an analysis duration. For each point the functions will be computed according to the type of interpolation and of extension defined. The number of points must be a power of 2 (fast Fourier transform computation).

**Note:**

*If the signals consist of a sufficient number (a power of two) of points with a constant step, it is preferable to choose this number in order to avoid interpolations which can generate artefacts. In particular, if the signals processed come from the operator GENE_FONC_ALEA, possibly via the computation of a dynamic response (operator DYNA_VIBRA for example), this number will correspond to twice the number of points supplied in GENE_FONC_ALEA, keyword NB_POIN, or obtained by INFO=2 in GENE_FONC_ALEA (cf. GENE_FONC_ALEA [U4.36.05](doc:u4.36.05)).*

### 3.4 Operand FONCTION

```text
♦    FONCTION=
```

List of the names of the functions (time signals) of concept type fonction, whose interspectral matrix one wishes to compute.

### 3.5 Operand TITRE

```text
◊    TITRE=
```

titre is the title of the interspectre concept to be printed at the head of the results [U4.03.01](doc:u4.03.01).

### 3.6 Operand INFO

```text
◊    INFO=
```

Specifies the printout options on the MESSAGE file.

| 1 | prints the initial frequency, the final frequency and the frequency step. |
| --- | --- |
| 2 | like 1, plus, for each auto-spectrum and interspectrum, a convergence criterion as a function of the number of random draws. (one random draw corresponds to an analysis window). |

## 4 Verification stage

One checks whether the number of points np is a power of 2.

## 5 Notes on use

The operator creates a concept of type interspectre which constitutes the interspectral matrix. This matrix being Hermitian and positive definite, the functions are of real type for the diagonal terms and of complex type for the off-diagonal terms. Only the upper triangular part of the matrix is stored.

These functions can be extracted by means of the operator RECU_FONCTION [U4.32.03](doc:u4.32.03).

## 6 Example

```text
FONC1=RECU_FONCTION(    RESU_GENE=DYNAMODE,
NOM_CHAM='DEPL',
NOEUD='N51',
NOM_CMP='DY',
INTERPOL='LIN'
)

FONC2=RECU_FONCTION(    RESU_GENE=DYNAMODE,
NOM_CHAM='DEPL',
NOEUD='N52',
NOM_CMP='DY',
INTERPOL='LIN'
)

INTERS=CALC_INTE_SPEC(    INST_INIT=0.,
INST_FIN=10.24,
DUREE_ANALYSE=1.024,
DUREE_DECALAGE=1.024,
NB_POIN=1024,
FONCTION=( FONCT1, FONCT2, )
)

REP1=RECU_FONCTION(    INTE_SPEC=INTERS,
NUME_ORDRE_I = 1,
)
```
