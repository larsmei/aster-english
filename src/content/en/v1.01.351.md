# v1.01.351 ZZZZ351 – Validation of the ELIM_LAGR command

**Summary:**

This test validates the ELIM_LAGR command, which allows the equations corresponding to dualised linear relationships to be removed in a matrix.

There is only one model (A).

## 1 Test principle

The problem addressed is that of searching for the first frequencies of a mechanical structure.

The reference solution is obtained by the CALC_MODES operator from the "complete" matrices (with the Lagrange equations).

The second calculation uses the ELIM_LAGR command to "reduce" the stiffness and mass matrices and performs a modal calculation with these reduced matrices.

## 2 Modelling A

The results with reduced matrices are tested in this model using ELIM_LAGR.

## 3 Modelling B

This test is an extract of Modelling A by replacing standard commands with Python extensions.

## 4 Modelling C

This test is an extract from Modelling A by replacing standard commands with Python extensions, and by cutting into two command files.

## 5 Summary of results

The eigenfrequencies obtained are checked for the same.
