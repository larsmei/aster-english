# v2.01.400 SDLD400 – Star-shaped spring-mass system

**Summary:**

This test consists of calculating the eigenfrequencies of a star-mass-spring system. The reference solution is analytical.

The test value is to check the methods available in modal analysis, in the presence of two discrete elements translation and rotation:

- elements discrete DIS_TR on a node (modelling A);
- elements discrete DIS_TR on a segment (modelization B).

In this test, the structure is also rotated by 30° to validate the input of the local reference data (keyword ORIENTATION in AFFE_CARA_ELEM).

A diagonal mass matrix is also used for these elements, which allows for complete coverage of this feature for discrete elements.
