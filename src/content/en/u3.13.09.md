# u3.13.09 Modellings 2D_DIS_T and 2D_DIS_TR

**Summary:**

This document describes, for the modellings 2D_DIS_T, 2D_DIS_TR (see [R5.03.17](doc:r5.03.17)):

- the degrees of freedom carried by the finite elements which support the modelling,
- the associated support mesh cells,
- the supported loadings,
- the non-linear capabilities,
- the test cases implementing the modellings.

The modelling 2D_DIS_T allows the representation of discrete translation elements with one or two nodes.

The modelling 2D_DIS_TR allows the representation of discrete translation and rotation elements with one or two nodes.

They are usable for two-dimensional problems in linear or non-linear mechanical analysis.

## 1 Discretisation

### 1.1 Degrees of freedom

The discretisation degrees of freedom are, at each node of the support mesh cell, the two translational displacement components and the rotation.

| **Finite element** | **Degrees of freedom (at each vertex node)** |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- |
| 2D_DIS_T | DX | DY |  |  |  |  |
| 2D_DIS_TR | DX | DY | DRZ |  |  |  |

### 1.2 Support mesh cell of the stiffness matrices

The support mesh cells of the discrete elements, in displacement formulation, are two-node segments SEG2 or point mesh cells POI1 coincident with a node:

| **Modelling** | **Mesh cell** | **Finite element** | **Notes** |
| --- | --- | --- | --- |
| 2D_DIS_T | POI1 | MECA_2D_DIS_T_N |  |
|  | SEG2 | MECA_2D_DIS_T_L |  |
| 2D_DIS_TR | POI1 | MECA_2D_DIS_TR_N |  |
|  | SEG2 | MECA_2D_DIS_TR_L |  |

As regards the POI1 mesh cells, the internal forces are computed from the differences between the degrees of freedom of the mesh cell and the fixed frame (as if this discrete node were attached to a fixed frame).

For the SEG2 mesh cells, the forces are computed from the differences between the degrees of freedom carried by each of the 2 nodes.

## 2 Assignment of the characteristics

For these discrete elements, it is necessary to assign geometrical characteristics which are complementary to the mesh data. The definition of these data is carried out with the command AFFE_CARA_ELEM associated with the following factor keywords:

- **DISCRET**

Makes it possible to define and assign the values of the stiffness, mass or damping matrices.

Supported modellings: 2D_DIS_T, 2D_DIS_TR

- **ORIENTATION**

Makes it possible to define and assign a local frame.

Supported modellings: 2D_DIS_T, 2D_DIS_TR

## 3 Supported loadings

The supported loading is the following:

- **'PESANTEUR'**

Makes it possible to apply a gravity-type loading.

Supported modellings: 2D_DIS_T, 2D_DIS_TR

## 4 Non-linear capabilities

All the modellings 2D_DIS_* are usable with STAT_NON_LINE and DYNA_NON_LINE. In this case one must define a material with DEFI_MATERIAU.

### 4.1 Constitutive law

The constitutive laws specific to these modellings, usable under COMPORTEMENT in STAT_NON_LINE and DYNA_NON_LINE, are the following (see [U4.51.11](doc:u4.51.11)):

**/** **'DIS_GOUJ2E_ELAS'**

Supported modelling: All

**/** **'DIS_GOUJ2E_PLAS'**

Supported modelling: All

**/** **'ELAS'**

Supported modellings: All

In addition to the assignment of the characteristics (AFFE_CARA_ELEM), the use of the modellings DIS_T and DIS_TR with STAT_NON_LINE/DYNA_NON_LINE requires material characteristics to be defined (AFFE_MATERIAU).

### 4.2 Strains

The available strains, used in the constitutive relations under the keyword DEFORMATION for the operators STAT_NON_LINE and DYNA_NON_LINE, are (see [U4.51.11](doc:u4.51.11)):

**/** **'PETIT'**

The strains used for the constitutive relation are the linearised strains computed on the initial geometry.

Supported modelling: All

**/** **'PETIT_REAC'**

The strains used in the incremental constitutive relation are the linearised strains computed on the updated geometry.

Supported modelling: All

## 5 Implementation examples: test cases

- **2D_DIS_T**
- Linear statics
- SSLL108A [V3.01.108](doc:v3.01.108): Analysis of the response of a bar, modelled by 10 discrete elements (SEG2 mesh cells) subjected to a tensile loading.
- Non-linear statics
- ZZZZ120A: Analysis of a stud-flange assembly without the upper flange, with an elastoplastic Von Mises constitutive law representing the local behaviour of a thread of a stud in a threaded assembly.
- Linear dynamics
- SDLD02E [V2.01.002](doc:v2.01.002): Computation of the vibration frequencies and of the associated modes of a mechanical structure composed of masses and springs.
- Non-linear dynamics
- SDNV104A: Dynamic response of a rigid friction pad subjected to a pressure and to a restoring force.
- **2D_DIS_TR**
- Linear dynamics
- SDLD02F [V2.01.002](doc:v2.01.002): Computation of the vibration frequencies and of the associated modes of a mechanical structure composed of masses and springs.
