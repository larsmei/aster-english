# v6.03.124 SSNP124 – Drained Biaxial Test with Softening DRUCK_PRAGER Behaviour

**Summary:**

This test case allows to run a drained biaxial test on two different modellingss when calculating nonlinearly. This allows to highlight the effect of the type of negative, parabolic or linear nutring in the case of D_PLAN models.

Modelling A

- DRUCK_PRAGER model with linear negative nutring for $2\mathrm{Mpa}$ containment.
- D_PLAN model with mesh cells QUAD4.

Modelling B:

- DRUCK_PRAGER model with parabolic negative nutring for $2\mathrm{MPa}$ containment.
- D_PLAN model with mesh cells QUAD4.
