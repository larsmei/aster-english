# v1.01.280 ERREU06 - Checking the operation of the NaN in Code_Aster

**Summary:**

This test validates the fact that in debug version on the central server Aster4, *Code_Aster* stops in error when attempting to manipulate a NaN (Not-a-Number) type SNaN (Signalling NaN).

## 1 Test principle

This test is a computer test. It validates that the NaN defines in envima.c is of the SNaN type and that, as a result, any manipulation causes the execution to stop in "digital error". This test is performed using the keyword TEST_NAN='OUI' command.
