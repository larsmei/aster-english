# v6.03.303 SSNP303 - element in flat stress and traction - Perfect plasticity

**Summary:**

This $\mathrm{2D}$ quasi-static non-linear mechanical test consists of loading three elements superimposed plates (type d-element MECPQU4). The 4 nodes are common to the 3 elements. The elements have different properties (perfect plasticity) to obtain a suitable traction curve. This test is taken from the NAFEMS guide.

The purpose is to compare the different methods of the Newton-Raphson type to solve the system of nonlinear equations (NEWTON: (MATRICE ‘ELASTIQUE) and NEWTON: (MATRICE ‘TANGENTE) with REAC_INCR and REAC_ITER). The chosen convergence criterion corresponds to $\text{0.01\%}$ of the residual force (RESI_GLOB_RELA).

The Modelling is done with elements MECPQU4 planes.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The results considered as reference were obtained by SAMCEF using 60 increments for each loading step. The characteristics of the different resolution methods are as follows:

| A | Use of elastic matrix. |
| --- | --- |
| B | Use of the tangent matrix; this matrix is re-evaluated only at the first iteration of each increment (REAC_INCR = 1 and REAC_ITER = 0). This is the modified Newton method. |
| C | Use of the tangent matrix, which is re-evaluated at each iteration of each increment (REAC_INCR = 1 and REAC_ITER = 1). This is the classic Newton method. |
