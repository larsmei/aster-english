# v1.01.338 ZZZZ338 - Validation of the frequency band balancing algorithm

**Summary:**

This test is intended to verify the correct functioning of the frequency band balancing algorithm
[DEFI_LIST_FREQ](doc:u4.34.04) operator (keyword EQUI_MODES).

The problem considered in this test is a problem with own values.
standard symmetric standard real, eigenfrequencies $f_1 \le \dots \le f_n$.
The rigidity and mass matrices of this problem do not correspond to the
a physical model, but are built to obtain $f_1,\dots,f_n$ eigenfrequencies.
To do this, a model of $n$ mesh cells of the POI1 type (DIS_T Modelling) is considered.
with degrees of freedom DY and DZ blocked, and with basic characteristics
defined so that the rigidity matrix is diagonally assembled with degrees of freedom DX only,
The associated mass matrix is equal to the identity matrix.

The frequency band balancing algorithm is then used to test two cases, namely:

- the case of the input specification of the $f_1,\dots,f_n$ (`TYPE_SAISIE = 'LISTE'`) frequency list,
- the case of the input specification of the rigidity and mass assemblies (`TYPE_SAISIE = 'MATR_ASSE'`).

The results tested consist of the frequency bands obtained after balancing, in both cases.
In particular, errors in the number of modes per desired band are verified to be less than the tolerance considered.
It is also checked that the results obtained via a list of input frequencies and via the assembled matrices
are identical.

This documentation is deliberately succinct.
