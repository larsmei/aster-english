# v3.02.112 FORMA06 - Practical work of the "Advanced use" training: multi-cracked traction plate

**Summary:**

This $\mathrm{2D}$ flat deformation test, in quasi-static form, is part of the post-processings validation in linear elastic fracture mechanics. The plate is multi-fissed. The cracks are represented by the X-FEM method.

## 1 Reference problem

The behaviour of a multi-cracked plate in traction is studied. In order not to break cracks, the X-FEM method is used.

An infinite tensile plate is considered, with 2 $\mathrm{2a}$ cracks in length (see ).

The purpose of this test is to check the abacus provided by the $G$ Handbook of stress-intensity factors. The stress intensity factor ${K}_{I}$ to point $A$ is given by the following formula:

${K}_{I}^{A}=F(\frac{2a}{r},\frac{e}{b})\sigma \sqrt{\pi a}$ where $F(\frac{2a}{r},\frac{e}{b})$ is given by the graph of the .

## 2 Modelling A

### 2.1 Geometry and mesh with Salome-Meca

Under Salomé-Méca, perform geometry.

One can consider a plate centered at the beginning, of finished dimension: $2m$ side.

Make the mesh. It is recalled that cracks are not gridded, so you can use a sufficiently fine quadrangle-set mesh anywhere (algorithm 1D = Wire discreteization + algorithm 2D = Quadrangle).

### 2.2 Creating the command file without post-processing of the break

#### 2.2.1 Reading healthy mesh and defining the unenriched model

| Play the mesh refined (LIRE_MAILLAGE) in MED format; |
| --- |
| Definition of the finished elements used (AFFE_MODELE, MODELISATION='D_PLAN'); |
| Elements normal reorientation: MODI_MAILLAGE/ORIE_PEAU_2D will be used to orient all elements in the same way, with a normal outward-facing attitude for the faces on which the load is applied; |

#### 2.2.2 Definition of the crack and elements X-FEM

| Definition of a single horizontal crack of length $\mathrm{2a}=0,3m$ (DEFI_FISS_XFEM): preferably use the crack catalogue (FORM_FISS='SEGMENT') |
| --- |
| Model modification to take into account elements X-FEM(MODI_MODELE_XFEM), |

#### 2.2.3 Definition of material, conditions and mechanical problem resolution

| Definition and allocation of material (DEFI_MATERIAU and AFFE_MATERIAU); |
| --- |
| Definition of limit conditions and loadings (AFFE_CHAR_MECA) on the enriched model: * Blocking of rigid modes (DDL_IMPO on GROUP_NO 'N_A', 'N_B'); * Application of traction (1 MPa) on 'M_top' and 'M_bas' (PRES_REP) |
| Elasticity problem (MECA_STATIQUE) resolution on the enriched model. |

#### 2.2.4 Post-processing displacement and constraints with X-FEM and visualization with Paravis

| Creating a visualization mesh (POST_MAIL_XFEM); |
| --- |
| Creating a model for visualization (AFFE_MODELE) on the mesh created for visualization; |
| Create a result field on the mesh visualization X-FEM (POST_CHAM_XFEM); |
| Print results in MED format (IMPR_RESU). |

Complete the control file with 2 cracks in the following case:

$a=0,15$ and $b=0,4$ (i.e. $2a/b=0,75$)

$e=0$

It is recalled that each DEFI_FISS_XFEM call produces a crack. For 2 cracks, you must call this command twice.

### 2.3 Added post-processing of the failure to the command file

1. **K-calculate with CALC_G**

Calculate the stress intensity factor (K1)(OPTION='CALC_K_G').

Use the result of the MECA_STATIQUE (RESULTAT).

Complete the information on the THETA field:

- the crack bottom, specifying the bottom number (in your case there are 2 crack bottoms A and B)
- the crown rays of the theta field(R_INF, R_SUP), to be defined according to the mesh used.

The CALC_G command produces a table-type data structure, so you have to print the results in a table with IMPR_TABLE.

1. **K-calculate with POST_K1_K2_K3**

Calculate K with POST_K1_K2_K3:

- use the result of the MECA_STATIQUE (RESULTAT)
- fill the crack bottom
- specify the ABSC_CURV_MAXI parameter
- print results in a table (IMPR_TABLE)

Note: do not take into account the alarm in CALC_CHAMP which specifies that EXCIT should be added.

Compare the results obtained with the Handbook solution.
