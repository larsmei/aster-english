# v2.03.104 SDLS104 - Coaxial shells under ring flow

**Summary**

A physical configuration consisting of two coaxial cylindrical hulls is considered in interaction with a fluid flowing into the ring space separating the hulls.

The purpose of this test case is to validate the fluid-structure coupling model developed in the CALC_FLUI_STRU operator for this type of configurations.

The evolution of modal parameters (frequency and reduced damping) according to the flow rate of the fluid is particularly interesting. The reference solution is provided by a calculation with the MOCCA code (Annal Containment Coupling Model).

## 1 Reference problem

### 1.1 Geometry

The configuration studied consists of two cylindrical coaxial hulls of $4m$ height

![Figure](/figures/v2.03.104/10001BB4000069D500003B6EB99021CCE3B62D62.svg)

The inner shell has an ${R}_{1}$ average radius of $0,98m$ and a ${e}_{1}$ thickness of $4\mathrm{cm}$.

The outer shell has an average ${R}_{2}$ radius of $1,105m$ and a ${e}_{2}$ thickness of $1\mathrm{cm}$.

**Note:**

*The thickness and the mean radius of the ring space between the two hulls are given*

| *per* | $H={R}_{\text{ext}}-{R}_{int}=0,1m$ | $R=\frac{{R}_{int}+{R}_{\text{ext}}}{2}=1,05m$ |
| --- | --- | --- |
| *with* | ${R}_{int}=R1+\frac{{e}_{1}}{2}=1m$ | ${R}_{\text{ext}}={R}_{2}–\frac{{e}_{2}}{2}=1,1m$ |

### 1.2 Material properties

The material constituting the two hulls is steel. Its physical characteristics are

| $\rho =7800\mathit{kg}/{m}^{3}$ | $E=2.{10}^{11}\mathit{Pa}$ | $\nu =0,3$ |
| --- | --- | --- |

### 1.3 Boundary conditions and loads

The outer shell is supposed to be rigid: all nodes are clamped.

For the inner shell, the support conditions are as follows: clamped bottom end ($z=0$) and free top part ($z=\mathrm{4m}$).

## 2 reference solution

### 2.1 Calculation method used for reference solution

The reference solution is obtained by a calculation using the MOCCA (Annal Containment Coupling Model) bib1, bib2. The latter has been validated on several experimental configurations including TAXI models of the CEA bib2 and GRAPPE2 d-EDF bib3.

The modal characteristics of the off-flow structure are indicated, so the MOCCA code allows the calculation of the reduced frequency and damping changes of each mode of the structure as a function of the flow speed. This resolution is numerically performed by a finite difference method.

The evolution of the modal parameters associated with the first mode of hull order equal to 1 is, in this case, the reference solution.

### 2.3 Uncertainty about the solution

The MOCCA_COQUE bib4 fluid-structure coupling model, which was absorbed in the CALC_FLUI_STRU operator, was developed in the context of hull structures. It allows for the consideration of any order of hull modes but is limited to uniform ring sets.

MOCCA code has been developed for beam-type motion, with the effect of variable thickness ring flow, and comparisons for hull-order modes of 1 will be made in the presence of uniform ring-flows.

The MOCCA_COQUE model is purely analytical, while the MOCCA code ss is based on a numerical solution method for the fluid problem. differences between the reference solution and the results of the *code_aster* are therefore to be expected.

## 3 Modelling A

### 3.1 Modelling characteristics

The structure geometry and characteristics of the material constituting the hulls were previously presented.

Concerning the absolute wall roughness of the structures, one takes a value of ${10}^{–5}m$ .

The surrounding fluid is water. The values taken for density and kinematic viscosity are respectively

$$
{\rho}_{f}=1000\mathrm{kg}/{m}^{3}
$$

Uncontained flow upstream and downstream of structures is considered.

The resolution model used is the MOCCA_COQUE analytical model that is absorbed in the *code_aster* (operator CALC_FLUI_STRU). The fifth air mode of the structure is selected and the coupling problem is resolved for this mode. Average flow speeds vary from $0$ to $40m/s$ per step from $5m/s$. Thus, for this mode, the evolutions of the eigenfrequency and the reduced damping depending on the flow speed are obtained.

### 3.2 Mesh characteristics

The two hulls are gridded in the same way. In order to make them solid together, an mesh-cell group connecting the nodes is added at the clamped support level.

| On a : | 17 nodes on a vertical generator |
| --- | --- |
|  | 60 nodes on a crown |
|  | 960 mesh cells QUAD4 on each shell |
|  | 60 mesh cells QUAD4 for solidarizing both hulls (base clamped) |

### 3.3 Tested Features

DEFI_FLUI_STRU operator: definition of the characteristics of a physical configuration consisting of two coaxial cylindrical hulls for a fluid-structure coupling calculation; factor keyword COQUE_COAX.

CALC_FLUI_STRU operator: fluid-structure coupling resolution for a configuration of the coaxial hull type; calculation of the evolutions of the modal parameters (reduced frequencies and damping) as a function of the fluid flow rate.

### 4.2 Remarks

The results are consistent with what could be expected.

A difference of the order of 2% on frequency and reduced damping appears, due to differences between models and resolution methods. This difference is reasonable given the initial frequency of the offflow structure ($90,4\mathrm{Hz}$).
