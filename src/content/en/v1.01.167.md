# v1.01.167 ZZZZ167 - CALC_THER_MULT command validation

**Summary:**

This test validates the correct operation of the [CALC_THER_MULT](doc:u4.54.04) command to obtain the answers of a thermal model for several loading cases.

The test structure is as follows: the macro-command results are compared to the results obtained by doing the calculation steps separately with the corresponding commands for the different load cases.

This documentation is deliberately succinct.
