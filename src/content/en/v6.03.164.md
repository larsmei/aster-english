## 2 reference solution

The constitutive law JOINT_MECA_ENDO was developed as part of the thesis of Ilaria Fontana supported in March 2022. The thesis manuscript contains all the theoretical elements of the law.

The following are the parameters of the law: normal stiffness and tangential stiffness ${K}_{n}$ and ${K}_{t}$, the friction coefficient $\mu$, the cohesion $C$, the maximum shear stress $T$, two parameters for controlling the cohesion peak and the shear peak ${B}_{n}$, ${B}_{t}$, two parameters for controlling the evolution of the shear peak ${m}_{1}$, ${m}_{2}$ and a parameter for regulating the post-pic ${D}_{1}$ phase (which allows for, inter alia, ensuring the absence of snapback). It is important to note that ${K}_{n}$, ${K}_{t}$, $\mu$, $C$ and $T$ are parameters "engineer" that can be identified on experimental tests. The Python script presented in the annex allows the numerical parameters of the law to be calculated from the engineering parameters. It is possible to use this script in the opposite direction, i.e. to calculate the engineering parameters from the numerical parameters defined beforehand. In the current version of the test case, a Python function is introduced at the beginning of each command file allowing the numerical parameters of the law to be calculated from the so-called "engineer" parameters.

For the shear test, reference solution is given by equations 2?38 and 2.39 of the thesis manuscript. For the tensile test, reference solution is given by equations 2.44 and 2.45 of the thesis manuscript. Each of these equations is expressed according to the alpha damage variable.

# Definition de la fonction S(alpha) :

def S(alpha):

    return ((1-alpha)**m1)/(alpha**m2)

# Definition de la fonction derivee de S(alpha) :

def Sp(alpha):

    return ((m2-m1)*alpha-m2)*((1-alpha)**(m1-1))/(alpha**(m2+1))

# Definition de la derivee seconde de S(alpha) :

def S2p(alpha):

    return ((m1-m2)*(m1-m2-1.)*alpha**2+2.*m2*(m1-m2-1.)*alpha+
            m2*(m2+1.))*(1.-alpha**(m1-2))/alpha**(m2+2)

# Definition de la fonction R(alpha) :

def R(alpha):

    return ((2.*(Sp(alpha))**2)/(S2p(alpha)))-S(alpha)

###############################################################

# Recherche du max de R(alpha) :

###############################################################

def FindMaxR():

    val_max = opt.fmin(lambda alpha: -R(alpha), 1.e-10)

def CalcBt():

    Bt = (-Sp(alpha_max)*(C**2-mu**2*T**2))/(2.*D1*S(alpha_max)**2)

    return Bt

def CalcC():

    C = sqrt(2.*D1*(Bn*(mu**2)+Bt))*S(alpha_max)/(sqrt(-Sp(alpha_max)))

    return C

def CalcT():

    T = sqrt(2.*D1*Bn)*S(alpha_max)/sqrt(-Sp(alpha_max))

    return T
