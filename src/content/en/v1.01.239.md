# v1.01.239 ZZZZ239 - Validation of the calculation of the non-symmetric matrix for elements DKT

**Summary:**

This test validates the calculation of non-symmetric matrices for elements DKT
(application with ENDO_LOCA_TC law).

The test consists of applying a shear load to a plate
Modeled by elements TRIA (Modelling A) or QUAD (Modelling B).
The use of a symmetrical matrix led to a lack of convergence.
The number of iterations for convergence is comparable to the equivalent 3D case.
