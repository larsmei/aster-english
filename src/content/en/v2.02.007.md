# v2.02.007 SDLL07- P with two support supports, subjected to a constant speed mobile charge

**Summary:**

The linear elasticity dynamic test is used to validate straight beam elements POU_D_T.

This test case concerns a slender beam on two supports, subject to a mobile charge of constant speed.

The frequencies and displacements are tested by comparing simulation results with reference solution AFNOR (ref. [1]).

The dynamic aster code calculation is performed using DYNA_VIBRA on the physical basis.

## 3 Summary of the results

The results show the elements `POU_D_T`'s smooth functioning in this test case of a slender beam based on two supports and subjected to a mobile constant speed charge.

The post-processing, made by calculating maximum envelopes via the `ENVELOPPE="NORME_MOMENT"` option, also confirms the correct behavior of this feature.
