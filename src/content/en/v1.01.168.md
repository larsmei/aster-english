# v1.01.168 ZZZZ168 - Validation of the CALC_MECA_MULT command

**Summary:**

This test validates the correct operation of the [CALC_MECA_MULT](doc:u4.51.05) control to obtain thermomechanical responses from a mechanical model for several cases of thermal stresses.

The test structure is as follows: the macro-command results are compared with the results obtained by doing the steps separately for the different loading cases.

This documentation is deliberately succinct.
