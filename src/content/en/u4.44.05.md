# u4.44.05 Operators AFFE_CHAR_SECH and AFFE_CHAR_SECH_F

## 1 Purpose

Assign loadings and boundary conditions on a drying analysis model.

For the operator AFFE_CHAR_SECH, the assigned values do not depend on any parameter and are defined by real values.

For the operator AFFE_CHAR_SECH_F, the values are functions of one or more parameters to be chosen from the set (INST, X, Y, Z). The functions depend solely on the water concentration (SECH) and must be tabulated.
Moreover, for certain loadings the values may depend on the command variables.

These functions must previously be defined by calling one of the operators:

- DEFI_CONSTANTE[U4.31.01];
- DEFI_FONCTION [U4.31.02](doc:u4.31.02);
- DEFI_NAPPE[U4.31.03];
- FORMULE[U4.31.05];
- CALC_FONC_INTERP [U4.32.01](doc:u4.32.01).

The concept produced is of type char_ther, as for the operator [AFFE_CHAR_THER](doc:u4.44.02).
The loadings can be applied only on elements to which a drying modelling is assigned.

## 2 Syntax

char_ther = AFFE_CHAR_SECH(

## 3 Operands

### 3.1 General remarks on the operands

#### 3.1.1 The two forms of operands under a factor keyword

The operands under a factor keyword are of two forms:

- the operands specifying the topological entities on which the loadings are assigned (keywords GROUP_NO and GROUP_MA, etc.). The arguments of these operands are identical for the two operators.
- the operand or operands specifying the assigned values (SECH, etc.). The meaning of these operands is the same for the two operators, but the arguments of these operands are all of type real for the operator AFFE_CHAR_SECH and of type fonction (created by one of the operators DEFI_FONCTION, DEFI_NAPPE, DEFI_CONSTANTE, FORMULE or CALC_FONC_INTERP) for the operator AFFE_CHAR_SECH_F.

We shall therefore not distinguish, in this document, except where expressly stated otherwise, between the two operators AFFE_CHAR_SECH and AFFE_CHAR_SECH_F.

#### 3.1.2 Topological entities for the assignment of the loadings

In general, the topological entities on which values are to be assigned are defined:

- by nodes, using the operand GROUP_NO, which makes it possible to introduce a list of node groups,
- by mesh cell, using the operand GROUP_MA, which makes it possible to introduce a list of mesh-cell groups,

**Rule:**

*In order to define the assignment domain as simply as possible, the overloading rule is used: it is the last assignment which takes precedence.*

### 3.2 Operand MODELE

```text
♦    MODELE =    mo,
```

Concept produced by the operator AFFE_MODELE [U4.41.01](doc:u4.41.01), in which the types of finite elements assigned on the mesh are defined.
Only a model containing solely drying modellings is accepted in these operators.
These modellings are: 3D_SECH, 3D_SECH_DIAG, AXIS_SECH and AXIS_SECH_DIAG.

### 3.3 Keyword SECH_IMPO

#### 3.3.1 Purpose

Factor keyword usable to impose, on nodes or node groups, a water concentration.

Depending on the name of the operator called, the values are supplied directly (AFFE_CHAR_SECH) or by means of a concept of type fonction (AFFE_CHAR_SECH_F).

#### 3.3.2 Operand

```text
SECH
```

Value of the **water concentration** imposed on the specified node(s).

### 3.4 Keyword FLUX_NL

#### 3.4.1 Purpose

Factor keyword usable to apply **normal fluxes** that are functions of the water concentration (SECH), to a **face** of a volume element defined by one or more mesh cells of type **triangle** or **quadrangle**.
This keyword also makes it possible to apply a normal flux to an edge (in AXIS) on mesh cells of type segment.
One can thus model a radiation condition of Stefan-law type.

This type of flux is available only in the command AFFE_CHAR_SECH_F.

The values are supplied by a concept of type fonction. The function depends on the water concentration, to the exclusion of any other parameter.
Moreover, it must necessarily be a tabulated function and not a formula.

#### 3.4.2 Syntax

- For AFFE_CHAR_SECH_F

```text
FLUX_NL = _F(
           ◆ / TOUT = "OUI" (ou non renseigné),
             / GROUP_MA = list[grma],
           ◆ FLUN = fonction,
        ),
```

#### 3.4.3 Operand

```text
FLUN : flux imposé normal à la maille.
```

This loading applies to the following mesh-cell types and modellings:

| **Mesh cell** | **Modelling** |
| --- | --- |
| TRIA3, TRIA6, QUAD4, QUAD8, QUAD9 | 3D_SECH, 3D_SECH_DIAG |
| SEG2, SEG3 | AXIS_SECH, AXIS_SECH_DIAG |

More precisely, the boundary condition applied is:

$\lambda (\mathrm{grad}C\cdot n)$ = fl

where $n$ is the normal oriented in the direction of the numbering of the nodes of the mesh cell. Orientation described in AFFE_CHAR_MECA, document [U4.44.01](doc:u4.44.01).
