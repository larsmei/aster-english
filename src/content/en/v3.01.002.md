# v3.01.002 SSLL02 - Short beam on two articulated supports

**Summary:**

The linear elasticity static test is used to validate straight beam elements POU_D_T.

This test case concerns a short beam on two articulated supports.

The deflections are tested by comparing simulation results with reference solution AFNOR (ref.) and those obtained with Pipestress software.
