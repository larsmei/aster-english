# v1.01.128 ZZZZ128 - Validation of LIRE_TABLE and IMPR_TABLE commands

**Summary:**

This test validates the LIRE_TABLE and IMPR_TABLE commands (in "ASTER" format).

## 1 Reference problem

A table is read on a ASCII file (so known in advance!). This table is rewritten on a new file, then rereaded. It can then be tested that the reread table still has the original content. This test allows you to validate the printing and playback of a table on a file in 'ASTER' format.
