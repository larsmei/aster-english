# v4.23.302 TTLP302 - Thermal transfer in a Plan domain with geometric singularity

**Summary:**

This test is based on independent validation of version 3 in linear transient thermal analysis.

This is a $\mathrm{2D}$ plane problem represented by two modellings, one plane, the other volume.

The functions tested are as follows:

- element thermal plane,
- element thermal volumetric,
- transient thermal analysis algorithm,
- geometric singularity,
- limit conditions: temperature imposed.

The interest of the test, in addition to the fact that it is an industrial case, lies in the consideration of geometric singularity in transient thermal analysis analysis.

### 2.1 Calculation method used for reference solution

The reference solution is a numerical solution obtained by the elements finite [bib2] method cited in the reference [bib1]. This solution is based on a 168 elements square $\mathrm{0.05m}$ mesh mesh squares sided, with 200 time step ($\Delta t=0.0005s$ ).

## 4 Summary of the results

The Modelling performed (PLAN with mesh cells QUAD4) gives satisfactory results. the difference maximum is $-0.73\text{\%}$ , and it is located on the smallest reference value.

The $\mathrm{erfc}(\frac{x}{2\sqrt{t}})$ initial condition was correctly taken into account and required the use of the CREA_CHAMP command to define an initial temperature field in each nodes of the model.
