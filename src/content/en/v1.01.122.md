# v1.01.122 ZZZZ122 – Validation of the deformation calculation due to control variables

**Summary:**

This test has no physical meaning, it is essentially a computer test. It checks the correct consideration of the control variables for the calculation of the so-called "removal" deformations (temperature, drying, hydration) for the law tested in comparison to the ELAS law.

Modelling A: KIT_DDI law, BETON_UMLV/MAZARS couplings and BETON_UMLV/ENDO_ISOT_BETON.

This documentation is deliberately succinct.
