# v3.01.110 SSLL110 - 3 bar U-shaped system under clean weight

**Summary:**

This test allows simple verification of gravity calculations for elements bar (2D and 3D) mechanically in static linear structures. The model is linear.

It allows testing the application of gravity on elements bar, located in a different point of view from the direction of the gravity.

The values tested are displacements, generalized forces and constraints.

## 1 Reference problem

### 1.1 Geometry

A 3 bar system made of $U$ , drawn here in a local $(x,y)$ marker :

![Figure](/figures/v3.01.110/10000000000001D30000011DAED2F2AF82E5748E.png)

The cross-sectional area is $A={\mathrm{1m}}^{2}$ . The length of each of the 3 bars is $L=\mathrm{10m}$ .

The marker in which is drawn here is turned from $60°$ to the $(X,Y)$ laboratory marker:

![Figure](/figures/v3.01.110/1000020000000164000000D7903DA24EA29E41FA.png)

### 1.2 Material properties

$E=2.{10}^{11}\mathit{Pa}$ for the 3 bars.

$\rho =8000\mathit{kg}/{m}^{3}$ only for the $\mathit{CD}$ bar . For the other 2 bars, $\rho =0$ .

### 1.3 Boundary conditions and loads

clamped support en $A$ et $B$ .

To avoid rigid body movements, $\mathit{DZ}=0$ for all nodes, and $\mathit{DX}=0$ for $C$ and $D$.

One load is applied: the gravity. The gravity is obviously linked to the laboratory's reference point, so in the $-Y$ direction, it is taken a virtual acceleration of $g=\mathrm{20m}/{s}^{2}$. In the structure's reference point, the gravity is expressed as $(\sin(60)g,-\cos(60)g)=(0.866\times g,-0.5\times g,0)$, which is equivalent to $g=\mathrm{10m}/{s}^{2}$, in the $–y$ direction.

## 2 reference solution

### 2.1 Calculation method used for reference solution

analytical solution :

- Normal effort in each of the $\mathrm{AC}$ and $\mathrm{BD}$ bars: $N=\rho .\mathrm{L.A.g}/2$
- ${U}_{y}$ moving in $C$ and $D$ : ${U}_{y}=\mathit{NL}/\mathit{ES}$

### 2.2 Baseline

- Normal effort in $\mathrm{AC}$ and $\mathrm{BD}$ bars: $N={4.10}^{5}N$
- $C$ and $D$ travel: ${U}_{y}=2{10}^{-5}m$

### 2.3 Uncertainty about the solution

analytical solution.

## 3 Modelling A

Each bar is modeled by a single element BARRE.

## 5 Summary of the results

This test, which is very simple, allows you to check the gravity in the elements bar simultaneously, which is verified by the perfect coincidence of the results with the analytical solution.
