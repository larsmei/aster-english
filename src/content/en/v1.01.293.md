# v1.01.293 ZZZZ293 – Validation of the position of the sub-points of multifibre beams

**Summary:**

This test validates the calculation of the position of the integration subpoints in the global benchmark for POU_D_EM and POU_D_TGM Modelling. An elementary mechanical calculation is performed to allow the creation of a table with CREA_TABLE from the result. Only the coordinates of some subpoints are tested in the table.

## 2 reference solution

### 2.1 Method of calculation

The position of nodes, integration points and integration subpoints is calculated from their coordinates in the local beam axes and the passage matrices between local and global axes.

By default, local and global axes coincide (Figure ).

![Figure](/figures/v1.01.293/1000020000000265000001AF7AE9B97C351F03B8.png)

**Figure** 2.1-a **:** **default position**

The two rotations (see Figure ) are applied to orient the beam axis, and a third rotation is used to position the right section:

- $\alpha =45°$ around $Z$
- $\beta =-35,26°$ around the new $\mathit{Y1}$ axis
- $\gamma =0°$ or $90°$ around the new $\mathit{X2}$ axis

**Note:**

Code_Aster nautical angle conventions are used (see ORIENTATION keyword AFFE_CARA_ELEM)

The rotation around the $Z$ axis ($\alpha$ ) is made from the following matrix:

$\mathit{Tz}(\alpha )=\left[\begin{array}{c}\cos(\alpha )\\ \sin(\alpha )\\ 0\end{array}\begin{array}{c}-\sin(\alpha )\\ \cos(\alpha )\\ 0\end{array}\begin{array}{c}0\\ 0\\ 1\end{array}\right]$

The rotation around the new $\mathit{Y1}$ axis ($\beta$ ) is made from the following matrix:

$\mathit{Ty1}(\beta )=\left[\begin{array}{c}\cos(\beta )\\ 0\\ -\sin(\beta )\end{array}\begin{array}{c}0\\ 1\\ 0\end{array}\begin{array}{c}\sin(\beta )\\ 0\\ \cos(\beta )\end{array}\right]$

The rotation around the new $\mathit{X2}$ axis ($\gamma$ ) is made from the following matrix:

$\mathit{Tx2}(\gamma )=\left[\begin{array}{c}1\\ 0\\ 0\end{array}\begin{array}{c}0\\ \cos(\gamma )\\ \sin(\gamma )\end{array}\begin{array}{c}0\\ -\sin(\gamma )\\ \cos(\gamma )\end{array}\right]$

So for any point coordinates $(X,Y,Z)$ before rotations, one can calculate its $(X',Y',Z')$ coordinates after rotations with the following transformation:

$\left[\begin{array}{c}X'\\ Y'\\ Z'\end{array}\right]=\left[\mathit{Tx2}(\gamma )\right]\left[\mathit{Tz}(\alpha )\right]\left[\mathit{Ty}(\beta )\right]\left[\begin{array}{c}X\\ Y\\ Z\end{array}\right]$

### 2.2 Quantities and reference results

The position of some sub-points of integration in the global benchmark, knowing their position in the local axes, is calculated.

With the chosen angles, the digital application gives:

$\mathit{Ty1}(\beta )=\left[\begin{array}{c}0.8165\\ 0\\ 0.5774\end{array}\begin{array}{c}0\\ 1\\ 0\end{array}\begin{array}{c}-0.5774\\ 0\\ 0.8165\end{array}\right]$ $\mathit{Tz}(\alpha )=\left[\begin{array}{c}0.7071\\ 0.7071\\ 0\end{array}\begin{array}{c}-0.7071\\ 0.7071\\ 0\end{array}\begin{array}{c}0\\ 0\\ 1\end{array}\right]$

et

$\mathit{Tx2}(\gamma )=\left[\begin{array}{c}1\\ 0\\ 0\end{array}\begin{array}{c}0\\ 1\\ 0\end{array}\begin{array}{c}0\\ 0\\ 1\end{array}\right]$ ou $\mathit{Tx2}(\gamma )=\left[\begin{array}{c}1\\ 0\\ 0\end{array}\begin{array}{c}0\\ 0\\ 1\end{array}\begin{array}{c}0\\ -1\\ 0\end{array}\right]$

## 3 Modelling A

### 3.1 Mesh characteristics

The mesh of the beam is composed of an element SEG2.

The mesh of the section is composed of 4 elements quadrilateral.

The node group $\mathit{ENC}$ is composed of the node $\mathit{P1}$ .

The node group $\mathit{CHA}$ is composed of the node $\mathit{P2}$ .

### 3.2 Modelling characteristics

This is a model POU_D_EM(elements at 2 points of Gauss). The angle of spin is equal to $0°$ .

Modelling:

MOPOU=AFFE_MODELE(mesh=MAPOU,

> AFFE=_F(TOUT='OUI', PHENOMENE='MECANIQUE',

> MODELISATION='POU_D_EM',),

)

boundary conditions:

BLOCAGE=AFFE_CHAR_MECA(MODELE=MO,

> DDL_IMPO=_F(GROUP_NO='ENC',

> DX=0.0, DY=0.0, DZ=0.0, DRX=0.0, DRY=0.0, DRZ=0.0,),

)

Mechanical loading:

CHARGE=AFFE_CHAR_MECA(MODELE=MO,

> FORCE_NODALE=_F(GROUP_NO='CHA', FX = 100, FY = 100, FZ = 100.),

)

Assigning elements characteristics:

POUCA_0=AFFE_CARA_ELEM(MODELE=MOPOU, GEOM_FIBRE=GF,

> POUTRE=_F(GROUP_MA=('POUTRE'),

> SECTION='RECTANGLE', CARA=('HY','HZ'), VALE=(0.2,0.1),
> PREC_AIRE=5.,PREC_INERTIE=10.,),

> ORIENTATION=_F(GROUP_MA=('POUTRE'), CARA='ANGL_VRIL', VALE=0.0,),
> MULTIFIBRE=_F(GROUP_MA=('POUTRE'), GROUP_FIBRE=('SBET',),),

)

The main purpose of this test is to check whether the positions of the modellings POU_D_EM and POU_D_TGM integration subpoints are well calculated.

For these modellings, the maximum error found is $1.3E-07\text{\%}$.
