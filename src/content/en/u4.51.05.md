# u4.51.05 Command CALC_MECA_MULT

## 1 Purpose

The role of the command CALC_MECA_MULT is to compute the thermomechanical responses of a mechanical model for
different cases of thermal loads. For this, one supplies a common mechanical loading and
a thermal result data structure per load case.

The data structure produced is of type evol_noli_dict.

## 3 Operands

### 3.1 Operands MODELE / CHAM_MATER / CARA_ELEM

MODELE is the name of the model whose elements are the subject of the mechanical analysis.

CHAM_MATER is the name of the material field assigned to the model supplied in MODELE.

CARA_ELEM contains additional characteristics for the shell, beam, pipe, bar, cable and discrete elements. This keyword is optional.

### 3.2 Operand CHAR_MECA_GLOBAL

Concept of type charge produced by the commands [AFFE_CHAR_MECA](doc:u4.44.01), [AFFE_CHAR_MECA_F](doc:u4.44.01), [AFFE_CHAR_CINE](doc:u4.44.03) or [AFFE_CHAR_CINE_F](doc:u4.44.03).
This keyword makes it possible to define the mechanical loading common to all the load cases defined by the user.

### 3.3 Operand LIST_INST

This keyword serves to supply a list of the analysis time instants so that it is common to all the load
cases. This list is defined in the concept of type `litpsr8` by the operator [DEFI_LIST_REEL](doc:u4.34.01) or in
the concept `litps` by the operator [DEFI_LIST_INST](doc:u4.34.03).
When this keyword is not supplied, the temporal discretisation chosen for each load case
is identical to the discretisation of the corresponding thermal field. The time instants are automatically
recovered and may therefore be different for each load case. When this keyword is supplied,
it is the time instants supplied in this keyword and only these time instants which are taken into account.

### 3.4 Operand CAS_CHARGE

This factor keyword makes it possible to define each load case by supplying a result data
structure coming from a thermal analysis, a name for the case, and possibly a reference value.

#### 3.4.1 Operand EVOL_THER

This keyword makes it possible to supply the thermal result to be used as loading. This may be
a result data structure of type evol_ther or a composite data structure of type
evol_ther_dict which may come from the command [CALC_THER_MULT](doc:u4.54.04).

#### 3.4.2 Operand NOM_CAS

Character string serving as the access variable to the result data structure. This operand is useful only if the result supplied in the keyword EVOL_THER is not a result of type evol_ther_dict.

#### 3.4.3 Operand VALE_REFE

This keyword makes it possible to define the reference temperature for the load case considered, the temperature
for which there is no thermal strain. By default this value is chosen as 0°C.
Caution: in the case of the analysis of a response to a unit shock for numerical analysis
methods, the choice of a temperature different from 0°C may lead to unexpected results.

For the definition of this value, one may refer to the documentation concerning the materials; VALE_REFE in AFFE_MATERIAU.

### 3.5 Keyword CONVERGENCE

See the keyword CONVERGENCE of [STAT_NON_LINE](doc:u4.51.03).

### 3.6 Keyword SOLVEUR

See the documentation of [SOLVEUR](doc:u4.50.01).

### 3.7 Keyword NEWTON

A Newton-Raphson algorithm is used; see the documentation of the Newton method.
