# v1.06.001 HROM001 – Verification of the API python for the reduced base construction

**Summary:**

This test case is intended to check the API python for the basic reduced construction (ROM)
by a *Proper Orthogonal Decomposition* (POD). Different types of linear algebra solvers
are tested, and the test is only for *snapshots* matrices obtained on the moving fields
nodes in the case of mechanical calculation.

This test focuses on basic construction algorithms in the sense of linear algebra, not
Field handling.

This documentation is deliberately succinct.
