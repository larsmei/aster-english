# v2.01.030 SDLD30 - Spectral seismic response of a 2 masses and 3 multi-supported springs system

**Summary:**

The problem is to calculate the spectral response of a system 2 masses - 3 springs subjected to multiple seismic excitation.

The element is tested in traction, the calculation of eigenmodes, static modes and spectral response by modal superposition via COMB_SISM_MODAL operator. Different cumulations are tested when calculating the support responses.

The results obtained are in very good agreement with the reference analytical results.

## 1 Reference problem

### 1.1 Geometry

The structure is modelled by a set of 3 springs and 2 point masses.

![Figure](/figures/v2.01.030/10000000000004D30000013067627D50353E3BCC.png)

### 1.2 Material properties

stiffness de restraint: ${k}_{\mathrm{1 }}={k}_{\mathrm{2 }}=k=\mathrm{1000 }N/m$ ; ${k}_{\mathrm{3 }}=10k=\mathrm{10000 }N/m$

point mass: ${m}_{\mathrm{2 }}={m}_{\mathrm{3 }}=m=\mathrm{10 }\mathit{kg}$ .

### 1.3 Boundary conditions and loads

- **boundary conditions**

The only travels allowed are $x$-axis translations.

The $\mathit{NO1}$ and $\mathit{NO4}$ points are clamped: DX=DY=DZ=DRX=DRY=DRZ=0.

The other points are free to translate according to the $x$ direction: DY=DZ=DRX=DRY=DRZ=0.

- **loading**

The structure is subjected to multiple spectral seismic excitation and differential displacement.

The response spectra d-oscillator in pseudoacceleration are simplified. Only the values corresponding to the 2 frequencies of the system are mentioned. They do not depend on damping:

- au node $\mathit{NO1}$ :

${\mathit{SRO}}_{\mathit{NO1}}({f}_{1})={A}_{11}=7m/{s}^{2}$

${\mathit{SRO}}_{\mathit{NO1}}({f}_{2})={A}_{21}=5m/{s}^{2}$

${\mathit{DDS}}_{\mathit{NO1}}=D1=-0.04m$

- au node $\mathit{NO4}$ :

${\mathit{SRO}}_{\mathit{NO4}}({f}_{1})={A}_{12}=12m/{s}^{2}$

${\mathit{SRO}}_{\mathit{NO4}}({f}_{2})={A}_{22}=6m/{s}^{2}$

${\mathit{DDS}}_{\mathit{NO4}}={D}_{2}=0.06m$

### 1.4 Initial conditions

The system is initially at rest.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The spectral response is calculated by modal superposition of a spring mass system subjected to two distinct excitations. The displacement of the masses and the supporting reactions to nodes $\mathit{NO1}$ and $\mathit{NO4}$ along the $x$ axis are determined.

The following are analytically calculated:

- ${f}_{i}$ eigenfrequencies,
- ${\varphi}_{\text{Ni}}$-associated own vectors standardized to modal mass,
- ${\psi}_{j}$ static support modes of the system,
- ${P}_{ij}$ modal participation factors for support,
- ${\mathrm{Rm}}_{ij}$ the maximum response of each mode from excitation spectra,
- ${\text{Re}}_{j}$ the contribution of the drive movement of each support from differential displacements,
- ${\mathrm{Rc}}_{j}$ the static correction term,
- the primary and secondary components of the response according to the cumulation rules adopted.

### 2.2 Baseline

$K=\left[\begin{array}{cccc}k& -k& 0& 0\\ -k& \mathrm{2k}& -k& 0\\ 0& -k& \mathrm{11k}& -\mathrm{10k}\\ 0& 0& -\mathrm{10k}& \mathrm{10k}\end{array}\right]$

${K}^{p}=\left[\begin{array}{cccc}\mathrm{2k}& -k& -k& 0\\ -k& \mathrm{11k}& 0& -\mathrm{10k}\\ -k& 0& k& 0\\ 0& -\mathrm{10k}& 0& \mathrm{10k}\end{array}\right]$

degrees of freedom structure matrix, 3, degrees of freedom support 1, 4

${K}^{p}=\left[\begin{array}{cc}{k}_{xx}& {k}_{\mathit{xs}}\\ {k}_{\mathit{sx}}& {k}_{\mathit{ss}}\end{array}\right]$         ${k}_{xx}=\left[\begin{array}{cc}\mathrm{2k}& -k\\ -k& \mathrm{11k}\end{array}\right]$             ${k}_{\mathit{xs}}=\left[\begin{array}{cc}-k& 0\\ 0& -\mathrm{10k}\end{array}\right]$

either ${\mu}_{1}=\frac{m}{4}(170-18\sqrt{85})$ ${\mu}_{2}=\frac{m}{4}(170+18\sqrt{85})$

1. eigenmodes standardized to the unit generalised modal mass ${\varphi}_{\text{Ni}}$:

- ${\mathrm{Fm}}_{i}$ modal reactions:

${r}_{i}={k}_{\mathrm{sx}}{\varphi}_{\mathrm{Nis}}$         ${\varphi}_{\text{Ni}}^{p}=(\begin{array}{c}{\varphi}_{\text{Nix}}\\ {\varphi}_{\text{Nis}}\end{array})$         ${\mathrm{Fm}}_{i}^{p}=(\begin{array}{c}0\\ {r}_{i}\end{array})$

either ${\mathrm{Fm}}_{1}=\frac{k}{\sqrt{{\mu}_{1}}}(\begin{array}{c}-1\\ 0\\ 0\\ 5(9-\sqrt{85})\end{array})$ ${\mathit{Fm}}_{2}=\frac{k}{\sqrt{{\mu}_{2}}}(\begin{array}{c}1\\ 0\\ 0\\ -5(9+\sqrt{85})\end{array})$

- contribution of dynamic mode 1 to the movement imposed on node $\mathit{NO1}$:

${P}_{11}={}^{T}\varphi _{1}M{\psi}_{1}=\frac{m}{42\sqrt{{\mu}_{1}}}(13+\sqrt{85})$

- contribution of dynamic mode 1 to the movement imposed on node $\mathit{NO4}$:

${P}_{12}={}^{T}\varphi _{1}M{\psi}_{2}=\frac{10m}{21\sqrt{{\mu}_{1}}}(-8+\sqrt{85})$

${P}_{21}={}^{T}\varphi _{2}M{\psi}_{1}=\frac{m}{42\sqrt{{\mu}_{2}}}(-13+\sqrt{85})$

- contribution of dynamic mode 2 to the movement imposed on node $\mathit{NO4}$:

${P}_{22}={}^{T}\varphi _{2}M{\psi}_{2}=\frac{10m}{21\sqrt{{\mu}_{2}}}(8+\sqrt{85})$

- Dynamic mode 1 participation factor in the $X$ direction:

${P}_{\mathrm{1X}}={P}_{11}+{P}_{12}$

- Dynamic mode 2 participation factor in $X$ direction:

${P}_{\mathrm{2X}}={P}_{21}+{P}_{22}$

- **Static support modes** ${\psi}_{j}$
- static solution for a unit displacement of node $\mathit{NO1}$:

displacement: ${\psi}_{1}=\frac{1}{21}(\begin{array}{c}21\\ 11\\ 1\\ 0\end{array})$ nodal reactions: ${F}_{1}=K{\psi}_{1}=\frac{10}{21}k(\begin{array}{c}1\\ 0\\ 0\\ -1\end{array})$

- static solution for a unit displacement of node $\mathit{NO4}$:

displacement: ${\psi}_{2}=\frac{1}{21}(\begin{array}{c}0\\ 10\\ 20\\ 21\end{array})$ nodal reactions: ${\mathit{Fs}}_{2}=K{\psi}_{2}=\frac{10}{21}k(\begin{array}{c}-1\\ 0\\ 0\\ 1\end{array})$

- **mode response** $i$ **support movement** $j$

${\mathit{Rm}}_{ij}={r}_{i}{P}_{ij}\frac{{A}_{ij}}{{\omega}_{i}^{2}}$ with ${r}_{i}={\varphi}_{\text{Ni}}$ or ${\mathit{Fm}}_{i}$

- **static correction**
- ${u}_{j}$ $K{u}_{j}=M{\psi}_{j}$ solution static modes:

displacement: ${u}_{1}=\frac{m}{441k}(\begin{array}{c}0\\ 122\\ 13\\ 0\end{array})$ nodal reactions: $F{u}_{1}=\frac{m}{441}(\begin{array}{c}-122\\ 231\\ 21\\ -130\end{array})$

- static adjustment for support movement $j$ if mode 2 is not used:

${\mathrm{Rc}}_{j}=({\mathrm{ru}}_{j}-\frac{{P}_{\mathrm{1j}}{r}_{1}}{{\omega}_{1}^{2}}){A}_{\mathrm{1j}}$ with: ${\mathrm{ru}}_{j}={u}_{j}\mathrm{ou}{\mathrm{Fu}}_{j}$ and ${r}_{1}={\varphi}_{\mathrm{N1}}\mathrm{ou}{\mathrm{Fm}}_{1}$

- **support contribution** $j$ **for training movement**

$R{e}_{j}={r}_{j}{D}_{j}$ with ${r}_{j}={\psi}_{j}\mathrm{ou}{\mathrm{Fs}}_{j}$
