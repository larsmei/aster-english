# u4.55.03 Operator ELIM_LAGR

## 1 Purpose

Remove the Lagrange equations from a matrix which contains them.

This command is experimental. It is intended above all to produce matrices “without Lagrange” for the modal analysis operator (CALC_MODES).

Notes:

- In order to eliminate the Lagrange equations, one is led to eliminate certain physical degrees of freedom (one eliminates one physical degree of freedom for each linear relation if the relations are not redundant).
- If one performs a modal analysis with “reduced” matrices, the computed modes must be restored onto the original degrees of freedom by means of the command REST_GENE_PHYS.

Produces a data structure of type matr_asse_elim_r, usable only in CALC_MODES.

## 2 Syntax

```text
matr_asse_elim_r = ELIM_LAGR(
    ◆ MATR_RIGI = matr_asse_depl_r,
    ◇ MATR_ASSE = matr_asse_depl_r,
    ◇ INFO = / 1,
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand MATR_RIGI

```text
♦    MATR_RIGI    =    K1,
```

Name of the assembled stiffness matrix (with linear relations to be eliminated)

If the keyword MATR_ASSE is not used, it is the matrix K1 which one “reduces” in order to create the result matrix (M2).

### 3.2 Operand MATR_ASSE

```text
◊    MATR_ASSE    =    M1,
```

Name of the assembled mass, damping, … matrix (not stiffness) which one wants to reduce.

If this keyword is used, it is the matrix M1 which one “reduces” in order to create the result matrix (M2).

### 3.3 Operand TITRE

```text
◊    TITRE    =    titr ,
```

Title which one wants to give to the result produced [U4.03.01](doc:u4.03.01).

### 3.4 Operand INFO

```text
◊    INFO    =
```

1: no printout.

2: printouts

## 4 Analysis on several processors

When one uses several processors, the data of the model must be replicated on all the processors taking part in the analysis, by using the keyword DISTRIBUTION of the command AFFE_MODELE

```text
MODEL=AFFE_MODELE(…

DISTRIBUTION=_F(METHODE='CENTRALISE'))
```

The analysis can then be performed on several processors. Warning: all the processors performing the same operations, there is no computational gain for the step of elimination of the Lagrange multipliers. The interest is then to perform a modal analysis on several processors.

## 5 Example

```text
K1 = ASSE_MATRICE(NUME_DDL=NU, MATR_ELEM=KEL,)

M1 = ASSE_MATRICE(NUME_DDL=NU, MATR_ELEM=MEL,)

# 1. calcul avec les matrices complètes :

#-------------------------------------------------------

mode1 = CALC_MODES( MATR_RIGI=K1,

MATR_MASS=M1,

OPTION='BANDE',

CALC_FREQ=_F( FREQ=(-2, 30),) )

# 2. calcul avec les matrices réduites par ELIM_LAGR :

#-------------------------------------------------------

K2=ELIM_LAGR(MATR_RIGI=K1, )

M2=ELIM_LAGR(MATR_RIGI=K1, MATR_ASSE=M1)

mode2 = CALC_MODES( MATR_RIGI=K2,

MATR_MASS=M2,

OPTION='BANDE',

CALC_FREQ=_F( FREQ=(-2, 30),) )
```

mode3 = REST_GENE_PHYS(RESU_GENE=mode2)
