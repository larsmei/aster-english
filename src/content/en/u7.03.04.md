# u7.03.04 Macro-command CREA_LIB_MFRONT

## 1 Purpose

Build a constitutive-law library from a `*.mfront` file.

The object produced is then used under the keyword COMPORTEMENT/COMPOR_MFRONT.

One will find more information on the MFront format in the dedicated [user's guide](doc:u2.10.02).

## 2 Syntax

```
compor_mgis = CREA_LIB_MFRONT(
    ◆ NOM_COMPOR = text,
    ◆ | UNITE_MFRONT = unit,
      | UNITE_LIBRAIRIE = unit,
    ◇ DEBUG = / "OUI",
              / "NON" (par défaut),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand NOM_COMPOR

```
◆    NOM_COMPOR    =    nom,
```

Name of the constitutive behaviour to be used, as defined in the `*.mfront` file (directive `@Behaviour`).

### 3.2 Operand UNITE_MFRONT

```
UNITE_MFRONT    =    unit_mfront,
```

Logical unit number of the `*.mfront` file containing the constitutive law in MFront format. The file supplied will be compiled using the `mfront` executable.

If UNITE_MFRONT is not filled in, one must indicate UNITE_LIBRAIRIE in order to specify which library to use. If both keywords are filled in, the library built will be copied onto the file corresponding to UNITE_LIBRAIRIE.

The version of **code_aster** used (since 16.3.13) must be compiled with support for [MGIS](https://thelfer.github.io/mgis/web/index.html) and for [MFront](https://thelfer.github.io/tfel/web/index.html) in order for the compilation to work.

### 3.3 Operand UNITE_LIBRAIRIE

```
UNITE_LIBRAIRIE    =    unit_lib,
```

If both keywords UNITE_MFRONT and UNITE_LIBRAIRIE are filled in, UNITE_LIBRAIRIE indicates the logical unit on which the compiled library will be written (it is a result).

If only UNITE_LIBRAIRIE is filled in, it indicates the library to be used (it is an input).

### 3.4 Operand DEBUG

```
◊    DEBUG    =    /     "OUI",
                   /     "NON"    (par défaut)
```

By using DEBUG="OUI", one activates the `--debug` option of MFront, which displays the input and output data.
