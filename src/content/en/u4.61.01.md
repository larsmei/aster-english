# u4.61.01 Operator CALC_MATR_ELEM

## 1 Purpose

Compute elementary matrices which one will be able to assemble by the command ASSE_MATRICE.

The possible analysis options are:

'AMOR_ACOU', 'mass_meca', 'RIGI_FLUI_STRU', 'rigi_rota', 'AMOR_MECA',

'MECA_GYRO', 'MASS_MECA_DIAG', 'rigi_geom', 'RIGI_THER',

'MASS_THER', 'IMPE_MECA', 'rigi_meca', 'MASS_ACOU', 'ONDE_FLUI',

'RIGI_MECA_HYST', 'MASS_FLUI_STRU', 'RIGI_ACOU', 'RIGI_GYRO'

Produces a data structure of type matr_elem_*.

### 3.2 Operands MODELE / CHAM_MATER / CARA_ELEM

```text
♦    MODELE= mo
```

This operand is used to indicate the elements for which the elementary analyses must be performed: one recalls that the finite elements are for the most part defined in the model.

There are two exceptions:

1. The elements of dualisation of the DIRICHLET conditions, that is the elements making it possible to impose conditions on the displacement degrees of freedom in mechanics, the temperature degrees of freedom in thermal analysis and the pressure degrees of freedom in acoustics.
2. The elements of nodal loading.

These elements are defined in the concepts of type char_meca, char_ther or char_acou.

One must therefore supply the argument l_char for the computation of the elementary stiffness matrices: RIGI_MECA, RIGI_THER, RIGI_ACOU, RIGI_MECA_HYST.

```text
◊    CHAM_MATER= chmat
```

Name of the material field in which the material characteristics of the elements are defined.

This argument is **almost always necessary**.

In practice, one can do without it:

- for the discrete elements whose elementary matrices are defined in the concept cara_elem. See AFFE_CARA_ELEM [U4.42.01](doc:u4.42.01),
- for the computation of the stiffnesses due to the dualisation of the boundary conditions.

```text
◊    INST= tps
```

The argument tps is used when the material characteristics or the loadings depend on time. A fairly frequent case is that of a mechanical material depending on the temperature which itself depends on time.

```text
◊    CARA_ELEM= carac
```

The elementary characteristics carac are necessary if there exist in the model beam or shell elements or discrete elements, or if an anisotropy reference frame has been defined on solid elements (keyword MASSIF of the command AFFE_CARA_ELEM).

### 3.3 Operand CHARGE

```text
◊    CHARGE = char
```

This operand has several distinct functions:

1. Make possible the computation of the elementary stiffness matrices corresponding to the dualisation of certain Dirichlet boundary conditions,
2. For the option 'ONDE_FLUI': give the value of the pressure of the incident wave,
3. For the option 'RIGI_ROTA': give the value of the rotation imposed on the model.

### 3.4 Operand MODE_FOURIER

```text
◊    MODE_FOURIER=     / nh
/    0            [DEFAUT]
```

Positive or zero integer indicating the Fourier harmonic on which one computes the elementary matrices.

### 3.5 Operand CALC_ELEM_MODELE

```text
◊    CALC_ELEM_MODELE=    / 'OUI'                                            [DEFAUT]
/ 'NON'
```

This operand makes it possible to compute the elementary stiffness matrix associated only with the macro-elements of the model ('NON'). By default, the matrix is computed on the whole of the model ('OUI').

### 3.6 Operand GROUP_MA

```text
◊    GROUP_MA = lgma,
```

This operand makes it possible to compute the elementary matrices only on the mesh cells of the groups lgma. The operand is allowed for the gyroscopy options, RIGI_MECA, RIGI_MECA_HYST, AMOR_MECA, MASS_MECA, IMPE_MECA, MASS_MECA_DIAG and MASS_FLUI_STRU.

### 3.7 Operand SIEF_ELGA (option 'RIGI_GEOM')

```text
♦    SIEF_ELGA= sig
```

The stress field sig given for the computation of the option 'RIGI_GEOM' must in principle have been computed with the option 'SIEF_ELGA' (stress field at the Gauss points of the elements) (cf. command CALC_CHAMP [U4.81.04](doc:u4.81.04)). The theory of linear buckling indeed assumes a theory of small elastic displacements.

### 3.8 Operands RIGI_MECA and MASS_MECA (options 'AMOR_MECA' and 'RIGI_MECA_HYST')

```text
♦    RIGI_MECA=
```

Real part of the elementary stiffness matrices ('RIGI_MECA') necessary for the computation of the matrices:

- of damping ('AMOR_MECA')
- of hysteretic stiffness by global hysteretic damping ('RIGI_MECA_HYST'), see "User's guide to damping and hysteretic stiffness" [U2.06.03](doc:u2.06.03).
- of complex stiffness for viscoelastic materials; the option 'RIGI_MECA_HYST' computes the imaginary part of the elementary stiffness matrix and assembles it with the real part passed as an argument of the option.

```text
◊    MASS_MECA=
```

Elementary mass matrices ('MASS_MECA' or 'MASS_MECA_DIAG') necessary for the computation of the damping matrices ('AMOR_MECA').

**Note**:

*For the option* *'RIGI_MECA_HYST', the result of the analysis will contain, in addition to the hysteretic stiffness of the elements of the model, the matrix associated with the Lagrange multipliers induced by the dualisation of the loads supplied.*

**Note**:

*For a model containing only massless finite elements (for example* '3D_ABSO' or 'D_PLAN_ABSO') *, the user can build a damping matrix* *without having to build a mass matrix* *by going through the operator* *ASSEMBLAGE.*

### 3.9 Operands AMOR_FLUI and VNOR

> ◊    AMOR_FLUI =

This option makes it possible for us to deactivate the contribution of the absorbing fluid boundaries ('3D_FLUI_ABSO', '2D_FLUI_ABSO' and 'AXIS_FLUI_ABSO'). In particular, if one uses the fluid formulation $u-p-\phi$ in a harmonic analysis, one has the possibility of taking into account the contribution of the absorbing fluid boundaries via the computation of a third-order matrix (with the option IMPE_MECA). This third-order matrix is usable only in a harmonic analysis (operand MATR_IMPE_PHI in DYNA_VIBRA) and makes it possible for us to symmetrise the matrix (unlike the computation of this contribution via AMOR_MECA). The option AMOR_FLUI = ‘NON’ saves us from computing this contribution twice. By default, AMOR_FLUI = ‘OUI’. This operand is available exclusively for the option AMOR_MECA.

◊    VNOR=

This option makes it possible for us to take into account the case of an emitting boundary. The most common case is the radiative one (or partially radiative if one defines a reflection coefficient $\alpha \ne 0$ ). In the case of a radiative boundary VNOR = 1. (option activated by default). In the case of an emitting boundary VNOR = -1. This coefficient is multiplied by the value of the impedance of the absorbing fluid boundaries ('3D_FLUI_ABSO', '2D_FLUI_ABSO' and 'AXIS_FLUI_ABSO'). This operand is available exclusively for the options AMOR_MECA, IMPE_MECA and AMOR_ACOU.

### 3.10 Operand TYPE_AMOR

> ◊    TYPE_AMOR=

This option makes it possible for us to compute all the sources of damping present in the model or only the source linked to the absorbing-boundary elements (fluid or not). The default option (TYPE_AMOR= ‘TOUT’) takes into account the possible Rayleigh damping, the damping coming from the discrete elements and that coming from the absorbing-boundary elements. In this case one is obliged to supply either the mass and stiffness matrices for the Rayleigh damping (and the material field), or the characteristics of the discrete elements. If one is in the presence of only the damping coming from the absorbing-boundary elements, one must specify TYPE_AMOR= ‘ABSO’ and supply as input only the material field.

## 4 Examples of analyses with CALC_MATR_ELEM

### 4.1 Geometric stiffness matrix for Euler buckling

```text
rigigeom = CALC_MATR_ELEM (    OPTION='RIGI_GEOM',    MODELE= mo ,
CARA_ELEM= carac    ,    SIEF_ELGA= chsig )
```

### 4.2 “Mass” matrix in acoustics

```text
massacou = CALC_MATR_ELEM (    OPTION='MASS_ACOU',    MODELE= mo ,
CHAM_MATER= chmat    )
```

### 4.3 Stiffness matrix in mechanics

```text
rigibloc = CALC_MATR_ELEM (    OPTION='RIGI_MECA',    CHARGE= ch_bloc )
```
