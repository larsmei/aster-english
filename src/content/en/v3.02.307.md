# v3.02.307 SSLP307 - Thin plate with two opposite edges in single support

**Summary:**

The purpose of the test is to validate the element automatically created from Fenicsx based on Reissner-Mindlin theory and MITC procedure.

The reference solution is an analytical.

The new finite element PLAQ_MITC (discretized with QUAD9 and TRI6) is compared with the element DST.

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v3.02.307/probleme_reference.svg)

Fig: Schematic of the Reference problem

The fine plate is defined by $\Omega=[0,L]\times[0,L]\times[-h/2,h/2]$ where

Length: $L = 1 \mathrm{m}$

Thickness: $h = 0.001 \mathrm{m}$

### 1.2 Material properties

Young's modulus: $E = 1 \mathrm{MPa}$

Poisson's ratio: $\nu = 0.3$

### 1.3 Boundary conditions and loads

- Simple support on two opposite edges ($w=0$ to $x=0$ and $x=L$)
- Free edges on the other two edges
- Constant overfacial load:

$$
f(x,y) = \frac{E h^{3}}{12 (1 - \nu^{2})}
$$

### 1.4 Initial conditions

Not applicable for static analysis.

## 3 Modelling A

### 3.1 Modelling characteristics

It is a PLAQ_MITC model made via fenicsx.

$\Omega=[0,1]^2$ mesh is built directly by:

```python
mesh = CA.Mesh.buildSquare(refine=FINE_REFINEMENT)
```

Limit conditions:

on the edges: $\lbrace 0, 1\rbrace\times[0, 1]$:

```python
MECA_IMPO=_F(DZ=0, GROUP_MA=("LEFT", "RIGHT"))
```

**Note:**

PLAQ_MITC now considers COQUE movement only and therefore does not require DX, DY, DRZ movements.

Loading:

```python
PRES_REP=_F(GROUP_MA="SURFACE", PRES=PRES)
```

where PRES is an CONSTANTE that depends only on the thickness Reference problem.

### 3.2 Mesh characteristics

The following data correspond to the level of refinement 6:

Number of nodes: 16641.

Number of mesh cells and types: 4352, 256 SEG3, 4096 QUAD9.

### 3.3 Test values

The relative error between theoretical displacement and the displacement obtained from the model is tested using the discrete standard $L^2$.
