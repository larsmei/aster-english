# v6.03.015 SSNP15 - Traction-slicing plate - Von Plating (isotropic hardening)

**Summary:**

This $\mathrm{2D}$ quasi-static flat stress test, based on the VPCS guide [1], is part of the validation of elasto-plastic behavior relationships. A element volume, made of a plastic material with linear isotropic nutring, is subjected to a tensile force and shearing effort.

The main interest of this test is the non-radial nature of the load.

### 2.1 Calculation method used for reference solution

In the $(\sigma ,\tau \sqrt{3})$ plane, the standard of von Mises translates into the classical distance in the octahedral plane between the projection of the stress state and the hydrostatic line, so that the loading and discharge phases can be predicted immediately during the loading journey, since they are respectively the phases where the standard grows or decreases:

| --- | --- | --- |
| $A$ | ( 151.2. ; | 93.10 ) |
| ${B}^{0}$ | ( 158.23 ; | 89.12 ) |
| $B$ | ( 257.2 ; | 33.10 ) |

| $O-{A}^{0}$ | Elastic load |
| --- | --- |
| ${A}^{0}-A$ | Plastic load |
| $A-{B}^{0}$ | Discharge |
| ${B}^{0}-B$ | Plastic load |

| $O-{A}^{0}$ | Elastic load |
| --- | --- |
| ${A}^{0}-A$ | Plastic load |
| $A-{B}^{0}$ | Discharge |

The load is carried out according to a curve set by the moment:

- Phase 1: point $O$ plasticization to point $A$ (scores 0.0 to 1.0).
- Phase 2: Discharge of point $A$ to point $B$ (Scores 1.0 to 2.0).
- Phase 3: Total discharge of point $B$ to point $C$ (scores 2.0 to 3.0).

#### 2.1.1 Resolution approach

Mechanically, it is a stress-controlled $\mathrm{0D}$ test, the material being elastoplastic with linear isotropic stress and hardening criterion. For a stress-controlled load, the cumulative plastic deformation is easily determined:

$F(\sigma ,p)={\sigma}_{\mathrm{éq}}-{\sigma}_{y}-R'p\le 0\Rightarrow p=\frac{{\sigma}_{\mathrm{éq}}-{\sigma}_{y}}{R'}\text{en charge}$ **éq** 2.1.1-1

The integration of plastic deformation is of course more delicate. The flow equation sss written:

$\dot{{\varepsilon}^{p}}=\frac{3}{2}\dot{p}\frac{\tilde{\sigma}}{{\sigma}_{\mathrm{éq}}}\Rightarrow \dot{{\varepsilon}^{p}}=\frac{3}{2R'}.\frac{\dot{{\sigma}_{\mathrm{éq}}}}{{\sigma}_{\mathrm{éq}}}.\tilde{\sigma}\text{en charge}$ **éq** 2.1.1-2

Finally, deformation will be inferred via the state relationship:

$\varepsilon ={\varepsilon}^{p}+{E}^{-1}:\sigma \Rightarrow {\varepsilon}_{xx}={\varepsilon}_{xx}^{p}+\frac{\sigma}{E}\text{et}{\varepsilon}_{xy}={\varepsilon}_{xy}^{p}+\frac{\tau}{2\mu }$ **éq** 2.1.1-3

#### 2.1.2 Radial loading phase treatment

Note that in the radial loading phase, the flow law [eq 2.1.2-1] directly integrates:

${\varepsilon}^{p}=\frac{3}{2}p\frac{\tilde{\sigma}}{{\sigma}_{\mathrm{éq}}}$                 éq 2.1.2-1

The cumulative plastic deformation is then given by [eq 2.1.1-1], the plastic deformation by [eq 2.1.2-1] and the total deformation by [eq 2.1.1-3].

| $E$ | $=195000\mathrm{MPa}$ | $2\mu$ | $=150000\mathrm{MPa}$ | $R'$ | $=1949.29\mathrm{MPa}$ |
| --- | --- | --- | --- | --- | --- |
| We get: |  |  |  |  |  |
| $p(A)$ | $={\mathrm{2.0547.10}}^{-2}$ | ${\varepsilon}_{xx}^{p}(A)$ | $={\mathrm{1.4054.10}}^{-2}$ | ${\varepsilon}_{xx}(A)$ | $={\mathrm{1.4830.10}}^{-2}$ |
|  |  | ${\varepsilon}_{xy}^{p}(A)$ | $={\mathrm{1.2981.10}}^{-2}$ | ${\varepsilon}_{xy}(A)$ | $={\mathrm{1.3601.10}}^{-2}$ |

#### 2.1.3 Treatment of non-radial loading phase

In the non radial ${B}^{0}-B$ loading phase, the stress path can be set by:

> $\sigma (q)={\sigma}^{{B}^{0}}+q\underset{\text{direction fixe}}{\underset{\underbrace{}}{({\sigma}^{B}-{\sigma}^{{B}^{0}})}}\text{avec}0\le q\le 1$ **éq 2.1.3-1**

As the loading path remains confined in the $(\sigma ,\tau )$ shear-pull plane, it is better to represent the stress state by a complex number:

$\Sigma =\sigma +i\sqrt{(3)}\tau \Rightarrow {\sigma}_{\text{éq}}=\mid \Sigma \mid \text{et}\Sigma (q)={\Sigma}^{{B}^{0}}+q\underset{\text{direction fixe}}{\underset{\underbrace{}}{({\Sigma}^{{B}^{0}}-{\Sigma}^{0})}}$ **éq 2.1.3-2**

The integration of the flow law [eq 2.1.1-2], followed by a part-integration, allows the expression of plastic deformation:

$\frac{\mathrm{2R}'}{3}{[{\varepsilon}^{p}]}_{0}^{1}={\int}_{0}^{1}\frac{{\dot{\sigma}}_{\text{éq}}}{{\sigma}_{\text{éq}}}\tilde{\sigma}\mathrm{dq}={\left[\ln({\sigma}_{\text{éq}})\tilde{\sigma}\right]}_{0}^{1}-\frac{1}{2}\underset{{\tilde{\sigma}}^{B}-{\tilde{\sigma}}^{{B}^{0}}}{\underset{\underbrace{}}{\dot{\tilde{\sigma}}}}{\int}_{0}^{1}\ln({\sigma}_{\text{éq}}^{2})\mathrm{dq}$

The adoption of the complex plan allows easy calculation of the last integral:

${\int}_{0}^{1}\ln({\sigma}_{\text{éq}}^{2})\mathrm{dq}={\int}_{0}^{1}\ln(\Sigma \stackrel{ˉ}{\Sigma})\mathrm{dq}={\int}_{0}^{1}\ln(\Sigma )\mathrm{dq}+{\int}_{0}^{1}\ln(\stackrel{ˉ}{\Sigma})\mathrm{dq}=2\text{Re}\left[{\int}_{0}^{1}\ln(\Sigma )\mathrm{dq}\right]=2\text{Re}{\left[\frac{\Sigma \ln(\Sigma )-\Sigma }{{\Sigma}^{B}-{\Sigma}^{{B}^{0}}}\right]}_{0}^{1}$

Finally, the plastic deformation increment on the ${B}^{0}-B$ route is:

> ${\left[{\varepsilon}^{p}\right]}_{{B}^{0}}^{B}=\frac{3}{2R'}{\left[\ln({\sigma}_{\text{éq}})\tilde{\sigma}\right]}_{{B}^{0}}^{B}-\frac{3}{2R'}\text{Re}{\left[\frac{\Sigma \ln(\Sigma )-\Sigma }{{\Sigma}^{B}-{\Sigma}^{{B}^{0}}}\right]}_{{B}^{0}}^{B}({\tilde{\sigma}}^{B}-{\tilde{\sigma}}^{{B}^{0}})$ **éq 2.1.3-4**
