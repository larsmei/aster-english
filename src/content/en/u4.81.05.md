# u4.81.05 Operator POST_CHAMP

## 1 Purpose

Specific post-processing for structural elements (shells, beams, …):

- extraction of a field for a sub-point
- computation of the minimum/maximum over all the sub-points of a point
- account taken of the offset of the plates for the computation of the forces

## 3 General points

When an sd_resultat (resu) contains fields «with sub-points» (the case of multi-layer shells, of pipe elements or of multi-fibre beam elements), the command POST_CHAMP makes it possible to create another sd_resultat (resu2) which will contain the restriction of the fields with sub-points to a single sub-point.

## 4 Operands

### 4.1 Operand RESULTAT

```text
♦    RESULTAT =    resu
```

Name of a result concept of type resultat.

### 4.2 Selection of the order numbers

The use of the keywords TOUT_ORDRE, NUME_ORDRE, INST, ... is described in the document [U4.71.00](doc:u4.71.00).

### 4.3 Selection of the elements concerned

By means of the keywords TOUT='OUI', and GROUP_MA, the user can select the elements on which the computations will take place.

*Note*  : if the user selects elements which are not structural elements, they are ignored.

### 4.4 Keyword EXTR_COQUE

This keyword is used to extract a field on a single sub-point for shell elements.

#### 4.4.1 Operand NOM_CHAM

The keyword NOM_CHAM makes it possible to designate the fields to be extracted in the result resu.

The following are permitted:

| SIGM_ELGA | SIGM_ELNO | SIEQ_ELGA | SIEQ_ELNO |
| --- | --- | --- | --- |
| EPSI_ELGA | EPSI_ELNO | EPEQ_ELGA | EPEQ_ELNO |
| SIEF_ELGA | SIEF_ELNO | VARI_ELGA | VARI_ELNO |

#### 4.4.2 Operand NUME_COUCHE

> ♦ NUME_COUCHE = nucou,            [I]

Number of the layer containing the sub-point to be extracted.

By convention, layer $1$ is the lower layer (in the direction of the normal) of the shell elements.

#### 4.4.3 Operand NIVE_COUCHE

> ♦    NIVE_COUCHE=

For the layer nucou defined by NUME_COUCHE, makes it possible to specify the ordinate of the sub-point:

| 'INF' | lower ordinate of the layer | (inner skin), |
| --- | --- | --- |
| 'SUP' | upper ordinate of the layer | (outer skin), |
| 'MOY' | mean ordinate of the layer | (middle surface). |

### 4.5 Keyword EXTR_TUYAU

This keyword is used to extract a field on a single sub-point for pipe elements.

#### 4.5.1 Operand NOM_CHAM

The keyword NOM_CHAM makes it possible to designate the fields to be extracted in the result resu.

The following are permitted: (see  4.4.1 )

#### 4.5.2 Operand NUME_COUCHE

> ♦ NUME_COUCHE = nucou,            [I]

Number of the layer containing the sub-point to be extracted.

By convention, layer $1$ is the inner layer of a TUYAU element.

#### 4.5.3 Operand NIVE_COUCHE

> ♦    NIVE_COUCHE=

For the layer nucou defined by NUME_COUCHE, makes it possible to specify the ordinate of the sub-point:

| 'INF' | lower ordinate of the layer | (inner skin), |
| --- | --- | --- |
| 'SUP' | upper ordinate of the layer | (outer skin), |
| 'MOY' | mean ordinate of the layer | (middle surface). |

#### 4.5.4 Operand ANGLE

```text
♦    ANGLE =    delta,                        [I]
```

delta: angle in degrees (integer value), counted from the position of the generatrix of the pipe element.

*Note*  : The sub-points of the pipes are spaced regularly through the thickness of the pipe and also in azimuth. When the user indicates an angle which does not correspond geometrically to a sub-point (in azimuth), a linear interpolation is performed between the 2 sub-points which «bracket» the specified angle.

### 4.6 Keyword EXTR_PMF

This keyword is used to extract a field on a single sub-point for multi-fibre beam elements.

#### 4.6.1 Operand NOM_CHAM

The keyword NOM_CHAM makes it possible to designate the fields to be extracted in the result resu.

The following are permitted: (see  4.4.1 )

#### 4.6.2 Operand NUME_FIBRE

> ♦ NUME_FIBRE = nufib,            [I]

Number of the fibre corresponding to the sub-point to be extracted.

### 4.7 Keyword MIN_MAX_SP

This keyword is used to compute the «maximum» (or minimum) value of a component of a field. The «max» is taken over all the sub-points.

If the input field is for example an ELGA stress field on the sub-points of a multi-layer shell, the output field will be an ELGA field (without sub-points) containing, for each Gauss point, the «max» value of the stress.

In addition to the «max» value, one also extracts the information making it possible to locate the sub-point which has reached the «max». In the end, on each «point», one computes 6 components:

| VAL | The value of the «max» |
| --- | --- |
| NUCOU | Number of the layer if the element is a multi-layer shell or a pipe |
| NUSECT | Number of the angular sector if the element is a pipe |
| NUFIBR | Number of the fibre if the element is a multi-fibre beam |
| POSIC | «Position» in the layer: -1. : position «INF» 0. : position «MOY» +1. : position «SUP» |
| POSIS | «Position» in the sector: -1. : «start» of the sector (in the direction of increasing azimuths) 0. : «middle» of the sector (in the direction of increasing azimuths) +1. : «end» of the sector (in the direction of increasing azimuths) |

#### 4.7.1 Operand NOM_CHAM

The keyword NOM_CHAM makes it possible to designate the field to be extracted in the result resu.

The following are permitted: (see  4.4.1 )

#### 4.7.2 Operands NOM_CMP/NOM_VARI

> ◊    NOM_CMP =        nocmp,                        [Kn]
> Name of the component for which one wishes to compute the «max».
> ◊    NOM_VARI=        novari,                    [Kn]

For the fields of internal variables (VARI_* ), one may give the name of the internal variable for which one wishes to compute the «max» (see [U4.51.11](doc:u4.51.11) for the naming rules of the internal variables).

#### 4.7.3 Operand TYPE_MAXI

This keyword is used to choose the «type» of maximum sought:

| 'MAXI' | One extracts the maximum value of the component taking its sign into account |
| --- | --- |
| 'MINI' | One extracts the minimum value of the component taking its sign into account |
| 'MAXI_ABS' | One extracts the maximum value of the absolute value of the component |
| 'MINI_ABS' | One extracts the minimum value of the absolute value of the component |

#### 4.7.4 Operand NUME_CHAM_RESU

> ♦ NUME_CHAM_RESU = nuch,            [I]

The number nuch is used to name the field produced.

If, for example, NOM_CHAM = 'SIEF_ELGA' and NUME_CHAM_RESU = 7, in the result data structure produced, the field will be accessible by NOM_CHAM = 'UT07_ELGA'. It is the 7th ELGA «user» field in the data structure.

Note: nuch is limited to 20.

### 4.8 Keyword COQU_EXCENT

This keyword is used to modify the «plane» of computation of the generalised forces in the offset plates.

The field found under the name NOM_CHAM in the input sd_resultat (resu) contains forces computed in the «plane» of the mesh.

Account is taken of the offset of the elements in order to modify the computation of the moments (they are computed in the mean «plane» of the offset plate).

#### 4.8.1 Operand NOM_CHAM

The keyword NOM_CHAM makes it possible to designate the field to be extracted in the result resu.

The following are permitted: 'EFGE_ELNO' and 'EFGE_ELGA'.

#### 4.8.2 Operand MODI_PLAN = 'OUI'

This keyword is used to confirm that one wishes to modify the «plane» of computation for the forces in the offset plates.

## 5 Examples

### 5.1 Extraction of the stresses on 1 sub-point for pipe elements

U2    =    POST_CHAMP(RESULTAT = U1,

TOUT_ORDRE = 'OUI',

TOUT = 'OUI',

EXTR_TUYAU =_F(NOM_CHAM = 'SIGM_ELGA',

> NUME_COUCHE = 3,

NIVE_COUCHE = 'SUP',

ANGLE = 90 ),);

### 5.2 Extraction of the maximum (and minimum) Von Mises stress for pipe elements

U2    =    POST_CHAMP(RESULTAT = U1, TOUT_ORDRE = 'OUI', GROUP_MA = 'TUYAU',

MIN_MAX_SP =(

_F(NOM_CHAM = 'SIEQ_ELGA', NOM_CMP='VMIS',

> TYPE_MAXI = 'MAXI', NUME_CHAM_RESU=1),

_F(NOM_CHAM = 'SIEQ_ELGA', NOM_CMP='VMIS',

> TYPE_MAXI = 'MINI', NUME_CHAM_RESU=2),

));
