# u4.32.05 Operator INFO_FONCTION

## 1 Purpose

Carry out mathematical operations on data structures of type fonction.

The following operations are currently available:

- the search for the maxima of a function,
- the calculation of the ${L}_{2}$ norm of a function,
- the standard deviation of a function,
- the RMS value of a function,
- the value of the earthquake harmfulness indicator.

Produces a data structure table.

## 3 Operands

### 3.1 Keyword MAX

```text
/    MAX =
```

Search for the abscissae where the maximum and the minimum are reached.

This operation is available on functions of nature fonction or nappe.

```text
♦    FONCTION = f
```

Name of the function or of the functions whose maxima are sought.

If f is a fonction, the concept produced is a table whose access parameters are:

> FONCTION, TYPE, the NOM_PARA of the function, the NOM_RESU of the function.

where one finds respectively the name of the function, MAXI or MINI, the abscissa of the maximum/minimum, the value of the maximum/minimum.

When several factors are supplied, the table contains the max or the maxima of the maxima, and the min or the minima of the minima.

If f is a nappe, the concept produced is a table whose access parameters are:

> FONCTION, TYPE, the NOM_PARA of the nappe, the name of the parameter of the functions
(NOM_PARA_FONC), the NOM_RESU of the functions.

```text
◊    INTERVALLE = inter
```

List of reals defining the bounds of the intervals over which the minima and the maxima of the functions will be sought.

`inter` is composed of pairs of reals of which the first corresponds to the lower bound of the first interval, the second corresponds to the upper bound of the first interval, and so on for the other intervals.

`inter` is therefore composed of an even number of elements.

This keyword is not taken into account for nappes.

### 3.2 Keyword NORME

This keyword makes it possible to monitor the convergence according to the ${L}_{2}$ norm of a sequence of functions ${f}_{N}$ given in the form of a nappe. The result table has one line per function; the input parameters are NORME and FONCTION.

```text
♦    FONCTION = f
```

Name of the nappe whose norm is to be evaluated.

### 3.3 Keyword ECART_TYPE

```text
/    ECART_TYPE =
```

One calculates the standard deviation of the function $f(t)$ which is defined by:

$\sigma =\sqrt{\frac{1}{({t}_{\mathit{fin}}-{t}_{\mathit{deb}})}{\int}_{{t}_{\mathit{deb}}}^{{t}_{\mathit{fin}}}{(f(t)-\bar{f})}^{2}\mathit{dt}}$ where $\bar{f}$ is the mean over $[{t}_{\mathrm{deb}},{t}_{\mathrm{fin}}]$

The keywords are identical to those supplied under the factor keyword RMS.

The concept produced is a table whose access parameters are:

```text
FONCTION, METHODE, MOYENNE, INST_INIT, INST_FIN, ECART_TYPE.
```

### 3.4 Keyword RMS

```text
/    RMS =
```

One calculates the RMS value of the function $f(t)$ which is defined by:

$\mathrm{RMS}=\sqrt{\frac{1}{({t}_{\mathrm{fin}}-{t}_{\mathrm{deb}})}{\int}_{{t}_{\mathrm{deb}}}^{{t}_{\mathrm{fin}}}{f}^{2}(t)\mathrm{dt}}$

```text
♦    FONCTION = f
```

Name of the function whose RMS value is calculated.

Does not apply to concepts of type nappe.

```text
◊    METHODE =
```

Name of the METHODE used to calculate the integral.

Two methods are available: the 'TRAPEZE' method (by default) and the 'SIMPSON' method.

```text
◊    INST_INIT = tdeb,
◊    INST_FIN = tfin,
```

Lower and upper bounds of the integration interval.

If these values are not supplied, the lower and upper discretisation points (the order relation being defined with respect to the abscissa parameter) are taken as the bounds of the integration interval.

```text
◊    PRECISION  =     /    0.001,
                      /    prec,

◊    CRITERE    =     /    'ABSOLU',
                      /    'RELATIF',            [DEFAUT]
```

One looks for a discretisation point of the function in an interval defined by the absolute or relative position around a value of the abscissa parameter for which the function is to be estimated:

| [inst (1-prec) , inst (1+prec)] | if CRITERE= 'RELATIF' |
| --- | --- |
| [inst - prec , inst + prec] | if CRITERE= 'ABSOLU' |

The concept produced is a table whose access parameters are:

```text
FONCTION,    METHODE,    INST_INIT,    INST_FIN,    RMS.
```

### 3.5 Keyword NOCI_SEISME

```text
/    NOCI_SEISME =

    ♦    /    FONCTION = f,
         /    SPEC_OSCI= sro,
```

Name of the function (acceleration signal $a(t)$ ) or of the nappe considered, which must be defined in DEFI_FONCTION [U4.31.02](doc:u4.31.02) with NOM_RESU=’ACCE’.

If a nappe is considered, only the calculation of the spectral intensity is available.

```text
◊    /    OPTION=
```

Makes it possible to choose one or more of the following six harmfulness indices:

```text
| 'TOUT'
```

gives the set of the six harmfulness indices,

```text
| 'MAXI'
```

gives the maximum of the acceleration $a(t)$ , of the velocity $v(t)$ and of the displacement (obtained by integration)

$\mathit{PGA}=\underset{t\in [{t}_{i},{t}_{f}]}{max}\left\lbrace ∣a(t)∣\right\rbrace$ , $\mathrm{PGV}=\underset{t\in [{t}_{i},{t}_{f}]}{\max}\left\lbrace ∣v(t)∣\right\rbrace$ , $\mathrm{PGD}=\underset{t\in [{t}_{i},{t}_{f}]}{\max}\left\lbrace ∣x(t)∣\right\rbrace$

```text
| 'INTE_ARIAS'
```

gives the Arias intensity ${I}_{A}=\frac{\pi}{2g}{\int}_{{t}_{i}}^{{t}_{f}}{a}^{2}(t)\mathit{dt}$

where $g$ is the acceleration of gravity. This value must be supplied via the keyword PESANTEUR.

```text
| 'VITE_ABSO_CUMU'
```

gives the cumulative absolute velocity $\mathit{CAV}={\int}_{{t}_{i}}^{{t}_{f}}∣a(t)∣\mathit{dt}$

```text
| 'DUREE_PHAS_FORT'
```

strong-phase duration (the Arias intensity being a monotonically increasing function):

Minimum duration ${t}_{\sup}-{t}_{\inf}$ such that, for the bounds ${b}_{\inf},{b}_{\sup}$ :

${b}_{\inf}\times {I}_{A}⩽\frac{\pi}{2g}{\int}_{{t}_{inf}}^{{t}_{\sup}}{a}^{2}(f)\mathit{dt}⩽{b}_{\sup}\times {I}_{A}$

where $g$ must be supplied by the keyword PESANTEUR.

The table produced contains ${t}_{inf}$ under DEBUT_PHAS_FORT.

```text
| 'ASA'(Average Spectral Acceleration)
```

This indicator is based on the spectral pseudo-acceleration of the structure and depends on its fundamental frequency.

Damage, characterised by a drop in this natural frequency, is taken into account by integrating the spectral pseudo-accelerations ${S}_{a}(f,\eta )$ over a frequency range:

> ${\mathit{ASA}}_{R}=\frac{1}{R{f}_{0}}{\int}_{(1-R){f}_{0}}^{{f}_{0}}{S}_{a}(f,\eta )\mathit{df}$

where R denotes the ratio defining the integration domain and $\eta$ is the reduced damping. The value of the ratio may be supplied by the user via the keyword RATIO. By default, one determines ${\mathit{ASA}}_{40}$ with R=0.4 and reduced damping $\eta =0.05$ . The keyword FREQ_PAS makes it possible to define the integration step. The spectral pseudo-acceleration will be normalised to the NORME supplied (by default 1.0).

Housner spectral intensity, between the frequencies ${f}_{\mathrm{deb}},{f}_{\mathrm{fin}}$ , ${S}_{V}(f,\eta )$ denoting the oscillator response spectrum in pseudo-velocities for the reduced damping $\eta$ :

${I}_{H}={\int}_{{f}_{\mathit{deb}}}^{{f}_{\mathit{fin}}}\frac{{S}_{V}(f,\eta )}{{f}^{2}}\mathit{df}$

$\text{ACCE\_SUR\_VITE}=\frac{\underset{t\in [{t}_{i},{t}_{f}]}{max}\left\lbrace ∣a(t)∣\right\rbrace }{\underset{t\in [{t}_{i},{t}_{f}]}{max}\left\lbrace ∣\nu (t)∣\right\rbrace }$

Depending on the option, certain parameters must be supplied; if no option is indicated, by default all the indices are calculated and therefore everything must be supplied. The integration method is the 'TRAPEZE' method.

```text
INST_INIT = tdeb,
INST_FIN = tfin,
```

Lower and upper bounds of the time interval considered.

If these values are not supplied, the lower and upper discretisation points (the order relation being defined with respect to the abscissa parameter) are taken as the bounds of the interval.

```text
PRECISION   =     /    0.001,
                  /    prec,

CRITERE     =     /    'ABSOLU',
                  /    'RELATIF',            [DEFAUT]
```

One looks for a discretisation point of the function in an interval defined by the absolute or relative position around a value of the abscissa parameter for which the function is to be estimated:

| [inst*(1-prec) , inst*(1+prec)] | if CRITERE= 'RELATIF' |
| --- | --- |
| [inst - prec , inst + prec] | if CRITERE= 'ABSOLU' |
| [freq*(1-prec) , freq*(1+prec)] | if CRITERE= 'RELATIF' |
| [freq - prec , freq + prec] | if CRITERE= 'ABSOLU' |

```text
COEF = r1
```

Integration constant, 0 by default. In the option 'MAXI', the velocity and the displacement are calculated by two successive integrations of the damping; COEF must therefore be supplied if one does not wish to take it by default.

```text
FREQ_INIT = fdeb,

FREQ_FIN = ffin,
```

Frequencies representing the two integration bounds for the calculation of the Housner spectral intensity. These must lie between the extrema of the frequency base defining the SRO nappe, otherwise an interpolation problem arises. By default, these two frequencies are equal to $0,4\mathrm{Hz}$ and $\mathrm{10Hz}$ .

AMOR_REDUIT= am

Reduced damping, for the calculation of the oscillator response spectrum within that of the Housner spectral intensity.

```text
FREQ = lfre
```

fre = $({\Phi}_{1,}\mathrm{...},{\Phi}_{i},\mathrm{...})$ . List of frequencies.

```text
LIST_FREQ = lfreq
```

List of the frequencies supplied under a listr8 concept.

```text
NORME = r2
```

The oscillator spectrum will be normalised to the value r2 (value of the pseudo-acceleration).

```text
BORNE_INF = binf,

BORNE_SUP = bsup,
```

Bounds limiting the share of Arias intensity defining the initial and final time instants of the strong phase (between $({b}_{\inf})\text{\%}$ and $({b}_{\sup})\text{\%}$ of ${({I}_{A})}_{\max}$ ) of the earthquake (one often takes 5% and 95%).

> PESANTEUR

Acceleration of gravity. Its value depending on the units of the model, this keyword is mandatory for the indices INTE_ARIAS, DUREE_PHAS_FORT.

### 3.6 Operand TITRE

```text
◊    TITRE = t
```

Title attached to the concept produced by this operator [U4.03.01](doc:u4.03.01).

### 3.7 Operand INFO

```text
◊    INFO
```

If INFO=2, the function is printed (IMPR_FONCTION format TABLEAU) in the MESSAGE file.

## 4 Examples

### 4.1 Without an interval

```text
A5=DEFI_FONCTION(
    NOM_RESU='SIGM',
    NOM_PARA='EPSI',
    VALE=(  0.002,  400.0,
            0.003,  500.0,
            0.0045, 550.0,
            0.0065, 580.0,
            0.008,  590.0,
            0.01,   600.0,
            0.02,   600.0,
            ),

    PROL_DROITE='CONSTANT',
    PROL_GAUCHE='LINEAIRE',
)

tab = INFO_FONCTION(MAX=_F(FONCTION=A5),)

IMPR_TABLE(TABLE=tab)
```

gives, in the 'RESULTAT' file.

```text
#

#ASTER 8.02.00 CONCEPT tab CALCULE LE 24/01/2006 A 16:14:04 DE TYPE

#TABLE_SDASTER

FONCTION TYPE EPSI SIGM

A5 MINI 2.00000E-03 4.00000E+02

A5 MAXI 1.00000E-02 6.00000E+02

A5 MAXI 2.00000E-02 6.00000E+02
```

tab2 = INFO_FONCTION(MAX      = _F(FONCTION=A5),
