# r5.05.09 Computation of reconstructed signals and of the transfer-function matrix

**Summary:**

This document presents the theoretical bases which made it possible to set up the macro-command CALC_TRANSFERT [U4.53.51](doc:u4.53.51).

The latter makes it possible to compute the transfer-function matrix between two points, but also to reconstruct the signals at a given point, knowing the signals at another point.

> Contents

## 1 Introduction

During linear dynamic studies, the user may be led to reconstruct an excitation signal knowing the signals measured at another point of the structure. The purpose of the present document is to present the theoretical elements which led to the creation of the macro-command CALC_TRANSFERT [U4.53.51](doc:u4.53.51). In particular the equations which make it possible to determine the transfer-function matrix and those which make it possible to determine the reconstructed signals.

## 2 Theory

In this chapter, one places oneself in a seismic example in order to present the problem, where one reasons in an absolute frame.

### 2.1 General principle

During an earthquake, the recorded signals are generally measured on a structure. Thus, when one wishes to study the dynamic behaviour of this structure, the input signal is an unknown of the numerical model which must be determined (see figure 1).

![Figure](/figures/r5.05.09/1000000000000249000001ECAA57C8CE42C4E48A.png)

Figure 1 – Schematic representation of the problem

In order to reconstruct the input signal knowing the output signal (a signal which is generally measured), one places oneself in the frequency domain and one seeks the transfer function $\underline{\underline{H}}(\omega )$ between the two points of our system (see figure 2). The input point corresponds to point E and the output point to point S in figure 1.

![Figure](/figures/r5.05.09/10000201000001DE0000007D177D3B57397AF4C6.png)

Figure 2 - Diagram of the transfer function

From several unidirectional dynamic analyses ${\gamma}_{i},\mathit{avec}i=x,y,z$, it is possible to obtain the transfer function by looking at the output $\underline{S}(\omega )$ and the input $\underline{E}(\omega )$.

**Notes:**

*Determination The input and output signals must be of the same nature (ACCE /* *ACCE or VITE / VITE or DEPL / DEPL.*

*It is* *recommended to use white-noise type signals in order to excite the structure uniformly over the whole frequency range.*

Once the transfer-function matrix is known, and knowing the desired output signal, it is possible to reconstruct the input signal to be injected into the dynamic model in order to recover the output signal by solving the following matrix system:

$\underline{{E}^{\mathit{absolu}}}(\omega )=\underline{\underline{{H}^{-1}}}(\omega )\underline{{S}^{\mathit{absolu}}}(\omega )$

Where:

| $\underline{{S}^{\mathit{absolu}}}(\omega )$ | Vector containing the absolute accelerations measured at the output point S of the structure during the earthquake |
| --- | --- |
| $\underline{{E}^{\mathit{absolu}}}(\omega )$ | Vector containing the absolute accelerations to be applied at the input point E in order to recover the absolute accelerations measured at the output point S |
| $\underline{\underline{{H}^{-1}}}(\omega )$ | Inverse transfer-function matrix |

### 2.2 Determination of the transfer-function matrix $\underline{\underline{H}}(\omega )$

In this paragraph, one proposes to present the equations which make it possible to determine the transfer-function matrix $\underline{\underline{H}}(\omega )$ in the three-dimensional case. In order to facilitate the data setup of the problem, one treats the problem in terms of acceleration (the latter can also be treated in terms of displacement or of velocity).

Let ${E}_{i}^{\mathit{absolu}}$ and ${S}_{i}^{\mathit{absolu}}$ be the absolute accelerations computed respectively at the input and output points. One seeks to solve the following system:

$\underline{{S}^{\mathit{absolu}}}(\omega )=\underline{\underline{H}}(\omega )\underline{{E}^{\mathit{absolu}}}(\omega )$

Where $\lbrace \begin{array}{c}{S}_{i}^{\mathit{absolu}}={S}_{i}^{\mathit{relatif}}+{\gamma}_{i},i=x,y,z\\ {E}_{i}^{\mathit{absolu}}={E}_{i}^{\mathit{relatif}}+{\gamma}_{i},i=x,y,z\end{array}$ and $\underline{\underline{H}}(\omega )=\left(\begin{array}{ccc}{H}_{xx}& {H}_{xy}& {H}_{xz}\\ {H}_{yx}& {H}_{yy}& {H}_{yz}\\ {H}_{\mathit{zx}}& {H}_{\mathit{zy}}& {H}_{zz}\end{array}\right)$

In order to determine the 9 unknowns of the problem, a system of 9 equations in 9 unknowns must be solved. This system is determined by carrying out three analyses with a unidirectional loading along the directions x, y or z so as not to neglect the possible coupling between directions.

*Harmonic analysis along X*

Let $X\text{\_}{\mathit{sortie}}_{i}^{a},i=x,y,z$ be the absolute acceleration computed at the output point and $X\text{\_}{\mathit{entree}}_{i}^{a},i=x,y,z$ the absolute acceleration computed at the input point for a unidirectional excitation ${\gamma}_{x}$.

The system (E1) to be solved is the following:

$(\mathit{E1})\text{}\lbrace \begin{array}{c}X\text{\_}{\mathit{sortie}}_{x}^{a}={H}_{xx}X\text{\_}{\mathit{entree}}_{x}^{a}+{H}_{xy}X\text{\_}{\mathit{entree}}_{y}^{a}+{H}_{xz}X\text{\_}{\mathit{entree}}_{z}^{a}\\ X\text{\_}{\mathit{sortie}}_{y}^{a}={H}_{yx}X\text{\_}{\mathit{entree}}_{x}^{a}+{H}_{yy}X\text{\_}{\mathit{entree}}_{y}^{a}+{H}_{yz}X\text{\_}{\mathit{entree}}_{z}^{a}\\ X\text{\_}{\mathit{sortie}}_{z}^{a}={H}_{\mathit{zx}}X\text{\_}{\mathit{entree}}_{x}^{a}+{H}_{\mathit{zy}}X\text{\_}{\mathit{entree}}_{y}^{a}+{H}_{\mathit{zxz}}X\text{\_}{\mathit{entree}}_{z}^{a}\end{array}$

*Harmonic analysis along Y*

Let $Y\text{\_}{\mathit{sortie}}_{i}^{a},i=x,y,z$ be the absolute acceleration computed at the output point and $Y\text{\_}{\mathit{entree}}_{i}^{a},i=x,y,z$ the absolute acceleration computed at the input point for a unidirectional excitation ${\gamma}_{y}$.

The system (E2) to be solved is the following:

$(\mathit{E2})\text{}\lbrace \begin{array}{c}Y\text{\_}{\mathit{sortie}}_{x}^{a}={H}_{xx}Y\text{\_}{\mathit{entree}}_{x}^{a}+{H}_{xy}Y\text{\_}{\mathit{entree}}_{y}^{a}+{H}_{xz}Y\text{\_}{\mathit{entree}}_{z}^{a}\\ Y\text{\_}{\mathit{sortie}}_{y}^{a}={H}_{yx}Y\text{\_}{\mathit{entree}}_{x}^{a}+{H}_{yy}Y\text{\_}{\mathit{entree}}_{y}^{a}+{H}_{yz}Y\text{\_}{\mathit{entree}}_{z}^{a}\\ Y\text{\_}{\mathit{sortie}}_{z}^{a}={H}_{\mathit{zx}}Y\text{\_}{\mathit{entree}}_{x}^{a}+{H}_{\mathit{zy}}Y\text{\_}{\mathit{entree}}_{y}^{a}+{H}_{\mathit{zxz}}Y\text{\_}{\mathit{entree}}_{z}^{a}\end{array}$

*Harmonic analysis along Z*

Let $Z\text{\_}{\mathit{sortie}}_{i}^{a},i=x,y,z$ be the absolute acceleration computed at the output point and $Z\text{\_}{\mathit{entree}}_{i}^{a},i=x,y,z$ the absolute acceleration computed at the input point for a unidirectional excitation ${\gamma}_{z}$.

The system (E3) to be solved is the following:

$(\mathit{E3})\text{}\lbrace \begin{array}{c}Z\text{\_}{\mathit{sortie}}_{x}^{a}={H}_{xx}Z\text{\_}{\mathit{entree}}_{x}^{a}+{H}_{xy}Z\text{\_}{\mathit{entree}}_{y}^{a}+{H}_{xz}Z\text{\_}{\mathit{entree}}_{z}^{a}\\ Z\text{\_}{\mathit{sortie}}_{y}^{a}={H}_{yx}Z\text{\_}{\mathit{entree}}_{x}^{a}+{H}_{yy}Z\text{\_}{\mathit{entree}}_{y}^{a}+{H}_{yz}Z\text{\_}{\mathit{entree}}_{z}^{a}\\ Z\text{\_}{\mathit{sortie}}_{z}^{a}={H}_{\mathit{zx}}Z\text{\_}{\mathit{entree}}_{x}^{a}+{H}_{\mathit{zy}}Z\text{\_}{\mathit{entree}}_{y}^{a}+{H}_{\mathit{zxz}}Z\text{\_}{\mathit{entree}}_{z}^{a}\end{array}$

By grouping the systems (E1), (E2) and (E3) in the form of a global system (E), one obtains a system of 9 equations in 9 unknowns.

$(E)\text{}\left(\begin{array}{c}X\text{\_}{\mathit{sortie}}_{x}^{a}\\ X\text{\_}{\mathit{sortie}}_{y}^{a}\\ X\text{\_}{\mathit{sortie}}_{z}^{a}\\ Y\text{\_}{\mathit{sortie}}_{x}^{a}\\ Y\text{\_}{\mathit{sortie}}_{y}^{a}\\ Y\text{\_}{\mathit{sortie}}_{z}^{a}\\ Z\text{\_}{\mathit{sortie}}_{x}^{a}\\ Z\text{\_}{\mathit{sortie}}_{y}^{a}\\ Z\text{\_}{\mathit{sortie}}_{z}^{a}\end{array}\right)=\left(\begin{array}{ccccccccc}X\text{\_}{\mathit{entree}}_{x}^{a}& X\text{\_}{\mathit{entree}}_{y}^{a}& X\text{\_}{\mathit{entree}}_{z}^{a}& 0& 0& 0& 0& 0& 0\\ 0& 0& 0& X\text{\_}{\mathit{entree}}_{x}^{a}& X\text{\_}{\mathit{entree}}_{y}^{a}& X\text{\_}{\mathit{entree}}_{z}^{a}& 0& 0& 0\\ 0& 0& 0& 0& 0& 0& X\text{\_}{\mathit{entree}}_{x}^{a}& X\text{\_}{\mathit{entree}}_{y}^{a}& X\text{\_}{\mathit{entree}}_{z}^{a}\\ Y\text{\_}{\mathit{entree}}_{x}^{a}& Y\text{\_}{\mathit{entree}}_{y}^{a}& Y\text{\_}{\mathit{entree}}_{z}^{a}& 0& 0& 0& 0& 0& 0\\ 0& 0& 0& Y\text{\_}{\mathit{entree}}_{x}^{a}& Y\text{\_}{\mathit{entree}}_{y}^{a}& Y\text{\_}{\mathit{entree}}_{z}^{a}& 0& 0& 0\\ 0& 0& 0& 0& 0& 0& Y\text{\_}{\mathit{entree}}_{x}^{a}& Y\text{\_}{\mathit{entree}}_{y}^{a}& Y\text{\_}{\mathit{entree}}_{z}^{a}\\ Z\text{\_}{\mathit{entree}}_{x}^{a}& Z\text{\_}{\mathit{entree}}_{y}^{a}& Z\text{\_}{\mathit{entree}}_{z}^{a}& 0& 0& 0& 0& 0& 0\\ 0& 0& 0& Z\text{\_}{\mathit{entree}}_{x}^{a}& Z\text{\_}{\mathit{entree}}_{y}^{a}& Z\text{\_}{\mathit{entree}}_{z}^{a}& 0& 0& 0\\ 0& 0& 0& 0& 0& 0& Z\text{\_}{\mathit{entree}}_{x}^{a}& Z\text{\_}{\mathit{entree}}_{y}^{a}& Z\text{\_}{\mathit{entree}}_{z}^{a}\end{array}\right)\left(\begin{array}{c}{H}_{xx}\\ {H}_{xy}\\ {H}_{xz}\\ {H}_{yx}\\ {H}_{yy}\\ {H}_{yz}\\ {H}_{\mathit{zx}}\\ {H}_{\mathit{zy}}\\ {H}_{zz}\end{array}\right)$

The terms ${H}_{ij}$ are then determined by inversion of the matrix system (E) via the linear-algebra solution operators available in the numpy library of Python,

### 2.3 Determination of the signal to be reconstructed

When the terms ${H}_{ij}(\omega )$ of the transfer-function matrix are known, it is possible to reconstruct the input signal knowing the output signal. To do this it is sufficient to solve the following matrix system:

$\underline{{E}_{\mathit{reconstitué}}^{\mathit{absolu}}}(\omega )=\underline{\underline{{H}^{-1}}}(\omega )\underline{{S}_{\mathit{mesuré}}^{\mathit{absolu}}}(\omega )$
