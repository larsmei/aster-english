# v1.01.169 ZZZZ169 - Validation of the EXTR_COUPE command

**Summary:**

This test validates the correct operation of the [EXTR_COUPE](doc:u4.71.07) command to obtain defined results on segments.

The test structure is as follows: The results of the command are compared to values extracted from the same positions on the structure. When calculations are made by the command, the steps are also performed separately to reproduce the operations performed by the command and then the results obtained are compared.

This documentation is deliberately succinct.
