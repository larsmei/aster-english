# v1.01.117 ZZZZ314 – Validation of the calculation of the object .BASLOC for the sizes

**Summary:**

As part of the CACL_G and DEFI_FOND_FISS operators renovation project, this test is intended to validate the DEFI_FISSURE work operator in an elementary way in the case of a structure containing a mesh crack in the off-take configuration (CONFIG_INIT='DECOLLEE'). This test does not necessarily have physical significance, it is essentially a computer test.

The test case consists of testing vectors from the local base to the crack bottom in different configurations of DEFI_FISSURE.
