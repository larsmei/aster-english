# v8.21.312 ADLV312 – Water-filled flexible cylindrical tank

**Summary:**

This test is for modal analysis of a water-filled tank. The fluid volume has a free surface. The tank is modeled by elements plate DKT and the fluid by elements vibro-acoustic 3D.

The calculation of hydroelastic eigenmodes is not particularly relevant to the slurry modes with low strain energy vis-à-vis hydroelastic modes.

To improve the identification of these modes, the generalised masses are calculated after imposing the standard on a given degree of freedom.

The reference values of the eigenfrequencies are obtained numerically from modellings 3D and Fourier in the SAMCEF software.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The reference values for the eigenfrequencies are obtained numerically: the average of the results obtained from an analysis of Fourier and two 3D analyses is obtained. The formulation for the fluid is the same in all three cases: it is an incompressible fluid, discretized by a potential displacement. The hull of Fourier is of the Reissner type, the models of 3D hulls are of the Mindlin (3D-1) type and hybrid (3D-2) type, respectively. The analyses were carried out using the SAMCEF software. In each case, the meshes are refined until a stable solution is obtained.

In order to improve the identification of these modes, the SAMCEF is identified in SAMCEF and the same is applied in the tests. This will allow the generalised masses to be compared.

## 3 Modelling A

### 3.1 Modelling characteristics A

![Figure](/figures/v8.21.312/1000000000000181000002BA15B2A2B6830E8138.png)

**Figure 3.1. mesh of Modelling A**

Only half of the tank is meshed. This model cannot be used to calculate the twist modes around the $Z$ axis.

The tank is regularly meshed with elements quadrangular plate (DKT Modelling). The fluid is meshed with elements fluid volume (3D_FLUIDE Modelling), the upper part is covered with a free surface layer of elements (2D_FLUI_PESA Modelling). The fluid-structure interface is lined with elements quadrangular coupling (FLUI_STRU Modelling).

### 3.2 Mesh characteristics

Number of nodes: 2822

Number of mesh cells and types: 64 TRIA3, 1280 QUAD4, 512 PENTA6 and 2048 HEXA8

## 4 Summary of the results

In this test, only the structural frequencies are tested; the frequencies of the free surface are not considered.

The results obtained are in good agreement with those obtained by SAMCEF since the difference maximum with reference solution reaches $7.5$ %.

It should be noted that a relatively fine mesh was also used to obtain near reference solution results (5 mesh cells depending on radius, 16 mesh cells height and 32 girth).
