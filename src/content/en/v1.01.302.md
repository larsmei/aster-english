# v1.01.302 SUPV002 – Checking message catalogues

**Summary:**

This test has no physical significance, it is only a computer test.

It allows to check that messages are correctly written in catalogues including that translated messages can always be formatted.

Thus, when creating a catalogue in a new language, you can easily add the check of the messages in that language and run this test to check that the translated messages can be displayed correctly.

Instructions on writing messages are given in [D6.04.01](doc:d6.04.01).

This documentation is deliberately succinct.
