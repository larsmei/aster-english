# v3.01.003 SSLL03 - slender beam on 3 supports

**Summary:**

The linear elasticity static test is used to validate straight beam elements POU_D_T and DIS_T.

This test case concerns a slender beam on 3 supports.

Support reactions and bending moments and deflection are tested by comparing simulation results with reference solution AFNOR (ref. [1]) and those obtained with Pipestress software.
