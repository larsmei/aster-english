# v1.01.140 ZZZZ140 – Validation of POST_MODE for MASS_EFFE and INER_EFFE calculation

**Summary:**

These test cases validate POST_MODE outputs for MASS_EFFE and INER_EFFE calculations by mesh cells groups.

This test includes 2 modellings:

- Modelling A consists of Modelling a system of 2 springs and 2 masses. MASS_EFFE values for each mass are checked.
- Modelling B consists of Modelling a rotating bar around an point with a point mass. The values of MASS_EFFE and INER_EFFE are checked.

This documentation is deliberately succinct.
