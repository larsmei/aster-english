# u4.71.07 Operator EXTR_COUPE

## 1 Purpose

Extraction of a result concept on a set of straight one-dimensional sections from the
result of a 2D or 3D analysis.

**Principle:**

This macro-command generates a mesh from the table defining the sections given by
the user. The mesh is a set of 1D segments discretising the section according to the arrangements
defined by the options of the macro-command. Then the fields coming from the result data structure
supplied by the user are projected onto the mesh created.

## 3 Operands

### 3.1 Operand COUPE

Table containing the description of the sections. The table must have the format of the table coming from
CREA_COUPE described in the paragraph COUPE of the user's manual of
[CREA_COUPE](doc:u4.81.53).

**Note 1:**

It must be noted that for each row of the table, the name of the section must be unique.

**Note 2:**

The support mesh of the newly generated fields contains mesh-cell groups
and node groups for each section created as well as for each group of sections. These mesh-cell groups
and node groups correspond to the names given in the table supplied

**Note 3:**

It is strongly recommended that this table be generated from the command
[CREA_COUPE](doc:u4.81.53). in order to ensure that the points at the ends are indeed on the skins of the
mesh so that the sections are indeed inside the structure considered.

### 3.2 Operand RESULTAT

Result from which the fields will be extracted on the created sections defined from the table described
in paragraph u4.71.07-coupes.

### 3.3 Operand NOM_CHAM

List of the fields to be extracted on the sections created. These fields must belong to the result concept
supplied in the keyword RESULTAT. Only nodal fields can be extracted.

If NOM_CHAM is not supplied, all the nodal fields are extracted on the sections.

### 3.4 Operand REPERE

Makes it possible to determine the frame in which the values of the components of the fields will be expressed.
If `GLOBAL` is supplied then the frame used is that of the result supplied. If `LOCAL` is
supplied then the frame will be the local frame of each section defined as follows:

- X axis: origin point → end point,
- Y axis: origin point → 3rd point, then projected so that the vector is orthogonal to the X axis in the plane containing the three points (origin point, end point and 3rd point).
- Z axis: orthogonal to the X and Y axes so that the frame is right-handed.

### 3.5 Operand LINEARISATION

The operand LINEARISATION defines a section discretised by only 5 points presented in u4.71.07-fig-linearisation

![Figure](/figures/u4.71.07/Linearisation.png)

*Diagram of the distribution of the quantity on a so-called "linearised" section*

The values MOMENT_0 and MOMENT_1 are those defined in §6.1 of the documentation of
POST_RELEVE_T ([u4.81.21](doc:u4.81.21)). The values of the entry and exit points correspond to the value of the
nodal field at these points. Any nodal field can be linearised. The selection is
made with NOM_CHAM; otherwise all the nodal fields are linearised.
The value of $\varepsilon$ is $10^{-7}$.

### 3.6 Operand REPARTITION

This operand allows the user to determine the method of discretisation of the sections.

The different options are:

- `UNIFORME`: the discretisation is uniform over the whole of the section; this is the default option;
- `GAUSSIENNE`: the distribution of the points along the section follows a normal distribution with the parameters supplied by the user in the operands `MOYENNE` and `ECART_TYPE`. These operands represent respectively the mean (lying between 0 and 1) and the standard deviation of the Gaussian distribution.
- `UTILISATEUR`: the user supplies a formula by means of the operand `FORMULE` defining the distribution of the points. This formula must be defined with a single parameter defined between 0 and 1.
