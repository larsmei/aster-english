# v4.04.007 TPLV07 - Cube orthotrope

**Summary:**

This test is based on independent validation of version 3 in linear steady-state thermal analysis.

It validates the elements thermal volume under conditions of imposed flux, convection but also linear variation of the outside temperature.

The results are compared with an analytical solution (VPCS).

In this test, we also check the integral calculation on the edge of a thermal domain and the calculation of the thermal energy with orthotropic material on 3D elements.

For this latter point two calculations are made in addition to that with orthotropic material:

  - a calculation with isotropic material (keyword THER of DEFI_MATERIAU ) as reference
  - a calculation with isotropic material but using keyword THER_ORTH from DEFI_MATERIAU validated by the first calculation.

For the calculation actually orthotropic one will use a reference NON_REGRESSION .

## 2 reference solution

### 2.1 Calculation method used for reference solution

The reference solution is the one given in the TPLV07/89 plug in the VPCS guide.

This is an analytical solution given by the following formula:

$\begin{array}{cc}T(x,y,z)& =\mathrm{ax}+\mathrm{by}+\mathrm{cz}+d\\ & =-\mathrm{45x}-\mathrm{80y}-\mathrm{60z}+22.5\end{array}$

![Figure](/figures/v4.04.007/Object_2.svg)

The normal flow density imposed on the $y=0.1$ face is constant, and the resulting normal flow is determined analytically.

## 4 Summary of the results

The results obtained are excellent. The values calculated by *Aster* are identical to the reference values. This is a "normally expected" result since the solution field that is linear belongs to the space of interpolation of the tested element.

The test was used to test the following commands:

- DEFI_NAPPE to define a variation of the outside temperature according to the $x$ abscisse and the $y$ order,
- DEFI_MATERIAU associated with the THER_ORTH keyword, allowing to define the characteristics of an orthotropic material,
- AFFE_CARA_ELEM associated with the MASSIF keyword, allowing to define the d-orthotropy axes.
