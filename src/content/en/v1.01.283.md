# v1.01.283 ZZZZ283 – Validation of the use of a grid with X-FEM crack on a mesh refined by Homard

**Summary:**

This test validates DEFI_FISS_XFEM's calculation of the level set functions of a $\text{X-FEM}$ crack on a grid in case the mesh of the structure is refined by Homard.

## 1 Reference problem

### 1.1 Geometry

A parallelepipede of dimensions $4\times 4\times 2\mathit{mm}$ with a flat crack is considered:

![Figure](/figures/v1.01.283/100002010000049D000002F92100DED386C126DA.png)

Figure 1.1-1: géométrie de la fissure

### 1.2 Boundary conditions and loads

The crack of the figure will be propagated by imposing the same $\beta$ propagation angle and the same $\Delta a$ advance in each point background so that the background remains always straight:

$\beta ={5}^{\text{o}}$

$\Delta a=0.6\mathit{mm}$

![Figure](/figures/v1.01.283/10000201000006F3000005101438F2CA85C562A5.png)

Figure 1.2-1: propagation imposée

## 2 Test principle

In DEFI_FISS_XFEM cracks can be defined on a grid by one of the following methods:

1. by giving the mesh of the grid to be used by MODELE_GRILLE,
2. giving a crack with a grid already associated with FISS_GRILLE.

The second method was designed for cases where Homard is used to refine the mesh structure. In this case, the grid associated with the crack given by FISS_GRILLE is also associated with the new crack and the already defined level sets are kept identical. Information about the location of the computational field and the use of an auxiliary grid is kept for the new crack, allowing it to be correctly propagated by PROPA_FISS. At the opposite, the level sets on the mesh are calculated by Homard interpolation and passed directly to DEFI_FISS_XFEM by DEFI_FISS/CHAMP_NO_LS*.

To check the correct functioning of the two methods, PROPA_FISS will propagate the $\mathit{FISS0}$ crack in the three-step figure:

1. $\mathit{FISS0}$ is propagated, cracked with an associated auxiliary grid, which was defined using MODELE_GRILLE operand in DEFI_FISS_XFEM. $\mathit{FISS1}$ is obtained.
2. $\mathit{FISS1}$ mesh is refined by Homard. Then the same crack is defined on the refined mesh by keeping the auxiliary grid (FISS_GRILLE DEFI_FISS_XFEM Operand). $\mathit{FISS1 raff}$ is obtained, which coincides with $\mathit{FISS1}$ except where the more refined mesh is.
3. $\mathit{FISS1 raff}$ is propagated and $\mathit{FISS2}$ is obtained.

The same propagation angle and crack advance values are imposed in each point of the crack bottom. These values are maintained constant between the two propagations. The propagated bottoms are therefore always straight and their position in the structure is known beforehand. If both methods work correctly, the position of $\mathit{FISS2}$ must be consistent with that expected.

### 2.1 Method of calculation

For each point of the bottom, at each propagation step, the same $\beta$ propagation angle and the same $\Delta a$ advance of the crack are imposed. Therefore, the coordinates of each point of the bottom can be calculated after each propagation step (figures and ):

${Y}_{i}={Y}_{i-1}+\Delta a\cdot \cos(i\cdot \beta )$

${Z}_{i}={Z}_{i-1}+\Delta a\cdot \mathrm{sen}(i\cdot \beta )$

where $(0,{Y}_{i},{Z}_{i})$ and $(4,{Y}_{i},{Z}_{i})$ are the end points of the segment that coincides with the bottom of the $\mathit{FISS i}$ crack. At the beginning, for the $\mathit{FISS0}$ crack (Figure ):

${Y}_{0}=1$

${Z}_{0}=0$

### 2.2 Quantities and reference results

The coordinates of the expected end points for the $\mathit{FISS2}$ background are therefore:

${X}_{2}=[0,4]$

${Y}_{2}=2.189\mathrm{mm}$

${Z}_{2}=0.156\mathit{mm}$

To verify the actual position of the $\mathit{FISS2}$ background in the elements finished model, the values of the level set at the intersection points between the segment defined by the two end points above and the faces of the elements of the mesh are used. If the position of the bottom after propagation is correctly calculated, the value of the two level set shall be zero for all points of intersection found because, by definition, the crack bottom is formed by all points where the level set tangent and normal are equal to zero.

The intersection points and the level set values at these points can be calculated using the post-processing MACR_LIGN_COUPE command.

## 3 Modelling A

### 3.1 Modelling characteristics

3D modelling is used.

### 3.2 Mesh characteristics

The mesh 3D contains 100 elements HEXA8 $0.4\times 0.4\times 0.2\mathit{mm}$ dimension:

![Figure](/figures/v1.01.283/1000020100000346000002D995CCAE0A41CACB38.png)

Figure 3.2-1: maillage utilisé

For the auxiliary grid, a mesh 3D containing 400 elements HEXA8 $0.2\times 0.2\times 0.1\mathit{mm}$ dimension is used:

![Figure](/figures/v1.01.283/100002010000033C000002CE4AD5B5F48318DF91.png)

Figure 3.2-2: grille auxiliaire

### 3.3 Tested quantities and results

After the two propagations imposed, the values of the level set at the intersection points between the segment connecting the $(0,2.189,0.156)$ and $(4,2.189,0.156)$ bottom end points (see § 2.2) and the elements sides of the mesh are calculated and the maximum and minimum values obtained are determined to be zero. Considering that the mesh is coarse, a tolerance equal to 15% of the length of the smallest mesh edge, i.e. $0.15\cdot 0.2\mathit{mm}=0.03\mathit{mm}$, is used. Therefore, the level set value to the point of the bottom is accepted if and only if it is in the $[-0.03,0.03]$ interval.

## 4 Summary of the results

The position of the $\mathit{FISS2}$ crack after the two propagation steps coincides with that expected. This means that DEFI_FISS_XFEM can well define a crack both on the mesh and on the auxiliary grid. In addition, information on the location of the domain and on the use of the auxiliary grid is transferred by the FISS_GRILLE operand which was set up to allow the use of the grid for a crack defined on an mesh refined by Homard.
