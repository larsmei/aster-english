# 1 **v6.03.123** SSNP123 - Elastoplasticity plate

**Summary:**

This quasi-static plane deformation test illustrates the questions of incompressibility when using an elastoplastic constitutive law: when the plasticity rate becomes significant, non-physical stress oscillations may occur. It is shown that the use of elements QUAD4 and HEXA8 under integrated can help to overcome this problem.

It is a rectangular plate, which is cut into a form of elastoplastic material with isotropic nutrification and is subject to traction at its ends. The elastoplastic solution is also a concern.

Modelling A is the use of elements QUAD4 under integrateds stabilized by the "assumed train" method.

Model B is the use of incompressible elements QUAD8 that allows for the reference solution for model A.

Model C is the use of elements HEXA8 under integrateds stabilized by the "assumed train" method.

Modelling D is the use of incompressible elements HEXA20 that allows for the reference solution for Modelling C.

In addition, modellings E to M check elements HHO and its robustness at the incompressible limit.

## 1 Reference problem

### 1.1 Geometry

This calculation is based on the modelling of a cut test piece required by a forced displacement.

### 1.2 Material properties

Elastoplastic behaviour with isotropic hardening:

$E=200\mathrm{GPa}$

$\nu =0.4999$

${\sigma}_{y}=200\mathit{MPa}$

${E}_{T}=1000\mathrm{MPa}$

### 1.3 Boundary conditions and loads

On $\mathrm{BD}$ : $\mathrm{DY}=0.$

On $\mathrm{DF}$ : $\mathrm{DX}=0.$

On $\mathrm{FG}$ : $\mathrm{DY}=0.1$

## 2 reference solution

The reference solution of Modelling A (C Modelling, respectively) is given by Modelling B (D Modelling, respectively) with near-incompressible elements.

The results obtained by using the different elements embeddeds stabilized by the "assumed train" method are very similar to the results provided by the incompressible quadratic elements, as can be seen from the graph below. This graph gathers the results for different elements:

| HEXA8 | elements HEXA8 classic |
| --- | --- |
| QUAD4 | elements QUAD4 classic |
| HEXA20 | elements HEXA20 quadratic |

| HEXS8 | elements HEXA8 embedded |
| QUAD8 | elements QUAD8 quadratic |
| QUAS8 | elements QUAD8 quadratics incompressible |
| QUAS4 | elements QUAD4 embedded |

This shows the good quality of the solution given by the elements under integrated and the disappearance of the stress oscillations given by the conventional linear elements.
