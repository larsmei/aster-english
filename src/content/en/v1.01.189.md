# v1.01.189 ZZZZ189 – Circumferential orientation by a Python loop

**Summary:**

The case of a concrete hemisphere with orthoradial reinforcements under pressure in linear elasticity is treated. The aim is to circumferentially orient the reinforcements. This operation can be carried out in two ways.

In the modellings $(A)$ and $(C)$, a Python function is offered to perform this action, orienting the mesh cells one by one.

In modellings $(B)$ and $(D)$, AXE command of GRILLE option is used, which allows a much simpler data set of the command file to direct all frames with a single command. The $(B)$ Modelling results are then compared to $(A)$ Modelling, and those of $(D)$ Modelling to $(C)$ Modelling.

In modellings $(A)$ and $(B)$ , the reference axis is $(0,0,1)$ . In modellings $(C)$ and $(D)$ , the reference axis is $(0,1,0)$ . The last two modellings have been added in order to have non-zero $\beta$ nautical angle values.

### 1.4 Policy issues

The reinforcement grids are intended to be circumferentially oriented in relation to the given axis. However, given the hemispheric shape considered, a Python function is proposed to achieve it.

The principle is:

1. Hemispheric axis is noted $Z$
2. for each mesh cell, the vector indicating the direction of the $V=Z\mathrm{\wedge }N$ ciconference where $N$ is normal at the mesh cell is calculated. $V=[\mathit{Vx},\mathit{Vy},\mathit{Vz}]$ is noted and its projection on the $(\mathit{XOY})$ plane is defined by $W=[\mathit{Vx},\mathit{Vy},0]$
3. calculates the values of ANGL_REP to be assigned to the current mesh cell by $\alpha =\arctan(\mathrm{Vy}/\mathrm{Vx})$ and $\beta =-\arctan(\mathit{Vz}/\mathit{norm}(W))$

The function called LIST_CARA_CIRCONF loops on all mesh cells grids, calculates $\alpha$ and $\beta$ and creates the keywords:

_F(SECTION=20.0,

> Mesh cell=Name_Size_Current,
> EXCENTREMENT=0.0, ANGL_REP=(,)),
> COEF_RIGI_DRZ=1.E-10

),

and it adds them to a list. This list is then provided to AFFE_CARA_ELEM. So we get the commands:

LIST_GRI=LIST_CARA_CIRCONF(

> GROUP_MA='GRILLE',
> AXE=(0.,0.,1.),
> MODELE=MODEL,
> GRILLE=_F(SECTION=20.,EXCENTREMENT=0.,)

)

CARA_COQ=AFFE_CARA_ELEM(

> MODELE=MODEL,
> COEF_RIGI_DRZ=0.,),
> GRILLE=LIST_GRI,

)

Finally, it should be noted that LIST_CARA_CIRCONF formally follows the following catalogue:

LIST_CARA_CIRCONF(

> GROUP_MA =SIMP(statut='o',typ=grma,max='**'),
> AXE =SIMP(statut='o',typ='R',max=3,min=3),
> MODE =SIMP(statut='o',typ=model_sdaster),
> GRILLE =FACT(statut='f',max=1,

> SECTION =SIMP(statut='o',typ='R'),
> EXCENTREMENT =SIMP(statut='f',typ='R'),
> COEF_RIGI_DRZ =SIMP(statut='f',typ='R'),

> ),

)
