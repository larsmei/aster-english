# v6.02.137 SSNL137 - Elastoplasticity Traction Bars with IMPLEX Method

**Summary:**

This test allows simple verification of calculations with VMIS_ISOT_LINE law for the elements bar.

A single-tension elastoplastic bar is considered. Resolution is done with the IMPLEX method. Tests are performed on stresses and deformations and are compared to the analytical solution.

## 1 Reference problem

### 1.1 Geometry

A $\mathrm{1cm}$ long bar, cut into 4 elements from $2,5\mathit{mm}$. It is clamped at one end and is subject to a $U$ forced displacement to the other.

![Figure](/figures/v6.02.137/10000200000001A2000000534BC84F64FCAC817C.png)

Figure 1: Diagram of the tensile bar geometry

The cross-sectional area is $A={\mathrm{1m}}^{2}$.

### 1.2 Material properties

A linear isotropic (VMIS_ISOT_LINE) isotropic elastoplastic material is considered to have the following characteristics:

$\begin{array}{c}E=100000\text{MPa}\\ \nu =0,3\\ {E}_{T}=10000\text{MPa}\\ {\sigma}_{Y}=100\text{MPa}\end{array}$

### 1.3 Boundary conditions and loads

clamped support en $A$ $(\mathrm{DZ}=\mathrm{DY}=\mathrm{DX}=0)$ .

To avoid rigid body movements, $\mathrm{DZ}=\mathrm{DY}=0$ for all nodes.

One load is applied: a displacement traction imposed from $U=1\text{mm}$ to node $B$.

## 2 reference solution

### 2.1 Calculation method used for reference solution

Simple traction induces uniform fields of stress and deformation. By definition, we have:

$\begin{array}{c}\sigma ={\sigma}_{Y}+{E}_{T}(\frac{U}{L}-\frac{\sigma}{E})=190\text{MPa}\\ \varepsilon =\frac{U}{L}=0,01\end{array}$

### 2.2 Baseline

- Node $B$ Constraint: ${\sigma}_{B}=190\text{MPa}$
- Node $B$ Deformation: ${\varepsilon}_{B}=0,01$

### 2.3 Uncertainty about the solution

Analytical solution. However, with the IMPLEX method, which is an approach method, a small error is possible. $\text{0,1\%}$ tolerance is allowed.

## 3 Modelling A

### 3.1 Modelling characteristics

The bar is modeled by elements bar.

### 3.2 Mesh characteristics

Four mesh cells SEG2.

## 4 Summary of the results

The results being accurate, it is deduced that the IMPLEX method is correctly programmed for the elements bar with the VMIS_ISOT_LINE relationship.
