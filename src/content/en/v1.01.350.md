# v1.01.350 ZZZZ350 – Validation of DIST_ESCL/DIST_MAIT keywords with a time function

**Summary**

This test validates the keywords DIST_MAIT/DIST_ESCL which allows you to add a fictitious game in the contact using a time function.

There is only one model (A).

## 1 Test principle

The problem is a 2D elastic problem (planes) consisting of two squares in contact via a edge. The keywords DIST_MAIT and DIST_ESCL are used to require that the distance between these two squares is a function of time.

## 2 Summary of results

The results obtained are accurate: the game between squares over time is strictly equal to what is given in the functions used in DIST_ESCL and DIST_MAIT.
