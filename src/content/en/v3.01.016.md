# v3.01.016 SSLL16- Beam on elastic floor, articulated ends

**Summary:**

The linear elasticity static test is used to validate straight beam elements POU_D_T.

This test case concerns a beam on elastic floor, with articulated ends.

Deflections, moments, reactions and rotations are tested by comparing simulation results with reference solution AFNOR (ref. [1]) and those obtained with Pipestress software.
