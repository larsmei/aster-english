# v1.04.111 MUMPS01 - Validation of the MUMPS solver

**Summary:**

This test case allows you to validate the MUMPS solver in different configurations:

- Whether or not Dirichlets (AFFE_CHAR_CINE/MECA) are taken into account
- Consideration of MUMPS problem type options (SYMDEF/SYMGEN/NONSYM)
- Change the value of keyword PARALLELISME (CENTRALISE, MAIL_DISPERSE, SOUS_DOMAINE).
