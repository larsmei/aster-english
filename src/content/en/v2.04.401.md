# v2.04.401 SDLV401 - Free-Free Full Sphere

**Summary:**

This three-dimensional modal analysis test consists of calculating the eigenfrequencies of a full free sphere.

The value of this test is to evaluate the robustness and performance of *Code_Aster* in the detection of rigid modes and multiple frequencies, when using density elements.

The reference solution is digital and is obtained using elements SAMCEF finished structure calculation software.

In this test, the results obtained with two types of elements are compared:

1. l-element HEXA8 (modelling A)
2. l-element HEXA20 (modelization B).

To determine the elements specific of this system, the SORENSEN method is used.

## 1 Reference problem

### 1.1 Geometry

Full sphere:

R

$R=0.01m$ internal radius

### 1.2 Material properties

The material assumed to be linear elastic has the following characteristics:

$E=1.E8\mathrm{Pa}$

$\nu =0.3$

$\rho =10000\mathrm{kg}/{m}^{3}$

### 1.3 Boundary conditions and loads

The structure studied is free in space.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The reference solution is digital: it is obtained with elements structure calculation software finished SAMCEF.

The method for calculating the eigenfrequencies is the SORENSEN method (default algorithm in the CALC_MODES operator).

## 5 Summary of the results

The results obtained are excellent since the differences frequency with the reference solution are less than $\text{0.03\%}$. Furthermore, *Code_Aster* detects the 6 rigid body modes, which it did not ask to calculate.

Two possibilities exist for the calculation of rigid modes. With the 'BANDE' option on the $(0,3000\mathrm{Hz})$ frequency band, either the 'SORENSEN' method or the LANCZOS ('TRI_DIAG') method can be used by specifying the 'MODE_RIGIDE' option.
