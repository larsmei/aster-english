# v6.04.302 SSNV302 – Nonlinear clamped beam

**Summary**

This test allows to create the reference for ssnv302 tests. The results are obtained by a very fine mesh in quadratic 3D

- Modelization A: PETIT kinematics in elasticity
- Modelization B: GDEF_LOG kinematics in elasticity
- Modelization C: VMIS_ISOT_LINE plasticity

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v6.04.302/100000000000052C00000246AD71FCBE068FC2A0.png)

The beam has the following dimensions:

- Length $L=10m$
- Width $l=1m$
- Thickness $e=0,1m$

### 1.2 Material properties

The material has two possible behaviors. In bending, linear isotropic elasticity:

- Young's modulus :     $E=1,0\times {10}^{7}\mathit{Pa}$
- Poisson's ratio:     $\nu =0.3$

In tensile, plasticity of von Linear isotropic hardening devices:

- Young's modulus :     $E=210\mathit{GPa}$
- Poisson's ratio:     $\nu =0.3$
- Elastic limit: ${\sigma}_{y}=3\mathit{MPa}$
- Narrowing pen: $H=2\mathit{GPa}$

### 1.3 Boundary conditions and loads

Boundary conditions: clamped support on left side $\mathit{DX}=\mathit{DY}=\mathit{DZ}=0$ in bending and traction

Flexion loading: FORCE_FACE load on the right side

Traction loading: FORCE_FACE on the right side

## 2 reference solution

### 2.1 reference solution

The reference solution is taken in non-regression on a fine quadratic 3D calculation: all tests are therefore AUTRE_ASTER type for displacement and stress.

In bending, we test:

- DZ moving to node I
- Constraints of von Mises SIEQ_NOEU, VMIS component at nodes C, E and G

In traction, the test shall be carried out:

- DX moving to node I
- Constraints of von Mises SIEQ_NOEU, VMIS component at nodes C, E and G
