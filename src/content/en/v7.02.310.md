# v7.02.310 HPLP310 – Biblio_35 Internal radial crack in thick cylinder under pressure and thermal loading

**Summary:**

This test is based on the independent validation of version 3 in the mechanical of the breakage.

This is a two-dimensional static test in which the contact nonlinearity due to partial closing of the crack is modelled.

The structure's behavior is linear isotropic thermoelastic.

The test case consists of two modellings $\mathrm{2D}$ plane for which the influence of the mechanical load factor $\alpha$ is studied. In the first Modelling a contact with infinitely rigid material is used to represent the (symmetric) closing of the crack while in the second a boundary condition of the restraint unilateral type is implemented.

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v7.02.310/100004A400001F6B00001D8FC4FC058CBFAE53E1.svg)

Right section of a thick tube with a

internal radial crack

| Ray ratio | $b={r}_{2}/{r}_{1}=2({r}_{1}=1\mathrm{mm},{r}_{2}=2\mathrm{mm})$ |
| --- | --- |
|  |  |
| Crack depth | $a/({r}_{2}-{r}_{1})=0,05$ |

### 1.2 Material properties

The material is standard isotropic linear thermoelastic.

| Young's modulus | $E=1000\mathrm{MPa}$ |
| --- | --- |
| Poisson's ratio | $\nu =0,3$ |
| Coefficient of linear expansion | ${\alpha}_{T}=1E-6$ |
| Elastic limit | ${\sigma}_{0}=1\mathrm{MPa}$ (to define the initial stress field created by the auto-fretting process in the hypothesis of an elastoplastic-type prior behavior of Von Mises) |

### 1.3 Boundary conditions and loads

Boundary conditions (for half a piece in $y\ge 0$ region)

$\mathrm{UY}=0$ block on the $\mathrm{AB}$ segment and $\mathrm{DE}$ ligament (symmetry).

Linear relation $\mathrm{UX}(A)+\mathrm{UX}(E)=0$ (to block horizontal translation)

**Charges**

| Loading No. 1: | ${\sigma}_{\mathrm{rr}}({r}_{2})={\sigma}_{0}$ radial traction on the external side; this mechanical loading produces the same ${K}_{I}$ as an internal pressure acting simultaneously on the internal ${r}_{1}$ radius and on the crack lips, without taking into account the contact nonlinearity. |
| --- | --- |
|  |  |
| Loading No. 2: | thermal loading equivalent to a selffrettage defined as follows:![Figure](/figures/v7.02.310/Object_1.svg) |
|  | In these formulas, $\rho$ is the maximum radius of the area that has been autofreted, ${T}_{1}$ is the temperature at ${r}_{1}$ and ${T}_{\rho}$ is the temperature at $r=\rho$ radius in the thick unfretted tube. In the application described here, $\rho ={r}_{2}$ is taken, which corresponds to the autofreting of the entire section of the thick tube, and the non-linearity of contact is not taken into account. A negative $K$ is expected for positive temperatures (compression of the unfretted tube). |
|  |  |
| Loading No. 3: | linear combination No. 2 $+$ $\alpha$ * load No. 1, $\alpha$ ($\ne \alpha T$!) designating the mechanical load factor; here we take into account the non-linearity of contact, which implies an incremental application of the mechanical charge. |

## 2 reference solution

### 2.1 Calculation method used for reference solution

Calculation by elements finished with ABAQUS code. Non-linearity of contact is modelled using elements GAP unidirectional. The stress intensity factor is calculated from the integral $J$ .

- $\mathrm{nbcour}=1$ (number of de-furnishing crowns)
