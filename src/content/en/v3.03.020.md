# v3.03.020 SSLS20 - Pinched cylindrical shell with free edges

**Summary:**

The VPCS guide test is used to test the effect of a punctual loading on a linear elasticity thin cylindrical hull. deflections is compared to point for loading application compared to elements DKT thin cylindrical shell Modelling, two modellings COQUE_3D (1/8 cylinder is represented) and elements COQUE_SOLIDE.

## 7 Summary of the results

For elements:

- DKT :
- Proper solution for a fine mesh.
- To be completed later:
- a less fine mesh,
- by analysing constraints,
- by 4 modellings (DKQ, DST, DSQ, Q4G).
- COQUE_3D on quadrangles: very good solution obtained with a relatively coarse mesh.
- COQUE_3D on triangles: to achieve a suitable solution, this requires a fine mesh, compared to that for the element MEC3QU9H. Similarly, compared to the element DKT, the total number of nodes is much larger.
- COQUE_SOLIDE: excellent results with a relatively coarse mesh. The approximation error due to the use of a flat element plate on the curved surface (facetization) remains reasonable.
