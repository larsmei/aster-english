# v3.01.117 SSLL117 – Validation of modellings second gradient

**Summary:**

This test validates modellings second gradient [R5.04.03](doc:r5.04.03) using analytical solutions.

## 1 Reference problem

### 1.1 Geometry

![Figure](/figures/v3.01.117/100000000000042B0000032F2D76C12239C001FA.png)

**Figure 1.1-a**

| Point coordinates | $X$ | $Y$ |

The geometry of the structure is a square of length of side $\mathrm{1m}$ .

The test is carried out on a single isoparametric finite element quadratic form, mesh-cell group named $\text{ROCHE}$. The different sides of this square, useful for this modelling, are groups of mesh cells, $\text{DA}$ and $\text{BC}$ *.* The mesh-cell group $\text{ROCHE}$ *,* also contains the groups of mesh cells $\text{SROCHE}$ and $\text{MROCHE}$, which correspond respectively to the tops and backgrounds of the same group.

### 1.2 Material properties

In the context of the second gradient media, it is necessary to define material properties for the parts attached to the first and second gradients of the displacement field. The Material properties are elastic for both parts:

    - Young's modulus: $\text{E}=1000\text{Pa}$ ;
    - Poisson's ratio: $\nu =0$ ;
    - Second gradient rigidity module: ${a}_{1}=10{\text{Pa.m}}^{2}$ .
    - Penalization parameter: $r=1E8$

### 1.3 Boundary conditions and loads

- $\mathrm{Dy}=0$ everywhere (Modelling is going back in case $\mathrm{1D}$)
- $\mathrm{Dx}=0$ on the $\text{BC}$ segment
- $\mathrm{Dx}=\mathrm{0.1m}$ on the $\text{AD}$ segment

## 2 reference solution

### 2.1 Method of calculation

The problem to be solved is:

${\int}_{\Omega}\sigma (\frac{\partial {u}^{\to }}{\partial x})+\sum(\frac{\partial {\nu}^{\to }}{\partial x})-\lambda (\frac{\partial {u}^{\to }}{\partial x}-{\nu}^{\to })+{\lambda}^{\to }(\frac{\partial u}{\partial x}-\nu )+r(\frac{\partial u}{\partial x}-\nu )(\frac{\partial {u}^{\to }}{\partial x}-{\nu}^{\to })=0$

with $\forall {u}^{},{\nu}^{},{\lambda}^{}$ kinematically eligible.

We have:

$\lbrace  \begin{array}{c}\sigma =E\frac{\partial u}{\partial x}\\ \Sigma =F\frac{\partial \nu }{\partial x}\end{array}$

Note $\omega$ the form functions of the second order and $\text{N}$ the form functions of the first order on the linear elements,

At the same time, we should also mention the definitions of SEG2 and SEG3:

SEG2: 2 nodes segment

number of nodes : 2

number of nodes peaks : 2

SEG3: 3 nodes segment

number of nodes : 3

number of nodes peaks : 2

![Figure](/figures/v3.01.117/100000000000016B0000006C23D2AE35EF82DE67.png)

**Figure 2.1-b**

${N}_{1}=\frac{1-x}{2}$ and ${N}_{2}=\frac{1+x}{2}$ on the element reference $x\in \left[-1,+1\right]$ with ${N}_{1}$ shape function

the first node.

The shape functions of the 3 nodes segment are:

${\omega}_{1}=-\frac{x(1-x)}{2}$ ${\omega}_{2}=\frac{x(1+x)}{2}$ et ${\omega}_{3}=1-{x}^{2}$

By posing ${u}^{}={\nu}^{}=0$ we show that:

${\int}_{-1}^{+1}{\lambda}^{}(\frac{\partial u}{\partial x}-\nu )\mathrm{dx}=0$ or $u={\omega}_{1}.{u}_{1}+{\omega}_{2}.{u}_{2}+{\omega}_{3}.{u}_{3}$ with ${u}_{2}=0$ ($\text{C.L.}$ )

where $\frac{\partial u}{\partial x}=(x-\frac{1}{2}){u}_{1}-2x{u}_{3}$ and $v={N}_{1}.{\nu}_{1}+{N}_{2}.{\nu}_{2}$ with ${\nu}_{2}=0$ ($\text{C.L.}$ )

So we have $\nu =\frac{(1-x)}{2}{\nu}_{1}$ gold, it should be noted after integration that: ${\nu}_{1}=-{u}_{1}$ (1) $\forall {u}^{},{\nu}^{},{\lambda}^{}$ kinematically eligible.

By doing the same thing and posing: ${\nu}^{}={\lambda}^{}=0$ we find that:

${u}_{3}=\frac{2(E-r)}{4(E+r)}.{u}_{1}\approx -\frac{{u}_{1}}{4}$ (2)

hence the general formula ${S}_{1}={\mathrm{3.a}}^{1}.\frac{\partial \nu }{\partial x}=-\frac{3}{2}.{a}^{1}.{\nu}_{1}$ and after simplification ${S}_{1}=\frac{3}{2}.{a}^{1}.{u}_{1}$ .

### 2.2 Quantities and reference results

The basic and very general formula for solid is ${S}_{1}=\frac{3}{2}.{a}^{1}.{u}_{1}$ .
