# r3.06.15 Stabilised mixed finite elements

**Summary:**

These finite elements aim to complete the library of available finite elements by placing at the user's disposal a finite element having the following characteristics:

- linear. The use of a linear finite element can, in certain cases, present advantages relative to a quadratic element: compatibility with linear structural elements; more diffuse damage with a local constitutive law, etc.
- mixed. The finite element carries, as additional degrees of freedom, all the components of the strain tensor. This confers on it an accuracy far superior to that of the usual linear finite elements.
- stabilised. The standard mixed formulations $(\disp , \strain)$ can in certain cases exhibit spurious oscillations of the stress field. The finite element presented here introduces a stabilisation term making it possible to remove these spurious oscillations.

These finite elements are available in [AFFE_MODELE](doc:u4.41.01) in 3D (modelling `3D_MIX_STA`) and in plane strain (modelling `D_PLAN_MIX_STA`). They can be used only in small strains.
Furthermore, two formulations are available: a standard formulation (formulation `STA`, taken from  and ) and an incompressible formulation (formulation `STA_INCO`, taken from ) inspired by the B-bar method.

## 2 Precautions for use

### 2.1 Choice of the stabilisation parameter

The choice of the stabilisation parameter $\tau_{\strain}$ is left to the user. In , the authors recommend choosing $\tau_{\strain} = \frac{h}{L}$ where L represents the characteristic length of the problem, and h the mesh-cell size.

### 2.2 Symmetry conditions

In the presence of a plane of symmetry, it is necessary to impose symmetry conditions on the strain degrees of freedom (in addition to the usual boundary conditions on the displacements).

For example, in plane strain, a plane of symmetry of normal $X$ will result in an additional boundary condition `EPXY = 0` on this plane.
In 3D, a plane of symmetry of normal $Y$ will result in `EPXY = EPYZ = 0`.

### 2.3 Command variables

The expression of the strain used as input to the constitutive law is recalled:

$$
\vector{\varepsilon} = (1 - \tau_{\strain}) \discMatr{N_E} \discVect{E} + \tau_{\strain} \discMatr{B_U} \discVect{U}
$$

In the expression above, $\discMatr{B_U} \discVect{U}$ is constant per element whereas $\discMatr{N_E} \discVect{E}$ is affine per element.

It is therefore recommended to use adapted command variables in order to avoid any numerical locking. For example, in the case of temperature, it is recommended to use the following temperature as command variable:

$$
\tilde{T} = (1 - \tau_{\strain}) T + \tau_{\strain} \overline{T}
$$

With $T$ an affine temperature and $\overline{T}$ a temperature constant per element. In practice, the parameter $\tau_{\strain}$ being small compared with 1, it would also be possible to use an affine temperature as command variable.

### 2.4 Discontinuities

The stabilised mixed finite elements have nodal strain unknowns. For small values of $\tau_{\strain}$ (which is often the case in practice), the strain and the stress are therefore almost continuous from one element to another.

This element is therefore not suited to the modelling of strong discontinuities (such as, for example, prestressing in a civil-engineering structure). However, it is entirely possible to mix usual linear finite elements and stabilised mixed finite elements (see ).

## 3 Validation

The test case of Cook's membrane in elasticity (sslp104) compares the results obtained with those of reference .

The test case of the clamped arch in elasticity  (sslp108) is an example of implementation of the symmetry boundary conditions specific to the stabilised mixed elements. This test case is also originally taken from , but in the absence of the numerical values making it possible to recover the
values of the original article, the results are compared with those obtained with standard quadratic elements.

The test case of Cook's membrane in small plastic strains (modellings V and W of ssnp178) makes it possible to test the incompressible formulation by comparing it with results taken from the literature and obtained with other modellings available for this type of problem (`HHO` and `INCO_UPG`).

The test case ssnp180 SCIENCE tests (modellings C and D) makes it possible to validate the use of the stabilised mixed finite elements on a structure representative of reinforced-concrete problems.
