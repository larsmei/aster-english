# v4.05.300 TPLP300 - Rectangular plate: convection, temperature imposed

**Summary:**

This test is based on independent validation of version 3 in linear steady-state thermal analysis.

This is a 2D plan problem represented by a single model (plane).

The tested features are the use of elements thermal planes under imposed temperature and convection limit conditions.

The results are compared with those provided by NAFEMS.

## 4 Summary of the results

The Modelling results in excess of the tolerance initially set. the difference maximum obtained is 1.9%, compared to the tolerance of 1%.

In this test, the thermal gradients are greater near the point B (imposed temperature and convection), a finer mesh in this area would improve the quality of the results.

The results are considered acceptable based on the mesh cell (QUAD4) type and the mesh density used

The interest of this test is its origin NAFEMS.
