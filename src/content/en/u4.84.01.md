# u4.84.01 Operator COMB_SISM_MODAL

## 1 Purpose

Compute the response to a seismic loading, by the spectral modal approach, based on the combination of the modal responses, under the assumption of linear elastic constitutive behaviour. (Spectral response = response resulting from the combinations)

The seismic loading consists of two parts:

- the static deformation motion of the structure under the effect of the displacements imposed at the supports (driving motion), represented by the seismic differential displacements DDS;
- the deformation motion relative to the static deflected shape (inertial), represented by the oscillator response spectrum SRO.

The analysis is either single-support (identical excitation of all the supports by the same SRO) or multi-support (excitations differentiated according to the supports). In the multi-support case, the excitations are either all correlated with one another, or related to (uncorrelated) groups of correlated supports.

The spectral modal approach makes it possible to estimate the probable mean maximum absolute values of the quantities of interest, obtained from the quadratic sum of the response to the DDS and of the inertial response.

The spectral modal method is strictly limited to the evaluation of quantities depending linearly on the displacements: strains, stresses (excluding equivalent quantities), generalised forces, nodal forces, support reactions.

Produces a concept of type mult_elas.

## 3 Operands

### 3.1 Modal basis of the structure

#### 3.1.1 Operand MODE_MECA

```text

```

Name of the concept of type mode_meca produced by the modal analysis operator CALC_MODES [u4.52.02](doc:u4.52.02).

#### 3.1.2 Operands TOUT_ORDRE / NUME_ORDRE / NUME_MODE/LIST_ORDRE

```text
/    TOUT_ORDRE= 'OUI'
```

Default value which makes it possible to extract all the eigenmodes available in the concept mode.

```text
/    NUME_ORDRE = l_ordre

/    NUME_MODE = l_mode
```

Extraction of the eigenmodes defined by a list l_ordre of order numbers (NUME_ORDRE) or a list l_mode of mode numbers (NUME_MODE).

```text
/    LIST_ORDRE = l_ordre
```

Identical to NUME_ORDRE but of type listis (produced by DEFI_LIST_ENTI).

#### 3.1.3 Operand FREQ / LIST_FREQ / PRECISION / CRITERE

```text
/    FREQ = l_freq
```

Makes it possible to extract the eigenmodes corresponding to a list of frequencies l_freq.

```text
/    LIST_FREQ = lfreqr8
```

Makes it possible to extract the eigenmodes corresponding to a list of frequencies lfreqr8, defined by the operator DEFI_LIST_REEL [U4.34.01](doc:u4.34.01) (lfreqr8 is therefore a concept of type listr8).

```text
◊    I    PRECISION = prec
     I    CRITERE =
```

These operands make it possible to indicate that one seeks all the eigenmodes whose frequency lies in the interval $\mathit{inst}\pm \mathit{prec}$ . By default $\mathit{prec}=\mathrm{1.0D}-3$ .

According to the value of the keyword CRITERE:

'RELATIF': the search interval is:

> $[\mathit{inst}(1-\mathit{prec}),\mathit{inst}(1+\mathit{prec})]$

'ABSOLU': the search interval is:

> $[\mathit{inst}-\mathit{prec},\mathit{inst}+\mathit{prec}]$

### 3.2 Modal damping

Three possibilities exist for defining the modal damping: a list of reduced damping values supplied by the user in the form of a list of reals (l_R) or of a concept of type listr8 built by the operator DEFI_LIST_REEL [U4.34.01](doc:u4.34.01), or a generalised damping matrix (damping matrix projected onto the basis of the real eigenmodes).

#### 3.2.1 Operand AMOR_REDUIT

```text
/    AMOR_REDUIT = amor
```

This operand makes it possible to supply the list of reduced damping values in the form of a list of reals (l_R). If the number of coefficients supplied is smaller than the number of eigenmodes taken into account, the last coefficient is assigned to the corresponding mode and to the following modes.

#### 3.2.2 Operand LIST_AMOR

```text
/    LIST_AMOR = lamor
```

This operand makes it possible to supply the list of reduced damping values in the form of a concept of type listr8. If the number of reduced damping values is smaller than the number of eigenmodes taken into account, the last coefficient is assigned to the corresponding mode and to the following modes.

**Example:**

LIST_AMOR =(‘0.01’, ‘0.02’)

first mode $\xi =\text{0.01}$ and, for all the other modes, $\xi =\text{0.02}$

#### 3.2.3 Operand AMOR_GENE

```text
/    AMOR_GENE= amogene
```

The name of the generalised damping matrix amogène produced by the operator PROJ_MATR_BASE [U4.63.12](doc:u4.63.12) or PROJ_BASE [U4.63.11](doc:u4.63.11) is given.

**Note**

For theoretical reasons (framework of COMB_SISM_MODAL restricted to “classical” damping) the damping matrix must be diagonal.

### 3.3 Corrections by pseudo-mode: operand MODE_CORR

The modal basis used is in general incomplete. The evaluation of the probable mean upper bound of the response to a seismic excitation therefore requires a correction by a term representing the contribution of the neglected eigenmodes, in each earthquake direction, called pseudo-mode correction or static correction.

For each earthquake direction, this correction is carried out by adding to the modal basis a pseudo-mode $\Psi$ obtained from a static mode $\varphi$ , the displacement field of the nodes of the structure subjected to a uniform acceleration **in the direction considered**, defined by:

$K\varphi =M\delta$

- $K$ stiffness matrix of the structure
- $M$ mass matrix of the structure
- $\delta$ unit field in the earthquake direction

The pseudo-mode $\Psi$ is obtained by subtracting the static contributions of the modes taken into account:

$\Psi =\varphi -\sum_{r=1}^{\mathrm{nmod}}\frac{{p}_{r}}{{\omega}_{r}^{2}}{\Phi}_{r}$

with:

- ${\Phi}_{r}$ eigenmode of index $r$
- ${p}_{r}$ participation factor in the direction $\delta$

In this direction $\delta$ , for each quantity, the contribution of the neglected modes is given by:

${R}_{t}={R}_{s}-\sum_{r=1}^{\mathrm{nmod}}{R}_{r}$

${R}_{s}$ is the quantity associated with the static mode

The definition of the pseudo-mode correction is as follows:

```text
◊    MODE_CORR      =    /    'OUI'
                         /    'NON'     [DEFAUT]

Uniquement si MODE_CORR = 'OUI':

♦    PSEUDO_MODE    = acce              [mode_stat_acce]
◊    FREQ_COUP      = freq              [R]
```

Compulsory if MODE_CORR = 'OUI', this keyword makes it possible to supply the displacement field(s) $\phi$ of the nodes of the structure subjected to a uniform acceleration in one (or more) direction(s), field(s) computed by the operator MODE_STATIQUE with the keyword PSEUDO_MODE [U4.52.14](doc:u4.52.14). For specific needs, it is also possible to supply a concept produced by CREA_RESU, by choosing TYPE_RESU='MODE_MECA' and by entering the keyword AXE of AFFE in order to indicate the direction corresponding to each field (defined by its order number) [U4.44.12](doc:u4.44.12). For every earthquake direction in which the response is computed, a pseudo-mode is computed if acce is supplied.

For the other quantities of interest (see the options u4.84.01-option-calcul) other than the displacement, it is important to compute these quantities mode by mode via CALC_CHAMP from the displacement fields $\varphi$ coming from the operator MODE_STATIQUE/PSEUDO_MODE.

By the very principle of the static analysis of the displacement fields $\phi$ at the nodes of the structure subjected to a uniform acceleration via MODE_STATIQUE/PSEUDO_MODE, it is therefore impossible to deduce from them fields of the responses in relative velocity or in absolute acceleration. Thus, it is impossible to take the static correction by pseudo-mode into account for the options 'VITE', 'ACCE_ABSOLU' (see the options u4.84.01-option-calcul), with the exception of the absolute-acceleration response in the single-support case, where the absolute-acceleration field 'ACCE_ABSOLU' of the structure subjected to a uniform acceleration is known analytically. This is the unit field of the absolute acceleration at the translational degrees of freedom. This correction is carried out automatically whatever the value entered for the keyword MODE_CORR.

**Warning: selection of the pseudo-modes**

When the concept supplied to PSEUDO_MODE contains several definitions of pseudo-modes (with both AXE and GROUP_NO), only the part compatible with the current TYPE_ANALYSE is used:

- In MONO_APPUI, only the pseudo-modes defined with AXE/DIRECTION are considered;
- In MULT_APPUI, only the pseudo-modes defined with NOEUD or GROUP_NO are used.

In order to guarantee a clear use, it is recommended to supply to COMB_SISM_MODAL a MODE_STATIQUE concept specific to each analysis configuration.

```text
◊    FREQ_COUP = fcoup
```

This keyword makes it possible to supply the frequency at which one reads, on the SRO, the value which will be used for the level of the pseudo-mode correction. This frequency normally corresponds to the cut-off frequency of the seismic signal, i.e. the frequency at which the SRO reaches (in absolute pseudo-acceleration) an asymptote. This keyword is particularly useful when the last frequency of the modal basis does not reach the cut-off frequency of the seismic signal, although it is nevertheless sufficient to take into account all the modes which predominate in the response of the structure (a practice which is not recommended).

The value entered in FREQ_COUP is applied for all the earthquake directions taken into account in the analysis.

If this keyword is absent, the last frequency existing in the modal basis MODE_MECA is used as soon as the pseudo-mode correction is activated (MODE_CORR = 'OUI'). In addition, the spectral value read on the spectrum corresponds to the smallest value of the damping.

### 3.4 Type of the excitation (single-support or multi-support)

Three configurations are possible:

- single-support: the structure is studied with the same driving motion at all the supports
- multi-support: the structure is studied with several different driving motions at the supports and, possibly, differential displacements of the supports (DDS)
- envelope: the structure is studied with several different driving motions at the supports, as in the multi-support case.

For a given direction, only the maximum value of the spectra read at the desired frequency is used.
Differential displacements of the supports (DDS) are not taken into account in this configuration.

The treatment of the three types of excitation is different.
The type of analysis is defined appropriately by the user via the operand TYPE_ANALYSE

```text
♦    TYPE_ANALYSE    =    /    'MONO_APPUI'                    [DEFAUT]
                          /    'MULT_APPUI'
                          /    'ENVELOPPE'
```

### 3.5 Description of the loading

The seismic loading is defined by:

- one or more oscillator spectra
- differential displacements of the support, only in the multi-support case

#### 3.5.1 Single-support

Only the oscillator spectra are defined for the single-support case.

```text
♦    SPECTRE =_F(
        ♦    LIST_AXE      = l_axe            [l_axe]

        ♦    SPEC_OSCI     = spec             [nappe]
        ◊    ECHELLE       = echel            [R]
        ◊    CORR_FREQ     =    /    'OUI'
                                /    'NON'    [DEFAUT]

        ◊    NATURE        =    /    'ACCE'   [DEFAUT]
                                /    'VITE'
                                /    'DEPL'
                )
```

##### 3.5.1.1 Oscillator spectrum

> ♦    SPEC_OSCI = spec

A single layer of oscillator spectra, where spec is the name of the layer to be used (oscillator spectra parameterised by the value of the reduced damping). This spectrum is computed beforehand by the command CALC_FONCTION [U4.32.04](doc:u4.32.04) or read from a file by the command LIRE_FONCTION [U4.32.02](doc:u4.32.02). In both cases, the concept produced is of type function of two variables (nappe).

> ◊    ECHELLE = echel

A scale factor echel to be applied to all the points of the spectrum spec.

```text
◊    NATURE = 'ACCE'        [DEFAUT]
```

Quantity of the oscillator spectrum. By default, a spectrum in absolute pseudo-acceleration 'ACCE' is used. It is possible, more rarely, to use other quantities: velocity 'VITE' (relative pseudo-velocity) or displacement 'DEPL' (relative displacement).

```text
♦    LIST_AXE    = (
                    |     'X',
                    |     'Y',
                    |     'Z',
                   )
```

At each occurrence of the factor keyword, the axes concerned by the excitation described are specified via a list composed of 'X', 'Y' and 'Z'.

```text
◊    CORR_FREQ    =    /    'OUI'
                       /    'NON'        [DEFAUT]
```

In fact, in order to compute the displacement response components from an oscillator spectrum in absolute pseudo-acceleration (NATURE = ‘ACCE’) or relative pseudo-velocity (NATURE = 'VITE'), one is led to divide each value once or twice by ${\omega}_{r}$ , the angular frequency of the real eigenmode (undamped oscillator). Strictly speaking, the oscillator $r$ is damped and its natural angular frequency is ${\omega}_{r}\sqrt{1-{\xi}^{2}}$ , and ${\omega}_{r}$ is only the natural pseudo-angular frequency. The operand CORR_FREQ = 'OUI' makes it possible to correct these values in order to take the damping of the eigenmode into account:

$\begin{array}{ccccc}{\mathit{vite}}_{max}& =& {\omega}_{r}\sqrt{1-{\xi}^{2}}{\mathit{depl}}_{\mathit{lu}}& =& \mathit{vitesse}\hfill \\ {\mathit{acce}}_{max}& =& {\omega}_{r}^{2}\left(1-{\xi}^{2}\right){\mathit{depl}}_{\mathit{lu}}& =& \mathit{accélération}\hfill \end{array}$

If a response spectrum in relative pseudo-velocity is supplied (NATURE = 'VITE'), the operand CORR_FREQ will be necessary in order to correct ${\mathrm{depl}}_{\max}$ and ${\mathrm{acce}}_{\max}$ if required. Likewise for a response spectrum in absolute pseudo-acceleration (NATURE = 'ACCE'), in order to correct ${\mathit{depl}}_{max}$ and ${\mathit{vite}}_{max}$ .

**Example:**

For a ground spectrum in absolute pseudo-acceleration sol_0_1 scaled to $0.1m/{s}^{2}$ and a scale factor making it possible to simulate a spectrum scaled to $0.25m/{s}^{2}$ , applied to the three global directions, and without taking the frequency correction into account:

```text
♦    SPECTRE =_F(  SPEC_OSCI = sol_0_1,
                   ECHELLE   = 2.5,
                   NATURE    = 'ACCE',
                   LIST_AXE  = ('X','Y','Z',),
                   CORR_FREQ = 'NON',
                 )
```

#### 3.5.2 Multi-support

In the multi-support case, the structure is studied with several different motions at the supports. There are two configurations:

- Correlated multi-support: all the supports are correlated with one another;
- Uncorrelated multi-support: one can exhibit groups which are perfectly uncorrelated with one another, the excitations within one and the same group of supports being assumed to be correlated with one another.

Thus, the steps for defining the loading are as follows:

- Definition of the supports via the operand APPUIS
- Definition of the groups of correlated supports via the operand GROUP_APPUI_CORRELE
- Definition of the oscillator spectra (SRO) for each support via the operand SPECTRE
- Definition of the Seismic Differential Displacements (DDS) for each support via the operand DEPL_MULT_APPUI

##### 3.5.2.1 Operand APPUIS

```text
♦    APPUIS    =_F(
       ♦    NOM       = nom_appui
       ♦    GROUP_NO  = lgrno          [l_gr_noeud]

            )
```

where:

```text
♦    NOM = nom_appui
```

Character string (limited to 4 characters at most) defined by the user to designate the name of the support.

```text
♦    GROUP_NO = lgrno
```

List of the GROUP_NO which constitute the support.

##### 3.5.2.2 Group of correlated supports in multi-support analysis: operand GROUP_APPUI_CORRELE

```text
♦    GROUP_APPUI_CORRELE =_F(
            ♦    NOM         = nom_group_appui
            ♦   / TOUT       = 'OUI'              [DEFAUT]
                / LIST_APPUI = l_appui
                            )
```

where:

```text
♦    NOM    = nom_group_appui
```

Character string (limited to 8 characters at most) defined by the user to designate the name of the group of correlated supports.

```text
♦    / TOUT = 'OUI'    [DEFAUT]
```

All the supports are correlated with one another and gathered into a single group of correlated supports. This case corresponds to the correlated multi-support configuration.

```text
♦    / LIST_APPUI = l_appui
```

List of the supports correlated with one another and gathered into the group of correlated supports.

The user must take care to define the groups of supports for all the supports defined by the operand APPUIS (see u4.84.01-operande-appuis); a support can belong to only one group of supports. And all the groups of correlated supports defined by the factor keyword GROUP_APPUI_CORRELE are uncorrelated with one another.

If all the supports form a single group of supports, this is the correlated multi-support case. Conversely, the case where there are at least two occurrences of the factor GROUP_APPUI_CORRELE, that is two groups of correlated supports, corresponds to the uncorrelated multi-support configuration.

##### 3.5.2.3 Operand SPECTRE

The spectra are defined for each support via the factor SPECTRE, as in the single-support case, with, in addition:

> ♦    NOM_APPUI    = nom_appui : the name of the support concerned

##### 3.5.2.4 Operand DEPL_MULT_APPUI

Since the driving motion of the structure is not uniform, this keyword makes it possible to define the contribution to the global response of a list of supports or of groups of supports. This contribution is established from the static modes with imposed displacements of the structure:

${R}_{\mathrm{ei}}={\Phi}_{\mathrm{si}}{\delta}_{i\max}$

with:

| ${\Phi}_{\mathrm{si}}$ | static mode for support $i$ |
| --- | --- |

#### 3.5.3 Envelope

The idea of this complementary type of analysis is to supply the
envelope response of a multi-support analysis
with a minimum of modifications in the command file.

##### 3.5.3.1 Selected envelope spectrum

For a given direction, only the maximum value of the spectra coming from different groups of correlated supports, read at an eigenfrequency of the structure, is retained in order to compute the modal response. Suppose that there exist *nbGr* groups of supports; the retained value of the spectra (in this example, the pseudo-acceleration) is:

$PSA_{retenu} = \max(PSA_1, PSA_2, ..., PSA_{nbGr})$

This envelope value is applied to all of the supports.
The combinations remain identical to those used in the single-support analysis case.

##### 3.5.3.2 Static corrections by pseudo-mode

If the static correction by pseudo-mode is activated in the multi-support analysis, it must be replaced by a MODE_STATIQUE result, computed under the assumption that the structure is treated as single-support.

When MODE_CORR = 'OUI', the result supplied with the compulsory keyword PSEUDO_MODE corresponds to the displacement field $\phi$ of the nodes of the structure, subjected to a uniform acceleration in one or more directions. These displacements are computed by the operator MODE_STATIQUE with the keyword PSEUDO_MODE [U4.52.14](doc:u4.52.14).

More concretely, in multi-support analysis, the static mode is computed with the following command:

```text
mode_meca_mult = MODE_STATIQUE(
    PSEUDO_MODE = _F(
                    GROUP_NO   = grno,
                # Si: exists("TOUT") or exists("NOEUD") or exists("GROUP_NO")
                    ◆ / TOUT_CMP = "OUI" (ou non renseigné),
                      / AVEC_CMP = text,
                      / SANS_CMP = text,
                    ),
                        )
```

It is necessary to modify this command in order to supply the static correction in the case of a single-support analysis, by using the operands AXE or DIRECTION, for example as below:

```text
mode_meca_mono = MODE_STATIQUE(
    PSEUDO_MODE = _F(
                ◆ / AXE = / "X",
                          / "Y",
                          / "Z",
                    ),
                            )
```

The last result, `mode_meca_mono`, is entered in COMB_SISM_MODAL as follows:

```text
reponse_env = COMB_SISM_MODAL(
                TYPE_ANALYSE = "ENVELOPPE",
                MODE_CORR    = "OUI",
                PSEUDO_MODE  = mode_meca_mono,
                ...
            )
```

##### 3.5.3.3 Differential displacements of the supports (DDS)

In the case where differential displacements of the supports (DDS) are taken into account in the multi-support analysis, they will not be considered when the envelope option is used.

### 3.6 Combination rules

One reasons quantity by quantity (displacement, velocity or acceleration, internal forces, stresses) from the modal values associated with the eigenmodes taken into consideration. For each quantity, each degree of freedom (nodal fields of displacement, velocity or acceleration), or each component of a wrench (internal forces) or of stress, will be treated **independently**. This is what we call the response $R$ in the statement of the combination rules.

Several levels of combination are necessary:

- combination of the eigenmodes,
- static correction by pseudo-mode,
- combination along the earthquake directions.

In the case of a multi-support analysis, the combination rules are modified in order to take into account the different excitations applied to groups of supports. It is also possible to compute separately the inertial components of the response and those due to the DDS.

#### 3.6.1 Single-support

The analysis of the total response resulting from the combinations of the modal responses and then of the directional responses is presented in u4.84.01-fig-calcul-spectral-mono-appui.

![Figure](/figures/u4.84.01/1000020100000357000002283EE9E22A65C91F43.png)

*Single-support spectral analysis (Ref. [6])*

The **total** response of the structure $R$ is obtained by **combination of the directional responses** ${R}_{X}$ where $X$ represents one of the directions of the GLOBAL frame of definition of the mesh $(X,Y,Z)$ . The directional response is given by:

${R}_{X}=\sqrt{{R}_{d}^{2}+{({R}_{t}+{R}_{\mathit{qs}})}^{2}}$

- ${R}_{d}$ combined dynamic response of the modal oscillators established by the combination of the modes with the rule defined by the keyword COMB_MODE (see u4.84.01-combinaison-modes-propres)
- ${R}_{t}$ correction of the static effects of the neglected modes (pseudo-mode) (see u4.84.01-spectre-oscillateur)
- ${R}_{\mathit{qs}}$ combined quasi-static response of the modal oscillators established by the combination of the modes only with the GUPTA rule by the keyword COMB_MODE (TYPE ='GUPTA') (see u4.84.01-combinaison-gupta)

The rule for combining the directional responses is defined by the keyword COMB_DIRECTION (see u4.84.01-combinaison-suivant-directions).

In summary, for the single-support case, the rule for combining the modes is defined by the keyword COMB_MODE (see u4.84.01-combinaison-modes-propres) and that of the directions by the keyword COMB_DIRECTION (see u4.84.01-combinaison-suivant-directions).

#### 3.6.2 Multi-support

For the total response of the multi-support case, the sequence of the combinations is presented in u4.84.01-fig-calcul-spectral-multi-appui.

![Figure](/figures/u4.84.01/10000201000003540000025DA4C8F2777AF093FD.png)

*Multi-support spectral analysis (Ref. [6])*

The **total** response of the structure $R$ is obtained by **combination of the directional responses** ${R}_{X}$ where $X$ represents one of the directions of the GLOBAL frame of definition of the mesh $(X,Y,Z)$ . The directional response is given by:

${R}_{X}=\sqrt{{R}_{d}^{2}+{R}_{t}^{2}+{R}_{e}^{2}}$

- ${R}_{d}$ combined dynamic response of the modal oscillators established by the combination of the modes with the rule defined by the keyword COMB_MODE (see u4.84.01-combinaison-modes-propres)
- ${R}_{t}$ correction of the static effects of the neglected modes (pseudo-mode) (see u4.84.01-corrections-pseudo-mode)
- ${R}_{e}$ response to the driving motion (see u4.84.01-operande-depl-mult-appui)

For the combined dynamic response ${R}_{d}$ by direction, **by default**, one combines quadratically the combined dynamic responses of the different groups of correlated supports:

${R}_{d}=\sqrt{\sum_{m=1}^{\mathit{nbG}}{R}_{d,m}^{2}}$

- ${R}_{d,m}$ combined dynamic response of the modal oscillators for the m-th group of correlated supports
- $\mathit{nbG}$ total number of groups of correlated supports

The user may choose other rules for combining the responses between the groups of supports (LINE, ABS), defined by the keyword CUMUL_INTER (see u4.84.01-mot-cle-cumul-inter).

**Warning:** These combinations can return very conservative results.

For the combined dynamic response of the m-th group of supports ${R}_{d,m}$ , one combines the responses of the modes of the m-th group of correlated supports with the combination rule defined by the keyword COMB_MODE (see u4.84.01-combinaison-modes-propres) (illustration example for the SRSS rule):

${R}_{d,m}=\sqrt{\sum_{i=1}^{\mathit{nbM}}{R}_{d,m,i}^{2}}$

- ${R}_{d,m,i}$ combined dynamic response of the i-th mode for the m-th group of correlated supports
- $\mathit{nbM}$ total number of modes

For the combined dynamic response of the i-th mode of the m-th group of supports ${R}_{d,m,i}$ , **by default**, one combines linearly the responses of the i-th mode of the correlated supports in the m-th group of correlated supports:

${R}_{d,m,i}=\sum_{n=1}^{{\mathit{nbA}}_{m}}{R}_{d,m,i,n}$

- ${R}_{d,m,i,n}$ dynamic response of the i-th mode due to the SRO at the n-th support in the m-th group of correlated supports
- ${\mathit{nbA}}_{m}$ total number of correlated supports constituting the m-th group of correlated supports

The user may also choose other rules for combining the responses of the supports within one and the same group of supports (QUAD, ABS), defined by the keyword CUMUL_INTRA (see u4.84.01-mot-cle-cumul-intra).

**Warning:** These combinations can return very conservative results.

In summary, the combined dynamic response ${R}_{d}$ of the direction considered results from the linear combination of the correlated supports, then from the combination of the modes by the rule defined by the keyword COMB_MODE (see u4.84.01-combinaison-modes-propres) and finally from the quadratic combination of the groups of supports.

For the combined correction of the static effects of the neglected modes (pseudo-mode) ${R}_{t}$ by direction, one combines linearly the corrections of the correlated supports within a group of supports and then quadratically the corrections of the groups of supports (no choice is left to the user for these combinations):

${R}_{t}=\sqrt{\sum_{m=1}^{\mathit{nbG}}{R}_{t,m}^{2}}$

${R}_{t,m}=\sum_{m=1}^{{\mathit{nbA}}_{m}}{R}_{t,m,n}$

- ${R}_{t,m,n}$ correction due to the SRO at the n-th support in the m-th group of correlated supports
- ${\mathit{nbA}}_{m}$ total number of correlated supports constituting the m-th group of correlated supports
- ${R}_{t,m}$ correction of the m-th group of correlated supports
- $\mathit{nbG}$ total number of groups of correlated supports

For the response to the driving motion ${R}_{e}$ by direction, one combines the responses of the correlated supports within a group of supports by the rule defined in COMB_DDS_CORRELE (see u4.84.01-mot-cle-comb-dds-correle) and then quadratically the responses of the groups of supports (no choice is left to the user for this inter-group combination). For this component, the rule for combining the DDS of the correlated supports is in absolute value, by default (illustration formula with the absolute rule):

${R}_{e}=\sqrt{\sum_{m=1}^{\mathit{nbG}}{R}_{e,m}^{2}}$

${R}_{e,m}=\sum_{m=1}^{{\mathit{nbA}}_{m}}\left|{R}_{e,m,n}\right|$

- ${R}_{e,m,n}$ response due to the DDS at the n-th support in the m-th group of correlated supports
- ${\mathit{nbA}}_{m}$ total number of correlated supports constituting the m-th group of correlated supports
- ${R}_{e,m}$ combined response of the m-th group of correlated supports
- $\mathit{nbG}$ total number of groups of correlated supports

In summary, for the multi-support case, the first combination, being linear, is carried out between the different nodes (NOEUD) of one and the same support for all the components, with no choice left to the user. Then, the intra-group combination rule (responses between correlated supports within one and the same group) is linear for the responses of the oscillators and of the pseudo-mode (no choice is left to the user), whereas for the response to the DDS the rule is defined in COMB_DDS_CORRELE (see u4.84.01-mot-cle-comb-dds-correle). Then, the combination of the modes is defined by the keyword COMB_MODE (see u4.84.01-combinaison-modes-propres), then the quadratic combination of the groups of supports (quadratic inter-group combination with no choice for the user). Finally, the combination of the directions is defined by the keyword COMB_DIRECTION (see u4.84.01-combinaison-suivant-directions).

#### 3.6.3 Combination of the eigenmodes: keyword COMB_MODE

```text
♦    COMB_MODE
```

The response of the structure ${R}_{d}$ , **in one earthquake direction**, is obtained by one of the possible combinations (defined by the operand TYPE) of the contributions of each of the eigenmodes taken into account. Each eigenmode is considered as an independent oscillator of response ${R}_{r}$ defined by $({\omega}_{r},{\xi}_{r})$ . The response is read by interpolation in the oscillator spectrum of the excitation signal in this direction.

For a single-support excitation, the response ${R}_{r}$ of the oscillator $r$ is given by:

${R}_{r}=\frac{{p}_{r}}{{\omega}_{r}^{2}}{S}_{r}{\Phi}_{r}$

| ${\Phi}_{r}$ | modal quantity (displacement, generalised force, reaction) associated with the eigenmode of index $r$ |
| --- | --- |
| ${P}_{r}$ | modal participation factor associated with mode $r$ in the direction studied |
| ${S}_{r}$ | value of the response spectrum, for example in pseudo-acceleration, for the oscillator $r$ , for the specified damping value |

Several rules for combining the eigenmodes are available. They are chosen by the operand TYPE. The rule for combining the eigenmodes is common to all the directions considered.

##### 3.6.3.1 Quadratic combination TYPE = ‘SRSS’

This combination (Square Root of Sum of Squares) corresponds to the assumption of strict independence of the oscillators associated with each eigenmode:

${R}_{d}=\sqrt{\sum_{r=1}^{\mathit{nmod}}{R}_{r}^{2}}$

Note that this combination rule, although very commonly used, may be ill-suited when the independence assumption is not satisfied for neighbouring eigenmodes or for strongly damped modes.

##### 3.6.3.2 Complete quadratic combination TYPE = ‘CQC’

The quadratic combination (established by DER KIUREGHIAN) provides a correction to the previous rule by introducing correlation coefficients depending on the damping ratios and on the distances between neighbouring eigenmodes (see [R4.05.03](doc:r4.05.03)):

${R}_{d}=\sqrt{\sum_{{r}_{1}}\sum_{{r}_{2}}{\rho}_{{r}_{1}{r}_{2}}{R}_{{r}_{1}}{R}_{{r}_{2}}}$

with the correlation coefficient:

${\rho}_{ij}=\frac{8\sqrt{{\xi}_{i}{\xi}_{j}{\omega}_{i}{\omega}_{j}}({\xi}_{i}{\omega}_{i}+{\xi}_{j}{\omega}_{j}){\omega}_{i}{\omega}_{j}}{{({\omega}_{i}^{2}-{\omega}_{j}^{2})}^{2}+4{\xi}_{i}{\xi}_{j}{\omega}_{i}{\omega}_{j}({\omega}_{i}^{2}+{\omega}_{j}^{2})+4({\xi}_{i}^{2}+{\xi}_{j}^{2}){\omega}_{i}^{2}{\omega}_{j}^{2}}$

##### 3.6.3.3 Sum of the absolute values TYPE = ‘ABS’

This combination corresponds to an assumption of complete dependence of the oscillators associated with each eigenmode:

${R}_{d}=\sum_{r=1}^{\mathit{nmod}}\left|{R}_{r}\right|$

Note that this combination rule is to be discouraged, because it is far too conservative and leads to systematic over-design.

##### 3.6.3.4 Combination with the 10% rule TYPE = ‘DPC’

Neighbouring modes (whose frequencies differ by less than 10%) are first combined by summation of the absolute values. The values resulting from this first combination are then combined quadratically. This method was proposed by the American regulations of the U.S. Nuclear Regulatory Commission (Regulatory Guide 1.92 – February 1976) in order to lessen the conservatism of the previous method. It remains inadequate for structures with a high modal density.

The modes $i$ and $i+1$ are neighbours when:

$2\frac{({f}_{i+1}-{f}_{i})}{({f}_{i+1}+{f}_{i})}\le 10\text{\%}$

##### 3.6.3.5 Combination with the "Grouping" method TYPE = ‘NRC_GROUPING’

This method is similar to the "DPC" method (10% rule).
It is also proposed by the American regulations of the U.S. Nuclear Regulatory Commission (NRC 1.92 Rev. 1).

**Important: it is recommended to use this method only in PipingMaster.**

For a given direction I (I = X, Y, Z), the periodic response is:

$R_{mode, I} = \sqrt{\sum_{i=1}^{nmode} R_{i, I}^2 + 2 \sum_{j>i}^{nmode} \varepsilon_{i, j} |R_{i, I} R_{j, I}|}$

The modes are grouped according to the following rule:

1. Start a new group by adding the lowest eigenmode k (in frequency) which has not yet been grouped.
2. Increase the eigenfrequencies starting from k.
3. As long as $\frac{({f}_{i}-{f}_{k})}{{f}_{k}} \le 10\text{\%}$ , add mode i to the group.
4. Return to step 1.

The correlation coefficient:

- $\varepsilon_{i, j} = 1$ if modes i, j belong to one and the same group
- $\varepsilon_{i, j} = 0$ otherwise.

##### 3.6.3.6 Combination with the "Ten Percent" method TYPE = ‘NRC_TEN_PERCENT’

This method is very similar to the "NRC_GROUPING" method.
It is also proposed by the American regulations of the U.S. Nuclear Regulatory Commission (NRC 1.92 Rev. 1).

For a given direction I (I = X, Y, Z), the periodic response is:

$R_{mode, I} = \sqrt{\sum_{i=1}^{nmode} R_{i, I}^2 + 2 \sum_{j>i}^{nmode} \varepsilon_{i, j} |R_{i, I} R_{j, I}|}$

There is no notion of "group" in this method.
The two modes are considered to be "close" when the gap between the two associated frequencies is less than or equal to 10%.

In other words, the two modes *i*, *j* are close if:
$\frac{({f}_{j}-{f}_{i})}{{f}_{i}} \le 10\text{\%}, \; f_i < f_j$

The correlation coefficient:

- $\varepsilon_{i, j} = 1$ if modes i, j are close
- $\varepsilon_{i, j} = 0$ otherwise.

The response obtained by the "NRC_TEN_PERCENT" combination is more conservative than that obtained by the "NRC_GROUPING" combination.

##### 3.6.3.7 ROSENBLUETH combination TYPE = ‘DSC’

This rule (proposed by E. ROSENBLUETH and J. ELORDY) introduces a correlation between modes, different from that of the CQC method. The responses of the oscillators are combined by a double sum (Double Sum Combination):

${R}_{d}=\sqrt{\sum_{{r}_{1}}\sum_{{r}_{2}}{\rho}_{{r}_{1}{r}_{2}}{R}_{{r}_{1}}{R}_{{r}_{2}}}$

It requires an additional datum, the duration $s$ of the “strong” phase of the earthquake defined by the operand DUREE. The user must take care to homogenise the units: the frequency is in Hz, so the duration must be in seconds.

The correlation coefficient is then:

$\begin{array}{c}{\rho}_{ij}={\left(1+{\left(\frac{\omega {'}_{i}-\omega {'}_{j}}{\xi {'}_{i}{\omega}_{i}+\xi {'}_{j}{\omega}_{j}}\right)}^{2}\right)}^{-1}\\ \mathit{où}\phantom{\rule{2em}{0ex}}\omega {'}_{i}={\omega}_{i}\sqrt{1-{\xi}_{i}^{2}}\phantom{\rule{2em}{0ex}}\mathit{et}\phantom{\rule{2em}{0ex}}\xi {'}_{i}={\xi}_{i}+\frac{2}{s{\omega}_{i}}\end{array}$

##### 3.6.3.8 Combination of "Double Sum Absolute" type TYPE = ‘NRC_DSA’

This rule is similar to the ‘DSC’ method, but the combination is carried out with the absolute value of the modal responses instead of the algebraic values.

${R}_{d}=\sqrt{\sum _{{r}_{1}}\sum _{{r}_{2}}{\rho }_{{r}_{1}{r}_{2}} |{R}_{{r}_{1}}{R}_{{r}_{2}}|}$

Reference: [bib4]_ Rev. 1

##### 3.6.3.9 Combination according to Gupta TYPE = ‘GUPTA’

Gupta [bib4]_, in order to take into account the correlations between modes due to the quasi-static part of the response, introduces the rigid response factor, which makes the correlation vary from 0 to 1 between the modal responses of intermediate frequencies between ${\mathit{FREQ}}_{1}$ and ${\mathit{FREQ}}_{2}$ , two frequencies to be determined by the user.

Gupta decomposes each modal response ${R}_{r}$ into a dynamic part ${R}_{r}^{p}$ and a quasi-static part ${R}_{r}^{\mathit{qs}}$ : ${R}_{r}^{\mathit{qs}}={\alpha}_{r}{R}_{r}$ and ${R}_{r}^{p}=\sqrt{1-{\alpha}_{r}^{2}}{R}_{r}$

Thus, for each mode $r$ , the rigid response factor ${\alpha}_{r}$ is assigned to the modal response ${R}_{r}$ :

${\alpha}_{r}=0$ for $f\le {f}_{1}$ and ${\alpha}_{r}=1$ for $f\ge {f}_{2}$

${\alpha}_{r}$ is estimated for the frequency ${f}_{r}$ according to the following formula:

${\alpha}_{r}=\frac{\ln{f}_{r}/{f}_{1}}{\ln{f}_{2}/{f}_{1}}$

The combined dynamic response of the modal oscillators is carried out according to the 'CQC' combination:

${R}_{d}=\sqrt{\sum_{{r}_{1}}\sum_{{r}_{2}}{\rho}_{{r}_{1}{r}_{2}}{R}_{{r}_{1}}^{p}{R}_{{r}_{2}}^{p}}$

The combined quasi-static response of the modal oscillators is carried out according to an algebraic combination:

${R}_{\mathit{qs}}=\sum_{r=1}^{\mathit{nmod}}{R}_{r}^{\mathit{qs}}$

This combination according to GUPTA is available only in the single-support case.

##### 3.6.3.10 Signed CQC combination TYPE = ‘CQC_SIGNE’

The signed CQC method is an extension of the classical CQC method (u4.84.01-combinaison-cqc).

For each direction $I$ ($I \in \{X, Y, Z\}$), the dynamic response ${R}_{d, I}$ is first obtained
by the modal combination using the CQC method described in u4.84.01-combinaison-cqc.

This response is then combined with any other responses, such as the static correction by pseudo-mode ${R}_t$,
or the response to the driving motion ${R}_e$. In the case of a multi-support analysis,
it is combined with the responses
of the supports belonging to one and the same group of supports (CUMUL_INTRA, see u4.84.01-mot-cle-cumul-intra) or with the
responses coming from different groups of supports (CUMUL_INTER, see u4.84.01-mot-cle-cumul-inter).

The response obtained in each direction $I$ is weighted by the sign of the response of a **dynamic
mode** ${\phi}_{r, I}$, **selected by the user.**

${R}_{I}^{signé}={R}_{I}*Sgn(\phi_r, I)$, with $I \in \{X, Y, Z\}$

where the sign function used in the implementation is defined by:

$Sgn(\phi_r) = \begin{cases} -1 & \text{si } \phi_r<0,\\ 1 & \text{si } \phi_r \geq 0. \end{cases}$

Note that the function $Sgn(\phi_k)$ *differs from the classical sign function by assigning the value 1
when* ${\phi}_{r}=0$

For each directional response $R_X$, $R_Y$, $R_Z$, the user must choose an eigenmode
${\phi}_{r, I}$ with which to sign it, via the keywords NUME_MODE_X, NUME_MODE_Y, NUME_MODE_Z.

> **Warning:**

- The number entered must correspond to the mode number (NUME_MODE) and not to the order number (NUME_ORDRE), which is

linked to the computational design of the data. After a mode filtering (by the command EXTR_MODE, for example),
the order numbers may be modified whereas the mode numbers remain unchanged.

- The modal shapes being defined up to a multiplicative factor. In other words,

${\phi}$ and ${-\phi}$ represent physically and mathematically the
same eigenmode. Depending on the desired orientation, it is sometimes necessary to use
suitable filters in order to select the reference modal shape.

- The CQC_SIGNE combination can be used only with the directional combination type 'NEWMARK'.

The modal quantities requested with the operand OPTION (see u4.84.01-option-calcul) as well as their associated signature field
are listed in the following table:

| --- | --- |

| VITE | DEPL |
| ACCE_ABSOLU | DEPL |
| EFGE_ELNO | EFGE_ELNO |

#### 3.6.4 Combination along the directions: keyword COMB_DIRECTION

```text
◊    COMB_DIRECTION =      /    'QUAD'

                           /    'NEWMARK'        [DEFAUT]

                           /    'ABS'
```

Three rules for combining the directional responses are available.

This operand is not compulsory. If more than one direction is entered in the operand SPECTRE, the rule COMB_DIRECTION = NEWMARK is applied by default. If only one direction is entered in the operand SPECTRE, no directional combination is carried out.

##### 3.6.4.1 Quadratic combination: COMB_DIRECTION = ‘QUAD’

This combination corresponds to the assumption of strict independence of the responses in each direction:

$R=\sqrt{{R}_{X}^{2}+{R}_{Y}^{2}+{R}_{Z}^{2}}$

##### 3.6.4.2 NEWMARK combination: COMB_DIRECTION = ‘NEWMARK’

For each of the directions $i(X,Y,Z)$ , one computes the 8 values:

${R}_{i}=\pm {R}_{X}\pm 0,4{R}_{Y}\pm 0,4{R}_{Z}$

Which leads, by circular permutation, to 24 (respectively 8 and 2) values if 3 (respectively 2 and 1) directional excitations are defined

${R}_{max}=max({R}_{i})$

##### 3.6.4.3 Absolute combination: COMB_DIRECTION = ‘ABS’

This combination corresponds to the assumption of correlation of the responses in each direction:

$R= |{R}_{X}| + |{R}_{Y}|+|{R}_{Z}|$

It should be noted that this assumption is very conservative.

#### 3.6.5 Keyword COMB_DDS_CORRELE

```text
◊    COMB_DDS_CORRELE =    / 'ABS'                            [DEFAUT]
                           / 'QUAD'
                           / 'LINE'
```

This keyword defines the rule for combining the responses to the driving motions of the correlated supports.

##### 3.6.5.1 Quadratic combination COMB_DDS_CORRELE = ‘QUAD’

${R}_{e}=\sqrt{\sum{R}_{\mathit{ej}}^{2}}$

##### 3.6.5.2 Linear combination COMB_DDS_CORRELE = ‘LINE’

${R}_{e}=\sum_{j=1}^{\mathit{nbA}}{R}_{\mathit{ej}}$

##### 3.6.5.3 Absolute-value combination COMB_DDS_CORRELE = ‘ABS’

${R}_{e}=\sum_{j=1}^{\mathit{nbA}}\left|{R}_{\mathit{ej}}\right|$

#### 3.6.6 Keyword CUMUL_INTRA

```text
◊    CUMUL_INTRA =     / 'LINE'  [DEFAUT]

                       / 'ABS'

                       / 'QUAD'
```

This keyword defines the rule for combining the modal responses corresponding to mode *i*.
Let *nbAm* be the number of supports in the m-th group of supports; the modal response of mode *i* for the group of correlated supports *m* is obtained by the following combination rules:

##### 3.6.6.1 Linear combination CUMUL_INTRA = ‘LINE’

$R_{d, m, i}=\sum_{n=1}^{nbAm} R_{d, m, i, n}$

##### 3.6.6.2 Absolute-value combination CUMUL_INTRA = ‘ABS’

$R_{d, m, i}=\sum_{n=1}^{nbAm} \left| R_{d, m, i, n} \right|$

##### 3.6.6.3 Quadratic combination CUMUL_INTRA = ‘QUAD’

$R_{d, m, i}=\sqrt{\sum_{n=1}^{nbAm} R_{d, m, i, n}^2}$

#### 3.6.7 Keyword CUMUL_INTER

```text
◊    CUMUL_INTER =     / 'QUAD' [DEFAUT]

                       / 'LINE'

                       / 'ABS'
```

This keyword defines the rule for combining the modal responses between the groups of supports.
Let *nbG* be the number of groups of supports and *d* the direction (d = X, Y, Z); the directional modal response is obtained by the following combination rules:

##### 3.6.7.1 Quadratic combination CUMUL_INTER = ‘QUAD’

$R_{d}=\sqrt{\sum_{m=1}^{nbG} R_{d, m}^2}$

##### 3.6.7.2 Linear combination CUMUL_INTER = ‘LINE’

$R_{d}= \sum_{m=1}^{nbG} R_{d, m}$

##### 3.6.7.3 Absolute-value combination CUMUL_INTER = ‘ABS’

$R_{d}= \sum_{m=1}^{nbG} \left| R_{d, m} \right|$

#### 3.8.1 Modal response TYPE = 'VALE_SPEC'

In single-support analysis, one can output the responses by mode and by direction:

${R}_{d,i,k}={r}_{i}{\lambda}_{i,k}\frac{\mathit{SA}({f}_{i},{\xi}_{i})}{{{\omega}_{i}}^{2}}$

where:

- ${r}_{i}$ modal response (eigenmode vector) of the i-th mode
- ${\lambda}_{i,k}$ modal participation factor of the i-th mode in the direction $k=X,Y,Z$
- $\mathit{SA}({f}_{i},{\xi}_{i})$ value read on the SRO at the frequency ${f}_{i}$ and at the damping ${\xi}_{i}$

In multi-support analysis, one can output the responses by mode, by support and by direction:

${R}_{d,i,n,k}={r}_{i}{\lambda}_{i,n,k}\frac{{\mathit{SA}}_{n}({f}_{i},{\xi}_{i})}{{{\omega}_{i}}^{2}}$

where:

- ${r}_{i}$ modal response (eigenmode vector) of the i-th mode
- ${\lambda}_{i,n,k}$ modal participation factor of the i-th mode for the motion at the n-th support in the direction $k=X,Y,Z$
- ${\mathit{SA}}_{n}({f}_{i},{\xi}_{i})$ value read on the SRO of the motion at the n-th support at the frequency ${f}_{i}$ and at the damping ${\xi}_{i}$

#### 3.8.4 Partition of the inertial components of the response and of those due to the DDS

For the seismic analysis of piping, the partition of the inertial components of the response and of those due to the DDS may prove necessary with a view to an RCC-M post-processing. It is possible to output these components for each direction as well as their combination by the rule COMB_DIRECTION = 'QUAD' (and only that).

```text
# Si TYPE        = 'VALE_INER', 'VALE_DDS':

♦    LIST_AXE    = l_axe
```

List of the axes concerned by the excitation described via a list composed of 'X', 'Y' and 'Z'.

##### 3.8.4.1 Inertial component: TYPE = 'VALE_INER'

For the direction $X$ , the directional inertial component is defined as follows:

${R}_{I,X}=\sqrt{{R}_{d,X}^{2}+{R}_{t,X}^{2}}$

- ${R}_{d,X}$ combined modal response of the modal oscillators for the direction $X$ (see u4.84.01-regles-combinaison)
- ${R}_{t,X}$ contribution of the static correction of the neglected modes (pseudo-mode) (see u4.84.01-regles-combinaison)

The inertial component is the result of the quadratic combination of the three directional inertial responses:

${R}_{I,\mathit{tot}}=\sqrt{{R}_{I,X}^{2}+{R}_{I,Y}^{2}+{R}_{I,Z}^{2}}$

##### 3.8.4.2 Component due to the DDS: TYPE = 'VALE_DDS'

This is the static response induced by the seismic differential displacements of the anchorages (driving motion), only in the multi-support case. For the single-support case, this component is considered to be zero.

For the direction $X$ , the directional component of the response due to the DDS is defined as presented in u4.84.01-multi-appui.

The component due to the DDS is the result of the quadratic combination of the three directions:

${R}_{E,\mathit{tot}}=\sqrt{{R}_{e,X}^{2}+{R}_{e,Y}^{2}+{R}_{e,Z}^{2}}$

It is recalled that the intra-group combination of the responses to the DDS is carried out according to the rule defined by the user via COMB_DDS_CORRELE (see u4.84.01-combinaison-valeur-absolue), whereas the inter-group combination is quadratic, with no choice left to the user.

#### 3.8.5 Partition of the dynamic and quasi-static contributions

It is possible to output these parts for each direction as well as their combination by the rule COMB_DIRECTION = 'QUAD' (and only that).

```text
# Si TYPE        = 'VALE_DYNA', 'VALE_QS':

♦    LIST_AXE    = l_axe
```

List of the axes concerned by the excitation described via a list composed of 'X', 'Y' and 'Z'.

##### 3.8.5.1 Dynamic part: TYPE = 'VALE_DYNA'

For the direction $X$ , the directional dynamic part ${R}_{d,X}$ is defined as the combined modal response of the modal oscillators for the direction $X$ (see u4.84.01-regles-combinaison).

The dynamic part is the result of the quadratic combination of the three directional dynamic responses:

${R}_{d,\mathit{tot}}=\sqrt{{R}_{d,X}^{2}+{R}_{d,Y}^{2}+{R}_{d,Z}^{2}}$

##### 3.8.5.2 Quasi-static part: TYPE = 'VALE_QS'

For the direction $X$ , the directional quasi-static part ${R}_{t,X}$ is defined as the contribution of the static correction of the neglected modes (pseudo-mode) (see u4.84.01-regles-combinaison).

The quasi-static part is the result of the quadratic combination of the three directional quasi-static responses:

${R}_{t,\mathit{tot}}=\sqrt{{R}_{t,X}^{2}+{R}_{t,Y}^{2}+{R}_{t,Z}^{2}}$
