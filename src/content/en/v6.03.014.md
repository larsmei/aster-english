# v6.03.014 SSNP14 - Traction-slicing plate - Von Plating (Cinematic hardening)

**Summary:**

This $\mathrm{2D}$ quasi-static flat stress test, which comes from the VPCS guide, is part of the validation of elasto-plastic behavior relationships. A element volume, made of a plastic material with linear kinematic nutring, is subjected to both tensile and shearing forces.

The main interest of this test is the non-radial nature of the load.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The stress is fixed by the loading path (stressed steering), i.e.:

$\sigma =\left[\begin{array}{ccc}{\sigma}^{D}& {\tau}^{D}& 0\\ {\tau}^{D}& 0& 0\\ 0& 0& 0\end{array}\right]$

The elastic part of the deformation is derived from:

${\varepsilon}^{e}=\frac{1}{E}\left[\begin{array}{ccc}{\sigma}^{D}& (1+\nu ){\tau}^{D}& 0\\ (1+\nu ){\tau}^{D}& -\nu {\sigma}^{D}& 0\\ 0& 0& -\nu {\sigma}^{D}\end{array}\right]$

If it is now assumed that $\varepsilon$ is known to be the total deformation, then the plastic deformation can be deduced: ${\varepsilon}^{p}=\varepsilon -{\varepsilon}^{e}$

Note:

${\varepsilon}_{xx}^{p}+{\varepsilon}_{yy}^{p}+{\varepsilon}_{zz}^{p}=0$ *and* ${\varepsilon}_{yy}^{p}={\varepsilon}_{zz}^{p}$ *so* ${\varepsilon}_{yy}^{p}={\varepsilon}_{zz}^{p}=\frac{-{\varepsilon}_{xx}^{p}}{2}$

then the reminder constraint:

$\chi =C{\varepsilon}^{p}$ with $\frac{2}{3C}=\frac{1}{{E}^{T}}-\frac{1}{E}$ with $C$: Prager constant

In addition, to obtain correct accuracy, a large number of increments must be used for the $\mathit{AB}$ route, in this case at least 30 in this case. Similarly for the $\mathrm{BC}$ route.

### 2.2 Baseline

The total $\varepsilon$ deformation data is required for the previous calculations and is obtained as an average of the results of several codes.
