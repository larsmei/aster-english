# 1 **v6.04.206** SSNV206 - Triaxial test: LETK, LKR and NLH_CSRM models

**Summary**

This test is used to validate the LETK, LKR and NLH_CSRM models in rock mechanics. This is a triaxial test in pure mechanics or drained conditions. The calculations are performed only on the solid part of the soil without hydromechanical coupling. A containment level of $5\mathit{MPa}$ is applied. Due to symmetry, one only cares about the eighth of a sample subjected to a triaxial test. The Modelling is axisymmetric.

## 1 Description of modellings

- Modelling A: The local model integration algorithm is explicit, classified as specific later: LETK model.
- Modelling B: The local model integration algorithm is implicit with the local jacobian matrix obtained by disturbance: model LETK.
- Modelling C: The local model integration algorithm is implicit with the local jacobian matrix obtained analytically: LETK model.
- Modelling D: The local model integration algorithm is explicit, classified as specific afterwards. The load is applied 100 times slower to highlight the role of viscosity in the model: model LETK.
- Modelling E: The local model integration algorithm is implicit with the local jacobian matrix obtained analytically. The load is applied 100 times slower to highlight the role of viscosity in the model: model LETK.
- Modelling G: The local model integration algorithm is implicit with the local jacobian matrix obtained by disturbance, no temperature imposed: modelLKR.
- Modelling H: The local model integration algorithm is implicit with the local jacobian matrix obtained analytically, no temperature imposed, no coupling between the plastic and viscoplastic mechanisms (COUPLAGE_P_VP = 0.): model LKR.
- Modelling J: The local model integration algorithm is implicit with the local jacobian matrix obtained analytically, increasing temperature (0°C-100°C) imposed via AFFE_VARC: model LKR.
- Modelling L: The local model integration algorithm is implicit with the local jacobian matrix obtained analytically. The load is applied 100 times slower to highlight the role of viscosity in the model, no temperature imposed: model LKR.
- Modelling M: validation of the NLH_CSRM model. The test is performed in the international unit system.

These are non-regression tests. The 13 modellings converge to match solutions for fine discretizations of the applied load.

### 2.5 Initial conditions, boundary conditions, and loading

**Phase 1:**

The sample is taken to a homogeneous state: ${\sigma}_{xx}^{0}={\sigma}_{yy}^{0}={\sigma}_{zz}^{0}$ , by imposing the corresponding containment pressure on the front, right side and upper side. The movements are blocked on the rear (${u}_{x}=0$ ), left side (${u}_{y}=0$ ) and lower (${u}_{z}=0$ ) faces.

**Phase 2:**

The blocked movements on the rear (${u}_{x}=0$), left (${u}_{y}=0$) and lower (${u}_{z}=0$) sides are maintained, as well as the containment pressure on the front and right side. A displacement is applied to the upper face: ${u}_{z}(t)$ , so that ${\epsilon}_{zz}=-6\text{\%}$ deformation is achieved over a 6e3 seconds duration for modellings A, B, C, F, G, H, I and J and a 6e5 seconds duration for modellings D, E, K and L.

For modellings I and J, increasing temperature is imposed in phases 1 and 2 via factor keyword AFFE_VARC. The temperature is increased from 0°C to 50°C during phase 1 and from 50°C to 100°C during phase 2.

For Modelling M, the deformation at the end of the test is 100 times higher than that obtained at the end of the containment phase: -0.00028571428571428574* 100.

## 3 Reference solutions

Reference solutions are obtained by fine discretization of the load. There are no known analytical solutions for the integration of the modelsLETK, LKR and KH_CSRM according to a triaxial compression test.

## 14 Summary of the results

These are non-regression tests developed to validate the LETK model in pure mechanics. Comparison between the two integration schemes allows to identify certain trends on convergence profiles.

An explicit integration scheme allows for fine discretization of the load to guarantee converged results and a lower machine run time than the implicit scheme. However, it is difficult to quantify the level of finesse of the load to be applied to ensure the convergence of studies with an explicit integration scheme.

The implicit integration scheme ensures a level of accuracy higher than the explicit scheme for the same load discretization. It also allows for a local tangential operator to be available. These advantages thus ensure that on a wide range of load discretizations a convergence on the results obtained with the implicit scheme is ensured.
