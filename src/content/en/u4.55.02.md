# u4.55.02 Operator RESOUDRE

## 1 Purpose

Solve a system of linear equations (direct or iterative method)

The solution methods implemented in *Code_Aster* and usable by this command are:

1. the MULT_FRONT method (direct method),
2. the LDLT method (direct method),
3. the MUMPS method (direct method),
4. the GCPC method (iterative method),
5. the PETSC method (iterative method).

The effective choice of the method is made through the command FACTORISER [U4.55.01](doc:u4.55.01).

For the direct methods, the matrix must have been factorised beforehand by the command FACTORISER [U4.55.01](doc:u4.55.01). In the case of the iterative methods with preconditioning, the preconditioning matrix is also supplied by the operator FACTORISER [U4.55.01](doc:u4.55.01).

The operator allows complex solutions for the "direct" methods (not for the iterative methods).

Produces a data structure of type cham_no.

## 2 Syntax

```text
cham_no = RESOUDRE(
    ◇ reuse = <objet de CHAM_NO>,
    ◆ MATR = matr_asse_depl_c / matr_asse_depl_r / matr_asse_pres_c / matr_asse_pres_r / matr_asse_temp_c / matr_asse_temp_r,
    ◆ CHAM_NO = cham_no,
    ◇ CHAM_CINE = cham_no,
    ◇ RESI_RELA = float (défaut: 1e-06),
    ◇ POSTTRAITEMENTS = / "AUTO" (par défaut),
                        / "FORCE",
                        / "MINI",
                        / "SANS",
    ◇ NMAX_ITER = int (défaut: 0),
    ◇ MATR_PREC = matr_asse_depl_r / matr_asse_pres_r / matr_asse_temp_r,
    ◇ ALGORITHME = / "CG",
                   / "CR",
                   / "FGMRES" (par défaut),
                   / "GCR",
                   / "GMRES",
    ◇ TITRE = text,
    ◇ INFO = / 1,
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 General points

This command makes it possible to solve:

    - by a direct method, the linear system $\mathrm{AX}=B$ , where $A$ is a matrix previously “factorised” by the command FACTORISER [U4.51.01.],
    - by an iterative method (GCPC or PETSC), the linear system ${P}^{-1}\mathrm{AX}={P}^{-1}B$ , where ${P}^{-1}$ is a preconditioning matrix determined by the command FACTORISER [U4.51.01](doc:u4.51.01) and $A$ the initial assembled matrix.

The solution is possible for Dirichlet boundary conditions (kinematic boundary conditions), whether dualised or eliminated [U2.01.02](doc:u2.01.02). In the latter case, if the loading $\mathrm{X}={\mathrm{X}}_{0}$ on the “edge” ${\Gamma}_{0}$ is applied with a kinematic load (operator AFFE_CHAR_CINE [U4.44.03](doc:u4.44.03)) taken into account in the assembled matrix (operator ASSE_MATRICE [U4.61.22](doc:u4.61.22)), the “value” of this loading $({X}_{0})$ , computed by the operator CALC_CHAR_CINE [U4.61.03](doc:u4.61.03), must be supplied by the keyword CHAM_CINE.

## 4 Operands

### 4.1 Operand MATR

```text
♦    MATR    =    A,
```

Name of the matrix of the system to be solved:

      - For the direct methods, one supplies to MATR the concept modified by the operator FACTORISER; this matrix may be real or complex, symmetric or not.
      - For the iterative methods, one supplies to MATR the initial matrix. The preconditioning matrix is to be supplied with the keyword MATR_PREC.

### 4.2 Operand CHAM_NO

```text
♦    CHAM_NO    =    B,
```

Name of the right-hand side vector (in general obtained by the command ASSE_VECTEUR).

### 4.3 Operand CHAM_CINE

```text
◊    CHAM_CINE =    vcine,
```

Name of the vector representing the “value” of the eliminated Dirichlet boundary conditions (that is, applied with one of the commands AFFE_CHAR_CINE or AFFE_CHAR_CINE_F).

This cham_no comes from the execution of the operator CALC_CHAR_CINE on the list of char_cine (kinematic loadings) associated with the assembled matrix A [U2.01.02](doc:u2.01.02).

### 4.4 Operand ALGORITHME

```text
◊    ALGORITHME = / 'GMRES'     [DEFAUT]
/ 'CG'
/ 'CR'
/ 'GCR'

Ce mot clé sert à choisir l'algorithme de la méthode itérative PETSC. Les différents algorithmes disponibles sont documentés dans le mot-clé SOLVEUR[U4.50.01].
```

### 4.5 Operand MATR_PREC

```text
◊    MATR_PREC    =    precond
```

Preconditioning matrix, obtained by the operator FACTORISER [U4.55.01](doc:u4.55.01).

Preconditioning is necessary in the iterative methods in order to obtain good convergence with a minimum of iterations.

With the GCPC method, the preconditioning matrix is a matrix distinct from the matrix of the problem (keyword MATR).

On the other hand, with the PETSC method, one uses the same matrix for MATR_PREC and MATR, which means that the command FACTORISER must be done “in place” (with the keyword reuse). See the example below.

### 4.6 Operand RESI_RELA

```text
◊    RESI_RELA =     /    1.e-6,                [DEFAUT]
/    eps    ,                [R]
```

This keyword is described in [U4.50.01](doc:u4.50.01)

For the iterative methods GCPC and PETSC, this is the convergence criterion of the algorithm.

For the MUMPS method, this keyword makes it possible to check the quality of the solution.

### 4.7 Operand NMAX_ITER

```text
◊    NMAX_ITER    =    niter
```

Maximum number of iterations of the iterative algorithm.

If niter = 0 then the algorithm chooses a default number of iterations.

### 4.8 Operand TITRE

```text
◊    TITRE    =    titr ,
```

Title which one wants to give to the result produced [U4.03.01](doc:u4.03.01).

### 4.9 Operand INFO

```text
◊    INFO    =
```

1: no printout.

2: printouts

## 5 Examples

### 5.1 Solution by the direct method MULT_FRONT

- Building of the assembled matrix and of the right-hand side:

The elementary terms KEL, FEL have been computed beforehand.

```text
NU    =NUME_DDL( MATR_RIGI=KEL )
K    =ASSE_MATRICE( MATR_ELEM=KEL,    NUME_DDL=NU, )
F    =ASSE_VECTEUR( MATR_ELEM=FEL,    NUME_DDL=NU, )
```

- Factorisation:

```text
K    =FACTORISER( reuse=K,    MATR_ASSE=K, METHODE='MULT_FRONT',)
```

- Solution:

```text
U    =RESOUDRE( MATR=K,    CHAM_NO=F,)
```

- for the use of kinematic loads (with elimination of the imposed degrees of freedom), see the example given in the command AFFE_CHAR_CINE [U4.44.03](doc:u4.44.03).

### 5.2 Solution by the MUMPS method

```text
NU        =    NUME_DDL( MATR_RIGI= KEL)

K        =    ASSE_MATRICE    (    MATR_ELEM= KEL, NUME_DDL= NU)

F        =    ASSE_VECTEUR    (    VECT_ELEM= FEL, NUME_DDL= NU )

K        =    FACTORISER    (    reuse= K, MATR_ASSE= K, METHODE= 'MUMPS' )

dep        =    RESOUDRE        (    CHAM_NO = F    ,    MATR= K)
```

### 5.3 Solution by the preconditioned conjugate gradient method

```text
NU        =    NUME_DDL( MATR_RIGI= KEL)

K        =    ASSE_MATRICE    (    MATR_ELEM= KEL, NUME_DDL= NU )

F        =    ASSE_VECTEUR    (    VECT_ELEM= FEL, NUME_DDL= NU )

KPREC    =    FACTORISER    (    MATR_ASSE= K, METHODE= 'GCPC',
PRE_COND='LDLT_INC' )

dep        =    RESOUDRE        (    CHAM_NO = F    ,    MATR= K, MATR_PREC= KPREC,
NMAX_ITER= 1000    ,    RESI_RELA= 1e-07
)
```

### 5.4 Solution by the PETSC method

```text
NU        =    NUME_DDL( MATR_RIGI= KEL)

K        =    ASSE_MATRICE    (    MATR_ELEM= KEL, NUME_DDL= NU )

F        =    ASSE_VECTEUR    (    VECT_ELEM= FEL, NUME_DDL= NU )

K        =    FACTORISER    (    reuse=K, MATR_ASSE= K, METHODE= 'PETSC')

dep        =    RESOUDRE        (    CHAM_NO = F    ,    MATR= K, MATR_PREC= K,
ALGORITHME='GMRES',
NMAX_ITER= 1000    ,    RESI_RELA= 1e-07)
```
