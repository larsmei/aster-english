# 1 **v4.01.004** TPLA04 - Power flow in a hollow cylinder

**Summary:**

This test is based on independent validation of version 3 in linear steady-state thermal analysis.

It includes 2D axisymmetric Modelling that tests elements axisymmetric in thermal, boundary conditions in temperature imposed and boundary conditions in heat source.

The objective of this test is to validate the heat source by comparing the results obtained with those provided by VPCS.

## 1 Reference problem

### 1.1 Geometry

| Internal radius | ${R}_{i}=\mathrm{1m}$ |
| --- | --- |
| Outside radius | ${R}_{e}=\mathrm{2m}$ |
| Length | $l$ |

### 1.2 Material properties

$$
\lambda =1.0W/m°C
$$

### 1.3 Boundary conditions and loads

- Temperatures imposed:

| Interior surface area: | ${T}_{i}=T(r={R}_{i})=20°C$ |
| --- | --- |
| Outer surface: | ${T}_{e}=T(r={R}_{e})=20°C$ |

- Unstable power output $Q=\mathrm{100W}/{m}^{3}$

### 1.4 Initial conditions

Not applicable.

## 2 reference solution

### 2.1 Calculation method used for reference solution

The reference solution is the one given in the TPLA04/89 plug in the VPCS guide.

- Temperature as $r$:

$T(r)={T}_{i}+\frac{Q}{4\lambda }\left[({R}_{e}^{2}-{R}_{i}^{2})\frac{\ln(\frac{r}{{R}_{i}})}{\ln(\frac{{R}_{e}}{{R}_{i}})}-({r}^{2}-{R}_{i}^{2})\right]$

- Flow density as a function of $r$:

$\Phi (r)=-\lambda \frac{\mathrm{dT}}{\mathrm{dr}}=-\frac{Q}{4r}\left[\frac{({R}_{e}^{2}-{R}_{i}^{2})}{\ln(\frac{{R}_{e}}{{R}_{i}})}-{\mathrm{2r}}^{2}\right]$

The cylinder is supposed to be infinitely long ($l\gg {R}_{e}$ )

### 2.2 Baseline

Temperature and flow density for $r=1.0,1.2\text{et}1.5$

### 2.3 Uncertainty about the solution

analytical solution.

## 4 Summary of the results

The results obtained are very satisfactory. the difference maximum is -0.008% in temperature and 0.316% in flux.

This test tested the inclusion of a source term in mesh cells QUAD9 with AXIS Modelling (AFFE_CHAR_THER associated with the SOURCE keyword).
