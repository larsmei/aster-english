# v1.01.257 ZZZZ257 - Error Estimator in Interest Quantity for Breaking Mechanics

**Summary:**

This test validates the error estimate in quantity of interest for the break mechanics. Thus, the 3 methods available in *Code_Aster* (residues, smoothing $\mathrm{ZZ1}$ and smoothing $\mathrm{ZZ2}$) are tested. In addition, the command files give a pattern for the implementation of the error estimate in quantity of interest and more specifically the definition of the load for the dual problem.

There are 3 modellings that have 3 different problems:

- Modelization A: cracked plate subjected to a uniform tensile force;
- Modelization B: cantilever beam subjected to shearing effort;
- Modelization C: plate with an inclined crack, subjected to a tensile force.

## 1 Reference problem

### 1.1 Geometry

In this test, three cracked plate configurations are considered. The first problem is a cracked plate subjected to a uniform tensile force (solicitation in $I$ mode). The second problem is a cantilever beam subjected to shearing effort (solicitation in $I$ mode and $\mathrm{II}$ mode). Finally, the third problem is a plate with an inclined crack, subject to tensile force (solicitation in $I$ mode and $\mathrm{II}$ mode).

The geometrical parameters are as follows:

- $L/b=16/7$ ;
- $h=L/2$ ;
- $a/b=1/2$ ;
- $L=16$ ;
- $\theta =60\text{°}$ .

The following shall be defined:

- mesh-cell group $\mathrm{HAUT}$ as the upper edge;
- the group of mesh cell $\mathrm{BAS}$ as the lower edge;
- the node $\mathrm{FONDFISS}$ group (one node) as the crack bottom;
- the node $\mathrm{BLOCAGE}$ group (one node) as the intersection of the crack extension and the right edge.

In addition, for calculating error in quantity of interest, it is necessary to define another problem (the dual problem) which differs from the original problem only by Neuman's conditions (the rigidity matrix and Dirichlet's conditions are the same). The specific loading of the dual problem in the context of the error estimation on stress intensity factors must be defined by means of functions to be imposed on the lips of the crack. To know how to define this load and how to impose it, we can refer on the one hand to the command files and on the other hand to the reference documentation on the error estimate in quantity of interest [R4.10.06](doc:r4.10.06).

### 1.2 Material properties

- Young's modulus: $E=200000\text{MPa}$
- Poisson's ratio: $\nu =0.3$

### 1.3 Boundary conditions and loads

Problem 1:

  - Mesh cell $\mathrm{HAUT}$ Group: $\mathrm{FY}=1$
  - Mesh cell $\mathrm{BAS}$ Group: $\mathrm{FY}=-1$
  - node $\mathrm{FONDFISS}$ : $\mathrm{DY}=0$
  - node $\mathrm{BLOCAGE}$ : $\mathrm{DX}=\mathrm{DY}=0$

Problem 2:

  - Mesh cell $\mathrm{HAUT}$ Group: $\mathrm{FX}=1$
  - Mesh cell $\mathrm{BAS}$ Group: $\mathrm{DX}=\mathrm{DY}=0$

Problem 3:

  - Mesh cell $\mathrm{HAUT}$ Group: $\mathrm{FY}=1$
  - Mesh cell $\mathrm{BAS}$ Group: $\mathrm{FY}=-1$
  - node $\mathrm{FONDFISS}$ : $\mathrm{DY}=0$
  - node $\mathrm{BLOCAGE}$ : $\mathrm{DX}=\mathrm{DY}=0$

## 2 reference solution

### 2.1 Method of calculation

The reference solutions for stress intensity factors are derived from the "Stress Intensity Factors Handbook" by Murakami [bib1]. Reference solutions for error estimation are solutions of non-regression. Error estimators have been validated in J. Delmas's thesis [bib2].

### 2.2 Quantities and reference results

Reference results for stress intensity factors are:

  1. Delmas, "Strategies of Error Controls in the Calculation of Industrial Structures. Implementation of Error Estimation in Amount of Interest and Adaptation of mesh", PhD Thesis, University of Picardie Jules Verne, 2008.

## 3 Modelling A

### 3.1 Modelling characteristics

The Modelling used is C_PLAN Modelling.

### 3.2 Mesh characteristics

The mesh is made up of 240 linear triangles. The mesh is converted into mesh quadratic in the command file. In addition, elements in the crack bottom is transformed into elements from Barsoum.
