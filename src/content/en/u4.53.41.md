# u4.53.41 Operator CALC_ERC_DYN

## 1 Purpose

For the case of linear dynamics, it makes it possible to obtain the solution fields of a problem of minimisation of an energy functional of constitutive-relation error type (ERC) in a modal formulation.

Furthermore, it makes it possible to evaluate the error functional for the solution fields.

Produces a data structure of type mode_meca.

## 3 Reminders

### 3.1 Optimisation problem associated with an energy functional

This operator solves the following problem:

Find the triplet of admissible fields $(u,v,w)\text{}$ which minimises the functional:

${e}_{\omega}^{2}(u,v,w)=\frac{\gamma}{2}{(u-v)}^{T}[K](u-v)+\frac{1-\gamma }{2}{(u-w)}^{T}{\omega}^{2}[M](u-w)+\frac{1-\alpha }{\alpha}{(\mathit{Hu}-\widehat{u})}^{T}\text{}[\mathit{Gr}](\mathit{Hu}-\widehat{u})$

under the constraint:

$\left[K\right]v-{\omega}^{2}\left[M\right]\text{w=}0$

Where:

$K$ represents a real stiffness matrix

$M$ represents a mass matrix

$H$ represents an observation matrix

$\mathit{Gr}$ represents a symmetric positive-definite matrix serving as the norm of the errors in the observation space

$\omega =2\pi f$ : excitation angular frequency

$\widehat{u}$ observation of the displacements at the angular frequency $\omega$

$\gamma$ weighting parameter of the errors $(u-v)$ and $(u-w)$

$\alpha$ weighting parameter of the functional, which can be likened to a regularisation term

### 3.2 Equations for the solution of the problem

Obtaining the triplet $(u,v,w)\text{}$ associated with the constrained problem above leads, at each frequency considered, to the solution of the following system of linear equations:

$Al=b$

with, for each natural angular frequency ${\omega}_{i}$ :

${A}_{i}=\left(\begin{array}{cc}\gamma \left(\text{K+γ}/\left(1-\gamma \right){\omega}_{i}^{2}M\right)& -\gamma \left(K-{\omega}_{i}^{2}M\right)\\ -\gamma \left(K-{\omega}_{i}^{2}M\right)& \left(-\text{2α}/\left(1-\alpha \right)\right){H}^{T}{G}_{r}H\end{array}\right)$ ; and ${b}_{i}=\left(\begin{array}{c}{0}_{n}\\ \left(-\text{2α}/\left(1-\alpha \right)\right){H}^{T}{G}_{r}{\widehat{u}}_{i}\end{array}\right)$

For further details on the formulation, one should refer to the document [R4.10.07](doc:r4.10.07).

## 4 Operands

### 4.1 Operand MATR_MASS

```text
♦    MATR_MASS = m
```

Name of the assembled-matrix concept corresponding to the mass matrix of the system.

### 4.2 Operand MATR_RIGI

```text
♦    MATR_RIGI = k
```

Name of the assembled-matrix concept corresponding to the stiffness matrix of the system.

### 4.3 Operand MATR_NORME

```text
♦    MATR_NORME = g
```

Name of the assembled generalised-matrix concept corresponding to the symmetric positive-definite matrix serving as the norm of the errors in the observation space.

### 4.4 Operand MATR_PROJECTION

```text
♦    MATR_PROJECTION = h
```

Name of the projection matrix making it possible to establish the geometric correspondence between the mesh associated with the mass and stiffness matrices on the one hand, and the mesh associated with the observations $\widehat{u}$ on the other hand.

The projection matrix h must come from an analysis with the operator PROJ_CHAMP [U4.72.05](doc:u4.72.05) with the method 'COLLOCATION'.

### 4.5 Operand MESURE

```text
♦    MESURE = me
```

Name of the concept of type mode_meca or dyna_harmo containing the fields which will be used as the observation. This concept must contain as many order numbers as the number of frequencies which will be studied when the operator is called (operands FREQ/LIST_FREQ).

Furthermore, the fields contained in me must not include degrees of freedom of Lagrange type.

The dimension of the fields contained in this concept must be consistent with the dimension of the norm matrix g supplied under the operand MATR_NORME.

The use of the operator OBSERVATION [U4.90.03](doc:u4.90.03) may be an appropriate means of conditioning a concept of type mode_meca or dyna_harmo as the measurement me.

### 4.10 Operand ALPHA

```text
♦    ALPHA        =    al,
```

Value of the weighting parameter of the functional, which can be likened to the regularisation term.

### 4.11 Operand GAMMA

```text
♦    GAMMA        =    ga,
```

Value of the weighting parameter of the errors $(u-v)$ and $(u-w)$ of the functional.

### 4.12 Operand EVAL_FONC

> ◊    EVAL_FONC        =    |     'OUI',        [DEFAUT]

```text
|    'NON',
```

Choice determining whether the value of the functional for the optimal triplet of fields will be evaluated and stored in the result.

If so, the operator will store the computed values under the dedicated parameter 'ERC_EVAL_FONC'.

The value of 'ERC_EVAL_FONC' is stored in the following way in the output concept of type mode_meca:

For the i-th analysis frequency, two values of 'ERC_EVAL_FONC' are stored:

- in the (2*(i-1)+1)-th nume_ordre of the output concept one stores the value of ${e}_{{\omega}_{i}}^{2}(u,v,w)$
- in the (2*(i-1)+2)-th nume_ordre of the output concept one stores the value associated with the term of the error fields $(u-v)$ and $(u-w)$ as follows:

$\frac{\gamma}{2}{(u-v)}^{T}[K](u-v)+\frac{1-\gamma }{2}{(u-w)}^{T}{\omega}^{2}[M](u-w)$

### 4.13 Operands SOLVEUR

```text
◊    SOLVEUR
```

This factor keyword is optional. It makes it possible to define the method of solution of the system. The syntax is described in the document [U4.50.01](doc:u4.50.01).

In the current version, the solvers available are MUMPS (default) and LDLT.

## 5 Storage of the solution fields

The operator CALC_ERC_DYN produces a result concept of type mode_meca.

At each required frequency, it computes the solution fields $u$ and $(u-v)$, which are stored in the following way:

For the i-th analysis frequency, the following are stored:

- in the (2*(i-1)+1)-th nume_ordre of the output concept the field $u$ is stored
- in the (2*(i-1)+2)-th nume_ordre of the output concept the field $(u-v)$ is stored

It is recalled that the field $(u-w)$ is not computed directly, because it can be obtained by the scalar relation:

$(u-w)=\frac{-\gamma }{1-\gamma }(u-v)$
