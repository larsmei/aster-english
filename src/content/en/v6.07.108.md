# v6.07.108 COMP008 – Thermo-mechanical validation of elasto-plastic laws

**Summary**

This test validates the temperature variation in the elastoplastic constitutive laws. These tests allow to check the following two points:

- Thermal expansion is well calculated (with consideration of the variation of thermal expansion with temperature)
- The variation of material coefficients with temperature is correct, especially in incremental behavior resolution,

The validated laws of behaviour are as follows:

- $A$ Modelling: this Modelling allows to validate the ELAS model with isotropic material
- $B$ Modelling: this Modelling allows to validate the ELAS model with orthotropic material,
- $C$ Modelling: this Modelling allows to validate the VMIS_ISOT_LINE model,
- $D$ Modelling: this Modelling allows to validate the VMIS_CINE_LINE model,
- $E$ Modelling: this Modelling allows to validate the VENDOCHAB model,
- $F$ Modelling: this Modelling allows to validate the VMIS_ECMI_LINE model,
- $G$ Modelling: this Modelling allows to validate the VMIS_CIN1_CHAB model,
- $H$ Modelling: this Modelling allows to validate the VMIS_CIN2_CHAB model,
- $I$ Modelling: this Modelling allows to validate the VMIS_CIN2_MEMO model,
- $J$ Modelling: this Modelling allows to validate the VISC_CIN1_CHAB model,
- $K$ Modelling: this Modelling allows to validate the VISC_CIN2_CHAB model,
- $L$ Modelling: this Modelling allows to validate the VISC_CIN2_MEMO model,
- $M$ modelling: this model validates the transverse isotropic elasticity,
- $N$ Modelling: This Modelling allows to validate the ROUSS_PR model.
- $O$ Modelling: This Modelling allows to validate the VMIS_JOHN_COOK model.

## 1 Methodology

It is a double simulation, the first in thermo-mechanical, the second in pure mechanics. The first will be validated in comparison with the second, assuming of course that the behaviour tested provides a correct solution in pure mechanics.

### 1.1 Simulation 1

The first simulation (solution that is being validated) is to apply a temperature variation to a material point, blocking the deformations following $x$: ${\varepsilon}_{xx}=0$ . The temperature imposed is increasing linearly with time.

Unless otherwise stated, the temperature varies from ${T}_{0}=20°C$ to ${T}_{\max}=500°C$. Material parameters are chosen for part of the transient to be in the nonlinear domain of the constitutive law, except in elasticity. The transient is made up of NCAL not. The reference temperature is ${T}_{\mathrm{Ref}}={T}_{0}$.

### 1.2 Simulation 2

The second simulation (which must be equivalent to the first) consists of applying, in pure mechanics, without thermal, and at each moment, a deformation imposed according to $x$ equivalent to the thermal deformation of the first simulation: This is therefore to perform a loop on NCAL mechanical calculations. At each $i$ calculation, the imposed load consists of the thermal deformation ${\varepsilon}_{xx}=-{\varepsilon}_{\mathrm{th}}=-\alpha (T)({T}_{i}-{T}_{\mathrm{Ref}})$. The initial load consists of the deformations, stresses and internal variables of the previous mechanical calculation.

> Indeed, for any behavior (assuming the additive decomposition of deformations):

${\sigma}_{xx}=E(T)({\varepsilon}_{xx}-{\varepsilon}^{\mathrm{th}}-{\varepsilon}_{xx}^{p})$

in the first case, ${\sigma}_{xx}=E(T)(0-{\varepsilon}^{\mathrm{th}}-{\varepsilon}_{xx}^{p})$, and in the second: ${\sigma}_{xx}=E(T)(\varepsilon -{\varepsilon}_{xx}^{p})$.

Therefore, at every moment, you can apply ${\varepsilon}_{xx}=-{\varepsilon}^{\mathrm{th}}=-\alpha (T)(T-{T}_{\mathrm{ref}})$ for mechanical calculation.

In addition, to obtain the same results in both cases, it is necessary, at each time step of the second simulation, to perform the pure mechanical calculation with coefficients whose values are interpolated according to the temperature at the current moment. This interpolation is performed in the command file of the test, in a loop in outside time at STAT_NON_LINE.

## 2 Interpretation of results

The purpose of this test is to verify that the result obtained at each moment of the thermomechanical transient of the first simulation is identical to the result obtained with the second simulation:

- the value to be tested is the component of the extracted field at a given moment $i$ of the first thermo-mechanical simulation performed on NCAL moments.
- the reference value is that obtained for the mechanical calculation
