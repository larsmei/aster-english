# v1.01.266 ZZZZ266 - Validation of COOR_ELGA option

**Summary:**

This test is valid in $\mathrm{2D}$ and $\mathrm{3D}$ for calculating the coordinates of Gauss' point using the CALC_CHAM_ELEM command.

Modelization A:

The principle is to read the mesh with the LIRE_MAILLAGE command, assign a model using the AFFE_MODELE command and calculate the coordinates of the point of Gauss using the COOR_ELGA option of the CALC_CHAM_ELEM command. There is therefore no uncertainty about the results to be obtained:

- For a discrete type "POI1" the Gauss point is in the same position as the node.
- For a discrete type "SEG2" the Gauss point is in the middle of the segment.

Modelling B:

This is the same approach but for different modellings:

- For elements in flat deformations.
- For elements in flat constraints.
- For the elements onboard in three-dimensional Modelling (faces and segments).
- For elements with 2D_FLUIDE Modelling (U_P and U_P_PHI)

This documentation is deliberately succinct.
