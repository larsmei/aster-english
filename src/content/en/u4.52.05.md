# u4.52.05 Operator MODE_ITER_CYCL

## 1 Purpose

Compute the eigenmodes of a structure with cyclic symmetry.

One computes the generalised components of the eigenmodes of the whole structure, by a cyclic substructuring method, from the modal base of a reference sector (cf [R4.06.03](doc:r4.06.03)). The axis of symmetry is the axis OZ. The modal base of the sector must be of type CLASSIQUE. The interfaces DROITE, GAUCHE and possibly AXE must be of the same type. The right and left sides are defined by the anticlockwise sense in the plane OXY.

Produces a data structure of type mode_cycl.

## 2 Syntax

```text
mode_cycl = MODE_ITER_CYCL(
    ◆ BASE_MODALE = mode_meca,
    ◇ NB_MODE = int,
    ◆ NB_SECTEUR = int,
    ◆ LIAISON = _F(
         ◆ DROITE = text,
         ◆ GAUCHE = text,
         ◇ AXE = text,
      ),
    ◇ VERI_CYCL = _F(
         ◇ PRECISION = float (défaut: 0.001),
         ◇ CRITERE = "RELATIF",
         ◇ DIST_REFE = float,
      ),
    ◆ CALCUL = _F(
         ◆ / TOUT_DIAM = "OUI" (ou non renseigné),
           / NB_DIAM = int,
         ◇ OPTION = / "PLUS_PETITE" (par défaut),
                    / "CENTRE",
                    / "BANDE",
         # Si: equal_to("OPTION", 'CENTRE')
             ◆ FREQ = float,
         # Si: equal_to("OPTION", 'BANDE')
             ◆ FREQ = float,
         ◇ NMAX_FREQ = int (défaut: 10),
         ◇ PREC_SEPARE = float (défaut: 100.0),
         ◇ PREC_AJUSTE = float (défaut: 1e-06),
         ◇ NMAX_ITER = int (défaut: 50),
      ),
    ◇ INFO = / 1 (par défaut),
             / 2,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand BASE_MODALE

```text
♦    BASE_MODALE= bamo
```

Name of the modal base of the sector built by DEFI_BASE_MODALE [U4.64.02](doc:u4.64.02).

### 3.2 Operand NB_MODE

```text
◊    NB_MODE= nbmo
```

Number of eigenmodes of the sector to be used for the cyclic analysis. By default, if the keyword does not appear, all the eigenmodes of the modal base are used.

### 3.3 Operand NB_SECTEUR

```text
♦    NB_SECTEUR= nbsec
```

Number of basic sectors required to build the global structure.

### 3.4 Keyword LIAISON

```text
♦    LIAISON
```

Factor keyword for the definition of the links between the sectors.

#### 3.4.1 Operands DROITE / GAUCHE / AXE

See [Figure 3.6-a].

```text
♦    DROITE    =    ’nom_int’
```

Name of the right interface of the sector.

```text
♦    GAUCHE    =    ’nom_int’
```

Name of the left interface of the sector.

```text
◊    AXE        =    ’nom_int’
```

Name of the interface of the axis of the sector.

These are points common to all the sectors.

### 3.5 Keyword CALCUL

```text
♦    CALCUL
```

Factor keyword for defining the search mode of the eigenmodes.

#### 3.5.1 Operands TOUT_DIAM / NB_DIAM

```text
◊    TOUT_DIAM    =    'OUI'
```

The modes associated with all the numbers of nodal diameters will be computed.

```text
◊    NB_DIAM    =    li
```

List of the numbers of nodal diameters to be computed. By default, all the possible numbers of nodal diameters are studied.

#### 3.5.2 Operand OPTION

```text
◊    OPTION=
```

| 'PLUS_PETITE': | compute, by an inverse-iteration method, the eigenmodes corresponding to the smallest frequencies for each number of diameters requested. |
| --- | --- |
| 'CENTRE': | compute the eigenmodes centred about a frequency requested by the keyword LIST_FREQ. |
| 'BANDE': | compute the eigenmodes between two frequencies given by the user by the keyword LIST_FREQ. The eigenfrequencies are separated by dichotomy and then the eigenmodes are computed by inverse iterations centred on the frequencies coming from the separation stage. |

#### 3.5.3 Operands FREQ / NMAX_FREQ

```text
◊    FREQ        =    lifreq
```

List of the frequencies whose use depends on the option chosen:

```text
OPTION    =    'BANDE'
```

One expects 2 values

![Figure](/figures/u4.52.05/Object_1.svg)

which define the band.

```text
OPTION    =    'CENTRE'
```

One expects 1 value, which is the central frequency of the interval.

```text
OPTION    =    'PLUS_PETITE'
```

One computes the smallest eigenfrequencies of the structure. By default, one computes the first 10. The keyword FREQ then has no meaning in this case; it does not have to be supplied.

```text
◊    NMAX_FREQ    =    nbfreq
```

Number of frequencies to be computed for each number of nodal diameters requested. If this keyword does not appear, one computes as many frequencies, for each nodal diameter, as there are eigenmodes used in the modal base (keyword NB_MODE).

#### 3.5.4 Operands PREC_SEPARE / PREC_AJUSTE / NMAX_ITER

```text
◊    PREC_SEPARE    =    pre_sep
```

Precision of separation of the frequencies for the option 'BANDE'.

```text
◊    PREC_AJUSTE    =    pre_ajus
```

Precision used for the computation of the modes (all OPTIONS).

```text
◊    NMAX_ITER        =    niter
```

Maximum number of inverse iterations (all OPTIONS).

### 3.6 Keyword VERI_CYCL

```text
♦    VERI_CYCL
```

Keyword for checking the consistency of the interfaces given in terms of cyclic repetitivity.

![Figure](/figures/u4.52.05/1000096A00002C2200000F9B40247FADF9EC8BF2.svg)

**Figure 3.6-a**

#### 3.6.1 Operands PRECISION / DIST_REFE

```text
◊    PRECISION    =    prec

◊    DIST_REFE    =    dist_ref
```

The consistency test between 2 contiguous sectors will be determined by the product prec*dist_ref. If DIST_REFE is not supplied, it will be computed automatically in proportion to prec and to a maximum coordinate value of a sector.

### 3.7 Operand INFO

```text
◊    INFO    =
```

Print level

| 1 | no printout, |
| --- | --- |
| 2 | writing of the frequencies and generalised parameters obtained and of the relative participations of the various modes of the base. |

## 4 Example of cyclic substructuring

```text
PLAQUE ANNULAIRE ENCASTREE SUR UN MOYEU - METHODE DE CRAIG-BAMPTON

secteur = LIRE_MAILLAGE        (    )

modele = AFFE_MODELE             (    MAILLAGE= secteur,
AFFE =_F(    TOUT    ='OUI',
PHENOMENE ='MECANIQUE',
MODELISATION='DKT')        )

mater = DEFI_MATERIAU        (ELAS =_F(E=2.E11, NU=0.3, RHO=7800.0)        )

chammat = AFFE_MATERIAU        (MAILLAGE= secteur,
AFFE =_F(TOUT ='OUI', MATER= mater)        )

chamcar = AFFE_CARA_ELEM    (MODELE = modele,
COQUE =(TOUT ='OUI', EPAIS= 0.001)    )

charge = AFFE_CHAR_MECA    (MODELE = modele
DDL_IMPO=(TOUT='OUI',DX=0.,DY=0.,DRZ=0.),
DDL_IMPO=(GROUP_NO=’AXE’,DZ=0.,DRX=0.,DRY=0.),
DDL_IMPO=(GROUP_NO=’DROIT’,DZ=0.,DRX=0.,DRY=0.),
DDL_IMPO=(GROUP_NO=’GAUCH’,DZ=0.,DRX=0.,DRY=0.))

#

#         CONSTRUCTION DES MATRICES DE RIGIDITE ET DE MASSE DU SECTEUR DE BASE

#

rigiele = CALC_MATR_ELEM     (MODELE = modèle,     CHARGE = charge,
CHAM_MATER= chammat,    CARA_ELEM = chamcar,
OPTION = 'RIGI_MECA'        )

massele = CALC_MATR_ELEM     (MODELE = modele,    CHARGE = charge,

CHAM_MATER= chammat,    CARA_ELEM = chamcar,

OPTION ='MASS_MECA'        )

numerot = NUME_DDL            (MATR_RIGI = rigiele            )

matrigi = ASSE_MATRICE        (MATR_ELEM = rigiele, NUME_DDL = numerot        )

matmass = ASSE_MATRICE        (MATR_ELEM = massele, NUME_DDL = numerot        )

#

#                     CALCUL DES MODES DYNAMIQUES DU SECTEUR DE BASE

#

modes = CALC_MODES (MATR_RIGI = matrigi,

MATR_MASS = matmass,

CALC_FREQ= _F(NMAX_FREQ= 15)    )

#

#         DEFINITION DES INTERFACES ET DES MODES STATIQUES ASSOCIES

#

lint = DEFI_INTERF_DYNA    (NUME_DDL = numerot, IMPR= 2,
INTERFACE= _F(NOM='DROITE', TYPE='CRAIGB',
GROUP_NO= ’DROIT’,
MASQUE= ('DX', 'DY', 'DRZ'), ),
INTERFACE= _F(NOM='GAUCHE', TYPE='CRAIGB',
GROUP_NO= ’GAUCH’,
MASQUE= ('DX', 'DY', 'DRZ') ) )

#

#         CALCUL DE LA BASE DE PROJECTION = RECUPERATION DES MODES DYNAMIQUES

# ET CALCUL DES MODES STATIQUES

bamo = DEFI_BASE_MODALE    (CLASSIQUE= _F(INTERF_DYNA= lint, IMPR= 2,
MODE_MECA = modes,
NMAX_MODE= 15 ) )

#

#                                 CALCUL DES MODES CYCLIQUES

#

modcyc = MODE_ITER_CYCL (BASE_MODALE= bamo, NB_MODE=15, NB_SECTEUR=18,

LIAISON=_F(DROITE= 'DROITE',    GAUCHE= 'GAUCHE'),

CALCUL =_F(NB_DIAM=(0, 1, 2, 3), NMAX_FREQ=2 ))
```
