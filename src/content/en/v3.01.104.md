# v3.01.104 SSLL104 - Pre-deformations in a straight beam

**Summary:**

This test validates the consideration of pre-deformations in the elastic calculation of an straight beam. The characteristics of the calculation are:

- static analysis,
- linear behaviour,
- Lineic model

Model A validates the consideration of value-based pre-deformations (AFFE_CHAR_MECA/PRE_EPSI) for elements POU_D_E, POU_D_T, POU_D_TG, POU_D_EM and POU_D_TGM. The solution is analytical.

Model B validates the consideration of function-indicated pre-deformations (AFFE_CHAR_MECA_F/PRE_EPSI) for elements POU_D_E, POU_D_T, POU_D_TG, POU_D_EM and POU_D_TGM. The reference solution is a calculation with value-indicated pre-deformations. It is specified that this loading is allowed for beam elements only if the value of the function to the two nodes of the same element is the same.

The C Modelling is valid for element BARRE, taking into account pre-deformations given by value, compared to element POU_D_E and taking into account pre-deformations given by function compared to a pre-deformation calculation given by value.

## 2 reference solution

### 2.1 Calculation method used for reference solution

**Model A:**

The solution is analytical, calculated in the local benchmark.

either:

$U=(u,v,w,{\theta}_{x},{\theta}_{y},{\theta}_{z})$ the displacement of the beam and $E=({\epsilon}_{x},{\chi }_{y},{\chi }_{z},{\gamma}_{xy},{\gamma}_{xz})$ the generalized deformation.

Or the solution:

$u=\alpha x$     $v=\gamma \frac{{x}^{2}}{2}$     $w=-\beta \frac{{x}^{2}}{2}$     ${\theta}_{x}=0$     ${\theta}_{y}=\beta x$     ${\theta}_{z}=\gamma x$

then:

${\epsilon}_{x}={u}_{,x}=\alpha$     ${\chi }_{y}={\theta}_{y,x}=\beta$     ${\chi }_{z}={\theta}_{z,x}=\gamma$     ${\gamma}_{xy}={v}_{,x}-{\theta}_{z}=0$     ${\gamma}_{xz}={w}_{,x}+{\theta}_{y}=0$

If you choose $\alpha ={\epsilon}_{X}(=0.001)$ , $\beta ={\chi }_{y}^{0}(=0.002)$ , $\gamma ={\chi }_{z}^{0}(=0.003)$ then $E-{E}_{\mathrm{init}}=0$ and the forces are zero: the balance is checked. Moreover, the solution checks the boundary conditions d的clamped support in $A$ . So this is the solution of the problem.

**Model B:**

The functions used to impose pre-deformations are "scaling" function-type depending on the nodes coordinates of the mesh cells. To obtain the reference solution, the mesh cells pre-deformation values are affected by mesh cells.

**Model C:**

In Modelling C, the mesh cells beam is duplicated in mesh cells bar.

For the validation of pre-deformations by value, a first calculation is made in which pre-deformations are imposed on the mesh cells beam, it is used as a reference to the second calculation in which pre-deformations are imposed on the mesh cells bar.

For the validation of pre-deformations by function, the reference solution is obtained by affecting each mesh cell the value of the function dependent on geometry (coordinates of the Gauss point).

### 4.3 Loading

For pre-deformation components, the functions are:

| EPX | $\mathrm{1E-3.}\mathit{escalier}(X).\mathit{INST}$ |
| --- | --- |
| KY | $\mathrm{2E-3.}\mathit{escalier}(Y).\mathit{INST}$ |
| KZ | $\mathrm{3E-3.}\mathit{escalier}(Z).\mathit{INST}$ |

For each node of mesh the $X$ coordinate is equal to the $Y$ coordinate, which is equal to the $Z$ coordinate. The staircase function is made in such a way that its value is:

- $1$ on mesh cells E1 and E2
- $2$ on mesh cells E4 and E5
- $3$ on mesh cells E7 and E8

There is no pre-deformation imposed on the other mesh cells: E3, E6, E9 and E10.

The following pre-deformation values are therefore affected in the reference calculation:

|  | E1, E2 | E4, E5 | E7, E8 |
| --- | --- | --- | --- |
| EPX | 1E-3 | 2E-3 | 3E-3 |
| KY | 2E-3 | 4E-3 | 6E-3 |
| KZ | 3E-3 | 6E-3 | 9E-3 |

The time dependence is taken into account by adding a multiplicative function to the load.
