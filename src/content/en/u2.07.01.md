# u2.07.01 User's guide to the FOURIER modelling

## 1 Purpose

Fourier analysis is intended to compute the response of structures of axisymmetric geometry subjected to non-axisymmetric loadings decomposed into Fourier series.

**Limitations:**

- the decomposition of the loading into Fourier series is assumed to have been carried out by the user,
- the *Aster* implementation concerns only isotropic or orthotropic materials,
- in thermal analysis, there is no global command making it possible to solve a problem over several harmonics. The analysis must be carried out harmonic by harmonic.

## 2 Notation

All the fields considered (forces, displacements, strains, stresses, fluxes) are expressed in cylindrical coordinates with the following convention on the order of the components:

| radial component along $r$ axial component along $z$ tangential (or circumferential) component along $\theta$ Example: $({u}_{r},{u}_{z},{u}_{\theta})$ $({f}_{r},{f}_{z},{f}_{\theta})$ | ![Figure](images/Object_1.svg) |
| --- | --- |

The mesh is located in the plane $(r,z)$ , the rotational symmetry being about the axis $\mathrm{Oz}$ . The triad $(r,z,\theta )$ is oriented in the right-handed sense.

![Figure](/figures/u2.07.01/Object_2.svg)

## 3 Modelling, loadings

To assign the Fourier axisymmetric finite elements on the mesh, one uses the operator AFFE_MODELE in the following way:

```text
mo = AFFE_MODELE    (    MAILLAGE = ma,
AFFE= _F    (    TOUT= 'OUI',
PHENOMENE= 'MECANIQUE'ou'THERMIQUE',
MODELISATION= 'AXIS_FOURIER'    )
);
```

The decomposition of the loading into Fourier series must have been carried out beforehand by the user

namely $f=\sum_{l=0}^{N}\left[(\begin{array}{ccc}\cos l\theta & & 0\\ & \cos l\theta & \\ 0& & -\sin l\theta \end{array}){F}_{l}^{s}(r,z)+(\begin{array}{ccc}\sin l\theta & & 0\\ & \sin l\theta & \\ 0& & \cos l\theta \end{array}){F}_{l}^{a}(r,z)\right]$

with ${F}_{l}^{s(a)}=({f}_{rl}^{\mathrm{ss}(a)},{f}_{zl}^{s(a)},{f}_{\theta l}^{s(a)})$

The loads ${F}_{l}^{s}$ and ${F}_{l}^{a}$ are introduced harmonic by harmonic and type by type by the operator AFFE_CHAR_MECA. One does not specify the mode or the type at this level.

Example: one assumes a distributed-pressure loading, symmetric mode 1, and pure torsion (antisymmetric mode 0).

One will write:

```text
ch1sym = AFFE_CHAR_MECA(Modele = mo,
                        PRES_REP = _F(
                    GROUP_MA = 'grma',
                    PRES = p))

ch0anti = AFFE_CHAR_MECA(Modele = mo,
                         FORCE_NODALE = _F(
                           FZ = f,
                           NOEUD = 'N1))
```

Dirichlet boundary conditions will be introduced in a separate load:

```text
chdir = AFFE_CHAR_MECA(Modele= mo,
                       DDL_IMPO = _F(GROUP_NO = 'grno',
                       DX = 0., DY = 0., DZ = 0.,))
```

The loadings admissible for the Fourier elements are:

**in elasticity:**

| **Elements** | **Nature of the loading** | **Keyword** **AFFE_CHAR_MECA** |
| --- | --- | --- |
| TRIA3 - TRIA6 QUAD4 - QUAD8 - QUAD9 | Body forces Rotation Gravity Point forces | FORCE_INTERNE ROTATION PESANTEUR FORCE_NODALE |
| SEG2 - SEG3 | Pressure Surface forces | PRES_REP FORCE_CONTOUR |

**in thermal analysis:**

| **Elements** | **Nature of the loading** | **Keyword** **AFFE_CHAR_THER** |
| --- | --- | --- |
| Surface | Heat source | SOURCE |
| Edge | Imposed normal flux Exchange | FLUX_REP ECHANGE |

## 4 Solution with Aster

Once the loading has been decomposed into Fourier harmonics, the harmonics being decoupled from one another (for a different Fourier number), one must assemble and solve as many linear systems as there are harmonics.

Moreover, the material being assumed non-anisotropic, for one and the same harmonic number the symmetric and antisymmetric modes are decoupled. One must therefore carry out as many solutions (with the corresponding load) as there are different (harmonic, mode) pairs.

The implementation in *Code_Aster* differs according to whether the phenomenon is thermal or mechanical.

### 4.1 Thermal analysis

In thermal analysis, there is no global command making it possible to compute several harmonics directly. One must therefore proceed harmonic by harmonic. Moreover, the analyses of the elementary matrices and right-hand sides can be carried out only with the commands CALC_MATR_ELEM and CALC_VECT_ELEM (and not with the command THER_LINEAIRE).

The Fourier mode is to be introduced in CALC_MATR_ELEM by the simple keyword MODE_FOURIER. The type of the harmonic is not required, the matrices (and vectors) being independent of the type. The type is taken into account only at the Fourier recombination.

It is important to assemble the matrices and vectors corresponding to the different harmonics with the same numbering, so as to be able to recombine the result fields. The operator NUME_DDL, which builds the numbering, is therefore used once for the first harmonic, the numbering thus created being reused for all the other harmonics. This is possible if one has separated the Dirichlet loads from the loadings proper (see example [§6.1]).

### 4.2 Mechanics

The command making it possible to treat several harmonics is MACRO_ELAS_MULT [U4.51.02](doc:u4.51.02). In this macro, the harmonics are considered as load cases and one therefore carries out as many solutions as there are harmonics. As in thermal analysis, one must separate the Dirichlet loads, which must be identical for all the harmonics, from the loadings proper, which may vary.

One obtains a RESULTAT data structure containing all the fields corresponding to the computed harmonics (see example [§6.2]).

## 5 Post-processing

### 5.1 Thermal analysis

The analysis of the fluxes is carried out by the operator CALC_CHAM_ELEM, specifying the number of the harmonic by the simple keyword MODE_FOURIER.

The flux-analysis options remain the standard options:

FLUX_ELNO to compute the fluxes at the nodes per element

FLUX_ELGA to compute the fluxes at the Gauss points

The order of the components of the flux vector is $({\phi }_{r},{\phi }_{z},{\phi }_{\theta})$ .

The Fourier recombination on the temperatures is carried out from the operator CREA_CHAMP [U4.72.04](doc:u4.72.04). It makes it possible to obtain the temperatures in different angular sections introduced by the user.

The Fourier recombination on the fluxes is carried out in CREA_CHAMP [U4.72.04](doc:u4.72.04) on the same principle.

### 5.2 Mechanics

The analysis of the strains and of the stresses is carried out by the operator CALC_CHAMP.

The analysis options remain the standard options:

EPSI_ELNO to compute the strains at the nodes per element

SIEF_ELGA to compute the stresses at the Gauss points

SIGM_ELNO to compute the stresses at the nodes per element

SIEQ_ELGA to compute the equivalent stresses at the Gauss points

SIEQ_ELNO to compute the equivalent stresses at the nodes per element

(for these last 2 options, one must have computed SIEF_ELGA beforehand)

The order of the components of the strain tensor (resp. stresses) is:

$({\varepsilon}_{\mathrm{rr}},{\varepsilon}_{zz},{\varepsilon}_{\theta \theta },{\varepsilon}_{\mathrm{rz}},{\varepsilon}_{r\theta },{\varepsilon}_{z\theta })$ $(\text{resp.}{\sigma}_{\mathrm{rr}},{\sigma}_{zz},{\sigma}_{\theta \theta },{\sigma}_{\mathrm{rz}},{\sigma}_{r\theta },{\sigma}_{z\theta })$

The Fourier recombination is carried out by the operator COMB_FOURIER [U4.83.31](doc:u4.83.31), which makes it possible to recombine all the harmonics of the field or fields present in the RESULTAT data structure. This recombination can be carried out on a list of angles.

The analysis of the equivalent stresses (von Mises, Tresca) is carried out by the operator CALC_CHAMP with the usual options SIEQ_ELGA and SIEQ_ELNO. It must be carried out **after** the Fourier recombination on the stresses SIGM_ELGA.
