# v1.01.372 PLEXU11 – Validation of the use of soil springs in CALC_EUROPLEXUS

**Summary:**

This test is intended to validate the use of elements DISCRET in CALC_EUROPLEXUS.

## 1 Modelling A

### 1.1 Purpose

In this Modelling, we want to validate the Modelling/characteristic couples DIS_T/K_T_D_N and DIS_T/A_T_D_N as well as the DIS_T/K_T_D_L and DIS_T/A_T_D_L couples, as GLOBAL reference and LOCAL reference. To do this, we reproduce the EPX bm_str_resl_nl tests (calculation 1) and bm_str_resg_nl (calculation 2).

## 2 Modelling B

### 2.1 Purpose

In this Modelling, we want to validate the use of spring mats with elements DIS_T of zero length. The functionality is already validated for elements DIS_TR of zero length. This therefore provides the reference values.

### 2.2 Description

A parallelepiped structure consisting of a single element is based on a carpet made up of 4 springs. A constant force is imposed on a node top of the $\mathit{XY}0$ cube (with components in the 3 directions of space). The node $\mathit{XY}0$ displacement values are then verified to be the same with DIS_T Modelling as with DIS_TR Modelling (reference).
