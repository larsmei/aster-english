# u4.23.02 Operator CREA_MAILLAGE

## 1 Purpose

Create a data structure of type maillage from another mesh. The new mesh is created from an existing mesh by duplicating, destroying, transforming or exploding mesh cells, or by copying a mesh (the case of geom_fibre).

Produces a data structure maillage.

## 3 Risk of producing a non-conforming mesh

A certain number of functionalities of the command CREA_MAILLAGE can lead to the production of a non-conforming mesh. For this reason, the user must be particularly vigilant when using CREA_MAILLAGE to transform mesh cells.

A mesh is non-conforming when the shape functions of 2 adjacent elements do not have the same trace on their common boundary.

For example:

- 2 pentahedra assembled to form a hexahedron and placed on another hexahedron (1 quadrangle facing 2 triangles).
- 1 QUAD8 sharing an edge with 1 QUAD4 or 1 TRIA3
- 1 TRIA6 sharing an edge with 2 TRIA3

Non-conforming meshes lead in general to incorrect results (at least locally).

Among the possibilities of CREA_MAILLAGE, several situations are potentially dangerous:

- Use of one of the keywords QUAD_TRIA3 (u4.23.02-QUADTRIA3), LINE_QUAD (u4.23.02-LINEQUAD), LINE_CUBI (u4.23.02-LINECUBI) , QUAD_LINE (u4.23.02-QUADLINE), HEXA20_27 (u4.23.02-HEXA2027), PENTA15_18 (u4.23.02-PENTA1518) with the keyword GROUP_MA. If, for example, one **partially** transforms a linear mesh into a quadratic mesh, the mesh will be non-conforming on the boundary between the linear elements and the quadratic elements. When the keyword GROUP_MA is used, the skin mesh cells will be added automatically.
- Use of the keyword HEXA20_27 or PENTA15_18 if there exist in the mesh volume elements with quadrangular faces of a type different from the elements that one is modifying. For example, if there exist pentahedra or pyramids when one modifies hexahedra. The risk is that, for example, a quadrangular face of an HEXA27 (9 nodes) is placed against a quadrangular face with 8 nodes of an adjacent PENTA15.
- Use of the keyword QUAD_TRIA3 if there exist TRIA6 elements in the mesh. In this case, the quadrangles transformed into TRIA3 will be incompatible with the TRIA6.

## 4 Operands

### 4.1 Keyword MAILLAGE

The keyword MAILLAGE gives the name of the initial mesh that one wishes to reproduce before modifying it by adding or deleting new mesh cells or nodes.

**Note**

The keyword is mandatory except when the keywords ECLA_PG and GEOM_FIBRE are used.

### 4.2 Factor keyword CREA_MAILLE

One occurrence of the factor keyword CREA_MAILLE makes it possible to define a new mesh-cell group made up of new mesh cells, themselves supported on existing nodes.

To duplicate several mesh-cell groups, one repeats the factor keyword CREA_MAILLE.

Unlike the command [DEFI_GROUP](doc:u4.22.01), for which the mesh concept always retains the same number of mesh cells and of nodes, here the number of mesh cells of the new mesh is increased (the number of nodes remains identical because the new mesh cells are supported on already existing nodes).

This can facilitate the creation of new geometrical locations in order to be able to apply different modellings to the same mesh-cell group.

#### 4.2.1 Keyword NOM

The name of the new mesh-cell group which will be created is given by the keyword NOM.

#### 4.2.2 Keywords GROUP_MA and TOUT

The set of mesh cells supplied by the user with these two keywords will be duplicated and the new mesh cells will be gathered in a mesh-cell group bearing the name stipulated by the keyword NOM. If the set of mesh cells to be duplicated contains duplicate mesh cells, they are eliminated.

### 4.3 Factor keyword CREA_POI1

One occurrence of the factor keyword CREA_POI1 makes it possible to define mesh cells of type 'POI1' (mesh cell with a single node) from nodes or from nodes of mesh cells.

#### 4.3.1 Keywords TOUT/GROUP_MA/GROUP_NO

All the nodes which belong to entities stipulated by the user with these keywords generate a mesh cell of type POI1. The mesh cell created will have the same name as the node which supports it.

#### 4.3.2 Keyword NOM_GROUP_MA

All the POI1 mesh cells created may be grouped in one and the same mesh-cell group named by the keyword NOM_GROUP_MA.

#### 4.3.3 How to create several POI1 mesh cells on each node?

The POI1 mesh cells created by CREA_POI1 have the same names as the nodes from which they were created. It is therefore not possible to create several POI1 mesh cells on one and the same node by using several occurrences of the keyword CREA_POI1.

A possible workaround is to combine the use of CREA_MAILLAGE / CREA_POI1 with CREA_MAILLAGE / CREA_MAILLE. For example, to create 2 POI1 mesh cells on each node of the group 'GNO1', one may do:

```python
MA2=CREA_MAILLAGE(MAILLAGE=MA1,

CREA_POI1 = _F(NOM_GROUP_MA='GM1', GROUP_NO='GNO1'))

MA3=CREA_MAILLAGE(MAILLAGE=MA2,

CREA_MAILLE =_F(NOM_GROUP_MA='GM2', GROUP_MA='GM1'))
```
### 4.4 Factor keyword MODI_MAILLE

One occurrence of the factor keyword MODI_MAILLE makes it possible to transform a set of mesh cells according to what is indicated by the keyword OPTION:

1. OPTION='SEG3_4': transformation of three-node segments into four-node segments (usable for example for the modelling 'TUYAU'
2. OPTION='TRIA6_7': transformation of six-node triangles into seven-node triangles,
3. OPTION='QUAD8_9': transformation of eight-node quadrangles into nine-node quadrangles,

1. OPTION='QUAD_TRIA3': transformation of quadrangles into 3-node triangles:

- transformation of mesh cells of type QUAD4 into two mesh cells of type TRIA3
- transformation of mesh cells of type QUAD8 into six mesh cells of type TRIA3
- transformation of mesh cells of type QUAD9 into eight mesh cells of type TRIA3

- An automatic procedure for cutting quadrangular mesh cells into triangles can generate a kind of "polarisation" of the mesh: starting from a given QUAD mesh, all the diagonals end up oriented in the same direction.

**Note**

Caution: use of the option 'QUAD_TRIA3' can lead to a non-conforming mesh. See u4.23.02-risqueNonConformite.

### 4.5 Factor keyword LINE_QUAD

This functionality makes it possible to create a quadratic mesh from a linear mesh.

One may apply it only to part of the mesh (keyword GROUP_MA), but this is not recommended. See u4.23.02-risqueNonConformite.

The mesh-cell groups are retained, as are the node groups (without change).

As when refining a mesh, the nodes created are not introduced into the existing node groups.

If a node group corresponds to a boundary, after LINE_QUAD this group does not contain the mid-edge nodes. In order to obtain a complete GROUP_NO, one may use for example the command [DEFI_GROUP](doc:u4.22.01) (OPTION = 'APPUI').

The set of mesh cells stipulated by the user with the two keywords GROUP_MA or TOUT will be transformed into quadratic mesh cells.

Caution: use of the keyword GROUP_MA is not recommended. See u4.23.02-risqueNonConformite.

### 4.6 Factor keyword LINE_CUBI

This functionality makes it possible to create a cubic mesh from a linear mesh.

One may apply it only to part of the mesh (keyword GROUP_MA), but this is not recommended. See u4.23.02-risqueNonConformite.

The mesh-cell groups are retained, as are the node groups (without change).

As when refining a mesh, the nodes created are not introduced into the existing node groups.

If a node group corresponds to a boundary, after LINE_CUBI this group does not contain the vertex nodes of the edges. In order to obtain a complete GROUP_NO, one may use for example the command [DEFI_GROUP](doc:u4.22.01) (OPTION = 'APPUI').

The set of mesh cells stipulated by the user with the two keywords GROUP_MA or TOUT will be transformed into quadratic mesh cells.

### 4.7 Factor keyword PENTA15_18

This factor keyword works like the factor keyword LINE_QUAD (same syntax). It is used to transform PENTA15 into PENTA18 by adding nodes at the centres of the quadrangular faces.

Caution: use of this keyword is not recommended if the mesh contains other types of volume mesh cells (HEXA and PYRAM). See u4.23.02-risqueNonConformite.

### 4.8 Factor keyword HEXA20_27

This factor keyword works like the factor keyword PENTA15_18 with the hexahedra. It is used to transform HEXA20 into HEXA27 by adding nodes at the centres of the faces and at the centre of each hexahedron.

Caution: use of this keyword is not recommended if the mesh contains other types of volume mesh cells (PENTA and PYRAM). See u4.23.02-risqueNonConformite.

### 4.9 Factor keyword MODI_HHO

This option makes it possible to create a mesh compatible with the HHO elements from any mesh. This option is indispensable in order to use the HHO method on tetrahedra, prisms and pyramids. The mesh created is composed of SEG3, QUAD9, TRIA7, HEXA27, TETRA15, PENTA21 and PYRAM19.

Caution: use of this keyword is not recommended if it is applied only to part of the mesh, because that can generate non-conforming meshes. See u4.23.02-risqueNonConformite.

### 4.10 Factor keyword COQUE_SOLIDE

This option makes it possible to create a mesh compatible with the COQUE_SOLIDE elements from a mesh of HEXA8 or PENTA6 elements. This option is indispensable in order to use the COQUE_SOLIDE modelling; the new HEXA9 and PENTA7 mesh cells contain a node in the middle of the support, which makes it possible to take the pinching degree of freedom into account. The mesh created is therefore composed of SEG2, QUAD4, HEXA9, PENTA7 and TRIA3.

In the case of hexahedral elements, it is necessary to supply the keyword GROUP_MA_SURF which identifies the surface used to orient the mesh cells. This surface may be the upper one or the lower one. This is not necessary for the prisms, since in that configuration it is the fact of having TRIA3 which identifies the upper and lower surfaces of the shell.

### 4.11 Factor keyword RAFFINEMENT

This option makes it possible to create a uniformly refined mesh from a given mesh. The option is applied to the whole mesh in order to avoid any conformity problem. The principle of uniform refinement is to cut each edge in two and then to propagate the cut to the other mesh cells. It is equivalent to the 'RAFFINEMENT_UNIFORME' adaptation of [MACR_ADAP_MAIL](doc:u7.03.01). Caution: the size of the mesh increases very rapidly and its quality may decrease if the starting mesh is not of sufficient quality. It is recommended to start from a mesh which already represents the geometry well, in particular if it is curved, before refining.

The refinement is applied to the whole mesh.

The keyword NIVEAU makes it possible to specify the number of successive refinements required.

### 4.12 Factor keyword QUAD_LINE

This functionality makes it possible to create a linear mesh from a quadratic mesh; one may apply it only to part of the mesh (caution in that case regarding the junction of the linear and quadratic zones). See u4.23.02-risqueNonConformite.

The set of mesh cells stipulated by the user with the two keywords GROUP_MA or TOUT will be transformed into linear mesh cells.

Caution: use of the keyword GROUP_MA is not recommended. See u4.23.02-risqueNonConformite.

### 4.13 Factor keyword REPERE

One occurrence of the factor keyword REPERE makes it possible to define a new mesh from the old mesh by carrying out a change of frame.

This functionality is used in particular in the command [MACR_CARA_POUTRE](doc:u4.42.02) for the computation of the warping constant.

The keyword TABLE gives the name of the concept table "geometrical characteristics", which contains in particular the coordinates of the centre of inertia and of the centre of torsion, the nautical angles defining the principal frame of inertia, etc.
This table may be obtained by the command [POST_ELEM](doc:u4.81.22) with the factor keywords CARA_GEOM or CARA_POUTRE.

The centre of the new frame is indicated by the keyword NOM_ORIG: the centre of gravity ('CDG') or the centre of torsion ('TORSION').

If NOM_ORIG= 'CDG', one may indicate by the keyword GROUP_MA the name of the mesh-cell group whose centre of gravity will be the origin of the new frame. If one does not use GROUP_MA, the centre of gravity of the whole model will be the origin of the new frame.

If NOM_ORIG= 'TORSION', the keyword GROUP_MA has no effect.

The direction of the new frame is indicated by the keyword NOM_ROTA. Only one solution is possible: the directions are those of the principal frame of inertia.

### 4.14 Factor keyword COQU_VOLU

From the data of a group of surface mesh cells (QUAD, TRIA3), the volume mesh (HEXA8, PENTA6) is built by extrusion along the normal to the elements (at a node, one takes the average of the normals of the elements meeting there). Only one layer of elements is created.

The operation applies only to linear meshes; if one wishes to create a quadratic mesh, it is enough to use LINE_QUAD afterwards.

The name of the mesh-cell group made up of the volume mesh cells created during this operation is indicated by the keyword NOM.

The keyword GROUP_MA gives the mesh-cell groups constituting the surface mesh to be extruded.

The thickness of the layer of elements created (thickness of the shell) is given by the keyword EPAIS.

The keyword PLAN specifies that the surface mesh to be extruded, given by GROUP_MA, will be the upper ('SUP'), lower ('INF') or middle ('MOY') plane of the shell.

In the case where PLAN='MOY', the keyword TRANSLATION specifies whether the initial surface to be extruded is translated to the upper skin ('SUP') or to the lower skin ('INF').

### 4.15 Factor keyword CREA_FISS

The factor keyword CREA_FISS makes it possible to create a crack with joint elements [R3.06.09](doc:r3.06.09) or elements with a discontinuity [R7.02.12](doc:r7.02.12) along a line defined by two node groups placed facing one another. The two node groups must have the same number of nodes and must have been ordered beforehand (for example with [DEFI_GROUP](doc:u4.22.01) and OPTION='NOEUD_ORDO') so that their numbering "starts" from the same side.

One may then assign a modelling of "joint" type to these new QUAD4 mesh cells (for example 'PLAN_JOINT').

A new GROUP_MA containing all the QUAD4 mesh cells created will also be created.

The keyword NOM gives the name of the mesh-cell group made up of the volume mesh cells created during this operation.

The node groups constituting the lips of the crack are given by the keywords GROUP_NO_1 and GROUP_NO_2. The node group GROUP_NO_1 carries the local nodes 1 and 2 (the first node of the group has a local numbering equal to 1), and GROUP_NO_2 carries the local nodes 3 and 4 (the first node of the group has a local numbering equal to 4).

These node groups must be chosen according to the geometry so that the local numbering of the elements is carried out in the anticlockwise direction.

### 4.16 Factor keyword ECLA_PG

Factor keyword to be removed.
.. The factor keyword ECLA_PG is not to be used directly. It is used by the command [MACR_ECLA_PG](doc:u4.44.14).

### 4.17 Factor keyword GEOM_FIBRE

The factor keyword GEOM_FIBRE makes it possible to obtain the mesh created by [DEFI_GEOM_FIBRE](doc:u4.26.01). This mesh contains all the fibre groups of the study as well as the mesh containing all the fibres.

### 4.18 Factor keyword RESTREINT

This factor keyword (non-repeatable) makes it possible to generate a "sub"-mesh extracted from an existing mesh.

The extracted (or "restricted") mesh is formed from a list of mesh cells supplied by the keyword GROUP_MA.

The nodes retained are those of the mesh cells retained. Moreover, if the keyword GROUP_NO is used, the nodes of these groups are added

The mesh will contain all the mesh-cell groups of the keyword GROUP_MA. Moreover, if the keyword TOUT_GROUP_MA='OUI' is used, the non-empty mesh-cell groups of the initial mesh are added.

The mesh will contain all the node groups of the keyword GROUP_NO. Moreover, if the keyword TOUT_GROUP_NO='OUI' is used, the non-empty node groups of ma_1 are added.

### 4.19 Factor keyword DECOUPE_LAC

The factor keyword DECOUPE_LAC makes it possible to obtain a mesh containing "patches" created on the mesh-cell group specified in GROUP_MA_ESCL. It is a pre-processing operation on the slave mesh cells for the treatment of contact by the mortar LAC method.

Note that the mesh cells underlying the mesh cells of GROUP_MA_ESCL are also cut.

The cuts of the elements PYRA5 PYRA13, PENTA6, PENTA15 and HEXA8 HEXA20 in the case DECOUPE_HEXA='PYRA' are "non-conforming" cuts in the sense that they introduce elements different from the element being cut (pyramids and/or tetrahedra) so as to add only one node per cut element in the mesh.

Cutting of PENTA18 is not supported.

DECOUPE_LAC must be the last command to act on the mesh. The MODI_MAILLAGE operations must be carried out beforehand.

The keyword DECOUPE_HEXA makes it possible to define the type of cut used on the HEXA8 and the HEXA20. By default, these elements are cut into pyramids in order to limit the number of nodes added. However, by using the value HEXA, they are cut into HEXA, which can be useful if the introduction of pyramids into the mesh poses a problem.

### 4.20 Keyword INFO

The keyword INFO specifies the information printed in the message file (1: no printout, 2: details on the number of mesh cells created, modified…).

### 4.21 Keyword TITRE

The keyword TITRE makes it possible to specify a title.

## 5 Examples

### 5.1 Duplication of mesh cells

Let there be a mesh already containing the mesh cells:

```
M1 M2 M3
```

and the shell mesh-cell group:

```
coque : M1 M2
```

Each mesh cell is supported on the following nodes:

```
M1 : N1 N2 N3
M2 : N3 N4 N5
M3 : N4 N5 N6
```

If one calls the following command:

```
ma_2 = CREA_MAILLAGE(MAILLAGE = ma_1,
                     CREA_MAILLE = _F(NOM = 'sol',
                                      GROUP_MA = 'coque', ),)
```
After the call to the command CREA_MAILLAGE, the new mesh then contains:

- the mesh-cell groups:

- coque (initial)
- sol containing the mesh cells M4 and M5

- the mesh cells are supported on the following nodes:

- M1 : N1 N2 N3
- M2 : N3 N4 N5
- M3 : N4 N5 N6
- M4 : N1 N2 N3
- M5 : N3 N4 N5

### 5.2 Transformation of 6-node triangles into 7-node triangles

```text
ma_2 = CREA_MAILLAGE(MAILLAGE = ma_1,
                     MODI_MAILLE = _F(GROUP_MA = 'triangle',
                                      OPTION = 'TRIA6_7', ),)
```

Suppose that in ma_1 the GROUP_MA triangle is composed of two mesh cells M1, M2 having the following nodes:

```
M1: N1 N2 N3 N4 N5 N6
M2: N1 N2 N7 N4 N8 N9
```

In the mesh ma_2, the two mesh cells M1, M2 will have the following nodes:

```
M1: N1 N2 N3 N4 N5 N6 N10
M2: N1 N2 N7 N4 N8 N9 N11
```
