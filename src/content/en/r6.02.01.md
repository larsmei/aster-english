## 1 Generalities on Gauss-type methods

### 1.1 Presentation of the method.

Starting from the observation that it is easy to solve the system $\mathrm{A.x}=b$ when $A$ is a lower or upper triangular matrix, one seeks to decompose the initial full matrix by a factorisation into triangular matrices.

The basic principle is to seek a regular matrix $P$ , called permutation matrix, such that the product $\mathrm{P.A}$ is triangular, then to solve $\mathrm{P.A.x}=\mathrm{P.b}$

**Note:**

*In practice,* *P is determined by products of elementary permutation matrices* $P={P}^{(k)}\mathrm{...}{P}^{(1)}.$

*The matrices* ${P}^{(i)}$ *depend on the variant chosen, but one never computes the matrix* $P$ *explicitly but only* $\mathrm{P.A}$ *and* $\mathrm{P.b}$

The matrix A having been factorised in the general form L.U (L lower triangular matrix, U upper triangular matrix), we are led to solve the two linear systems:

$\lbrace \begin{array}{c}L.\text{y = b}\\ U.\text{x = y}\end{array}$

**Note:**

*In the method called* **GAUSS elimination**, *one carries out simultaneously the factorisation of A and the solution of* $\mathrm{L.y}=b$

The following algorithm carries out the GAUSS elimination and the solution of $\mathrm{L.y}=b$

at step (p+1) we have

| ${a}_{ij}^{(p+1)}={a}_{ij}^{(p)}-{a}_{ij}^{(p)}.{({a}_{\text{pp}}^{(p)})}^{-1}.{a}_{\text{pj}}^{(p)}$ | for $p+1\le i\le n$ $p+1\le j\le n+1$ |
| --- | --- |
| ${a}_{ij}^{(p+1)}={a}_{ij}^{(p)}$ | for $1\le i\le p$ $1\le j\le n+1$ |
| ${a}_{ij}^{(p+1)}=0.$ | for $p+1\le i\le n$ $1\le j\le p$ |

**Note:**

*In this writing of the GAUSS elimination algorithm, the right-hand side* *b is considered as an additional column of the matrix which is then treated as an* *n x (n+1) matrix.*

### 1.2 Notion of pivot

The previous implementation of the GAUSS elimination algorithm implicitly assumes that the diagonal terms called **pivots**  are not zero in the course of the calculation.

**Case of zero pivots**  : A regular matrix may have a zero pivot.

example: the matrix $(\begin{array}{cc}0& 1\\ 2& 1\end{array})$

To remedy this drawback, one may use a **pivoting strategy**

- **complete pivoting**  : this strategy consists in choosing as pivot the largest term in the remaining block then in carrying out a permutation of row and of column.

One then has the system $\mathrm{P.A.Q}({Q}^{T}x)=\mathrm{P.b}$

where P is the row-permutation matrix and Q that of the columns.

The solution found is then $y={Q}^{T}x,$ and it is therefore necessary to keep the permutation matrix $Q$ in order to obtain the sought solution $x=\mathrm{Q.y}$

- **partial pivoting**  : the pivot is sought as being the term of maximum value, among the terms not yet treated, in the current column (the k-th at step k) then one carries out a row permutation.

### 1.3 Stability of the method

| **Definition:** | A numerical method for solving a linear system is said to be mathematically **stable** when 'whatever the regular matrix A, the algorithm succeeds'. |
| --- | --- |
|  |  |
| **Theorem:** | The GAUSS method with a pivoting strategy is mathematically stable for any regular matrix. |
|  |  |
| **Corollary:** | If in the course of a GAUSS factorisation with pivoting a zero pivot is detected then the matrix is singular and this system does not have a unique solution. |
|  |  |
| **Theorem:** | The GAUSS method (without pivoting) is stable for real positive-definite matrices. |

For more details, one will consult the basic books which are [bib13] [bib14] [bib6].

| **Proposition:** | The GAUSS decomposition is not unique, but if one specifies the diagonal of L or of U then one has uniqueness of the decomposition. |

### 1.5 A variant: the CROUT factorisation

The CROUT factorisation method [1] is the same algorithm, which requires the same number of operations and performs the same fill-in of the matrix but the calculations are carried out in a different way.

We place ourselves in the case where the matrix is factorisable, which is always the case up to a permutation of the rows and of the columns as soon as the matrix is regular: one therefore has $A=LU$

Then one proceeds by identification

$\lbrace \begin{array}{c}\text{pour}i\le {\text{j a}}_{ij}={u}_{ij}+\sum_{\text{k=1}}^{\text{i-1}}{l}_{\text{ik}}.{u}_{\text{kj}}\\ \text{pour}i>{\text{j a}}_{ij}=\sum_{\text{k=1}}^{j}{l}_{\text{ik}}.{u}_{\text{kj}}\text{}\end{array}$

(${l}_{ij}$  and ${u}_{ij}$ are the elements of $L$  and $U$ )

whence the values of uij and lij as a function of aij

| ${u}_{\mathrm{1j}}={a}_{\mathrm{1j}}$ | $j=1,\dots ,n$ |
| --- | --- |
| ${l}_{\text{i1}}=$ | $i=1,\dots ,n$ |
| ${u}_{ij}={a}_{ij}-\sum_{\text{k=1}}^{\text{i-1}}{l}_{\text{ik}}.{u}_{\text{kj}}$ | $i\le j$ |
| ${l}_{ij}=\frac{1}{{u}_{jj}}({a}_{ij}-\sum_{\text{k=1}}^{\text{j-1}}{l}_{\text{ik}}.{u}_{\text{kj}})$ | $i>j$ |

**Note:**

*The order of the calculations is not arbitrary, one must know the* *l_ik located on the left and the* *u_kj above each term to be computed.*

One then sees that at the k-th step, one carries over onto the k-th row all the previous contributions leaving unchanged the rows k+1 to n.

This CROUT variant is also called GAUSS elimination by columns (or active columm), and favours the scalar-product operation.

### 1.6 Case of symmetric matrices

**Proposition:**  The GAUSS decomposition respects symmetry.

It suffices to note that at each step the terms ${a}_{ij}$ and ${a}_{ji}$ receive the same contribution.

Indeed:

| ![Figure](images/10000C240000186400000DA50BF1DE60CB7FB381.svg) | by the induction hypothesis, one assumes the matrix symmetric at step k and from then on one has:$\begin{array}{}{a}_{ij}^{(k+1)}={a}_{ij}^{(k)}-{a}_{\text{ik}}^{(k)}{a}_{\text{kj}}^{(k)}{\text{/a}}_{kk}^{(k)}\\ {a}_{ji}^{(k+1)}={a}_{ji}^{(k)}-{a}_{\text{jk}}^{(k)}{a}_{\text{ki}}^{(k)}{\text{/a}}_{kk}^{(k)}\end{array}$whence the proposition. |
| --- | --- |

Henceforth, a symmetric matrix A can be factorised in the form $A=LD{L}^{T}$

where D is a diagonal matrix and L a unit lower matrix (that is to say with unit diagonal)

This decomposition, unique since one has fixed a diagonal, applies to any non-singular symmetric matrix.

If the matrix $A$ is positive definite, then the diagonal terms are strictly positive and one may use the so-called CHOLESKY form $A=L{L}^{T}=(L{D}^{1/2}.{D}^{1/2}{L}^{T}).$

Let us note that the CHOLESKY decomposition requires n square-root extractions (which is an operation costly in time).

In the case of an LDLT factorisation for symmetric matrices, we can write the CROUT algorithm in the following form:

$\begin{array}{}\text{Boucle sur les colonnes ic=2,...,n}\\ \mid \begin{array}{}\begin{array}{}\text{Boucle sur les contributions im=1,}\mathrm{¼}\text{,ic}-1\\ {l}_{\text{ic,ic}}\neg {l}_{\text{ic,ic}}-{l}_{\text{ic,im}}\ast {l}_{\text{im,ic}}\\ \text{Fin boucle}\end{array}\\ \mid \begin{array}{}\text{Boucle sur les lignes il=1,...,ic}-1\\ \mid \begin{array}{}\text{Boucle sur les contributions im=1,}\mathrm{...}\text{,il}-1\\ {l}_{\text{il,ic}}\neg {l}_{\text{il,ic}}-{l}_{\text{ic,im}}\ast {l}_{\text{im,il}}\\ \text{Fin boucle}\\ {l}_{\text{il,ic}}\neg {l}_{\text{il,ic}}/{l}_{\text{il,il}}\end{array}\\ \text{Fin boucle}\end{array}\mid \\ \end{array}\end{array}$

## 2 Disadvantages of Gauss-type methods

The disadvantages of Gauss-type methods are essentially of three types:

1. a high number of operations
2. a fill-in of the matrix
3. a loss of precision in the course of the calculation

The first two points are often qualified as major defects whereas the third is considered as a minor defect.

### 2.1 The number of operations

For a full system of size n, at the p-th step, we must carry out, in order to compute the new coefficients of the matrix and the right-hand side:

- (n-p) divisions
- (n-p+1)(n-p) additions and multiplications

The number of operations is therefore:

$\sum_{p=1}^{n-1}(n-p)=\frac{n(n-1)}{2}$ divisions

$\sum_{p=1}^{n-1}(n-\text{p+1})(n-p)=\sum_{q=1}^{n-1}{q}^{2}+\sum_{q=1}^{n-1}q=(\frac{n(n-1)(n-2)}{6}+\frac{n(n-1)}{2})$ additions and as many multiplications.

That is $\frac{1}{3}$ $n(n-1)$ $(n+\frac{1}{2})$ operations to which it is appropriate to add the ${n}^{2}$ operations of the solution of the triangular system.

| --- | --- |

**Note:**

*In the case of a matrix stored in band form, the number of operations is* ${\mathrm{n.b}}^{2}$ *where* $b$ *is the bandwidth.*

Let us begin with a classical example of a so-called "arrow" matrix which one encounters for example in chemistry [bib9].

Let $A$ be the matrix such that $a(1,i)\ne 0,a(i,1)\ne 0,a(i,i)\ne 0$ and all its other terms are zero, the matrix then has the following appearance:

A =

After the 1st factorisation step (by the GAUSS algorithm), the matrix is full in the sense that there are no longer any theoretically zero terms.

Let us look more formally at the fill-in phenomenon due to the algorithm; for this let us rewrite the algorithm:

For k varying from 1 to n - 1 do % loop on the steps

For i varying from k + 1 to n do % loop on the rows

For j varying from k + 1 to n do % loop on the columns

$a(i,j)=a(i,j)-a(i,k).a(k,j)/a(k,k)$

end do

end do

end do

What one can schematise graphically, at the k-th step, for the computation of the term a(i,j) by:

![Figure](/figures/r6.02.01/10000C34000069BB00002A951F168E78365B63C5.svg)

The term $a(i,j)$ is non-zero at the end of the k-th step:

- if it was non-zero at the beginning of this k-th step,
- or if the terms $a(i,k)$  and $a(k,j)$ are both non-zero at the beginning of the k-th step, and this independently of the initial value of the term $a(i,j)$ .

Moreover, one sees that the GAUSS method fills the envelope profile of the matrix in the course of the factorisation steps.

In the example of the "arrow" matrix: the envelope profile is the full matrix, whence the result observed.

This example highlights the importance of the numbering of the unknowns of the matrix since the matrix can be rewritten, after permutation of the unknowns, in the form:

![Figure](/figures/r6.02.01/1000022800000FD00000087ADC49393EAAABC39A.svg)

whose envelope profile is the matrix itself (there is therefore no fill-in).

We have just seen the importance of the numbering of the unknowns.

We cannot insist too much on the fact that "optimal" renumbering algorithms must be used in order to minimise the fill-in of the matrix.

These algorithms rest on heuristics and are specialised.

**Intrinsic formulation of the fill-in**

One can give an intrinsic formulation of the fill-in during the elimination of an unknown in terms of a graph [bib5].

Let a matrix A to which we associate the graph $G(X,E)$ , where $X$ is the set of nodes and $E$ the set of undirected edges.

The problem of elimination of an unknown of the matrix is then equivalent to eliminating a node of the graph.

**Definition:** Let $x,y\in X$ , one will say that $x$ and $y$ are **adjacent**  if and only if $x,y\in E$

If $Y$ is a subset of nodes of $X(X\supset Y)$ we can define the following sets:

| the set of nodes adjacent to Y | $\mathrm{Adj}(Y)=x/x\in X-Y\mathrm{et}y\in Y\mathrm{tel}\mathrm{que}x,y\in E$ |
| --- | --- |
| the set of edges incident on Y | $\mathrm{Inc}(Y)=x,y/y\in Y,x\in \mathrm{Adj}(Y)$ |
| the definition set of X | $\text{Def}(X)=y,z/y,z\in \mathrm{Adj}(X),y\ne z\mathrm{et}z\notin \mathrm{Adj}(Y)$ |

![Figure](/figures/r6.02.01/10003392000069BB000029A7B409778D5B06CDFC.svg)

**Elimination operation of** **y**

The elimination of y then consists in considering the subset

$\mathrm{Elim}(y,G)=X-y,(E-\mathrm{Inc}(y))U\stackrel{\scriptscriptstyle\mathrm{def}}{=}(y)$

One must therefore indeed consider the fill-in which is linked to $\text{Def}(y).$

To minimise the fill-in one may use a heuristic consisting in eliminating the y of minimal degree, the degree of {y} being the cardinal of the set Adj(y). This is the guiding idea of the use of the minimum-degree algorithm before a GAUSS-type factorisation.

This approach is used in the multifrontal method implemented in *Aster*  [bib15].

The problem comes from the fact that in the course of the algorithm the pivots decrease and that they are used as denominator for the following steps [bib13].

#### 2.3.2 Estimation of the error on the solution

We have solved the system

$\mathrm{L.}Ux=A(0).x+\mathrm{E.x}$

| where | $\mathrm{E.x}$ is the error term induced by the rounding/truncation errors in the operations of the factorisation. |
| --- | --- |
|  | $A(0)x$ is the right-hand side (in fact $b$ ). |

The approximate solution found $\tilde{x}$ which approximates the true solution x is:

$\tilde{x}$ $={(A+E)}^{\text{-1}}b$

One then shows that the evaluation of the error on x is linked to the **conditioning of** A.

Let us pose the problem in the form: $(A+\delta A)(x+\delta x)=b$

Assuming $\delta \mathrm{A.}\delta x$  small one has: $\delta x=A-1.\delta \mathrm{A.x}$

whence by taking norms $\frac{\parallel \mathrm{\delta \; x}\parallel }{\parallel x\parallel }\le \text{Cond}(A).\frac{\parallel \mathrm{\delta \; A}\parallel }{\parallel A\parallel }$

where $\mathrm{Cond}(A)$ = $(\parallel A\parallel .{\parallel A\parallel }^{-1})$ is the conditioning of the matrix A.

**Note:**

*One notes that the error induced on the right-hand side is small and perturbs the solution only through a poor conditioning of the matrix* *A.*

*Indeed, if one considers the system* $A(x+\delta x)=b+\delta b,$

*because of the equalities:* $\mathrm{\delta x}=A-1.\mathrm{\delta b}\mathrm{et}\mathrm{Ax}=b$

$\begin{array}{}\text{on a}\text{}\parallel \mathrm{\delta \; x}\parallel \le \parallel {A}^{\text{-1}}\parallel .\parallel \mathrm{\delta \; b}\parallel \text{et}\parallel b\parallel <\parallel A\parallel .\parallel x\parallel \\ \text{et donc}\text{}\parallel \frac{\mathrm{\delta \; x}}{x}\parallel \le (\parallel A\parallel .\parallel {A}^{\text{-1}}\parallel )\parallel \frac{\mathrm{\delta \; b}}{b}\parallel \end{array}$

**Note:**

*If one considers the variations on* $A,x,$ *and* *b* simultaneously, one has the following estimate [bib14]:

$\frac{\parallel \mathrm{\delta \; x}\parallel }{\parallel x\parallel }\le \frac{\text{Cond}(A)}{1-\parallel {A}^{-1}\parallel .\parallel \mathrm{\delta \; A}\parallel }.(\frac{\parallel \mathrm{\delta \; A}\parallel }{\parallel A\parallel }+\frac{\parallel \mathrm{\delta \; b}\parallel }{\parallel b\parallel })$

**A few remarks on the conditioning**

- the conditioning is defined only for a regular matrix,
- the conditioning depends on the norm chosen on ${ℝ}^{n}$ ,
- whatever the norm chosen, we have $1\le \mathrm{Cond}(A)$ and a matrix is all the better conditioned as its conditioning is close to 1.

If the **Euclidean**  norm is chosen as the norm, then

- the conditioning of an arbitrary matrix A is

$\mathrm{Cond}(A)=$ $\mid \frac{{\mu}_{n}}{{\mu}_{1}}\mid$

where ${\mu}_{1}$ and ${\mu}_{n}$ are the extreme singular values of A (that is to say the smallest and the largest of the eigenvalues of ${A}^{\text{*}}.A$ ).

- If the matrix A is symmetric (or Hermitian) then

$\mathrm{Cond}(A)$ = $\mid \frac{{\lambda}_{n}}{{\lambda}_{1}}\mid$

where ${\lambda}_{1}$ and ${\lambda}_{n}$ are the eigenvalues of minimal and maximal modulus of $A$ .

#### 2.3.3 Estimation of the number of significant digits of the solution

If one has a precision of p significant (decimal) digits, one then has:

$\frac{\parallel \mathrm{dA}\parallel }{\parallel A\parallel }\simeq {10}^{-p}$

If one desires a precision of s significant (decimal) digits on the solution

$\frac{\parallel \deltax \parallel }{\parallel x\parallel }\le {10}^{-s}$

whence the estimate of the number of exact significant decimal digits of the solution

$s\ge p-{\log}_{10}(\mathrm{Cond}(A))$

#### 2.3.4 Method for reducing the conditioning

The simplest method is that of scaling:

One "passes" from A to ${\varphi}_{1}\text{.A.}{\varphi}_{2}$ with ${\varphi}_{i}$ a diagonal matrix such that Cond(${\varphi}_{1}\text{.A.}{\varphi}_{2}$ ) is better than $\mathrm{Cond}(A)$ .

This is very theoretical and there exists no universal method for determining ${\varphi}_{1}\text{et}{\varphi}_{2}$ .

Let us note that if the matrix A is symmetric and one wishes to preserve this property, one must then take ${\varphi}_{1}={\varphi}_{2}$ .

#### 2.3.6 A geometric interpretation of poor conditioning

One can give a very simple interpretation of the poor conditioning of a linear system $\mathrm{Ax}=b$ in the particular case where A is normal (i.e. ${A}^{\text{*}}.A={\mathrm{A.A}}^{\text{*}}$ ).

Let ${\lambda}_{1}$ be the smallest eigenvalue of the matrix $A$ and ${\lambda}_{n}$ its largest eigenvalue and let ${v}_{1}$ and v_n be the associated eigenvectors.

for $b={v}_{n}\text{et}\deltab ,$ one has $\parallel \frac{\deltax }{x}\parallel =\text{cond}(A)\parallel \frac{\deltab }{b}\parallel$

### 2.4 Criteria for determining a zero pivot

| **Definition:** | A **numerically degenerate system** is a system for which a pivot is zero or has no exact significant digit. |
| --- | --- |

Let us note that a system may be numerically degenerate without being so mathematically.

In these two cases, it is appropriate not to solve the system, whence the necessity of determining a stopping criterion as soon as one of the pivots no longer has exact significant digits.

Let A be the matrix to be factorised and F the free-diagonal matrix resulting from the factorisation.

| **Criterion 1**: | The simplest criterion is to consider that the pivot is zero as soon as it is less, in absolute value, than a given threshold. |
| --- | --- |

$\mid {f}_{ii}\mid <{\varepsilon}_{1}$

${\varepsilon}_{1}$ is a "small number" below which one considers that the values are arbitrarily zero.

| **Criterion 2**: | This criterion applies to the number of significant digits still available. Noting that one cannot have more than p significant digits on a given machine, one will check that the decrease of the pivot does not take place in a ratio greater than 10-p. |
| --- | --- |

$\mid \frac{{f}_{ii}}{{a}_{ii}}\mid \le {\varepsilon}_{2}={10}^{\text{-p}}$

Let us note that the ratio $\mid \frac{{f}_{ii}}{{a}_{ii}}\mid$ is always less than or equal to 1 because of the decrease of the pivots.

The basic cause of a poor numerical conditioning is the rounding error caused by the introduction of large numbers without physical meaning.

## 3 Block LDLT method implemented in Aster

This paragraph details the implementation in *Aster*  of the solution of the linear system A.x = b by the LDLT factorisation method of the symmetric matrix A.

The matrix A is stored in profile (or skyline) form by block.

| **Basic principle:** | A column of the matrix is contained entirely in a single block: we do not segment the columns. |
| --- | --- |

The arrays allowing the description of the matrix stored in profile form by block are:

- HCOL column height of the matrix

HCOL(i) height of the i-th column

- ADIA address of the diagonal term in its block

ADIA(i) returns the address of the i-th diagonal term in its block

- ABLO block pointer

ABLO(i+1) returns the number of the last equation in the global numbering contained in the i-th block

By convention ABLO(1) = 0 and the number of equations in the i-th block is given by the relation ABLO(i+1) - ABLO(i) + 1

The total number of equations is deduced as being ABLO(nombre_de_bloc + 1)

It is also necessary to store the total number of blocks used to contain the coefficients of the matrix.

**Note:**

*Formally the array* *HCOL is useless because it is deduced from the arrays* *ADIA* *and* *ABLO, but it makes it possible to carry out the calculations more rapidly.*

### 3.1 Implementation of the factorisation

- the factorisation is carried out in place, that is to say by overwriting the initial matrix,

- the criteria for detection of zero pivots may be adapted to the factorisation of quasi-singular matrices,
- in the case of detection of a zero pivot, this pivot is replaced by a very large value (1040) which amounts to introducing a blocking condition by penalisation.

### 3.3 Scaling

It is possible to carry out a scaling of the matrix to be factorised; this simple scaling is done so as to obtain a matrix whose diagonal terms are equal to 1.

The diagonal matrix is such that:

${\varphi}_{i}=\lbrace \begin{array}{cc}\frac{1}{\sqrt{\mid {a}_{ii}\mid }}& {\text{si a}}_{ii}\ne 0\\ 1& {\text{si a}}_{ii}=0\end{array}$

It is to be noted that during the solution, one obtains the solution of the system only after deconditioning.

**Indeed**  : the initial system is $\mathrm{Ax}=b$

after multiplication on the left by $\varphi$ , one has:

$\varphi \mathrm{Ax}=\varphi .b$

Now the system solved is:

$\varphia \varphix =\varphib$

whence the solution $\varphix$ obtained which one must "decondition".

### 3.4 Tests on the pivot

Two criteria for detection of zero pivots are implemented:

- the test in absolute value $\mid {a}_{ii}\mid <\varepsilon$ , with $\varepsilon$ given,
- the test in relative value on the number of exact significant digits.

Let us note that these tests can be reduced to their simplest expression by supplying an $\varepsilon =0$ . and by giving, by convention, a zero number of exact significant digits.

This option is made necessary by the fact that algorithms such as the algorithms for searching for eigenvalues [R5.01.01](doc:r5.01.01) [R5.01.02](doc:r5.01.02) seek to factorise quasi-singular matrices.

### 3.5 Factorisation of complex matrices

The algorithm implemented in *Aster*  also makes it possible to treat **symmetric**  matrices with complex coefficients.

The algorithm implemented does not treat Hermitian matrices, although this is theoretically possible.

**Classical storage methods**

**A1.1** **Full matrix**

A non-symmetric full matrix of size n has n2 coefficients.

If the matrix is symmetric, one may store only its lower or upper triangular part, that is $\frac{n(n+1)}{2}$ values.

No array describing the matrix is necessary.

**A1.2** **Band matrix**

b + 1 = bandwidth

![Figure](/figures/r6.02.01/1000074800000AC000000AF5F225F66ACDD58B76.svg)

In this case one stores the band (sometimes called the straightened matrix) in a rectangular array n (2b + 1); one then includes the b (b + 1) zero values corresponding to the complements of the tips.

In the case of a symmetric matrix, one may store only n (b + 1) values of which $\frac{b(b+1)}{2}$ zero values (useless).

This method requires only knowing the bandwidth.

**A1.3** **Profile matrix or skyline matrix**

This technique consists in storing the terms of the matrix by columns and rows of variable lengths. The terms outside the "skyline", which is the envelope of the tops of the columns, being assumed to have no contribution in the calculations, are not stored.

The profile of the i-th row (resp. column) is determined by:

```text
min {j tel que 1  j  n        aij:math:`\ne`0}
(resp    min {j tel que 1  j  n        aji:math:`\ne`0})
```

If the profile is symmetric, one speaks of a matrix with symmetric profile.

This storage method requires storage arrays which we are going to detail in the case of a matrix with symmetric profile.

Classically, in this storage option, the matrix is arranged in the form of a one-dimensional array requiring a column-entry pointer array ADIA in order to explore the matrix: entry is made through the diagonal terms, the number of terms of the column is obtained by differences of two successive terms: ADIA(i+1) - ADIA(i).

If the matrix is non-symmetric, but with symmetric profile, it is necessary to store the i-th row and the i-th column. Classically, one places them "end to end" and the number of terms of the column or of the row is (ADIA(i+1) - ADIA(i))/2.

**A1.4** **Block storage**

The storage methods seen previously implicitly assume that the matrix can reside in central memory, which is not always the case.

Whence the notion of a matrix stored by block (or segmented on disk).

All the previous storages can be segmented, but we shall set out only the case of the symmetric matrix stored in profile form.

**Profile matrix stored by block**

We consider here only the case of symmetric matrices, which takes nothing away from the generality of the discussion.

![Figure](/figures/r6.02.01/100021A6000013540000170C18DB836487ED2AE9.svg)

**Figure A1.4-a:** Maximum size of a block: 20 elements

In this example, we assume the blocks of the same size; in order to use blocks of variable size, one must introduce an additional array containing the size of each block.

We also consider that a column can belong to only one block: "we do not cut the columns".

In order to manage the matrix, it is always necessary to know the address of the diagonal terms; but now, this address is relative to the block to which the column belongs.

To this array, it is necessary to join an array giving the equations contained in a block.

This array, dimensioned to the number of blocks plus 1, contains the last equation of the block.

**Variations on the GAUSS algorithm**

As we have seen with the CROUT variant, there exist several implementations of the GAUSS algorithm: it consists in carrying out the computations of the coefficients in a different order.

Schematically, one considers that there are three nested loops:

- loop i on the rows,
- loop j on the columns,
- loop k on the steps.

The standard algorithm is characterised by the sequence kij, but there exist 5 other permutations of the indices which give rise to as many variants (or algorithms).

- the CROUT algorithm is characterised by the sequence jki,
- the algorithm corresponding to the sequence ikj, which works by row, is known under the name of "Doolitle" algorithm.
