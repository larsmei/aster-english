# u4.92.03 Procedure TEST_TABLE

## 1 Purpose

Test a "cell" (or a whole column) of a concept of type table.

Prints OK if the value found in the cell is identical to the value given as reference,

NOOK otherwise.

This command is used essentially by the test cases in order to validate the non-regression of the results.

## 2 Syntax

```text
TEST_TABLE(
    ◆ TABLE = table,
    ◇ FILTRE = _F(
         ◆ NOM_PARA = text,
         ◇ CRIT_COMP = / "EQ" (par défaut),
                       / "LT",
                       / "GT",
                       / "NE",
                       / "LE",
                       / "GE",
                       / "VIDE",
                       / "NON_VIDE",
                       / "MAXI",
                       / "MAXI_ABS",
                       / "MINI",
                       / "MINI_ABS",
         # Si: (is_in("CRIT_COMP", ('EQ','NE','GT','LT','GE','LE')))
             ◆ / VALE = float,
               / VALE_I = int,
               / VALE_K = text,
               / VALE_C = complex,
         ◇ CRITERE = / "RELATIF" (par défaut),
                     / "ABSOLU",
         ◇ PRECISION = float (défaut: 0.001),
      ),
    ◆ NOM_PARA = text,
    ◇ INFO = / 1 (par défaut),
             / 2,
    # Si: True
        ◆ / VALE_CALC_I = int,
          / VALE_CALC = float,
          / VALE_CALC_C = complex,
          / VALE_CALC_K = text,
        ◇ VALE_ABS = / "OUI",
                     / "NON" (par défaut),
        ◇ TYPE_TEST = / "SOMM_ABS",
                      / "SOMM",
                      / "MAX",
                      / "MIN",
        ◇ TOLE_MACHINE = float (défaut: 1e-06),
        ◇ CRITERE = / "RELATIF" (par défaut),
                    / "ABSOLU",
        # Si: exists("REFERENCE")
            ◆ / VALE_REFE_I = int,
              / VALE_REFE = float,
              / VALE_REFE_C = complex,
              / VALE_REFE_K = text,
            ◇ PRECISION = float (défaut: 0.001),
        ◇ REFERENCE = / "ANALYTIQUE",
                      / "SOURCE_EXTERNE",
                      / "AUTRE_ASTER",
                      / "NON_DEFINI",
        # Si: exists("VALE_CALC") and abs(VALE_CALC if type(VALE_CALC) not in (list, tuple) else VALE_CALC[0]) < 1.e-16
            ◇ ORDRE_GRANDEUR = float,
        ◇ LEGENDE = text,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand TABLE

One gives the name of the table that one wants to test.

### 3.2 Operand NOM_PARA

One gives the name of the parameter identifying the column to be tested.

### 3.3 Testing a cell; keyword FILTRE

This factor keyword (repeatable at will) is used to select the line containing the cell to be tested. The use of this keyword is described in the command IMPR_TABLE [U4.91.03](doc:u4.91.03). The only difference with respect to IMPR_TABLE is that the inequality comparison criteria (CRIT_COMP) are not available.

**Note:**

*It is often necessary to repeat this keyword in order to select a single line, which is why the command* *TEST_TABLE makes it possible to test only one value at a time. If one wants to test 3 values in a table, one must call the command 3 times.*

### 3.4 Testing a whole column

```text
/    TYPE_TEST= ‘SOMM_ABS’
```

The sum of the absolute values of the whole column of the table.

```text
/    TYPE_TEST= ‘SOMM’
```

The sum of the values of the whole column of the table.

```text
/    TYPE_TEST= ‘MAX’
```

The maximum of the values of the whole column of the table.

```text
/    TYPE_TEST= ‘MIN’
```

The minimum of the values of the whole column of the table.

### 3.5 Keywords common to the commands TEST_XXX

The definition of the non-regression and reference values, as well as of the allowable tolerances and of the comparison criteria, is detailed in the documentation [u4.92.01](doc:u4.92.01) of the command TEST_RESU.

### 3.6 Operand INFO

◊    INFO = inf

Prints additional information in the "message" file if inf=2. Prints nothing if inf=1.

## 4 Example

To test the table maxFchoc:

```text
TEST_TABLE    (    TABLE=    maxFchoc        ,    NOM_PARA= 'MAXI',
FILTRE    = (    _F(NOM_PARA= 'FONCTION',    VALE_K= 'effochoc'),
_F(NOM_PARA= 'INST'    ,    VALE= 3.76E-1),)
REFERENCE= 'ANALYTIQUE',
VALE_CALC= –6,298299978E2
VALE_REFE = -6.2983E2,)
```
