# u4.63.01 Operator CALC_CHAR_SEISME

## 1 Purpose

Establish the seismic loading (unit entrainment inertia forces) for a response analysis in relative motion with respect to the motions of the supports. For a better theoretical understanding of this loading, one should refer to the document [R4.05.01](doc:r4.05.01).

The concept produced can be used directly during a direct transient analysis or a modal-synthesis analysis with DYNA_VIBRA[U4.53.03]. On the other hand, for a non-linear direct transient analysis with DYNA_NON_LINE[U4.53.01], this concept must be transformed into a load by means of the operator AFFE_CHAR_MECA[U4.44.01].

Produces a field at the nodes of quantity DEPL_R.

## 2 Syntax

```text
cham_no = CALC_CHAR_SEISME(
    ◆ MATR_MASS = matr_asse_depl_r,
    ◆ DIRECTION = float,
    ◆ / MONO_APPUI = "OUI" (ou non renseigné),
      / MODE_STAT = mode_meca,
    # Si: exists("MODE_STAT")
        ◆ GROUP_NO = grno,
    ◇ TITRE = text,
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Operand MATR_MASS

```text
♦    MATR_MASS = m
```

Mass matrix $M$ of the system, built with the boundary conditions of blocking of the supports.

### 3.2 Operand DIRECTION

```text
♦    DIRECTION =    (d1,d2,d3,r1,r2,r3)
```

Components of the vector giving the direction of the entrainment motion of the earthquake in the global frame. It is a list of three reals if the imposed accelerograms are translations only. If infinitesimal rotational accelerations are also imposed, a list of six reals is expected (valid for modellings with discrete elements or structural finite elements having rotational degrees of freedom). This vector $\Delta$ will be normalised automatically by the operator. For example, if one supplies: DIRECTION =    (1., 2., 2.,), the result will be the same as for: DIRECTION =    (0.333, 0.666, 0.666,).

### 3.3 Description of the entrainment motion

#### 3.3.1 Operand MONO_APPUI

```text
♦    /    MONO_APPUI =    'OUI'
```

```text
La structure est excitée uniformément sur tous ses appuis: le mouvement d'entraînement est de corps rigide, dans la direction donnée par le mot-cléDIRECTION(en général de translation, mais on peut aussi considérer une rotation infinitésimale).
```

In accordance with what is explained in the reference document [R4.05.01](doc:r4.05.01) the operator CALC_CHAR_SEISME computes the following expression:

$-M.\Delta$

with $\Delta$ the direction of the earthquake specified by the operand DIRECTION.

#### 3.3.2 Multi-support excitation

In this case, the accelerations undergone by all the support points of the structure under study are not necessarily identical or in phase. The entrainment motions are not rigid-body motions, but are described by linear elastic static modes.

##### 3.3.2.1 Operand MODE_STAT

```text
/    MODE_STAT =    mode
```

Static modes of the structure: concept of type mode_meca produced by the operator MODE_STATIQUE[U4.52.14] with the option MODE_STAT. They correspond to the $6\times {\mathrm{nb}}_{\mathrm{appuis}}$ linear elastic static modes with a unit degree of freedom imposed at the supports, where ${\mathrm{nb}}_{\mathrm{appuis}}$ is the number of different accelerograms (translations, rotations) undergone by the structure and defined on each unit degree of freedom imposed on each support considered.

**Note:**

*If the structure is loaded only by translational degrees of freedom, there are then* $3{\mathrm{nb}}_{\mathrm{appuis}}$ *static modes.*

##### 3.3.2.2 Operand GROUP_NO

```text
♦    GROUP_NO =    g_noeu
```

List of node groups (g_noeu) of the structure subjected to the seismic excitation: these nodes support the support degrees of freedom of the structure to which the imposed motions are applied.

In accordance with what is explained in the reference document [R4.05.01](doc:r4.05.01) the operator CALC_CHAR_SEISME computes the following expression:

$-M.{\Psi}_{Pj}.s$

with $s$ the direction of the earthquake, specified by the operand DIRECTION, and ${\Psi}_{Pj}$ the unit linear static modes, specified by the operand MODE_STAT, computed for each degree of freedom of the blocked supports listed in the node groups (g_noeu).

### 3.4 Operand TITRE

```text
◊    TITRE =    titre
```

Title attached to the concept produced by this operator [U4.63.01](doc:u4.63.01).

## 4 Examples

The two examples which follow illustrate the use of the operator CALC_CHAR_SEISME in the cases of a single-support seismic excitation and in the multi-support case (identical acceleration, then a different acceleration, on each support).

### 4.1 Computation of a right-hand side in the single-support case

One considers the beam seismic modelling of the building represented in the test SDLL109B, as presented in the documentation of the operator POST_ELEM[U4.81.22].

One wishes to determine the forces during the transient dynamic response of the structure to an earthquake in the direction $X$ . The transient response analysis is carried out here by modal recombination by DYNA_VIBRA[U4.53.03].

One computes the vibration modes of the structure of the model resting on a single elastic support (soil spring):

```text
# --- recherche des modes propres de vibration -------------------------

MODES = CALC_MODES( MATR_RIGI = RIGIDITE,

MATR_MASS = MASSE,

OPTION = 'PLUS_PETITE',

CALC_FREQ =_F( NMAX_FREQ = 33 ),

)
```

One defines the accelerogram of the earthquake:

```text
# --- excitation -------------------------------------------------------

LBNSNL1 = DEFI_FONCTION( NOM_RESU = 'ACCE', NOM_PARA = 'INST',

PROL_GAUCHE = 'EXCLU', PROL_DROIT = 'EXCLU',

VALE =(

0.00000E+00 9.98700E-02 1.00000E-02 6.60700E-02

2.00000E-02 -5.65000E-03 3.00000E-02 -9.46800E-02

-----------------------------------------------------

1.19800E+01 1.68110E-01 1.19900E+01 8.80300E-02

1.20000E+01 0.00000E+00 9.98700E-02 0.00000E+00 )

) ;

ACCELERO = CALC_FONCTION( COMB =_F(FONCTION= LBNSNL1, COEF= 1.47 ) ) ;
```

One computes the right-hand side (field at the nodes of the entrainment inertia forces) and one defines the direction of the earthquake:

```text
DIRSEISM = CALC_CHAR_SEISME ( MATR_MASS = MASSE,

MONO_APPUI = 'OUI',

DIRECTION = ( -1., 0., 0. ) ) ;
```

One proceeds to the computation of the transient response in the modal space

```text
# --- projection des matrices et vecteur assemblés sur les modes

PROJ_BASE( BASE=MODE,

NB_VECT=33,MATR_ASSE_GENE=(

_F(

MATRICE = CO("MASSGENE"),

MATR_ASSE = MASSE),

_F(

MATRICE = CO("RIGIGENE"),

MATR_ASSE = RIGIDITE)),

VECT_ASSE_GENE=_F(

VECTEUR = CO("VECTGENE"),

VECT_ASSE = SEISME)

);

# --- calcul par combinaison modale ------------------------------------

LISTAMOR=( 0.055, 0.055, 0.070, 0.070, 0.071, 0.072, 0.157, 0.085, 0.086,

0.070, 0.076, 0.074, 0.071, 0.072, 0.115, 0.073, 0.076, 0.086,

0.081, 0.070, 0.072, 0.075, 0.074, 0.070, 0.152, 0.148, 0.074,

0.297, 0.074, 0.075, 0.089, 0.138, 0.118, )

TRANGENE=DYNA_VIBRA(TYPE_CALCUL='TRAN',BASE_CALCUL='GENE',

MATR_MASS=MASSGENE, MATR_RIGI=RIGIGENE,

AMOR_MODAL=_F(AMOR_REDUIT=LISTAMOR,),

SCHEMA_TEMPS=_F(SCHEMA=METHODE,),

INCREMENT=_F(INST_INIT = 0., INST_FIN = 4.,

PAS = 0.002, VERI_PAS = 'NON'),

EXCIT=_F(VECT_ASSE_GENE = VECTGENE,

FONC_MULT = ACCELERO),)
```

One has used here the accelerogram of the imposed motion.

One returns to the physical space:

```text
# --- restitution en base physique -------------------------------------
```

```text
LISTINST=DEFI_LIST_REEL( DEBUT=1.334,

INTERVALLE=_F( JUSQU_A = 3.154, NOMBRE = 1) )

TRANPHYS=REST_GENE_PHYS( RESU_GENE=TRANGENE,

CRITERE='RELATIF', PRECISION=1.E-06,

LIST_INST=LISTINST, TOUT_CHAM='OUI' )
```

### 4.2 Computation of a right-hand side in the multi-support case

The example which follows shows the computation of the right-hand sides of entrainment inertia forces when the seismic signals are different on the supports.

One considers the beam-element modelling of the following piping line on which an earthquake is applied in the direction $X$ :

![Figure](/figures/u4.63.01/10000B280000251B00000AA5A1535B4DA884E027.svg)

One computes the unit linear static modes for each degree of freedom of the supports blocked in the direction $X$ , in order then to express the vector of the entrainment inertia forces as a linear combination of these:

```text
MODST = MODE_STATIQUE ( MATR_RIGI = RG,

MATR_MASS = MS,

MODE_STAT =_F( GROUP_NO =

('GP1','GP2','GP3'), )

( AVEC_CMP = 'DX'),) ) ;
```

One must compute three different right-hand sides (field at the nodes of the entrainment inertia forces) for each node group subjected to the same seismic signal:

```text
SMP1 = CALC_CHAR_SEISME ( MATR_MASS = MS,

DIRECTION =( 1., 0., 0.),

MODE_STAT = MODST,

GROUP_NO = 'GP1' ) ;

SMP2 = CALC_CHAR_SEISME ( MATR_MASS = MS,

DIRECTION =( 1., 0., 0.),

MODE_STAT = MODST,

GROUP_NO = 'GP2' ) ;

SMP3 = CALC_CHAR_SEISME ( MATR_MASS = MS,

DIRECTION =( 1., 0., 0.),

MODE_STAT = MODST,

GROUP_NO = 'GP3' ) ;
```

In accordance with what is explained in the reference document [R4.05.01](doc:r4.05.01) the operator CALC_CHAR_SEISME computes the following expression:

$-M.{\Psi}_{Pj,X}.s$

with $s=(1,0,0)$ , the direction of the earthquake, specified by the operand DIRECTION, and ${\Psi}_{Pj,X}$ the unit linear static modes, specified by the operand MODE_STAT, computed for each degree of freedom of the supports blocked in the direction $X$ .

Computation of the transient response (here without damping) with the accumulation of the contribution of the three different seismic signals ACCELP1, ACCELP2 and ACCELP3:

```text
TRANGENE = DYNA_VIBRA ( TYPE_CALCUL='TRAN', BASE_CALCUL='PHYS',

MATR_MASS = MS, MATR_RIGI = RG,

SCHEMA_TEMPS=_F(SCHEMA='NEWMARK',),

INCREMENT=_F(LIST_INST=LI),

EXCIT =(

_F(VECT_ASSE = SMP1, FONC_MULT = ACCELP1),

_F(VECT_ASSE = SMP2, FONC_MULT = ACCELP2),

_F(VECT_ASSE = SMP3, FONC_MULT = ACCELP3),

)

) ;
```

Other examples of multi-supported structures subjected to seismic loadings can be found by consulting the tests SDLD103 and SDND102.
