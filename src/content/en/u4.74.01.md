# u4.74.01 Operator MODI_REPERE

This operator makes it possible to modify the reference frame in which fields carried by continuum elements and by structural elements (shells, plates, beams, ...) are expressed.

The call to MODI_REPERE generally produces a new result concept:

RESUOUT = MODI_REPERE(RESULTAT= RESUIN … )

The result concept in output is of the same type as the concept in input. For the changes of reference frame COQUE_INTR_UTIL, COQUE_UTIL_INTR and UTILISATEUR for the beams, it is possible (although not recommended) to use the same result concept in input and in output. In all the other cases, this mode of operation is forbidden.

It is strongly recommended not to use the concept produced by MODI_REPERE as input to another analysis command.

It is moreover necessary to take care to comply properly with the rules of paragraph §3.
