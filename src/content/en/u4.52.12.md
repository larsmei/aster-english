# u4.52.12 Operator EXTR_MODE

## 1 Purpose

Selectively extract modes from modal data structures. The modes are selected according to a criterion of a modal-parameter value greater than a certain threshold, then concatenated into a single final data structure.

One can also print in the MESSAGE file a summary table of the cumulative sums of the unit effective modal masses or of the generalised masses of the modes retained.

Produces a data structure of type mode_meca or mode_gene according to the type of the modes on input.

## 2 Syntax

```text
/ mode_gene
/ mode_meca
/ mode_meca_c = EXTR_MODE(
    ◆ FILTRE_MODE = _F(
         ◆ MODE = mode_gene / mode_meca / mode_meca_c,
         ◆ / TOUT_ORDRE = / "NON",
                          / "OUI",
           / NUME_ORDRE = int,
           / NUME_MODE = int,
           / NUME_MODE_EXCLU = int,
           / FREQ_MIN = float,
           / CRIT_EXTR = / "INER_EFFE",
                         / "INER_EFFE_UN",
                         / "MASS_EFFE",
                         / "MASS_EFFE_UN",
                         / "MASS_GENE",
         # Si: exists("FREQ_MIN")
             ◆ FREQ_MAX = float,
             ◇ PRECISION = float (défaut: 0.001),
         # Si: exists("CRIT_EXTR")
             ◆ | SEUIL = float,
               | SEUIL_X = float,
               | SEUIL_Y = float,
               | SEUIL_Z = float,
      ),
    ◇ TITRE = text,
    ◇ IMPRESSION = _F(
         ◇ CUMUL = / "NON" (par défaut),
                   / "OUI",
         ◇ CRIT_EXTR = / "INER_EFFE",
                       / "INER_EFFE_UN",
                       / "MASS_EFFE",
                       / "MASS_EFFE_UN" (par défaut),
                       / "MASS_GENE",
      ),
)

◆ : obligatoire
◇ : optionnel
⟐ : présent par défaut
& : ensemble
/ : un seul parmi
| : plusieurs choix possibles
```

## 3 Operands

### 3.1 Keyword FILTRE_MODE

One repeats this keyword as many times as there are data structures of type mode_meca_* or mode_gene to filter and to concatenate.

### 3.2 Operand MODE

Name of the mode_meca_* or mode_gene data structure to be sorted and concatenated with the others.

### 3.3 Filtering of the modes

To filter the modes, three possibilities are offered to the user.

#### 3.3.1 Operands NUME_MODE / NUME_ORDRE / TOUT_ORDRE

List of the order numbers or of the modal positions of the modes that one wishes to keep.

#### 3.3.2 Operand NUME_MODE_EXCLU

List of the modal positions of the modes that one wishes to delete.

#### 3.3.3 Operands FREQ_MIN / FREQ_MAX / PRECISION

One keeps all the modes that correspond to frequencies lying between f_min and f_max to the relative precision prec. One must have f_min less than f_max.

#### 3.3.4 Operand CRIT_EXTR

Choice of the parameter that serves as the criterion for filtering the modes. The parameters are defined in the reference documentation [R5.01.03](doc:r5.01.03).

If the criterion is 'MASS_EFFE_UN' or 'MASS_EFFE' a mode will be retained as soon as one of its unit, or non-unit, directional effective modal masses is greater than a threshold set by the user.

If the criterion is 'INER_EFFE_UN' or 'INER_EFFE' a mode will be retained as soon as one of its unit, or non-unit, directional effective modal inertias is greater than a threshold set by the user.

If the criterion is 'MASS_GENE' a mode will be retained as soon as the ratio of the generalised mass to the sum of the generalised masses of the modes of the filtered structure is greater than a threshold set by the user.

These criteria are meaningful only for data structures of type mode_meca_*.

#### 3.3.5 Operands SEUIL, SEUIL_X, SEUIL_Y, SEUIL_Z

Limit value of the criterion below which one considers that the mode can be filtered.

This value, in the case of the parameters currently taken into account, is a dimensionless relative value.

One can apply the same threshold in all directions (keyword SEUIL) or differentiate the thresholds according to the directions $X$ , $Y$ or $Z$ (SEUIL_X, SEUIL_Y, SEUIL_Z)

### 3.4 Keyword IMPRESSION

This keyword makes it possible to print a cumulative table of certain parameters. These parameters may be different from those chosen in the keywords FILTRE_MODE.

#### 3.4.1 Operand CUMUL

Printing or not printing the cumulative sums of the modal parameter retained by CRIT_EXTR for the result data structure resu_mod.

#### 3.4.2 Operand CRIT_EXTR

Choice of the print parameter for which one performs the cumulative operation. If the criterion is 'MASS_EFFE_UN' (unit effective mass), one cumulates separately the values of the parameters 'MASS_EFFE_UN_DX', 'MASS_EFFE_UN_DY', 'MASS_EFFE_UN_DZ' (unit effective modal mass in the direction D*) of the extracted modes.

If the criterion is 'MASS_GENE' one cumulates the values of the parameter MASS_GENE (generalised mass) of the extracted modes.

The parameters mentioned in this paragraph are defined more precisely in the reference documentation [R5.01.03](doc:r5.01.03).

### 3.5 Keyword TITRE

Title attached to the concept produced by this operator [U4.03.01](doc:u4.03.01).

## 4 Execution

One checks that the parameter for which one performs the filtering does indeed exist in the input data structure mod. If this parameter is not supplied, one exits in fatal error. On the other hand, for the keyword IMPRESSION, if the parameters MASS_EFFE_UN_* are not supplied, one only issues an alarm.

On output, the concept produced resu_mod must not be empty, otherwise one exits in fatal error.

One also checks that all the mode_meca_* or mode_gene concepts are of the same type and that they come from the same initial problem (same matrices).

After having filtered the modes of interest, one checks that they all have a different modal position. Otherwise, one issues an alarm message. To delete these duplicated modes, one must use the command EXTR_MODE again and activate the operand NUME_MODE_EXCLU.

To date, one does not check that the data structures of type mode_meca_* correspond to one and the same norm.

## 5 Printout examples

If the factor keyword IMPRESSION is present, the operator EXTR_MODE writes in the MESSAGE file a certain number of parameters on the extracted modes.

Example of a printout, with the keywords CRIT_EXTR='MASS_EFFE_UN' and CUMUL='OUI':

```text
--------------------------------------------------------------------

CONCEPT MODESX DE TYPE MODE_MECA ISSU DE L OPERATEUR EXTR_MODE

M A S S E E F

NUME_ORDRE NUME_MODE FREQUENCE MASS_EFFE_UN_DX CUMUL_DX

1 1 2.66902D-01 4.12685D-02 4.12685D-02

2 11 6.49621D+01 1.18667D-01 1.59935D-01

3 19 2.56692D+02 1.02927D-02 1.70228D-01

--------------------------------------------------------------------

----------------------------------------------------------

F E C T I V E U N I T A I R E

MASS_EFFE_UN_DY CUMUL_DY MASS_EFFE_UN_DZ CUMUL_DZ

2.22156D-25 2.22156D-25 3.80903D-01 3.80903D-01

4.69363D-25 6.91519D-25 3.11195D-03 3.84015D-01

4.22168D-27 6.95741D-25 7.06977D-03 3.91085D-01

----------------------------------------------------------

Le NUME_ORDRE est la position du mode dans la structure de donnée, le NUME_MODE est la position modale dans le spectre (cf. opérateur CALC_MODES [:external:ref:`U4.52.02 <U4.52.02>`]).

FREQUENCE est la fréquence propre du mode.

MASS_EFFE_UN_D* est la masse modale effective unitaire dans la direction * (* = Xou You Z).

Ces grandeurs sont définies dans la documentation de référence [:ref:`R5.01.03 <R5.01.03>`].

CUMUL_* sont les sommes cumulées des masses effectives unitaires par direction.

Exemple d'impression, avec les mot-clés CRIT_EXTR='MASS_GENE' et CUMUL='OUI':

-------------------------------------------------------------------

CONCEPT MODESX DE TYPE MODE_MECA ISSU DE L OPERATEUR EXTR_MODE

MASSE GENERALISEE

NUME_ORDRE NUME_MODE FREQUENCE MASS_GENE CUMUL_MASS_GENE

1 1 2.66902D-01 1.00000D+00 1.00000D+00

2 11 6.49621D+01 1.00000D+00 2.00000D+00

3 19 2.56692D+02 1.00000D+00 3.00000D+00

-------------------------------------------------------------------

MASS_GENE est la masse généralisée du mode, définie dans la documentation de référence [:ref:`R5.01.03 <R5.01.03>`].

CUMUL_MASS_GENE est la somme cumulée des masses généralisées.
```

## 6 Example of use

Here is an example presenting the various possibilities of the command EXTR_MODE for a modal analysis carried out by 5 successive mode searches:

# Computation of the total mass of the structure (for checking)

```text
massestr    =    POST_ELEM    (... MASS_INER = (...));
```

# Computation of the first 17 frequencies (NUME_ORDRE from 1 to 17; NUME_MODE from 1 to 17)

```text
mode1    =    CALC_MODES(MATR_RIGI = rigidité,
                         MATR_MASS = masse,
                         OPTION = 'PLUS_PETITE',
                         CALC_FREQ    = _F( NMAX_FREQ = 17 ))
```

```text
mode1    =    NORM_MODE(MODE = mode1, reuse = mode1,
                        NORME = 'TRAN_ROTA')
```

# Computation of other frequencies (NUME_ORDRE from 1 to 5; NUME_MODE from 18 to 22)

```text
mode2    =    CALC_MODES(MATR_RIGI = rigidité,
                         MATR_MASS = masse,
                         OPTION = 'BANDE',
                         CALC_FREQ    =_F    ( FREQ = (20. , 25.) ),)
```

```text
mode2    =    NORM_MODE(MODE = mode2, reuse = mode2,
                        NORME = 'TRAN_ROTA')
```

# Computation of other frequencies (NUME_ORDRE from 1 to 6; NUME_MODE from 23 to 28)

```text
mode3    =    CALC_MODES (MATR_RIGI = rigidité,
                          MATR_MASS = masse,
                          OPTION = 'BANDE',
                          CALC_FREQ    =_F    ( FREQ = (25. , 30.) ),)
```

```text
mode3    =    NORM_MODE(MODE = mode3,
                        reuse = mode3,
                        NORME ='TRAN_ROTA',)
```

# Computation of other frequencies (NUME_ORDRE from 1 to 3; NUME_MODE from 28 to 30)

```text
mode4    =    CALC_MODES(MATR_RIGI = rigidité,
                         MATR_MASS = masse,
                         OPTION = 'BANDE',
                         CALC_FREQ    =_F( FREQ = (29. , 32.) ),)
```

```text
mode4    =    NORM_MODE(MODE = mode4,
                        reuse = mode4,
                        NORME ='TRAN_ROTA',)
```

# Computation of other frequencies (NUME_ORDRE from 1 to 6; NUME_MODE from 31 to 34)

```text
mode5    =    CALC_MODES(MATR_RIGI = rigidité,
                          MATR_MASS = masse,
                          OPTION = 'BANDE',
                          CALC_FREQ    =_F    ( FREQ = (32. , 35.) ),)
```

```text
mode5    =    NORM_MODE(MODE = mode5,
                        reuse = mode5,
                        NORME = 'TRAN_ROTA')
```

# Extraction of the modes

```text
mode    =    EXTR_MODE(FILTRE_MODE =(_F(MODE    =    mode1,
                                        TOUT_ORDRE    =    'OUI'    ),
                                     _F(MODE    =    mode2,
                                        NUME_MODE    = (18,19,20,21,22)),
                                     _F(MODE    =    mode3,
                                        FREQ_MIN    =    25.,
                                        FREQ_MAX    =    30.    ),
                                     _F(MODE    =    mode4,
                                        NUME_MODE_EXCLU    =    28    ),
                                     _F(MODE    =    mode5,
                                        CRITERE    =    'MASS_EFFE_UN',
                                        SEUIL    =    0.005    ),
                                    ),
                       IMPRESSION    =_F    (    CUMUL    =    'OUI'    ))
```
